식별자 어휘 번역은 gettext 카탈로그와 검토한 운영체제 핵심 용어를 우선 사용합니다. 대응 고유어가 없으면 통용성이 확인된 차용어만 사용하고, 영어 알파벳 이름을 이어 붙인 합성 독음은 만들지 않습니다. 희소 언어의 핵심 동사는 검토 전사 `curated-seed`를 사용합니다. 원사전 fallback을 숨기지 않고 `용어근거.tsv`에 기록합니다.

대표 확인 예시는 `ResolveCopyOnWriteFault`의 한국어 `R해결복사때쓰기결함`, 일본어 `R解決複製時書込み障害`, 중국어 `R解决复制时写入故障`, 아랍어 `Rحلنسخعندكتابةخلل`입니다. `ProcessPendingKeyboardEvents`도 각각 사건·事象·事件·أحداث 의미의 이름으로 생성됩니다.

`main.go` 파일은 함수 `main`의 Go ABI 이름과 분리해 한국어 `주요.go`, 일본어·중국어 `主要.go`, 아랍어 `رئيسي.go`, 러시아어 `главный.go`, 독일어 `haupt.go`, 프랑스어·스페인어·포르투갈어 `principal.go`로 생성됩니다. 함수와 패키지의 `main` 자체만 Go 진입 규약 때문에 유지합니다.

국가별 소스의 대표 언어는 CLDR 공용어 중 인구 비율 최댓값 기준입니다. 프로젝트 식별자와 파일은 원래 이름을 기능 단어로 분해해 번역합니다. `main`, `init`, Go 런타임 이름, POSIX 공개 함수명과 CPU/프로토콜 표준 약어는 ABI 호환을 위해 유지하며 커널 진입 심볼은 모든 독립 트리에서 NASM 호환 ASCII 이름 `KKernelEntry`를 사용합니다.

전체 빌드 결과는 `build-verification/status.tsv`, 국가별 출력은 `build-verification/<ALPHA3>.log`에 있습니다. QEMU의 HDD 미연결 시험은 커널 진입 후 기존 디스크 없음 경로에서 정지하므로 파일시스템 실행 시험과 구분합니다.
