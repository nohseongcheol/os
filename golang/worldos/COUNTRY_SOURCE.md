# 국가별 독립 소스 생성 기준

> 아래 단어별 생성 설명은 최초 생성 단계의 이력입니다. 현재는 생성 직후
> [기능·언어별 전체 표현 정책](명명/정책.md)을 적용합니다. `go.sh`, `linker.ld`,
> `asm/`, `tools/`, `userland/` 등의 사유 경로는 번역 가능하며,
> 실제 위치는 각 국가의 `파일대응표.tsv`로 찾습니다. `Makefile`, `src`, `build`와
> 공개 ABI는 유지합니다. 86종 전체 언어의 번역 완료를 뜻하지 않습니다.

## 구조

각 ISO 3166-1 국가 폴더에는 `소스/`가 있으며 다른 국가 폴더, `공통/`, engos 및 `/home/user/test1`에 의존하지 않고 컴파일됩니다. 국가 폴더의 Makefile도 공용 Makefile을 include하지 않습니다.

- Go 소스: 43개
- Go 어셈블리 소스: 14개
- `이름대응표.tsv`: 원래 식별자와 국가 언어 식별자
- `파일대응표.tsv`: 원래 파일·패키지 경로와 국가 언어 경로
- `나라언어.md`: 선택한 언어, 원어 이름, 인구 비율 및 전사 방식
- `용어사전.tsv`: 생성에 실제 사용한 영어 구성 단어와 현지어 의미
- `용어근거.tsv`: 설치된 gettext 번역, 검토 용어 및 원사전 fallback 여부
- 원래 `tools/`에 대응하는 현지어 경로: 직렬 로그 진단 도구
- 원래 `userland/posix/`에 대응하는 현지어 경로: C 헤더, libc 래퍼 및 POSIX 실행 테스트 소스

`Makefile`, GOPATH의 `src`, 산출물 `build`는 호환 이름을 유지합니다. `go.sh`, `linker.ld`는 사유 파일이므로 빌드 참조와 함께 이름을 바꿉니다. 커널 ABI 진입점 `main`, `init`, `KKernelEntry`와 Go 표준 묶음 API는 유지합니다.

## 언어 선택

`supplementalData.xml`의 CLDR territory 정보를 사용합니다.

1. `official` 및 `de_facto_official` 중 인구 비율이 가장 높은 언어
2. 해당 표시가 없으면 인구 비율이 가장 높은 언어
3. 언어 자료가 없는 무인 지역 등은 영어 fallback

## 의미 기반 명명

최초 생성은 원래 이름을 기능 단어로 분해하여 번역합니다. 그 뒤 명명 개정 단계에서 전체 기능을 다시 표현합니다. 예를 들어 한국어판의 `Read`, `Write`, `ReadFile`은 각각 `M읽기`, `M쓰기`, `M파일읽기`입니다. 앞의 라틴 대문자는 대소문자가 없는 문자 체계에서 Go 공개 심볼과 역할을 유지하기 위한 최소 호환 표지입니다.

복합 식별자는 단어별 번역 전에 문맥을 포함한 개념열로 정규화합니다. 예를 들어 `PICMasterCommandPort`는 `primary + PIC + command + I/O + port`, `srcPort`는 `source + port + number`, `ip_be`는 `IP + network + byte + order`로 해석합니다. 이 단계에서 장치 I/O 포트와 전송 계층 포트 번호처럼 철자는 같지만 뜻이 다른 말을 구분합니다. 상세 기준은 `용어-의미-검토.md`에 있습니다.

언어명 접두사와 이름 해시는 사용하지 않습니다. POSIX 공개 함수명, Go 키워드·내장 함수, CPU 레지스터와 ELF·PCI·UDP 같은 국제 표준 약어는 ABI 및 기술 호환을 위해 유지합니다. 설치된 gettext 카탈로그와 검토한 운영체제 핵심 용어를 우선 사용하며, 대응 고유어가 없을 때는 통용성이 확인된 기술 차용어만 사용합니다. 영어 알파벳 이름을 이어 붙인 새 독음은 금지합니다. 검토된 번역이 없는 항목은 원문과 `fallback-English` 근거를 그대로 남겨 잘못된 번역으로 위장하지 않습니다.

## 재생성과 검증

```sh
cd /home/user/worldos
make country-sources
make verify-country-sources
make verify-country-builds
```

검증기는 심볼릭 링크, 공용 프로젝트 절대경로, `../../공통` include 및 과거 언어명+8자리 해시 패턴을 거부합니다. 비라틴 문자 언어의 `src/` 경로에 영문이 있으면 국제 표준 약어 또는 `용어근거.tsv`에 공개된 미해결 원문이어야 합니다. 근거 없이 현지 문자로 변형한 합성 독음은 생성하지 않습니다. 생성기는 `이름대응표.tsv`가 없는 기존 `소스/`를 삭제하지 않습니다. 전체 빌드는 4개 작업자로 병렬 수행되고 모든 국가 로그와 `status.tsv`를 남깁니다.
