# WorldOS 기능·어원 중심 명명 개정 결과

검증일: 2026-09-09. 이 문서는 이번 변경 결과이며 최초 생성 당시의 `VERIFICATION.md`와 구별한다.

## 적용 결과

- 기존 독립 소스 249개 국가판에 적용했다. engos나 koros4의 실행 코드를 덮어쓰지 않았다.
- 국가별 합계로 식별자 대응 8,636건, Go 식별자 토큰 76,187곳, 파일 경로 11,783건을 변경했다. 같은 언어를 사용하는 여러 국가의 중복분을 포함한다.
- Go 파일 10,707개(국가당 43개)를 구문 분석하고 식별자·가져오기 경로만 변경했다.
- 각 국가의 C·C 헤더·C 어셈블리는 경로만 바꾸고 원래 바이트를 보존했다.
- 이름 충돌은 서로 다른 심볼을 합치지 않도록 구분했다. 어셈블리 심볼과 빌드 참조도 함께 변경했다.
- 원래 `이름대응표.tsv`, `파일대응표.tsv`는 현재 이름으로 갱신했고 별도로 변경 전후 기록을 남겼다.

## 번역 완료와 적용 완료의 구분

**전체 언어·전체 식별자의 번역 완료가 아니다.** 대표 언어·문자 코드 86종 중 새 전체 표현
50개를 마련한 대상은 22종이다. 해당 표현들은 프로젝트 제안이며 원어민 감수 완료가 아니다.

- 새 표현이 있는 국가판: 175개. 이 국가판들에도 미검토 복합어·함수·변수가 남아 있다.
- 새 표현이 없는 63개 언어·문자 코드의 국가판: 70개. 기존 현지어 식별자는 보존했다.
  `PushBack`, `PushFront`, `PushAt`, `UnsetBit`, `ModelToScreen`의 확인된 의미 문제만
  기능이 명확한 영어 이름으로 교정했고, 이를 현지어 번역으로 집계하지 않았다.
- 언어 미지정 `und` 지역: 4개. 영어 대체판이며 별도 언어 번역이 아니다.
- C 내부 이름, 일부 보조 Go 도구, 지역별 표현 차이 및 미검토 이름은 추가 작업이 필요하다.

국가별 수치는 [적용 현황](../명명-적용현황.tsv), 새 표현은 [언어별 표현](언어별표현.tsv),
판단 기준은 [명명 정책](정책.md)을 참고한다. 각 소스의 `명명검토대기.tsv`가 남은 검토 목록이다.

임시 raw 복사본과 QEMU 스냅샷만 사용했다.

## 기존에 남아 있던 문제

주 커널에 연결하지 않는 `gate`, `phymem`, `text_mode` 원본 계열은 별도 컴파일에 실패한다.
이름 변경 전 미국판 소스와 변경 후 소스 모두에서 재현했다.

- gate: 아키텍처별 소스가 함께 포함되어 구조체·상수가 중복 선언된다. 기존 생성 이름에서 `_amd64` 파일 선택 접미어가 사라져 있었다.
- phymem: `FreeBlocks` 미정의.
- text_mode: `Outb` / `Inb` 미정의.

이름 개정으로 위 미구현 문제를 고쳤다고 주장하지 않으며 이번 작업에서 실행 로직은 수정하지 않았다.
해당 비교 로그는 아래 백업 디렉터리의 `preservation.log`에 있다.

## 복구 자료

변경 전 소스 보관본: `/tmp/worldos-naming.nOqnlWBs/before.tar.gz`.
중간 검증 단계도 같은 디렉터리의 `intermediate-sources/`에 보존했다.
기존 `build/` 산출물은 소스 백업 대상이 아니며 새 이름으로 다시 빌드했다.
`/tmp`는 영구 보관 장소가 아니므로 장기 보관이 필요하면 별도로 복사해야 한다.

명명 후 소스를 편집하면 기록된 해시와 달라지므로 검증 실패가 정상이다.
편집을 지우지 말고 실제 변경 내용을 검토한 뒤 명명 감사 기록을 갱신한다.
