# 현재 기능·언어별 표현에 따른 명명 정책

이 정책은 `용어-의미-검토.md`의 예전 독음 허용 예시보다 우선한다.
국가에 하나의 고정된 언어 철학이 있다고 가정하지 않는다. 현재 프로젝트가 선택한
대표 언어·문자 체계를 유지하면서, 의미·어순·명사와 동사의 역할을 구분한다.
한 국가의 모든 공용어를 구현했다는 뜻도 아니다.

## 판단 순서

1. 실제 구현의 입력·결과·자료형·단위를 확인한다.
2. 어원이 설명하는 초기 개념과 현재 기능을 구분한다.
3. 영어 단어를 순서대로 치환하지 않고 해당 언어의 전체 표현을 만든다.
4. 같은 철자라도 의미가 다른 것은 일괄 치환하지 않는다.
5. 번역 근거가 부족하면 기존 현지어를 보존하고 검토 대상을 기록한다.
6. 새 이름이 있다고 새 기능이 구현되었다고 간주하지 않는다.

## 적용 범위와 검토 수준

현재 독립 소스는 249개 국가의 대표 언어·문자 코드 86종을 사용한다. 여기에는
언어 미지정 코드 `und`도 포함되며 이 지역의 영어 대체판을 새로운 언어로 집계하지 않는다. 7,847개 언어 폴더는
카탈로그·배포 설정이며 7,847개 언어로 번역된 커널 소스가 아니다.

`tools/naming_lexicon.py`의 전체 표현 50개는 22개 언어·문자 변형에 대한 **프로젝트 제안**이다.
영어, 한국어, 일본어, 중국어 간체·번체, 독일어, 프랑스어, 스페인어, 포르투갈어,
이탈리아어, 러시아어, 우크라이나어, 아랍어, 튀르키예어, 베트남어, 인도네시아어,
말레이어 라틴 문자, 폴란드어, 네덜란드어, 스웨덴어, 핀란드어, 체코어를 포함한다.
일부 제안은 용어집에만 있으며 모든 관련 복합 이름에 적용된 것은 아니다.

이 표현들은 공인 표준 번역이나 원어민 감수 완료를 뜻하지 않는다. 22개 언어에서도
아직 전체 식별자·지역별 어휘를 다 검토한 것은 아니다. 나머지 언어에 영어 표현을
사용한 경우 이를 현지어 번역으로 집계하지 않는다. 기존 gettext 단어의 출현 횟수도
이 코드에서 그 번역이 옳다는 증거가 아니다.

| 기록 상태 | 의미 |
| --- | --- |
| `project-proposal` | 현재 기능을 기준으로 작성한 전체 표현; 언어 공동체의 추가 검토 대상 |
| `koros4-function-reviewed` | 앞선 koros4 기능 검토 결과 중 원래 이름에 단일 대응이 있는 항목 |
| `compatibility` | Go·외부 규약의 고정 이름 |
| `existing-unreviewed` | 기존 표기를 보존했으며 이번 기능·언어 검토는 미완료 |
| `pending-language-review` | 해당 언어의 새 번역 미완료; 필요한 기능 교정에는 명시적인 영어 이름 사용 |
| `undefined-language-English` | 언어 미지정 `und` 지역에 사용하는 영어 대체판; 현지어 번역 아님 |

`명명검토대기.tsv`를 비워야 할 대상으로 취급하되, 검토 없이 지우거나 영어 대체명을
번역 완료로 올리면 안 된다. 현재 모든 국가의 `linguistic_review_complete`는 `false`다.

## 어원과 현재 기능

| 개념 | 현재 코드에 대한 결정 |
| --- | --- |
| Internet | 연결된 통신망의 체계라는 뜻을 반영한다. 한국어 제안은 상호연결망이다. |
| Ethernet | 초기 공동 전송 매체 Ether의 역사에 근거한다. 한국어는 공유매체망전송틀이다. 현재 모든 Ethernet 연결이 공유 매체라는 뜻은 아니다. |
| pointer | 기억 주소를 참조하는 값이다. 일본어 제안은 番地参照이며 거주지 주소가 아니다. |
| page directory | 하위 기억쪽표를 가리키는 상위 표이지 파일목록이 아니다. |
| frame | 통신 전송틀·물리 기억쪽·예외 저장 상태를 구분한다. `frame` 전체 치환을 금지한다. |
| master boot record | 시동 코드·분할 정보를 담은 기록이지 음성 녹음이 아니다. |
| BIOS parameter block | 여기서는 FAT 파일체계의 구성 정보다. |
| ELF | 실행과 연결 두 기능을 모두 표현한다. |
| PushBack / PushFront | 연결목록의 끝/앞에 추가한다. 되돌리기/앞으로 이동이 아니다. |
| UnsetBit | 이 구현은 XOR로 사용 비트를 뒤집는다. 해제로 위장하지 않으며 XOR 자체는 변경하지 않는다. |
| ModelToScreen | 현재 구현은 지역 좌표를 저장한다. 실제 좌표 변환을 구현한 것으로 표현하지 않는다. |

개념 확인 자료: [RFC 2828](https://www.rfc-editor.org/rfc/rfc2828.html),
[RFC 768](https://www.rfc-editor.org/rfc/rfc768.html),
[Metcalfe·Boggs의 Ethernet 원논문](https://www.cl.cam.ac.uk/teaching/0708/DigiCommI/metcalfe1976ethernet.pdf).
이 자료는 기술적 개념을 뒷받침하며, 이 프로젝트가 만든 22개 언어 표현을 공인하지 않는다.

## 코드 표기와 호환 경계

현지어 구절의 어순은 그대로 두고 공백을 밑줄로 연결한다. 한글·한자 이름 등은
필요한 경우 `T`(형식), `I`(인터페이스), `M`(메서드), `V`(값) 표지를 사용한다.
이 표지는 영어 단어의 독음이 아니라 Go 공개성·구분을 위한 표기다.

[Go 식별자 규칙](https://go.dev/ref/spec#Identifiers)은 유니코드 글자와 숫자를 허용하지만
모든 결합문자를 허용하지 않는다. 결합문자를 지워 현지어를 손상시키거나 영문 철자를
임의의 독음으로 바꾸지 않는다. 필요한 경우 현지어 원문과 별도로 검토된 코드 표기가 필요하다.

현재 C·어셈블리 ABI, POSIX 공개 함수·헤더, Go 표준 API, CPU 명령·저장기 이름,
`Makefile`, GOPATH의 `src`, 산출물의 `build`, 기존 make 목표는 유지한다.
C 구현 파일은 경로만 변경하고 내용은 바이트 단위로 보존한다. 도구용 Go 소스의
내부 식별자 및 아직 미검토된 복합어도 남아 있다.

## 수정과 재생성

기존 소스는 `make refine-country-names`로 이름만 변경한다. 기본 스크립트 실행은 미리보기다.
`make country-sources`는 원본에서 다시 생성하는 별도 작업이다. 관리 경로를 현지화한
기존 판에서는 새 한국어 경로가 생기거나 편집 내용을 지우지 않도록 재생성을 거부한다.
평소에는 현재 원문을 편집하고 빌드한다. 관리 이름만 갱신하려면 `make localize-layout`을 사용한다.

국가별 `이름대응표.tsv`와 `파일대응표.tsv`가 현재 경로·이름의 기준이다.
예전 단어별 `용어사전.tsv`, `용어근거.tsv`는 최초 생성 이력이고, 이번 전체 표현은
`새명명-용어.tsv`에 따로 기록한다. 이전·현재 식별자는 `새명명-식별자.tsv`,
이동 경로는 `새명명-경로.tsv`, 내용 해시는 `명명검증.json`으로 확인한다.
위 파일명은 한국어판의 이름이다. 다른 언어판에서는 같은 역할의 현지어 파일을 사용하며
원문 폴더의 `layout.json`에 정확한 대응이 있다. [관리 경로 정책과 상태](관리경로-현지화.md)를 참고한다.

검증 후 소스를 편집하면 해시 검사 실패가 정상이다. 편집 내용을 무조건 덮어쓰지 않고
다시 기능·이름을 검토한 뒤 감사 기록을 갱신해야 한다.
