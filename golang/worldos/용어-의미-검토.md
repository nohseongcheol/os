# 운영체제 식별자 용어 의미 검토

> 이 문서는 이전 생성기의 검토 이력이다. 현재 이름은 [명명 정책](명명/정책.md)과
> 국가별 `새명명-식별자.tsv`, `새명명-용어.tsv`를 우선한다. 아래의 인터넷·이더넷
> 독음 권장, 레지스터·포인터 예시를 새 명명에 다시 적용하지 않는다.

이 문서는 국가별 소스 생성기가 번역 전에 사용하는 개념을 정리한다. 아래 한국어는
한국어판의 권장 표기이며, 다른 언어판은 같은 영어 개념을 해당 언어의 뜻말로 번역한다.
한 단어의 번역을 모든 문맥에 강제로 적용하지 않는다.

## 입출력 포트 주의사항

`I/O port는 보통 status/control/data-in/data-out 네 레지스터로 구성된다`는 문장을
일반 규칙으로 사용하면 안 된다. 그 구성은 일부 장치의 인터페이스 설명에는 맞을 수
있지만 장치마다 레지스터 수와 의미가 다르다. 예를 들어 8259 PIC는 주 제어기에
`0x20/0x21`, 보조 제어기에 `0xA0/0xA1` I/O 주소를 쓰며, 기록하는 제어어에 따라 같은
주소에서 선택되는 내부 레지스터의 의미가 달라진다. 따라서 생성기는 `port`를
무조건 `접속장치`나 네 개 레지스터의 묶음으로 해석하지 않는다.

## 생성 규칙

1. 먼저 전체 합성어를 `대상 + 세부 대상 + 역할/동작`의 개념열로 정규화한다.
2. 각 언어는 개념열의 단어를 현지 뜻말로 번역하고 그 언어의 자연스러운 어순으로 조합한다.
3. 약어, CPU 레지스터, ABI 함수명처럼 호환에 꼭 필요한 영문만 유지한다.
4. 검토되지 않은 뜻말을 만들거나 영문 철자를 글자별 독음으로 바꾸지 않는다.
5. 하나의 영어 단어가 여러 장치 문맥에서 다른 뜻이면 합성어 규칙으로 구분한다.
