# POSIX 전체 구현까지 남은 범위

요청한 “모든 POSIX 함수”는 아직 완료되지 않았다. 107개 공개 진입점과 각 판의 실제 빌드·부팅 검증은 전체 POSIX.1-2024 적합성·인증을 뜻하지 않는다. 표준은 함수 이름뿐 아니라 반환·오류·동시성·환경·셸 동작까지 규정한다. [표준의 범위](https://pubs.opengroup.org/onlinepubs/9799919799/basedefs/V1_chap01.html).

아래는 남은 **범주의 예시**이며, 표준 전체 인터페이스 목록을 수집한 완전한 누락 개수표는 아니다. 선언이나 항상 실패하는 가짜 구현을 추가해 완료 수를 늘리지 않았다.

| 범주 | 아직 없거나 제한적인 기능 | 필요한 작업 |
| --- | --- | --- |
| 표준 입출력 | `FILE`, `fopen`, `fclose`, `fread`, `fwrite`, `printf`, `scanf`, 버퍼 상태·오류 | 사용자 영역 스트림 관리와 서식 해석, 실패·부분 전송 시험 |
| 파일·목록 변경 | 일반 파일 쓰기·생성은 읽기 전용 제한, `mkdir`, `unlink`, `rename`, `opendir`, `readdir` 등 미구현 | 쓰기 가능한 파일체계와 커널 호출·권한·일관성 보장 |
| 신호·과정 제어 | `sigaction`, `kill`, 신호 가림, 파이프·세션·작업 제어 등 | 커널 전달 규약과 사용자 진입/복귀 처리 |
| 스레드·동기화 | `pthread_*`, 잠금·조건변수, 스레드별 errno | 커널 스레드 지원, TLS와 경쟁 상태 시험 |
| 시각·타이머 | `clock_gettime`, `nanosleep`, 달력·시간대 변환 등 | 커널 시계·대기와 달력 자료 |
| 기억영역 매핑 | `mmap`, `munmap`, `mprotect` 등 | 주소 공간·파일 매핑·보호 동작 |
| 다국어 실행 환경 | `setlocale`, `wchar_t` 계열, 다중바이트 변환·문화권 정렬 | 로케일 자료·유니코드 처리·상태 있는 변환 |
| 수학·숫자 변환 | 부동소수점 변환·수학 함수, 긴긴정수 변환 등 | 수치 정확도·경계·오류 규칙 |
| 통신 | 현재 게스트 내부 IPv4 UDP 한정; TCP·이름 해석·다중화 등 | 커널 망 장치·프로토콜 및 사용자 영역 해석 |
| 셸 | 현재 12개 명령 중심; POSIX 셸 전체 문법·파이프·치환·작업 제어 미완료 | 구문 분석과 과정·입출력 연결 |
| 이름 현지화 | 107개 함수 이름 전체 대응은 82개 판(영어 64개 포함), 나머지 213개 부분 번역 | 언어별 전체 구절 제안, 문자 변종 검토, 원어민 감수 |

국가 코드 폴더와 언어의 관계는 일대일이 아니다. 예를 들어 인도 각 언어·문자판의 `posix-IND`는 서로 독립된 폴더다. 영어 이름을 남긴 항목을 해당 언어 번역으로 세지 않으며, `이름대응.tsv`의 상태와 `보존식별자.tsv`를 함께 확인해야 한다.

추가한 할당기는 단일 스레드 한정이다. 표준의 오류 번호는 스레드마다 독립적으로 유지되어야 하므로 전역 `errno`를 쓰는 현재 구조는 다중 스레드 POSIX를 충족하지 않는다. [오류·스레드 관련 일반 요구](https://pubs.opengroup.org/onlinepubs/9799919799/functions/V2_chap02.html).
