# 전체 ملاتړ_ارزښت 요청의 현재 انکړ_ارزښت

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 실제 C POSIX 일부 기능, 한국어 API/سرچينه نوم, IDE دوتنه 보존, 게스트 Java دوتنه 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/ماولوله_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 실행 가능한 ټوټه | 전체 지원에 필요한 작업 |
|---|---|---|
| Java جوړول_سرچینه·실행 | 게스트 제한형 javac/JVM, ولاړ_ارزښت 단일 클래스와 일부 표준 객체 | 일반 객체·پاړکى_ارزښت نښلېدل·예외·GC·스레드, 완전한 javac와 표준 پاړکى_ارزښت کتابتون |
| دوتنه | POSIX 서술자, Java 단일 بايټ_ارزښت دوتنه بهنګ_ارزښت, 전용 رسنۍ_ارزښت 보존 | 일반 java.io/nio, 디렉터리·권한·잠금·일반 دوتنه_سېسټم·شاتاړى_ارزښت 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP کوربه 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 پېښه·ليکبڼه_ارزښت·کړکۍ چليز_غونډال_ارزښت, AWT 네이티브 연결과 Swing 실행 기반 |
| POSIX | 문서화한 دوتنه·단말·UDP 부분 | 과정·exec/fork·스레드·시그널·시간·mmap·poll·파이프 등과 적합성 검증 |
| 언어별 نوم | 한국어 46개 대응 ننوت_ارزښت, 실제 C/Java/دوتنه نوم 적용 | 대상 کمپیوټر_ژبه 확정, 언어별 용례·역사 근거와 해당 سرچينه·도구의 검증 |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 실행 환경을 추가하는 방식은 별도의 نوغی_ارزښت·루트 دوتنه_سېسټم·OpenJDK·그래픽 서버·영구 저장 구성을 가진 실행 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

실행 기반과 추가 대상 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
