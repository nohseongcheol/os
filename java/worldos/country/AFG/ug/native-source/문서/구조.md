# JAfgOS 구조

아래는 ئوبيېكت_قىممىتى 기반 관리 يادرو_قىممىتى 전체의 نىشان_ئوبيېكت 구조다. 현재 ھەقىقىي_مەلۇمات 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 مەشغۇلات_سىستېمىسى چۈشەندۈرۈش_ھۆججىتى_eb81d7d9](../os/چۈشەندۈرۈش_ھۆججىتى_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·كونتېكست_قىممىتى ئۆزگەرتمەك_ھالەت·ھۆججەت_سىستېمىسى 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 قەۋەت_قىممىتى
  ↓
Java AOT 실행기와 ئوبيېكت_قىممىتى·رەت_قىممىتى·GC 런타임
  ↓
قاتتىق_دېتال_قىممىتى 경계
  ↓
Java 관리 يادرو_قىممىتى
  ├─ 기억공간/쪽관리/COW
  ├─ جەريان_قىممىتى/배정/wait
  ├─ ھۆججەت_سىستېمىسى/ELF/POSIX
  └─ 입력/بوشلۇق_كۆچمە/تور_دۆۋە
```

OpenJDK 자체는 이미 운영체제가 제공하는 ھۆججەت, 스레드, 가상 기억공간을 전제로 한다. 따라서 يادرو_قىممىتى 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, كونتېكست_قىممىتى 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
