# Raspberry Pi 4 ίδιο Java πυρήνας_τιμή — χρήστης εκτελώ_εντολή 기반

τρέχων_στοιχείο ίδιο 코드의 COSL 상업 πάθηση, 제3자 고지 및 LGPL 재연결 자료는 [COSL 배포 αρχείο_readme_eb81d7d9](COSL배포안내.md)를 참고한다. αλλάζω_λειτουργία 전 GPL 구성의 판단은 [이전 라이선스 검토](Άδεια_Χρήσης_κριτική.md)에 기록했다.

ελληνικά 통신·εξαίρεση 사용법은 [ελληνικά Java API](한국어자바/αρχείο_readme_eb81d7d9.md), συνάρτηση_τιμή·μεταβλητή_τιμή·Αρχείο 이름의 변경과 어원 근거는 [명명 αρχείο_readme_eb81d7d9](명명/αρχείο_readme_eb81d7d9.md)를 참고한다.

Linux 없이 부팅하는 ίδιο AArch64 커널이다. Java AOT πυρήνας_τιμή 위에 **γραμμή_εντολών κέλυφος, 게스트 Java πρόγραμμα_μεταγλώττισης·JVM, MicroPython, EL0 C++ εκτελώ_εντολή, Αρχείο·UDP 루프백 시스템 호출, 여러 한글 GUI Τερματικό·vi Βοηθός_γραφής·Swing 부분집합**을 제공한다. 커널의 Αρχείο δεδομένα/정책·루프백 Μεταφορά_τιμή·κέλυφος 상태는 Java, 화면 합성·화소 αλλάζω_τιμή·δείκτης·클리핑도 Java로 구현하며, CPU/MMU/συσκευή_τιμή 경계와 Τερματικό·χαρακτήρας_τιμή 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 ίδιο 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 εκτελώ_εντολή, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 ενσύρματος_τιμή 송수신은 아직 미검증이다.** εκτελώ_εντολή·σύνδεση_e05f319b·κωδικός_πρόσβασης_τιμή 확인은 [εξωτερικός_τιμή σύνδεση_e05f319b αρχείο_readme_eb81d7d9](εξωτερικός_σύνδεση_οδηγός.md)에 정리했다.

셸은 EL1 πυρήνας_τιμή, `java` 등 χρήστης εκτελώ_εντολή 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 εκτελώ_εντολή·σύνδεση_e05f319b 방법 및 πραγματικός_δεδομένα 검증은
[εκτελώ_εντολή 계층과 εξωτερικός_τιμή 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 πραγματικός_δεδομένα εκτελώ_εντολή 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 στατικός_τιμή ELF는 `run --linux όνομα_αρχείου_μήνυμα`으로 실행한다. [ELF·Linux ABI στήριγμα_τιμή 범위와 동일 바이너리 시험](실행파일규약.md).

GUI와 네트워크는 `python3 Εργαλεία/εκτελώ_εντολή.py --desktop --network`로 함께 사용한다. Java·C·Python의 ελληνικά 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 부팅 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 수 있다. Remmina에서 **F9/Shift+Space/한·μηδέν_τελεστέος Κλειδί_τιμή**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·πραγματικός_δεδομένα TCP/UDP·Αρχείο 바이트·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java ΠαράδειγμαΠαραθύρου`로 ελληνικά Swing 예제를 실행한다. Τερματικό 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 τρέχων_στοιχείο στήλη_τιμή·σειρά_τιμή_fc48bc81 수를 보여 준다.

UART와 πραγματικός_δεδομένα 프레임버퍼의 한글 표시를 시험한다. 루프백은 동일 πυρήνας_τιμή 내부의 αυτοδύναμο_πακέτο 전달이며 IP 패킷을 Ethernet으로 내보내는 드라이버가 아니다. 바깥 IPv4는 lwIP TCP/UDP 스택으로 보조 UART SLIP 경로를 사용한다. `python3 Εργαλεία/εκτελώ_εντολή.py --network`로 QEMU NAT를 연결하고 `ftpd start`로 서비스를 시작한다.

Java의 정확한 API·문법·εκτελώ_εντολή 제한과 ελληνικά 사용법은 [ίδιο JVM과 ελληνικά βιβλιοθήκη](자바실행환경.md)에 정리했다. Τάξη_τιμή Αρχείο/JAR 배포는 [한국어자바](한국어자바) 소스에서 재현한다. 기존 Linux판 `ελληνικά.자바`와 별도인 `ελληνικά.ίδιο` 패키지다.

**vi·여러 Παράθυρο·Swing·한글 Java/Python/C/C++·posix-kor 예제는 [한글 개발 매뉴얼](개발안내.md)에 정리했다.**

GUI Τερματικό εκτελώ_εντολή·단축키·κέλυφος Εντολή·제한은 [셸과 Τερματικό 사용법](κέλυφος_λογικό_ΚΑΙ_Τερματικό.md)에 정리했다.

## τρέχων_στοιχείο 컴퓨터에서 εκτελώ_εντολή

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

Έξοδος_εφαρμογή: **Ctrl+A Επόμενο_στοιχείο X**. 게스트 C/AOT Εργαλεία 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. φιλοξενώ 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. πρόγραμμα_μεταγλώττισης 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/ΔΙΑΔΡΟΜΗ/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` στήριγμα_τιμή 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 εκτελώ_εντολή**한다. 기존 한 χαρακτήρας_τιμή 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 Παράμετροι 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

| Εντολή | Ενέργεια |
|---|---|
| `help` / `info` | Εντολή·πραγματικός_δεδομένα 구현 Κατάσταση_τιμή |
| `ls` / `cat FILE` / `rm FILE` | RAM Αρχείο καταχώρηση_Λίστα·Περιεχόμενο_τιμή·삭제 |
| `vi FILE` | χρήστης περιοχή_τιμή_0e9a97ab vi 부분집합, 한글 Τροποποίησε_τιμή·αποθηκεύω_τιμή·검색·되돌리기 |
| `edit FILE` | Αρχείο 전체를 새로 είσοδος_τιμή; 단독 `.` 줄로 αποθηκεύω_τιμή, Ctrl-C로 Άκυρο_εγχείρηση |
| `javac FILE.java` / `java CLASS [ARGS]` | ίδιο 제한형 Java δόμηση_προέλευση·εκτελώ_εντολή |
| `python FILE.py [ARGS]` / `python -c 'CODE'` | MicroPython δόμηση_προέλευση·εκτελώ_εντολή |

예를 들어 `edit 인사.java`를 입력한 Επόμενο_στοιχείο 아래 소스를 입력한다.

```java
public class 인사 { public static void main(String[] args) { int τιμή = 7; System.out.println("한글=" + τιμή); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 인사.java`, `java 인사`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. Άκυρο_εγχείρηση·잘못된 16진수·Δυνατότητα_τιμή 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, εκτελώ_εντολή 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 Εντολή 인수는 최대 32개다. προσφορά·백슬래시·κέλυφος μεταβλητή_τιμή·파이프·리다이렉션 범위는 [κέλυφος 설명](κέλυφος_λογικό_ΚΑΙ_Τερματικό.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, διεύθυνση **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode είσοδος_τιμή·명시적 επικολλώ_τιμή·εκτελώ_εντολή 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 Εργαλεία/εκτελώ_εντολή.py --desktop --network
# 다른 υλικό_θύρα: python3 Εργαλεία/εκτελώ_εντολή.py --desktop --port 5903
```

종료는 실행한 φιλοξενώ 터미널에서 Ctrl+C다. 기존 `python3 Εργαλεία/εκτελώ_εντολή.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. πραγματικός_δεδομένα Pi4 USB 입력기는 아직 없으며, VNC Σύνδεση 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 πραγματικός_δεδομένα C++/UDP ELF εκτελώ_εντολή, `Hello.java` δόμηση_προέλευση 후 JVM εκτελώ_εντολή, `hello.py` εκτελώ_εντολή, GUI Τερματικό 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 αλληλεπιδραστικός 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 Μνήμη_δεδομένα·CPU 문맥을 보관한다. κέλυφος·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

이미지는 확인된 공식 Pi 부팅 묶음에서 `start4.elf`, `fixup4.dat`, Pi4 DTB와 disable-bt overlay를 가져온다. Linux kernel/initramfs/rootfs는 넣지 않는다. 펌웨어·MicroPython·Τερματικό γραμματοσειρά_τιμή 라이선스와 γραμματοσειρά_τιμή προέλευση_τιμή 해시도 동봉한다. Αρχείο δημιουργώ 스크립트는 물리 디스크에 기록하지 않는다.

예비 microSD에 δομή_εικόνα καταγράφω_ρεκόρ 도구로 `.img`를 기록하거나 FAT32 부팅 파티션 최상위에 ZIP 내용을 푼다. δομή_εικόνα 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 προεπιλεγμένη_τιμή EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD Αρχείο 구성·πυρήνας_τιμή 체크섬 검사와 물리 Πίνακας 부팅 검증은 별개다. MMU χρήση_τιμή 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 부팅 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 ελληνικά API χρήση_τιμή

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/ΠαράδειγμαΑρχείου.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int αρχή_χρήστης_εφαρμογή(int)`이다. χρήστης C++는 FP/SIMD를 사용할 수 있다. πυρήνας_τιμή C/Java AOT는 일반 레지스터만 사용하므로 εξαίρεση διεργασία_τιμή_καταχώρηση 중 χρήστης FP 상태를 건드리지 않는다. χρήστης σημείο_εισόδου_τιμή 시 FP 상태를 초기화하고 πυρήνας_τιμή 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int αρχή_χρήστης_εφαρμογή(int) {
    int Αρχείο = ανοίγω_Αρχείο("인사.txt", 읽고쓰기 | 없으면만들기 | περικοπή_Περιεχόμενα, 0600);
    if (Αρχείο < 0) return 1;
    const char Περιεχόμενο_τιμή[] = "안녕하세요";
    int μέτρηση = εγγράφω_Αρχείο_δεδομένα(Αρχείο, Περιεχόμενο_τιμή, sizeof(Περιεχόμενο_τιμή) - 1);
    κλείνω_Αρχείο(Αρχείο);
    return μέτρηση == sizeof(Περιεχόμενο_τιμή) - 1 ? 0 : 2;
}
```

[Αρχείο 예제](χρήστης/ΠαράδειγμαΑρχείου.cpp)와 [통신 예제](χρήστης/통신예제.cpp)가 πραγματικός_δεδομένα 부팅 시험 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 Αρχείο διεργασία_τιμή_καταχώρηση 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 υποδοχή_τιμή 함수는 τρέχων_στοιχείο 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 πυρήνας_τιμή 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 Επόμενο_στοιχείο 도구를 사용하면 **새 QEMU를 부팅해 업로드한 πραγματικός_δεδομένα 바이트를 재확인한 Πίσω_τιμή 게스트에서 εκτελώ_εντολή**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 Εργαλεία/εκτελώ_Αρχείο.py build/jkoros-native-sdk/demo.elf
python3 Εργαλεία/εκτελώ_Αρχείο.py 예제/Hello.java "한글 Παράμετροι"
python3 Εργαλεία/εκτελώ_Αρχείο.py 예제/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 πυρήνας_τιμή 묶음에 포함되어 이 Αρχείο 한도를 적용받지 않는다. **C++ 컴파일러는 φιλοξενώ SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 βιβλιοθήκη, PT_TLS, PT_INTERP, PT_DYNAMIC, εκτελώ_εντολή·Εγγραφή 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 Ευρετήριο·διεύθυνση απόσπασμα·오류는 [χρήστης ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `δέσμευση_Αρχεία`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 άδεια_τιμή·dup/fcntl은 없다. 디렉터리와 ομότιμος_τιμή/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, λαμβάνω_τιμή_cef4d8ab 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. χρήστης Έξοδος_εφαρμογή 시 열린 Αρχείο 서술자와 소켓을 회수한다.

## Java와 Python의 정확한 απόσπασμα

ίδιο `javac`는 버전 49 `.class`를 생성하며 JVM은 στήριγμα_τιμή 명령으로 구성된 버전 45–52 클래스를 실행한다. στατικός_τιμή συνάρτηση_τιμή·재귀·int/boolean/char/String·πάθηση/επανάληψη_τιμή·συμβολοσειρά_τιμή 결합과 일부 Αρχείο 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/조합 자모 식별자를 처리한다. Unicode αναγνωριστικό_τιμή 전체 Αναζήτηση_πίνακας·Unicode προέλευση_δέντρο 이스케이프는 구현하지 않았다. 게스트 προέλευση_δέντρο 컴파일러는 일반 αντικείμενο_τιμή·εξαίρεση·Thread 구문을 아직 컴파일하지 못한다. φιλοξενώ `javac --release 8`로 만든 στήριγμα_τιμή 부분집합 클래스는 ίδιο JVM 0.4의 αντικείμενο_τιμή·εξαίρεση·Thread·UDP와 ελληνικά API를 사용할 수 있다. Swing은 문서화한 ίδιο API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [ίδιο JVM 설명](자바실행환경.md)이 기준이다. 상세 Γλώσσα 범위는 [공유 Java Εργαλεία 설명](../../문서/περιβάλλον_ανάπτυξης_Java.md)을 참고하되, 그 문서의 x86 κέλυφος/αποθηκεύω_τιμή/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 προέλευση_δέντρο**를 ίδιο AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 συνάρτηση_τιμή·Τάξη_τιμή·εξαίρεση·리스트/λεξικό·Unicode·GC·가변 πιστότητα_τιμή 정수를 제공한다. τρέχων_στοιχείο 구성은 ακέραιος 빌드로 `float`, `complex`, `math`가 없으며 CPython 전체 표준 βιβλιοθήκη, pip, subprocess, threading, 일반 socket과 προεπιλεγμένη_τιμή `open()` Αρχείο 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 αντικείμενο_τιμή·모듈은 Έξοδος_εφαρμογή 시 회수되고 RAM 파일만 Επόμενο_στοιχείο 실행에 남는다.

`import jkoros`로 Επόμενο_στοιχείο 시스템 연결을 쓴다. 모두 SVC를 통해 ίδιο Java 커널에 접근한다.

| συνάρτηση_τιμή | Ενέργεια |
|---|---|
| `stdin(limit)` | τρέχων_στοιχείο 표준 입력에서 최대 limit바이트(0…16384)를 bytes로 읽음; EOF는 빈 bytes, UART δεδομένα 없음은 OSError(11) |
| `read(name)` | ομότιμος_τιμή/절대 RAM 경로의 Αρχείο 전체를 bytes로 읽음 |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 αποθηκεύω_τιμή, 쓴 바이트 수 επιστρέφω_μέτρηση |
| `remove(name)` | RAM Αρχείο 삭제 |
| `rect(x, y, w, h, color)` | 선택한 πραγματικός_δεδομένα 화면 Μέγεθος 안의 ορθογώνιο σχέδιο_τιμή; 기존 보드의 RGB32 τιμή |
| `ticks_ms()` | 부팅 후 밀리초, 32비트 Κύκλος_τιμή |
| `udp_open(port)` | 127.0.0.1의 UDP υποδοχή_τιμή Άνοιγμα/συνδέω_τελικό_σημείο_bbe6b410; 0은 자동 υλικό_θύρα |
| `udp_send(fd, port, data)` | 루프백 προορισμός_τιμή 포트에 str/bytes 버퍼 Μεταφορά_τιμή |
| `udp_recv(fd)` | `(bytes, 보낸포트)` επιστρέφω_μέτρηση; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | υποδοχή_τιμή Κλείσιμο |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```

이식 κωδικός_τιμή: [python/](파이썬연결/), [χρήστης Java Σύνδεση](χρήστης/자바연결.c). 공식 [MicroPython 이식 αρχείο_readme_eb81d7d9](https://docs.micropython.org/en/latest/develop/porting.html)를 참고했다. προέλευση_δέντρο URL·κατακερματισμός_Αρχείο·라이선스는 [vendor αρχείο_readme_eb81d7d9](vendor/README.md)에 기록했다.

## ελληνικά C τύπος_δεδομένων·Python ΣΦΑΛΜΑ·πακέτο εγκαθιστώ_τιμή

C 네트워크 API는 `struct πλέγμα_υποδοχή_διεύθυνση`, enum 상수와 πραγματικός_δεδομένα ελληνικά 함수로
