# ίδιο 커널에서 vi·여러 Τερματικό·한글 프로그래밍 사용하기

ελληνικά 통신·εξαίρεση 사용법은 [ελληνικά Java API](한국어자바/αρχείο_readme_eb81d7d9.md), συνάρτηση_τιμή·μεταβλητή_τιμή·Αρχείο 이름의 변경과 어원 근거는 [명명 αρχείο_readme_eb81d7d9](명명/αρχείο_readme_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 ίδιο AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 στήριγμα_τιμή 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 εκτελώ_εντολή, εξωτερικός_τιμή TCP/UDP와 FTP는 [새 εκτελώ_εντολή 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 Τερματικό

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, διεύθυνση **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 Τερματικό 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **오른쪽 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 εκτελώ_εντολή 버튼으로 δοκιμάζω_ξανά_τιμή στήλη_τιμή 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 τρέχων_στοιχείο 디렉터리, κέλυφος μεταβλητή_τιμή, Εντολή καταγράφω_ρεκόρ, είσοδος_τιμή 중인 명령과 εφαρμογή_f5044b9b εκτελώ_εντολή 상태를 보관한다. Αρχείο 저장소는 공유한다. vi와 Swing의 이벤트 περίμενε_τιμή 중에 다른 터미널로 전환하면 χρήστης Μνήμη_δεδομένα·레지스터·Αρχείο/υποδοχή_τιμή 연결을 보존했다가 돌아올 때 재개한다. **τρέχων_στοιχείο 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 Επόμενο_στοιχείο είσοδος_τιμή περίμενε_τιμή 또는 기존 εκτελώ_εντολή 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 εκτελώ_εντολή 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 Τροποποίησε_τιμή 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. τρέχων_στοιχείο 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 Παράθυρο 판단은 게스트 커널이 처리한다. QEMU εκτελώ_εντολή 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. πραγματικός_δεδομένα Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI Εργαλεία 종료는 φιλοξενώ 터미널의 Ctrl+C다.

## ίδιο JVM의 Swing απόσπασμα

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 ίδιο Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | Ενέργεια |
|---|---|
| `JFrame` | Παράθυρο_Τίτλος, Μέγεθος·Θέση, εμφανίζω_Παράθυρο, Κλείσιμο 정책, dispose |
| `JPanel` | παιδί_τιμή 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 συμβολοσειρά_τιμή εμφανίζω_τιμή·αλλάζω_τιμή |
| `JButton` | 버튼과 ActionListener κλικ_τιμή διεργασία_τιμή_καταχώρηση |
| `JTextField` | 한 Γραμμή UTF-8 είσοδος_τιμή, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 ίδιο JVM의 단일 이벤트 εκτελώ_εντολή 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. Παράθυρο·요소는 εκτελώ_εντολή 하나당 σύνολο_τιμή 32개, στοιχείο_τιμή 글자는 최대 127 코드포인트다. προεπιλεγμένη_τιμή 서체와 색은 커널이 제공한다.

[Σουϊνγκ_δοκιμή.java](시험/자바/Σουϊνγκ_δοκιμή.java)는 Παράθυρο·한글 ετικέτα_τιμή·πεδίο_κειμένου·버튼·이벤트 처리의 εκτελώ_εντολή 가능한 예제다. [ίδιο Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

ελληνικά 라이브러리에는 다음을 추가했다. φιλοξενώ δόμηση_προέλευση 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `ελληνικά.ίδιο.Παράθυρο`: `Προσθήκη_στοιχείο`, `εμφανίζω_Παράθυρο`, `Κλείσιμο`.
- `ελληνικά.ίδιο.γραφικό_στοιχείο`: `ετικέτα_τιμή`, `κουμπί`, `πεδίο_κειμένου` δημιουργώ.
- `ελληνικά.ίδιο.연결통신`: `Σύνδεση`, `ακρόαση_τελικό_σημείο`, `λαμβάνω`.
- 기존 `Έξοδος`, `문자`, `Αρχείο`, `작업`, `καταχώρηση_Λίστα`, `λεξικό`, `통신`, `화면`, `πυρήνας_τιμή`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **πυρήνας_τιμή 내부 연결형 바이트 ροή_τιμή**을 추가했다. Αρχείο/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java

java.net.Socket Επισκέπτης_τιμή = new java.net.Socket("localhost", 9250);
java.net.Socket Σύνδεση = διακομιστής_τιμή.accept();
Επισκέπτης_τιμή.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int διάρκεια_τιμή = Σύνδεση.getInputStream().read(받은것);
Σύνδεση.close(); Επισκέπτης_τιμή.close(); διακομιστής_τιμή.close();
```

δημιουργώ·Σύνδεση·accept·양방향 바이트/πίνακας_τιμή είσοδος_έξοδος·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 Τελική_οντότητα_μόριο 16개, λαμβάνω_τιμή_cef4d8ab 버퍼당 1024바이트, περίμενε_τιμή Σύνδεση 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. προεπιλεγμένη_τιμή τιμή_ώρας 제한 0은 별도 υποδοχή_τιμή 기한을 설정하지 않지만 JVM Εντολή 수/πυρήνας_τιμή εκτελώ_εντολή 기한은 여전히 적용된다.

εξωτερικός_τιμή ψηφίο_τιμή IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. πραγματικός_δεδομένα Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP βιβλιοθήκη 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [δοκιμή_ροή.java](시험/자바/δοκιμή_ροή.java)는 πραγματικός_δεδομένα 송수신·EOF·기한·Σύνδεση 회수의 시험 예제다.

파일은 게스트 vi로 작성할 수 있다. C는 게스트 `cc` 또는 φιλοξενώ SDK, C++는 φιλοξενώ SDK의 Clang++로 컴파일한다. 아래 예제는 기존 φιλοξενώ SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

τρέχων_στοιχείο GUI VM에서 실행하려면 `python3 Εργαλεία/ανεβάζω_Αρχεία.py ΔΙΑΔΡΟΜΗ/인사-c.elf`의 출력을 게스트에 보내고 `run 인사-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex όνομα_αρχείου_μήνυμα`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 수 있다. 호스트와 게스트의 Αρχείο 시스템은 별개다.

| ελληνικά Όνομα | C σύμβολο | απόσπασμα |
|---|---|---|
| ανοίγω_Αρχείο/κλείνω_Αρχείο | pk_open/pk_close | RAM Αρχείο, ομότιμος_τιμή/절대 ΔΙΑΔΡΟΜΗ |

| αναζητώ_Αρχείο | pk_lseek | 처음기준/τρέχων_ρίζα/Τελική_οντότητα_προέλευση |
| μέγεθος_αρχείου/σύνολο_Αρχείο_διάρκεια | pk_size/pk_ftruncate | διάρκεια_τιμή ερώτημα_τιμή/αλλάζω_τιμή |
| καταργώ_Αρχείο_καταχώρηση_όνομα | pk_unlink | Αρχείο Όνομα 삭제 |
| δέσμευση_Αρχεία | pk_fsync | RAM이므로 -1, αριθμός_σφάλματος=ENOSYS |
| ανοίγω_τελικό_σημείο/συνδέω_διεύθυνση | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |

| 통신연결기다리기 | pk_listen | περίμενε_τιμή Σύνδεση 최대 4개 |

| 통신주소읽기 | pk_getsockname | 로컬 διεύθυνση/θύρα_τιμή |

`통신규약.h`의 ίδιο `pk_sockaddr_in`을 사용하며 θύρα_τιμή·주소는 `망차례짧은수`/`δίκτυο_ακέραιος`로 변환한다. C υποδοχή_τιμή 호출은 비차단이며 δεδομένα/연결이 없으면 -1과 `αριθμός_σφάλματος=11`(EAGAIN)을 반환한다. 양수 είσοδος_έξοδος 결과가 요청보다 작을 수 있으므로 επανάληψη_τιμή 처리한다. αποτυχία_τιμή 후에만 오류번호를 확인한다.

[ροή_τιμή.c](예제/한글코딩/ροή_τιμή.c)는 C에서 ελληνικά 이름으로 Σύνδεση·accept·부분 Ανάγνωση/Εγγραφή·큐 포화·EOF를 처리하는 εκτελώ_εντολή 예제다. SDK의 `examples/ροή_τιμή.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → πραγματικός_δεδομένα ελληνικά C συνάρτηση_τιμή 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·δείκτης 검사 → Java RAM Αρχείο/루프백 또는 εξωτερικός_τιμή lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 πυρήνας_τιμή 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 Σύνδεση, 표준 C printf, libstdc++/STL, εξαίρεση·RTTI는 제공하지 않으며 C++의 στατικός_τιμή 생성자·τοπικός_Πεδίο αντικείμενο_τιμή 소멸자는 지원한다. 상세 Ευρετήριο·Μνήμη_δεδομένα 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.
