## 기존 αντικείμενο_τιμή 기반 관리 πυρήνας_τιμή 전체를 부팅하기 위해 남은 Σύνδεση

Επόμενο_στοιχείο 항목은 Java 문법만으로 실행할 수 없는 CPU/συσκευή_τιμή 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot σημείο_εισόδου_τιμή, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 περιβάλλον_τιμή αποθηκεύω_τιμή
- πραγματικός_δεδομένα PIC/PIT/PS2/ATA/PCI υλικό_θύρα 및 AMD PCnet DMA βρόχος_τιμή
- Java αντικείμενο_τιμή·πίνακας_τιμή συνδέω_Διάταξη, εξαίρεση, στατικός_τιμή προετοιμάζω, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT σκηνή_τιμή
- FAT 디스크 구역을 πραγματικός_δεδομένα ATA 장치와 연결하는 είσοδος_έξοδος 접착 επίπεδο_τιμή

위 관리 계층은 engos 기능의 Java 관리 구현과 φιλοξενώ 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot σημείο_εισόδου_τιμή, στατικός_τιμή προετοιμάζω·ακέραιος πίνακας_τιμή, VGA/직렬/PS2, 명령해석기, χρήστης ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 φιλοξενώ 루프백 패킷 왕복을 검증했다. 위 표의 αντικείμενο_τιμή 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
