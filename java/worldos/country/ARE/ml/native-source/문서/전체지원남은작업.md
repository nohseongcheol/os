# 전체 പിന്തുണ_മൂല്യം 요청의 현재 അവസ്ഥ_മൂല്യം

HTTP_അപേക്ഷ 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 വാസ്തവമായ_ഡാറ്റാ C POSIX 일부 기능, 한국어 API/ഉറവിടം പേരു്, IDE ഫയല് 보존, 게스트 Java ഫയല് 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/readme_ഫയല്_eb81d7d9.md)를 기준으로 판단한다.

| HTTP_അപേക്ഷ 분야 | 현재 നടപ്പാക്കുക_കമാന്_ഡ് 가능한 ക്ലിപ്പ് | 전체 지원에 필요한 작업 |
|---|---|---|
| Java കംപൈല്_ചെയ്യുക_ഉറവിടം·നടപ്പാക്കുക_കമാന്_ഡ് | 게스트 제한형 javac/JVM, സ്ഥിരമായ_മൂല്യം 단일 클래스와 일부 표준 ഓബ്ജക്റ്റ്_മൂല്യം | 일반 ഓബ്ജക്റ്റ്_മൂല്യം·ക്ലാസ്_മൂല്യം കണക്ടു്_ചെയ്യുക·ഒഴിവാക്കൽ·GC·스레드, 완전한 javac와 표준 ക്ലാസ്_മൂല്യം లైబ్రరీ |
| ഫയല് | POSIX 서술자, Java 단일 బైట్_മൂല്യം ഫയല് സ്ട്രീം_മൂല്യം, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·അനുമതി_മൂല്യം·ലോക്ക്_മൂല്യം·일반 ഫയല്_സിസ്റ്റം·വിപുലീകരണം_മൂല്യം 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP ഹോസ്റ്റ് 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 ഇവന്റ്·ഫോണ്ട്_മൂല്യം·ജാലകം ഓപ്പറേറ്റിംഗ്_സിസ്റ്റം_മൂല്യം, AWT 네이티브 연결과 Swing നടപ്പാക്കുക_കമാന്_ഡ് 기반 |
| POSIX | 문서화한 ഫയല്·단말·UDP 부분 | പ്രോസസ്_മൂല്യം·exec/fork·스레드·시그널·സമയ_മൂല്യം·mmap·poll·파이프 등과 적합성 സാധൂകരിക്കുക |
| 언어별 പേരു് | 한국어 46개 대응 എന്_ട്രി_മൂല്യം, വാസ്തവമായ_ഡാറ്റാ C/Java/ഫയല് പേരു് 적용 | ലക്_ഷ്യം భాష 확정, 언어별 용례·역사 근거와 해당 ഉറവിടം·도구의 സാധൂകരിക്കുക |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 നടപ്പാക്കുക_കമാന്_ഡ് 환경을 추가하는 방식은 별도의 കെര്_ണല്_മൂല്യം·루트 ഫയല്_സിസ്റ്റം·OpenJDK·그래픽 സെര്_വര്_മൂല്യം·영구 സ്_റ്റോർ_മൂല്യം 구성을 가진 നടപ്പാക്കുക_കമാന്_ഡ് 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

നടപ്പാക്കുക_കമാന്_ഡ് 기반과 추가 ലക്_ഷ്യം 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
