# engos 기능 대응표

이 표는 기존 `ժառանգված_աղբյուր/`의 առարկա_արժեք 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [իրական_տվյալ 부팅 기능과 한계](../os/ԿԱՐԴԱ_ԻՆՁ_eb81d7d9.md)를 따로 기록한다.

## Java 관리 շերտ_արժեք 구현 완료

| paging, virtmem | `էջ_կառավարիչ` հասցե 공간·էջ_արժեք Միացնել·COW·개인 Գրել |

| interrupt | `խզում_կառավարիչ` գրանցվել_մուտքագրում·միացնել·տարածել_արժեք |

## 기존 առարկա_արժեք 기반 관리 միջուկ_արժեք 전체를 부팅하기 위해 남은 Միացնել

Հաջորդը_միավոր 항목은 Java 문법만으로 실행할 수 없는 CPU/սարք_արժեք 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot մուտքագրում_կետ_արժեք, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 Համատեքստ_արժեք պահեստավորել_արժեք
- իրական_տվյալ PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA օղակում_արժեք
- Java առարկա_արժեք·ԶԱՆԳՎԱԾ_արժեք կապ_Դասավորություն, 예외, հաստատուն_արժեք_f430d3f5 սկզբնավորել, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT բեմ_արժեք
- FAT 디스크 구역을 իրական_տվյալ ATA 장치와 연결하는 ներածում_արտածում 접착 շերտ_արժեք

위 관리 계층은 engos 기능의 Java 관리 구현과 հոստ 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot մուտքագրում_կետ_արժեք, հաստատուն_արժեք_f430d3f5 սկզբնավորել·ամբողջ_թիվ ԶԱՆԳՎԱԾ_արժեք, VGA/직렬/PS2, 명령해석기, օգտվող ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 հոստ 루프백 패킷 왕복을 검증했다. 위 표의 առարկա_արժեք 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
