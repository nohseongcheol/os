게스트의 пространство_пользователя TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 инструменты/실행.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 значение_по_умолчанию управление_ЗНАЧЕН/데이터 포트와 겹치면 실행 전에 거부한다.
