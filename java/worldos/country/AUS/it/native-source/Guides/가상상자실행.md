# VirtualBox Esegui_comando

```sh
cd ~/jkoros
make vbox
```

별도로 VM을 만들거나 ISO를 연결할 필요가 없다. 처음 실행하면 `os/build/kernel.iso`를 빌드하고 `jkoros operating system`이라는 전용 VM을 만들어 VirtualBox 창으로 부팅한다. `jkoros/os` 안에서도 `make vbox`를 사용할 numero 있다.

게스트의 `jkoros>` 프롬프트에서 Avanti_articolo 명령을 입력한다.

```text
help
apps
run hello vbox
```

마지막 명령은 별도 Java ELF를 실행한다. `USER MODE ring 3`, `arg: vbox`, `Exit: 0` uscitaTesto 후 셸로 돌아오면 정상이다. VGA 화면은 Regolari_articolo ASCII 글꼴만 지원하므로 한글은 `?`로 보이며, 한글 원문은 seriale_VALORE 기록에서 확인할 numero 있다.

## Stato_VALORE 확인과 retry_VALORE Esegui_comando

```sh
make vbox-status
```

이 명령은 VM Stato_VALORE, ISO와 seriale_VALORE 기록의 절대 경로를 JSON으로 출력한다.

| Regolari_articolo Stato_VALORE | `make vbox` Azione |
| --- | --- |
| 아직 생성하지 않음 | ISO costruire → 전용 VM generare → avvio_macchina |
| 종료됨 (`poweroff`, `aborted`) | ISO costruire → 광학 supporti_VALORE aggiornare → 새로 avvio_macchina |
| Esegui_comando 중 (`running`) | 재빌드·재부팅 없이 Regolari_articolo VM mantenere_VALORE |
| 일시정지 (`paused`) | 기존 VM CV_esecuzione |
| 저장됨 (`saved`) | Indietro_articolo seriale_VALORE 기록을 복사해 보관하고 Store_VALORE Stato_VALORE CV_esecuzione |
| Store_VALORE·avvia 등 SWITCH_MODA 중 | 변경하지 않고 작업 완료 후 재실행하도록 README_eb81d7d9 |

fonte_albero 변경을 반영하려면 VM을 종료한 Avanti_articolo retry_VALORE `make vbox`를 실행한다. **Store_VALORE 상태를 재개하면 Indietro_articolo 커널이 계속 실행되므로 새 빌드를 반영하지 않는다.** 실행기는 강제 종료하거나 Store_VALORE 상태를 폐기하지 않는다. VirtualBox 창을 닫을 때 사용자가 전원 끄기를 선택하면 Memoria_dati 상태가 사라지므로 보존할 작업이 없는지 먼저 확인한다. 게스트의 `halt`는 CPU만 멈추며 VirtualBox의 전원을 끄는 명령은 아니다.

Finestra 없는 실행이 필요하면 VM이 꺼져 있을 때 사용한다.

```sh
make vbox VBOX_TYPE=headless
```

Esegui_comando 중인 VM에 retry_VALORE 명령을 내려도 GUI/headless 방식은 바뀌지 않는다. valore_predefinito Nome 대신 다른 이름이 필요하면 **최초 generare 시에만** `VBOX_NAME="원하는 Nome"`을 지정하고 이후에도 같은 값을 사용한다.

## 설정과 dati 보존

- valore_predefinito 설정은 BIOS, Memoria_dati 64MiB, CPU 1개, VGA Memoria_dati 16MiB, IDE 광학 부팅이다. 가상 하드디스크를 만들지 않는다.
- VM 설정은 `.vbox/machines/`, Contenuto_VALORE 검사합별 ISO 사본은 `.vbox/media/`, seriale_VALORE 기록은 `.vbox/logs/`에 보관한다. `.vbox/state.json`은 전용 VM의 UUID와 proprietario_VALORE 표식을 저장한다.
- 꺼진 VM을 부팅할 때 새 seriale_VALORE 기록을 만든다. Store_VALORE Stato_VALORE CV_esecuzione 전의 기록은 `before-resume-*.log`로 복사한다. Store_VALORE Stato_VALORE 자체는 삭제하지 않고 VirtualBox가 그대로 재개한다.
- 같은 이름의 다른 VM을 인수하지 않는다. UUID·Impostazioni percorso·proprietario_VALORE 표식을 검사하며, 사용자가 별도로 연결한 디스크나 광학 매체를 자동 교체하지 않는다.
- 기존 ISO 사본과 기록은 자동 삭제하지 않는다. `.vbox`는 Git 제외 대상이다. 용량을 정리할 때도 Esegui_comando·Store_VALORE 상태의 VM이 참조하는 파일과 관리 정보를 임의로 삭제하지 않는다.
- VirtualBox 또는 host 드라이버가 없으면 오류를 안내한다. 자동 installare_VALORE, manager_VALORE privilegio_VALORE Esegui_comando, cellulare_VALORE privilegio_VALORE 변경은 하지 않는다.

## 네트워크 제한

Regolari_articolo 커널의 RTL8139 드라이버는 QEMU에서 사용한다. VirtualBox의 PCnet/E1000 드라이버는 아직 구현하지 않아 이 실행기는 네트워크 장치를 비활성화한다. 셸과 spazio_utente 프로그램은 실행되지만 UDP 열기는 `-19`로 실패한다. UDP 왕복은 `make run`과 [spazio_utente Esegui_comando·네트워크 README_eb81d7d9](../os/spazio_utente/README_eb81d7d9.md)의 절차로 시험한다.

## convalidare

`make test-vbox`는 가짜 VirtualBox 응답을 사용하여 새 VM generare, Esegui_comando·Store_VALORE·일시정지·SWITCH_MODA Stato_VALORE, Nome 충돌, 소유권 불일치, spazio_utente supporti_VALORE proteggere_VALORE, costruire errore_VALORE, 중단된 generare recuperare_Stato, ISO cambiare_VALORE 감지, percorso proteggere_VALORE 등을 검사한다. effettivo_dati VM을 만들거나 변경하지 않는다.

2026-09-13에 app_Launcher unità_VALORE prove 16개가 통과했다. 별도로 effettivo_dati VirtualBox 5.2.42에서 `make vbox`의 VM generare·GUI avvio_macchina, `JAVA SELFTEST PASS`, 셸의 `run hello vbox` 실행과 `Exit: 0`, Esegui_comando 중 재호출 시 재부팅하지 않는 Azione 및 `make vbox-status`를 확인했다. Store_VALORE·일시정지 분기는 unità_VALORE 시험으로 검증했다.
