# vlastiti 커널에서 vi·여러 Terminal·한글 프로그래밍 사용하기

hrvatski 통신·iznimka 사용법은 [hrvatski Java API](한국어자바/안내.md), FUNCTION_VALUE·varijabla_VALUE·Datoteka 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

대상은 `platforms/rpi4-native`의 vlastiti AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 Podrška_VALUE 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 Izvrši_naredba, vanjski_VALUE TCP/UDP와 FTP는 [새 Izvrši_naredba 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 Terminal

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, adresa **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 Terminal 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **RIGHT 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 Izvrši_naredba 버튼으로 pokušati_ponovno_VALUE COLUMN_VALUE 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 redovno_artikl 디렉터리, ljuska varijabla_VALUE, Naredba LOG_zapis, 입력 중인 명령과 program_f5044b9b Izvrši_naredba 상태를 보관한다. Datoteka 저장소는 공유한다. vi와 Swing의 이벤트 čekaj_VALUE 중에 다른 터미널로 전환하면 korisnik Memorija_podaci·레지스터·Datoteka/소켓 연결을 보존했다가 돌아올 때 재개한다. **redovno_artikl 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 Dalje_artikl 입력 čekaj_VALUE 또는 기존 Izvrši_naredba 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 Izvrši_naredba 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 Uredi_VALUE 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. redovno_artikl 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 Prozor 판단은 게스트 커널이 처리한다. QEMU Izvrši_naredba 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. stvaran_podaci Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI Alati 종료는 domaćin 터미널의 Ctrl+C다.

붙여 넣은 한글을 문자 경계에 맞춰 pomicati_se_VALUE·삭제한다. 일반 vi의 수량 접두사, makro_VALUE, Postavke Datoteka, 플러그인, 정규식, 여러 버퍼/분할 Prozor, 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/nula_operand 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 Prozor prozor_Naslov `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 Naredba**으로 실행한다. 파이프·리다이렉션·skripta_VALUE·`;`/`&&`/`||`로 연결한 실행에서 대화형 대기를 시작하면 거부한다. 입력 대기는 약 2초 CPU 기한을 갱신하지만 입력 čekaj_VALUE 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## vlastiti JVM의 Swing isječak

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 vlastiti Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | Aktivnost |
|---|---|
| `JFrame` | prozor_Naslov, Veličina·Položaj, emisija_prozor, Zatvori 정책, dispose |
| `JPanel` | dijete_VALUE 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 niz_VALUE emisija_VALUE·promijeniti_VALUE |
| `JButton` | 버튼과 ActionListener klik_VALUE Proces_VALUE_unos |
| `JTextField` | 한 red UTF-8 입력, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 vlastiti JVM의 단일 이벤트 Izvrši_naredba 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. Prozor·요소는 Izvrši_naredba 하나당 ukupni_zbroj_VALUE 32개, element_VALUE 글자는 최대 127 코드포인트다. zadana_vrijednost 서체와 색은 커널이 제공한다.

[스윙시험.java](시험/자바/스윙시험.java)는 Prozor·한글 oznaka_VALUE·tekstno_polje·버튼·이벤트 처리의 Izvrši_naredba 가능한 예제다. [vlastiti Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

hrvatski 라이브러리에는 다음을 추가했다. domaćin programski_prevesti_izvor 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `hrvatski.vlastiti.Prozor`: `Dodaj_element`, `emisija_prozor`, `Zatvori`.
- `hrvatski.vlastiti.widget`: `oznaka_VALUE`, `gumb`, `tekstno_polje` generirati.
- `hrvatski.vlastiti.연결통신`: `Spoji_se`, `osluškivati_sudionik`, `primiti`.
- 기존 `Izlaz`, `문자`, `Datoteka`, `작업`, `unos_Popis`, `rječnik`, `통신`, `화면`, `jezgra_sustava_VALUE`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **jezgra_sustava_VALUE 내부 연결형 bajt_VALUE tok_VALUE**을 추가했다. Datoteka/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket server_VALUE = new java.net.ServerSocket(9250);
java.net.Socket gost_VALUE = new java.net.Socket("localhost", 9250);
java.net.Socket Spoji_se = server_VALUE.accept();
gost_VALUE.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] RECEIVED_artikl = new byte[64];
int 길이 = Spoji_se.getInputStream().read(RECEIVED_artikl);
Spoji_se.close(); gost_VALUE.close(); server_VALUE.close();
```

generirati·Spoji_se·accept·양방향 bajt_VALUE/ARRAY_VALUE U_I·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 završiti_razgovor_p 16개, primiti_VALUE 버퍼당 1024바이트, čekaj_VALUE Spoji_se 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. zadana_vrijednost TIME_VALUE 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM Naredba 수/jezgra_sustava_VALUE Izvrši_naredba 기한은 여전히 적용된다.

vanjski_VALUE znamenka_VALUE IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. stvaran_podaci Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP biblioteka 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 stvaran_podaci 송수신·EOF·기한·Spoji_se 회수의 시험 예제다.

CPython과 일반 nastavak_VALUE 모듈은 아직 없다. 제한형 `pip`의 izvor_stablo 설치는 [Python komplet 안내](PYTHON_komplet.md)를 따른다. [세 언어의 stvaran_podaci 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 Jezik 모두 hrvatski 헤더와 FUNCTION_VALUE 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 stvaran_podaci EL0 Izvrši_naredba 시험 대상이다.

```c
#include "파일규약.h"
#ifdef __cplusplus
extern "C"
#endif
int START_korisnik_program(int Argumenti) {
    (void)Argumenti;
    const char 인사말[] = "안녕하세요\n";
    int 문서 = otvoreno_Datoteka("인사.txt", 읽고쓰기 | 없으면만들기 | skratiti_Sadržaj, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = zapisivanje_Datoteka_podaci(문서, 인사말, sizeof(인사말) - 1);
    Zatvori_Datoteka(문서);
    zapisivanje_Datoteka_podaci(1, 인사말, sizeof(인사말) - 1); /* redovno_artikl Terminal stdout */
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 수 있다. C는 게스트 `cc` 또는 domaćin SDK, C++는 domaćin SDK의 Clang++로 컴파일한다. 아래 예제는 기존 domaćin SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh
# 호스트에서 SDK generirati·izdvojiti
make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/인사.c -o 인사-c.elf
python3 compile.py examples/인사.cpp -o 인사-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 stvaran_podaci Izvrši_naredba
cd /home/user/jkoros/platforms/rpi4-native
python3 Alati/Izvrši_Datoteka.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 Alati/Izvrši_Datoteka.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

[tok_VALUE.c](예제/한글코딩/tok_VALUE.c)는 C에서 hrvatski 이름으로 Spoji_se·accept·부분 Čitaj/Zapisuj·큐 포화·EOF를 처리하는 Izvrši_naredba 예제다. SDK의 `examples/tok_VALUE.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → stvaran_podaci hrvatski C FUNCTION_VALUE 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·pokazivač 검사 → Java RAM Datoteka/루프백 또는 vanjski_VALUE lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 jezgra_sustava_VALUE 내부용이므로 EL0 프로그램에 링크하지 않는다. ## hrvatski 이름으로 직접 작성하는 창과 nit_VALUE

`example/java/PrimjerProzora.java`는 `실행할일.Izvrši`,
`동작받이.primiti_akcija(akcija_obavijest)`, `gumb`, `događaj_red_čekanja.나중에실행`, `Pokreni()`을 쓴다.
vlastiti JVM에 이 이름들의 objekt_VALUE·postupak_VALUE·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `작업가닥`도 vlastiti 스케줄러와 직접 연결된다.
세부 메서드와 기존 hrvatski API에서의 변경은 [hrvatski API 문서](한국어자바/안내.md)를 본다.

domaćin javac는 배포 JAR를 poduka_VALUE 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/PrimjerProzora.java
python3 Alati/Izvrši_naredba.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java PrimjerProzora
```

직접 화면/nit_VALUE API와 `Pokreni()` 진입점은 vlastiti JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
