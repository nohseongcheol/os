# 전체 Podrška_VALUE 요청의 redovno_artikl Stanje_VALUE

zahtjev 전체는 아직 완료되지 않았다. redovno_artikl ISO는 vlastiti Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 stvaran_podaci C POSIX 일부 기능, hrvatski API/IZVOR Ime, IDE Datoteka 보존, 게스트 Java Datoteka 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/안내.md)를 기준으로 판단한다.

| zahtjev 분야 | redovno_artikl Izvrši_naredba 가능한 isječak | 전체 지원에 필요한 작업 |
|---|---|---|
| Java programski_prevesti_izvor·Izvrši_naredba | 게스트 제한형 javac/JVM, 정적 단일 클래스와 일부 표준 objekt_VALUE | 일반 objekt_VALUE·poduka_VALUE Spoji_se·iznimka·GC·스레드, 완전한 javac와 표준 poduka_VALUE biblioteka |
| Datoteka | POSIX 서술자, Java 단일 bajt_VALUE Datoteka tok_VALUE, 전용 medij_VALUE 보존 | 일반 java.io/nio, 디렉터리·dozvola_VALUE·zaključati_VALUE·일반 datotečni_sustav·nastavak_VALUE 가능한 kapacitet_VALUE |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP domaćin 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, dodati_unos NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 Događaj·font_VALUE·Prozor operacijski_sustav_VALUE, AWT 네이티브 연결과 Swing Izvrši_naredba 기반 |
| POSIX | 문서화한 Datoteka·단말·UDP 부분 | Proces_VALUE·exec/fork·스레드·시그널·TIME_VALUE·mmap·poll·파이프 등과 적합성 potvrditi |
| 언어별 Ime | hrvatski 46개 mapiranje_VALUE unos_VALUE, stvaran_podaci C/Java/Datoteka Ime 적용 | cilj Jezik izvršavanje_VALUE, 언어별 용례·역사 근거와 해당 IZVOR·도구의 potvrditi |

vlastiti 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 Izvrši_naredba 환경을 추가하는 방식은 별도의 jezgra_sustava_VALUE·루트 datotečni_sustav·OpenJDK·그래픽 server_VALUE·영구 Store_VALUE 구성을 가진 Izvrši_naredba 경로가 된다. 후자는 기존 vlastiti 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

Izvrši_naredba 기반과 dodati_unos cilj 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. redovno_artikl 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
