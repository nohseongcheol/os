# lastno 커널에서 vi·여러 Terminal·한글 프로그래밍 사용하기

slovenščina 통신·izjema 사용법은 [slovenščina Java API](한국어자바/안내.md), FUNCTION_VALUE·변수·Datoteka 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

대상은 `platforms/rpi4-native`의 lastno AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 Podpora_VALUE 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 Izvedi_ukaz, zunanji_VALUE TCP/UDP와 FTP는 [새 Izvedi_ukaz 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 Terminal

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, naslov **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 Terminal 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **RIGHT 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 Izvedi_ukaz 버튼으로 znova_poskusiti_VALUE COLUMN_VALUE 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 sprotno_element 디렉터리, lupina 변수, Ukaz LOG_zapis, 입력 중인 명령과 aplikacija_f5044b9b Izvedi_ukaz 상태를 보관한다. Datoteka 저장소는 공유한다. vi와 Swing의 이벤트 počakaj_VALUE 중에 다른 터미널로 전환하면 uporabnik pomnilnik_podatki·레지스터·Datoteka/vtičnica_VALUE 연결을 보존했다가 돌아올 때 재개한다. **sprotno_element 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 Naprej_element 입력 počakaj_VALUE 또는 기존 Izvedi_ukaz 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 Izvedi_ukaz 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 Uredi_VALUE 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. sprotno_element 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 okno 판단은 게스트 커널이 처리한다. QEMU Izvedi_ukaz 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. dejanski_podatki Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI Orodja 종료는 gostiti 터미널의 Ctrl+C다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **jedro_VALUE 내부 연결형 bajt_VALUE tok_VALUE**을 추가했다. Datoteka/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket strežnik_VALUE = new java.net.ServerSocket(9250);
java.net.Socket gost_VALUE = new java.net.Socket("localhost", 9250);
java.net.Socket Poveži = strežnik_VALUE.accept();
gost_VALUE.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] RECEIVED_element = new byte[64];
int 길이 = Poveži.getInputStream().read(RECEIVED_element);
Poveži.close(); gost_VALUE.close(); strežnik_VALUE.close();
```

ustvariti·Poveži·accept·양방향 bajt_VALUE/ARRAY_VALUE V_I·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 končati_klic_p 16개, sprejeti_sprejemati_prejeti_prejemati_VALUE 버퍼당 1024바이트, počakaj_VALUE Poveži 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. privzeta_vrednost čas_VALUE 제한 0은 별도 vtičnica_VALUE 기한을 설정하지 않지만 JVM Ukaz 수/jedro_VALUE Izvedi_ukaz 기한은 여전히 적용된다.

zunanji_VALUE številka_VALUE IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. dejanski_podatki Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP knjižnica 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [preskusiti_tok.java](시험/자바/preskusiti_tok.java)는 dejanski_podatki 송수신·EOF·기한·Poveži 회수의 시험 예제다.

## C·C++에서 posix-kor 호출

두 jezik 모두 slovenščina 헤더와 FUNCTION_VALUE 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 dejanski_podatki EL0 Izvedi_ukaz 시험 대상이다.

```c

#endif

    (void)Argumenti;
```
