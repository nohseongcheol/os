# 전체 Dəstək_VALUE 요청의 현재 vəziyyət_VALUE

HTTP_sorğusu 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 faktiki_verilənlər C POSIX 일부 기능, 한국어 API/QAYNAQ Ad, IDE FAYL 보존, 게스트 Java FAYL 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/OXUMƏNİ_eb81d7d9.md)를 기준으로 판단한다.

| HTTP_sorğusu 분야 | 현재 icra_etmək_əmr 가능한 klip | 전체 지원에 필요한 작업 |
|---|---|---|
| Java qurmaq_mənbə·icra_etmək_əmr | 게스트 제한형 javac/JVM, statik_VALUE 단일 클래스와 일부 표준 obyekt_VALUE | 일반 obyekt_VALUE·Sinif_VALUE Bağlan·istisna·GC·스레드, 완전한 javac와 표준 Sinif_VALUE kitabxana |
| FAYL | POSIX 서술자, Java 단일 bayt_VALUE FAYL axın_VALUE, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·icazə_VALUE·잠금·일반 fayl_sistemi·genişlənmə_VALUE 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP host 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 icra_etmək_əmr 환경을 추가하는 방식은 별도의 nüvə_VALUE·루트 fayl_sistemi·OpenJDK·그래픽 server_VALUE·영구 Store_VALUE 구성을 가진 icra_etmək_əmr 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

icra_etmək_əmr 기반과 추가 hədəf 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
