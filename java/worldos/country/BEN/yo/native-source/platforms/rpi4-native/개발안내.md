# 자체 커널에서 vi·여러 터미널·한글 프로그래밍 사용하기

한국어 통신·예외 사용법은 [한국어 Java API](한국어자바/KÀ_MÍ_eb81d7d9.md), ÀKÀNṢEFỌMÚLÀ_iye·변수·Fáìlì 이름의 변경과 어원 근거는 [명명 KÀ_MÍ_eb81d7d9](명명/KÀ_MÍ_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 자체 AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 àtìlẹ́yìn_iye 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 ṣiṣẹ́_àṣẹ, 외부 TCP/UDP와 FTP는 [새 ṣiṣẹ́_àṣẹ 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 터미널

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, àdírẹ́ẹ̀sì **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 터미널 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **오른쪽 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 ṣiṣẹ́_àṣẹ 버튼으로 다시 ìlà_òró_iye 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 현재 디렉터리, ṣẹ́ẹ̀lì 변수, Àṣẹ àkọsílẹ̀_ìṣe_ìlà_ìbú, 입력 중인 명령과 àtòjọ_ètò_f5044b9b ṣiṣẹ́_àṣẹ 상태를 보관한다. Fáìlì 저장소는 공유한다. vi와 Swing의 이벤트 대기 중에 다른 터미널로 전환하면 aṣàmúlò ibi_ìpamọ́_détà·레지스터·Fáìlì/소켓 연결을 보존했다가 돌아올 때 재개한다. **현재 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 다음 입력 대기 또는 기존 ṣiṣẹ́_àṣẹ 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 ṣiṣẹ́_àṣẹ 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 ṣàtúnṣe_iye 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. 현재 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 wínńdò 판단은 게스트 커널이 처리한다. QEMU ṣiṣẹ́_àṣẹ 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. gangan_détà Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI Àwọn_irinṣẹ́ 종료는 olùpèsè 터미널의 Ctrl+C다.

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. 출력 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.ọ̀wọ́_iye.class` 형식이다. 내장 한국어 라이브러리는 별도 업로드가 필요 없다. 한국어 wínńdò API의 예제는 [한글창시험.java](시험/자바/한글창시험.java)이며 같은 방법으로 ṣàkójọ_ìtumò_èdè_kọ̀ǹpútà_orísun·업로드해 `java 한글창시험`으로 실행한다.

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 자체 Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

|---|---|
| `JFrame` | wínńdò_Àkọlé, Ìwọ̀n·위치, ṣàfihàn_wínńdò, Ti 정책, dispose |
| `JPanel` | ọmọ_iye 요소를 담는 패널 |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 자체 JVM의 단일 이벤트 ṣiṣẹ́_àṣẹ 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. wínńdò·요소는 ṣiṣẹ́_àṣẹ 하나당 합계 32개, ìdá_ìpìlẹ̀_iye 글자는 최대 127 코드포인트다. àdáwọ̀ 서체와 색은 커널이 제공한다.

- `한국어.자체.wínńdò`: `ròmọ́_ìdá_ìpìlẹ̀`, `ṣàfihàn_wínńdò`, `Ti`.
- `한국어.자체.wíjẹ́ẹ̀tì`: `sàmì_iye`, `bọ́tìnnì`, `SMS_àayè_wúnrẹ̀n` 생성.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **kánẹ́ẹ̀lì_iye 내부 연결형 báìtì_iye Stream_iye**을 추가했다. Fáìlì/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket apèsè_iye = new java.net.ServerSocket(9250);
java.net.Socket àlejò_iye = new java.net.Socket("localhost", 9250);
java.net.Socket Darapọ̀ = apèsè_iye.accept();
àlejò_iye.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int gígùn_iye = Darapọ̀.getInputStream().read(받은것);
Darapọ̀.close(); àlejò_iye.close(); apèsè_iye.close();
```

생성·Darapọ̀·accept·양방향 báìtì_iye/ÀRÉÈ_iye I_O·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 parí_kókó 16개, 수신 버퍼당 1024바이트, 대기 Darapọ̀ 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. àdáwọ̀ 시간 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM Àṣẹ 수/kánẹ́ẹ̀lì_iye ṣiṣẹ́_àṣẹ 기한은 여전히 적용된다.

외부 díjììtì_iye IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. gangan_détà Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP ibi_ìpamọ́ 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 gangan_détà 송수신·EOF·기한·Darapọ̀ 회수의 시험 예제다.

```c
}
```

파일은 게스트 vi로 작성할 수 있다. C는 게스트 `cc` 또는 olùpèsè SDK, C++는 olùpèsè SDK의 Clang++로 컴파일한다. 아래 예제는 기존 olùpèsè SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh
# 호스트에서 SDK 생성·fà_yọ
make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/인사.c -o 인사-c.elf
python3 compile.py examples/인사.cpp -o 인사-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 gangan_détà ṣiṣẹ́_àṣẹ
cd /home/user/jkoros/platforms/rpi4-native
python3 Àwọn_irinṣẹ́/ṣiṣẹ́_fáìlì.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 Àwọn_irinṣẹ́/ṣiṣẹ́_fáìlì.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

현재 GUI VM에서 실행하려면 `python3 Àwọn_irinṣẹ́/fífi_ẹ̀dà_fáìlì_ṣọwọ́_Àwọn_fáìlì.py ọ̀nà/인사-c.elf`의 출력을 게스트에 보내고 `run 인사-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex fáìlì_orúkọ_SMS`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 수 있다. 호스트와 게스트의 Fáìlì 시스템은 별개다.

| 한국어 Orúkọ | C àmì | ní_ṣókí |
|---|---|---|
| ṣí_fáìlì/pa_dé_fáìlì | pk_open/pk_close | RAM Fáìlì, ọ̀gbà_iye/절대 ọ̀nà |
| 파일자료읽기/kọ_fáìlì_détà | pk_read/pk_write | Fáìlì, fd 0/1/2 표준 I_O, 연결형 소켓 |
| ṣàwárí_fáìlì | pk_lseek | 처음기준/현재기준/끝기준 |
| fáìlì_ìwọn/ọ̀wọ̀_fáìlì_gígùn | pk_size/pk_ftruncate | gígùn_iye aṣèbéèré_iye/ṣàyípadà_iye |
| ṣèmúkúro_fáìlì_ìgbéwọlé_orúkọ | pk_unlink | Fáìlì Orúkọ 삭제 |
| 파일저장확정 | pk_fsync | RAM이므로 -1, 오류번호=ENOSYS |
| 통신종단점만들기/BIND_àdírẹ́ẹ̀sì | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |
| 자료전문보내기/자료전문받기 | pk_sendto/pk_recvfrom | UDP 루프백 |
| SOMỌ́_Alásopọ̀ | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | 대기 Darapọ̀ 최대 4개 |
| gbà_ìsopọ̀_alásopọ̀ | pk_accept | 현재 àdírẹ́ẹ̀sì 인수는 NULL/NULL만 àtìlẹ́yìn_iye |
| 통신주소읽기 | pk_getsockname | 로컬 àdírẹ́ẹ̀sì/ojú_iye |

`통신규약.h`의 자체 `pk_sockaddr_in`을 사용하며 ojú_iye·주소는 `망차례짧은수`/`Alásopọ̀_nọ́ńbà_odindi`로 변환한다. C 소켓 호출은 비차단이며 détà/연결이 없으면 -1과 `오류번호=11`(EAGAIN)을 반환한다. 양수 I_O 결과가 요청보다 작을 수 있으므로 àṣetúnṣe_iye 처리한다. ìkùnà_iye 후에만 오류번호를 확인한다.

[Stream_iye.c](예제/한글코딩/Stream_iye.c)는 C에서 한국어 이름으로 Darapọ̀·accept·부분 Kàá/Kọ·큐 포화·EOF를 처리하는 ṣiṣẹ́_àṣẹ 예제다. SDK의 `examples/Stream_iye.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → gangan_détà 한국어 C ÀKÀNṢEFỌMÚLÀ_iye 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·ìtọ́ka 검사 → Java RAM Fáìlì/루프백 또는 외부 lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 kánẹ́ẹ̀lì_iye 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 Darapọ̀, 표준 C printf, libstdc++/STL, 예외·RTTI는 제공하지 않으며 C++의 ìdágún_iye 생성자·agbègbè_sàkání nǹkan_iye 소멸자는 지원한다. 상세 wá_atọ̀ka_àkóónú·ibi_ìpamọ́_détà 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## ìfọwọ́síìwé

`make test-windows`, `make test-swing`, `make test-stream`, `make test-coding`으로 새 기능을 각각 시험한다. `make test`는 기존 ṣẹ́ẹ̀lì·VNC·JVM·AOT·kánẹ́ẹ̀lì_iye dáàbòbò_iye 시험까지 포함한다. gangan_détà 보드 대신 QEMU raspi4b에서 수행한다. 결과는 [이전 GUI Àfikún_iye ìfọwọ́síìwé àkọsílẹ̀_ìṣe_ìlà_ìbú](build/verification/release.json)과 [현재 àkókò_iṣẹ́_èdè_tówọ́pọ̀ ìfọwọ́síìwé àkọsílẹ̀_ìṣe_ìlà_ìbú](build/verification/native-runtime-summary.json), [여러 터미널 화면](build/verification/windows/four-terminals.png), [Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

구현 시 참고한 표준 API: [Socket](https://docs.oracle.com/javase/8/docs/api/java/net/Socket.html), [JFrame](https://docs.oracle.com/javase/8/docs/api/javax/swing/JFrame.html), [JButton](https://docs.oracle.com/javase/8/docs/api/javax/swing/JButton.html). 이 문서의 구현 범위가 위 표준 전체를 지원한다는 뜻은 아니다.

## 한국어 이름으로 직접 작성하는 창과 èròjà_atẹ̀lélànà_iye

`example/java/창예제.java`는 `실행할일.ṣiṣẹ́_iṣẹ́`,
`동작받이.동작받기(동작알림)`, `bọ́tìnnì`, `ìgbéṣẹ̀_ìtòléra.나중에실행`, `Rọ́ọ̀nù()`을 쓴다.
자체 JVM에 이 이름들의 nǹkan_iye·ìlànà_iye·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `작업가닥`도 자체 스케줄러와 직접 연결된다.
세부 메서드와 기존 한국어 API에서의 변경은 [한국어 API 문서](한국어자바/KÀ_MÍ_eb81d7d9.md)를 본다.

olùpèsè javac는 배포 JAR를 ọ̀wọ́_iye 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/창예제.java
python3 Àwọn_irinṣẹ́/ṣiṣẹ́_àṣẹ.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java 창예제
```

직접 화면/èròjà_atẹ̀lélànà_iye API와 `Rọ́ọ̀nù()` 진입점은 자체 JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
