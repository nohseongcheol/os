# JBenOS 구조

아래는 nǹkan_iye 기반 관리 kánẹ́ẹ̀lì_iye 전체의 àfojúsùn_nǹkan 구조다. 현재 gangan_détà 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 OS KÀ_MÍ_eb81d7d9](../os/KÀ_MÍ_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·Ìṣètò_kíkà_iye ṣèpapòdà_móòdù·ìlànà_ètò_fáìlì 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 ìpele_iye
  ↓
Java AOT 실행기와 nǹkan_iye·ÀRÉÈ_iye·GC 런타임
  ↓
ohun_èlò_alárídìmú_iye 경계
  ↓
Java 관리 kánẹ́ẹ̀lì_iye
  ├─ 기억공간/쪽관리/COW
  ├─ Ìlànà_iye/배정/wait
  ├─ ìlànà_ètò_fáìlì/ELF/POSIX
  └─ 입력/Ibi_ìpamọ́_ohun_èlò/Alásopọ̀_kójọ
```

OpenJDK 자체는 이미 운영체제가 제공하는 Fáìlì, 스레드, 가상 기억공간을 전제로 한다. 따라서 kánẹ́ẹ̀lì_iye 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, Ìṣètò_kíkà_iye 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
