# নিজ ARM64 Java 커널의 C/C++ নথির_নাম·루프백 সংযোগ_স্থাপনা

이 디렉터리는 `platforms/rpi4-native` নিজ কারনেল_মান 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 বাংলা 함수명과 `extern "C"` ABI를 제공한다. `সংযোগ_স্থাপনা.c`는 কারনেল_মান 안에서 AOT Java নথির_নাম 메서드에 직접 연결하고, `ব্যবহারকারী_ব্রিজ.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. প্রকৃত_ডাটা নথির_নাম 처리는 `মেমরি_ফাইলগুলি.java`, 루프백 전문 처리는 `되돌림망.java`, 연결형 흐름은 `প্রবাহ_নেটওয়ার্ক.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 কারনেল_মান 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·실수 অপারেশন_মান·নথির_নাম·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

সমর্থন_মান: `খোলা_ফাইল`, `파일자료읽기`, `লেখা_ফাইল_ডাটা`, `বন্ধ_ফাইল`, `সিক_ফাইল`, `সরানো_ফাইল_ভুক্তি_নাম`, `সেট_ফাইল_দৈর্ঘ্য`, 보조 ফাংশন_মান `ফাইল_আয়তন`. ত্রুটি 시 -1과 작업별 `오류번호`를 반환한다. `파일저장확정`은 RAM 파일이므로 ENOSYS를 반환한다. নথির_নাম 16개, 각 16384바이트, নাম 63바이트, 서술자 16개이며 RAM 디렉터리·পিয়ার_মান/절대 경로를 제공한다. অনুমতি_মান/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 প্রকৃত_ডাটা বাংলা 함수와 독립 구조체를 선언한다.
`통신종단점만들기`, `বন্ধন_করা_ইমেইল`, `자료전문보내기/받기`, `সংযোগ_নেটওয়ার্ক/기다리기/받기`는
`ব্যবহারকারী_ব্রিজ.c`에서 SVC를 호출하며 ম্যাক্রো_মান 별칭이 아니다. `struct 인터넷통신주소`의
`ইমেইল_পরিবার`, `পোর্ট_নম্বর`, `ইন্টারনেট_ঠিকানা.ইমেইল_মান`을 사용한다. 상수는 enum의
`ক্লাউড_পরিবার`, `전문통신`, `전문전송규약`, `প্রবাহ_নেটওয়ার্ক`, `흐름전송규약`이다.
বাংলা·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. 외부 통신은 নিজ 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. প্রকৃত_ডাটা Pi 4 GENET 드라이버는 미지원이다.
소켓도 প্রকৃত_ডাটা ফাংশন_মান `বন্ধ_ফাইল`로 닫는다.
