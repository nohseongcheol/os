# 전체 সমর্থন_মান 요청의 현재 অবস্হা_মান

요청 전체는 아직 완료되지 않았다. 현재 ISO는 নিজ Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 প্রকৃত_ডাটা C POSIX 일부 기능, বাংলা API/উৎস_নথি নাম, IDE নথির_নাম 보존, 게스트 Java নথির_নাম 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/স্বনিবন্ধ_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 কার্যকর_করুন_আদেশ 가능한 ক্লিপ | 전체 지원에 필요한 작업 |
|---|---|---|
| Java গঠন_উত্স·কার্যকর_করুন_আদেশ | 게스트 제한형 javac/JVM, স্থির_মান 단일 클래스와 일부 표준 বস্তু_মান | 일반 বস্তু_মান·শ্রেণী_মান সংযোগ_স্থাপনা·ব্যতিক্রম·GC·스레드, 완전한 javac와 표준 শ্রেণী_মান লাইব্রেরি |
| নথির_নাম | POSIX 서술자, Java 단일 বাইট_মান নথির_নাম প্রবাহ_মান, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·অনুমতি_মান·잠금·일반 ফাইল_পদ্ধতি·প্রসার_মান 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP হোস্ট 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 ঘটনা·হরফ_মান·উইন্ডো অপারেটিং_সিস্টেম_মান, AWT 네이티브 연결과 Swing কার্যকর_করুন_আদেশ 기반 |
| POSIX | 문서화한 নথির_নাম·단말·UDP 부분 | প্রসেসর_মান·exec/fork·스레드·시그널·সময়_মান·mmap·poll·파이프 등과 적합성 বৈধ_করুন |
| 언어별 নাম | বাংলা 46개 대응 ভুক্তি_মান, প্রকৃত_ডাটা C/Java/নথির_নাম নাম 적용 | লক্ষ্য ভাষা 확정, 언어별 용례·역사 근거와 해당 উৎস_নথি·도구의 বৈধ_করুন |

নিজ 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 কার্যকর_করুন_আদেশ 환경을 추가하는 방식은 별도의 কারনেল_মান·루트 ফাইল_পদ্ধতি·OpenJDK·그래픽 সার্ভার_মান·영구 ভাণ্ডার_মান 구성을 가진 কার্যকর_করুন_আদেশ 경로가 된다. 후자는 기존 নিজ 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

কার্যকর_করুন_আদেশ 기반과 추가 লক্ষ্য 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
