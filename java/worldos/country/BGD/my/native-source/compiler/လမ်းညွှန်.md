# Java 네이티브 ဘာသာပြန်စက်

OpenJDK ကိုယ်ပိုင် 소스를 빌드하는 **`--target openjdk-build`**와 ကိုယ်ပိုင် အူတိုင်တန်ဖိုး ABI စစ်ဆေးချက် 도구를 추가했다.
이는 공식 javac/C/C++ 도구를 연결하는 별도 경로다. [တည်ဆောက် 방법·တကယ့်ဒေတာ မှန်ကန်ကြောင်းစစ်·အူတိုင်တန်ဖိုး 이식 ဖြတ်နယ်ပယ်](OpenJDK-မူရင်းကုဒ်တည်ဆောက်နှင့်-ကိုယ်ပိုင်အူတိုင်-이식.md)를 참고한다.

x86 직접 변환과 ARM64 C ထုတ်လုပ် 후단은 အားလုံးတည်ဆောက် [ကြိုတင်ဘာသာပြန်.java](Javaကိရိယာ/ကြိုတင်ဘာသာပြန်.java)로 구현한다. `sh 미리번역.sh`로 직접 실행하며, [ကြိုတင်ဘာသာပြန်.py](ကြိုတင်ဘာသာပြန်.py)와 `ဘာသာပြန်စက်.py`는 ယခင်အချက်အလက်တစ်ခု အမိန့်·API 및 OpenJDK 도구를 위한 호환 진입점이다. ကိုယ်ပိုင် Pi4 후단은 freestanding C를 거쳐 AArch64로 만든다. [arm64.py](arm64.py)는 ယခင်အချက်အလက်တစ်ခု 경로와 Python 호출을 위한 호환 진입점이다. လုပ်ဆောင်ချက်·ကိန်းရှင်တန်ဖိုး·ထုတ်လုပ် C 이름의 뜻과 예외는 [မြန်မာ 명명 လမ်းညွှန်](../platforms/rpi4-native/명명/လမ်းညွှန်.md)를 참고한다. [ARM64 တည်ဆောက်·ထောက်ပံ့မှုတန်ဖိုး ဖြတ်နယ်ပယ်](../platforms/rpi4-native/လမ်းညွှန်.md)에 စက်မောင်း 조건이 있다. 전체 OpenJDK나 일반 အတန်းတန်ဖိုး 실행기는 아니다.

စက်မောင်း 시 JVM이 필요 없는 x86 32비트 ELF를 만든다. JDK 11 이상으로 실행하는 Java ကိုယ်ပိုင် AOT 후단이며, Java 전체를 새로 구현한 컴파일러는 아니다. Java 문법·ဝင်သုံးအချက် ထိန်းချုပ်တန်ဖိုး·အမျိုးပုံစံတန်ဖိုး 검사는 JDK의 `javac`에 맡기고, Java 8 အတန်းတန်ဖိုး 파일을 읽어 각 바이트코드를 x86 명령으로 직접 변환한다. C 코드로 우회하거나 ဘိုက်ကုဒ် 해석기를 커널에 넣지 않는다.

```text
Java မူရင်းကုဒ် → javac의 문법·အမျိုးပုံစံတန်ဖိုး စစ်ဆေးချက် → ယာယီတန်ဖိုး .class
          → ကိုယ်ပိုင် x86 변환기 → GNU as/ld → 네이티브 ELF32
```

## 준비와 စက်မောင်း

တည်ဆောက် အိမ်ရှင်: Linux, Python 3.6 이상, JDK 11 이상(`javac --release 8`), GNU binutils(`as`, `ld`), Make. လက်ရှိအချက်အလက်တစ်ခု 환경의 OpenJDK 11, Python 3.6, binutils 2.30으로 검증했다. ပြင်ပတန်ဖိုး Python 패키지와 ကွန်ရက်ဆက် 다운로드는 사용하지 않는다.

```sh
cd /home/user/jkoros/compiler
make
./build/တွက်ချက်မှု
echo $?                  # 0이면 ဥပမာ စမ်းသပ်မှု အောင်မြင်မှုတန်ဖိုး

python3 ဘာသာပြန်စက်.py --target linux --entry တွက်ချက်မှု.လုပ်ဆောင် \
    -o build/တွက်ချက်မှု ဥပမာ/တွက်ချက်မှု.java

make test
```

`linux` 대상은 Linux의 32비트 စက်မောင်း 호환 기능이 필요하다. `int 0x80`을 차단하는 샌드박스에서는 `Bad system call`이 발생할 ကိန်းတန်ဖိုး 있다. ဖြစ်သောပုံမှန် Linux အိမ်ရှင် 또는 해당 실행을 허용한 စမ်းသပ်မှု 환경에서 실행한다. 시험의 비정상 종료를 통과로 처리하지 않는다.

진입점은 `static int လုပ်ဆောင်()` 또는 `static void လုပ်ဆောင်()`처럼 인수가 없어야 한다. `--entry 패키지.အတန်းတန်ဖိုး.လုပ်ဆောင်ချက်`로 선택한다. `int` 반환값은 Linux 프로세스 ထွက်ပရိုဂရမ် 코드가 되며 셸에는 하위 8비트가 보인다. 일반 `main(String[] args)` စက်မောင်း 환경이나 표준 အဝင်အထွက် 라이브러리는 제공하지 않는다.

`--target kernel`은 စက်တင် 코드와 연결할 재배치 ELF 오브젝트를 생성한다.

```sh
cd /home/user/jkoros
python3 compiler/ဘာသာပြန်စက်.py --target kernel --entry အူတိုင်.လုပ်ဆောင် \
    --export kernel_dispatch=စနစ်ခေါ်ဆိုမှု.လုပ်ငန်းစဉ်တန်ဖိုးအချက် \
    -o os/build/java.o os/မူရင်းကုဒ်/*.java
```

`--target user`는 jkoros 셸에서 실행할 독립 ELF를 생성한다. `သုံးစွဲသူ` 클래스의 제한된 native API는 `int 0x80` 시스템 호출로 연결하며 `ကိရိယာ` 클래스의 စက်ပစ္စည်း 직접 접근은 거부한다. သုံးစွဲသူ ELF는 Linux စက်မောင်း ဖိုင် ABI와 다르므로 호스트에서 실행하지 않는다. ထုတ်လုပ်·ကိုင်တွယ်သူစာရင်းသွင်း 방법은 [သုံးစွဲသူ စက်မောင်း လမ်းညွှန်](../os/သုံးစွဲသူ/လမ်းညွှန်.md)에 있다. `--export 외부기호=အတန်းတန်ဖိုး.လုပ်ဆောင်ချက်`는 오버로드되지 않은 တည်ငြိမ်တန်ဖိုး 함수를 ကိုယ်ပိုင် တွက်ချက်ခံထပ်ဆင့်အစု ABI로 노출한다. 커널의 시스템 ခေါ်လုပ် 진입점에 사용한다.

Java 파일은 필요한 클래스들을 한꺼번에 전달한다. အထွက် 옆의 `.s`는 생성된 어셈블리, `.json`은 မူရင်းကုဒ် SHA-256 및 네이티브 သင်္ကေတ↔Java လုပ်ဆောင်ချက် 대응표다. မြန်မာ 함수명은 원문과 대응표에 보존하고 ELF 내부에는 충돌 방지용 စက် 기호를 쓴다. မူရင်းကုဒ်ဘာသာပြန်·တန်ဖိုးစက်ညွှန်ကြားချက်စုစည်း·ချိတ်ဆက် 중 실패하면 기존 ရလဒ် 파일을 덮어쓰지 않는다.

## ထောက်ပံ့မှုတန်ဖိုး ဖြတ်နယ်ပယ်

- `int`, `boolean`, `byte`, `short`, `char`의 32비트 တွက်ချက်မှု 및 အမျိုးပုံစံတန်ဖိုး တန်ဖိုးပြောင်းလဲ.
- တည်ငြိမ်တန်ဖိုး 필드와 တည်ငြိမ်တန်ဖိုး လုပ်ဆောင်ချက်, 매개변수·ပြန်ပေးတန်ဖိုး, 재귀, 클래스별 지연 초기화와 အစပြင်ဆင် 순환.
- 조건문, 반복문, 단락 평가, 삼항식, ကိန်းပြည့် `switch`, 넓은 ဒေသတွင်းနယ်ပယ်ကန့်သတ် ကိန်းရှင်တန်ဖိုး 인덱스.
- 덧셈·뺄셈·곱셈·나눗셈·나머지·ဘစ်တန်ဖိုး 연산과 ရွှေ့တန်ဖိုး. Java의 오버플로 및 `MIN_VALUE / -1` 동작을 유지한다.
- `int[]` ထုတ်လုပ်·အစဦးတန်ဖိုး 0·အလျား·ဖတ်·ရေး·ကိုးကားချက် 비교. 256KiB 고정 အခင်းအကျင်းတန်ဖိုး နယ်ပယ်တန်ဖိုး, 널/အောက်ညွှန်း/အရွယ်/သတ်မှတ်လိပ်စာနယ် စစ်ဆေးချက်.
- အက္ခရာစဉ် 리터럴과 `String` ကိုးကားချက်, `length()` 및 `charAt()`. 문자열은 UTF-16 ကုဒ်တန်ဖိုး 단위로 저장하고 같은 리터럴은 공유한다. NUL 및 대리쌍도 시험한다.
- မြန်မာ အတန်းတန်ဖိုး·လုပ်ဆောင်ချက်·ကိန်းရှင်တန်ဖိုး·ဖိုင် အမည်.

`new Object`, 인스턴스 အကွက်တန်ဖိုး/လုပ်ဆောင်ချက်, 상속/인터페이스, `long/float/double` စက်မောင်း တွက်ချက်လုပ်ဆောင်မှု, `int[]` 이외 အခင်းအကျင်းတန်ဖိုး, အက္ခရာစဉ် 동적 ပေါင်းစပ်တန်ဖိုးများ, Java 표준 စာကြည့်တိုက်, ခြွင်းချက် လုပ်ငန်းစဉ်တန်ဖိုးအချက်, 스레드·တစ်ပြေးညီလုပ်·GC는 미지원이다. 실행에 필요한 미지원 바이트코드나 ပြင်ပတန်ဖိုး 호출을 발견하면 실패한다. 사용되지 않는 မူလသတ်မှတ်တန်ဖိုး 생성자는 စက်မောင်း 코드로 만들지 않는다. Java 8 문법이어도 모든 프로그램을 컴파일할 ကိန်းတန်ဖိုး 있다는 뜻은 아니다.

ခြွင်းချက် အရာဝတ္ထုတန်ဖိုး 대신 런타임 အမှား 번호로 중단한다. Linux와 jkoros သုံးစွဲသူ 대상에서는 `100 + နံပါတ်`로 종료하고 အူတိုင်တန်ဖိုး 대상에서는 `JKOROS PANIC နံပါတ်`를 출력하고 정지한다. သုံးစွဲသူ 프로그램만 종료한 경우 셸은 ဆက်လုပ်လုပ်ငန်းစဉ်ဆောင်ရွက်မှု 실행된다.

| နံပါတ် | 원인 |
| --- | --- |
| 1 | 0으로 စားလဒ် |
| 2 | 널 ကိုးကားချက် |
| 3 | အခင်းအကျင်းတန်ဖိုး/အက္ခရာစဉ် အောက်ညွှန်း ဖြတ်နယ်ပယ် 초과 |
| 4 | အနုတ်တန်ဖိုး အခင်းအကျင်းတန်ဖိုး အရွယ် |
| 5 | အခင်းအကျင်းတန်ဖိုး နယ်ပယ်တန်ဖိုး 부족 |

အခင်းအကျင်းတန်ဖိုး 영역은 증가식 할당이며 회수하지 않는다. 재귀 스택의 နယ်နိမိတ်တန်ဖိုး 검사도 아직 없으므로 무제한 재귀를 안전하게 처리하는 런타임은 아니다. 특권 အူတိုင်တန်ဖိုး 및 신뢰할 ကိန်းတန်ဖိုး 있는 작은 프로그램용 အစဦးအခြေအနေ 구현이다.

## native 경계와 ABI

အူတိုင်တန်ဖိုး 대상에서는 `os/မူရင်းကုဒ်/ကိရိယာ.java`, သုံးစွဲသူ 대상에서는 `os/သုံးစွဲသူ/ကြေညာချက်/သုံးစွဲသူ.java`의 정확한 နည်းလမ်းအမည်စာသား·서술만 허용한다. 임의의 `native` 함수와 Linux/သုံးစွဲသူ 대상의 စက်ပစ္စည်း 접근은 거부한다. Java 인수를 왼쪽부터 32비트 한 칸씩 스택에 놓으며, 반환값은 EAX, EBP/ESP 이외 레지스터는 호출자가 보존한다고 가정하지 않는다. C의 cdecl/JNI ABI가 아니므로 C 함수와 바로 연결하면 안 된다.

Java မူရင်းကုဒ် 또는 `.class` 입력을 받는다. 전체 JVM ဘိုက်ကုဒ် 검증기는 제공하지 않는다. 어노테이션 처리는 비활성화하고 비어 있는 အတန်းတန်ဖိုး လမ်း/မူရင်းကုဒ် 경로에서 명시한 소스만 컴파일한다.

## 검증과 အကောင်အထည်ဖော်မှု 근거

`စမ်းသပ်မှု/test_compiler.py`의 14개 시험에는 네이티브 ELF와 OpenJDK의 တွက်ချက်လုပ်ဆောင်မှု ရလဒ် 대조, အတန်းတန်ဖိုး အစပြင်ဆင်, ကိန်းပြည့် 극값, အက္ခရာစဉ်/အခင်းအကျင်းတန်ဖိုး, 재귀·switch·wide, 런타임 오류와 미지원 기능 တန်ဖိုးငြင်းပယ်, မအောင်မြင်မှု 시 အထွက် 보존, သုံးစွဲသူ ELF/ခွင့်ပြုချက်တန်ဖိုး နယ်နိမိတ်တန်ဖိုး 및 တန်ဖိုးထုတ်လွှတ် 검증이 포함된다. 이것은 Java 전체 적합성 시험은 아니다.

အမိန့် 의미와 အတန်းတန်ဖိုး ဖိုင် 형식은 Oracle의 [JVM အမိန့် သတ်မှတ်စံ](https://docs.oracle.com/javase/specs/jvms/se11/html/jvms-6.html), [အတန်းတန်ဖိုး ဖိုင် သတ်မှတ်စံ](https://docs.oracle.com/javase/specs/jvms/se11/html/jvms-4.html)를 참고했다.
