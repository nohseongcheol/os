# ကိုယ်ပိုင် 커널의 Python အထုပ် တန်ဖိုးတပ်ဆင်

ကိုယ်ပိုင် ARM64 커널의 `python`은 **MicroPython 1.24.1 ကိန်းပြည့် တည်ဆောက်**တတိယအော်ပရန်း.
`pip`와 `python -m pip`는 이 환경을 위한 제한형 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ တန်ဖိုးတပ်ဆင် 명령이다.
PyPA pip 전체나 CPython을 이식한 것은 아니다.

호스트에서 실행한다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
python3 ကိရိယာစု/စက်မောင်း.py --desktop --network --pip
```

게스트 셸에서 설치하고 사용한다.

```text
pip install micropython-bisect==3.3.3
pip list
python -c 'from bisect import insort as 순서대로넣기; တန်ဖိုး=[1,5]; 순서대로넣기(တန်ဖိုး,3); print(တန်ဖိုး)'
python -m pip list
pip uninstall micropython-bisect
```

ဖြစ်သောပုံမှန် စက်မောင်း 결과는 `[1, 3, 5]`တတိယအော်ပရန်း. 예시 ဖြန့်ချိမှုတန်ဖိုး 파일은
[PyPI의 micropython-bisect 3.3.3](https://pypi.org/project/micropython-bisect/3.3.3/)이며
SHA-256은 `b8d09d0bb4b2add706078dfa3f306e22fad1f4b5340b87d13f2c852507d720c8`이다.
`bisect`는 တန်ဖိုးတပ်ဆင် 전 내장되어 있지 않다. 내려받은 `.py`를 ကိုယ်ပိုင် 커널의 EL0
MicroPython이 import하여 실행한다.

## တန်ဖိုးတပ်ဆင် 경로와 역할

호스트의 [꾸러미중계.py](ကိရိယာစု/꾸러미중계.py)는 PyPI HTTPS 다운로드, 인증서 အတည်ပြု,
ဖြန့်ချိမှုတန်ဖိုး ဖိုင် SHA-256 검증과 မော်ကွန်းတန်ဖိုး 해제를 맡는다. 호스트에서 `setup.py`ဒုတိယတွက်ချက်ခံ 내려받은
Python 코드를 실행하지 않는다. အိမ်ရှင် pip 설치도 필요 없다.
중계는 `127.0.0.1:8027`에만 열리며 게스트는 QEMU NAT의 `10.0.2.2:8027`로 연결한다.
게스트 자체에 DNS·TLS·PyPI မော်ကွန်းတန်ဖိုး သိုလှောင်ရာလွှတ်ပေး 기능을 추가했다는 뜻은 아니다.

게스트의 [အထုပ်.py](Pythonတံတား/စာကြည့်တိုက်/အထုပ်.py)는 TCP로 받은 파일의 SHA-256과
လမ်း·အရွယ်·문법을 검사한 နောက်တန်ဖိုး `/lib`에 설치하고 `/lib/.pip.json`에 목록을 기록한다.
`/lib`와 စက်မောင်း အမိန့်စာတမ်းတန်ဖိုး 폴더를 မော်ဂျူးတန်ဖိုး 검색 경로에 추가했으므로 အလုပ် 폴더가 달라도
설치한 모듈을 import할 ကိန်းတန်ဖိုး 있다. 패키지 폴더와 တစ်ဖက်တန်ဖိုး import도 지원한다.

တန်ဖိုးတပ်ဆင် 도중 သတ်မှတ်လိပ်စာနယ် 부족 등 오류가 발생하면 새 파일과 폴더를 지우고 기존 목록을
복원한다. 이미 있는 သုံးစွဲသူ 파일을 덮어쓰지 않는다. 동일 버전 재설치 요청은
ဖိုင် 지문을 확인하고 유지한다. 다른 버전은 အချက်ဖယ်ရှား 후 설치한다. အချက်ဖယ်ရှား 시 사용자가
수정한 파일이 발견되면 보존하고 오류를 알린다. 빈 패키지 폴더는 남을 ကိန်းတန်ဖိုး 있다.

**`/lib`도 RAM 파일이다. 재부팅하면 설치한 패키지가 사라진다.**
အိမ်ရှင် `build/pip-cache`에는 ဖြန့်ချိမှုတန်ဖိုး 파일과 출처·지문이 남으므로 နောက်တစ်ခုအချက်အလက်တစ်ခု 부팅에서 ပြန်ကြိုးစား
설치할 ကိန်းတန်ဖိုး 있다. 버전을 지정하면 같은 ဖြန့်ချိမှုတန်ဖိုး 파일을 재사용한다.

```sh
# အိမ်ရှင်: 인터넷이 있을 때 ဖြန့်ချိမှုတန်ဖိုး 파일만 ပြင်ဆင်
python3 ကိရိယာစု/꾸러미중계.py --fetch micropython-bisect==3.3.3
# နောက်တစ်ခုအချက်အလက်တစ်ခု စက်မောင်း: PyPI ချိတ်ဆက် 없이 캐시 သုံးစွဲမှု
python3 ကိရိယာစု/စက်မောင်း.py --network --pip --pip-offline
```

다른 포트는 အိမ်ရှင် `--pip-port 8028`, 게스트
`pip install micropython-bisect==3.3.3 --port 8028`로 맞춘다.
အိမ်ရှင် 중계는 `python3 ကိရိယာစု/꾸러미중계.py --port 8027`로 별도 실행할 수도 있다.
QEMU를 종료하거나 중계 실행을 끝내면 이 서비스도 닫힌다.

## ထောက်ပံ့မှုတန်ဖိုး ဖြတ်နယ်ပယ်

- 의존성 없는 순수 Python wheel(`*-none-any.whl`, `Root-Is-Purelib: true`).
- 구형 `micropython-*` မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 배포형의 `.py`와 `PKG-INFO`.
- 꾸러미당 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 16개, အကုန်စုစုပေါင်းတန်ဖိုး 64 KiB, 파일당 16 KiB, 절대 လမ်း UTF-8 63바이트 이하.
  전체 RAM ဖိုင် 64개·ဖိုင်တွဲတန်ဖိုး 16개의 남은 공간과 Python ပုံတင်မှတ်ဉာဏ်တန်ဖိုး 256 KiB 한도도 적용된다.
- `install`, `list`, `uninstall`, `--help`, `--version`.
- SHA-256, JSON, မှတ်ဉာဏ်ဒေတာ `io.StringIO`/`BytesIO`를 실행기에 추가했다.
  일반 ဖိုင် အရာဝတ္ထုတန်ဖိုး `open()`은 미지원이며 `မြန်မာ.ဖိုင်ဖတ်/ဖိုင်ရေး` 또는
  `jkoros.read/write`를 사용한다.

C တိုးချဲ့မှု·플랫폼 전용 wheel, 일반 sdist တည်ဆောက်, 자동 의존성 해결, extras, VCS/임의 URL,
NumPy 같은 CPython 전용 패키지는 지원하지 않는다. 순수 Python 패키지도
MicroPython의 문법·표준 မော်ဂျူးတန်ဖိုး·ကိန်းပြည့် 전용 환경과 맞아야 실제로 실행할 ကိန်းတန်ဖိုး 있다.
တန်ဖိုးတပ်ဆင် 시 문법을 검사하지만 모든 စက်မောင်း 경로의 호환성을 증명하지는 않는다.
တကယ့်ဒေတာ Raspberry Pi 4의 LAN을 통한 설치는 검증하지 않았으며 လက်ရှိအချက်အလက်တစ်ခု 중계는 QEMU용이다.

MicroPython 자체의 패키지 체계와 CPython pip의 차이는
[MicroPython 패키지 စာတမ်း](https://docs.micropython.org/en/v1.24.0/reference/packages.html),
wheel 형식은 [PyPA ဖြန့်ချိမှုတန်ဖိုး ပုံစံတန်ဖိုး 규격](https://packaging.python.org/en/latest/specifications/binary-distribution-format/)을 참고한다.

```sh
make test-pip
```

မှန်ကန်ကြောင်းစစ် 기록은 `build/verification/pip/report.json`과 `serial.log`에 저장한다.
တကယ့်ဒေတာ PyPI အထုပ် 시험과 별도로 시험용 wheel로 패키지 ဖိုင်တွဲတန်ဖိုး, 구문 အမှား,
သတ်မှတ်လိပ်စာနယ် 부족 되돌림을 확인한다.
