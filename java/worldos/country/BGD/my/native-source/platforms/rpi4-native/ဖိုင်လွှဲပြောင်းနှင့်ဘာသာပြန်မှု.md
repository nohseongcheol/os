# ကိုယ်ပိုင် ARM64 အူတိုင်တန်ဖိုး: FTP, C, JAR와 AOT စက်မောင်း

대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT အူတိုင်တန်ဖိုး**이다. CPU·ကိရိယာ 경계는 C/어셈블리, ဖိုင် 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 အိမ်ရှင် JVM으로 대신 실행하지 않는다.

## 먼저 알아둘 ထောက်ပံ့မှုတန်ဖိုး နယ်နိမိတ်တန်ဖိုး

| တောင်းဆိုချက် | 이번 အကောင်အထည်ဖော်မှု | 남은 ဖြတ်နယ်ပယ် |
|---|---|---|
| JAR를 စက်မောင်း 파일처럼 စက်မောင်း | `java -jar ဖိုင်.jar`, `./ဖိုင်.jar အချက်များ`; Main-Class와 သိုလှောင်တန်ဖိုး/DEFLATE ZIP, CRC စစ်ဆေးချက် | 전체 Java SE, 임의의 모든 JAR 호환성 |
| 게스트 AOT | `jaot ဖိုင်.class -o ဖိုင်.elf`, `jaot ဖိုင်.jar -o ဖိုင်.elf`; တကယ့်ဒေတာ ARM64 기계어 ထုတ်လုပ် | အရာဝတ္ထုတန်ဖိုး·ခြွင်းချက်·Thread·Swing·Socket의 AOT တန်ဖိုးပြောင်းလဲ, 여러 애플리케이션 အတန်းတန်ဖိုး ချိတ်ဆက် |
| C မူရင်းကုဒ်ဘာသာပြန် | 게스트 `cc`/`tcc`, TinyCC C 전처리기·ARM64 생성기·링커; မြန်မာ 식별자와 posix-kor | 전체 libc, 일반 Linux စက်မောင်း ဖိုင်, 게스트 C++ ဘာသာပြန်စက် |
| 업로드한 ELF စက်မောင်း | ELF64/AArch64 헤더 စစ်ဆေးချက်, 확장자 없는 `./ဖိုင်`; ကိုယ်ပိုင် ABI 및 명시적인 제한형 Linux ABI | 일반 Linux 바이너리 호환, 동적 링커, 공유 စာကြည့်တိုက် |
| ပြင်ပတန်ဖိုး TCP/UDP | 게스트 lwIP IPv4 တွက်ချက်ခံထပ်ဆင့်အစု, POSIX 소켓과 JVM의 ဂဏန်းတန်ဖိုး IPv4 လိပ်စာ | GENET/Wi-Fi 드라이버, DHCP·DNS·TLS, ရုပ်ပိုင်းစက်ပစ္စည်း ဆားကစ်ပြား ကွန်ရက်ဆက် စမ်းသပ်မှု |
| FTP | 게스트 서비스, 패시브 လွှဲပြောင်းတန်ဖိုး, UTF-8 အမည်, STOR/RETR/SIZE/LIST/NLST/MLSD/DELE | TLS·사용자별 ခွင့်ပြုချက်တန်ဖိုး·하위 디렉터리·영속 သိုလှောင်တန်ဖိုး |
| ဟန်ဂုစာသား Java | 기존 `မြန်မာ.ကိုယ်ပိုင်` 클래스와 ပြင်ပတန်ဖိုး လိပ်စာ UDP 오버로드 | 전체 JDK의 일대일 မြန်မာ ချိတ်ဆက်ပုံတန်ဖိုး API |

JVM은 အတန်းတန်ဖိုး 버전 45…52의 문서화한 부분집합이다. `java`는 ဘိုက်ကုဒ် 실행기이고, `jaot`ပထမတွက်ချက်ခံ 별도의 네이티브 စက်မောင်း 파일을 만든다. **JAR မော်ကွန်းတန်ဖိုး 해제나 JVM을 함께 묶는 것을 AOT라고 표시하지 않는다.** 지원하지 않는 ဘိုက်ကုဒ်/API는 `jaot`ပထမတွက်ချက်ခံ 진단하고 출력을 만들지 않는다. 기존 အထွက် ELF도 မူရင်းကုဒ်ဘာသာပြန် မအောင်မြင်မှု 때 보존한다.

Android의 Dalvik/ART는 일반 JVM အတန်းတန်ဖိုး/JAR가 아닌 **DEX**를 실행한다. ART의 AOT에는 GC, အတန်းတန်ဖိုး 로딩, JNI 등 စက်မောင်း 기반도 필요하다. 따라서 ART처럼 기계어로 바꾸는 기능만으로 임의의 OpenJDK JAR 및 Swing이 자동 호환되지는 않는다. [Android 공식 런타임 ရှင်းလင်းချက်](https://source.android.com/docs/core/runtime)

## လက်ရှိအချက်အလက်တစ်ခု 컴퓨터에서 FTP ချိတ်ဆက်မှု

အိမ်ရှင် အဆုံးသုံးမျက်နှာပြင် 1:

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
python3 ကိရိယာစု/စက်မောင်း.py --network
```

Remmina GUI에서도 같은 네트워크를 사용하려면 စက်မောင်း 명령을
`python3 ကိရိယာစု/စက်မောင်း.py --desktop --network`로 바꾸고 VNC `127.0.0.1:5902`에
접속한다. FTP와 네트워크는 같은 게스트 안에서 동작한다.

부팅한 **jkoros အမိန့်ဝင်း**:

```text
ftpd start
```

အိမ်ရှင် အဆုံးသုံးမျက်နှာပြင် 2:

제공한 예제로 작은 စက်မောင်း JAR를 먼저 만든다. မြန်မာ 라이브러리는 게스트에 내장되어 있어 이 ဥပမာ JAR에 중복해서 넣지 않는다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
mkdir -p build/upload
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/upload ဥပမာ/ဖြန့်ချိမှုတန်ဖိုး/အလင်း.java
jar cfe build/upload/နှုတ်ဆက်.jar အလင်း -C build/upload အလင်း.class
```

```sh
python3 - <<'PY'
from ftplib import FTP
ftp = FTP()
ftp.encoding = 'utf-8'
ftp.connect('127.0.0.1', 2121)
ftp.login()                         # anonymous; jkoros도 같은 အလုပ် သတ်မှတ်လိပ်စာနယ်
with open('build/upload/နှုတ်ဆက်.jar', 'rb') as f:
    ftp.storbinary('STOR နှုတ်ဆက်.jar', f)
print(ftp.nlst())
ftp.quit()
PY
```

ပြန်ကြိုးစား **jkoros အမိန့်ဝင်း**:

```text
java -jar /နှုတ်ဆက်.jar
/နှုတ်ဆက်.jar
ftpd status
ftpd stop
```

FTP는 루트 RAM 파일만 공개한다. 익명 로그인이며 비밀번호로 권한을 구분하지 않는다. မူလသတ်မှတ်တန်ဖိုး အိမ်ရှင် 바인딩은 `127.0.0.1`이고, ထိန်းချုပ်တန်ဖိုး 포트는 2121, 데이터 포트는 50000…50007이다. `--ftp-port 2122`로 ထိန်းချုပ်တန်ဖိုး 포트를 바꿀 ကိန်းတန်ဖိုး 있다. 동시에 한 FTP 세션을 제공하며 명령이 없는 세션은 60초 후 닫는다. TYPE A도 바이트를 변경하지 않으므로 프로그램은 바이너리 전송한다.

파일은 **64개, 각각 16 KiB**, 경로는 UTF-8 63바이트이다. စက်တင် 시 준비되는 `/example`도 이 한도를 공유한다. 초과/끊어진 STOR는 기존 파일에 반영하지 않는다. FTP 업로드는 RAM에만 저장되며 재부팅하면 사라진다. 이 ကန့်သတ်ချက်တန်ဖိုး 때문에 일반적인 대형 JAR 배포판을 그대로 올릴 ကိန်းတန်ဖိုး 없다.

QEMU의 raspi4b에는 GENET Ethernet 장치가 없다. 따라서 `network_bridge.py`ပထမတွက်ချက်ခံ QEMU NAT의 Ethernet과 보조 UART의 SLIP를 변환한다. **TCP ချိတ်ဆက် လုပ်ငန်းစဉ်တန်ဖိုးအချက်·체크섬·재전송·FTP 명령과 ဖိုင် 저장은 게스트 안에서 수행한다.** အိမ်ရှင် 브리지는 FTP 서버가 아니다. [QEMU 공식 ကိရိယာ ထောက်ပံ့မှုတန်ဖိုး အချက်စာရင်း](https://www.qemu.org/docs/master/system/arm/raspi.html)

이 경로는 QEMU에서 검증했다. 보조 UART의 တကယ့်ဒေတာ Pi 4 핀/클럭 설정과 내장 RJ45 GENET 드라이버는 အကောင်အထည်ဖော်မှု·검증하지 않았으므로, SD 이미지에 커널이 포함되어 있다는 사실을 တကယ့်ဒေတာ 보드의 LAN/FTP လှုပ်ရှားမှု 보장으로 해석하면 안 된다.

## မြန်မာ Java를 게스트에서 컴파일하고 AOT စက်မောင်း

게스트 `vi အလင်း.java`로 နောက်တစ်ခုအချက်အလက်တစ်ခု 소스를 작성한다.

```java
public class အလင်း {
    public static void main(String[] အချက်များ) throws Exception {
        int စုစုပေါင်းတန်ဖိုး = 0;
        int ကိန်းတန်ဖိုး = 1;
        while (ကိန်းတန်ဖိုး <= 10) {
            စုစုပေါင်းတန်ဖိုး = စုစုပေါင်းတန်ဖိုး + ကိန်းတန်ဖိုး;
            ကိန်းတန်ဖိုး = ကိန်းတန်ဖိုး + 1;
        }
        မြန်မာ.ကိုယ်ပိုင်.အထွက်.ကိန်းထုတ်(စုစုပေါင်းတန်ဖိုး);
        မြန်မာ.ကိုယ်ပိုင်.ဖိုင်.ရေး("aot.txt", "ဟန်ဂုစာသား AOT ဖိုင် 😀");
        မြန်မာ.ကိုယ်ပိုင်.အထွက်.စာကြောင်းထုတ်(မြန်မာ.ကိုယ်ပိုင်.ဖိုင်.ဖတ်("aot.txt"));
    }
}
```

```text
javac အလင်း.java
java အလင်း
jaot အလင်း.class -o အလင်း.elf
run အလင်း.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**ပထမတွက်ချက်ခံ ARM64 명령어를 ထုတ်လုပ်·연결한다. စက်မောင်း 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 ထောက်ပံ့မှုတန်ဖိုး 범위이면 다음도 가능하다.

```text
jaot အလင်း.jar -o အလင်း.elf
run အလင်း.elf
```

AOT 지원은 한 애플리케이션 클래스의 တည်ငြိမ်တန်ဖိုး နည်းလမ်းတန်ဖိုး/အကွက်တန်ဖိုး, int 계열, ကိန်းပြည့် 배열과 ကိုးကားချက်, အချက်များ အခင်းအကျင်းတန်ဖိုး, အခြေအနေစည်းကမ်း·အခွဲ·반복, အက္ခရာစဉ် 리터럴, `System.out.print/println`의 int/String, မြန်မာ အထွက်·ဖိုင် ဖတ်/쓰기로 제한된다. အတန်းတန်ဖိုး/နည်းလမ်းတန်ဖိုး 수와 တွက်ချက်ခံထပ်ဆင့်အစု 등에도 고정 상한이 있다. Java ခြွင်းချက် လုပ်ငန်းစဉ်တန်ဖိုးအချက်, အရာဝတ္ထုတန်ဖိုး ထုတ်လုပ်, 가상 နည်းလမ်းတန်ဖိုး 일반, switch/wide, long/float/double, invokedynamic, အက္ခရာစဉ် 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 အခင်းအကျင်းတန်ဖိုး ဝင်သုံးအချက်/0으로 စားတန်ဖိုးများ 등은 네이티브 런타임 오류로 종료하며 Java ခြွင်းချက် 객체로 전달하지 않는다.

ဝင်ဒေတာ 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 ညှိတန်ဖိုး 때문에 짧은 클래스도 이 한도를 넘을 ကိန်းတန်ဖိုး 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 အရာဝတ္ထုတန်ဖိုး·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 ထောက်ပံ့မှုတန်ဖိုး ဖြတ်နယ်ပယ် 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](Javaလည်ပတ်ဝန်းကျင်.md)과 [ဟန်ဂုစာသား ဖွံ့ဖြိုးရေး 매뉴얼](ဖွံ့ဖြိုးရေးလမ်းညွှန်.md)을 참고한다.

JAR는 하나의 애플리케이션 အတန်းတန်ဖိုး 경로다. 내부 အမည် `အထုပ်/ပရိုဂရမ်.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 မြန်မာ 클래스를 추가로 찾지만 လက်ရှိအချက်အလက်တစ်ခု အလုပ် 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·암호화 ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 ကိန်းတန်ဖိုး/VM ပုံတင်မှတ်ဉာဏ်တန်ဖိုး 제한은 그대로 적용된다.

## C에서 မြန်မာ POSIX ခေါ်လုပ်

게스트에서 `vi နှုတ်ဆက်.c`로 작성하거나 FTP로 소스를 업로드한다.

```c
#include <파일규약.h>

int main(void) {
    const char နှုတ်ဆက်စကား[] = "ကိုယ်ပိုင် ARM64 C에서 ဟန်ဂုစာသား POSIX ခေါ်လုပ်\n";
    int စာတမ်း = ဖိုင်ဖွင့်("နှုတ်ဆက်.txt", ဖတ်ရေး | 없으면만들기 | 내용비우기, 0600);
    if (စာတမ်း < 0) return 1;
    အဝင်အထွက်ရလဒ်အမျိုးပုံစံ 기록한수 = ဖိုင်ဒေတာရေး(စာတမ်း, နှုတ်ဆက်စကား, sizeof(နှုတ်ဆက်စကား) - 1);
    ဖိုင်ပိတ်(စာတမ်း);
    ဖိုင်ဒေတာရေး(1, နှုတ်ဆက်စကား, sizeof(နှုတ်ဆက်စကား) - 1);
    return 기록한수 == sizeof(နှုတ်ဆက်စကား) - 1 ? 0 : 2;
}
```

```text
cc နှုတ်ဆက်.c -o နှုတ်ဆက်.elf
run နှုတ်ဆက်.elf
cat နှုတ်ဆက်.txt
```

TinyCC의 표준 C အချက်အမှတ်တစ်ခု `main`을 사용한다. 기존 အိမ်ရှင် C/C++ SDK의 `သုံးစွဲသူပရိုဂရမ်စတင်(int)` 진입점과 구분한다. ခေါင်းစီးဖိုင် ဖိုင်·လုပ်ဆောင် အရာဝတ္ထုတန်ဖိုး·`libposix-kor-user.a`는 ဘာသာပြန်စက် 내부의 ဖတ် 전용 SDK에 들어 있다. C 전처리기/구조체/လုပ်ဆောင်ချက်/재귀/ညွှန်တံ/부동소수점 ထုတ်လုပ် 등을 사용하되 **일반 libc/libstdc++를 제공한다는 뜻은 아니다**. 제공하지 않는 함수는 ချိတ်ဆက် 오류가 난다. ဘာသာပြန်စက် 자체의 အက္ခရာ/ဂဏန်းတန်ဖိုး တန်ဖိုးပြောင်းလဲ 지원도 완전한 libc 대체품이 아니다.

`ဖိုင်ဖွင့်` 등은 별도의 모의 호출이 아닌 기존 `pk_open` 등의 မြန်မာ 매크로이며, ELF의 SVC를 통해 တကယ့်ဒေတာ Java ဖိုင် 체계에 도달한다. ဖိုင်/ကွန်ရက်ပေါက်တန်ဖိုး ခေါ်လုပ် 목록은 [သုံးစွဲသူ ABI](사용자호출규약.md)에 있다. C/C++ အိမ်ရှင် SDK စက်မောင်း 파일도 FTP로 업로드 후 `run` 또는 `./ဖိုင်`로 실행하며 확장자는 필요 없다. Linux ARM64 တည်ငြိမ်တန်ဖိုး ELF에는 별도의 제한된 호환 လမ်း `run --linux ဖိုင်`을 추가했다. [ELF·Linux ABI 매뉴얼](실행파일규약.md)에 정확한 ပုံစံတန်ဖိုး·시스템 ခေါ်လုပ်·လိပ်စာ 제한을 정리했다.

## မြန်မာ ကွန်ရက်ဆက်·အလုပ်·မျက်နှာပြင် API

| အတန်းတန်ဖိုး | ခေါ်လုပ် 예 | စက်မောင်း လမ်း |
|---|---|---|
| `အထွက်` | `စာကြောင်းထုတ်("안녕")`, `ကိန်းထုတ်(42)` | JVM 및 제한형 AOT |
| `ဖိုင်` | `ရေး("စာတမ်း.txt", "အကြောင်းအရာတန်ဖိုး")`, `ဖတ်("စာတမ်း.txt")` | JVM 및 제한형 AOT |
| `ဆက်သွယ်မှု` | `ဖွင့်(0)`, `ပို့(ဆုံးမှတ်, "10.0.2.2", 9000, "ဟန်ဂုစာသား")`, `လက်ခံ(ဆုံးမှတ်)` | JVM의 UDP |
| `ချိတ်ဆက်သယ်ပို့` | `ချိတ်ဆက်("10.0.2.2", 9000)`, `အဆုံးမှတ်နားထောင်(9000)`, `လက်ခံ(ဝန်ဆောင်စက်တန်ဖိုး)` | JVM의 Socket/ServerSocket |
| `အလုပ်` | `လုပ်ဆောင်(Runnable)`, `စောင့်(Thread)`, `အလုပ်အလှည့်ပေး()` | JVM의 협력식 အလုပ်ကြိုးတန်ဖိုး |
| `ဝင်း`, `မြင်ကွင်းအစိတ်အပိုင်း` | ဝင်း·버튼·အက္ခရာတန်ဖိုး·စာသားအကွက်·ဖြစ်ရပ် ချိတ်ဆက် | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 မြန်မာ ခေါ်လုပ် 계층을 추가한다. `ဆက်သွယ်မှု(通信)`, `ချိတ်ဆက်(連結)`, `အထွက်(出力)`은 기존 단어의 뜻을 사용한다. `အလုပ် အလုပ်ကြိုးတန်ဖိုး`은 한 စက်မောင်း 흐름을 가닥에 빗댄 အညွှန်းတန်ဖိုး 표현, `ဆက်သွယ်ပေါက်တန်ဖိုး`는 포트의 접점을 설명하는 표현이다. 새 အညွှန်းတန်ဖိုး 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

ပြင်ပတန်ဖိုး 주소는 ဂဏန်းတန်ဖိုး IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`တတိယအော်ပရန်း. UDP 전문은 512바이트까지다. 소켓은 비차단 ကိုယ်ပိုင် ABI이며 JVM이 제한된 တန်ဖိုးစောင့်/재시도를 제공한다. TCP connect 대기는 အများဆုံးတန်ဖိုး 1초, သုံးစွဲသူ ပရိုဂရမ် 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 စက်မောင်း သုံးစွဲသူ 서버와 pthread는 아직 없다. FTP는 သုံးစွဲသူ ပရိုဂရမ် 기한과 별개인 အူတိုင်တန်ဖိုး 서비스다.

게스트의 သုံးစွဲသူ TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 ကိရိယာစု/စက်မောင်း.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 မူလသတ်မှတ်တန်ဖိုး ထိန်းချုပ်တန်ဖိုး/데이터 포트와 겹치면 စက်မောင်း 전에 거부한다.

## 시험과 တည်ဆောက် 재현

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test-ftp
make test
make image
```

`build/verification/ftp/report.json`은 တကယ့်ဒေတာ FTP လွှဲပြောင်းတန်ဖိုး, ဟန်ဂုစာသား ဖိုင်, အရွယ် 초과 보존, မော်ကွန်းတန်ဖိုး JAR စက်မောင်း, 게스트 C မူရင်းကုဒ်ဘာသာပြန်/ELF 재업로드, ပြင်ပတန်ဖိုး Java TCP/UDP, 게스트 javac/AOT 실행을 기록한다. `serial.log`에서 게스트 명령과 결과를 확인할 ကိန်းတန်ဖိုး 있다. 보고서의 အူတိုင်တန်ဖိုး SHA-256과 ဖြန့်ချိမှုတန်ဖိုး 이미지의 커널을 비교한다.

빌드는 기존 JDK/Clang/AArch64 binutils와 함께 `../rpi4/build/rootfs`의 ARM64 SDK ကြေညာချက် 헤더와 libgcc ဂဏန်းသင်္ချာတန်ဖိုး 보조 함수를 사용한다(`make rpi-prepare`). **musl libc, Linux အူတိုင်တန်ဖိုး, 동적 로더를 게스트에 링크하지 않는다.** TinyCC/lwIP/uzlib 원본과 라이선스·버전 정보는 `vendor/`, 이식 코드는 `ccompiler/`, `network/`, `သုံးစွဲသူ/အထုပ်.c`에 있다.

전체 JDK/AOT JVM으로 확장하려면 타입 မှန်ကန်ကြောင်းစစ်·အရာဝတ္ထုတန်ဖိုး/ခြွင်းချက်/GC·동적 로딩·JNI, 영속 ဖိုင် လည်ပတ်မှုစနစ်တန်ဖိုး·mmap/TLS/시그널·스레드 ABI, OpenJDK native စာကြည့်တိုက်, GUI peer/폰트/입력기, GENET 및 ရုပ်ပိုင်းစက်ပစ္စည်း ကိရိယာ 검증이 더 필요하다. 이 문서의 စက်မောင်း 시험은 그 전체 이식을 대신하지 않는다.
