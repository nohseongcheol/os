# ကိုယ်ပိုင် 커널에서 vi·여러 အဆုံးသုံးမျက်နှာပြင်·ဟန်ဂုစာသား 프로그래밍 사용하기

မြန်မာ ဆက်သွယ်မှု·ခြွင်းချက် 사용법은 [မြန်မာ Java API](မြန်မာJava/လမ်းညွှန်.md), လုပ်ဆောင်ချက်·ကိန်းရှင်တန်ဖိုး·ဖိုင် 이름의 변경과 어원 근거는 [명명 လမ်းညွှန်](명명/လမ်းညွှန်.md)를 참고한다.

대상은 `platforms/rpi4-native`의 ကိုယ်ပိုင် AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 အောက်ဆုံးတန်ဖိုး ထောက်ပံ့မှုတန်ဖိုး 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 စက်မောင်း, ပြင်ပတန်ဖိုး TCP/UDP와 FTP는 [새 စက်မောင်း 매뉴얼](ဖိုင်လွှဲပြောင်းနှင့်ဘာသာပြန်မှု.md)을 참고한다.

## GUI와 여러 အဆုံးသုံးမျက်နှာပြင်

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, လိပ်စာ **127.0.0.1:5902**로 연결한다. မျက်နှာပြင် ထိပ်တန်ဖိုး **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. အများဆုံးတန်ဖိုး 네 개다. အပေါ်ဘက် အဆုံးသုံးမျက်နှာပြင် 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **ညာ ထိပ်တန်ဖိုး X**를 클릭하면 닫힌다. နောက်ဆုံးအချက်အလက်တစ်ခု 창을 닫아도 အပေါ်ဘက် စက်မောင်း 버튼으로 ပြန်ကြိုးစား ကော်လံတန်ဖိုး ကိန်းတန်ဖိုး 있다. 기존 `terminal`, `exit`, F12도 사용할 ကိန်းတန်ဖိုး 있다.

창마다 လက်ရှိအချက်အလက်တစ်ခု 디렉터리, အမိန့်ဝင်း ကိန်းရှင်တန်ဖိုး, အမိန့် မှတ်တမ်းမှတ်တမ်းတစ်ခု, ဝင်ဒေတာ 중인 명령과 ပရိုဂရမ် စက်မောင်း 상태를 보관한다. ဖိုင် 저장소는 공유한다. vi와 Swing의 이벤트 တန်ဖိုးစောင့် 중에 다른 터미널로 전환하면 သုံးစွဲသူ မှတ်ဉာဏ်ဒေတာ·레지스터·ဖိုင်/ကွန်ရက်ပေါက်တန်ဖိုး 연결을 보존했다가 돌아올 때 재개한다. **လက်ရှိအချက်အလက်တစ်ခု 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** တွက်ချက်မှု 중인 프로그램은 နောက်တစ်ခုအချက်အလက်တစ်ခု ဝင်ဒေတာ တန်ဖိုးစောင့် 또는 기존 စက်မောင်း 기한까지 전환이 지연될 ကိန်းတန်ဖိုး 있다.

X로 터미널을 닫으면 그 터미널의 စက်မောင်း 중인 프로그램도 종료하며 အညွှန်း·소켓을 회수한다. 저장하지 않은 တည်းဖြတ်တန်ဖိုး 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. လက်ရှိအချက်အလက်တစ်ခု 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 ဝင်း 판단은 게스트 커널이 처리한다. QEMU စက်မောင်း 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. တကယ့်ဒေတာ Pi4 USB 입력기와 ရုပ်ပိုင်းစက်ပစ္စည်း 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI ကိရိယာစု 종료는 အိမ်ရှင် 터미널의 Ctrl+C다.

## vi သုံးစွဲမှု

```text
mkdir အလုပ်
cd အလုပ်
vi နှုတ်ဆက်.py
```

`vi`는 새로 구현한 **vi အမိန့် 부분집합** 편집기다. 내장 `build/user/vi.elf`를 보호된 သုံးစွဲသူ 영역에 적재한다. ဖိုင် 크기는 UTF-8 ဘိုက်တန်ဖိုး စီမံကိန်းအမြစ် 16 KiB, 경로는 63바이트까지다. 디스크에 설치한 Vim/Neovim 바이너리를 실행하는 것이 아니다.

| သော့တန်ဖိုး/အမိန့် | လှုပ်ရှားမှု |
|---|---|
| `i`, `a`, `I`, `A` | လက်ရှိအချက်အလက်တစ်ခု/နောက်တစ်ခုအချက်အလက်တစ်ခု နေရာ 또는 စာကြောင်း အစဦးအချက်အလက်တစ်ခု/끝에서 ဝင်ဒေတာ |
| `o`, `O` | အောက်ဆုံးတန်ဖိုး/위에 새 줄을 만들고 ဝင်ဒေတာ |
| Esc | 일반 နည်းစနစ်တန်ဖိုး |
| `h j k l`, 방향키 | UTF-8 အက္ခရာ/စာကြောင်း ရွှေ့တန်ဖိုး |
| `0`, `$`, Home, End | စာကြောင်း အစဦးအချက်အလက်တစ်ခု/အဆုံး |
| `gg`, `G`, `:နံပါတ်` | ဖိုင် အစဦးအချက်အလက်တစ်ခု/နောက်ဆုံးအချက်အလက်တစ်ခု စာကြောင်း/သတ်မှတ်ပေးတန်ဖိုး စာကြောင်း |
| PgUp, PgDn | မျက်နှာပြင် ယူနစ်တန်ဖိုး ရွှေ့တန်ဖိုး |
| `x`, Delete | လက်ရှိအချက်အလက်တစ်ခု အက္ခရာ 삭제 |
| `dd`, `yy`, `p` | စာကြောင်း 삭제/တန်ဖိုးမိတ္တူကူး/စာသားကူးထည့် |
| `u` | နောက်ဆုံးအချက်အလက်တစ်ခု 편집을 ပြန်ပေးတံတား; 한 အဆင့်ကာလတန်ဖိုး 토글 |
| `/အက္ခရာစဉ်`, `n` | 단순 အက္ခရာစဉ် 검색/နောက်တစ်ခုအချက်အလက်တစ်ခု ဖြစ်သောညီ; 정규식 없음 |
| `:w`, `:w 다른이름` | RAM ဖိုင် သိုလှောင်တန်ဖိုး/다른 경로로 သိုလှောင်တန်ဖိုး |
| `:q` | 변경이 없을 때 ထွက်ပရိုဂရမ် |
| `:q!` | 변경을 버리고 ထွက်ပရိုဂရမ် |
| `:wq`, `ZZ` | 저장하고 ထွက်ပရိုဂရမ် |

붙여 넣은 한글을 အက္ခရာ 경계에 맞춰 ရွှေ့တန်ဖိုး·삭제한다. 일반 vi의 수량 접두사, 매크로, သတ်မှတ်ချက် ဖိုင်, 플러그인, 정규식, 여러 버퍼/분할 ဝင်း, 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/သုညတွက်ချက်ခံ 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 ဝင်း ဝင်းခေါင်းစဉ် `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 အမိန့်**으로 실행한다. 파이프·리다이렉션·အမိန့်စာတမ်းတန်ဖိုး·`;`/`&&`/`||`로 연결한 실행에서 အပြန်အလှန် 대기를 시작하면 거부한다. ဝင်ဒေတာ 대기는 약 2초 CPU 기한을 갱신하지만 ဝင်ဒေတာ တန်ဖိုးစောင့် 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## ဟန်ဂုစာသား Java

vi에서 다음을 `နှုတ်ဆက်.java`에 입력하고 Esc → `:wq`로 저장한다.

```java
public class နှုတ်ဆက် {
    static int တန်ဖိုးများထည့်(int ပထမအစဉ်, int ဒုတိယအစဉ်) { return ပထမအစဉ် + ဒုတိယအစဉ်; }
    public static void main(String[] အချက်များ) {
        int အကုန်စုစုပေါင်းတန်ဖိုး = တန်ဖိုးများထည့်(20, 22);
        System.out.println("안녕하세요 · အကုန်စုစုပေါင်းတန်ဖိုး=" + အကုန်စုစုပေါင်းတန်ဖိုး);
    }
}
```

게스트 셸에서 실행한다.

```text
javac နှုတ်ဆက်.java
java နှုတ်ဆက်
```

ဟန်ဂုစာသား ဖိုင်အမည်စာသား·Javaအတန်းအမည်·နည်းလမ်းအမည်စာသား·변수명·문자열을 사용할 ကိန်းတန်ဖိုး 있다. **게스트 javac는 တည်ငြိမ်တန်ဖိုး Java 부분집합**이다. အရာဝတ္ထုတန်ဖိုး·리스너·Swing·소켓을 사용하는 소스는 လက်ရှိအချက်အလက်တစ်ခု အိမ်ရှင် JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 ကိုယ်ပိုင် JVM에 class를 올린다. ကိုယ်ပိုင် JVM에서 지원하는 ဘိုက်ကုဒ်/API 범위는 [Javaလည်ပတ်ဝန်းကျင်.md](Javaလည်ပတ်ဝန်းကျင်.md)를 따른다.

```sh
# အိမ်ရှင်
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java စမ်းသပ်မှု/Java/Swingစမ်းသပ်.java
python3 ကိရိယာစု/ဖိုင်တင်.py build/my-java/Swingစမ်းသပ်.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. အထွက် 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java Swingစမ်းသပ်`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.အတန်းတန်ဖိုး.class` 형식이다. 내장 မြန်မာ 라이브러리는 별도 업로드가 필요 없다. မြန်မာ ဝင်း API의 예제는 [ဟန်ဂုဝင်းစမ်းသပ်.java](စမ်းသပ်မှု/Java/ဟန်ဂုဝင်းစမ်းသပ်.java)이며 같은 방법으로 မူရင်းကုဒ်ဘာသာပြန်·업로드해 `java ဟန်ဂုဝင်းစမ်းသပ်`으로 실행한다.

GUI가 필요 없는 단일 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ/클래스는 호스트의 `python3 ကိရိယာစု/ဖိုင်လုပ်ဆောင်.py လမ်း/နှုတ်ဆက်.java`로 별도 QEMU에 업로드·စက်မောင်း·종료할 ကိန်းတန်ဖိုး 있다. အပြန်အလှန် Swing에는 စက်မောင်း 후 သုံးစွဲသူ 입력을 유지하는 `make desktop`을 사용한다.

## ကိုယ်ပိုင် JVM의 Swing ဖြတ်နယ်ပယ်

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 ကိုယ်ပိုင် Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | လှုပ်ရှားမှု |
|---|---|
| `JFrame` | ဝင်းခေါင်းစဉ်, အရွယ်·နေရာ, ပြသ, ပိတ် 정책, dispose |
| `JPanel` | သားသမီးတန်ဖိုး 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 အက္ခရာစဉ် တန်ဖိုးပြသ·တန်ဖိုးပြောင်း |
| `JButton` | 버튼과 ActionListener 클릭 လုပ်ငန်းစဉ်တန်ဖိုးအချက် |
| `JTextField` | 한 စာကြောင်း UTF-8 ဝင်ဒေတာ, 삭제, getText/setText, Enter 이벤트 |
| အများသုံးတန်ဖိုး | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 အက္ခရာ 조판은 아직 없다. 이벤트 콜백은 ကိုယ်ပိုင် JVM의 단일 이벤트 စက်မောင်း 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. ဝင်း·요소는 စက်မောင်း 하나당 အကုန်စုစုပေါင်းတန်ဖိုး 32개, အင်္ဂါရပ်တန်ဖိုး 글자는 အများဆုံးတန်ဖိုး 127 코드포인트다. မူလသတ်မှတ်တန်ဖိုး 서체와 색은 커널이 제공한다.

[Swingစမ်းသပ်.java](စမ်းသပ်မှု/Java/Swingစမ်းသပ်.java)는 ဝင်း·ဟန်ဂုစာသား တံဆိပ်တန်ဖိုး·စာသားအကွက်·버튼·이벤트 처리의 စက်မောင်း 가능한 예제다. [ကိုယ်ပိုင် Swing မျက်နှာပြင်](build/verification/swing/native-swing.png)을 참고한다.

မြန်မာ 라이브러리에는 다음을 추가했다. အိမ်ရှင် မူရင်းကုဒ်ဘာသာပြန် 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `မြန်မာ.ကိုယ်ပိုင်.ဝင်း`: `ထည့်သွင်း`, `ပြသ`, `ပိတ်`.
- `မြန်မာ.ကိုယ်ပိုင်.မြင်ကွင်းအစိတ်အပိုင်း`: `တံဆိပ်တန်ဖိုး`, `ခလုတ်`, `စာသားအကွက်` ထုတ်လုပ်.
- `မြန်မာ.ကိုယ်ပိုင်.ချိတ်ဆက်သယ်ပို့`: `ချိတ်ဆက်`, `အဆုံးမှတ်နားထောင်`, `လက်ခံ`.
- 기존 `အထွက်`, `အက္ခရာ`, `ဖိုင်`, `အလုပ်`, `အချက်စာရင်း`, `အဘိဓာန်`, `ဆက်သွယ်မှု`, `မျက်နှာပြင်`, `အူတိုင်တန်ဖိုး`도 유지한다.

## Java ကွန်ရက်ဆက်

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **အူတိုင်တန်ဖိုး 내부 연결형 ဘိုက်တန်ဖိုး စီးကြောင်းတန်ဖိုး**을 추가했다. ဖိုင်/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket ဝန်ဆောင်စက်တန်ဖိုး = new java.net.ServerSocket(9250);
java.net.Socket ဧည့်သည်တန်ဖိုး = new java.net.Socket("localhost", 9250);
java.net.Socket ချိတ်ဆက် = ဝန်ဆောင်စက်တန်ဖိုး.accept();
ဧည့်သည်တန်ဖိုး.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] ရရှိအချက် = new byte[64];
int အလျား = ချိတ်ဆက်.getInputStream().read(ရရှိအချက်);
ချိတ်ဆက်.close(); ဧည့်သည်တန်ဖိုး.close(); ဝန်ဆောင်စက်တန်ဖိုး.close();
```

ထုတ်လုပ်·ချိတ်ဆက်·accept·양방향 ဘိုက်တန်ဖိုး/အခင်းအကျင်းတန်ဖိုး အဝင်အထွက်·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 အဆုံးမှတ် 16개, တန်ဖိုးလက်ခံရယူ 버퍼당 1024바이트, တန်ဖိုးစောင့် ချိတ်ဆက် အများဆုံးတန်ဖိုး 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. မူလသတ်မှတ်တန်ဖိုး အချိန်တန်ဖိုး ကန့်သတ်ချက်တန်ဖိုး 0은 별도 ကွန်ရက်ပေါက်တန်ဖိုး 기한을 설정하지 않지만 JVM အမိန့် ကိန်းတန်ဖိုး/အူတိုင်တန်ဖိုး စက်မောင်း 기한은 여전히 적용된다.

ပြင်ပတန်ဖိုး ဂဏန်းတန်ဖိုး IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. တကယ့်ဒေတာ Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP စာကြည့်တိုက် 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [စီးကြောင်းစမ်းသပ်.java](စမ်းသပ်မှု/Java/စီးကြောင်းစမ်းသပ်.java)는 တကယ့်ဒေတာ 송수신·EOF·기한·ချိတ်ဆက် 회수의 စမ်းသပ်မှု 예제다.

## ဟန်ဂုစာသား Python

게스트 vi에서 ဟန်ဂုစာသား 이름을 사용해 작성한다.

```python
တန်ဖိုး = 21

def 두배(ဂဏန်းတန်ဖိုး):
    return ဂဏန်းတန်ဖိုး * 2

print("ရလဒ်:", 두배(တန်ဖိုး))
```

သိုလှောင်တန်ဖိုး 후 `python နှုတ်ဆက်.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 လုပ်ဆောင်ချက်·ကိန်းရှင်တန်ဖိုး·ဖိုင် 이름과 문자열을 한글로 쓴다.

[မြန်မာ.py](ဥပမာ/ဟန်ဂုကုဒ်ရေး/မြန်မာ.py)를 같은 디렉터리에 두면 နောက်တစ်ခုအချက်အလက်တစ်ခု 별칭을 사용할 ကိန်းတန်ဖိုး 있다.

```python
import မြန်မာ
မြန်မာ.ဖိုင်ရေး("နှုတ်ဆက်.txt", "안녕하세요")
မြန်မာ.အထွက်(မြန်မာ.ဖိုင်ဖတ်("နှုတ်ဆက်.txt").decode())
```

အထွက်·ဖိုင် ဖတ်/ရေး/삭제·표준 ဝင်ဒေတာ·စတုဂံ·အချိန်တန်ဖိုး·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 ဂဏန်းတန်ဖိုး IPv4 လိပ်စာ 전송이다. `wait_key()`는 화면을 확인할 때 အပြန်အလှန် 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor တည်ငြိမ်တန်ဖိုး 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 တိုးချဲ့မှု 모듈은 아직 없다. 제한형 `pip`의 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 설치는 [Python အထုပ် လမ်းညွှန်](Pythonအထုပ်.md)를 따른다. [သုံးတန်ဖိုး 언어의 တကယ့်ဒေတာ ဥပမာ](../../example/README.md).

## C·C++에서 posix-kor ခေါ်လုပ်

두 ဘာသာစကား အားလုံးတည်ဆောက် မြန်မာ 헤더와 လုပ်ဆောင်ချက် 이름을 직접 사용한다. [နှုတ်ဆက်.c](ဥပမာ/ဟန်ဂုကုဒ်ရေး/နှုတ်ဆက်.c), [နှုတ်ဆက်.cpp](ဥပမာ/ဟန်ဂုကုဒ်ရေး/နှုတ်ဆက်.cpp)ပထမတွက်ချက်ခံ တကယ့်ဒေတာ EL0 စက်မောင်း စမ်းသပ်မှု 대상이다.

```c
#include "파일규약.h"
#ifdef __cplusplus
extern "C"
#endif
int သုံးစွဲသူပရိုဂရမ်စတင်(int အချက်များ) {
    (void)အချက်များ;
    const char နှုတ်ဆက်စကား[] = "안녕하세요\n";
    int စာတမ်း = ဖိုင်ဖွင့်("နှုတ်ဆက်.txt", ဖတ်ရေး | 없으면만들기 | 내용비우기, 0600);
    if (စာတမ်း < 0) return 1;
    အဝင်အထွက်ရလဒ်အမျိုးပုံစံ 기록한수 = ဖိုင်ဒေတာရေး(စာတမ်း, နှုတ်ဆက်စကား, sizeof(နှုတ်ဆက်စကား) - 1);
    ဖိုင်ပိတ်(စာတမ်း);
    ဖိုင်ဒေတာရေး(1, နှုတ်ဆက်စကား, sizeof(နှုတ်ဆက်စကား) - 1); /* လက်ရှိအချက်အလက်တစ်ခု အဆုံးသုံးမျက်နှာပြင် stdout */
    return 기록한수 == sizeof(နှုတ်ဆက်စကား) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 ကိန်းတန်ဖိုး 있다. C는 게스트 `cc` 또는 အိမ်ရှင် SDK, C++는 အိမ်ရှင် SDK의 Clang++로 컴파일한다. အောက်ဆုံးတန်ဖိုး 예제는 기존 အိမ်ရှင် SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh
# 호스트에서 SDK ထုတ်လုပ်·ထုတ်ယူ
make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/နှုတ်ဆက်.c -o နှုတ်ဆက်-c.elf
python3 compile.py examples/နှုတ်ဆက်.cpp -o နှုတ်ဆက်-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 တကယ့်ဒေတာ စက်မောင်း
cd /home/user/jkoros/platforms/rpi4-native
python3 ကိရိယာစု/ဖိုင်လုပ်ဆောင်.py build/sdk-work/jkoros-native-sdk/နှုတ်ဆက်-c.elf
python3 ကိရိယာစု/ဖိုင်လုပ်ဆောင်.py build/sdk-work/jkoros-native-sdk/နှုတ်ဆက်-cpp.elf
```

လက်ရှိအချက်အလက်တစ်ခု GUI VM에서 실행하려면 `python3 ကိရိယာစု/ဖိုင်တင်.py လမ်း/နှုတ်ဆက်-c.elf`의 출력을 게스트에 보내고 `run နှုတ်ဆက်-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex ဖိုင်အမည်စာသား`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 ကိန်းတန်ဖိုး 있다. 호스트와 게스트의 ဖိုင် 시스템은 별개다.

| မြန်မာ အမည် | C သင်္ကေတ | ဖြတ်နယ်ပယ် |
|---|---|---|
| ဖိုင်ဖွင့်/ဖိုင်ပိတ် | pk_open/pk_close | RAM ဖိုင်, တစ်ဖက်တန်ဖိုး/절대 လမ်း |
| ဖိုင်ဒေတာဖတ်/ဖိုင်ဒေတာရေး | pk_read/pk_write | ဖိုင်, fd 0/1/2 표준 အဝင်အထွက်, 연결형 ကွန်ရက်ပေါက်တန်ဖိုး |
| ဖိုင်နေရာရွှေ့ | pk_lseek | 처음기준/လက်ရှိအမြစ်/끝기준 |
| ဖိုင်အရွယ်/ဖိုင်အလျားသတ်မှတ် | pk_size/pk_ftruncate | အလျား 조회/တန်ဖိုးပြောင်း |
| ဖိုင်အချက်အမည်ဖယ်ရှား | pk_unlink | ဖိုင် အမည် 삭제 |
| ဖိုင်သိုလှောင်အတည်ပြု | pk_fsync | RAM이므로 -1, အမှားကိန်း=ENOSYS |
| အဆုံးမှတ်ဖန်တီး/လိပ်စာချည်နှောင် | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |
| ဒေတာစာဒေတာပို့/ဒေတာစာဒေတာလက်ခံရယူ | pk_sendto/pk_recvfrom | UDP 루프백 |
| ကွန်ရက်ချိတ်ဆက် | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | တန်ဖိုးစောင့် ချိတ်ဆက် အများဆုံးတန်ဖိုး 4개 |
| ကွန်ရက်ချိတ်ဆက်မှုလက်ခံ | pk_accept | လက်ရှိအချက်အလက်တစ်ခု လိပ်စာ 인수는 NULL/NULL만 ထောက်ပံ့မှုတန်ဖိုး |
| ကွန်ရက်ပေါက်လိပ်စာဖတ် | pk_getsockname | 로컬 လိပ်စာ/ဆက်သွယ်ပေါက်တန်ဖိုး |

`통신규약.h`의 ကိုယ်ပိုင် `pk_sockaddr_in`을 사용하며 ဆက်သွယ်ပေါက်တန်ဖိုး·주소는 `ကွန်ရက်တို`/`ကွန်ရက်ကိန်းပြည့်`로 변환한다. C ကွန်ရက်ပေါက်တန်ဖိုး 호출은 비차단이며 ဒေတာ/연결이 없으면 -1과 `အမှားကိန်း=11`(EAGAIN)을 반환한다. 양수 အဝင်အထွက် 결과가 요청보다 작을 ကိန်းတန်ဖိုး 있으므로 반복 처리한다. မအောင်မြင်မှု 후에만 오류번호를 확인한다.

[စီးကြောင်းတန်ဖိုး.c](ဥပမာ/ဟန်ဂုကုဒ်ရေး/စီးကြောင်းတန်ဖိုး.c)는 C에서 မြန်မာ 이름으로 ချိတ်ဆက်·accept·အစိတ်အပိုင်းတန်ဖိုး ဖတ်/ရေး·큐 포화·EOF를 처리하는 စက်မောင်း 예제다. SDK의 `examples/စီးကြောင်းတန်ဖိုး.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. ခေါ်လုပ် 흐름은 C/C++ → တကယ့်ဒေတာ မြန်မာ C လုပ်ဆောင်ချက် 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·ညွှန်တံ စစ်ဆေးချက် → Java RAM ဖိုင်/루프백 또는 ပြင်ပတန်ဖိုး lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 အူတိုင်တန်ဖိုး 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 ချိတ်ဆက်, 표준 C printf, libstdc++/STL, ခြွင်းချက်·RTTI는 제공하지 않으며 C++의 တည်ငြိမ်တန်ဖိုး 생성자·ဒေသတွင်းနယ်ပယ်ကန့်သတ် အရာဝတ္ထုတန်ဖိုး 소멸자는 지원한다. 상세 နံပါတ်·မှတ်ဉာဏ်ဒေတာ 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## မှန်ကန်ကြောင်းစစ်

`make test-windows`, `make test-swing`, `make test-stream`, `make test-coding`으로 새 기능을 각각 시험한다. `make test`는 기존 အမိန့်ဝင်း·VNC·JVM·AOT·အူတိုင်တန်ဖိုး တန်ဖိုးကာကွယ် 시험까지 포함한다. တကယ့်ဒေတာ ဆားကစ်ပြား 대신 QEMU raspi4b에서 수행한다. 결과는 [ယခင်အချက်အလက်တစ်ခု GUI တိုးချဲ့မှု မှန်ကန်ကြောင်းစစ် မှတ်တမ်းမှတ်တမ်းတစ်ခု](build/verification/release.json)과 [လက်ရှိအချက်အလက်တစ်ခု လည်ပတ်ဝန်းကျင် မှန်ကန်ကြောင်းစစ် မှတ်တမ်းမှတ်တမ်းတစ်ခု](build/verification/native-runtime-summary.json), [여러 အဆုံးသုံးမျက်နှာပြင် မျက်နှာပြင်](build/verification/windows/four-terminals.png), [Swing မျက်နှာပြင်](build/verification/swing/native-swing.png)을 참고한다.

အကောင်အထည်ဖော်မှု 시 참고한 표준 API: [Socket](https://docs.oracle.com/javase/8/docs/api/java/net/Socket.html), [JFrame](https://docs.oracle.com/javase/8/docs/api/javax/swing/JFrame.html), [JButton](https://docs.oracle.com/javase/8/docs/api/javax/swing/JButton.html). 이 문서의 အကောင်အထည်ဖော်မှု 범위가 ထိပ်တန်ဖိုး 표준 전체를 지원한다는 뜻은 아니다.

## မြန်မာ 이름으로 직접 작성하는 창과 အလုပ်ကြိုးတန်ဖိုး

`example/java/ဝင်းဥပမာ.java`는 `လုပ်ဆောင်ရန်အလုပ်.အလုပ်လုပ်ဆောင်`,
`လှုပ်ရှားမှုလက်ခံသူ.လုပ်ဆောင်ချက်လက်ခံရယူ(လှုပ်ရှားမှုအသိပေးချက်)`, `ခလုတ်`, `ဖြစ်ရပ်တန်းစီရာ.နောက်မှလုပ်ဆောင်`, `လုပ်ဆောင်()`을 쓴다.
ကိုယ်ပိုင် JVM에 이 이름들의 အရာဝတ္ထုတန်ဖိုး·နည်းလမ်းတန်ဖိုး·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `အလုပ်သမား`도 ကိုယ်ပိုင် 스케줄러와 직접 연결된다.
세부 메서드와 기존 မြန်မာ API에서의 변경은 [မြန်မာ API စာတမ်း](မြန်မာJava/လမ်းညွှန်.md)를 본다.

အိမ်ရှင် javac는 ဖြန့်ချိမှုတန်ဖိုး JAR를 အတန်းတန်ဖိုး 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/ဝင်းဥပမာ.java
python3 ကိရိယာစု/စက်မောင်း.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java ဝင်းဥပမာ
```

직접 မျက်နှာပြင်/အလုပ်ကြိုးတန်ဖိုး API와 `လုပ်ဆောင်()` 진입점은 ကိုယ်ပိုင် JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 ဆက်လုပ်လုပ်ငန်းစဉ်ဆောင်ရွက်မှု 실행할 ကိန်းတန်ဖိုး 있다.
