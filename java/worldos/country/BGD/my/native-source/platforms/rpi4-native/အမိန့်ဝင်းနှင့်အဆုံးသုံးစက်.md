# ကိုယ်ပိုင် 커널의 GUI 터미널과 အမိန့်ဝင်း

이 터미널은 ကိုယ်ပိုင် Java 커널의 셸을 프레임버퍼 창과 UART에서 사용한다. အမိန့် လုပ်ငန်းစဉ်တန်ဖိုးအချက်·RAM ဖိုင်·파이프는 Java အူတိုင်တန်ဖိုး, 화면의 အက္ခရာတန်ဖိုး 그리기는 freestanding C에서 수행한다. Linux·X11·Bash 없이 동작하며, ကိုယ်ပိုင် JVM의 Swing ထောက်ပံ့မှုတန်ဖိုး 부분집합도 같은 ဝင်း 시스템을 이용한다. 자세한 vi·다중 ဝင်း·코딩 사용법은 [ဖွံ့ဖြိုးရေး 매뉴얼](ဖွံ့ဖြိုးရေးလမ်းညွှန်.md)을 참고한다.

## လက်ရှိအချက်အလက်တစ်ခု 컴퓨터에서 စက်မောင်း

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, လိပ်စာ **127.0.0.1:5902**로 연결한다. အဆုံးသုံးမျက်နှာပြင် 창은 자동으로 열린다. 연결한 VNC 창에 키를 입력하면 ကိုယ်ပိုင် 커널의 셸로 전달된다. 종료하려면 `make desktop`을 실행한 အိမ်ရှင် 터미널에서 Ctrl+C를 누른다. 포트를 바꾸려면 တည်ဆောက် 후 `python3 ကိရိယာစု/စက်မောင်း.py --desktop --port 5903`을 사용한다. 서버는 localhost에만 바인드하며 동시에 한 클라이언트가 제어한다.

일반 UART 셸은 `make run`으로 시작한다. QEMU 종료는 Ctrl+A နောက်တစ်ခုအချက်အလက်တစ်ခု X이다. 같은 VM의 UART에서 `terminal` 또는 F12로 GUI 터미널을 ကော်လံတန်ဖိုး ကိန်းတန်ဖိုး 있다. `gui` စက်မောင်း 화면에서는 다섯 번째 **OPEN TERMINAL** 버튼, ဂဏန်းတန်ဖိုး 5 또는 T로 연다. `--vnc 127.0.0.1:2`만 사용한 기존 စက်မောင်း 방식은 မျက်နှာပြင် 보기용이며, VNC 키보드를 연결하려면 `--desktop`을 사용한다.

FTP와 ပြင်ပတန်ဖိုး 네트워크도 함께 쓰려면 `python3 ကိရိယာစု/စက်မောင်း.py --desktop --network`로
실행한다. Remmina VNC는 `127.0.0.1:5902`, 게스트에서 `ftpd start` 후 FTP는
`127.0.0.1:2121`이다. `--port`, `--ftp-port`, `--forward`를 함께 지정할 ကိန်းတန်ဖိုး 있다.
한 VM의 보조 UART로 SLIP를 전송하고 주 UART로 GUI 입력을 전달한다.

QEMU စက်မောင်း 도구가 VNC 키보드/마우스를 UART 입력으로 변환한다. တကယ့်ဒေတာ Pi4의 USB 키보드·마우스 드라이버를 구현한 것은 아니다. တကယ့်ဒေတာ 보드에서는 လက်ရှိအချက်အလက်တစ်ခု UART 입력이 필요하며 ရုပ်ပိုင်းစက်ပစ္စည်း 부팅은 아직 미검증이다.

## 창과 ဝင်ဒေတာ

- 640×480~1920×1080 화면에서 အများဆုံးတန်ဖိုး 네 개 အဆုံးသုံးမျက်နှာပြင် ဝင်း, မူလသတ်မှတ်တန်ဖိုး 568×360(68열 × 19행)과 မကြာသေးမီတန်ဖိုး 160행 တန်ဖိုးထိန်းသိမ်း, မူလသတ်မှတ်တန်ဖိုး ANSI ပုံမှတ်အရောင်·စာညွှန်းတန်ဖိုး·အချက်ဖျက် လုပ်ငန်းစဉ်တန်ဖိုးအချက်.
- 상단 **+ New terminal** 또는 Ctrl+Shift+T로 새 창을 연다. 제목줄을 끌어 이동하고 ဝင်း/상단 버튼을 클릭하거나 F6으로 전환한다. 각 창의 အလုပ် လမ်း·ကိန်းရှင်တန်ဖိုး·အမိန့် မှတ်တမ်းမှတ်တမ်းတစ်ခု·ဝင်ဒေတာ 중인 줄은 독립적이다.
- UTF-8 ဟန်ဂုစာသား·CJK·라틴 문자와 일부 이모지 비트맵 စာလုံးပုံစံတန်ဖိုး. 복잡한 အက္ခရာ 조판·ပေါင်းစပ်တန်ဖိုးများ အက္ခရာ·양방향 နေရာချထားပုံ·모든 Unicode 글리프를 보장하지 않는다.
- 좌우 방향키/Home/End/Delete/Backspace로 명령을 편집하고 위아래 방향키로 မကြာသေးမီတန်ဖိုး 16개 명령을 찾는다. 긴 명령은 ဝင်ဒေတာ 줄을 가로로 이동해 보여 주며 `<`, `>`ပထမတွက်ချက်ခံ 숨겨진 부분을 나타낸다.
- Tab은 အမိန့် အမည် 또는 လက်ရှိအချက်အလက်တစ်ခု 디렉터리의 파일명에서 후보가 하나일 때 완성한다. 디렉터리를 포함한 လမ်း 접두사·ကိုးကားအမှတ် 안의 완성은 아직 없다.
- Ctrl+A/E: အစဦးအချက်အလက်တစ်ခု/အဆုံး, Ctrl+U/K: စာညွှန်းတန်ဖိုး ရှေ့တန်ဖိုး/နောက်တန်ဖိုး 삭제, Ctrl+C: ဝင်ဒေတာ ပယ်ဖျက်လုပ်ငန်း. စက်မောင်း 중인 임의 프로그램에 SIGINT를 보내는 기능은 없다. vi와 Swing의 ဝင်ဒေတာ 대기는 စက်မောင်း 기한을 갱신하지만 일반 계산의 약 2초 제한은 유지한다.
- PgUp/PgDn 또는 마우스 휠: ယခင်အချက်အလက်တစ်ခု အထွက်. 새 출력이 오면 최신 위치로 돌아온다.
- F12/제목줄 ညာ 버튼/`exit`: ဝင်း ပိတ်. 빈 입력에서 Ctrl+D도 창을 닫는다. VM을 종료하는 명령은 아니다.

`--desktop`의 VNC ဝင်ဒေတာ 연결에 **두벌식 ဟန်ဂုစာသား ပေါင်းစပ်မှု**을 제공한다. 접속한 PC의
입력기를 영어로 두고 **F9**, **Shift+Space**, **한/သုညတွက်ချက်ခံ သော့တန်ဖိုး** 중 하나를 누르면
ဝင်း 제목이 `[EN]`에서 `[KO]`로 바뀐다. `gksrmf` → `ဟန်ဂုစာသား`,
`dkssudgktpdy` → `안녕하세요`. 같은 키로 영어로 돌아간다.
겹받침·복합 모음과 ပေါင်းစပ်မှု 단계별 Backspace를 지원한다. စာညွှန်းတန်ဖိုး ရွှေ့တန်ဖိုး·마우스 클릭·
단축키·붙여넣기·Enter 때 조합을 확정한다. PC가 Shift+Space나 한/သုညတွက်ချက်ခံ 키를
ကိုယ်ပိုင် 처리하면 **F9**를 사용한다. Alt 단독은 အလှည့်ပြောင်းနည်းစနစ် 키가 아니다.

이 조합기는 QEMU의 VNC→UART ဝင်ဒေတာ 연결에서 실행된다. 일반 အစဉ်ဆက်တန်ဖိုး 접속과
ရုပ်ပိုင်းစက်ပစ္စည်း Pi의 USB 키보드 입력기에 추가된 기능은 아니다. 이미 완성된 Unicode
ဟန်ဂုစာသား 키도 그대로 전달한다. 클립보드 공유가 활성화되어 표준 VNC ClientCutText가
도착하면 Ctrl+Shift+V로 붙여 넣는다. 클립보드 동기화만으로 명령을 실행하지 않는다.
줄바꿈을 포함해 명시적으로 붙여 넣으면 해당 줄이 실행된다.

게스트에서 `help` 또는 `help ko`를 입력하면 ဟန်ဂုစာသား ဝင်ဒေတာ 안내를 볼 ကိန်းတန်ဖိုး 있다.
`help`와 `help ko`에는 한/သုညတွက်ချက်ခံ သော့တန်ဖိုး·Shift+Space·F9 및 `[EN]`/`[KO]` 안내를 표시한다.
긴 도움말은 PgUp/PgDn으로 스크롤한다.

터미널에서 Java·Python·C++ စက်မောင်း 결과를 바로 볼 ကိန်းတန်ဖိုး 있다. 프로그램이 직접 프레임버퍼에 그림을 그린 경우 ထွက်ပရိုဂရမ် 후 အဆုံးသုံးမျက်နှာပြင် 창을 복원한다. vi/Swing တန်ဖိုးစောင့် 중 다른 창으로 전환하면 해당 EL0 프로그램의 မှတ်ဉာဏ်ဒေတာ·레지스터를 보관하고 돌아올 때 재개한다. ရွေးချယ်မှုတန်ဖိုး တန်ဖိုးမိတ္တူကူး·PTY·전체 VT100/xterm 호환과 임의 프로그램의 동시 병렬 실행은 제공하지 않는다. X로 닫으면 해당 창의 프로그램도 종료되므로 vi에서 저장하지 않은 내용은 사라진다.

```sh
echo "$이름: ${PWD}"
false && echo 건너뜀 || echo အခြေအနေပြန်လည်ရယူ
python -c 'print(123)' > ရလဒ်.txt
echo ဝင်ဒေတာ | python -c 'import jkoros; print(jkoros.stdin(64))'
echo 'echo "$이름"' > စက်မောင်း.sh
sh စက်မောင်း.sh
echo $?
```

## 문법과 ကန့်သတ်ချက်တန်ဖိုး

작은따옴표·큰따옴표·백슬래시, `$NAME`/`${NAME}`/`$?`, စကားလုံးတန်ဖိုး ရှေ့တန်ဖိုး `~`, စာကြောင်း 주석 `#`, 순차 စက်မောင်း `;`, အခြေအနေစည်းကမ်း စက်မောင်း `&&`/`||`, 파이프 `|`, ဝင်ဒေတာ `<`, 새 အထွက် `>`, အချက်နောက်တွဲ အထွက် `>>`를 제공한다. ကိန်းရှင်တန်ဖိုး 확장은 အချက်များ 안에서 수행하며 တိုးချဲ့မှု 결과를 공백으로 ပြန်ကြိုးစား 나누지 않는다. `export`의 값은 အမိန့်ဝင်း 안에서만 공유하며 သုံးစွဲသူ ELF의 envp/getenv 환경은 아직 없다.

파이프는 각 단계를 순서대로 실행하고 အများဆုံးတန်ဖိုး **16384바이트**를 နောက်တစ်ခုအချက်အလက်တစ်ခု 단계로 넘긴다. 여러 프로세스가 동시에 읽고 쓰는 POSIX 파이프가 아니다. ဆံ့ပမာဏ 초과는 အမှား 28과 မအောင်မြင်မှု 상태를 반환하고 해당 실행을 중단한다. `<`는 EOF를 제공하며 `>`/`>>`는 stdout만 바꾼다. EL0 fd 2는 မျက်နှာပြင်/UART로 출력된다. `2>` 등 번호를 붙인 리다이렉션은 거부한다. 일부 내장 명령의 진단은 stdout을 사용한다. 연결한 프로그램의 `exit N` 진단은 데이터에 섞이지 않도록 생략한다.

`vi`, `edit`, `load`, `gui`, `terminal`, `sh`, `source`에는 파이프와 리다이렉션을 적용할 ကိန်းတန်ဖိုး 없다. 리다이렉션 파일을 열지 못하거나 파이프 용량을 초과하면 လက်ရှိအချက်အလက်တစ်ခု 명령줄을 중단하며, 그 줄의 뒤쪽 `||` 명령도 실행하지 않는다. အမိန့်စာတမ်းတန်ဖိုး 파일을 입력할 때 멀티라인 ကိုးကားအမှတ်·ဆက်လက်တန်ဖိုး 쓰기는 제공하지 않는다. `if`/`for`/`while`, လုပ်ဆောင်ချက်, အမိန့် 치환, glob, 별칭, 백그라운드 `&`, jobs/fg/bg, 일반 프로세스·신호·PTY는 아직 없다. Bash/POSIX sh 전체 호환으로 표시하지 않는다.

ဖိုင် 64개 × 각 16384바이트, 루트 외 디렉터리 15개, ဖိုင် အညွှန်း 16개, လမ်း အများဆုံးတန်ဖိုး UTF-8 63바이트다. တစ်ဖက်တန်ဖိုး/절대 경로와 `.`/`..`를 정규화하지만 ခွင့်ပြုချက်တန်ဖိုး·심볼릭 링크·마운트·디스크 영속 저장은 없다. **ဖိုင်·디렉터리·ကိန်းရှင်တန်ဖိုး·기록의 수정 내용은 재부팅하면 사라진다.** သုံးစွဲသူ 실행도 လက်ရှိအချက်အလက်တစ်ခု အမိန့်ဝင်း 경로를 사용한다. Java/Python/C++의 ဖိုင် API는 같은 RAM 저장소를 본다. `/example`의 သုံးတန်ဖိုး ဘာသာစကား 예제와 설명서는 부팅할 때 원본으로 준비된다.

한 명령줄은 4096바이트, 구문 သင်္ကေတစကားလုံးတန်ဖိုး 128개, စက်မောင်း အချက်များ 32개, 변수는 16개(အမည် 31바이트·တန်ဖိုး 255바이트)까지다. သုံးစွဲသူ 프로그램에 전달하는 인수는 기존 ABI대로 အများဆုံးတန်ဖိုး 8개·각 255바이트다. အမိန့် 기록은 1024바이트 이하 줄을 မကြာသေးမီတန်ဖိုး 16개까지 저장한다.

## 재현 가능한 စမ်းသပ်မှု

```sh
make test-shell
make test-desktop
make test-windows
make test-swing
make test
```

အမိန့်ဝင်း 시험은 တကယ့်ဒေတာ raspi4b QEMU에서 လမ်း·ဖိုင်·ကိန်းရှင်တန်ဖိုး·အခြေအနေစည်းကမ်း·파이프·리다이렉션·အမှား အခြေအနေပြန်လည်ရယူ·အမိန့်စာတမ်းတန်ဖိုး·편집을 검사하고, Java/Python 출력과 Python stdin의 EOF를 확인한다. VNC 시험은 တကယ့်ဒေတာ RFB 클라이언트로 ဟန်ဂုစာသား သော့တန်ဖိုး·Ctrl ပေါင်းစပ်မှု·명시적 붙여넣기·마우스와 게스트 프레임버퍼를 검사한다. Remmina 앱 자체의 자동화 시험과 ရုပ်ပိုင်းစက်ပစ္စည်း USB ဝင်ဒေတာ 시험은 별개다.

결과와 မျက်နှာပြင်: [အမိန့်ဝင်း ရလဒ်](build/verification/shell/report.json), [VNC ရလဒ်](build/verification/desktop/report.json), [အဆုံးသုံးမျက်နှာပြင် မျက်နှာပြင်](build/verification/desktop/vnc-terminal.png). စာလုံးပုံစံတန်ဖိုး 출처·ဖိုင်ဟက်ရှ်တွက်·라이선스는 [vendor](vendor/README.md)에 있다.

## 마우스로 အရွယ် တန်ဖိုးပြောင်း

네 모서리의 안쪽 8픽셀에 마우스를 대면 방향에 맞는 대각선 양방향 포인터가
나타난다. **ဘယ်ဘက် 버튼을 누른 채 끌고 놓는다.** ညာ 버튼으로는 크기가 바뀌지 않는다.
ဝင်းခေါင်းစဉ် 표시줄의 나머지 부분은 ရွှေ့တန်ဖိုး, ညာ ထိပ်တန်ဖိုး X는 닫기다.
အနည်းဆုံးတန်ဖိုး 크기는 360×216이며 အများဆုံးတန်ဖိုး 크기는 လက်ရှိအချက်အလက်တစ်ခု မျက်နှာပြင် 안에 제한된다.
각 창의 အက္ခရာတန်ဖိုး 칸은 `(အကျယ်အဝန်း-24)/8`ကော်လံတန်ဖိုး, `(အမြင့်တန်ဖိုး-56)/16`행이다. `terminal size`로 조회한다.

명령줄의 ဝင်ဒေတာ·စာညွှန်းတန်ဖိုး·기록과 vi의 미저장 문서를 유지하며 보이는 영역을 갱신한다.
지난 출력은 저장된 စာကြောင်း 단위를 유지하고, 좁아진 창에서 가려진 열은 ပြန်ကြိုးစား 넓히면
볼 ကိန်းတန်ဖိုး 있다. 과거 အထွက် 전체를 새 너비에 맞춰 재배열하는 기능은 아니다.
크기를 바꾼 နောက်တန်ဖိုး 출력되는 글은 새 ကော်လံတန်ဖိုး 수로 줄바꿈한다. vi는 ဝင်ဒေတာ တန်ဖိုးစောင့် 중에도
SVC 16의 လှုပ်ရှားမှု 3으로 လက်ရှိအချက်အလက်တစ်ခု အရွယ်(상위 16비트 အတန်းလိုက်တန်ဖိုး, 하위 16비트 ကော်လံတန်ဖိုး)를 조회한다.
အပြန်အလှန် tty의 အူတိုင်တန်ဖိုး မျက်နှာပြင် အထွက် 시간은 သုံးစွဲသူ တွက်ချက်မှု 기한에서 제외하며, ဝင်ဒေတာ တန်ဖိုးစောင့် 없이
계산만 반복하는 သုံးစွဲသူ 프로그램의 အချိန်တန်ဖိုး 제한은 유지한다.
커널이 프레임버퍼에 포인터를 그리며, Remmina 중계는 အဝေးတန်ဖိုး 포인터를 숨겨 중복을 피한다.
로컬 VNC 중계는 မူလသတ်မှတ်တန်ဖိုး Raw 인코딩을 사용한다.

မှန်ကန်ကြောင်းစစ်: `make test-resize` — 640×480·1920×1080에서 네 모서리, ဘယ်ဘက်/ညာ 버튼,
အနည်းဆုံးတန်ဖိုး·အများဆုံးတန်ဖိုး အရွယ်, ညွှန်တံ 복원, ဝင်ဒေတာ 보존, vi သိုလှောင်တန်ဖိုး·ဆက်လုပ်လုပ်ငန်းစဉ်ဆောင်ရွက်မှု ဝင်ဒေတာ, 창별 크기를 확인한다.
