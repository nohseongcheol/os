# VirtualBox စက်မောင်း

```sh
cd ~/jkoros
make vbox
```

별도로 VM을 만들거나 ISO를 연결할 필요가 없다. အစဦးအချက်အလက်တစ်ခု 실행하면 `os/build/kernel.iso`를 빌드하고 `jkoros operating system`이라는 전용 VM을 만들어 VirtualBox 창으로 부팅한다. `jkoros/os` 안에서도 `make vbox`를 사용할 ကိန်းတန်ဖိုး 있다.

게스트의 `jkoros>` 프롬프트에서 နောက်တစ်ခုအချက်အလက်တစ်ခု 명령을 입력한다.

```text
help
apps
run hello vbox
```

နောက်ဆုံးအချက်အလက်တစ်ခု 명령은 별도 Java ELF를 실행한다. `USER MODE ring 3`, `arg: vbox`, `Exit: 0` အထွက် 후 셸로 돌아오면 정상이다. VGA 화면은 လက်ရှိအချက်အလက်တစ်ခု ASCII 글꼴만 지원하므로 한글은 `?`로 보이며, ဟန်ဂုစာသား 원문은 အစဉ်ဆက်တန်ဖိုး 기록에서 확인할 ကိန်းတန်ဖိုး 있다.

## အခြေအနေတန်ဖိုး 확인과 ပြန်ကြိုးစား စက်မောင်း

```sh
make vbox-status
```

이 명령은 VM အခြေအနေတန်ဖိုး, ISO와 အစဉ်ဆက်တန်ဖိုး 기록의 절대 경로를 JSON으로 출력한다.

| လက်ရှိအချက်အလက်တစ်ခု အခြေအနေတန်ဖိုး | `make vbox` လှုပ်ရှားမှု |
| --- | --- |
| 아직 생성하지 않음 | ISO တည်ဆောက် → 전용 VM ထုတ်လုပ် → စက်တင် |
| 종료됨 (`poweroff`, `aborted`) | ISO တည်ဆောက် → 광학 매체 ပြန်လည်မွမ်းမံ → 새로 စက်တင် |
| စက်မောင်း 중 (`running`) | 재빌드·재부팅 없이 လက်ရှိအချက်အလက်တစ်ခု VM 유지 |
| 일시정지 (`paused`) | 기존 VM လုပ်ဆောင်မှုပြန်စ |
| 저장됨 (`saved`) | ယခင်အချက်အလက်တစ်ခု အစဉ်ဆက်တန်ဖိုး 기록을 복사해 보관하고 သိုလှောင်တန်ဖိုး အခြေအနေတန်ဖိုး လုပ်ဆောင်မှုပြန်စ |
| သိုလှောင်တန်ဖိုး·လုပ်ဆောင် 등 အလှည့်ပြောင်းနည်းစနစ် 중 | 변경하지 않고 အလုပ် ဖြစ်သောအပြည့်အစုံ 후 재실행하도록 လမ်းညွှန် |

မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 변경을 반영하려면 VM을 종료한 နောက်တစ်ခုအချက်အလက်တစ်ခု ပြန်ကြိုးစား `make vbox`를 실행한다. **သိုလှောင်တန်ဖိုး 상태를 재개하면 ယခင်အချက်အလက်တစ်ခု 커널이 ဆက်လုပ်လုပ်ငန်းစဉ်ဆောင်ရွက်မှု 실행되므로 새 빌드를 반영하지 않는다.** 실행기는 강제 종료하거나 သိုလှောင်တန်ဖိုး 상태를 폐기하지 않는다. VirtualBox 창을 닫을 때 사용자가 전원 끄기를 선택하면 မှတ်ဉာဏ်ဒေတာ 상태가 사라지므로 보존할 작업이 없는지 먼저 확인한다. 게스트의 `halt`는 CPU만 멈추며 VirtualBox의 전원을 끄는 명령은 아니다.

ဝင်း 없는 실행이 필요하면 VM이 꺼져 있을 때 사용한다.

```sh
make vbox VBOX_TYPE=headless
```

စက်မောင်း 중인 VM에 ပြန်ကြိုးစား 명령을 내려도 GUI/headless 방식은 바뀌지 않는다. မူလသတ်မှတ်တန်ဖိုး အမည် 대신 다른 이름이 필요하면 **최초 ထုတ်လုပ် 시에만** `VBOX_NAME="원하는 အမည်"`을 지정하고 이후에도 같은 값을 사용한다.

## 설정과 ဒေတာ 보존

- မူလသတ်မှတ်တန်ဖိုး 설정은 BIOS, မှတ်ဉာဏ်ဒေတာ 64MiB, CPU 1개, VGA မှတ်ဉာဏ်ဒေတာ 16MiB, IDE 광학 부팅이다. 가상 하드디스크를 만들지 않는다.
- VM 설정은 `.vbox/machines/`, အကြောင်းအရာတန်ဖိုး 검사합별 ISO 사본은 `.vbox/media/`, အစဉ်ဆက်တန်ဖိုး 기록은 `.vbox/logs/`에 보관한다. `.vbox/state.json`은 전용 VM의 UUID와 ပိုင်ရှင်တန်ဖိုး 표식을 저장한다.
- 꺼진 VM을 부팅할 때 새 အစဉ်ဆက်တန်ဖိုး 기록을 만든다. သိုလှောင်တန်ဖိုး အခြေအနေတန်ဖိုး လုပ်ဆောင်မှုပြန်စ 전의 기록은 `before-resume-*.log`로 복사한다. သိုလှောင်တန်ဖိုး အခြေအနေတန်ဖိုး 자체는 삭제하지 않고 VirtualBox가 그대로 재개한다.
- 같은 이름의 다른 VM을 인수하지 않는다. UUID·သတ်မှတ်ချက် လမ်း·ပိုင်ရှင်တန်ဖိုး 표식을 검사하며, 사용자가 별도로 연결한 디스크나 광학 매체를 자동 교체하지 않는다.
- 기존 ISO 사본과 기록은 자동 삭제하지 않는다. `.vbox`는 Git 제외 대상이다. 용량을 정리할 때도 စက်မောင်း·သိုလှောင်တန်ဖိုး 상태의 VM이 참조하는 파일과 관리 정보를 임의로 삭제하지 않는다.
- VirtualBox 또는 အိမ်ရှင် 드라이버가 없으면 오류를 안내한다. 자동 တန်ဖိုးတပ်ဆင်, စီမံသူတန်ဖိုး ခွင့်ပြုချက်တန်ဖိုး စက်မောင်း, ကိရိယာ ခွင့်ပြုချက်တန်ဖိုး 변경은 하지 않는다.

## ကွန်ရက်ဆက် ကန့်သတ်ချက်တန်ဖိုး

လက်ရှိအချက်အလက်တစ်ခု 커널의 RTL8139 드라이버는 QEMU에서 사용한다. VirtualBox의 PCnet/E1000 드라이버는 아직 구현하지 않아 이 실행기는 ကွန်ရက်ဆက် 장치를 비활성화한다. 셸과 သုံးစွဲသူ 프로그램은 실행되지만 UDP 열기는 `-19`로 실패한다. UDP 왕복은 `make run`과 [သုံးစွဲသူ စက်မောင်း·ကွန်ရက်ဆက် လမ်းညွှန်](../os/သုံးစွဲသူ/လမ်းညွှန်.md)의 절차로 시험한다.

## မှန်ကန်ကြောင်းစစ်

`make test-vbox`는 가짜 VirtualBox 응답을 사용하여 새 VM ထုတ်လုပ်, စက်မောင်း·သိုလှောင်တန်ဖိုး·일시정지·အလှည့်ပြောင်းနည်းစနစ် အခြေအနေတန်ဖိုး, အမည် 충돌, 소유권 불일치, သုံးစွဲသူ 매체 တန်ဖိုးကာကွယ်, တည်ဆောက် မအောင်မြင်မှု, 중단된 ထုတ်လုပ် အခြေအနေပြန်လည်ရယူ, ISO တန်ဖိုးပြောင်း 감지, လမ်း တန်ဖိုးကာကွယ် 등을 검사한다. တကယ့်ဒေတာ VM을 만들거나 변경하지 않는다.

2026-09-13에 ပရိုဂရမ်စက်နှိုးကိရိယာ ယူနစ်တန်ဖိုး စမ်းသပ်မှု 16개가 통과했다. 별도로 တကယ့်ဒေတာ VirtualBox 5.2.42에서 `make vbox`의 VM ထုတ်လုပ်·GUI စက်တင်, `JAVA SELFTEST PASS`, 셸의 `run hello vbox` 실행과 `Exit: 0`, စက်မောင်း 중 재호출 시 재부팅하지 않는 လှုပ်ရှားမှု 및 `make vbox-status`를 확인했다. သိုလှောင်တန်ဖိုး·일시정지 분기는 ယူနစ်တန်ဖိုး 시험으로 검증했다.
