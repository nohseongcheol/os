# မြန်မာ Java အကူတန်ဖိုး စာကြည့်တိုက်

OpenJDK 11 이상과 함께 쓰는 프로젝트 ပိုင်ရှင်တန်ဖိုး API다. 표준 Java စာကြည့်တိုက် 전체의 번역판을 뜻하지 않는다. 기존 Java API·키워드·ခြွင်းချက်·자료형은 그대로 함께 쓴다.

전체 22개 အကူတန်ဖိုး 메서드의 အချက်များ·ပြန်ပေးတန်ဖိုး·제약, စက်စနစ် 안의 사용법, Python·C++ ခေါ်လုပ် 방법은 **[မြန်မာ စာကြည့်တိုက် အသုံးပြုလက်စွဲ](အသုံးပြုလက်စွဲ.md)**에 정리했다. [Python ခေါ်လုပ် ဥပမာ](ဥပမာ/အခြားဘာသာ/Pythonခေါ်.py)와 [C++ JNI ခေါ်လုပ် ဥပမာ](ဥပမာ/အခြားဘာသာ/Javaခေါ်.cpp)도 제공한다.

`make`로 `build/မြန်မာJava.jar`를 만든다. `javac -encoding UTF-8 -cp build/မြန်မာJava.jar ဥပမာ/နှုတ်ဆက်.java`로 예제를 컴파일한다. 실행은 `java -cp build/မြန်မာJava.jar:ဥပမာ နှုတ်ဆက်`တတိယအော်ပရန်း.

`နှုတ်ဆက်` 예제는 그래픽 화면이 없으면 ဖိုင်·အက္ခရာ·스레드 결과와 안내만 출력한다. Swing 창은 그래픽 세션에서 실행해야 한다. QEMU에서는 [그래픽 စက်မောင်း လမ်းညွှန်](../platforms/rpi4/README.md)의 `make run`으로 부팅한 နောက်တန်ဖိုး VNC 데스크톱의 터미널을 사용한다.

| အတန်းတန်ဖိုး | 제공 기능 |
|---|---|
| ဖိုင် | UTF-8 텍스트·ဘိုက်တန်ဖိုး ဖတ်/ရေး, 디렉터리·အချက်စာရင်း |
| အက္ခရာ | UTF-8 တန်ဖိုးပြောင်းလဲ, NFC စံပုံစံပြောင်း, ကုဒ်တန်ဖိုး 포인트 ကိန်းတန်ဖိုး, 언어별 ဝေါဟာရ နယ်နိမိတ်တန်ဖိုး |
| ဆက်သွယ်မှု | HTTP(S) တောင်းဆိုချက်, 제한시간을 가진 TCP ချိတ်ဆက် |
| အလုပ် | 스레드 လုပ်ဆောင်·합류·တန်ဖိုးစောင့်, အလုပ် ပရိုဂရမ်စက်နှိုးကိရိယာ |
| မျက်နှာပြင် | Swing 이벤트 처리와 ဝင်း ထုတ်လုပ် |
| အလုပ်နယ်ပယ် | မူရင်းကုဒ် တည်းဖြတ်တန်ဖိုး·မူရင်းကုဒ်ဘာသာပြန်·စက်မောင်း·စက်မောင်း ဖိုင် ထုတ်လုပ် မျက်နှာပြင် |

`char`는 UTF-16 ကုဒ်တန်ဖိုး 단위이므로 이모지 등을 한 글자로 처리할 때 ကုဒ်တန်ဖိုး 포인트 또는 အက္ခရာ နယ်နိမိတ်တန်ဖိုး API를 사용한다. 파일은 UTF-8로 저장한다. OpenJDK의 모든 Java2D/စာလုံးပုံစံတန်ဖိုး/입력기 조합을 각각 검증한 것은 아니다.

이름은 လက်ရှိအချက်အလက်တစ်ခု 의미가 분명한 မြန်မာ 용례를 사용했다. 개별 명칭의 역사적 어원 검토를 완료했다고 주장하지 않는다. အရင်းအမြစ်တန်ဖိုး 종료와 ခြွင်းချက် 처리는 표준 API의 계약을 따른다.
