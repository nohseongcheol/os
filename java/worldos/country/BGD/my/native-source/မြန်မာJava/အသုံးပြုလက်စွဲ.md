# jkoros မြန်မာ စာကြည့်တိုက် အသုံးပြုလက်စွဲ

확인일: 2026-09-27. 대상은 `platforms/rpi4`의 **ARM64 Linux + OpenJDK 실행판**이며, QEMU에서도 같은 Java 라이브러리를 사용한다. `os/`의 ကိုယ်ပိုင် x86 အူတိုင်တန်ဖိုး 및 `အခြေခံကုဒ်/`의 관리 အူတိုင်တန်ဖိုး 모형과 구분한다.

## 1. လက်ရှိအချက်အလက်တစ်ခု 제공하는 စာကြည့်တိုက်

패키지는 `မြန်မာ.Java`, စက်စနစ် 안의 JAR 경로는 `/opt/jkoros/lib/မြန်မာJava.jar`တတိယအော်ပရန်း. **အကူတန်ဖိုး အတန်းတန်ဖိုး 5개, 공개 တည်ငြိမ်တန်ဖိုး နည်းလမ်းတန်ဖိုး 22개, 별도 GUI 프로그램인 အလုပ်နယ်ပယ် 1개**ပထမတွက်ချက်ခံ 있다. JAR는 Java 11 이상을 대상으로 빌드하며 လက်ရှိအချက်အလက်တစ်ခု ARM64 배포판에는 OpenJDK 25가 포함돼 있다.

| အတန်းတန်ဖိုး | နည်းလမ်းတန်ဖိုး ကိန်းတန်ဖိုး | 기능 | မူရင်းကုဒ် |
|---|---:|---|---|

| `မျက်နှာပြင်` | 2 | Swing 이벤트 လုပ်ငန်းစဉ်တန်ဖိုးအချက် 가닥에 အလုပ် 예약, ဝင်း ထုတ်လုပ် | [မျက်နှာပြင်.java](မူရင်းကုဒ်/မြန်မာ/Java/မျက်နှာပြင်.java) |

표준 JDK 전체를 한국어로 번역한 라이브러리는 아니다. Java 키워드와 `String`, `Path`, `Socket`, `JFrame`, `IOException` 같은 표준 ဒေတာအမျိုးပုံစံ·예외를 함께 사용한다. 이 도우미에 없는 기능은 OpenJDK의 표준 API 또는 별도 라이브러리로 구현한다. 예를 들어 HTTP POST, UDP, Swing ခလုတ်·메뉴에는 각각 표준 Java API를 사용한다.

## 2. Java에서 အလုပ်စတင်

게스트 운영체제의 အလုပ် 폴더에서 `사용예.java`를 작성한다.

```java
import မြန်မာ.Java.*;
import java.nio.file.Path;

public class 사용예 {
    public static void main(String[] အချက်များ) throws Exception {
        Path ဖိုင်တွဲတန်ဖိုး = ဖိုင်.ဖိုင်တွဲဖန်တီး(ဖိုင်.လမ်း("사용예자료"));
        Path စာတမ်း = ဖိုင်တွဲတန်ဖိုး.resolve("နှုတ်ဆက်.txt");
        ဖိုင်.ရေး(စာတမ်း, "ဟန်ဂုစာသား 😀");
        String အကြောင်းအရာတန်ဖိုး = ဖိုင်.ဖတ်(စာတမ်း);
        System.out.println(အကြောင်းအရာတန်ဖိုး);
        System.out.println(အက္ခရာ.ကုဒ်အမှတ်တစ်ခုအရေအတွက်(အကြောင်းအရာတန်ဖိုး)); // 한, စာသား, 공백, 😀 → 4
        Thread လုပ်စရာတန်ဖိုး = အလုပ်.လုပ်ဆောင်("နှုတ်ဆက် အလုပ်", () -> System.out.println("အလုပ် စက်မောင်း"));
        အလုပ်.စောင့်(လုပ်စရာတန်ဖိုး);
    }
}
```

```sh
javac -encoding UTF-8 -cp /opt/jkoros/lib/မြန်မာJava.jar 사용예.java
java -cp .:/opt/jkoros/lib/မြန်မာJava.jar 사용예
```

로그인 환경에 မူလသတ်မှတ်တန်ဖိုး `CLASSPATH`도 설정돼 있지만, 명시적인 `-cp`는 다른 စက်မောင်း 환경에서도 경로를 분명하게 한다. 사용자가 `-cp`를 지정하면 필요한 JAR와 အတန်းတန်ဖိုး 폴더를 အားလုံးတည်ဆောက် 그 값에 포함해야 한다.

အိမ်ရှင် 저장소에서는 다음처럼 တည်ဆောက်·실행한다. အိမ်ရှင် 경로와 게스트의 `/opt/...` 경로는 서로 다르다.

```sh
cd /home/user/jkoros/မြန်မာJava
make
javac -encoding UTF-8 -cp build/မြန်မာJava.jar ဥပမာ/နှုတ်ဆက်.java
java -cp build/မြန်မာJava.jar:ဥပမာ နှုတ်ဆက်
```

## 3. 전체 အကူတန်ဖိုး API

အောက်ဆုံးတန်ဖိုး 메서드는 အားလုံးတည်ဆောက် `public static`이며, 객체를 만들지 않고 `ဖိုင်.ဖတ်(...)`처럼 호출한다. 표의 이름은 တကယ့်ဒေတာ မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 및 JAR의 `javap -public` 결과와 대조했다. 선언된 စစ်ဆေးချက် ခြွင်းချက် 외에도 잘못된 အချက်များ 등에 대한 표준 Java စက်မောင်း 시 예외가 발생할 ကိန်းတန်ဖိုး 있다.

### ဖိုင်: `မြန်မာ.Java.ဖိုင်`

`Path`는 `java.nio.file.Path`, `List`는 `java.util.List`တတိယအော်ပရန်း.

| နည်းလမ်းတန်ဖိုး | ပြန်ပေးအမျိုးပုံစံ | လှုပ်ရှားမှု·အခြေအနေစည်းကမ်း |
|---|---|---|
| `လမ်း(String အမည်)` | `Path` | 이름을 လမ်း 객체로 တန်ဖိုးပြောင်းလဲ. တကယ့်ဒေတာ 파일을 만들지는 않음 |
| `ဖတ်(Path လမ်း)` | `String` | ဖိုင် 전체를 UTF-8 텍스트로 ရလဒ်ဖတ် |
| `ရေး(Path လမ်း, String အကြောင်းအရာတန်ဖိုး)` | `Path` | UTF-8 သိုလှောင်တန်ဖိုး. 파일이 없으면 생성하고, 있으면 기존 내용을 비움 |
| `ဘိုက်တန်ဖိုးဖတ်(Path လမ်း)` | `byte[]` | ဖိုင် 전체를 ဘိုက်တန်ဖိုး 배열로 ရလဒ်ဖတ် |
| `ဘိုက်တန်ဖိုးရေး(Path လမ်း, byte[] အကြောင်းအရာတန်ဖိုး)` | `Path` | ဘိုက်တန်ဖိုး သိုလှောင်တန်ဖိုး. 없으면 생성하고, 있으면 기존 내용을 비움 |
| `ဖိုင်တွဲဖန်တီး(Path လမ်း)` | `Path` | 필요한 상위 폴더까지 ထုတ်လုပ် |
| `ရှိသလား(Path လမ်း)` | `boolean` | 존재 ဟုတ်မဟုတ် အတည်ပြု. 확인할 ကိန်းတန်ဖိုး 없는 경우도 `false`လုပ်စရာတန်ဖိုး ကိန်းတန်ဖိုး 있음 |
| `အချက်ဖျက်(Path လမ်း)` | `boolean` | 삭제했으면 `true`, 없으면 `false`. 폴더의 재귀 삭제는 아님 |
| `အချက်စာရင်း(Path လမ်း)` | `List<Path>` | 바로 အောက်ဆုံးတန်ဖိုး 항목을 လမ်း ညှိတန်ဖိုး 순서로 ပြန်ပေးရလဒ်. 재귀 탐색은 아님 |

`လမ်း`, `ရှိသလား`를 제외한 ထိပ်တန်ဖိုး 메서드는 `IOException`을 선언한다. `ရေး`와 `ဘိုက်တန်ဖိုးရေး`는 상위 폴더를 자동으로 만들거나 내용을 ဆက်လက်တန်ဖိုး 쓰지 않는다. 필요한 폴더는 먼저 생성한다. 큰 파일은 전체 내용을 메모리에 담는 대신 표준 Java 스트림·ချန်နယ်တန်ဖိုး API를 사용하는 방식으로 작성할 ကိန်းတန်ဖိုး 있다.

### အက္ခရာ: `မြန်မာ.Java.အက္ခရာ`

| နည်းလမ်းတန်ဖိုး | ပြန်ပေးအမျိုးပုံစံ | လှုပ်ရှားမှု·အခြေအနေစည်းကမ်း |
|---|---|---|
| `ကုဒ်သွင်း(String အကြောင်းအရာတန်ဖိုး)` | `byte[]` | 문자열을 UTF-8 바이트로 တန်ဖိုးပြောင်းလဲ |
| `လျှို့ဝှက်ကုဒ်ဖြည်(byte[] အကြောင်းအရာတန်ဖိုး)` | `String` | UTF-8 바이트를 문자열로 တန်ဖိုးပြောင်းလဲ. 잘못된 입력은 대체 문자로 လုပ်ငန်းစဉ်တန်ဖိုးအချက် |
| `စံပုံစံပြောင်း(String အကြောင်းအရာတန်ဖိုး)` | `String` | Unicodeတန်ဖိုး NFC စံပုံစံပြောင်း. 예: ပေါင်းစပ်မှု 자모 `ᄀ` + `ᅡ` → `ပထမတွက်ချက်ခံ` |
| `ကုဒ်အမှတ်တစ်ခုအရေအတွက်(String အကြောင်းအရာတန်ဖိုး)` | `int` | UTF-16 ကုဒ်တန်ဖိုး 단위가 아닌 Unicodeတန်ဖိုး ကုဒ်တန်ဖိုး 포인트 ကိန်းတန်ဖိုး |
| `ဝေါဟာရ(String အကြောင်းအရာတန်ဖိုး, Locale ဘာသာစကား)` | `List<String>` | သတ်မှတ်ပေးတန်ဖိုး 언어의 `BreakIterator` ဝေါဟာရ 경계로 나눈 စာသားအပိုင်းအခြား |

`ဝေါဟာရ`은 공백·문장부호 구간도 반환한다. 자연어 형태소 분석기나 공백을 제거한 စကားလုံးတန်ဖိုး အချက်စာရင်း API는 아니다. `စံပုံစံပြောင်း`는 입력기나 မူရင်းကုဒ်ဘာသာပြန်ဆို 기능이 아니다. ကုဒ်တန်ဖိုး 포인트 ကိန်းတန်ဖိုး 역시 사람이 보는 အက္ခရာတန်ဖိုး 수와 항상 같지는 않다. 여러 ကုဒ်တန်ဖိုး 포인트로 이루어진 ပေါင်းစပ်တန်ဖိုးများ အက္ခရာ·가족 이모지 등을 구분해야 한다.

### ဆက်သွယ်မှု: `မြန်မာ.Java.ဆက်သွယ်မှု`

| နည်းလမ်းတန်ဖိုး | ပြန်ပေးအမျိုးပုံစံ | လှုပ်ရှားမှု·အခြေအနေစည်းကမ်း |
|---|---|---|
| `တန်ဖိုးယူ(URI လိပ်စာ, Duration အချိန်ကန့်သတ်ချက်)` | `HttpResponse<String>` | HTTP(S) GET. ချိတ်ဆက် 및 တောင်းဆိုချက် အချိန်ကန့်သတ်ချက် သတ်မှတ်ချက်. အကြောင်းပြန်ချက် 본문을 UTF-8로 တန်ဖိုးသဒ္ဒါခွဲခြမ်း |
| `အဆုံးမှတ်ချိတ်ဆက်(String လိပ်စာ, int စက်ပစ္စည်းဆက်သွယ်ပေါက်, int အများဆုံးမီလီစက္ကန့်)` | `Socket` | TCP ချိတ်ဆက် 후 같은 값으로 ဖတ် 제한시간도 သတ်မှတ်ချက် |

`တန်ဖိုးယူ`는 `IOException`, `InterruptedException`을 선언한다. 제한시간은 양수다. 404·500 같은 HTTP အမှား 상태도 응답으로 반환하므로 `statusCode()`로 판단하고 `body()`로 본문을 읽는다. လက်ရှိအချက်အလက်တစ်ခု 구현은 호출마다 HTTP 클라이언트를 만들며 자동 리다이렉트 설정을 추가하지 않는다.

`အဆုံးမှတ်ချိတ်ဆက်`는 `IOException`을 선언한다. 연결된 소켓은 호출자가 `close()` 또는 try-with-resources로 닫아야 한다. 제한밀리초의 0은 ကန့်သတ်ချက်တန်ဖိုး 없음이며, ရေး 전체의 마감 시간을 보장하는 옵션은 아니다.

```java
var အကြောင်းပြန်ချက် = ဆက်သွယ်မှု.တန်ဖိုးယူ(
    java.net.URI.create("http://127.0.0.1:8000/"),
    java.time.Duration.ofSeconds(5));
System.out.println(အကြောင်းပြန်ချက်.statusCode());
System.out.println(အကြောင်းပြန်ချက်.body());
```

ထိပ်တန်ဖိုး 조각은 နည်းလမ်းတန်ဖိုး 안에서 실행하며 별도로 해당 주소의 서버를 실행해야 한다. Java ခြွင်းချက် 처리가 필요하다.

### အလုပ်: `မြန်မာ.Java.အလုပ်`

| နည်းလမ်းတန်ဖိုး | ပြန်ပေးအမျိုးပုံစံ | လှုပ်ရှားမှု·အခြေအနေစည်းကမ်း |
|---|---|---|
| `လုပ်ဆောင်(String အမည်, Runnable လှုပ်ရှားမှု)` | `Thread` | 이름을 지정한 스레드를 만들고 즉시 လုပ်ဆောင် |
| `စောင့်(Thread အလုပ်ကြိုးတန်ဖိုး)` | `void` | 해당 스레드가 종료할 때까지 `join()` |
| `ခဏနား(long မီလီစက္ကန့်)` | `void` | 호출한 스레드를 သတ်မှတ်ပေးတန်ဖိုး အချိန်တန်ဖိုး 동안 `sleep()` |
| `အလုပ်ခုံတန်ဖိုး(int အလုပ်ကြိုးအရေအတွက်)` | `ExecutorService` | 고정 အရွယ် အလုပ် ပရိုဂရမ်စက်နှိုးကိရိယာ ထုတ်လုပ်. 가닥수는 양수 |

`စောင့်`, `ခဏနား`는 `InterruptedException`을 선언한다. အလုပ် 실행기는 သုံးစွဲမှု 후 `shutdown()`으로 종료하고 필요하면 `awaitTermination(...)`으로 완료를 기다린다. Swing 이벤트 လုပ်ငန်းစဉ်တန်ဖိုးအချက် 가닥에서 긴 작업이나 `စောင့်`를 실행하면 화면이 멈출 ကိန်းတန်ဖိုး 있다.

### မျက်နှာပြင်: `မြန်မာ.Java.မျက်နှာပြင်`

| နည်းလမ်းတန်ဖိုး | ပြန်ပေးအမျိုးပုံစံ | လှုပ်ရှားမှု·အခြေအနေစည်းကမ်း |
|---|---|---|
| `နောက်မှ(Runnable လှုပ်ရှားမှု)` | `void` | Swing 이벤트 လုပ်ငန်းစဉ်တန်ဖိုးအချက် 가닥에 실행을 예약하고 ပြန်ပေးရလဒ် |
| `ဝင်း(String ဝင်းခေါင်းစဉ်, JComponent အကြောင်းအရာတန်ဖိုး, int အနံတန်ဖိုး, int အမြင့်တန်ဖိုး)` | `JFrame` | အကြောင်းအရာတန်ဖိုး·크기를 지정한 창을 생성해 တန်ဖိုးပြသ |

`ဝင်း`을 Swing 이벤트 လုပ်ငန်းစဉ်တန်ဖိုးအချက် အလုပ်ကြိုးတန်ဖိုး 밖에서 부르면 `IllegalStateException`이 발생한다. 그래픽 세션도 필요하다. QEMU에서는 VNC 데스크톱의 터미널에서 실행한다.

```java
မျက်နှာပြင်.နောက်မှ(() -> မျက်နှာပြင်.ဝင်း(
    "မြန်မာ မျက်နှာပြင်", new javax.swing.JLabel("안녕하세요"), 500, 180));
```

반환된 `JFrame`에 표준 Swing API를 추가로 사용할 ကိန်းတန်ဖိုး 있다. 창의 ပိတ် 동작은 `DISPOSE_ON_CLOSE`တတိယအော်ပရန်း. `မျက်နှာပြင်.နောက်မှ`ပထမတွက်ချက်ခံ 반환됐다고 ဝင်း 생성이 이미 끝난 것은 아니다.

### အလုပ်နယ်ပယ်: တည်းဖြတ်တန်ဖိုး·မူရင်းကုဒ်ဘာသာပြန် GUI

```sh
java -cp /opt/jkoros/lib/မြန်မာJava.jar မြန်မာ.Java.အလုပ်နယ်ပယ်
```

`~/workspace`의 원문을 ဖွင့်·저장하고, `javac`로 컴파일해 `java`로 실행한다. စက်မောင်း ဖိုင် 만들기는 `jclassc --target openjdk` 경로를 사용한다. 작업마당은 개발용 프로그램이며 별도의 ဖိုင်·အက္ခရာ API 클래스가 아니다. 생성하는 စက်မောင်း ဖိုင် 방식은 [ဘာသာပြန်စက် ရှင်းလင်းချက်](../compiler/OpenJDK-စက်ဖိုင်ဖိုင်.md)을 따른다.

## 4. Python과 C++에서 사용할 ကိန်းတန်ဖိုး ရှိသလား?

| နည်းလမ်းနည်းစနစ် | လက်ရှိအချက်အလက်တစ်ခု ခေါင်းစီးဖိုင် အခြေအနေတန်ဖိုး | ခေါ်လုပ် 가능 ဖြတ်နယ်ပယ် |
|---|---|---|
| Java → မြန်မာ JAR | မူလသတ်မှတ်တန်ဖိုး ခေါင်းစီးဖိုင် | ထိပ်တန်ဖိုး 22개 메서드와 အလုပ်နယ်ပယ် |
| Python → `java` သားသမီးတန်ဖိုး 프로세스 | Python·Java မူလသတ်မှတ်တန်ဖိုး ခေါင်းစီးဖိုင် | 작은 Java 진입점을 통해 호출하고 표준 အထွက်·ဖိုင် 등으로 ရလဒ် ဆက်ပို့တန်ဖိုး |
| Python → JPype → JVM | JPype는 မူလသတ်မှတ်တန်ဖိုး 배포에 없음 | 별도 တန်ဖိုးတပ်ဆင် 후 Java အတန်းတန်ဖိုး·နည်းလမ်းတန်ဖိုး ခေါ်လုပ် 가능. 이 배포판의 ARM64/musl/Python 3.14 조합은 အချက်နောက်တွဲ မှန်ကန်ကြောင်းစစ် 필요 |
| C++ → JNI → JVM | `g++`, JNI 헤더, `libjvm.so` ခေါင်းစီးဖိုင် | JVM을 생성하고 မြန်မာ အတန်းတန်ဖိုး·메서드를 직접 호출할 ကိန်းတန်ဖိုး 있음 |
| Python용 독립 မြန်မာ စာကြည့်တိုက် | လက်ရှိအချက်အလက်တစ်ခု မူလသတ်မှတ်တန်ဖိုး 제공 없음 | 필요하면 Python 표준 라이브러리를 감싸는 မြန်မာ 모듈을 별도로 작성 |
| C/C++용 독립 မြန်မာ စာကြည့်တိုက် | ကိုယ်ပိုင် x86 `posix-kor`와 ကိုယ်ပိုင် ARM64 커널용 အစဦးအခြေအနေ RAM ဖိုင် 연결이 별도로 존재 | နှစ်တန်ဖိုး တတိယအော်ပရန်း 이 Linux/OpenJDK 실행판의 libc 라이브러리는 아님 |

Python의 일반 `import`ဒုတိယတွက်ချက်ခံ `ctypes.CDLL`로 JAR를 바로 읽을 수는 없다. C++의 `#include`ဒုတိယတွက်ချက်ခံ 일반 네이티브 링커만으로 Java 메서드를 연결할 수도 없다. JVM 프로세스 또는 JVM ချိတ်ဆက် 계층을 거쳐야 한다.

### Python: အချက်နောက်တွဲ 패키지 없이 ခေါ်လုပ်

စက်မောင်း 가능한 ဥပမာ 원문은 [စာသားအမိန့်.java](ဥပမာ/အခြားဘာသာ/စာသားအမိန့်.java), [Pythonခေါ်.py](ဥပမာ/အခြားဘာသာ/Pythonခေါ်.py)တတိယအော်ပရန်း. Python이 Java 진입점을 실행하고 `အက္ခရာ.ကုဒ်အမှတ်တစ်ခုအရေအတွက်`의 ကိန်းပြည့် 결과를 받는다. အချက်များ 목록을 사용하며 အမိန့်ဝင်း အမိန့် 문자열을 조립하지 않는다. `subprocess.run`의 프로세스 စက်မောင်း·ထွက်ပရိုဂရမ် ကုဒ်တန်ဖိုး·အထွက် လုပ်ငန်းစဉ်တန်ဖိုးအချက် 방식은 [Python 공식 စာတမ်း](https://docs.python.org/3/library/subprocess.html)를 따른다.

두 ဥပမာ 파일을 게스트의 같은 폴더에 복사한 နောက်တန်ဖိုး 그 폴더에서 실행한다. ဥပမာ ဖိုင် 자체는 မူလသတ်မှတ်တန်ဖိုး 시스템 이미지에 자동 설치돼 있지 않다.

```sh
mkdir -p classes
javac -encoding UTF-8 -cp /opt/jkoros/lib/မြန်မာJava.jar -d classes စာသားအမိန့်.java
python3 Pythonခေါ်.py --text 'ဟန်ဂုစာသား 😀'
```

အထွက်: `Python → မြန်မာ.Java.အက္ခရာ.ကုဒ်အမှတ်တစ်ခုအရေအတွက်: 4`

이 예제의 Python လုပ်ဆောင်ချက် `ကုဒ်အမှတ်တစ်ခုအရေအတွက်`는 이번 문서의 ချိတ်ဆက် 예제이며 기존에 설치된 Python 라이브러리는 아니다. လက်ရှိအချက်အလက်တစ်ခု 예제는 호출할 때마다 JVM 프로세스를 시작한다. Java အရာဝတ္ထုတန်ဖိုး 자체를 Python으로 가져오는 방식은 아니며, 다른 메서드를 사용하려면 진입점의 အချက်များ·ရလဒ် 형식을 확장한다.

### Python: JPype로 같은 프로세스에서 ခေါ်လုပ်

JPype를 별도 설치한 환경에서는 နောက်တစ်ခုအချက်အလက်တစ်ခု 형태로 연결할 ကိန်းတန်ဖိုး 있다. **아래는 ရွေးချယ်မှုတန်ဖိုး 가능한 ချိတ်ဆက် 방법이며, လက်ရှိအချက်အလက်တစ်ခု 배포판에 JPype가 설치돼 있거나 စက်မောင်း 검증됐다는 뜻은 아니다.** JVM 시작과 `JClass`를 통한 အတန်းတန်ဖိုး 접근은 [JPype 공식 ရှင်းလင်းချက်](https://jpype.readthedocs.io/en/latest/userguide.html)을 참고한다.

```python
import jpype

jpype.startJVM(
    "/usr/lib/jvm/java-25-openjdk/lib/server/libjvm.so",
    classpath=["/opt/jkoros/lib/မြန်မာJava.jar"])
try:
    အက္ခရာ = jpype.JClass("မြန်မာ.Java.အက္ခရာ")
    print(အက္ခရာ.ကုဒ်အမှတ်တစ်ခုအရေအတွက်(jpype.JString("ဟန်ဂုစာသား 😀")))
finally:
    jpype.shutdownJVM()
```

Python·JVM·ချိတ်ဆက် 모듈의 CPU 아키텍처가 맞아야 한다. 이 실행판은 ARM64 + musl이므로 일반 x86_64/glibc용 바이너리를 그대로 설치하는 방식은 맞지 않는다. JPype တန်ဖိုးတပ်ဆင်·패키지 빌드는 이번 စာတမ်း 작업에서 수행하지 않았다.

### C++: JNI로 직접 ခေါ်လုပ်

[Javaခေါ်.cpp](ဥပမာ/အခြားဘာသာ/Javaခေါ်.cpp)는 တကယ့်ဒေတာ စက်မောင်း 가능한 예제다. JVM을 အလုပ် 스레드에서 생성하고 နောက်တစ်ခုအချက်အလက်တစ်ခု 메서드를 찾는다.

```cpp
jclass type = env->FindClass("မြန်မာ/Java/အက္ခရာ");
jmethodID method = env->GetStaticMethodID(
    type, "ကုဒ်အမှတ်တစ်ခုအရေအတွက်", "(Ljava/lang/String;)I");
```

JVM ထုတ်လုပ်·종료와 스레드 연결은 [JNI Invocation API](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/invocation.html)의 방식이다. `JNIEnv*`는 ထုတ်လုပ်·연결된 스레드에서 사용해야 한다. 예제는 Java 예외를 확인하고 JVM 종료까지 처리한다.

게스트에 `Javaခေါ်.cpp`를 복사한 နောက်တန်ဖိုး 컴파일한다. 로그인 환경의 `JAVA_HOME`은 `/usr/lib/jvm/java-25-openjdk`တတိယအော်ပရန်း.

```sh
g++ -std=c++11 -Wall -Wextra -pthread \
  -I"$JAVA_HOME/include" -I"$JAVA_HOME/include/linux" \
  Javaခေါ်.cpp -L"$JAVA_HOME/lib/server" \
  -Wl,-rpath,"$JAVA_HOME/lib/server" -ljvm -o Javaခေါ်
./Javaခေါ် /opt/jkoros/lib/မြန်မာJava.jar
```

အထွက်: `C++ → မြန်မာ.Java.အက္ခရာ.ကုဒ်အမှတ်တစ်ခုအရေအတွက်: 4`

예제는 `ဟန်ဂုစာသား 😀`을 UTF-16으로 만들어 `NewString`에 전달한다. `NewStringUTF`ပထမတွက်ချက်ခံ 받는 modified UTF-8은 일반 UTF-8과 차이가 있으므로, 일반 UTF-8 이모지 바이트를 그대로 넘기는 예제로 작성하지 않았다. [JNI အက္ခရာစဉ် ပုံစံတန်ဖိုး](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/types.html#modified-utf-8-strings)

다른 မြန်မာ 메서드도 JNI 서명과 အချက်များ 자료형을 맞춰 호출할 ကိန်းတန်ဖိုး 있다. 예를 들어 `Path`를 받는 ဖိုင် API는 먼저 `ဖိုင်.လမ်း`로 Java လမ်း 객체를 얻어 전달한다. Swing 호출에는 그래픽 세션과 이벤트 လုပ်ငန်းစဉ်တန်ဖိုးအချက် အလုပ်ကြိုးတန်ဖိုး 규칙도 그대로 적용된다. JNI는 Java 실행을 기계어로 대체하는 기능이 아니며 JVM이 ဆက်လုပ်လုပ်ငန်းစဉ်ဆောင်ရွက်မှု 필요하다.

### 기존 posix-kor와의 관계

추가된 [ကိုယ်ပိုင် ARM64 ချိတ်ဆက်](../posix-kor/arm64-native/လမ်းညွှန်.md)은 C++에서 AOT Java 커널의 RAM ဖိုင် API를 직접 호출하며, 별도 EL0 သုံးစွဲသူ 라이브러리로 ဖိုင်/UDP 루프백 SVC 호출도 제공한다. JNI를 사용하지 않는다. 이 문서의 ARM64 **Linux** 및 မြန်မာ Java JAR와는 다른 စက်မောင်း 기반이며 ကိုယ်ပိုင် 커널은 별도 제한형 Java ဘာသာပြန်စက်/JVM과 MicroPython 1.24.1을 실행한다. MicroPython의 `import jkoros`로 Java အူတိုင်တန်ဖိုး ဖိုင်·UDP 루프백·စတုဂံ 호출이 가능하지만 이 문서의 JAR를 가져오는 기능은 아니다. ကိုယ်ပိုင် 커널의 전체 OpenJDK/JRE/CPython 이식은 아직 미완성이다.

[posix-kor](../posix-kor/လမ်းညွှန်.md)에는 `ဖိုင်ဖွင့်`, `ဖိုင်ဒေတာဖတ်`, `ဖိုင်ဒေတာရေး`, `ဖိုင်ပိတ်`, `အဆုံးမှတ်ဖန်တီး`, `ဒေတာစာဒေတာပို့` 등의 မြန်မာ C 별칭이 있다. 그러나 구현은 **ကိုယ်ပိုင် jkoros i386 커널의 `int 0x80` ခေါ်လုပ် 규약용**이다.

이 `libposix-kor.a`와 ကိုယ်ပိုင် `sys/stat.h` 등의 헤더는 လက်ရှိအချက်အလက်တစ်ခု ARM64 Linux 실행판의 libc/C++용 라이브러리가 아니다. 해당 헤더·바이너리를 ARM64 Linux 프로그램에 그대로 연결해서는 ABI가 맞지 않는다. C++용 မြန်မာ အတန်းတန်ဖိုး 라이브러리나 Python용 바인딩을 မူလသတ်မှတ်တန်ဖိုး 제공하는 상태도 아니다. လက်ရှိအချက်အလက်တစ်ခု Linux 실행판에서 그와 같은 독립 API를 제공하려면 Linux 표준 라이브러리를 대상으로 별도로 အကောင်အထည်ဖော်မှု·빌드해야 한다.

## 5. အတည်ပြု 범위와 재현

패키지 ခေါင်းစီးဖိုင် 여부는 [ဖြန့်ချိမှုတန်ဖိုး 패키지 အချက်စာရင်း](../platforms/rpi4/dist/packages.lock.json) 및 တည်ဆောက် 루트의 တကယ့်ဒေတာ 파일로 확인했다. JNI 헤더는 JDK의 `include/jni.h`, `include/linux/jni_md.h`, JVM 라이브러리는 `lib/server/libjvm.so`에 있다. 사용자가 이후 별도로 설치한 패키지는 이 မူလသတ်မှတ်တန်ဖိုး ဖြန့်ချိမှုတန်ဖိုး 목록과 다를 ကိန်းတန်ဖိုး 있다.

이번에 **အိမ်ရှင် x86_64/OpenJDK 11에서** Python သားသမီးတန်ဖိုး 프로세스 호출과 C++ JNI 직접 호출을 မူရင်းကုဒ်ဘာသာပြန်·실행해 각각 ရလဒ် 4를 확인했다. JAR 공개 메서드도 소스와 대조했다. Python ချိတ်ဆက် 예제는 အချက်နောက်တွဲ 패키지를 설치하지 않는다.

문서의 Java သုံးစွဲမှု 예제도 မူရင်းကုဒ်ဘာသာပြန်·실행했고, 22개 메서드의 စာတမ်း ခေါင်းစီးဖိုင် 여부와 로컬 စာတမ်း 링크를 확인했다. [ဥပမာ မှန်ကန်ကြောင်းစစ် မှတ်တမ်းမှတ်တမ်းတစ်ခု](build/အခြားဘာသာ/검증기록.json)

기존 ARM64 QEMU에서는 Java의 ဖိုင်·Unicodeတန်ဖိုး·스레드·HTTP 및 Swing စမ်းသပ်မှု 결과가 있다. 이번 Python/C++ ချိတ်ဆက် 예제의 **ARM64 게스트 실행과 JPype 설치는 별도 검증하지 않았다.** 이미지와 စက်မောင်း 중인 သုံးစွဲသူ 환경은 이 စာတမ်း 작업에서 변경하지 않았다. [기존 စက်စနစ် မှန်ကန်ကြောင်းစစ် မှတ်တမ်းမှတ်တမ်းတစ်ခု](../platforms/rpi4/VERIFICATION.md)

호스트에서 Python 예제를 재현하려면:

```sh
cd /home/user/jkoros/မြန်မာJava
make
mkdir -p build/အခြားဘာသာ
javac -encoding UTF-8 --release 11 -cp build/မြန်မာJava.jar \
  -d build/အခြားဘာသာ ဥပမာ/အခြားဘာသာ/စာသားအမိန့်.java
python3 ဥပမာ/အခြားဘာသာ/Pythonခေါ်.py \
  --jar build/မြန်မာJava.jar --classes build/အခြားဘာသာ
```

အိမ်ရှင် C++ 예제는 ထိပ်တန်ဖိုး JNI မူရင်းကုဒ်ဘာသာပြန် 명령의 JDK 경로를 **အိမ်ရှင် JDK လမ်း**로 바꾸고, မူရင်းကုဒ် `ဥပမာ/အခြားဘာသာ/Javaခေါ်.cpp`와 JAR `build/မြန်မာJava.jar`를 지정한다. ARM64 게스트 JDK의 헤더·စာကြည့်တိုက် 경로를 အိမ်ရှင် x86_64 링크 명령에 섞지 않는다.
