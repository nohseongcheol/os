# JBgdOS

လက်ရှိအချက်အလက်တစ်ခု ကိုယ်ပိုင် ARM64 배포판은 [LICENSE](LICENSE)의 COSL 상업 조건을 유지한다. 제3자 라이선스의 권리는 별도로 보장하며, ဖြန့်ချိမှုတန်ဖိုး 시 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ·재연결 자료를 포함하는 절차는 [COSL ဖြန့်ချိမှုတန်ဖိုး လမ်းညွှန်](platforms/rpi4-native/COSL배포안내.md)에 있다.

ကိုယ်ပိုင် ARM64 판의 `ipconfig`/`ip`, `ping`, `ps`/`top`, `free`/`df`, `poweroff`와 မြန်မာ 명령은 [ကွန်ရက်ဆက်·လည်ပတ်မှုစနစ်တန်ဖိုး အမိန့် လမ်းညွှန်](platforms/rpi4-native/ကွန်ရက်နှင့်စနစ်အမိန့်များ.md)를 참고한다. 새 커널을 부팅한 နောက်တန်ဖိုး `help system`으로 볼 ကိန်းတန်ဖိုး 있다.

Raspberry Pi 4 **ကိုယ်ပိုင် Java ARM64 အူတိုင်တန်ဖိုး**은 [ကိုယ်ပိုင် Pi4 လမ်းညွှန်](platforms/rpi4-native/လမ်းညွှန်.md)에 있다. Linux 없이 부팅하며 GUI အဆုံးသုံးမျက်နှာပြင်·vi, ကိုယ်ပိုင် JVM의 Swing 일부 API, TCP/UDP·FTP, 게스트 TinyCC·MicroPython, C/C++의 posix-kor 호출을 제공한다. [မြန်မာ Java ဆက်သွယ်မှု·ခြွင်းချက် API](platforms/rpi4-native/မြန်မာJava/လမ်းညွှန်.md)와 [မြန်မာ မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 명명](platforms/rpi4-native/명명/လမ်းညွှန်.md)을 지원한다. [ကိုယ်ပိုင် SSH·VNC 및 GENET 드라이버](platforms/rpi4-native/ပြင်ပချိတ်ဆက်မှုလမ်းညွှန်.md)를 포함하며, 네트워크는 QEMU의 UART SLIP 경로로 검증했다. တကယ့်ဒေတာ Pi 4 GENET 동작은 미검증이고, USB ဝင်ဒေတာ·영속 저장과 전체 OpenJDK·Swing은 아직 ထောက်ပံ့မှုတန်ဖိုး ဖြတ်နယ်ပယ် 밖이다.

Raspberry Pi 4용 Linux·OpenJDK 실행판과 သုံးစွဲသူ ဝန်းကျင် ရွှေ့တန်ဖိုး 기능은 [라즈베리파이 실행판](platforms/rpi4/README.md)에 있다. တကယ့်ဒေတာ ARM64 JDK/JRE와 시스템·သုံးစွဲသူ စက်ပုံရိပ်တည်ဆောက် တည်ဆောက် 경로를 제공한다. 기존 ကိုယ်ပိုင် x86 커널과는 별도 စက်မောင်း 기반이다. 일반 Java `.class`/JAR의 စက်မောင်း ဖိုင် 생성은 [OpenJDK စက်မောင်း ဖိုင်](compiler/OpenJDK-စက်ဖိုင်ဖိုင်.md), မြန်မာ API는 [မြန်မာ Java စာကြည့်တိုက်](မြန်မာJava/လမ်းညွှန်.md)를 참고한다.

`jkoros`는 `engos`의 기능을 Java 관리 커널로 옮기는 프로젝트다. 프로젝트가 소유하는 Java လုပ်ဆောင်ချက်, ကိန်းရှင်တန်ဖိုး, ပုံစံတန်ဖိုး 및 Java ဖိုင် 이름은 한국어로 작성한다. 표준 Java 실행기의 `main`, Java 표준 စာကြည့်တိုက် ပုံစံတန်ဖိုး, x86 부트 ABI 등 ပြင်ပတန်ဖိုး 계약은 보존한다. ကိုယ်ပိုင် ARM64 실행기는 မြန်မာ `လုပ်ဆောင်()`도 진입점으로 지원하며, မြန်မာ GUI·အလုပ် 가닥을 JVM에 직접 구현했다. ကိုယ်ပိုင် ARM64 C 연결부·Python 도구와 공용 x86·ARM64 AOT 번역기의 ကိုယ်ပိုင် 이름도 한국어로 작성한다. ယခင်အချက်အလက်တစ်ခု 경로의 호환 အချက်အမှတ်တစ်ခု, OpenJDK 보조 도구와 Linux ထုတ်ဝေမှုတန်ဖိုး 도구에는 영어 이름이 남아 있고 [명명 원칙·말의 근거·전체 မူရင်းကုဒ် 검토 ဖြတ်နယ်ပယ်](platforms/rpi4-native/명명/လမ်းညွှန်.md)를 별도로 기록한다.

## လက်ရှိအချက်အလက်တစ်ခု အကောင်အထည်ဖော်မှု

အောက်ဆုံးတန်ဖိုး 목록은 기존 `အခြေခံကုဒ်/`의 JVM 관리 커널에 대한 것이다. တကယ့်ဒေတာ 네이티브 커널의 범위는 `os/လမ်းညွှန်.md`에서 별도로 설명한다.

- ညှိတန်ဖိုး 할당과 해제를 지원하는 မှတ်ဉာဏ်နယ်ပယ် စီမံသူတန်ဖိုး
- လိပ်စာ သတ်မှတ်လိပ်စာနယ်, စာမျက်နှာတန်ဖိုး ချိတ်ဆက်, ရေး 시 တန်ဖိုးမိတ္တူကူး(COW)
- လုပ်ငန်းစဉ် သတ်မှတ်နံပါတ်တန်ဖိုး, ပြင်ဆင် 대기열, fork/wait အခြေအနေတန်ဖိုး
- 과정별 ဖိုင် အညွှန်း, open/read/seek/dup/close
- ELF32 식별 및 ကဏ္ဍတန်ဖိုး စစ်ဆေးချက်
- 키보드·마우스 ဝင်ဒေတာ ဖြစ်ရပ် 대기열
- အစဉ်ဆက်တန်ဖိုး 단말과 네이티브 စက်ပစ္စည်း နယ်နိမိတ်တန်ဖိုး
- 관리 အူတိုင်တန်ဖိုး 전체 자동 စမ်းသပ်မှု

세부 ချိတ်ဆက်ပုံတန်ဖိုး 범위와 아직 필요한 네이티브 연결은 [기능 대응표](စာတမ်း/လုပ်ဆောင်ချက်နှိုင်းယှဉ်.md)에 기록한다.

## 빌드와 စမ်းသပ်မှု

새 네이티브 구현은 `compiler/`와 `os/`에 있다. 기존 `အခြေခံကုဒ်/`의 JVM 관리 커널은 그대로 보존하며, 두 구현의 시험과 기능 범위는 서로 다르다.

```sh
cd /home/user/jkoros
make                 # 네이티브 တွက်ချက်မှု ဥပမာ + Java အူတိုင်တန်ဖိုး ELF
make iso             # os/build/kernel.iso
make run             # QEMU အစဉ်ဆက်တန်ဖိုး အဆုံးသုံးစက်; help ဝင်ဒေတာ (종료는 Ctrl+A, X)
make run-gui         # ISO를 QEMU မျက်နှာပြင်/PS2 키보드로 စက်မောင်း
make vbox            # 전용 VirtualBox VM 자동 ထုတ်လုပ်·စက်မောင်း (GUI)
make vbox-status     # VirtualBox အခြေအနေတန်ဖိုး·ISO·အစဉ်ဆက်တန်ဖိုး မှတ်တမ်းမှတ်တမ်းတစ်ခု လမ်း အတည်ပြု
make test-vbox       # VirtualBox ပရိုဂရမ်စက်နှိုးကိရိယာ အခြေအနေတန်ဖိုး လုပ်ငန်းစဉ်တန်ဖိုးအချက် စမ်းသပ်မှု (တကယ့်ဒေတာ VM တန်ဖိုးပြောင်း 없음)
make test            # ဘာသာပြန်စက် စမ်းသပ်မှု + ELF/ISO စက်တင် 및 အမိန့် ဝင်ဒေတာ စမ်းသပ်မှု
make apps            # 독립 သုံးစွဲသူ ELF ပရိုဂရမ် တည်ဆောက်
make test-network    # သုံးစွဲသူ နည်းစနစ်တန်ဖိုး·UDP 왕복·မှတ်ဉာဏ်ဒေတာ တန်ဖိုးကာကွယ် စမ်းသပ်မှု
make test-java       # 게스트 javac/JVM + OpenJDK 양방향 교차 စက်မောင်း စမ်းသပ်မှု
make posix-kor       # မြန်မာ C 헤더와 တကယ့်ဒေတာ အူတိုင်တန်ဖိုး ခေါ်လုပ် စာကြည့်တိုက်
make test-posix      # ဖိုင်/UDP/သိုလှောင်တန်ဖိုး/Java ဖိုင် အဝင်အထွက် စမ်းသပ်မှု
make -C os run-store # 전용 သိုလှောင်တန်ဖိုး 매체로 QEMU စက်တင်
make legacy-test     # အောက်ဆုံးတန်ဖိုး 기존 JVM 관리 커널의 47개 စမ်းသပ်မှု
```

`compiler/`는 호스트의 `javac`를 문법·အမျိုးပုံစံတန်ဖိုး စစ်ဆေးချက် 전단으로 사용하고 ကိုယ်ပိုင် ဘိုက်ကုဒ်→x86 변환기로 ELF32 기계어를 만든다. 빌드할 때는 JDK가 필요하지만 생성된 커널과 ELF는 ပြင်ပတန်ဖိုး JVM 없이 실행된다. 전체 Java, အရာဝတ္ထုတန်ဖိုး 모델, 표준 라이브러리와 기존 관리 အူတိုင်တန်ဖိုး 전체의 AOT 변환은 아직 지원하지 않는다. 자세한 ထောက်ပံ့မှုတန်ဖိုး 문법과 명령은 [ဘာသာပြန်စက် လမ်းညွှန်](compiler/လမ်းညွှန်.md), တကယ့်ဒေတာ စက်တင် 기능과 한계는 [네이티브 စက်စနစ် လမ်းညွှန်](os/လမ်းညွှန်.md)를 참고한다.

네이티브 셸에 ကိုယ်ပိုင် 제한형 `javac`와 `java`를 추가했다. `edit Demo.java`로 소스를 입력하고 `.save`로 저장한 နောက်တန်ဖိုး `javac Demo.java`, `java Demo`로 **게스트 내부에서 컴파일하고 စက်မောင်း**할 ကိန်းတန်ဖိုး 있다. မူလသတ်မှတ်တန်ဖိုး 예제는 `javac Hello.java`, `java Hello`တတိယအော်ပရန်း. 파일은 RAM에서 동작하며, 전용 သိုလှောင်တန်ဖိုး 매체를 연결하면 `sync`로 재부팅 후에도 보존할 ကိန်းတန်ဖိုး 있다. **OpenJDK/JDK 전체 이식은 아니며**, 단일 အတန်းတန်ဖိုး·တည်ငြိမ်တန်ဖိုး လုပ်ဆောင်ချက်·ကိန်းပြည့်·အက္ခရာစဉ်·အခြေအနေစည်းကမ်း/반복문과 일부 표준 호출을 지원한다. ထောက်ပံ့မှုတန်ဖိုး ဖြတ်နယ်ပယ်, ပြင်ပတန်ဖိုး ဖိုင် 적재와 시험은 [Java ဖွံ့ဖြိုးရေး ဝန်းကျင် လမ်းညွှန်](စာတမ်း/Javaဖွံ့ဖြိုးဝန်းကျင်.md)에 있다.

네이티브 셸에서 `apps`, `run hello first second`, `net`, `run netcheck`를 사용할 ကိန်းတန်ဖိုး 있다. 독립 ELF를 ring 3에 적재하고 `int 0x80` 호출을 통해 အထွက်·အချက်များ·UDP 네트워크를 제공한다. 별도 အိမ်ရှင် 터미널에서 `python3 os/ကိရိယာစု/ဒေတာပြန်ယူ.py --port 9000`을 실행한 နောက်တန်ဖိုး 게스트에서 `run udp 10.0.2.2 9000 hello`로 တကယ့်ဒေတာ 왕복을 확인한다. 새 ပရိုဂရမ် ကိုင်တွယ်သူစာရင်းသွင်း, API 및 제한은 [သုံးစွဲသူ စက်မောင်း·ကွန်ရက်ဆက် လမ်းညွှန်](os/သုံးစွဲသူ/လမ်းညွှန်.md)를 참고한다. လက်ရှိအချက်အလက်တစ်ခု QEMU RTL8139·တည်ငြိမ်တန်ဖိုး IPv4·UDP 전용이며 TCP/DNS는 미지원이며, 전용 IDE သိုလှောင်တန်ဖိုး 형식과 POSIX ဖိုင်/UDP 일부 기능을 추가했다.

`make vbox`는 `jkoros operating system` 전용 VM을 만들고 디스크 없이 ISO로 부팅한다. စက်မောင်း 중이면 유지하고, သိုလှောင်တန်ဖိုး·일시정지 상태이면 재개하며, 꺼져 있을 때만 새 ISO를 빌드해 연결한다. VirtualBox에서 부팅과 셸의 သုံးစွဲသူ ပရိုဂရမ် 실행을 확인했다. 다만 လက်ရှိအချက်အလက်တစ်ခု VirtualBox용 ကွန်ရက်ဆက် 드라이버는 없어 ကွန်ရက်ဆက် 장치를 비활성화한다. UDP 시험에는 `make run`을 사용한다. 상태별 동작과 새 တည်ဆောက် 반영 방법은 [VirtualBox စက်မောင်း လမ်းညွှန်](စာတမ်း/VirtualBoxလုပ်ဆောင်.md)에 있다.

기존 관리 커널만 시험하려면:

```sh
cd /home/user/jkoros
make -f အချက်ဖန်တီး.mk စစ်ဆေးချက်
make -f အချက်ဖန်တီး.mk အိမ်ရှင်
```

`အိမ်ရှင်`는 여전히 JVM 관리 계층의 လှုပ်ရှားမှု 시험이다. `make -f အချက်ဖန်တီး.mk စက်ပုံရိပ်တည်ဆောက်`는 새 `os/`의 제한형 네이티브 အူတိုင်တန်ဖိုး ISO를 만든다. 기존 `အခြေခံကုဒ်/`의 ဖိုင်စနစ်·လုပ်ငန်းစဉ်·ကွန်ရက်အလွှာစု အကောင်အထည်ဖော်မှု 전체를 이 ISO에 이식했다는 의미는 아니다.

မြန်မာ လုပ်ဆောင်ချက်·ကိန်းရှင်တန်ဖိုး·ဖိုင် 이름과 တကယ့်ဒေတာ C API는 [posix-kor](posix-kor/လမ်းညွှန်.md)에 있다. 게스트 Java에서는 `FileInputStream`·`FileOutputStream`의 단일 ဘိုက်တန်ဖိုး 입출력도 지원한다. 전체 POSIX·OpenJDK·Swing 지원으로 확대된 것은 아니다.

ပြင်ပတန်ဖိုး 배포용 `pack.sh` / `unpack.sh`와 자동 의존성 복원은 [ဖြန့်ချိမှုတန်ဖိုး လမ်းညွှန်](distribution/README.md)를 참고하세요.
