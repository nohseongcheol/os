# 자체 ARM64 Java 커널의 C/C++ Файл·루프백 Свързване

이 디렉터리는 `platforms/rpi4-native` 자체 ядро_стойност 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 Български 함수명과 `extern "C"` ABI를 제공한다. `Свързване.c`는 ядро_стойност 안에서 AOT Java Файл 메서드에 직접 연결하고, `потребител_мост.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. действителен_данни Файл 처리는 `Памет_Файлове.java`, 루프백 дейтаграма 처리는 `обръщане_към_себе_си_за_компютър_в_мрежа_мрежа.java`, 연결형 흐름은 `поток_мрежа.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 ядро_стойност 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·Плаващ_пункт_стойност операция_стойност·Файл·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

Поддръжка_стойност: `отварям_Файл`, `파일자료읽기`, `записване_Файл_данни`, `затварям_Файл`, `търся_Файл`, `премахвам_Файл_запис_препратка_към_клетка`, `파일길이정하기`, 보조 функция_стойност `размер_на_файл`. ГРЕШКА 시 -1과 작업별 `Номер_на_грешка`를 반환한다. `фиксиране_място_за_съхранение_на_файлове`은 RAM 파일이므로 ENOSYS를 반환한다. Файл 16개, 각 16384바이트, Име 63바이트, 서술자 16개이며 RAM 디렉터리·крайно_устройство_стойност/절대 경로를 제공한다. разрешение_стойност/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 действителен_данни Български 함수와 독립 구조체를 선언한다.
`Създаване_участник`, `обвързвам_адрес`, `изпращам_дейтаграма_данни/получавам`, `връзка_мрежа/기다리기/получавам`는
`потребител_мост.c`에서 SVC를 호출하며 макрос_стойност 별칭이 아니다. `struct 인터넷통신주소`의
`адрес_семейни`, `номер_на_порт`, `Интернет_адрес.адрес_стойност`을 사용한다. 상수는 enum의
`облак_семейни`, `дейтаграмно_гнездо`, `дейтаграма_протокол`, `поток_мрежа`, `поток_транспортен_протокол`이다.
Български·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. външен_стойност 통신은 자체 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. действителен_данни Pi 4 GENET 드라이버는 미지원이다.
소켓도 действителен_данни функция_стойност `затварям_Файл`로 닫는다.
