# Öz ARM64 JVM 0.4와 Türkçe kitaplık

Türkçe iletişim·özel_durum 사용법은 [Türkçe Java API](한국어자바/안내.md), işlev_değer·değişken_değer·dosya 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

JAR yürütmek_komut, dış_değer IPv4 TCP/UDP, 별도 statik_değer 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 nesne_değer·Thread·Swing은 JVM 경로의 기능이며 AOT Destek_değer 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 yürütmek_komut**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK Sınıf_değer kitaplık 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 Sınıf_değer·statik_değer metot_değer 중심이던 실행기를 nesne_değer·kitaplık yürütmek_komut 기반으로 넓힌 것이다.

## 실행과 derlemek_kaynak

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# Öz çekirdek_değer 안에서 kaynak_ağaç derlemek_kaynak → class yürütmek_komut, Türkçe API 호출
python3 araçlar/yürütmek_Dosya.py sınamalar/자바/한글소스.java

# nesne_değer·özel_durum 등은 konak JDK로 Java 8 class를 만든 후 Öz 커널에서 yürütmek_komut
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java sınamalar/자바/한글시험.java
python3 araçlar/yürütmek_Dosya.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 devir_değer
javac --release 8 -encoding UTF-8 -d build/my-java sınamalar/자바/객체시험.java
python3 araçlar/yürütmek_Dosya.py build/my-java/객체시험.class \
  --include build/my-java/Arka_Plan_değer.class --include build/my-java/dal_değer.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.Sınıf_değer.class`라는 RAM dosya 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.Sınıf_değer`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.Sınıf_değer`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar dosya.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 Türkçe 클래스만 찾는다. dağıtım_değer Türkçe kitaplık JAR는 konak javac의 classpath로 사용하며, 같은 클래스가 kullanıcı_alanı JVM ELF에도 Okuma 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 statik_değer metot_değer, int/boolean/char/String, koşul·öğe_değer_58902391, dize_değer 결합, 일부 dosya 스트림 등의 **Öz 부분집합 derleyici**다. nesne_değer bildirim·상속·try/catch·Thread kullanmak_değer 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 Öz JVM에서 실행한다. Türkçe API 중 metinÇıktısı·문자 스칼라 işlev_değer·dosya Okuma/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] bağımsız_değişkenler) throws Exception {
        Türkçe.Öz.metinÇıktısı.yazma_hat("안녕하세요😀");
        Türkçe.Öz.metinÇıktısı.수쓰기(Türkçe.Öz.문자.kod_öğesi_BAĞ_DEĞ_SAY("한글😀"));
        Türkçe.Öz.dosya.Yazma("인사.txt", "한글 dosya😀");
        Türkçe.Öz.metinÇıktısı.yazma_hat(Türkçe.Öz.dosya.Okuma("인사.txt"));
    }
}
```

## Türkçe API

독립 패키지 **`Türkçe.Öz`**를 사용한다. Linux판 `Türkçe.자바`가 요구하는 NIO/Swing/HTTP API를 Öz 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 Sınıf_değer İsim·metot_değer·bağımsız_değişkenler·alan_değeri·dosya 이름에 한국어를 사용한다. 표준 Java Sınıf_değer 이름은 호환성을 위해 보존한다.

## yürütmek_komut 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(Türkçe Sınıf_değer bildirimler), class당 16 KiB·sabit_değer 풀 511항목, 전체 metot_değer/alan_değeri 각각 512개. metot_değer KOD_değer 8 KiB, yerel_Scope değişken_değer·피연산자 işlenen_Yığın 각각 128슬롯, bağımsız_değişkenler 최대 16개(this bildirimler).
- VM 가닥은 main bildirimler **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 yürütmek_komut 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- nesne_değer 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 fiili_veri 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 dosya·대형 dize_değer·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 komut 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 artış_değer 대기는 기한을 갱신하고 Pencere geçiş_mod 시 중단·재개한다. 일반 sunucu_değer·계산의 무제한 실행은 아직 없다. 미지원 komut·kaynak_değer 부족은 명시적인 오류로 종료한다.
- RAM dosya 최대 64개, 파일당 16384바이트, yol UTF-8 63바이트. RAM 디렉터리와 eş_değer/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 Türkçe class는 RAM dosya 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 geçerli_öğe 경로에서 kaynak_ağaç·Sınıf_değer·veri 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 dış_değer IPv4를 제공한다. fiili_veri GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. veri_birimi 512바이트, yuva_değer 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 yürütmek_komut 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 DİZİ_değer, 완전한 DİZİ_değer 공변성·인터페이스 katman_değer_e65604ef 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/Şifrele_veri/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 Destek_değer 부분집합은 아래 및 개발 매뉴얼을 참고한다. Sınıf_değer dosya 전체 검증기·erişim_girdi izin_değer/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 korumak_değer sınır_değer 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 gerçekleme 단계다: 완전한 JVM değer/doğrulamak_5fb2b747/Sınıf_değer 로더와 özel_durum 모델 → 영속 VFS·mmap·Saat·원자 işlem_değer_c96707fb·fiili_veri 스레드/eşitlemek ABI → OpenJDK java.base 및 native kitaplık 이식 → cihaz_değer 네트워크·TCP/IP → Pencere 시스템/yazı_tipi_değer/입력기·java.desktop → Java SE 호환성 sınamalar. geçerli_öğe Öz JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## JVM 0.3: 네트워크와 GUI uzantı_değer

`Socket`/`ServerSocket` oluşturmak·Bağlan·accept·양방향 InputStream/OutputStream·close·EOF·zaman_değeri 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 dış_değer rakam_değer IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 Bitiş_puan 16개, Java 루프백 버퍼 1024바이트, dış_değer TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. devralmak 이벤트 대기는 yürütmek_komut 기한을 갱신하고 uçbirim geçiş_mod 시 프로세스 상태를 depo_değer·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

Türkçe `Pencere`, `ekran_öğesi`, `cxn_taşıma` 클래스를 dağıtım_değer JAR와 Öz JVM 내장 자원에 추가했다. 상세 metot_değer·제한·kaynak_ağaç·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## Türkçe 객체의 직접 yürütmek_komut

`Pencere`, `Etiket`, `metin_alanı`, `düğme`, `olay_sıra`, `Eylem_uyarı`, `arkaPlanGörevi`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. Öz JVM의 nesne_değer oluşturmak,
biçim_değer 검사, 화면 호출, Olay 큐, yazışma_değer 스케줄러에 Türkçe 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 yürütmek_komut 경로도 유지한다.
Türkçe 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

Öz 실행기의 Türkçe 진입점은 `public static void çalıştır()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 Türkçe 진입점을 우선한다.
명령행 인수는 `실행인수.öğe_BAĞ_DEĞ_SAY()`와 `실행인수.metin(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. statik_değer dosya 예제는 게스트
javac로도 컴파일하며, GUI/yazışma_değer 소스는 konak `javac --release 8`을 사용한다.
직접 GUI/yazışma_değer API는 Öz JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
Türkçe 가닥의 yürütmek_komut·bekle_değer·중복 çalıştır reddetmek_değer, GUI Olay origin_değer·Dizin·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

metot_değer 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
Türkçe 클래스도 실행되지만, dize_değer 리터럴·표준 kitaplık 재정의·native
Bağlan·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 예제](한국어자바/안내.md)를 참고한다.

## uçbirim 부분 yenilemek

taşımak_değer_83b651b8·Boyut 변경은 새 Pencere 영역과 Önceki_öğe 자리에서 드러난 띠만 합성한다.
1920×32 piksel(240 KiB)의 임시 그림에서 배경·겹친 Pencere·karakter_değer·GUI를 먼저

32줄보다 큰 영역은 여러 띠로 처리하므로 전체 프레임을 원자적으로
교체하거나 수직 동기에 맞추는 방식은 아니다. 전체 배경을 먼저 지우는
중간 화면은 표시하지 않는다. 좌표가 같으면 yeniden_denemek_değer 그리지 않는다.
