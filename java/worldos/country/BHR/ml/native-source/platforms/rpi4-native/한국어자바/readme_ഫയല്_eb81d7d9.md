# 한국어 Java 통신·ഇന്_പുട്ട്_ഔട്ട്_പുട്ട്·ഒഴിവാക്കൽ API

패키지는 `한국어.자체`다. ഹോസ്റ്റ് `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·ഫയല്·ഒഴിവാക്കൽ API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 ത്രെഡ്_മൂല്യം API는 자체 JVM 전용이다.
기존 표준 Java లైబ్రరీ 전체의 한국어 번역판은 아니다.

```java
import 한국어.자체.*;

public class നെറ്റ്_വർക്ക് {
    public static void main(String[] 인수) throws ഇന്_പുട്ട്_ഔട്ട്_പുട്ട്_ഒഴിവാക്കൽ {
        കണക്ഷൻ കണക്ടു്_ചെയ്യുക = കണക്ഷൻ.തുറക്കുക("10.0.2.2", 9000);
        try {
            കണക്ടു്_ചെയ്യുക.ടൈംഔട്ട്(700);
            കണക്ടു്_ചെയ്യുക.ഫലം().എഴുത്തു്(문자.부호화("안녕하세요\n"));
            ഇന്_പുട്ട്_തുടര്_ച്ച 입력 = കണക്ടു്_ചെയ്യുക.입력();
            ഫലം.수쓰기(입력.വായന());
        } catch (കാക്കുക_ടൈംഔട്ട്_ഒഴിവാക്കൽ പിശക്) {
            ഫലം.റൈറ്റ്_ചെയ്യുക_ലൈൻ(പിശക്.설명());
        } finally {
            കണക്ടു്_ചെയ്യുക.അടയ്ക്കു();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
ഉപയോക്താവ് 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 സ്ട്രിംഗ്_മൂല്യം 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void നടപ്പിലാക്കുക()`도 진입점으로 받는다.

## 통신과 സ്ട്രീം_മൂല്യം

| ക്ലാസ്_മൂല്യം | 한국어 호출 |
|---|---|
| കണക്ഷൻ | `തുറക്കുക(ഇമെയിൽ, പോര്_ട്ട്_നമ്പര്)`, `입력()`, `ഫലം()`, `ടൈംഔട്ട്(밀리초)`, `പോര്_ട്ട്_നമ്പര്()`, `ലോക്കല്_പോര്_ട്ട്_നമ്പര്()`, `연결됨()`, `닫힘()`, `അടയ്ക്കു()` |
| 수신창구 | `തുറക്കുക(പോര്_ട്ട്_നമ്പര്)`, `받기()`, `പോര്_ട്ട്_നമ്പര്()`, `ടൈംഔട്ട്(밀리초)`, `닫힘()`, `അടയ്ക്കു()` |
| ഇന്_പുട്ട്_തുടര്_ച്ച | `വായന()`, `വായന(byte[])`, `വായന(byte[], നടപ്പിലാക്കുക, ദൈര്_ഘ്യം_മൂല്യം)`, `അടയ്ക്കു()` |
| ഔട്ട്പുട്ട്_തുടര്_ച്ച | `എഴുത്തു്(int)`, `എഴുത്തു്(byte[])`, `എഴുത്തു്(byte[], നടപ്പിലാക്കുക, ദൈര്_ഘ്യം_മൂല്യം)`, `내보내기()`, `അടയ്ക്കു()` |
| 전문통로 | `തുറക്കുക(പോര്_ട്ട്_നമ്പര്)`, `അയയ്ക്കുക(ഇമെയിൽ, പോര്_ട്ട്_നമ്പര്, പദാവലി)`, `받기()`, `ടൈംഔട്ട്(밀리초)`, `പോര്_ട്ട്_നമ്പര്()`, `닫힘()`, `അടയ്ക്കു()` |
| 연결통신 | `തുറക്കുക(...)`, `수신열기(...)`는 위 한국어 객체를 반환 |
| 검사 | `참인지(അവസ്ഥ, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`വായന()`의 ഫയല് 끝은 -1, അരേ_മൂല്യം 읽기의 반환값은 വാസ്തവമായ_ഡാറ്റാ 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. പോര്_ട്ട്_നമ്പര് 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 자체 커널에서 512바이트까지 받으며, 주소는 അക്കം_മൂല്യം IPv4를 사용한다.
`localhost` 루프백 외의 പേരു് 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.കണക്ടു്_ചെയ്യുക/ശ്രദ്ധിക്കുക_അവസാനബിന്ദു/받기`, `통신.തുറക്കുക/അയയ്ക്കുക/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `കണക്ഷൻ`, `수신창구`, `전문통로`를 쓴다.

## 한국어 ഒഴിവാക്കൽ

모든 아래 클래스는 സ്ഥിരസ്ഥിതി_മൂല്യം 생성자, `새예외("설명")` 형태의 സ്ട്രിംഗ്_മൂല്യം 생성자와
`설명()`을 제공한다. വാസ്തവമായ_ഡാറ്റാ സൃഷ്_ടിക്കുക 문법은 `new കാക്കുക_ടൈംഔട്ട്_ഒഴിവാക്കൽ("കാക്കുക_അവസ്ഥ 끝")`이다.

| 한국어 ഒഴിവാക്കൽ | 상위 ക്ലാസ്_മൂല്യം / 용도 |
|---|---|
| ഒഴിവാക്കൽ | `java.lang.Exception`, 직접 던지는 일반 검사 ഒഴിവാക്കൽ |
| 실행예외 | `java.lang.RuntimeException` |
| ഇന്_പുട്ട്_ഔട്ട്_പുട്ട്_ഒഴിവാക്കൽ | `java.io.IOException`, 한국어 ഫയല്·통신 API의 검사 ഒഴിവാക്കൽ |
| കാക്കുക_ടൈംഔട്ട്_ഒഴിവാക്കൽ | `ഇന്_പുട്ട്_ഔട്ട്_പുട്ട്_ഒഴിവാക്കൽ`, 통신 ടൈംഔട്ട് 초과 |
| ഇമെയിൽ_തിരഞ്ഞു_നോക്കൽ_ഒഴിവാക്കൽ | `ഇന്_പുട്ട്_ഔട്ട്_പുട്ട്_ഒഴിവാക്കൽ`, ഇമെയിൽ പരിശോധിക്കുക പരാജയം_മൂല്യം |
| 파일없음예외 | `ഇന്_പുട്ട്_ഔട്ട്_പുട്ട്_ഒഴിവാക്കൽ`, ഫയല് തുറക്കുക പരാജയം_മൂല്യം |
| 통신예외 | `ഇന്_പുട്ട്_ഔട്ട്_പുട്ട്_ഒഴിവാക്കൽ`, 표준 SocketException 변환 |
| അസാധുവായ_ആര്_ഗ്യുമെന്_റ്_ഒഴിവാക്കൽ | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `അസാധുവായ_ആര്_ഗ്യുമെന്_റ്_ഒഴിവാക്കൽ` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| അജ്ഞാത_പരാമര്_ശം_ഒഴിവാക്കൽ | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| അവസ്ഥ_ഒഴിവാക്കൽ | `java.lang.IllegalStateException` |
| ടൈപ്പ്_ചെയ്യുക_കാസ്റ്റ്_ഒഴിവാക്കൽ | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| അരേ_സ്_റ്റോർ_പരാജയം | `java.lang.ArrayStoreException` |
| ത്രെഡ്_അവസ്ഥ_ഒഴിവാക്കൽ | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 കാക്കുക_മൂല്യം 중단 |

`ഒഴിവാക്കൽ`와 `실행예외`는 모든 한국어 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, ഫയല്·통신 전체를 잡으려면 `catch (ഇന്_പുട്ട്_ഔട്ട്_പുട്ട്_ഒഴിവാക്കൽ പിശക്)`를 쓴다.
한국어 API가 표준 ഇന്_പുട്ട്_ഔട്ട്_പുട്ട് 오류를 한국어 예외로 변환한다.
기존 한국어 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`കാക്കുക_ടൈംഔട്ട്_ഒഴിവാക്കൽ`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
ഒഴിവാക്കൽ 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 자체 JVM에 이 20종을 추가했다. 임의의 ഉപയോക്താവ് Throwable 하위 ക്ലാസ്_മൂല്യം 전체를
지원하도록 확장했다는 뜻은 아니다.

## കംപൈല്_ചെയ്യുക_ഉറവിടം·നടപ്പാക്കുക_കമാന്_ഡ്

```sh
cd /home/user/jkoros/platforms/rpi4-native
make ബിൽഡ്_సిస్టమ్
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 ഉപകരണങ്ങൾ/നടപ്പാക്കുക_ഫയല്.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 ഉപയോക്താവ് JVM ELF 안에 탑재된다. `.jar`는 ഹോസ്റ്റ് javac의
ക്ലാസ്_മൂല്യം 경로로 사용한다. ഉറവിടം_ശാഖി 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 한국어 예외의 `throws` 선언과 그 import를 인식한다.
자체 JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·ഓബ്ജക്റ്റ്_മൂല്യം·소켓 예제 전체의 ഉറവിടം_ശാഖി 컴파일은 ഹോസ്റ്റ് javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 수 있다.

വാസ്തവമായ_ഡാറ്റാ TCP/UDP 예제는 [네트워크예제.java](../../../example/java/네트워크예제.java),
നടപ്പാക്കുക_കമാന്_ഡ് 절차는 [example readme_ഫയല്_eb81d7d9](../../../example/README.md),
ഉറവിടം_ശാഖി 명명 원칙은 [명명 readme_ഫയല്_eb81d7d9](../명명/readme_ഫയല്_eb81d7d9.md)에 있다.

## Swing ജാലകം 예제

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` അടുത്തത്_ഇനം `java 창예제`로 연다. പേരു് 입력, 인사하기 버튼,
인사말과 ക്ലിക്ക്_ചെയ്യുക_മൂല്യം 횟수 പുതുക്കിയെടുക്കുക, X 닫기를 지원한다.

| 기능 | 한국어 직접 API |
|---|---|
| Runnable / run | `실행할일.പ്രവര്_ത്തിപ്പിയ്ക്കുക()` |
| ActionListener / actionPerformed | `동작받이.동작받기(동작알림 알림)` |
| ActionEvent | `동작알림.കമാന്_ഡ്_ലിഖിതം()`, `ഇവന്റ്_ഉറവിടം()`, `സൂചിക()` |
| JFrame | `ജാലകം(ജാലകം_ശീർഷകം, 폭, 높이)`, `ചേ൪ക്കുക_ഘടകാംശം(화면구성요소)`, `പ്രദർശനം_ജാലകം()`, `അടയ്ക്കു()`, `보이는가()` |
| JButton | `ബട്ടണ്(പദാവലി, 가로, ലംബം_പദവി, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `ലേബല്(...)`, `പാഠ_മണ്ഡലം(...)` |
| 공통 화면 ഘടകാംശം_മൂല്യം | `화면구성요소.글읽기()`, `റൈറ്റ്_ചെയ്യുക_ലിഖിതം(പദാവലി)`, `자리정하기(가로, ലംബം_പദവി, 폭, 높이)` |
| SwingUtilities.invokeLater | `ഇവന്റ്_ക്യൂ.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `ആരംഭം_ചുമതല()`, `기다리기()`, `살아있는가()`, `താല്_ക്കാലികമായി_നിര്_ത്തുക_ചുമതല()` |
| 명령행 | `നടപ്പിലാക്കുക()`, `실행인수.개수()`, `실행인수.പദാവലി(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `പ്രോസസ്_ത്രെഡ്`가 한국어 ക്ലാസ്_മൂല്യം·విధానం_മൂല്യം·서술자를
해석해 화면 요소와 നടപ്പാക്കുക_കമാന്_ഡ് 가닥을 직접 만든다. നടപടി 알림도 자체 객체이며
콜백으로 `പ്രവര്_ത്തിപ്പിയ്ക്കുക`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 നടപ്പാക്കുക_കമാന്_ഡ് 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 ഹോസ്റ്റ് JVM에서 무동작 객체가 생기지 않도록 하는 നിരസിക്കുക_മൂല്യം 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. ഹോസ്റ്റ് javac로 컴파일한 പിന്നിലേക്ക്_മൂല്യം 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import 한국어.자체.*;
public class 가닥예제 implements 실행할일 {
    public void പ്രവര്_ത്തിപ്പിയ്ക്കുക() { ഫലം.റൈറ്റ്_ചെയ്യുക_ലൈൻ("한국어 작업 നടപ്പാക്കുക_കമാന്_ഡ്"); }
    public static void നടപ്പിലാക്കുക() throws 대기중단예외 {
        작업가닥 ത്രെഡ്_മൂല്യം = 작업.നടപ്പിലാക്കുക(new 가닥예제());
        작업.기다리기(ത്രെഡ്_മൂല്യം);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
അരേ_മൂല്യം 인수 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 인수 없는 `നടപ്പിലാക്കുക()`을 우선한다.
기존 한국어 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.നടപ്പിലാക്കുക(Runnable)`을 사용하던 코드는 새 한국어 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API പിന്തുണ_മൂല്യം 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 ക്ലാസ്_മൂല്യം·విధానం_മൂല്യം 이름과 서술자가 남는다.
한국어 പേരു് 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·విధానం_മൂല്യം 재정의, native കണക്ടു്_ചെയ്യുക, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS ఐడెంటిఫయర్_മൂല്യം](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS విధానం_മൂല്യം റഫറൻസ്](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
