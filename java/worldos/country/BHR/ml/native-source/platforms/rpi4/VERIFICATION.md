# 배포 ബിൽഡ്_ഇമേജ് സാധൂകരിക്കുക ലോഗ്_രേഖ

검증일: 2026-09-27 (Asia/Seoul)

ലക്_ഷ്യം: `jkoros-rpi4-aarch64-349b52891a471c8e782da597`

이번 배포는 Raspberry Pi 4용 **ARM64 Linux 실행판**이다. 기존 자체 x86 커널을 ARM으로 이식한 결과가 아니다. വാസ്തവമായ_ഡാറ്റാ Pi 보드는 연결되어 있지 않아 하드웨어 부팅 성공을 확인하지 못했다.

## 구현 범위와 남은 സാധൂകരിക്കുക

### QEMU 그래픽 നടപ്പാക്കുക_കമാന്_ഡ് 보완

ടെ_ര്മിനല് 전용 실행에서 `인사.java`가 Swing 창을 만들 때 발생한 `HeadlessException`을 해결하기 위해 `make run`과 `make run-console`을 추가했다. 그래픽 실행은 bochs 가상 GPU, USB 키보드·태블릿, Xorg, 로컬 VNC를 사용한다. QEMU 전용 initramfs가 필요한 드라이버를 기존 루트 파일시스템에서 로딩한다. 배포 시스템 이미지와 base-id는 변경하지 않아 기존 ഉപയോക്താവ് ഡാറ്റാ 이미지를 계속 사용할 수 있다.

വാസ്തവമായ_ഡാറ്റാ Xorg/VNC 화면에서 한국어 Java వర్క్_స్పేస్, Swing 시험 ജാലകം, 기존 이미지의 `인사.java` 창을 표시했다. VNC를 통한 USB 마우스 클릭과 키보드 입력이 Swing 이벤트로 전달되는 것도 확인했다. പുറത്തുകടക്കൽ_പ്രോഗ്രാം 시 시스템 OverlayFS와 ഡാറ്റാ 파일시스템의 വായന 전용 전환을 확인했다. 이번 시험은 Xvfb를 사용하지 않는다.

- [키보드·마우스 시험 화면](build/verification/desktop-input.png)

ഉറവിടം 예제에는 `GraphicsEnvironment.isHeadless()` 분기를 추가했다. 화면이 없는 환경에서는 ഫയല്·문자·스레드 기능을 실행하고 안내를 출력한다. ഉപയോക്താവ് 홈의 기존 원문을 자동 교체하지는 않는다. 향후 ബിൽഡ്_ഇമേജ് 빌드에는 udev의 `add` 이벤트를 명시적으로 발생시키는 수정도 반영된다.

### 한글 입력·ഫോണ്ട്_മൂല്യം 보완

`make test-korean`으로 വാസ്തവമായ_ഡാറ്റാ Xorg/VNC 화면의 Swing 입력창과 xterm에서 Ctrl+Space സ്വിച്ച്_മോഡ് 및 두벌식 കീ_മൂല്യം 입력을 시험했다. 양쪽에서 `한글 입력`을 조합했고 UTF-8 파일의 내용과 일치했다. 시험은 별도 ഉപയോക്താവ് ഡാറ്റാ 이미지에서 실행했으며 정상 പുറത്തുകടക്കൽ_പ്രോഗ്രാം 시 두 파일시스템의 വായന 전용 전환을 확인했다.

ടെ_ര്മിനല് ഫോണ്ട്_മൂല്യം 진단에서 영문 DejaVu Sans Mono와 한글 Noto Sans Mono CJK KR의 വാസ്തവമായ_ഡാറ്റാ ഫയല് 로딩을 확인했다. 한글용으로 요청한 글꼴이 영문 전용 글꼴로 대체되던 Fontconfig 규칙의 우선순위도 수정했다. 화면 캡처에서 한글·영문 പ്രദർശനം_മൂല്യം, Java 작업마당의 확대된 글꼴과 안티앨리어싱을 확인했다.

수정은 QEMU 전용 initramfs를 통해 ഉപയോക്താവ് 시스템 변경분에 적용하며 배포 സ്ഥിരസ്ഥിതി_മൂല്യം 이미지와 base-id는 유지한다. 기존 ഫയല് 백업, 동일 수정의 ആവര്_ത്തനം_മൂല്യം 적용 방지, 손상된 수정 ഫയല് 및 다른 base-id നിരസിക്കുക_മൂല്യം, ഉപയോക്താവ് 입력기 സജ്ജീകരണം 병합에 대한 ഹോസ്റ്റ് 시험 4개도 통과했다. 원래 ഉപയോക്താവ് ഡാറ്റാ ബിൽഡ്_ഇമേജ് `build/manual-user.img`는 시험에 사용하지 않았다.

### 남은 ക്ലിപ്പ്

- 새 കംപൈല്_ചെയ്യുക_ഉറവിടം ലക്_ഷ്യം `openjdk`는 **네이티브 പ്രോഗ്രാം_ആപ്പ്_ഡ്രോയർ + JVM/JRE** 방식이다. 모든 Java 바이트코드를 JVM 없이 기계어로 변환하는 범용 AOT 컴파일러는 구현하지 않았다. 기존 x86 AOT의 പിന്തുണ_മൂല്യം 범위는 여전히 제한적이다.
- നടപ്പാക്കുക_കമാന്_ഡ് 프로그램에는 main എന്_ട്രി_പോയിന്_റ്, 호환 ക്ലാസ്_മൂല്യം 버전과 의존 JAR/JNI가 필요하다. 개별 상용 പ്രോഗ്രാം_f5044b9b, 모든 Java മൊഡ്യൂൾ_മൂല്യം, 모든 문자권을 시험한 것은 아니다.
- 한국어 Java 라이브러리는 ഫയല്·문자·통신·스레드·Swing을 위한 보조 API이며 JDK 전체 API의 한국어 번역판은 아니다.
- Pi 4 전용 펌웨어·കെര്_ണല്_മൂല്യം·മൊബൈൽ_മൂല്യം 트리는 이미지에 들어 있지만 വാസ്തവമായ_ഡാറ്റാ SD 부팅, HDMI/KMS, USB, Wi-Fi, 물리 키보드의 한글 입력은 실기 확인이 남아 있다. QEMU는 Pi 장치를 에뮬레이션하는 시험이 아니다.
- ഉപയോക്താവ് ഡയറക്ടറി_മൂല്യം 이동은 동일 시스템 ബിൽഡ്_ഇമേജ് ఐడెంటిఫయర్_മൂല്യം, ARM64, `/home/user`, UID 1000을 전제로 한다. പുറത്തുകടക്കൽ_പ്രോഗ്രാം 후 소유권·അനുമതി_മൂല്യം·링크·വിപുലീകരണം_മൂല്യം ആട്രിബ്യൂട്ട്_മൂല്യം·삭제 정보를 보존하여 복사해야 한다. 다른 OS 버전으로의 자동 이관은 제공하지 않는다.

ഇന്_സ്റ്റാള്_ചെയ്യുക_മൂല്യം·ദൃഷ്ടാന്തം_മൂല്യം 절차는 [README.md](README.md), കംപൈല്_ചെയ്യുക_ഉറവിടം 방식은 [OpenJDK നടപ്പാക്കുക_കമാന്_ഡ് ഫയല് readme_ഫയല്_eb81d7d9](../../compiler/OpenJDK-നിര്_വ്വഹണക്ഷമമായ_ഫയല്.md)를 따른다. ബിൽഡ്_ഇമേജ് 파일만 생성했으며 വാസ്തവമായ_ഡാറ്റാ SD 카드나 USB 디스크에 기록하지 않았다.
