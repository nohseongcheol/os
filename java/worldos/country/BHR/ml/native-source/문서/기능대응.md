# engos 기능 대응표

이 표는 기존 `പാരമ്പര്യ_ഉറവിടം/`의 ഓബ്ജക്റ്റ്_മൂല്യം 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [വാസ്തവമായ_ഡാറ്റാ 부팅 기능과 한계](../os/readme_ഫയല്_eb81d7d9.md)를 따로 기록한다.

## Java 관리 ലെയര്_മൂല്യം 구현 완료

## 기존 ഓബ്ജക്റ്റ്_മൂല്യം 기반 관리 കെര്_ണല്_മൂല്യം 전체를 부팅하기 위해 남은 കണക്ടു്_ചെയ്യുക

അടുത്തത്_ഇനം 항목은 Java 문법만으로 실행할 수 없는 CPU/മൊബൈൽ_മൂല്യം 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot എന്_ട്രി_പോയിന്_റ്_മൂല്യം, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 സന്ദര്_ഭം_മൂല്യം സ്_റ്റോർ_മൂല്യം
- വാസ്തവമായ_ഡാറ്റാ PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA ലൂപ്_മൂല്യം
- Java ഓബ്ജക്റ്റ്_മൂല്യം·അരേ_മൂല്യം ലിങ്ക്_ലേഔട്ട്, ഒഴിവാക്കൽ, സ്ഥിരമായ_മൂല്യം തുടക്കമിടുക, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT വേദി_മൂല്യം
- FAT 디스크 구역을 വാസ്തവമായ_ഡാറ്റാ ATA 장치와 연결하는 ഇന്_പുട്ട്_ഔട്ട്_പുട്ട് 접착 ലെയര്_മൂല്യം

위 관리 계층은 engos 기능의 Java 관리 구현과 ഹോസ്റ്റ് 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot എന്_ട്രി_പോയിന്_റ്_മൂല്യം, സ്ഥിരമായ_മൂല്യം തുടക്കമിടുക·പൂര്_ണ്ണസംഖ്യ അരേ_മൂല്യം, VGA/직렬/PS2, 명령해석기, ഉപയോക്താവ് ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 ഹോസ്റ്റ് 루프백 패킷 왕복을 검증했다. 위 표의 ഓബ്ജക്റ്റ്_മൂല്യം 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
