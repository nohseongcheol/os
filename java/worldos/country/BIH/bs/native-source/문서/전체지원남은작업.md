# 전체 Podrška_VALUE 요청의 trenutno_stavka stanje_VALUE

HTTP_zahtjev 전체는 아직 완료되지 않았다. trenutno_stavka ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 stvaran_podaci C POSIX 일부 기능, 한국어 API/IZVOR Naziv, IDE Fajl 보존, 게스트 Java Fajl 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/Pročitaj_me_eb81d7d9.md)를 기준으로 판단한다.

| HTTP_zahtjev 분야 | trenutno_stavka Izvrši_komanda 가능한 isječak | 전체 지원에 필요한 작업 |
|---|---|---|
| Java napraviti_izvor·Izvrši_komanda | 게스트 제한형 javac/JVM, statični_VALUE 단일 클래스와 일부 표준 objekt_VALUE | 일반 objekt_VALUE·klasa_VALUE Spoji_se·izuzetak·GC·스레드, 완전한 javac와 표준 klasa_VALUE biblioteka |
| Fajl | POSIX 서술자, Java 단일 bajt_VALUE Fajl tok_VALUE, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·dozvola_VALUE·잠금·일반 fajl_sistem·ekstenzija_VALUE 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP organizator 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 događaj·font_VALUE·prozor operativni_sistem_VALUE, AWT 네이티브 연결과 Swing Izvrši_komanda 기반 |
| POSIX | 문서화한 Fajl·단말·UDP 부분 | proces_VALUE·exec/fork·스레드·시그널·TIME_VALUE·mmap·poll·파이프 등과 적합성 ovjeriti |
| 언어별 Naziv | 한국어 46개 대응 unos_VALUE, stvaran_podaci C/Java/Fajl Naziv 적용 | cilj Jezik 확정, 언어별 용례·역사 근거와 해당 IZVOR·도구의 ovjeriti |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 Izvrši_komanda 환경을 추가하는 방식은 별도의 jezgro_VALUE·루트 fajl_sistem·OpenJDK·그래픽 server_VALUE·영구 Store_VALUE 구성을 가진 Izvrši_komanda 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

Izvrši_komanda 기반과 추가 cilj 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. trenutno_stavka 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
