# 한국어 Java 통신·увод_вывад·выключэнне API

패키지는 `한국어.자체`다. вузел `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·Файл·выключэнне API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 паток_значэнне_5b72a632 API는 자체 JVM 전용이다.
기존 표준 Java бібліятэка 전체의 한국어 번역판은 아니다.

```java
import 한국어.자체.*;

public class Сетка {
    public static void main(String[] 인수) throws увод_вывад_выключэнне {
        кантакт Злучыцца = кантакт.Адкрыць("10.0.2.2", 9000);
        try {
            Злучыцца.대기시간(700);
            Злучыцца.Выхад().Запіс(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = Злучыцца.입력();
            Выхад.수쓰기(입력.Чытанне());
        } catch (대기시간초과예외 ПАМЫЛКА) {
            Выхад.напісаць_лінія(ПАМЫЛКА.설명());
        } finally {
            Злучыцца.Закрыць();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
карыстальнік 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 радок_значэнне 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void Выканаць()`도 진입점으로 받는다.

## 통신과 паток_значэнне

| клас_значэнне | 한국어 호출 |
|---|---|
| кантакт | `Адкрыць(адрас, нумар_порта)`, `입력()`, `Выхад()`, `대기시간(밀리초)`, `нумар_порта()`, `мясцовы_нумар_порта()`, `연결됨()`, `닫힘()`, `Закрыць()` |
| 수신창구 | `Адкрыць(нумар_порта)`, `받기()`, `нумар_порта()`, `대기시간(밀리초)`, `닫힘()`, `Закрыць()` |
| 입력흐름 | `Чытанне()`, `Чытанне(byte[])`, `Чытанне(byte[], Выканаць, даўжыня_значэнне)`, `Закрыць()` |
| 출력흐름 | `Запіс(int)`, `Запіс(byte[])`, `Запіс(byte[], Выканаць, даўжыня_значэнне)`, `내보내기()`, `Закрыць()` |
| 전문통로 | `Адкрыць(нумар_порта)`, `адправіць(адрас, нумар_порта, Тэкст)`, `받기()`, `대기시간(밀리초)`, `нумар_порта()`, `닫힘()`, `Закрыць()` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`Чытанне()`의 Файл 끝은 -1, масіў_значэнне 읽기의 반환값은 фактычны_дадзеныя 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. нумар_порта 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 자체 커널에서 512바이트까지 받으며, 주소는 лічба_значэнне IPv4를 사용한다.
`localhost` 루프백 외의 Назва 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.Злучыцца/듣기/받기`, `통신.Адкрыць/адправіць/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `кантакт`, `수신창구`, `전문통로`를 쓴다.

## 한국어 выключэнне

모든 아래 클래스는 значэнне_па_змаўчанні 생성자, `새예외("설명")` 형태의 радок_значэнне 생성자와
`설명()`을 제공한다. фактычны_дадзеныя 생성 문법은 `new 대기시간초과예외("чакае_стан 끝")`이다.

| 한국어 выключэнне | 상위 клас_значэнне / 용도 |
|---|---|
| выключэнне | `java.lang.Exception`, 직접 던지는 일반 검사 выключэнне |
| 실행예외 | `java.lang.RuntimeException` |
| увод_вывад_выключэнне | `java.io.IOException`, 한국어 Файл·통신 API의 검사 выключэнне |
| 대기시간초과예외 | `увод_вывад_выключэнне`, 통신 대기시간 초과 |
| 주소확인예외 | `увод_вывад_выключэнне`, адрас праверыць няўдача_значэнне |
| 파일없음예외 | `увод_вывад_выключэнне`, Файл Адкрыць няўдача_значэнне |
| 통신예외 | `увод_вывад_выключэнне`, 표준 SocketException 변환 |
| памылковы_аргумент_выключэнне | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `памылковы_аргумент_выключэнне` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| 빈참조예외 | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| стан_выключэнне | `java.lang.IllegalStateException` |
| друкаваць_вяшчаць_выключэнне | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| масіў_сховішча_няўдача | `java.lang.ArrayStoreException` |
| паток_стан_выключэнне | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 чакае_значэнне 중단 |

`выключэнне`와 `실행예외`는 모든 한국어 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, Файл·통신 전체를 잡으려면 `catch (увод_вывад_выключэнне ПАМЫЛКА)`를 쓴다.
한국어 API가 표준 увод_вывад 오류를 한국어 예외로 변환한다.
기존 한국어 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
выключэнне 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 자체 JVM에 이 20종을 추가했다. 임의의 карыстальнік Throwable 하위 клас_значэнне 전체를
지원하도록 확장했다는 뜻은 아니다.

## будаваць_крыніца·выканаць_каманда

```sh
cd /home/user/jkoros/platforms/rpi4-native
make зборка_сістэма
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 Інструменты/выканаць_файл.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 карыстальнік JVM ELF 안에 탑재된다. `.jar`는 вузел javac의
клас_значэнне 경로로 사용한다. крыніца_дрэва 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 한국어 예외의 `throws` 선언과 그 import를 인식한다.
자체 JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·аб_ект_значэнне·소켓 예제 전체의 крыніца_дрэва 컴파일은 вузел javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 수 있다.

фактычны_дадзеныя TCP/UDP 예제는 [네트워크예제.java](../../../example/java/네트워크예제.java),
выканаць_каманда 절차는 [example файл_звестак_eb81d7d9](../../../example/README.md),
крыніца_дрэва 명명 원칙은 [명명 файл_звестак_eb81d7d9](../명명/файл_звестак_eb81d7d9.md)에 있다.

## Swing акно 예제

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` 다음 `java 창예제`로 연다. Назва 입력, 인사하기 버튼,
인사말과 націснуць_значэнне 횟수 абнавіць, X 닫기를 지원한다.

| 기능 | 한국어 직접 API |
|---|---|
| Runnable / run | `실행할일.Выкананне()` |
| ActionListener / actionPerformed | `동작받이.동작받기(동작알림 알림)` |
| ActionEvent | `동작알림.каманда_Тэкст()`, `падзея_крыніца()`, `індэкс()` |
| JFrame | `акно(акно_Загаловак, 폭, 높이)`, `дадаць_элемент(화면구성요소)`, `паказаць_акно()`, `Закрыць()`, `보이는가()` |
| JButton | `кнопка(Тэкст, 가로, 세로, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `Адмеціна(...)`, `Тэкст_поле(...)` |
| 공통 화면 элемент_значэнне | `화면구성요소.글읽기()`, `напісаць_Тэкст(Тэкст)`, `자리정하기(가로, 세로, 폭, 높이)` |

| 명령행 | `Выканаць()`, `실행인수.개수()`, `실행인수.Тэкст(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `Працэс_паток`가 한국어 клас_значэнне·спосаб_значэнне·서술자를
해석해 화면 요소와 выканаць_каманда 가닥을 직접 만든다. Дзеянне 알림도 자체 객체이며
콜백으로 `Выкананне`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 выканаць_каманда 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 вузел JVM에서 무동작 객체가 생기지 않도록 하는 адхіліць_значэнне 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. вузел javac로 컴파일한 Назад_значэнне 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import 한국어.자체.*;
public class 가닥예제 implements 실행할일 {
    public void Выкананне() { Выхад.напісаць_лінія("한국어 작업 выканаць_каманда"); }
    public static void Выканаць() throws 대기중단예외 {
        작업가닥 паток_значэнне_5b72a632 = 작업.Выканаць(new 가닥예제());
        작업.기다리기(паток_значэнне_5b72a632);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
масіў_значэнне 인수 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 인수 없는 `Выканаць()`을 우선한다.
기존 한국어 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.Выканаць(Runnable)`을 사용하던 코드는 새 한국어 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API апора_значэнне 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 клас_значэнне·спосаб_значэнне 이름과 서술자가 남는다.
한국어 Назва 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·спосаб_значэнне 재정의, native Злучыцца, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS ідэнтыфікатар_значэнне](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS спосаб_значэнне Даведачныя_матэрыялы](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
