# JBraOS 構造

아래는 オブジェクト値 基盤 관리 中核値 전체의 対象オブジェクト 구조다. 現在項目 実際データ 起動 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 稼働システム 案内](../os/案内.md)에 実装 범위를 명시한다. 아래의 GC·文脈値 切替方式·ファイルシステム 등이 새 ISO에 全体構築 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 最小値 부트·트랩 階層値
  ↓
Java AOT 실행기와 オブジェクト値·配列値·GC 런타임
  ↓
機器値 境界位置値
  ↓
Java 관리 中核値
  ├─ 記憶領域/ページ管理業務/COW
  ├─ プロセス値/배정/wait
  ├─ ファイルシステム/ELF/POSIX
  └─ 入力値/記憶装置装置/通信網
```

OpenJDK 자체는 이미 운영체제가 제공하는 ファイル, 스레드, 가상 기억공간을 전제로 한다. 따라서 中核値 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java バイトコード AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, 文脈値 저장처럼 Java로 표현할 数 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
