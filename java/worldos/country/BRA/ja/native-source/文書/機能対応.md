# engos 기능 대응표

이 표는 기존 `基幹ソース/`의 オブジェクト値 基盤 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [実際データ 起動 기능과 境界位置上限](../os/案内.md)를 따로 기록한다.

## 기존 オブジェクト値 基盤 관리 中核値 전체를 부팅하기 위해 남은 接続

次回項目 항목은 Java 문법만으로 실행할 数 없는 CPU/装置 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot 入口点値, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 文脈値 格納値
- 実際データ PIC/PIT/PS2/ATA/PCI 機器ポート 및 AMD PCnet DMA ループ値
- Java オブジェクト値·配列値 連結配置, 例外, 静的値 初期化, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT 工程値
- FAT 디스크 구역을 実際データ ATA 장치와 연결하는 入力出力 접착 階層値

上端値 관리 계층은 engos 기능의 Java 관리 구현과 ホスト 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot 入口点値, 静的値 初期化·整数値 配列値, VGA/直列値/PS2, 命令解釈器, 利用者 ELF/ring 3/시스템 呼出, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 ホスト 루프백 패킷 왕복을 검증했다. 上端値 표의 オブジェクト値 基盤 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
