# Asli ARM64 JVM 0.4와 Melayu pustaka

Melayu 통신·pengecualian 사용법은 [Melayu Java API](한국어자바/README_eb81d7d9.md), fungsi_VALUE·pemboleh_ubah_VALUE·Fail 이름의 변경과 어원 근거는 [명명 README_eb81d7d9](명명/README_eb81d7d9.md)를 참고한다.

JAR laksanakan_perintah, 외부 IPv4 TCP/UDP, 별도 statik_VALUE 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 objek_VALUE·Thread·Swing은 JVM 경로의 기능이며 AOT Sokongan_VALUE 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 laksanakan_perintah**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK Kelas_VALUE pustaka 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 Kelas_VALUE·statik_VALUE kaedah_VALUE 중심이던 실행기를 objek_VALUE·pustaka laksanakan_perintah 기반으로 넓힌 것이다.

## 실행과 bina_sumber

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# Asli kernel_VALUE 안에서 sumber_pepohon bina_sumber → class laksanakan_perintah, Melayu API 호출
python3 alat/laksanakan_fail.py ujian/자바/한글소스.java

# objek_VALUE·pengecualian 등은 hos JDK로 Java 8 class를 만든 후 Asli 커널에서 laksanakan_perintah
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java ujian/자바/한글시험.java
python3 alat/laksanakan_fail.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 pindah_VALUE
javac --release 8 -encoding UTF-8 -d build/my-java ujian/자바/객체시험.java
python3 alat/laksanakan_fail.py build/my-java/객체시험.class \
  --include build/my-java/latar_VALUE.class --include build/my-java/cabang_VALUE.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.Kelas_VALUE.class`라는 RAM Fail 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.Kelas_VALUE`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.Kelas_VALUE`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar Fail.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 Melayu 클래스만 찾는다. 배포 Melayu pustaka JAR는 hos javac의 classpath로 사용하며, 같은 클래스가 ruang_pengguna JVM ELF에도 Baca 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 statik_VALUE kaedah_VALUE, int/boolean/char/String, syarat·lelaran_VALUE, rentetan_VALUE 결합, 일부 Fail 스트림 등의 **Asli 부분집합 컴파일러**다. objek_VALUE pengisytiharan_4f4f026b·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 Asli JVM에서 실행한다. Melayu API 중 출력·문자 스칼라 fungsi_VALUE·Fail Baca/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] 인수) throws Exception {
        Melayu.Asli.출력.tulis_baris("안녕하세요😀");
        Melayu.Asli.출력.수쓰기(Melayu.Asli.문자.titik_kod_COUNT("한글😀"));
        Melayu.Asli.Fail.Tulis("인사.txt", "한글 Fail😀");
        Melayu.Asli.출력.tulis_baris(Melayu.Asli.Fail.Baca("인사.txt"));
    }
}
```

## Melayu API

독립 패키지 **`Melayu.Asli`**를 사용한다. Linux판 `Melayu.자바`가 요구하는 NIO/Swing/HTTP API를 Asli 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 Kelas_VALUE Nama·kaedah_VALUE·인수·medan_VALUE·Fail 이름에 한국어를 사용한다. 표준 Java Kelas_VALUE 이름은 호환성을 위해 보존한다.

| Kelas_VALUE | 공개 기능 | 이름의 의미 |
|---|---|---|
| 출력 | Tulis, tulis_baris, 수쓰기 | 출력(出力): 내용을 바깥으로 내보냄 |
| 문자 | kepanjangan_VALUE, 같음, tampal_SMS, potong_VALUE, hurai_integer/tulis_integer_VALUE, titik_kod_COUNT, 부호화/nyahsulit_data | 문자(文字), pengekodan_VALUE(符號): 글의 단위와 그 값을 바이트로 나타내는 penapis_VALUE |
| Fail | Baca/Tulis(String Nama), 바이트읽기/tulis_bait_VALUE | 널리 쓰는 ruang_pengguna 용어를 보존; RAM 자료의 Nama |
| pemasukan_Senarai | 더하기, Baca, ganti_VALUE, padam_pemasukan, Saiz, 비었는가, buang_TOC | pemasukan_Senarai(目錄): 순서가 있는 pemasukan_VALUE 모음 |

## laksanakan_perintah 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(Melayu Kelas_VALUE pengisytiharan), class당 16 KiB·pemalar_VALUE 풀 511항목, 전체 kaedah_VALUE/medan_VALUE 각각 512개. kaedah_VALUE kod_VALUE 8 KiB, setempat_Skop pemboleh_ubah_VALUE·피연산자 스택 각각 128슬롯, 인수 최대 16개(this pengisytiharan).
- VM 가닥은 main pengisytiharan **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 laksanakan_perintah 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- objek_VALUE 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 sebenar_data 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 Fail·대형 rentetan_VALUE·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 Perintah 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 Tetingkap tukar_mod 시 중단·재개한다. 일반 pelayan_VALUE·계산의 무제한 실행은 아직 없다. 미지원 Perintah·sumber_VALUE 부족은 명시적인 오류로 종료한다.
- RAM Fail 최대 64개, 파일당 16384바이트, LALUAN UTF-8 63바이트. RAM 디렉터리와 rakan_VALUE/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 Melayu class는 RAM Fail 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 현재 경로에서 sumber_pepohon·Kelas_VALUE·data 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 외부 IPv4를 제공한다. sebenar_data GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. 전문 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 laksanakan_perintah 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 ARRAY_VALUE, 완전한 ARRAY_VALUE 공변성·인터페이스 lapisan_VALUE 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/sulitkan_data/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 Sokongan_VALUE 부분집합은 아래 및 개발 매뉴얼을 참고한다. Kelas_VALUE Fail 전체 검증기·capai_pemasukan keizinan_VALUE/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 lindung_VALUE 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 pelaksanaan 단계다: 완전한 JVM VALUE/sahkan/Kelas_VALUE 로더와 pengecualian 모델 → 영속 VFS·mmap·Jam·원자 operasi_VALUE·sebenar_data 스레드/segerak ABI → OpenJDK java.base 및 native pustaka 이식 → peranti_VALUE 네트워크·TCP/IP → Tetingkap 시스템/fon_VALUE/입력기·java.desktop → Java SE 호환성 ujian. 현재 Asli JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## JVM 0.3: 네트워크와 GUI sambungan_VALUE

`Socket`/`ServerSocket` jana·Sambung·accept·양방향 InputStream/OutputStream·close·EOF·nilai_masa 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 외부 digit_VALUE IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 tamat_p 16개, Java 루프백 버퍼 1024바이트, 외부 TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. interaktif 이벤트 대기는 laksanakan_perintah 기한을 갱신하고 Terminal tukar_mod 시 프로세스 상태를 stor_VALUE·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

Melayu `Tetingkap`, `unsur_skrin`, `연결통신` 클래스를 배포 JAR와 Asli JVM 내장 자원에 추가했다. 상세 kaedah_VALUE·제한·sumber_pepohon·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## Melayu 객체의 직접 laksanakan_perintah

`Tetingkap`, `label`, `medan_teks`, `Butang`, `acara_baris`, `동작알림`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. Asli JVM의 objek_VALUE jana,
format_VALUE 검사, 화면 호출, Peristiwa 큐, urutan_VALUE 스케줄러에 Melayu 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 laksanakan_perintah 경로도 유지한다.
Melayu 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

Asli 실행기의 Melayu 진입점은 `public static void Jalan()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 Melayu 진입점을 우선한다.
명령행 인수는 `실행인수.item_COUNT()`와 `실행인수.Teks(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. statik_VALUE Fail 예제는 게스트
javac로도 컴파일하며, GUI/urutan_VALUE 소스는 hos `javac --release 8`을 사용한다.
직접 GUI/urutan_VALUE API는 Asli JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
Melayu 가닥의 laksanakan_perintah·tunggu_VALUE·중복 Jalan tolak_VALUE, GUI Peristiwa 출처·INDEX·콜백을 검사한다.
