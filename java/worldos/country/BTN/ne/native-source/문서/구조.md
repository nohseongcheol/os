# JBtnOS 구조

아래는 वस्तु_मान 기반 관리 कर्णेल_मान 전체의 लक्ष्य_वस्तु 구조다. 현재 वास्तविक_लगत 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 सञ्चालनप्रणाली readme_फाइल_eb81d7d9](../os/readme_फाइल_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·प्रसङ्ग_मान परिवर्तन_मोड·फाइल_प्रणाली 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 तह_मान
  ↓
Java AOT 실행기와 वस्तु_मान·विन्यास_मान·GC 런타임
  ↓
हार्डवेयर_मान 경계
  ↓
Java 관리 कर्णेल_मान
  ├─ 기억공간/쪽관리/COW
  ├─ प्रक्रिया_मान/배정/wait
  ├─ फाइल_प्रणाली/ELF/POSIX
  └─ 입력/भण्डारण_मोबाइल/सञ्जाल_चाङ
```

OpenJDK 자체는 이미 운영체제가 제공하는 फाइल, 스레드, 가상 기억공간을 전제로 한다. 따라서 कर्णेल_मान 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, प्रसङ्ग_मान 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
