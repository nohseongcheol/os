요청 전체는 아직 완료되지 않았다. ga_jaana_selwana ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 tota_tshedimosetso C POSIX 일부 기능, 한국어 API/Motswedi leina, IDE faele 보존, 게스트 Java faele 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/MPUISE_eb81d7d9.md)를 기준으로 판단한다.

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 diragatsa_Taelo 환경을 추가하는 방식은 별도의 Khenele_Boleng·루트 setsamaisadifaele·OpenJDK·그래픽 sefara_Boleng·영구 Store_Boleng 구성을 가진 diragatsa_Taelo 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

diragatsa_Taelo 기반과 추가 setotwa 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. ga_jaana_selwana 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
