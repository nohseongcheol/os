# Raspberry Pi 4 ذاتي Java نواة_قيمة — فضاء_المستخدم ينفذ_أمر 기반

حديث_عنصر ذاتي 코드의 COSL 상업 شرط, 제3자 고지 및 LGPL 재연결 자료는 [COSL توزيع_قيمة 안내](COSL배포안내.md)를 참고한다. تبديل_الوضع 전 GPL 구성의 판단은 [이전 라이선스 검토](ترخيص_تقييم.md)에 기록했다.

العربية 통신·استثناء 사용법은 [العربية Java API](한국어자바/안내.md), دالة_قيمة·متغيّر_قيمة·ملف 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

Linux 없이 부팅하는 ذاتي AArch64 커널이다. Java AOT نواة_قيمة 위에 **سطر_الأوامر 셸, 게스트 Java محول_برمجي·JVM, MicroPython, EL0 C++ ينفذ_أمر, ملف·UDP 루프백 시스템 호출, 여러 한글 GUI طرفية·vi محرر·Swing 부분집합**을 제공한다. 커널의 ملف بيانات/정책·루프백 نقل_قيمة_630ba093·셸 상태는 Java, 화면 합성·عنصر_صورة يغيّر_قيمة·مؤشر·클리핑도 Java로 구현하며, CPU/MMU/جهاز_قيمة 경계와 طرفية·حرف_قيمة 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 ذاتي 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 ينفذ_أمر, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 سلكي_قيمة 송수신은 아직 미검증이다.** ينفذ_أمر·صديق_e05f319b·رمز_الوصول_قيمة 확인은 [خارجي_قيمة صديق_e05f319b 안내](خارجي_صديق_دليل.md)에 정리했다.

셸은 EL1 نواة_قيمة, `java` 등 فضاء_المستخدم ينفذ_أمر 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 ينفذ_أمر·صديق_e05f319b 방법 및 الفعلي_بيانات 검증은
[ينفذ_أمر 계층과 خارجي_قيمة 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 الفعلي_بيانات ينفذ_أمر 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 ثابت_قيمة_f430d3f5 ELF는 `run --linux اسم_الملف_نص`으로 실행한다. [ELF·Linux ABI دعم_قيمة 범위와 동일 바이너리 اختبارات](실행파일규약.md).

GUI와 네트워크는 `python3 أدوات/ينفذ_أمر.py --desktop --network`로 함께 사용한다. Java·C·Python의 العربية 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 إقلاع_الآلة 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 رقم 있다. Remmina에서 **F9/Shift+Space/한·صفر_مُعامل مفتاح_قيمة**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·الفعلي_بيانات TCP/UDP·ملف بايت_قيمة·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java مثالنافذة`로 العربية Swing 예제를 실행한다. طرفية 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 حديث_عنصر عمود_قيمة·صف_قيمة 수를 보여 준다.

ينفذ_أمر 버튼 화면은 5×7 영문 글꼴을 쓰며, طرفية 창은 Noto CJK/DejaVu에서 생성한 한글·Unicode 비트맵 글꼴을 쓴다. UART와 الفعلي_بيانات 프레임버퍼의 한글 표시를 시험한다. 루프백은 동일 نواة_قيمة 내부의 رزمةمستقلة 전달이며 IP 패킷을 Ethernet으로 내보내는 드라이버가 아니다. 바깥 IPv4는 lwIP TCP/UDP 스택으로 보조 UART SLIP 경로를 사용한다. `python3 أدوات/ينفذ_أمر.py --network`로 QEMU NAT를 연결하고 `ftpd start`로 서비스를 시작한다.

Java의 정확한 API·문법·ينفذ_أمر 제한과 العربية 사용법은 [ذاتي JVM과 العربية مكتبة](자바실행환경.md)에 정리했다. فئة_قيمة_55654bf1 ملف/JAR 배포는 [한국어자바](한국어자바) 소스에서 재현한다. 기존 Linux판 `العربية.자바`와 별도인 `العربية.ذاتي` 패키지다.

**vi·여러 نافذة·Swing·한글 Java/Python/C/C++·posix-kor 예제는 [한글 개발 매뉴얼](개발안내.md)에 정리했다.**

GUI طرفية ينفذ_أمر·단축키·셸 أمر·제한은 [셸과 طرفية 사용법](셸과터미널.md)에 정리했다.

## حديث_عنصر 컴퓨터에서 ينفذ_أمر

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

خروج_تطبيق: **Ctrl+A التالي_عنصر X**. 게스트 C/AOT أدوات 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. مضيف 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. محول_برمجي 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/مسار/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` دعم_قيمة 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 ينفذ_أمر**한다. 기존 한 حرف_قيمة 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 وسائط 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

| أمر | إجراء |
|---|---|
| `help` / `info` | أمر·الفعلي_بيانات 구현 حالة_قيمة |
| `ls` / `cat FILE` / `rm FILE` | RAM ملف إدخال_قائمة_f07b3200·محتوى_قيمة·삭제 |
| `vi FILE` | فضاء_المستخدم منطقة_قيمة vi 부분집합, 한글 يحرر_قيمة·مخزن_قيمة·검색·되돌리기 |
| `edit FILE` | ملف 전체를 새로 إدخال_قيمة; 단독 `.` 줄로 مخزن_قيمة, Ctrl-C로 يلغي_تشغيل |
| `javac FILE.java` / `java CLASS [ARGS]` | ذاتي 제한형 Java يحول_برمجياً_مصدر·ينفذ_أمر |
| `python FILE.py [ARGS]` / `python -c 'CODE'` | MicroPython يحول_برمجياً_مصدر·ينفذ_أمر |
| `load FILE` / `hex FILE` | 16진수 바이너리 إدخال_قيمة/مخرجات; 입력은 단독 `.` 줄로 مخزن_قيمة |
| `run FILE.elf [ARGS]` / `run cpp` | 업로드한 ذاتي ABI ELF / 내장 C++ 예제 |
| `net test` / `tasks` / `selftest` | UDP 루프백 / 협력식 작업 / EL0 يحمي_قيمة اختبارات |
| `gui` / `terminal` | ينفذ_أمر 화면 / 한글 GUI طرفية; F12로 طرفية فتح·إغلاق |
| `samples` | 삭제한 قيمة_افتراضية 예제 يسترد_حالة; 기존 파일은 보존 |

예를 들어 `edit 인사.java`를 입력한 التالي_عنصر 아래 소스를 입력한다.

```java
public class 인사 { public static void main(String[] args) { int قيمة = 7; System.out.println("한글=" + قيمة); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 인사.java`, `java 인사`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. يلغي_تشغيل·잘못된 16진수·قدرة_قيمة 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, ينفذ_أمر 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 أمر 인수는 최대 32개다. اقتباس·백슬래시·셸 متغيّر_قيمة·파이프·리다이렉션 범위는 [셸 설명](셸과터미널.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, عنوان **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode إدخال_قيمة·명시적 لصق_قيمة·ينفذ_أمر 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 أدوات/ينفذ_أمر.py --desktop --network
# 다른 أجهزة_منفذ: python3 أدوات/ينفذ_أمر.py --desktop --port 5903
```

종료는 실행한 مضيف 터미널에서 Ctrl+C다. 기존 `python3 أدوات/ينفذ_أمر.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. الفعلي_بيانات Pi4 USB 입력기는 아직 없으며, VNC اتصال 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 الفعلي_بيانات C++/UDP ELF ينفذ_أمر, `Hello.java` يحول_برمجياً_مصدر 후 JVM ينفذ_أمر, `hello.py` ينفذ_أمر, GUI طرفية 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 تفاعلي 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 ذاكرة_بيانات·CPU 문맥을 보관한다. 셸·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

| `dist/jkoros-native-aarch64-sdk.tar.gz` | 사용자용 헤더·تشغيل رمز_قيمة_f3cd31ee·مكتبة·링커 نص_قيمة·예제 |
| `dist/manifest.json`, `build/build.json` | SHA256과 الفعلي_بيانات دعم_قيمة حالة_قيمة |

이미지는 확인된 공식 Pi إقلاع_الآلة 묶음에서 `start4.elf`, `fixup4.dat`, Pi4 DTB와 disable-bt overlay를 가져온다. Linux kernel/initramfs/rootfs는 넣지 않는다. 펌웨어·MicroPython·طرفية خط_قيمة 라이선스와 خط_قيمة نقطة_الأصل_قيمة 해시도 동봉한다. ملف إنشاء 스크립트는 물리 디스크에 기록하지 않는다.

예비 microSD에 بنية_صورة سجل_سجل 도구로 `.img`를 기록하거나 FAT32 إقلاع_الآلة 파티션 최상위에 ZIP 내용을 푼다. بنية_صورة 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 قيمة_افتراضية EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD ملف 구성·نواة_قيمة 체크섬 검사와 물리 لوحة إقلاع_الآلة 검증은 별개다. MMU يستخدم_قيمة 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 إقلاع_الآلة 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 العربية API يستخدم_قيمة

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/مثالملف.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int بدء_مستخدم_تطبيق(int)`이다. فضاء_المستخدم C++는 FP/SIMD를 사용할 رقم 있다. نواة_قيمة C/Java AOT는 일반 레지스터만 사용하므로 استثناء عملية_قيمة_إدخال 중 فضاء_المستخدم FP 상태를 건드리지 않는다. فضاء_المستخدم نقطة_الإدخال_قيمة 시 FP 상태를 초기화하고 نواة_قيمة 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int بدء_مستخدم_تطبيق(int) {
    int ملف = فتح_ملف("인사.txt", مقروء_مكتوب | 없으면만들기 | يقتطع_المحتويات, 0600);
    if (ملف < 0) return 1;
    const char محتوى_قيمة[] = "안녕하세요";
    int نتيجة = كتابة_ملف_بيانات(ملف, محتوى_قيمة, sizeof(محتوى_قيمة) - 1);
    يغلق_ملف(ملف);
    return نتيجة == sizeof(محتوى_قيمة) - 1 ? 0 : 2;
}
```

[ملف 예제](فضاء_المستخدم/مثالملف.cpp)와 [통신 예제](فضاء_المستخدم/통신예제.cpp)가 الفعلي_بيانات إقلاع_الآلة اختبارات 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 ملف عملية_قيمة_إدخال 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 مأخذ_التوصيل_قيمة 함수는 حديث_عنصر 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 نواة_قيمة 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 التالي_عنصر 도구를 사용하면 **새 QEMU를 부팅해 업로드한 الفعلي_بيانات 바이트를 재확인한 عودة_قيمة 게스트에서 ينفذ_أمر**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 أدوات/ينفذ_ملف.py build/jkoros-native-sdk/demo.elf
python3 أدوات/ينفذ_ملف.py 예제/Hello.java "한글 وسائط"
python3 أدوات/ينفذ_ملف.py 예제/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 نواة_قيمة 묶음에 포함되어 이 ملف 한도를 적용받지 않는다. **C++ 컴파일러는 مضيف SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 مكتبة, PT_TLS, PT_INTERP, PT_DYNAMIC, ينفذ_أمر·كتابة 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 فهرس·عنوان يقص·오류는 [فضاء_المستخدم ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `تثبيت_تخزين_الملفات`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 إذن_قيمة·dup/fcntl은 없다. 디렉터리와 نظير_قيمة/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, يستلم_قيمة 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. فضاء_المستخدم خروج_تطبيق 시 열린 ملف 서술자와 소켓을 회수한다.

## Java와 Python의 정확한 يقص

ذاتي `javac`는 버전 49 `.class`를 생성하며 JVM은 دعم_قيمة 명령으로 구성된 버전 45–52 클래스를 실행한다. ثابت_قيمة_f430d3f5 دالة_قيمة·재귀·int/boolean/char/String·شرط/تكرار_قيمة·سلسلة_قيمة 결합과 일부 ملف 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/تركيب_قيمة 자모 식별자를 처리한다. Unicode معرف_قيمة 전체 جدول_البحث·Unicode مصدر_شجرة 이스케이프는 구현하지 않았다. 게스트 مصدر_شجرة 컴파일러는 일반 عنصر_قيمة_2ed200e9·استثناء·Thread 구문을 아직 컴파일하지 못한다. مضيف `javac --release 8`로 만든 دعم_قيمة 부분집합 클래스는 ذاتي JVM 0.4의 عنصر_قيمة_2ed200e9·استثناء·Thread·UDP와 العربية API를 사용할 رقم 있다. Swing은 문서화한 ذاتي API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [ذاتي JVM 설명](자바실행환경.md)이 기준이다. 상세 لغة 범위는 [공유 Java أدوات 설명](../../문서/자바개발환경.md)을 참고하되, 그 문서의 x86 셸/مخزن_قيمة/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 مصدر_شجرة**를 ذاتي AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 دالة_قيمة·فئة_قيمة_55654bf1·استثناء·리스트/قاموس·Unicode·GC·가변 الدقة_قيمة 정수를 제공한다. حديث_عنصر 구성은 عدد_صحيح 빌드로 `float`, `complex`, `math`가 없으며 CPython 전체 표준 مكتبة, pip, subprocess, threading, 일반 socket과 قيمة_افتراضية `open()` ملف 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 عنصر_قيمة_2ed200e9·모듈은 خروج_تطبيق 시 회수되고 RAM 파일만 التالي_عنصر 실행에 남는다.

`import jkoros`로 التالي_عنصر 시스템 연결을 쓴다. 모두 SVC를 통해 ذاتي Java 커널에 접근한다.

| دالة_قيمة | إجراء |
|---|---|
| `stdin(limit)` | حديث_عنصر 표준 입력에서 최대 limit바이트(0…16384)를 bytes로 يقرأ_مقياس; EOF는 빈 bytes, UART بيانات 없음은 OSError(11) |
| `read(name)` | نظير_قيمة/절대 RAM 경로의 ملف 전체를 bytes로 يقرأ_مقياس |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 مخزن_قيمة, 쓴 بايت_قيمة رقم إرجاع_مقياس |
| `remove(name)` | RAM ملف 삭제 |
| `rect(x, y, w, h, color)` | 선택한 الفعلي_بيانات 화면 حجم 안의 مستطيل رسم_قيمة; 기존 보드의 RGB32 قيمة |
| `ticks_ms()` | إقلاع_الآلة 후 밀리초, 32비트 دورة_قيمة |
| `udp_open(port)` | 127.0.0.1의 UDP مأخذ_التوصيل_قيمة فتح/يربط_المشارك; 0은 자동 أجهزة_منفذ |
| `udp_send(fd, port, data)` | 루프백 وجهة_قيمة 포트에 str/bytes 버퍼 نقل_قيمة_630ba093 |
| `udp_recv(fd)` | `(bytes, 보낸포트)` إرجاع_مقياس; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | مأخذ_التوصيل_قيمة إغلاق |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```

이식 رمز_قيمة_f3cd31ee: [python/](파이썬연결/), [فضاء_المستخدم Java اتصال](فضاء_المستخدم/자바연결.c). 공식 [MicroPython 이식 안내](https://docs.micropython.org/en/latest/develop/porting.html)를 참고했다. مصدر_شجرة URL·تجزئة_ملف·라이선스는 [vendor 안내](vendor/README.md)에 기록했다.

| GUI ملحق_قيمة | USB HID, 게스트 입력기·문자 조판, Swing نافذة حجم 조절·클리핑 ملحق_قيمة, 전체 AWT/Swing 이식 |

이 표는 남은 작업이며 구현 완료 목록이 아니다. QEMU Pi4 모델에는 GENET Ethernet과 PCIe root port가 없어 خارجي_قيمة 네트워크 드라이버는 실물 검증도 필요하다. [QEMU جهاز_قيمة 지원표](https://www.qemu.org/docs/master/system/arm/raspi.html)

أجهزة_قيمة 및 ABI 참고: [BCM2711 ملحق](https://datasheets.raspberrypi.com/bcm2711/bcm2711-peripherals.pdf), [Pi4 GIC عنوان](https://github.com/raspberrypi/linux/blob/rpi-6.12.y/arch/arm/boot/dts/broadcom/bcm2711.dtsi), [mailbox قيمة_العقد](https://github.com/raspberrypi/firmware/wiki/Mailbox-property-interface), [Arm ELF64](https://github.com/ARM-software/abi-aa/blob/main/aaelf64/aaelf64.rst), [Arm FP تحكم_قيمة 레지스터 تعريف_قيمة](https://github.com/ARM-software/arm-trusted-firmware/blob/master/include/arch/aarch64/arch.h).


## العربية C نوع_البيانات·Python خطأ·يُجمع تثبيت_قيمة

C 네트워크 API는 `struct سحابة_مأخذ_التوصيل_عنوان`, enum 상수와 الفعلي_بيانات العربية 함수로
구현한다. ماكرو_قيمة 별칭을 사용하지 않으며 이전 pk_* ABI도 유지한다.
Python 예제는 `فشل_النظام`, `خطأ.فهرس`, `خطأ.설명`을 사용한다.

`python3 أدوات/ينفذ_أمر.py --desktop --network --pip`로 시작하면 게스트에서
`pip install micropython-bisect==3.3.3`을 사용할 رقم 있다. 현재는 مضيف 중계를
이용하는 제한형 MicroPython مصدر_شجرة 설치기이며 CPython pip·자동 의존성 해결·C 확장은
미지원이다. 설치한 `/lib` 자료는 RAM이다. [사용법과 제한](파이썬꾸러미.md).

## 화면 حجم تحديد_قيمة

`python3 أدوات/ينفذ_أمر.py --desktop --network --resolution 1920x1080`으로 Full HD 화면을 사용한다. 기본값은 640×480이며 1280×720도 가능하다. طرفية نقل_قيمة, Swing 가운데 تخطيط_الربط, Java·C·Python 그리기도 الفعلي_بيانات 크기를 따른다. SD 영상은 `make image RESOLUTION=1920x1080`으로 만든다. [إعدادات·العربية API·التحقق_من_صحة 안내](دقة_الشاشة.md).

## العربية 직접 API와 화면 يحدث

`example/java`는 `실행할일`, `동작받이`, `إجراء_إشعار`, `زر`, `حدث_يدرج`,
`خيطالعمل`, `تشغيل()`을 사용할 رقم 있다. العربية GUI/가닥을 ذاتي JVM에 직접
연결했으며, 표준 Swing/Thread를 감싸지 않는다. سلسلة_قيمة 등 javac의 표준
계약과 전체 مصدر_شجرة 검토 범위는 [명명 안내](명명/안내.md), 사용법과 호환성 변경은
[العربية Java API](한국어자바/안내.md)를 본다.

طرفية نقل_قيمة·حجم 변경은 바뀐 영역만 합성하고 달라진 화소만 표시한다.
[화면 يحدث 설명](자바실행환경.md#طرفية-부분-يحدث),
[부분 يحدث 검사](build/verification/redraw/report.json)를 참고한다.
