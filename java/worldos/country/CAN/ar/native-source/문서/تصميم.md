# JCanOS تصميم

아래는 عنصر_قيمة_2ed200e9 기반 관리 نواة_قيمة 전체의 هدف_عنصر 구조다. حديث_عنصر الفعلي_بيانات إقلاع_الآلة 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 نظام_تشغيل 안내](../os/안내.md)에 구현 범위를 명시한다. 아래의 GC·سياق_قيمة تبديل_الوضع·نظام_الملفات 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 طبقة_قيمة
  ↓
Java AOT 실행기와 عنصر_قيمة_2ed200e9·صفيف_قيمة·GC 런타임
  ↓
أجهزة_قيمة 경계
  ↓
Java 관리 نواة_قيمة
  ├─ ذاكرة_منطقة/쪽관리/COW
  ├─ عملية_قيمة/배정/wait
  ├─ نظام_الملفات/ELF/POSIX
  └─ إدخال_قيمة/جهاز_تخزين/شبكة_رمز
```

OpenJDK 자체는 이미 운영체제가 제공하는 ملف, 스레드, 가상 기억공간을 전제로 한다. 따라서 نواة_قيمة 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, سياق_قيمة 저장처럼 Java로 표현할 رقم 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
