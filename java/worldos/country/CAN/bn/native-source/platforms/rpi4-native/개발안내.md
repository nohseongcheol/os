# নিজ 커널에서 vi·여러 আদেশ_ব্যাখ্যাকারী·한글 프로그래밍 사용하기

বাংলা 통신·ব্যতিক্রম 사용법은 [বাংলা Java API](한국어자바/স্বনিবন্ধ_eb81d7d9.md), ফাংশন_মান·변수·নথির_নাম 이름의 변경과 어원 근거는 [명명 স্বনিবন্ধ_eb81d7d9](명명/স্বনিবন্ধ_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 নিজ AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 সমর্থন_মান 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 কার্যকর_করুন_আদেশ, 외부 TCP/UDP와 FTP는 [새 কার্যকর_করুন_আদেশ 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 আদেশ_ব্যাখ্যাকারী

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, ইমেইল **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 আদেশ_ব্যাখ্যাকারী 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **오른쪽 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 কার্যকর_করুন_আদেশ 버튼으로 다시 কলাম_মান 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 현재 디렉터리, শেল 변수, আদেশ লগ_সারি, 입력 중인 명령과 অ্যাপ_f5044b9b কার্যকর_করুন_আদেশ 상태를 보관한다. নথির_নাম 저장소는 공유한다. vi와 Swing의 이벤트 অপেক্ষা_মান 중에 다른 터미널로 전환하면 ব্যবহারকারী মেমরি_ডাটা·레지스터·নথির_নাম/소켓 연결을 보존했다가 돌아올 때 재개한다. **현재 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 পরবর্তী_দফা 입력 অপেক্ষা_মান 또는 기존 কার্যকর_করুন_আদেশ 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 কার্যকর_করুন_আদেশ 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 সম্পাদন_মান 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. 현재 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 উইন্ডো 판단은 게스트 커널이 처리한다. QEMU কার্যকর_করুন_আদেশ 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. প্রকৃত_ডাটা Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI সরঞ্জামগুলি 종료는 হোস্ট 터미널의 Ctrl+C다.

## vi 사용

```text
mkdir 작업
cd 작업
vi 인사.py
```

`vi`는 새로 구현한 **vi আদেশ 부분집합** 편집기다. 내장 `build/user/vi.elf`를 보호된 ব্যবহারকারী 영역에 적재한다. নথির_নাম 크기는 UTF-8 বাইট_মান প্রকল্প_মূল 16 KiB, 경로는 63바이트까지다. 디스크에 설치한 Vim/Neovim 바이너리를 실행하는 것이 아니다.

| কী_মান/আদেশ | কাজ |
|---|---|
| `i`, `a`, `I`, `A` | 현재/পরবর্তী_দফা অবস্থান 또는 নিবেশের_পঙ্_ক্তি 처음/끝에서 입력 |
| `o`, `O` | 아래/위에 새 줄을 만들고 입력 |
| Esc | 일반 মোড_মান |
| `h j k l`, 방향키 | UTF-8 문자/নিবেশের_পঙ্_ক্তি অপসারণ_করা_মান |
| `0`, `$`, Home, End | নিবেশের_পঙ্_ক্তি 처음/끝 |
| `gg`, `G`, `:সূচি` | নথির_নাম 처음/마지막 নিবেশের_পঙ্_ক্তি/নিয়োগ_করুন_মান নিবেশের_পঙ্_ক্তি |
| PgUp, PgDn | 화면 একক_মান অপসারণ_করা_মান |
| `x`, Delete | 현재 문자 삭제 |
| `dd`, `yy`, `p` | নিবেশের_পঙ্_ক্তি 삭제/নজির_মান/লেপন_করা_পাঠ |
| `u` | 마지막 편집을 되돌림; 한 স্টেজ_মান 토글 |
| `/স্ট্রিং_মান`, `n` | 단순 স্ট্রিং_মান 검색/পরবর্তী_দফা 일치; 정규식 없음 |
| `:w`, `:w 다른이름` | RAM নথির_নাম ভাণ্ডার_মান/다른 경로로 ভাণ্ডার_মান |
| `:q` | 변경이 없을 때 প্রস্থান_অ্যাপ |
| `:q!` | 변경을 버리고 প্রস্থান_অ্যাপ |
| `:wq`, `ZZ` | 저장하고 প্রস্থান_অ্যাপ |

붙여 넣은 한글을 문자 경계에 맞춰 অপসারণ_করা_মান·삭제한다. 일반 vi의 수량 접두사, ম্যাক্রো_মান, সেটিংস নথির_নাম, 플러그인, 정규식, 여러 버퍼/분할 উইন্ডো, 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/영 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 উইন্ডো উইন্ডো_শিরোনাম `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 আদেশ**으로 실행한다. 파이프·리다이렉션·লিপি_মান·`;`/`&&`/`||`로 연결한 실행에서 মিথস্ক্রিয় 대기를 시작하면 거부한다. 입력 대기는 약 2초 CPU 기한을 갱신하지만 입력 অপেক্ষা_মান 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## 한글 Java

vi에서 다음을 `인사.java`에 입력하고 Esc → `:wq`로 저장한다.

```java
public class 인사 {
    static int 더하기(int 첫째, int 둘째) { return 첫째 + 둘째; }
    public static void main(String[] আর্গুমেন্ট_তালিকা) {
        int 합계 = 더하기(20, 22);
        System.out.println("안녕하세요 · 합계=" + 합계);
    }
}
```

게스트 셸에서 실행한다.

```text
javac 인사.java
java 인사
```

한글 ফাইল_নাম_পাঠ·শ্রেণী_নাম·পদ্ধতি_নাম_পাঠ·변수명·문자열을 사용할 수 있다. **게스트 javac는 স্থির_মান Java 부분집합**이다. বস্তু_মান·리스너·Swing·소켓을 사용하는 소스는 현재 হোস্ট JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 নিজ JVM에 class를 올린다. নিজ JVM에서 지원하는 바이트코드/API 범위는 [자바실행환경.md](자바실행환경.md)를 따른다.

```sh
# হোস্ট
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/스윙시험.java
python3 সরঞ্জামগুলি/আপলোড_ফাইলগুলি.py build/my-java/스윙시험.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. নির্গম 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.শ্রেণী_মান.class` 형식이다. 내장 বাংলা 라이브러리는 별도 업로드가 필요 없다. বাংলা উইন্ডো API의 예제는 [한글창시험.java](시험/자바/한글창시험.java)이며 같은 방법으로 গঠন_উত্স·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 উত্স_ট্রী/클래스는 호스트의 `python3 সরঞ্জামগুলি/কার্যকর_করুন_ফাইল.py পথ_2/인사.java`로 별도 QEMU에 업로드·কার্যকর_করুন_আদেশ·종료할 수 있다. মিথস্ক্রিয় Swing에는 কার্যকর_করুন_আদেশ 후 ব্যবহারকারী 입력을 유지하는 `make desktop`을 사용한다.

## নিজ JVM의 Swing ক্লিপ

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 নিজ Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | কাজ |
|---|---|
| `JFrame` | উইন্ডো_শিরোনাম, আকার·অবস্থান, শো_উইন্ডো, বন্ধ_করুন 정책, dispose |
| `JPanel` | শিশু_মান 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 স্ট্রিং_মান শো_মান·পরিবর্তন_করা_মান |
| `JButton` | 버튼과 ActionListener ক্লিক_করা_মান প্রসেসর_মান_ভুক্তি |
| `JTextField` | 한 নিবেশের_পঙ্_ক্তি UTF-8 입력, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 নিজ JVM의 단일 이벤트 কার্যকর_করুন_আদেশ 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. উইন্ডো·요소는 কার্যকর_করুন_আদেশ 하나당 합계 32개, উপাদান_মান 글자는 최대 127 코드포인트다. অমনোনীত_মান 서체와 색은 커널이 제공한다.

[스윙시험.java](시험/자바/스윙시험.java)는 উইন্ডো·한글 ট্যাগ_মান·পাঠ্য_ক্ষেত্র·버튼·이벤트 처리의 কার্যকর_করুন_আদেশ 가능한 예제다. [নিজ Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

বাংলা 라이브러리에는 다음을 추가했다. হোস্ট গঠন_উত্স 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `বাংলা.নিজ.উইন্ডো`: `যোগ_করা_উপাদান`, `শো_উইন্ডো`, `বন্ধ_করুন`.
- `বাংলা.নিজ.উইজেট`: `ট্যাগ_মান`, `বোতাম`, `পাঠ্য_ক্ষেত্র` সৃষ্টি_করুন.
- `বাংলা.নিজ.연결통신`: `সংযোগ_স্থাপনা`, `듣기`, `받기`.
- 기존 `নির্গম`, `문자`, `নথির_নাম`, `작업`, `ভুক্তি_তালিকা`, `অভিধান`, `통신`, `화면`, `কারনেল_মান`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **কারনেল_মান 내부 연결형 বাইট_মান প্রবাহ_মান**을 추가했다. নথির_নাম/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket সার্ভার_মান = new java.net.ServerSocket(9250);
java.net.Socket অতিথি_মান = new java.net.Socket("localhost", 9250);
java.net.Socket সংযোগ_স্থাপনা = সার্ভার_মান.accept();
অতিথি_মান.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int দৈর্ঘ্য_মান = সংযোগ_স্থাপনা.getInputStream().read(받은것);
সংযোগ_স্থাপনা.close(); অতিথি_মান.close(); সার্ভার_মান.close();
```

সৃষ্টি_করুন·সংযোগ_স্থাপনা·accept·양방향 বাইট_মান/অ্যারে_মান ইনপুট_আউটপুট·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 শেষ_করা_বিন্দু 16개, 수신 버퍼당 1024바이트, অপেক্ষা_মান সংযোগ_স্থাপনা 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. অমনোনীত_মান সময়_মান 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM আদেশ 수/কারনেল_মান কার্যকর_করুন_আদেশ 기한은 여전히 적용된다.

외부 সংখ্যা_মান IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. প্রকৃত_ডাটা Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP লাইব্রেরি 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 প্রকৃত_ডাটা 송수신·EOF·기한·সংযোগ_স্থাপনা 회수의 시험 예제다.

## 한글 Python

게스트 vi에서 한글 이름을 사용해 작성한다.

```python
মান = 21

def 두배(সংখ্যা_মান):
    return সংখ্যা_মান * 2

print("পরিমাপ:", 두배(মান))
```

ভাণ্ডার_মান 후 `python 인사.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 ফাংশন_মান·변수·নথির_নাম 이름과 문자열을 한글로 쓴다.

[বাংলা.py](예제/한글코딩/বাংলা.py)를 같은 디렉터리에 두면 পরবর্তী_দফা 별칭을 사용할 수 있다.

```python
import বাংলা
বাংলা.লেখা_ফাইল("인사.txt", "안녕하세요")
বাংলা.নির্গম(বাংলা.파일읽기("인사.txt").decode())
```

নির্গম·নথির_নাম পড়া/লেখা/삭제·표준 입력·사각형·সময়_মান·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 সংখ্যা_মান IPv4 ইমেইল 전송이다. `wait_key()`는 화면을 확인할 때 মিথস্ক্রিয় 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor স্থির_মান 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 প্রসার_মান 모듈은 아직 없다. 제한형 `pip`의 উত্স_ট্রী 설치는 [Python পাঁজা স্বনিবন্ধ_eb81d7d9](파이썬꾸러미.md)를 따른다. [세 언어의 প্রকৃত_ডাটা 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 ভাষা 모두 বাংলা 헤더와 ফাংশন_মান 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 প্রকৃত_ডাটা EL0 কার্যকর_করুন_আদেশ 시험 대상이다.

```c
#include "파일규약.h"
#ifdef __cplusplus
extern "C"
#endif
int শুরু_ব্যবহারকারী_অ্যাপ(int আর্গুমেন্ট_তালিকা) {
    (void)আর্গুমেন্ট_তালিকা;
    const char 인사말[] = "안녕하세요\n";
    int 문서 = খোলা_ফাইল("인사.txt", পঠন_লিখন | 없으면만들기 | 내용비우기, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = লেখা_ফাইল_ডাটা(문서, 인사말, sizeof(인사말) - 1);
    বন্ধ_ফাইল(문서);
    লেখা_ফাইল_ডাটা(1, 인사말, sizeof(인사말) - 1); /* 현재 আদেশ_ব্যাখ্যাকারী stdout */
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 수 있다. C는 게스트 `cc` 또는 হোস্ট SDK, C++는 হোস্ট SDK의 Clang++로 컴파일한다. 아래 예제는 기존 হোস্ট SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh
# 호스트에서 SDK সৃষ্টি_করুন·এক্সট্রাক্ট
make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/인사.c -o 인사-c.elf
python3 compile.py examples/인사.cpp -o 인사-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 প্রকৃত_ডাটা কার্যকর_করুন_আদেশ
cd /home/user/jkoros/platforms/rpi4-native
python3 সরঞ্জামগুলি/কার্যকর_করুন_ফাইল.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 সরঞ্জামগুলি/কার্যকর_করুন_ফাইল.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

현재 GUI VM에서 실행하려면 `python3 সরঞ্জামগুলি/আপলোড_ফাইলগুলি.py পথ_2/인사-c.elf`의 출력을 게스트에 보내고 `run 인사-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex ফাইল_নাম_পাঠ`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 수 있다. 호스트와 게스트의 নথির_নাম 시스템은 별개다.

| বাংলা নাম | C প্রতীক | ক্লিপ |
|---|---|---|
| খোলা_ফাইল/বন্ধ_ফাইল | pk_open/pk_close | RAM নথির_নাম, পিয়ার_মান/절대 পথ_2 |
| 파일자료읽기/লেখা_ফাইল_ডাটা | pk_read/pk_write | নথির_নাম, fd 0/1/2 표준 ইনপুট_আউটপুট, 연결형 소켓 |
| সিক_ফাইল | pk_lseek | 처음기준/현재기준/끝기준 |
| ফাইল_আয়তন/সেট_ফাইল_দৈর্ঘ্য | pk_size/pk_ftruncate | দৈর্ঘ্য_মান জিজ্ঞাসা_মান/পরিবর্তন_করা_মান |
| সরানো_ফাইল_ভুক্তি_নাম | pk_unlink | নথির_নাম নাম 삭제 |
| 파일저장확정 | pk_fsync | RAM이므로 -1, 오류번호=ENOSYS |
| 통신종단점만들기/বন্ধন_করা_ইমেইল | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |
| 자료전문보내기/자료전문받기 | pk_sendto/pk_recvfrom | UDP 루프백 |
| সংযোগ_নেটওয়ার্ক | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | অপেক্ষা_মান সংযোগ_স্থাপনা 최대 4개 |
| স্বীকার_করুন_নেটওয়ার্ক_সংযোগ | pk_accept | 현재 ইমেইল 인수는 NULL/NULL만 সমর্থন_মান |
| 통신주소읽기 | pk_getsockname | 로컬 ইমেইল/পোর্ট_মান |

`통신규약.h`의 নিজ `pk_sockaddr_in`을 사용하며 পোর্ট_মান·주소는 `망차례짧은수`/`নেটওয়ার্ক_পূর্ণসংখ্যা`로 변환한다. C 소켓 호출은 비차단이며 ডাটা/연결이 없으면 -1과 `오류번호=11`(EAGAIN)을 반환한다. 양수 ইনপুট_আউটপুট 결과가 요청보다 작을 수 있으므로 পুনরুক্তি_মান 처리한다. বিফলতা_মান 후에만 오류번호를 확인한다.

[প্রবাহ_মান.c](예제/한글코딩/প্রবাহ_মান.c)는 C에서 বাংলা 이름으로 সংযোগ_স্থাপনা·accept·부분 পড়া/লেখা·큐 포화·EOF를 처리하는 কার্যকর_করুন_আদেশ 예제다. SDK의 `examples/প্রবাহ_মান.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → প্রকৃত_ডাটা বাংলা C ফাংশন_মান 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·নির্দেশক 검사 → Java RAM নথির_নাম/루프백 또는 외부 lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 কারনেল_মান 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 সংযোগ_স্থাপনা, 표준 C printf, libstdc++/STL, ব্যতিক্রম·RTTI는 제공하지 않으며 C++의 স্থির_মান 생성자·স্থানীয়_সুযোগ বস্তু_মান 소멸자는 지원한다. 상세 সূচি·মেমরি_ডাটা 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## বৈধ_করুন

`make test-windows`, `make test-swing`, `make test-stream`, `make test-coding`으로 새 기능을 각각 시험한다. `make test`는 기존 শেল·VNC·JVM·AOT·কারনেল_মান রক্ষা_করুন_মান 시험까지 포함한다. প্রকৃত_ডাটা বোর্ড 대신 QEMU raspi4b에서 수행한다. 결과는 [이전 GUI প্রসার_মান বৈধ_করুন লগ_সারি](build/verification/release.json)과 [현재 সাধারণ_ভাষা_রানটাইম বৈধ_করুন লগ_সারি](build/verification/native-runtime-summary.json), [여러 আদেশ_ব্যাখ্যাকারী 화면](build/verification/windows/four-terminals.png), [Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

구현 시 참고한 표준 API: [Socket](https://docs.oracle.com/javase/8/docs/api/java/net/Socket.html), [JFrame](https://docs.oracle.com/javase/8/docs/api/javax/swing/JFrame.html), [JButton](https://docs.oracle.com/javase/8/docs/api/javax/swing/JButton.html). 이 문서의 구현 범위가 위 표준 전체를 지원한다는 뜻은 아니다.

## বাংলা 이름으로 직접 작성하는 창과 থ্রেড_মান

`example/java/জানালানমুনা.java`는 `실행할일.চালানো`,
`동작받이.동작받기(동작알림)`, `বোতাম`, `ঘটনা_সারিবদ্ধ.나중에실행`, `চালনা()`을 쓴다.
নিজ JVM에 이 이름들의 বস্তু_মান·পদ্ধতি_মান·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `작업가닥`도 নিজ 스케줄러와 직접 연결된다.
세부 메서드와 기존 বাংলা API에서의 변경은 [বাংলা API 문서](한국어자바/স্বনিবন্ধ_eb81d7d9.md)를 본다.

হোস্ট javac는 배포 JAR를 শ্রেণী_মান 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/জানালানমুনা.java
python3 সরঞ্জামগুলি/কার্যকর_করুন_আদেশ.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java জানালানমুনা
```

직접 화면/থ্রেড_মান API와 `চালনা()` 진입점은 নিজ JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
