# নিজ ARM64 কারনেল_মান: FTP, C, JAR와 AOT কার্যকর_করুন_আদেশ

대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT কারনেল_মান**이다. CPU·ডিভাইস_মান 경계는 C/어셈블리, নথির_নাম 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 হোস্ট JVM으로 대신 실행하지 않는다.

## 먼저 알아둘 সমর্থন_মান 경계

| 요청 | 이번 구현 | 남은 ক্লিপ |
|---|---|---|
| JAR를 কার্যকর_করুন_আদেশ 파일처럼 কার্যকর_করুন_আদেশ | `java -jar নথির_নাম.jar`, `./নথির_নাম.jar আর্গুমেন্ট_তালিকা`; Main-Class와 ভাণ্ডার_মান/DEFLATE ZIP, CRC 검사 | 전체 Java SE, 임의의 모든 JAR 호환성 |
| 게스트 AOT | `jaot নথির_নাম.class -o নথির_নাম.elf`, `jaot নথির_নাম.jar -o নথির_নাম.elf`; প্রকৃত_ডাটা ARM64 기계어 সৃষ্টি_করুন | বস্তু_মান·ব্যতিক্রম·Thread·Swing·Socket의 AOT 변환, 여러 애플리케이션 শ্রেণী_মান সংযোগ_স্থাপনা |
| C গঠন_উত্স | 게스트 `cc`/`tcc`, TinyCC C 전처리기·ARM64 생성기·링커; বাংলা 식별자와 posix-kor | 전체 libc, 일반 Linux কার্যকর_করুন_আদেশ নথির_নাম, 게스트 C++ 컴파일러 |
| 업로드한 ELF কার্যকর_করুন_আদেশ | ELF64/AArch64 헤더 검사, 확장자 없는 `./নথির_নাম`; নিজ ABI 및 명시적인 제한형 Linux ABI | 일반 Linux 바이너리 호환, 동적 링커, 공유 লাইব্রেরি |
| 외부 TCP/UDP | 게스트 lwIP IPv4 스택, POSIX 소켓과 JVM의 সংখ্যা_মান IPv4 ইমেইল | GENET/Wi-Fi 드라이버, DHCP·DNS·TLS, 실물 বোর্ড 네트워크 시험 |
| FTP | 게스트 서비스, 패시브 স্থানান্তর_মান, UTF-8 নাম, STOR/RETR/SIZE/LIST/NLST/MLSD/DELE | TLS·사용자별 অনুমতি_মান·하위 디렉터리·영속 ভাণ্ডার_মান |
| 한글 Java | 기존 `বাংলা.নিজ` 클래스와 외부 ইমেইল UDP 오버로드 | 전체 JDK의 일대일 বাংলা 대응 API |

JVM은 শ্রেণী_মান 버전 45…52의 문서화한 부분집합이다. `java`는 바이트코드 실행기이고, `jaot`가 별도의 네이티브 কার্যকর_করুন_আদেশ 파일을 만든다. **JAR সংগ্রহ_করা_মান 해제나 JVM을 함께 묶는 것을 AOT라고 표시하지 않는다.** 지원하지 않는 바이트코드/API는 `jaot`가 진단하고 출력을 만들지 않는다. 기존 নির্গম ELF도 গঠন_উত্স বিফলতা_মান 때 보존한다.

Android의 Dalvik/ART는 일반 JVM শ্রেণী_মান/JAR가 아닌 **DEX**를 실행한다. ART의 AOT에는 GC, শ্রেণী_মান 로딩, JNI 등 কার্যকর_করুন_আদেশ 기반도 필요하다. 따라서 ART처럼 기계어로 바꾸는 기능만으로 임의의 OpenJDK JAR 및 Swing이 자동 호환되지는 않는다. [Android 공식 런타임 설명](https://source.android.com/docs/core/runtime)

FTP는 루트 RAM 파일만 공개한다. 익명 로그인이며 비밀번호로 권한을 구분하지 않는다. অমনোনীত_মান হোস্ট 바인딩은 `127.0.0.1`이고, নিয়ন্ত্রণ_মান 포트는 2121, 데이터 포트는 50000…50007이다. `--ftp-port 2122`로 নিয়ন্ত্রণ_মান 포트를 바꿀 수 있다. 동시에 한 FTP 세션을 제공하며 명령이 없는 세션은 60초 후 닫는다. TYPE A도 바이트를 변경하지 않으므로 프로그램은 바이너리 전송한다.

파일은 **64개, 각각 16 KiB**, 경로는 UTF-8 63바이트이다. 부팅 시 준비되는 `/example`도 이 한도를 공유한다. 초과/끊어진 STOR는 기존 파일에 반영하지 않는다. FTP 업로드는 RAM에만 저장되며 재부팅하면 사라진다. 이 제한 때문에 일반적인 대형 JAR 배포판을 그대로 올릴 수 없다.

QEMU의 raspi4b에는 GENET Ethernet 장치가 없다. 따라서 `network_bridge.py`가 QEMU NAT의 Ethernet과 보조 UART의 SLIP를 변환한다. **TCP সংযোগ_স্থাপনা প্রসেসর_মান_ভুক্তি·체크섬·재전송·FTP 명령과 নথির_নাম 저장은 게스트 안에서 수행한다.** হোস্ট 브리지는 FTP 서버가 아니다. [QEMU 공식 ডিভাইস_মান সমর্থন_মান ভুক্তি_তালিকা](https://www.qemu.org/docs/master/system/arm/raspi.html)

이 경로는 QEMU에서 검증했다. 보조 UART의 প্রকৃত_ডাটা Pi 4 핀/클럭 설정과 내장 RJ45 GENET 드라이버는 구현·검증하지 않았으므로, SD 이미지에 커널이 포함되어 있다는 사실을 প্রকৃত_ডাটা 보드의 LAN/FTP কাজ 보장으로 해석하면 안 된다.

## বাংলা Java를 게스트에서 컴파일하고 AOT কার্যকর_করুন_আদেশ

게스트 `vi 빛.java`로 পরবর্তী_দফা 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] আর্গুমেন্ট_তালিকা) throws Exception {
        int 합 = 0;
        int 수 = 1;
        while (수 <= 10) {
            합 = 합 + 수;
            수 = 수 + 1;
        }
        বাংলা.নিজ.নির্গম.수쓰기(합);
        বাংলা.নিজ.নথির_নাম.লেখা("aot.txt", "한글 AOT নথির_নাম 😀");
        বাংলা.নিজ.নির্গম.লেখা_লাইন(বাংলা.নিজ.নথির_নাম.পড়া("aot.txt"));
    }
}
```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 সৃষ্টি_করুন·연결한다. কার্যকর_করুন_আদেশ 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 সমর্থন_মান 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 স্থির_মান পদ্ধতি_মান/ক্ষেত্র_মান, int 계열, পূর্ণসংখ্যা 배열과 প্রসঙ্গ, আর্গুমেন্ট_তালিকা অ্যারে_মান, শর্ত·শাখা·পুনরুক্তি_মান, স্ট্রিং_মান 리터럴, `System.out.print/println`의 int/String, বাংলা নির্গম·নথির_নাম পড়া/쓰기로 제한된다. শ্রেণী_মান/পদ্ধতি_মান 수와 스택 등에도 고정 상한이 있다. Java ব্যতিক্রম প্রসেসর_মান_ভুক্তি, বস্তু_মান সৃষ্টি_করুন, 가상 পদ্ধতি_মান 일반, switch/wide, long/float/double, invokedynamic, স্ট্রিং_মান 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 অ্যারে_মান অ্যাক্সেস_ভুক্তি/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java ব্যতিক্রম 객체로 전달하지 않는다.

입력 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 সারিকরণ_করা_মান 때문에 짧은 클래스도 이 한도를 넘을 수 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 বস্তু_মান·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 সমর্থন_মান ক্লিপ 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 개발 매뉴얼](개발안내.md)을 참고한다.

JAR는 하나의 애플리케이션 শ্রেণী_মান 경로다. 내부 নাম `পাঁজা/অ্যাপ_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 বাংলা 클래스를 추가로 찾지만 현재 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·এনক্রিপ্ট_ডাটা ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 수/VM 힙 제한은 그대로 적용된다.

## C에서 বাংলা POSIX 호출

게스트에서 `vi 인사.c`로 작성하거나 FTP로 소스를 업로드한다.

```c
#include <파일규약.h>

int main(void) {
    const char 인사말[] = "নিজ ARM64 C에서 한글 POSIX 호출\n";
    int 문서 = খোলা_ফাইল("인사.txt", পঠন_লিখন | 없으면만들기 | 내용비우기, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = লেখা_ফাইল_ডাটা(문서, 인사말, sizeof(인사말) - 1);
    বন্ধ_ফাইল(문서);
    লেখা_ফাইল_ডাটা(1, 인사말, sizeof(인사말) - 1);
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

```text
cc 인사.c -o 인사.elf
run 인사.elf
cat 인사.txt
```

TinyCC의 표준 C ভুক্তি_বিন্দু `main`을 사용한다. 기존 হোস্ট C/C++ SDK의 `শুরু_ব্যবহারকারী_অ্যাপ(int)` 진입점과 구분한다. 포함 নথির_নাম·চালনা বস্তু_মান·`libposix-kor-user.a`는 컴파일러 내부의 পড়া 전용 SDK에 들어 있다. C 전처리기/구조체/ফাংশন_মান/재귀/নির্দেশক/부동소수점 সৃষ্টি_করুন 등을 사용하되 **일반 libc/libstdc++를 제공한다는 뜻은 아니다**. 제공하지 않는 함수는 সংযোগ_স্থাপনা 오류가 난다. 컴파일러 자체의 문자/সংখ্যা_মান 변환 지원도 완전한 libc 대체품이 아니다.

`খোলা_ফাইল` 등은 별도의 모의 호출이 아닌 기존 `pk_open` 등의 বাংলা 매크로이며, ELF의 SVC를 통해 প্রকৃত_ডাটা Java নথির_নাম 체계에 도달한다. নথির_নাম/소켓 호출 목록은 [ব্যবহারকারী ABI](사용자호출규약.md)에 있다. C/C++ হোস্ট SDK কার্যকর_করুন_আদেশ 파일도 FTP로 업로드 후 `run` 또는 `./নথির_নাম`로 실행하며 확장자는 필요 없다. Linux ARM64 স্থির_মান ELF에는 별도의 제한된 호환 পথ_2 `run --linux নথির_নাম`을 추가했다. [ELF·Linux ABI 매뉴얼](실행파일규약.md)에 정확한 বিন্যাস_মান·시스템 호출·ইমেইল 제한을 정리했다.

## বাংলা 네트워크·작업·화면 API

| শ্রেণী_মান | 호출 예 | কার্যকর_করুন_আদেশ পথ_2 |
|---|---|---|
| `নির্গম` | `লেখা_লাইন("안녕")`, `수쓰기(42)` | JVM 및 제한형 AOT |
| `নথির_নাম` | `লেখা("문서.txt", "সামগ্রি_মান")`, `পড়া("문서.txt")` | JVM 및 제한형 AOT |
| `통신` | `খুলুন(0)`, `পাঠান(종단, "10.0.2.2", 9000, "한글")`, `받기(종단)` | JVM의 UDP |
| `연결통신` | `সংযোগ_স্থাপনা("10.0.2.2", 9000)`, `듣기(9000)`, `받기(সার্ভার_মান)` | JVM의 Socket/ServerSocket |
| `작업` | `চালনা(Runnable)`, `기다리기(Thread)`, `স্থগিত_করুন_কার্য()` | JVM의 협력식 থ্রেড_মান |
| `উইন্ডো`, `উইজেট` | উইন্ডো·버튼·অক্ষর_মান·পাঠ্য_ক্ষেত্র·ঘটনা সংযোগ_স্থাপনা | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 বাংলা 호출 계층을 추가한다. `통신(通信)`, `সংযোগ_স্থাপনা(連結)`, `নির্গম(出力)`은 기존 단어의 뜻을 사용한다. `작업 থ্রেড_মান`은 한 কার্যকর_করুন_আদেশ 흐름을 가닥에 빗댄 기술 표현, `পোর্ট_মান`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

외부 주소는 সংখ্যা_মান IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 নিজ ABI이며 JVM이 제한된 অপেক্ষা_মান/재시도를 제공한다. TCP connect 대기는 최대 1초, ব্যবহারকারী অ্যাপ_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 কার্যকর_করুন_আদেশ ব্যবহারকারী 서버와 pthread는 아직 없다. FTP는 ব্যবহারকারী অ্যাপ_f5044b9b 기한과 별개인 কারনেল_মান 서비스다.

게스트의 ব্যবহারকারী TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 সরঞ্জামগুলি/কার্যকর_করুন_আদেশ.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 অমনোনীত_মান নিয়ন্ত্রণ_মান/데이터 포트와 겹치면 কার্যকর_করুন_আদেশ 전에 거부한다.

## 시험과 গঠন_সিস্টেম 재현

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test-ftp
make test
make image
```

`build/verification/ftp/report.json`은 প্রকৃত_ডাটা FTP স্থানান্তর_মান, 한글 নথির_নাম, আকার 초과 보존, সংগ্রহ_করা_মান JAR কার্যকর_করুন_আদেশ, 게스트 C গঠন_উত্স/ELF 재업로드, 외부 Java TCP/UDP, 게스트 javac/AOT 실행을 기록한다. `serial.log`에서 게스트 명령과 결과를 확인할 수 있다. 보고서의 কারনেল_মান SHA-256과 배포 이미지의 커널을 비교한다.

빌드는 기존 JDK/Clang/AArch64 binutils와 함께 `../rpi4/build/rootfs`의 ARM64 SDK ঘোষণা 헤더와 libgcc 산술 보조 함수를 사용한다(`make rpi-prepare`). **musl libc, Linux কারনেল_মান, 동적 로더를 게스트에 링크하지 않는다.** TinyCC/lwIP/uzlib 원본과 라이선스·버전 정보는 `vendor/`, 이식 코드는 `ccompiler/`, `network/`, `ব্যবহারকারী/পাঁজা.c`에 있다.

전체 JDK/AOT JVM으로 확장하려면 타입 বৈধ_করুন·বস্তু_মান/ব্যতিক্রম/GC·동적 로딩·JNI, 영속 নথির_নাম অপারেটিং_সিস্টেম_মান·mmap/TLS/시그널·스레드 ABI, OpenJDK native লাইব্রেরি, GUI peer/폰트/입력기, GENET 및 실물 ডিভাইস_মান 검증이 더 필요하다. 이 문서의 কার্যকর_করুন_আদেশ 시험은 그 전체 이식을 대신하지 않는다.
