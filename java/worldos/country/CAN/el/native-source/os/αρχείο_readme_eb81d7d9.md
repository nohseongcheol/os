# Java 네이티브 λειτουργικό_σύστημα

이 문서는 기존 **x86 πυρήνας_τιμή**을 설명한다. Raspberry Pi 4의 ίδιο ARM64 αρχική_κατάσταση 이식은 [별도 αρχείο_readme_eb81d7d9](../platforms/rpi4-native/README.md)를 참고한다. 아래 x86 χρήστης ELF·네트워크·IDE αποθηκεύω_τιμή 기능이 ARM64에 모두 이식된 상태는 아니다.

Java 원문을 ίδιο AOT 후단으로 x86 기계어로 컴파일해 부팅하는 작은 운영체제다. 커널과 별도로 ίδιο 제한형 Java πρόγραμμα_μεταγλώττισης·JVM ELF를 χρήστης 모드에 적재할 수 있다. Linux, engos, koros4와 εξωτερικός_τιμή OpenJDK는 게스트에 적재하지 않는다. 부팅 진입과 υλικό_θύρα/물리 Μνήμη_περιοχή 접근은 어셈블리이며, 문자 단말·είσοδος_τιμή διεργασία_τιμή_καταχώρηση·Εντολή ανάλυση_τιμή_7cebddfb·작업 ενότητα_τιμή 관리는 `ΠΗΓΗ/*.java`에 있다.

## 게스트 Java 개발

`javac Hello.java`, `java Hello`로 부팅된 λειτουργικό_σύστημα 안에서 δόμηση_προέλευση·실행한다. `edit FILE.java`와 `.save`로 소스를 작성하며 `ls`, `cat`, `rm`을 제공한다. RAM 파일은 최대 8개, 각각 16KiB이다. 전용 IDE 매체를 연결하면 `sync`로 보존할 수 있다. 이 기능은 ίδιο 제한형 구현이며 전체 OpenJDK/JDK 호환은 아니다. 사용법·στήριγμα_τιμή 문법·Αρχείο 적재·교차 시험은 [Java 개발 περιβάλλον_5d36e09c](../문서/περιβάλλον_ανάπτυξης_Java.md)에 있다. `make test-java`로 검증한다.

## 빌드와 εκτελώ_εντολή

`compiler/`가 요구하는 도구에 더해 ISO 생성에는 `grub-file`, `grub-mkrescue`, GRUB BIOS μονάδα_τιμή, `xorriso`가 필요하다. 실행에는 QEMU 또는 VirtualBox가 필요하다. τρέχων_στοιχείο 설치된 도구만 사용한다. `make run-store`는 새 전용 가상 αποθηκεύω_τιμή 매체를 만들어 연결한다. VirtualBox 실행기는 이 프로젝트가 만든 전용 VM만 설정하고 다른 VM은 변경하지 않는다. 가상 메모리는 προεπιλεγμένη_τιμή 64MiB이며 최소 16MiB가 필요하다.

```sh
cd /home/user/jkoros/os
make                 # build/kernel.elf
make iso             # build/kernel.iso (χρήστης ELF Ομάδα_τιμή 포함)
make run             # ELF 직접 부팅, 직렬 단말
make run-gui         # GRUB ISO 부팅, VGA 창과 PS/2 자판
make vbox            # 상위 폴더의 실행기로 전용 VirtualBox VM εκτελώ_εντολή
make vbox-status     # 전용 VirtualBox VM Κατάσταση_τιμή επαληθεύω
make test            # ELF와 ISO 두 경로의 πραγματικός_δεδομένα 부팅/είσοδος_τιμή 시험
make apps            # χρήστης 프로그램만 δομή_Σύστημα
make test-network    # χρήστης εκτελώ_εντολή/UDP/προστασία_τιμή 시험
```

`make run`은 QEMU의 직렬 표준 입출력을 쓴다. `Ctrl+A`를 누른 Πίσω_τιμή `X`로 QEMU를 종료할 수 있다. `halt`는 게스트 CPU만 정지시키므로 QEMU Παράθυρο/프로세스는 별도로 닫는다. 폴링 방식이라 περίμενε_τιμή 중에도 φιλοξενώ CPU를 사용할 수 있다.

VirtualBox는 `make vbox`로 실행한다. 새 전용 VM을 Μνήμη_δεδομένα 64MiB, BIOS, 광학 드라이브 부팅으로 자동 설정하며 디스크는 필요 없다. πραγματικός_δεδομένα VirtualBox 5.2.42에서 부팅, Java ίδιο 시험, κέλυφος είσοδος_τιμή, `run hello vbox`의 ring 3 실행과 πληροφοριακά_συστήματα_απλά 종료를 확인했다. τρέχων_στοιχείο 통신 드라이버는 QEMU의 RTL8139 전용이며 VirtualBox의 PCnet/E1000에서는 네트워크를 사용할 수 없어 네트워크 장치를 비활성화한다. αποθηκεύω_τιμή Κατάσταση_τιμή 재개와 새 δομή_Σύστημα 반영 방법은 [VirtualBox εκτελώ_εντολή αρχείο_readme_eb81d7d9](../문서/가상상자실행.md)에 있다.

## 셸에서 χρήστης εφαρμογή_f5044b9b εκτελώ_εντολή 및 네트워크 호출

독립 ELF32 εκτελώ_εντολή 파일을 적재해 **ring 3**에서 실행한다. `int 0x80` 시스템 호출을 통해 단말 Έξοδος, Παράμετροι ερώτημα_τιμή, UDP Άνοιγμα·στέλνω·λαμβάνω·닫기를 제공한다. χρήστης 코드를 πυρήνας_τιμή 함수로 직접 호출하는 구조가 아니다.

```text
jkoros> apps
jkoros> run hello first second
jkoros> net
jkoros> run netcheck
jkoros> run udp 10.0.2.2 9000 hello
```

마지막 명령의 응답을 받으려면 호스트의 별도 터미널에서 `python3 /home/user/jkoros/os/Εργαλεία/ηχώ_δεδομένα.py --port 9000`을 먼저 실행한다. 상세 API, εφαρμογή_f5044b9b προσαρτώ_καταχώρηση, διεύθυνση 공간과 제한은 [χρήστης εκτελώ_εντολή·네트워크 αρχείο_readme_eb81d7d9](χρήστης/αρχείο_readme_eb81d7d9.md)에 있다.

부팅 επαληθεύω 문구:

```text
JKOROS NATIVE JAVA
자바 기계어 πυρήνας_τιμή Εκτέλεση_2
JAVA SELFTEST PASS
USER ELF: ring 3 / paging / int 0x80
help | info | mem | alloc | free N | echo TEXT | clear | test | halt
apps | run NAME [ARGS] | net
READY
jkoros>
```

## 구현한 기능

- GRUB Multiboot 1 ELF 부팅, x86 προστασία_τιμή λειτουργία_τιμή GDT, BSS προετοιμάζω, 64KiB τελεστέος_δέσμη.
- Java συνάρτηση_τιμή πραγματικός_δεδομένα 실행과 부팅 Πληροφορίες_συστήματος δείκτης_τιμή_7e8f90bd επαληθεύω.
- COM1 직렬 είσοδος_έξοδος, VGA 문자 화면·δρομέας_τιμή·스크롤·διαγράφω_καταχώρηση.
- PS/2 προεπιλεγμένη_τιμή 자판, 좌우 Shift, Enter, Backspace. επέκταση_τιμή Κλειδί_τιμή/마우스 자료는 Εντολή 입력으로 쓰지 않는다.
- διάρκεια_τιμή 128의 Εντολή είσοδος_τιμή 버퍼, Υπερχείλιση_τιμή 방지, CR/LF διεργασία_τιμή_καταχώρηση.
- `help`, `info`, `mem`, `alloc`, `free N`, `echo TEXT`, `clear`, `test`, `halt`.
- 4KiB 작업 ενότητα_τιμή 8개의 εκχωρώ_Χώρος_αποθήκευσης·επιστρέφω_μέτρηση·재사용과 중복 επιστρέφω_μέτρηση 방지.
- Java πίνακας_τιμή 256KiB 영역의 Μέγεθος·δείκτης_τιμή 검사와 런타임 ΣΦΑΛΜΑ 중단.
- Ανάγνωση 전용 JKAP εκτελώ_εντολή Ομάδα_τιμή, ELF32 ενότητα_τιμή/σημείο_εισόδου επικυρώνω, χρήστης λειτουργία_τιμή·Παράμετροι·Έξοδος_εφαρμογή κωδικός_τιμή.
- πυρήνας_τιμή/χρήστης 페이지 άδεια_τιμή 분리, TSS, IDT, PIT 100Hz, χρήστης CPU εξαίρεση διεργασία_τιμή_καταχώρηση 및 εκτελώ_εντολή τιμή_ώρας 상한.
- PCI RTL8139 폴링 드라이버, ARP, στατικός_τιμή IPv4, UDP άθροισμα_ελέγχου·송수신·περίμενε_τιμή 제한.

`mem`의 Upper memory는 Multiboot의 1MiB 위쪽 연속 Μνήμη_δεδομένα Μέγεθος(KiB)이며, 전체 Μνήμη_δεδομένα 지도 분석이나 자유 물리 Μνήμη_δεδομένα 수치가 아니다. `alloc`은 이미 확보한 ακέραιος πίνακας_τιμή 안의 작업 ενότητα_τιμή 번호를 반환한다. 일반 물리 σελίδα_τιμή εκχωρώ_Χώρος_αποθήκευσης, διεύθυνση διεύθυνση_περιοχή 또는 χρήστης διεργασία_τιμή Μνήμη_δεδομένα 관리가 아니다.

## 명시적인 한계

이 커널은 **χρήστης 프로그램을 한 번에 하나 실행하는 αρχική_κατάσταση πυρήνας_τιμή**이다. PIT IRQ0만 사용하며 키보드와 NIC는 폴링한다. χρήστης CPU 예외는 해당 프로그램을 끝내고 셸로 복귀시키지만 πυρήνας_τιμή 예외는 중단한다. εκτελώ_εντολή 시간은 약 3초로 제한한다. 완전한 선점 다중 διεργασία_τιμή 스케줄러, FAT/ext 등 일반 디스크 σύστημα_αρχείων, TCP·DNS·DHCP·IPv6·HTTP, 전체 POSIX, 일반 αντικείμενο_τιμή 모델/GC는 아직 없다. 전용 IDE Αρχείο 보존과 POSIX Αρχείο/UDP 일부 기능은 구현했다. JVM은 RAM 파일의 단일 클래스를 εκτελώ_εντολή 시 적재하며 일반 ClassLoader나 JAR 로딩은 지원하지 않는다. 네이티브 εκτελώ_εντολή 파일은 δομή_Σύστημα 시 Ανάγνωση 전용 묶음에 넣으며, 일반 Linux ELF를 실행하는 환경이 아니다. 기존 `../παλαιού_τύπου_προέλευση/`의 JVM 관리 πυρήνας_τιμή 전체를 이식한 것도 아니다.

Java 식별자는 한국어다. 직렬 출력은 이 프로젝트의 한글(BMP 문자)을 UTF-8로 표시한다. VGA는 προεπιλεγμένη_τιμή ASCII 글꼴만 사용하므로 한글 자리에 `?`가 나온다. Εντολή 입력도 τρέχων_στοιχείο ASCII만 지원하며 한글 γραμματοσειρά_τιμή·입력기 및 보조 평면 문자 출력은 후속 작업이다. `test`는 작은 배열을 새로 할당하고 GC가 없으므로 무한 반복하지 않는다.

## 자동 시험

`시험/부팅시험.py`는 디스크 없는 독립 QEMU를 생성해 다음을 검증하고 종료한다.

- ELF 직접 부팅 및 GRUB ISO 부팅.
- Java ίδιο 시험과 UTF-8 직렬 문구.
- Εντολή εμφανίζω_βοήθεια·Πληροφορίες_συστήματος·Μνήμη_δεδομένα·Έξοδος·ΣΦΑΛΜΑ είσοδος_τιμή·화면 διαγράφω_καταχώρηση.
- 작업 ενότητα_τιμή 8개 εκχωρώ_Χώρος_αποθήκευσης, 부족 διεργασία_τιμή_καταχώρηση, επιστρέφω_μέτρηση/중복 επιστρέφω_μέτρηση/재할당.
- 직렬 줄바꿈·백스페이스·긴 είσοδος_τιμή διεργασία_τιμή_καταχώρηση.
- QEMU PS/2 Κλειδί_τιμή 입력으로 `info` εκτελώ_εντολή, `halt` 정지.

성공 로그는 `build/부팅시험.json`에 남는다. 로컬 Unix 소켓을 금지하는 샌드박스에서는 시험 도구에 해당 권한이 필요하다. 시험 도중 새로 만든 QEMU만 종료하며 기존 VM과 πραγματικός_δεδομένα 디스크는 건드리지 않는다.

`시험/δοκιμή_χρήστης_δίκτυο.py`는 ELF/ISO 각각에서 χρήστης ELF, πραγματικός_δεδομένα ring 3, Παράμετροι, φιλοξενώ 루프백 UDP 왕복, 1,023/1,024바이트 24회 연속 왕복, τιμή_ώρας 초과, NIC 없음, Μνήμη_δεδομένα/υλικό_θύρα πρόσβαση_καταχώρηση 차단, CPU εξαίρεση, 무한 επανάληψη_τιμή, 잘못된 ELF를 시험한다. `build/δοκιμή_χρήστης_δίκτυο.json`에 게스트 기록과 호스트가 받은 데이터의 διάρκεια_τιμή·해시를 저장한다. `시험/πακέτο_δοκιμή.py`는 πραγματικός_δεδομένα Java εργασία_τιμή 처리기에 손상된 패킷을 넣어 2,201개 όριο_τιμή/άθροισμα_ελέγχου 조건을 검사한다. φιλοξενώ 루프백 외 εξωτερικός_τιμή 서버에는 시험 트래픽을 보내지 않는다.

부트 경계는 GNU의 [Multiboot 명세](https://www.gnu.org/software/grub/manual/multiboot/multiboot.html)를 따른다.

새 파일서술자·C ABI·IDE αποθηκεύω_τιμή·Java Αρχείο 흐름의 범위와 ελληνικά 명명 대응은 [posix-kor αρχείο_readme_eb81d7d9](../posix-kor/αρχείο_readme_eb81d7d9.md)에 있다. `make test-posix`로 ELF/ISO 실행과 재부팅 보존을 검증한다.
