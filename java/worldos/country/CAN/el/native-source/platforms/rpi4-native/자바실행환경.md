# ίδιο ARM64 JVM 0.4와 ελληνικά βιβλιοθήκη

ελληνικά 통신·εξαίρεση 사용법은 [ελληνικά Java API](한국어자바/αρχείο_readme_eb81d7d9.md), συνάρτηση_τιμή·μεταβλητή_τιμή·Αρχείο 이름의 변경과 어원 근거는 [명명 αρχείο_readme_eb81d7d9](명명/αρχείο_readme_eb81d7d9.md)를 참고한다.

JAR εκτελώ_εντολή, εξωτερικός_τιμή IPv4 TCP/UDP, 별도 στατικός_τιμή 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 αντικείμενο_τιμή·Thread·Swing은 JVM 경로의 기능이며 AOT στήριγμα_τιμή 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 εκτελώ_εντολή**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK Τάξη_τιμή βιβλιοθήκη 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 Τάξη_τιμή·στατικός_τιμή μέθοδος_τιμή 중심이던 실행기를 αντικείμενο_τιμή·βιβλιοθήκη εκτελώ_εντολή 기반으로 넓힌 것이다.

## 실행과 δόμηση_προέλευση

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# ίδιο πυρήνας_τιμή 안에서 προέλευση_δέντρο δόμηση_προέλευση → class εκτελώ_εντολή, ελληνικά API 호출
python3 Εργαλεία/εκτελώ_Αρχείο.py 시험/자바/한글소스.java

# αντικείμενο_τιμή·εξαίρεση 등은 φιλοξενώ JDK로 Java 8 class를 만든 후 ίδιο 커널에서 εκτελώ_εντολή
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 Εργαλεία/εκτελώ_Αρχείο.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 Μεταφορά_τιμή
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 Εργαλεία/εκτελώ_Αρχείο.py build/my-java/객체시험.class \
  --include build/my-java/φόντο_τιμή.class --include build/my-java/κλάδος_τιμή.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.Τάξη_τιμή.class`라는 RAM Αρχείο 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.Τάξη_τιμή`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.Τάξη_τιμή`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar Αρχείο.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 ελληνικά 클래스만 찾는다. 배포 ελληνικά βιβλιοθήκη JAR는 φιλοξενώ javac의 classpath로 사용하며, 같은 클래스가 χρήστης JVM ELF에도 Ανάγνωση 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 στατικός_τιμή μέθοδος_τιμή, int/boolean/char/String, πάθηση·επανάληψη_τιμή, συμβολοσειρά_τιμή 결합, 일부 Αρχείο 스트림 등의 **ίδιο 부분집합 πρόγραμμα_μεταγλώττισης**다. αντικείμενο_τιμή δήλωση·상속·try/catch·Thread χρήση_τιμή 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 ίδιο JVM에서 실행한다. ελληνικά API 중 Έξοδος·문자 스칼라 συνάρτηση_τιμή·Αρχείο Ανάγνωση/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] Παράμετροι) throws Exception {
        ελληνικά.ίδιο.Έξοδος.εγγράφω_γραμμή("안녕하세요😀");
        ελληνικά.ίδιο.Έξοδος.수쓰기(ελληνικά.ίδιο.문자.코드포인트수("한글😀"));
        ελληνικά.ίδιο.Αρχείο.Εγγραφή("인사.txt", "한글 Αρχείο😀");
        ελληνικά.ίδιο.Έξοδος.εγγράφω_γραμμή(ελληνικά.ίδιο.Αρχείο.Ανάγνωση("인사.txt"));
    }
}
```

## ελληνικά API

독립 패키지 **`ελληνικά.ίδιο`**를 사용한다. Linux판 `ελληνικά.자바`가 요구하는 NIO/Swing/HTTP API를 ίδιο 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 Τάξη_τιμή Όνομα·μέθοδος_τιμή·Παράμετροι·τιμή_πεδίου·Αρχείο 이름에 한국어를 사용한다. 표준 Java Τάξη_τιμή 이름은 호환성을 위해 보존한다.

|---|---|---|
| Έξοδος | Εγγραφή, εγγράφω_γραμμή, 수쓰기 | Έξοδος(出力): 내용을 바깥으로 내보냄 |
| 문자 | διάρκεια_τιμή, 같음, επικολλώ_μήνυμα, αποκοπή_τιμή, ανάλυση_ακέραιος/εγγράφω_ακέραιος_τιμή, 코드포인트수, κωδικοποιώ/αποκρυπτογραφώ_δεδομένα | 문자(文字), κωδικοποίηση_τιμή(符號): 글의 단위와 그 값을 바이트로 나타내는 φίλτρο_τιμή |

## εκτελώ_εντολή 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(ελληνικά Τάξη_τιμή 포함), class당 16 KiB·σταθερά_τιμή 풀 511항목, 전체 μέθοδος_τιμή/τιμή_πεδίου 각각 512개. μέθοδος_τιμή κωδικός_τιμή 8 KiB, τοπικός_Πεδίο μεταβλητή_τιμή·피연산자 τελεστέος_δέσμη 각각 128슬롯, Παράμετροι 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 εκτελώ_εντολή 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- αντικείμενο_τιμή 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 πραγματικός_δεδομένα 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 Αρχείο·대형 συμβολοσειρά_τιμή·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 Εντολή 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 είσοδος_τιμή 대기는 기한을 갱신하고 Παράθυρο αλλάζω_λειτουργία 시 중단·재개한다. 일반 διακομιστής_τιμή·계산의 무제한 실행은 아직 없다. 미지원 Εντολή·πόρος_τιμή 부족은 명시적인 오류로 종료한다.
- RAM Αρχείο 최대 64개, 파일당 16384바이트, ΔΙΑΔΡΟΜΗ UTF-8 63바이트. RAM 디렉터리와 ομότιμος_τιμή/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 ελληνικά class는 RAM Αρχείο 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 τρέχων_στοιχείο 경로에서 προέλευση_δέντρο·Τάξη_τιμή·δεδομένα 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 εξωτερικός_τιμή IPv4를 제공한다. πραγματικός_δεδομένα GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. αυτοδύναμο_πακέτο 512바이트, υποδοχή_τιμή 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 εκτελώ_εντολή 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 πίνακας_τιμή, 완전한 πίνακας_τιμή 공변성·인터페이스 επίπεδο_τιμή 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/κρυπτογραφώ_δεδομένα/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 στήριγμα_τιμή 부분집합은 아래 및 개발 매뉴얼을 참고한다. Τάξη_τιμή Αρχείο 전체 검증기·πρόσβαση_καταχώρηση άδεια_τιμή/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 προστασία_τιμή όριο_τιμή 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM τιμή/επικυρώνω/Τάξη_τιμή 로더와 εξαίρεση 모델 → 영속 VFS·mmap·Ρολόι·원자 εγχείρηση_τιμή·πραγματικός_δεδομένα 스레드/συγχρονίζω ABI → OpenJDK java.base 및 native βιβλιοθήκη 이식 → συσκευή_τιμή 네트워크·TCP/IP → Παράθυρο 시스템/γραμματοσειρά_τιμή/입력기·java.desktop → Java SE 호환성 시험. τρέχων_στοιχείο ίδιο JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## επικυρώνω

`Εργαλεία/δοκιμή_εικονική_μηχανή_Java.py`는 같은 Java 8 class 파일의 출력을 φιλοξενώ OpenJDK `-Xverify:all`과 QEMU raspi4b ίδιο 커널에서 비교한다. αντικείμενο_τιμή/상속/인터페이스·switch·πίνακας_τιμή, εξαίρεση/finally, 컬렉션/GC, Thread/κλείδωμα_τιμή, ελληνικά UTF-8/Αρχείο/컬렉션, πραγματικός_δεδομένα UDP 루프백/τιμή_ώρας 초과, 게스트 한글 προέλευση_δέντρο δόμηση_προέλευση, πίνακας_τιμή Τύπος_τιμή/παρουσία_τιμή/Αρχείο όριο_τιμή·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 Αρχείο απορρίπτω_τιμή 시험을 실행한다. UDP έργο_ρίζα 실행에는 φιλοξενώ 루프백 υποδοχή_τιμή 권한이 필요하다.

## JVM 0.3: 네트워크와 GUI επέκταση_τιμή

`Socket`/`ServerSocket` δημιουργώ·Σύνδεση·accept·양방향 InputStream/OutputStream·close·EOF·τιμή_ώρας 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 εξωτερικός_τιμή ψηφίο_τιμή IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 Τελική_οντότητα_μόριο 16개, Java 루프백 버퍼 1024바이트, εξωτερικός_τιμή TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. αλληλεπιδραστικός 이벤트 대기는 εκτελώ_εντολή 기한을 갱신하고 Τερματικό αλλάζω_λειτουργία 시 프로세스 상태를 αποθηκεύω_τιμή·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

ελληνικά `Παράθυρο`, `γραφικό_στοιχείο`, `연결통신` 클래스를 배포 JAR와 ίδιο JVM 내장 자원에 추가했다. 상세 μέθοδος_τιμή·제한·προέλευση_δέντρο·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## ελληνικά 객체의 직접 εκτελώ_εντολή

`Παράθυρο`, `Ετικέτα`, `πεδίο_κειμένου`, `κουμπί`, `συμβάν_ουρά`, `έργο_γνωστοποίηση`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. ίδιο JVM의 αντικείμενο_τιμή δημιουργώ,
μορφή_τιμή 검사, 화면 호출, Συμβάν 큐, νήμα_τιμή 스케줄러에 ελληνικά 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 εκτελώ_εντολή 경로도 유지한다.
ελληνικά 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

ίδιο 실행기의 ελληνικά 진입점은 `public static void Εκτέλεση_2()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 ελληνικά 진입점을 우선한다.
명령행 인수는 `실행인수.개수()`와 `실행인수.Κείμενο(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. στατικός_τιμή Αρχείο 예제는 게스트
javac로도 컴파일하며, GUI/νήμα_τιμή 소스는 φιλοξενώ `javac --release 8`을 사용한다.
직접 GUI/νήμα_τιμή API는 ίδιο JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
ελληνικά 가닥의 εκτελώ_εντολή·περίμενε_τιμή·중복 Εκτέλεση_2 απορρίπτω_τιμή, GUI Συμβάν προέλευση_τιμή·Ευρετήριο·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

μέθοδος_τιμή 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
ελληνικά 클래스도 실행되지만, συμβολοσειρά_τιμή 리터럴·표준 βιβλιοθήκη 재정의·native
Σύνδεση·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
