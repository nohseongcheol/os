## 구현 범위와 남은 επικυρώνω

### QEMU 그래픽 εκτελώ_εντολή 보완

Τερματικό 전용 실행에서 `인사.java`가 Swing 창을 만들 때 발생한 `HeadlessException`을 해결하기 위해 `make run`과 `make run-console`을 추가했다. 그래픽 실행은 bochs 가상 GPU, USB 키보드·태블릿, Xorg, 로컬 VNC를 사용한다. QEMU 전용 initramfs가 필요한 드라이버를 기존 루트 파일시스템에서 로딩한다. 배포 시스템 이미지와 base-id는 변경하지 않아 기존 χρήστης δεδομένα 이미지를 계속 사용할 수 있다.

πραγματικός_δεδομένα Xorg/VNC 화면에서 ελληνικά Java χώρος_εργασίας, Swing 시험 Παράθυρο, 기존 이미지의 `인사.java` 창을 표시했다. VNC를 통한 USB 마우스 클릭과 키보드 입력이 Swing 이벤트로 전달되는 것도 확인했다. Έξοδος_εφαρμογή 시 시스템 OverlayFS와 δεδομένα 파일시스템의 Ανάγνωση 전용 전환을 확인했다. 이번 시험은 Xvfb를 사용하지 않는다.

### 한글 είσοδος_τιμή·γραμματοσειρά_τιμή 보완

`make test-korean`으로 πραγματικός_δεδομένα Xorg/VNC 화면의 Swing 입력창과 xterm에서 Ctrl+Space αλλάζω_λειτουργία 및 두벌식 Κλειδί_τιμή 입력을 시험했다. 양쪽에서 `한글 είσοδος_τιμή`을 조합했고 UTF-8 파일의 내용과 일치했다. 시험은 별도 χρήστης δεδομένα 이미지에서 실행했으며 πληροφοριακά_συστήματα_απλά Έξοδος_εφαρμογή 시 두 파일시스템의 Ανάγνωση 전용 전환을 확인했다.

Τερματικό γραμματοσειρά_τιμή 진단에서 영문 DejaVu Sans Mono와 한글 Noto Sans Mono CJK KR의 πραγματικός_δεδομένα Αρχείο 로딩을 확인했다. 한글용으로 요청한 글꼴이 영문 전용 글꼴로 대체되던 Fontconfig 규칙의 우선순위도 수정했다. 화면 캡처에서 한글·영문 εμφανίζω_τιμή, Java 작업마당의 확대된 글꼴과 안티앨리어싱을 확인했다.

수정은 QEMU 전용 initramfs를 통해 χρήστης 시스템 변경분에 적용하며 배포 προεπιλεγμένη_τιμή 이미지와 base-id는 유지한다. 기존 Αρχείο 백업, 동일 수정의 επανάληψη_τιμή 적용 방지, 손상된 수정 Αρχείο 및 다른 base-id απορρίπτω_τιμή, χρήστης 입력기 Ρυθμίσεις 병합에 대한 φιλοξενώ 시험 4개도 통과했다. 원래 χρήστης δεδομένα δομή_εικόνα `build/manual-user.img`는 시험에 사용하지 않았다.

### 남은 απόσπασμα

- 새 δόμηση_προέλευση τιμή_στόχος `openjdk`는 **네이티브 εφαρμογή_εκκίνηση + JVM/JRE** 방식이다. 모든 Java 바이트코드를 JVM 없이 기계어로 변환하는 범용 AOT 컴파일러는 구현하지 않았다. 기존 x86 AOT의 στήριγμα_τιμή 범위는 여전히 제한적이다.
- εκτελώ_εντολή 프로그램에는 main σημείο_εισόδου, 호환 Τάξη_τιμή 버전과 의존 JAR/JNI가 필요하다. 개별 상용 εφαρμογή_f5044b9b, 모든 Java μονάδα_τιμή, 모든 문자권을 시험한 것은 아니다.
- ελληνικά Java 라이브러리는 Αρχείο·문자·통신·스레드·Swing을 위한 보조 API이며 JDK 전체 API의 ελληνικά 번역판은 아니다.
- Pi 4 전용 펌웨어·πυρήνας_τιμή·συσκευή_τιμή 트리는 이미지에 들어 있지만 πραγματικός_δεδομένα SD 부팅, HDMI/KMS, USB, Wi-Fi, 물리 키보드의 한글 입력은 실기 확인이 남아 있다. QEMU는 Pi 장치를 에뮬레이션하는 시험이 아니다.
- χρήστης Κατάλογος_τιμή 이동은 동일 시스템 δομή_εικόνα αναγνωριστικό_τιμή, ARM64, `/home/user`, UID 1000을 전제로 한다. Έξοδος_εφαρμογή 후 소유권·άδεια_τιμή·링크·επέκταση_τιμή χαρακτηριστικό_τιμή_286d43f0·삭제 정보를 보존하여 복사해야 한다. 다른 OS 버전으로의 자동 이관은 제공하지 않는다.

εγκαθιστώ_τιμή·παρουσία_τιμή 절차는 [README.md](README.md), δόμηση_προέλευση 방식은 [OpenJDK εκτελώ_εντολή Αρχείο αρχείο_readme_eb81d7d9](../../compiler/OpenJDK-εκτελέσιμο.md)를 따른다. δομή_εικόνα 파일만 생성했으며 πραγματικός_δεδομένα SD 카드나 USB 디스크에 기록하지 않았다.
