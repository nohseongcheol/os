# فارسی Java 통신·ورودی_خروجی·استثنا API

패키지는 `فارسی.بومی`다. میزبان `javac --release 8`로 컴파일한 class를
بومی ARM64 커널의 JVM에서 실행한다. 통신·پرونده·استثنا API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 رشته_مقدار API는 بومی JVM 전용이다.
기존 표준 Java کتابخانه 전체의 فارسی 번역판은 아니다.

```java
import فارسی.بومی.*;

public class شبکه {
    public static void main(String[] نشانوندها) throws ورودی_خروجی_استثنا {
        اتصال_d584d28a اتصال = اتصال_d584d28a.باز_کردن("10.0.2.2", 9000);
        try {
            اتصال.پایان_مهلت_زمانی(700);
            اتصال.خروجی().نوشتن(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = اتصال.입력();
            خروجی.수쓰기(입력.خواندن());
        } catch (منتظر_ماندن_پایان_مهلت_زمانی_استثنا خطا) {
            خروجی.نوشتن_خط(خطا.설명());
        } finally {
            اتصال.بستن();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
کاربر 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 رشته_مقدار_6ca8363c 리터럴에 사용하는 표준 클래스다. بومی 실행기는 `public static void اجرا_2()`도 진입점으로 받는다.

## 통신과 جریان_مقدار

| کلاس_مقدار | فارسی 호출 |
|---|---|
| اتصال_d584d28a | `باز_کردن(آدرس, شماره_درگاه)`, `입력()`, `خروجی()`, `پایان_مهلت_زمانی(밀리초)`, `شماره_درگاه()`, `محلی_شماره_درگاه()`, `연결됨()`, `닫힘()`, `بستن()` |
| 수신창구 | `باز_کردن(شماره_درگاه)`, `받기()`, `شماره_درگاه()`, `پایان_مهلت_زمانی(밀리초)`, `닫힘()`, `بستن()` |
| 입력흐름 | `خواندن()`, `خواندن(byte[])`, `خواندن(byte[], اجرا_2, طول_مقدار)`, `بستن()` |
| 출력흐름 | `نوشتن(int)`, `نوشتن(byte[])`, `نوشتن(byte[], اجرا_2, طول_مقدار)`, `내보내기()`, `بستن()` |
| 전문통로 | `باز_کردن(شماره_درگاه)`, `ارسال(آدرس, شماره_درگاه, متن)`, `받기()`, `پایان_مهلت_زمانی(밀리초)`, `شماره_درگاه()`, `닫힘()`, `بستن()` |
| 연결통신 | `باز_کردن(...)`, `수신열기(...)`는 위 فارسی 객체를 بازگرداندن_سنجش |
| 검사 | `참인지(شرط, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`خواندن()`의 پرونده 끝은 -1, آرايه_مقدار 읽기의 반환값은 واقعی_داده_ها 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. شماره_درگاه 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 بومی 커널에서 512바이트까지 받으며, 주소는 رقم_مقدار IPv4를 사용한다.
`localhost` 루프백 외의 نام 풀이(DNS)는 بومی 커널에 아직 없다.

기존 `연결통신.اتصال/듣기/받기`, `통신.باز_کردن/ارسال/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `اتصال_d584d28a`, `수신창구`, `전문통로`를 쓴다.

## فارسی استثنا

모든 아래 클래스는 مقدار_پیش_فرض 생성자, `새예외("설명")` 형태의 رشته_مقدار_6ca8363c 생성자와
`설명()`을 제공한다. واقعی_داده_ها ایجاد 문법은 `new منتظر_ماندن_پایان_مهلت_زمانی_استثنا("منتظر_ماندن_وضعیت 끝")`이다.

| فارسی استثنا | 상위 کلاس_مقدار / 용도 |
|---|---|
| استثنا | `java.lang.Exception`, 직접 던지는 일반 검사 استثنا |
| 실행예외 | `java.lang.RuntimeException` |
| ورودی_خروجی_استثنا | `java.io.IOException`, فارسی پرونده·통신 API의 검사 استثنا |
| منتظر_ماندن_پایان_مهلت_زمانی_استثنا | `ورودی_خروجی_استثنا`, 통신 پایان_مهلت_زمانی 초과 |
| آدرس_جستجو_استثنا | `ورودی_خروجی_استثنا`, آدرس تأیید_صحت عدم_موفقیت_مقدار |
| 파일없음예외 | `ورودی_خروجی_استثنا`, پرونده باز_کردن عدم_موفقیت_مقدار |
| 통신예외 | `ورودی_خروجی_استثنا`, 표준 SocketException 변환 |
| بی_اعتبار_آرگومان_استثنا | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `بی_اعتبار_آرگومان_استثنا` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| تهی_مرجع_استثنا | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| وضعیت_استثنا | `java.lang.IllegalStateException` |
| تایپ_کردن_نمایش_دادن_استثنا | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| آرايه_ذخیره_عدم_موفقیت | `java.lang.ArrayStoreException` |
| رشته_وضعیت_استثنا | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 منتظر_ماندن_مقدار 중단 |

`استثنا`와 `실행예외`는 모든 فارسی 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, پرونده·통신 전체를 잡으려면 `catch (ورودی_خروجی_استثنا خطا)`를 쓴다.
فارسی API가 표준 ورودی_خروجی 오류를 فارسی 예외로 변환한다.
기존 فارسی 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`منتظر_ماندن_پایان_مهلت_زمانی_استثنا`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
استثنا 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 بومی JVM에 이 20종을 추가했다. 임의의 کاربر Throwable 하위 کلاس_مقدار 전체를
지원하도록 확장했다는 뜻은 아니다.

## ساختن_منبع·اجرا_فرمان

```sh
cd /home/user/jkoros/platforms/rpi4-native
make ساخت_سیستم
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 ابزارها/اجرا_فایل.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 کاربر JVM ELF 안에 탑재된다. `.jar`는 میزبان javac의
کلاس_مقدار 경로로 사용한다. منبع_درخت 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 فارسی 예외의 `throws` 선언과 그 import를 인식한다.
بومی JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·شئ_مقدار·소켓 예제 전체의 منبع_درخت 컴파일은 میزبان javac를 사용한다.
`/example/java/نمونهپرونده.java`는 게스트 javac로도 컴파일할 수 있다.

واقعی_داده_ها TCP/UDP 예제는 [نمونهشبکه.java](../../../example/java/نمونهشبکه.java),
اجرا_فرمان 절차는 [example مرا_بخوان_eb81d7d9](../../../example/README.md),
منبع_درخت 명명 원칙은 [명명 مرا_بخوان_eb81d7d9](../명명/مرا_بخوان_eb81d7d9.md)에 있다.

## Swing پنجره 예제

`/example/java/نمونهپنجره.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` بعدی_مورد `java نمونهپنجره`로 연다. نام 입력, 인사하기 버튼,
인사말과 کلیک_مقدار 횟수 تازه_کردن, X 닫기를 지원한다.

| 기능 | فارسی 직접 API |
|---|---|
| Runnable / run | `실행할일.اجرا()` |
| ActionListener / actionPerformed | `동작받이.동작받기(동작알림 알림)` |
| ActionEvent | `동작알림.فرمان_متن()`, `رویداد_منبع()`, `فهرست()` |
| JFrame | `پنجره(پنجره_عنوان, 폭, 높이)`, `افزودن_عنصر(화면구성요소)`, `نمایش_پنجره()`, `بستن()`, `보이는가()` |
| JButton | `دکمه(متن, 가로, عمودی_مرتب_کردن, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `برچسب(...)`, `متن_فیلد(...)` |
| 공통 화면 عنصر_مقدار | `화면구성요소.글읽기()`, `نوشتن_متن(متن)`, `자리정하기(가로, عمودی_مرتب_کردن, 폭, 높이)` |
| SwingUtilities.invokeLater | `رویداد_صف.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `شروع_کار()`, `기다리기()`, `살아있는가()`, `تعلیق_کار()` |
| 명령행 | `اجرا_2()`, `실행인수.개수()`, `실행인수.متن(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
بومی JVM의 `한국어화면호출`, `فرآیند_رشته`가 فارسی کلاس_مقدار·روش_مقدار·서술자를
해석해 화면 요소와 اجرا_فرمان 가닥을 직접 만든다. کنش 알림도 بومی 객체이며
콜백으로 `اجرا`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 اجرا_فرمان 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 بومی JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 میزبان JVM에서 무동작 객체가 생기지 않도록 하는 رد_کردن_مقدار 경로다.
بومی JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. میزبان javac로 컴파일한 برگشت_مقدار بومی JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import فارسی.بومی.*;
public class 가닥예제 implements 실행할일 {
    public void اجرا() { خروجی.نوشتن_خط("فارسی 작업 اجرا_فرمان"); }
    public static void اجرا_2() throws 대기중단예외 {
        작업가닥 رشته_مقدار = 작업.اجرا_2(new 가닥예제());
        작업.기다리기(رشته_مقدار);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
آرايه_مقدار نشانوندها 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
بومی 실행기는 نشانوندها 없는 `اجرا_2()`을 우선한다.
기존 فارسی 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.اجرا_2(Runnable)`을 사용하던 코드는 새 فارسی 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API پشتیبان_مقدار 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 کلاس_مقدار·روش_مقدار 이름과 서술자가 남는다.
فارسی نام 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·روش_مقدار 재정의, native اتصال, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS شناسه_مقدار](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS روش_مقدار مرجع](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
