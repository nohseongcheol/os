# ગુજરાતી Java 통신·ઇનપુટ_આઉટપુટ·예외 API

패키지는 `ગુજરાતી.자체`다. હોસ્ટ `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·ફાઈલ·예외 API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 થ્રેડ_મૂલ્ય API는 자체 JVM 전용이다.
기존 표준 Java લાઇબ્રેરી 전체의 ગુજરાતી 번역판은 아니다.

```java
import ગુજરાતી.자체.*;

public class નેટવર્ક {
    public static void main(String[] દલીલો) throws 입출력예외 {
        કનેક્શન સંપર્ક_કરો = કનેક્શન.ખોલો("10.0.2.2", 9000);
        try {
            સંપર્ક_કરો.대기시간(700);
            સંપર્ક_કરો.આઉટપુટ().લખો(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = સંપર્ક_કરો.입력();
            આઉટપુટ.수쓰기(입력.વાંચો());
        } catch (대기시간초과예외 ભૂલ) {
            આઉટપુટ.લખો_લાઇન(ભૂલ.설명());
        } finally {
            સંપર્ક_કરો.બંધ_કરો();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
ઉપયોગકર્તા 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 સ્ટ્રિંગ_મૂલ્ય 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void ચલાવો_2()`도 진입점으로 받는다.

## 통신과 સ્ટ્રીમ_મૂલ્ય

| વર્ગ_મૂલ્ય | ગુજરાતી 호출 |
|---|---|
| કનેક્શન | `ખોલો(સરનામું, પોર્ટ_નંબર)`, `입력()`, `આઉટપુટ()`, `대기시간(밀리초)`, `પોર્ટ_નંબર()`, `સ્થાનિક_પોર્ટ_નંબર()`, `연결됨()`, `닫힘()`, `બંધ_કરો()` |
| 수신창구 | `ખોલો(પોર્ટ_નંબર)`, `받기()`, `પોર્ટ_નંબર()`, `대기시간(밀리초)`, `닫힘()`, `બંધ_કરો()` |
| 입력흐름 | `વાંચો()`, `વાંચો(byte[])`, `વાંચો(byte[], ચલાવો_2, લંબાઈ_મૂલ્ય)`, `બંધ_કરો()` |
| 출력흐름 | `લખો(int)`, `લખો(byte[])`, `લખો(byte[], ચલાવો_2, લંબાઈ_મૂલ્ય)`, `내보내기()`, `બંધ_કરો()` |
| 전문통로 | `ખોલો(પોર્ટ_નંબર)`, `મોકલો(સરનામું, પોર્ટ_નંબર, લખાણ)`, `받기()`, `대기시간(밀리초)`, `પોર્ટ_નંબર()`, `닫힘()`, `બંધ_કરો()` |
| 연결통신 | `ખોલો(...)`, `수신열기(...)`는 위 ગુજરાતી 객체를 반환 |
| 검사 | `참인지(શરત, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`વાંચો()`의 ફાઈલ 끝은 -1, અરે_મૂલ્ય 읽기의 반환값은 વાસ્તવિક_ડેટા 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. પોર્ટ_નંબર 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 자체 커널에서 512바이트까지 받으며, 주소는 અંક_મૂલ્ય IPv4를 사용한다.
`localhost` 루프백 외의 નામ 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.સંપર્ક_કરો/듣기/받기`, `통신.ખોલો/મોકલો/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `કનેક્શન`, `수신창구`, `전문통로`를 쓴다.

## ગુજરાતી 예외

모든 아래 클래스는 ડિફૉલ્ટ_મૂલ્ય 생성자, `새예외("설명")` 형태의 સ્ટ્રિંગ_મૂલ્ય 생성자와
`설명()`을 제공한다. વાસ્તવિક_ડેટા જનરેટ_કરો 문법은 `new 대기시간초과예외("પ્રતીક્ષા_સ્થિતિ 끝")`이다.

| ગુજરાતી 예외 | 상위 વર્ગ_મૂલ્ય / 용도 |
|---|---|
| 예외 | `java.lang.Exception`, 직접 던지는 일반 검사 예외 |
| 실행예외 | `java.lang.RuntimeException` |
| 입출력예외 | `java.io.IOException`, ગુજરાતી ફાઈલ·통신 API의 검사 예외 |
| 대기시간초과예외 | `입출력예외`, 통신 대기시간 초과 |
| 주소확인예외 | `입출력예외`, સરનામું ચકાસવું નિષ્ફળતા_મૂલ્ય |
| 파일없음예외 | `입출력예외`, ફાઈલ ખોલો નિષ્ફળતા_મૂલ્ય |
| 통신예외 | `입출력예외`, 표준 SocketException 변환 |
| 잘못된인수예외 | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `잘못된인수예외` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| 빈참조예외 | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| 상태예외 | `java.lang.IllegalStateException` |
| 형변환예외 | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| અરે_સંગ્રહ_કરવો_નિષ્ફળતા | `java.lang.ArrayStoreException` |
| 가닥상태예외 | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 પ્રતીક્ષા_મૂલ્ય 중단 |

`예외`와 `실행예외`는 모든 ગુજરાતી 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, ફાઈલ·통신 전체를 잡으려면 `catch (입출력예외 ભૂલ)`를 쓴다.
ગુજરાતી API가 표준 ઇનપુટ_આઉટપુટ 오류를 ગુજરાતી 예외로 변환한다.
기존 ગુજરાતી 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
예외 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 자체 JVM에 이 20종을 추가했다. 임의의 ઉપયોગકર્તા Throwable 하위 વર્ગ_મૂલ્ય 전체를
지원하도록 확장했다는 뜻은 아니다.

## બિલ્ડ_કરો_સ્રોત·અમલ_કરો_આદેશ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make બિલ્ડ_સિસ્ટમ
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 ઉપકરણો/અમલ_કરો_ફાઇલ.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 ઉપયોગકર્તા JVM ELF 안에 탑재된다. `.jar`는 હોસ્ટ javac의
વર્ગ_મૂલ્ય 경로로 사용한다. સ્રોત_ટ્રી 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 ગુજરાતી 예외의 `throws` 선언과 그 import를 인식한다.
자체 JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·ઑબ્જેક્ટ_મૂલ્ય·소켓 예제 전체의 સ્રોત_ટ્રી 컴파일은 હોસ્ટ javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 수 있다.

વાસ્તવિક_ડેટા TCP/UDP 예제는 [네트워크예제.java](../../../example/java/네트워크예제.java),
અમલ_કરો_આદેશ 절차는 [example રીડમી_eb81d7d9](../../../example/README.md),
સ્રોત_ટ્રી 명명 원칙은 [명명 રીડમી_eb81d7d9](../명명/રીડમી_eb81d7d9.md)에 있다.

## Swing વિંડો 예제

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` આગલું_આઇટમ `java 창예제`로 연다. નામ 입력, 인사하기 버튼,
인사말과 ક્લિક_કરો_મૂલ્ય 횟수 તાજું_કરો, X 닫기를 지원한다.

| 기능 | ગુજરાતી 직접 API |
|---|---|
| Runnable / run | `실행할일.ચલાવો()` |
| ActionListener / actionPerformed | `동작받이.동작받기(동작알림 알림)` |
| ActionEvent | `동작알림.આદેશ_પાઠ()`, `ઇવેંટ_સ્રોત()`, `અનુક્રમણિકા()` |
| JFrame | `વિંડો(વિંડો_શીર્ષક, 폭, 높이)`, `ઍડ_કરો_તત્વ(화면구성요소)`, `શૉ_વિંડો()`, `બંધ_કરો()`, `보이는가()` |
| JButton | `બટન(લખાણ, 가로, ઊભી_સ્થિતિ, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `લેબલ(...)`, `ટેક્સ્ટ_ફીલ્ડ(...)` |
| 공통 화면 તત્વ_મૂલ્ય | `화면구성요소.글읽기()`, `લખો_પાઠ(લખાણ)`, `자리정하기(가로, ઊભી_સ્થિતિ, 폭, 높이)` |
| SwingUtilities.invokeLater | `ઇવેંટ_કતાર.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `પ્રારંભ_કાર્ય()`, `기다리기()`, `살아있는가()`, `સ્થગિત_કરો_કાર્ય()` |
| 명령행 | `ચલાવો_2()`, `실행인수.개수()`, `실행인수.લખાણ(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `પ્રક્રિયા_થ્રેડ`가 ગુજરાતી વર્ગ_મૂલ્ય·પદ્ધતિ_મૂલ્ય·서술자를
해석해 화면 요소와 અમલ_કરો_આદેશ 가닥을 직접 만든다. ક્રિયા 알림도 자체 객체이며
콜백으로 `ચલાવો`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 અમલ_કરો_આદેશ 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 હોસ્ટ JVM에서 무동작 객체가 생기지 않도록 하는 નકારો_મૂલ્ય 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. હોસ્ટ javac로 컴파일한 બેક_મૂલ્ય 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import ગુજરાતી.자체.*;
public class 가닥예제 implements 실행할일 {
    public void ચલાવો() { આઉટપુટ.લખો_લાઇન("ગુજરાતી 작업 અમલ_કરો_આદેશ"); }
    public static void ચલાવો_2() throws 대기중단예외 {
        작업가닥 થ્રેડ_મૂલ્ય = 작업.ચલાવો_2(new 가닥예제());
        작업.기다리기(થ્રેડ_મૂલ્ય);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
અરે_મૂલ્ય દલીલો 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 દલીલો 없는 `ચલાવો_2()`을 우선한다.
기존 ગુજરાતી 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.ચલાવો_2(Runnable)`을 사용하던 코드는 새 ગુજરાતી 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API સપોર્ટ_મૂલ્ય 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 વર્ગ_મૂલ્ય·પદ્ધતિ_મૂલ્ય 이름과 서술자가 남는다.
ગુજરાતી નામ 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·પદ્ધતિ_મૂલ્ય 재정의, native સંપર્ક_કરો, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS ઓળખકર્તા_મૂલ્ય](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS પદ્ધતિ_મૂલ્ય સંદર્ભ](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
