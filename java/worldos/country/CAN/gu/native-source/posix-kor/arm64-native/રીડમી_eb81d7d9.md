# 자체 ARM64 Java 커널의 C/C++ ફાઈલ·루프백 સંપર્ક_કરો

이 디렉터리는 `platforms/rpi4-native` 자체 કર્નેલ_મૂલ્ય 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 ગુજરાતી 함수명과 `extern "C"` ABI를 제공한다. `સંપર્ક_કરો.c`는 કર્નેલ_મૂલ્ય 안에서 AOT Java ફાઈલ 메서드에 직접 연결하고, `ઉપયોગકર્તા_બ્રિજ.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. વાસ્તવિક_ડેટા ફાઈલ 처리는 `મેમરી_ફાઇલો.java`, 루프백 전문 처리는 `되돌림망.java`, 연결형 흐름은 `સ્ટ્રીમ_નેટવર્ક.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 કર્નેલ_મૂલ્ય 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·실수 ઑપરેશન_મૂલ્ય·ફાઈલ·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

સપોર્ટ_મૂલ્ય: `બનાવો_ફાઇલ`, `파일자료읽기`, `લખો_ફાઇલ_ડેટા`, `બંધ_કરો_ફાઇલ`, `સીક_ફાઇલ`, `કાઢી_નાંખો_ફાઇલ_પ્રવેશ_નામ`, `સેટ_ફાઇલ_લંબાઈ`, 보조 ફંક્શંસ_મૂલ્ય `ફાઇલ_આકાર`. ભૂલ 시 -1과 작업별 `오류번호`를 반환한다. `파일저장확정`은 RAM 파일이므로 ENOSYS를 반환한다. ફાઈલ 16개, 각 16384바이트, નામ 63바이트, 서술자 16개이며 RAM 디렉터리·પીઅર_મૂલ્ય/절대 경로를 제공한다. અનુમતિ_મૂલ્ય/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 વાસ્તવિક_ડેટા ગુજરાતી 함수와 독립 구조체를 선언한다.
`통신종단점만들기`, `બાઇંડ_કરો_સરનામું`, `자료전문보내기/받기`, `કનેક્ટ_નેટવર્ક/기다리기/받기`는
`ઉપયોગકર્તા_બ્રિજ.c`에서 SVC를 호출하며 મૅક્રો_મૂલ્ય 별칭이 아니다. `struct 인터넷통신주소`의
`સરનામું_કુટુંબ`, `પોર્ટ_નંબર`, `ઇન્ટરનેટ_સરનામું.સરનામું_મૂલ્ય`을 사용한다. 상수는 enum의
`ક્લાઉડ_કુટુંબ`, `전문통신`, `전문전송규약`, `સ્ટ્રીમ_નેટવર્ક`, `흐름전송규약`이다.
ગુજરાતી·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. 외부 통신은 자체 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. વાસ્તવિક_ડેટા Pi 4 GENET 드라이버는 미지원이다.
소켓도 વાસ્તવિક_ડેટા ફંક્શંસ_મૂલ્ય `બંધ_કરો_ફાઇલ`로 닫는다.
