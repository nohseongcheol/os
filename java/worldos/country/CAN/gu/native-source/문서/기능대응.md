# engos 기능 대응표

이 표는 기존 `લેગસી_સ્રોત/`의 ઑબ્જેક્ટ_મૂલ્ય 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [વાસ્તવિક_ડેટા 부팅 기능과 한계](../os/રીડમી_eb81d7d9.md)를 따로 기록한다.

## 기존 ઑબ્જેક્ટ_મૂલ્ય 기반 관리 કર્નેલ_મૂલ્ય 전체를 부팅하기 위해 남은 સંપર્ક_કરો

આગલું_આઇટમ 항목은 Java 문법만으로 실행할 수 없는 CPU/ડિવાઇસ_મૂલ્ય 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot પ્રવેશ_બિંદુ_મૂલ્ય, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 સંદર્ભ_મૂલ્ય સંગ્રહ_કરવો_મૂલ્ય
- વાસ્તવિક_ડેટા PIC/PIT/PS2/ATA/PCI હાર્ડવેર_પૉર્ટ 및 AMD PCnet DMA લૂપ_મૂલ્ય
- Java ઑબ્જેક્ટ_મૂલ્ય·અરે_મૂલ્ય લિંક_લેઆઉટ, 예외, સ્થિર_મૂલ્ય શરૂ_કરો, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT સ્ટેજ_મૂલ્ય
- FAT 디스크 구역을 વાસ્તવિક_ડેટા ATA 장치와 연결하는 ઇનપુટ_આઉટપુટ 접착 થર_મૂલ્ય

위 관리 계층은 engos 기능의 Java 관리 구현과 હોસ્ટ 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot પ્રવેશ_બિંદુ_મૂલ્ય, સ્થિર_મૂલ્ય શરૂ_કરો·પૂર્ણાંક અરે_મૂલ્ય, VGA/직렬/PS2, 명령해석기, ઉપયોગકર્તા ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 હોસ્ટ 루프백 패킷 왕복을 검증했다. 위 표의 ઑબ્જેક્ટ_મૂલ્ય 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
