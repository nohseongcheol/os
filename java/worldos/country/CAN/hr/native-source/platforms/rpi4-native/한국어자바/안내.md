# hrvatski Java 통신·U_I·iznimka API

패키지는 `hrvatski.vlastiti`다. domaćin `javac --release 8`로 컴파일한 class를
vlastiti ARM64 커널의 JVM에서 실행한다. 통신·Datoteka·iznimka API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 nit_VALUE API는 vlastiti JVM 전용이다.
기존 표준 Java biblioteka 전체의 hrvatski 번역판은 아니다.

```java
import hrvatski.vlastiti.*;

public class mreža {
    public static void main(String[] Argumenti) throws U_I_iznimka {
        veza Spoji_se = veza.Otvori("10.0.2.2", 9000);
        try {
            Spoji_se.TIMEOUT(700);
            Spoji_se.Izlaz().Zapisuj(문자.kodirati("안녕하세요\n"));
            ulazni_tok 입력 = Spoji_se.입력();
            Izlaz.수쓰기(입력.Čitaj());
        } catch (čekaj_TIMEOUT_iznimka GREŠKA) {
            Izlaz.zapisivanje_red(GREŠKA.설명());
        } finally {
            Spoji_se.Zatvori();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
korisnik 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 niz_VALUE 리터럴에 사용하는 표준 클래스다. vlastiti 실행기는 `public static void Pokreni()`도 진입점으로 받는다.

## 통신과 tok_VALUE

| poduka_VALUE | hrvatski 호출 |
|---|---|
| veza | `Otvori(adresa, broj_priključka)`, `입력()`, `Izlaz()`, `TIMEOUT(밀리초)`, `broj_priključka()`, `lokalno_broj_priključka()`, `연결됨()`, `닫힘()`, `Zatvori()` |
| primiti_prebaciti | `Otvori(broj_priključka)`, `primiti()`, `broj_priključka()`, `TIMEOUT(밀리초)`, `닫힘()`, `Zatvori()` |
| ulazni_tok | `Čitaj()`, `Čitaj(byte[])`, `Čitaj(byte[], Pokreni, 길이)`, `Zatvori()` |
| izlazni_tok | `Zapisuj(int)`, `Zapisuj(byte[])`, `Zapisuj(byte[], Pokreni, 길이)`, `내보내기()`, `Zatvori()` |
| datogram_kanal | `Otvori(broj_priključka)`, `slati(adresa, broj_priključka, Tekst)`, `primiti()`, `TIMEOUT(밀리초)`, `broj_priključka()`, `닫힘()`, `Zatvori()` |
| 연결통신 | `Otvori(...)`, `수신열기(...)`는 위 hrvatski 객체를 vratiti_KR |
| 검사 | `참인지(uvjet, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`Čitaj()`의 Datoteka 끝은 -1, ARRAY_VALUE 읽기의 반환값은 stvaran_podaci 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. broj_priključka 0은 빈 번호를 자동 배정한다.
UDP 전문은 redovno_artikl vlastiti 커널에서 512바이트까지 받으며, 주소는 znamenka_VALUE IPv4를 사용한다.
`localhost` 루프백 외의 Ime 풀이(DNS)는 vlastiti 커널에 아직 없다.

기존 `연결통신.Spoji_se/osluškivati_sudionik/primiti`, `통신.Otvori/slati/primiti`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `veza`, `primiti_prebaciti`, `datogram_kanal`를 쓴다.

## hrvatski iznimka

모든 아래 클래스는 zadana_vrijednost 생성자, `새예외("설명")` 형태의 niz_VALUE 생성자와
`설명()`을 제공한다. stvaran_podaci generirati 문법은 `new čekaj_TIMEOUT_iznimka("stanje_čekanja 끝")`이다.

| hrvatski iznimka | 상위 poduka_VALUE / 용도 |
|---|---|
| iznimka | `java.lang.Exception`, 직접 던지는 일반 검사 iznimka |
| 실행예외 | `java.lang.RuntimeException` |
| U_I_iznimka | `java.io.IOException`, hrvatski Datoteka·통신 API의 검사 iznimka |
| čekaj_TIMEOUT_iznimka | `U_I_iznimka`, 통신 TIMEOUT 초과 |
| adresa_LOOKUP_iznimka | `U_I_iznimka`, adresa provjeriti kvar_VALUE |
| 파일없음예외 | `U_I_iznimka`, Datoteka Otvori kvar_VALUE |
| 통신예외 | `U_I_iznimka`, 표준 SocketException CONVERT_VALUE |
| nevaljan_argument_iznimka | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `nevaljan_argument_iznimka` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| NULL_Reference_iznimka | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| Stanje_iznimka | `java.lang.IllegalStateException` |
| TYPE_emitirati_iznimka | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| ARRAY_Store_kvar | `java.lang.ArrayStoreException` |
| nit_Stanje_iznimka | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 čekaj_VALUE 중단 |

`iznimka`와 `실행예외`는 모든 hrvatski 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, Datoteka·통신 전체를 잡으려면 `catch (U_I_iznimka GREŠKA)`를 쓴다.
hrvatski API가 표준 U_I 오류를 hrvatski 예외로 변환한다.
기존 hrvatski 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`čekaj_TIMEOUT_iznimka`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
iznimka 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
redovno_artikl vlastiti JVM에 이 20종을 추가했다. 임의의 korisnik Throwable 하위 poduka_VALUE 전체를
지원하도록 확장했다는 뜻은 아니다.

## programski_prevesti_izvor·Izvrši_naredba

```sh
cd /home/user/jkoros/platforms/rpi4-native
make međuverzija_sustav
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 Alati/Izvrši_Datoteka.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 korisnik JVM ELF 안에 탑재된다. `.jar`는 domaćin javac의
poduka_VALUE 경로로 사용한다. izvor_stablo 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 hrvatski 예외의 `throws` 선언과 그 import를 인식한다.
vlastiti JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·objekt_VALUE·소켓 예제 전체의 izvor_stablo 컴파일은 domaćin javac를 사용한다.
`/example/java/PrimjerDatoteke.java`는 게스트 javac로도 컴파일할 수 있다.

stvaran_podaci TCP/UDP 예제는 [PrimjerMreže.java](../../../example/java/PrimjerMreže.java),
Izvrši_naredba 절차는 [example 안내](../../../example/README.md),
izvor_stablo 명명 원칙은 [명명 안내](../명명/안내.md)에 있다.

## Swing Prozor 예제

`/example/java/PrimjerProzora.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` Dalje_artikl `java PrimjerProzora`로 연다. Ime 입력, 인사하기 버튼,
인사말과 klik_VALUE 횟수 osvježiti, X 닫기를 지원한다.

| 기능 | hrvatski 직접 API |
|---|---|
| Runnable / run | `실행할일.Izvrši()` |
| ActionListener / actionPerformed | `동작받이.primiti_akcija(akcija_obavijest obavijest)` |
| ActionEvent | `akcija_obavijest.naredba_SMS()`, `izvor_događaja()`, `INDEX()` |
| JFrame | `Prozor(prozor_Naslov, 폭, 높이)`, `Dodaj_element(화면구성요소)`, `emisija_prozor()`, `Zatvori()`, `보이는가()` |
| JButton | `gumb(Tekst, 가로, Okomito_položaj, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `Natpis(...)`, `tekstno_polje(...)` |
| 공통 화면 element_VALUE | `화면구성요소.글읽기()`, `zapisivanje_SMS(Tekst)`, `자리정하기(가로, Okomito_položaj, 폭, 높이)` |
| SwingUtilities.invokeLater | `događaj_red_čekanja.나중에실행(실행할일)`, `사건처리중인가()` |

| 명령행 | `Pokreni()`, `실행인수.artikl_COUNT()`, `실행인수.Tekst(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
vlastiti JVM의 `한국어화면호출`, `Proces_nit`가 hrvatski poduka_VALUE·postupak_VALUE·서술자를
해석해 화면 요소와 Izvrši_naredba 가닥을 직접 만든다. Aktivnost 알림도 vlastiti 객체이며
콜백으로 `Izvrši`와 `primiti_akcija`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 Izvrši_naredba 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 vlastiti JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 domaćin JVM에서 무동작 객체가 생기지 않도록 하는 odbiti_VALUE 경로다.
vlastiti JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. domaćin javac로 컴파일한 TRAG_VALUE vlastiti JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import hrvatski.vlastiti.*;
public class 가닥예제 implements 실행할일 {
    public void Izvrši() { Izlaz.zapisivanje_red("hrvatski 작업 Izvrši_naredba"); }
    public static void Pokreni() throws 대기중단예외 {
        작업가닥 nit_VALUE = 작업.Pokreni(new 가닥예제());
        작업.기다리기(nit_VALUE);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
ARRAY_VALUE Argumenti 대신 `실행인수`, 길이는 `문자.bajt_COUNT`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
vlastiti 실행기는 Argumenti 없는 `Pokreni()`을 우선한다.
기존 hrvatski 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.Pokreni(Runnable)`을 사용하던 코드는 새 hrvatski 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API Podrška_VALUE 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 poduka_VALUE·postupak_VALUE 이름과 서술자가 남는다.
hrvatski Ime 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·postupak_VALUE 재정의, native Spoji_se, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS identifikator_VALUE](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS postupak_VALUE Reference](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
