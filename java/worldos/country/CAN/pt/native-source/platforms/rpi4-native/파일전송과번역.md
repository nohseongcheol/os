# nativo ARM64 kernel_VALOR: FTP, C, JAR와 AOT Executar_comando

대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT kernel_VALOR**이다. CPU·celular_VALOR 경계는 C/어셈블리, ficheiro 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 host JVM으로 대신 실행하지 않는다.

JVM은 aula_VALOR 버전 45…52의 문서화한 부분집합이다. `java`는 바이트코드 실행기이고, `jaot`가 별도의 네이티브 Executar_comando 파일을 만든다. **JAR arquivo_VALOR 해제나 JVM을 함께 묶는 것을 AOT라고 표시하지 않는다.** 지원하지 않는 바이트코드/API는 `jaot`가 진단하고 출력을 만들지 않는다. 기존 saídaTexto ELF도 compilar_fonte falha_VALOR 때 보존한다.

## Português Java를 게스트에서 컴파일하고 AOT Executar_comando

게스트 `vi 빛.java`로 Avançar_item 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] argumentos) throws Exception {
        int SUM_VALOR = 0;
        int número = 1;
        while (número <= 10) {
            SUM_VALOR = SUM_VALOR + número;
            número = número + 1;
        }
        Português.nativo.saídaTexto.gravar_número(SUM_VALOR);
        Português.nativo.ficheiro.Escrita("aot.txt", "한글 AOT ficheiro 😀");
        Português.nativo.saídaTexto.gravar_linha(Português.nativo.ficheiro.Leitura("aot.txt"));
    }
}
```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 gerar·연결한다. Executar_comando 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 Suporte_VALOR 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 estático_VALOR método_VALOR/valor_do_campo, int 계열, inteiro 배열과 Referência, argumentos MATRIZ_VALOR, doença·branch·sprint_VALOR, cadeia_VALOR 리터럴, `System.out.print/println`의 int/String, Português saídaTexto·ficheiro Leitura/쓰기로 제한된다. aula_VALOR/método_VALOR 수와 operando_pilha 등에도 고정 상한이 있다. Java exceção Processo_VALOR_entrada, objeto_VALOR gerar, 가상 método_VALOR 일반, switch/wide, long/float/double, invokedynamic, cadeia_VALOR 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 MATRIZ_VALOR acesso_entrada/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java exceção 객체로 전달하지 않는다.

entrada_VALOR 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 alinhar_VALOR 때문에 짧은 클래스도 이 한도를 넘을 número 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 objeto_VALOR·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 Suporte_VALOR recortar 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 개발 매뉴얼](개발안내.md)을 참고한다.

JAR는 하나의 애플리케이션 aula_VALOR 경로다. 내부 Nome `grupo/app_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 Português 클래스를 추가로 찾지만 em_dia_item 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·Criptografar_dados ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 número/VM heap_VALOR 제한은 그대로 적용된다.

## Português 네트워크·작업·tela API

| aula_VALOR | 호출 예 | Executar_comando caminho |
|---|---|---|
| `saídaTexto` | `gravar_linha("안녕")`, `gravar_número(42)` | JVM 및 제한형 AOT |
| `ficheiro` | `Escrita("문서.txt", "Conteúdo_VALOR")`, `Leitura("문서.txt")` | JVM 및 제한형 AOT |
| `comunicação` | `Abrir(0)`, `enviar(empresa, "10.0.2.2", 9000, "한글")`, `receber(empresa)` | JVM의 UDP |
| `conexão_transporte` | `Ligar("10.0.2.2", 9000)`, `escutar_empresa(9000)`, `receber(servidor_VALOR)` | JVM의 Socket/ServerSocket |
| `작업` | `iniciar(Runnable)`, `기다리기(Thread)`, `LUCRO_Tarefa()` | JVM의 협력식 thread_VALOR |
| `Janela`, `elemento_de_ecrã` | Janela·버튼·caractere_VALOR·campo_de_texto·Evento Ligar | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 Português 호출 계층을 추가한다. `comunicação(通信)`, `Ligar(連結)`, `saídaTexto(出力)`은 기존 단어의 뜻을 사용한다. `작업 thread_VALOR`은 한 Executar_comando 흐름을 가닥에 빗댄 descritor_VALOR 표현, `porta_VALOR`는 포트의 접점을 설명하는 표현이다. 새 descritor_VALOR 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

externo_VALOR 주소는 dígito_VALOR IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 nativo ABI이며 JVM이 제한된 aguarde_VALOR/재시도를 제공한다. TCP connect 대기는 최대 1초, espaço_do_utilizador app_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 Executar_comando espaço_do_utilizador 서버와 pthread는 아직 없다. FTP는 espaço_do_utilizador app_f5044b9b 기한과 별개인 kernel_VALOR 서비스다.

게스트의 espaço_do_utilizador TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 ferramentas/Executar_comando.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 valor_padrão visual_VALOR/데이터 포트와 겹치면 Executar_comando 전에 거부한다.
