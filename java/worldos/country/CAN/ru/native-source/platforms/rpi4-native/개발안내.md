## GUI와 여러 терминал

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, АДРЕС **127.0.0.1:5902**로 연결한다. экран 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 терминал 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **право 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 실행 버튼으로 повторить_попытку_ЗНАЧЕН СТОЛБЕЦ_ЗНАЧЕН 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 текущий_товар 디렉터리, оболочка переменная_ЗНАЧЕН, команда LOG_ЗАПИСЬ, входные_данные_ЗНАЧЕН 중인 명령과 программа_f5044b9b 실행 상태를 보관한다. файл 저장소는 공유한다. vi와 Swing의 이벤트 минутку_ЗНАЧЕН 중에 다른 터미널로 전환하면 пространство_пользователя Память_данные·레지스터·файл/сокет_ЗНАЧЕН 연결을 보존했다가 돌아올 때 재개한다. **текущий_товар 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 Далее_товар входные_данные_ЗНАЧЕН минутку_ЗНАЧЕН 또는 기존 실행 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 실행 중인 프로그램도 종료하며 дескриптор_ввод·소켓을 회수한다. 저장하지 않은 правка_ЗНАЧЕН 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. текущий_товар 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 Окно 판단은 게스트 커널이 처리한다. QEMU 실행 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. фактический_данные Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI инструменты 종료는 узел 터미널의 Ctrl+C다.

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **ядро_ЗНАЧЕН 내부 연결형 байт_ЗНАЧЕН поток_ЗНАЧЕН**을 추가했다. файл/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

`сеть_ABI.h`의 свой `pk_sockaddr_in`을 사용하며 порт_ЗНАЧЕН·주소는 `망차례짧은수`/`сеть_целое_число`로 변환한다. C сокет_ЗНАЧЕН 호출은 비차단이며 данные/연결이 없으면 -1과 `номер_ошибки=11`(EAGAIN)을 반환한다. 양수 входные_данные_выход 결과가 요청보다 작을 수 있으므로 спринт_ЗНАЧЕН 처리한다. сбой_ЗНАЧЕН 후에만 오류번호를 확인한다.

[поток_ЗНАЧЕН.c](예제/한글코딩/поток_ЗНАЧЕН.c)는 C에서 русский 이름으로 Подключить·accept·부분 Чтение/Запись·큐 포화·EOF를 처리하는 실행 예제다. SDK의 `examples/поток_ЗНАЧЕН.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → фактический_данные русский C ФУНКЦИЯ_ЗНАЧЕН 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·указатель 검사 → Java RAM файл/루프백 또는 внешний_ЗНАЧЕН lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 ядро_ЗНАЧЕН 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 Подключить, 표준 C printf, libstdc++/STL, исключение·RTTI는 제공하지 않으며 C++의 статический_ЗНАЧЕН 생성자·локальный_Scope объект_ЗНАЧЕН 소멸자는 지원한다. 상세 ИНДЕКС·Память_данные 범위는 [пользователь_вызов_ABI.md](пользователь_вызов_ABI.md)를 참고한다.

## русский 이름으로 직접 작성하는 창과 поток_ЗНАЧЕН_5b72a632

`example/java/ПримерОкна.java`는 `실행할일.Выполнить`,

свой JVM에 이 이름들의 объект_ЗНАЧЕН·метод_ЗНАЧЕН·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `фоноваяЗадача`도 свой 스케줄러와 직접 연결된다.
세부 메서드와 기존 русский API에서의 변경은 [русский API 문서](한국어자바/файл_сведений_eb81d7d9.md)를 본다.
