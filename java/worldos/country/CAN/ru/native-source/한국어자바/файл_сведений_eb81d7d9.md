# русский Java вспомогательное_приложение_ЗНАЧЕН библиотека

OpenJDK 11 이상과 함께 쓰는 프로젝트 владелец_ЗНАЧЕН API다. 표준 Java библиотека 전체의 번역판을 뜻하지 않는다. 기존 Java API·키워드·исключение·자료형은 그대로 함께 쓴다.

전체 22개 вспомогательное_приложение_ЗНАЧЕН 메서드의 аргументы·반환값·제약, операционная_система 안의 사용법, Python·C++ 호출 방법은 **[русский библиотека пользователь_гид](пользователь_гид.md)**에 정리했다. [Python 호출 예제](예제/다른언어/PYTHON_Вызовы.py)와 [C++ JNI 호출 예제](예제/다른언어/자바호출.cpp)도 제공한다.

`make`로 `build/한국어자바.jar`를 만든다. `javac -encoding UTF-8 -cp build/한국어자바.jar 예제/приветствие_ae353e94.java`로 예제를 컴파일한다. 실행은 `java -cp build/한국어자바.jar:예제 приветствие_ae353e94`다.

`приветствие_ae353e94` 예제는 그래픽 화면이 없으면 файл·문자·스레드 결과와 안내만 출력한다. Swing 창은 그래픽 세션에서 실행해야 한다. QEMU에서는 [그래픽 실행 файл_сведений_eb81d7d9](../platforms/rpi4/README.md)의 `make run`으로 부팅한 BACK_ЗНАЧЕН VNC 데스크톱의 터미널을 사용한다.

| Класс_ЗНАЧЕН | 제공 기능 |
|---|---|
| файл | UTF-8 텍스트·байт_ЗНАЧЕН Чтение/Запись, 디렉터리·ввод_Список |
| 문자 | UTF-8 ПРЕОБР_ЗНАЧЕН, NFC нормализовать_ЗНАЧЕН, кодовое_значение 포인트 수, 언어별 낱말 граница_ЗНАЧЕН |
| коммуникация | HTTP(S) запрос, 제한시간을 가진 TCP Подключить |
| 작업 | 스레드 запустить·합류·минутку_ЗНАЧЕН, 작업 программа_Launcher |
| экран | Swing 이벤트 처리와 Окно генерировать |
| рабочая_область | исходныйКод правка_ЗНАЧЕН·компилировать_источник·실행·실행 файл генерировать экран |

`char`는 UTF-16 кодовое_значение 단위이므로 이모지 등을 한 글자로 처리할 때 кодовое_значение 포인트 또는 문자 граница_ЗНАЧЕН API를 사용한다. 파일은 UTF-8로 저장한다. OpenJDK의 모든 Java2D/шрифт_ЗНАЧЕН/입력기 조합을 각각 검증한 것은 아니다.

이름은 текущий_товар 의미가 분명한 русский 용례를 사용했다. 개별 명칭의 역사적 어원 검토를 완료했다고 주장하지 않는다. ресурс_ЗНАЧЕН 종료와 исключение 처리는 표준 API의 계약을 따른다.
