# 자체 ARM64 கரு_மதிப்பு: FTP, C, JAR와 AOT இயக்கு_கட்டளை

대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT கரு_மதிப்பு**이다. CPU·சாதனம்_மதிப்பு 경계는 C/어셈블리, கோப்பின்_பெயர் 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 ஓம்பு JVM으로 대신 실행하지 않는다.

## 먼저 알아둘 ஆதரவு_மதிப்பு 경계

JVM은 பிரிவு_மதிப்பு_55654bf1 버전 45…52의 문서화한 부분집합이다. `java`는 바이트코드 실행기이고, `jaot`가 별도의 네이티브 இயக்கு_கட்டளை 파일을 만든다. **JAR காப்பகம்_மதிப்பு 해제나 JVM을 함께 묶는 것을 AOT라고 표시하지 않는다.** 지원하지 않는 바이트코드/API는 `jaot`가 진단하고 출력을 만들지 않는다. 기존 வெளியீட்டு_இடம் ELF도 தொகு_மூலம் செயலிழப்பு_மதிப்பு 때 보존한다.

Android의 Dalvik/ART는 일반 JVM பிரிவு_மதிப்பு_55654bf1/JAR가 아닌 **DEX**를 실행한다. ART의 AOT에는 GC, பிரிவு_மதிப்பு_55654bf1 로딩, JNI 등 இயக்கு_கட்டளை 기반도 필요하다. 따라서 ART처럼 기계어로 바꾸는 기능만으로 임의의 OpenJDK JAR 및 Swing이 자동 호환되지는 않는다. [Android 공식 런타임 설명](https://source.android.com/docs/core/runtime)

FTP는 루트 RAM 파일만 공개한다. 익명 로그인이며 비밀번호로 권한을 구분하지 않는다. இயல்புநிலை_மதிப்பு ஓம்பு 바인딩은 `127.0.0.1`이고, கட்டுப்பாடு_மதிப்பு 포트는 2121, 데이터 포트는 50000…50007이다. `--ftp-port 2122`로 கட்டுப்பாடு_மதிப்பு 포트를 바꿀 수 있다. 동시에 한 FTP 세션을 제공하며 명령이 없는 세션은 60초 후 닫는다. TYPE A도 바이트를 변경하지 않으므로 프로그램은 바이너리 전송한다.

파일은 **64개, 각각 16 KiB**, 경로는 UTF-8 63바이트이다. 부팅 시 준비되는 `/example`도 이 한도를 공유한다. 초과/끊어진 STOR는 기존 파일에 반영하지 않는다. FTP 업로드는 RAM에만 저장되며 재부팅하면 사라진다. 이 제한 때문에 일반적인 대형 JAR 배포판을 그대로 올릴 수 없다.

QEMU의 raspi4b에는 GENET Ethernet 장치가 없다. 따라서 `network_bridge.py`가 QEMU NAT의 Ethernet과 보조 UART의 SLIP를 변환한다. **TCP இணைக்க செயலகம்_மதிப்பு_உள்ளீடு·체크섬·재전송·FTP 명령과 கோப்பின்_பெயர் 저장은 게스트 안에서 수행한다.** ஓம்பு 브리지는 FTP 서버가 아니다. [QEMU 공식 சாதனம்_மதிப்பு ஆதரவு_மதிப்பு உள்ளீடு_பட்டியல்](https://www.qemu.org/docs/master/system/arm/raspi.html)

이 경로는 QEMU에서 검증했다. 보조 UART의 அசல்_தரவு Pi 4 핀/클럭 설정과 내장 RJ45 GENET 드라이버는 구현·검증하지 않았으므로, SD 이미지에 커널이 포함되어 있다는 사실을 அசல்_தரவு 보드의 LAN/FTP செயல் 보장으로 해석하면 안 된다.

## தமிழ் Java를 게스트에서 컴파일하고 AOT இயக்கு_கட்டளை

게스트 `vi 빛.java`로 அடுத்து_உருப்படி 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] செயலுருபுகள்) throws Exception {
        int 합 = 0;
        int 수 = 1;
        while (수 <= 10) {
            합 = 합 + 수;
            수 = 수 + 1;
        }
        தமிழ்.자체.வெளியீட்டு_இடம்.수쓰기(합);
        தமிழ்.자체.கோப்பின்_பெயர்.எழுது("aot.txt", "한글 AOT கோப்பின்_பெயர் 😀");
        தமிழ்.자체.வெளியீட்டு_இடம்.எழுது_வரி(தமிழ்.자체.கோப்பின்_பெயர்.படி("aot.txt"));
    }
}
```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 உருவாக்குக·연결한다. இயக்கு_கட்டளை 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 ஆதரவு_மதிப்பு 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 மாறா_மதிப்பு முறை_மதிப்பு_ba7ce9bf/புலம்_மதிப்பு, int 계열, முழு_எண் 배열과 மேற்கோள், செயலுருபுகள் கோவை_மதிப்பு_ed437109, நிபந்தனை·கிளை·மீள்செயல்_மதிப்பு, சரம்_மதிப்பு 리터럴, `System.out.print/println`의 int/String, தமிழ் வெளியீட்டு_இடம்·கோப்பின்_பெயர் படி/쓰기로 제한된다. பிரிவு_மதிப்பு_55654bf1/முறை_மதிப்பு_ba7ce9bf 수와 스택 등에도 고정 상한이 있다. Java விதிவிலக்கு செயலகம்_மதிப்பு_உள்ளீடு, பொருள்_மதிப்பு உருவாக்குக, 가상 முறை_மதிப்பு_ba7ce9bf 일반, switch/wide, long/float/double, invokedynamic, சரம்_மதிப்பு 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 கோவை_மதிப்பு_ed437109 அணுகு_உள்ளீடு/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java விதிவிலக்கு 객체로 전달하지 않는다.

입력 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 சீரமை_மதிப்பு 때문에 짧은 클래스도 이 한도를 넘을 수 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 பொருள்_மதிப்பு·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 ஆதரவு_மதிப்பு கிளிப் 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 개발 매뉴얼](개발안내.md)을 참고한다.

JAR는 하나의 애플리케이션 பிரிவு_மதிப்பு_55654bf1 경로다. 내부 பெயர் `மூட்டை/நிரல்_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 தமிழ் 클래스를 추가로 찾지만 현재 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·குறியாக்கு_தரவு ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 수/VM குவியல்_மதிப்பு 제한은 그대로 적용된다.

## C에서 தமிழ் POSIX 호출

게스트에서 `vi 인사.c`로 작성하거나 FTP로 소스를 업로드한다.

```c
#include <파일규약.h>

int main(void) {
    const char 인사말[] = "자체 ARM64 C에서 한글 POSIX 호출\n";
    int 문서 = திற_கோப்பு("인사.txt", படிக்க_எழுத | 없으면만들기 | 내용비우기, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = எழுது_கோப்பு_தரவு(문서, 인사말, sizeof(인사말) - 1);
    மூடு_கோப்பு(문서);
    எழுது_கோப்பு_தரவு(1, 인사말, sizeof(인사말) - 1);
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

```text
cc 인사.c -o 인사.elf
run 인사.elf
cat 인사.txt
```

TinyCC의 표준 C நுழைவுப்_புள்ளி `main`을 사용한다. 기존 ஓம்பு C/C++ SDK의 `தொடங்கு_பயனர்_நிரல்(int)` 진입점과 구분한다. 포함 கோப்பின்_பெயர்·செயல்படுத்துக பொருள்_மதிப்பு·`libposix-kor-user.a`는 컴파일러 내부의 படி 전용 SDK에 들어 있다. C 전처리기/구조체/செயல்பாடு_மதிப்பு/재귀/குறிப்பான்/부동소수점 உருவாக்குக 등을 사용하되 **일반 libc/libstdc++를 제공한다는 뜻은 아니다**. 제공하지 않는 함수는 இணைக்க 오류가 난다. 컴파일러 자체의 문자/இலக்கம்_மதிப்பு 변환 지원도 완전한 libc 대체품이 아니다.

`திற_கோப்பு` 등은 별도의 모의 호출이 아닌 기존 `pk_open` 등의 தமிழ் 매크로이며, ELF의 SVC를 통해 அசல்_தரவு Java கோப்பின்_பெயர் 체계에 도달한다. கோப்பின்_பெயர்/소켓 호출 목록은 [பயனர் ABI](사용자호출규약.md)에 있다. C/C++ ஓம்பு SDK இயக்கு_கட்டளை 파일도 FTP로 업로드 후 `run` 또는 `./கோப்பின்_பெயர்`로 실행하며 확장자는 필요 없다. Linux ARM64 மாறா_மதிப்பு ELF에는 별도의 제한된 호환 பாதை_2 `run --linux கோப்பின்_பெயர்`을 추가했다. [ELF·Linux ABI 매뉴얼](실행파일규약.md)에 정확한 வடிவமை_மதிப்பு·시스템 호출·முகவரி 제한을 정리했다.

| `통신` | `திற(0)`, `அனுப்பு(முடிவுப்_புள்ளி, "10.0.2.2", 9000, "한글")`, `받기(முடிவுப்_புள்ளி)` | JVM의 UDP |
| `연결통신` | `இணைக்க("10.0.2.2", 9000)`, `கவனி_முடிவுப்_புள்ளி(9000)`, `받기(சேவையகம்_மதிப்பு)` | JVM의 Socket/ServerSocket |
| `작업` | `செயல்படுத்துக(Runnable)`, `기다리기(Thread)`, `இடைநீக்கம்_செய்யப்பட்டது_பணி()` | JVM의 협력식 தொடரிழை_மதிப்பு |
| `சாளரம்`, `விட்ஜெட்` | சாளரம்·버튼·எழுத்துக்குறி_மதிப்பு·உரைப்_புலம்·நிகழ்வு இணைக்க | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 தமிழ் 호출 계층을 추가한다. `통신(通信)`, `இணைக்க(連結)`, `வெளியீட்டு_இடம்(出力)`은 기존 단어의 뜻을 사용한다. `작업 தொடரிழை_மதிப்பு`은 한 இயக்கு_கட்டளை 흐름을 가닥에 빗댄 기술 표현, `முணையம்_மதிப்பு`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

외부 주소는 இலக்கம்_மதிப்பு IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 자체 ABI이며 JVM이 제한된 காத்திரு_மதிப்பு/재시도를 제공한다. TCP connect 대기는 최대 1초, பயனர் நிரல்_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 இயக்கு_கட்டளை பயனர் 서버와 pthread는 아직 없다. FTP는 பயனர் நிரல்_f5044b9b 기한과 별개인 கரு_மதிப்பு 서비스다.

게스트의 பயனர் TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 கருவிகள்/இயக்கு_கட்டளை.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 இயல்புநிலை_மதிப்பு கட்டுப்பாடு_மதிப்பு/데이터 포트와 겹치면 இயக்கு_கட்டளை 전에 거부한다.

## 시험과 தொகு_முறைமை 재현

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test-ftp
make test
make image
```

`build/verification/ftp/report.json`은 அசல்_தரவு FTP இடமாற்று_மதிப்பு, 한글 கோப்பின்_பெயர், அளவு 초과 보존, காப்பகம்_மதிப்பு JAR இயக்கு_கட்டளை, 게스트 C தொகு_மூலம்/ELF 재업로드, 외부 Java TCP/UDP, 게스트 javac/AOT 실행을 기록한다. `serial.log`에서 게스트 명령과 결과를 확인할 수 있다. 보고서의 கரு_மதிப்பு SHA-256과 배포 이미지의 커널을 비교한다.

빌드는 기존 JDK/Clang/AArch64 binutils와 함께 `../rpi4/build/rootfs`의 ARM64 SDK அறிவிப்பு 헤더와 libgcc 산술 보조 함수를 사용한다(`make rpi-prepare`). **musl libc, Linux கரு_மதிப்பு, 동적 로더를 게스트에 링크하지 않는다.** TinyCC/lwIP/uzlib 원본과 라이선스·버전 정보는 `vendor/`, 이식 코드는 `ccompiler/`, `network/`, `பயனர்/மூட்டை.c`에 있다.

전체 JDK/AOT JVM으로 확장하려면 타입 சரிபார்_5fb2b747·பொருள்_மதிப்பு/விதிவிலக்கு/GC·동적 로딩·JNI, 영속 கோப்பின்_பெயர் இயக்க_முறைமை_மதிப்பு·mmap/TLS/시그널·스레드 ABI, OpenJDK native நூலகம், GUI peer/폰트/입력기, GENET 및 실물 சாதனம்_மதிப்பு 검증이 더 필요하다. 이 문서의 இயக்கு_கட்டளை 시험은 그 전체 이식을 대신하지 않는다.
