# 자체 ARM64 Java 커널의 C/C++ கோப்பின்_பெயர்·루프백 இணைக்க

이 디렉터리는 `platforms/rpi4-native` 자체 கரு_மதிப்பு 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 தமிழ் 함수명과 `extern "C"` ABI를 제공한다. `இணைக்க.c`는 கரு_மதிப்பு 안에서 AOT Java கோப்பின்_பெயர் 메서드에 직접 연결하고, `பயனர்_பிரிட்ஜ்.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. அசல்_தரவு கோப்பின்_பெயர் 처리는 `நினைவகம்_கோப்புகள்.java`, 루프백 전문 처리는 `되돌림망.java`, 연결형 흐름은 `தொடரோடி_பிணையம்.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 கரு_மதிப்பு 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·실수 இயக்கம்_மதிப்பு·கோப்பின்_பெயர்·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

ஆதரவு_மதிப்பு: `திற_கோப்பு`, `파일자료읽기`, `எழுது_கோப்பு_தரவு`, `மூடு_கோப்பு`, `தேடு_கோப்பு`, `அகற்று_கோப்பு_உள்ளீடு_பெயர்`, `அமை_கோப்பு_நீளம்`, 보조 செயல்பாடு_மதிப்பு `கோப்பு_அளவு`. பிழை 시 -1과 작업별 `오류번호`를 반환한다. `파일저장확정`은 RAM 파일이므로 ENOSYS를 반환한다. கோப்பின்_பெயர் 16개, 각 16384바이트, பெயர் 63바이트, 서술자 16개이며 RAM 디렉터리·பியர்_மதிப்பு/절대 경로를 제공한다. அனுமதி_மதிப்பு/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 அசல்_தரவு தமிழ் 함수와 독립 구조체를 선언한다.
`உருவாக்கு_முடிவுப்_புள்ளி`, `கட்டு_முகவரி`, `자료전문보내기/받기`, `இணை_பிணையம்/기다리기/받기`는
`பயனர்_பிரிட்ஜ்.c`에서 SVC를 호출하며 மேக்ரோ_மதிப்பு 별칭이 아니다. `struct 인터넷통신주소`의
`முகவரி_குடும்பம்`, `முனைய_எண்`, `இணைய_முகவரி.முகவரி_மதிப்பு`을 사용한다. 상수는 enum의
`இணையம்_குடும்பம்`, `전문통신`, `전문전송규약`, `தொடரோடி_பிணையம்`, `흐름전송규약`이다.
தமிழ்·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. 외부 통신은 자체 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. அசல்_தரவு Pi 4 GENET 드라이버는 미지원이다.
소켓도 அசல்_தரவு செயல்பாடு_மதிப்பு `மூடு_கோப்பு`로 닫는다.
