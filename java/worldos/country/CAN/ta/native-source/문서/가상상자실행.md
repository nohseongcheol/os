# VirtualBox இயக்கு_கட்டளை

```sh
cd ~/jkoros
make vbox
```

별도로 VM을 만들거나 ISO를 연결할 필요가 없다. 처음 실행하면 `os/build/kernel.iso`를 빌드하고 `jkoros operating system`이라는 전용 VM을 만들어 VirtualBox 창으로 부팅한다. `jkoros/os` 안에서도 `make vbox`를 사용할 수 있다.

게스트의 `jkoros>` 프롬프트에서 அடுத்து_உருப்படி 명령을 입력한다.

```text
help
apps
run hello vbox
```

마지막 명령은 별도 Java ELF를 실행한다. `USER MODE ring 3`, `arg: vbox`, `Exit: 0` வெளியீட்டு_இடம் 후 셸로 돌아오면 정상이다. VGA 화면은 현재 ASCII 글꼴만 지원하므로 한글은 `?`로 보이며, 한글 원문은 직렬 기록에서 확인할 수 있다.

## நிலை_மதிப்பு_e10195a1 확인과 다시 இயக்கு_கட்டளை

```sh
make vbox-status
```

이 명령은 VM நிலை_மதிப்பு_e10195a1, ISO와 직렬 기록의 절대 경로를 JSON으로 출력한다.

| 현재 நிலை_மதிப்பு_e10195a1 | `make vbox` செயல் |
| --- | --- |
| 아직 생성하지 않음 | ISO தொகு_முறைமை → 전용 VM உருவாக்குக → 부팅 |
| 종료됨 (`poweroff`, `aborted`) | ISO தொகு_முறைமை → 광학 매체 புதுப்பி → 새로 부팅 |
| இயக்கு_கட்டளை 중 (`running`) | 재빌드·재부팅 없이 현재 VM 유지 |
| 일시정지 (`paused`) | 기존 VM 재개 |
| 저장됨 (`saved`) | 이전 직렬 기록을 복사해 보관하고 சேகரி_மதிப்பு நிலை_மதிப்பு_e10195a1 재개 |
| சேகரி_மதிப்பு·செயல்படுத்துக 등 சுவிட்ச்_பயன்முறை 중 | 변경하지 않고 작업 완료 후 재실행하도록 பயனர்_உதவிக்_கோப்பு_eb81d7d9 |

மூலம்_மரம் 변경을 반영하려면 VM을 종료한 அடுத்து_உருப்படி 다시 `make vbox`를 실행한다. **சேகரி_மதிப்பு 상태를 재개하면 이전 커널이 계속 실행되므로 새 빌드를 반영하지 않는다.** 실행기는 강제 종료하거나 சேகரி_மதிப்பு 상태를 폐기하지 않는다. VirtualBox 창을 닫을 때 사용자가 전원 끄기를 선택하면 நினைவகம்_தரவு 상태가 사라지므로 보존할 작업이 없는지 먼저 확인한다. 게스트의 `halt`는 CPU만 멈추며 VirtualBox의 전원을 끄는 명령은 아니다.

சாளரம் 없는 실행이 필요하면 VM이 꺼져 있을 때 사용한다.

```sh
make vbox VBOX_TYPE=headless
```

இயக்கு_கட்டளை 중인 VM에 다시 명령을 내려도 GUI/headless 방식은 바뀌지 않는다. இயல்புநிலை_மதிப்பு பெயர் 대신 다른 이름이 필요하면 **최초 உருவாக்குக 시에만** `VBOX_NAME="원하는 பெயர்"`을 지정하고 이후에도 같은 값을 사용한다.

## 설정과 தரவு 보존

- இயல்புநிலை_மதிப்பு 설정은 BIOS, நினைவகம்_தரவு 64MiB, CPU 1개, VGA நினைவகம்_தரவு 16MiB, IDE 광학 부팅이다. 가상 하드디스크를 만들지 않는다.
- VM 설정은 `.vbox/machines/`, உள்ளடக்கம்_மதிப்பு 검사합별 ISO 사본은 `.vbox/media/`, 직렬 기록은 `.vbox/logs/`에 보관한다. `.vbox/state.json`은 전용 VM의 UUID와 உரிமையாளர்_மதிப்பு 표식을 저장한다.
- 꺼진 VM을 부팅할 때 새 직렬 기록을 만든다. சேகரி_மதிப்பு நிலை_மதிப்பு_e10195a1 재개 전의 기록은 `before-resume-*.log`로 복사한다. சேகரி_மதிப்பு நிலை_மதிப்பு_e10195a1 자체는 삭제하지 않고 VirtualBox가 그대로 재개한다.
- 같은 이름의 다른 VM을 인수하지 않는다. UUID·அமைப்புகள் பாதை_2·உரிமையாளர்_மதிப்பு 표식을 검사하며, 사용자가 별도로 연결한 디스크나 광학 매체를 자동 교체하지 않는다.
- 기존 ISO 사본과 기록은 자동 삭제하지 않는다. `.vbox`는 Git 제외 대상이다. 용량을 정리할 때도 இயக்கு_கட்டளை·சேகரி_மதிப்பு 상태의 VM이 참조하는 파일과 관리 정보를 임의로 삭제하지 않는다.
- VirtualBox 또는 ஓம்பு 드라이버가 없으면 오류를 안내한다. 자동 நிறுவு_மதிப்பு, மேலாளர்_மதிப்பு அனுமதி_மதிப்பு இயக்கு_கட்டளை, சாதனம்_மதிப்பு அனுமதி_மதிப்பு 변경은 하지 않는다.

## 네트워크 제한

현재 커널의 RTL8139 드라이버는 QEMU에서 사용한다. VirtualBox의 PCnet/E1000 드라이버는 아직 구현하지 않아 이 실행기는 네트워크 장치를 비활성화한다. 셸과 பயனர் 프로그램은 실행되지만 UDP 열기는 `-19`로 실패한다. UDP 왕복은 `make run`과 [பயனர் இயக்கு_கட்டளை·네트워크 பயனர்_உதவிக்_கோப்பு_eb81d7d9](../os/பயனர்/பயனர்_உதவிக்_கோப்பு_eb81d7d9.md)의 절차로 시험한다.

## சரிபார்_5fb2b747

`make test-vbox`는 가짜 VirtualBox 응답을 사용하여 새 VM உருவாக்குக, இயக்கு_கட்டளை·சேகரி_மதிப்பு·일시정지·சுவிட்ச்_பயன்முறை நிலை_மதிப்பு_e10195a1, பெயர் 충돌, 소유권 불일치, பயனர் 매체 பாதுகாப்பளி_மதிப்பு, தொகு_முறைமை செயலிழப்பு_மதிப்பு, 중단된 உருவாக்குக மீட்டெடு_நிலை, ISO மாற்று_மதிப்பு_16f64fe4 감지, பாதை_2 பாதுகாப்பளி_மதிப்பு 등을 검사한다. அசல்_தரவு VM을 만들거나 변경하지 않는다.

2026-09-13에 நிரல்_துவக்குநர் பாடம்_மதிப்பு 시험 16개가 통과했다. 별도로 அசல்_தரவு VirtualBox 5.2.42에서 `make vbox`의 VM உருவாக்குக·GUI 부팅, `JAVA SELFTEST PASS`, 셸의 `run hello vbox` 실행과 `Exit: 0`, இயக்கு_கட்டளை 중 재호출 시 재부팅하지 않는 செயல் 및 `make vbox-status`를 확인했다. சேகரி_மதிப்பு·일시정지 분기는 பாடம்_மதிப்பு 시험으로 검증했다.
