# Öz 커널에서 vi·여러 uçbirim·한글 프로그래밍 사용하기

Türkçe iletişim·özel_durum 사용법은 [Türkçe Java API](한국어자바/안내.md), işlev_değer·değişken_değer·dosya 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

대상은 `platforms/rpi4-native`의 Öz AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 Destek_değer 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 yürütmek_komut, dış_değer TCP/UDP와 FTP는 [새 yürütmek_komut 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 uçbirim

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, ADRES **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 uçbirim 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **hak 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 yürütmek_komut 버튼으로 yeniden_denemek_değer SÜTUN_değer 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 geçerli_öğe 디렉터리, kabuk değişken_değer, komut LOG_KAYIT, artış_değer 중인 명령과 program_f5044b9b yürütmek_komut 상태를 보관한다. dosya 저장소는 공유한다. vi와 Swing의 이벤트 bekle_değer 중에 다른 터미널로 전환하면 kullanıcı_alanı Bellek_veri·레지스터·dosya/yuva_değer 연결을 보존했다가 돌아올 때 재개한다. **geçerli_öğe 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 Sonraki_öğe artış_değer bekle_değer 또는 기존 yürütmek_komut 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 yürütmek_komut 중인 프로그램도 종료하며 tanımlayıcı_girdi·소켓을 회수한다. 저장하지 않은 Düzenle_değer 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. geçerli_öğe 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 Pencere 판단은 게스트 커널이 처리한다. QEMU yürütmek_komut 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. fiili_veri Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI araçlar 종료는 konak 터미널의 Ctrl+C다.

## vi kullanmak_değer

```text
mkdir 작업
cd 작업
vi 인사.py
```

`vi`는 새로 구현한 **vi komut 부분집합** 편집기다. 내장 `build/user/vi.elf`를 보호된 kullanıcı_alanı 영역에 적재한다. dosya 크기는 UTF-8 bayt_değer işlem_kök 16 KiB, 경로는 63바이트까지다. 디스크에 설치한 Vim/Neovim 바이너리를 실행하는 것이 아니다.

| tuş_değer/komut | Eylem |
|---|---|
| `i`, `a`, `I`, `A` | geçerli_öğe/Sonraki_öğe konum 또는 girdi_satırı 처음/끝에서 artış_değer |
| `o`, `O` | 아래/위에 새 줄을 만들고 artış_değer |
| Esc | 일반 mod_değer |
| `h j k l`, 방향키 | UTF-8 문자/girdi_satırı taşımak_değer_83b651b8 |
| `0`, `$`, Home, End | girdi_satırı 처음/끝 |
| `gg`, `G`, `:Dizin` | dosya 처음/마지막 girdi_satırı/Ata_değer girdi_satırı |
| PgUp, PgDn | 화면 ders_değer taşımak_değer_83b651b8 |
| `x`, Delete | geçerli_öğe 문자 삭제 |
| `dd`, `yy`, `p` | girdi_satırı 삭제/örnek_değer/yapıştırmak_SMS |
| `u` | 마지막 편집을 İade_köprü; 한 aşama_değer 토글 |
| `/dize_değer`, `n` | 단순 dize_değer 검색/Sonraki_öğe 일치; 정규식 없음 |
| `:w`, `:w 다른이름` | RAM dosya depo_değer/다른 경로로 depo_değer |
| `:q` | 변경이 없을 때 Çıkış_program |
| `:q!` | 변경을 버리고 Çıkış_program |
| `:wq`, `ZZ` | 저장하고 Çıkış_program |

붙여 넣은 한글을 문자 경계에 맞춰 taşımak_değer_83b651b8·삭제한다. 일반 vi의 수량 접두사, makro_değer, Ayarlar dosya, 플러그인, 정규식, 여러 버퍼/분할 Pencere, 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/sıfır_işlenen 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 Pencere pencere_Başlık `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 komut**으로 실행한다. 파이프·리다이렉션·betik_değer·`;`/`&&`/`||`로 연결한 실행에서 devralmak 대기를 시작하면 거부한다. artış_değer 대기는 약 2초 CPU 기한을 갱신하지만 artış_değer bekle_değer 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## 한글 Java

vi에서 다음을 `인사.java`에 입력하고 Esc → `:wq`로 저장한다.

```java
public class 인사 {
    static int 더하기(int 첫째, int 둘째) { return 첫째 + 둘째; }
    public static void main(String[] bağımsız_değişkenler) {
        int toplam_değer = 더하기(20, 22);
        System.out.println("안녕하세요 · toplam_değer=" + toplam_değer);
    }
}
```

게스트 셸에서 실행한다.

```text
javac 인사.java
java 인사
```

한글 dosya_adı_SMS·sınıf_adı·metot_ad_SMS·변수명·문자열을 사용할 수 있다. **게스트 javac는 statik_değer Java 부분집합**이다. nesne_değer·리스너·Swing·소켓을 사용하는 소스는 geçerli_öğe konak JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 Öz JVM에 class를 올린다. Öz JVM에서 지원하는 바이트코드/API 범위는 [자바실행환경.md](자바실행환경.md)를 따른다.

```sh
# konak
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java sınamalar/자바/Swing_test.java
python3 araçlar/yükle_Dosyalar.py build/my-java/Swing_test.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. metinÇıktısı 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java Swing_test`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.Sınıf_değer.class` 형식이다. 내장 Türkçe 라이브러리는 별도 업로드가 필요 없다. Türkçe Pencere API의 예제는 [한글창시험.java](sınamalar/자바/한글창시험.java)이며 같은 방법으로 derlemek_kaynak·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 kaynak_ağaç/클래스는 호스트의 `python3 araçlar/yürütmek_Dosya.py yol/인사.java`로 별도 QEMU에 업로드·yürütmek_komut·종료할 수 있다. devralmak Swing에는 yürütmek_komut 후 kullanıcı_alanı 입력을 유지하는 `make desktop`을 사용한다.

## Öz JVM의 Swing klip

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 Öz Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | Eylem |
|---|---|
| `JFrame` | pencere_Başlık, Boyut·konum, şov_pencere, Kapat 정책, dispose |
| `JPanel` | alt_değer 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 dize_değer şov_değer·değiştirmek_değer |
| `JButton` | 버튼과 ActionListener tık_değer işlem_değer_girdi |
| `JTextField` | 한 girdi_satırı UTF-8 artış_değer, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 Öz JVM의 단일 이벤트 yürütmek_komut 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. Pencere·요소는 yürütmek_komut 하나당 toplam_değer 32개, öğe_değer 글자는 최대 127 코드포인트다. varsayılan_değer 서체와 색은 커널이 제공한다.

[Swing_test.java](sınamalar/자바/Swing_test.java)는 Pencere·한글 etiket_değer·metin_alanı·버튼·이벤트 처리의 yürütmek_komut 가능한 예제다. [Öz Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

Türkçe 라이브러리에는 다음을 추가했다. konak derlemek_kaynak 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `Türkçe.Öz.Pencere`: `Ekle_öğe`, `şov_pencere`, `Kapat`.
- `Türkçe.Öz.ekran_öğesi`: `etiket_değer`, `düğme`, `metin_alanı` oluşturmak.
- `Türkçe.Öz.cxn_taşıma`: `Bağlan`, `dinlemek_uç_nokta`, `almak`.
- 기존 `metinÇıktısı`, `문자`, `dosya`, `작업`, `girdi_Liste`, `sözlük`, `iletişim`, `화면`, `çekirdek_değer`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **çekirdek_değer 내부 연결형 bayt_değer akış_değer**을 추가했다. dosya/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket sunucu_değer = new java.net.ServerSocket(9250);
java.net.Socket konuk_değer = new java.net.Socket("localhost", 9250);
java.net.Socket Bağlan = sunucu_değer.accept();
konuk_değer.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] GETİRİ_öğe = new byte[64];
int süre_değer = Bağlan.getInputStream().read(GETİRİ_öğe);
Bağlan.close(); konuk_değer.close(); sunucu_değer.close();
```

oluşturmak·Bağlan·accept·양방향 bayt_değer/DİZİ_değer G_Ç·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 Bitiş_puan 16개, almak_değer 버퍼당 1024바이트, bekle_değer Bağlan 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. varsayılan_değer zaman_değeri 제한 0은 별도 yuva_değer 기한을 설정하지 않지만 JVM komut 수/çekirdek_değer yürütmek_komut 기한은 여전히 적용된다.

dış_değer rakam_değer IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. fiili_veri Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP kitaplık 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [test_akış.java](sınamalar/자바/test_akış.java)는 fiili_veri 송수신·EOF·기한·Bağlan 회수의 sınamalar 예제다.

## 한글 Python

게스트 vi에서 한글 이름을 사용해 작성한다.

```python
değer = 21

def 두배(rakam_değer):
    return rakam_değer * 2

print("sonuç:", 두배(değer))
```

depo_değer 후 `python 인사.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 işlev_değer·değişken_değer·dosya 이름과 문자열을 한글로 쓴다.

[Türkçe.py](예제/한글코딩/Türkçe.py)를 같은 디렉터리에 두면 Sonraki_öğe 별칭을 사용할 수 있다.

```python
import Türkçe
Türkçe.yazma_Dosya("인사.txt", "안녕하세요")
Türkçe.metinÇıktısı(Türkçe.파일읽기("인사.txt").decode())
```

metinÇıktısı·dosya Okuma/Yazma/삭제·표준 artış_değer·dikdörtgen·zaman_değeri·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 rakam_değer IPv4 ADRES 전송이다. `wait_key()`는 화면을 확인할 때 devralmak 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor statik_değer 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 uzantı_değer 모듈은 아직 없다. 제한형 `pip`의 kaynak_ağaç 설치는 [Python paket_iş 안내](PYTHON_paket_iş.md)를 따른다. [세 언어의 fiili_veri 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 Dil 모두 Türkçe 헤더와 işlev_değer 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 fiili_veri EL0 yürütmek_komut sınamalar 대상이다.

```c
#include "Dosya_ABI.h"
#ifdef __cplusplus
extern "C"
#endif
int Start_kullanıcı_program(int bağımsız_değişkenler) {
    (void)bağımsız_değişkenler;
    const char 인사말[] = "안녕하세요\n";
    int 문서 = açık_Dosya("인사.txt", R_W | 없으면만들기 | kesmek_içindekiler, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = yazma_Dosya_veri(문서, 인사말, sizeof(인사말) - 1);
    Kapat_Dosya(문서);
    yazma_Dosya_veri(1, 인사말, sizeof(인사말) - 1); /* geçerli_öğe uçbirim stdout */
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 수 있다. C는 게스트 `cc` 또는 konak SDK, C++는 konak SDK의 Clang++로 컴파일한다. 아래 예제는 기존 konak SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh
# 호스트에서 SDK oluşturmak·ayıklamak
make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/인사.c -o 인사-c.elf
python3 compile.py examples/인사.cpp -o 인사-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 fiili_veri yürütmek_komut
cd /home/user/jkoros/platforms/rpi4-native
python3 araçlar/yürütmek_Dosya.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 araçlar/yürütmek_Dosya.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

geçerli_öğe GUI VM에서 실행하려면 `python3 araçlar/yükle_Dosyalar.py yol/인사-c.elf`의 출력을 게스트에 보내고 `run 인사-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex dosya_adı_SMS`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 수 있다. 호스트와 게스트의 dosya 시스템은 별개다.

| Türkçe İsim | C simge | klip |
|---|---|---|
| açık_Dosya/Kapat_Dosya | pk_open/pk_close | RAM dosya, eş_değer/절대 yol |
| 파일자료읽기/yazma_Dosya_veri | pk_read/pk_write | dosya, fd 0/1/2 표준 G_Ç, 연결형 yuva_değer |
| arama_Dosya | pk_lseek | 처음기준/geçerli_kök/Bitiş_origin |

[akış_değer.c](예제/한글코딩/akış_değer.c)는 C에서 Türkçe 이름으로 Bağlan·accept·부분 Okuma/Yazma·큐 포화·EOF를 처리하는 yürütmek_komut 예제다. SDK의 `examples/akış_değer.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → fiili_veri Türkçe C işlev_değer 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·işaretçi 검사 → Java RAM dosya/루프백 또는 dış_değer lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 çekirdek_değer 내부용이므로 EL0 프로그램에 링크하지 않는다. ## Türkçe 이름으로 직접 작성하는 창과 yazışma_değer
