# 전체 Supporto_VALORE 요청의 Regolari_articolo Stato_VALORE

richiesta 전체는 아직 완료되지 않았다. Regolari_articolo ISO는 nativo Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 effettivo_dati C POSIX 일부 기능, Italiano API/codiceSorgente Nome, IDE file 보존, 게스트 Java file 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/README_eb81d7d9.md)를 기준으로 판단한다.

| richiesta 분야 | Regolari_articolo Esegui_comando 가능한 ritagliare | 전체 지원에 필요한 작업 |
|---|---|---|
| Java compilare_fonte·Esegui_comando | 게스트 제한형 javac/JVM, statico_VALORE 단일 클래스와 일부 표준 oggetto_VALORE | 일반 oggetto_VALORE·Corso_VALORE Connetti·eccezione·GC·스레드, 완전한 javac와 표준 Corso_VALORE Catalogo |

nativo 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 Esegui_comando 환경을 추가하는 방식은 별도의 kernel_VALORE·루트 file_system·OpenJDK·그래픽 server_VALORE·영구 Store_VALORE 구성을 가진 Esegui_comando 경로가 된다. 후자는 기존 nativo 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

Esegui_comando 기반과 Aggiunta_voce target 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. Regolari_articolo 원문과 prove 결과를 후속 구현의 출발점으로 보존한다.
