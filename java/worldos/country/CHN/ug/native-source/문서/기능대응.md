# engos 기능 대응표

이 표는 기존 `كونا_مەنبە/`의 ئوبيېكت_قىممىتى 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [ھەقىقىي_مەلۇمات 부팅 기능과 한계](../os/چۈشەندۈرۈش_ھۆججىتى_eb81d7d9.md)를 따로 기록한다.

## 기존 ئوبيېكت_قىممىتى 기반 관리 يادرو_قىممىتى 전체를 부팅하기 위해 남은 ئۇلا

كېيىنكى_تۈر 항목은 Java 문법만으로 실행할 수 없는 CPU/كۆچمە_قىممىتى 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot كىرگۈزۈش_نوقتا_قىممىتى, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 كونتېكست_قىممىتى ساقلىماق_قىممىتى
- ھەقىقىي_مەلۇمات PIC/PIT/PS2/ATA/PCI قاتتىق_دېتال_ئېغىز 및 AMD PCnet DMA ئايلانما_قىممىتى
- Java ئوبيېكت_قىممىتى·رەت_قىممىتى ئۇلانما_لايىھە, 예외, ئىستاتىك_قىممىتى دەسلەپلەشتۈرمەك, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT ئېكران_قىممىتى
- FAT 디스크 구역을 ھەقىقىي_مەلۇمات ATA 장치와 연결하는 입출력 접착 قەۋەت_قىممىتى

위 관리 계층은 engos 기능의 Java 관리 구현과 باقار 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot كىرگۈزۈش_نوقتا_قىممىتى, ئىستاتىك_قىممىتى دەسلەپلەشتۈرمەك·پۈتۈن_سان رەت_قىممىتى, VGA/직렬/PS2, 명령해석기, ئىشلەتكۈچى ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 باقار 루프백 패킷 왕복을 검증했다. 위 표의 ئوبيېكت_قىممىتى 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
