# 전체 قوللاش_قىممىتى 요청의 현재 ھالەت_قىممىتى

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 ھەقىقىي_مەلۇمات C POSIX 일부 기능, 한국어 API/مەنبە ئاتى, IDE ھۆججەت 보존, 게스트 Java ھۆججەت 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/چۈشەندۈرۈش_ھۆججىتى_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 ئىجرا_قىلىش_بۇيرۇق 가능한 كەسمە | 전체 지원에 필요한 작업 |
|---|---|---|
| Java قۇرماق_مەنبە·ئىجرا_قىلىش_بۇيرۇق | 게스트 제한형 javac/JVM, ئىستاتىك_قىممىتى 단일 클래스와 일부 표준 ئوبيېكت_قىممىتى | 일반 ئوبيېكت_قىممىتى·تۈركۈم_قىممىتى ئۇلا·예외·GC·스레드, 완전한 javac와 표준 تۈركۈم_قىممىتى ئامبار |
| ھۆججەت | POSIX 서술자, Java 단일 بايت_قىممىتى ھۆججەت ئېقىم_قىممىتى, 전용 مېدىيا_قىممىتى 보존 | 일반 java.io/nio, 디렉터리·ئىجازەت_قىممىتى·잠금·일반 ھۆججەت_سىستېمىسى·كېڭەيتمە_قىممىتى 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP باقار 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 ھادىسە·خەت_نۇسخا_قىممىتى·كۆزنەك مەشغۇلات_سىستېمىسى_قىممىتى, AWT 네이티브 연결과 Swing ئىجرا_قىلىش_بۇيرۇق 기반 |
| POSIX | 문서화한 ھۆججەت·단말·UDP 부분 | جەريان_قىممىتى·exec/fork·스레드·시그널·시간·mmap·poll·파이프 등과 적합성 دەلىللەش |
| 언어별 ئاتى | 한국어 46개 대응 كىرگۈزۈش_قىممىتى, ھەقىقىي_مەلۇمات C/Java/ھۆججەت ئاتى 적용 | نىشان تىل 확정, 언어별 용례·역사 근거와 해당 مەنبە·도구의 دەلىللەش |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 ئىجرا_قىلىش_بۇيرۇق 환경을 추가하는 방식은 별도의 يادرو_قىممىتى·루트 ھۆججەت_سىستېمىسى·OpenJDK·그래픽 مۇلازىمىتېر_قىممىتى·영구 ساقلىماق_قىممىتى 구성을 가진 ئىجرا_قىلىش_بۇيرۇق 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

ئىجرا_قىلىش_بۇيرۇق 기반과 추가 نىشان 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
