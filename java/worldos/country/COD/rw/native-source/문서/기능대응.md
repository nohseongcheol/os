## 기존 ikintu_agaciro_2ed200e9 기반 관리 intima_agaciro 전체를 부팅하기 위해 남은 Guhuza

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/igendanwa_agaciro 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot icyinjizwa_inota_agaciro, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 Imikoreshereze_agaciro Store_agaciro
- nyakuri_amakurushingiro PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA gukora_mu_matsinda_agaciro
- Java ikintu_agaciro_2ed200e9·ARRAY_agaciro Ihuza_Imimerere, 예외, kitayega_agaciro gutangiza, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT icyiciro_agaciro_29ee1bb7
- FAT 디스크 구역을 nyakuri_amakurushingiro ATA 장치와 연결하는 I_O 접착 akugara_agaciro

위 관리 계층은 engos 기능의 Java 관리 구현과 gucumbikira 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot icyinjizwa_inota_agaciro, kitayega_agaciro gutangiza·umubare_wuzuye ARRAY_agaciro, VGA/직렬/PS2, 명령해석기, ukoresha ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 gucumbikira 루프백 패킷 왕복을 검증했다. 위 표의 ikintu_agaciro_2ed200e9 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
