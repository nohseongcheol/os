# 전체 Ubufasha_agaciro 요청의 현재 imimerere_agaciro

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 nyakuri_amakurushingiro C POSIX 일부 기능, Ikinyarwanda API/Inkomoko Izina, IDE Idosiye 보존, 게스트 Java Idosiye 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/NSOMA_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 gukora_ibwiriza 가능한 kiripu | 전체 지원에 필요한 작업 |
|---|---|---|
| Java gusohora_inkomoko·gukora_ibwiriza | 게스트 제한형 javac/JVM, kitayega_agaciro 단일 클래스와 일부 표준 ikintu_agaciro_2ed200e9 | 일반 ikintu_agaciro_2ed200e9·icyiciro_agaciro_55654bf1 Guhuza·예외·GC·스레드, 완전한 javac와 표준 icyiciro_agaciro_55654bf1 isomero |
| Idosiye | POSIX 서술자, Java 단일 bayiti_agaciro Idosiye Stream_agaciro, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·권한·잠금·일반 sisitemu_ya_dosiye·umugereka_agaciro 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP gucumbikira 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 icyabaye·imyandikire_agaciro·idirishya sisitemu_ngengamikorere_agaciro, AWT 네이티브 연결과 Swing gukora_ibwiriza 기반 |
| POSIX | 문서화한 Idosiye·단말·UDP 부분 | Inzira_agaciro·exec/fork·스레드·시그널·시간·mmap·poll·파이프 등과 적합성 kwemeza |
| 언어별 Izina | Ikinyarwanda 46개 대응 icyinjizwa_agaciro, nyakuri_amakurushingiro C/Java/Idosiye Izina 적용 | gusimbuza_igishya Ururimi 확정, 언어별 용례·역사 근거와 해당 Inkomoko·도구의 kwemeza |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 gukora_ibwiriza 환경을 추가하는 방식은 별도의 intima_agaciro·루트 sisitemu_ya_dosiye·OpenJDK·그래픽 seriveri_agaciro·영구 Store_agaciro 구성을 가진 gukora_ibwiriza 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

gukora_ibwiriza 기반과 추가 gusimbuza_igishya 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
