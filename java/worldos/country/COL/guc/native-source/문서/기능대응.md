## 기존 객체 기반 관리 keetnerü_ajutuu 전체를 부팅하기 위해 남은 a_ataa

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/serulaalü_ajutuu 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot ekeroliaa_o_uchikanain_ajutuu, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 문맥 저장
- 실제 PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA eitawaakualü_ajutuu
- Java 객체·matüriisü_ajutuu wopu_akumajiakuai_pa, 예외, jimatüsü_ajutuu anaajaa, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT 단계
- FAT 디스크 구역을 실제 ATA 장치와 연결하는 E_A 접착 ayaleriaa_ajutuu

위 관리 계층은 engos 기능의 Java 관리 구현과 epiajatü 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot ekeroliaa_o_uchikanain_ajutuu, jimatüsü_ajutuu anaajaa·waneepiasü matüriisü_ajutuu, VGA/직렬/PS2, 명령해석기, ka_yataayakalü ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 epiajatü 루프백 패킷 왕복을 검증했다. 위 표의 객체 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
