# Java 네이티브 نظام_تشغيل

이 문서는 기존 **x86 نواة_قيمة**을 설명한다. Raspberry Pi 4의 ذاتي ARM64 حالة_أولية 이식은 [별도 안내](../platforms/rpi4-native/README.md)를 참고한다. 아래 x86 فضاء_المستخدم ELF·네트워크·IDE مخزن_قيمة 기능이 ARM64에 모두 이식된 상태는 아니다.

Java 원문을 ذاتي AOT 후단으로 x86 기계어로 컴파일해 부팅하는 작은 운영체제다. 커널과 별도로 ذاتي 제한형 Java محول_برمجي·JVM ELF를 فضاء_المستخدم 모드에 적재할 رقم 있다. Linux, engos, koros4와 خارجي_قيمة OpenJDK는 게스트에 적재하지 않는다. إقلاع_الآلة 진입과 أجهزة_منفذ/물리 ذاكرة_منطقة 접근은 어셈블리이며, 문자 단말·إدخال_قيمة عملية_قيمة_إدخال·أمر يوزّع_قيمة·작업 قسم_قيمة_366e0bfa 관리는 `مصدر/*.java`에 있다.

## 게스트 Java 개발

`javac Hello.java`, `java Hello`로 부팅된 نظام_تشغيل 안에서 يحول_برمجياً_مصدر·실행한다. `edit FILE.java`와 `.save`로 소스를 작성하며 `ls`, `cat`, `rm`을 제공한다. RAM 파일은 최대 8개, 각각 16KiB이다. 전용 IDE 매체를 연결하면 `sync`로 보존할 رقم 있다. 이 기능은 ذاتي 제한형 구현이며 전체 OpenJDK/JDK 호환은 아니다. 사용법·دعم_قيمة 문법·ملف 적재·교차 시험은 [Java 개발 بيئة_التشغيل](../문서/자바개발환경.md)에 있다. `make test-java`로 검증한다.

## 빌드와 ينفذ_أمر

`compiler/`가 요구하는 도구에 더해 ISO 생성에는 `grub-file`, `grub-mkrescue`, GRUB BIOS وحدة_نمطية_قيمة, `xorriso`가 필요하다. 실행에는 QEMU 또는 VirtualBox가 필요하다. حديث_عنصر 설치된 도구만 사용한다. `make run-store`는 새 전용 가상 مخزن_قيمة 매체를 만들어 연결한다. VirtualBox 실행기는 이 프로젝트가 만든 전용 VM만 설정하고 다른 VM은 변경하지 않는다. 가상 메모리는 قيمة_افتراضية 64MiB이며 최소 16MiB가 필요하다.

```sh
cd /home/user/jkoros/os
make                 # build/kernel.elf
make iso             # build/kernel.iso (فضاء_المستخدم ELF يجمع_قيمة تصريحات)
make run             # ELF 직접 إقلاع_الآلة, 직렬 단말
make run-gui         # GRUB ISO إقلاع_الآلة, VGA 창과 PS/2 자판
make vbox            # 상위 폴더의 실행기로 전용 VirtualBox VM ينفذ_أمر
make vbox-status     # 전용 VirtualBox VM حالة_قيمة يتحقق
make test            # ELF와 ISO 두 경로의 الفعلي_بيانات إقلاع_الآلة/إدخال_قيمة اختبارات
make apps            # فضاء_المستخدم 프로그램만 بنية_نظام
make test-network    # فضاء_المستخدم ينفذ_أمر/UDP/يحمي_قيمة اختبارات
```

`make run`은 QEMU의 직렬 표준 입출력을 쓴다. `Ctrl+A`를 누른 عودة_قيمة `X`로 QEMU를 종료할 رقم 있다. `halt`는 게스트 CPU만 정지시키므로 QEMU نافذة/프로세스는 별도로 닫는다. 폴링 방식이라 انتظر_قيمة 중에도 مضيف CPU를 사용할 رقم 있다.

VirtualBox는 `make vbox`로 실행한다. 새 전용 VM을 ذاكرة_بيانات 64MiB, BIOS, 광학 드라이브 부팅으로 자동 설정하며 디스크는 필요 없다. الفعلي_بيانات VirtualBox 5.2.42에서 إقلاع_الآلة, Java ذاتي اختبارات, 셸 إدخال_قيمة, `run hello vbox`의 ring 3 실행과 أنظمة_المعلومات_عادي 종료를 확인했다. حديث_عنصر 통신 드라이버는 QEMU의 RTL8139 전용이며 VirtualBox의 PCnet/E1000에서는 네트워크를 사용할 رقم 없어 네트워크 장치를 비활성화한다. مخزن_قيمة حالة_قيمة 재개와 새 بنية_نظام 반영 방법은 [VirtualBox ينفذ_أمر 안내](../문서/가상상자실행.md)에 있다.

## 셸에서 فضاء_المستخدم تطبيق_f5044b9b ينفذ_أمر 및 네트워크 호출

독립 ELF32 ينفذ_أمر 파일을 적재해 **ring 3**에서 실행한다. `int 0x80` 시스템 호출을 통해 단말 مخرجات, وسائط يستعلم_قيمة, UDP فتح·يرسل·يستلم·닫기를 제공한다. فضاء_المستخدم 코드를 نواة_قيمة 함수로 직접 호출하는 구조가 아니다.

```text
jkoros> apps
jkoros> run hello first second
jkoros> net
jkoros> run netcheck
jkoros> run udp 10.0.2.2 9000 hello
```

마지막 명령의 응답을 받으려면 호스트의 별도 터미널에서 `python3 /home/user/jkoros/os/أدوات/ارتداد_بيانات.py --port 9000`을 먼저 실행한다. 상세 API, تطبيق_f5044b9b إلحاق_إدخال, عنوان 공간과 제한은 [فضاء_المستخدم ينفذ_أمر·네트워크 안내](فضاء_المستخدم/안내.md)에 있다.

إقلاع_الآلة يتحقق 문구:

```text
JKOROS NATIVE JAVA
자바 기계어 نواة_قيمة تشغيل
JAVA SELFTEST PASS
USER ELF: ring 3 / paging / int 0x80
help | info | mem | alloc | free N | echo TEXT | clear | test | halt
apps | run NAME [ARGS] | net
READY
jkoros>
```

## 구현한 기능

- GRUB Multiboot 1 ELF إقلاع_الآلة, x86 يحمي_قيمة الوضع_قيمة GDT, BSS تهيئة, 64KiB مُعامل_رمز.
- Java دالة_قيمة الفعلي_بيانات 실행과 إقلاع_الآلة معلومات_النظام علامة_قيمة_7e8f90bd يتحقق.
- COM1 직렬 إدخال_إخراج, VGA 문자 화면·مؤشر_قيمة_04ee3e20·스크롤·مسح_إدخال.
- PS/2 قيمة_افتراضية 자판, 좌우 Shift, Enter, Backspace. ملحق_قيمة مفتاح_قيمة/마우스 자료는 أمر 입력으로 쓰지 않는다.
- 길이 128의 أمر إدخال_قيمة 버퍼, تجاوز_قيمة 방지, CR/LF عملية_قيمة_إدخال.
- `help`, `info`, `mem`, `alloc`, `free N`, `echo TEXT`, `clear`, `test`, `halt`.
- 4KiB 작업 قسم_قيمة_366e0bfa 8개의 يخصص_تخزين·إرجاع_مقياس·재사용과 중복 إرجاع_مقياس 방지.
- Java صفيف_قيمة 256KiB 영역의 حجم·منخفض_قيمة 검사와 런타임 خطأ 중단.
- قراءة 전용 JKAP ينفذ_أمر يجمع_قيمة, ELF32 قسم_قيمة_366e0bfa/نقطة_الإدخال التحقق_من_صحة, فضاء_المستخدم الوضع_قيمة·وسائط·خروج_تطبيق رمز_قيمة_f3cd31ee.
- نواة_قيمة/فضاء_المستخدم 페이지 إذن_قيمة 분리, TSS, IDT, PIT 100Hz, فضاء_المستخدم CPU استثناء عملية_قيمة_إدخال 및 ينفذ_أمر قيمة_الوقت 상한.
- PCI RTL8139 폴링 드라이버, ARP, ثابت_قيمة_f430d3f5 IPv4, UDP مجموع_اختباري·송수신·انتظر_قيمة 제한.

`mem`의 Upper memory는 Multiboot의 1MiB 위쪽 연속 ذاكرة_بيانات حجم(KiB)이며, 전체 ذاكرة_بيانات 지도 분석이나 자유 물리 ذاكرة_بيانات 수치가 아니다. `alloc`은 이미 확보한 عدد_صحيح صفيف_قيمة 안의 작업 قسم_قيمة_366e0bfa 번호를 반환한다. 일반 물리 صفحة_قيمة يخصص_تخزين, عنوان عنوان_منطقة 또는 فضاء_المستخدم عملية_قيمة ذاكرة_بيانات 관리가 아니다.

## 명시적인 한계

이 커널은 **فضاء_المستخدم 프로그램을 한 번에 하나 실행하는 حالة_أولية نواة_قيمة**이다. PIT IRQ0만 사용하며 키보드와 NIC는 폴링한다. فضاء_المستخدم CPU 예외는 해당 프로그램을 끝내고 셸로 복귀시키지만 نواة_قيمة 예외는 중단한다. ينفذ_أمر 시간은 약 3초로 제한한다. 완전한 선점 다중 عملية_قيمة 스케줄러, FAT/ext 등 일반 디스크 نظام_الملفات, TCP·DNS·DHCP·IPv6·HTTP, 전체 POSIX, 일반 عنصر_قيمة_2ed200e9 모델/GC는 아직 없다. 전용 IDE ملف 보존과 POSIX ملف/UDP 일부 기능은 구현했다. JVM은 RAM 파일의 단일 클래스를 ينفذ_أمر 시 적재하며 일반 ClassLoader나 JAR 로딩은 지원하지 않는다. 네이티브 ينفذ_أمر 파일은 بنية_نظام 시 قراءة 전용 묶음에 넣으며, 일반 Linux ELF를 실행하는 환경이 아니다. 기존 `../قديم_مصدر/`의 JVM 관리 نواة_قيمة 전체를 이식한 것도 아니다.

Java 식별자는 한국어다. 직렬 출력은 이 프로젝트의 한글(BMP 문자)을 UTF-8로 표시한다. VGA는 قيمة_افتراضية ASCII 글꼴만 사용하므로 한글 자리에 `?`가 나온다. أمر 입력도 حديث_عنصر ASCII만 지원하며 한글 خط_قيمة·입력기 및 보조 평면 문자 출력은 후속 작업이다. `test`는 작은 배열을 새로 할당하고 GC가 없으므로 무한 반복하지 않는다.

## 자동 اختبارات

`اختبارات/부팅시험.py`는 디스크 없는 독립 QEMU를 생성해 다음을 검증하고 종료한다.

- ELF 직접 إقلاع_الآلة 및 GRUB ISO إقلاع_الآلة.
- Java ذاتي 시험과 UTF-8 직렬 문구.
- أمر عرض_المساعدة·معلومات_النظام·ذاكرة_بيانات·مخرجات·خطأ إدخال_قيمة·화면 مسح_إدخال.
- 작업 قسم_قيمة_366e0bfa 8개 يخصص_تخزين, 부족 عملية_قيمة_إدخال, إرجاع_مقياس/중복 إرجاع_مقياس/재할당.
- 직렬 줄바꿈·백스페이스·긴 إدخال_قيمة عملية_قيمة_إدخال.
- QEMU PS/2 مفتاح_قيمة 입력으로 `info` ينفذ_أمر, `halt` 정지.

성공 로그는 `build/부팅시험.json`에 남는다. 로컬 Unix 소켓을 금지하는 샌드박스에서는 اختبارات 도구에 해당 권한이 필요하다. اختبارات 도중 새로 만든 QEMU만 종료하며 기존 VM과 الفعلي_بيانات 디스크는 건드리지 않는다.

`اختبارات/يختبر_مستخدم_شبكة.py`는 ELF/ISO 각각에서 فضاء_المستخدم ELF, الفعلي_بيانات ring 3, وسائط, مضيف 루프백 UDP 왕복, 1,023/1,024바이트 24회 연속 왕복, قيمة_الوقت 초과, NIC 없음, ذاكرة_بيانات/أجهزة_منفذ يصل_إدخال 차단, CPU استثناء, 무한 تكرار_قيمة, 잘못된 ELF를 시험한다. `build/يختبر_مستخدم_شبكة.json`에 게스트 기록과 호스트가 받은 데이터의 길이·해시를 저장한다. `اختبارات/حزمة_يختبر.py`는 الفعلي_بيانات Java قيمة_العقد 처리기에 손상된 패킷을 넣어 2,201개 경계/مجموع_اختباري 조건을 검사한다. مضيف 루프백 외 خارجي_قيمة 서버에는 اختبارات 트래픽을 보내지 않는다.

부트 경계는 GNU의 [Multiboot المواصفات](https://www.gnu.org/software/grub/manual/multiboot/multiboot.html)를 따른다.

새 파일서술자·C ABI·IDE مخزن_قيمة·Java ملف 흐름의 범위와 العربية 명명 대응은 [posix-kor 안내](../posix-kor/안내.md)에 있다. `make test-posix`로 ELF/ISO 실행과 재부팅 보존을 검증한다.
