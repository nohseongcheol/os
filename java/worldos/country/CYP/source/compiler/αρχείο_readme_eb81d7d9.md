# Java 네이티브 πρόγραμμα_μεταγλώττισης

OpenJDK ίδιο 소스를 빌드하는 **`--target openjdk-build`**와 ίδιο πυρήνας_τιμή ABI 검사 도구를 추가했다.
이는 공식 javac/C/C++ 도구를 연결하는 별도 경로다. [δομή_Σύστημα 방법·πραγματικός_δεδομένα επικυρώνω·πυρήνας_τιμή 이식 απόσπασμα](OpenJDK-προέλευση_δομή_λογικό_ΚΑΙ-εγγενής_πυρήνας-이식.md)를 참고한다.

x86 직접 변환과 ARM64 C δημιουργώ 후단은 모두 [기계어미리번역.java](자바도구/기계어미리번역.java)로 구현한다. `sh 미리번역.sh`로 직접 실행하며, [기계어미리번역.py](기계어미리번역.py)와 `πρόγραμμα_μεταγλώττισης.py`는 이전 Εντολή·API 및 OpenJDK 도구를 위한 호환 진입점이다. ίδιο Pi4 후단은 freestanding C를 거쳐 AArch64로 만든다. [arm64.py](arm64.py)는 이전 경로와 Python 호출을 위한 호환 진입점이다. συνάρτηση_τιμή·μεταβλητή_τιμή·δημιουργώ C 이름의 뜻과 예외는 [ελληνικά 명명 αρχείο_readme_eb81d7d9](../platforms/rpi4-native/명명/αρχείο_readme_eb81d7d9.md)를 참고한다. [ARM64 δομή_Σύστημα·στήριγμα_τιμή απόσπασμα](../platforms/rpi4-native/αρχείο_readme_eb81d7d9.md)에 εκτελώ_εντολή 조건이 있다. 전체 OpenJDK나 일반 Τάξη_τιμή 실행기는 아니다.

εκτελώ_εντολή 시 JVM이 필요 없는 x86 32비트 ELF를 만든다. JDK 11 이상으로 실행하는 Java ίδιο AOT 후단이며, Java 전체를 새로 구현한 컴파일러는 아니다. Java 문법·πρόσβαση_καταχώρηση έλεγχος_τιμή·Τύπος_τιμή 검사는 JDK의 `javac`에 맡기고, Java 8 Τάξη_τιμή 파일을 읽어 각 바이트코드를 x86 명령으로 직접 변환한다. C 코드로 우회하거나 바이트코드 해석기를 커널에 넣지 않는다.

```text
Java ΠΗΓΗ → javac의 문법·Τύπος_τιμή 검사 → 임시 .class
          → ίδιο x86 변환기 → GNU as/ld → 네이티브 ELF32
```

## 준비와 εκτελώ_εντολή

δομή_Σύστημα φιλοξενώ: Linux, Python 3.6 이상, JDK 11 이상(`javac --release 8`), GNU binutils(`as`, `ld`), Make. τρέχων_στοιχείο 환경의 OpenJDK 11, Python 3.6, binutils 2.30으로 검증했다. εξωτερικός_τιμή Python 패키지와 네트워크 다운로드는 사용하지 않는다.

```sh
cd /home/user/jkoros/compiler
make
./build/계산
echo $?                  # 0이면 예제 시험 성공

python3 πρόγραμμα_μεταγλώττισης.py --target linux --entry 계산.Εκτέλεση_2 \
    -o build/계산 예제/계산.java

make test
```

`linux` 대상은 Linux의 32비트 εκτελώ_εντολή 호환 기능이 필요하다. `int 0x80`을 차단하는 샌드박스에서는 `Bad system call`이 발생할 수 있다. πληροφοριακά_συστήματα_απλά Linux φιλοξενώ 또는 해당 실행을 허용한 시험 환경에서 실행한다. 시험의 비정상 종료를 통과로 처리하지 않는다.

진입점은 `static int Εκτέλεση_2()` 또는 `static void Εκτέλεση_2()`처럼 인수가 없어야 한다. `--entry 패키지.Τάξη_τιμή.συνάρτηση_τιμή`로 선택한다. `int` 반환값은 Linux 프로세스 Έξοδος_εφαρμογή 코드가 되며 셸에는 하위 8비트가 보인다. 일반 `main(String[] args)` εκτελώ_εντολή 환경이나 표준 είσοδος_έξοδος 라이브러리는 제공하지 않는다.

`--target kernel`은 부팅 코드와 연결할 재배치 ELF 오브젝트를 생성한다.

```sh
cd /home/user/jkoros
python3 compiler/πρόγραμμα_μεταγλώττισης.py --target kernel --entry πυρήνας.Εκτέλεση_2 \
    --export kernel_dispatch=체계호출.διεργασία_τιμή_καταχώρηση \
    -o os/build/java.o os/ΠΗΓΗ/*.java
```

`--target user`는 jkoros 셸에서 실행할 독립 ELF를 생성한다. `χρήστης` 클래스의 제한된 native API는 `int 0x80` 시스템 호출로 연결하며 `συσκευή_τιμή` 클래스의 υλικό_τιμή 직접 접근은 거부한다. χρήστης ELF는 Linux εκτελώ_εντολή Αρχείο ABI와 다르므로 호스트에서 실행하지 않는다. δημιουργώ·δήλωση_καταχώρηση 방법은 [χρήστης εκτελώ_εντολή αρχείο_readme_eb81d7d9](../os/χρήστης/αρχείο_readme_eb81d7d9.md)에 있다. `--export 외부기호=Τάξη_τιμή.συνάρτηση_τιμή`는 오버로드되지 않은 στατικός_τιμή 함수를 ίδιο τελεστέος_δέσμη ABI로 노출한다. 커널의 시스템 호출 진입점에 사용한다.

Java 파일은 필요한 클래스들을 한꺼번에 전달한다. Έξοδος 옆의 `.s`는 생성된 어셈블리, `.json`은 ΠΗΓΗ SHA-256 및 네이티브 σύμβολο↔Java συνάρτηση_τιμή 대응표다. ελληνικά 함수명은 원문과 대응표에 보존하고 ELF 내부에는 충돌 방지용 υπολογιστής_5eb260fa 기호를 쓴다. δόμηση_προέλευση·κατασκευή_αντικειμενικού_κώδικα_τιμή·Σύνδεση 중 실패하면 기존 μέτρηση 파일을 덮어쓰지 않는다.

## στήριγμα_τιμή απόσπασμα

- `int`, `boolean`, `byte`, `short`, `char`의 32비트 계산 및 Τύπος_τιμή μετατρέπω_τιμή.
- στατικός_τιμή 필드와 στατικός_τιμή συνάρτηση_τιμή, 매개변수·반환값, 재귀, 클래스별 지연 초기화와 προετοιμάζω Κύκλος_τιμή.
- 조건문, 반복문, 단락 평가, 삼항식, ακέραιος `switch`, 넓은 τοπικός_Πεδίο μεταβλητή_τιμή 인덱스.
- 덧셈·뺄셈·곱셈·나눗셈·나머지·δυαδικό_ψηφίο_τιμή 연산과 μετακινώ_τιμή_83b651b8. Java의 오버플로 및 `MIN_VALUE / -1` 동작을 유지한다.
- `int[]` δημιουργώ·초기값 0·διάρκεια_τιμή·Ανάγνωση·Εγγραφή·Αναφορά 비교. 256KiB 고정 πίνακας_τιμή περιοχή_τιμή_0e9a97ab, 널/δείκτης_τιμή/Μέγεθος/διεύθυνση_περιοχή 검사.
- συμβολοσειρά_τιμή 리터럴과 `String` Αναφορά, `length()` 및 `charAt()`. 문자열은 UTF-16 κωδικός_τιμή 단위로 저장하고 같은 리터럴은 공유한다. NUL 및 대리쌍도 시험한다.
- ελληνικά Τάξη_τιμή·συνάρτηση_τιμή·μεταβλητή_τιμή·Αρχείο Όνομα.

`new Object`, 인스턴스 τιμή_πεδίου/συνάρτηση_τιμή, 상속/인터페이스, `long/float/double` εκτελώ_εντολή εγχείρηση_τιμή, `int[]` 이외 πίνακας_τιμή, συμβολοσειρά_τιμή 동적 결합, Java 표준 βιβλιοθήκη, εξαίρεση διεργασία_τιμή_καταχώρηση, 스레드·συγχρονίζω·GC는 미지원이다. 실행에 필요한 미지원 바이트코드나 εξωτερικός_τιμή 호출을 발견하면 실패한다. 사용되지 않는 προεπιλεγμένη_τιμή 생성자는 εκτελώ_εντολή 코드로 만들지 않는다. Java 8 문법이어도 모든 프로그램을 컴파일할 수 있다는 뜻은 아니다.

εξαίρεση αντικείμενο_τιμή 대신 런타임 ΣΦΑΛΜΑ 번호로 중단한다. Linux와 jkoros χρήστης 대상에서는 `100 + Ευρετήριο`로 종료하고 πυρήνας_τιμή 대상에서는 `JKOROS PANIC Ευρετήριο`를 출력하고 정지한다. χρήστης 프로그램만 종료한 경우 셸은 계속 실행된다.

| Ευρετήριο | 원인 |
| --- | --- |
| 1 | 0으로 τμήμα_μέτρηση |
| 2 | 널 Αναφορά |
| 3 | πίνακας_τιμή/συμβολοσειρά_τιμή δείκτης_τιμή απόσπασμα 초과 |
| 4 | 음수 πίνακας_τιμή Μέγεθος |
| 5 | πίνακας_τιμή περιοχή_τιμή_0e9a97ab 부족 |

πίνακας_τιμή 영역은 증가식 할당이며 회수하지 않는다. 재귀 스택의 όριο_τιμή 검사도 아직 없으므로 무제한 재귀를 안전하게 처리하는 런타임은 아니다. 특권 πυρήνας_τιμή 및 신뢰할 수 있는 작은 프로그램용 αρχική_κατάσταση 구현이다.

## native 경계와 ABI

πυρήνας_τιμή 대상에서는 `os/ΠΗΓΗ/συσκευή_τιμή.java`, χρήστης 대상에서는 `os/χρήστης/δήλωση/χρήστης.java`의 정확한 μέθοδος_όνομα_μήνυμα·서술만 허용한다. 임의의 `native` 함수와 Linux/χρήστης 대상의 υλικό_τιμή 접근은 거부한다. Java 인수를 왼쪽부터 32비트 한 칸씩 스택에 놓으며, 반환값은 EAX, EBP/ESP 이외 레지스터는 호출자가 보존한다고 가정하지 않는다. C의 cdecl/JNI ABI가 아니므로 C 함수와 바로 연결하면 안 된다.

Java ΠΗΓΗ 또는 `.class` 입력을 받는다. 전체 JVM 바이트코드 검증기는 제공하지 않는다. 어노테이션 처리는 비활성화하고 비어 있는 Τάξη_τιμή ΔΙΑΔΡΟΜΗ/ΠΗΓΗ 경로에서 명시한 소스만 컴파일한다.

## 검증과 구현 근거

`시험/test_compiler.py`의 14개 시험에는 네이티브 ELF와 OpenJDK의 εγχείρηση_τιμή μέτρηση 대조, Τάξη_τιμή προετοιμάζω, ακέραιος 극값, συμβολοσειρά_τιμή/πίνακας_τιμή, 재귀·switch·wide, 런타임 오류와 미지원 기능 απορρίπτω_τιμή, αποτυχία_τιμή 시 Έξοδος 보존, χρήστης ELF/άδεια_τιμή όριο_τιμή 및 내보내기 검증이 포함된다. 이것은 Java 전체 적합성 시험은 아니다.

Εντολή 의미와 Τάξη_τιμή Αρχείο 형식은 Oracle의 [JVM Εντολή 명세](https://docs.oracle.com/javase/specs/jvms/se11/html/jvms-6.html), [Τάξη_τιμή Αρχείο 명세](https://docs.oracle.com/javase/specs/jvms/se11/html/jvms-4.html)를 참고했다.
