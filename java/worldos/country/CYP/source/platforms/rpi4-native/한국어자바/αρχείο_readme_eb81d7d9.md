# ελληνικά Java 통신·είσοδος_έξοδος·εξαίρεση API

패키지는 `ελληνικά.ίδιο`다. φιλοξενώ `javac --release 8`로 컴파일한 class를
ίδιο ARM64 커널의 JVM에서 실행한다. 통신·Αρχείο·εξαίρεση API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 νήμα_τιμή API는 ίδιο JVM 전용이다.
기존 표준 Java βιβλιοθήκη 전체의 ελληνικά 번역판은 아니다.

```java
import ελληνικά.ίδιο.*;

public class δίκτυο {
    public static void main(String[] Παράμετροι) throws είσοδος_έξοδος_εξαίρεση {
        σύνδεση Σύνδεση = σύνδεση.Άνοιγμα("10.0.2.2", 9000);
        try {
            Σύνδεση.ΤΕΛΟΣ_ΧΡΟΝΟΥ(700);
            Σύνδεση.Έξοδος().Εγγραφή(문자.κωδικοποιώ("안녕하세요\n"));
            ροή_εισόδου είσοδος_τιμή = Σύνδεση.είσοδος_τιμή();
            Έξοδος.수쓰기(είσοδος_τιμή.Ανάγνωση());
        } catch (περίμενε_ΤΕΛΟΣ_ΧΡΟΝΟΥ_εξαίρεση ΣΦΑΛΜΑ) {
            Έξοδος.εγγράφω_γραμμή(ΣΦΑΛΜΑ.설명());
        } finally {
            Σύνδεση.Κλείσιμο();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
χρήστης 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 συμβολοσειρά_τιμή 리터럴에 사용하는 표준 클래스다. ίδιο 실행기는 `public static void Εκτέλεση_2()`도 진입점으로 받는다.

## 통신과 ροή_τιμή

| Τάξη_τιμή | ελληνικά 호출 |
|---|---|
| σύνδεση | `Άνοιγμα(διεύθυνση, αριθμός_θύρας)`, `είσοδος_τιμή()`, `Έξοδος()`, `ΤΕΛΟΣ_ΧΡΟΝΟΥ(밀리초)`, `αριθμός_θύρας()`, `τοπικός_αριθμός_θύρας()`, `연결됨()`, `πληροφοριακά_συστήματα_κλειστή()`, `Κλείσιμο()` |
| λαμβάνω_θύρα | `Άνοιγμα(αριθμός_θύρας)`, `λαμβάνω()`, `αριθμός_θύρας()`, `ΤΕΛΟΣ_ΧΡΟΝΟΥ(밀리초)`, `πληροφοριακά_συστήματα_κλειστή()`, `Κλείσιμο()` |
| ροή_εισόδου | `Ανάγνωση()`, `Ανάγνωση(byte[])`, `Ανάγνωση(byte[], Εκτέλεση_2, διάρκεια_τιμή)`, `Κλείσιμο()` |
| ροή_εξόδου | `Εγγραφή(int)`, `Εγγραφή(byte[])`, `Εγγραφή(byte[], Εκτέλεση_2, διάρκεια_τιμή)`, `내보내기()`, `Κλείσιμο()` |
| αυτοδύναμο_πακέτο_Κανάλι | `Άνοιγμα(αριθμός_θύρας)`, `στέλνω(διεύθυνση, αριθμός_θύρας, Κείμενο)`, `λαμβάνω()`, `ΤΕΛΟΣ_ΧΡΟΝΟΥ(밀리초)`, `αριθμός_θύρας()`, `πληροφοριακά_συστήματα_κλειστή()`, `Κλείσιμο()` |
| 연결통신 | `Άνοιγμα(...)`, `수신열기(...)`는 위 ελληνικά 객체를 επιστρέφω_μέτρηση |
| 검사 | `참인지(πάθηση, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`Ανάγνωση()`의 Αρχείο 끝은 -1, πίνακας_τιμή 읽기의 반환값은 πραγματικός_δεδομένα 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. αριθμός_θύρας 0은 빈 번호를 자동 배정한다.
UDP 전문은 τρέχων_στοιχείο ίδιο 커널에서 512바이트까지 받으며, 주소는 ψηφίο_τιμή IPv4를 사용한다.
`localhost` 루프백 외의 Όνομα 풀이(DNS)는 ίδιο 커널에 아직 없다.

기존 `연결통신.Σύνδεση/ακρόαση_τελικό_σημείο/λαμβάνω`, `통신.Άνοιγμα/στέλνω/λαμβάνω`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `σύνδεση`, `λαμβάνω_θύρα`, `αυτοδύναμο_πακέτο_Κανάλι`를 쓴다.

## ελληνικά εξαίρεση

모든 아래 클래스는 προεπιλεγμένη_τιμή 생성자, `새예외("설명")` 형태의 συμβολοσειρά_τιμή 생성자와
`설명()`을 제공한다. πραγματικός_δεδομένα δημιουργώ 문법은 `new περίμενε_ΤΕΛΟΣ_ΧΡΟΝΟΥ_εξαίρεση("κατάσταση_αναμονής 끝")`이다.

| ελληνικά εξαίρεση | 상위 Τάξη_τιμή / 용도 |
|---|---|
| εξαίρεση | `java.lang.Exception`, 직접 던지는 일반 검사 εξαίρεση |
| εκτέλεση_εξαίρεση | `java.lang.RuntimeException` |
| είσοδος_έξοδος_εξαίρεση | `java.io.IOException`, ελληνικά Αρχείο·통신 API의 검사 εξαίρεση |
| περίμενε_ΤΕΛΟΣ_ΧΡΟΝΟΥ_εξαίρεση | `είσοδος_έξοδος_εξαίρεση`, 통신 ΤΕΛΟΣ_ΧΡΟΝΟΥ 초과 |
| διεύθυνση_Αναζήτηση_εξαίρεση | `είσοδος_έξοδος_εξαίρεση`, διεύθυνση επαληθεύω αποτυχία_τιμή |
| 파일없음예외 | `είσοδος_έξοδος_εξαίρεση`, Αρχείο Άνοιγμα αποτυχία_τιμή |
| 통신예외 | `είσοδος_έξοδος_εξαίρεση`, 표준 SocketException μετατρέπω_τιμή |
| άκυρος_όρισμα_εξαίρεση | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `άκυρος_όρισμα_εξαίρεση` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| αναφορά_null_εξαίρεση | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| Κατάσταση_εξαίρεση | `java.lang.IllegalStateException` |
| Τύπος_Διανομή_εξαίρεση | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| πίνακας_αποθηκεύω_αποτυχία | `java.lang.ArrayStoreException` |
| νήμα_Κατάσταση_εξαίρεση | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 περίμενε_τιμή 중단 |

`εξαίρεση`와 `εκτέλεση_εξαίρεση`는 모든 ελληνικά 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, Αρχείο·통신 전체를 잡으려면 `catch (είσοδος_έξοδος_εξαίρεση ΣΦΑΛΜΑ)`를 쓴다.
ελληνικά API가 표준 είσοδος_έξοδος 오류를 ελληνικά 예외로 변환한다.
기존 ελληνικά 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`περίμενε_ΤΕΛΟΣ_ΧΡΟΝΟΥ_εξαίρεση`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
εξαίρεση 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
τρέχων_στοιχείο ίδιο JVM에 이 20종을 추가했다. 임의의 χρήστης Throwable 하위 Τάξη_τιμή 전체를
지원하도록 확장했다는 뜻은 아니다.

## δόμηση_προέλευση·εκτελώ_εντολή

```sh
cd /home/user/jkoros/platforms/rpi4-native
make δομή_Σύστημα
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 Εργαλεία/εκτελώ_Αρχείο.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 χρήστης JVM ELF 안에 탑재된다. `.jar`는 φιλοξενώ javac의
Τάξη_τιμή 경로로 사용한다. προέλευση_δέντρο 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 ελληνικά 예외의 `throws` 선언과 그 import를 인식한다.
ίδιο JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·αντικείμενο_τιμή·υποδοχή_τιμή 예제 전체의 προέλευση_δέντρο 컴파일은 φιλοξενώ javac를 사용한다.
`/example/java/ΠαράδειγμαΑρχείου.java`는 게스트 javac로도 컴파일할 수 있다.

πραγματικός_δεδομένα TCP/UDP 예제는 [ΠαράδειγμαΔικτύου.java](../../../example/java/ΠαράδειγμαΔικτύου.java),
εκτελώ_εντολή 절차는 [example αρχείο_readme_eb81d7d9](../../../example/README.md),
προέλευση_δέντρο 명명 원칙은 [명명 αρχείο_readme_eb81d7d9](../명명/αρχείο_readme_eb81d7d9.md)에 있다.

## Swing Παράθυρο 예제

`/example/java/ΠαράδειγμαΠαραθύρου.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` Επόμενο_στοιχείο `java ΠαράδειγμαΠαραθύρου`로 연다. Όνομα είσοδος_τιμή, 인사하기 버튼,
인사말과 κλικ_τιμή 횟수 ανανεώνω, X 닫기를 지원한다.

| 기능 | ελληνικά 직접 API |
|---|---|
| Runnable / run | `실행할일.Εκτέλεση()` |
| ActionListener / actionPerformed | `동작받이.λαμβάνω_έργο(έργο_γνωστοποίηση γνωστοποίηση)` |
| ActionEvent | `έργο_γνωστοποίηση.εντολή_μήνυμα()`, `προέλευση_συμβάντος()`, `Ευρετήριο()` |
| JFrame | `Παράθυρο(Παράθυρο_Τίτλος, 폭, ύψος_τιμή)`, `Προσθήκη_στοιχείο(화면구성요소)`, `εμφανίζω_Παράθυρο()`, `Κλείσιμο()`, `보이는가()` |
| JButton | `κουμπί(Κείμενο, 가로, τομέας_θέση, 폭, ύψος_τιμή, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `Ετικέτα(...)`, `πεδίο_κειμένου(...)` |
| 공통 화면 στοιχείο_τιμή | `화면구성요소.글읽기()`, `εγγράφω_μήνυμα(Κείμενο)`, `자리정하기(가로, τομέας_θέση, 폭, ύψος_τιμή)` |
| SwingUtilities.invokeLater | `συμβάν_ουρά.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `αρχή_εργασία()`, `기다리기()`, `살아있는가()`, `Απόδοση_εργασία()` |
| 명령행 | `Εκτέλεση_2()`, `실행인수.개수()`, `실행인수.Κείμενο(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
ίδιο JVM의 `한국어화면호출`, `διεργασία_νήμα`가 ελληνικά Τάξη_τιμή·μέθοδος_τιμή·서술자를
해석해 화면 요소와 εκτελώ_εντολή 가닥을 직접 만든다. Ενέργεια 알림도 ίδιο 객체이며
콜백으로 `Εκτέλεση`와 `λαμβάνω_έργο`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 εκτελώ_εντολή 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 ίδιο JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 φιλοξενώ JVM에서 무동작 객체가 생기지 않도록 하는 απορρίπτω_τιμή 경로다.
ίδιο JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. φιλοξενώ javac로 컴파일한 Πίσω_τιμή ίδιο JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import ελληνικά.ίδιο.*;
public class 가닥예제 implements 실행할일 {
    public void Εκτέλεση() { Έξοδος.εγγράφω_γραμμή("ελληνικά 작업 εκτελώ_εντολή"); }
    public static void Εκτέλεση_2() throws 대기중단예외 {
        작업가닥 νήμα_τιμή = 작업.Εκτέλεση_2(new 가닥예제());
        작업.기다리기(νήμα_τιμή);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
πίνακας_τιμή Παράμετροι 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
ίδιο 실행기는 Παράμετροι 없는 `Εκτέλεση_2()`을 우선한다.
기존 ελληνικά 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.Εκτέλεση_2(Runnable)`을 사용하던 코드는 새 ελληνικά 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API στήριγμα_τιμή 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 Τάξη_τιμή·μέθοδος_τιμή 이름과 서술자가 남는다.
ελληνικά Όνομα 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·μέθοδος_τιμή 재정의, native Σύνδεση, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS αναγνωριστικό_τιμή](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS μέθοδος_τιμή Αναφορά](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
