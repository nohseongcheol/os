# Öz 커널과 번역기의 Türkçe İsim

대상은 `platforms/rpi4-native`의 Öz Java çekirdek_değer, kullanıcı_alanı JVM, C makine Bağlan,
TCP/UDP·FTP, C derleyici_araç 이식부, MicroPython 이식부, oluştur·yürütmek_komut·sınamalar 도구다.
`golang/worldos/Country_değer/KOR/kaynakKod`의 원칙처럼 기능을 먼저 구분하고 이름을 정한다.
x86 Java 커널과 공용 x86·ARM64 미리 번역기의 Öz 선언도 명명 검사에 포함한다.
Linux 실행판의 konak araçlar, OpenJDK 보조 araçlar 및 dış_değer dağıtım_değer kaynak_ağaç 전체를
한국어로 yeniden_denemek_değer 작성했다는 뜻은 아니다.

## 명명 원칙과 말의 근거

- 명사는 자료의 역할을 나타낸다: `dosya_tanıtıcısı`, `eş_bağlantı_noktası_numarası`, `dinamik_bellek`, `klavye`.
- 함수는 행위를 나타낸다: `Okuma`, `Yazma`, `Aç`, `Kapat`, `NET_BIND`, `çalıştırma_program`.
- TCP의 이어진 bayt_değer 흐름과 UDP의 sınır_değer 있는 자료를 `cxn`와 `veri_birimi_Kanal`로 구별한다.
- 짧은 영어 변수도 쓰임에 따라 `süre_değer`, `veri_konum`, `ARA_Dizin`, `반환값`으로 풀어 쓴다.
  순번·임시 산술값처럼 여러 역할에 재사용되는 변수는 `순번`, `첫째값`, `SANİYE_değer`으로 구별한다.
- 이름이 같아도 dış_değer 구조체의 필드와 Öz 변수는 별도로 분석한다.

`Kanal_girdi(通路)`는 이동이나 교류가 이루어지는 길이라는 기존 의미를 iletişim 연결에
적용했다. `taşımak_değer(窓口)`의 주고받는 접점이라는 의미를 연결을 받는 곳에 적용했다.
이는 국립국어원 한국어기초사전의 [Kanal_girdi](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=49310),
[taşımak_değer](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=24898)의 뜻에 근거한다.

`veri_birimi(電文)`은 전보에 담는 글이라는 기존 iletişim 어휘에서 가져와, UDP 자료의
경계가 보존된다는 특징을 드러내는 데 쓴다. 근거는
[한국어기초사전 veri_birimi](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=74335)이다.
`akış_değer`, `yazışma_değer`, `쌓임`은 우리말의 움직임·이어짐·쌓이는 모양을 빌린 표현이다.
`giriş_akışı`, `arkaPlanGörevi`, `yığın_belleği` 같은 복합 이름은 이 프로젝트의 기능별 조어다.
이 sözlük 근거를 특정 중세 문헌의 최초 출현이나 공인 전산 번역으로 확대하지 않는다.
공인 표준 çevir_kaynak·국어사 veri_birimi 감수를 마쳤다는 뜻도 아니다.

| 기능 | 채택한 İsim | 이유 |
|---|---|---|
| TCP Socket | cxn | 상대와 연결되어 düzen_değer 있는 바이트를 주고받음 |

| InputStream / OutputStream | giriş_akışı / çıkış_akışı | 들어오고 나가는 바이트의 düzen_değer |
| heap / stack | dinamik_bellek / yığın_belleği | ayırmak_Depolama 방식과 쌓고 꺼내는 mimari |
| thread / keyboard | arkaPlanGörevi / klavye | 이어지는 실행과 글쇠의 DİZİ_değer |
| exception / timeout | özel_durum / bekle_ZAMANAŞIMI_özel_durum | bilgi_teknolojisi_normal 처리에서 벗어남과 그 구체적 이유 |

## 보존하는 SD İsim

`public`, `class`, `int`는 예약어다. `String`, `main`, 배열의 `length`는 예약어가 아니다.
geçerli_öğe 다섯 Java 예제는 `çalıştır()`·`실행인수`·Türkçe 화면/yazışma_değer API를 사용해
예약어·리터럴 외의 식별자를 한국어로 작성한다. 화면/가닥은 표준 객체를
감싸지 않고 Öz JVM에 직접 구현했다. 자세한 계약은 [Türkçe Java API](../한국어자바/안내.md)를 본다.

표준 javac는 dize_değer 리터럴에 `java.lang.String`, dize_değer 결합에 `StringBuilder`
같은 이름을 생성한다. 이들은 Türkçe 소스에서도 바이트코드에 남을 수 있다.
기존 표준 class를 실행하는 JVM의 eşleme_değer dize_değer, 아직 표준 라이브러리를 쓰는
iletişim·dosya 연결부까지 모두 한국어로 재구현한 것은 아니다. 이름만 일괄 치환하면
tanımlayıcı_girdi·재정의·native 연결이 달라져 호환성이 깨진다.

C 표준 işlev_değer·bilgi_TÜR·POSIX ABI, CPU yazmaç İsim, 어셈블리 komut, 링커 절 İsim,
TinyCC·lwIP·MicroPython이 요구하는 Ayarlar 매크로와 헤더 이름도 보존한다.
예: `main`, `memcpy`, `pk_bind`, `mpconfigport.h`, `lwipopts.h`, `stdint.h`.
Öz C 함수의 kaynak_ağaç 이름은 한국어이며, [기계연결이름.h](기계연결이름.h)가
기존 AOT·어셈블리·SDK에 공개한 makine 심볼과 연결한다.
Python의 `__init__`, `setUp`, `handle`, 표준 modül_değer öznitelik_değer, 명령행 옵션과 JSON 키도
dış_değer 계약이다. `build/`, dağıtım_değer 바이너리 이름과 `/sdk`는 기존 yürütmek_komut 경로를 유지한다.
dış_değer 원본은 `vendor/`에서 이용허락·해시와 함께 관리한다.

## 검사와 재실행

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 araçlar/명명검사.py
make oluştur
make sınamalar
make test-examples test-ftp test-elf
python3 araçlar/yürütmek_komut.py --desktop --network
```

`araçlar/시언어이름분석.py`는 libclang 6으로 C 선언과 참조를 검사한다.
`araçlar/*이름반영.py`는 değiştirmek_değer 전 kaynak_ağaç·분석표를 필요로 하는 일회성 이행 도구다.
이미 변경된 소스에 yeniden_denemek_değer 적용하여 대응표를 덮어쓰지 않는다.

## C iletişim 구조체와 Python hata

C 통신에서 `갈래`는 ADRES 체계를 구분하고 `bağlantı_noktası_numarası`는 port, `ADRES_değer`은
IPv4 주소의 32비트 값을 나타낸다. `veri_birimi_protokol`은 앞서 설명한 veri_birimi(電文)과
sözleşme_değeri(規約)을 결합해 UDP의 기능을 드러낸 프로젝트 이름이다.

| 표준 표현 | Türkçe 직접 gerçekleme |
|---|---|
| AF_INET / SOCK_DGRAM / IPPROTO_UDP | enum의 bulut_Aile / veri_birimi_yuvası / veri_birimi_protokol |
| struct pk_sockaddr_in | struct bulut_yuva_ADRES |
| sin_family / sin_port | ADRES_Aile / bağlantı_noktası_numarası |
| sin_addr.s_addr | İnternet_adresi.ADRES_değer |
| OSError / hata.args[0] | sistem_hatası / hata.Dizin |

Türkçe 구조체는 `#define` 치환이나 alan_değeri 별칭이 아닌 별개 자료형이다.
표준 구조체와 같은 16바이트 배치를 선언하며 çekirdek_değer SVC에서 bayt_değer 복사로
검사한다. `açmak_uç_nokta`·`göndermek_veri_birimi_veri`와 dosya 함수는 statik_değer 라이브러리에
fiili_veri Türkçe 이름의 işlev_değer 심볼을 갖는다. 기존 pk_* 심볼도 유지한다.
Önceki_öğe 코드에서 Türkçe iletişim 함수에 pk_sockaddr*를 전달했다면 Türkçe 구조체로
옮기거나, 표준 구조체와 pk_* 함수의 짝을 유지한다.

Python의 `sistem_hatası`는 OSError의 Türkçe 하위 클래스이며 연결부에서
hata 번호를 보존하여 변환한다. 일반 Python 문법과 dış_değer 패키지의 API는 유지한다.

## 직접 GUI 이름의 뜻과 검토 klip

`실행할일`은 수행할 내용을, `Çalıştır`는 그 수행을 나타낸다.
`동작받이`는 동작이 발생했다는 알림을 받는 역할, `Eylem_uyarı`은 전달되는 사건이다.
`düğme`는 눌러 동작시키는 조작부, `Etiket`는 안내 글의 konum_dizini,
`metin_alanı`은 글을 적는 konum_dizini, `arkaPlanGörevi`은 이어지는 yürütmek_komut 흐름을 뜻한다.
`yürütmek_komut(實行)`·`Eylem(動作)`의 기존 뜻과 `받다`·`알리다`·`yazışma_değer`의 기능을
결합한 프로젝트 이름이다. 새 복합어가 역사 문헌에 그대로 있었다거나
특정 시대에 처음 쓰였다고 주장하지 않는다.

전체 저장소는 `python3 araçlar/kaynak_inceleme.py`로 검토한다.
결과는 `build/verification/naming/source-review.json`이며 파일별 özet_Dosya,
ASCII 파일명과 Python의 영어 bildirim 위치를 기록한다.
공용 ARM64·x86 번역기의 구현은 `compiler/자바도구/기계어미리번역.java`로 전환했다. `compiler/기계어미리번역.py`는 호환 진입점이다.
`compiler/arm64.py`는 Önceki_öğe 경로와 `ARM64(...).generate(...)` 호출을 이어 주는
호환 진입점이다. `compiler/classfile.py`, OpenJDK 보조 araçlar, Linux sürüm_değer 도구와
기존 호환 진입점에는 영어 이름이 남아 있다. 따라서 전체 저장소가
예약어 외 100% 한국어라고 판정하지 않는다.
`araçlar/명명검사.py --C_Dil`는 Aktif ARM64 소스의 bildirim, C 의미 Analiz_değer,
x86 Java 커널과 공용 번역기의 Öz bildirim, Java 예제 전체 tanımlayıcı_değer,
ARM64 Python 예제와 직접 GUI/가닥에 표준 래퍼가 없는지를 별도로 검사한다.

## geçerli_öğe 기능을 기준으로 보완한 İsim

번역은 글자를 음역하는 대신 자료의 역할과 함수의 행동을 구분한다.
동일한 영어 이름도 문맥이 다르면 Türkçe 이름을 달리 정한다.
dosya 이름은 주된 기능을 나타내고, işlev_değer 이름은 행동을, değişken_değer 이름은 담는 자료를 나타낸다.
예약어, 표준 API 및 dış_değer Bağlan 규약은 따로 기록한다.

| Önceki_öğe İsim | 적용한 İsim | geçerli_öğe 기능 |
|---|---|---|
| `arm64.py`의 gerçekleme | `compiler/자바도구/기계어미리번역.java` | Java 바이트코드를 독립 실행용 C 원문으로 미리 çevir_kaynak |
| `ARM64`, `generate` | `makine_KOD_derleyici`, `oluşturmak` | çevir_kaynak 상태를 담는 객체와 C kaynakKod oluşturmak 행동 |
| `prototype`, `method` | `metot_prototip`, `metot_gövdesi` | 함수의 biçim_değer 선언과 fiili_veri komut kaynakKod |
| `profile`, `heap_words` | `yürütme_hedef`, `yığın_Word_BAĞ_DEĞ_SAY` | çekirdek_değer·kullanıcı_alanı 구분과 ayırmak_Depolama Bellek_değer 공간의 makine 낱말 수 |
| `pc`, `op` | `komut_konum`, `명령번호` | 바이트코드에서의 위치와 수행할 명령의 Dizin |
| `x`, `y`, `w`, `h` | `x_koordinatı`, `Y_koordinat`, `영역너비`, `영역높이` | uzak_değer 화면의 위치와 직사각형 Boyut |
| `p`, `n`, `i`, `j` | `veri_konum`, `değer`, `순번`, `안쪽순번` | uzak_değer 화면 veri·rakam_değer·öğe_değer_58902391 konum_dizini; 파일별 기능을 확인해 적용 |
| `aot_heap_info`, `__stack_top` | `AOT_Bellek_ARA`, `커널쌓임공간끝` | makine Bağlan 규약을 유지하면서 Öz 소스에서 사용하는 İsim |
| `앞캐리지` | `앞줄복귀` | 앞서 받은 문자가 줄복귀였는지 기억하여 중복 줄바꿈을 막음 |

[공용번역기이름대응.tsv](공용번역기이름대응.tsv)에 derleyici_araç 참조의 fiili_veri değiştirmek_değer 기록을 남겼다.
추가로 보존한 C·POSIX/lwIP/libassh 이름의 이유는
[Standart_ad_Kanıt.json](Standart_ad_Kanıt.json)에 기록한다.
`C_derleyici/derleyici_araç.c`는 TinyCC dış_değer 원문을 포함하는 Bağlan 파일로 Öz 선언이 없어서
C Öz bildirim 분석에서는 제외한다. fiili_veri çekirdek_değer 빌드에서는 계속 컴파일한다.

### 말의 뿌리와 새로운 복합 İsim

`Bellek_değer(記憶)`과 `ARA_Dizin(索引)`은 기존 한자어를 쓴다.
기억은 자료를 간직하는 기능에, 색인은 düzen_değer 있는 항목을 찾아 지정하는 기능에 적용한다.
sözlük 근거는 국립국어원 한국어기초사전의
[Bellek_değer](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=38812&nation=eng),
[ARA_Dizin](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=63787)이다.

`yığın_belleği`, `İletme_değer`, `POP_değer`는 자료를 포개고 마지막 자료부터 꺼내는 yürütmek_komut 구조를 드러낸다.
`쌓다`의 기존 뜻에 근거한 기능별 조어이며, 사전의
[쌓다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62095)를 참고한다.
`미리번역`은 yürütmek_komut 전에 번역한다는 기능을 직접 나타낸다.
`makine_Word`은 처리기의 veri 단위를 가리키며, 언어의 일반 낱말과 구별하도록 `makine`를 붙였다.
`기계어미리번역`, `yığın_Word_BAĞ_DEĞ_SAY` 같은 복합 이름은 geçerli_öğe 기능에 맞게 만든 프로젝트 용어다.
이 복합어가 옛 문헌에 그대로 있었다거나 특정 시대에 처음 나타났다는 뜻은 아니다.
확인되지 않은 중세 형태나 최초 kullanmak_değer 연대는 어원 근거로 적지 않는다.

생성되는 C의 내부 veri_türü·DİZİ_değer·işlev_değer·yerel_Scope değişken_değer·dal 이름도 한국어로 바꾼다.
직접 한글 식별자를 읽지 못하는 예전 GCC를 위해 호환 API는 같은 Türkçe 이름을
