## IP 설정과 komunikace ověřit

```sh
ipconfig
ip addr show
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2
아이피설정 set 10.0.2.20 255.255.255.0 10.0.2.2
ping -c 4 -W 1 10.0.2.2
test_odpověď -c 4 10.0.2.2
ip route show
ip link set dev sl0 down
ip link set dev sl0 up
netstat
```

초깃값은 `sl0`, `10.0.2.15/24`, brána_HODNOTA `10.0.2.2`다. Adresa 설정은 재부팅 전까지 유지된다. TCP/UDP 끝점이 열려 있으면 `error -16`으로 변경을 거부한다. 먼저 `ftpd stop` 등으로 서비스를 닫고 프로그램의 소켓을 닫는다. 잘못된 Adresa·비연속 넷마스크·다른 망의 관문은 적용하지 않는다.

`ip`는 위 구문의 부분집합이며 Linux iproute2 전체 문법을 구현하지 않는다. `ping`은 IPv4 číslice_HODNOTA Adresa, `-c 1..100`, `-W 1..10`초를 지원한다. Název parsovat_HODNOTA·IPv6는 미지원이며 GENET의 DHCP는 externí_HODNOTA kontakt_e05f319b 구현에 추가했다. 응답이 없으면 ukončovací_kód 1, 잘못된 인수는 2, uživatelský_prostor 취소는 130이다. `ping ...; echo $?`로 확인한다.

QEMU externí_HODNOTA 통신은 UART SLIP→NAT 연결을 사용한다. `--network` 없이도 vlastní Adresa dotaz_HODNOTA·설정은 가능하지만 externí_HODNOTA 응답은 오지 않는다. výchozí_hodnota NAT는 `10.0.2.0/24`다. 실물 Pi의 GENET 드라이버는 별도로 추가했으며 Panel 검증이 필요하다. Wi-Fi는 미지원이다.

주소를 `.20`으로 바꾼 BACK_HODNOTA FTP 등 **외부에서 들어오는 Připojit**까지 사용할 때는 Provést_příkaz 시 Vpřed_HODNOTA 대상도 지정한다.

```sh

# 부팅한 게스트 안에서
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2

```

`--guest-ip`는 NAT Vpřed_HODNOTA 대상이며 게스트의 주소를 자동 설정하지 않는다. FTP řízení_HODNOTA 포트는 hostit `127.0.0.1:2121`, 수동 데이터 포트는 50000~50007이다. 여러 VM을 함께 띄울 때는 `--network-host 127.0.0.2 --port 5903`처럼 hostit 루프백 주소와 VNC 포트를 구분한다. FTP와 Java/C 소켓은 변경된 skutečný_data 게스트 IP를 사용한다.

## Stav_HODNOTA 조회의 의미

`ps`는 jádro_HODNOTA/prostředí, 살아 있는 협력 작업, 최대 4개의 EL0 uživatelský_prostor 세션을 표시한다. 다른 터미널에 열린 `vi` 등을 `SUSPENDED` 상태로 볼 číslo 있다. `MAPPED_KiB`는 skutečný_data 페이지 매핑, `RUN_ms`는 해당 세션이 선택된 동안의 경과 časová_hodnota(시스템 호출 deklarace)이며 정밀 CPU 사용률이 아니다. `top -n 1`은 한 번, `top -n 2`는 두 번 표시한다. 리다이렉션된 `top`의 기본값은 한 번이다.

`free`의 AOT halda_HODNOTA 사용량은 할당기에서 읽는다. 힙은 jádro_HODNOTA BSS에 포함되므로 각 줄을 모두 더하면 중복된다. 고정 예약 영역과 uživatelský_prostor 페이지 매핑을 표시하며 Linux의 가용 RAM 계산이나 hostit Paměť_data 통계를 꾸며서 표시하지 않는다.

`df`는 RAM 파일시스템의 název_souboru 64칸 × 16 KiB를 표시한다. název_souboru 하나는 논리 크기와 별도로 16 KiB 칸을 예약한다. `Data`는 skutečný_data data délka_HODNOTA celkem_HODNOTA, `Reserved`는 použít_HODNOTA 중인 přihrádka_položka 용량이다. 삭제 후에도 열린 파일은 마지막 참조를 닫을 때까지 계산한다. SD/영구 디스크 사용량은 아직 지원하지 않는다.
