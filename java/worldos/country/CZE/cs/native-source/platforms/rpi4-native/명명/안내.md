## 보존하는 SD Název

`public`, `class`, `int`는 예약어다. `String`, `main`, 배열의 `length`는 예약어가 아니다.
dobrá_zboží 다섯 Java 예제는 `Spustit_2()`·`실행인수`·čeština 화면/vlákno_HODNOTA API를 사용해
예약어·리터럴 외의 식별자를 한국어로 작성한다. 화면/가닥은 표준 객체를
감싸지 않고 vlastní JVM에 직접 구현했다. 자세한 계약은 [čeština Java API](../한국어자바/안내.md)를 본다.

표준 javac는 řetězec_HODNOTA 리터럴에 `java.lang.String`, řetězec_HODNOTA 결합에 `StringBuilder`
같은 이름을 생성한다. 이들은 čeština 소스에서도 바이트코드에 남을 číslo 있다.
기존 표준 class를 실행하는 JVM의 대응 řetězec_HODNOTA, 아직 표준 라이브러리를 쓰는
komunikace·název_souboru 연결부까지 모두 한국어로 재구현한 것은 아니다. 이름만 일괄 치환하면
popisovač_položka·재정의·native 연결이 달라져 호환성이 깨진다.

C 표준 funkce_HODNOTA·integer_TYP·POSIX ABI, CPU registr Název, 어셈블리 příkaz, 링커 절 Název,
TinyCC·lwIP·MicroPython이 요구하는 Nastavení 매크로와 헤더 이름도 보존한다.
예: `main`, `memcpy`, `pk_bind`, `mpconfigport.h`, `lwipopts.h`, `stdint.h`.
vlastní C 함수의 zdroj_strom 이름은 한국어이며, [기계연결이름.h](기계연결이름.h)가
기존 AOT·어셈블리·SDK에 공개한 počítač 심볼과 연결한다.
Python의 `__init__`, `setUp`, `handle`, 표준 modul_HODNOTA hodnota_atributu, 명령행 옵션과 JSON 키도
externí_HODNOTA 계약이다. `build/`, distribuce_HODNOTA 바이너리 이름과 `/sdk`는 기존 Provést_příkaz 경로를 유지한다.
externí_HODNOTA 원본은 `vendor/`에서 이용허락·해시와 함께 관리한다.

## C komunikace 구조체와 Python chyba

C 통신에서 `갈래`는 Adresa 체계를 구분하고 `číslo_portu`는 port, `ODKAZ_HODNOTA`은
IPv4 주소의 32비트 값을 나타낸다. `datagram_protokol`은 앞서 설명한 datagram(電文)과
hodnota_smlouvy(規約)을 결합해 UDP의 기능을 드러낸 프로젝트 이름이다.

| 표준 표현 | čeština 직접 implementace |
|---|---|
| AF_INET / SOCK_DGRAM / IPPROTO_UDP | enum의 cloud_řada / datagramový_soket / datagram_protokol |
| struct pk_sockaddr_in | struct cloud_soket_ODKAZ |
| sin_family / sin_port | ODKAZ_řada / číslo_portu |
| sin_addr.s_addr | internetová_adresa.ODKAZ_HODNOTA |
| OSError / chyba.args[0] | chyba_systému / chyba.INDEX |

čeština 구조체는 `#define` 치환이나 hodnota_pole 별칭이 아닌 별개 자료형이다.
표준 구조체와 같은 16바이트 배치를 선언하며 jádro_HODNOTA SVC에서 bajt_HODNOTA 복사로
검사한다. `Create_účastník`·`poslat_datagram_data`와 název_souboru 함수는 statický_HODNOTA 라이브러리에
skutečný_data čeština 이름의 funkce_HODNOTA 심볼을 갖는다. 기존 pk_* 심볼도 유지한다.
Předchozí_zboží 코드에서 čeština komunikace 함수에 pk_sockaddr*를 전달했다면 čeština 구조체로
옮기거나, 표준 구조체와 pk_* 함수의 짝을 유지한다.

Python의 `chyba_systému`는 OSError의 čeština 하위 클래스이며 연결부에서
chyba 번호를 보존하여 변환한다. 일반 Python 문법과 externí_HODNOTA 패키지의 API는 유지한다.

### 말의 뿌리와 새로운 복합 Název

`Paměť_HODNOTA(記憶)`과 `VYHLEDAT_INDEX(索引)`은 기존 한자어를 쓴다.
기억은 자료를 간직하는 기능에, 색인은 pořadí_HODNOTA 있는 항목을 찾아 지정하는 기능에 적용한다.
slovník 근거는 국립국어원 한국어기초사전의
[Paměť_HODNOTA](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=38812&nation=eng),
[VYHLEDAT_INDEX](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=63787)이다.

`paměť_zásobníku`, `nabídka_HODNOTA`, `POP_HODNOTA`는 자료를 포개고 마지막 자료부터 꺼내는 Provést_příkaz 구조를 드러낸다.
`쌓다`의 기존 뜻에 근거한 기능별 조어이며, 사전의
[쌓다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62095)를 참고한다.
`미리번역`은 Provést_příkaz 전에 번역한다는 기능을 직접 나타낸다.
`počítač_Word`은 처리기의 data 단위를 가리키며, 언어의 일반 낱말과 구별하도록 `počítač`를 붙였다.
`기계어미리번역`, `halda_počet_slov` 같은 복합 이름은 dobrá_zboží 기능에 맞게 만든 프로젝트 용어다.
