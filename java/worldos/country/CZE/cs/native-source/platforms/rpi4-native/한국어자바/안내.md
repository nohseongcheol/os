# čeština Java komunikace·vstup_a_výstup·výjimka API

패키지는 `čeština.vlastní`다. hostit `javac --release 8`로 컴파일한 class를
vlastní ARM64 커널의 JVM에서 실행한다. komunikace·název_souboru·výjimka API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 vlákno_HODNOTA API는 vlastní JVM 전용이다.
기존 표준 Java knihovna 전체의 čeština 번역판은 아니다.

```java
import čeština.vlastní.*;

public class síť {
    public static void main(String[] argumenty) throws vstup_a_výstup_výjimka {
        kontakt Připojit = kontakt.Otevřít("10.0.2.2", 9000);
        try {
            Připojit.TIMEOUT(700);
            Připojit.výstupní_pozice().Zápis(문자.kódovat("안녕하세요\n"));
            vstupní_datový_proud vstup_HODNOTA = Připojit.vstup_HODNOTA();
            výstupní_pozice.zápis_číslo(vstup_HODNOTA.Čtení());
        } catch (počkej_TIMEOUT_výjimka chyba) {
            výstupní_pozice.zápis_čára(chyba.설명());
        } finally {
            Připojit.Zavřené();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
uživatelský_prostor 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 řetězec_HODNOTA 리터럴에 사용하는 표준 클래스다. vlastní 실행기는 `public static void Spustit_2()`도 진입점으로 받는다.

## 통신과 tok_HODNOTA

| Třída_HODNOTA | čeština 호출 |
|---|---|
| kontakt | `Otevřít(Adresa, číslo_portu)`, `vstup_HODNOTA()`, `výstupní_pozice()`, `TIMEOUT(밀리초)`, `číslo_portu()`, `místní_číslo_portu()`, `연결됨()`, `informační_systémy_uzavřeno()`, `Zavřené()` |
| dostat_port | `Otevřít(číslo_portu)`, `dostat()`, `číslo_portu()`, `TIMEOUT(밀리초)`, `informační_systémy_uzavřeno()`, `Zavřené()` |
| vstupní_datový_proud | `Čtení()`, `Čtení(byte[])`, `Čtení(byte[], Spustit_2, délka_HODNOTA)`, `Zavřené()` |
| výstupní_datový_proud | `Zápis(int)`, `Zápis(byte[])`, `Zápis(byte[], Spustit_2, délka_HODNOTA)`, `내보내기()`, `Zavřené()` |
| datagram_Kanál | `Otevřít(číslo_portu)`, `poslat(Adresa, číslo_portu, text)`, `dostat()`, `TIMEOUT(밀리초)`, `číslo_portu()`, `informační_systémy_uzavřeno()`, `Zavřené()` |
| kontakt_přenos | `Otevřít(...)`, `수신열기(...)`는 위 čeština 객체를 Vratka_KV |
| 검사 | `참인지(podmínka, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`Čtení()`의 název_souboru 끝은 -1, pole_HODNOTA 읽기의 반환값은 skutečný_data 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. číslo_portu 0은 빈 번호를 자동 배정한다.
UDP 전문은 dobrá_zboží vlastní 커널에서 512바이트까지 받으며, 주소는 číslice_HODNOTA IPv4를 사용한다.
`localhost` 루프백 외의 Název 풀이(DNS)는 vlastní 커널에 아직 없다.

기존 `kontakt_přenos.Připojit/naslouchat_účastník/dostat`, `komunikace.Otevřít/poslat/dostat`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `kontakt`, `dostat_port`, `datagram_Kanál`를 쓴다.

## čeština výjimka

모든 아래 클래스는 výchozí_hodnota 생성자, `새예외("설명")` 형태의 řetězec_HODNOTA 생성자와
`설명()`을 제공한다. skutečný_data generovat 문법은 `new počkej_TIMEOUT_výjimka("čekací_stav 끝")`이다.

| čeština výjimka | 상위 Třída_HODNOTA / 용도 |
|---|---|
| výjimka | `java.lang.Exception`, 직접 던지는 일반 검사 výjimka |
| spuštění_výjimka | `java.lang.RuntimeException` |
| vstup_a_výstup_výjimka | `java.io.IOException`, čeština název_souboru·komunikace API의 검사 výjimka |
| počkej_TIMEOUT_výjimka | `vstup_a_výstup_výjimka`, komunikace TIMEOUT 초과 |
| ODKAZ_VYHLEDAT_výjimka | `vstup_a_výstup_výjimka`, Adresa ověřit selhání_HODNOTA |
| 파일없음예외 | `vstup_a_výstup_výjimka`, název_souboru Otevřít selhání_HODNOTA |
| komunikace_výjimka | `vstup_a_výstup_výjimka`, 표준 SocketException CONVERT_HODNOTA |
| neplatný_argument_výjimka | `java.lang.IllegalArgumentException` |
| číslo_formát_selhání | `neplatný_argument_výjimka` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| nulový_odkaz_výjimka | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| Stav_výjimka | `java.lang.IllegalStateException` |
| TYP_převod_výjimka | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| pole_Store_selhání | `java.lang.ArrayStoreException` |
| vlákno_Stav_výjimka | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 počkej_HODNOTA 중단 |

`výjimka`와 `spuštění_výjimka`는 모든 čeština 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, název_souboru·komunikace 전체를 잡으려면 `catch (vstup_a_výstup_výjimka chyba)`를 쓴다.
čeština API가 표준 vstup_a_výstup 오류를 čeština 예외로 변환한다.
기존 čeština komunikace 호출에서 `SocketTimeoutException`을 잡던 코드는
`počkej_TIMEOUT_výjimka`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
výjimka 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
dobrá_zboží vlastní JVM에 이 20종을 추가했다. 임의의 uživatelský_prostor Throwable 하위 Třída_HODNOTA 전체를
지원하도록 확장했다는 뜻은 아니다.

## kompilovat_zdroj·Provést_příkaz

```sh
cd /home/user/jkoros/platforms/rpi4-native
make BLD_Systém
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 zkoušky/자바/한국어통신시험.java
python3 nástroje/Provést_Soubor.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 uživatelský_prostor JVM ELF 안에 탑재된다. `.jar`는 hostit javac의
Třída_HODNOTA 경로로 사용한다. zdroj_strom 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 čeština 예외의 `throws` 선언과 그 import를 인식한다.
vlastní JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·objekt_HODNOTA·soket_HODNOTA 예제 전체의 zdroj_strom 컴파일은 hostit javac를 사용한다.
`/example/java/UkázkaSouboru.java`는 게스트 javac로도 컴파일할 číslo 있다.

skutečný_data TCP/UDP 예제는 [UkázkaSítě.java](../../../example/java/UkázkaSítě.java),
Provést_příkaz 절차는 [example 안내](../../../example/README.md),
zdroj_strom 명명 원칙은 [명명 안내](../명명/안내.md)에 있다.

## Swing Okno 예제

`/example/java/UkázkaOkna.java`와 컴파일된 `.class`가 spuštění_stroje 시 준비된다.
`cd /example/java` Další_zboží `java UkázkaOkna`로 연다. Název vstup_HODNOTA, 인사하기 버튼,
인사말과 klepnout_HODNOTA opakování_POČET aktualizovat, X 닫기를 지원한다.

| 기능 | čeština 직접 API |
|---|---|
| Runnable / run | `실행할일.Spustit()` |
| ActionListener / actionPerformed | `동작받이.dostat_Akce(Akce_povinnost_zvěřejnit povinnost_zvěřejnit)` |
| ActionEvent | `Akce_povinnost_zvěřejnit.příkaz_SMS()`, `zdroj_události()`, `INDEX()` |
| JFrame | `Okno(okno_Název, 폭, výška_HODNOTA)`, `Přidat_prvek(화면구성요소)`, `zobrazit_okno()`, `Zavřené()`, `보이는가()` |
| JButton | `tlačítko(text, 가로, Svislá_pozice, 폭, výška_HODNOTA, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `Popisek(...)`, `textové_pole(...)` |
| 공통 화면 prvek_HODNOTA | `화면구성요소.글읽기()`, `zápis_SMS(text)`, `자리정하기(가로, Svislá_pozice, 폭, výška_HODNOTA)` |
| SwingUtilities.invokeLater | `událost_fronta.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `pracovník(실행할일)`, `START_úkol()`, `기다리기()`, `살아있는가()`, `YIELD_úkol()` |
| 명령행 | `Spustit_2()`, `실행인수.zboží_POČET()`, `실행인수.text(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
vlastní JVM의 `한국어화면호출`, `Proces_vlákno`가 čeština Třída_HODNOTA·metoda_HODNOTA·서술자를
해석해 화면 요소와 Provést_příkaz 가닥을 직접 만든다. Akce 알림도 vlastní 객체이며
콜백으로 `Spustit`와 `dostat_Akce`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 Provést_příkaz 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 vlastní JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 hostit JVM에서 무동작 객체가 생기지 않도록 하는 odmítnout_HODNOTA 경로다.
vlastní JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 implementace API를
실행할 číslo 없다. hostit javac로 컴파일한 BACK_HODNOTA vlastní JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import čeština.vlastní.*;
public class 가닥예제 implements 실행할일 {
    public void Spustit() { výstupní_pozice.zápis_čára("čeština 작업 Provést_příkaz"); }
    public static void Spustit_2() throws 대기중단예외 {
        pracovník vlákno_HODNOTA = 작업.Spustit_2(new 가닥예제());
        작업.기다리기(vlákno_HODNOTA);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
pole_HODNOTA argumenty 대신 `실행인수`, 길이는 `문자.bajt_POČET`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
vlastní 실행기는 argumenty 없는 `Spustit_2()`을 우선한다.
기존 čeština 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.Spustit_2(Runnable)`을 사용하던 코드는 새 čeština 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API vzpěra_HODNOTA 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 Třída_HODNOTA·metoda_HODNOTA 이름과 서술자가 남는다.
čeština Název 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·metoda_HODNOTA 재정의, native Připojit, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS identifikátor_HODNOTA](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS metoda_HODNOTA odkaz](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
