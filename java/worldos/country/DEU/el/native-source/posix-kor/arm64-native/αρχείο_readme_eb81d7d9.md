# ίδιο ARM64 Java 커널의 C/C++ Αρχείο·루프백 Σύνδεση

이 디렉터리는 `platforms/rpi4-native` ίδιο πυρήνας_τιμή 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 ελληνικά 함수명과 `extern "C"` ABI를 제공한다. `Σύνδεση.c`는 πυρήνας_τιμή 안에서 AOT Java Αρχείο 메서드에 직접 연결하고, `χρήστης_γέφυρα.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. πραγματικός_δεδομένα Αρχείο 처리는 `Μνήμη_Αρχεία.java`, 루프백 αυτοδύναμο_πακέτο 처리는 `βρόχος_επιστροφής_δίκτυο.java`, 연결형 흐름은 `ροή_δίκτυο.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 πυρήνας_τιμή 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·κινητή_υποδιαστολή_τιμή εγχείρηση_τιμή·Αρχείο·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

στήριγμα_τιμή: `ανοίγω_Αρχείο`, `파일자료읽기`, `εγγράφω_Αρχείο_δεδομένα`, `κλείνω_Αρχείο`, `αναζητώ_Αρχείο`, `καταργώ_Αρχείο_καταχώρηση_όνομα`, `σύνολο_Αρχείο_διάρκεια`, 보조 συνάρτηση_τιμή `μέγεθος_αρχείου`. ΣΦΑΛΜΑ 시 -1과 작업별 `αριθμός_σφάλματος`를 반환한다. `δέσμευση_Αρχεία`은 RAM 파일이므로 ENOSYS를 반환한다. Αρχείο 16개, 각 16384바이트, Όνομα 63바이트, 서술자 16개이며 RAM 디렉터리·ομότιμος_τιμή/절대 경로를 제공한다. άδεια_τιμή/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 πραγματικός_δεδομένα ελληνικά 함수와 독립 구조체를 선언한다.
`ανοίγω_τελικό_σημείο`, `συνδέω_διεύθυνση`, `στέλνω_αυτοδύναμο_πακέτο_δεδομένα/λαμβάνω`, `συνδέω_δίκτυο/기다리기/λαμβάνω`는
`χρήστης_γέφυρα.c`에서 SVC를 호출하며 μακροεντολή_τιμή 별칭이 아니다. `struct πλέγμα_υποδοχή_διεύθυνση`의
`διεύθυνση_παιδικά`, `αριθμός_θύρας`, `διεύθυνση_Internet.διεύθυνση_τιμή`을 사용한다. 상수는 enum의
`πλέγμα_παιδικά`, `υποδοχή_αυτοδύναμου_πακέτου`, `αυτοδύναμο_πακέτο_πρωτόκολλο`, `ροή_δίκτυο`, `ροή_πρωτόκολλο_μεταφοράς`이다.
ελληνικά·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. εξωτερικός_τιμή 통신은 ίδιο 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. πραγματικός_δεδομένα Pi 4 GENET 드라이버는 미지원이다.
소켓도 πραγματικός_δεδομένα συνάρτηση_τιμή `κλείνω_Αρχείο`로 닫는다.
