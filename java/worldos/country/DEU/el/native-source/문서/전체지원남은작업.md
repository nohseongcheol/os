# 전체 στήριγμα_τιμή 요청의 τρέχων_στοιχείο Κατάσταση_τιμή

αίτηση 전체는 아직 완료되지 않았다. τρέχων_στοιχείο ISO는 ίδιο Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 πραγματικός_δεδομένα C POSIX 일부 기능, ελληνικά API/ΠΗΓΗ Όνομα, IDE Αρχείο 보존, 게스트 Java Αρχείο 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/αρχείο_readme_eb81d7d9.md)를 기준으로 판단한다.

| αίτηση 분야 | τρέχων_στοιχείο εκτελώ_εντολή 가능한 απόσπασμα | 전체 지원에 필요한 작업 |
|---|---|---|
| Java δόμηση_προέλευση·εκτελώ_εντολή | 게스트 제한형 javac/JVM, στατικός_τιμή 단일 클래스와 일부 표준 αντικείμενο_τιμή | 일반 αντικείμενο_τιμή·Τάξη_τιμή Σύνδεση·εξαίρεση·GC·스레드, 완전한 javac와 표준 Τάξη_τιμή βιβλιοθήκη |
| Αρχείο | POSIX 서술자, Java 단일 바이트 Αρχείο ροή_τιμή, 전용 μέσα_τιμή 보존 | 일반 java.io/nio, 디렉터리·άδεια_τιμή·κλείδωμα_τιμή·일반 σύστημα_αρχείων·επέκταση_τιμή 가능한 Δυνατότητα_τιμή |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP φιλοξενώ 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, προσαρτώ_καταχώρηση NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·είσοδος_τιμή Συμβάν·γραμματοσειρά_τιμή·Παράθυρο λειτουργικό_σύστημα_τιμή, AWT 네이티브 연결과 Swing εκτελώ_εντολή 기반 |
| POSIX | 문서화한 Αρχείο·단말·UDP 부분 | διεργασία_τιμή·exec/fork·스레드·시그널·τιμή_ώρας·mmap·poll·파이프 등과 적합성 επικυρώνω |

ίδιο 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 εκτελώ_εντολή 환경을 추가하는 방식은 별도의 πυρήνας_τιμή·루트 σύστημα_αρχείων·OpenJDK·그래픽 διακομιστής_τιμή·영구 αποθηκεύω_τιμή 구성을 가진 εκτελώ_εντολή 경로가 된다. 후자는 기존 ίδιο 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

εκτελώ_εντολή 기반과 προσαρτώ_καταχώρηση τιμή_στόχος 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. τρέχων_στοιχείο 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
