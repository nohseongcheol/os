# Java 네이티브 derleyici

OpenJDK Öz 소스를 빌드하는 **`--target openjdk-build`**와 Öz çekirdek_değer ABI 검사 도구를 추가했다.
이는 공식 javac/C/C++ 도구를 연결하는 별도 경로다. [oluştur 방법·fiili_veri doğrulamak_5fb2b747·çekirdek_değer 이식 klip](OpenJDK-kaynak_BLD_VE-yerel_çekirdek-이식.md)를 참고한다.

x86 직접 변환과 ARM64 C oluşturmak 후단은 모두 [기계어미리번역.java](자바도구/기계어미리번역.java)로 구현한다. `sh 미리번역.sh`로 직접 실행하며, [기계어미리번역.py](기계어미리번역.py)와 `derleyici.py`는 Önceki_öğe komut·API 및 OpenJDK 도구를 위한 호환 진입점이다. Öz Pi4 후단은 freestanding C를 거쳐 AArch64로 만든다. [arm64.py](arm64.py)는 Önceki_öğe 경로와 Python 호출을 위한 호환 진입점이다. işlev_değer·değişken_değer·oluşturmak C 이름의 뜻과 예외는 [Türkçe 명명 안내](../platforms/rpi4-native/명명/안내.md)를 참고한다. [ARM64 oluştur·Destek_değer klip](../platforms/rpi4-native/안내.md)에 yürütmek_komut 조건이 있다. 전체 OpenJDK나 일반 Sınıf_değer 실행기는 아니다.

yürütmek_komut 시 JVM이 필요 없는 x86 32비트 ELF를 만든다. JDK 11 이상으로 실행하는 Java Öz AOT 후단이며, Java 전체를 새로 구현한 컴파일러는 아니다. Java 문법·erişim_girdi denetim_değer·TÜR_değer 검사는 JDK의 `javac`에 맡기고, Java 8 Sınıf_değer 파일을 읽어 각 바이트코드를 x86 명령으로 직접 변환한다. C 코드로 우회하거나 바이트코드 해석기를 커널에 넣지 않는다.

```text
Java kaynakKod → javac의 문법·TÜR_değer 검사 → 임시 .class
          → Öz x86 변환기 → GNU as/ld → 네이티브 ELF32
```

## 준비와 yürütmek_komut

oluştur konak: Linux, Python 3.6 이상, JDK 11 이상(`javac --release 8`), GNU binutils(`as`, `ld`), Make. geçerli_öğe 환경의 OpenJDK 11, Python 3.6, binutils 2.30으로 검증했다. dış_değer Python 패키지와 네트워크 다운로드는 사용하지 않는다.

```sh
cd /home/user/jkoros/compiler
make
./build/계산
echo $?                  # 0이면 예제 sınamalar 성공

python3 derleyici.py --target linux --entry 계산.çalıştır \
    -o build/계산 예제/계산.java

make test
```

`linux` 대상은 Linux의 32비트 yürütmek_komut 호환 기능이 필요하다. `int 0x80`을 차단하는 샌드박스에서는 `Bad system call`이 발생할 수 있다. bilgi_teknolojisi_normal Linux konak 또는 해당 실행을 허용한 sınamalar 환경에서 실행한다. 시험의 비정상 종료를 통과로 처리하지 않는다.

진입점은 `static int çalıştır()` 또는 `static void çalıştır()`처럼 인수가 없어야 한다. `--entry 패키지.Sınıf_değer.işlev_değer`로 선택한다. `int` 반환값은 Linux 프로세스 Çıkış_program 코드가 되며 셸에는 하위 8비트가 보인다. 일반 `main(String[] args)` yürütmek_komut 환경이나 표준 G_Ç 라이브러리는 제공하지 않는다.

`--target kernel`은 makine_başlatma 코드와 연결할 재배치 ELF 오브젝트를 생성한다.

```sh
cd /home/user/jkoros
python3 compiler/derleyici.py --target kernel --entry Çekirdek.çalıştır \
    --export kernel_dispatch=sistem_çağrısı.işlem_değer_girdi \
    -o os/build/java.o os/kaynakKod/*.java
```

`--target user`는 jkoros 셸에서 실행할 독립 ELF를 생성한다. `kullanıcı_alanı` 클래스의 제한된 native API는 `int 0x80` 시스템 호출로 연결하며 `cihaz_değer` 클래스의 donanım_değer 직접 접근은 거부한다. kullanıcı_alanı ELF는 Linux yürütmek_komut dosya ABI와 다르므로 호스트에서 실행하지 않는다. oluşturmak·yazmaç_girdi 방법은 [kullanıcı_alanı yürütmek_komut 안내](../os/kullanıcı_alanı/안내.md)에 있다. `--export 외부기호=Sınıf_değer.işlev_değer`는 오버로드되지 않은 statik_değer 함수를 Öz işlenen_Yığın ABI로 노출한다. 커널의 시스템 호출 진입점에 사용한다.

Java 파일은 필요한 클래스들을 한꺼번에 전달한다. metinÇıktısı 옆의 `.s`는 생성된 어셈블리, `.json`은 kaynakKod SHA-256 및 네이티브 simge↔Java işlev_değer 대응표다. Türkçe 함수명은 원문과 대응표에 보존하고 ELF 내부에는 충돌 방지용 makine 기호를 쓴다. derlemek_kaynak·çevirmek_değer·Bağlan 중 실패하면 기존 sonuç 파일을 덮어쓰지 않는다.

## Destek_değer klip

- `int`, `boolean`, `byte`, `short`, `char`의 32비트 계산 및 TÜR_değer ÇEVİR_değer.
- statik_değer 필드와 statik_değer işlev_değer, 매개변수·반환값, 재귀, 클래스별 지연 초기화와 başlat Döngü_değer.
- 조건문, 반복문, 단락 평가, 삼항식, bilgi `switch`, 넓은 yerel_Scope değişken_değer 인덱스.
- 덧셈·뺄셈·곱셈·나눗셈·나머지·bit_değer 연산과 taşımak_değer_83b651b8. Java의 오버플로 및 `MIN_VALUE / -1` 동작을 유지한다.
- `int[]` oluşturmak·초기값 0·süre_değer·Okuma·Yazma·Başvuru 비교. 256KiB 고정 DİZİ_değer bölge_değer, 널/alt_simge_değer/Boyut/ADRES_bölge 검사.
- dize_değer 리터럴과 `String` Başvuru, `length()` 및 `charAt()`. 문자열은 UTF-16 KOD_değer 단위로 저장하고 같은 리터럴은 공유한다. NUL 및 대리쌍도 시험한다.
- Türkçe Sınıf_değer·işlev_değer·değişken_değer·dosya İsim.

`new Object`, 인스턴스 alan_değeri/işlev_değer, 상속/인터페이스, `long/float/double` yürütmek_komut işlem_değer_c96707fb, `int[]` 이외 DİZİ_değer, dize_değer 동적 결합, Java 표준 kitaplık, özel_durum işlem_değer_girdi, 스레드·eşitlemek·GC는 미지원이다. 실행에 필요한 미지원 바이트코드나 dış_değer 호출을 발견하면 실패한다. 사용되지 않는 varsayılan_değer 생성자는 yürütmek_komut 코드로 만들지 않는다. Java 8 문법이어도 모든 프로그램을 컴파일할 수 있다는 뜻은 아니다.

özel_durum nesne_değer 대신 런타임 hata 번호로 중단한다. Linux와 jkoros kullanıcı_alanı 대상에서는 `100 + Dizin`로 종료하고 çekirdek_değer 대상에서는 `JKOROS PANIC Dizin`를 출력하고 정지한다. kullanıcı_alanı 프로그램만 종료한 경우 셸은 계속 실행된다.

| Dizin | 원인 |
| --- | --- |
| 1 | 0으로 Bölge_KR |
| 2 | 널 Başvuru |
| 3 | DİZİ_değer/dize_değer alt_simge_değer klip 초과 |
| 4 | Negatif_değer DİZİ_değer Boyut |
| 5 | DİZİ_değer bölge_değer 부족 |

DİZİ_değer 영역은 증가식 할당이며 회수하지 않는다. 재귀 스택의 sınır_değer 검사도 아직 없으므로 무제한 재귀를 안전하게 처리하는 런타임은 아니다. 특권 çekirdek_değer 및 신뢰할 수 있는 작은 프로그램용 başlangıç_durumu 구현이다.

## native 경계와 ABI

çekirdek_değer 대상에서는 `os/kaynakKod/cihaz_değer.java`, kullanıcı_alanı 대상에서는 `os/kullanıcı_alanı/bildirim/kullanıcı_alanı.java`의 정확한 metot_ad_SMS·서술만 허용한다. 임의의 `native` 함수와 Linux/kullanıcı_alanı 대상의 donanım_değer 접근은 거부한다. Java 인수를 왼쪽부터 32비트 한 칸씩 스택에 놓으며, 반환값은 EAX, EBP/ESP 이외 레지스터는 호출자가 보존한다고 가정하지 않는다. C의 cdecl/JNI ABI가 아니므로 C 함수와 바로 연결하면 안 된다.

Java kaynakKod 또는 `.class` 입력을 받는다. 전체 JVM 바이트코드 검증기는 제공하지 않는다. 어노테이션 처리는 비활성화하고 비어 있는 Sınıf_değer yol/kaynakKod 경로에서 명시한 소스만 컴파일한다.

## 검증과 gerçekleme 근거

`sınamalar/test_compiler.py`의 14개 시험에는 네이티브 ELF와 OpenJDK의 işlem_değer_c96707fb sonuç 대조, Sınıf_değer başlat, bilgi 극값, dize_değer/DİZİ_değer, 재귀·switch·wide, 런타임 오류와 미지원 기능 reddetmek_değer, hata_değer 시 metinÇıktısı 보존, kullanıcı_alanı ELF/izin_değer sınır_değer 및 내보내기 검증이 포함된다. 이것은 Java 전체 적합성 시험은 아니다.

komut 의미와 Sınıf_değer dosya 형식은 Oracle의 [JVM komut 명세](https://docs.oracle.com/javase/specs/jvms/se11/html/jvms-6.html), [Sınıf_değer dosya 명세](https://docs.oracle.com/javase/specs/jvms/se11/html/jvms-4.html)를 참고했다.
