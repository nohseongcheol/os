# 셸에서 실행하는 kullanıcı_alanı 프로그램과 UDP

게스트에서 일반적인 `main(String[] args)` 형식의 소스를 직접 작성하고 컴파일하려면 [제한형 Java 개발 ortam 안내](../../문서/Java_IDE.md)를 참고한다. 아래의 네이티브 ELF 개발과 별도로 `javac FILE.java`, `java CLASS`를 제공한다.

## 바로 yürütmek_komut

konak uçbirim 1:

```sh
cd /home/user/jkoros
python3 os/araçlar/yankı_veri.py --port 9000
```

이 서버는 `127.0.0.1`에만 바인딩한다. dış_değer 연결을 받도록 방화벽이나 donanım_taşımak 전달을 변경하지 않는다. Ctrl+C로 종료한다.

konak uçbirim 2:

```sh
cd /home/user/jkoros
make run
```

게스트의 `jkoros>` 프롬프트에 artış_değer:

```text
apps
run hello first second
net
run netcheck
run udp 10.0.2.2 9000 hello
run stress 9000
```

- `hello`: 독립 Java ELF 실행과 fiili_veri CPU izin_değer `ring 3`, bağımsız_değişkenler metinÇıktısı.
- `netcheck`: taşımak_değer 중복, 잘못된 sap_değer/işaretçi/süre_değer, 비차단 받기와 zaman_değeri 초과 doğrulamak.
- `udp`: IPv4 ADRES·hedef_değer taşımak_değer·한 Word_değer 메시지를 받아 UDP로 보내고 같은 응답을 doğrulamak. `UDP ECHO PASS`, `Exit: 0`이면 성공.
- `stress`: konak `10.0.2.2`의 Ata_değer 창구와 1,023/1,024바이트 데이터그램을 24회 왕복. almak_değer Loop_değer 경계를 여러 번 지난다.

`make run`/`run-gui`는 `-netdev user,id=net0 -device rtl8139,netdev=net0`을 사용한다. geçerli_öğe 주소는 게스트 `10.0.2.15/24`, ağ_geçidi_değer `10.0.2.2`로 고정돼 있다. QEMU kullanıcı_alanı 네트워크의 konak erişim_girdi 주소를 사용한 예제다. 다른 네트워크 설정에는 맞춰 수정해야 하며 자동 DHCP는 없다. NIC 없이 실행하려면 `make -C os run NET_ARGS='-net none'`을 사용한다. 이때 program_f5044b9b 실행은 되지만 UDP 열기는 `-19`로 실패한다.

## 새 Java program_f5044b9b Ekleme_girdi

`예제/내프로그램.java`를 Sonraki_öğe 형식으로 만든다. 진입점은 bağımsız_değişkenler 없는 `static int` 또는 `static void` 함수다. 인수는 kullanıcı_alanı API로 조회한다.

```java
public final class 내프로그램 {
    public static int çalıştır() {
        kullanıcı_alanı.Yazma("My program is running in user mode.\n");
        return 0;
    }
}
```

`os/kullanıcı_alanı/program_f5044b9b.mk`에 추가한다.

```make
APP_NAMES += mine
APP_SOURCE_mine := kullanıcı_alanı/예제/내프로그램.java
APP_ENTRY_mine := 내프로그램.çalıştır
```

여러 Java 파일을 쓰면 `APP_SOURCE_mine`에 공백으로 모두 나열한다. `kullanıcı_alanı/bildirim/kullanıcı_alanı.java`는 자동으로 함께 컴파일한다.

```sh
cd /home/user/jkoros
make iso
make run
```

새로 부팅한 셸에서 `run mine`을 실행한다. 이미 yürütmek_komut 중인 VM에는 oluştur 결과가 자동 반영되지 않는다. program_f5044b9b 이름은 geçerli_öğe 셸의 ASCII artış_değer 제한에 맞춘 1~15자의 소문자 이름이며 Java Sınıf_değer·işlev_değer·변수에는 한국어를 쓴다. 최대 32개 program_f5044b9b, 한 yürütmek_komut 파일은 최대 2MiB다.

독립 ELF만 컴파일할 수도 있다.

```sh
cd /home/user/jkoros
python3 compiler/derleyici.py --target user --entry 인사.çalıştır \
    -o os/build/apps/hello.elf os/kullanıcı_alanı/bildirim/kullanıcı_alanı.java os/kullanıcı_alanı/예제/인사.java
```

`--target user`는 **jkoros 전용 ABI**다. Linux 대상과 시스템 호출 번호가 다르므로 konak 터미널에서 직접 실행하면 안 된다. `.class`는 별도 `java CLASS` 명령의 Destek_değer klip 안에서 실행한다. `.jar`와 일반 Linux yürütmek_komut 파일은 지원하지 않는다.

## kullanıcı_alanı 네트워크 API

선언은 `bildirim/kullanıcı_alanı.java`에 있다. `göndermek_veri`/`almak_veri`의 `int[]` öğe_öğe 한 개는 bayt_değer 하나(0~255)를 나타낸다. 한 데이터그램의 최대 veri 길이는 1,024바이트다.

```java
int sap_değer = kullanıcı_alanı.açık_ağ(0); // 0: 임시 yerel_Scope UDP taşımak_değer 자동 seçim_değer
int[] veri = new int[32];
veri[0] = 'H'; veri[1] = 'i';
int 보낸길이 = kullanıcı_alanı.göndermek_veri(sap_değer, 0x0a000202, 9000, veri, 2);
int GETİRİ_süre = kullanıcı_alanı.almak_veri(sap_değer, veri, 1500);
kullanıcı_alanı.Kapat_ağ(sap_değer);
```

fiili_veri 프로그램에서는 Aç·göndermek·받기의 Negatif_değer 반환값을 각각 검사한다. 완성된 예제는 `예제/veri_iletişim.java`에 있다. `almak_veri`의 bekle_değer 시간은 0~2,000밀리초이며 0은 즉시 반환이다. 받은 데이터그램이 배열보다 크면 해당 데이터그램을 버리고 `-90`을 반환한다. 창구당 almak_değer 대기열은 한 개뿐이므로 Ekleme_girdi 도착분은 버린다. `보낸주소`와 `보낸창구`로 마지막으로 받은 상대를 조회한다.

| 반환값 | 의미 |
| --- | --- |
| 0 이상 | sap_değer·işlem_değer_girdi süre_değer·성공 등 해당 함수의 sonuç |
| -5 | cihaz_değer göndermek_değer hata_değer |
| -9 | 잘못되었거나 닫힌 iletişim sap_değer |
| -11 | 비차단 받기에서 도착한 veri 없음 |
| -14 | kullanıcı_alanı işaretçi/DİZİ_değer klip hata |
| -19 | Destek_değer NIC 없음 |
| -22 | taşımak_değer/bekle_değer zaman_değeri/bağımsız_değişkenler değer hata |
| -24 | 열린 ağ_taşımak 4개 한도 |
| -38 | 알 수 없는 시스템 호출 |
| -90 | veri 또는 almak_değer DİZİ_değer Boyut 문제 |
| -98 | yerel_Scope taşımak_değer Dizin 중복 |
| -101 | 지원하지 않는 hedef_değer ADRES |
| -110 | ARP·cihaz_değer·almak_değer zaman_değeri 초과 |

IP 주소는 상위 바이트부터 표기한 32비트 값이다. `10.0.2.2`는 `0x0a000202`이다. 주소를 반환하는 함수는 kodlama_değer 있는 Java `int`의 bit_değer 패턴을 사용하므로 상위 비트가 1인 bilgi_teknolojisi_normal IP 주소가 음수로 보일 수 있다. 단순히 모든 API 반환값의 부호를 오류로 판단하면 안 된다.

## yürütmek_komut 경계와 시스템 호출

```text
kabuk run → JKAP에서 ELF doğrulamak_5fb2b747·적재 → ring 3 kullanıcı_alanı program_f5044b9b
                                 ↓ int 0x80
                      işaretçi 검사 → Java çekirdek_değer API → RTL8139/UDP
                                 ↓ Çıkış_program·özel_durum·zaman_değeri 초과
                                kabuk 복귀
```

시스템 호출 레지스터는 `EAX=Dizin`, `EBX,ECX,EDX,ESI,EDI=bağımsız_değişkenler`, `EAX=sonuç`다. Java 호출 işlenen_Yığın ABI는 컴파일러가 kullanıcı_alanı 스텁에서 이 형식으로 바꾼다. C의 POSIX/JNI ABI가 아니다.

| Dizin | 호출 |
| --- | --- |
| 0 | Çıkış_program(Durum_değer KOD_değer) — çalıştır/hata 런타임에서 kullanmak_değer |
| 1 | dize_değer Yazma |
| 2 / 3 | bağımsız_değişkenler öğe_BAĞ_DEĞ_SAY / bağımsız_değişkenler dize_değer ADRES |
| 10 | UDP Aç |
| 11 | UDP göndermek(sap_değer, IP, hedef_değer taşımak_değer, DİZİ_değer ADRES, süre_değer) |
| 12 | UDP almak(sap_değer, DİZİ_değer ADRES, 제한 밀리초) |
| 13 | UDP Kapat |
| 14 | yerel_Scope IP ADRES |
| 15 / 16 | 마지막 eş_değer IP / UDP taşımak_değer |
| 20 | RAM dosya Okuma(İsim int[] ADRES, metinÇıktısı int[] ADRES) |
| 21 | RAM dosya Yazma(İsim int[] ADRES, artış_değer int[] ADRES, bayt_değer süre_değer) |
| 22 | UTF-16 KOD_değer ders_değer 문자 metinÇıktısı(0~65535) |

dosya API는 `kullanıcı_alanı.파일읽기(int[] İsim, int[] veri)`와 `kullanıcı_alanı.yazma_Dosya(int[] İsim, int[] veri, int süre_değer)`다. 이름은 ASCII KOD_değer DİZİ_değer(최대 64칸, 0 Çıkış_program 또는 DİZİ_değer 끝), veri öğe_öğe 하나는 한 바이트다. 반환값은 읽거나 쓴 길이이며 dosya 없음 `-2`, işaretçi hata `-14`, İsim/süre_değer hata `-22`, dosya yuva_değer_ff41a4f1 부족 `-28`, Boyut 초과 `-90`을 반환한다. 쓰기는 doğrulamak_5fb2b747 후 dosya 전체를 대체한다. `kullanıcı_alanı.yazma_karakter_değer(int)`는 문자를 단말에 출력한다. Java 프로그램의 일반 `java.io` 구현은 아니다.

`yürütme_izin()`은 시스템 호출이 아니라 kullanıcı_alanı 모드에서 CS의 하위 비트를 직접 읽으므로 fiili_veri yürütmek_komut 권한을 확인한다. çekirdek_değer donanım_taşımak 접근용 `cihaz_değer` native 함수는 kullanıcı_alanı hedef 컴파일에서 거부한다. ELF에 직접 특권 명령을 넣더라도 CPU가 차단한다.

## 범위와 제한

- 한 번에 한 프로그램만 실행하며 완료 후 셸로 돌아온다. 백그라운드 yürütmek_komut, 파이프, 프로세스 간 통신은 없다. yürütmek_komut 파일은 커널의 Okuma 전용 JKAP 묶음에서 적재한다. veri 파일에는 주기억 파일체계와 전용 IDE 보존 형식이 있다.
- kullanıcı_alanı 가상 ADRES `0x04000000..0x043fffff`를 물리 8~12MiB에 연결한다. yürütmek_komut 영상은 ön_kamera_değer 2MiB, 인수는 `0x04300000`부터, 스택은 bölge_değer 끝에서 시작한다. çekirdek_değer identity 페이지는 supervisor 전용이다.
- 실행마다 4MiB kullanıcı_alanı 영역을 비우고 dosya 구역을 복사해 BSS·DİZİ_değer 영역을 초기화한다. kullanıcı_alanı GC는 없지만 Çıkış_program 후 Sonraki_öğe yürütmek_komut 때 영역을 재사용한다. 인수는 공백으로 분리한 최대 16개이며 Alıntı/이스케이프 파싱은 없다.
- kullanıcı_alanı 페이지의 KOD_değer/veri 분리 Okuma 전용 Ayarlar, NX, işlenen_Yığın guard, ASLR은 아직 없다. 커널과 kullanıcı_alanı Bellek_veri·donanım_taşımak izin_değer 경계를 구현한 초기판이지 보안 인증된 샌드박스는 아니다.
- PIT 100Hz로 약 3초 yürütmek_komut 상한을 두며 zaman_değeri 초과는 `Exit: 124`다. kullanıcı_alanı CPU 예외는 `128 + özel_durum Dizin`(페이지 hata 142, 특권 위반 141), Java DİZİ_değer/계산 오류는 101~105다. çekirdek_değer 오류까지 복구하는 구조는 아니다.
- 네트워크는 PCI bus 0/function 0의 RTL8139, statik_değer IPv4, ARP, UDP만 지원한다. NIC는 폴링하고 송신은 동기식이다. IPv4 단편 재조립·TCP·DNS·DHCP·IPv6·HTTP·TLS·일반 `java.net`은 미지원이다. IPv4 UDP sağlama_toplamı 0은 규약에 따라 허용하고, 그 외 UDP/IP 검사합과 길이는 검증한다.
- kullanıcı_alanı yürütmek_komut·네트워크·korumak_değer sınır_değer 전체 시험은 QEMU에서 수행했다. VirtualBox에서도 `make vbox`로 부팅과 `run hello vbox`의 ring 3 yürütmek_komut·bilgi_teknolojisi_normal 종료를 확인했다. VirtualBox PCnet/E1000용 드라이버는 없어 그 환경의 네트워크는 지원하지 않는다.

## doğrulamak_5fb2b747 근거

`make test`는 derleyici 14개 sınamalar, Java 패킷 koşul 2,201개 검사, 기존 kabuk ELF/ISO makine_başlatma sınamalar, kullanıcı_alanı ELF/fiili_veri UDP/korumak_değer sınır_değer 시험을 실행한다. 네트워크 시험은 루프백 서버가 받은 자료의 süre_değer·해시까지 `os/build/test_kullanıcı_ağ.json`에 기록한다. 시험용 손상된 ELF·특권 komut·무한 öğe_değer_58902391 프로그램은 임시 묶음에만 넣으며 배포용 `apps` 목록에는 넣지 않는다.
