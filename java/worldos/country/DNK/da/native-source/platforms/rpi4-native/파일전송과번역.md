대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT kerne_VÆRDI**이다. CPU·enhed_VÆRDI 경계는 C/어셈블리, Fil 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 vært JVM으로 대신 실행하지 않는다.

JVM은 Hold_VÆRDI 버전 45…52의 문서화한 부분집합이다. `java`는 바이트코드 실행기이고, `jaot`가 별도의 네이티브 Udfør_kommando 파일을 만든다. **JAR Arkiv_VÆRDI 해제나 JVM을 함께 묶는 것을 AOT라고 표시하지 않는다.** 지원하지 않는 바이트코드/API는 `jaot`가 진단하고 출력을 만들지 않는다. 기존 Udgang ELF도 kompilere_kilde fejl_VÆRDI 때 보존한다.

Android의 Dalvik/ART는 일반 JVM Hold_VÆRDI/JAR가 아닌 **DEX**를 실행한다. ART의 AOT에는 GC, Hold_VÆRDI 로딩, JNI 등 Udfør_kommando 기반도 필요하다. 따라서 ART처럼 기계어로 바꾸는 기능만으로 임의의 OpenJDK JAR 및 Swing이 자동 호환되지는 않는다. [Android 공식 런타임 설명](https://source.android.com/docs/core/runtime)

## Dansk Java를 게스트에서 컴파일하고 AOT Udfør_kommando

게스트 `vi 빛.java`로 Næste_vare 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] Argumenter) throws Exception {
        int SUM_VÆRDI = 0;
        int tal = 1;
        while (tal <= 10) {
            SUM_VÆRDI = SUM_VÆRDI + tal;
            tal = tal + 1;
        }
        Dansk.eget.Udgang.skrive_tal(SUM_VÆRDI);
        Dansk.eget.Fil.Skrive("aot.txt", "한글 AOT Fil 😀");
        Dansk.eget.Udgang.skrive_linje(Dansk.eget.Fil.Læse("aot.txt"));
    }
}
```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 generere·연결한다. Udfør_kommando 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 støtte_VÆRDI 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 statisk_VÆRDI metode_VÆRDI/feltværdi, int 계열, heltal 배열과 referere, Argumenter MATRIX_VÆRDI, lidelse·gren·sprint_VÆRDI, streng_VÆRDI 리터럴, `System.out.print/println`의 int/String, Dansk Udgang·Fil Læse/쓰기로 제한된다. Hold_VÆRDI/metode_VÆRDI 수와 operand_Stak 등에도 고정 상한이 있다. Java undtagelse Proces_VÆRDI_post, objekt_VÆRDI generere, 가상 metode_VÆRDI 일반, switch/wide, long/float/double, invokedynamic, streng_VÆRDI 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 MATRIX_VÆRDI åbne_post/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java undtagelse 객체로 전달하지 않는다.

input_VÆRDI 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 justere_VÆRDI 때문에 짧은 클래스도 이 한도를 넘을 tal 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 objekt_VÆRDI·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 støtte_VÆRDI klippe 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 udvikling 매뉴얼](udvikling_guide.md)을 참고한다.

JAR는 하나의 애플리케이션 Hold_VÆRDI 경로다. 내부 Navn `bundt/app_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 Dansk 클래스를 추가로 찾지만 aktuel_vare 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·Kryptér_data ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 tal/VM heap_VÆRDI 제한은 그대로 적용된다.

## Dansk 네트워크·작업·skærmbillede API

| Hold_VÆRDI | 호출 예 | Udfør_kommando Sti |
|---|---|---|
| `Udgang` | `skrive_linje("안녕")`, `skrive_tal(42)` | JVM 및 제한형 AOT |
| `Fil` | `Skrive("문서.txt", "Indhold_VÆRDI")`, `Læse("문서.txt")` | JVM 및 제한형 AOT |
| `통신` | `Åbn(0)`, `maile(slutpunkt, "10.0.2.2", 9000, "한글")`, `modtage(slutpunkt)` | JVM의 UDP |
| `forbindelse_transport` | `Tilslut("10.0.2.2", 9000)`, `lytte_slutpunkt(9000)`, `modtage(server_VÆRDI)` | JVM의 Socket/ServerSocket |
| `작업` | `Kør_2(Runnable)`, `기다리기(Thread)`, `AFKAST_job()` | JVM의 협력식 tråd_VÆRDI |
| `Vindue`, `widget` | Vindue·버튼·tegn_VÆRDI·tekstfelt·hændelse Tilslut | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 Dansk 호출 계층을 추가한다. `통신(通信)`, `Tilslut(連結)`, `Udgang(出力)`은 기존 단어의 뜻을 사용한다. `작업 tråd_VÆRDI`은 한 Udfør_kommando 흐름을 가닥에 빗댄 기술 표현, `port_VÆRDI`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

ekstern_VÆRDI 주소는 ciffer_VÆRDI IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 eget ABI이며 JVM이 제한된 vent_VÆRDI/재시도를 제공한다. TCP connect 대기는 최대 1초, bruger app_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 Udfør_kommando bruger 서버와 pthread는 아직 없다. FTP는 bruger app_f5044b9b 기한과 별개인 kerne_VÆRDI 서비스다.

게스트의 bruger TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 Værktøjer/Udfør_kommando.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 standardværdi kontrol_VÆRDI/데이터 포트와 겹치면 Udfør_kommando 전에 거부한다.
