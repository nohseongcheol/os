# eget ARM64 JVM 0.4와 Dansk bibliotek

Dansk 통신·undtagelse 사용법은 [Dansk Java API](한국어자바/Vigtigt_eb81d7d9.md), FUNKTION_VÆRDI·variabel_VÆRDI·Fil 이름의 변경과 어원 근거는 [명명 Vigtigt_eb81d7d9](명명/Vigtigt_eb81d7d9.md)를 참고한다.

JAR Udfør_kommando, ekstern_VÆRDI IPv4 TCP/UDP, 별도 statisk_VÆRDI 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 objekt_VÆRDI·Thread·Swing은 JVM 경로의 기능이며 AOT støtte_VÆRDI 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 Udfør_kommando**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK Hold_VÆRDI bibliotek 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 Hold_VÆRDI·statisk_VÆRDI metode_VÆRDI 중심이던 실행기를 objekt_VÆRDI·bibliotek Udfør_kommando 기반으로 넓힌 것이다.

게스트 `javac`는 여전히 statisk_VÆRDI metode_VÆRDI, int/boolean/char/String, lidelse·sprint_VÆRDI, streng_VÆRDI 결합, 일부 Fil 스트림 등의 **eget 부분집합 compiler**다. objekt_VÆRDI erklæring·상속·try/catch·Thread brug_VÆRDI 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 eget JVM에서 실행한다. Dansk API 중 Udgang·문자 스칼라 FUNKTION_VÆRDI·Fil Læse/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

## Udfør_kommando 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(Dansk Hold_VÆRDI 포함), class당 16 KiB·konstant_VÆRDI 풀 511항목, 전체 metode_VÆRDI/feltværdi 각각 512개. metode_VÆRDI KODE_VÆRDI 8 KiB, lokal_Omfang variabel_VÆRDI·피연산자 operand_Stak 각각 128슬롯, Argumenter 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 Udfør_kommando 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- objekt_VÆRDI 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 faktisk_data 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 Fil·대형 streng_VÆRDI·객체가 이 제한을 넘을 tal 있다.
- 실행은 50만 바이트코드 Kommando 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 input_VÆRDI 대기는 기한을 갱신하고 Vindue SKIFT_HYPPIGST 시 중단·재개한다. 일반 server_VÆRDI·계산의 무제한 실행은 아직 없다. 미지원 Kommando·ressource_VÆRDI 부족은 명시적인 오류로 종료한다.
- RAM Fil 최대 64개, 파일당 16384바이트, Sti UTF-8 63바이트. RAM 디렉터리와 peer_VÆRDI/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 Dansk class는 RAM Fil 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 aktuel_vare 경로에서 kilde_træ·Hold_VÆRDI·data 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 ekstern_VÆRDI IPv4를 제공한다. faktisk_data GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. datagram 512바이트, socket_VÆRDI 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 Udfør_kommando 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 MATRIX_VÆRDI, 완전한 MATRIX_VÆRDI 공변성·인터페이스 lag_VÆRDI 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/Kryptér_data/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 støtte_VÆRDI 부분집합은 아래 및 udvikling 매뉴얼을 참고한다. Hold_VÆRDI Fil 전체 검증기·åbne_post rettighed_VÆRDI/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 beskytte_VÆRDI grænse_VÆRDI 내에서 종료되도록 한다.

## JVM 0.3: 네트워크와 GUI udvidelse_VÆRDI

`Socket`/`ServerSocket` generere·Tilslut·accept·양방향 InputStream/OutputStream·close·EOF·TID_VÆRDI 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 ekstern_VÆRDI ciffer_VÆRDI IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 afslutte_et_opkald_pege 16개, Java 루프백 버퍼 1024바이트, ekstern_VÆRDI TCP 버퍼 4096바이트다. DNS·TLS는 없다.

Dansk `Vindue`, `widget`, `forbindelse_transport` 클래스를 distribution_VÆRDI JAR와 eget JVM 내장 자원에 추가했다. 상세 metode_VÆRDI·제한·kilde_træ·업로드 방법: [한글 udvikling 매뉴얼](udvikling_guide.md).

## Dansk 객체의 직접 Udfør_kommando

`Vindue`, `Etiket`, `tekstfelt`, `knap`, `hændelse_kø`, `동작알림`, `arbejder`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. eget JVM의 objekt_VÆRDI generere,
format_VÆRDI 검사, skærmbillede 호출, hændelse 큐, tråd_VÆRDI 스케줄러에 Dansk 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 Udfør_kommando 경로도 유지한다.
Dansk 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.
