# jkoros العربية مكتبة مستخدم_دليل

확인일: 2026-09-27. 대상은 `platforms/rpi4`의 **ARM64 Linux + OpenJDK 실행판**이며, QEMU에서도 같은 Java 라이브러리를 사용한다. `os/`의 ذاتي x86 نواة_قيمة 및 `قديم_مصدر/`의 관리 نواة_قيمة 모형과 구분한다.

## 1. حديث_عنصر 제공하는 مكتبة

패키지는 `العربية.자바`, نظام_تشغيل 안의 JAR 경로는 `/opt/jkoros/lib/한국어자바.jar`다. **مساعد_قيمة فئة_قيمة_55654bf1 5개, 공개 ثابت_قيمة_f430d3f5 أسلوب_قيمة 22개, 별도 GUI 프로그램인 مساحة_عمل 1개**가 있다. JAR는 Java 11 이상을 대상으로 빌드하며 حديث_عنصر ARM64 배포판에는 OpenJDK 25가 포함돼 있다.

| فئة_قيمة_55654bf1 | أسلوب_قيمة رقم | 기능 | مصدر |
|---|---:|---|---|
| `ملف` | 9 | UTF-8 텍스트·بايت_قيمة ملف, دليل_قيمة, إدخال_قائمة_f07b3200 | [ملف.java](مصدر/العربية/자바/ملف.java) |
| `문자` | 5 | UTF-8 تحويل_قيمة, NFC يقلل_التكرار_قيمة, رمز_قيمة_f3cd31ee 포인트, سلسلة_قيمة 경계 | [문자.java](مصدر/العربية/자바/문자.java) |
| `통신` | 2 | HTTP(S) GET, TCP اتصال | [통신.java](مصدر/العربية/자바/통신.java) |
| `작업` | 4 | 스레드 ينفذ_أمر·انتظر_قيمة, 고정 حجم 작업 تطبيق_مشغّل | [작업.java](مصدر/العربية/자바/작업.java) |
| `화면` | 2 | Swing 이벤트 عملية_قيمة_إدخال 가닥에 작업 예약, نافذة إنشاء | [화면.java](مصدر/العربية/자바/화면.java) |
| `مساحة_عمل` | نقطة_الإدخال `main` | Java مصدر يحرر_قيمة·مخزن_قيمة·يحول_برمجياً_مصدر·ينفذ_أمر | [مساحة_عمل.java](مصدر/العربية/자바/مساحة_عمل.java) |

표준 JDK 전체를 한국어로 번역한 라이브러리는 아니다. Java 키워드와 `String`, `Path`, `Socket`, `JFrame`, `IOException` 같은 표준 نوع_البيانات·예외를 함께 사용한다. 이 도우미에 없는 기능은 OpenJDK의 표준 API 또는 별도 라이브러리로 구현한다. 예를 들어 HTTP POST, UDP, Swing زر·메뉴에는 각각 표준 Java API를 사용한다.

## 2. Java에서 بدء_مهمة

게스트 운영체제의 작업 폴더에서 `사용예.java`를 작성한다.

```java
import العربية.자바.*;
import java.nio.file.Path;

public class 사용예 {
    public static void main(String[] وسائط) throws Exception {
        Path دليل_قيمة = ملف.فتح_دليل(ملف.مسار("사용예자료"));
        Path 문서 = دليل_قيمة.resolve("인사.txt");
        ملف.كتابة(문서, "한글 😀");
        String محتوى_قيمة = ملف.قراءة(문서);
        System.out.println(محتوى_قيمة);
        System.out.println(문자.코드포인트수(محتوى_قيمة)); // 한, نص, 공백, 😀 → 4
        Thread عمل_قيمة = 작업.تشغيل("인사 작업", () -> System.out.println("작업 ينفذ_أمر"));
        작업.기다리기(عمل_قيمة);
    }
}
```

```sh
javac -encoding UTF-8 -cp /opt/jkoros/lib/한국어자바.jar 사용예.java
java -cp .:/opt/jkoros/lib/한국어자바.jar 사용예
```

로그인 환경에 قيمة_افتراضية `CLASSPATH`도 설정돼 있지만, 명시적인 `-cp`는 다른 ينفذ_أمر 환경에서도 경로를 분명하게 한다. 사용자가 `-cp`를 지정하면 필요한 JAR와 فئة_قيمة_55654bf1 폴더를 모두 그 값에 포함해야 한다.

مضيف 저장소에서는 다음처럼 بنية_نظام·실행한다. مضيف 경로와 게스트의 `/opt/...` 경로는 서로 다르다.

```sh
cd /home/user/jkoros/한국어자바
make
javac -encoding UTF-8 -cp build/한국어자바.jar 예제/인사.java
java -cp build/한국어자바.jar:예제 인사
```

## 3. 전체 مساعد_قيمة API

아래 메서드는 모두 `public static`이며, 객체를 만들지 않고 `ملف.قراءة(...)`처럼 호출한다. 표의 이름은 الفعلي_بيانات مصدر_شجرة 및 JAR의 `javap -public` 결과와 대조했다. 선언된 검사 استثناء 외에도 잘못된 وسائط 등에 대한 표준 Java ينفذ_أمر 시 예외가 발생할 رقم 있다.

### ملف: `العربية.자바.ملف`

`Path`는 `java.nio.file.Path`, `List`는 `java.util.List`다.

| أسلوب_قيمة | إرجاع_نوع | إجراء·شرط |
|---|---|---|
| `مسار(String اسم)` | `Path` | 이름을 مسار 객체로 تحويل_قيمة. الفعلي_بيانات 파일을 만들지는 않음 |
| `قراءة(Path مسار)` | `String` | ملف 전체를 UTF-8 텍스트로 يقرأ_مقياس |
| `كتابة(Path مسار, String محتوى_قيمة)` | `Path` | UTF-8 مخزن_قيمة. 파일이 없으면 생성하고, 있으면 기존 내용을 비움 |
| `يقرأ_بايت_قيمة(Path مسار)` | `byte[]` | ملف 전체를 بايت_قيمة 배열로 يقرأ_مقياس |
| `كتابة_بايت_قيمة(Path مسار, byte[] محتوى_قيمة)` | `Path` | بايت_قيمة مخزن_قيمة. 없으면 생성하고, 있으면 기존 내용을 비움 |
| `فتح_دليل(Path مسار)` | `Path` | 필요한 상위 폴더까지 إنشاء |
| `있는가(Path مسار)` | `boolean` | 존재 여부 يتحقق. 확인할 رقم 없는 경우도 `false`عمل_قيمة رقم 있음 |
| `مسح_إدخال(Path مسار)` | `boolean` | 삭제했으면 `true`, 없으면 `false`. 폴더의 재귀 삭제는 아님 |
| `إدخال_قائمة_f07b3200(Path مسار)` | `List<Path>` | 바로 아래 항목을 مسار يحاذي_قيمة 순서로 إرجاع_مقياس. 재귀 탐색은 아님 |

`مسار`, `있는가`를 제외한 위 메서드는 `IOException`을 선언한다. `كتابة`와 `كتابة_بايت_قيمة`는 상위 폴더를 자동으로 만들거나 내용을 이어 쓰지 않는다. 필요한 폴더는 먼저 생성한다. 큰 파일은 전체 내용을 메모리에 담는 대신 표준 Java 스트림·قناة_قيمة API를 사용하는 방식으로 작성할 رقم 있다.

### 문자: `العربية.자바.문자`

| أسلوب_قيمة | إرجاع_نوع | إجراء·شرط |
|---|---|---|
| `يرمّز(String محتوى_قيمة)` | `byte[]` | 문자열을 UTF-8 바이트로 تحويل_قيمة |
| `يفك_التشفير_بيانات(byte[] محتوى_قيمة)` | `String` | UTF-8 바이트를 문자열로 تحويل_قيمة. 잘못된 입력은 대체 문자로 عملية_قيمة_إدخال |
| `يقلل_التكرار_قيمة(String محتوى_قيمة)` | `String` | 유니코드 NFC يقلل_التكرار_قيمة. 예: تركيب_قيمة 자모 `ᄀ` + `ᅡ` → `가` |
| `코드포인트수(String محتوى_قيمة)` | `int` | UTF-16 رمز_قيمة_f3cd31ee 단위가 아닌 유니코드 رمز_قيمة_f3cd31ee 포인트 رقم |
| `낱말(String محتوى_قيمة, Locale لغة)` | `List<String>` | تعيين_قيمة 언어의 `BreakIterator` 낱말 경계로 나눈 نص_نطاق |

`낱말`은 공백·문장부호 구간도 반환한다. 자연어 형태소 분석기나 공백을 제거한 الكلمات_قيمة إدخال_قائمة_f07b3200 API는 아니다. `يقلل_التكرار_قيمة`는 입력기나 تحويل_مصدر 기능이 아니다. رمز_قيمة_f3cd31ee 포인트 رقم 역시 사람이 보는 حرف_قيمة 수와 항상 같지는 않다. 여러 رمز_قيمة_f3cd31ee 포인트로 이루어진 결합 문자·가족 이모지 등을 구분해야 한다.

### 통신: `العربية.자바.통신`

| أسلوب_قيمة | إرجاع_نوع | إجراء·شرط |
|---|---|---|
| `가져오기(URI عنوان, Duration الحد_الزمني)` | `HttpResponse<String>` | HTTP(S) GET. اتصال 및 طلب الحد_الزمني إعدادات. رد 본문을 UTF-8로 يوزّع_قيمة |
| `يتصل_المشارك(String عنوان, int أجهزة_منفذ, int 제한밀리초)` | `Socket` | TCP اتصال 후 같은 값으로 قراءة 제한시간도 إعدادات |

`가져오기`는 `IOException`, `InterruptedException`을 선언한다. 제한시간은 양수다. 404·500 같은 HTTP خطأ 상태도 응답으로 반환하므로 `statusCode()`로 판단하고 `body()`로 본문을 읽는다. حديث_عنصر 구현은 호출마다 HTTP 클라이언트를 만들며 자동 리다이렉트 설정을 추가하지 않는다.

`يتصل_المشارك`는 `IOException`을 선언한다. 연결된 소켓은 호출자가 `close()` 또는 try-with-resources로 닫아야 한다. 제한밀리초의 0은 제한 없음이며, كتابة 전체의 موعد_نهائي_قيمة 시간을 보장하는 옵션은 아니다.

```java
var رد = 통신.가져오기(
    java.net.URI.create("http://127.0.0.1:8000/"),
    java.time.Duration.ofSeconds(5));
System.out.println(رد.statusCode());
System.out.println(رد.body());
```

위 조각은 أسلوب_قيمة 안에서 실행하며 별도로 해당 주소의 서버를 실행해야 한다. Java استثناء 처리가 필요하다.

### 작업: `العربية.자바.작업`

| أسلوب_قيمة | إرجاع_نوع | إجراء·شرط |
|---|---|---|
| `تشغيل(String اسم, Runnable إجراء)` | `Thread` | 이름을 지정한 스레드를 만들고 즉시 تشغيل |
| `기다리기(Thread محادثة_قيمة)` | `void` | 해당 스레드가 종료할 때까지 `join()` |
| `쉬기(long 밀리초)` | `void` | 호출한 스레드를 تعيين_قيمة قيمة_الوقت 동안 `sleep()` |
| `작업대(int عدد_العمليات_الجزئية)` | `ExecutorService` | 고정 حجم 작업 تطبيق_مشغّل إنشاء. 가닥수는 양수 |

`기다리기`, `쉬기`는 `InterruptedException`을 선언한다. 작업 실행기는 يستخدم_قيمة 후 `shutdown()`으로 종료하고 필요하면 `awaitTermination(...)`으로 완료를 기다린다. Swing 이벤트 عملية_قيمة_إدخال 가닥에서 긴 작업이나 `기다리기`를 실행하면 화면이 멈출 رقم 있다.

### 화면: `العربية.자바.화면`

| أسلوب_قيمة | إرجاع_نوع | إجراء·شرط |
|---|---|---|
| `나중에(Runnable إجراء)` | `void` | Swing 이벤트 عملية_قيمة_إدخال 가닥에 실행을 예약하고 إرجاع_مقياس |
| `نافذة(String نافذة_عنوان, JComponent محتوى_قيمة, int 너비, int ارتفاع_قيمة)` | `JFrame` | محتوى_قيمة·크기를 지정한 창을 생성해 عرض_قيمة_487749b8 |

`نافذة`을 Swing 이벤트 عملية_قيمة_إدخال محادثة_قيمة 밖에서 부르면 `IllegalStateException`이 발생한다. 그래픽 세션도 필요하다. QEMU에서는 VNC 데스크톱의 터미널에서 실행한다.

```java
화면.나중에(() -> 화면.نافذة(
    "العربية 화면", new javax.swing.JLabel("안녕하세요"), 500, 180));
```

반환된 `JFrame`에 표준 Swing API를 추가로 사용할 رقم 있다. 창의 إغلاق 동작은 `DISPOSE_ON_CLOSE`다. `화면.나중에`가 반환됐다고 نافذة 생성이 이미 끝난 것은 아니다.

### مساحة_عمل: يحرر_قيمة·يحول_برمجياً_مصدر GUI

```sh
java -cp /opt/jkoros/lib/한국어자바.jar العربية.자바.مساحة_عمل
```

`~/workspace`의 원문을 فتح·저장하고, `javac`로 컴파일해 `java`로 실행한다. ينفذ_أمر ملف 만들기는 `jclassc --target openjdk` 경로를 사용한다. 작업마당은 개발용 프로그램이며 별도의 ملف·문자 API 클래스가 아니다. 생성하는 ينفذ_أمر ملف 방식은 [محول_برمجي 설명](../compiler/OpenJDK-실행파일.md)을 따른다.

## 4. Python과 C++에서 사용할 رقم 있는가?

| أسلوب_الوضع | حديث_عنصر تصريحات حالة_قيمة | 호출 가능 يقص |
|---|---|---|
| Java → العربية JAR | قيمة_افتراضية تصريحات | 위 22개 메서드와 مساحة_عمل |
| Python → `java` طفل_قيمة 프로세스 | Python·Java قيمة_افتراضية تصريحات | 작은 Java 진입점을 통해 호출하고 표준 مخرجات·ملف 등으로 نتيجة تحويل_قيمة_24592b8a |
| Python → JPype → JVM | JPype는 قيمة_افتراضية 배포에 없음 | 별도 تثبيت_قيمة 후 Java فئة_قيمة_55654bf1·أسلوب_قيمة 호출 가능. 이 배포판의 ARM64/musl/Python 3.14 조합은 إلحاق_إدخال التحقق_من_صحة 필요 |
| C++ → JNI → JVM | `g++`, JNI 헤더, `libjvm.so` تصريحات | JVM을 생성하고 العربية فئة_قيمة_55654bf1·메서드를 직접 호출할 رقم 있음 |
| Python용 독립 العربية مكتبة | حديث_عنصر قيمة_افتراضية 제공 없음 | 필요하면 Python 표준 라이브러리를 감싸는 العربية 모듈을 별도로 작성 |
| C/C++용 독립 العربية مكتبة | ذاتي x86 `posix-kor`와 ذاتي ARM64 커널용 حالة_أولية RAM ملف 연결이 별도로 존재 | 둘 다 이 Linux/OpenJDK 실행판의 libc 라이브러리는 아님 |

Python의 일반 `import`나 `ctypes.CDLL`로 JAR를 바로 읽을 수는 없다. C++의 `#include`나 일반 네이티브 링커만으로 Java 메서드를 연결할 수도 없다. JVM 프로세스 또는 JVM اتصال 계층을 거쳐야 한다.

### Python: إلحاق_إدخال 패키지 없이 호출

ينفذ_أمر 가능한 예제 원문은 [문자명령.java](예제/다른언어/문자명령.java), [파이썬호출.py](예제/다른언어/파이썬호출.py)다. Python이 Java 진입점을 실행하고 `문자.코드포인트수`의 عدد_صحيح 결과를 받는다. وسائط 목록을 사용하며 셸 أمر 문자열을 조립하지 않는다. `subprocess.run`의 프로세스 ينفذ_أمر·خروج_تطبيق رمز_قيمة_f3cd31ee·مخرجات عملية_قيمة_إدخال 방식은 [Python 공식 문서](https://docs.python.org/3/library/subprocess.html)를 따른다.

두 예제 파일을 게스트의 같은 폴더에 복사한 عودة_قيمة 그 폴더에서 실행한다. 예제 ملف 자체는 قيمة_افتراضية 시스템 이미지에 자동 설치돼 있지 않다.

```sh
mkdir -p classes
javac -encoding UTF-8 -cp /opt/jkoros/lib/한국어자바.jar -d classes 문자명령.java
python3 파이썬호출.py --text '한글 😀'
```

مخرجات: `Python → العربية.자바.문자.코드포인트수: 4`

이 예제의 Python دالة_قيمة `코드포인트수`는 이번 문서의 اتصال 예제이며 기존에 설치된 Python 라이브러리는 아니다. حديث_عنصر 예제는 호출할 때마다 JVM 프로세스를 시작한다. Java عنصر_قيمة_2ed200e9 자체를 Python으로 가져오는 방식은 아니며, 다른 메서드를 사용하려면 진입점의 وسائط·نتيجة 형식을 확장한다.

### Python: JPype로 같은 프로세스에서 호출

JPype를 별도 설치한 환경에서는 التالي_عنصر 형태로 연결할 رقم 있다. **아래는 تحديد_قيمة 가능한 اتصال 방법이며, حديث_عنصر 배포판에 JPype가 설치돼 있거나 ينفذ_أمر 검증됐다는 뜻은 아니다.** JVM 시작과 `JClass`를 통한 فئة_قيمة_55654bf1 접근은 [JPype 공식 설명](https://jpype.readthedocs.io/en/latest/userguide.html)을 참고한다.

```python
import jpype

jpype.startJVM(
    "/usr/lib/jvm/java-25-openjdk/lib/server/libjvm.so",
    classpath=["/opt/jkoros/lib/한국어자바.jar"])
try:
    문자 = jpype.JClass("العربية.자바.문자")
    print(문자.코드포인트수(jpype.JString("한글 😀")))
finally:
    jpype.shutdownJVM()
```

Python·JVM·اتصال 모듈의 CPU 아키텍처가 맞아야 한다. 이 실행판은 ARM64 + musl이므로 일반 x86_64/glibc용 바이너리를 그대로 설치하는 방식은 맞지 않는다. JPype تثبيت_قيمة·패키지 빌드는 이번 문서 작업에서 수행하지 않았다.

### C++: JNI로 직접 호출

[자바호출.cpp](예제/다른언어/자바호출.cpp)는 الفعلي_بيانات ينفذ_أمر 가능한 예제다. JVM을 작업 스레드에서 생성하고 التالي_عنصر 메서드를 찾는다.

```cpp
jclass type = env->FindClass("العربية/자바/문자");
jmethodID method = env->GetStaticMethodID(
    type, "코드포인트수", "(Ljava/lang/String;)I");
```

JVM إنشاء·종료와 스레드 연결은 [JNI Invocation API](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/invocation.html)의 방식이다. `JNIEnv*`는 إنشاء·연결된 스레드에서 사용해야 한다. 예제는 Java 예외를 확인하고 JVM 종료까지 처리한다.

게스트에 `자바호출.cpp`를 복사한 عودة_قيمة 컴파일한다. 로그인 환경의 `JAVA_HOME`은 `/usr/lib/jvm/java-25-openjdk`다.

```sh
g++ -std=c++11 -Wall -Wextra -pthread \
  -I"$JAVA_HOME/include" -I"$JAVA_HOME/include/linux" \
  자바호출.cpp -L"$JAVA_HOME/lib/server" \
  -Wl,-rpath,"$JAVA_HOME/lib/server" -ljvm -o 자바호출
./자바호출 /opt/jkoros/lib/한국어자바.jar
```

مخرجات: `C++ → العربية.자바.문자.코드포인트수: 4`

예제는 `한글 😀`을 UTF-16으로 만들어 `NewString`에 전달한다. `NewStringUTF`가 받는 modified UTF-8은 일반 UTF-8과 차이가 있으므로, 일반 UTF-8 이모지 바이트를 그대로 넘기는 예제로 작성하지 않았다. [JNI سلسلة_قيمة ينسق_قيمة](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/types.html#modified-utf-8-strings)

다른 العربية 메서드도 JNI 서명과 وسائط 자료형을 맞춰 호출할 رقم 있다. 예를 들어 `Path`를 받는 ملف API는 먼저 `ملف.مسار`로 Java مسار 객체를 얻어 전달한다. Swing 호출에는 그래픽 세션과 이벤트 عملية_قيمة_إدخال محادثة_قيمة 규칙도 그대로 적용된다. JNI는 Java 실행을 기계어로 대체하는 기능이 아니며 JVM이 계속 필요하다.

### 기존 posix-kor와의 관계

추가된 [ذاتي ARM64 اتصال](../posix-kor/arm64-native/안내.md)은 C++에서 AOT Java 커널의 RAM ملف API를 직접 호출하며, 별도 EL0 فضاء_المستخدم 라이브러리로 ملف/UDP 루프백 SVC 호출도 제공한다. JNI를 사용하지 않는다. 이 문서의 ARM64 **Linux** 및 العربية Java JAR와는 다른 ينفذ_أمر 기반이며 ذاتي 커널은 별도 제한형 Java محول_برمجي/JVM과 MicroPython 1.24.1을 실행한다. MicroPython의 `import jkoros`로 Java نواة_قيمة ملف·UDP 루프백·مستطيل 호출이 가능하지만 이 문서의 JAR를 가져오는 기능은 아니다. ذاتي 커널의 전체 OpenJDK/JRE/CPython 이식은 아직 미완성이다.

[posix-kor](../posix-kor/안내.md)에는 `فتح_ملف`, `يقرأ_ملف_بيانات`, `كتابة_ملف_بيانات`, `يغلق_ملف`, `فتح_المشارك`, `يرسل_مخطط_بيانات_بيانات` 등의 العربية C 별칭이 있다. 그러나 구현은 **ذاتي jkoros i386 커널의 `int 0x80` 호출 규약용**이다.

이 `libposix-kor.a`와 ذاتي `sys/stat.h` 등의 헤더는 حديث_عنصر ARM64 Linux 실행판의 libc/C++용 라이브러리가 아니다. 해당 헤더·바이너리를 ARM64 Linux 프로그램에 그대로 연결해서는 ABI가 맞지 않는다. C++용 العربية فئة_قيمة_55654bf1 라이브러리나 Python용 바인딩을 قيمة_افتراضية 제공하는 상태도 아니다. حديث_عنصر Linux 실행판에서 그와 같은 독립 API를 제공하려면 Linux 표준 라이브러리를 대상으로 별도로 구현·빌드해야 한다.

## 5. يتحقق 범위와 재현

패키지 تصريحات 여부는 [توزيع_قيمة 패키지 إدخال_قائمة_f07b3200](../platforms/rpi4/dist/packages.lock.json) 및 بنية_نظام 루트의 الفعلي_بيانات 파일로 확인했다. JNI 헤더는 JDK의 `include/jni.h`, `include/linux/jni_md.h`, JVM 라이브러리는 `lib/server/libjvm.so`에 있다. 사용자가 이후 별도로 설치한 패키지는 이 قيمة_افتراضية توزيع_قيمة 목록과 다를 رقم 있다.

이번에 **مضيف x86_64/OpenJDK 11에서** Python طفل_قيمة 프로세스 호출과 C++ JNI 직접 호출을 يحول_برمجياً_مصدر·실행해 각각 نتيجة 4를 확인했다. JAR 공개 메서드도 소스와 대조했다. Python اتصال 예제는 إلحاق_إدخال 패키지를 설치하지 않는다.

문서의 Java يستخدم_قيمة 예제도 يحول_برمجياً_مصدر·실행했고, 22개 메서드의 문서 تصريحات 여부와 로컬 문서 링크를 확인했다. [예제 التحقق_من_صحة سجل_سجل](build/다른언어/التحقق_من_صحة_إبلاغ.json)

기존 ARM64 QEMU에서는 Java의 ملف·유니코드·스레드·HTTP 및 Swing اختبارات 결과가 있다. 이번 Python/C++ اتصال 예제의 **ARM64 게스트 실행과 JPype 설치는 별도 검증하지 않았다.** 이미지와 ينفذ_أمر 중인 فضاء_المستخدم 환경은 이 문서 작업에서 변경하지 않았다. [기존 نظام_تشغيل التحقق_من_صحة سجل_سجل](../platforms/rpi4/VERIFICATION.md)

호스트에서 Python 예제를 재현하려면:

```sh
cd /home/user/jkoros/한국어자바
make
mkdir -p build/다른언어
javac -encoding UTF-8 --release 11 -cp build/한국어자바.jar \
  -d build/다른언어 예제/다른언어/문자명령.java
python3 예제/다른언어/파이썬호출.py \
  --jar build/한국어자바.jar --classes build/다른언어
```

مضيف C++ 예제는 위 JNI يحول_برمجياً_مصدر 명령의 JDK 경로를 **مضيف JDK مسار**로 바꾸고, مصدر `예제/다른언어/자바호출.cpp`와 JAR `build/한국어자바.jar`를 지정한다. ARM64 게스트 JDK의 헤더·مكتبة 경로를 مضيف x86_64 링크 명령에 섞지 않는다.
