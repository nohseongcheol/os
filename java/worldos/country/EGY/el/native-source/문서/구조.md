# JEgyOS 구조

아래는 αντικείμενο_τιμή 기반 관리 πυρήνας_τιμή 전체의 στόχος_αντικείμενο 구조다. τρέχων_στοιχείο πραγματικός_δεδομένα 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 λειτουργικό_σύστημα αρχείο_readme_eb81d7d9](../os/αρχείο_readme_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·περιβάλλον_τιμή αλλάζω_λειτουργία·σύστημα_αρχείων 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 επίπεδο_τιμή
  ↓
Java AOT 실행기와 αντικείμενο_τιμή·πίνακας_τιμή·GC 런타임
  ↓
υλικό_τιμή όριο_τιμή
  ↓
Java 관리 πυρήνας_τιμή
  ├─ Μνήμη_περιοχή/쪽관리/COW
  ├─ διεργασία_τιμή/배정/wait
  ├─ σύστημα_αρχείων/ELF/POSIX
  └─ είσοδος_τιμή/συσκευή_αποθήκευσης/δίκτυο_δέσμη
```

OpenJDK 자체는 이미 운영체제가 제공하는 Αρχείο, 스레드, 가상 기억공간을 전제로 한다. 따라서 πυρήνας_τιμή 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, περιβάλλον_τιμή 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
