# 전체 دعم_قيمة 요청의 حديث_عنصر حالة_قيمة

طلب 전체는 아직 완료되지 않았다. حديث_عنصر ISO는 ذاتي Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 الفعلي_بيانات C POSIX 일부 기능, العربية API/مصدر اسم, IDE ملف 보존, 게스트 Java ملف 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/안내.md)를 기준으로 판단한다.

| طلب 분야 | حديث_عنصر ينفذ_أمر 가능한 يقص | 전체 지원에 필요한 작업 |
|---|---|---|
| Java يحول_برمجياً_مصدر·ينفذ_أمر | 게스트 제한형 javac/JVM, ثابت_قيمة_f430d3f5 단일 클래스와 일부 표준 عنصر_قيمة_2ed200e9 | 일반 عنصر_قيمة_2ed200e9·فئة_قيمة_55654bf1 اتصال·استثناء·GC·스레드, 완전한 javac와 표준 فئة_قيمة_55654bf1 مكتبة |
| ملف | POSIX 서술자, Java 단일 بايت_قيمة ملف بث_قيمة, 전용 وسائط_قيمة 보존 | 일반 java.io/nio, 디렉터리·إذن_قيمة·قفل_قيمة·일반 نظام_الملفات·ملحق_قيمة 가능한 قدرة_قيمة |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP مضيف 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, إلحاق_إدخال NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·إدخال_قيمة حدث·خط_قيمة·نافذة نظام_تشغيل_قيمة, AWT 네이티브 연결과 Swing ينفذ_أمر 기반 |
| POSIX | 문서화한 ملف·단말·UDP 부분 | عملية_قيمة·exec/fork·스레드·시그널·قيمة_الوقت·mmap·poll·파이프 등과 적합성 التحقق_من_صحة |

ذاتي 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 ينفذ_أمر 환경을 추가하는 방식은 별도의 نواة_قيمة·루트 نظام_الملفات·OpenJDK·그래픽 خادم_قيمة·영구 مخزن_قيمة 구성을 가진 ينفذ_أمر 경로가 된다. 후자는 기존 ذاتي 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

ينفذ_أمر 기반과 إلحاق_إدخال الهدف 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. حديث_عنصر 원문과 اختبارات 결과를 후속 구현의 출발점으로 보존한다.
