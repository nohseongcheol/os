# 자체 커널의 Python ጥማር ጸዓን_ዋጋ

자체 ARM64 커널의 `python`은 **MicroPython 1.24.1 ኢንቲጀር ህነጽ_ስርዓት**다.
`pip`와 `python -m pip`는 이 환경을 위한 제한형 ምንጪ_ገረብ ጸዓን_ዋጋ 명령이다.
PyPA pip 전체나 CPython을 이식한 것은 아니다.

호스트에서 실행한다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
python3 መሳርሒታት/ተግብር_ትእዛዝ.py --desktop --network --pip
```

게스트 셸에서 설치하고 사용한다.

```text
pip install micropython-bisect==3.3.3
pip list
python -c 'from bisect import insort as 순서대로넣기; ዋጋ=[1,5]; 순서대로넣기(ዋጋ,3); print(ዋጋ)'
python -m pip list
pip uninstall micropython-bisect
```

정상 ተግብር_ትእዛዝ 결과는 `[1, 3, 5]`다. 예시 배포 파일은
[PyPI의 micropython-bisect 3.3.3](https://pypi.org/project/micropython-bisect/3.3.3/)이며
SHA-256은 `b8d09d0bb4b2add706078dfa3f306e22fad1f4b5340b87d13f2c852507d720c8`이다.
`bisect`는 ጸዓን_ዋጋ 전 내장되어 있지 않다. 내려받은 `.py`를 자체 커널의 EL0
MicroPython이 import하여 실행한다.

## ጸዓን_ዋጋ 경로와 역할

호스트의 [꾸러미중계.py](መሳርሒታት/꾸러미중계.py)는 PyPI HTTPS 다운로드, 인증서 ኣረጋግጽ,
배포 ፋይል SHA-256 검증과 ሰንድ_ዋጋ 해제를 맡는다. 호스트에서 `setup.py`나 내려받은
Python 코드를 실행하지 않는다. አዐንግድ pip 설치도 필요 없다.
중계는 `127.0.0.1:8027`에만 열리며 게스트는 QEMU NAT의 `10.0.2.2:8027`로 연결한다.
게스트 자체에 DNS·TLS·PyPI ሰንድ_ዋጋ ፍታሕ_መኽዘን 기능을 추가했다는 뜻은 아니다.

게스트의 [ጥማር.py](파이썬연결/ቤት_ንባብ/ጥማር.py)는 TCP로 받은 파일의 SHA-256과
መገዲ·መጠን·문법을 검사한 ድሕሪት_ዋጋ `/lib`에 설치하고 `/lib/.pip.json`에 목록을 기록한다.
`/lib`와 ተግብር_ትእዛዝ ስክሪፕት_ዋጋ 폴더를 모듈 검색 경로에 추가했으므로 작업 폴더가 달라도
설치한 모듈을 import할 수 있다. 패키지 폴더와 መዘና_ዋጋ import도 지원한다.

ጸዓን_ዋጋ 도중 공간 부족 등 오류가 발생하면 새 파일과 폴더를 지우고 기존 목록을
복원한다. 이미 있는 ተጠቃሚ 파일을 덮어쓰지 않는다. 동일 버전 재설치 요청은
ፋይል 지문을 확인하고 유지한다. 다른 버전은 ኣልግስ_ምእታው 후 설치한다. ኣልግስ_ምእታው 시 사용자가
수정한 파일이 발견되면 보존하고 오류를 알린다. 빈 패키지 폴더는 남을 수 있다.

**`/lib`도 RAM 파일이다. 재부팅하면 설치한 패키지가 사라진다.**
አዐንግድ `build/pip-cache`에는 배포 파일과 출처·지문이 남으므로 다음 부팅에서 다시
설치할 수 있다. 버전을 지정하면 같은 배포 파일을 재사용한다.

```sh
# አዐንግድ: 인터넷이 있을 때 배포 파일만 ኣዳልው
python3 መሳርሒታት/꾸러미중계.py --fetch micropython-bisect==3.3.3
# 다음 ተግብር_ትእዛዝ: PyPI ኣላግብ 없이 캐시 사용
python3 መሳርሒታት/ተግብር_ትእዛዝ.py --network --pip --pip-offline
```

다른 포트는 አዐንግድ `--pip-port 8028`, 게스트
`pip install micropython-bisect==3.3.3 --port 8028`로 맞춘다.
አዐንግድ 중계는 `python3 መሳርሒታት/꾸러미중계.py --port 8027`로 별도 실행할 수도 있다.
QEMU를 종료하거나 중계 실행을 끝내면 이 서비스도 닫힌다.

## ሓገዝ_ዋጋ ቅንጣብ

- 의존성 없는 순수 Python wheel(`*-none-any.whl`, `Root-Is-Purelib: true`).
- 구형 `micropython-*` ምንጪ_ገረብ 배포형의 `.py`와 `PKG-INFO`.
- 꾸러미당 ምንጪ_ገረብ 16개, 합계 64 KiB, 파일당 16 KiB, 절대 መገዲ UTF-8 63바이트 이하.
  전체 RAM ፋይል 64개·ሓባሪ_ማህደር_ዋጋ 16개의 남은 공간과 Python 힙 256 KiB 한도도 적용된다.
- `install`, `list`, `uninstall`, `--help`, `--version`.
- SHA-256, JSON, ማህደር_ዝኽረት_ሓበሬታ `io.StringIO`/`BytesIO`를 실행기에 추가했다.
  일반 ፋይል ነገር_ዋጋ `open()`은 미지원이며 `ትግርኛ.파일읽기/ጸሓፍ_ፋይል` 또는
  `jkoros.read/write`를 사용한다.

C ቅጥያ_ዋጋ·플랫폼 전용 wheel, 일반 sdist ህነጽ_ስርዓት, 자동 의존성 해결, extras, VCS/임의 URL,
NumPy 같은 CPython 전용 패키지는 지원하지 않는다. 순수 Python 패키지도
MicroPython의 문법·표준 모듈·ኢንቲጀር 전용 환경과 맞아야 실제로 실행할 수 있다.
ጸዓን_ዋጋ 시 문법을 검사하지만 모든 ተግብር_ትእዛዝ 경로의 호환성을 증명하지는 않는다.
ትኽክለኛ_ሓበሬታ Raspberry Pi 4의 LAN을 통한 설치는 검증하지 않았으며 현재 중계는 QEMU용이다.

MicroPython 자체의 패키지 체계와 CPython pip의 차이는
[MicroPython 패키지 문서](https://docs.micropython.org/en/v1.24.0/reference/packages.html),
wheel 형식은 [PyPA 배포 ቅረጽ_ዋጋ 규격](https://packaging.python.org/en/latest/specifications/binary-distribution-format/)을 참고한다.

```sh
make test-pip
```

አረጋግፅ 기록은 `build/verification/pip/report.json`과 `serial.log`에 저장한다.
ትኽክለኛ_ሓበሬታ PyPI ጥማር 시험과 별도로 시험용 wheel로 패키지 ሓባሪ_ማህደር_ዋጋ, 구문 ጌጋ,
공간 부족 되돌림을 확인한다.
