# 전체 ሓገዝ_ዋጋ 요청의 현재 ደረጃ_ዋጋ

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 ትኽክለኛ_ሓበሬታ C POSIX 일부 기능, ትግርኛ API/ምንጪ ሽም, IDE ፋይል 보존, 게스트 Java ፋይል 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/ኣንብበኒ_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 ተግብር_ትእዛዝ 가능한 ቅንጣብ | 전체 지원에 필요한 작업 |
|---|---|---|
| Java ህነጽ_ምንጪ·ተግብር_ትእዛዝ | 게스트 제한형 javac/JVM, ቀዋሚ_ዋጋ 단일 클래스와 일부 표준 ነገር_ዋጋ | 일반 ነገር_ዋጋ·ክፍሊ_ዋጋ ኣላግብ·예외·GC·스레드, 완전한 javac와 표준 ክፍሊ_ዋጋ ቤት_ንባብ |
| ፋይል | POSIX 서술자, Java 단일 ባይት_ዋጋ ፋይል ወሓዚ_ዋጋ, 전용 መራኸቢ_ብዙሃን_ዋጋ 보존 | 일반 java.io/nio, 디렉터리·ፍቓድ_ዋጋ·잠금·일반 ናይ_ፋይል_ስርዓት·ቅጥያ_ዋጋ 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP አዐንግድ 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 ፍጻመ·ቅርጺ_ፊደል_ዋጋ·መስኮት ስርዓት_ስርሒት_ዋጋ, AWT 네이티브 연결과 Swing ተግብር_ትእዛዝ 기반 |
| POSIX | 문서화한 ፋይል·단말·UDP 부분 | መስርሕ_ዋጋ·exec/fork·스레드·시그널·시간·mmap·poll·파이프 등과 적합성 አረጋግፅ |
| 언어별 ሽም | ትግርኛ 46개 대응 ምእታው_ዋጋ, ትኽክለኛ_ሓበሬታ C/Java/ፋይል ሽም 적용 | ዕላማ ቋንቋ 확정, 언어별 용례·역사 근거와 해당 ምንጪ·도구의 አረጋግፅ |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 ተግብር_ትእዛዝ 환경을 추가하는 방식은 별도의 ፍረ_ዋጋ·루트 ናይ_ፋይል_ስርዓት·OpenJDK·그래픽 ኣገልጋሊ_ዋጋ·영구 ከዝን_ዋጋ 구성을 가진 ተግብር_ትእዛዝ 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

ተግብር_ትእዛዝ 기반과 추가 ዕላማ 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
