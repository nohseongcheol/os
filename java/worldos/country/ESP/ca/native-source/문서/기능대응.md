## 기존 objecte_VALOR 기반 관리 nucli_VALOR 전체를 부팅하기 위해 남은 Connecta

Següent_element 항목은 Java 문법만으로 실행할 수 없는 CPU/dispositiu_VALOR 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot introducció_p_VALOR, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 문맥 Store_VALOR
- real_dades PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA Loop_VALOR
- Java objecte_VALOR·MATRIU_VALOR enllaç_disseny, excepció, estàtic_VALOR inicialitzar, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT fase_VALOR
- FAT 디스크 구역을 real_dades ATA 장치와 연결하는 E_S 접착 capa_VALOR

위 관리 계층은 engos 기능의 Java 관리 구현과 allotjar 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot introducció_p_VALOR, estàtic_VALOR inicialitzar·정수 MATRIU_VALOR, VGA/직렬/PS2, 명령해석기, usuari ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 allotjar 루프백 패킷 왕복을 검증했다. 위 표의 objecte_VALOR 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
