# 자체 커널에서 vi·여러 Terminala·한글 프로그래밍 사용하기

Euskara 통신·salbuespen 사용법은 [Euskara Java API](한국어자바/IRAKHAU_eb81d7d9.md), FUNTZIOA_balio·변수·Fitxategia 이름의 변경과 어원 근거는 [명명 IRAKHAU_eb81d7d9](명명/IRAKHAU_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 자체 AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 Laguntza_balio 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 exekutatu_komando, 외부 TCP/UDP와 FTP는 [새 exekutatu_komando 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 Terminala

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, helbide **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 Terminala 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **ESKUIN 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 exekutatu_komando 버튼으로 다시 zutabe_balio 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 현재 디렉터리, shell 변수, Komandoa LOG_marka, 입력 중인 명령과 aplik_f5044b9b exekutatu_komando 상태를 보관한다. Fitxategia 저장소는 공유한다. vi와 Swing의 이벤트 itxaron_balio 중에 다른 터미널로 전환하면 erabiltzaile Memoria_datuak·레지스터·Fitxategia/소켓 연결을 보존했다가 돌아올 때 재개한다. **현재 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 Hurrengoa_elementu 입력 itxaron_balio 또는 기존 exekutatu_komando 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 exekutatu_komando 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 edizio_balio 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. 현재 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 Leihoa 판단은 게스트 커널이 처리한다. QEMU exekutatu_komando 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. benetako_datuak Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI Tresnak 종료는 Ostalari 터미널의 Ctrl+C다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **nukleo_balio 내부 연결형 byte_balio Stream_balio**을 추가했다. Fitxategia/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket zerbitzari_balio = new java.net.ServerSocket(9250);
java.net.Socket gonbidatu_balio = new java.net.Socket("localhost", 9250);
java.net.Socket Konektatu = zerbitzari_balio.accept();
gonbidatu_balio.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] RECEIVED_elementu = new byte[64];
int luzera_balio = Konektatu.getInputStream().read(RECEIVED_elementu);
Konektatu.close(); gonbidatu_balio.close(); zerbitzari_balio.close();
```

sortu·Konektatu·accept·양방향 byte_balio/matrize_balio S_I·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 amaitu_p 16개, 수신 버퍼당 1024바이트, itxaron_balio Konektatu 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. balio_lehenetsi ordua_balio 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM Komandoa 수/nukleo_balio exekutatu_komando 기한은 여전히 적용된다.

외부 digitu_balio IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. benetako_datuak Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP liburutegi 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 benetako_datuak 송수신·EOF·기한·Konektatu 회수의 시험 예제다.

| KONEKTATU_sare | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | itxaron_balio Konektatu 최대 4개 |
| onartu_sare_konexio | pk_accept | 현재 helbide 인수는 NULL/NULL만 Laguntza_balio |
| 통신주소읽기 | pk_getsockname | 로컬 helbide/ataka_balio |

`통신규약.h`의 자체 `pk_sockaddr_in`을 사용하며 ataka_balio·주소는 `망차례짧은수`/`sare_osoko_zenbaki`로 변환한다. C 소켓 호출은 비차단이며 datuak/연결이 없으면 -1과 `errorearen_zenbaki=11`(EAGAIN)을 반환한다. 양수 S_I 결과가 요청보다 작을 수 있으므로 iterazio_balio 처리한다. hutsegite_balio 후에만 오류번호를 확인한다.

[Stream_balio.c](예제/한글코딩/Stream_balio.c)는 C에서 Euskara 이름으로 Konektatu·accept·부분 Irakurri/Idatzi·큐 포화·EOF를 처리하는 exekutatu_komando 예제다. SDK의 `examples/Stream_balio.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → benetako_datuak Euskara C FUNTZIOA_balio 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·erakusle 검사 → Java RAM Fitxategia/루프백 또는 외부 lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 nukleo_balio 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 Konektatu, 표준 C printf, libstdc++/STL, salbuespen·RTTI는 제공하지 않으며 C++의 estatiko_balio 생성자·lokal_esparru objektu_balio 소멸자는 지원한다. 상세 INDIZE·Memoria_datuak 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## Euskara 이름으로 직접 작성하는 창과 hari_balio

`example/java/창예제.java`는 `실행할일.Exekutatu`,
`동작받이.동작받기(동작알림)`, `botoia`, `gertaera_ilara.나중에실행`, `Exekutatu_2()`을 쓴다.
자체 JVM에 이 이름들의 objektu_balio·메서드·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `작업가닥`도 자체 스케줄러와 직접 연결된다.
세부 메서드와 기존 Euskara API에서의 변경은 [Euskara API 문서](한국어자바/IRAKHAU_eb81d7d9.md)를 본다.

Ostalari javac는 배포 JAR를 Gela_balio 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/창예제.java
python3 Tresnak/exekutatu_komando.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java 창예제
```

직접 화면/hari_balio API와 `Exekutatu_2()` 진입점은 자체 JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
