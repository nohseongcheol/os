# 자체 ARM64 JVM 0.4와 Euskara liburutegi

Euskara 통신·salbuespen 사용법은 [Euskara Java API](한국어자바/IRAKHAU_eb81d7d9.md), FUNTZIOA_balio·변수·Fitxategia 이름의 변경과 어원 근거는 [명명 IRAKHAU_eb81d7d9](명명/IRAKHAU_eb81d7d9.md)를 참고한다.

JAR exekutatu_komando, 외부 IPv4 TCP/UDP, 별도 estatiko_balio 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 objektu_balio·Thread·Swing은 JVM 경로의 기능이며 AOT Laguntza_balio 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 exekutatu_komando**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK Gela_balio liburutegi 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 Gela_balio·estatiko_balio 메서드 중심이던 실행기를 objektu_balio·liburutegi exekutatu_komando 기반으로 넓힌 것이다.

## 실행과 eraiki_iturburu

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# 자체 nukleo_balio 안에서 iturburu_zuhaitz eraiki_iturburu → class exekutatu_komando, Euskara API 호출
python3 Tresnak/exekutatu_fitxategi.py 시험/자바/한글소스.java

# objektu_balio·salbuespen 등은 Ostalari JDK로 Java 8 class를 만든 후 자체 커널에서 exekutatu_komando
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 Tresnak/exekutatu_fitxategi.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 transferitu_balio
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 Tresnak/exekutatu_fitxategi.py build/my-java/객체시험.class \
  --include build/my-java/horma_paper_balio.class --include build/my-java/adar_balio.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.Gela_balio.class`라는 RAM Fitxategia 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.Gela_balio`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.Gela_balio`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar Fitxategia.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 Euskara 클래스만 찾는다. 배포 Euskara liburutegi JAR는 Ostalari javac의 classpath로 사용하며, 같은 클래스가 erabiltzaile JVM ELF에도 Irakurri 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 estatiko_balio 메서드, int/boolean/char/String, baldintza·iterazio_balio, kate_balio 결합, 일부 Fitxategia 스트림 등의 **자체 부분집합 컴파일러**다. objektu_balio deklarazio·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 자체 JVM에서 실행한다. Euskara API 중 Irteera·문자 스칼라 FUNTZIOA_balio·Fitxategia Irakurri/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] Argumentuak) throws Exception {
        Euskara.자체.Irteera.idatzi_lerro("안녕하세요😀");
        Euskara.자체.Irteera.수쓰기(Euskara.자체.문자.karaktere_kode_ZENBATU("한글😀"));
        Euskara.자체.Fitxategia.Idatzi("인사.txt", "한글 Fitxategia😀");
        Euskara.자체.Irteera.idatzi_lerro(Euskara.자체.Fitxategia.Irakurri("인사.txt"));
    }
}
```

## Euskara API

독립 패키지 **`Euskara.자체`**를 사용한다. Linux판 `Euskara.자바`가 요구하는 NIO/Swing/HTTP API를 자체 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 Gela_balio Izena·메서드·Argumentuak·eremu_balio·Fitxategia 이름에 한국어를 사용한다. 표준 Java Gela_balio 이름은 호환성을 위해 보존한다.

## exekutatu_komando 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(Euskara Gela_balio 포함), class당 16 KiB·konstante_balio 풀 511항목, 전체 메서드/eremu_balio 각각 512개. 메서드 KODE_balio 8 KiB, lokal_esparru 변수·피연산자 스택 각각 128슬롯, Argumentuak 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 exekutatu_komando 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- objektu_balio 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 benetako_datuak 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 Fitxategia·대형 kate_balio·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 Komandoa 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 Leihoa ALDATU_MODA 시 중단·재개한다. 일반 zerbitzari_balio·계산의 무제한 실행은 아직 없다. 미지원 Komandoa·baliabide_balio 부족은 명시적인 오류로 종료한다.
- RAM Fitxategia 최대 64개, 파일당 16384바이트, Bide_izena UTF-8 63바이트. RAM 디렉터리와 pareko_balio/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 Euskara class는 RAM Fitxategia 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 현재 경로에서 iturburu_zuhaitz·Gela_balio·datuak 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 외부 IPv4를 제공한다. benetako_datuak GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. 전문 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 exekutatu_komando 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 matrize_balio, 완전한 matrize_balio 공변성·인터페이스 maila_balio 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/enkriptatu_datuak/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 Laguntza_balio 부분집합은 아래 및 개발 매뉴얼을 참고한다. Gela_balio Fitxategia 전체 검증기·atzitu_sarrera baimen_balio/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 babestu_balio 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM balio/baliozkotu/Gela_balio 로더와 salbuespen 모델 → 영속 VFS·mmap·erloju·원자 kirurgia_balio·benetako_datuak 스레드/sinkronizatu ABI → OpenJDK java.base 및 native liburutegi 이식 → gailu_balio 네트워크·TCP/IP → Leihoa 시스템/letra_tipo_balio/입력기·java.desktop → Java SE 호환성 시험. 현재 자체 JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## JVM 0.3: 네트워크와 GUI luzapen_balio

`Socket`/`ServerSocket` sortu·Konektatu·accept·양방향 InputStream/OutputStream·close·EOF·ordua_balio 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 외부 digitu_balio IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 amaitu_p 16개, Java 루프백 버퍼 1024바이트, 외부 TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. interaktibo 이벤트 대기는 exekutatu_komando 기한을 갱신하고 Terminala ALDATU_MODA 시 프로세스 상태를 Store_balio·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

Euskara `Leihoa`, `widget`, `연결통신` 클래스를 배포 JAR와 자체 JVM 내장 자원에 추가했다. 상세 메서드·제한·iturburu_zuhaitz·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## Euskara 객체의 직접 exekutatu_komando

`Leihoa`, `Etiketa`, `SMS_eremu`, `botoia`, `gertaera_ilara`, `동작알림`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. 자체 JVM의 objektu_balio sortu,
formatu_balio 검사, 화면 호출, Gertaera 큐, hari_balio 스케줄러에 Euskara 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 exekutatu_komando 경로도 유지한다.
Euskara 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

자체 실행기의 Euskara 진입점은 `public static void Exekutatu_2()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 Euskara 진입점을 우선한다.
