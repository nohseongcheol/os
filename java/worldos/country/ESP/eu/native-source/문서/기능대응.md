## 기존 objektu_balio 기반 관리 nukleo_balio 전체를 부팅하기 위해 남은 Konektatu

Hurrengoa_elementu 항목은 Java 문법만으로 실행할 수 없는 CPU/gailu_balio 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot sarrera_p_balio, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 문맥 Store_balio
- benetako_datuak PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA Loop_balio
- Java objektu_balio·matrize_balio lotu_diseinu, salbuespen, estatiko_balio hasieratu, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT fase_balio
- FAT 디스크 구역을 benetako_datuak ATA 장치와 연결하는 S_I 접착 maila_balio

위 관리 계층은 engos 기능의 Java 관리 구현과 Ostalari 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot sarrera_p_balio, estatiko_balio hasieratu·osoko_zenbaki matrize_balio, VGA/직렬/PS2, 명령해석기, erabiltzaile ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 Ostalari 루프백 패킷 왕복을 검증했다. 위 표의 objektu_balio 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
