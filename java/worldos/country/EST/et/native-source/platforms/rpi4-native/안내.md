# Raspberry Pi 4 oma Java tuum_VALUE — kasutaja Täida_käsk 기반

tähtaja_piires_kaup oma 코드의 COSL 상업 tingimus, 제3자 고지 및 LGPL 재연결 자료는 [COSL turustus_VALUE 안내](COSL배포안내.md)를 참고한다. SWITCH_MODE 전 GPL 구성의 판단은 [이전 라이선스 검토](litsents_arvustus.md)에 기록했다.

Eesti 통신·erand 사용법은 [Eesti Java API](한국어자바/안내.md), FUNCTION_VALUE·변수·Fail 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

Linux 없이 부팅하는 oma AArch64 커널이다. Java AOT tuum_VALUE 위에 **käsurida kest, 게스트 Java kompilaator·JVM, MicroPython, EL0 C++ Täida_käsk, Fail·UDP 루프백 시스템 호출, 여러 한글 GUI terminal·vi korrektor·Swing 부분집합**을 제공한다. 커널의 Fail andmed/정책·루프백 Edasta_VALUE·kest 상태는 Java, 화면 합성·piksel muutma_VALUE·kursor·클리핑도 Java로 구현하며, CPU/MMU/seade_VALUE 경계와 terminal·märk_VALUE 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 oma 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 Täida_käsk, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 juhtmega_ühendatud_VALUE 송수신은 아직 미검증이다.** Täida_käsk·ühendus_e05f319b·parool_VALUE 확인은 [väline_VALUE ühendus_e05f319b 안내](väline_ühendus_juhik.md)에 정리했다.

셸은 EL1 tuum_VALUE, `java` 등 kasutaja Täida_käsk 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 Täida_käsk·ühendus_e05f319b 방법 및 tegelik_andmed 검증은
[Täida_käsk 계층과 väline_VALUE 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 tegelik_andmed Täida_käsk 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 정적 ELF는 `run --linux failinimi_SMS`으로 실행한다. [ELF·Linux ABI tugi_VALUE 범위와 동일 바이너리 시험](실행파일규약.md).

GUI와 네트워크는 `python3 Tööriistad/Täida_käsk.py --desktop --network`로 함께 사용한다. Java·C·Python의 Eesti 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 부팅 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 number 있다. 예비 microSD에 järk_pilt LOG_kirje 도구로 `.img`를 기록하거나 FAT32 부팅 파티션 최상위에 ZIP 내용을 푼다. järk_pilt 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 vaikeväärtus EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD Fail 구성·tuum_VALUE 체크섬 검사와 물리 Tahvel 부팅 검증은 별개다. MMU kasutus_VALUE 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 부팅 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 Eesti API kasutus_VALUE

SDK를 풀고 호스트에서 컴파일한다.

```sh

cd build/jkoros-native-sdk
python3 compile.py examples/FailiNäide.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int START_kasutaja_programm(int)`이다. kasutaja C++는 FP/SIMD를 사용할 number 있다. tuum_VALUE C/Java AOT는 일반 레지스터만 사용하므로 erand Joonis_VALUE_kirje 중 kasutaja FP 상태를 건드리지 않는다. kasutaja kirje_p_VALUE 시 FP 상태를 초기화하고 tuum_VALUE 복귀에 필요한 상태를 보존한다.

SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 teek, PT_TLS, PT_INTERP, PT_DYNAMIC, Täida_käsk·Kirjutamine 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 INDEX·ADDRESS klipp·오류는 [kasutaja ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `kinnitamine_failisalvestusruum`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 luba_VALUE·dup/fcntl은 없다. 디렉터리와 partner_VALUE/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, saama_VALUE 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. kasutaja Välju_programm 시 열린 Fail 서술자와 소켓을 회수한다.
