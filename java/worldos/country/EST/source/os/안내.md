# Java 네이티브 operatsioonisüsteem

이 문서는 기존 **x86 tuum_VALUE**을 설명한다. Raspberry Pi 4의 oma ARM64 lähteolek 이식은 [별도 안내](../platforms/rpi4-native/README.md)를 참고한다. 아래 x86 kasutaja ELF·네트워크·IDE salv_VALUE 기능이 ARM64에 모두 이식된 상태는 아니다.

Java 원문을 oma AOT 후단으로 x86 기계어로 컴파일해 부팅하는 작은 운영체제다. 커널과 별도로 oma 제한형 Java kompilaator·JVM ELF를 kasutaja 모드에 적재할 number 있다. Linux, engos, koros4와 väline_VALUE OpenJDK는 게스트에 적재하지 않는다. 부팅 진입과 포트/물리 Mälu_regioon 접근은 어셈블리이며, 문자 단말·입력 Joonis_VALUE_kirje·Käsk sõeluma_VALUE·작업 jaotis_VALUE 관리는 `ALLIKAS/*.java`에 있다.

## 게스트 Java 개발

`javac Hello.java`, `java Hello`로 부팅된 operatsioonisüsteem 안에서 kompileerima_lähe·실행한다. `edit FILE.java`와 `.save`로 소스를 작성하며 `ls`, `cat`, `rm`을 제공한다. RAM 파일은 최대 8개, 각각 16KiB이다. 전용 IDE 매체를 연결하면 `sync`로 보존할 number 있다. 이 기능은 oma 제한형 구현이며 전체 OpenJDK/JDK 호환은 아니다. 사용법·tugi_VALUE 문법·Fail 적재·교차 시험은 [Java 개발 환경](../문서/자바개발환경.md)에 있다. `make test-java`로 검증한다.

## 빌드와 Täida_käsk

`compiler/`가 요구하는 도구에 더해 ISO 생성에는 `grub-file`, `grub-mkrescue`, GRUB BIOS moodul_VALUE, `xorriso`가 필요하다. 실행에는 QEMU 또는 VirtualBox가 필요하다. tähtaja_piires_kaup 설치된 도구만 사용한다. `make run-store`는 새 전용 가상 salv_VALUE 매체를 만들어 연결한다. VirtualBox 실행기는 이 프로젝트가 만든 전용 VM만 설정하고 다른 VM은 변경하지 않는다. 가상 메모리는 vaikeväärtus 64MiB이며 최소 16MiB가 필요하다.

```sh
cd /home/user/jkoros/os
make                 # build/kernel.elf
make iso             # build/kernel.iso (kasutaja ELF Rühm_VALUE 포함)
make run             # ELF 직접 부팅, 직렬 단말
make run-gui         # GRUB ISO 부팅, VGA 창과 PS/2 자판
make vbox            # 상위 폴더의 실행기로 전용 VirtualBox VM Täida_käsk
make vbox-status     # 전용 VirtualBox VM Olek_VALUE kinnitama
make test            # ELF와 ISO 두 경로의 tegelik_andmed 부팅/입력 시험
make apps            # kasutaja 프로그램만 järk_süsteem
make test-network    # kasutaja Täida_käsk/UDP/kaitsma_VALUE 시험
```

`make run`은 QEMU의 직렬 표준 입출력을 쓴다. `Ctrl+A`를 누른 Tagasi_VALUE `X`로 QEMU를 종료할 number 있다. `halt`는 게스트 CPU만 정지시키므로 QEMU aken/프로세스는 별도로 닫는다. 폴링 방식이라 Oota_VALUE 중에도 host CPU를 사용할 number 있다.

VirtualBox는 `make vbox`로 실행한다. 새 전용 VM을 Mälu_andmed 64MiB, BIOS, 광학 드라이브 부팅으로 자동 설정하며 디스크는 필요 없다. tegelik_andmed VirtualBox 5.2.42에서 부팅, Java oma 시험, kest 입력, `run hello vbox`의 ring 3 실행과 정상 종료를 확인했다. tähtaja_piires_kaup 통신 드라이버는 QEMU의 RTL8139 전용이며 VirtualBox의 PCnet/E1000에서는 네트워크를 사용할 number 없어 네트워크 장치를 비활성화한다. salv_VALUE Olek_VALUE 재개와 새 järk_süsteem 반영 방법은 [VirtualBox Täida_käsk 안내](../문서/가상상자실행.md)에 있다.

- GRUB Multiboot 1 ELF 부팅, x86 kaitsma_VALUE MODE_VALUE GDT, BSS 초기화, 64KiB operand_Virn.
- Java FUNCTION_VALUE tegelik_andmed 실행과 부팅 msinfo32_exe marker_VALUE kinnitama.

- Java ARRAY_VALUE 256KiB 영역의 Suurus·allindeks_VALUE 검사와 런타임 VIGA 중단.
- Lugemine 전용 JKAP Täida_käsk Rühm_VALUE, ELF32 jaotis_VALUE/kirje_p valideerima, kasutaja MODE_VALUE·Argumendid·Välju_programm CODE_VALUE.

`mem`의 Upper memory는 Multiboot의 1MiB 위쪽 연속 Mälu_andmed Suurus(KiB)이며, 전체 Mälu_andmed 지도 분석이나 자유 물리 Mälu_andmed 수치가 아니다. `alloc`은 이미 확보한 täisarv ARRAY_VALUE 안의 작업 jaotis_VALUE 번호를 반환한다. 일반 물리 leht_VALUE lisama_salvesti, ADDRESS ADDRESS_regioon 또는 kasutaja Joonis_VALUE Mälu_andmed 관리가 아니다.

## 명시적인 한계

이 커널은 **kasutaja 프로그램을 한 번에 하나 실행하는 lähteolek tuum_VALUE**이다. PIT IRQ0만 사용하며 키보드와 NIC는 폴링한다. kasutaja CPU 예외는 해당 프로그램을 끝내고 셸로 복귀시키지만 tuum_VALUE 예외는 중단한다. Täida_käsk 시간은 약 3초로 제한한다. 완전한 선점 다중 Joonis_VALUE 스케줄러, FAT/ext 등 일반 디스크 failisüsteem, TCP·DNS·DHCP·IPv6·HTTP, 전체 POSIX, 일반 objekt_VALUE 모델/GC는 아직 없다. 전용 IDE Fail 보존과 POSIX Fail/UDP 일부 기능은 구현했다. JVM은 RAM 파일의 단일 클래스를 Täida_käsk 시 적재하며 일반 ClassLoader나 JAR 로딩은 지원하지 않는다. 네이티브 Täida_käsk 파일은 järk_süsteem 시 Lugemine 전용 묶음에 넣으며, 일반 Linux ELF를 실행하는 환경이 아니다. 기존 `../pärand_lähe/`의 JVM 관리 tuum_VALUE 전체를 이식한 것도 아니다.

Java 식별자는 한국어다. 직렬 출력은 이 프로젝트의 한글(BMP 문자)을 UTF-8로 표시한다. VGA는 vaikeväärtus ASCII 글꼴만 사용하므로 한글 자리에 `?`가 나온다. Käsk 입력도 tähtaja_piires_kaup ASCII만 지원하며 한글 font_VALUE·입력기 및 보조 평면 문자 출력은 후속 작업이다. `test`는 작은 배열을 새로 할당하고 GC가 없으므로 무한 반복하지 않는다.

## 자동 시험

`시험/부팅시험.py`는 디스크 없는 독립 QEMU를 생성해 다음을 검증하고 종료한다.

- ELF 직접 부팅 및 GRUB ISO 부팅.
- Java oma 시험과 UTF-8 직렬 문구.
- Käsk saade_spikker·msinfo32_exe·Mälu_andmed·Väljund·VIGA 입력·화면 kustutama_kirje.
- 작업 jaotis_VALUE 8개 lisama_salvesti, 부족 Joonis_VALUE_kirje, tagasi_saatma_näitaja/중복 tagasi_saatma_näitaja/재할당.
- 직렬 줄바꿈·백스페이스·긴 입력 Joonis_VALUE_kirje.
- QEMU PS/2 Võti_VALUE 입력으로 `info` Täida_käsk, `halt` 정지.

성공 로그는 `build/부팅시험.json`에 남는다. 로컬 Unix 소켓을 금지하는 샌드박스에서는 시험 도구에 해당 권한이 필요하다. 시험 도중 새로 만든 QEMU만 종료하며 기존 VM과 tegelik_andmed 디스크는 건드리지 않는다.

`시험/사용자통신시험.py`는 ELF/ISO 각각에서 kasutaja ELF, tegelik_andmed ring 3, Argumendid, host 루프백 UDP 왕복, 1,023/1,024바이트 24회 연속 왕복, Aeg_VALUE 초과, NIC 없음, Mälu_andmed/포트 pöördus_kirje 차단, CPU erand, 무한 sprint_VALUE, 잘못된 ELF를 시험한다. `build/사용자통신시험.json`에 게스트 기록과 호스트가 받은 데이터의 길이·해시를 저장한다. `시험/패킷시험.py`는 tegelik_andmed Java lepingu_väärtus 처리기에 손상된 패킷을 넣어 2,201개 경계/kontrollsumma 조건을 검사한다. host 루프백 외 väline_VALUE 서버에는 시험 트래픽을 보내지 않는다.

부트 경계는 GNU의 [Multiboot 명세](https://www.gnu.org/software/grub/manual/multiboot/multiboot.html)를 따른다.

새 파일서술자·C ABI·IDE salv_VALUE·Java Fail 흐름의 범위와 Eesti 명명 대응은 [posix-kor 안내](../posix-kor/안내.md)에 있다. `make test-posix`로 ELF/ISO 실행과 재부팅 보존을 검증한다.
