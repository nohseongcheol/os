# Eesti Java 통신·I_O·erand API

패키지는 `Eesti.oma`다. host `javac --release 8`로 컴파일한 class를
oma ARM64 커널의 JVM에서 실행한다. 통신·Fail·erand API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 lõim_VALUE API는 oma JVM 전용이다.
기존 표준 Java teek 전체의 Eesti 번역판은 아니다.

```java
import Eesti.oma.*;

public class võrk {
    public static void main(String[] Argumendid) throws I_O_erand {
        ühendus Ühendu = ühendus.Ava("10.0.2.2", 9000);
        try {
            Ühendu.TIMEOUT(700);
            Ühendu.Väljund().Kirjutamine(문자.kodeerima("안녕하세요\n"));
            sisendvoog 입력 = Ühendu.입력();
            Väljund.kirjutamine_number(입력.Lugemine());
        } catch (Oota_TIMEOUT_erand VIGA) {
            Väljund.kirjutamine_liin(VIGA.설명());
        } finally {
            Ühendu.Suletud();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
kasutaja 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 string_VALUE 리터럴에 사용하는 표준 클래스다. oma 실행기는 `public static void Käivita_2()`도 진입점으로 받는다.

## 통신과 voog_VALUE

| tund_VALUE | Eesti 호출 |
|---|---|
| ühendus | `Ava(ADDRESS, pordinumber)`, `입력()`, `Väljund()`, `TIMEOUT(밀리초)`, `pordinumber()`, `kohalik_pordinumber()`, `연결됨()`, `infotehnoloogia_suletud()`, `Suletud()` |
| saama_port | `Ava(pordinumber)`, `saama()`, `pordinumber()`, `TIMEOUT(밀리초)`, `infotehnoloogia_suletud()`, `Suletud()` |
| sisendvoog | `Lugemine()`, `Lugemine(byte[])`, `Lugemine(byte[], Käivita_2, 길이)`, `Suletud()` |
| väljundvoog | `Kirjutamine(int)`, `Kirjutamine(byte[])`, `Kirjutamine(byte[], Käivita_2, 길이)`, `내보내기()`, `Suletud()` |
| datagramm_Kanal | `Ava(pordinumber)`, `saatma(ADDRESS, pordinumber, Tekst)`, `saama()`, `TIMEOUT(밀리초)`, `pordinumber()`, `infotehnoloogia_suletud()`, `Suletud()` |
| ühendus_transport | `Ava(...)`, `수신열기(...)`는 위 Eesti 객체를 tagasi_saatma_näitaja |
| 검사 | `참인지(tingimus, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`Lugemine()`의 Fail 끝은 -1, ARRAY_VALUE 읽기의 반환값은 tegelik_andmed 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. pordinumber 0은 빈 번호를 자동 배정한다.
UDP 전문은 tähtaja_piires_kaup oma 커널에서 512바이트까지 받으며, 주소는 number_VALUE IPv4를 사용한다.
`localhost` 루프백 외의 Nimi_2 풀이(DNS)는 oma 커널에 아직 없다.

기존 `ühendus_transport.Ühendu/jälgima_osaleja/saama`, `통신.Ava/saatma/saama`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `ühendus`, `saama_port`, `datagramm_Kanal`를 쓴다.

## Eesti erand

모든 아래 클래스는 vaikeväärtus 생성자, `새예외("설명")` 형태의 string_VALUE 생성자와
`설명()`을 제공한다. tegelik_andmed genereerima 문법은 `new Oota_TIMEOUT_erand("ooteolek 끝")`이다.

| Eesti erand | 상위 tund_VALUE / 용도 |
|---|---|
| erand | `java.lang.Exception`, 직접 던지는 일반 검사 erand |
| 실행예외 | `java.lang.RuntimeException` |
| I_O_erand | `java.io.IOException`, Eesti Fail·통신 API의 검사 erand |
| Oota_TIMEOUT_erand | `I_O_erand`, 통신 TIMEOUT 초과 |
| ADDRESS_LOOKUP_erand | `I_O_erand`, ADDRESS kinnitama tõrge_VALUE |
| 파일없음예외 | `I_O_erand`, Fail Ava tõrge_VALUE |
| 통신예외 | `I_O_erand`, 표준 SocketException CONVERT_VALUE |
| kehtetu_argument_erand | `java.lang.IllegalArgumentException` |
| number_vorming_tõrge | `kehtetu_argument_erand` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| NULL_viide_erand | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| Olek_erand | `java.lang.IllegalStateException` |
| TYPE_esitama_erand | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| ARRAY_salv_tõrge | `java.lang.ArrayStoreException` |
| lõim_Olek_erand | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 Oota_VALUE 중단 |

`erand`와 `실행예외`는 모든 Eesti 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, Fail·통신 전체를 잡으려면 `catch (I_O_erand VIGA)`를 쓴다.
Eesti API가 표준 I_O 오류를 Eesti 예외로 변환한다.
기존 Eesti 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`Oota_TIMEOUT_erand`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
erand 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
tähtaja_piires_kaup oma JVM에 이 20종을 추가했다. 임의의 kasutaja Throwable 하위 tund_VALUE 전체를
지원하도록 확장했다는 뜻은 아니다.

## kompileerima_lähe·Täida_käsk

```sh
cd /home/user/jkoros/platforms/rpi4-native
make järk_süsteem
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 Tööriistad/Täida_Fail.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 kasutaja JVM ELF 안에 탑재된다. `.jar`는 host javac의
tund_VALUE 경로로 사용한다. lähe_puu 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 Eesti 예외의 `throws` 선언과 그 import를 인식한다.
oma JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·objekt_VALUE·소켓 예제 전체의 lähe_puu 컴파일은 host javac를 사용한다.
`/example/java/FailiNäide.java`는 게스트 javac로도 컴파일할 number 있다.

tegelik_andmed TCP/UDP 예제는 [VõrguNäide.java](../../../example/java/VõrguNäide.java),
Täida_käsk 절차는 [example 안내](../../../example/README.md),
lähe_puu 명명 원칙은 [명명 안내](../명명/안내.md)에 있다.

## Swing aken 예제

`/example/java/AknaNäide.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` Edasi_kaup `java AknaNäide`로 연다. Nimi_2 입력, 인사하기 버튼,
인사말과 klõps_VALUE 횟수 värskendama, X 닫기를 지원한다.

| 기능 | Eesti 직접 API |
|---|---|
| Runnable / run | `실행할일.Käivita()` |
| ActionListener / actionPerformed | `동작받이.saama_Toiming(Toiming_teatamine teatamine)` |
| ActionEvent | `Toiming_teatamine.käsk_SMS()`, `sündmuse_allikas()`, `INDEX()` |
| JFrame | `aken(aken_teos, 폭, 높이)`, `Lisa_element(화면구성요소)`, `saade_aken()`, `Suletud()`, `보이는가()` |
| JButton | `nupp(Tekst, 가로, vertikaal_ametikoht, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `Silt(...)`, `tekstiväli(...)` |
| 공통 화면 element_VALUE | `화면구성요소.글읽기()`, `kirjutamine_SMS(Tekst)`, `자리정하기(가로, vertikaal_ametikoht, 폭, 높이)` |

| 명령행 | `Käivita_2()`, `실행인수.kaup_COUNT()`, `실행인수.Tekst(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
oma JVM의 `한국어화면호출`, `Joonis_lõim`가 Eesti tund_VALUE·meetod_VALUE·서술자를
해석해 화면 요소와 Täida_käsk 가닥을 직접 만든다. Nimi 알림도 oma 객체이며
콜백으로 `Käivita`와 `saama_Toiming`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 Täida_käsk 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 oma JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 host JVM에서 무동작 객체가 생기지 않도록 하는 keelduma_VALUE 경로다.
oma JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 number 없다. host javac로 컴파일한 Tagasi_VALUE oma JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import Eesti.oma.*;
public class 가닥예제 implements 실행할일 {
    public void Käivita() { Väljund.kirjutamine_liin("Eesti 작업 Täida_käsk"); }
    public static void Käivita_2() throws 대기중단예외 {
        töötaja lõim_VALUE = 작업.Käivita_2(new 가닥예제());
        작업.기다리기(lõim_VALUE);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
ARRAY_VALUE Argumendid 대신 `실행인수`, 길이는 `문자.bait_COUNT`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
oma 실행기는 Argumendid 없는 `Käivita_2()`을 우선한다.
기존 Eesti 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.Käivita_2(Runnable)`을 사용하던 코드는 새 Eesti 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API tugi_VALUE 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 tund_VALUE·meetod_VALUE 이름과 서술자가 남는다.
Eesti Nimi_2 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·meetod_VALUE 재정의, native Ühendu, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS identifikaator_VALUE](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS meetod_VALUE viide](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
