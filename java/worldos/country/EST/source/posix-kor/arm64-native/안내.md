# oma ARM64 Java 커널의 C/C++ Fail·루프백 Ühendu

이 디렉터리는 `platforms/rpi4-native` oma tuum_VALUE 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 Eesti 함수명과 `extern "C"` ABI를 제공한다. `Ühendu.c`는 tuum_VALUE 안에서 AOT Java Fail 메서드에 직접 연결하고, `kasutaja_sild.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. tegelik_andmed Fail 처리는 `Mälu_Failid.java`, 루프백 datagramm 처리는 `tagastusliides_võrk.java`, 연결형 흐름은 `voog_võrk.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 tuum_VALUE 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·ujuv_p_VALUE lõikus_VALUE·Fail·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

tugi_VALUE: `avama_Fail`, `파일자료읽기`, `kirjutamine_Fail_andmed`, `Sule_Fail`, `otsima_Fail`, `eemaldama_Fail_kirje_nimetus`, `파일길이정하기`, 보조 FUNCTION_VALUE `faili_maht`. VIGA 시 -1과 작업별 `tõrke_number`를 반환한다. `kinnitamine_failisalvestusruum`은 RAM 파일이므로 ENOSYS를 반환한다. Fail 16개, 각 16384바이트, Nimi_2 63바이트, 서술자 16개이며 RAM 디렉터리·partner_VALUE/절대 경로를 제공한다. luba_VALUE/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 tegelik_andmed Eesti 함수와 독립 구조체를 선언한다.
`avama_osaleja`, `BIND_ADDRESS`, `saatma_datagramm_andmed/saama`, `Ühenda_võrk/기다리기/saama`는
`kasutaja_sild.c`에서 SVC를 호출하며 makro_VALUE 별칭이 아니다. `struct 인터넷통신주소`의
`ADDRESS_Pere`, `pordinumber`, `Interneti_aadress.ADDRESS_VALUE`을 사용한다. 상수는 enum의
`pilv_Pere`, `datagrammisokkel`, `datagramm_protokoll`, `voog_võrk`, `voog_transpordiprotokoll`이다.
Eesti·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. väline_VALUE 통신은 oma 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. tegelik_andmed Pi 4 GENET 드라이버는 미지원이다.
소켓도 tegelik_andmed FUNCTION_VALUE `Sule_Fail`로 닫는다.
