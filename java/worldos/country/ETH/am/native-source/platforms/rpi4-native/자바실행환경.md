# 자체 ARM64 JVM 0.4와 አማርኛ ማከማቻ_ስፍራ

አማርኛ 통신·ልዩነት 사용법은 [አማርኛ Java API](한국어자바/አንበኝ_eb81d7d9.md), ተግባር_እሴት·변수·ፋይል 이름의 변경과 어원 근거는 [명명 አንበኝ_eb81d7d9](명명/አንበኝ_eb81d7d9.md)를 참고한다.

JAR ፈጽም_ትእዛዝ, 외부 IPv4 TCP/UDP, 별도 አይንቀሳቀሴ_እሴት 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 ነገር_እሴት·Thread·Swing은 JVM 경로의 기능이며 AOT ድገፍ_እሴት 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 ፈጽም_ትእዛዝ**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK መደብ_እሴት ማከማቻ_ስፍራ 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 መደብ_እሴት·አይንቀሳቀሴ_እሴት ስልት_እሴት 중심이던 실행기를 ነገር_እሴት·ማከማቻ_ስፍራ ፈጽም_ትእዛዝ 기반으로 넓힌 것이다.

## 실행과 መገንባት_ምንጭ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# 자체 ዓንኳር_እሴት 안에서 ምንጭ_ዛፍ መገንባት_ምንጭ → class ፈጽም_ትእዛዝ, አማርኛ API 호출
python3 መሳሪያዎች/ፈጽም_ፋይል.py 시험/자바/한글소스.java

# ነገር_እሴት·ልዩነት 등은 አዘጋጅ_b78e430d JDK로 Java 8 class를 만든 후 자체 커널에서 ፈጽም_ትእዛዝ
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 መሳሪያዎች/ፈጽም_ፋይል.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 ትልልፍ_እሴት
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 መሳሪያዎች/ፈጽም_ፋይል.py build/my-java/객체시험.class \
  --include build/my-java/ልጣፍ_እሴት.class --include build/my-java/ቅርንጫፍ_እሴት.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.መደብ_እሴት.class`라는 RAM ፋይል 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.መደብ_እሴት`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.መደብ_እሴት`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar ፋይል.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 አማርኛ 클래스만 찾는다. 배포 አማርኛ ማከማቻ_ስፍራ JAR는 አዘጋጅ_b78e430d javac의 classpath로 사용하며, 같은 클래스가 ተጠቃሚ JVM ELF에도 ማንበቢያ 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 አይንቀሳቀሴ_እሴት ስልት_እሴት, int/boolean/char/String, ሁኔታ·ሽምጥ_እሴት, ኅብረቁምፊ_እሴት 결합, 일부 ፋይል 스트림 등의 **자체 부분집합 컴파일러**다. ነገር_እሴት እወጃ·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 자체 JVM에서 실행한다. አማርኛ API 중 ውጤት·문자 스칼라 ተግባር_እሴት·ፋይል ማንበቢያ/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] 인수) throws Exception {
        አማርኛ.자체.ውጤት.ጻፍ_መስመር("안녕하세요😀");
        አማርኛ.자체.ውጤት.수쓰기(አማርኛ.자체.문자.코드포인트수("한글😀"));
        አማርኛ.자체.ፋይል.መጻፊያ("인사.txt", "한글 ፋይል😀");
        አማርኛ.자체.ውጤት.ጻፍ_መስመር(አማርኛ.자체.ፋይል.ማንበቢያ("인사.txt"));
    }
}
```

예외는 Throwable/Exception/RuntimeException, ArithmeticException, NullPointerException, IndexOutOfBoundsException/ArrayIndexOutOfBoundsException/StringIndexOutOfBoundsException, IllegalArgumentException/NumberFormatException/IllegalThreadStateException, IOException/FileNotFoundException, IllegalStateException, ClassCastException, NegativeArraySizeException, ArrayStoreException, UnknownHostException, SocketTimeoutException의 제한된 አዘጋጅ·ምድብ_እሴት·처리를 제공한다. ተጠቃሚ ፍቺ_እሴት Throwable 상속, stack trace/cause/suppressed ልዩነት, try-with-resources의 addSuppressed, 완전한 ጀምር ስህተት 포장은 아직 없다. 잡히지 않은 예외는 현재 전체 Java 실행을 실패로 끝낸다.

## አማርኛ API

독립 패키지 **`አማርኛ.자체`**를 사용한다. Linux판 `አማርኛ.자바`가 요구하는 NIO/Swing/HTTP API를 자체 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 መደብ_እሴት ስም·ስልት_እሴት·인수·መስክ_እሴት·ፋይል 이름에 한국어를 사용한다. 표준 Java መደብ_እሴት 이름은 호환성을 위해 보존한다.

| መደብ_እሴት | 공개 기능 | 이름의 의미 |
|---|---|---|
| ውጤት | መጻፊያ, ጻፍ_መስመር, 수쓰기 | ውጤት(出力): 내용을 바깥으로 내보냄 |
| 문자 | ርዝመት_እሴት, 같음, ለጥፍ_ጽሁፍ, ቁረጥ_እሴት, ተንትን_ኢንተጀር/ጻፍ_ኢንተጀር_እሴት, 코드포인트수, 부호화/ምስጠራውን_ፍታ_ውሂብ | 문자(文字), በኮድ_መክተት_እሴት(符號): 글의 단위와 그 값을 바이트로 나타내는 ደንብ_እሴት |
| ፋይል | ማንበቢያ/መጻፊያ(String ስም), 바이트읽기/ጻፍ_ባይት_እሴት | 널리 쓰는 ተጠቃሚ 용어를 보존; RAM 자료의 ስም |
| ምዝግብ_ዝርዝር | 더하기, ማንበቢያ, ተካ_እሴት, አስወግድ_ምዝግብ_c8dbc399, መጠን, የመረጃ_ቴክኖሎጂ_ባዶ_እሴት, አጽዳ_ይዞታዎች | ምዝግብ_ዝርዝር(目錄): 순서가 있는 ምዝግብ_እሴት 모음 |
| መዝገበ_ቃላት | 넣기, አግኝ_ምዝግብ, 있는가, አስወግድ_ምዝግብ_c8dbc399, መጠን, አጽዳ_ይዞታዎች | መዝገበ_ቃላት(辭典): 찾는 말인 열쇠에 값을 대응 |
| 작업 | ማስኬጃ(실행할일), 기다리기(작업가닥), አግድ_ተግባር, 살아있는가 | 작업 ክር_እሴት: 한 ፕሮግራም_f5044b9b 안의 ፈጽም_ትእዛዝ ልቀቅ_እሴት |
| 통신 | መክፈቻ, ላክ, 받기, 대기시간, መዝጊያ | 통신(通信), 전문(電文), ወደብ_እሴት: ውሂብ 교환·메시지·포트의 역할 |
| 화면 | 사각형, አስወግድ_ምዝግብ_c8dbc399 | 화면(畫面): ትክክለኛ_ውሂብ 그림을 표시하는 면 |

이 명명은 현재 기능을 설명하는 용어 선택이다. 기존 한국어에 없던 역사적 어원을 만들어 주장하지 않는다. ፋይል_ስም_ጽሁፍ·식별자는 UTF-8 소스로 보관한다. `문자.ምስጠራውን_ፍታ_ውሂብ`는 잘못된 UTF-8에 IllegalArgumentException을 던지며, `부호화`는 짝이 없는 서로게이트를 `?`로 바꾼다. `ፋይል.ማንበቢያ`는 엄격한 UTF-8 복호화를 적용한다. 화면 색은 `빨강 | (초록 << 8) | (파랑 << 16)` 형식이다.

## ፈጽም_ትእዛዝ 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(አማርኛ መደብ_እሴት 포함), class당 16 KiB·ቋሚ_እሴት 풀 511항목, 전체 ስልት_እሴት/መስክ_እሴት 각각 512개. ስልት_እሴት 코드 8 KiB, የአካባቢ_ስፋት 변수·피연산자 스택 각각 128슬롯, 인수 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 ፈጽም_ትእዛዝ 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- ነገር_እሴት 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 ትክክለኛ_ውሂብ 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 ፋይል·대형 ኅብረቁምፊ_እሴት·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 ትእዛዝ 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 መስኮት ቀይር_ሁነታ 시 중단·재개한다. 일반 አገልጋይ_እሴት·계산의 무제한 실행은 아직 없다. 미지원 ትእዛዝ·ሃብት_እሴት 부족은 명시적인 오류로 종료한다.
- RAM ፋይል 최대 64개, 파일당 16384바이트, መተላለፊያ UTF-8 63바이트. RAM 디렉터리와 አቻ_እሴት/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 አማርኛ class는 RAM ፋይል 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 현재 경로에서 ምንጭ_ዛፍ·መደብ_እሴት·ውሂብ 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 외부 IPv4를 제공한다. ትክክለኛ_ውሂብ GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. 전문 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 ፈጽም_ትእዛዝ 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 ድርድር_እሴት, 완전한 ድርድር_እሴት 공변성·인터페이스 ንብርብር_እሴት 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/አመስጥር_ውሂብ/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 ድገፍ_እሴት 부분집합은 아래 및 개발 매뉴얼을 참고한다. መደብ_እሴት ፋይል 전체 검증기·መዳረሻ_ምዝግብ ፈቃድ_እሴት/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 ጠብቅ_እሴት 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM እሴት/ትክክለኛነት_አረጋግጥ/መደብ_እሴት 로더와 ልዩነት 모델 → 영속 VFS·mmap·ሰዓት·원자 ክወና_እሴት·ትክክለኛ_ውሂብ 스레드/አመሳስል ABI → OpenJDK java.base 및 native ማከማቻ_ስፍራ 이식 → መሳሪያ_እሴት 네트워크·TCP/IP → መስኮት 시스템/ቅርጸ_ቁምፊ_እሴት/입력기·java.desktop → Java SE 호환성 시험. 현재 자체 JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## ትክክለኛነት_አረጋግጥ

`መሳሪያዎች/자바가상기계시험.py`는 같은 Java 8 class 파일의 출력을 አዘጋጅ_b78e430d OpenJDK `-Xverify:all`과 QEMU raspi4b 자체 커널에서 비교한다. ነገር_እሴት/상속/인터페이스·switch·ድርድር_እሴት, ልዩነት/finally, 컬렉션/GC, Thread/잠금, አማርኛ UTF-8/ፋይል/컬렉션, ትክክለኛ_ውሂብ UDP 루프백/ጊዜ_እሴት 초과, 게스트 한글 ምንጭ_ዛፍ መገንባት_ምንጭ, ድርድር_እሴት ተይብ_እሴት/ቅዳ_እሴት/ፋይል 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 ፋይል አትቀበል_እሴት 시험을 실행한다. UDP አሳይ_ስር 실행에는 አዘጋጅ_b78e430d 루프백 소켓 권한이 필요하다.

`መሳሪያዎች/부팅시험.py`는 ዓንኳር_እሴት ጠብቅ_እሴት/회귀 시험과 별도로 አማርኛ Java 화면 API가 ትክክለኛ_ውሂብ 픽셀을 그렸는지도 QMP 화면 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. ትክክለኛ_ውሂብ Pi4 하드웨어 부팅 시험과 전체 JDK 호환성 시험 결과는 아니다.


## JVM 0.3: 네트워크와 GUI ቅጥያ_እሴት

`Socket`/`ServerSocket` አዘጋጅ·መገናኛ·accept·양방향 InputStream/OutputStream·close·EOF·ጊዜ_እሴት 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 외부 숫자 IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 ጨርስ_ቦታ 16개, Java 루프백 버퍼 1024바이트, 외부 TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. በይነተገናኝ 이벤트 대기는 ፈጽም_ትእዛዝ 기한을 갱신하고 ተርሚናል ቀይር_ሁነታ 시 프로세스 상태를 ማከማቻ_እሴት·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

አማርኛ `መስኮት`, `ዊድጌት`, `연결통신` 클래스를 배포 JAR와 자체 JVM 내장 자원에 추가했다. 상세 ስልት_እሴት·제한·ምንጭ_ዛፍ·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## አማርኛ 객체의 직접 ፈጽም_ትእዛዝ

`መስኮት`, `ምልክት`, `ጽሁፍ_መስክ`, `አዝራር`, `ፍጻሜ_ሰልፍ`, `동작알림`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. 자체 JVM의 ነገር_እሴት አዘጋጅ,
ቅርጸት_እሴት 검사, 화면 호출, ፍጻሜ 큐, ክር_እሴት 스케줄러에 አማርኛ 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 ፈጽም_ትእዛዝ 경로도 유지한다.
አማርኛ 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

자체 실행기의 አማርኛ 진입점은 `public static void ማስኬጃ()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 አማርኛ 진입점을 우선한다.
명령행 인수는 `실행인수.개수()`와 `실행인수.ጽሁፍ(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. አይንቀሳቀሴ_እሴት ፋይል 예제는 게스트
javac로도 컴파일하며, GUI/ክር_እሴት 소스는 አዘጋጅ_b78e430d `javac --release 8`을 사용한다.
직접 GUI/ክር_እሴት API는 자체 JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
አማርኛ 가닥의 ፈጽም_ትእዛዝ·መጠበቅ_እሴት·중복 ማስኬጃ አትቀበል_እሴት, GUI ፍጻሜ 출처·መረጃ_ጠቆመ·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

ስልት_እሴት 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
አማርኛ 클래스도 실행되지만, ኅብረቁምፊ_እሴት 리터럴·표준 ማከማቻ_ስፍራ 재정의·native
መገናኛ·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 예제](한국어자바/አንበኝ_eb81d7d9.md)를 참고한다.

## ተርሚናል 부분 አድስ

አንቀሳቅስ_እሴት·መጠን 변경은 새 መስኮት 영역과 이전 자리에서 드러난 띠만 합성한다.
1920×32 ፒክስል(240 KiB)의 임시 그림에서 배경·겹친 መስኮት·ቁምፊ_እሴት·GUI를 먼저
완성하고, 현재 አሳይ_እሴት 메모리와 비교하여 달라진 화소만 기록한다.
32줄보다 큰 영역은 여러 띠로 처리하므로 전체 프레임을 원자적으로
교체하거나 수직 동기에 맞추는 방식은 아니다. 전체 배경을 먼저 지우는
중간 화면은 표시하지 않는다. 좌표가 같으면 다시 그리지 않는다.

`make test-redraw`는 ትክክለኛ_ውሂብ C 그리기 코드를 호스트의 ማስቀመጫ_ውሂብ 화면에 연결해
አንቀሳቅስ_እሴት 80회·መጠን ለውጥ_እሴት 40회·겹친 መስኮት 4개를 전체 합성 결과와 ፒክስል 단위로 대조한다.
영역 밖 ተጠቃሚ ስዕል_እሴት, 동일 ፒክስል 무기록, ጠቋሚ 밑그림, ትክክለኛ_ውሂብ 화면 መስመር 간격을
검사한다. 이 시험의 시간은 አዘጋጅ_b78e430d CPU 측정이며 Pi 4/QEMU 속도로 해석하지 않는다.
`make test-resize`는 QEMU/VNC의 640×480 및 1920×1080에서 왼쪽 모서리 ጎትት_እሴት,
한글 입력·vi 미저장 ይዘት_እሴት·독립 መስኮት 크기를 검사한다.
