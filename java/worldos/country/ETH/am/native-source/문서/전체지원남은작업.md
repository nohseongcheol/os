# 전체 ድገፍ_እሴት 요청의 현재 ዞን_እሴት

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 ትክክለኛ_ውሂብ C POSIX 일부 기능, አማርኛ API/ምንጭ ስም, IDE ፋይል 보존, 게스트 Java ፋይል 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/አንበኝ_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 ፈጽም_ትእዛዝ 가능한 ቅንጥብ | 전체 지원에 필요한 작업 |
|---|---|---|
| Java መገንባት_ምንጭ·ፈጽም_ትእዛዝ | 게스트 제한형 javac/JVM, አይንቀሳቀሴ_እሴት 단일 클래스와 일부 표준 ነገር_እሴት | 일반 ነገር_እሴት·መደብ_እሴት መገናኛ·ልዩነት·GC·스레드, 완전한 javac와 표준 መደብ_እሴት ማከማቻ_ስፍራ |
| ፋይል | POSIX 서술자, Java 단일 ባይት_እሴት ፋይል ልቀቅ_እሴት, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·ፈቃድ_እሴት·잠금·일반 የፋይል_ስርዓት·ቅጥያ_እሴት 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP አዘጋጅ_b78e430d 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 ፍጻሜ·ቅርጸ_ቁምፊ_እሴት·መስኮት ስርዓተ_ክወና_እሴት, AWT 네이티브 연결과 Swing ፈጽም_ትእዛዝ 기반 |
| POSIX | 문서화한 ፋይል·단말·UDP 부분 | ሂደት_እሴት·exec/fork·스레드·시그널·ጊዜ_እሴት·mmap·poll·파이프 등과 적합성 ትክክለኛነት_አረጋግጥ |
| 언어별 ስም | አማርኛ 46개 대응 ምዝግብ_እሴት, ትክክለኛ_ውሂብ C/Java/ፋይል ስም 적용 | ዓላማ ቋንቋ 확정, 언어별 용례·역사 근거와 해당 ምንጭ·도구의 ትክክለኛነት_አረጋግጥ |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 ፈጽም_ትእዛዝ 환경을 추가하는 방식은 별도의 ዓንኳር_እሴት·루트 የፋይል_ስርዓት·OpenJDK·그래픽 አገልጋይ_እሴት·영구 ማከማቻ_እሴት 구성을 가진 ፈጽም_ትእዛዝ 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

ፈጽም_ትእዛዝ 기반과 추가 ዓላማ 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
