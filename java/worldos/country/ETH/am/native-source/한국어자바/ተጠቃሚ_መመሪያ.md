# jkoros አማርኛ ማከማቻ_ስፍራ ተጠቃሚ_መመሪያ

확인일: 2026-09-27. 대상은 `platforms/rpi4`의 **ARM64 Linux + OpenJDK 실행판**이며, QEMU에서도 같은 Java 라이브러리를 사용한다. `os/`의 자체 x86 ዓንኳር_እሴት 및 `ነባር_ምንጭ/`의 관리 ዓንኳር_እሴት 모형과 구분한다.

## 1. 현재 제공하는 ማከማቻ_ስፍራ

패키지는 `አማርኛ.자바`, ስርዓተ_ክወና 안의 JAR 경로는 `/opt/jkoros/lib/한국어자바.jar`다. **도우미 መደብ_እሴት 5개, 공개 አይንቀሳቀሴ_እሴት ስልት_እሴት 22개, 별도 GUI 프로그램인 የሥራ_ቦታ 1개**가 있다. JAR는 Java 11 이상을 대상으로 빌드하며 현재 ARM64 배포판에는 OpenJDK 25가 포함돼 있다.

| መደብ_እሴት | ስልት_እሴት 수 | 기능 | ምንጭ |
|---|---:|---|---|
| `ፋይል` | 9 | UTF-8 텍스트·ባይት_እሴት ፋይል, ማውጫ_እሴት, ምዝግብ_ዝርዝር | [ፋይል.java](ምንጭ/አማርኛ/자바/ፋይል.java) |
| `문자` | 5 | UTF-8 변환, NFC አጠናቅር_እሴት, 코드 포인트, ኅብረቁምፊ_እሴት 경계 | [문자.java](ምንጭ/አማርኛ/자바/문자.java) |
| `통신` | 2 | HTTP(S) GET, TCP መገናኛ | [통신.java](ምንጭ/አማርኛ/자바/통신.java) |
| `작업` | 4 | 스레드 ፈጽም_ትእዛዝ·መጠበቅ_እሴት, 고정 መጠን 작업 ፕሮግራም_የመተግበሪያ_መሳቢያ | [작업.java](ምንጭ/አማርኛ/자바/작업.java) |
| `화면` | 2 | Swing 이벤트 ሂደት_እሴት_ምዝግብ 가닥에 작업 예약, መስኮት አዘጋጅ | [화면.java](ምንጭ/አማርኛ/자바/화면.java) |
| `የሥራ_ቦታ` | ምዝግብ_ቦታ `main` | Java ምንጭ አርትዕ_እሴት·ማከማቻ_እሴት·መገንባት_ምንጭ·ፈጽም_ትእዛዝ | [የሥራ_ቦታ.java](ምንጭ/አማርኛ/자바/የሥራ_ቦታ.java) |

표준 JDK 전체를 한국어로 번역한 라이브러리는 아니다. Java 키워드와 `String`, `Path`, `Socket`, `JFrame`, `IOException` 같은 표준 የውሂብ_ዓይነት·예외를 함께 사용한다. 이 도우미에 없는 기능은 OpenJDK의 표준 API 또는 별도 라이브러리로 구현한다. 예를 들어 HTTP POST, UDP, Swing አዝራር·메뉴에는 각각 표준 Java API를 사용한다.

## 2. Java에서 ጀምር_ተግባር

게스트 운영체제의 작업 폴더에서 `사용예.java`를 작성한다.

```java
import አማርኛ.자바.*;
import java.nio.file.Path;

public class 사용예 {
    public static void main(String[] 인수) throws Exception {
        Path ማውጫ_እሴት = ፋይል.ፍጠር_ማውጫ(ፋይል.መተላለፊያ("사용예자료"));
        Path 문서 = ማውጫ_እሴት.resolve("인사.txt");
        ፋይል.መጻፊያ(문서, "한글 😀");
        String ይዘት_እሴት = ፋይል.ማንበቢያ(문서);
        System.out.println(ይዘት_እሴት);
        System.out.println(문자.코드포인트수(ይዘት_እሴት)); // 한, ጽሁፍ, 공백, 😀 → 4
        Thread 일 = 작업.ማስኬጃ("인사 작업", () -> System.out.println("작업 ፈጽም_ትእዛዝ"));
        작업.기다리기(일);
    }
}
```

```sh
javac -encoding UTF-8 -cp /opt/jkoros/lib/한국어자바.jar 사용예.java
java -cp .:/opt/jkoros/lib/한국어자바.jar 사용예
```

로그인 환경에 ነባሪ_እሴት `CLASSPATH`도 설정돼 있지만, 명시적인 `-cp`는 다른 ፈጽም_ትእዛዝ 환경에서도 경로를 분명하게 한다. 사용자가 `-cp`를 지정하면 필요한 JAR와 መደብ_እሴት 폴더를 모두 그 값에 포함해야 한다.

አዘጋጅ_b78e430d 저장소에서는 다음처럼 ግንብ_ስርዓት·실행한다. አዘጋጅ_b78e430d 경로와 게스트의 `/opt/...` 경로는 서로 다르다.

```sh
cd /home/user/jkoros/한국어자바
make
javac -encoding UTF-8 -cp build/한국어자바.jar 예제/인사.java
java -cp build/한국어자바.jar:예제 인사
```

## 3. 전체 도우미 API

아래 메서드는 모두 `public static`이며, 객체를 만들지 않고 `ፋይል.ማንበቢያ(...)`처럼 호출한다. 표의 이름은 ትክክለኛ_ውሂብ ምንጭ_ዛፍ 및 JAR의 `javap -public` 결과와 대조했다. 선언된 검사 ልዩነት 외에도 잘못된 인수 등에 대한 표준 Java ፈጽም_ትእዛዝ 시 예외가 발생할 수 있다.

### ፋይል: `አማርኛ.자바.ፋይል`

`Path`는 `java.nio.file.Path`, `List`는 `java.util.List`다.

| ስልት_እሴት | 반환형 | ተግባር·ሁኔታ |
|---|---|---|
| `መተላለፊያ(String ስም)` | `Path` | 이름을 መተላለፊያ 객체로 변환. ትክክለኛ_ውሂብ 파일을 만들지는 않음 |
| `ማንበቢያ(Path መተላለፊያ)` | `String` | ፋይል 전체를 UTF-8 텍스트로 읽음 |
| `መጻፊያ(Path መተላለፊያ, String ይዘት_እሴት)` | `Path` | UTF-8 ማከማቻ_እሴት. 파일이 없으면 생성하고, 있으면 기존 내용을 비움 |
| `바이트읽기(Path መተላለፊያ)` | `byte[]` | ፋይል 전체를 ባይት_እሴት 배열로 읽음 |
| `ጻፍ_ባይት_እሴት(Path መተላለፊያ, byte[] ይዘት_እሴት)` | `Path` | ባይት_እሴት ማከማቻ_እሴት. 없으면 생성하고, 있으면 기존 내용을 비움 |
| `ፍጠር_ማውጫ(Path መተላለፊያ)` | `Path` | 필요한 상위 폴더까지 አዘጋጅ |
| `있는가(Path መተላለፊያ)` | `boolean` | 존재 여부 አረጋግጥ. 확인할 수 없는 경우도 `false`일 수 있음 |
| `አስወግድ_ምዝግብ_c8dbc399(Path መተላለፊያ)` | `boolean` | 삭제했으면 `true`, 없으면 `false`. 폴더의 재귀 삭제는 아님 |
| `ምዝግብ_ዝርዝር(Path መተላለፊያ)` | `List<Path>` | 바로 아래 항목을 መተላለፊያ አሰልፍ_እሴት 순서로 반환. 재귀 탐색은 아님 |

`መተላለፊያ`, `있는가`를 제외한 위 메서드는 `IOException`을 선언한다. `መጻፊያ`와 `ጻፍ_ባይት_እሴት`는 상위 폴더를 자동으로 만들거나 내용을 이어 쓰지 않는다. 필요한 폴더는 먼저 생성한다. 큰 파일은 전체 내용을 메모리에 담는 대신 표준 Java 스트림·ሰርጥ_እሴት API를 사용하는 방식으로 작성할 수 있다.

### 문자: `አማርኛ.자바.문자`

| ስልት_እሴት | 반환형 | ተግባር·ሁኔታ |
|---|---|---|
| `부호화(String ይዘት_እሴት)` | `byte[]` | 문자열을 UTF-8 바이트로 변환 |
| `ምስጠራውን_ፍታ_ውሂብ(byte[] ይዘት_እሴት)` | `String` | UTF-8 바이트를 문자열로 변환. 잘못된 입력은 대체 문자로 ሂደት_እሴት_ምዝግብ |
| `አጠናቅር_እሴት(String ይዘት_እሴት)` | `String` | ዩኒኮድ_እሴት NFC አጠናቅር_እሴት. 예: 조합 자모 `ᄀ` + `ᅡ` → `가` |
| `코드포인트수(String ይዘት_እሴት)` | `int` | UTF-16 코드 단위가 아닌 ዩኒኮድ_እሴት 코드 포인트 수 |
| `낱말(String ይዘት_እሴት, Locale ቋንቋ)` | `List<String>` | 지정 언어의 `BreakIterator` 낱말 경계로 나눈 구간 |

`낱말`은 공백·문장부호 구간도 반환한다. 자연어 형태소 분석기나 공백을 제거한 ቃል_እሴት ምዝግብ_ዝርዝር API는 아니다. `አጠናቅር_እሴት`는 입력기나 ተርጉም_ምንጭ 기능이 아니다. 코드 포인트 수 역시 사람이 보는 ቁምፊ_እሴት 수와 항상 같지는 않다. 여러 코드 포인트로 이루어진 결합 문자·가족 이모지 등을 구분해야 한다.

### 통신: `አማርኛ.자바.통신`

| ስልት_እሴት | 반환형 | ተግባር·ሁኔታ |
|---|---|---|
| `가져오기(URI አድራሻ, Duration የ_ግዜ_ገደብ)` | `HttpResponse<String>` | HTTP(S) GET. መገናኛ 및 요청 የ_ግዜ_ገደብ ማሰናጃዎች. መልስ 본문을 UTF-8로 ተንትን_እሴት |
| `연결하기(String አድራሻ, int 포트, int 제한밀리초)` | `Socket` | TCP መገናኛ 후 같은 값으로 ማንበቢያ 제한시간도 ማሰናጃዎች |

`가져오기`는 `IOException`, `InterruptedException`을 선언한다. 제한시간은 양수다. 404·500 같은 HTTP ስህተት 상태도 응답으로 반환하므로 `statusCode()`로 판단하고 `body()`로 본문을 읽는다. 현재 구현은 호출마다 HTTP 클라이언트를 만들며 자동 리다이렉트 설정을 추가하지 않는다.

`연결하기`는 `IOException`을 선언한다. 연결된 소켓은 호출자가 `close()` 또는 try-with-resources로 닫아야 한다. 제한밀리초의 0은 제한 없음이며, መጻፊያ 전체의 마감 시간을 보장하는 옵션은 아니다.

```java
var መልስ = 통신.가져오기(
    java.net.URI.create("http://127.0.0.1:8000/"),
    java.time.Duration.ofSeconds(5));
System.out.println(መልስ.statusCode());
System.out.println(መልስ.body());
```

위 조각은 ስልት_እሴት 안에서 실행하며 별도로 해당 주소의 서버를 실행해야 한다. Java ልዩነት 처리가 필요하다.

### 작업: `አማርኛ.자바.작업`

| ስልት_እሴት | 반환형 | ተግባር·ሁኔታ |
|---|---|---|
| `ማስኬጃ(String ስም, Runnable ተግባር)` | `Thread` | 이름을 지정한 스레드를 만들고 즉시 ማስኬጃ |
| `기다리기(Thread ክር_እሴት)` | `void` | 해당 스레드가 종료할 때까지 `join()` |
| `쉬기(long 밀리초)` | `void` | 호출한 스레드를 지정 ጊዜ_እሴት 동안 `sleep()` |
| `작업대(int 가닥수)` | `ExecutorService` | 고정 መጠን 작업 ፕሮግራም_የመተግበሪያ_መሳቢያ አዘጋጅ. 가닥수는 양수 |

`기다리기`, `쉬기`는 `InterruptedException`을 선언한다. 작업 실행기는 사용 후 `shutdown()`으로 종료하고 필요하면 `awaitTermination(...)`으로 완료를 기다린다. Swing 이벤트 ሂደት_እሴት_ምዝግብ 가닥에서 긴 작업이나 `기다리기`를 실행하면 화면이 멈출 수 있다.

### 화면: `አማርኛ.자바.화면`

| ስልት_እሴት | 반환형 | ተግባር·ሁኔታ |
|---|---|---|
| `나중에(Runnable ተግባር)` | `void` | Swing 이벤트 ሂደት_እሴት_ምዝግብ 가닥에 실행을 예약하고 반환 |
| `መስኮት(String መስኮት_ርዕስ, JComponent ይዘት_እሴት, int 너비, int 높이)` | `JFrame` | ይዘት_እሴት·크기를 지정한 창을 생성해 አሳይ_እሴት |

`መስኮት`을 Swing 이벤트 ሂደት_እሴት_ምዝግብ ክር_እሴት 밖에서 부르면 `IllegalStateException`이 발생한다. 그래픽 세션도 필요하다. QEMU에서는 VNC 데스크톱의 터미널에서 실행한다.

```java
화면.나중에(() -> 화면.መስኮት(
    "አማርኛ 화면", new javax.swing.JLabel("안녕하세요"), 500, 180));
```

반환된 `JFrame`에 표준 Swing API를 추가로 사용할 수 있다. 창의 መዝጊያ 동작은 `DISPOSE_ON_CLOSE`다. `화면.나중에`가 반환됐다고 መስኮት 생성이 이미 끝난 것은 아니다.

### የሥራ_ቦታ: አርትዕ_እሴት·መገንባት_ምንጭ GUI

```sh
java -cp /opt/jkoros/lib/한국어자바.jar አማርኛ.자바.የሥራ_ቦታ
```

`~/workspace`의 원문을 መክፈቻ·저장하고, `javac`로 컴파일해 `java`로 실행한다. ፈጽም_ትእዛዝ ፋይል 만들기는 `jclassc --target openjdk` 경로를 사용한다. 작업마당은 개발용 프로그램이며 별도의 ፋይል·문자 API 클래스가 아니다. 생성하는 ፈጽም_ትእዛዝ ፋይል 방식은 [컴파일러 설명](../compiler/OpenJDK-실행파일.md)을 따른다.

## 4. Python과 C++에서 사용할 수 있는가?

| ስልት_ሁነታ | 현재 포함 ዞን_እሴት | 호출 가능 ቅንጥብ |
|---|---|---|
| Java → አማርኛ JAR | ነባሪ_እሴት 포함 | 위 22개 메서드와 የሥራ_ቦታ |
| Python → `java` ልጅ_እሴት 프로세스 | Python·Java ነባሪ_እሴት 포함 | 작은 Java 진입점을 통해 호출하고 표준 ውጤት·ፋይል 등으로 ልኬት አሳልፍ_እሴት |
| Python → JPype → JVM | JPype는 ነባሪ_እሴት 배포에 없음 | 별도 ጫን_እሴት 후 Java መደብ_እሴት·ስልት_እሴት 호출 가능. 이 배포판의 ARM64/musl/Python 3.14 조합은 추가 ትክክለኛነት_አረጋግጥ 필요 |
| C++ → JNI → JVM | `g++`, JNI 헤더, `libjvm.so` 포함 | JVM을 생성하고 አማርኛ መደብ_እሴት·메서드를 직접 호출할 수 있음 |
| Python용 독립 አማርኛ ማከማቻ_ስፍራ | 현재 ነባሪ_እሴት 제공 없음 | 필요하면 Python 표준 라이브러리를 감싸는 አማርኛ 모듈을 별도로 작성 |
| C/C++용 독립 አማርኛ ማከማቻ_ስፍራ | 자체 x86 `posix-kor`와 자체 ARM64 커널용 초기 RAM ፋይል 연결이 별도로 존재 | 둘 다 이 Linux/OpenJDK 실행판의 libc 라이브러리는 아님 |

Python의 일반 `import`나 `ctypes.CDLL`로 JAR를 바로 읽을 수는 없다. C++의 `#include`나 일반 네이티브 링커만으로 Java 메서드를 연결할 수도 없다. JVM 프로세스 또는 JVM መገናኛ 계층을 거쳐야 한다.

### Python: 추가 패키지 없이 호출

ፈጽም_ትእዛዝ 가능한 예제 원문은 [문자명령.java](예제/다른언어/문자명령.java), [파이썬호출.py](예제/다른언어/파이썬호출.py)다. Python이 Java 진입점을 실행하고 `문자.코드포인트수`의 ኢንተጀር 결과를 받는다. 인수 목록을 사용하며 ሼል ትእዛዝ 문자열을 조립하지 않는다. `subprocess.run`의 프로세스 ፈጽም_ትእዛዝ·ውጣ_ፕሮግራም 코드·ውጤት ሂደት_እሴት_ምዝግብ 방식은 [Python 공식 문서](https://docs.python.org/3/library/subprocess.html)를 따른다.

두 예제 파일을 게스트의 같은 폴더에 복사한 ተመለስ_እሴት 그 폴더에서 실행한다. 예제 ፋይል 자체는 ነባሪ_እሴት 시스템 이미지에 자동 설치돼 있지 않다.

```sh
mkdir -p classes
javac -encoding UTF-8 -cp /opt/jkoros/lib/한국어자바.jar -d classes 문자명령.java
python3 파이썬호출.py --text '한글 😀'
```

ውጤት: `Python → አማርኛ.자바.문자.코드포인트수: 4`

이 예제의 Python ተግባር_እሴት `코드포인트수`는 이번 문서의 መገናኛ 예제이며 기존에 설치된 Python 라이브러리는 아니다. 현재 예제는 호출할 때마다 JVM 프로세스를 시작한다. Java ነገር_እሴት 자체를 Python으로 가져오는 방식은 아니며, 다른 메서드를 사용하려면 진입점의 인수·ልኬት 형식을 확장한다.

### Python: JPype로 같은 프로세스에서 호출

JPype를 별도 설치한 환경에서는 ቀጣይ_ንጥል_ነገር 형태로 연결할 수 있다. **아래는 የተመረጠ_እሴት 가능한 መገናኛ 방법이며, 현재 배포판에 JPype가 설치돼 있거나 ፈጽም_ትእዛዝ 검증됐다는 뜻은 아니다.** JVM 시작과 `JClass`를 통한 መደብ_እሴት 접근은 [JPype 공식 설명](https://jpype.readthedocs.io/en/latest/userguide.html)을 참고한다.

```python
import jpype

jpype.startJVM(
    "/usr/lib/jvm/java-25-openjdk/lib/server/libjvm.so",
    classpath=["/opt/jkoros/lib/한국어자바.jar"])
try:
    문자 = jpype.JClass("አማርኛ.자바.문자")
    print(문자.코드포인트수(jpype.JString("한글 😀")))
finally:
    jpype.shutdownJVM()
```

Python·JVM·መገናኛ 모듈의 CPU 아키텍처가 맞아야 한다. 이 실행판은 ARM64 + musl이므로 일반 x86_64/glibc용 바이너리를 그대로 설치하는 방식은 맞지 않는다. JPype ጫን_እሴት·패키지 빌드는 이번 문서 작업에서 수행하지 않았다.

### C++: JNI로 직접 호출

[자바호출.cpp](예제/다른언어/자바호출.cpp)는 ትክክለኛ_ውሂብ ፈጽም_ትእዛዝ 가능한 예제다. JVM을 작업 스레드에서 생성하고 ቀጣይ_ንጥል_ነገር 메서드를 찾는다.

```cpp
jclass type = env->FindClass("አማርኛ/자바/문자");
jmethodID method = env->GetStaticMethodID(
    type, "코드포인트수", "(Ljava/lang/String;)I");
```

JVM አዘጋጅ·종료와 스레드 연결은 [JNI Invocation API](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/invocation.html)의 방식이다. `JNIEnv*`는 አዘጋጅ·연결된 스레드에서 사용해야 한다. 예제는 Java 예외를 확인하고 JVM 종료까지 처리한다.

게스트에 `자바호출.cpp`를 복사한 ተመለስ_እሴት 컴파일한다. 로그인 환경의 `JAVA_HOME`은 `/usr/lib/jvm/java-25-openjdk`다.

```sh
g++ -std=c++11 -Wall -Wextra -pthread \
  -I"$JAVA_HOME/include" -I"$JAVA_HOME/include/linux" \
  자바호출.cpp -L"$JAVA_HOME/lib/server" \
  -Wl,-rpath,"$JAVA_HOME/lib/server" -ljvm -o 자바호출
./자바호출 /opt/jkoros/lib/한국어자바.jar
```

ውጤት: `C++ → አማርኛ.자바.문자.코드포인트수: 4`

예제는 `한글 😀`을 UTF-16으로 만들어 `NewString`에 전달한다. `NewStringUTF`가 받는 modified UTF-8은 일반 UTF-8과 차이가 있으므로, 일반 UTF-8 이모지 바이트를 그대로 넘기는 예제로 작성하지 않았다. [JNI ኅብረቁምፊ_እሴት ቅርጸት_እሴት](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/types.html#modified-utf-8-strings)

다른 አማርኛ 메서드도 JNI 서명과 인수 자료형을 맞춰 호출할 수 있다. 예를 들어 `Path`를 받는 ፋይል API는 먼저 `ፋይል.መተላለፊያ`로 Java መተላለፊያ 객체를 얻어 전달한다. Swing 호출에는 그래픽 세션과 이벤트 ሂደት_እሴት_ምዝግብ ክር_እሴት 규칙도 그대로 적용된다. JNI는 Java 실행을 기계어로 대체하는 기능이 아니며 JVM이 계속 필요하다.

### 기존 posix-kor와의 관계

추가된 [자체 ARM64 መገናኛ](../posix-kor/arm64-native/አንበኝ_eb81d7d9.md)은 C++에서 AOT Java 커널의 RAM ፋይል API를 직접 호출하며, 별도 EL0 ተጠቃሚ 라이브러리로 ፋይል/UDP 루프백 SVC 호출도 제공한다. JNI를 사용하지 않는다. 이 문서의 ARM64 **Linux** 및 አማርኛ Java JAR와는 다른 ፈጽም_ትእዛዝ 기반이며 자체 커널은 별도 제한형 Java 컴파일러/JVM과 MicroPython 1.24.1을 실행한다. MicroPython의 `import jkoros`로 Java ዓንኳር_እሴት ፋይል·UDP 루프백·사각형 호출이 가능하지만 이 문서의 JAR를 가져오는 기능은 아니다. 자체 커널의 전체 OpenJDK/JRE/CPython 이식은 아직 미완성이다.

[posix-kor](../posix-kor/አንበኝ_eb81d7d9.md)에는 `ክፈት_ፋይል`, `파일자료읽기`, `ጻፍ_ፋይል_ውሂብ`, `ዝጋ_ፋይል`, `통신종단점만들기`, `자료전문보내기` 등의 አማርኛ C 별칭이 있다. 그러나 구현은 **자체 jkoros i386 커널의 `int 0x80` 호출 규약용**이다.

이 `libposix-kor.a`와 자체 `sys/stat.h` 등의 헤더는 현재 ARM64 Linux 실행판의 libc/C++용 라이브러리가 아니다. 해당 헤더·바이너리를 ARM64 Linux 프로그램에 그대로 연결해서는 ABI가 맞지 않는다. C++용 አማርኛ መደብ_እሴት 라이브러리나 Python용 바인딩을 ነባሪ_እሴት 제공하는 상태도 아니다. 현재 Linux 실행판에서 그와 같은 독립 API를 제공하려면 Linux 표준 라이브러리를 대상으로 별도로 구현·빌드해야 한다.

## 5. አረጋግጥ 범위와 재현

패키지 포함 여부는 [배포 패키지 ምዝግብ_ዝርዝር](../platforms/rpi4/dist/packages.lock.json) 및 ግንብ_ስርዓት 루트의 ትክክለኛ_ውሂብ 파일로 확인했다. JNI 헤더는 JDK의 `include/jni.h`, `include/linux/jni_md.h`, JVM 라이브러리는 `lib/server/libjvm.so`에 있다. 사용자가 이후 별도로 설치한 패키지는 이 ነባሪ_እሴት 배포 목록과 다를 수 있다.

이번에 **አዘጋጅ_b78e430d x86_64/OpenJDK 11에서** Python ልጅ_እሴት 프로세스 호출과 C++ JNI 직접 호출을 መገንባት_ምንጭ·실행해 각각 ልኬት 4를 확인했다. JAR 공개 메서드도 소스와 대조했다. Python መገናኛ 예제는 추가 패키지를 설치하지 않는다.

문서의 Java 사용 예제도 መገንባት_ምንጭ·실행했고, 22개 메서드의 문서 포함 여부와 로컬 문서 링크를 확인했다. [예제 ትክክለኛነት_አረጋግጥ መዝግብ_ረድፍ](build/다른언어/ማረጋገጥ_ዘገባ.json)

기존 ARM64 QEMU에서는 Java의 ፋይል·ዩኒኮድ_እሴት·스레드·HTTP 및 Swing 시험 결과가 있다. 이번 Python/C++ መገናኛ 예제의 **ARM64 게스트 실행과 JPype 설치는 별도 검증하지 않았다.** 이미지와 ፈጽም_ትእዛዝ 중인 ተጠቃሚ 환경은 이 문서 작업에서 변경하지 않았다. [기존 ስርዓተ_ክወና ትክክለኛነት_አረጋግጥ መዝግብ_ረድፍ](../platforms/rpi4/VERIFICATION.md)

호스트에서 Python 예제를 재현하려면:

```sh
cd /home/user/jkoros/한국어자바
make
mkdir -p build/다른언어
javac -encoding UTF-8 --release 11 -cp build/한국어자바.jar \
  -d build/다른언어 예제/다른언어/문자명령.java
python3 예제/다른언어/파이썬호출.py \
  --jar build/한국어자바.jar --classes build/다른언어
```

አዘጋጅ_b78e430d C++ 예제는 위 JNI መገንባት_ምንጭ 명령의 JDK 경로를 **አዘጋጅ_b78e430d JDK መተላለፊያ**로 바꾸고, ምንጭ `예제/다른언어/자바호출.cpp`와 JAR `build/한국어자바.jar`를 지정한다. ARM64 게스트 JDK의 헤더·ማከማቻ_ስፍራ 경로를 አዘጋጅ_b78e430d x86_64 링크 명령에 섞지 않는다.
