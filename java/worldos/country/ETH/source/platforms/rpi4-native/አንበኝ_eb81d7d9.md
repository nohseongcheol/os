# Raspberry Pi 4 자체 Java ዓንኳር_እሴት — ተጠቃሚ ፈጽም_ትእዛዝ 기반

현재 자체 코드의 COSL 상업 ሁኔታ, 제3자 고지 및 LGPL 재연결 자료는 [COSL 배포 አንበኝ_eb81d7d9](COSL배포안내.md)를 참고한다. ቀይር_ሁነታ 전 GPL 구성의 판단은 [이전 라이선스 검토](ፈቃድ_ክለሳ.md)에 기록했다.

አማርኛ 통신·ልዩነት 사용법은 [አማርኛ Java API](한국어자바/አንበኝ_eb81d7d9.md), ተግባር_እሴት·변수·ፋይል 이름의 변경과 어원 근거는 [명명 አንበኝ_eb81d7d9](명명/አንበኝ_eb81d7d9.md)를 참고한다.

Linux 없이 부팅하는 자체 AArch64 커널이다. Java AOT ዓንኳር_እሴት 위에 **የትእዛዝ_መስመር ሼል, 게스트 Java 컴파일러·JVM, MicroPython, EL0 C++ ፈጽም_ትእዛዝ, ፋይል·UDP 루프백 시스템 호출, 여러 한글 GUI ተርሚናል·vi አርታዒ·Swing 부분집합**을 제공한다. 커널의 ፋይል ውሂብ/정책·루프백 ትልልፍ_እሴት·ሼል 상태는 Java, 화면 합성·ፒክስል ለውጥ_እሴት·ጠቋሚ·클리핑도 Java로 구현하며, CPU/MMU/መሳሪያ_እሴት 경계와 ተርሚናል·ቁምፊ_እሴት 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 자체 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 ፈጽም_ትእዛዝ, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 ባለሽቦ_እሴት 송수신은 아직 미검증이다.** ፈጽም_ትእዛዝ·ግንኙነት_e05f319b·የይለፍ_ቃል_እሴት 확인은 [외부 ግንኙነት_e05f319b አንበኝ_eb81d7d9](외부접속안내.md)에 정리했다.

셸은 EL1 ዓንኳር_እሴት, `java` 등 ተጠቃሚ ፈጽም_ትእዛዝ 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 ፈጽም_ትእዛዝ·ግንኙነት_e05f319b 방법 및 ትክክለኛ_ውሂብ 검증은
[ፈጽም_ትእዛዝ 계층과 외부 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 ትክክለኛ_ውሂብ ፈጽም_ትእዛዝ 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 አይንቀሳቀሴ_እሴት ELF는 `run --linux ፋይል_ስም_ጽሁፍ`으로 실행한다. [ELF·Linux ABI ድገፍ_እሴት 범위와 동일 바이너리 시험](실행파일규약.md).

GUI와 네트워크는 `python3 መሳሪያዎች/ፈጽም_ትእዛዝ.py --desktop --network`로 함께 사용한다. Java·C·Python의 አማርኛ 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 부팅 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 수 있다. Remmina에서 **F9/Shift+Space/한·영 ቁልፍ_እሴት**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·ትክክለኛ_ውሂብ TCP/UDP·ፋይል ባይት_እሴት·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java 창예제`로 አማርኛ Swing 예제를 실행한다. ተርሚናል 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 현재 አምድ_እሴት·ረድፍ_እሴት 수를 보여 준다.

ፈጽም_ትእዛዝ 버튼 화면은 5×7 영문 글꼴을 쓰며, ተርሚናል 창은 Noto CJK/DejaVu에서 생성한 한글·Unicode 비트맵 글꼴을 쓴다. UART와 ትክክለኛ_ውሂብ 프레임버퍼의 한글 표시를 시험한다. 루프백은 동일 ዓንኳር_እሴት 내부의 전문 전달이며 IP 패킷을 Ethernet으로 내보내는 드라이버가 아니다. 바깥 IPv4는 lwIP TCP/UDP 스택으로 보조 UART SLIP 경로를 사용한다. `python3 መሳሪያዎች/ፈጽም_ትእዛዝ.py --network`로 QEMU NAT를 연결하고 `ftpd start`로 서비스를 시작한다.

Java의 정확한 API·문법·ፈጽም_ትእዛዝ 제한과 አማርኛ 사용법은 [자체 JVM과 አማርኛ ማከማቻ_ስፍራ](자바실행환경.md)에 정리했다. መደብ_እሴት ፋይል/JAR 배포는 [한국어자바](한국어자바) 소스에서 재현한다. 기존 Linux판 `አማርኛ.자바`와 별도인 `አማርኛ.자체` 패키지다.

**vi·여러 መስኮት·Swing·한글 Java/Python/C/C++·posix-kor 예제는 [한글 개발 매뉴얼](개발안내.md)에 정리했다.**

GUI ተርሚናል ፈጽም_ትእዛዝ·단축키·ሼል ትእዛዝ·제한은 [셸과 ተርሚናል 사용법](셸과터미널.md)에 정리했다.

## 현재 컴퓨터에서 ፈጽም_ትእዛዝ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

ውጣ_ፕሮግራም: **Ctrl+A ቀጣይ_ንጥል_ነገር X**. 게스트 C/AOT መሳሪያዎች 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. አዘጋጅ_b78e430d 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. 컴파일러 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/መተላለፊያ/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` ድገፍ_እሴት 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 ፈጽም_ትእዛዝ**한다. 기존 한 ቁምፊ_እሴት 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 인수 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

| `gui` / `terminal` | ፈጽም_ትእዛዝ 화면 / 한글 GUI ተርሚናል; F12로 ተርሚናል መክፈቻ·መዝጊያ |
| `samples` | 삭제한 ነባሪ_እሴት 예제 ወደ_ነበረበት_መልስ_ዞን; 기존 파일은 보존 |

예를 들어 `edit 인사.java`를 입력한 ቀጣይ_ንጥል_ነገር 아래 소스를 입력한다.

```java
public class 인사 { public static void main(String[] args) { int እሴት = 7; System.out.println("한글=" + እሴት); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 인사.java`, `java 인사`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. ሰርዝ_ክወና·잘못된 16진수·용량 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, ፈጽም_ትእዛዝ 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 ትእዛዝ 인수는 최대 32개다. ጥቅስ·백슬래시·ሼል 변수·파이프·리다이렉션 범위는 [ሼል 설명](셸과터미널.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, አድራሻ **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode 입력·명시적 ለጥፍ_እሴት·ፈጽም_ትእዛዝ 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 መሳሪያዎች/ፈጽም_ትእዛዝ.py --desktop --network
# 다른 포트: python3 መሳሪያዎች/ፈጽም_ትእዛዝ.py --desktop --port 5903
```

종료는 실행한 አዘጋጅ_b78e430d 터미널에서 Ctrl+C다. 기존 `python3 መሳሪያዎች/ፈጽም_ትእዛዝ.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. ትክክለኛ_ውሂብ Pi4 USB 입력기는 아직 없으며, VNC መገናኛ 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 ትክክለኛ_ውሂብ C++/UDP ELF ፈጽም_ትእዛዝ, `Hello.java` መገንባት_ምንጭ 후 JVM ፈጽም_ትእዛዝ, `hello.py` ፈጽም_ትእዛዝ, GUI ተርሚናል 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 በይነተገናኝ 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 ማስቀመጫ_ውሂብ·CPU 문맥을 보관한다. ሼል·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

make image   # ዓንኳር_እሴት, SD ግንብ_ምስል, 부팅 ZIP, 사용자용 SDK

이미지는 확인된 공식 Pi 부팅 묶음에서 `start4.elf`, `fixup4.dat`, Pi4 DTB와 disable-bt overlay를 가져온다. Linux kernel/initramfs/rootfs는 넣지 않는다. 펌웨어·MicroPython·ተርሚናል ቅርጸ_ቁምፊ_እሴት 라이선스와 ቅርጸ_ቁምፊ_እሴት 출처 해시도 동봉한다. ፋይል አዘጋጅ 스크립트는 물리 디스크에 기록하지 않는다.

예비 microSD에 ግንብ_ምስል መዝግብ_ረድፍ 도구로 `.img`를 기록하거나 FAT32 부팅 파티션 최상위에 ZIP 내용을 푼다. ግንብ_ምስል 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 ነባሪ_እሴት EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD ፋይል 구성·ዓንኳር_እሴት 체크섬 검사와 물리 ቦርድ 부팅 검증은 별개다. MMU 사용 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 부팅 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 አማርኛ API 사용

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/파일예제.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int ጀምር_ተጠቃሚ_ፕሮግራም(int)`이다. ተጠቃሚ C++는 FP/SIMD를 사용할 수 있다. ዓንኳር_እሴት C/Java AOT는 일반 레지스터만 사용하므로 ልዩነት ሂደት_እሴት_ምዝግብ 중 ተጠቃሚ FP 상태를 건드리지 않는다. ተጠቃሚ ምዝግብ_ቦታ_እሴት 시 FP 상태를 초기화하고 ዓንኳር_እሴት 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int ጀምር_ተጠቃሚ_ፕሮግራም(int) {
    int ፋይል = ክፈት_ፋይል("인사.txt", ተነባቢ_የሚጻፍበት | 없으면만들기 | 내용비우기, 0600);
    if (ፋይል < 0) return 1;
    const char ይዘት_እሴት[] = "안녕하세요";
    int ልኬት = ጻፍ_ፋይል_ውሂብ(ፋይል, ይዘት_እሴት, sizeof(ይዘት_እሴት) - 1);
    ዝጋ_ፋይል(ፋይል);
    return ልኬት == sizeof(ይዘት_እሴት) - 1 ? 0 : 2;
}
```

[ፋይል 예제](ተጠቃሚ/파일예제.cpp)와 [통신 예제](ተጠቃሚ/통신예제.cpp)가 ትክክለኛ_ውሂብ 부팅 시험 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 ፋይል ሂደት_እሴት_ምዝግብ 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 소켓 함수는 현재 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 ዓንኳር_እሴት 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 ቀጣይ_ንጥል_ነገር 도구를 사용하면 **새 QEMU를 부팅해 업로드한 ትክክለኛ_ውሂብ 바이트를 재확인한 ተመለስ_እሴት 게스트에서 ፈጽም_ትእዛዝ**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 መሳሪያዎች/ፈጽም_ፋይል.py build/jkoros-native-sdk/demo.elf
python3 መሳሪያዎች/ፈጽም_ፋይል.py 예제/Hello.java "한글 인수"
python3 መሳሪያዎች/ፈጽም_ፋይል.py 예제/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 ዓንኳር_እሴት 묶음에 포함되어 이 ፋይል 한도를 적용받지 않는다. **C++ 컴파일러는 አዘጋጅ_b78e430d SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 ማከማቻ_ስፍራ, PT_TLS, PT_INTERP, PT_DYNAMIC, ፈጽም_ትእዛዝ·መጻፊያ 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 መረጃ_ጠቆመ·አድራሻ ቅንጥብ·오류는 [ተጠቃሚ ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `파일저장확정`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 ፈቃድ_እሴት·dup/fcntl은 없다. 디렉터리와 አቻ_እሴት/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, 수신 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. ተጠቃሚ ውጣ_ፕሮግራም 시 열린 ፋይል 서술자와 소켓을 회수한다.

## ትክክለኛነት_አረጋግጥ ልኬት

`make test-jvm`은 9개 프로그램을 OpenJDK와 ትክክለኛ_ውሂብ 자체 커널에서 실행해 결과를 비교한다. `make test`에도 포함된다. 별도 `መሳሪያዎች/부팅시험.py`는 Java 사각형 API의 ትክክለኛ_ውሂብ 화면 픽셀까지 검사한다. `make test-shell`, `make test-desktop`은 새 셸과 ትክክለኛ_ውሂብ VNC 입력·한글 ተርሚናል 화면을 검사하며 `make test`에도 포함된다.

`make test-windows`, `make test-swing`, `make test-stream`, `make test-coding`도 제공하며 `make test`에 포함된다.

`make test`는 OpenJDK와 AOT ክወና_እሴት ልኬት 비교, 런타임 ስህተት 중단, 미지원 Java 거부와 함께 별도 QEMU VM에서 다음을 검사한다.

- 기존 Java ዓንኳር_እሴት 계산·UTF-8·C++ 직접 호출·협력식 작업 및 프레임버퍼.
- 손상/잘못된 ABI/አድራሻ 초과/겹친 페이지/W+X 등 ELF አትቀበል_እሴት 사례 22개.
- EL0 C++ 생성자·RAII·실수 ክወና_እሴት·ፋይል·힙 및 잘못된 시스템 호출 ጠቋሚ.
- ዓንኳር_እሴት/코드/MMIO መጻፊያ·መዳረሻ_ምዝግብ, NX 스택·NULL ፈጽም_ትእዛዝ, guard page, 특권 ትእዛዝ 차단.
- SVC를 호출하지 않는 무한 반복을 타이머로 종료한 후 정상 ፕሮግራም_f5044b9b 재실행.
- ሽምጥ_እሴት ፈጽም_ትእዛዝ 시 ፋይል/소켓 누수 방지, UDP 왕복·보낸 አድራሻ·잘린 수신·큐 포화·빈 전문·미지원 통신 ስህተት.
- ሼል አርትዕ_እሴት·ሰርዝ_ክወና·16진수 업로드/다운로드·ተጠቃሚ ELF 실행과 잘못된 ELF አትቀበል_እሴት.

## Java와 Python의 정확한 ቅንጥብ

자체 `javac`는 버전 49 `.class`를 생성하며 JVM은 ድገፍ_እሴት 명령으로 구성된 버전 45–52 클래스를 실행한다. አይንቀሳቀሴ_እሴት ተግባር_እሴት·재귀·int/boolean/char/String·ሁኔታ/ሽምጥ_እሴት·ኅብረቁምፊ_እሴት 결합과 일부 ፋይል 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/조합 자모 식별자를 처리한다. Unicode መለያ_እሴት_5b7b8b77 전체 ፍለጋ_ሰንጠረዥ·Unicode ምንጭ_ዛፍ 이스케이프는 구현하지 않았다. 게스트 ምንጭ_ዛፍ 컴파일러는 일반 ነገር_እሴት·ልዩነት·Thread 구문을 아직 컴파일하지 못한다. አዘጋጅ_b78e430d `javac --release 8`로 만든 ድገፍ_እሴት 부분집합 클래스는 자체 JVM 0.4의 ነገር_እሴት·ልዩነት·Thread·UDP와 አማርኛ API를 사용할 수 있다. Swing은 문서화한 자체 API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [자체 JVM 설명](자바실행환경.md)이 기준이다. 상세 ቋንቋ 범위는 [공유 Java መሳሪያዎች 설명](../../문서/자바개발환경.md)을 참고하되, 그 문서의 x86 ሼል/ማከማቻ_እሴት/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 ምንጭ_ዛፍ**를 자체 AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 ተግባር_እሴት·መደብ_እሴት·ልዩነት·리스트/መዝገበ_ቃላት·Unicode·GC·가변 정밀도 정수를 제공한다. 현재 구성은 ኢንተጀር 빌드로 `float`, `complex`, `math`가 없으며 CPython 전체 표준 ማከማቻ_ስፍራ, pip, subprocess, threading, 일반 socket과 ነባሪ_እሴት `open()` ፋይል 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 ነገር_እሴት·모듈은 ውጣ_ፕሮግራም 시 회수되고 RAM 파일만 ቀጣይ_ንጥል_ነገር 실행에 남는다.

`import jkoros`로 ቀጣይ_ንጥል_ነገር 시스템 연결을 쓴다. 모두 SVC를 통해 자체 Java 커널에 접근한다.

| ተግባር_እሴት | ተግባር |
|---|---|
| `stdin(limit)` | 현재 표준 입력에서 최대 limit바이트(0…16384)를 bytes로 읽음; EOF는 빈 bytes, UART ውሂብ 없음은 OSError(11) |
| `read(name)` | አቻ_እሴት/절대 RAM 경로의 ፋይል 전체를 bytes로 읽음 |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 ማከማቻ_እሴት, 쓴 ባይት_እሴት 수 반환 |
| `remove(name)` | RAM ፋይል 삭제 |
| `rect(x, y, w, h, color)` | 선택한 ትክክለኛ_ውሂብ 화면 መጠን 안의 사각형 ስዕል_እሴት; 기존 보드의 RGB32 እሴት |
| `ticks_ms()` | 부팅 후 밀리초, 32비트 ዑደት_እሴት |
| `udp_open(port)` | 127.0.0.1의 UDP 소켓 መክፈቻ/묶기; 0은 자동 포트 |
| `udp_send(fd, port, data)` | 루프백 መድረሻ_እሴት 포트에 str/bytes 버퍼 ትልልፍ_እሴት |
| `udp_recv(fd)` | `(bytes, 보낸포트)` 반환; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | 소켓 መዝጊያ |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```

이식 코드: [python/](파이썬연결/), [ተጠቃሚ Java መገናኛ](ተጠቃሚ/자바연결.c). 공식 [MicroPython 이식 አንበኝ_eb81d7d9](https://docs.micropython.org/en/latest/develop/porting.html)를 참고했다. ምንጭ_ዛፍ URL·ሃሽ_ፋይል·라이선스는 [vendor አንበኝ_eb81d7d9](vendor/README.md)에 기록했다.

## አማርኛ C የውሂብ_ዓይነት·Python ስህተት·ቀርቅብ ጫን_እሴት

C 네트워크 API는 `struct 인터넷통신주소`, enum 상수와 ትክክለኛ_ውሂብ አማርኛ 함수로
구현한다. ማክሮ_እሴት 별칭을 사용하지 않으며 이전 pk_* ABI도 유지한다.
Python 예제는 `ስርዓት_ስህተት`, `ስህተት.መረጃ_ጠቆመ`, `ስህተት.설명`을 사용한다.

`python3 መሳሪያዎች/ፈጽም_ትእዛዝ.py --desktop --network --pip`로 시작하면 게스트에서
`pip install micropython-bisect==3.3.3`을 사용할 수 있다. 현재는 አዘጋጅ_b78e430d 중계를
이용하는 제한형 MicroPython ምንጭ_ዛፍ 설치기이며 CPython pip·자동 의존성 해결·C 확장은
미지원이다. 설치한 `/lib` 자료는 RAM이다. [사용법과 제한](파이썬꾸러미.md).

## 화면 መጠን የተመረጠ_እሴት

`python3 መሳሪያዎች/ፈጽም_ትእዛዝ.py --desktop --network --resolution 1920x1080`으로 Full HD 화면을 사용한다. 기본값은 640×480이며 1280×720도 가능하다. ተርሚናል አንቀሳቅስ_እሴት, Swing 가운데 አገናኝ_አሰሳ, Java·C·Python 그리기도 ትክክለኛ_ውሂብ 크기를 따른다. SD 영상은 `make image RESOLUTION=1920x1080`으로 만든다. [ማሰናጃዎች·አማርኛ API·ትክክለኛነት_አረጋግጥ አንበኝ_eb81d7d9](화면해상도.md).

## አማርኛ 직접 API와 화면 አድስ

`example/java`는 `실행할일`, `동작받이`, `동작알림`, `አዝራር`, `ፍጻሜ_ሰልፍ`,
`작업가닥`, `ማስኬጃ()`을 사용할 수 있다. አማርኛ GUI/가닥을 자체 JVM에 직접

계약과 전체 ምንጭ_ዛፍ 검토 범위는 [명명 አንበኝ_eb81d7d9](명명/አንበኝ_eb81d7d9.md), 사용법과 호환성 변경은
[አማርኛ Java API](한국어자바/አንበኝ_eb81d7d9.md)를 본다.

ተርሚናል አንቀሳቅስ_እሴት·መጠን 변경은 바뀐 영역만 합성하고 달라진 화소만 표시한다.
