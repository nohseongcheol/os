# JEthOS 구조

아래는 ነገር_ዋጋ 기반 관리 ፍረ_ዋጋ 전체의 ዕላማ_ነገር 구조다. 현재 ትኽክለኛ_ሓበሬታ 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 ስርዓት_ስርሒት ኣንብበኒ_eb81d7d9](../os/ኣንብበኒ_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·ኣተኣታትዋ_ዋጋ ቀይር_ኹነት·ናይ_ፋይል_ስርዓት 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 ንጻፍ_ዋጋ
  ↓
Java AOT 실행기와 ነገር_ዋጋ·ተርታ_ዋጋ_ed437109·GC 런타임
  ↓
ሃርድዌር_ዋጋ 경계
  ↓
Java 관리 ፍረ_ዋጋ
  ├─ 기억공간/쪽관리/COW
  ├─ መስርሕ_ዋጋ/배정/wait
  ├─ ናይ_ፋይል_ስርዓት/ELF/POSIX
  └─ 입력/መኽዘን_መሳርሒ/ማሕበራዊ_ኔትወርክ_ድርደራ
```

OpenJDK 자체는 이미 운영체제가 제공하는 ፋይል, 스레드, 가상 기억공간을 전제로 한다. 따라서 ፍረ_ዋጋ 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, ኣተኣታትዋ_ዋጋ 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
