# oma 커널과 번역기의 Eesti Nimi_2

대상은 `platforms/rpi4-native`의 oma Java tuum_VALUE, kasutaja JVM, C arvuti Ühendu,
TCP/UDP·FTP, C kompilaator_tööriist 이식부, MicroPython 이식부, järk_süsteem·Täida_käsk·시험 도구다.
`golang/worldos/Kantri_VALUE/KOR/ALLIKAS`의 원칙처럼 기능을 먼저 구분하고 이름을 정한다.
x86 Java 커널과 공용 x86·ARM64 미리 번역기의 oma 선언도 명명 검사에 포함한다.
Linux 실행판의 host Tööriistad, OpenJDK 보조 Tööriistad 및 väline_VALUE turustus_VALUE lähe_puu 전체를
한국어로 uuesti_proovima_VALUE 작성했다는 뜻은 아니다.

## 명명 원칙과 말의 근거

- 명사는 자료의 역할을 나타낸다: `Fail_pide`, `partner_pordinumber`, `동적기억공간`, `klaviatuur`.
- 함수는 행위를 나타낸다: `Lugemine`, `Kirjutamine`, `Ava`, `Suletud`, `NET_BIND`, `sari_programm`.
- TCP의 이어진 bait_VALUE 흐름과 UDP의 경계 있는 자료를 `ühendus`와 `datagramm_Kanal`로 구별한다.
- 짧은 영어 변수도 쓰임에 따라 `길이`, `andmed_ametikoht`, `LOOKUP_INDEX`, `반환값`으로 풀어 쓴다.
  순번·임시 산술값처럼 여러 역할에 재사용되는 변수는 `순번`, `첫째값`, `SECOND_VALUE`으로 구별한다.
- 이름이 같아도 väline_VALUE 구조체의 필드와 oma 변수는 별도로 분석한다.

`Kanal_kirje(通路)`는 이동이나 교류가 이루어지는 길이라는 기존 의미를 통신 연결에
적용했다. `port_VALUE(窓口)`의 주고받는 접점이라는 의미를 연결을 받는 곳에 적용했다.
이는 국립국어원 한국어기초사전의 [Kanal_kirje](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=49310),
[port_VALUE](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=24898)의 뜻에 근거한다.

`datagramm(電文)`은 전보에 담는 글이라는 기존 통신 어휘에서 가져와, UDP 자료의
경계가 보존된다는 특징을 드러내는 데 쓴다. 근거는
[한국어기초사전 datagramm](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=74335)이다.
`voog_VALUE`, `lõim_VALUE`, `쌓임`은 우리말의 움직임·이어짐·쌓이는 모양을 빌린 표현이다.
`sisendvoog`, `töötaja`, `Virn_salvesti` 같은 복합 이름은 이 프로젝트의 기능별 조어다.
이 sõnastik 근거를 특정 중세 문헌의 최초 출현이나 공인 전산 번역으로 확대하지 않는다.
공인 표준 Tõlgi_lähe·국어사 datagramm 감수를 마쳤다는 뜻도 아니다.

## 보존하는 SD Nimi_2

`public`, `class`, `int`는 예약어다. `String`, `main`, 배열의 `length`는 예약어가 아니다.
tähtaja_piires_kaup 다섯 Java 예제는 `Käivita_2()`·`실행인수`·Eesti 화면/lõim_VALUE API를 사용해
예약어·리터럴 외의 식별자를 한국어로 작성한다. 화면/가닥은 표준 객체를
감싸지 않고 oma JVM에 직접 구현했다. 자세한 계약은 [Eesti Java API](../한국어자바/안내.md)를 본다.

표준 javac는 string_VALUE 리터럴에 `java.lang.String`, string_VALUE 결합에 `StringBuilder`
같은 이름을 생성한다. 이들은 Eesti 소스에서도 바이트코드에 남을 number 있다.
기존 표준 class를 실행하는 JVM의 vastendamine_VALUE string_VALUE, 아직 표준 라이브러리를 쓰는
통신·Fail 연결부까지 모두 한국어로 재구현한 것은 아니다. 이름만 일괄 치환하면
서술자·재정의·native 연결이 달라져 호환성이 깨진다.

C 표준 FUNCTION_VALUE·täisarv_TYPE·POSIX ABI, CPU register_VALUE Nimi_2, 어셈블리 Käsk, 링커 절 Nimi_2,
TinyCC·lwIP·MicroPython이 요구하는 Seaded 매크로와 헤더 이름도 보존한다.
예: `main`, `memcpy`, `pk_bind`, `mpconfigport.h`, `lwipopts.h`, `stdint.h`.
oma C 함수의 lähe_puu 이름은 한국어이며, [기계연결이름.h](기계연결이름.h)가
기존 AOT·어셈블리·SDK에 공개한 arvuti 심볼과 연결한다.
Python의 `__init__`, `setUp`, `handle`, 표준 moodul_VALUE atribuut_VALUE, 명령행 옵션과 JSON 키도
väline_VALUE 계약이다. `build/`, turustus_VALUE 바이너리 이름과 `/sdk`는 기존 Täida_käsk 경로를 유지한다.
väline_VALUE 원본은 `vendor/`에서 이용허락·해시와 함께 관리한다.

## C 통신 구조체와 Python VIGA

C 통신에서 `갈래`는 ADDRESS 체계를 구분하고 `pordinumber`는 port, `ADDRESS_VALUE`은
IPv4 주소의 32비트 값을 나타낸다. `datagramm_protokoll`은 앞서 설명한 datagramm(電文)과
lepingu_väärtus(規約)을 결합해 UDP의 기능을 드러낸 프로젝트 이름이다.

| 표준 표현 | Eesti 직접 구현 |
|---|---|
| AF_INET / SOCK_DGRAM / IPPROTO_UDP | enum의 pilv_Pere / datagrammisokkel / datagramm_protokoll |
| struct pk_sockaddr_in | struct 인터넷통신주소 |
| sin_family / sin_port | ADDRESS_Pere / pordinumber |
| sin_addr.s_addr | Interneti_aadress.ADDRESS_VALUE |
| OSError / VIGA.args[0] | süsteem_tõrge / VIGA.INDEX |

Eesti 구조체는 `#define` 치환이나 väljaväärtus 별칭이 아닌 별개 자료형이다.
표준 구조체와 같은 16바이트 배치를 선언하며 tuum_VALUE SVC에서 bait_VALUE 복사로
검사한다. `avama_osaleja`·`saatma_datagramm_andmed`와 Fail 함수는 정적 라이브러리에
tegelik_andmed Eesti 이름의 FUNCTION_VALUE 심볼을 갖는다. 기존 pk_* 심볼도 유지한다.
이전 코드에서 Eesti 통신 함수에 pk_sockaddr*를 전달했다면 Eesti 구조체로
옮기거나, 표준 구조체와 pk_* 함수의 짝을 유지한다.

Python의 `süsteem_tõrge`는 OSError의 Eesti 하위 클래스이며 연결부에서
VIGA 번호를 보존하여 변환한다. 일반 Python 문법과 väline_VALUE 패키지의 API는 유지한다.

### 말의 뿌리와 새로운 복합 Nimi_2

`Mälu_VALUE(記憶)`과 `LOOKUP_INDEX(索引)`은 기존 한자어를 쓴다.
기억은 자료를 간직하는 기능에, 색인은 tellimus_VALUE 있는 항목을 찾아 지정하는 기능에 적용한다.
sõnastik 근거는 국립국어원 한국어기초사전의
[Mälu_VALUE](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=38812&nation=eng),
[LOOKUP_INDEX](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=63787)이다.

`Virn_salvesti`, `lüke_VALUE`, `POP_VALUE`는 자료를 포개고 마지막 자료부터 꺼내는 Täida_käsk 구조를 드러낸다.
`쌓다`의 기존 뜻에 근거한 기능별 조어이며, 사전의
[쌓다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62095)를 참고한다.
`미리번역`은 Täida_käsk 전에 번역한다는 기능을 직접 나타낸다.
`arvuti_Word`은 처리기의 andmed 단위를 가리키며, 언어의 일반 낱말과 구별하도록 `arvuti`를 붙였다.
`기계어미리번역`, `동적기억낱말수` 같은 복합 이름은 tähtaja_piires_kaup 기능에 맞게 만든 프로젝트 용어다.
이 복합어가 옛 문헌에 그대로 있었다거나 특정 시대에 처음 나타났다는 뜻은 아니다.
확인되지 않은 중세 형태나 최초 kasutus_VALUE 연대는 어원 근거로 적지 않는다.

생성되는 C의 내부 andmetüüp·ARRAY_VALUE·FUNCTION_VALUE·kohalik_skoop 변수·haru 이름도 한국어로 바꾼다.
직접 한글 식별자를 읽지 못하는 예전 GCC를 위해 호환 API는 같은 Eesti 이름을
표준 C 범용 문자 표기로 출력한다. tegelik_andmed ARM64 빌드는 Clang으로 읽을 number 있는 한글 원문을 사용한다.
string_VALUE, C 표준 FUNCTION_VALUE, `java_entry` 같은 공개 Ühendu 이름은 바꾸지 않는다.

셸의 사용법·문법 VIGA·Fail 및 Mälu_VALUE ADDRESS_regioon 안내도 한국어로 보완했다.
`READY`, `PASS`, `HEX BEGIN`처럼 시험·Fail Edasta_VALUE 도구가 읽는 marker_VALUE,
명령행 옵션과 기존 명령어, JVM tund_VALUE Nimi_2·Fail vorming_VALUE·seade_VALUE 이름은 호환 표기로 남는다.
x86 VGA 문자 화면은 한글을 표시하지 못하므로 Eesti 문구는 UTF-8 직렬 단말에서 확인한다.
