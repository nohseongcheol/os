## 빌드와 시험

새 네이티브 구현은 `compiler/`와 `os/`에 있다. 기존 `pärand_lähe/`의 JVM 관리 커널은 그대로 보존하며, 두 구현의 시험과 기능 범위는 서로 다르다.

```sh
cd /home/user/jkoros
make                 # 네이티브 계산 예제 + Java tuum_VALUE ELF
make iso             # os/build/kernel.iso
make run             # QEMU 직렬 단말; help 입력 (종료는 Ctrl+A, X)
make run-gui         # ISO를 QEMU 화면/PS2 키보드로 Täida_käsk
make vbox            # 전용 VirtualBox VM 자동 genereerima·Täida_käsk (GUI)
make vbox-status     # VirtualBox Olek_VALUE·ISO·직렬 LOG_kirje RADA kinnitama
make test-vbox       # VirtualBox programm_käiviti Olek_VALUE Joonis_VALUE_kirje 시험 (tegelik_andmed VM muutma_VALUE 없음)
make test            # kompilaator 시험 + ELF/ISO 부팅 및 Käsk 입력 시험
make apps            # 독립 kasutaja ELF programm_f5044b9b järk_süsteem
make test-network    # kasutaja MODE_VALUE·UDP 왕복·Mälu_andmed kaitsma_VALUE 시험
make test-java       # 게스트 javac/JVM + OpenJDK 양방향 교차 Täida_käsk 시험
make posix-kor       # Eesti C 헤더와 tegelik_andmed tuum_VALUE 호출 teek
make test-posix      # Fail/UDP/salv_VALUE/Java Fail I_O 시험
make -C os run-store # 전용 salv_VALUE 매체로 QEMU 부팅
make legacy-test     # 아래 기존 JVM 관리 커널의 47개 시험
```

`compiler/`는 호스트의 `javac`를 문법·TYPE_VALUE 검사 전단으로 사용하고 oma 바이트코드→x86 변환기로 ELF32 기계어를 만든다. 빌드할 때는 JDK가 필요하지만 생성된 커널과 ELF는 väline_VALUE JVM 없이 실행된다. 전체 Java, objekt_VALUE 모델, 표준 라이브러리와 기존 관리 tuum_VALUE 전체의 AOT 변환은 아직 지원하지 않는다. 자세한 tugi_VALUE 문법과 명령은 [kompilaator 안내](compiler/안내.md), tegelik_andmed 부팅 기능과 한계는 [네이티브 operatsioonisüsteem 안내](os/안내.md)를 참고한다.

네이티브 셸에 oma 제한형 `javac`와 `java`를 추가했다. `edit Demo.java`로 소스를 입력하고 `.save`로 저장한 Tagasi_VALUE `javac Demo.java`, `java Demo`로 **게스트 내부에서 컴파일하고 Täida_käsk**할 number 있다. vaikeväärtus 예제는 `javac Hello.java`, `java Hello`다. 파일은 RAM에서 동작하며, 전용 salv_VALUE 매체를 연결하면 `sync`로 재부팅 후에도 보존할 number 있다. **OpenJDK/JDK 전체 이식은 아니며**, 단일 tund_VALUE·정적 FUNCTION_VALUE·täisarv·string_VALUE·tingimus/반복문과 일부 표준 호출을 지원한다. tugi_VALUE klipp, väline_VALUE Fail 적재와 시험은 [Java 개발 환경 안내](문서/자바개발환경.md)에 있다.

네이티브 셸에서 `apps`, `run hello first second`, `net`, `run netcheck`를 사용할 number 있다. 독립 ELF를 ring 3에 적재하고 `int 0x80` 호출을 통해 Väljund·Argumendid·UDP 네트워크를 제공한다. 별도 host 터미널에서 `python3 os/Tööriistad/kaja_andmed.py --port 9000`을 실행한 Tagasi_VALUE 게스트에서 `run udp 10.0.2.2 9000 hello`로 tegelik_andmed 왕복을 확인한다. 새 programm_f5044b9b register_kirje, API 및 제한은 [kasutaja Täida_käsk·네트워크 안내](os/kasutaja/안내.md)를 참고한다. tähtaja_piires_kaup QEMU RTL8139·정적 IPv4·UDP 전용이며 TCP/DNS는 미지원이며, 전용 IDE salv_VALUE 형식과 POSIX Fail/UDP 일부 기능을 추가했다.

`make vbox`는 `jkoros operating system` 전용 VM을 만들고 디스크 없이 ISO로 부팅한다. Täida_käsk 중이면 유지하고, salv_VALUE·일시정지 상태이면 재개하며, 꺼져 있을 때만 새 ISO를 빌드해 연결한다. VirtualBox에서 부팅과 셸의 kasutaja programm_f5044b9b 실행을 확인했다. 다만 tähtaja_piires_kaup VirtualBox용 네트워크 드라이버는 없어 네트워크 장치를 비활성화한다. UDP 시험에는 `make run`을 사용한다. 상태별 동작과 새 järk_süsteem 반영 방법은 [VirtualBox Täida_käsk 안내](문서/가상상자실행.md)에 있다.

기존 관리 커널만 시험하려면:

```sh
cd /home/user/jkoros
make -f avama_kirje.mk 검사
make -f avama_kirje.mk host
```

`host`는 여전히 JVM 관리 계층의 Nimi 시험이다. `make -f avama_kirje.mk järk_pilt`는 새 `os/`의 제한형 네이티브 tuum_VALUE ISO를 만든다. 기존 `pärand_lähe/`의 failisüsteem·Joonis_VALUE·võrk_Virn 구현 전체를 이 ISO에 이식했다는 의미는 아니다.

Eesti FUNCTION_VALUE·변수·Fail 이름과 tegelik_andmed C API는 [posix-kor](posix-kor/안내.md)에 있다. 게스트 Java에서는 `FileInputStream`·`FileOutputStream`의 단일 bait_VALUE 입출력도 지원한다. 전체 POSIX·OpenJDK·Swing 지원으로 확대된 것은 아니다.

väline_VALUE 배포용 `pack.sh` / `unpack.sh`와 자동 의존성 복원은 [turustus_VALUE 안내](distribution/README.md)를 참고하세요.
