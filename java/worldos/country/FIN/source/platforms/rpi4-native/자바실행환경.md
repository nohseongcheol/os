# oma ARM64 JVM 0.4와 suomi kirjasto

suomi 통신·poikkeus 사용법은 [suomi Java API](한국어자바/Lueminut_eb81d7d9.md), funktio_ARVO·muuttuja_ARVO·tiedoston_nimi 이름의 변경과 어원 근거는 [명명 Lueminut_eb81d7d9](명명/Lueminut_eb81d7d9.md)를 참고한다.

JAR Suorita_komento, ulkoinen_ARVO IPv4 TCP/UDP, 별도 staattinen_ARVO 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 objekti_ARVO·Thread·Swing은 JVM 경로의 기능이며 AOT Tuki_ARVO 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 Suorita_komento**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK Luokka_ARVO kirjasto 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 Luokka_ARVO·staattinen_ARVO menetelmä_ARVO 중심이던 실행기를 objekti_ARVO·kirjasto Suorita_komento 기반으로 넓힌 것이다.

## 실행과 kääntää_lähde

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# oma ydin_ARVO 안에서 lähde_puu kääntää_lähde → class Suorita_komento, suomi API 호출
python3 työkalut/Suorita_Tiedosto.py testit/자바/한글소스.java

# objekti_ARVO·poikkeus 등은 isäntä JDK로 Java 8 class를 만든 후 oma 커널에서 Suorita_komento
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java testit/자바/한글시험.java
python3 työkalut/Suorita_Tiedosto.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 Siirrä_ARVO
javac --release 8 -encoding UTF-8 -d build/my-java testit/자바/객체시험.java
python3 työkalut/Suorita_Tiedosto.py build/my-java/객체시험.class \
  --include build/my-java/Tausta_ARVO.class --include build/my-java/haara_ARVO.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.Luokka_ARVO.class`라는 RAM tiedoston_nimi 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.Luokka_ARVO`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.Luokka_ARVO`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar tiedoston_nimi.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 suomi 클래스만 찾는다. jakelu_ARVO suomi kirjasto JAR는 isäntä javac의 classpath로 사용하며, 같은 클래스가 käyttäjätila JVM ELF에도 Luku 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 staattinen_ARVO menetelmä_ARVO, int/boolean/char/String, ehto·sprintti_ARVO, merkkijono_ARVO 결합, 일부 tiedoston_nimi 스트림 등의 **oma 부분집합 kääntäjä**다. objekti_ARVO esittely·상속·try/catch·Thread käyttö_ARVO 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 oma JVM에서 실행한다. suomi API 중 tulostuspaikka·문자 스칼라 funktio_ARVO·tiedoston_nimi Luku/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] argumentit) throws Exception {
        suomi.oma.tulostuspaikka.kirjoitus_rivi("안녕하세요😀");
        suomi.oma.tulostuspaikka.kirjoitus_numero(suomi.oma.문자.koodipiste_LASKE("한글😀"));
        suomi.oma.tiedoston_nimi.Kirjoitus("인사.txt", "한글 tiedoston_nimi😀");
        suomi.oma.tulostuspaikka.kirjoitus_rivi(suomi.oma.tiedoston_nimi.Luku("인사.txt"));
    }
}
```

## suomi API

독립 패키지 **`suomi.oma`**를 사용한다. Linux판 `suomi.자바`가 요구하는 NIO/Swing/HTTP API를 oma 커널에서 실행할 numero 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 Luokka_ARVO Nimi·menetelmä_ARVO·argumentit·kentän_arvo·tiedoston_nimi 이름에 한국어를 사용한다. 표준 Java Luokka_ARVO 이름은 호환성을 위해 보존한다.

## Suorita_komento 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(suomi Luokka_ARVO esittelyt), class당 16 KiB·vakio_ARVO 풀 511항목, 전체 menetelmä_ARVO/kentän_arvo 각각 512개. menetelmä_ARVO KOODI_ARVO 8 KiB, paikallinen_laajuus muuttuja_ARVO·피연산자 operandi_Pino 각각 128슬롯, argumentit 최대 16개(this esittelyt).
- VM 가닥은 main esittelyt **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 Suorita_komento 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- objekti_ARVO 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 todellinen_data 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 tiedoston_nimi·대형 merkkijono_ARVO·객체가 이 제한을 넘을 numero 있다.
- 실행은 50만 바이트코드 komento 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 syöte_ARVO 대기는 기한을 갱신하고 Ikkuna MUUTA_tila 시 중단·재개한다. 일반 palvelin_ARVO·계산의 무제한 실행은 아직 없다. 미지원 komento·resurssi_ARVO 부족은 명시적인 오류로 종료한다.
- RAM tiedoston_nimi 최대 64개, 파일당 16384바이트, polku_2 UTF-8 63바이트. RAM 디렉터리와 vertaissolmu_ARVO/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 suomi class는 RAM tiedoston_nimi 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 nykyinen_kohde 경로에서 lähde_puu·Luokka_ARVO·data 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 ulkoinen_ARVO IPv4를 제공한다. todellinen_data GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. datagrammi 512바이트, vastake_ARVO 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 Suorita_komento 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 MATRIISI_ARVO, 완전한 MATRIISI_ARVO 공변성·인터페이스 kerros_ARVO_e65604ef 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/Salaa_data/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 Tuki_ARVO 부분집합은 아래 및 kehitystuote 매뉴얼을 참고한다. Luokka_ARVO tiedoston_nimi 전체 검증기·pääsy_merkintä_68aed533 lupa_ARVO/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 suojata_ARVO rajattu_alue_ARVO 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 toteutus 단계다: 완전한 JVM ARVO/vahvista/Luokka_ARVO 로더와 poikkeus 모델 → 영속 VFS·mmap·Kello·원자 leikkaus_ARVO·todellinen_data 스레드/synkronoi ABI → OpenJDK java.base 및 native kirjasto 이식 → laite_ARVO 네트워크·TCP/IP → Ikkuna 시스템/fontti_ARVO/입력기·java.desktop → Java SE 호환성 testit. nykyinen_kohde oma JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## JVM 0.3: 네트워크와 GUI tarkenne_ARVO

`Socket`/`ServerSocket` generoida·Yhdistä·accept·양방향 InputStream/OutputStream·close·EOF·AIKA_ARVO 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 ulkoinen_ARVO numero_ARVO IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 lopettaa_puhelu_piste 16개, Java 루프백 버퍼 1024바이트, ulkoinen_ARVO TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. vuorovaikutteinen 이벤트 대기는 Suorita_komento 기한을 갱신하고 komentotulkki MUUTA_tila 시 프로세스 상태를 Store_ARVO·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

suomi `Ikkuna`, `näyttöelementti`, `yhteys_välitys` 클래스를 jakelu_ARVO JAR와 oma JVM 내장 자원에 추가했다. 상세 menetelmä_ARVO·제한·lähde_puu·업로드 방법: [한글 kehitystuote 매뉴얼](kehitystuote_opas.md).

## suomi 객체의 직접 Suorita_komento

`Ikkuna`, `Nimike`, `tekstikenttä`, `painike`, `tapahtuma_jono`, `동작알림`, `työntekijä`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. oma JVM의 objekti_ARVO generoida,
muoto_ARVO 검사, 화면 호출, Tapahtuma 큐, säie_ARVO 스케줄러에 suomi 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 Suorita_komento 경로도 유지한다.
suomi 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

oma 실행기의 suomi 진입점은 `public static void Suorita_2()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 suomi 진입점을 우선한다.
