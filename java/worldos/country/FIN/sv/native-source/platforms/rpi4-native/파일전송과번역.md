# eget ARM64 kärna_värde: FTP, C, JAR와 AOT köra_kommando

대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT kärna_värde**이다. CPU·enhet_värde 경계는 C/어셈블리, filnamn 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 värd JVM으로 대신 실행하지 않는다.

JVM은 Kurs_värde 버전 45…52의 문서화한 부분집합이다. `java`는 바이트코드 실행기이고, `jaot`가 별도의 네이티브 köra_kommando 파일을 만든다. **JAR Arkiv_värde 해제나 JVM을 함께 묶는 것을 AOT라고 표시하지 않는다.** 지원하지 않는 바이트코드/API는 `jaot`가 진단하고 출력을 만들지 않는다. 기존 utmatningsposition ELF도 kompilera_källa fel_värde 때 보존한다.

Android의 Dalvik/ART는 일반 JVM Kurs_värde/JAR가 아닌 **DEX**를 실행한다. ART의 AOT에는 GC, Kurs_värde 로딩, JNI 등 köra_kommando 기반도 필요하다. 따라서 ART처럼 기계어로 바꾸는 기능만으로 임의의 OpenJDK JAR 및 Swing이 자동 호환되지는 않는다. [Android 공식 런타임 설명](https://source.android.com/docs/core/runtime)

## Svenska Java를 게스트에서 컴파일하고 AOT köra_kommando

게스트 `vi 빛.java`로 Nästa_objekt 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] argument) throws Exception {
        int SUM_värde = 0;
        int nummer = 1;
        while (nummer <= 10) {
            SUM_värde = SUM_värde + nummer;
            nummer = nummer + 1;
        }
        Svenska.eget.utmatningsposition.skriva_nummer(SUM_värde);
        Svenska.eget.filnamn.Skriv("aot.txt", "한글 AOT filnamn 😀");
        Svenska.eget.utmatningsposition.skriva_rad(Svenska.eget.filnamn.Läs("aot.txt"));
    }
}
```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 generera·연결한다. köra_kommando 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 stöd_värde 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 statisk_värde metod_värde/fältvärde, int 계열, heltal 배열과 referens, argument MATRIS_värde, villkor·gren·sprint_värde, sträng_värde 리터럴, `System.out.print/println`의 int/String, Svenska utmatningsposition·filnamn Läs/쓰기로 제한된다. Kurs_värde/metod_värde 수와 operand_Stack 등에도 고정 상한이 있다. Java fel_31f743d2 Process_värde_post, objekt_värde generera, 가상 metod_värde 일반, switch/wide, long/float/double, invokedynamic, sträng_värde 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 MATRIS_värde ansluta_post/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java fel_31f743d2 객체로 전달하지 않는다.

indata_värde 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 justera_värde 때문에 짧은 클래스도 이 한도를 넘을 nummer 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 objekt_värde·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 stöd_värde klipp 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 utveckling 매뉴얼](utveckling_guide.md)을 참고한다.

JAR는 하나의 애플리케이션 Kurs_värde 경로다. 내부 Namn `bunt/app_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 Svenska 클래스를 추가로 찾지만 aktuellt_objekt 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·Kryptera_data ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 nummer/VM heap_värde 제한은 그대로 적용된다.

`skapa_fil` 등은 별도의 모의 호출이 아닌 기존 `pk_open` 등의 Svenska 매크로이며, ELF의 SVC를 통해 verklig_data Java filnamn 체계에 도달한다. filnamn/socket_värde 호출 목록은 [användarutrymme ABI](사용자호출규약.md)에 있다. C/C++ värd SDK köra_kommando 파일도 FTP로 업로드 후 `run` 또는 `./filnamn`로 실행하며 확장자는 필요 없다. Linux ARM64 statisk_värde ELF에는 별도의 제한된 호환 sökväg_2 `run --linux filnamn`을 추가했다. [ELF·Linux ABI 매뉴얼](실행파일규약.md)에 정확한 format_värde·시스템 호출·Adress 제한을 정리했다.

## Svenska 네트워크·작업·skärmbild API

| Kurs_värde | 호출 예 | köra_kommando sökväg_2 |
|---|---|---|
| `utmatningsposition` | `skriva_rad("안녕")`, `skriva_nummer(42)` | JVM 및 제한형 AOT |
| `filnamn` | `Skriv("문서.txt", "Innehåll_värde")`, `Läs("문서.txt")` | JVM 및 제한형 AOT |
| `kommunikation` | `Öppna(0)`, `skicka(deltagare, "10.0.2.2", 9000, "한글")`, `få(deltagare)` | JVM의 UDP |
| `kontakt_transport` | `Anslut("10.0.2.2", 9000)`, `lyssna_deltagare(9000)`, `få(server_värde)` | JVM의 Socket/ServerSocket |
| `작업` | `Kör(Runnable)`, `기다리기(Thread)`, `NOMAVK_uppgift()` | JVM의 협력식 tråd_värde |
| `Fönster`, `skärmelement` | Fönster·버튼·tecken_värde·textfält·Händelse Anslut | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 Svenska 호출 계층을 추가한다. `kommunikation(通信)`, `Anslut(連結)`, `utmatningsposition(出力)`은 기존 단어의 뜻을 사용한다. `작업 tråd_värde`은 한 köra_kommando 흐름을 가닥에 빗댄 기술 표현, `port_värde`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

extern_värde 주소는 siffra_värde IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 eget ABI이며 JVM이 제한된 vänta_värde/재시도를 제공한다. TCP connect 대기는 최대 1초, användarutrymme app_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 köra_kommando användarutrymme 서버와 pthread는 아직 없다. FTP는 användarutrymme app_f5044b9b 기한과 별개인 kärna_värde 서비스다.

게스트의 användarutrymme TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 verktyg/köra_kommando.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 standardvärde kontroll_värde/데이터 포트와 겹치면 köra_kommando 전에 거부한다.
