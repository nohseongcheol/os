# 전체 suport_VALOR 요청의 현재 Estat_VALOR

sol_licitud 전체는 아직 완료되지 않았다. 현재 ISO는 propi Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 real_dades C POSIX 일부 기능, Català API/FONT Nom, IDE Fitxer 보존, 게스트 Java Fitxer 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/LLEGIU_ME_eb81d7d9.md)를 기준으로 판단한다.

| sol_licitud 분야 | 현재 Executa_ordre 가능한 clip | 전체 지원에 필요한 작업 |
|---|---|---|
| Java generar_font·Executa_ordre | 게스트 제한형 javac/JVM, estàtic_VALOR 단일 클래스와 일부 표준 objecte_VALOR | 일반 objecte_VALOR·Classe_VALOR Connecta·excepció·GC·스레드, 완전한 javac와 표준 Classe_VALOR biblioteca |
| Fitxer | POSIX 서술자, Java 단일 byte_VALOR Fitxer flux_VALOR, 전용 suport_físic_VALOR 보존 | 일반 java.io/nio, 디렉터리·permís_VALOR·blocar_VALOR·일반 sistema_d_arxius·extensió_VALOR 가능한 capacitat_VALOR |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP allotjar 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, Annexa_introducció NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 Esdeveniment·tipus_de_lletra_VALOR·Finestra sistema_operatiu_VALOR, AWT 네이티브 연결과 Swing Executa_ordre 기반 |
| POSIX | 문서화한 Fitxer·단말·UDP 부분 | Procés_VALOR·exec/fork·스레드·시그널·Hora_VALOR·mmap·poll·파이프 등과 적합성 validar |
| 언어별 Nom | Català 46개 대응 introducció_VALOR, real_dades C/Java/Fitxer Nom 적용 | objectiu Idioma 확정, 언어별 용례·역사 근거와 해당 FONT·도구의 validar |

propi 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 Executa_ordre 환경을 추가하는 방식은 별도의 nucli_VALOR·루트 sistema_d_arxius·OpenJDK·그래픽 servidor_VALOR·영구 Store_VALOR 구성을 가진 Executa_ordre 경로가 된다. 후자는 기존 propi 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

Executa_ordre 기반과 Annexa_introducció objectiu 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
