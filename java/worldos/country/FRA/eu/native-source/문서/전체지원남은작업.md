# 전체 Laguntza_balio 요청의 현재 Egoera_balio

eskaera 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 benetako_datuak C POSIX 일부 기능, Euskara API/ITURBURUA Izena, IDE Fitxategia 보존, 게스트 Java Fitxategia 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/IRAKHAU_eb81d7d9.md)를 기준으로 판단한다.

| eskaera 분야 | 현재 exekutatu_komando 가능한 klip | 전체 지원에 필요한 작업 |
|---|---|---|
| Java eraiki_iturburu·exekutatu_komando | 게스트 제한형 javac/JVM, estatiko_balio 단일 클래스와 일부 표준 objektu_balio | 일반 objektu_balio·Gela_balio Konektatu·salbuespen·GC·스레드, 완전한 javac와 표준 Gela_balio liburutegi |
| Fitxategia | POSIX 서술자, Java 단일 byte_balio Fitxategia Stream_balio, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·baimen_balio·잠금·일반 fitxategi_sistema·luzapen_balio 가능한 ahalmen_balio |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP Ostalari 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, Erantsi_sarrera NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 Gertaera·letra_tipo_balio·Leihoa sistema_eragile_balio, AWT 네이티브 연결과 Swing exekutatu_komando 기반 |
| POSIX | 문서화한 Fitxategia·단말·UDP 부분 | prozesu_balio·exec/fork·스레드·시그널·ordua_balio·mmap·poll·파이프 등과 적합성 baliozkotu |
| 언어별 Izena | Euskara 46개 대응 sarrera_balio, benetako_datuak C/Java/Fitxategia Izena 적용 | helburu_balio Hizkuntza 확정, 언어별 용례·역사 근거와 해당 ITURBURUA·도구의 baliozkotu |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 exekutatu_komando 환경을 추가하는 방식은 별도의 nukleo_balio·루트 fitxategi_sistema·OpenJDK·그래픽 zerbitzari_balio·영구 Store_balio 구성을 가진 exekutatu_komando 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

exekutatu_komando 기반과 Erantsi_sarrera helburu_balio 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
