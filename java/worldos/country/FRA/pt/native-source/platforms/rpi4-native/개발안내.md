# nativo 커널에서 vi·여러 terminal·한글 프로그래밍 사용하기

Português comunicação·exceção 사용법은 [Português Java API](한국어자바/LEIAME_eb81d7d9.md), FUNÇÃO_VALOR·variável_VALOR·ficheiro 이름의 변경과 어원 근거는 [명명 LEIAME_eb81d7d9](명명/LEIAME_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 nativo AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 Suporte_VALOR 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 Executar_comando, externo_VALOR TCP/UDP와 FTP는 [새 Executar_comando 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 terminal

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, Endereço **127.0.0.1:5902**로 연결한다. tela 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 terminal 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **DIREITA 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 Executar_comando 버튼으로 repetir_VALOR COL_VALOR número 있다. 기존 `terminal`, `exit`, F12도 사용할 número 있다.

창마다 em_dia_item 디렉터리, shell variável_VALOR, comando LOG_linha, entrada_VALOR 중인 명령과 app_f5044b9b Executar_comando 상태를 보관한다. ficheiro 저장소는 공유한다. vi와 Swing의 이벤트 aguarde_VALOR 중에 다른 터미널로 전환하면 espaço_do_utilizador Memória_dados·레지스터·ficheiro/soquete_VALOR 연결을 보존했다가 돌아올 때 재개한다. **em_dia_item 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 Avançar_item entrada_VALOR aguarde_VALOR 또는 기존 Executar_comando 기한까지 전환이 지연될 número 있다.

X로 터미널을 닫으면 그 터미널의 Executar_comando 중인 프로그램도 종료하며 descritor_entrada·소켓을 회수한다. 저장하지 않은 Editar_VALOR 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. em_dia_item 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 Janela 판단은 게스트 커널이 처리한다. QEMU Executar_comando 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. real_dados Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI ferramentas 종료는 host 터미널의 Ctrl+C다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **kernel_VALOR 내부 연결형 byte_VALOR fluxo_VALOR**을 추가했다. ficheiro/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket servidor_VALOR = new java.net.ServerSocket(9250);
java.net.Socket convidado_VALOR = new java.net.Socket("localhost", 9250);
java.net.Socket Ligar = servidor_VALOR.accept();
convidado_VALOR.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] RECEBER_item = new byte[64];
int duração_VALOR = Ligar.getInputStream().read(RECEBER_item);
Ligar.close(); convidado_VALOR.close(); servidor_VALOR.close();
```

gerar·Ligar·accept·양방향 byte_VALOR/MATRIZ_VALOR E_S·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 encerrar_ponto 16개, receber_VALOR 버퍼당 1024바이트, aguarde_VALOR Ligar 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. valor_padrão valor_temporal 제한 0은 별도 soquete_VALOR 기한을 설정하지 않지만 JVM comando número/kernel_VALOR Executar_comando 기한은 여전히 적용된다.

externo_VALOR dígito_VALOR IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. real_dados Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP biblioteca 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [teste_fluxo.java](testes/자바/teste_fluxo.java)는 real_dados 송수신·EOF·기한·Ligar 회수의 testes 예제다.

`rede_ABI.h`의 nativo `pk_sockaddr_in`을 사용하며 porta_VALOR·주소는 `망차례짧은수`/`rede_inteiro`로 변환한다. C soquete_VALOR 호출은 비차단이며 dados/연결이 없으면 -1과 `número_do_erro=11`(EAGAIN)을 반환한다. 양수 E_S 결과가 요청보다 작을 número 있으므로 sprint_VALOR 처리한다. falha_VALOR 후에만 오류번호를 확인한다.

[fluxo_VALOR.c](예제/한글코딩/fluxo_VALOR.c)는 C에서 Português 이름으로 Ligar·accept·부분 Leitura/Escrita·큐 포화·EOF를 처리하는 Executar_comando 예제다. SDK의 `examples/fluxo_VALOR.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → real_dados Português C FUNÇÃO_VALOR 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·ponteiro 검사 → Java RAM ficheiro/루프백 또는 externo_VALOR lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 kernel_VALOR 내부용이므로 EL0 프로그램에 링크하지 않는다. ## Português 이름으로 직접 작성하는 창과 thread_VALOR

`example/java/ExemploJanela.java`는 `실행할일.Executar`,
`동작받이.receber_Ação(Ação_aviso)`, `botão`, `Evento_Fila.나중에실행`, `iniciar()`을 쓴다.
nativo JVM에 이 이름들의 objeto_VALOR·método_VALOR·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `tarefaSegundoPlano`도 nativo 스케줄러와 직접 연결된다.
세부 메서드와 기존 Português API에서의 변경은 [Português API 문서](한국어자바/LEIAME_eb81d7d9.md)를 본다.

host javac는 distribuição_VALOR JAR를 aula_VALOR 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/ExemploJanela.java
python3 ferramentas/Executar_comando.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text

```

직접 tela/thread_VALOR API와 `iniciar()` 진입점은 nativo JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 número 있다.
