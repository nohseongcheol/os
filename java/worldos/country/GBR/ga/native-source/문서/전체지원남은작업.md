# 전체 Tacaíocht_VALUE 요청의 현재 staid_VALUE

iarratas_HTTP 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 iarbhír_sonraí C POSIX 일부 기능, Gaeilge API/FOINSE Ainm, IDE Comhad 보존, 게스트 Java Comhad 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/LÉIGHMÉ_eb81d7d9.md)를 기준으로 판단한다.

| iarratas_HTTP 분야 | 현재 Rith_ordú 가능한 gearrthóg | 전체 지원에 필요한 작업 |
|---|---|---|
| Java tóg_foinse·Rith_ordú | 게스트 제한형 javac/JVM, statach_VALUE 단일 클래스와 일부 표준 oibiacht_VALUE | 일반 oibiacht_VALUE·aicme_VALUE Nasc·eisceacht·GC·스레드, 완전한 javac와 표준 aicme_VALUE leabharlann |
| Comhad | POSIX 서술자, Java 단일 beart_VALUE Comhad sruth_VALUE, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·cead_VALUE·잠금·일반 córas_comhad·breisiú_VALUE 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP óstach 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 ócáid·clófhoireann_VALUE·fuinneog córas_oibriúcháin_VALUE, AWT 네이티브 연결과 Swing Rith_ordú 기반 |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 Rith_ordú 환경을 추가하는 방식은 별도의 eithne_VALUE·루트 córas_comhad·OpenJDK·그래픽 freastalaí_VALUE·영구 Store_VALUE 구성을 가진 Rith_ordú 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

Rith_ordú 기반과 추가 sprioc 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
