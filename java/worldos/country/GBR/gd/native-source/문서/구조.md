아래는 nì_VALUE 기반 관리 eitean_VALUE 전체의 targaid_nì 구조다. 현재 dearbh_dàta 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 siostam_obrachaidh LEUGHMI_eb81d7d9](../os/LEUGHMI_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·co_theacsa_VALUE SWITCH_MODE·siostam_fhaidhlichean 등이 새 ISO에 모두 포함돼 있지는 않다.


OpenJDK 자체는 이미 운영체제가 제공하는 faidhle, 스레드, 가상 기억공간을 전제로 한다. 따라서 eitean_VALUE 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, co_theacsa_VALUE 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
