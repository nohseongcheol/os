# 자체 커널에서 vi·여러 ટર્મિનલ·한글 프로그래밍 사용하기

ગુજરાતી 통신·예외 사용법은 [ગુજરાતી Java API](한국어자바/રીડમી_eb81d7d9.md), ફંક્શંસ_મૂલ્ય·변수·ફાઈલ 이름의 변경과 어원 근거는 [명명 રીડમી_eb81d7d9](명명/રીડમી_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 자체 AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 સપોર્ટ_મૂલ્ય 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 અમલ_કરો_આદેશ, 외부 TCP/UDP와 FTP는 [새 અમલ_કરો_આદેશ 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 ટર્મિનલ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, સરનામું **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 ટર્મિનલ 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **오른쪽 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 અમલ_કરો_આદેશ 버튼으로 다시 હરોળ_મૂલ્ય 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 현재 디렉터리, શેલ 변수, આદેશ લૉગ_પંક્તિ, 입력 중인 명령과 એપ્લિકેશન_f5044b9b અમલ_કરો_આદેશ 상태를 보관한다. ફાઈલ 저장소는 공유한다. vi와 Swing의 이벤트 પ્રતીક્ષા_મૂલ્ય 중에 다른 터미널로 전환하면 ઉપયોગકર્તા મેમરી_ડેટા·레지스터·ફાઈલ/소켓 연결을 보존했다가 돌아올 때 재개한다. **현재 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 આગલું_આઇટમ 입력 પ્રતીક્ષા_મૂલ્ય 또는 기존 અમલ_કરો_આદેશ 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 અમલ_કરો_આદેશ 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 સંપાદન_મૂલ્ય 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. 현재 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 વિંડો 판단은 게스트 커널이 처리한다. QEMU અમલ_કરો_આદેશ 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. વાસ્તવિક_ડેટા Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI ઉપકરણો 종료는 હોસ્ટ 터미널의 Ctrl+C다.

## vi 사용

```text
mkdir 작업
cd 작업
vi 인사.py
```

`vi`는 새로 구현한 **vi આદેશ 부분집합** 편집기다. 내장 `build/user/vi.elf`를 보호된 ઉપયોગકર્તા 영역에 적재한다. ફાઈલ 크기는 UTF-8 બાઇટ_મૂલ્ય પ્રોજેક્ટ_રૂટ 16 KiB, 경로는 63바이트까지다. 디스크에 설치한 Vim/Neovim 바이너리를 실행하는 것이 아니다.

| કી_મૂલ્ય/આદેશ | ક્રિયા |
|---|---|
| `i`, `a`, `I`, `A` | 현재/આગલું_આઇટમ સ્થાન 또는 લાઇન 처음/끝에서 입력 |
| `o`, `O` | 아래/위에 새 줄을 만들고 입력 |
| Esc | 일반 મોડ_મૂલ્ય |
| `h j k l`, 방향키 | UTF-8 문자/લાઇન ખસેડવું_મૂલ્ય |
| `0`, `$`, Home, End | લાઇન 처음/끝 |
| `gg`, `G`, `:અનુક્રમણિકા` | ફાઈલ 처음/마지막 લાઇન/지정 લાઇન |
| PgUp, PgDn | 화면 એકમ_મૂલ્ય ખસેડવું_મૂલ્ય |
| `x`, Delete | 현재 문자 삭제 |
| `dd`, `yy`, `p` | લાઇન 삭제/ઉદાહરણ_મૂલ્ય/ચોંટાડો_પાઠ |
| `u` | 마지막 편집을 되돌림; 한 સ્ટેજ_મૂલ્ય 토글 |
| `/સ્ટ્રિંગ_મૂલ્ય`, `n` | 단순 સ્ટ્રિંગ_મૂલ્ય 검색/આગલું_આઇટમ 일치; 정규식 없음 |
| `:w`, `:w 다른이름` | RAM ફાઈલ સંગ્રહ_કરવો_મૂલ્ય/다른 경로로 સંગ્રહ_કરવો_મૂલ્ય |
| `:q` | 변경이 없을 때 પ્રસ્થાન_એપ્લિકેશન |
| `:q!` | 변경을 버리고 પ્રસ્થાન_એપ્લિકેશન |
| `:wq`, `ZZ` | 저장하고 પ્રસ્થાન_એપ્લિકેશન |

붙여 넣은 한글을 문자 경계에 맞춰 ખસેડવું_મૂલ્ય·삭제한다. 일반 vi의 수량 접두사, મૅક્રો_મૂલ્ય, સુયોજના ફાઈલ, 플러그인, 정규식, 여러 버퍼/분할 વિંડો, 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/영 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 વિંડો વિંડો_શીર્ષક `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 આદેશ**으로 실행한다. 파이프·리다이렉션·સ્ક્રિપ્ટ_મૂલ્ય·`;`/`&&`/`||`로 연결한 실행에서 સહભાગી 대기를 시작하면 거부한다. 입력 대기는 약 2초 CPU 기한을 갱신하지만 입력 પ્રતીક્ષા_મૂલ્ય 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## 한글 Java

vi에서 다음을 `인사.java`에 입력하고 Esc → `:wq`로 저장한다.

```java
public class 인사 {
    static int 더하기(int 첫째, int 둘째) { return 첫째 + 둘째; }
    public static void main(String[] દલીલો) {
        int 합계 = 더하기(20, 22);
        System.out.println("안녕하세요 · 합계=" + 합계);
    }
}
```

게스트 셸에서 실행한다.

```text
javac 인사.java
java 인사
```

한글 ફાઇલ_નામ_પાઠ·વર્ગ_નામ·પદ્ધતિ_નામ_પાઠ·변수명·문자열을 사용할 수 있다. **게스트 javac는 સ્થિર_મૂલ્ય Java 부분집합**이다. ઑબ્જેક્ટ_મૂલ્ય·리스너·Swing·소켓을 사용하는 소스는 현재 હોસ્ટ JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 자체 JVM에 class를 올린다. 자체 JVM에서 지원하는 바이트코드/API 범위는 [자바실행환경.md](자바실행환경.md)를 따른다.

```sh
# હોસ્ટ
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/스윙시험.java
python3 ઉપકરણો/અપલોડ_કરો_ફાઇલો.py build/my-java/스윙시험.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. આઉટપુટ 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.વર્ગ_મૂલ્ય.class` 형식이다. 내장 ગુજરાતી 라이브러리는 별도 업로드가 필요 없다. ગુજરાતી વિંડો API의 예제는 [한글창시험.java](시험/자바/한글창시험.java)이며 같은 방법으로 બિલ્ડ_કરો_સ્રોત·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 સ્રોત_ટ્રી/클래스는 호스트의 `python3 ઉપકરણો/અમલ_કરો_ફાઇલ.py પથ/인사.java`로 별도 QEMU에 업로드·અમલ_કરો_આદેશ·종료할 수 있다. સહભાગી Swing에는 અમલ_કરો_આદેશ 후 ઉપયોગકર્તા 입력을 유지하는 `make desktop`을 사용한다.

## 자체 JVM의 Swing ક્લિપ

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 자체 Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | ક્રિયા |
|---|---|
| `JFrame` | વિંડો_શીર્ષક, માપ·સ્થાન, શૉ_વિંડો, બંધ_કરો 정책, dispose |
| `JPanel` | બાળક_મૂલ્ય 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 સ્ટ્રિંગ_મૂલ્ય શૉ_મૂલ્ય·પરિવર્તન_કરો_મૂલ્ય |
| `JButton` | 버튼과 ActionListener ક્લિક_કરો_મૂલ્ય પ્રક્રિયા_મૂલ્ય_પ્રવેશ |
| `JTextField` | 한 લાઇન UTF-8 입력, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 자체 JVM의 단일 이벤트 અમલ_કરો_આદેશ 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. વિંડો·요소는 અમલ_કરો_આદેશ 하나당 합계 32개, તત્વ_મૂલ્ય 글자는 최대 127 코드포인트다. ડિફૉલ્ટ_મૂલ્ય 서체와 색은 커널이 제공한다.

[스윙시험.java](시험/자바/스윙시험.java)는 વિંડો·한글 ટૅગ_મૂલ્ય·ટેક્સ્ટ_ફીલ્ડ·버튼·이벤트 처리의 અમલ_કરો_આદેશ 가능한 예제다. [자체 Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

ગુજરાતી 라이브러리에는 다음을 추가했다. હોસ્ટ બિલ્ડ_કરો_સ્રોત 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `ગુજરાતી.자체.વિંડો`: `ઍડ_કરો_તત્વ`, `શૉ_વિંડો`, `બંધ_કરો`.
- `ગુજરાતી.자체.વિજેટ`: `ટૅગ_મૂલ્ય`, `બટન`, `ટેક્સ્ટ_ફીલ્ડ` જનરેટ_કરો.
- `ગુજરાતી.자체.연결통신`: `સંપર્ક_કરો`, `듣기`, `받기`.
- 기존 `આઉટપુટ`, `문자`, `ફાઈલ`, `작업`, `પ્રવેશ_સૂચી`, `શબ્દકોશ`, `통신`, `화면`, `કર્નેલ_મૂલ્ય`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **કર્નેલ_મૂલ્ય 내부 연결형 બાઇટ_મૂલ્ય સ્ટ્રીમ_મૂલ્ય**을 추가했다. ફાઈલ/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket સર્વર_મૂલ્ય = new java.net.ServerSocket(9250);
java.net.Socket અતિથિ_મૂલ્ય = new java.net.Socket("localhost", 9250);
java.net.Socket સંપર્ક_કરો = સર્વર_મૂલ્ય.accept();
અતિથિ_મૂલ્ય.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int લંબાઈ_મૂલ્ય = સંપર્ક_કરો.getInputStream().read(받은것);
સંપર્ક_કરો.close(); અતિથિ_મૂલ્ય.close(); સર્વર_મૂલ્ય.close();
```

જનરેટ_કરો·સંપર્ક_કરો·accept·양방향 બાઇટ_મૂલ્ય/અરે_મૂલ્ય ઇનપુટ_આઉટપુટ·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 અંત_કરો_બિંદુ 16개, 수신 버퍼당 1024바이트, પ્રતીક્ષા_મૂલ્ય સંપર્ક_કરો 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. ડિફૉલ્ટ_મૂલ્ય સમય_મૂલ્ય 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM આદેશ 수/કર્નેલ_મૂલ્ય અમલ_કરો_આદેશ 기한은 여전히 적용된다.

외부 અંક_મૂલ્ય IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. વાસ્તવિક_ડેટા Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP લાઇબ્રેરી 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 વાસ્તવિક_ડેટા 송수신·EOF·기한·સંપર્ક_કરો 회수의 시험 예제다.

## 한글 Python

게스트 vi에서 한글 이름을 사용해 작성한다.

```python

def 두배(અંક_મૂલ્ય):
    return અંક_મૂલ્ય * 2

print("પરિમાણ:", 두배(મૂલ્ય))
```

સંગ્રહ_કરવો_મૂલ્ય 후 `python 인사.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 ફંક્શંસ_મૂલ્ય·변수·ફાઈલ 이름과 문자열을 한글로 쓴다.

[ગુજરાતી.py](예제/한글코딩/ગુજરાતી.py)를 같은 디렉터리에 두면 આગલું_આઇટમ 별칭을 사용할 수 있다.

```python
import ગુજરાતી
ગુજરાતી.લખો_ફાઇલ("인사.txt", "안녕하세요")
ગુજરાતી.આઉટપુટ(ગુજરાતી.파일읽기("인사.txt").decode())
```

આઉટપુટ·ફાઈલ વાંચો/લખો/삭제·표준 입력·사각형·સમય_મૂલ્ય·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 અંક_મૂલ્ય IPv4 સરનામું 전송이다. `wait_key()`는 화면을 확인할 때 સહભાગી 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor સ્થિર_મૂલ્ય 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 એક્સ્ટેંશન_મૂલ્ય 모듈은 아직 없다. 제한형 `pip`의 સ્રોત_ટ્રી 설치는 [Python બન્ડલ રીડમી_eb81d7d9](파이썬꾸러미.md)를 따른다. [세 언어의 વાસ્તવિક_ડેટા 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 ભાષા 모두 ગુજરાતી 헤더와 ફંક્શંસ_મૂલ્ય 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 વાસ્તવિક_ડેટા EL0 અમલ_કરો_આદેશ 시험 대상이다.

```c
#include "파일규약.h"
#ifdef __cplusplus
extern "C"
#endif
int પ્રારંભ_ઉપયોગકર્તા_એપ્લિકેશન(int દલીલો) {
    (void)દલીલો;
    const char 인사말[] = "안녕하세요\n";
    int 문서 = બનાવો_ફાઇલ("인사.txt", વાંચન_લેખન | 없으면만들기 | 내용비우기, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = લખો_ફાઇલ_ડેટા(문서, 인사말, sizeof(인사말) - 1);
    બંધ_કરો_ફાઇલ(문서);
    લખો_ફાઇલ_ડેટા(1, 인사말, sizeof(인사말) - 1); /* 현재 ટર્મિનલ stdout */
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 수 있다. C는 게스트 `cc` 또는 હોસ્ટ SDK, C++는 હોસ્ટ SDK의 Clang++로 컴파일한다. 아래 예제는 기존 હોસ્ટ SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh
# 호스트에서 SDK જનરેટ_કરો·બહાર_કાઢો
make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/인사.c -o 인사-c.elf
python3 compile.py examples/인사.cpp -o 인사-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 વાસ્તવિક_ડેટા અમલ_કરો_આદેશ
cd /home/user/jkoros/platforms/rpi4-native
python3 ઉપકરણો/અમલ_કરો_ફાઇલ.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 ઉપકરણો/અમલ_કરો_ફાઇલ.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

현재 GUI VM에서 실행하려면 `python3 ઉપકરણો/અપલોડ_કરો_ફાઇલો.py પથ/인사-c.elf`의 출력을 게스트에 보내고 `run 인사-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex ફાઇલ_નામ_પાઠ`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 수 있다. 호스트와 게스트의 ફાઈલ 시스템은 별개다.

| ગુજરાતી નામ | C પ્રતીક | ક્લિપ |
|---|---|---|
| બનાવો_ફાઇલ/બંધ_કરો_ફાઇલ | pk_open/pk_close | RAM ફાઈલ, પીઅર_મૂલ્ય/절대 પથ |
| 파일자료읽기/લખો_ફાઇલ_ડેટા | pk_read/pk_write | ફાઈલ, fd 0/1/2 표준 ઇનપુટ_આઉટપુટ, 연결형 소켓 |
| સીક_ફાઇલ | pk_lseek | 처음기준/현재기준/끝기준 |
| ફાઇલ_આકાર/સેટ_ફાઇલ_લંબાઈ | pk_size/pk_ftruncate | લંબાઈ_મૂલ્ય ક્વેરી_મૂલ્ય/પરિવર્તન_કરો_મૂલ્ય |
| કાઢી_નાંખો_ફાઇલ_પ્રવેશ_નામ | pk_unlink | ફાઈલ નામ 삭제 |
| 파일저장확정 | pk_fsync | RAM이므로 -1, 오류번호=ENOSYS |
| 통신종단점만들기/બાઇંડ_કરો_સરનામું | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |
| 자료전문보내기/자료전문받기 | pk_sendto/pk_recvfrom | UDP 루프백 |
| કનેક્ટ_નેટવર્ક | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | પ્રતીક્ષા_મૂલ્ય સંપર્ક_કરો 최대 4개 |
| સ્વીકારો_નેટવર્ક_કનેક્શન | pk_accept | 현재 સરનામું 인수는 NULL/NULL만 સપોર્ટ_મૂલ્ય |
| 통신주소읽기 | pk_getsockname | 로컬 સરનામું/પૉર્ટ_મૂલ્ય |

`통신규약.h`의 자체 `pk_sockaddr_in`을 사용하며 પૉર્ટ_મૂલ્ય·주소는 `망차례짧은수`/`નેટવર્ક_પૂર્ણાંક`로 변환한다. C 소켓 호출은 비차단이며 ડેટા/연결이 없으면 -1과 `오류번호=11`(EAGAIN)을 반환한다. 양수 ઇનપુટ_આઉટપુટ 결과가 요청보다 작을 수 있으므로 પુનરાવર્તન_મૂલ્ય 처리한다. નિષ્ફળતા_મૂલ્ય 후에만 오류번호를 확인한다.

[સ્ટ્રીમ_મૂલ્ય.c](예제/한글코딩/સ્ટ્રીમ_મૂલ્ય.c)는 C에서 ગુજરાતી 이름으로 સંપર્ક_કરો·accept·부분 વાંચો/લખો·큐 포화·EOF를 처리하는 અમલ_કરો_આદેશ 예제다. SDK의 `examples/સ્ટ્રીમ_મૂલ્ય.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → વાસ્તવિક_ડેટા ગુજરાતી C ફંક્શંસ_મૂલ્ય 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·સૂચક 검사 → Java RAM ફાઈલ/루프백 또는 외부 lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 કર્નેલ_મૂલ્ય 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 સંપર્ક_કરો, 표준 C printf, libstdc++/STL, 예외·RTTI는 제공하지 않으며 C++의 સ્થિર_મૂલ્ય 생성자·સ્થાનિક_અવકાશ ઑબ્જેક્ટ_મૂલ્ય 소멸자는 지원한다. 상세 અનુક્રમણિકા·મેમરી_ડેટા 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## માન્ય_કરો

`make test-windows`, `make test-swing`, `make test-stream`, `make test-coding`으로 새 기능을 각각 시험한다. `make test`는 기존 શેલ·VNC·JVM·AOT·કર્નેલ_મૂલ્ય રક્ષણ_કરો_મૂલ્ય 시험까지 포함한다. વાસ્તવિક_ડેટા બોર્ડ 대신 QEMU raspi4b에서 수행한다. 결과는 [이전 GUI એક્સ્ટેંશન_મૂલ્ય માન્ય_કરો લૉગ_પંક્તિ](build/verification/release.json)과 [현재 સામાન્ય_ભાષા_રનટાઇમ માન્ય_કરો લૉગ_પંક્તિ](build/verification/native-runtime-summary.json), [여러 ટર્મિનલ 화면](build/verification/windows/four-terminals.png), [Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

구현 시 참고한 표준 API: [Socket](https://docs.oracle.com/javase/8/docs/api/java/net/Socket.html), [JFrame](https://docs.oracle.com/javase/8/docs/api/javax/swing/JFrame.html), [JButton](https://docs.oracle.com/javase/8/docs/api/javax/swing/JButton.html). 이 문서의 구현 범위가 위 표준 전체를 지원한다는 뜻은 아니다.

## ગુજરાતી 이름으로 직접 작성하는 창과 થ્રેડ_મૂલ્ય

`example/java/창예제.java`는 `실행할일.ચલાવો`,
`동작받이.동작받기(동작알림)`, `બટન`, `ઇવેંટ_કતાર.나중에실행`, `ચલાવો_2()`을 쓴다.
자체 JVM에 이 이름들의 ઑબ્જેક્ટ_મૂલ્ય·પદ્ધતિ_મૂલ્ય·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `작업가닥`도 자체 스케줄러와 직접 연결된다.
세부 메서드와 기존 ગુજરાતી API에서의 변경은 [ગુજરાતી API 문서](한국어자바/રીડમી_eb81d7d9.md)를 본다.

હોસ્ટ javac는 배포 JAR를 વર્ગ_મૂલ્ય 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/창예제.java
python3 ઉપકરણો/અમલ_કરો_આદેશ.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java 창예제
```

직접 화면/થ્રેડ_મૂલ્ય API와 `ચલાવો_2()` 진입점은 자체 JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
