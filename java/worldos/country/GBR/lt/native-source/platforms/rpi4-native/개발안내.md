# savas 커널에서 vi·여러 Terminalas·한글 프로그래밍 사용하기

Lietuvių 통신·išimtis 사용법은 [Lietuvių Java API](한국어자바/안내.md), FUNCTION_VALUE·kintamasis_VALUE·Failas 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

대상은 `platforms/rpi4-native`의 savas AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 pagalba_VALUE 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 Vykdyti_komanda, išorinis_VALUE TCP/UDP와 FTP는 [새 Vykdyti_komanda 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 Terminalas

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, ADDRESS **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 Terminalas 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **RIGHT 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 Vykdyti_komanda 버튼으로 kartoti_VALUE COLUMN_VALUE numeris 있다. 기존 `terminal`, `exit`, F12도 사용할 numeris 있다.

창마다 dabartinis_prekė 디렉터리, apvalkalas kintamasis_VALUE, Komanda LOG_RECORD, 입력 중인 명령과 programa_f5044b9b Vykdyti_komanda 상태를 보관한다. Failas 저장소는 공유한다. vi와 Swing의 이벤트 Palauk_VALUE 중에 다른 터미널로 전환하면 naudotojas atmintis_duomenys·레지스터·Failas/소켓 연결을 보존했다가 돌아올 때 재개한다. **dabartinis_prekė 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 toliau_prekė 입력 Palauk_VALUE 또는 기존 Vykdyti_komanda 기한까지 전환이 지연될 numeris 있다.

X로 터미널을 닫으면 그 터미널의 Vykdyti_komanda 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 redaguoti_VALUE 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. dabartinis_prekė 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 Langas 판단은 게스트 커널이 처리한다. QEMU Vykdyti_komanda 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. faktinis_duomenys Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI Įrankiai 종료는 organizuoti 터미널의 Ctrl+C다.


게스트 셸에서 실행한다.

```text

```

한글 failo_vardas_SMS·klasės_pavadinimas·metodas_pavadinimas_SMS·변수명·문자열을 사용할 numeris 있다. **게스트 javac는 정적 Java 부분집합**이다. objektas_VALUE·리스너·Swing·소켓을 사용하는 소스는 dabartinis_prekė organizuoti JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 savas JVM에 class를 올린다. savas JVM에서 지원하는 바이트코드/API 범위는 [자바실행환경.md](자바실행환경.md)를 따른다.

```sh

mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/스윙시험.java
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. Išvestis 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.klasė_VALUE.class` 형식이다. 내장 Lietuvių 라이브러리는 별도 업로드가 필요 없다. Lietuvių Langas API의 예제는 [한글창시험.java](시험/자바/한글창시험.java)이며 같은 방법으로 kompiliuoti_šaltinis·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 šaltinis_medis/클래스는 호스트의 `python3 Įrankiai/Vykdyti_Failas.py KELIAS/인사.java`로 별도 QEMU에 업로드·Vykdyti_komanda·종료할 numeris 있다. 대화형 Swing에는 Vykdyti_komanda 후 naudotojas 입력을 유지하는 `make desktop`을 사용한다.

## savas JVM의 Swing klipas

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 savas Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | Veiksmas |
|---|---|
| `JFrame` | langas_Pavadinimas, Dydis·Pozicija, laida_langas, Užverti 정책, dispose |
| `JPanel` | vaikas_VALUE 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 eilutė_VALUE laida_VALUE·keisti_VALUE |
| `JButton` | 버튼과 ActionListener spustelėti_VALUE Procesas_VALUE_įrašas |
| `JTextField` | 한 Eilutė UTF-8 입력, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 savas JVM의 단일 이벤트 Vykdyti_komanda 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. Langas·요소는 Vykdyti_komanda 하나당 bendras_VALUE 32개, elementas_VALUE 글자는 최대 127 코드포인트다. numatytoji_reikšmė 서체와 색은 커널이 제공한다.

[스윙시험.java](시험/자바/스윙시험.java)는 Langas·한글 žyma_VALUE·teksto_laukas·버튼·이벤트 처리의 Vykdyti_komanda 가능한 예제다. [savas Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

Lietuvių 라이브러리에는 다음을 추가했다. organizuoti kompiliuoti_šaltinis 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `Lietuvių.savas.Langas`: `Įtraukti_elementas`, `laida_langas`, `Užverti`.
- `Lietuvių.savas.valdiklis`: `žyma_VALUE`, `mygtukas`, `teksto_laukas` generuoti.
- `Lietuvių.savas.ryšys_transportavimas`: `Prisijungti`, `laukti_dalyvis`, `gauti`.
- 기존 `Išvestis`, `문자`, `Failas`, `작업`, `įrašas_Sąrašas`, `žodynas`, `통신`, `화면`, `branduolys_VALUE`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **branduolys_VALUE 내부 연결형 baitas_VALUE Stream_VALUE**을 추가했다. Failas/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket serveris_VALUE = new java.net.ServerSocket(9250);
java.net.Socket svečias_VALUE = new java.net.Socket("localhost", 9250);
java.net.Socket Prisijungti = serveris_VALUE.accept();
svečias_VALUE.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] RECEIVED_prekė = new byte[64];
int 길이 = Prisijungti.getInputStream().read(RECEIVED_prekė);
Prisijungti.close(); svečias_VALUE.close(); serveris_VALUE.close();
```

generuoti·Prisijungti·accept·양방향 baitas_VALUE/ARRAY_VALUE Į_I·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 baigti_pokalbį_p 16개, gauti_VALUE_cef4d8ab 버퍼당 1024바이트, Palauk_VALUE Prisijungti 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. numatytoji_reikšmė TIME_VALUE 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM Komanda numeris/branduolys_VALUE Vykdyti_komanda 기한은 여전히 적용된다.

išorinis_VALUE skaitmuo_VALUE IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. faktinis_duomenys Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP biblioteka 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 faktinis_duomenys 송수신·EOF·기한·Prisijungti 회수의 시험 예제다.

Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor 정적 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 plėtinys_VALUE 모듈은 아직 없다. 제한형 `pip`의 šaltinis_medis 설치는 [Python paketas 안내](PYTHON_paketas.md)를 따른다. [세 언어의 faktinis_duomenys 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 Kalba 모두 Lietuvių 헤더와 FUNCTION_VALUE 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 faktinis_duomenys EL0 Vykdyti_komanda 시험 대상이다.

```c
#include "파일규약.h"
#ifdef __cplusplus
extern "C"
#endif
int Start_naudotojas_programa(int Argumentai) {
    (void)Argumentai;
    const char 인사말[] = "안녕하세요\n";
    int 문서 = kurti_Failas("인사.txt", 읽고쓰기 | 없으면만들기 | trumpinti_Turinys, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = rašymas_Failas_duomenys(문서, 인사말, sizeof(인사말) - 1);
    Uždaryti_Failas(문서);
    rašymas_Failas_duomenys(1, 인사말, sizeof(인사말) - 1); /* dabartinis_prekė Terminalas stdout */
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 numeris 있다. C는 게스트 `cc` 또는 organizuoti SDK, C++는 organizuoti SDK의 Clang++로 컴파일한다. 아래 예제는 기존 organizuoti SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh

make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/인사.c -o 인사-c.elf
python3 compile.py examples/인사.cpp -o 인사-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 faktinis_duomenys Vykdyti_komanda
cd /home/user/jkoros/platforms/rpi4-native
python3 Įrankiai/Vykdyti_Failas.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 Įrankiai/Vykdyti_Failas.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

| kurti_dalyvis/BIND_ADDRESS | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |

| ryšys_tinklas | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | Palauk_VALUE Prisijungti 최대 4개 |
| priimti_tinklo_ryšys | pk_accept | dabartinis_prekė ADDRESS 인수는 NULL/NULL만 pagalba_VALUE |
| 통신주소읽기 | pk_getsockname | 로컬 ADDRESS/jungtis_VALUE |

`통신규약.h`의 savas `pk_sockaddr_in`을 사용하며 jungtis_VALUE·주소는 `망차례짧은수`/`tinklas_sveikasis_skaičius`로 변환한다. C 소켓 호출은 비차단이며 duomenys/연결이 없으면 -1과 `klaidos_numeris=11`(EAGAIN)을 반환한다. 양수 Į_I 결과가 요청보다 작을 numeris 있으므로 sprintas_VALUE 처리한다. triktis_VALUE 후에만 오류번호를 확인한다.

[Stream_VALUE.c](예제/한글코딩/Stream_VALUE.c)는 C에서 Lietuvių 이름으로 Prisijungti·accept·부분 Skaitymas/Rašymas·큐 포화·EOF를 처리하는 Vykdyti_komanda 예제다. SDK의 `examples/Stream_VALUE.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → faktinis_duomenys Lietuvių C FUNCTION_VALUE 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·rodyklė 검사 → Java RAM Failas/루프백 또는 išorinis_VALUE lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 branduolys_VALUE 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 Prisijungti, 표준 C printf, libstdc++/STL, išimtis·RTTI는 제공하지 않으며 C++의 정적 생성자·vietinis_Aprėptis objektas_VALUE 소멸자는 지원한다. 상세 INDEX·atmintis_duomenys 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## Lietuvių 이름으로 직접 작성하는 창과 gija_VALUE

`example/java/LangoPavyzdys.java`는 `실행할일.Vykdyti`,
`동작받이.gauti_gavinys(gavinys_pranešimas)`, `mygtukas`, `įvykis_eilė.나중에실행`, `Paleisti()`을 쓴다.
savas JVM에 이 이름들의 objektas_VALUE·metodas_VALUE·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `darbininkas`도 savas 스케줄러와 직접 연결된다.
세부 메서드와 기존 Lietuvių API에서의 변경은 [Lietuvių API 문서](한국어자바/안내.md)를 본다.

organizuoti javac는 paskirstymas_VALUE JAR를 klasė_VALUE 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/LangoPavyzdys.java
python3 Įrankiai/Vykdyti_komanda.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java LangoPavyzdys
```

직접 화면/gija_VALUE API와 `Paleisti()` 진입점은 savas JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 numeris 있다.
