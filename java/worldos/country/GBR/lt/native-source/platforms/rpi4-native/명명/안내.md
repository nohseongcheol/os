# savas 커널과 번역기의 Lietuvių Pavadinimas_2

대상은 `platforms/rpi4-native`의 savas Java branduolys_VALUE, naudotojas JVM, C mašina Prisijungti,
TCP/UDP·FTP, C kompiliatorius_įrankis 이식부, MicroPython 이식부, kompiliuoti_sistema·Vykdyti_komanda·시험 도구다.
`golang/worldos/Kantri_VALUE/KOR/ŠALTINIS`의 원칙처럼 기능을 먼저 구분하고 이름을 정한다.
x86 Java 커널과 공용 x86·ARM64 미리 번역기의 savas 선언도 명명 검사에 포함한다.
Linux 실행판의 organizuoti Įrankiai, OpenJDK 보조 Įrankiai 및 išorinis_VALUE paskirstymas_VALUE šaltinis_medis 전체를
한국어로 kartoti_VALUE 작성했다는 뜻은 아니다.

## 명명 원칙과 말의 근거

- 명사는 자료의 역할을 나타낸다: `Failas_rodyklė`, `lygiavertis_mazgas_prievado_numeris`, `동적기억공간`, `klaviatūra`.
- 함수는 행위를 나타낸다: `Skaitymas`, `Rašymas`, `Atverti`, `Užverti`, `NET_BIND`, `vykdyti_programa`.
- TCP의 이어진 baitas_VALUE 흐름과 UDP의 경계 있는 자료를 `ryšys`와 `paketų_kelio_schema_kanalas`로 구별한다.
- 짧은 영어 변수도 쓰임에 따라 `길이`, `duomenys_padėtis`, `LOOKUP_INDEX`, `반환값`으로 풀어 쓴다.
  순번·임시 산술값처럼 여러 역할에 재사용되는 변수는 `순번`, `첫째값`, `SECOND_VALUE`으로 구별한다.
- 이름이 같아도 išorinis_VALUE 구조체의 필드와 savas 변수는 별도로 분석한다.

`kanalas_įrašas(通路)`는 이동이나 교류가 이루어지는 길이라는 기존 의미를 통신 연결에
적용했다. `jungtis_VALUE(窓口)`의 주고받는 접점이라는 의미를 연결을 받는 곳에 적용했다.
이는 국립국어원 한국어기초사전의 [kanalas_įrašas](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=49310),
[jungtis_VALUE](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=24898)의 뜻에 근거한다.

`paketų_kelio_schema(電文)`은 전보에 담는 글이라는 기존 통신 어휘에서 가져와, UDP 자료의
경계가 보존된다는 특징을 드러내는 데 쓴다. 근거는
[한국어기초사전 paketų_kelio_schema](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=74335)이다.
`Stream_VALUE`, `gija_VALUE`, `쌓임`은 우리말의 움직임·이어짐·쌓이는 모양을 빌린 표현이다.
`įvesties_srautas`, `darbininkas`, `eilė_Saugykla` 같은 복합 이름은 이 프로젝트의 기능별 조어다.
이 žodynas 근거를 특정 중세 문헌의 최초 출현이나 공인 전산 번역으로 확대하지 않는다.
공인 표준 Versti_šaltinis·국어사 paketų_kelio_schema 감수를 마쳤다는 뜻도 아니다.

## 보존하는 SD Pavadinimas_2

`public`, `class`, `int`는 예약어다. `String`, `main`, 배열의 `length`는 예약어가 아니다.
dabartinis_prekė 다섯 Java 예제는 `Paleisti()`·`실행인수`·Lietuvių 화면/gija_VALUE API를 사용해
예약어·리터럴 외의 식별자를 한국어로 작성한다. 화면/가닥은 표준 객체를
감싸지 않고 savas JVM에 직접 구현했다. 자세한 계약은 [Lietuvių Java API](../한국어자바/안내.md)를 본다.

표준 javac는 eilutė_VALUE 리터럴에 `java.lang.String`, eilutė_VALUE 결합에 `StringBuilder`
같은 이름을 생성한다. 이들은 Lietuvių 소스에서도 바이트코드에 남을 numeris 있다.
기존 표준 class를 실행하는 JVM의 susiejimas_VALUE eilutė_VALUE, 아직 표준 라이브러리를 쓰는
통신·Failas 연결부까지 모두 한국어로 재구현한 것은 아니다. 이름만 일괄 치환하면
서술자·재정의·native 연결이 달라져 호환성이 깨진다.

C 표준 FUNCTION_VALUE·sveikasis_skaičius_TYPE·POSIX ABI, CPU registras_VALUE Pavadinimas_2, 어셈블리 Komanda, 링커 절 Pavadinimas_2,
TinyCC·lwIP·MicroPython이 요구하는 Nustatymai 매크로와 헤더 이름도 보존한다.
예: `main`, `memcpy`, `pk_bind`, `mpconfigport.h`, `lwipopts.h`, `stdint.h`.
savas C 함수의 šaltinis_medis 이름은 한국어이며, [기계연결이름.h](기계연결이름.h)가
기존 AOT·어셈블리·SDK에 공개한 mašina 심볼과 연결한다.
Python의 `__init__`, `setUp`, `handle`, 표준 modulis_VALUE atributas_VALUE, 명령행 옵션과 JSON 키도
išorinis_VALUE 계약이다. `build/`, paskirstymas_VALUE 바이너리 이름과 `/sdk`는 기존 Vykdyti_komanda 경로를 유지한다.
išorinis_VALUE 원본은 `vendor/`에서 이용허락·해시와 함께 관리한다.

## C 통신 구조체와 Python KLAIDA

C 통신에서 `갈래`는 ADDRESS 체계를 구분하고 `prievado_numeris`는 port, `ADDRESS_VALUE`은
IPv4 주소의 32비트 값을 나타낸다. `paketų_kelio_schema_protokolas`은 앞서 설명한 paketų_kelio_schema(電文)과
sutarties_vertė(規約)을 결합해 UDP의 기능을 드러낸 프로젝트 이름이다.

| 표준 표현 | Lietuvių 직접 구현 |
|---|---|
| AF_INET / SOCK_DGRAM / IPPROTO_UDP | enum의 debesis_Šeima / paketų_maršruto_schemos_jungtis / paketų_kelio_schema_protokolas |
| struct pk_sockaddr_in | struct 인터넷통신주소 |
| sin_family / sin_port | ADDRESS_Šeima / prievado_numeris |
| sin_addr.s_addr | interneto_adresas.ADDRESS_VALUE |
| OSError / KLAIDA.args[0] | 운영체제오류 / KLAIDA.INDEX |

Lietuvių 구조체는 `#define` 치환이나 lauko_reikšmė 별칭이 아닌 별개 자료형이다.
표준 구조체와 같은 16바이트 배치를 선언하며 branduolys_VALUE SVC에서 baitas_VALUE 복사로
검사한다. `kurti_dalyvis`·`siųsti_paketų_kelio_schema_duomenys`와 Failas 함수는 정적 라이브러리에
faktinis_duomenys Lietuvių 이름의 FUNCTION_VALUE 심볼을 갖는다. 기존 pk_* 심볼도 유지한다.
이전 코드에서 Lietuvių 통신 함수에 pk_sockaddr*를 전달했다면 Lietuvių 구조체로
옮기거나, 표준 구조체와 pk_* 함수의 짝을 유지한다.

Python의 `운영체제오류`는 OSError의 Lietuvių 하위 클래스이며 연결부에서
KLAIDA 번호를 보존하여 변환한다. 일반 Python 문법과 išorinis_VALUE 패키지의 API는 유지한다.

## 직접 GUI 이름의 뜻과 검토 klipas

`실행할일`은 수행할 내용을, `Vykdyti`는 그 수행을 나타낸다.
`동작받이`는 동작이 발생했다는 알림을 받는 역할, `gavinys_pranešimas`은 전달되는 사건이다.
`mygtukas`는 눌러 동작시키는 조작부, `Pavadinimas`는 안내 글의 vietos_rodyklė,
`teksto_laukas`은 글을 적는 vietos_rodyklė, `darbininkas`은 이어지는 Vykdyti_komanda 흐름을 뜻한다.
`Vykdyti_komanda(實行)`·`Veiksmas(動作)`의 기존 뜻과 `받다`·`알리다`·`gija_VALUE`의 기능을
결합한 프로젝트 이름이다. 새 복합어가 역사 문헌에 그대로 있었다거나
특정 시대에 처음 쓰였다고 주장하지 않는다.

전체 저장소는 `python3 Įrankiai/šaltinis_atsiliepimas.py`로 검토한다.
결과는 `build/verification/naming/source-review.json`이며 파일별 maiša_Failas,
ASCII 파일명과 Python의 영어 deklaracija 위치를 기록한다.
공용 ARM64·x86 번역기의 구현은 `compiler/자바도구/기계어미리번역.java`로 전환했다. `compiler/기계어미리번역.py`는 호환 진입점이다.
`compiler/arm64.py`는 이전 경로와 `ARM64(...).generate(...)` 호출을 이어 주는
호환 진입점이다. `compiler/classfile.py`, OpenJDK 보조 Įrankiai, Linux versija_VALUE 도구와
기존 호환 진입점에는 영어 이름이 남아 있다. 따라서 전체 저장소가
예약어 외 100% 한국어라고 판정하지 않는다.
`Įrankiai/명명검사.py --C_Kalba`는 Aktyvus ARM64 소스의 deklaracija, C 의미 Analizė_VALUE,
x86 Java 커널과 공용 번역기의 savas deklaracija, Java 예제 전체 identifikatorius_VALUE,
ARM64 Python 예제와 직접 GUI/가닥에 표준 래퍼가 없는지를 별도로 검사한다.

## dabartinis_prekė 기능을 기준으로 보완한 Pavadinimas_2

번역은 글자를 음역하는 대신 자료의 역할과 함수의 행동을 구분한다.
동일한 영어 이름도 문맥이 다르면 Lietuvių 이름을 달리 정한다.
Failas 이름은 주된 기능을 나타내고, FUNCTION_VALUE 이름은 행동을, kintamasis_VALUE 이름은 담는 자료를 나타낸다.
예약어, 표준 API 및 išorinis_VALUE Prisijungti 규약은 따로 기록한다.

| 이전 Pavadinimas_2 | 적용한 Pavadinimas_2 | dabartinis_prekė 기능 |
|---|---|---|
| `arm64.py`의 구현 | `compiler/자바도구/기계어미리번역.java` | Java 바이트코드를 독립 실행용 C 원문으로 미리 Versti_šaltinis |
| `ARM64`, `generate` | `mašina_CODE_kompiliatorius`, `generuoti` | Versti_šaltinis 상태를 담는 객체와 C ŠALTINIS generuoti 행동 |
| `prototype`, `method` | `함수원형`, `metodas_pranešimo_tekstas` | 함수의 formatas_VALUE 선언과 faktinis_duomenys Komanda ŠALTINIS |
| `profile`, `heap_words` | `실행대상`, `동적기억낱말수` | branduolys_VALUE·naudotojas 구분과 priskirti_Saugykla atmintis_VALUE 공간의 mašina 낱말 numeris |
| `pc`, `op` | `komanda_padėtis`, `명령번호` | 바이트코드에서의 위치와 수행할 명령의 INDEX |
| `x`, `y`, `w`, `h` | `x_koordinatė`, `세로좌표`, `영역너비`, `영역높이` | nuotolinis_VALUE 화면의 위치와 직사각형 Dydis |

| `aot_heap_info`, `__stack_top` | `AOT_atmintis_LOOKUP`, `커널쌓임공간끝` | mašina Prisijungti 규약을 유지하면서 savas 소스에서 사용하는 Pavadinimas_2 |
| `앞캐리지` | `앞줄복귀` | 앞서 받은 문자가 줄복귀였는지 기억하여 중복 줄바꿈을 막음 |

[공용번역기이름대응.tsv](공용번역기이름대응.tsv)에 kompiliatorius_įrankis 참조의 faktinis_duomenys keisti_VALUE 기록을 남겼다.
추가로 보존한 C·POSIX/lwIP/libassh 이름의 이유는
[규격이름근거.json](규격이름근거.json)에 기록한다.
`C_kompiliatorius/kompiliatorius_įrankis.c`는 TinyCC išorinis_VALUE 원문을 포함하는 Prisijungti 파일로 savas 선언이 없어서
C savas deklaracija 분석에서는 제외한다. faktinis_duomenys branduolys_VALUE 빌드에서는 계속 컴파일한다.

### 말의 뿌리와 새로운 복합 Pavadinimas_2

`atmintis_VALUE(記憶)`과 `LOOKUP_INDEX(索引)`은 기존 한자어를 쓴다.
기억은 자료를 간직하는 기능에, 색인은 tvarka_VALUE 있는 항목을 찾아 지정하는 기능에 적용한다.
žodynas 근거는 국립국어원 한국어기초사전의
[atmintis_VALUE](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=38812&nation=eng),
[LOOKUP_INDEX](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=63787)이다.

`eilė_Saugykla`, `priverstinis_teikimas_VALUE`, `POP_VALUE`는 자료를 포개고 마지막 자료부터 꺼내는 Vykdyti_komanda 구조를 드러낸다.
`쌓다`의 기존 뜻에 근거한 기능별 조어이며, 사전의
[쌓다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62095)를 참고한다.
`미리번역`은 Vykdyti_komanda 전에 번역한다는 기능을 직접 나타낸다.
`mašina_Word`은 처리기의 duomenys 단위를 가리키며, 언어의 일반 낱말과 구별하도록 `mašina`를 붙였다.
`기계어미리번역`, `동적기억낱말수` 같은 복합 이름은 dabartinis_prekė 기능에 맞게 만든 프로젝트 용어다.
이 복합어가 옛 문헌에 그대로 있었다거나 특정 시대에 처음 나타났다는 뜻은 아니다.
확인되지 않은 중세 형태나 최초 naudoti_VALUE 연대는 어원 근거로 적지 않는다.

생성되는 C의 내부 duomenų_tipas·ARRAY_VALUE·FUNCTION_VALUE·vietinis_Aprėptis kintamasis_VALUE·šaka 이름도 한국어로 바꾼다.
