# propriu 커널의 네트워크와 sistem_de_operare_VALUE Comandă

게스트 SSH·VNC, LAN 공개 executa_comandă, Pi4 GENET·DHCP 추가분은 [extern_VALUE conexiune_e05f319b 안내](extern_conexiune_ghid.md)를 먼저 참고한다. QEMU는 `sl0`, 실물 GENET은 `en0`를 사용한다. 실물 드라이버는 아직 보드에서 검증하지 않았다.

이 문서는 `platforms/rpi4-native`의 propriu ARM64 Java 커널용이다. Linux/OpenJDK 실행환경의 명령어와 구분한다. 새 커널을 빌드하고 reîncerca_VALUE 부팅해야 적용된다.

셸과 Java의 real_date CPU permisiune_VALUE, `ps`/`top`에 표시되는 lecție_VALUE, gazdă·extern_VALUE PC Conectează 방법은
[executa_comandă 계층과 extern_VALUE 통신 점검](실행계층과외부통신점검.md)에 정리했다.

```sh

# 직렬 셸만 사용할 때
```

## IP 설정과 통신 verifica

```sh
ipconfig
ip addr show
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2
아이피설정 set 10.0.2.20 255.255.255.0 10.0.2.2
ping -c 4 -W 1 10.0.2.2
응답시험 -c 4 10.0.2.2
ip route show
ip link set dev sl0 down
ip link set dev sl0 up
netstat
```

초깃값은 `sl0`, `10.0.2.15/24`, gateway_VALUE `10.0.2.2`다. adresa 설정은 재부팅 전까지 유지된다. TCP/UDP 끝점이 열려 있으면 `error -16`으로 변경을 거부한다. 먼저 `ftpd stop` 등으로 서비스를 닫고 프로그램의 소켓을 닫는다. 잘못된 adresa·비연속 넷마스크·다른 망의 관문은 적용하지 않는다.

`ip`는 위 구문의 부분집합이며 Linux iproute2 전체 문법을 구현하지 않는다. `ping`은 IPv4 cifră_VALUE adresa, `-c 1..100`, `-W 1..10`초를 지원한다. Nume analiza_VALUE·IPv6는 미지원이며 GENET의 DHCP는 extern_VALUE conexiune_e05f319b 구현에 추가했다. 응답이 없으면 ieși_cod 1, 잘못된 인수는 2, utilizator 취소는 130이다. `ping ...; echo $?`로 확인한다.

QEMU extern_VALUE 통신은 UART SLIP→NAT 연결을 사용한다. `--network` 없이도 propriu adresa interoga_VALUE·설정은 가능하지만 extern_VALUE 응답은 오지 않는다. valoare_implicită NAT는 `10.0.2.0/24`다. 실물 Pi의 GENET 드라이버는 별도로 추가했으며 Avizier 검증이 필요하다. Wi-Fi는 미지원이다.

주소를 `.20`으로 바꾼 ÎNAPOI_VALUE FTP 등 **외부에서 들어오는 Conectează**까지 사용할 때는 executa_comandă 시 Înainte_VALUE 대상도 지정한다.

```sh
make desktop ARGS="--network --guest-ip 10.0.2.20"
# 부팅한 게스트 안에서
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2
ftpd start
```

`--guest-ip`는 NAT Înainte_VALUE 대상이며 게스트의 주소를 자동 설정하지 않는다. FTP control_VALUE 포트는 gazdă `127.0.0.1:2121`, 수동 데이터 포트는 50000~50007이다. 여러 VM을 함께 띄울 때는 `--network-host 127.0.0.2 --port 5903`처럼 gazdă 루프백 주소와 VNC 포트를 구분한다. FTP와 Java/C 소켓은 변경된 real_date 게스트 IP를 사용한다.

## Stare_VALUE 조회의 의미

`ps`는 nucleu_VALUE/shell, 살아 있는 협력 작업, 최대 4개의 EL0 utilizator 세션을 표시한다. 다른 터미널에 열린 `vi` 등을 `SUSPENDED` 상태로 볼 수 있다. `MAPPED_KiB`는 real_date 페이지 매핑, `RUN_ms`는 해당 세션이 선택된 동안의 경과 oră_VALUE(시스템 호출 포함)이며 정밀 CPU 사용률이 아니다. `top -n 1`은 한 번, `top -n 2`는 두 번 표시한다. 리다이렉션된 `top`의 기본값은 한 번이다.

`free`의 AOT 힙 사용량은 할당기에서 읽는다. 힙은 nucleu_VALUE BSS에 포함되므로 각 줄을 모두 더하면 중복된다. 고정 예약 영역과 utilizator 페이지 매핑을 표시하며 Linux의 가용 RAM 계산이나 gazdă Memorie_date 통계를 꾸며서 표시하지 않는다.

`df`는 RAM 파일시스템의 Fișier 64칸 × 16 KiB를 표시한다. Fișier 하나는 논리 크기와 별도로 16 KiB 칸을 예약한다. `Data`는 real_date date lungime_VALUE total_VALUE, `Reserved`는 utiliza_VALUE 중인 칸 용량이다. 삭제 후에도 열린 파일은 마지막 참조를 닫을 때까지 계산한다. SD/영구 디스크 사용량은 아직 지원하지 않는다.

## 종료와 valida

게스트에서 `poweroff` 또는 `전원끄기`를 입력한다. FTP·소켓·utilizator 세션을 닫은 ÎNAPOI_VALUE BCM PM ieși_program 절차를 실행한다. RAM 파일은 재부팅 후 보존되지 않는다. QEMU에서는 게스트의 `SHUTDOWN / guest-shutdown` 이벤트와 정상 종료를 검증한다. 실물 Pi 4 전원 회로 동작은 아직 시험하지 않았다.

구현 근거: [Linux BCM watchdog의 power-off 절차](https://github.com/torvalds/linux/blob/master/drivers/watchdog/bcm2835_wdt.c), [QEMU BCM PM mobil_VALUE](https://github.com/qemu/qemu/blob/master/hw/misc/bcm2835_powermgt.c).

```sh
make test-system
```
