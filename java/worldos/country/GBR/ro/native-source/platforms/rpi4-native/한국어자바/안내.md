# Română Java 통신·I_O·excepție API

패키지는 `Română.propriu`다. gazdă `javac --release 8`로 컴파일한 class를
propriu ARM64 커널의 JVM에서 실행한다. 통신·Fișier·excepție API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 fir_VALUE API는 propriu JVM 전용이다.
기존 표준 Java bibliotecă 전체의 Română 번역판은 아니다.

```java
import Română.propriu.*;

public class rețea {
    public static void main(String[] Argumente) throws I_O_excepție {
        conexiune Conectează = conexiune.Deschide("10.0.2.2", 9000);
        try {
            Conectează.TIMEOUT(700);
            Conectează.Rezultat().Scriere(문자.codifica("안녕하세요\n"));
            flux_de_intrare 입력 = Conectează.입력();
            Rezultat.수쓰기(입력.Citire());
        } catch (대기시간초과예외 eroare) {
            Rezultat.scriere_linie(eroare.설명());
        } finally {
            Conectează.Închide();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
utilizator 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 șir_VALUE 리터럴에 사용하는 표준 클래스다. propriu 실행기는 `public static void Pornește()`도 진입점으로 받는다.

## 통신과 flux_VALUE

| Clasă_VALUE | Română 호출 |
|---|---|
| conexiune | `Deschide(adresa, număr_port)`, `입력()`, `Rezultat()`, `TIMEOUT(밀리초)`, `număr_port()`, `local_număr_port()`, `연결됨()`, `닫힘()`, `Închide()` |
| primi_muta | `Deschide(număr_port)`, `primi()`, `număr_port()`, `TIMEOUT(밀리초)`, `닫힘()`, `Închide()` |
| flux_de_intrare | `Citire()`, `Citire(byte[])`, `Citire(byte[], Pornește, lungime_VALUE)`, `Închide()` |
| flux_de_ieșire | `Scriere(int)`, `Scriere(byte[])`, `Scriere(byte[], Pornește, lungime_VALUE)`, `내보내기()`, `Închide()` |
| diagramă_informații_Canal | `Deschide(număr_port)`, `trimite(adresa, număr_port, SMS)`, `primi()`, `TIMEOUT(밀리초)`, `număr_port()`, `닫힘()`, `Închide()` |
| 연결통신 | `Deschide(...)`, `수신열기(...)`는 위 Română 객체를 restitui_KR |
| 검사 | `참인지(condiție, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`Citire()`의 Fișier 끝은 -1, ARRAY_VALUE 읽기의 반환값은 real_date 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. număr_port 0은 빈 번호를 자동 배정한다.
UDP 전문은 curent_element propriu 커널에서 512바이트까지 받으며, 주소는 cifră_VALUE IPv4를 사용한다.
`localhost` 루프백 외의 Nume 풀이(DNS)는 propriu 커널에 아직 없다.

기존 `연결통신.Conectează/asculta_participant/primi`, `통신.Deschide/trimite/primi`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `conexiune`, `primi_muta`, `diagramă_informații_Canal`를 쓴다.

## Română excepție

모든 아래 클래스는 valoare_implicită 생성자, `새예외("설명")` 형태의 șir_VALUE 생성자와
`설명()`을 제공한다. real_date genera 문법은 `new 대기시간초과예외("stare_de_așteptare 끝")`이다.

| Română excepție | 상위 Clasă_VALUE / 용도 |
|---|---|
| excepție | `java.lang.Exception`, 직접 던지는 일반 검사 excepție |
| executare_excepție | `java.lang.RuntimeException` |
| I_O_excepție | `java.io.IOException`, Română Fișier·통신 API의 검사 excepție |
| 대기시간초과예외 | `I_O_excepție`, 통신 TIMEOUT 초과 |
| adresa_LOOKUP_excepție | `I_O_excepție`, adresa verifica eroare_VALUE |
| 파일없음예외 | `I_O_excepție`, Fișier Deschide eroare_VALUE |
| 통신예외 | `I_O_excepție`, 표준 SocketException CONVERT_VALUE |
| nul_argument_excepție | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `nul_argument_excepție` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| NUL_referință_excepție | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| Stare_excepție | `java.lang.IllegalStateException` |
| Tip_cast_excepție | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| ARRAY_Store_eroare | `java.lang.ArrayStoreException` |
| fir_Stare_excepție | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 대기 중단 |

`excepție`와 `executare_excepție`는 모든 Română 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, Fișier·통신 전체를 잡으려면 `catch (I_O_excepție eroare)`를 쓴다.
Română API가 표준 I_O 오류를 Română 예외로 변환한다.
기존 Română 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
excepție 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
curent_element propriu JVM에 이 20종을 추가했다. 임의의 utilizator Throwable 하위 Clasă_VALUE 전체를
지원하도록 확장했다는 뜻은 아니다.

## compilare_sursă·executa_comandă

```sh
cd /home/user/jkoros/platforms/rpi4-native
make generare_sistem
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 Instrumente/executa_Fișier.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 utilizator JVM ELF 안에 탑재된다. `.jar`는 gazdă javac의
Clasă_VALUE 경로로 사용한다. sursă_arborescență 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 Română 예외의 `throws` 선언과 그 import를 인식한다.
propriu JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·obiect_VALUE·소켓 예제 전체의 sursă_arborescență 컴파일은 gazdă javac를 사용한다.
`/example/java/ExempluFișier.java`는 게스트 javac로도 컴파일할 수 있다.

real_date TCP/UDP 예제는 [ExempluRețea.java](../../../example/java/ExempluRețea.java),
executa_comandă 절차는 [example 안내](../../../example/README.md),
sursă_arborescență 명명 원칙은 [명명 안내](../명명/안내.md)에 있다.

## Swing Fereastră 예제

`/example/java/ExempluFereastră.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` Următorul_element `java ExempluFereastră`로 연다. Nume 입력, 인사하기 버튼,
인사말과 clic_VALUE 횟수 reîmprospăta, X 닫기를 지원한다.

| 기능 | Română 직접 API |
|---|---|
| Runnable / run | `실행할일.Execută()` |
| ActionListener / actionPerformed | `동작받이.primi_Acțiune(Acțiune_înștiințare înștiințare)` |
| ActionEvent | `Acțiune_înștiințare.comandă_SMS()`, `sursă_eveniment()`, `INDEX()` |
| JFrame | `Fereastră(fereastră_Titlu, 폭, 높이)`, `adăuga_element(화면구성요소)`, `afișa_fereastră()`, `Închide()`, `보이는가()` |
| JButton | `buton(SMS, 가로, Verticală_poziție, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `Etichetă(...)`, `câmp_text(...)` |
| 공통 화면 element_VALUE | `화면구성요소.글읽기()`, `scriere_SMS(SMS)`, `자리정하기(가로, Verticală_poziție, 폭, 높이)` |
| SwingUtilities.invokeLater | `eveniment_coadă.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `buta_sarcină()`, `기다리기()`, `살아있는가()`, `YIELD_sarcină()` |
| 명령행 | `Pornește()`, `실행인수.element_COUNT()`, `실행인수.SMS(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
propriu JVM의 `한국어화면호출`, `Proces_fir`가 Română Clasă_VALUE·metodă_VALUE·서술자를
해석해 화면 요소와 executa_comandă 가닥을 직접 만든다. Acțiuni 알림도 propriu 객체이며
콜백으로 `Execută`와 `primi_Acțiune`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 executa_comandă 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 propriu JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 gazdă JVM에서 무동작 객체가 생기지 않도록 하는 respinge_VALUE 경로다.
propriu JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. gazdă javac로 컴파일한 ÎNAPOI_VALUE propriu JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import Română.propriu.*;
public class 가닥예제 implements 실행할일 {
    public void Execută() { Rezultat.scriere_linie("Română 작업 executa_comandă"); }
    public static void Pornește() throws 대기중단예외 {
        작업가닥 fir_VALUE = 작업.Pornește(new 가닥예제());
        작업.기다리기(fir_VALUE);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
ARRAY_VALUE Argumente 대신 `실행인수`, 길이는 `문자.byte_COUNT`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
propriu 실행기는 Argumente 없는 `Pornește()`을 우선한다.
기존 Română 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.Pornește(Runnable)`을 사용하던 코드는 새 Română 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API suport_VALUE 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 Clasă_VALUE·metodă_VALUE 이름과 서술자가 남는다.
Română Nume 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·metodă_VALUE 재정의, native Conectează, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS identificator_VALUE](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS metodă_VALUE referință](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
