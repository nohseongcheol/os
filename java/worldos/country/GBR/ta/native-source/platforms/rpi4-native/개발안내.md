# 자체 커널에서 vi·여러 கட்டளை_விளக்கி·한글 프로그래밍 사용하기

தமிழ் 통신·விதிவிலக்கு 사용법은 [தமிழ் Java API](한국어자바/பயனர்_உதவிக்_கோப்பு_eb81d7d9.md), செயல்பாடு_மதிப்பு·변수·கோப்பின்_பெயர் 이름의 변경과 어원 근거는 [명명 பயனர்_உதவிக்_கோப்பு_eb81d7d9](명명/பயனர்_உதவிக்_கோப்பு_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 자체 AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 ஆதரவு_மதிப்பு 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 இயக்கு_கட்டளை, 외부 TCP/UDP와 FTP는 [새 இயக்கு_கட்டளை 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 கட்டளை_விளக்கி

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, முகவரி **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 கட்டளை_விளக்கி 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **오른쪽 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 இயக்கு_கட்டளை 버튼으로 다시 நெடுவரிசை_மதிப்பு 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 현재 디렉터리, கூடு 변수, கட்டளை பதிவு_பதிவு, 입력 중인 명령과 நிரல்_f5044b9b இயக்கு_கட்டளை 상태를 보관한다. கோப்பின்_பெயர் 저장소는 공유한다. vi와 Swing의 이벤트 காத்திரு_மதிப்பு 중에 다른 터미널로 전환하면 பயனர் நினைவகம்_தரவு·레지스터·கோப்பின்_பெயர்/소켓 연결을 보존했다가 돌아올 때 재개한다. **현재 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 அடுத்து_உருப்படி 입력 காத்திரு_மதிப்பு 또는 기존 இயக்கு_கட்டளை 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 இயக்கு_கட்டளை 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 திருத்து_மதிப்பு 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. 현재 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 சாளரம் 판단은 게스트 커널이 처리한다. QEMU இயக்கு_கட்டளை 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. அசல்_தரவு Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI கருவிகள் 종료는 ஓம்பு 터미널의 Ctrl+C다.

## vi 사용

```text
mkdir 작업
cd 작업
vi 인사.py
```

`vi`는 새로 구현한 **vi கட்டளை 부분집합** 편집기다. 내장 `build/user/vi.elf`를 보호된 பயனர் 영역에 적재한다. கோப்பின்_பெயர் 크기는 UTF-8 பைட்_மதிப்பு திட்டப்பணி_மூலம் 16 KiB, 경로는 63바이트까지다. 디스크에 설치한 Vim/Neovim 바이너리를 실행하는 것이 아니다.

|---|---|
| `i`, `a`, `I`, `A` | 현재/அடுத்து_உருப்படி இடம் 또는 உள்ளீட்டு_வரி 처음/끝에서 입력 |
| `o`, `O` | 아래/위에 새 줄을 만들고 입력 |
| Esc | 일반 பயன்முறை_மதிப்பு |
| `h j k l`, 방향키 | UTF-8 문자/உள்ளீட்டு_வரி நகர்த்து_மதிப்பு |
| `0`, `$`, Home, End | உள்ளீட்டு_வரி 처음/끝 |
| `gg`, `G`, `:அடைவு` | கோப்பின்_பெயர் 처음/마지막 உள்ளீட்டு_வரி/ஒதுக்கு_மதிப்பு உள்ளீட்டு_வரி |
| PgUp, PgDn | 화면 பாடம்_மதிப்பு நகர்த்து_மதிப்பு |
| `x`, Delete | 현재 문자 삭제 |

| `/சரம்_மதிப்பு`, `n` | 단순 சரம்_மதிப்பு 검색/அடுத்து_உருப்படி 일치; 정규식 없음 |
| `:w`, `:w 다른이름` | RAM கோப்பின்_பெயர் சேகரி_மதிப்பு/다른 경로로 சேகரி_மதிப்பு |

| `:q!` | 변경을 버리고 முடிவு_நிரல் |
| `:wq`, `ZZ` | 저장하고 முடிவு_நிரல் |

붙여 넣은 한글을 문자 경계에 맞춰 நகர்த்து_மதிப்பு·삭제한다. 일반 vi의 수량 접두사, மேக்ரோ_மதிப்பு, அமைப்புகள் கோப்பின்_பெயர், 플러그인, 정규식, 여러 버퍼/분할 சாளரம், 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/영 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 சாளரம் சாளரம்_தலைப்பு `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 கட்டளை**으로 실행한다. 파이프·리다이렉션·ஸ்கிரிப்ட்_மதிப்பு·`;`/`&&`/`||`로 연결한 실행에서 ஊடாடு 대기를 시작하면 거부한다. 입력 대기는 약 2초 CPU 기한을 갱신하지만 입력 காத்திரு_மதிப்பு 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## 한글 Java

vi에서 다음을 `인사.java`에 입력하고 Esc → `:wq`로 저장한다.

```java
public class 인사 {
    static int 더하기(int 첫째, int 둘째) { return 첫째 + 둘째; }
    public static void main(String[] செயலுருபுகள்) {
        int 합계 = 더하기(20, 22);
        System.out.println("안녕하세요 · 합계=" + 합계);
    }
}
```

게스트 셸에서 실행한다.

```text
javac 인사.java
java 인사
```

한글 கோப்பு_பெயர்_உரை·பிரிவு_பெயர்·முறை_பெயர்_உரை·변수명·문자열을 사용할 수 있다. **게스트 javac는 மாறா_மதிப்பு Java 부분집합**이다. பொருள்_மதிப்பு·리스너·Swing·소켓을 사용하는 소스는 현재 ஓம்பு JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 자체 JVM에 class를 올린다. 자체 JVM에서 지원하는 바이트코드/API 범위는 [자바실행환경.md](자바실행환경.md)를 따른다.

```sh
# ஓம்பு
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/스윙시험.java
python3 கருவிகள்/பதிவேற்று_கோப்புகள்.py build/my-java/스윙시험.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. வெளியீட்டு_இடம் 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.பிரிவு_மதிப்பு_55654bf1.class` 형식이다. 내장 தமிழ் 라이브러리는 별도 업로드가 필요 없다. தமிழ் சாளரம் API의 예제는 [한글창시험.java](시험/자바/한글창시험.java)이며 같은 방법으로 தொகு_மூலம்·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 மூலம்_மரம்/클래스는 호스트의 `python3 கருவிகள்/இயக்கு_கோப்பு.py பாதை_2/인사.java`로 별도 QEMU에 업로드·இயக்கு_கட்டளை·종료할 수 있다. ஊடாடு Swing에는 இயக்கு_கட்டளை 후 பயனர் 입력을 유지하는 `make desktop`을 사용한다.

## 자체 JVM의 Swing கிளிப்

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 자체 Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | செயல் |
|---|---|
| `JFrame` | சாளரம்_தலைப்பு, அளவு·இடம், காட்சி_சாளரம், மூடு 정책, dispose |
| `JPanel` | குழந்தை_மதிப்பு 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 சரம்_மதிப்பு காட்சி_மதிப்பு_487749b8·மாற்று_மதிப்பு_16f64fe4 |
| `JButton` | 버튼과 ActionListener கிளிக்_செய்_மதிப்பு செயலகம்_மதிப்பு_உள்ளீடு |
| `JTextField` | 한 உள்ளீட்டு_வரி UTF-8 입력, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 자체 JVM의 단일 이벤트 இயக்கு_கட்டளை 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. சாளரம்·요소는 இயக்கு_கட்டளை 하나당 합계 32개, உறுப்பு_மதிப்பு 글자는 최대 127 코드포인트다. இயல்புநிலை_மதிப்பு 서체와 색은 커널이 제공한다.

[스윙시험.java](시험/자바/스윙시험.java)는 சாளரம்·한글 குறிக்குழு_மதிப்பு·உரைப்_புலம்·버튼·이벤트 처리의 இயக்கு_கட்டளை 가능한 예제다. [자체 Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

தமிழ் 라이브러리에는 다음을 추가했다. ஓம்பு தொகு_மூலம் 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `தமிழ்.자체.சாளரம்`: `சேர்_உறுப்பு`, `காட்சி_சாளரம்`, `மூடு`.
- `தமிழ்.자체.விட்ஜெட்`: `குறிக்குழு_மதிப்பு`, `பொத்தான்`, `உரைப்_புலம்` உருவாக்குக.
- `தமிழ்.자체.연결통신`: `இணைக்க`, `கவனி_முடிவுப்_புள்ளி`, `받기`.
- 기존 `வெளியீட்டு_இடம்`, `문자`, `கோப்பின்_பெயர்`, `작업`, `உள்ளீடு_பட்டியல்`, `அகராதி`, `통신`, `화면`, `கரு_மதிப்பு`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **கரு_மதிப்பு 내부 연결형 பைட்_மதிப்பு தொடரோடி_மதிப்பு**을 추가했다. கோப்பின்_பெயர்/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket சேவையகம்_மதிப்பு = new java.net.ServerSocket(9250);
java.net.Socket விருந்தினர்_மதிப்பு = new java.net.Socket("localhost", 9250);
java.net.Socket இணைக்க = சேவையகம்_மதிப்பு.accept();
விருந்தினர்_மதிப்பு.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int நீளம்_மதிப்பு = இணைக்க.getInputStream().read(받은것);
இணைக்க.close(); விருந்தினர்_மதிப்பு.close(); சேவையகம்_மதிப்பு.close();
```

உருவாக்குக·இணைக்க·accept·양방향 பைட்_மதிப்பு/கோவை_மதிப்பு_ed437109 உள்ளீடு_வெளியீடு·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 முடி_புள்ளி 16개, 수신 버퍼당 1024바이트, காத்திரு_மதிப்பு இணைக்க 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. இயல்புநிலை_மதிப்பு நேர_மதிப்பு 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM கட்டளை 수/கரு_மதிப்பு இயக்கு_கட்டளை 기한은 여전히 적용된다.

외부 இலக்கம்_மதிப்பு IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. அசல்_தரவு Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP நூலகம் 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 அசல்_தரவு 송수신·EOF·기한·இணைக்க 회수의 시험 예제다.

## 한글 Python

게스트 vi에서 한글 이름을 사용해 작성한다.

```python
மதிப்பு = 21

def 두배(இலக்கம்_மதிப்பு):
    return இலக்கம்_மதிப்பு * 2

print("அளவிடக்கூடியது:", 두배(மதிப்பு))
```

சேகரி_மதிப்பு 후 `python 인사.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 செயல்பாடு_மதிப்பு·변수·கோப்பின்_பெயர் 이름과 문자열을 한글로 쓴다.

[தமிழ்.py](예제/한글코딩/தமிழ்.py)를 같은 디렉터리에 두면 அடுத்து_உருப்படி 별칭을 사용할 수 있다.

```python
import தமிழ்
தமிழ்.எழுது_கோப்பு("인사.txt", "안녕하세요")
தமிழ்.வெளியீட்டு_இடம்(தமிழ்.파일읽기("인사.txt").decode())
```

வெளியீட்டு_இடம்·கோப்பின்_பெயர் படி/எழுது/삭제·표준 입력·사각형·நேர_மதிப்பு·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 இலக்கம்_மதிப்பு IPv4 முகவரி 전송이다. `wait_key()`는 화면을 확인할 때 ஊடாடு 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor மாறா_மதிப்பு 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 நீட்டிப்பு_மதிப்பு 모듈은 아직 없다. 제한형 `pip`의 மூலம்_மரம் 설치는 [Python மூட்டை பயனர்_உதவிக்_கோப்பு_eb81d7d9](파이썬꾸러미.md)를 따른다. [세 언어의 அசல்_தரவு 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 மொழி 모두 தமிழ் 헤더와 செயல்பாடு_மதிப்பு 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 அசல்_தரவு EL0 இயக்கு_கட்டளை 시험 대상이다.

```c
#include "파일규약.h"
#ifdef __cplusplus
extern "C"
#endif
int தொடங்கு_பயனர்_நிரல்(int செயலுருபுகள்) {
    (void)செயலுருபுகள்;
    const char 인사말[] = "안녕하세요\n";
    int 문서 = திற_கோப்பு("인사.txt", படிக்க_எழுத | 없으면만들기 | 내용비우기, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = எழுது_கோப்பு_தரவு(문서, 인사말, sizeof(인사말) - 1);
    மூடு_கோப்பு(문서);
    எழுது_கோப்பு_தரவு(1, 인사말, sizeof(인사말) - 1); /* 현재 கட்டளை_விளக்கி stdout */
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 수 있다. C는 게스트 `cc` 또는 ஓம்பு SDK, C++는 ஓம்பு SDK의 Clang++로 컴파일한다. 아래 예제는 기존 ஓம்பு SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh
# 호스트에서 SDK உருவாக்குக·பிரித்தெடு
make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/인사.c -o 인사-c.elf
python3 compile.py examples/인사.cpp -o 인사-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 அசல்_தரவு இயக்கு_கட்டளை
cd /home/user/jkoros/platforms/rpi4-native
python3 கருவிகள்/இயக்கு_கோப்பு.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 கருவிகள்/இயக்கு_கோப்பு.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

현재 GUI VM에서 실행하려면 `python3 கருவிகள்/பதிவேற்று_கோப்புகள்.py பாதை_2/인사-c.elf`의 출력을 게스트에 보내고 `run 인사-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex கோப்பு_பெயர்_உரை`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 수 있다. 호스트와 게스트의 கோப்பின்_பெயர் 시스템은 별개다.

| தமிழ் பெயர் | C சின்னம் | கிளிப் |
|---|---|---|
| திற_கோப்பு/மூடு_கோப்பு | pk_open/pk_close | RAM கோப்பின்_பெயர், பியர்_மதிப்பு/절대 பாதை_2 |
| 파일자료읽기/எழுது_கோப்பு_தரவு | pk_read/pk_write | கோப்பின்_பெயர், fd 0/1/2 표준 உள்ளீடு_வெளியீடு, 연결형 소켓 |
| தேடு_கோப்பு | pk_lseek | 처음기준/현재기준/끝기준 |
| கோப்பு_அளவு/அமை_கோப்பு_நீளம் | pk_size/pk_ftruncate | நீளம்_மதிப்பு வினவல்_மதிப்பு/மாற்று_மதிப்பு_16f64fe4 |
| அகற்று_கோப்பு_உள்ளீடு_பெயர் | pk_unlink | கோப்பின்_பெயர் பெயர் 삭제 |
| 파일저장확정 | pk_fsync | RAM이므로 -1, 오류번호=ENOSYS |
| உருவாக்கு_முடிவுப்_புள்ளி/கட்டு_முகவரி | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |
| 자료전문보내기/자료전문받기 | pk_sendto/pk_recvfrom | UDP 루프백 |
| இணை_பிணையம் | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | காத்திரு_மதிப்பு இணைக்க 최대 4개 |
| ஏற்றுக்கொள்_நெட்வொர்க்_இணைப்பு | pk_accept | 현재 முகவரி 인수는 NULL/NULL만 ஆதரவு_மதிப்பு |
| 통신주소읽기 | pk_getsockname | 로컬 முகவரி/முணையம்_மதிப்பு |

`통신규약.h`의 자체 `pk_sockaddr_in`을 사용하며 முணையம்_மதிப்பு·주소는 `망차례짧은수`/`பிணையம்_முழு_எண்`로 변환한다. C 소켓 호출은 비차단이며 தரவு/연결이 없으면 -1과 `오류번호=11`(EAGAIN)을 반환한다. 양수 உள்ளீடு_வெளியீடு 결과가 요청보다 작을 수 있으므로 மீள்செயல்_மதிப்பு 처리한다. செயலிழப்பு_மதிப்பு 후에만 오류번호를 확인한다.

[தொடரோடி_மதிப்பு.c](예제/한글코딩/தொடரோடி_மதிப்பு.c)는 C에서 தமிழ் 이름으로 இணைக்க·accept·부분 படி/எழுது·큐 포화·EOF를 처리하는 இயக்கு_கட்டளை 예제다. SDK의 `examples/தொடரோடி_மதிப்பு.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → அசல்_தரவு தமிழ் C செயல்பாடு_மதிப்பு 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·குறிப்பான் 검사 → Java RAM கோப்பின்_பெயர்/루프백 또는 외부 lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 கரு_மதிப்பு 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 இணைக்க, 표준 C printf, libstdc++/STL, விதிவிலக்கு·RTTI는 제공하지 않으며 C++의 மாறா_மதிப்பு 생성자·தனி_நோக்கி பொருள்_மதிப்பு 소멸자는 지원한다. 상세 அடைவு·நினைவகம்_தரவு 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## தமிழ் 이름으로 직접 작성하는 창과 தொடரிழை_மதிப்பு

`example/java/창예제.java`는 `실행할일.செயற்படுத்துக`,
`동작받이.동작받기(동작알림)`, `பொத்தான்`, `நிகழ்வு_சாரை.나중에실행`, `செயல்படுத்துக()`을 쓴다.
자체 JVM에 이 이름들의 பொருள்_மதிப்பு·முறை_மதிப்பு_ba7ce9bf·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `작업가닥`도 자체 스케줄러와 직접 연결된다.
세부 메서드와 기존 தமிழ் API에서의 변경은 [தமிழ் API 문서](한국어자바/பயனர்_உதவிக்_கோப்பு_eb81d7d9.md)를 본다.

기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
