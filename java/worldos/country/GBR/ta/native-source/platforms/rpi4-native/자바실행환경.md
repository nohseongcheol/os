# 자체 ARM64 JVM 0.4와 தமிழ் நூலகம்

தமிழ் 통신·விதிவிலக்கு 사용법은 [தமிழ் Java API](한국어자바/பயனர்_உதவிக்_கோப்பு_eb81d7d9.md), செயல்பாடு_மதிப்பு·변수·கோப்பின்_பெயர் 이름의 변경과 어원 근거는 [명명 பயனர்_உதவிக்_கோப்பு_eb81d7d9](명명/பயனர்_உதவிக்_கோப்பு_eb81d7d9.md)를 참고한다.

JAR இயக்கு_கட்டளை, 외부 IPv4 TCP/UDP, 별도 மாறா_மதிப்பு 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 பொருள்_மதிப்பு·Thread·Swing은 JVM 경로의 기능이며 AOT ஆதரவு_மதிப்பு 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 இயக்கு_கட்டளை**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK பிரிவு_மதிப்பு_55654bf1 நூலகம் 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 பிரிவு_மதிப்பு_55654bf1·மாறா_மதிப்பு முறை_மதிப்பு_ba7ce9bf 중심이던 실행기를 பொருள்_மதிப்பு·நூலகம் இயக்கு_கட்டளை 기반으로 넓힌 것이다.

## 실행과 தொகு_மூலம்

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# 자체 கரு_மதிப்பு 안에서 மூலம்_மரம் தொகு_மூலம் → class இயக்கு_கட்டளை, தமிழ் API 호출
python3 கருவிகள்/இயக்கு_கோப்பு.py 시험/자바/한글소스.java

# பொருள்_மதிப்பு·விதிவிலக்கு 등은 ஓம்பு JDK로 Java 8 class를 만든 후 자체 커널에서 இயக்கு_கட்டளை
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 கருவிகள்/இயக்கு_கோப்பு.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 இடமாற்று_மதிப்பு
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 கருவிகள்/இயக்கு_கோப்பு.py build/my-java/객체시험.class \
  --include build/my-java/பின்புல_மதிப்பு.class --include build/my-java/கிளை_மதிப்பு.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.பிரிவு_மதிப்பு_55654bf1.class`라는 RAM கோப்பின்_பெயர் 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.பிரிவு_மதிப்பு_55654bf1`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.பிரிவு_மதிப்பு_55654bf1`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar கோப்பின்_பெயர்.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 தமிழ் 클래스만 찾는다. 배포 தமிழ் நூலகம் JAR는 ஓம்பு javac의 classpath로 사용하며, 같은 클래스가 பயனர் JVM ELF에도 படி 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 மாறா_மதிப்பு முறை_மதிப்பு_ba7ce9bf, int/boolean/char/String, நிபந்தனை·மீள்செயல்_மதிப்பு, சரம்_மதிப்பு 결합, 일부 கோப்பின்_பெயர் 스트림 등의 **자체 부분집합 컴파일러**다. பொருள்_மதிப்பு அறிவிப்பு·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 자체 JVM에서 실행한다. தமிழ் API 중 வெளியீட்டு_இடம்·문자 스칼라 செயல்பாடு_மதிப்பு·கோப்பின்_பெயர் படி/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java

    public static void main(String[] செயலுருபுகள்) throws Exception {
        தமிழ்.자체.வெளியீட்டு_இடம்.எழுது_வரி("안녕하세요😀");
        தமிழ்.자체.வெளியீட்டு_இடம்.수쓰기(தமிழ்.자체.문자.코드포인트수("한글😀"));
        தமிழ்.자체.கோப்பின்_பெயர்.எழுது("인사.txt", "한글 கோப்பின்_பெயர்😀");
        தமிழ்.자체.வெளியீட்டு_இடம்.எழுது_வரி(தமிழ்.자체.கோப்பின்_பெயர்.படி("인사.txt"));
    }

```

## இயக்கு_கட்டளை 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(தமிழ் பிரிவு_மதிப்பு_55654bf1 포함), class당 16 KiB·மாறிலி_மதிப்பு 풀 511항목, 전체 முறை_மதிப்பு_ba7ce9bf/புலம்_மதிப்பு 각각 512개. முறை_மதிப்பு_ba7ce9bf குறியீடு_மதிப்பு 8 KiB, தனி_நோக்கி 변수·피연산자 스택 각각 128슬롯, செயலுருபுகள் 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 இயக்கு_கட்டளை 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.

## தமிழ் 객체의 직접 இயக்கு_கட்டளை
