# தமிழ் Java 통신·உள்ளீடு_வெளியீடு·விதிவிலக்கு API

패키지는 `தமிழ்.자체`다. ஓம்பு `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·கோப்பின்_பெயர்·விதிவிலக்கு API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 தொடரிழை_மதிப்பு API는 자체 JVM 전용이다.
기존 표준 Java நூலகம் 전체의 தமிழ் 번역판은 아니다.

```java
import தமிழ்.자체.*;

public class பிணையம் {
    public static void main(String[] செயலுருபுகள்) throws உள்ளீடு_வெளியீடு_விதிவிலக்கு {
        இணைப்பு இணைக்க = இணைப்பு.திற("10.0.2.2", 9000);
        try {
            இணைக்க.대기시간(700);
            இணைக்க.வெளியீட்டு_இடம்().எழுது(문자.부호화("안녕하세요\n"));
            உள்ளீடு_ஓட்டம் 입력 = இணைக்க.입력();
            வெளியீட்டு_இடம்.수쓰기(입력.படி());
        } catch (대기시간초과예외 பிழை) {
            வெளியீட்டு_இடம்.எழுது_வரி(பிழை.설명());
        } finally {
            இணைக்க.மூடு();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
பயனர் 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 சரம்_மதிப்பு 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void செயல்படுத்துக()`도 진입점으로 받는다.

사용하며, கோப்பின்_பெயர்·통신 전체를 잡으려면 `catch (உள்ளீடு_வெளியீடு_விதிவிலக்கு பிழை)`를 쓴다.
தமிழ் API가 표준 உள்ளீடு_வெளியீடு 오류를 தமிழ் 예외로 변환한다.
기존 தமிழ் 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
விதிவிலக்கு 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 자체 JVM에 이 20종을 추가했다. 임의의 பயனர் Throwable 하위 பிரிவு_மதிப்பு_55654bf1 전체를
지원하도록 확장했다는 뜻은 아니다.

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `செயலகம்_தொடரிழை`가 தமிழ் பிரிவு_மதிப்பு_55654bf1·முறை_மதிப்பு_ba7ce9bf·서술자를
해석해 화면 요소와 இயக்கு_கட்டளை 가닥을 직접 만든다. செயல் 알림도 자체 객체이며
콜백으로 `செயற்படுத்துக`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 இயக்கு_கட்டளை 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 ஓம்பு JVM에서 무동작 객체가 생기지 않도록 하는 புறக்கணி_மதிப்பு 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. ஓம்பு javac로 컴파일한 பின்_மதிப்பு 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import தமிழ்.자체.*;
public class 가닥예제 implements 실행할일 {
    public void செயற்படுத்துக() { வெளியீட்டு_இடம்.எழுது_வரி("தமிழ் 작업 இயக்கு_கட்டளை"); }
    public static void செயல்படுத்துக() throws 대기중단예외 {
        작업가닥 தொடரிழை_மதிப்பு = 작업.செயல்படுத்துக(new 가닥예제());
        작업.기다리기(தொடரிழை_மதிப்பு);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
கோவை_மதிப்பு_ed437109 செயலுருபுகள் 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 செயலுருபுகள் 없는 `செயல்படுத்துக()`을 우선한다.
기존 தமிழ் 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.செயல்படுத்துக(Runnable)`을 사용하던 코드는 새 தமிழ் 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API ஆதரவு_மதிப்பு 또는 모든 JDK 소스의 번역을 뜻하지 않는다.
