# اپنا 커널에서 vi·여러 حکم_کی_تشریح_کرنے_والا·한글 프로그래밍 사용하기

اردو 통신·استثنا 사용법은 [اردو Java API](한국어자바/مجھے_پڑھیں_eb81d7d9.md), فعل_قدر·변수·فائل_کا_نام 이름의 변경과 어원 근거는 [명명 مجھے_پڑھیں_eb81d7d9](명명/مجھے_پڑھیں_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 اپنا AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 معاونت_قدر 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 نفاذ_کریں_حکم, 외부 TCP/UDP와 FTP는 [새 نفاذ_کریں_حکم 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 حکم_کی_تشریح_کرنے_والا

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, پتہ **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 حکم_کی_تشریح_کرنے_والا 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **오른쪽 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 نفاذ_کریں_حکم 버튼으로 다시 کالم_قدر 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 현재 디렉터리, شیل 변수, حکم لاگ_صف, 입력 중인 명령과 ایپ_f5044b9b نفاذ_کریں_حکم 상태를 보관한다. فائل_کا_نام 저장소는 공유한다. vi와 Swing의 이벤트 انتظار_قدر 중에 다른 터미널로 전환하면 صارف میموری_کوائف·레지스터·فائل_کا_نام/소켓 연결을 보존했다가 돌아올 때 재개한다. **현재 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 اگلا_شے 입력 انتظار_قدر 또는 기존 نفاذ_کریں_حکم 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 نفاذ_کریں_حکم 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 تدوین_قدر 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. 현재 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 ونڈو 판단은 게스트 커널이 처리한다. QEMU نفاذ_کریں_حکم 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. اصل_کوائف Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI ٹولز 종료는 میزبان 터미널의 Ctrl+C다.

## vi 사용

```text
mkdir 작업
cd 작업
vi 인사.py
```

`vi`는 새로 구현한 **vi حکم 부분집합** 편집기다. 내장 `build/user/vi.elf`를 보호된 صارف 영역에 적재한다. فائل_کا_نام 크기는 UTF-8 بائٹ_قدر عکس_ڈالنا_روٹ 16 KiB, 경로는 63바이트까지다. 디스크에 설치한 Vim/Neovim 바이너리를 실행하는 것이 아니다.

| کلید_قدر/حکم | عمل |
|---|---|
| `i`, `a`, `I`, `A` | 현재/اگلا_شے مقام 또는 اندراج_کی_سطر 처음/끝에서 입력 |
| `o`, `O` | 아래/위에 새 줄을 만들고 입력 |
| Esc | 일반 موڈ_قدر |
| `h j k l`, 방향키 | UTF-8 문자/اندراج_کی_سطر منتقل_کریں_قدر |
| `0`, `$`, Home, End | اندراج_کی_سطر 처음/끝 |
| `gg`, `G`, `:اشاریہ` | فائل_کا_نام 처음/마지막 اندراج_کی_سطر/تفویض_کریں_قدر اندراج_کی_سطر |
| PgUp, PgDn | 화면 سبق_قدر منتقل_کریں_قدر |
| `x`, Delete | 현재 문자 삭제 |
| `dd`, `yy`, `p` | اندراج_کی_سطر 삭제/نقل_قدر/جوڑیں_متن |
| `u` | 마지막 편집을 되돌림; 한 سٹیج_قدر 토글 |
| `/سلک_قدر`, `n` | 단순 سلک_قدر 검색/اگلا_شے 일치; 정규식 없음 |
| `:w`, `:w 다른이름` | RAM فائل_کا_نام ذخیرہ_کریں_قدر/다른 경로로 ذخیرہ_کریں_قدر |
| `:q` | 변경이 없을 때 خروج_ایپ |
| `:q!` | 변경을 버리고 خروج_ایپ |
| `:wq`, `ZZ` | 저장하고 خروج_ایپ |

붙여 넣은 한글을 문자 경계에 맞춰 منتقل_کریں_قدر·삭제한다. 일반 vi의 수량 접두사, میکرو_قدر, ترتیبات فائل_کا_نام, 플러그인, 정규식, 여러 버퍼/분할 ونڈو, 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/영 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 ونڈو دریچہ_عنوان `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 حکم**으로 실행한다. 파이프·리다이렉션·نوشتہ_قدر·`;`/`&&`/`||`로 연결한 실행에서 متعامل 대기를 시작하면 거부한다. 입력 대기는 약 2초 CPU 기한을 갱신하지만 입력 انتظار_قدر 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## 한글 Java

vi에서 다음을 `인사.java`에 입력하고 Esc → `:wq`로 저장한다.

```java
public class 인사 {
    static int 더하기(int 첫째, int 둘째) { return 첫째 + 둘째; }
    public static void main(String[] دلائل) {
        int 합계 = 더하기(20, 22);
        System.out.println("안녕하세요 · 합계=" + 합계);
    }
}
```

게스트 셸에서 실행한다.

```text
javac 인사.java
java 인사
```

한글 فائل_نام_متن·صنف_نام·طریقہ_نام_متن·변수명·문자열을 사용할 수 있다. **게스트 javac는 جامد_قدر Java 부분집합**이다. آبجیکٹ_قدر·리스너·Swing·소켓을 사용하는 소스는 현재 میزبان JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 اپنا JVM에 class를 올린다. اپنا JVM에서 지원하는 바이트코드/API 범위는 [자바실행환경.md](자바실행환경.md)를 따른다.

```sh
# میزبان
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/스윙시험.java
python3 ٹولز/اپ_لوڈ_کريں_فائلیں.py build/my-java/스윙시험.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. اخراج_کا_مقام 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.صنف_قدر.class` 형식이다. 내장 اردو 라이브러리는 별도 업로드가 필요 없다. اردو ونڈو API의 예제는 [한글창시험.java](시험/자바/한글창시험.java)이며 같은 방법으로 مرتب_کریں_ماخذ·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 ماخذ_شجر/클래스는 호스트의 `python3 ٹولز/نفاذ_کریں_فائل.py راستہ_2/인사.java`로 별도 QEMU에 업로드·نفاذ_کریں_حکم·종료할 수 있다. متعامل Swing에는 نفاذ_کریں_حکم 후 صارف 입력을 유지하는 `make desktop`을 사용한다.

## اپنا JVM의 Swing تراشہ

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 اپنا Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | عمل |
|---|---|
| `JFrame` | دریچہ_عنوان, حجم·مقام, دکھانا_دریچہ, بند_کریں 정책, dispose |
| `JPanel` | بچہ_قدر 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 سلک_قدر دکھانا_قدر·تبدیل_کریں_قدر |
| `JButton` | 버튼과 ActionListener کلک_قدر عمل_قدر_اندراج |
| `JTextField` | 한 اندراج_کی_سطر UTF-8 입력, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 اپنا JVM의 단일 이벤트 نفاذ_کریں_حکم 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. ونڈو·요소는 نفاذ_کریں_حکم 하나당 합계 32개, عنصر_قدر 글자는 최대 127 코드포인트다. طے_شدہ_قدر 서체와 색은 커널이 제공한다.

[스윙시험.java](시험/자바/스윙시험.java)는 ونڈو·한글 ٹیگ_قدر·متن_فیلڈ·버튼·이벤트 처리의 نفاذ_کریں_حکم 가능한 예제다. [اپنا Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

اردو 라이브러리에는 다음을 추가했다. میزبان مرتب_کریں_ماخذ 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `اردو.اپنا.ونڈو`: `شامل_کریں_عنصر`, `دکھانا_دریچہ`, `بند_کریں`.
- `اردو.اپنا.ویجٹ`: `ٹیگ_قدر`, `بٹن`, `متن_فیلڈ` تخلیق_کرنا.
- `اردو.اپنا.연결통신`: `متصل_ہوں`, `듣기`, `받기`.
- 기존 `اخراج_کا_مقام`, `문자`, `فائل_کا_نام`, `작업`, `اندراج_فہرست`, `لغت`, `통신`, `화면`, `کرنیل_قدر`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **کرنیل_قدر 내부 연결형 بائٹ_قدر بہاؤ_قدر**을 추가했다. فائل_کا_نام/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket سرور_قدر = new java.net.ServerSocket(9250);
java.net.Socket مہمان_قدر = new java.net.Socket("localhost", 9250);
java.net.Socket متصل_ہوں = سرور_قدر.accept();
مہمان_قدر.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int لمبا_ئی_قدر = متصل_ہوں.getInputStream().read(받은것);
متصل_ہوں.close(); مہمان_قدر.close(); سرور_قدر.close();
```

تخلیق_کرنا·متصل_ہوں·accept·양방향 بائٹ_قدر/لڑی_قدر ان_پٹ_آؤٹ_پٹ·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 اختتام_نقطہ 16개, 수신 버퍼당 1024바이트, انتظار_قدر متصل_ہوں 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. طے_شدہ_قدر وقت_قدر 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM حکم 수/کرنیل_قدر نفاذ_کریں_حکم 기한은 여전히 적용된다.

외부 عدد_قدر IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. اصل_کوائف Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP لائبریری 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 اصل_کوائف 송수신·EOF·기한·متصل_ہوں 회수의 시험 예제다.

## 한글 Python

게스트 vi에서 한글 이름을 사용해 작성한다.

```python
قدر = 21

def 두배(عدد_قدر):
    return عدد_قدر * 2

print("پیمائش:", 두배(قدر))
```

ذخیرہ_کریں_قدر 후 `python 인사.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 فعل_قدر·변수·فائل_کا_نام 이름과 문자열을 한글로 쓴다.

[اردو.py](예제/한글코딩/اردو.py)를 같은 디렉터리에 두면 اگلا_شے 별칭을 사용할 수 있다.

```python
import اردو
اردو.لکھیں_فائل("인사.txt", "안녕하세요")
اردو.اخراج_کا_مقام(اردو.파일읽기("인사.txt").decode())
```

اخراج_کا_مقام·فائل_کا_نام پڑھیں/لکھیں/삭제·표준 입력·사각형·وقت_قدر·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 عدد_قدر IPv4 پتہ 전송이다. `wait_key()`는 화면을 확인할 때 متعامل 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor جامد_قدر 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 توسیع_قدر 모듈은 아직 없다. 제한형 `pip`의 ماخذ_شجر 설치는 [Python بنڈل مجھے_پڑھیں_eb81d7d9](파이썬꾸러미.md)를 따른다. [세 언어의 اصل_کوائف 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 زبان 모두 اردو 헤더와 فعل_قدر 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 اصل_کوائف EL0 نفاذ_کریں_حکم 시험 대상이다.

```c
#include "파일규약.h"
#ifdef __cplusplus
extern "C"
#endif
int ابتدا_صارف_ایپ(int دلائل) {
    (void)دلائل;
    const char 인사말[] = "안녕하세요\n";
    int 문서 = بنائیں_فائل("인사.txt", مطالعہ_تحریری | 없으면만들기 | 내용비우기, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = لکھیں_فائل_کوائف(문서, 인사말, sizeof(인사말) - 1);
    بند_فائل(문서);
    لکھیں_فائل_کوائف(1, 인사말, sizeof(인사말) - 1); /* 현재 حکم_کی_تشریح_کرنے_والا stdout */
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 수 있다. C는 게스트 `cc` 또는 میزبان SDK, C++는 میزبان SDK의 Clang++로 컴파일한다. 아래 예제는 기존 میزبان SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh
# 호스트에서 SDK تخلیق_کرنا·اخذ_کریں
make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/인사.c -o 인사-c.elf
python3 compile.py examples/인사.cpp -o 인사-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 اصل_کوائف نفاذ_کریں_حکم
cd /home/user/jkoros/platforms/rpi4-native
python3 ٹولز/نفاذ_کریں_فائل.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 ٹولز/نفاذ_کریں_فائل.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

현재 GUI VM에서 실행하려면 `python3 ٹولز/اپ_لوڈ_کريں_فائلیں.py راستہ_2/인사-c.elf`의 출력을 게스트에 보내고 `run 인사-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex فائل_نام_متن`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 수 있다. 호스트와 게스트의 فائل_کا_نام 시스템은 별개다.

| اردو نام | C علامت | تراشہ |
|---|---|---|
| بنائیں_فائل/بند_فائل | pk_open/pk_close | RAM فائل_کا_نام, ساتھی_قدر/절대 راستہ_2 |
| 파일자료읽기/لکھیں_فائل_کوائف | pk_read/pk_write | فائل_کا_نام, fd 0/1/2 표준 ان_پٹ_آؤٹ_پٹ, 연결형 소켓 |
| تلاش_کرنا_فائل | pk_lseek | 처음기준/현재기준/끝기준 |
| فائل_سائز_دیں/سیٹ_فائل_لمبا_ئی | pk_size/pk_ftruncate | لمبا_ئی_قدر طلب_قدر/تبدیل_کریں_قدر |
| ہٹائیں_فائل_اندراج_نام | pk_unlink | فائل_کا_نام نام 삭제 |
| 파일저장확정 | pk_fsync | RAM이므로 -1, 오류번호=ENOSYS |
| 통신종단점만들기/باندھیں_پتہ | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |
| 자료전문보내기/자료전문받기 | pk_sendto/pk_recvfrom | UDP 루프백 |
| جڑیں_نیٹ_ورک | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | انتظار_قدر متصل_ہوں 최대 4개 |
| قبول_کریں_نیٹ_ورک_کنکشن | pk_accept | 현재 پتہ 인수는 NULL/NULL만 معاونت_قدر |
| 통신주소읽기 | pk_getsockname | 로컬 پتہ/پورٹ_قدر |

`통신규약.h`의 اپنا `pk_sockaddr_in`을 사용하며 پورٹ_قدر·주소는 `망차례짧은수`/`نیٹ_ورک_سالم_عدد`로 변환한다. C 소켓 호출은 비차단이며 کوائف/연결이 없으면 -1과 `오류번호=11`(EAGAIN)을 반환한다. 양수 ان_پٹ_آؤٹ_پٹ 결과가 요청보다 작을 수 있으므로 تکرار_قدر 처리한다. ناکامی_قدر 후에만 오류번호를 확인한다.

[بہاؤ_قدر.c](예제/한글코딩/بہاؤ_قدر.c)는 C에서 اردو 이름으로 متصل_ہوں·accept·부분 پڑھیں/لکھیں·큐 포화·EOF를 처리하는 نفاذ_کریں_حکم 예제다. SDK의 `examples/بہاؤ_قدر.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → اصل_کوائف اردو C فعل_قدر 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·پوائنٹر 검사 → Java RAM فائل_کا_نام/루프백 또는 외부 lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 کرنیل_قدر 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 متصل_ہوں, 표준 C printf, libstdc++/STL, استثنا·RTTI는 제공하지 않으며 C++의 جامد_قدر 생성자·مقامی_اسکوپ آبجیکٹ_قدر 소멸자는 지원한다. 상세 اشاریہ·میموری_کوائف 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## جواز_دہی_کریں

`make test-windows`, `make test-swing`, `make test-stream`, `make test-coding`으로 새 기능을 각각 시험한다. `make test`는 기존 شیل·VNC·JVM·AOT·کرنیل_قدر بچانا_قدر 시험까지 포함한다. اصل_کوائف بورڈ 대신 QEMU raspi4b에서 수행한다. 결과는 [이전 GUI توسیع_قدر جواز_دہی_کریں لاگ_صف](build/verification/release.json)과 [현재 عام_زبان_چلت_عرصہ جواز_دہی_کریں لاگ_صف](build/verification/native-runtime-summary.json), [여러 حکم_کی_تشریح_کرنے_والا 화면](build/verification/windows/four-terminals.png), [Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

구현 시 참고한 표준 API: [Socket](https://docs.oracle.com/javase/8/docs/api/java/net/Socket.html), [JFrame](https://docs.oracle.com/javase/8/docs/api/javax/swing/JFrame.html), [JButton](https://docs.oracle.com/javase/8/docs/api/javax/swing/JButton.html). 이 문서의 구현 범위가 위 표준 전체를 지원한다는 뜻은 아니다.

## اردو 이름으로 직접 작성하는 창과 تھریڈ_قدر

`example/java/کھڑکیمثال.java`는 `실행할일.اطلاق`,
`동작받이.동작받기(동작알림)`, `بٹن`, `ایونٹ_قطار.나중에실행`, `چلائیں()`을 쓴다.
اپنا JVM에 이 이름들의 آبجیکٹ_قدر·طریقہ_قدر·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `작업가닥`도 اپنا 스케줄러와 직접 연결된다.
세부 메서드와 기존 اردو API에서의 변경은 [اردو API 문서](한국어자바/مجھے_پڑھیں_eb81d7d9.md)를 본다.

میزبان javac는 배포 JAR를 صنف_قدر 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/کھڑکیمثال.java
python3 ٹولز/نفاذ_کریں_حکم.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java کھڑکیمثال
```

직접 화면/تھریڈ_قدر API와 `چلائیں()` 진입점은 اپنا JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
