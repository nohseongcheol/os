# اردو Java 통신·ان_پٹ_آؤٹ_پٹ·استثنا API

패키지는 `اردو.اپنا`다. میزبان `javac --release 8`로 컴파일한 class를
اپنا ARM64 커널의 JVM에서 실행한다. 통신·فائل_کا_نام·استثنا API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 تھریڈ_قدر API는 اپنا JVM 전용이다.
기존 표준 Java لائبریری 전체의 اردو 번역판은 아니다.

```java
import اردو.اپنا.*;

public class نیٹ_ورک {
    public static void main(String[] دلائل) throws ان_پٹ_آؤٹ_پٹ_استثنا {
        رابطہ متصل_ہوں = رابطہ.کھولیں("10.0.2.2", 9000);
        try {
            متصل_ہوں.ٹائم_آؤٹ(700);
            متصل_ہوں.اخراج_کا_مقام().لکھیں(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = متصل_ہوں.입력();
            اخراج_کا_مقام.수쓰기(입력.پڑھیں());
        } catch (انتظار_ٹائم_آؤٹ_استثنا غلطی) {
            اخراج_کا_مقام.لکھیں_لائن(غلطی.설명());
        } finally {
            متصل_ہوں.بند_کریں();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
صارف 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 سلک_قدر 리터럴에 사용하는 표준 클래스다. اپنا 실행기는 `public static void چلائیں()`도 진입점으로 받는다.

## 통신과 بہاؤ_قدر

| صنف_قدر | اردو 호출 |
|---|---|
| رابطہ | `کھولیں(پتہ, دہانہ_نمبر)`, `입력()`, `اخراج_کا_مقام()`, `ٹائم_آؤٹ(밀리초)`, `دہانہ_نمبر()`, `مقامی_دہانہ_نمبر()`, `연결됨()`, `닫힘()`, `بند_کریں()` |
| 수신창구 | `کھولیں(دہانہ_نمبر)`, `받기()`, `دہانہ_نمبر()`, `ٹائم_آؤٹ(밀리초)`, `닫힘()`, `بند_کریں()` |
| 입력흐름 | `پڑھیں()`, `پڑھیں(byte[])`, `پڑھیں(byte[], چلائیں, لمبا_ئی_قدر)`, `بند_کریں()` |
| 출력흐름 | `لکھیں(int)`, `لکھیں(byte[])`, `لکھیں(byte[], چلائیں, لمبا_ئی_قدر)`, `내보내기()`, `بند_کریں()` |
| 전문통로 | `کھولیں(دہانہ_نمبر)`, `بھیجیں(پتہ, دہانہ_نمبر, متن)`, `받기()`, `ٹائم_آؤٹ(밀리초)`, `دہانہ_نمبر()`, `닫힘()`, `بند_کریں()` |
| 연결통신 | `کھولیں(...)`, `수신열기(...)`는 위 اردو 객체를 반환 |
| 검사 | `참인지(شرط, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`پڑھیں()`의 فائل_کا_نام 끝은 -1, لڑی_قدر 읽기의 반환값은 اصل_کوائف 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. دہانہ_نمبر 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 اپنا 커널에서 512바이트까지 받으며, 주소는 عدد_قدر IPv4를 사용한다.
`localhost` 루프백 외의 نام 풀이(DNS)는 اپنا 커널에 아직 없다.

기존 `연결통신.متصل_ہوں/듣기/받기`, `통신.کھولیں/بھیجیں/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `رابطہ`, `수신창구`, `전문통로`를 쓴다.

## اردو استثنا

모든 아래 클래스는 طے_شدہ_قدر 생성자, `새예외("설명")` 형태의 سلک_قدر 생성자와
`설명()`을 제공한다. اصل_کوائف تخلیق_کرنا 문법은 `new انتظار_ٹائم_آؤٹ_استثنا("انتظار_حالت 끝")`이다.

| اردو استثنا | 상위 صنف_قدر / 용도 |
|---|---|
| استثنا | `java.lang.Exception`, 직접 던지는 일반 검사 استثنا |
| 실행예외 | `java.lang.RuntimeException` |
| ان_پٹ_آؤٹ_پٹ_استثنا | `java.io.IOException`, اردو فائل_کا_نام·통신 API의 검사 استثنا |
| انتظار_ٹائم_آؤٹ_استثنا | `ان_پٹ_آؤٹ_پٹ_استثنا`, 통신 ٹائم_آؤٹ 초과 |
| پتہ_لُک_اپ_استثنا | `ان_پٹ_آؤٹ_پٹ_استثنا`, پتہ تصدیق_کریں ناکامی_قدر |
| 파일없음예외 | `ان_پٹ_آؤٹ_پٹ_استثنا`, فائل_کا_نام کھولیں ناکامی_قدر |
| 통신예외 | `ان_پٹ_آؤٹ_پٹ_استثنا`, 표준 SocketException 변환 |
| بے_جواز_دلائل_استثنا | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `بے_جواز_دلائل_استثنا` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| خالی_حوالہ_جات_استثنا | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| حالت_استثنا | `java.lang.IllegalStateException` |
| ٹائپ_کریں_کاسٹ_استثنا | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| لڑی_ذخیرہ_کریں_ناکامی | `java.lang.ArrayStoreException` |
| تھریڈ_حالت_استثنا | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 انتظار_قدر 중단 |

`استثنا`와 `실행예외`는 모든 اردو 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, فائل_کا_نام·통신 전체를 잡으려면 `catch (ان_پٹ_آؤٹ_پٹ_استثنا غلطی)`를 쓴다.
اردو API가 표준 ان_پٹ_آؤٹ_پٹ 오류를 اردو 예외로 변환한다.
기존 اردو 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`انتظار_ٹائم_آؤٹ_استثنا`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
استثنا 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 اپنا JVM에 이 20종을 추가했다. 임의의 صارف Throwable 하위 صنف_قدر 전체를
지원하도록 확장했다는 뜻은 아니다.

## مرتب_کریں_ماخذ·نفاذ_کریں_حکم

```sh
cd /home/user/jkoros/platforms/rpi4-native
make بلڈ_نظام
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 ٹولز/نفاذ_کریں_فائل.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 صارف JVM ELF 안에 탑재된다. `.jar`는 میزبان javac의
صنف_قدر 경로로 사용한다. ماخذ_شجر 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 اردو 예외의 `throws` 선언과 그 import를 인식한다.
اپنا JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·آبجیکٹ_قدر·소켓 예제 전체의 ماخذ_شجر 컴파일은 میزبان javac를 사용한다.
`/example/java/فائلمثال.java`는 게스트 javac로도 컴파일할 수 있다.

اصل_کوائف TCP/UDP 예제는 [نیٹورکمثال.java](../../../example/java/نیٹورکمثال.java),
نفاذ_کریں_حکم 절차는 [example مجھے_پڑھیں_eb81d7d9](../../../example/README.md),
ماخذ_شجر 명명 원칙은 [명명 مجھے_پڑھیں_eb81d7d9](../명명/مجھے_پڑھیں_eb81d7d9.md)에 있다.

## Swing ونڈو 예제

`/example/java/کھڑکیمثال.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` اگلا_شے `java کھڑکیمثال`로 연다. نام 입력, 인사하기 버튼,
인사말과 کلک_قدر 횟수 تازہ_کریں, X 닫기를 지원한다.

| 기능 | اردو 직접 API |
|---|---|
| Runnable / run | `실행할일.اطلاق()` |
| ActionListener / actionPerformed | `동작받이.동작받기(동작알림 알림)` |
| ActionEvent | `동작알림.حکم_متن()`, `ایونٹ_ماخذ()`, `اشاریہ()` |
| JFrame | `ونڈو(دریچہ_عنوان, 폭, 높이)`, `شامل_کریں_عنصر(화면구성요소)`, `دکھانا_دریچہ()`, `بند_کریں()`, `보이는가()` |
| JButton | `بٹن(متن, 가로, عمودی_پوزیشن_ٹھیک_کریں, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `سرنامہ(...)`, `متن_فیلڈ(...)` |
| 공통 화면 عنصر_قدر | `화면구성요소.글읽기()`, `لکھیں_متن(متن)`, `자리정하기(가로, عمودی_پوزیشن_ٹھیک_کریں, 폭, 높이)` |
| SwingUtilities.invokeLater | `ایونٹ_قطار.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `ابتدا_ٹاسک()`, `기다리기()`, `살아있는가()`, `معطل_کریں_ٹاسک()` |
| 명령행 | `چلائیں()`, `실행인수.개수()`, `실행인수.متن(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
اپنا JVM의 `한국어화면호출`, `عمل_تھریڈ`가 اردو صنف_قدر·طریقہ_قدر·서술자를
해석해 화면 요소와 نفاذ_کریں_حکم 가닥을 직접 만든다. عمل 알림도 اپنا 객체이며
콜백으로 `اطلاق`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 نفاذ_کریں_حکم 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 اپنا JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 میزبان JVM에서 무동작 객체가 생기지 않도록 하는 رد_کریں_قدر 경로다.
اپنا JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. میزبان javac로 컴파일한 واپس_قدر اپنا JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import اردو.اپنا.*;
public class 가닥예제 implements 실행할일 {
    public void اطلاق() { اخراج_کا_مقام.لکھیں_لائن("اردو 작업 نفاذ_کریں_حکم"); }
    public static void چلائیں() throws 대기중단예외 {
        작업가닥 تھریڈ_قدر = 작업.چلائیں(new 가닥예제());
        작업.기다리기(تھریڈ_قدر);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
لڑی_قدر دلائل 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
اپنا 실행기는 دلائل 없는 `چلائیں()`을 우선한다.
기존 اردو 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.چلائیں(Runnable)`을 사용하던 코드는 새 اردو 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API معاونت_قدر 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 صنف_قدر·طریقہ_قدر 이름과 서술자가 남는다.
اردو نام 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·طریقہ_قدر 재정의, native متصل_ہوں, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS شناخت_کنندہ_قدر](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS طریقہ_قدر حوالہ_جات](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
