# 배포 აწყობა_ნახატი შემოწმება ჟურნალი_ჩაწერა

검증일: 2026-09-27 (Asia/Seoul)

მიზანი: `jkoros-rpi4-aarch64-349b52891a471c8e782da597`

이번 배포는 Raspberry Pi 4용 **ARM64 Linux 실행판**이다. 기존 자체 x86 커널을 ARM으로 이식한 결과가 아니다. რეალური_მონაცემები Pi 보드는 연결되어 있지 않아 하드웨어 부팅 성공을 확인하지 못했다.

## 구현 범위와 남은 შემოწმება

### QEMU 그래픽 შესრულება_ბრძანება 보완

ტერმინალი 전용 실행에서 `인사.java`가 Swing 창을 만들 때 발생한 `HeadlessException`을 해결하기 위해 `make run`과 `make run-console`을 추가했다. 그래픽 실행은 bochs 가상 GPU, USB 키보드·태블릿, Xorg, 로컬 VNC를 사용한다. QEMU 전용 initramfs가 필요한 드라이버를 기존 루트 파일시스템에서 로딩한다. 배포 시스템 이미지와 base-id는 변경하지 않아 기존 მომხმარებელი მონაცემები 이미지를 계속 사용할 수 있다.

რეალური_მონაცემები Xorg/VNC 화면에서 한국어 Java სამუშაო_სივრცე, Swing 시험 ფანჯარა, 기존 이미지의 `인사.java` 창을 표시했다. VNC를 통한 USB 마우스 클릭과 키보드 입력이 Swing 이벤트로 전달되는 것도 확인했다. გასვლა_აპი 시 시스템 OverlayFS와 მონაცემები 파일시스템의 კითხვა 전용 전환을 확인했다. 이번 시험은 Xvfb를 사용하지 않는다.

- [그래픽 시험 ჟურნალი_მნიშვნელობა](build/verification/desktop.log)
- [키보드·마우스 시험 화면](build/verification/desktop-input.png)
- [인사 예제 화면](build/verification/desktop-greeting.png)

წყარო 예제에는 `GraphicsEnvironment.isHeadless()` 분기를 추가했다. 화면이 없는 환경에서는 ფაილი·문자·스레드 기능을 실행하고 안내를 출력한다. მომხმარებელი 홈의 기존 원문을 자동 교체하지는 않는다. 향후 აწყობა_ნახატი 빌드에는 udev의 `add` 이벤트를 명시적으로 발생시키는 수정도 반영된다.

### 한글 입력·შრიფტი_მნიშვნელობა 보완

`make test-korean`으로 რეალური_მონაცემები Xorg/VNC 화면의 Swing 입력창과 xterm에서 Ctrl+Space გადართვა_რეჟიმი 및 두벌식 კლავიში_მნიშვნელობა 입력을 시험했다. 양쪽에서 `한글 입력`을 조합했고 UTF-8 파일의 내용과 일치했다. 시험은 별도 მომხმარებელი მონაცემები 이미지에서 실행했으며 정상 გასვლა_აპი 시 두 파일시스템의 კითხვა 전용 전환을 확인했다.

ტერმინალი შრიფტი_მნიშვნელობა 진단에서 영문 DejaVu Sans Mono와 한글 Noto Sans Mono CJK KR의 რეალური_მონაცემები ფაილი 로딩을 확인했다. 한글용으로 요청한 글꼴이 영문 전용 글꼴로 대체되던 Fontconfig 규칙의 우선순위도 수정했다. 화면 캡처에서 한글·영문 ჩვენება_მნიშვნელობა, Java 작업마당의 확대된 글꼴과 안티앨리어싱을 확인했다.

수정은 QEMU 전용 initramfs를 통해 მომხმარებელი 시스템 변경분에 적용하며 배포 ნაგულისხმევი_მნიშვნელობა 이미지와 base-id는 유지한다. 기존 ფაილი 백업, 동일 수정의 იტერაცია_მნიშვნელობა 적용 방지, 손상된 수정 ფაილი 및 다른 base-id 거부, მომხმარებელი 입력기 პარამეტრები 병합에 대한 მასპინძელი 시험 4개도 통과했다. 원래 მომხმარებელი მონაცემები აწყობა_ნახატი `build/manual-user.img`는 시험에 사용하지 않았다.

### 남은 კლიპი

- 새 აწყობა_წყარო მიზანი `openjdk`는 **네이티브 აპი_გამშვები + JVM/JRE** 방식이다. 모든 Java 바이트코드를 JVM 없이 기계어로 변환하는 범용 AOT 컴파일러는 구현하지 않았다. 기존 x86 AOT의 მხარდაჭერა_მნიშვნელობა 범위는 여전히 제한적이다.
- შესრულება_ბრძანება 프로그램에는 main შენატანი_პტ, 호환 კლასი_მნიშვნელობა 버전과 의존 JAR/JNI가 필요하다. 개별 상용 აპი_f5044b9b, 모든 Java მოდული_მნიშვნელობა, 모든 문자권을 시험한 것은 아니다.
- 한국어 Java 라이브러리는 ფაილი·문자·통신·스레드·Swing을 위한 보조 API이며 JDK 전체 API의 한국어 번역판은 아니다.
- Pi 4 전용 펌웨어·ბირთვი_მნიშვნელობა·მობილური_მნიშვნელობა 트리는 이미지에 들어 있지만 რეალური_მონაცემები SD 부팅, HDMI/KMS, USB, Wi-Fi, 물리 키보드의 한글 입력은 실기 확인이 남아 있다. QEMU는 Pi 장치를 에뮬레이션하는 시험이 아니다.
- მომხმარებელი საქაღალდე_მნიშვნელობა 이동은 동일 시스템 აწყობა_ნახატი იდენტიფიკატორი_მნიშვნელობა, ARM64, `/home/user`, UID 1000을 전제로 한다. გასვლა_აპი 후 소유권·ნებართვა_მნიშვნელობა·링크·გაფართოება_მნიშვნელობა ატრიბუტი_მნიშვნელობა·삭제 정보를 보존하여 복사해야 한다. 다른 OS 버전으로의 자동 이관은 제공하지 않는다.

ინსტალაცია_მნიშვნელობა·ასლი_მნიშვნელობა 절차는 [README.md](README.md), აწყობა_წყარო 방식은 [OpenJDK შესრულება_ბრძანება ფაილი წასაკითხი_ფაილი_eb81d7d9](../../compiler/OpenJDK-실행파일.md)를 따른다. აწყობა_ნახატი 파일만 생성했으며 რეალური_მონაცემები SD 카드나 USB 디스크에 기록하지 않았다.
