# 자체 커널과 번역기의 Български Име

대상은 `platforms/rpi4-native`의 자체 Java ядро_стойност, потребител JVM, C машина Свързване,
TCP/UDP·FTP, C компилатор_инструмент 이식부, MicroPython 이식부, компилация_система·изпълнявам_команда·시험 도구다.
`golang/worldos/кънтри_стойност/KOR/ИЗТОЧНИК`의 원칙처럼 기능을 먼저 구분하고 이름을 정한다.
x86 Java 커널과 공용 x86·ARM64 미리 번역기의 자체 선언도 명명 검사에 포함한다.
Linux 실행판의 хост Инструменти, OpenJDK 보조 Инструменти 및 външен_стойност 배포 източник_дърво 전체를
한국어로 опитвам_повторно_стойност 작성했다는 뜻은 아니다.

## 명명 원칙과 말의 근거

- 명사는 자료의 역할을 나타낸다: `Файл_манипулатор`, `крайно_устройство_номер_на_порт`, `동적기억공간`, `клавиатура`.
- 함수는 행위를 나타낸다: `Четене`, `Писане`, `Отваряне`, `Затворен`, `망주소묶기`, `изпълнение_програма`.
- TCP의 이어진 байт_стойност 흐름과 UDP의 경계 있는 자료를 `връзка`와 `дейтаграма_Канал`로 구별한다.
- 짧은 영어 변수도 쓰임에 따라 `길이`, `данни_позиция`, `Търсене_индекс`, `반환값`으로 풀어 쓴다.
  순번·임시 산술값처럼 여러 역할에 재사용되는 변수는 `순번`, `첫째값`, `둘째값`으로 구별한다.
- 이름이 같아도 външен_стойност 구조체의 필드와 자체 변수는 별도로 분석한다.

`Канал_запис(通路)`는 이동이나 교류가 이루어지는 길이라는 기존 의미를 통신 연결에
적용했다. `порт_стойност(窓口)`의 주고받는 접점이라는 의미를 연결을 받는 곳에 적용했다.
이는 국립국어원 한국어기초사전의 [Канал_запис](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=49310),
[порт_стойност](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=24898)의 뜻에 근거한다.

`дейтаграма(電文)`은 전보에 담는 글이라는 기존 통신 어휘에서 가져와, UDP 자료의
경계가 보존된다는 특징을 드러내는 데 쓴다. 근거는
[한국어기초사전 дейтаграма](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=74335)이다.
`поток_стойност`, `нишка_стойност`, `쌓임`은 우리말의 움직임·이어짐·쌓이는 모양을 빌린 표현이다.
`входен_поток`, `작업가닥`, `стек_Памет` 같은 복합 이름은 이 프로젝트의 기능별 조어다.
이 речник 근거를 특정 중세 문헌의 최초 출현이나 공인 전산 번역으로 확대하지 않는다.
공인 표준 Превод_източник·국어사 дейтаграма 감수를 마쳤다는 뜻도 아니다.

| 기능 | 채택한 Име | 이유 |
|---|---|---|
| TCP Socket | връзка | 상대와 연결되어 ред_стойност 있는 바이트를 주고받음 |
| ServerSocket | получавам_порт | 새 연결이 들어오는 접점 |
| DatagramSocket | дейтаграма_Канал | 각 자료의 경계를 보존하는 통신 |
| InputStream / OutputStream | входен_поток / изходен_поток | 들어오고 나가는 바이트의 ред_стойност |
| heap / stack | 동적기억공간 / стек_Памет | заделям_Памет 방식과 쌓고 꺼내는 구조 |
| thread / keyboard | 작업가닥 / клавиатура | 이어지는 실행과 글쇠의 масив_стойност |
| exception / timeout | изключение / почакай_време_на_изчакване_изключение | 정상 처리에서 벗어남과 그 구체적 이유 |

## 보존하는 규격 Име

`public`, `class`, `int`는 예약어다. `String`, `main`, 배열의 `length`는 예약어가 아니다.
в_срок_артикул 다섯 Java 예제는 `Стартиране()`·`실행인수`·Български 화면/нишка_стойност API를 사용해
예약어·리터럴 외의 식별자를 한국어로 작성한다. 화면/가닥은 표준 객체를
감싸지 않고 자체 JVM에 직접 구현했다. 자세한 계약은 [Български Java API](../한국어자바/안내.md)를 본다.

표준 javac는 низ_стойност 리터럴에 `java.lang.String`, низ_стойност 결합에 `StringBuilder`
같은 이름을 생성한다. 이들은 Български 소스에서도 바이트코드에 남을 수 있다.
기존 표준 class를 실행하는 JVM의 съпоставяне_стойност низ_стойност, 아직 표준 라이브러리를 쓰는
통신·Файл 연결부까지 모두 한국어로 재구현한 것은 아니다. 이름만 일괄 치환하면
서술자·재정의·native 연결이 달라져 호환성이 깨진다.

C 표준 функция_стойност·цяло_число_Тип·POSIX ABI, CPU регистър_стойност Име, 어셈블리 Команда, 링커 절 Име,
TinyCC·lwIP·MicroPython이 요구하는 Настройки 매크로와 헤더 이름도 보존한다.
예: `main`, `memcpy`, `pk_bind`, `mpconfigport.h`, `lwipopts.h`, `stdint.h`.
자체 C 함수의 източник_дърво 이름은 한국어이며, [기계연결이름.h](기계연결이름.h)가
기존 AOT·어셈블리·SDK에 공개한 машина 심볼과 연결한다.
Python의 `__init__`, `setUp`, `handle`, 표준 модул_стойност атрибут_стойност, 명령행 옵션과 JSON 키도
външен_стойност 계약이다. `build/`, 배포 바이너리 이름과 `/sdk`는 기존 изпълнявам_команда 경로를 유지한다.
външен_стойност 원본은 `vendor/`에서 이용허락·해시와 함께 관리한다.

이미 변경된 소스에 опитвам_повторно_стойност 적용하여 대응표를 덮어쓰지 않는다.

## C 통신 구조체와 Python ГРЕШКА

C 통신에서 `갈래`는 адрес 체계를 구분하고 `номер_на_порт`는 port, `адрес_стойност`은
IPv4 주소의 32비트 값을 나타낸다. `дейтаграма_протокол`은 앞서 설명한 дейтаграма(電文)과
случай_стойност(規約)을 결합해 UDP의 기능을 드러낸 프로젝트 이름이다.

| 표준 표현 | Български 직접 구현 |
|---|---|
| AF_INET / SOCK_DGRAM / IPPROTO_UDP | enum의 облак_семейни / дейтаграмно_гнездо / дейтаграма_протокол |
| struct pk_sockaddr_in | struct 인터넷통신주소 |
| sin_family / sin_port | адрес_семейни / номер_на_порт |
| sin_addr.s_addr | Интернет_адрес.адрес_стойност |
| OSError / ГРЕШКА.args[0] | система_грешка / ГРЕШКА.индекс |

Български 구조체는 `#define` 치환이나 стойност_на_поле 별칭이 아닌 별개 자료형이다.
표준 구조체와 같은 16바이트 배치를 선언하며 ядро_стойност SVC에서 байт_стойност 복사로
검사한다. `Създаване_участник`·`изпращам_дейтаграма_данни`와 Файл 함수는 정적 라이브러리에
действителен_данни Български 이름의 функция_стойност 심볼을 갖는다. 기존 pk_* 심볼도 유지한다.
이전 코드에서 Български 통신 함수에 pk_sockaddr*를 전달했다면 Български 구조체로
옮기거나, 표준 구조체와 pk_* 함수의 짝을 유지한다.

Python의 `система_грешка`는 OSError의 Български 하위 클래스이며 연결부에서
ГРЕШКА 번호를 보존하여 변환한다. 일반 Python 문법과 външен_стойност 패키지의 API는 유지한다.

## 직접 GUI 이름의 뜻과 검토 клип

`실행할일`은 수행할 내용을, `Изпълнение`는 그 수행을 나타낸다.
`동작받이`는 동작이 발생했다는 알림을 받는 역할, `проект_предупреждение`은 전달되는 사건이다.
`бутон`는 눌러 동작시키는 조작부, `Етикет`는 안내 글의 позиционен_указател,
`текстово_поле`은 글을 적는 позиционен_указател, `작업가닥`은 이어지는 изпълнявам_команда 흐름을 뜻한다.
`изпълнявам_команда(實行)`·`Операция(動作)`의 기존 뜻과 `받다`·`알리다`·`нишка_стойност`의 기능을
결합한 프로젝트 이름이다. 새 복합어가 역사 문헌에 그대로 있었다거나
특정 시대에 처음 쓰였다고 주장하지 않는다.

전체 저장소는 `python3 Инструменти/източник_рецензия.py`로 검토한다.
결과는 `build/verification/naming/source-review.json`이며 파일별 хеширане_Файл,
ASCII 파일명과 Python의 영어 декларация 위치를 기록한다.
공용 ARM64·x86 번역기의 구현은 `compiler/자바도구/기계어미리번역.java`로 전환했다. `compiler/기계어미리번역.py`는 호환 진입점이다.
`compiler/arm64.py`는 이전 경로와 `ARM64(...).generate(...)` 호출을 이어 주는
호환 진입점이다. `compiler/classfile.py`, OpenJDK 보조 Инструменти, Linux версия_стойност 도구와
기존 호환 진입점에는 영어 이름이 남아 있다. 따라서 전체 저장소가
예약어 외 100% 한국어라고 판정하지 않는다.
`Инструменти/명명검사.py --시언어`는 Онлайн ARM64 소스의 декларация, C 의미 Анализ_стойност,
x86 Java 커널과 공용 번역기의 자체 декларация, Java 예제 전체 Идентификатор_стойност,
ARM64 Python 예제와 직접 GUI/가닥에 표준 래퍼가 없는지를 별도로 검사한다.

## в_срок_артикул 기능을 기준으로 보완한 Име

번역은 글자를 음역하는 대신 자료의 역할과 함수의 행동을 구분한다.
동일한 영어 이름도 문맥이 다르면 Български 이름을 달리 정한다.
Файл 이름은 주된 기능을 나타내고, функция_стойност 이름은 행동을, променлива_стойност 이름은 담는 자료를 나타낸다.
예약어, 표준 API 및 външен_стойност Свързване 규약은 따로 기록한다.

| 이전 Име | 적용한 Име | в_срок_артикул 기능 |
|---|---|---|
| `arm64.py`의 구현 | `compiler/자바도구/기계어미리번역.java` | Java 바이트코드를 독립 실행용 C 원문으로 미리 Превод_източник |
| `ARM64`, `generate` | `машина_код_компилатор`, `генерирам` | Превод_източник 상태를 담는 객체와 C ИЗТОЧНИК генерирам 행동 |
| `prototype`, `method` | `함수원형`, `метод_основен_текст` | 함수의 формат_стойност 선언과 действителен_данни Команда ИЗТОЧНИК |
| `profile`, `heap_words` | `실행대상`, `동적기억낱말수` | ядро_стойност·потребител 구분과 заделям_Памет Памет_стойност 공간의 машина 낱말 수 |
| `pc`, `op` | `команда_позиция`, `명령번호` | 바이트코드에서의 위치와 수행할 명령의 индекс |
| `x`, `y`, `w`, `h` | `x_координата`, `세로좌표`, `영역너비`, `영역높이` | отдалечен_стойност 화면의 위치와 직사각형 Размер |
| `p`, `n`, `i`, `j` | `данни_позиция`, `стойност`, `순번`, `안쪽순번` | отдалечен_стойност 화면 данни·цифра_стойност·спринт_стойност позиционен_указател; 파일별 기능을 확인해 적용 |
| `aot_heap_info`, `__stack_top` | `미리번역기억조회`, `커널쌓임공간끝` | машина Свързване 규약을 유지하면서 자체 소스에서 사용하는 Име |
| `앞캐리지` | `앞줄복귀` | 앞서 받은 문자가 줄복귀였는지 기억하여 중복 줄바꿈을 막음 |

[공용번역기이름대응.tsv](공용번역기이름대응.tsv)에 компилатор_инструмент 참조의 действителен_данни променям_стойност 기록을 남겼다.
추가로 보존한 C·POSIX/lwIP/libassh 이름의 이유는
[규격이름근거.json](규격이름근거.json)에 기록한다.
`시언어번역기/компилатор_инструмент.c`는 TinyCC външен_стойност 원문을 포함하는 Свързване 파일로 자체 선언이 없어서
C 자체 декларация 분석에서는 제외한다. действителен_данни ядро_стойност 빌드에서는 계속 컴파일한다.

### 말의 뿌리와 새로운 복합 Име

`Памет_стойност(記憶)`과 `Търсене_индекс(索引)`은 기존 한자어를 쓴다.
기억은 자료를 간직하는 기능에, 색인은 ред_стойност 있는 항목을 찾아 지정하는 기능에 적용한다.
речник 근거는 국립국어원 한국어기초사전의
[Памет_стойност](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=38812&nation=eng),
[Търсене_индекс](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=63787)이다.

`стек_Памет`, `принудително_изпращане_стойност`, `поп_стойност`는 자료를 포개고 마지막 자료부터 꺼내는 изпълнявам_команда 구조를 드러낸다.
`쌓다`의 기존 뜻에 근거한 기능별 조어이며, 사전의

`미리번역`은 изпълнявам_команда 전에 번역한다는 기능을 직접 나타낸다.
