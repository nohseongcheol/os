# jkoros 안에서 Java δόμηση_προέλευση·εκτελώ_εντολή

이 문서의 부팅·κέλυφος·αποθηκεύω_τιμή 명령은 **x86 έκδοση_τιμή** 기준이다. 공유 Java πρόγραμμα_μεταγλώττισης/JVM은 [ίδιο ARM64 Pi4 έκδοση_τιμή](../platforms/rpi4-native/README.md)에도 연결되어 있다. ARM64에서는 UTF-8 UART είσοδος_τιμή·한글 όνομα_αρχείου_μήνυμα, `edit`의 단독 `.` αποθηκεύω_τιμή, 16개 RAM Αρχείο, 약 2초 εκτελώ_εντολή 제한을 사용한다.

`javac FILE.java`와 `java CLASS [ARGS]`를 네이티브 jkoros 셸에서 실행한다. 컴파일러와 JVM은 각각 독립 ELF로 적재되어 ring 3에서 동작한다. 소스를 게스트에서 읽어 πραγματικός_δεδομένα JVM `.class` 파일을 만들고, 그 파일의 바이트코드를 게스트 JVM이 해석한다. φιλοξενώ δόμηση_προέλευση 서버나 Linux 게스트는 사용하지 않는다.

**τρέχων_στοιχείο 구현은 ίδιο 제한형 πρόγραμμα_μεταγλώττισης·JVM이다. OpenJDK/JDK 전체를 이식하거나 설치한 것이 아니며 Java SE 호환 환경도 아니다.** 표준 라이브러리는 아래의 일부 호출을 구현한 것이다. `java -version`과 `javac -version`에도 이 범위를 표시한다. 일반 JAR, Maven/Gradle, 임의의 Java εφαρμογή_f5044b9b 실행은 아직 지원하지 않는다.

## 바로 εκτελώ_εντολή

호스트에서:

```sh
cd /home/user/jkoros
make iso
make run
```

게스트에서:

```text
jkoros> javac -version
jkoros> java -version
jkoros> ls
jkoros> cat Hello.java
jkoros> javac Hello.java
Compiled: Hello.class (JVM class version 49)
Exit: 0
jkoros> java Hello
Hello from jkoros JVM!
55
Exit: 0
```

ISO는 `os/build/kernel.iso`다. 기존 VirtualBox 실행기도 같은 ISO를 사용한다. εκτελώ_εντολή 중이거나 저장된 VM에는 새 ISO가 자동 반영되지 않는다. 새 부팅 절차는 [VirtualBox εκτελώ_εντολή αρχείο_readme_eb81d7d9](가상상자실행.md)를 따른다. 이 변경의 Java 자동 시험은 QEMU에서 수행했다.

## 직접 작성

`edit`는 Αρχείο 전체를 새 내용으로 작성한다. 기존 내용의 Γραμμή Τροποποίησε_τιμή 기능은 아니다. `.save`로 저장하고 `.cancel`로 취소한다.

```text
jkoros> edit Demo.java
...> public class Demo {
...>  public static int square(int n) { return n * n; }
...>  public static void main(String[] args) {
...>   int n = Integer.parseInt(args[0]);
...>   System.out.println("square=" + square(n));
...>  }
...> }
...> .save
jkoros> javac Demo.java
jkoros> java Demo 12
square=144
Exit: 0
```

- `ls`: 파일과 바이트 수 εμφανίζω_τιμή.
- `cat FILE`: Αρχείο Περιεχόμενο_τιμή εμφανίζω_τιμή. 텍스트 소스에 사용한다.
- `rm FILE`: Μνήμη_δεδομένα Αρχείο 삭제.
- `edit FILE`: 전체 내용을 새로 είσοδος_τιμή. 빈 파일도 저장할 수 있다.
- 구문·Τύπος_τιμή 검사 αποτυχία_τιμή 시 기존 `.class`는 유지된다. 소스를 고친 Πίσω_τιμή 컴파일이 실패했다면 이전 εκτελώ_εντολή 파일이 남아 있으므로 δόμηση_προέλευση 성공 여부를 확인한다.

파일은 RAM에서 동작한다. 전용 αποθηκεύω_τιμή 매체가 없거나 `sync`하지 않은 내용은 재부팅하면 사라진다. `make -C os run-store`로 연결한 매체에는 `sync`로 προέλευση_δέντρο·Τάξη_τιμή·δεδομένα 파일을 보존할 수 있다. 최대 8개, 파일마다 16KiB, Αρχείο 이름은 ASCII 1~63자다. προέλευση_δέντρο 이름은 `.class` 확장자 διεύθυνση_περιοχή 때문에 최대 62자다. Τροποποίησε_τιμή 입력은 ASCII이고 한 Γραμμή 최대 128자다. Γραμμή 또는 Αρχείο 한도를 넘긴 편집은 `.save`에서 거부하여 기존 파일을 보존한다. πυρήνας_τιμή/πρόγραμμα_μεταγλώττισης/JVM 구현의 Java 식별자는 한국어이며, τρέχων_στοιχείο 게스트 είσοδος_τιμή 제한 때문에 χρήστης 예제 이름은 ASCII로 작성한다.

## εξωτερικός_τιμή Αρχείο 적재

호스트에서 만든 소스나 στήριγμα_τιμή απόσπασμα 안의 `.class`를 부팅 이미지에 포함할 수 있다. `JAVA_FILES`는 `게스트이름=호스트경로` 목록이다. 아래의 경로는 예시이며 πραγματικός_δεδομένα 파일의 절대 경로로 바꾼다. 공백 없는 경로를 사용한다.

```sh
# φιλοξενώ JDK로 컴파일한 클래스도 사용할 수 있다.
javac --release 8 /tmp/Demo.java
make -C /home/user/jkoros iso \
  JAVA_FILES='Demo.java=/tmp/Demo.java Demo.class=/tmp/Demo.class'
make -C /home/user/jkoros run \
  JAVA_FILES='Demo.java=/tmp/Demo.java Demo.class=/tmp/Demo.class'
```

새 부팅 후 `java Demo 12`를 실행한다. 소스만 넣었으면 게스트에서 `javac Demo.java`부터 실행한다. `JAVA_FILES`를 생략한 Επόμενο_στοιχείο 빌드에서는 προσαρτώ_καταχώρηση 파일을 포함하지 않는다. Αρχείο Περιεχόμενο_τιμή 변경과 καταχώρηση_Λίστα 제거도 Επόμενο_στοιχείο 빌드에 반영된다. 원본 φιλοξενώ 파일에는 쓰지 않는다. προεπιλεγμένη_τιμή `Hello.java`까지 합해 8개이며, 같은 이름을 명시하면 προεπιλεγμένη_τιμή 예제를 대체한다. 새 `.class`를 저장할 빈 슬롯도 남겨 둔다.

`--release 8`은 Τάξη_τιμή Αρχείο 버전을 맞추는 옵션이다. 사용하는 문법·바이트코드·라이브러리도 아래 στήριγμα_τιμή απόσπασμα 안에 있어야 한다.

## στήριγμα_τιμή απόσπασμα

| 기능 | 게스트 javac | 게스트 JVM |
| --- | --- | --- |
| Τάξη_τιμή | 패키지 없는 단일 Τάξη_τιμή, στατικός_τιμή συνάρτηση_τιμή, 재귀, Παράμετροι/επιστρέφω_μέτρηση | 실행마다 단일 Τάξη_τιμή 적재, public static main(String[]) |
| προεπιλεγμένη_τιμή τιμή | int, boolean, char, String, main의 String[] Παράμετροι | ακέραιος·Αναφορά τελεστέος_δέσμη, String, int[], String[], 내부 StringBuilder |
| Πρόταση_τιμή | 초기값 있는 τοπικός_Πεδίο δήλωση, ανάθεση_τιμή, `+=`, `-=`, `*=`, `/=`, `%=`, 후위 ++/--, 블록, if/else, while, for, return | 해당 ακέραιος·Αναφορά 바이트코드와 πάθηση κλάδος |
| παράσταση_τιμή | 십진 ακέραιος, UTF-8 소스의 συμβολοσειρά_τιμή/문자, + - * / %, 비교, ==/!=, !/&&/\|\|, συμβολοσειρά_τιμή 결합 | ακέραιος εγχείρηση_τιμή·δυαδικό_ψηφίο_τιμή εγχείρηση_τιμή·Τύπος_τιμή μετατρέπω_τιμή, 단락 평가, πίνακας_τιμή πρόσβαση_καταχώρηση |
| Αρχείο | FileInputStream(String), FileOutputStream(String[, boolean]), read()/write(int)/close() | πραγματικός_δεδομένα πυρήνας_τιμή 파일서술자와 Σύνδεση, δημιουργώ·εκκαθαρίζω_Περιεχόμενα·이어쓰기·EOF |
| Έξοδος | System.out.print/println: int/boolean/char/String, println() | 동일 |
| συμβολοσειρά_τιμή/Παράμετροι | String.length(), args.length, args[index], Integer.parseInt | 추가로 String.charAt(), συμβολοσειρά_τιμή 상수의 modified UTF-8 해독 |

선언은 지원하는 문법만 허용한다. 여러 변수를 한 선언에 나열하기, 초기값 없는 τοπικός_Πεδίο δήλωση, 오버로드, 임의 Τύπος_τιμή μετατρέπω_τιμή, πίνακας_τιμή δημιουργώ ΠΗΓΗ, 8/16진 리터럴, Unicode προέλευση_δέντρο 이스케이프 등은 미지원이다. `char`는 문자 리터럴로 초기화하며 일반 JDK의 모든 σταθερά_τιμή 축소 변환을 구현하지 않는다. εξωτερικός_τιμή `.class`의 `int[]` δημιουργώ/Ανάγνωση/쓰기는 지원하므로 φιλοξενώ `javac --release 8`로 만든 πίνακας_τιμή 예제는 실행할 수 있다.

αντικείμενο_τιμή τιμή_πεδίου·일반 αντικείμενο_τιμή δημιουργώ·상속·인터페이스·여러 Τάξη_τιμή Σύνδεση, long/float/double, εξαίρεση διεργασία_τιμή_καταχώρηση, 스레드·모니터, 리플렉션, JNI, JIT, GC, 위 표에 없는 `java.io`와 `java.nio`/`java.net` 일반 API, 컬렉션, JAR와 클래스패스는 미지원이다. 런타임 오류는 Java εξαίρεση 객체를 던지지 않고 진단 후 τρέχων_στοιχείο 프로그램을 종료한다. 객체와 συμβολοσειρά_τιμή αποθηκεύω_τιμή 공간은 εκτελώ_εντολή Έξοδος_εφαρμογή 시 χρήστης περιοχή_τιμή_0e9a97ab 전체와 함께 회수한다. 지속 εκτελώ_εντολή 중 GC는 없다.

## εκτελώ_εντολή 한도와 ΣΦΑΛΜΑ

| πόρος_τιμή | 한도 |
| --- | --- |
| προέλευση_δέντρο/Τάξη_τιμή Αρχείο | 각각 16KiB |
| πρόγραμμα_μεταγλώττισης | διακριτικό_τιμή 2,047개, δημιουργώ κωδικός_τιμή 4KiB, σταθερά_τιμή 풀 4KiB |
| συνάρτηση_τιμή/Παράμετροι | 클래스당 32함수, 함수당 16인수 |
| JVM σταθερά_τιμή | 511개 |
| JVM συνάρτηση_τιμή κωδικός_τιμή | 함수당 8KiB |
| JVM 호출/τελεστέος_δέσμη/τοπικός_Πεδίο μεταβλητή_τιμή | 32프레임, 프레임당 τελεστέος_δέσμη 128칸·τοπικός_Πεδίο 128칸 |
| JVM αντικείμενο_τιμή αποθηκεύω_τιμή διεύθυνση_περιοχή | 8,192개 32비트 υποδοχή_καταχώρηση, 헤더 포함 약 32KiB |
| εκτελώ_εντολή | 최대 500,000 Εντολή, 기존 커널의 약 3초 CPU εκτελώ_εντολή 상한도 적용 |

게스트 컴파일러는 버전 49.0 `.class`를 생성하며 JVM은 45.0~52.0 중 στήριγμα_τιμή 명령으로 구성된 파일을 읽는다. 스택맵을 이용한 완전한 JVM λεξικό 검증기를 구현한 것은 아니다. Αρχείο/χαρακτηριστικό_τιμή_286d43f0 διάρκεια_τιμή, σταθερά_τιμή Αναφορά, Εντολή·κλάδος 경계를 검사하고, εκτελώ_εντολή 중 τελεστέος_δέσμη μορφή_τιμή·τοπικός_Πεδίο προετοιμάζω·πίνακας_τιμή δείκτης_τιμή·αντικείμενο_τιμή 참조를 검사한다. χρήστης 코드의 페이지·υλικό_θύρα 접근은 기존 ring 3 경계로 보호한다.

일반 성공은 `Exit: 0`, δόμηση_προέλευση·JVM 오류는 `Exit: 1`, Εντολή Παράμετροι 오류는 `Exit: 2`다. CPU τιμή_ώρας 상한은 기존 `Exit: 124`이며, χρήστης ELF 자체의 CPU/런타임 오류는 기존 Έξοδος_εφαρμογή 코드를 따른다. αποτυχία_τιμή 후 셸에서 다른 프로그램을 계속 실행할 수 있다.

## Java Αρχείο είσοδος_έξοδος

[FileDemo.java](../posix-kor/자바예제/FileDemo.java)는 일반 Java 표준 Τάξη_τιμή 이름을 사용한다. 소스를 `edit FileDemo.java`로 입력하거나 `JAVA_FILES`로 부팅 이미지에 넣은 Πίσω_τιμή `javac FileDemo.java`, `java FileDemo`를 실행한다. 결과는 `65`, `255`, `66`, `-1`, `JAVA FILE IO PASS`다. `write(int)`는 하위 8비트를 쓰고 `read()`는 0~255 또는 EOF -1을 반환한다. προεπιλεγμένη_τιμή Έξοδος 생성자는 내용을 비우고, boolean 인수가 true이면 이어쓴다.

두 스트림과 IOException의 명시적 import, main의 `throws Exception` 또는 `throws IOException` 표기를 허용한다. εξαίρεση αντικείμενο_τιμή·try/catch·try-with-resources는 지원하지 않으며 Αρχείο 오류를 진단하고 프로그램을 종료한다. πίνακας_τιμή είσοδος_έξοδος, InputStream/OutputStream으로의 다형성, Reader/Writer, getFD, 일반 Αρχείο 메타데이터 API는 아직 없다. close는 열린 서술자를 닫고, 재부팅 보존에는 κέλυφος `sync`가 필요하다. 예제의 Αρχείο 이름은 τρέχων_στοιχείο 셸과 파일체계에 맞춰 ASCII로 쓴다.

`os/시험/자바파일시험.py`는 πραγματικός_δεδομένα 게스트 δόμηση_προέλευση 결과를 OpenJDK `-Xverify:all`로 δοκιμάζω_ξανά_τιμή 실행해 Αρχείο 바이트와 출력을 대조한다. 범위와 αποθηκεύω_τιμή μέσα_τιμή 사용법은 [posix-kor αρχείο_readme_eb81d7d9](../posix-kor/αρχείο_readme_eb81d7d9.md)를 참고한다. 참고한 표준 API는 Oracle [FileOutputStream](https://docs.oracle.com/javase/8/docs/api/java/io/FileOutputStream.html)이다.
