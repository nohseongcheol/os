# JGrcOS 구조

아래는 objekt_VALUE 기반 관리 bërthamë_VALUE 전체의 objektiv_objekt 구조다. 현재 aktual_të_dhëna 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 sistem_operativ LEXOMË_eb81d7d9](../os/LEXOMË_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·Konteksti_VALUE SWITCH_MODE·sistemi_i_skedarëve 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 Shtresë_VALUE
  ↓
Java AOT 실행기와 objekt_VALUE·ARRAY_VALUE·GC 런타임
  ↓
하드웨어 경계
  ↓
Java 관리 bërthamë_VALUE
  ├─ 기억공간/쪽관리/COW
  ├─ Proces_VALUE/배정/wait
  ├─ sistemi_i_skedarëve/ELF/POSIX
  └─ 입력/hapësira_ruajtëse_pajisje/rrjet_Stivë
```

OpenJDK 자체는 이미 운영체제가 제공하는 Kartelë, 스레드, 가상 기억공간을 전제로 한다. 따라서 bërthamë_VALUE 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, Konteksti_VALUE 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
