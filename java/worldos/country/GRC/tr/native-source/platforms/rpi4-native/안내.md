# Raspberry Pi 4 Öz Java çekirdek_değer — kullanıcı_alanı yürütmek_komut 기반

geçerli_öğe Öz 코드의 COSL 상업 koşul, 제3자 고지 및 LGPL 재연결 자료는 [COSL dağıtım_değer 안내](COSL배포안내.md)를 참고한다. geçiş_mod 전 GPL 구성의 판단은 [Önceki_öğe 라이선스 검토](lisans_inceleme.md)에 기록했다.

Türkçe iletişim·özel_durum 사용법은 [Türkçe Java API](한국어자바/안내.md), işlev_değer·değişken_değer·dosya 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

Linux 없이 부팅하는 Öz AArch64 커널이다. Java AOT çekirdek_değer 위에 **komut_satırı kabuk, 게스트 Java derleyici·JVM, MicroPython, EL0 C++ yürütmek_komut, dosya·UDP 루프백 시스템 호출, 여러 한글 GUI uçbirim·vi Düzenleyici·Swing 부분집합**을 제공한다. 커널의 dosya veri/정책·루프백 devir_değer·kabuk 상태는 Java, 화면 합성·piksel değiştirmek_değer·işaretçi·클리핑도 Java로 구현하며, CPU/MMU/cihaz_değer 경계와 uçbirim·karakter_değer 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 Öz 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 yürütmek_komut, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 kablolu_değer 송수신은 아직 미검증이다.** yürütmek_komut·cxn_e05f319b·parola_değer 확인은 [dış_değer cxn_e05f319b 안내](dış_cxn_kılavuz.md)에 정리했다.

셸은 EL1 çekirdek_değer, `java` 등 kullanıcı_alanı yürütmek_komut 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 yürütmek_komut·cxn_e05f319b 방법 및 fiili_veri 검증은
[yürütmek_komut 계층과 dış_değer iletişim 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 fiili_veri yürütmek_komut 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 statik_değer ELF는 `run --linux dosya_adı_SMS`으로 실행한다. [ELF·Linux ABI Destek_değer 범위와 동일 바이너리 sınamalar](yürütülebilir_ABI.md).

GUI와 네트워크는 `python3 araçlar/yürütmek_komut.py --desktop --network`로 함께 사용한다. Java·C·Python의 Türkçe 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 makine_başlatma 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 수 있다. Remmina에서 **F9/Shift+Space/한·sıfır_işlenen tuş_değer**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·fiili_veri TCP/UDP·dosya bayt_değer·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java PencereÖrneği`로 Türkçe Swing 예제를 실행한다. uçbirim 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 geçerli_öğe SÜTUN_değer·SATIR_değer 수를 보여 준다.

yürütmek_komut 버튼 화면은 5×7 영문 글꼴을 쓰며, uçbirim 창은 Noto CJK/DejaVu에서 생성한 한글·Unicode 비트맵 글꼴을 쓴다. UART와 fiili_veri 프레임버퍼의 한글 표시를 시험한다. 루프백은 동일 çekirdek_değer 내부의 veri_birimi 전달이며 IP 패킷을 Ethernet으로 내보내는 드라이버가 아니다. 바깥 IPv4는 lwIP TCP/UDP 스택으로 보조 UART SLIP 경로를 사용한다. `python3 araçlar/yürütmek_komut.py --network`로 QEMU NAT를 연결하고 `ftpd start`로 서비스를 시작한다.

Java의 정확한 API·문법·yürütmek_komut 제한과 Türkçe 사용법은 [Öz JVM과 Türkçe kitaplık](자바실행환경.md)에 정리했다. Sınıf_değer dosya/JAR 배포는 [한국어자바](한국어자바) 소스에서 재현한다. 기존 Linux판 `Türkçe.자바`와 별도인 `Türkçe.Öz` 패키지다.

**vi·여러 Pencere·Swing·한글 Java/Python/C/C++·posix-kor 예제는 [한글 개발 매뉴얼](개발안내.md)에 정리했다.**

GUI uçbirim yürütmek_komut·단축키·kabuk komut·제한은 [셸과 uçbirim 사용법](kabuk_VE_Terminal.md)에 정리했다.

## geçerli_öğe 컴퓨터에서 yürütmek_komut

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

Çıkış_program: **Ctrl+A Sonraki_öğe X**. 게스트 C/AOT araçlar 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. konak 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. derleyici 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/yol/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` Destek_değer 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 yürütmek_komut**한다. 기존 한 karakter_değer 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 bağımsız_değişkenler 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

| komut | Eylem |
|---|---|
| `help` / `info` | komut·fiili_veri gerçekleme Durum_değer |
| `ls` / `cat FILE` / `rm FILE` | RAM dosya girdi_Liste·içerik_değer·삭제 |
| `vi FILE` | kullanıcı_alanı bölge_değer vi 부분집합, 한글 Düzenle_değer·depo_değer·검색·되돌리기 |
| `edit FILE` | dosya 전체를 새로 artış_değer; 단독 `.` 줄로 depo_değer, Ctrl-C로 İptal_işlem |
| `javac FILE.java` / `java CLASS [ARGS]` | Öz 제한형 Java derlemek_kaynak·yürütmek_komut |
| `python FILE.py [ARGS]` / `python -c 'CODE'` | MicroPython derlemek_kaynak·yürütmek_komut |
| `load FILE` / `hex FILE` | 16진수 바이너리 artış_değer/metinÇıktısı; 입력은 단독 `.` 줄로 depo_değer |
| `run FILE.elf [ARGS]` / `run cpp` | 업로드한 Öz ABI ELF / 내장 C++ 예제 |
| `net test` / `tasks` / `selftest` | UDP 루프백 / 협력식 작업 / EL0 korumak_değer sınamalar |
| `gui` / `terminal` | yürütmek_komut 화면 / 한글 GUI uçbirim; F12로 uçbirim Aç·Kapat |
| `samples` | 삭제한 varsayılan_değer 예제 kurtarmak_Durum; 기존 파일은 보존 |

예를 들어 `edit 인사.java`를 입력한 Sonraki_öğe 아래 소스를 입력한다.

```java
public class 인사 { public static void main(String[] args) { int değer = 7; System.out.println("한글=" + değer); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 인사.java`, `java 인사`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. İptal_işlem·잘못된 16진수·kapasite_değer 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, yürütmek_komut 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 komut 인수는 최대 32개다. Alıntı·백슬래시·kabuk değişken_değer·파이프·리다이렉션 범위는 [kabuk 설명](kabuk_VE_Terminal.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, ADRES **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode artış_değer·명시적 yapıştırmak_değer·yürütmek_komut 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 araçlar/yürütmek_komut.py --desktop --network
# 다른 donanım_taşımak: python3 araçlar/yürütmek_komut.py --desktop --port 5903
```

종료는 실행한 konak 터미널에서 Ctrl+C다. 기존 `python3 araçlar/yürütmek_komut.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. fiili_veri Pi4 USB 입력기는 아직 없으며, VNC Bağlan 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 fiili_veri C++/UDP ELF yürütmek_komut, `Hello.java` derlemek_kaynak 후 JVM yürütmek_komut, `hello.py` yürütmek_komut, GUI uçbirim 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 devralmak 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 Bellek_veri·CPU 문맥을 보관한다. kabuk·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

이미지는 확인된 공식 Pi makine_başlatma 묶음에서 `start4.elf`, `fixup4.dat`, Pi4 DTB와 disable-bt overlay를 가져온다. Linux kernel/initramfs/rootfs는 넣지 않는다. 펌웨어·MicroPython·uçbirim yazı_tipi_değer 라이선스와 yazı_tipi_değer origin_değer 해시도 동봉한다. dosya oluşturmak 스크립트는 물리 디스크에 기록하지 않는다.

예비 microSD에 BLD_RESİM LOG_KAYIT 도구로 `.img`를 기록하거나 FAT32 makine_başlatma 파티션 최상위에 ZIP 내용을 푼다. BLD_RESİM 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 varsayılan_değer EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD dosya 구성·çekirdek_değer 체크섬 검사와 물리 Pano makine_başlatma 검증은 별개다. MMU kullanmak_değer 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 makine_başlatma 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 Türkçe API kullanmak_değer

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/DosyaÖrneği.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int Start_kullanıcı_program(int)`이다. kullanıcı_alanı C++는 FP/SIMD를 사용할 수 있다. çekirdek_değer C/Java AOT는 일반 레지스터만 사용하므로 özel_durum işlem_değer_girdi 중 kullanıcı_alanı FP 상태를 건드리지 않는다. kullanıcı_alanı giriş_noktası_değer 시 FP 상태를 초기화하고 çekirdek_değer 복귀에 필요한 상태를 보존한다.

```cpp
#include "Dosya_ABI.h"
extern "C" int Start_kullanıcı_program(int) {
    int dosya = açık_Dosya("인사.txt", R_W | 없으면만들기 | kesmek_içindekiler, 0600);
    if (dosya < 0) return 1;
    const char içerik_değer[] = "안녕하세요";
    int sonuç = yazma_Dosya_veri(dosya, içerik_değer, sizeof(içerik_değer) - 1);
    Kapat_Dosya(dosya);
    return sonuç == sizeof(içerik_değer) - 1 ? 0 : 2;
}
```

[dosya 예제](kullanıcı_alanı/DosyaÖrneği.cpp)와 [iletişim 예제](kullanıcı_alanı/통신예제.cpp)가 fiili_veri makine_başlatma sınamalar 대상이다. `Dosya_ABI.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 dosya işlem_değer_girdi 및 루프백 전달은 Java 커널에서 실행한다. `ağ_ABI.h`의 yuva_değer 함수는 geçerli_öğe 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 çekirdek_değer 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 Sonraki_öğe 도구를 사용하면 **새 QEMU를 부팅해 업로드한 fiili_veri 바이트를 재확인한 BACK_değer 게스트에서 yürütmek_komut**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 araçlar/yürütmek_Dosya.py build/jkoros-native-sdk/demo.elf
python3 araçlar/yürütmek_Dosya.py 예제/Hello.java "한글 bağımsız_değişkenler"
python3 araçlar/yürütmek_Dosya.py 예제/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 çekirdek_değer 묶음에 포함되어 이 dosya 한도를 적용받지 않는다. **C++ 컴파일러는 konak SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 kitaplık, PT_TLS, PT_INTERP, PT_DYNAMIC, yürütmek_komut·Yazma 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 Dizin·ADRES klip·오류는 [kullanıcı_alanı ABI](kullanıcı_Ara_ABI.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `commit_Dosyalar`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 izin_değer·dup/fcntl은 없다. 디렉터리와 eş_değer/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, almak_değer 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. kullanıcı_alanı Çıkış_program 시 열린 dosya 서술자와 소켓을 회수한다.

## Java와 Python의 정확한 klip

Öz `javac`는 버전 49 `.class`를 생성하며 JVM은 Destek_değer 명령으로 구성된 버전 45–52 클래스를 실행한다. statik_değer işlev_değer·재귀·int/boolean/char/String·koşul/öğe_değer_58902391·dize_değer 결합과 일부 dosya 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/조합 자모 식별자를 처리한다. Unicode tanımlayıcı_değer 전체 arama_tablosu·Unicode kaynak_ağaç 이스케이프는 구현하지 않았다. 게스트 kaynak_ağaç 컴파일러는 일반 nesne_değer·özel_durum·Thread 구문을 아직 컴파일하지 못한다. konak `javac --release 8`로 만든 Destek_değer 부분집합 클래스는 Öz JVM 0.4의 nesne_değer·özel_durum·Thread·UDP와 Türkçe API를 사용할 수 있다. Swing은 문서화한 Öz API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [Öz JVM 설명](자바실행환경.md)이 기준이다. 상세 Dil 범위는 [공유 Java araçlar 설명](../../문서/Java_IDE.md)을 참고하되, 그 문서의 x86 kabuk/depo_değer/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 kaynak_ağaç**를 Öz AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 işlev_değer·Sınıf_değer·özel_durum·리스트/sözlük·Unicode·GC·가변 duyarlık_değer 정수를 제공한다. geçerli_öğe 구성은 bilgi 빌드로 `float`, `complex`, `math`가 없으며 CPython 전체 표준 kitaplık, pip, subprocess, threading, 일반 socket과 varsayılan_değer `open()` dosya 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 nesne_değer·모듈은 Çıkış_program 시 회수되고 RAM 파일만 Sonraki_öğe 실행에 남는다.

`import jkoros`로 Sonraki_öğe 시스템 연결을 쓴다. 모두 SVC를 통해 Öz Java 커널에 접근한다.

| işlev_değer | Eylem |
|---|---|
| `stdin(limit)` | geçerli_öğe 표준 입력에서 최대 limit바이트(0…16384)를 bytes로 읽음; EOF는 빈 bytes, UART veri 없음은 OSError(11) |
| `read(name)` | eş_değer/절대 RAM 경로의 dosya 전체를 bytes로 읽음 |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 depo_değer, 쓴 bayt_değer 수 İade_KR |
| `remove(name)` | RAM dosya 삭제 |
| `rect(x, y, w, h, color)` | 선택한 fiili_veri 화면 Boyut 안의 dikdörtgen çizim_değer; 기존 보드의 RGB32 değer |
| `ticks_ms()` | makine_başlatma 후 밀리초, 32비트 Döngü_değer |
| `udp_open(port)` | 127.0.0.1의 UDP yuva_değer Aç/BIND_uç_nokta; 0은 자동 donanım_taşımak |
| `udp_send(fd, port, data)` | 루프백 hedef_değer 포트에 str/bytes 버퍼 devir_değer |
| `udp_recv(fd)` | `(bytes, 보낸포트)` İade_KR; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | yuva_değer Kapat |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```

`arkaPlanGörevi`, `çalıştır()`을 사용할 수 있다. Türkçe GUI/가닥을 Öz JVM에 직접
연결했으며, 표준 Swing/Thread를 감싸지 않는다. dize_değer 등 javac의 표준
계약과 전체 kaynak_ağaç 검토 범위는 [명명 안내](명명/안내.md), 사용법과 호환성 변경은
[Türkçe Java API](한국어자바/안내.md)를 본다.

uçbirim taşımak_değer_83b651b8·Boyut 변경은 바뀐 영역만 합성하고 달라진 화소만 표시한다.
