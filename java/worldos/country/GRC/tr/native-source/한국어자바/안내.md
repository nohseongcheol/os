# Türkçe Java yardımcı_değer kitaplık

OpenJDK 11 이상과 함께 쓰는 프로젝트 sahip_değer API다. 표준 Java kitaplık 전체의 번역판을 뜻하지 않는다. 기존 Java API·키워드·özel_durum·자료형은 그대로 함께 쓴다.

전체 22개 yardımcı_değer 메서드의 bağımsız_değişkenler·반환값·제약, işletim_sistemi 안의 사용법, Python·C++ 호출 방법은 **[Türkçe kitaplık kullanıcı_kılavuz](kullanıcı_kılavuz.md)**에 정리했다. [Python 호출 예제](예제/다른언어/PYTHON_Çağrılar.py)와 [C++ JNI 호출 예제](예제/다른언어/자바호출.cpp)도 제공한다.

`make`로 `build/한국어자바.jar`를 만든다. `javac -encoding UTF-8 -cp build/한국어자바.jar 예제/인사.java`로 예제를 컴파일한다. 실행은 `java -cp build/한국어자바.jar:예제 인사`다.

`인사` 예제는 그래픽 화면이 없으면 dosya·문자·스레드 결과와 안내만 출력한다. Swing 창은 그래픽 세션에서 실행해야 한다. QEMU에서는 [그래픽 yürütmek_komut 안내](../platforms/rpi4/README.md)의 `make run`으로 부팅한 BACK_değer VNC 데스크톱의 터미널을 사용한다.

| Sınıf_değer | 제공 기능 |
|---|---|
| dosya | UTF-8 텍스트·bayt_değer Okuma/Yazma, 디렉터리·girdi_Liste |
| 문자 | UTF-8 ÇEVİR_değer, NFC normalleştirmek_değer, KOD_değer 포인트 수, 언어별 낱말 sınır_değer |
| iletişim | HTTP(S) istek, 제한시간을 가진 TCP Bağlan |
| 작업 | 스레드 çalıştır·합류·bekle_değer, 작업 program_Launcher |
| 화면 | Swing 이벤트 처리와 Pencere oluşturmak |
| çalışma_alanı | kaynakKod Düzenle_değer·derlemek_kaynak·yürütmek_komut·yürütmek_komut dosya oluşturmak 화면 |

`char`는 UTF-16 KOD_değer 단위이므로 이모지 등을 한 글자로 처리할 때 KOD_değer 포인트 또는 문자 sınır_değer API를 사용한다. 파일은 UTF-8로 저장한다. OpenJDK의 모든 Java2D/yazı_tipi_değer/입력기 조합을 각각 검증한 것은 아니다.

이름은 geçerli_öğe 의미가 분명한 Türkçe 용례를 사용했다. 개별 명칭의 역사적 어원 검토를 완료했다고 주장하지 않는다. kaynak_değer 종료와 özel_durum 처리는 표준 API의 계약을 따른다.
