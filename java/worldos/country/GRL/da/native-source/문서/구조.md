# JGrlOS 구조

아래는 objekt_VÆRDI 기반 관리 kerne_VÆRDI 전체의 mål_objekt 구조다. aktuel_vare faktisk_data 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 operativsystem Vigtigt_eb81d7d9](../os/Vigtigt_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·kontekst_VÆRDI SKIFT_HYPPIGST·filsystem 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 lag_VÆRDI
  ↓
Java AOT 실행기와 objekt_VÆRDI·MATRIX_VÆRDI·GC 런타임
  ↓
hardware_VÆRDI grænse_VÆRDI
  ↓
Java 관리 kerne_VÆRDI
  ├─ Hukommelse_område/쪽관리/COW
  ├─ Proces_VÆRDI/배정/wait
  ├─ filsystem/ELF/POSIX
  └─ input_VÆRDI/lagerenhed/netværk_Stak
```

OpenJDK 자체는 이미 운영체제가 제공하는 Fil, 스레드, 가상 기억공간을 전제로 한다. 따라서 kerne_VÆRDI 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, kontekst_VÆRDI 저장처럼 Java로 표현할 tal 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
