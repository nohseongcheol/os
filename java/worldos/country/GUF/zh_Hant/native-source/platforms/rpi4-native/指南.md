# Raspberry Pi 4 內建 Java 內核值 — 使用者 執行命令 基礎

當前項目 內建 코드의 COSL 상업 條件, 제3자 고지 및 LGPL 重新連接端點 자료는 [COSL 分發值 指南](COSL分發指南.md)를 참고한다. 切換模式 之前值 GPL 구성의 판단은 [上一個項目 라이선스 검토](許可審閱.md)에 기록했다.

中文 通信·異常 사용법은 [中文 Java API](中文Java/指南.md), 函數·變量值·檔案 이름의 변경과 어원 근거는 [命名 指南](命名/指南.md)를 참고한다.

Linux 없이 부팅하는 內建 AArch64 커널이다. Java AOT 內核值 위에 **命令行 命令殼, 게스트 Java 編譯器·JVM, MicroPython, EL0 C++ 執行命令, 檔案·UDP 루프백 시스템 調用, 여러 韓文文本 GUI 終端·vi 編輯器·Swing 부분집합**을 제공한다. 커널의 檔案 資料/정책·루프백 傳送值·命令殼 상태는 Java, 屏幕 합성·像素 更改值·指針·클리핑도 Java로 구현하며, CPU/MMU/設備 경계와 終端·字元值 畫圖屏幕 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 內建 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 執行命令, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](檔案傳送與編譯過程.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 物理硬件 Pi4의 有線值 송수신은 아직 미검증이다.** 執行命令·接通狀態·密碼值 확인은 [外部值 接通狀態 指南](外部連接狀態指南.md)에 정리했다.

셸은 EL1 內核值, `java` 등 使用者 執行命令 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 限制值, QEMU 네트워크 執行命令·接通狀態 방법 및 實際資料 검증은
[執行命令 계층과 外部值 通信 審查狀態](運行時與外部網路檢查項.md)을 참고한다.

ELF는 확장자가 아닌 實際資料 執行命令 형식으로 검사한다. `./問候例`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 靜態值 ELF는 `run --linux 檔案名稱文本`으로 실행한다. [ELF·Linux ABI 支持值 범위와 동일 바이너리 測試](可執行文件ABI.md).

GUI와 네트워크는 `python3 工具集/執行命令.py --desktop --network`로 함께 사용한다. Java·C·Python의 中文 範例 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 啓動 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 數 있다. Remmina에서 **F9/Shift+Space/한·零操作數 鍵值**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·實際資料 TCP/UDP·檔案 位元組值·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 之後狀態 `java 窗口例`로 中文 Swing 예제를 실행한다. 終端 모서리에 마우스를 대고 **左側 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 當前項目 欄值·列值 수를 보여 준다.

執行命令 버튼 화면은 5×7 영문 글꼴을 쓰며, 終端 창은 Noto CJK/DejaVu에서 생성한 韓文文本·Unicode 비트맵 글꼴을 쓴다. UART와 實際資料 프레임버퍼의 韓文文本 표시를 시험한다. 루프백은 동일 內核值 내부의 數據報 전달이며 IP 패킷을 Ethernet으로 내보내는 드라이버가 아니다. 바깥 IPv4는 lwIP TCP/UDP 스택으로 輔助值 UART SLIP 경로를 사용한다. `python3 工具集/執行命令.py --network`로 QEMU NAT를 연결하고 `ftpd start`로 서비스를 시작한다.

Java의 정확한 API·문법·執行命令 제한과 中文 사용법은 [內建 JVM과 中文 庫](Java運行時環境.md)에 정리했다. 類別值 檔案/JAR 배포는 [中文Java](中文Java) 소스에서 재현한다. 기존 Linux판 `中文.Java`와 별도인 `中文.內建` 패키지다.

**vi·여러 窗口·Swing·韓文文本 Java/Python/C/C++·posix-kor 예제는 [韓文文本 開發 매뉴얼](開發指南.md)에 정리했다.**

GUI 終端 執行命令·단축키·命令殼 命令·제한은 [셸과 終端 사용법](命令殼與終端.md)에 정리했다.

## 當前項目 컴퓨터에서 執行命令

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

退出程式: **Ctrl+A 下一項目 X**. 게스트 C/AOT 工具集 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 算術值 輔助值 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. 宿主 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 移植·링크한 것은 아니다. 編譯器 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/路徑/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` 支持值 여부를 확인한 之後狀態 실행한다.

명령은 **Enter를 눌러 執行命令**한다. 기존 한 字元值 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "韓文文本 實參 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

| 命令 | 動作 |
|---|---|
| `help` / `info` | 命令·實際資料 實現 狀態值 |
| `ls` / `cat FILE` / `rm FILE` | RAM 檔案 條目列表·內容值·삭제 |
| `vi FILE` | 使用者 區域值 vi 부분집합, 韓文文本 編輯值·存儲值·검색·되돌리기 |
| `edit FILE` | 檔案 전체를 새로 輸入值; 단독 `.` 줄로 存儲值, Ctrl-C로 取消操作 |
| `javac FILE.java` / `java CLASS [ARGS]` | 內建 제한형 Java 編譯原始碼·執行命令 |
| `python FILE.py [ARGS]` / `python -c 'CODE'` | MicroPython 編譯原始碼·執行命令 |
| `load FILE` / `hex FILE` | 16진수 바이너리 輸入值/輸出; 입력은 단독 `.` 줄로 存儲值 |
| `run FILE.elf [ARGS]` / `run cpp` | 업로드한 內建 ABI ELF / 내장 C++ 範例 |
| `net test` / `tasks` / `selftest` | UDP 루프백 / 협력식 任務 / EL0 保護值 測試 |
| `gui` / `terminal` | 執行命令 屏幕 / 韓文文本 GUI 終端; F12로 終端 打開·關閉 |
| `samples` | 삭제한 默認值 範例 恢復狀態; 기존 파일은 보존 |

예를 들어 `edit 問候例.java`를 입력한 下一項目 底端值 소스를 입력한다.

```java
public class 問候例 { public static void main(String[] args) { int 值 = 7; System.out.println("韓文文本=" + 值); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 問候例.java`, `java 問候例`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. 取消操作·잘못된 16진수·容量值 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, 執行命令 인수는 最大值 8개·각각 UTF-8 255바이트다. 일반 命令 인수는 最大值 32개다. 引號·백슬래시·命令殼 變量值·파이프·리다이렉션 범위는 [命令殼 說明](命令殼與終端.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, 地址 **127.0.0.1:5902**로 연결한다. 키보드·韓文文本 Unicode 輸入值·명시적 粘貼值·執行命令 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 工具集/執行命令.py --desktop --network
# 다른 硬件埠: python3 工具集/執行命令.py --desktop --port 5903
```

종료는 실행한 宿主 터미널에서 Ctrl+C다. 기존 `python3 工具集/執行命令.py --vnc 127.0.0.1:2`는 屏幕 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. 實際資料 Pi4 USB 입력기는 아직 없으며, VNC 連接 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 實際資料 C++/UDP ELF 執行命令, `Hello.java` 編譯原始碼 之後狀態 JVM 執行命令, `hello.py` 執行命令, GUI 終端 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 交互式 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 記憶體資料·CPU 문맥을 보관한다. 命令殼·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

## 實際資料 산출물과 Pi4 SD 構建映像

```sh
make image   # 內核值, SD 構建映像, 啓動 ZIP, 사용자용 SDK
make sdk     # SDK만 重試值 生成
```

| 路徑 | 용도 |
|---|---|
| `build/kernel8.img` | 內建 內核值 기계어, 적재 地址 0x80000 |
| `build/kernel.elf`, `kernel.map` | 內核值 符號值·鏈接佈局 |
| `build/user/demo.elf` | 使用者 模式值 C++ 檔案/堆值/浮點型分值/그래픽 範例 |
| `build/user/network.elf` | 使用者 模式值 C++ UDP 루프백 範例 |
| `build/user/java-tools.elf` | 內建 Java 부분집합 編譯器/JVM, 전체 JDK/JRE 아님 |
| `dist/jkoros-native-korean.jar` | 宿主 javac용 中文 API 類別值; 같은 클래스가 內建 JVM에도 내장됨 |
| `dist/jkoros-native-korean-sources.zip` | 中文 API Java 原始碼 |
| `build/user/vi.elf` | 內建 UTF-8 vi 命令 부분집합 編輯器 |

| `build/libposix-kor-user.a` | **EL0 使用者 程式**에서 SVC로 檔案/루프백을 호출하는 새 連接 |
| `dist/jkoros-native-rpi4.img` | 128 MiB MBR/FAT32 SD 構建映像 |
| `dist/jkoros-native-rpi4-boot.zip` | FAT32 啓動 파티션에 복사할 檔案 組值 |
| `dist/jkoros-native-aarch64-sdk.tar.gz` | 사용자용 헤더·運行 程式碼值·庫·링커 腳本值·範例 |
| `dist/manifest.json`, `build/build.json` | SHA256과 實際資料 支持值 狀態值 |

이미지는 확인된 공식 Pi 啓動 묶음에서 `start4.elf`, `fixup4.dat`, Pi4 DTB와 disable-bt overlay를 가져온다. Linux kernel/initramfs/rootfs는 넣지 않는다. 펌웨어·MicroPython·終端 字體值 라이선스와 字體值 原點值 해시도 동봉한다. 檔案 生成 스크립트는 물리 디스크에 기록하지 않는다.

예비 microSD에 構建映像 日誌記錄 도구로 `.img`를 기록하거나 FAT32 啓動 파티션 최상위에 ZIP 내용을 푼다. 構建映像 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 默認值 EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**物理硬件 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD 檔案 구성·內核值 체크섬 검사와 물리 板 啓動 검증은 별개다. MMU 使用值 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 啓動 조건을 전제로 한다. 三值 輔助值 코어는 대기시키며 한 코어만 사용한다.

## C++와 中文 API 使用值

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/檔案例.cpp -o demo.elf
python3 compile.py examples/通信範例.cpp -o network.elf
```

진입점은 `extern "C" int 開始用戶程式(int)`이다. 使用者 C++는 FP/SIMD를 사용할 數 있다. 內核值 C/Java AOT는 일반 레지스터만 사용하므로 異常 程序值條目 중 使用者 FP 상태를 건드리지 않는다. 使用者 條目分值 시 FP 상태를 초기화하고 內核值 복귀에 필요한 상태를 보존한다.

```cpp
#include "檔案ABI.h"
extern "C" int 開始用戶程式(int) {
    int 檔案 = 打開檔案("問候例.txt", 讀取寫入 | 創建條件缺失 | 截斷內容, 0600);
    if (檔案 < 0) return 1;
    const char 內容值[] = "안녕하세요";
    int 結果 = 寫入檔案資料(檔案, 內容值, sizeof(內容值) - 1);
    關閉檔案(檔案);
    return 結果 == sizeof(內容值) - 1 ? 0 : 2;
}
```

[檔案 範例](使用者/檔案例.cpp)와 [通信 範例](使用者/通信範例.cpp)首位操作數 實際資料 啓動 測試 대상이다. `檔案ABI.h`의 이름은 커널용/사용자용 構建全部 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 檔案 程序值條目 및 루프백 전달은 Java 커널에서 실행한다. `網路ABI.h`의 通訊端值 함수는 當前項目 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 內核值 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 下一項目 도구를 사용하면 **새 QEMU를 부팅해 업로드한 實際資料 바이트를 재확인한 後端值 게스트에서 執行命令**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 工具集/執行檔案.py build/jkoros-native-sdk/demo.elf
python3 工具集/執行檔案.py 範例/Hello.java "韓文文本 實參"
python3 工具集/執行檔案.py 範例/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 內核值 묶음에 포함되어 이 檔案 한도를 적용받지 않는다. **C++ 컴파일러는 宿主 SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 庫, PT_TLS, PT_INTERP, PT_DYNAMIC, 執行命令·寫入 겸용 세그먼트는 로더가 거부한다. 구체적인 調用 編號·地址 裁剪·오류는 [使用者 ABI](用戶呼叫ABI.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `提交檔案存儲裝置`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 權限值·dup/fcntl은 없다. 디렉터리와 對端值/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 最大值 512바이트, 소켓은 8개, 接收值 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. 使用者 退出程式 시 열린 檔案 서술자와 소켓을 회수한다.

## Java와 Python의 정확한 裁剪

內建 `javac`는 버전 49 `.class`를 생성하며 JVM은 支持值 명령으로 구성된 버전 45–52 클래스를 실행한다. 靜態值 函數·재귀·int/boolean/char/String·條件/迭代值·字符串 결합과 일부 檔案 스트림을 지원한다. UTF-8 문자열과 字元 리터럴, ASCII 및 현대 韓文文本 음절/組合 字母構件值 식별자를 처리한다. Unicode 標識符值 전체 表·Unicode 原始碼樹 이스케이프는 구현하지 않았다. 게스트 原始碼樹 컴파일러는 일반 物件值·異常·Thread 구문을 아직 컴파일하지 못한다. 宿主 `javac --release 8`로 만든 支持值 부분집합 클래스는 內建 JVM 0.4의 物件值·異常·Thread·UDP와 中文 API를 사용할 數 있다. Swing은 문서화한 內建 API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [內建 JVM 說明](Java運行時環境.md)이 기준이다. 상세 語言 범위는 [공유 Java 工具集 說明](../../文檔集/Java開發環境.md)을 참고하되, 그 문서의 x86 命令殼/存儲值/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 原始碼樹**를 內建 AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 函數·類別值·異常·리스트/字典·Unicode·GC·가변 精度值 정수를 제공한다. 當前項目 구성은 整數 빌드로 `float`, `complex`, `math`首位操作數 없으며 CPython 전체 표준 庫, pip, subprocess, threading, 일반 socket과 默認值 `open()` 檔案 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 物件值·모듈은 退出程式 시 회수되고 RAM 파일만 下一項目 실행에 남는다.

`import jkoros`로 下一項目 시스템 연결을 쓴다. 構建全部 SVC를 통해 內建 Java 커널에 접근한다.

| 函數 | 動作 |
|---|---|
| `stdin(limit)` | 當前項目 표준 입력에서 最大值 limit바이트(0…16384)를 bytes로 讀取結果; EOF는 빈 bytes, UART 資料 없음은 OSError(11) |
| `read(name)` | 對端值/절대 RAM 경로의 檔案 전체를 bytes로 讀取結果 |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 存儲值, 쓴 位元組值 數 發回結果 |
| `remove(name)` | RAM 檔案 삭제 |
| `rect(x, y, w, h, color)` | 선택한 實際資料 屏幕 大小 안의 矩形 繪圖; 기존 보드의 RGB32 值 |
| `ticks_ms()` | 啓動 之後狀態 毫秒, 32비트 週期值 |
| `udp_open(port)` | 127.0.0.1의 UDP 通訊端值 打開/可執行束打包; 0은 자동 硬件埠 |
| `udp_send(fd, port, data)` | 루프백 目的地址值 포트에 str/bytes 버퍼 傳送值 |
| `udp_recv(fd)` | `(bytes, 보낸포트)` 發回結果; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | 通訊端值 關閉 |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```

移植 程式碼值: [python/](Python橋接/), [使用者 Java 連接](使用者/Java橋接.c). 공식 [MicroPython 移植 指南](https://docs.micropython.org/en/latest/develop/porting.html)를 참고했다. 原始碼樹 URL·哈希檔案·라이선스는 [vendor 指南](vendor/README.md)에 기록했다.
