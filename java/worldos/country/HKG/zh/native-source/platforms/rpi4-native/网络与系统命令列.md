# 内置 커널의 네트워크와 运行系统值 命令

게스트 SSH·VNC, LAN 공개 执行命令, Pi4 GENET·DHCP 추가분은 [外部值 接通状态 指南](外部连接状态指南.md)를 먼저 참고한다. QEMU는 `sl0`, 物理硬件 GENET은 `en0`를 사용한다. 物理硬件 드라이버는 아직 보드에서 검증하지 않았다.

이 문서는 `platforms/rpi4-native`의 内置 ARM64 Java 커널용이다. Linux/OpenJDK 실행환경의 명령어와 구분한다. 새 커널을 빌드하고 重试值 부팅해야 적용된다.

셸과 Java의 实际数据 CPU 权限值, `ps`/`top`에 표시되는 单位值, 宿主·外部值 PC 连接 방법은
[执行命令 계층과 外部值 通信 审查状态](运行时与外部网络检查项.md)에 정리했다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop ARGS=--network RESOLUTION=1920x1080
# 串行值 셸만 사용할 때
make run ARGS=--network
```

게스트에서 `help`, `help system` 또는 `显示帮助 system`을 입력한다. 底端值 두 이름은 같은 동작을 하며 현지어 이름도 Tab으로 완성할 数 있다.

| 표준 命令 | 中文 命令 | 기능 |
|---|---|---|
| ipconfig, ifconfig | 아이피설정 | 实际数据 IPv4 地址·넷마스크·网关值·송수신 통계 |
| ip | IP地址 | 地址 查询值·设置, 连接 上传文件集·내리기, 路径 查询值 |
| ping | 测试响应 | 实际数据 ICMPv4 回复·손실률·왕복 时间值 |
| route | 경로표 | 직접 연결망과 默认值 网关值 |
| netstat, ss | 통신현황 | 实际数据 TCP/UDP 끝점의 地址·硬件端口·状态值·接收值 대기량 |

## IP 설정과 通信 验证

```sh
ipconfig
ip addr show
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2
아이피설정 set 10.0.2.20 255.255.255.0 10.0.2.2
ping -c 4 -W 1 10.0.2.2
测试响应 -c 4 10.0.2.2
ip route show
ip link set dev sl0 down
ip link set dev sl0 up
netstat
```

초깃값은 `sl0`, `10.0.2.15/24`, 网关值 `10.0.2.2`第三操作数. 地址 설정은 재부팅 전까지 유지된다. TCP/UDP 끝점이 열려 있으면 `error -16`으로 변경을 거부한다. 먼저 `ftpd stop` 등으로 서비스를 닫고 프로그램의 소켓을 닫는다. 잘못된 地址·비연속 넷마스크·다른 망의 관문은 적용하지 않는다.

`ip`는 顶端值 구문의 부분집합이며 Linux iproute2 전체 문법을 구현하지 않는다. `ping`은 IPv4 数字值 地址, `-c 1..100`, `-W 1..10`초를 지원한다. 名称 解析值·IPv6는 미지원이며 GENET의 DHCP는 外部值 接通状态 구현에 추가했다. 응답이 없으면 退出代码 1, 잘못된 인수는 2, 用户 취소는 130이다. `ping ...; echo $?`로 확인한다.

QEMU 外部值 통신은 UART SLIP→NAT 연결을 사용한다. `--network` 없이도 内置 地址 查询值·설정은 가능하지만 外部值 응답은 오지 않는다. 默认值 NAT는 `10.0.2.0/24`第三操作数. 物理硬件 Pi의 GENET 드라이버는 별도로 추가했으며 板 검증이 필요하다. Wi-Fi는 미지원이다.

주소를 `.20`으로 바꾼 后端值 FTP 등 **외부에서 들어오는 连接**直到 사용할 때는 执行命令 시 前向值 대상도 지정한다.

```sh
make desktop ARGS="--network --guest-ip 10.0.2.20"
# 부팅한 게스트 안에서
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2
ftpd start
```

`--guest-ip`는 NAT 前向值 대상이며 게스트의 주소를 자동 설정하지 않는다. FTP 控制值 포트는 宿主 `127.0.0.1:2121`, 수동 데이터 포트는 50000~50007이다. 여러 VM을 함께 띄울 때는 `--network-host 127.0.0.2 --port 5903`처럼 宿主 루프백 주소와 VNC 포트를 구분한다. FTP와 Java/C 소켓은 변경된 实际数据 게스트 IP를 사용한다.

## 状态值 조회의 의미

`ps`는 内核值/命令壳, 살아 있는 협력 任务, 最大值 4개의 EL0 用户 세션을 표시한다. 다른 터미널에 열린 `vi` 등을 `SUSPENDED` 상태로 볼 数 있다. `MAPPED_KiB`는 实际数据 페이지 已映射值, `RUN_ms`는 해당 세션이 선택된 동안의 경과 时间值(시스템 调用 头文件)이며 정밀 CPU 사용률이 아니다. `top -n 1`은 한 번, `top -n 2`는 두 번 표시한다. 리다이렉션된 `top`의 기본값은 한 번이다.

`free`의 AOT 堆值 사용량은 할당기에서 읽는다. 힙은 内核值 BSS에 포함되므로 각 줄을 构建全部 더하면 중복된다. 고정 예약 영역과 用户 페이지 매핑을 표시하며 Linux의 가용 RAM 계산이나 宿主 内存数据 통계를 꾸며서 표시하지 않는다.

`df`는 RAM 파일시스템의 文件 64칸 × 16 KiB를 표시한다. 文件 하나는 논리 크기와 별도로 16 KiB 칸을 예약한다. `Data`는 实际数据 数据 长度 总计值, `Reserved`는 使用值 중인 槽条目 용량이다. 삭제 후에도 열린 파일은 最后项目 참조를 닫을 때까지 계산한다. SD/영구 디스크 사용량은 아직 지원하지 않는다.

## 종료와 有效性校验

게스트에서 `poweroff` 또는 `电源关闭侧`를 입력한다. FTP·套接字值·用户 세션을 닫은 后端值 BCM PM 退出程序 절차를 실행한다. RAM 파일은 재부팅 之后状态 보존되지 않는다. QEMU에서는 게스트의 `SHUTDOWN / guest-shutdown` 이벤트와 是否常规 종료를 검증한다. 物理硬件 Pi 4 전원 회로 동작은 아직 시험하지 않았다.

实现 근거: [Linux BCM watchdog의 power-off 절차](https://github.com/torvalds/linux/blob/master/drivers/watchdog/bcm2835_wdt.c), [QEMU BCM PM 设备](https://github.com/qemu/qemu/blob/master/hw/misc/bcm2835_powermgt.c).

```sh
make test-system
# 结果: build/verification/system-tools/report.json 및 serial.log
```

이 시험은 잘못된 IP 拒绝值, 实际数据 ICMP 成功值·시간초과, 连接 up/down, IP 更改值 之后状态 FTP 송수신, df 生成·삭제, 堆值 计算结果, 다른 터미널의 vi PID·内存数据, top 刷新·退出程序, 韩文文本 命令·Tab, 게스트 poweroff를 검사한다.

`java/worldos/国家值/국가코드` 판에는 같은 기능과 국가별 命令 대응표 `native-commands.json`이 들어간다. 표준 명령은 모든 판에서 유지한다. 새 현지어 이름은 기능 중심 제안이며 현지 화자·어원 검토를 완료한 표준 용어는 아니다. 미번역 항목은 대응표의 `pending`에 명시한다.
