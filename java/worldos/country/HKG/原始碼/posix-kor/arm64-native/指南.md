# 內建 ARM64 Java 커널의 C/C++ 檔案·루프백 連接

이 디렉터리는 `platforms/rpi4-native` 內建 內核值 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`頭文件/檔案ABI.h`는 中文 함수명과 `extern "C"` ABI를 제공한다. `連接.c`는 內核值 안에서 AOT Java 檔案 메서드에 직접 연결하고, `用戶橋接.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. 實際資料 檔案 처리는 `記憶體檔案集.java`, 루프백 數據報 처리는 `環回網路.java`, 연결형 흐름은 `流網路.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 內核值 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`第三操作數. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·浮點型分值 操作值·檔案·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

支持值: `打開檔案`, `讀取檔案資料`, `寫入檔案資料`, `關閉檔案`, `尋道檔案`, `移除檔案條目名稱`, `設定檔案長度`, 輔助值 函數 `檔案大小`. 錯誤 시 -1과 작업별 `錯誤編號`를 반환한다. `提交檔案存儲裝置`은 RAM 파일이므로 ENOSYS를 반환한다. 檔案 16개, 각 16384바이트, 名稱 63바이트, 描述符條目 16개이며 RAM 디렉터리·對端值/절대 경로를 제공한다. 權限值/영속 저장은 없다.

사용자용 `頭文件/網路ABI.h`는 實際資料 中文 함수와 독립 구조체를 선언한다.
`創建端點`, `綁定地址`, `發送數據報資料/接收`, `連接網路/等待/接收`는
`用戶橋接.c`에서 SVC를 호출하며 宏值 별칭이 아니다. `struct 互聯網通訊端地址`의
`地址族`, `埠編號`, `互聯網地址.地址值`을 사용한다. 상수는 enum의
`互聯網族`, `數據報通訊端`, `數據報通訊協定`, `流網路`, `流傳輸通訊協定`이다.
中文·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. 外部值 통신은 內建 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. 實際資料 Pi 4 GENET 드라이버는 미지원이다.
소켓도 實際資料 函數 `關閉檔案`로 닫는다.
