# vlastiti ARM64 JVM 0.4와 hrvatski biblioteka

hrvatski 통신·iznimka 사용법은 [hrvatski Java API](한국어자바/안내.md), FUNCTION_VALUE·varijabla_VALUE·Datoteka 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

JAR Izvrši_naredba, vanjski_VALUE IPv4 TCP/UDP, 별도 정적 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 objekt_VALUE·Thread·Swing은 JVM 경로의 기능이며 AOT Podrška_VALUE 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 Izvrši_naredba**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK poduka_VALUE biblioteka 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 poduka_VALUE·정적 postupak_VALUE 중심이던 실행기를 objekt_VALUE·biblioteka Izvrši_naredba 기반으로 넓힌 것이다.

## 실행과 programski_prevesti_izvor

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# vlastiti jezgra_sustava_VALUE 안에서 izvor_stablo programski_prevesti_izvor → class Izvrši_naredba, hrvatski API 호출
python3 Alati/Izvrši_Datoteka.py 시험/자바/한글소스.java

# objekt_VALUE·iznimka 등은 domaćin JDK로 Java 8 class를 만든 후 vlastiti 커널에서 Izvrši_naredba
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 Alati/Izvrši_Datoteka.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 Prijenos_VALUE
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 Alati/Izvrši_Datoteka.py build/my-java/객체시험.class \
  --include build/my-java/podloga_VALUE.class --include build/my-java/grana_VALUE.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.poduka_VALUE.class`라는 RAM Datoteka 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.poduka_VALUE`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.poduka_VALUE`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar Datoteka.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 hrvatski 클래스만 찾는다. 배포 hrvatski biblioteka JAR는 domaćin javac의 classpath로 사용하며, 같은 클래스가 korisnik JVM ELF에도 Čitaj 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 정적 postupak_VALUE, int/boolean/char/String, uvjet·sprint_VALUE, niz_VALUE 결합, 일부 Datoteka 스트림 등의 **vlastiti 부분집합 kompilator**다. objekt_VALUE deklaracija·상속·try/catch·Thread uporaba_VALUE 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 vlastiti JVM에서 실행한다. hrvatski API 중 Izlaz·문자 스칼라 FUNCTION_VALUE·Datoteka Čitaj/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] Argumenti) throws Exception {
        hrvatski.vlastiti.Izlaz.zapisivanje_red("안녕하세요😀");
        hrvatski.vlastiti.Izlaz.수쓰기(hrvatski.vlastiti.문자.točka_koda_COUNT("한글😀"));
        hrvatski.vlastiti.Datoteka.Zapisuj("인사.txt", "한글 Datoteka😀");
        hrvatski.vlastiti.Izlaz.zapisivanje_red(hrvatski.vlastiti.Datoteka.Čitaj("인사.txt"));
    }
}
```

## hrvatski API

독립 패키지 **`hrvatski.vlastiti`**를 사용한다. Linux판 `hrvatski.자바`가 요구하는 NIO/Swing/HTTP API를 vlastiti 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 poduka_VALUE Ime·postupak_VALUE·Argumenti·vrijednost_polja·Datoteka 이름에 한국어를 사용한다. 표준 Java poduka_VALUE 이름은 호환성을 위해 보존한다.

| poduka_VALUE | 공개 기능 | 이름의 의미 |
|---|---|---|
| Izlaz | Zapisuj, zapisivanje_red, 수쓰기 | Izlaz(出力): 내용을 바깥으로 내보냄 |
| 문자 | 길이, 같음, zalijepiti_SMS, izrezati_VALUE, rastavljati_cijeli_broj/zapisivanje_cijeli_broj_VALUE, točka_koda_COUNT, kodirati/dešifrirati_podaci | 문자(文字), šifriranje_VALUE(符號): 글의 단위와 그 값을 바이트로 나타내는 filtar_VALUE |
| Datoteka | Čitaj/Zapisuj(String Ime), 바이트읽기/zapisivanje_bajt_VALUE | 널리 쓰는 korisnik 용어를 보존; RAM 자료의 Ime |
| unos_Popis | 더하기, Čitaj, REPLACE_VALUE, izbrisati_unos, Veličina, 비었는가, očistiti_Sadržaj | unos_Popis(目錄): 순서가 있는 unos_VALUE 모음 |
| rječnik | 넣기, FIND_unos, 있는가, izbrisati_unos, Veličina, očistiti_Sadržaj | rječnik(辭典): 찾는 말인 열쇠에 값을 mapiranje_VALUE |
| 작업 | Pokreni(실행할일), 기다리기(작업가닥), YIELD_obaveza, 살아있는가 | 작업 nit_VALUE: 한 program_f5044b9b 안의 Izvrši_naredba tok_VALUE |
| 통신 | Otvori, slati, primiti, TIMEOUT, Zatvori | 통신(通信), datogram(電文), prebaciti_VALUE: podaci 교환·메시지·포트의 역할 |
| 화면 | pravokutnik, izbrisati_unos | 화면(畫面): stvaran_podaci 그림을 표시하는 면 |

이 명명은 redovno_artikl 기능을 설명하는 용어 선택이다. 기존 한국어에 없던 역사적 어원을 만들어 주장하지 않는다. naziv_datoteke_SMS·식별자는 UTF-8 소스로 보관한다. `문자.dešifrirati_podaci`는 잘못된 UTF-8에 IllegalArgumentException을 던지며, `kodirati`는 짝이 없는 서로게이트를 `?`로 바꾼다. `Datoteka.Čitaj`는 엄격한 UTF-8 복호화를 적용한다. 화면 색은 `빨강 | (초록 << 8) | (파랑 << 16)` 형식이다.

## Izvrši_naredba 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(hrvatski poduka_VALUE 포함), class당 16 KiB·konstanta_VALUE 풀 511항목, 전체 postupak_VALUE/vrijednost_polja 각각 512개. postupak_VALUE kod_VALUE 8 KiB, lokalno_doseg varijabla_VALUE·피연산자 operand_hrpa 각각 128슬롯, Argumenti 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 Izvrši_naredba 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- objekt_VALUE 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 stvaran_podaci 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 Datoteka·대형 niz_VALUE·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 Naredba 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 Prozor SWITCH_MODE 시 중단·재개한다. 일반 server_VALUE·계산의 무제한 실행은 아직 없다. 미지원 Naredba·resurs_VALUE 부족은 명시적인 오류로 종료한다.
- RAM Datoteka 최대 64개, 파일당 16384바이트, PUTANJA UTF-8 63바이트. RAM 디렉터리와 ravnopravan_član_VALUE/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 hrvatski class는 RAM Datoteka 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 redovno_artikl 경로에서 izvor_stablo·poduka_VALUE·podaci 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 vanjski_VALUE IPv4를 제공한다. stvaran_podaci GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. datogram 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 Izvrši_naredba 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 ARRAY_VALUE, 완전한 ARRAY_VALUE 공변성·인터페이스 sloj_VALUE 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/Šifriraj_podaci/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 Podrška_VALUE 부분집합은 아래 및 개발 매뉴얼을 참고한다. poduka_VALUE Datoteka 전체 검증기·pristup_unos dozvola_VALUE/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 zaštititi_VALUE 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM VALUE/potvrditi/poduka_VALUE 로더와 iznimka 모델 → 영속 VFS·mmap·Sat·원자 operacija_VALUE·stvaran_podaci 스레드/sinkronizacija ABI → OpenJDK java.base 및 native biblioteka 이식 → uređaj_VALUE 네트워크·TCP/IP → Prozor 시스템/font_VALUE/입력기·java.desktop → Java SE 호환성 시험. redovno_artikl vlastiti JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## potvrditi

`Alati/자바가상기계시험.py`는 같은 Java 8 class 파일의 출력을 domaćin OpenJDK `-Xverify:all`과 QEMU raspi4b vlastiti 커널에서 비교한다. objekt_VALUE/상속/인터페이스·switch·ARRAY_VALUE, iznimka/finally, 컬렉션/GC, Thread/zaključati_VALUE, hrvatski UTF-8/Datoteka/컬렉션, stvaran_podaci UDP 루프백/TIME_VALUE 초과, 게스트 한글 izvor_stablo programski_prevesti_izvor, ARRAY_VALUE TYPE_VALUE/instanca_VALUE/Datoteka 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 Datoteka odbiti_VALUE 시험을 실행한다. UDP akcija_korijen 실행에는 domaćin 루프백 소켓 권한이 필요하다.

`Alati/부팅시험.py`는 jezgra_sustava_VALUE zaštititi_VALUE/회귀 시험과 별도로 hrvatski Java 화면 API가 stvaran_podaci 픽셀을 그렸는지도 QMP 화면 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. stvaran_podaci Pi4 하드웨어 부팅 시험과 전체 JDK 호환성 시험 결과는 아니다.


## JVM 0.3: 네트워크와 GUI nastavak_VALUE

`Socket`/`ServerSocket` generirati·Spoji_se·accept·양방향 InputStream/OutputStream·close·EOF·TIME_VALUE 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 vanjski_VALUE znamenka_VALUE IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 završiti_razgovor_p 16개, Java 루프백 버퍼 1024바이트, vanjski_VALUE TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. 대화형 이벤트 대기는 Izvrši_naredba 기한을 갱신하고 Terminal SWITCH_MODE 시 프로세스 상태를 Store_VALUE·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

hrvatski `Prozor`, `widget`, `연결통신` 클래스를 배포 JAR와 vlastiti JVM 내장 자원에 추가했다. 상세 postupak_VALUE·제한·izvor_stablo·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## hrvatski 객체의 직접 Izvrši_naredba

`Prozor`, `Natpis`, `tekstno_polje`, `gumb`, `događaj_red_čekanja`, `akcija_obavijest`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. vlastiti JVM의 objekt_VALUE generirati,
oblik_VALUE 검사, 화면 호출, Događaj 큐, nit_VALUE 스케줄러에 hrvatski 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 Izvrši_naredba 경로도 유지한다.
hrvatski 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

vlastiti 실행기의 hrvatski 진입점은 `public static void Pokreni()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 hrvatski 진입점을 우선한다.
명령행 인수는 `실행인수.artikl_COUNT()`와 `실행인수.Tekst(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. 정적 Datoteka 예제는 게스트
javac로도 컴파일하며, GUI/nit_VALUE 소스는 domaćin `javac --release 8`을 사용한다.
직접 GUI/nit_VALUE API는 vlastiti JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
