# engos 기능 대응표

이 표는 기존 `원천/`의 객체 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [실제 부팅 기능과 한계](../os/안내.md)를 따로 기록한다.

## Java 관리 계층 구현 완료

| engos 영역 | JHtiOS 구현 |
|---|---|
| memorymanager, phymem | `기억공간관리자` 정렬 할당·해제·병합 |
| paging, virtmem | `쪽관리자` 주소 공간·쪽 연결·COW·개인 쓰기 |
| gdt, tss | `전역서술자표`, `작업상태구역` |
| interrupt | `개입중단관리자` 등록·활성화·분배 |
| process, scheduler, thread | `과정`, `배정기` PID·fork·wait·상태 전환 |
| systemcall/POSIX 1단계 | 읽기·쓰기·열기·닫기·seek·dup·fcntl·접근·작업목록·사용자/무리 ID·동기화·brk·fork·wait·exec·stat·uname 의미 |
| ATA | `고급기술결합장치` 512바이트 구역 읽기·쓰기 |
| MSDOS partition | `기본분할영역표` MBR 검증과 네 항목 해석 |
| FAT 공개 파일 계층 | `파일체계`, `파일서술자표` 읽기 전용 파일과 과정별 FD |
| ELF | ELF32 검사, 구역 범위 검사, 적재, NOBITS 영 초기화, 시작 주소·인자·환경 반영 |
| keyboard, mouse | `입력관리자`의 손실 계수 포함 사건 대기열 |
| timer | `시계` 틱과 시간 변환 |
| PCI | `주변장치연결관리자` 검색 결과와 장치 선택 |
| VGA/text mode | `문자화면` 80x25 출력과 스크롤 |
| Ethernet/ARP/IPv4/ICMP/UDP/TCP | `통신망도구`, `통신망계층` 틀 검사·검사합·규약/포트 분배 |

## 기존 객체 기반 관리 커널 전체를 부팅하기 위해 남은 연결

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/장치 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot 진입, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 문맥 저장
- 실제 PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA 고리
- Java 객체·배열 배치, 예외, 정적 초기화, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT 단계
- FAT 디스크 구역을 실제 ATA 장치와 연결하는 입출력 접착 계층

위 관리 계층은 engos 기능의 Java 관리 구현과 호스트 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot 진입, 정적 초기화·정수 배열, VGA/직렬/PS2, 명령해석기, 사용자 ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 호스트 루프백 패킷 왕복을 검증했다. 위 표의 객체 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
