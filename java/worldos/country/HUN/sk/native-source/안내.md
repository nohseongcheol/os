# JHunOS

v_termíne_splatnosti_položka vlastné ARM64 배포판은 [LICENSE](LICENSE)의 COSL 상업 조건을 유지한다. 제3자 라이선스의 권리는 별도로 보장하며, 배포 시 zdroj_strom·재연결 자료를 포함하는 절차는 [COSL 배포 안내](platforms/rpi4-native/COSL배포안내.md)에 있다.

vlastné ARM64 판의 `ipconfig`/`ip`, `ping`, `ps`/`top`, `free`/`df`, `poweroff`와 Slovenský 명령은 [네트워크·operačný_systém_VALUE Príkaz 안내](platforms/rpi4-native/네트워크와체계명령.md)를 참고한다. 새 커널을 부팅한 BACK_VALUE `help system`으로 볼 수 있다.

Raspberry Pi 4 **vlastné Java ARM64 jadro_VALUE**은 [vlastné Pi4 안내](platforms/rpi4-native/안내.md)에 있다. Linux 없이 부팅하며 GUI Terminál·vi, vlastné JVM의 Swing 일부 API, TCP/UDP·FTP, 게스트 TinyCC·MicroPython, C/C++의 posix-kor 호출을 제공한다. [Slovenský Java 통신·výnimka API](platforms/rpi4-native/한국어자바/안내.md)와 [Slovenský zdroj_strom 명명](platforms/rpi4-native/명명/안내.md)을 지원한다. [vlastné SSH·VNC 및 GENET 드라이버](platforms/rpi4-native/externý_kontakt_sprievodca.md)를 포함하며, 네트워크는 QEMU의 UART SLIP 경로로 검증했다. skutočný_údaje Pi 4 GENET 동작은 미검증이고, USB vstup_VALUE·영속 저장과 전체 OpenJDK·Swing은 아직 Podpora_VALUE klip 밖이다.

Raspberry Pi 4용 Linux·OpenJDK 실행판과 používateľ 환경 premiestniť_VALUE 기능은 [라즈베리파이 실행판](platforms/rpi4/README.md)에 있다. skutočný_údaje ARM64 JDK/JRE와 시스템·používateľ zostava_IMAGE zostava_systém 경로를 제공한다. 기존 vlastné x86 커널과는 별도 Vykonať_príkaz 기반이다. 일반 Java `.class`/JAR의 Vykonať_príkaz Súbor 생성은 [OpenJDK Vykonať_príkaz Súbor](compiler/OpenJDK-spustiteľný_súbor.md), Slovenský API는 [Slovenský Java knižnica](한국어자바/안내.md)를 참고한다.

`jkoros`는 `engos`의 기능을 Java 관리 커널로 옮기는 프로젝트다. 프로젝트가 소유하는 Java funkcia_VALUE, 변수, formát_VALUE 및 Java Súbor 이름은 한국어로 작성한다. 표준 Java 실행기의 `main`, Java 표준 knižnica formát_VALUE, x86 부트 ABI 등 externý_VALUE 계약은 보존한다. vlastné ARM64 실행기는 Slovenský `Spustiť_2()`도 진입점으로 지원하며, Slovenský GUI·작업 가닥을 JVM에 직접 구현했다. vlastné ARM64 C 연결부·Python 도구와 공용 x86·ARM64 AOT 번역기의 vlastné 이름도 한국어로 작성한다. 이전 경로의 호환 položka_bod, OpenJDK 보조 도구와 Linux verzia_VALUE 도구에는 영어 이름이 남아 있고 [명명 원칙·말의 근거·전체 ZDROJ 검토 klip](platforms/rpi4-native/명명/안내.md)를 별도로 기록한다.

## v_termíne_splatnosti_položka 구현

아래 목록은 기존 `starší_zdroj/`의 JVM 관리 커널에 대한 것이다. skutočný_údaje 네이티브 커널의 범위는 `os/안내.md`에서 별도로 설명한다.

- zarovnať_VALUE 할당과 해제를 지원하는 Pamäť_oblasť 관리자
- adresa adresa_oblasť, strana_VALUE Pripojiť, Zápis 시 inštancia_VALUE(COW)
- Proces_VALUE identifikátor_VALUE, Pripraviť 대기열, fork/wait Stav_VALUE
- 과정별 Súbor 서술자, open/read/seek/dup/close

- 키보드·마우스 vstup_VALUE Udalosť 대기열

세부 mapovanie_VALUE 범위와 아직 필요한 네이티브 연결은 [기능 대응표](문서/funkcia_mapovanie.md)에 기록한다.

## 빌드와 시험

새 네이티브 구현은 `compiler/`와 `os/`에 있다. 기존 `starší_zdroj/`의 JVM 관리 커널은 그대로 보존하며, 두 구현의 시험과 기능 범위는 서로 다르다.

```sh
cd /home/user/jkoros
make                 # 네이티브 계산 예제 + Java jadro_VALUE ELF
make iso             # os/build/kernel.iso
make run             # QEMU 직렬 단말; help vstup_VALUE (종료는 Ctrl+A, X)
make run-gui         # ISO를 QEMU 화면/PS2 키보드로 Vykonať_príkaz
make vbox            # 전용 VirtualBox VM 자동 generovať·Vykonať_príkaz (GUI)
make vbox-status     # VirtualBox Stav_VALUE·ISO·직렬 LOG_RECORD Cesta overiť
make test-vbox       # VirtualBox program_spúšťač Stav_VALUE Proces_VALUE_položka 시험 (skutočný_údaje VM zmeniť_VALUE 없음)
make test            # kompilátor 시험 + ELF/ISO 부팅 및 Príkaz vstup_VALUE 시험
make apps            # 독립 používateľ ELF program_f5044b9b zostava_systém
make test-network    # používateľ MODE_VALUE·UDP 왕복·Pamäť_údaje chrániť_VALUE 시험
make test-java       # 게스트 javac/JVM + OpenJDK 양방향 교차 Vykonať_príkaz 시험
make posix-kor       # Slovenský C 헤더와 skutočný_údaje jadro_VALUE 호출 knižnica
make test-posix      # Súbor/UDP/Store_VALUE/Java Súbor vstup_a_výstup 시험
make -C os run-store # 전용 Store_VALUE 매체로 QEMU 부팅
make legacy-test     # 아래 기존 JVM 관리 커널의 47개 시험
```

`compiler/`는 호스트의 `javac`를 문법·Typ_VALUE 검사 전단으로 사용하고 vlastné 바이트코드→x86 변환기로 ELF32 기계어를 만든다. 빌드할 때는 JDK가 필요하지만 생성된 커널과 ELF는 externý_VALUE JVM 없이 실행된다. 전체 Java, objekt_VALUE 모델, 표준 라이브러리와 기존 관리 jadro_VALUE 전체의 AOT 변환은 아직 지원하지 않는다. 자세한 Podpora_VALUE 문법과 명령은 [kompilátor 안내](compiler/안내.md), skutočný_údaje 부팅 기능과 한계는 [네이티브 operačný_systém 안내](os/안내.md)를 참고한다.

네이티브 셸에 vlastné 제한형 `javac`와 `java`를 추가했다. `edit Demo.java`로 소스를 입력하고 `.save`로 저장한 BACK_VALUE `javac Demo.java`, `java Demo`로 **게스트 내부에서 컴파일하고 Vykonať_príkaz**할 수 있다. predvolená_hodnota 예제는 `javac Hello.java`, `java Hello`다. 파일은 RAM에서 동작하며, 전용 Store_VALUE 매체를 연결하면 `sync`로 재부팅 후에도 보존할 수 있다. **OpenJDK/JDK 전체 이식은 아니며**, 단일 lekcia_VALUE·정적 funkcia_VALUE·celé_číslo·reťazec_VALUE·podmienka/반복문과 일부 표준 호출을 지원한다. Podpora_VALUE klip, externý_VALUE Súbor 적재와 시험은 [Java 개발 환경 안내](문서/자바개발환경.md)에 있다.

네이티브 셸에서 `apps`, `run hello first second`, `net`, `run netcheck`를 사용할 수 있다. 독립 ELF를 ring 3에 적재하고 `int 0x80` 호출을 통해 Výstup·Argumenty·UDP 네트워크를 제공한다. 별도 hostiteľ 터미널에서 `python3 os/Nástroje/ozvena_údaje.py --port 9000`을 실행한 BACK_VALUE 게스트에서 `run udp 10.0.2.2 9000 hello`로 skutočný_údaje 왕복을 확인한다. 새 program_f5044b9b register_položka, API 및 제한은 [používateľ Vykonať_príkaz·네트워크 안내](os/používateľ/안내.md)를 참고한다. v_termíne_splatnosti_položka QEMU RTL8139·정적 IPv4·UDP 전용이며 TCP/DNS는 미지원이며, 전용 IDE Store_VALUE 형식과 POSIX Súbor/UDP 일부 기능을 추가했다.

`make vbox`는 `jkoros operating system` 전용 VM을 만들고 디스크 없이 ISO로 부팅한다. Vykonať_príkaz 중이면 유지하고, Store_VALUE·일시정지 상태이면 재개하며, 꺼져 있을 때만 새 ISO를 빌드해 연결한다. VirtualBox에서 부팅과 셸의 používateľ program_f5044b9b 실행을 확인했다. 다만 v_termíne_splatnosti_položka VirtualBox용 네트워크 드라이버는 없어 네트워크 장치를 비활성화한다. UDP 시험에는 `make run`을 사용한다. 상태별 동작과 새 zostava_systém 반영 방법은 [VirtualBox Vykonať_príkaz 안내](문서/가상상자실행.md)에 있다.

기존 관리 커널만 시험하려면:

```sh
cd /home/user/jkoros
make -f Create_položka.mk 검사
make -f Create_položka.mk hostiteľ
```

`hostiteľ`는 여전히 JVM 관리 계층의 Akcia 시험이다. `make -f Create_položka.mk zostava_IMAGE`는 새 `os/`의 제한형 네이티브 jadro_VALUE ISO를 만든다. 기존 `starší_zdroj/`의 systém_súborov·Proces_VALUE·sieť_Vrstvy 구현 전체를 이 ISO에 이식했다는 의미는 아니다.

Slovenský funkcia_VALUE·변수·Súbor 이름과 skutočný_údaje C API는 [posix-kor](posix-kor/안내.md)에 있다. 게스트 Java에서는 `FileInputStream`·`FileOutputStream`의 단일 Byte_VALUE 입출력도 지원한다. 전체 POSIX·OpenJDK·Swing 지원으로 확대된 것은 아니다.

externý_VALUE 배포용 `pack.sh` / `unpack.sh`와 자동 의존성 복원은 [배포 안내](distribution/README.md)를 참고하세요.
