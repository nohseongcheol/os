# 셸에서 실행하는 uporabnik 프로그램과 UDP

게스트에서 일반적인 `main(String[] args)` 형식의 소스를 직접 작성하고 컴파일하려면 [제한형 Java 개발 환경 안내](../../문서/자바개발환경.md)를 참고한다. 아래의 네이티브 ELF 개발과 별도로 `javac FILE.java`, `java CLASS`를 제공한다.

## 바로 Izvedi_ukaz

gostiti Terminal 1:

```sh
cd /home/user/jkoros
python3 os/Orodja/odmev_podatki.py --port 9000
```

이 서버는 `127.0.0.1`에만 바인딩한다. zunanji_VALUE 연결을 받도록 방화벽이나 strojna_oprema_vrata 전달을 변경하지 않는다. Ctrl+C로 종료한다.

gostiti Terminal 2:

```sh
cd /home/user/jkoros
make run
```

게스트의 `jkoros>` 프롬프트에 입력:

```text
apps
run hello first second
net
run netcheck
run udp 10.0.2.2 9000 hello
run stress 9000
```

- `hello`: 독립 Java ELF 실행과 dejanski_podatki CPU dovoljenje_VALUE `ring 3`, Argumenti Izpis.
- `netcheck`: vrata_VALUE 중복, 잘못된 ročica_VALUE/kazalec/길이, 비차단 받기와 čas_VALUE 초과 확인.
- `udp`: IPv4 naslov·cilj_VALUE vrata_VALUE·한 Word_VALUE 메시지를 받아 UDP로 보내고 같은 응답을 확인. `UDP ECHO PASS`, `Exit: 0`이면 성공.
- `stress`: gostiti `10.0.2.2`의 Dodeli_VALUE 창구와 1,023/1,024바이트 데이터그램을 24회 왕복. sprejeti_sprejemati_prejeti_prejemati_VALUE Loop_VALUE 경계를 여러 번 지난다.

`make run`/`run-gui`는 `-netdev user,id=net0 -device rtl8139,netdev=net0`을 사용한다. sprotno_element 주소는 게스트 `10.0.2.15/24`, prehod_VALUE `10.0.2.2`로 고정돼 있다. QEMU uporabnik 네트워크의 gostiti dostop_vnos 주소를 사용한 예제다. 다른 네트워크 설정에는 맞춰 수정해야 하며 자동 DHCP는 없다. NIC 없이 실행하려면 `make -C os run NET_ARGS='-net none'`을 사용한다. 이때 aplikacija_f5044b9b 실행은 되지만 UDP 열기는 `-19`로 실패한다.

## 새 Java aplikacija_f5044b9b dodati_vnos

`예제/내프로그램.java`를 Naprej_element 형식으로 만든다. 진입점은 Argumenti 없는 `static int` 또는 `static void` 함수다. 인수는 uporabnik API로 조회한다.

```java
public final class 내프로그램 {
    public static int Zaženi() {
        uporabnik.Pisanje("My program is running in user mode.\n");
        return 0;
    }
}
```

`os/uporabnik/aplikacija_f5044b9b.mk`에 추가한다.

```make
APP_NAMES += mine
APP_SOURCE_mine := uporabnik/예제/내프로그램.java
APP_ENTRY_mine := 내프로그램.Zaženi
```

여러 Java 파일을 쓰면 `APP_SOURCE_mine`에 공백으로 모두 나열한다. `uporabnik/deklaracija/uporabnik.java`는 자동으로 함께 컴파일한다.

```sh
cd /home/user/jkoros
make iso
make run
```

새로 부팅한 셸에서 `run mine`을 실행한다. 이미 Izvedi_ukaz 중인 VM에는 graditev_sistem 결과가 자동 반영되지 않는다. aplikacija_f5044b9b 이름은 sprotno_element 셸의 ASCII 입력 제한에 맞춘 1~15자의 소문자 이름이며 Java Razred_VALUE·FUNCTION_VALUE·변수에는 한국어를 쓴다. 최대 32개 aplikacija_f5044b9b, 한 Izvedi_ukaz 파일은 최대 2MiB다.

독립 ELF만 컴파일할 수도 있다.

```sh
cd /home/user/jkoros
python3 compiler/prevajalnik.py --target user --entry 인사.Zaženi \
    -o os/build/apps/hello.elf os/uporabnik/deklaracija/uporabnik.java os/uporabnik/예제/인사.java
```

`--target user`는 **jkoros 전용 ABI**다. Linux 대상과 시스템 호출 번호가 다르므로 gostiti 터미널에서 직접 실행하면 안 된다. `.class`는 별도 `java CLASS` 명령의 Podpora_VALUE izrezek 안에서 실행한다. `.jar`와 일반 Linux Izvedi_ukaz 파일은 지원하지 않는다.

## uporabnik 네트워크 API

선언은 `deklaracija/uporabnik.java`에 있다. `poslati_podatki`/`sprejeti_sprejemati_prejeti_prejemati_podatki`의 `int[]` element_element 한 개는 bajt_VALUE 하나(0~255)를 나타낸다. 한 데이터그램의 최대 podatki 길이는 1,024바이트다.

```java
int ročica_VALUE = uporabnik.odprto_mreža(0); // 0: 임시 lokalen_krajeven_obseg UDP vrata_VALUE 자동 izbor_VALUE
int[] podatki = new int[32];
podatki[0] = 'H'; podatki[1] = 'i';
int 보낸길이 = uporabnik.poslati_podatki(ročica_VALUE, 0x0a000202, 9000, podatki, 2);
int 받은길이 = uporabnik.sprejeti_sprejemati_prejeti_prejemati_podatki(ročica_VALUE, podatki, 1500);
uporabnik.Zapri_mreža(ročica_VALUE);
```

dejanski_podatki 프로그램에서는 Odpri·poslati·받기의 음수 반환값을 각각 검사한다. 완성된 예제는 `예제/자료통신.java`에 있다. `sprejeti_sprejemati_prejeti_prejemati_podatki`의 počakaj_VALUE 시간은 0~2,000밀리초이며 0은 즉시 반환이다. 받은 데이터그램이 배열보다 크면 해당 데이터그램을 버리고 `-90`을 반환한다. 창구당 sprejeti_sprejemati_prejeti_prejemati_VALUE 대기열은 한 개뿐이므로 dodati_vnos 도착분은 버린다. `보낸주소`와 `보낸창구`로 마지막으로 받은 상대를 조회한다.

| 반환값 | 의미 |
| --- | --- |
| 0 이상 | ročica_VALUE·Proces_VALUE_vnos 길이·성공 등 해당 함수의 REZULTAT |
| -5 | naprava_VALUE poslati_VALUE napaka_VALUE |
| -9 | 잘못되었거나 닫힌 통신 ročica_VALUE |
| -11 | 비차단 받기에서 도착한 podatki 없음 |
| -14 | uporabnik kazalec/ARRAY_VALUE izrezek NAPAKA |
| -19 | Podpora_VALUE NIC 없음 |
| -22 | vrata_VALUE/počakaj_VALUE čas_VALUE/Argumenti VALUE NAPAKA |
| -24 | 열린 mreža_vrata 4개 한도 |
| -38 | 알 수 없는 시스템 호출 |
| -90 | podatki 또는 sprejeti_sprejemati_prejeti_prejemati_VALUE ARRAY_VALUE Velikost 문제 |
| -98 | lokalen_krajeven_obseg vrata_VALUE INDEX 중복 |
| -101 | 지원하지 않는 cilj_VALUE naslov |
| -110 | ARP·naprava_VALUE·sprejeti_sprejemati_prejeti_prejemati_VALUE čas_VALUE 초과 |

IP 주소는 상위 바이트부터 표기한 32비트 값이다. `10.0.2.2`는 `0x0a000202`이다. 주소를 반환하는 함수는 kodiranje_VALUE 있는 Java `int`의 bit_VALUE 패턴을 사용하므로 상위 비트가 1인 정상 IP 주소가 음수로 보일 수 있다. 단순히 모든 API 반환값의 부호를 오류로 판단하면 안 된다.

## Izvedi_ukaz 경계와 시스템 호출

```text
lupina run → JKAP에서 ELF preveriti_veljavnost·적재 → ring 3 uporabnik aplikacija_f5044b9b
                                 ↓ int 0x80
                      kazalec 검사 → Java jedro_VALUE API → RTL8139/UDP
                                 ↓ Izhod_aplikacija·izjema·čas_VALUE 초과
                                lupina 복귀
```

시스템 호출 레지스터는 `EAX=INDEX`, `EBX,ECX,EDX,ESI,EDI=Argumenti`, `EAX=REZULTAT`다. Java 호출 operand_Sklad ABI는 컴파일러가 uporabnik 스텁에서 이 형식으로 바꾼다. C의 POSIX/JNI ABI가 아니다.

| INDEX | 호출 |
| --- | --- |
| 0 | Izhod_aplikacija(stanje_VALUE CODE_VALUE) — Zaženi/NAPAKA 런타임에서 uporaba_VALUE |
| 1 | niz_VALUE Pisanje |
| 2 / 3 | Argumenti element_COUNT / Argumenti niz_VALUE naslov |
| 10 | UDP Odpri |
| 11 | UDP poslati(ročica_VALUE, IP, cilj_VALUE vrata_VALUE, ARRAY_VALUE naslov, 길이) |
| 12 | UDP sprejeti_sprejemati_prejeti_prejemati(ročica_VALUE, ARRAY_VALUE naslov, 제한 밀리초) |
| 13 | UDP Zapri |
| 14 | lokalen_krajeven_obseg IP naslov |
| 15 / 16 | 마지막 enakovreden_VALUE IP / UDP vrata_VALUE |
| 20 | RAM Datoteka Branje(Ime int[] naslov, Izpis int[] naslov) |
| 21 | RAM Datoteka Pisanje(Ime int[] naslov, 입력 int[] naslov, bajt_VALUE 길이) |
| 22 | UTF-16 CODE_VALUE enota_VALUE 문자 Izpis(0~65535) |

Datoteka API는 `uporabnik.파일읽기(int[] Ime, int[] podatki)`와 `uporabnik.pisati_Datoteka(int[] Ime, int[] podatki, int 길이)`다. 이름은 ASCII CODE_VALUE ARRAY_VALUE(최대 64칸, 0 Izhod_aplikacija 또는 ARRAY_VALUE 끝), podatki element_element 하나는 한 바이트다. 반환값은 읽거나 쓴 길이이며 Datoteka 없음 `-2`, kazalec NAPAKA `-14`, Ime/길이 NAPAKA `-22`, Datoteka 슬롯 부족 `-28`, Velikost 초과 `-90`을 반환한다. 쓰기는 preveriti_veljavnost 후 Datoteka 전체를 대체한다. `uporabnik.pisati_znak_VALUE(int)`는 문자를 단말에 출력한다. Java 프로그램의 일반 `java.io` 구현은 아니다.

`실행권한()`은 시스템 호출이 아니라 uporabnik 모드에서 CS의 하위 비트를 직접 읽으므로 dejanski_podatki Izvedi_ukaz 권한을 확인한다. jedro_VALUE strojna_oprema_vrata 접근용 `naprava_VALUE` native 함수는 uporabnik tarča 컴파일에서 거부한다. ELF에 직접 특권 명령을 넣더라도 CPU가 차단한다.

## 범위와 제한

- 한 번에 한 프로그램만 실행하며 완료 후 셸로 돌아온다. 백그라운드 Izvedi_ukaz, 파이프, 프로세스 간 통신은 없다. Izvedi_ukaz 파일은 커널의 Branje 전용 JKAP 묶음에서 적재한다. podatki 파일에는 주기억 파일체계와 전용 IDE 보존 형식이 있다.
- uporabnik 가상 naslov `0x04000000..0x043fffff`를 물리 8~12MiB에 연결한다. Izvedi_ukaz 영상은 sprednja_VALUE 2MiB, 인수는 `0x04300000`부터, 스택은 območje_VALUE_0e9a97ab 끝에서 시작한다. jedro_VALUE identity 페이지는 supervisor 전용이다.
- 실행마다 4MiB uporabnik 영역을 비우고 Datoteka 구역을 복사해 BSS·ARRAY_VALUE 영역을 초기화한다. uporabnik GC는 없지만 Izhod_aplikacija 후 Naprej_element Izvedi_ukaz 때 영역을 재사용한다. 인수는 공백으로 분리한 최대 16개이며 Navedek/이스케이프 파싱은 없다.
- uporabnik 페이지의 CODE_VALUE/podatki 분리 Branje 전용 Nastavitve, NX, operand_Sklad guard, ASLR은 아직 없다. 커널과 uporabnik pomnilnik_podatki·strojna_oprema_vrata dovoljenje_VALUE 경계를 구현한 초기판이지 보안 인증된 샌드박스는 아니다.
- PIT 100Hz로 약 3초 Izvedi_ukaz 상한을 두며 čas_VALUE 초과는 `Exit: 124`다. uporabnik CPU 예외는 `128 + izjema INDEX`(페이지 NAPAKA 142, 특권 위반 141), Java ARRAY_VALUE/계산 오류는 101~105다. jedro_VALUE 오류까지 복구하는 구조는 아니다.
- 네트워크는 PCI bus 0/function 0의 RTL8139, statičen_VALUE IPv4, ARP, UDP만 지원한다. NIC는 폴링하고 송신은 동기식이다. IPv4 단편 재조립·TCP·DNS·DHCP·IPv6·HTTP·TLS·일반 `java.net`은 미지원이다. IPv4 UDP kontrolna_vsota 0은 규약에 따라 허용하고, 그 외 UDP/IP 검사합과 길이는 검증한다.
- uporabnik Izvedi_ukaz·네트워크·zaščititi_VALUE 경계 전체 시험은 QEMU에서 수행했다. VirtualBox에서도 `make vbox`로 부팅과 `run hello vbox`의 ring 3 Izvedi_ukaz·정상 종료를 확인했다. VirtualBox PCnet/E1000용 드라이버는 없어 그 환경의 네트워크는 지원하지 않는다.

## preveriti_veljavnost 근거

`make test`는 prevajalnik 14개 시험, Java 패킷 pogoj 2,201개 검사, 기존 lupina ELF/ISO 부팅 시험, uporabnik ELF/dejanski_podatki UDP/zaščititi_VALUE 경계 시험을 실행한다. 네트워크 시험은 루프백 서버가 받은 자료의 길이·해시까지 `os/build/preskusiti_uporabnik_mreža.json`에 기록한다. 시험용 손상된 ELF·특권 Ukaz·무한 sprint_VALUE 프로그램은 임시 묶음에만 넣으며 배포용 `apps` 목록에는 넣지 않는다.
