# slovenščina Java 통신·V_I·izjema API

패키지는 `slovenščina.lastno`다. gostiti `javac --release 8`로 컴파일한 class를
lastno ARM64 커널의 JVM에서 실행한다. 통신·Datoteka·izjema API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 nit_VALUE API는 lastno JVM 전용이다.
기존 표준 Java knjižnica 전체의 slovenščina 번역판은 아니다.

```java
import slovenščina.lastno.*;

public class mreža {
    public static void main(String[] Argumenti) throws V_I_izjema {
        povezava Poveži = povezava.Odpri("10.0.2.2", 9000);
        try {
            Poveži.TIMEOUT(700);
            Poveži.Izpis().Pisanje(문자.kodirati("안녕하세요\n"));
            vhodni_tok 입력 = Poveži.입력();
            Izpis.수쓰기(입력.Branje());
        } catch (počakaj_TIMEOUT_izjema NAPAKA) {
            Izpis.pisati_linija(NAPAKA.설명());
        } finally {
            Poveži.Zapri();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
uporabnik 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 niz_VALUE 리터럴에 사용하는 표준 클래스다. lastno 실행기는 `public static void Zaženi()`도 진입점으로 받는다.

## 통신과 tok_VALUE

| Razred_VALUE | slovenščina 호출 |
|---|---|
| povezava | `Odpri(naslov, številka_vrat)`, `입력()`, `Izpis()`, `TIMEOUT(밀리초)`, `številka_vrat()`, `lokalen_krajeven_številka_vrat()`, `연결됨()`, `닫힘()`, `Zapri()` |
| sprejeti_sprejemati_prejeti_prejemati_vrata | `Odpri(številka_vrat)`, `sprejeti_sprejemati_prejeti_prejemati()`, `številka_vrat()`, `TIMEOUT(밀리초)`, `닫힘()`, `Zapri()` |
| vhodni_tok | `Branje()`, `Branje(byte[])`, `Branje(byte[], Zaženi, 길이)`, `Zapri()` |
| izhodni_tok | `Pisanje(int)`, `Pisanje(byte[])`, `Pisanje(byte[], Zaženi, 길이)`, `내보내기()`, `Zapri()` |
| datagram_Kanal | `Odpri(številka_vrat)`, `poslati(naslov, številka_vrat, Besedilo)`, `sprejeti_sprejemati_prejeti_prejemati()`, `TIMEOUT(밀리초)`, `številka_vrat()`, `닫힘()`, `Zapri()` |
| 연결통신 | `Odpri(...)`, `수신열기(...)`는 위 slovenščina 객체를 vrni_KR |
| 검사 | `참인지(pogoj, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`Branje()`의 Datoteka 끝은 -1, ARRAY_VALUE 읽기의 반환값은 dejanski_podatki 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. številka_vrat 0은 빈 번호를 자동 배정한다.
UDP 전문은 sprotno_element lastno 커널에서 512바이트까지 받으며, 주소는 številka_VALUE IPv4를 사용한다.
`localhost` 루프백 외의 Ime 풀이(DNS)는 lastno 커널에 아직 없다.

기존 `연결통신.Poveži/poslušati_končna_točka/sprejeti_sprejemati_prejeti_prejemati`, `통신.Odpri/poslati/sprejeti_sprejemati_prejeti_prejemati`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `povezava`, `sprejeti_sprejemati_prejeti_prejemati_vrata`, `datagram_Kanal`를 쓴다.

## slovenščina izjema

모든 아래 클래스는 privzeta_vrednost 생성자, `새예외("설명")` 형태의 niz_VALUE 생성자와
`설명()`을 제공한다. dejanski_podatki ustvariti 문법은 `new počakaj_TIMEOUT_izjema("čakalno_stanje 끝")`이다.

| slovenščina izjema | 상위 Razred_VALUE / 용도 |
|---|---|
| izjema | `java.lang.Exception`, 직접 던지는 일반 검사 izjema |
| 실행예외 | `java.lang.RuntimeException` |
| V_I_izjema | `java.io.IOException`, slovenščina Datoteka·통신 API의 검사 izjema |
| počakaj_TIMEOUT_izjema | `V_I_izjema`, 통신 TIMEOUT 초과 |
| naslov_LOOKUP_izjema | `V_I_izjema`, naslov 확인 napaka_VALUE |
| 파일없음예외 | `V_I_izjema`, Datoteka Odpri napaka_VALUE |
| 통신예외 | `V_I_izjema`, 표준 SocketException CONVERT_VALUE |
| neveljaven_argument_izjema | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `neveljaven_argument_izjema` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| NULL_Gradiva_izjema | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| stanje_izjema | `java.lang.IllegalStateException` |
| Tip_pretvorba_izjema | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| ARRAY_Store_napaka | `java.lang.ArrayStoreException` |
| nit_stanje_izjema | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 počakaj_VALUE 중단 |

`izjema`와 `실행예외`는 모든 slovenščina 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, Datoteka·통신 전체를 잡으려면 `catch (V_I_izjema NAPAKA)`를 쓴다.
slovenščina API가 표준 V_I 오류를 slovenščina 예외로 변환한다.
기존 slovenščina 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`počakaj_TIMEOUT_izjema`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
izjema 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
sprotno_element lastno JVM에 이 20종을 추가했다. 임의의 uporabnik Throwable 하위 Razred_VALUE 전체를
지원하도록 확장했다는 뜻은 아니다.

## prevajati_vir·Izvedi_ukaz

```sh
cd /home/user/jkoros/platforms/rpi4-native
make graditev_sistem
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 Orodja/Izvedi_Datoteka.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 uporabnik JVM ELF 안에 탑재된다. `.jar`는 gostiti javac의
Razred_VALUE 경로로 사용한다. vir_drevo 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 slovenščina 예외의 `throws` 선언과 그 import를 인식한다.
lastno JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·predmet_VALUE·vtičnica_VALUE 예제 전체의 vir_drevo 컴파일은 gostiti javac를 사용한다.
`/example/java/PrimerDatoteke.java`는 게스트 javac로도 컴파일할 수 있다.

dejanski_podatki TCP/UDP 예제는 [PrimerOmrežja.java](../../../example/java/PrimerOmrežja.java),
Izvedi_ukaz 절차는 [example 안내](../../../example/README.md),
vir_drevo 명명 원칙은 [명명 안내](../명명/안내.md)에 있다.

## Swing okno 예제

`/example/java/PrimerOkna.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` Naprej_element `java PrimerOkna`로 연다. Ime 입력, 인사하기 버튼,
인사말과 klik_VALUE 횟수 osvežiti, X 닫기를 지원한다.

| 기능 | slovenščina 직접 API |
|---|---|
| Runnable / run | `실행할일.Izvedi()` |
| ActionListener / actionPerformed | `동작받이.sprejeti_sprejemati_prejeti_prejemati_akcija(akcija_obvestilo obvestilo)` |
| ActionEvent | `akcija_obvestilo.ukaz_SMS()`, `vir_dogodka()`, `INDEX()` |
| JFrame | `okno(okno_naslov, 폭, višina_VALUE)`, `Dodaj_element(화면구성요소)`, `oddaja_okno()`, `Zapri()`, `보이는가()` |
| JButton | `Gumb(Besedilo, 가로, Navpično_položaj, 폭, višina_VALUE, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `Oznaka(...)`, `SMS_polje(...)` |
| 공통 화면 element_VALUE | `화면구성요소.글읽기()`, `pisati_SMS(Besedilo)`, `자리정하기(가로, Navpično_položaj, 폭, višina_VALUE)` |
| SwingUtilities.invokeLater | `dogodek_čakalna_vrsta.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `Start_opravek()`, `기다리기()`, `살아있는가()`, `YIELD_opravek()` |
| 명령행 | `Zaženi()`, `실행인수.element_COUNT()`, `실행인수.Besedilo(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
lastno JVM의 `한국어화면호출`, `Proces_nit`가 slovenščina Razred_VALUE·metoda_VALUE·서술자를
해석해 화면 요소와 Izvedi_ukaz 가닥을 직접 만든다. Dejanje 알림도 lastno 객체이며
콜백으로 `Izvedi`와 `sprejeti_sprejemati_prejeti_prejemati_akcija`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 Izvedi_ukaz 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 lastno JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 gostiti JVM에서 무동작 객체가 생기지 않도록 하는 zavrniti_VALUE 경로다.
lastno JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. gostiti javac로 컴파일한 ZAJ_VALUE lastno JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import slovenščina.lastno.*;
public class 가닥예제 implements 실행할일 {
    public void Izvedi() { Izpis.pisati_linija("slovenščina 작업 Izvedi_ukaz"); }
    public static void Zaženi() throws 대기중단예외 {
        작업가닥 nit_VALUE = 작업.Zaženi(new 가닥예제());
        작업.기다리기(nit_VALUE);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
ARRAY_VALUE Argumenti 대신 `실행인수`, 길이는 `문자.bajt_COUNT`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
lastno 실행기는 Argumenti 없는 `Zaženi()`을 우선한다.
기존 slovenščina 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.Zaženi(Runnable)`을 사용하던 코드는 새 slovenščina 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API Podpora_VALUE 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 Razred_VALUE·metoda_VALUE 이름과 서술자가 남는다.
slovenščina Ime 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·metoda_VALUE 재정의, native Poveži, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS identifikator_VALUE](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS metoda_VALUE Gradiva](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
