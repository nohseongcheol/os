# 전체 dukung_VALUE 요청의 saat_ini_item Status_VALUE

permintaan 전체는 아직 완료되지 않았다. saat_ini_item ISO는 Asli Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 aktual_data C POSIX 일부 기능, Indonesia API/kodeSumber Nama_2, IDE berkas 보존, 게스트 Java berkas 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/baca_saya_eb81d7d9.md)를 기준으로 판단한다.

| permintaan 분야 | saat_ini_item Jalankan_perintah 가능한 klip | 전체 지원에 필요한 작업 |
|---|---|---|
| Java bangun_sumber·Jalankan_perintah | 게스트 제한형 javac/JVM, statik_VALUE 단일 클래스와 일부 표준 objek_VALUE | 일반 objek_VALUE·Kelas_VALUE Sambung·pengecualian·GC·스레드, 완전한 javac와 표준 Kelas_VALUE pustaka |
| berkas | POSIX 서술자, Java 단일 byte_VALUE berkas Stream_VALUE, 전용 media_VALUE 보존 | 일반 java.io/nio, 디렉터리·izin_VALUE·kunci_VALUE·일반 sistem_berkas·ekstensi_VALUE 가능한 kapasitas_VALUE |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP host 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, tambah_entri NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 Even·font_VALUE·Jendela sistem_operasi_VALUE, AWT 네이티브 연결과 Swing Jalankan_perintah 기반 |

Asli 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 Jalankan_perintah 환경을 추가하는 방식은 별도의 kernel_VALUE·루트 sistem_berkas·OpenJDK·그래픽 server_VALUE·영구 Store_VALUE 구성을 가진 Jalankan_perintah 경로가 된다. 후자는 기존 Asli 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

Jalankan_perintah 기반과 tambah_entri target 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. saat_ini_item 원문과 pengujian 결과를 후속 구현의 출발점으로 보존한다.
