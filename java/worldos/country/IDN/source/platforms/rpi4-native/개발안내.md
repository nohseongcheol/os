# Asli 커널에서 vi·여러 terminal·한글 프로그래밍 사용하기

Indonesia komunikasi·pengecualian 사용법은 [Indonesia Java API](한국어자바/baca_saya_eb81d7d9.md), fungsi_VALUE·variabel_VALUE·berkas 이름의 변경과 어원 근거는 [명명 baca_saya_eb81d7d9](명명/baca_saya_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 Asli AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 dukung_VALUE 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 Jalankan_perintah, eksternal_VALUE TCP/UDP와 FTP는 [새 Jalankan_perintah 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 terminal

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, surel **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 terminal 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **RIGHT 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 Jalankan_perintah 버튼으로 coba_lagi_VALUE kolom_VALUE 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 saat_ini_item 디렉터리, shell variabel_VALUE, perintah LOG_baris, 입력 중인 명령과 apl_f5044b9b Jalankan_perintah 상태를 보관한다. berkas 저장소는 공유한다. vi와 Swing의 이벤트 tunggu_VALUE 중에 다른 터미널로 전환하면 ruang_pengguna Memori_data·레지스터·berkas/소켓 연결을 보존했다가 돌아올 때 재개한다. **saat_ini_item 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 Berikutnya_item 입력 tunggu_VALUE 또는 기존 Jalankan_perintah 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 Jalankan_perintah 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 Edit_VALUE 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. saat_ini_item 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 Jendela 판단은 게스트 커널이 처리한다. QEMU Jalankan_perintah 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. aktual_data Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI alat 종료는 host 터미널의 Ctrl+C다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **kernel_VALUE 내부 연결형 byte_VALUE Stream_VALUE**을 추가했다. berkas/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket server_VALUE = new java.net.ServerSocket(9250);
java.net.Socket tamu_VALUE = new java.net.Socket("localhost", 9250);
java.net.Socket Sambung = server_VALUE.accept();
tamu_VALUE.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] RECEIVED_item = new byte[64];
int panjang_VALUE = Sambung.getInputStream().read(RECEIVED_item);
Sambung.close(); tamu_VALUE.close(); server_VALUE.close();
```

buat·Sambung·accept·양방향 byte_VALUE/ARRAY_VALUE I_O·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 mengakhiri_p 16개, terima_VALUE 버퍼당 1024바이트, tunggu_VALUE Sambung 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. nilai_default TIME_VALUE 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM perintah 수/kernel_VALUE Jalankan_perintah 기한은 여전히 적용된다.

eksternal_VALUE angka_VALUE IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. aktual_data Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP pustaka 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](pengujian/자바/흐름시험.java)는 aktual_data 송수신·EOF·기한·Sambung 회수의 pengujian 예제다.

`통신규약.h`의 Asli `pk_sockaddr_in`을 사용하며 port_VALUE·주소는 `망차례짧은수`/`jaringan_bilangan_bulat`로 변환한다. C 소켓 호출은 비차단이며 data/연결이 없으면 -1과 `nomor_kesalahan=11`(EAGAIN)을 반환한다. 양수 I_O 결과가 요청보다 작을 수 있으므로 sprint_VALUE 처리한다. kegagalan_VALUE 후에만 오류번호를 확인한다.

[Stream_VALUE.c](예제/한글코딩/Stream_VALUE.c)는 C에서 Indonesia 이름으로 Sambung·accept·부분 Baca/Tulis·큐 포화·EOF를 처리하는 Jalankan_perintah 예제다. SDK의 `examples/Stream_VALUE.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → aktual_data Indonesia C fungsi_VALUE 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·pointer 검사 → Java RAM berkas/루프백 또는 eksternal_VALUE lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 kernel_VALUE 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 Sambung, 표준 C printf, libstdc++/STL, pengecualian·RTTI는 제공하지 않으며 C++의 statik_VALUE 생성자·lokal_Cakupan objek_VALUE 소멸자는 지원한다. 상세 INDEX·Memori_data 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## Indonesia 이름으로 직접 작성하는 창과 alur_VALUE

`example/java/ContohJendela.java`는 `실행할일.Eksekusi`,
`동작받이.terima_Tugas(동작알림)`, `tombol`, `acara_antrean.나중에실행`, `jalankan()`을 쓴다.
Asli JVM에 이 이름들의 objek_VALUE·metode_VALUE·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `tugasLatar`도 Asli 스케줄러와 직접 연결된다.
세부 메서드와 기존 Indonesia API에서의 변경은 [Indonesia API 문서](한국어자바/baca_saya_eb81d7d9.md)를 본다.

host javac는 배포 JAR를 Kelas_VALUE 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/ContohJendela.java
python3 alat/Jalankan_perintah.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java ContohJendela
```

직접 화면/alur_VALUE API와 `jalankan()` 진입점은 Asli JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
