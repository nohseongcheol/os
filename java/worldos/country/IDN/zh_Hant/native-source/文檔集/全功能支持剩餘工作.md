# 전체 支持值 요청의 當前項目 狀態值

申請 전체는 아직 완료되지 않았다. 當前項目 ISO는 內建 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 實際資料 C POSIX 일부 기능, 中文 API/原始碼 名稱, IDE 檔案 보존, 게스트 Java 檔案 흐름을 구현하고 시험했다. [구현과 邊界位置限制](../posix-kor/指南.md)를 기준으로 판단한다.

| 申請 분야 | 當前項目 執行命令 가능한 裁剪 | 전체 지원에 필요한 任務 |
|---|---|---|
| Java 編譯原始碼·執行命令 | 게스트 제한형 javac/JVM, 靜態值 단일 클래스와 일부 표준 物件值 | 일반 物件值·類別值 連接·異常·GC·스레드, 완전한 javac와 표준 類別值 庫 |
| 檔案 | POSIX 描述符條目, Java 단일 位元組值 檔案 流值, 전용 介質值 보존 | 일반 java.io/nio, 디렉터리·權限值·鎖值·일반 檔案系統·擴展名值 가능한 容量值 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP 宿主 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 追加條目 NIC |
| GUI·Swing | VGA 字元 終端輸入輸出 | 프레임버퍼·輸入值 事件·字體值·窗口 運行系統值, AWT 네이티브 연결과 Swing 執行命令 基礎 |
| POSIX | 문서화한 檔案·終端輸入輸出·UDP 子部分值 | 程序值·exec/fork·스레드·시그널·時間值·mmap·poll·파이프 등과 적합성 有效性校驗 |
| 언어별 名稱 | 中文 46개 映射值 條目值, 實際資料 C/Java/檔案 名稱 적용 | 目標值 語言 提交值, 언어별 용례·역사 근거와 해당 原始碼·도구의 有效性校驗 |

內建 커널을 유지하면 頂端值 基礎 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 基礎 執行命令 환경을 추가하는 방식은 별도의 內核值·루트 檔案系統·OpenJDK·그래픽 服務器值·영구 存儲值 구성을 가진 執行命令 경로가 된다. 후자는 기존 內建 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

執行命令 기반과 追加條目 目標值 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 當前項目 원문과 測試 결과를 후속 구현의 출발점으로 보존한다.
