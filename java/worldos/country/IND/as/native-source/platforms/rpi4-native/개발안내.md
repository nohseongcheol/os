# 자체 커널에서 vi·여러 টাৰ্মিনেল·한글 프로그래밍 사용하기

한국어 통신·예외 사용법은 [한국어 Java API](한국어자바/ৰিডমি_ফাইল_eb81d7d9.md), ফাংছন_মান·변수·নথিপত্ৰ 이름의 변경과 어원 근거는 [명명 ৰিডমি_ফাইল_eb81d7d9](명명/ৰিডমি_ফাইল_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 자체 AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 সমর্থন_মান 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 নিষ্পাদন_আদেশ, 외부 TCP/UDP와 FTP는 [새 নিষ্পাদন_আদেশ 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 টাৰ্মিনেল

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, ঠিকনা **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 টাৰ্মিনেল 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **오른쪽 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 নিষ্পাদন_আদেশ 버튼으로 다시 স্তম্ভ_মান 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 현재 디렉터리, শ্বেল 변수, কমান্ড লগ_শাৰী, 입력 중인 명령과 এপ্প্_f5044b9b নিষ্পাদন_আদেশ 상태를 보관한다. নথিপত্ৰ 저장소는 공유한다. vi와 Swing의 이벤트 대기 중에 다른 터미널로 전환하면 ব্যৱহাৰকৰ্তা মেম_ৰি_ডাটা·레지스터·নথিপত্ৰ/소켓 연결을 보존했다가 돌아올 때 재개한다. **현재 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 পৰৱৰ্তী_আইটেম 입력 대기 또는 기존 নিষ্পাদন_আদেশ 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 নিষ্পাদন_আদেশ 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 সম্পাদনা_মান 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. 현재 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 উইণ্ড 판단은 게스트 커널이 처리한다. QEMU নিষ্পাদন_আদেশ 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. প্ৰকৃত_ডাটা Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI সঁজুলিসমূহ 종료는 হ_ষ্ট 터미널의 Ctrl+C다.

## vi 사용

```text
mkdir 작업
cd 작업
vi 인사.py
```

`vi`는 새로 구현한 **vi কমান্ড 부분집합** 편집기다. 내장 `build/user/vi.elf`를 보호된 ব্যৱহাৰকৰ্তা 영역에 적재한다. নথিপত্ৰ 크기는 UTF-8 বাইট_মান 기준 16 KiB, 경로는 63바이트까지다. 디스크에 설치한 Vim/Neovim 바이너리를 실행하는 것이 아니다.

| কী_মান/কমান্ড | কাৰ্য্য |
|---|---|
| `i`, `a`, `I`, `A` | 현재/পৰৱৰ্তী_আইটেম অৱস্থান 또는 লাইন 처음/끝에서 입력 |
| `o`, `O` | 아래/위에 새 줄을 만들고 입력 |
| Esc | 일반 মোড_মান |
| `h j k l`, 방향키 | UTF-8 문자/লাইন লৈ_যাওক_মান |
| `0`, `$`, Home, End | লাইন 처음/끝 |
| `gg`, `G`, `:ইনডেক্স` | নথিপত্ৰ 처음/마지막 লাইন/지정 লাইন |
| PgUp, PgDn | 화면 পাঠ্য_মান লৈ_যাওক_মান |
| `x`, Delete | 현재 문자 삭제 |
| `dd`, `yy`, `p` | লাইন 삭제/নজিৰ_মান/লেপন_কৰক_পাঠ |
| `u` | 마지막 편집을 되돌림; 한 ষ্টেজ_মান 토글 |
| `/ষ্ট্ৰিং_মান`, `n` | 단순 ষ্ট্ৰিং_মান 검색/পৰৱৰ্তী_আইটেম 일치; 정규식 없음 |
| `:w`, `:w 다른이름` | RAM নথিপত্ৰ জমা_কৰক_মান/다른 경로로 জমা_কৰক_মান |
| `:q` | 변경이 없을 때 প্ৰস্থান_এপ্প্ |
| `:q!` | 변경을 버리고 প্ৰস্থান_এপ্প্ |
| `:wq`, `ZZ` | 저장하고 প্ৰস্থান_এপ্প্ |

붙여 넣은 한글을 문자 경계에 맞춰 লৈ_যাওক_মান·삭제한다. 일반 vi의 수량 접두사, মেক্ৰ_মান, বৈশিষ্ট্য নথিপত্ৰ, 플러그인, 정규식, 여러 버퍼/분할 উইণ্ড, 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/영 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 উইণ্ড উইণ্ড_শিৰোনাম `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 কমান্ড**으로 실행한다. 파이프·리다이렉션·লিপি_মান·`;`/`&&`/`||`로 연결한 실행에서 আন্তঃসক্রিয় 대기를 시작하면 거부한다. 입력 대기는 약 2초 CPU 기한을 갱신하지만 입력 대기 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## 한글 Java

vi에서 다음을 `인사.java`에 입력하고 Esc → `:wq`로 저장한다.

```java
public class 인사 {
    static int 더하기(int 첫째, int 둘째) { return 첫째 + 둘째; }
    public static void main(String[] 인수) {
        int 합계 = 더하기(20, 22);
        System.out.println("안녕하세요 · 합계=" + 합계);
    }
}
```

게스트 셸에서 실행한다.

```text
javac 인사.java
java 인사
```

한글 ফাইল_নাম_পাঠ·শ্ৰেণী_নাম·পদ্ধতি_নাম_পাঠ·변수명·문자열을 사용할 수 있다. **게스트 javac는 স্থিৰ_মান Java 부분집합**이다. অবজেক্ট_মান·리스너·Swing·소켓을 사용하는 소스는 현재 হ_ষ্ট JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 자체 JVM에 class를 올린다. 자체 JVM에서 지원하는 바이트코드/API 범위는 [자바실행환경.md](자바실행환경.md)를 따른다.

```sh
# হ_ষ্ট
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/스윙시험.java
python3 সঁজুলিসমূহ/আপল_ড_কৰক_ফাইলসমূহ.py build/my-java/스윙시험.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. নিৰ্গম 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.শ্ৰেণী_মান.class` 형식이다. 내장 한국어 라이브러리는 별도 업로드가 필요 없다. 한국어 উইণ্ড API의 예제는 [한글창시험.java](시험/자바/한글창시험.java)이며 같은 방법으로 বিল্ড_উৎস·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 উৎস_ট্ৰি/클래스는 호스트의 `python3 সঁজুলিসমূহ/নিষ্পাদন_ফাইল.py পথ/인사.java`로 별도 QEMU에 업로드·নিষ্পাদন_আদেশ·종료할 수 있다. আন্তঃসক্রিয় Swing에는 নিষ্পাদন_আদেশ 후 ব্যৱহাৰকৰ্তা 입력을 유지하는 `make desktop`을 사용한다.

## 자체 JVM의 Swing ক্লিপ

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 자체 Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | কাৰ্য্য |
|---|---|
| `JFrame` | উইণ্ড_শিৰোনাম, মাপ·অৱস্থান, শ্ব_উইণ্ড, বন্ধ_কৰক 정책, dispose |
| `JPanel` | শিশু_মান 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 ষ্ট্ৰিং_মান শ্ব_মান·পৰিবৰ্তন_কৰক_মান |
| `JButton` | 버튼과 ActionListener ক্লিক_কৰক_মান প্ৰক্ৰিয়া_মান_প্রবিষ্ট |
| `JTextField` | 한 লাইন UTF-8 입력, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 자체 JVM의 단일 이벤트 নিষ্পাদন_আদেশ 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. উইণ্ড·요소는 নিষ্পাদন_আদেশ 하나당 합계 32개, উপাদান_মান 글자는 최대 127 코드포인트다. ডিফ_ল্ট_মান 서체와 색은 커널이 제공한다.

[스윙시험.java](시험/자바/스윙시험.java)는 উইণ্ড·한글 টেগ_মান·পাঠৰ_ক্ষেত্ৰ·버튼·이벤트 처리의 নিষ্পাদন_আদেশ 가능한 예제다. [자체 Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

한국어 라이브러리에는 다음을 추가했다. হ_ষ্ট বিল্ড_উৎস 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `한국어.자체.উইণ্ড`: `যোগ_কৰক_উপাদান`, `শ্ব_উইণ্ড`, `বন্ধ_কৰক`.
- `한국어.자체.ৱিজেট`: `টেগ_মান`, `বুটাম`, `পাঠৰ_ক্ষেত্ৰ` সৃষ্টি_কৰক.
- `한국어.자체.연결통신`: `সংযোগ_স্থাপনা`, `듣기`, `받기`.
- 기존 `নিৰ্গম`, `문자`, `নথিপত্ৰ`, `작업`, `প্রবিষ্ট_সূচী`, `অভিধান`, `통신`, `화면`, `কাৰ্ণেল_মান`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **কাৰ্ণেল_মান 내부 연결형 বাইট_মান ষ্ট্ৰিম_মান**을 추가했다. নথিপত্ৰ/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket ছাৰ্ভাৰ_মান = new java.net.ServerSocket(9250);
java.net.Socket অতিথি_মান = new java.net.Socket("localhost", 9250);
java.net.Socket সংযোগ_স্থাপনা = ছাৰ্ভাৰ_মান.accept();
অতিথি_মান.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int দৈর্ঘ্য_মান = সংযোগ_স্থাপনা.getInputStream().read(받은것);
সংযোগ_স্থাপনা.close(); অতিথি_মান.close(); ছাৰ্ভাৰ_মান.close();
```

সৃষ্টি_কৰক·সংযোগ_স্থাপনা·accept·양방향 বাইট_মান/শৃঙ্খলা_মান ইনপুট_আউটপুট·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 অন্ত_কৰক_পইণ্ট 16개, 수신 버퍼당 1024바이트, 대기 সংযোগ_স্থাপনা 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. ডিফ_ল্ট_মান 시간 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM কমান্ড 수/কাৰ্ণেল_মান নিষ্পাদন_আদেশ 기한은 여전히 적용된다.

외부 অংক_মান IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. প্ৰকৃত_ডাটা Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP লাইব্ৰেৰী 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 প্ৰকৃত_ডাটা 송수신·EOF·기한·সংযোগ_স্থাপনা 회수의 시험 예제다.

## 한글 Python

게스트 vi에서 한글 이름을 사용해 작성한다.

```python
মান = 21

def 두배(অংক_মান):
    return অংক_মান * 2

print("পৰিমাপ:", 두배(মান))
```

জমা_কৰক_মান 후 `python 인사.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 ফাংছন_মান·변수·নথিপত্ৰ 이름과 문자열을 한글로 쓴다.

[한국어.py](예제/한글코딩/한국어.py)를 같은 디렉터리에 두면 পৰৱৰ্তী_আইটেম 별칭을 사용할 수 있다.

```python
import 한국어
한국어.লিখক_ফাইল("인사.txt", "안녕하세요")
한국어.নিৰ্গম(한국어.파일읽기("인사.txt").decode())
```

নিৰ্গম·নথিপত্ৰ পড়া/লিখা/삭제·표준 입력·사각형·시간·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 অংক_মান IPv4 ঠিকনা 전송이다. `wait_key()`는 화면을 확인할 때 আন্তঃসক্রিয় 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor স্থিৰ_মান 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 সম্প্রসাৰণ_মান 모듈은 아직 없다. 제한형 `pip`의 উৎস_ট্ৰি 설치는 [Python বাণ্ডল ৰিডমি_ফাইল_eb81d7d9](파이썬꾸러미.md)를 따른다. [세 언어의 প্ৰকৃত_ডাটা 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 ভাষা 모두 한국어 헤더와 ফাংছন_মান 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 প্ৰকৃত_ডাটা EL0 নিষ্পাদন_আদেশ 시험 대상이다.

```c
#include "파일규약.h"
#ifdef __cplusplus
extern "C"
#endif
int আৰম্ভ_ব্যৱহাৰকৰ্তা_এপ্প্(int 인수) {
    (void)인수;
    const char 인사말[] = "안녕하세요\n";
    int 문서 = খোলক_ফাইল("인사.txt", পঢ়িব_লিখিব_পৰা | 없으면만들기 | 내용비우기, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = লিখক_ফাইল_ডাটা(문서, 인사말, sizeof(인사말) - 1);
    বন্ধ_কৰক_ফাইল(문서);
    লিখক_ফাইল_ডাটা(1, 인사말, sizeof(인사말) - 1); /* 현재 টাৰ্মিনেল stdout */
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 수 있다. C는 게스트 `cc` 또는 হ_ষ্ট SDK, C++는 হ_ষ্ট SDK의 Clang++로 컴파일한다. 아래 예제는 기존 হ_ষ্ট SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh
# 호스트에서 SDK সৃষ্টি_কৰক·এক্সট্ৰেক্ট_কৰক
make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/인사.c -o 인사-c.elf
python3 compile.py examples/인사.cpp -o 인사-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 প্ৰকৃত_ডাটা নিষ্পাদন_আদেশ
cd /home/user/jkoros/platforms/rpi4-native
python3 সঁজুলিসমূহ/নিষ্পাদন_ফাইল.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 সঁজুলিসমূহ/নিষ্পাদন_ফাইল.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

현재 GUI VM에서 실행하려면 `python3 সঁজুলিসমূহ/আপল_ড_কৰক_ফাইলসমূহ.py পথ/인사-c.elf`의 출력을 게스트에 보내고 `run 인사-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex ফাইল_নাম_পাঠ`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 수 있다. 호스트와 게스트의 নথিপত্ৰ 시스템은 별개다.

| 한국어 নাম | C প্ৰতীক | ক্লিপ |
|---|---|---|
| খোলক_ফাইল/বন্ধ_কৰক_ফাইল | pk_open/pk_close | RAM নথিপত্ৰ, পীয়েৰ_মান/절대 পথ |
| 파일자료읽기/লিখক_ফাইল_ডাটা | pk_read/pk_write | নথিপত্ৰ, fd 0/1/2 표준 ইনপুট_আউটপুট, 연결형 소켓 |
| ছীক_ফাইল | pk_lseek | 처음기준/현재기준/끝기준 |
| ফাইল_আকাৰ_কৰক/ছেট_ফাইল_দৈর্ঘ্য | pk_size/pk_ftruncate | দৈর্ঘ্য_মান কুৱেৰী_মান/পৰিবৰ্তন_কৰক_মান |
| আঁতৰাওক_ফাইল_প্রবিষ্ট_নাম | pk_unlink | নথিপত্ৰ নাম 삭제 |
| 파일저장확정 | pk_fsync | RAM이므로 -1, 오류번호=ENOSYS |
| 통신종단점만들기/বান্ধক_ঠিকনা | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |
| 자료전문보내기/자료전문받기 | pk_sendto/pk_recvfrom | UDP 루프백 |
| সংযোগ_নেটৱৰ্ক | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | 대기 সংযোগ_স্থাপনা 최대 4개 |
| গ্ৰহণ_নেটৱৰ্ক_সংযোগ | pk_accept | 현재 ঠিকনা 인수는 NULL/NULL만 সমর্থন_মান |
| 통신주소읽기 | pk_getsockname | 로컬 ঠিকনা/পৰ্ট_মান |

`통신규약.h`의 자체 `pk_sockaddr_in`을 사용하며 পৰ্ট_মান·주소는 `망차례짧은수`/`নেটৱৰ্ক_পূর্ণ_সংখ্যা`로 변환한다. C 소켓 호출은 비차단이며 ডাটা/연결이 없으면 -1과 `오류번호=11`(EAGAIN)을 반환한다. 양수 ইনপুট_আউটপুট 결과가 요청보다 작을 수 있으므로 পুণৰাবৃত্তি_মান 처리한다. বিফলতা_মান 후에만 오류번호를 확인한다.

[ষ্ট্ৰিম_মান.c](예제/한글코딩/ষ্ট্ৰিম_মান.c)는 C에서 한국어 이름으로 সংযোগ_স্থাপনা·accept·부분 পড়া/লিখা·큐 포화·EOF를 처리하는 নিষ্পাদন_আদেশ 예제다. SDK의 `examples/ষ্ট্ৰিম_মান.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → প্ৰকৃত_ডাটা 한국어 C ফাংছন_মান 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·পইণ্টাৰ 검사 → Java RAM নথিপত্ৰ/루프백 또는 외부 lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 কাৰ্ণেল_মান 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 সংযোগ_স্থাপনা, 표준 C printf, libstdc++/STL, 예외·RTTI는 제공하지 않으며 C++의 স্থিৰ_মান 생성자·স্থানীয়_সুযোগ অবজেক্ট_মান 소멸자는 지원한다. 상세 ইনডেক্স·মেম_ৰি_ডাটা 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## 한국어 이름으로 직접 작성하는 창과 আঁহ_মান

`example/java/창예제.java`는 `실행할일.চলাওক`,
`동작받이.동작받기(동작알림)`, `বুটাম`, `ইভেণ্ট_লানি.나중에실행`, `সঞ্চালন()`을 쓴다.
자체 JVM에 이 이름들의 অবজেক্ট_মান·পদ্ধতি_মান·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `작업가닥`도 자체 스케줄러와 직접 연결된다.
세부 메서드와 기존 한국어 API에서의 변경은 [한국어 API 문서](한국어자바/ৰিডমি_ফাইল_eb81d7d9.md)를 본다.

হ_ষ্ট javac는 배포 JAR를 শ্ৰেণী_মান 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/창예제.java
python3 সঁজুলিসমূহ/নিষ্পাদন_আদেশ.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java 창예제
```

직접 화면/আঁহ_মান API와 `সঞ্চালন()` 진입점은 자체 JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
