# 자체 ARM64 JVM 0.4와 한국어 লাইব্ৰেৰী

한국어 통신·예외 사용법은 [한국어 Java API](한국어자바/ৰিডমি_ফাইল_eb81d7d9.md), ফাংছন_মান·변수·নথিপত্ৰ 이름의 변경과 어원 근거는 [명명 ৰিডমি_ফাইল_eb81d7d9](명명/ৰিডমি_ফাইল_eb81d7d9.md)를 참고한다.

JAR নিষ্পাদন_আদেশ, 외부 IPv4 TCP/UDP, 별도 স্থিৰ_মান 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 অবজেক্ট_মান·Thread·Swing은 JVM 경로의 기능이며 AOT সমর্থন_মান 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 নিষ্পাদন_আদেশ**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK শ্ৰেণী_মান লাইব্ৰেৰী 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 শ্ৰেণী_মান·স্থিৰ_মান পদ্ধতি_মান 중심이던 실행기를 অবজেক্ট_মান·লাইব্ৰেৰী নিষ্পাদন_আদেশ 기반으로 넓힌 것이다.

## 실행과 বিল্ড_উৎস

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# 자체 কাৰ্ণেল_মান 안에서 উৎস_ট্ৰি বিল্ড_উৎস → class নিষ্পাদন_আদেশ, 한국어 API 호출
python3 সঁজুলিসমূহ/নিষ্পাদন_ফাইল.py 시험/자바/한글소스.java

# অবজেক্ট_মান·예외 등은 হ_ষ্ট JDK로 Java 8 class를 만든 후 자체 커널에서 নিষ্পাদন_আদেশ
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 সঁজুলিসমূহ/নিষ্পাদন_ফাইল.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 স্থানান্তৰণ_মান
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 সঁজুলিসমূহ/নিষ্পাদন_ফাইল.py build/my-java/객체시험.class \
  --include build/my-java/পটভূমি_মান.class --include build/my-java/শাখা_মান.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.শ্ৰেণী_মান.class`라는 RAM নথিপত্ৰ 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.শ্ৰেণী_মান`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.শ্ৰেণী_মান`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar নথিপত্ৰ.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 한국어 클래스만 찾는다. 배포 한국어 লাইব্ৰেৰী JAR는 হ_ষ্ট javac의 classpath로 사용하며, 같은 클래스가 ব্যৱহাৰকৰ্তা JVM ELF에도 পড়া 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 স্থিৰ_মান পদ্ধতি_মান, int/boolean/char/String, চৰ্ত·পুণৰাবৃত্তি_মান, ষ্ট্ৰিং_মান 결합, 일부 নথিপত্ৰ 스트림 등의 **자체 부분집합 컴파일러**다. অবজেক্ট_মান 선언·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 자체 JVM에서 실행한다. 한국어 API 중 নিৰ্গম·문자 스칼라 ফাংছন_মান·নথিপত্ৰ পড়া/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] 인수) throws Exception {
        한국어.자체.নিৰ্গম.লিখক_লাইন("안녕하세요😀");
        한국어.자체.নিৰ্গম.수쓰기(한국어.자체.문자.코드포인트수("한글😀"));
        한국어.자체.নথিপত্ৰ.লিখা("인사.txt", "한글 নথিপত্ৰ😀");
        한국어.자체.নিৰ্গম.লিখক_লাইন(한국어.자체.নথিপত্ৰ.পড়া("인사.txt"));
    }
}
```

컬렉션은 지정한 메서드만 제공하며 iterator/stream/সংৰেখন_কৰক_মান·ব্যৱহাৰকৰ্তা সংজ্ঞা_মান equals/hashCode 콜백은 없다. 사전의 열쇠는 String/Integer/null 사용을 시험했다. UTF-16 코드 단위와 Unicode 코드 포인트 수는 구분한다. 한글 입력 조합·সাধাৰণীকৰণ_কৰক_মান·아랍어 조판·GUI 다국어 글꼴은 이 ষ্ট্ৰিং_মান 지원과 별개다.

예외는 Throwable/Exception/RuntimeException, ArithmeticException, NullPointerException, IndexOutOfBoundsException/ArrayIndexOutOfBoundsException/StringIndexOutOfBoundsException, IllegalArgumentException/NumberFormatException/IllegalThreadStateException, IOException/FileNotFoundException, IllegalStateException, ClassCastException, NegativeArraySizeException, ArrayStoreException, UnknownHostException, SocketTimeoutException의 제한된 সৃষ্টি_কৰক·বর্গ_মান·처리를 제공한다. ব্যৱহাৰকৰ্তা সংজ্ঞা_মান Throwable 상속, stack trace/cause/suppressed 예외, try-with-resources의 addSuppressed, 완전한 আৰম্ভণি_কৰক ত্ৰুটি 포장은 아직 없다. 잡히지 않은 예외는 현재 전체 Java 실행을 실패로 끝낸다.

## 한국어 API

독립 패키지 **`한국어.자체`**를 사용한다. Linux판 `한국어.자바`가 요구하는 NIO/Swing/HTTP API를 자체 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 শ্ৰেণী_মান নাম·পদ্ধতি_মান·인수·ফিল্ড_মান·নথিপত্ৰ 이름에 한국어를 사용한다. 표준 Java শ্ৰেণী_মান 이름은 호환성을 위해 보존한다.

| শ্ৰেণী_মান | 공개 기능 | 이름의 의미 |
|---|---|---|
| নিৰ্গম | লিখা, লিখক_লাইন, 수쓰기 | নিৰ্গম(出力): 내용을 바깥으로 내보냄 |
| 문자 | দৈর্ঘ্য_মান, 같음, লেপন_কৰক_পাঠ, কাটক_মান, পাৰ্ছ_কৰক_পূর্ণ_সংখ্যা/লিখক_পূর্ণ_সংখ্যা_মান, 코드포인트수, 부호화/ডিক্ৰিপ্ট_কৰক_ডাটা | 문자(文字), এনকোডিং_মান(符號): 글의 단위와 그 값을 바이트로 나타내는 নীতি_মান |
| নথিপত্ৰ | পড়া/লিখা(String নাম), 바이트읽기/লিখক_বাইট_মান | 널리 쓰는 ব্যৱহাৰকৰ্তা 용어를 보존; RAM 자료의 নাম |
| প্রবিষ্ট_সূচী | 더하기, পড়া, পুনঃস্থাপন_কৰক_মান, 지우기, মাপ, 비었는가, পৰিষ্কাৰ_কৰক_সামগ্ৰী | প্রবিষ্ট_সূচী(目錄): 순서가 있는 প্রবিষ্ট_মান 모음 |
| অভিধান | 넣기, বিচাৰক_প্রবিষ্ট, 있는가, 지우기, মাপ, পৰিষ্কাৰ_কৰক_সামগ্ৰী | অভিধান(辭典): 찾는 말인 열쇠에 값을 대응 |
| 작업 | সঞ্চালন(실행할일), 기다리기(작업가닥), নিলম্বিত_কার্য্য, 살아있는가 | 작업 আঁহ_মান: 한 এপ্প্_f5044b9b 안의 নিষ্পাদন_আদেশ ষ্ট্ৰিম_মান |
| 통신 | খোলো, ই_মেইল_কৰক, 받기, 대기시간, বন্ধ_কৰক | 통신(通信), 전문(電文), পৰ্ট_মান: ডাটা 교환·메시지·포트의 역할 |
| 화면 | 사각형, 지우기 | 화면(畫面): প্ৰকৃত_ডাটা 그림을 표시하는 면 |
| কাৰ্ণেল_মান | 밀리초, 사각형 | 자체 JVM의 고정 native সংযোগ_স্থাপনা; 일반 JNI는 아님 |

이 명명은 현재 기능을 설명하는 용어 선택이다. 기존 한국어에 없던 역사적 어원을 만들어 주장하지 않는다. ফাইল_নাম_পাঠ·식별자는 UTF-8 소스로 보관한다. `문자.ডিক্ৰিপ্ট_কৰক_ডাটা`는 잘못된 UTF-8에 IllegalArgumentException을 던지며, `부호화`는 짝이 없는 서로게이트를 `?`로 바꾼다. `নথিপত্ৰ.পড়া`는 엄격한 UTF-8 복호화를 적용한다. 화면 색은 `빨강 | (초록 << 8) | (파랑 << 16)` 형식이다.

## নিষ্পাদন_আদেশ 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(한국어 শ্ৰেণী_মান 포함), class당 16 KiB·ধ্রুৱক_মান 풀 511항목, 전체 পদ্ধতি_মান/ফিল্ড_মান 각각 512개. পদ্ধতি_মান 코드 8 KiB, স্থানীয়_সুযোগ 변수·피연산자 스택 각각 128슬롯, 인수 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 নিষ্পাদন_আদেশ 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- অবজেক্ট_মান 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 প্ৰকৃত_ডাটা 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 নথিপত্ৰ·대형 ষ্ট্ৰিং_মান·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 কমান্ড 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 উইণ্ড সাল_সলনি_মোড 시 중단·재개한다. 일반 ছাৰ্ভাৰ_মান·계산의 무제한 실행은 아직 없다. 미지원 কমান্ড·সম্পদ_মান 부족은 명시적인 오류로 종료한다.
- RAM নথিপত্ৰ 최대 64개, 파일당 16384바이트, পথ UTF-8 63바이트. RAM 디렉터리와 পীয়েৰ_মান/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 한국어 class는 RAM নথিপত্ৰ 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 현재 경로에서 উৎস_ট্ৰি·শ্ৰেণী_মান·ডাটা 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 외부 IPv4를 제공한다. প্ৰকৃত_ডাটা GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. 전문 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 নিষ্পাদন_আদেশ 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 শৃঙ্খলা_মান, 완전한 শৃঙ্খলা_মান 공변성·인터페이스 তৰপ_মান 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/এনক্ৰিপ্ট_কৰক_ডাটা/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 সমর্থন_মান 부분집합은 아래 및 개발 매뉴얼을 참고한다. শ্ৰেণী_মান নথিপত্ৰ 전체 검증기·প্ৰৱেশ_কৰক_প্রবিষ্ট অনুমতি_মান/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 প্রতিৰোধ_কৰক_মান 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM মান/বৈধকৰণ_কৰক/শ্ৰেণী_মান 로더와 예외 모델 → 영속 VFS·mmap·ঘড়ী·원자 অপাৰেচন_মান·প্ৰকৃত_ডাটা 스레드/সকালীকৄত_কৰক ABI → OpenJDK java.base 및 native লাইব্ৰেৰী 이식 → চেলফোন_মান 네트워크·TCP/IP → উইণ্ড 시스템/ফ_ন্ট_মান/입력기·java.desktop → Java SE 호환성 시험. 현재 자체 JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## বৈধকৰণ_কৰক

`সঁজুলিসমূহ/자바가상기계시험.py`는 같은 Java 8 class 파일의 출력을 হ_ষ্ট OpenJDK `-Xverify:all`과 QEMU raspi4b 자체 커널에서 비교한다. অবজেক্ট_মান/상속/인터페이스·switch·শৃঙ্খলা_মান, 예외/finally, 컬렉션/GC, Thread/잠금, 한국어 UTF-8/নথিপত্ৰ/컬렉션, প্ৰকৃত_ডাটা UDP 루프백/시간 초과, 게스트 한글 উৎস_ট্ৰি বিল্ড_উৎস, শৃঙ্খলা_মান প্ৰকাৰ_মান/নজিৰ_মান/নথিপত্ৰ 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 নথিপত্ৰ 거부 시험을 실행한다. UDP 기준 실행에는 হ_ষ্ট 루프백 소켓 권한이 필요하다.

`সঁজুলিসমূহ/부팅시험.py`는 কাৰ্ণেল_মান প্রতিৰোধ_কৰক_মান/회귀 시험과 별도로 한국어 Java 화면 API가 প্ৰকৃত_ডাটা 픽셀을 그렸는지도 QMP 화면 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. প্ৰকৃত_ডাটা Pi4 하드웨어 부팅 시험과 전체 JDK 호환성 시험 결과는 아니다.


## JVM 0.3: 네트워크와 GUI সম্প্রসাৰণ_মান

`Socket`/`ServerSocket` সৃষ্টি_কৰক·সংযোগ_স্থাপনা·accept·양방향 InputStream/OutputStream·close·EOF·시간 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 외부 অংক_মান IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 অন্ত_কৰক_পইণ্ট 16개, Java 루프백 버퍼 1024바이트, 외부 TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. আন্তঃসক্রিয় 이벤트 대기는 নিষ্পাদন_আদেশ 기한을 갱신하고 টাৰ্মিনেল সাল_সলনি_মোড 시 프로세스 상태를 জমা_কৰক_মান·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

한국어 `উইণ্ড`, `ৱিজেট`, `연결통신` 클래스를 배포 JAR와 자체 JVM 내장 자원에 추가했다. 상세 পদ্ধতি_মান·제한·উৎস_ট্ৰি·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## 한국어 객체의 직접 নিষ্পাদন_আদেশ

`উইণ্ড`, `লেবেল`, `পাঠৰ_ক্ষেত্ৰ`, `বুটাম`, `ইভেণ্ট_লানি`, `동작알림`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. 자체 JVM의 অবজেক্ট_মান সৃষ্টি_কৰক,
সজ্জা_মান 검사, 화면 호출, ইভেণ্ট 큐, আঁহ_মান 스케줄러에 한국어 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 নিষ্পাদন_আদেশ 경로도 유지한다.
한국어 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

자체 실행기의 한국어 진입점은 `public static void সঞ্চালন()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 한국어 진입점을 우선한다.
명령행 인수는 `실행인수.개수()`와 `실행인수.টেক্সট(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. স্থিৰ_মান নথিপত্ৰ 예제는 게스트
javac로도 컴파일하며, GUI/আঁহ_মান 소스는 হ_ষ্ট `javac --release 8`을 사용한다.
직접 GUI/আঁহ_মান API는 자체 JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
한국어 가닥의 নিষ্পাদন_আদেশ·대기·중복 সঞ্চালন 거부, GUI ইভেণ্ট 출처·ইনডেক্স·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

পদ্ধতি_মান 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
한국어 클래스도 실행되지만, ষ্ট্ৰিং_মান 리터럴·표준 লাইব্ৰেৰী 재정의·native
সংযোগ_স্থাপনা·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 예제](한국어자바/ৰিডমি_ফাইল_eb81d7d9.md)를 참고한다.

## টাৰ্মিনেল 부분 সতেজ_কৰক

লৈ_যাওক_মান·মাপ 변경은 새 উইণ্ড 영역과 이전 자리에서 드러난 띠만 합성한다.
1920×32 পিক্সেল(240 KiB)의 임시 그림에서 배경·겹친 উইণ্ড·বৰ্ণ_মান·GUI를 먼저
완성하고, 현재 শ্ব_মান 메모리와 비교하여 달라진 화소만 기록한다.
32줄보다 큰 영역은 여러 띠로 처리하므로 전체 프레임을 원자적으로
교체하거나 수직 동기에 맞추는 방식은 아니다. 전체 배경을 먼저 지우는
중간 화면은 표시하지 않는다. 좌표가 같으면 다시 그리지 않는다.

`make test-redraw`는 প্ৰকৃত_ডাটা C 그리기 코드를 호스트의 মেম_ৰি_ডাটা 화면에 연결해
লৈ_যাওক_মান 80회·মাপ পৰিবৰ্তন_কৰক_মান 40회·겹친 উইণ্ড 4개를 전체 합성 결과와 পিক্সেল 단위로 대조한다.
영역 밖 ব্যৱহাৰকৰ্তা অংকন_মান, 동일 পিক্সেল 무기록, পইণ্টাৰ 밑그림, প্ৰকৃত_ডাটা 화면 লাইন 간격을
검사한다. 이 시험의 시간은 হ_ষ্ট CPU 측정이며 Pi 4/QEMU 속도로 해석하지 않는다.
`make test-resize`는 QEMU/VNC의 640×480 및 1920×1080에서 왼쪽 모서리 টানক_মান,
한글 입력·vi 미저장 সামগ্ৰী_মান·독립 উইণ্ড 크기를 검사한다.
