# 한국어 Java 통신·ইনপুট_আউটপুট·예외 API

패키지는 `한국어.자체`다. হ_ষ্ট `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·নথিপত্ৰ·예외 API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 আঁহ_মান API는 자체 JVM 전용이다.
기존 표준 Java লাইব্ৰেৰী 전체의 한국어 번역판은 아니다.

```java
import 한국어.자체.*;

public class নেটৱৰ্ক {
    public static void main(String[] 인수) throws 입출력예외 {
        সংযোগ সংযোগ_স্থাপনা = সংযোগ.খোলো("10.0.2.2", 9000);
        try {
            সংযোগ_স্থাপনা.대기시간(700);
            সংযোগ_স্থাপনা.নিৰ্গম().লিখা(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = সংযোগ_স্থাপনা.입력();
            নিৰ্গম.수쓰기(입력.পড়া());
        } catch (대기시간초과예외 ত্ৰুটি) {
            নিৰ্গম.লিখক_লাইন(ত্ৰুটি.설명());
        } finally {
            সংযোগ_স্থাপনা.বন্ধ_কৰক();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
ব্যৱহাৰকৰ্তা 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 ষ্ট্ৰিং_মান 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void সঞ্চালন()`도 진입점으로 받는다.

## 통신과 ষ্ট্ৰিম_মান

| শ্ৰেণী_মান | 한국어 호출 |
|---|---|
| সংযোগ | `খোলো(ঠিকনা, 접속번호)`, `입력()`, `নিৰ্গম()`, `대기시간(밀리초)`, `접속번호()`, `지역접속번호()`, `연결됨()`, `닫힘()`, `বন্ধ_কৰক()` |
| 수신창구 | `খোলো(접속번호)`, `받기()`, `접속번호()`, `대기시간(밀리초)`, `닫힘()`, `বন্ধ_কৰক()` |
| 입력흐름 | `পড়া()`, `পড়া(byte[])`, `পড়া(byte[], সঞ্চালন, দৈর্ঘ্য_মান)`, `বন্ধ_কৰক()` |
| 출력흐름 | `লিখা(int)`, `লিখা(byte[])`, `লিখা(byte[], সঞ্চালন, দৈর্ঘ্য_মান)`, `내보내기()`, `বন্ধ_কৰক()` |
| 전문통로 | `খোলো(접속번호)`, `ই_মেইল_কৰক(ঠিকনা, 접속번호, টেক্সট)`, `받기()`, `대기시간(밀리초)`, `접속번호()`, `닫힘()`, `বন্ধ_কৰক()` |
| 연결통신 | `খোলো(...)`, `수신열기(...)`는 위 한국어 객체를 반환 |
| 검사 | `참인지(চৰ্ত, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`পড়া()`의 নথিপত্ৰ 끝은 -1, শৃঙ্খলা_মান 읽기의 반환값은 প্ৰকৃত_ডাটা 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. 접속번호 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 자체 커널에서 512바이트까지 받으며, 주소는 অংক_মান IPv4를 사용한다.
`localhost` 루프백 외의 নাম 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.সংযোগ_স্থাপনা/듣기/받기`, `통신.খোলো/ই_মেইল_কৰক/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `সংযোগ`, `수신창구`, `전문통로`를 쓴다.

## 한국어 예외

모든 아래 클래스는 ডিফ_ল্ট_মান 생성자, `새예외("설명")` 형태의 ষ্ট্ৰিং_মান 생성자와
`설명()`을 제공한다. প্ৰকৃত_ডাটা সৃষ্টি_কৰক 문법은 `new 대기시간초과예외("기다림 끝")`이다.

| 한국어 예외 | 상위 শ্ৰেণী_মান / 용도 |
|---|---|
| 예외 | `java.lang.Exception`, 직접 던지는 일반 검사 예외 |
| 실행예외 | `java.lang.RuntimeException` |
| 입출력예외 | `java.io.IOException`, 한국어 নথিপত্ৰ·통신 API의 검사 예외 |
| 대기시간초과예외 | `입출력예외`, 통신 대기시간 초과 |
| 주소확인예외 | `입출력예외`, ঠিকনা প্ৰমাণিত_কৰক বিফলতা_মান |
| 파일없음예외 | `입출력예외`, নথিপত্ৰ খোলো বিফলতা_মান |
| 통신예외 | `입출력예외`, 표준 SocketException 변환 |
| 잘못된인수예외 | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `잘못된인수예외` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| 빈참조예외 | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| 상태예외 | `java.lang.IllegalStateException` |
| 형변환예외 | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| শৃঙ্খলা_জমা_কৰক_বিফলতা | `java.lang.ArrayStoreException` |
| 가닥상태예외 | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 대기 중단 |

`예외`와 `실행예외`는 모든 한국어 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, নথিপত্ৰ·통신 전체를 잡으려면 `catch (입출력예외 ত্ৰুটি)`를 쓴다.
한국어 API가 표준 ইনপুট_আউটপুট 오류를 한국어 예외로 변환한다.
기존 한국어 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
예외 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 자체 JVM에 이 20종을 추가했다. 임의의 ব্যৱহাৰকৰ্তা Throwable 하위 শ্ৰেণী_মান 전체를
지원하도록 확장했다는 뜻은 아니다.

## বিল্ড_উৎস·নিষ্পাদন_আদেশ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make বিল্ড_ছিষ্টেম
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 সঁজুলিসমূহ/নিষ্পাদন_ফাইল.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 ব্যৱহাৰকৰ্তা JVM ELF 안에 탑재된다. `.jar`는 হ_ষ্ট javac의
শ্ৰেণী_মান 경로로 사용한다. উৎস_ট্ৰি 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 한국어 예외의 `throws` 선언과 그 import를 인식한다.
자체 JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·অবজেক্ট_মান·소켓 예제 전체의 উৎস_ট্ৰি 컴파일은 হ_ষ্ট javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 수 있다.

প্ৰকৃত_ডাটা TCP/UDP 예제는 [네트워크예제.java](../../../example/java/네트워크예제.java),
নিষ্পাদন_আদেশ 절차는 [example ৰিডমি_ফাইল_eb81d7d9](../../../example/README.md),
উৎস_ট্ৰি 명명 원칙은 [명명 ৰিডমি_ফাইল_eb81d7d9](../명명/ৰিডমি_ফাইল_eb81d7d9.md)에 있다.

## Swing উইণ্ড 예제

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` পৰৱৰ্তী_আইটেম `java 창예제`로 연다. নাম 입력, 인사하기 버튼,
인사말과 ক্লিক_কৰক_মান 횟수 সতেজ_কৰক, X 닫기를 지원한다.

| 기능 | 한국어 직접 API |
|---|---|
| Runnable / run | `실행할일.চলাওক()` |
| ActionListener / actionPerformed | `동작받이.동작받기(동작알림 알림)` |
| ActionEvent | `동작알림.আদেশ_পাঠ()`, `ইভেণ্ট_উৎস()`, `ইনডেক্স()` |
| JFrame | `উইণ্ড(উইণ্ড_শিৰোনাম, 폭, 높이)`, `যোগ_কৰক_উপাদান(화면구성요소)`, `শ্ব_উইণ্ড()`, `বন্ধ_কৰক()`, `보이는가()` |
| JButton | `বুটাম(টেক্সট, 가로, উলম্ব_স্থান_সলনি_কৰক, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `লেবেল(...)`, `পাঠৰ_ক্ষেত্ৰ(...)` |
| 공통 화면 উপাদান_মান | `화면구성요소.글읽기()`, `লিখক_পাঠ(টেক্সট)`, `자리정하기(가로, উলম্ব_স্থান_সলনি_কৰক, 폭, 높이)` |
| SwingUtilities.invokeLater | `ইভেণ্ট_লানি.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `আৰম্ভ_কার্য্য()`, `기다리기()`, `살아있는가()`, `নিলম্বিত_কার্য্য()` |
| 명령행 | `সঞ্চালন()`, `실행인수.개수()`, `실행인수.টেক্সট(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `প্ৰক্ৰিয়া_আঁহ`가 한국어 শ্ৰেণী_মান·পদ্ধতি_মান·서술자를
해석해 화면 요소와 নিষ্পাদন_আদেশ 가닥을 직접 만든다. কাৰ্য্য 알림도 자체 객체이며
콜백으로 `চলাওক`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 নিষ্পাদন_আদেশ 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 হ_ষ্ট JVM에서 무동작 객체가 생기지 않도록 하는 거부 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. হ_ষ্ট javac로 컴파일한 পাছলৈ_মান 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import 한국어.자체.*;
public class 가닥예제 implements 실행할일 {
    public void চলাওক() { নিৰ্গম.লিখক_লাইন("한국어 작업 নিষ্পাদন_আদেশ"); }
    public static void সঞ্চালন() throws 대기중단예외 {
        작업가닥 আঁহ_মান = 작업.সঞ্চালন(new 가닥예제());
        작업.기다리기(আঁহ_মান);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
শৃঙ্খলা_মান 인수 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 인수 없는 `সঞ্চালন()`을 우선한다.
기존 한국어 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.সঞ্চালন(Runnable)`을 사용하던 코드는 새 한국어 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API সমর্থন_মান 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 শ্ৰেণী_মান·পদ্ধতি_মান 이름과 서술자가 남는다.
한국어 নাম 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·পদ্ধতি_মান 재정의, native সংযোগ_স্থাপনা, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS চিনাক্তকাৰী_মান](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS পদ্ধতি_মান 참조](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
