# 자체 ARM64 Java 커널의 C/C++ নথিপত্ৰ·루프백 সংযোগ_স্থাপনা

이 디렉터리는 `platforms/rpi4-native` 자체 কাৰ্ণেল_মান 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 한국어 함수명과 `extern "C"` ABI를 제공한다. `সংযোগ_স্থাপনা.c`는 কাৰ্ণেল_মান 안에서 AOT Java নথিপত্ৰ 메서드에 직접 연결하고, `ব্যৱহাৰকৰ্তা_ব্ৰীজ.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. প্ৰকৃত_ডাটা নথিপত্ৰ 처리는 `মেম_ৰি_ফাইলসমূহ.java`, 루프백 전문 처리는 `되돌림망.java`, 연결형 흐름은 `ষ্ট্ৰিম_নেটৱৰ্ক.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 কাৰ্ণেল_মান 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·실수 অপাৰেচন_মান·নথিপত্ৰ·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

সমর্থন_মান: `খোলক_ফাইল`, `파일자료읽기`, `লিখক_ফাইল_ডাটা`, `বন্ধ_কৰক_ফাইল`, `ছীক_ফাইল`, `আঁতৰাওক_ফাইল_প্রবিষ্ট_নাম`, `ছেট_ফাইল_দৈর্ঘ্য`, 보조 ফাংছন_মান `ফাইল_আকাৰ_কৰক`. ত্ৰুটি 시 -1과 작업별 `오류번호`를 반환한다. `파일저장확정`은 RAM 파일이므로 ENOSYS를 반환한다. নথিপত্ৰ 16개, 각 16384바이트, নাম 63바이트, 서술자 16개이며 RAM 디렉터리·পীয়েৰ_মান/절대 경로를 제공한다. অনুমতি_মান/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 প্ৰকৃত_ডাটা 한국어 함수와 독립 구조체를 선언한다.
`통신종단점만들기`, `বান্ধক_ঠিকনা`, `자료전문보내기/받기`, `সংযোগ_নেটৱৰ্ক/기다리기/받기`는
`ব্যৱহাৰকৰ্তা_ব্ৰীজ.c`에서 SVC를 호출하며 মেক্ৰ_মান 별칭이 아니다. `struct 인터넷통신주소`의
`ঠিকনা_পৰিয়াল`, `접속번호`, `ইন্টাৰনেট_ঠিকনা.ঠিকনা_মান`을 사용한다. 상수는 enum의
`ক্লাউড_পৰিয়াল`, `전문통신`, `전문전송규약`, `ষ্ট্ৰিম_নেটৱৰ্ক`, `흐름전송규약`이다.
한국어·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. 외부 통신은 자체 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. প্ৰকৃত_ডাটা Pi 4 GENET 드라이버는 미지원이다.
소켓도 প্ৰকৃত_ডাটা ফাংছন_মান `বন্ধ_কৰক_ফাইল`로 닫는다.
