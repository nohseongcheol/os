# ব্যৱহাৰকৰ্তা 호출 경계

대상은 jkoros i386 ELF32다. Linux i386의 호출 번호와 바이너리 호환이 아니다. C의 cdecl 인수를 `মেচিন/অপাৰেটিং_ছিষ্টেম_কলসমূহ.s`에서 EAX(ইনডেক্স), EBX·ECX·EDX·ESI·EDI(첫째~다섯째 인수)로 변환한다. EBX·ESI·EDI·EBP를 보존하며 결과는 EAX다. কাৰ্ণেল_মান 실패는 음수 ত্ৰুটি ইনডেক্স, C লাইব্ৰেৰী 실패는 -1과 양수 errno다.

커널은 0x04000000 이상, 0x04400000 미만의 ব্যৱহাৰকৰ্তা 영역 안에 자료의 전체 길이가 들어가는지 확인한다. 단순 널 검사가 아니다. C ডাটা 주소는 বাইট_মান 주소이며, 기존 Java AOT `int[]` 포인터와 혼용하지 않는다. Java নথিপত্ৰ 흐름의 어셈블리 경계가 별도 বাইট_মান 버퍼를 마련하여 같은 호출을 사용한다.

| ইনডেক্স | কাৰ্য্য | 인수 |
|---|---|---|
| 30 | খোলক_ফাইল | NUL 끝 নাম ঠিকনা, বৈশিষ্ট্য, 허가 |
| 31 | 파일자료읽기 | 서술자, ডাটা ঠিকনা, বাইট_মান 수 |
| 32 | লিখক_ফাইল_ডাটা | 서술자, ডাটা ঠিকনা, বাইট_মান 수 |
| 33 | বন্ধ_কৰক_ফাইল | 서술자 |
| 34 | ছীক_ফাইল | 서술자, এনকোডিং_মান 있는 অফছেট_মান, 기준 |
| 35 | 파일서술자복제 | 서술자 |
| 36 | 파일서술자지정복제 | 서술자, 새 서술자 |
| 37 | 파일상태읽기 | 서술자, 48바이트 অৱস্থা_মান ঠিকনা |
| 38 | আঁতৰাওক_ফাইল_প্রবিষ্ট_নাম | NUL 끝 নাম ঠিকনা |
| 39 | ছেট_ফাইল_দৈর্ঘ্য | 서술자, 새 দৈর্ঘ্য_মান |
| 40 | 파일서술자제어 | 서술자, কমান্ড, মান |
| 41 | 통신종단점만들기 | ঠিকনা অপাৰেটিং_ছিষ্টেম_মান, 종류, কেছ_মান ইনডেক্স |
| 42 | বান্ধক_ঠিকনা | 서술자, sockaddr_in ঠিকনা, দৈর্ঘ্য_মান |
| 43 | 자료전문보내기 | 서술자, ডাটা ঠিকনা, দৈর্ঘ্য_মান, বৈশিষ্ট্য, 요청 ঠিকনা |
| 44 | 자료전문받기 | 서술자, ডাটা ঠিকনা, দৈর্ঘ্য_মান, বৈশিষ্ট্য, 요청 ঠিকনা |
| 45 | 통신주소읽기 | 서술자, sockaddr ঠিকনা, socklen_t ঠিকনা |
| 46 | 수신대기정하기 | 서술자, 0~2000 밀리초 |
| 47 | 파일저장확정 | 서술자 |

43번 요청은 32비트 주소와 32비트 길이의 두 칸이다. 44번 요청은 32비트 주소와 길이를 담은 32비트 값의 ঠিকনা 두 칸이다. 수신 주소가 NULL이면 পীয়েৰ_মান ঠিকনা 기록을 생략한다. sockaddr_in은 16바이트이며 ঠিকনা 체계는 চেলফোন_মান বাইট_মান 차례, 접속번호와 IP 주소는 네트워크 বাইট_মান 차례다. 축소된 ঠিকনা 버퍼에도 들어가는 앞부분을 쓰고 전체 ঠিকনা মাপ 16을 반환한다.

0~22번의 기존 Java AOT 호출은 유지한다. 0은 প্ৰস্থান_এপ্প্, 2·3은 기존 인수 조회다. 현재 커널의 인수 목록이 নিষ্পাদন_আদেশ 이름을 제외하므로 C 진입기는 argv[0]에 고정 ষ্ট্ৰিং_মান `jkoros-app`을 넣고 이후 인수를 전달한다. argv 끝에는 NULL이 있다. 이 제한도 일반 UNIX প্ৰক্ৰিয়া_মান ABI와 다른 점이다.

표준 헤더의 পূর্ণ_সংখ্যা মাপ, 플래그 মান, stat ফিল্ড_মান 순서는 `উৎস/포함/`에 정의한다. 동적 সংযোগ_স্থাপনা·다중 প্ৰক্ৰিয়া_মান·스레드가 추가되면 ত্ৰুটি ইনডেক্স 저장과 সম্পদ_মান 수명, 호출 경계도 함께 검토해야 한다.
