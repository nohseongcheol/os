# engos 기능 대응표

이 표는 기존 `লীগেছি_উৎস/`의 অবজেক্ট_মান 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [প্ৰকৃত_ডাটা 부팅 기능과 한계](../os/ৰিডমি_ফাইল_eb81d7d9.md)를 따로 기록한다.

## 기존 অবজেক্ট_মান 기반 관리 কাৰ্ণেল_মান 전체를 부팅하기 위해 남은 সংযোগ_স্থাপনা

পৰৱৰ্তী_আইটেম 항목은 Java 문법만으로 실행할 수 없는 CPU/চেলফোন_মান 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot প্রবিষ্ট_পইণ্ট_মান, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 প্ৰসংগ_মান জমা_কৰক_মান
- প্ৰকৃত_ডাটা PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA লুপ_মান
- Java অবজেক্ট_মান·শৃঙ্খলা_মান লিংক_লেআউট, 예외, স্থিৰ_মান আৰম্ভণি_কৰক, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT ষ্টেজ_মান
- FAT 디스크 구역을 প্ৰকৃত_ডাটা ATA 장치와 연결하는 ইনপুট_আউটপুট 접착 তৰপ_মান

위 관리 계층은 engos 기능의 Java 관리 구현과 হ_ষ্ট 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot প্রবিষ্ট_পইণ্ট_মান, স্থিৰ_মান আৰম্ভণি_কৰক·পূর্ণ_সংখ্যা শৃঙ্খলা_মান, VGA/직렬/PS2, 명령해석기, ব্যৱহাৰকৰ্তা ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 হ_ষ্ট 루프백 패킷 왕복을 검증했다. 위 표의 অবজেক্ট_মান 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
