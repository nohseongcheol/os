# 전체 সমর্থন_মান 요청의 현재 অৱস্থা_মান

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 প্ৰকৃত_ডাটা C POSIX 일부 기능, 한국어 API/উৎস নাম, IDE নথিপত্ৰ 보존, 게스트 Java নথিপত্ৰ 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/ৰিডমি_ফাইল_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 নিষ্পাদন_আদেশ 가능한 ক্লিপ | 전체 지원에 필요한 작업 |
|---|---|---|
| Java বিল্ড_উৎস·নিষ্পাদন_আদেশ | 게스트 제한형 javac/JVM, স্থিৰ_মান 단일 클래스와 일부 표준 অবজেক্ট_মান | 일반 অবজেক্ট_মান·শ্ৰেণী_মান সংযোগ_স্থাপনা·예외·GC·스레드, 완전한 javac와 표준 শ্ৰেণী_মান লাইব্ৰেৰী |
| নথিপত্ৰ | POSIX 서술자, Java 단일 বাইট_মান নথিপত্ৰ ষ্ট্ৰিম_মান, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·অনুমতি_মান·잠금·일반 ফাইল_ছিষ্টেম·সম্প্রসাৰণ_মান 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP হ_ষ্ট 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 ইভেণ্ট·ফ_ন্ট_মান·উইণ্ড অপাৰেটিং_ছিষ্টেম_মান, AWT 네이티브 연결과 Swing নিষ্পাদন_আদেশ 기반 |
| POSIX | 문서화한 নথিপত্ৰ·단말·UDP 부분 | প্ৰক্ৰিয়া_মান·exec/fork·스레드·시그널·시간·mmap·poll·파이프 등과 적합성 বৈধকৰণ_কৰক |
| 언어별 নাম | 한국어 46개 대응 প্রবিষ্ট_মান, প্ৰকৃত_ডাটা C/Java/নথিপত্ৰ নাম 적용 | লক্ষ্য ভাষা 확정, 언어별 용례·역사 근거와 해당 উৎস·도구의 বৈধকৰণ_কৰক |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 নিষ্পাদন_আদেশ 환경을 추가하는 방식은 별도의 কাৰ্ণেল_মান·루트 ফাইল_ছিষ্টেম·OpenJDK·그래픽 ছাৰ্ভাৰ_মান·영구 জমা_কৰক_মান 구성을 가진 নিষ্পাদন_আদেশ 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

নিষ্পাদন_আদেশ 기반과 추가 লক্ষ্য 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
