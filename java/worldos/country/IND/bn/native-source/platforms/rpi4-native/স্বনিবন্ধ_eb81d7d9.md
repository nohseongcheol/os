# Raspberry Pi 4 নিজ Java কারনেল_মান — ব্যবহারকারী কার্যকর_করুন_আদেশ 기반

현재 নিজ 코드의 COSL 상업 শর্ত, 제3자 고지 및 LGPL 재연결 자료는 [COSL 배포 স্বনিবন্ধ_eb81d7d9](COSL배포안내.md)를 참고한다. সুইচ_মোড 전 GPL 구성의 판단은 [이전 라이선스 검토](লাইসেন্স_পর্যালোচনা.md)에 기록했다.

বাংলা 통신·ব্যতিক্রম 사용법은 [বাংলা Java API](한국어자바/স্বনিবন্ধ_eb81d7d9.md), ফাংশন_মান·변수·নথির_নাম 이름의 변경과 어원 근거는 [명명 স্বনিবন্ধ_eb81d7d9](명명/স্বনিবন্ধ_eb81d7d9.md)를 참고한다.

Linux 없이 부팅하는 নিজ AArch64 커널이다. Java AOT কারনেল_মান 위에 **আদেশ_পংক্তি শেল, 게스트 Java 컴파일러·JVM, MicroPython, EL0 C++ কার্যকর_করুন_আদেশ, নথির_নাম·UDP 루프백 시스템 호출, 여러 한글 GUI আদেশ_ব্যাখ্যাকারী·vi সম্পাদক·Swing 부분집합**을 제공한다. 커널의 নথির_নাম ডাটা/정책·루프백 স্থানান্তর_মান·শেল 상태는 Java, 화면 합성·পেল্ পরিবর্তন_করা_মান·নির্দেশক·클리핑도 Java로 구현하며, CPU/MMU/ডিভাইস_মান 경계와 আদেশ_ব্যাখ্যাকারী·অক্ষর_মান 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 নিজ 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 কার্যকর_করুন_আদেশ, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 ওয়্যার্ড_মান 송수신은 아직 미검증이다.** কার্যকর_করুন_আদেশ·সংযোগ_e05f319b·পাসওয়ার্ড_মান 확인은 [외부 সংযোগ_e05f319b স্বনিবন্ধ_eb81d7d9](외부접속안내.md)에 정리했다.

셸은 EL1 কারনেল_মান, `java` 등 ব্যবহারকারী কার্যকর_করুন_আদেশ 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 কার্যকর_করুন_আদেশ·সংযোগ_e05f319b 방법 및 প্রকৃত_ডাটা 검증은
[কার্যকর_করুন_আদেশ 계층과 외부 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 প্রকৃত_ডাটা কার্যকর_করুন_আদেশ 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 স্থির_মান ELF는 `run --linux ফাইল_নাম_পাঠ`으로 실행한다. [ELF·Linux ABI সমর্থন_মান 범위와 동일 바이너리 시험](실행파일규약.md).

GUI와 네트워크는 `python3 সরঞ্জামগুলি/কার্যকর_করুন_আদেশ.py --desktop --network`로 함께 사용한다. Java·C·Python의 বাংলা 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 부팅 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 수 있다. Remmina에서 **F9/Shift+Space/한·영 কী_মান**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·প্রকৃত_ডাটা TCP/UDP·নথির_নাম বাইট_মান·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java জানালানমুনা`로 বাংলা Swing 예제를 실행한다. আদেশ_ব্যাখ্যাকারী 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 현재 কলাম_মান·সারি_মান 수를 보여 준다.

কার্যকর_করুন_আদেশ 버튼 화면은 5×7 영문 글꼴을 쓰며, আদেশ_ব্যাখ্যাকারী 창은 Noto CJK/DejaVu에서 생성한 한글·Unicode 비트맵 글꼴을 쓴다. UART와 প্রকৃত_ডাটা 프레임버퍼의 한글 표시를 시험한다. 루프백은 동일 কারনেল_মান 내부의 전문 전달이며 IP 패킷을 Ethernet으로 내보내는 드라이버가 아니다. 바깥 IPv4는 lwIP TCP/UDP 스택으로 보조 UART SLIP 경로를 사용한다. `python3 সরঞ্জামগুলি/কার্যকর_করুন_আদেশ.py --network`로 QEMU NAT를 연결하고 `ftpd start`로 서비스를 시작한다.

Java의 정확한 API·문법·কার্যকর_করুন_আদেশ 제한과 বাংলা 사용법은 [নিজ JVM과 বাংলা লাইব্রেরি](자바실행환경.md)에 정리했다. শ্রেণী_মান নথির_নাম/JAR 배포는 [한국어자바](한국어자바) 소스에서 재현한다. 기존 Linux판 `বাংলা.자바`와 별도인 `বাংলা.নিজ` 패키지다.

**vi·여러 উইন্ডো·Swing·한글 Java/Python/C/C++·posix-kor 예제는 [한글 개발 매뉴얼](개발안내.md)에 정리했다.**

GUI আদেশ_ব্যাখ্যাকারী কার্যকর_করুন_আদেশ·단축키·শেল আদেশ·제한은 [셸과 আদেশ_ব্যাখ্যাকারী 사용법](셸과터미널.md)에 정리했다.

## 현재 컴퓨터에서 কার্যকর_করুন_আদেশ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

প্রস্থান_অ্যাপ: **Ctrl+A পরবর্তী_দফা X**. 게스트 C/AOT সরঞ্জামগুলি 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. হোস্ট 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. 컴파일러 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/পথ_2/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` সমর্থন_মান 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 কার্যকর_করুন_আদেশ**한다. 기존 한 অক্ষর_মান 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 আর্গুমেন্ট_তালিকা 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

| আদেশ | কাজ |
|---|---|
| `help` / `info` | আদেশ·প্রকৃত_ডাটা 구현 অবস্হা_মান |
| `ls` / `cat FILE` / `rm FILE` | RAM নথির_নাম ভুক্তি_তালিকা·সামগ্রি_মান·삭제 |
| `vi FILE` | ব্যবহারকারী 영역 vi 부분집합, 한글 সম্পাদন_মান·ভাণ্ডার_মান·검색·되돌리기 |
| `edit FILE` | নথির_নাম 전체를 새로 입력; 단독 `.` 줄로 ভাণ্ডার_মান, Ctrl-C로 বাতিল_অপারেশন |
| `javac FILE.java` / `java CLASS [ARGS]` | নিজ 제한형 Java গঠন_উত্স·কার্যকর_করুন_আদেশ |
| `python FILE.py [ARGS]` / `python -c 'CODE'` | MicroPython গঠন_উত্স·কার্যকর_করুন_আদেশ |
| `load FILE` / `hex FILE` | 16진수 바이너리 입력/নির্গম; 입력은 단독 `.` 줄로 ভাণ্ডার_মান |
| `run FILE.elf [ARGS]` / `run cpp` | 업로드한 নিজ ABI ELF / 내장 C++ 예제 |
| `net test` / `tasks` / `selftest` | UDP 루프백 / 협력식 작업 / EL0 রক্ষা_করুন_মান 시험 |
| `gui` / `terminal` | কার্যকর_করুন_আদেশ 화면 / 한글 GUI আদেশ_ব্যাখ্যাকারী; F12로 আদেশ_ব্যাখ্যাকারী খুলুন·বন্ধ_করুন |
| `samples` | 삭제한 অমনোনীত_মান 예제 পুনরুদ্ধার_অবস্হা; 기존 파일은 보존 |

예를 들어 `edit 인사.java`를 입력한 পরবর্তী_দফা 아래 소스를 입력한다.

```java
public class 인사 { public static void main(String[] args) { int মান = 7; System.out.println("한글=" + মান); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 인사.java`, `java 인사`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. বাতিল_অপারেশন·잘못된 16진수·용량 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, কার্যকর_করুন_আদেশ 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 আদেশ 인수는 최대 32개다. কোট·백슬래시·শেল 변수·파이프·리다이렉션 범위는 [শেল 설명](셸과터미널.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, ইমেইল **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode 입력·명시적 লেপন_করা_মান·কার্যকর_করুন_আদেশ 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 সরঞ্জামগুলি/কার্যকর_করুন_আদেশ.py --desktop --network
# 다른 হার্ডওয়্যার_পোর্ট: python3 সরঞ্জামগুলি/কার্যকর_করুন_আদেশ.py --desktop --port 5903
```

종료는 실행한 হোস্ট 터미널에서 Ctrl+C다. 기존 `python3 সরঞ্জামগুলি/কার্যকর_করুন_আদেশ.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. প্রকৃত_ডাটা Pi4 USB 입력기는 아직 없으며, VNC সংযোগ_স্থাপনা 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 প্রকৃত_ডাটা C++/UDP ELF কার্যকর_করুন_আদেশ, `Hello.java` গঠন_উত্স 후 JVM কার্যকর_করুন_আদেশ, `hello.py` কার্যকর_করুন_আদেশ, GUI আদেশ_ব্যাখ্যাকারী 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 মিথস্ক্রিয় 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 মেমরি_ডাটা·CPU 문맥을 보관한다. শেল·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

예비 microSD에 গঠন_ছবি লগ_সারি 도구로 `.img`를 기록하거나 FAT32 부팅 파티션 최상위에 ZIP 내용을 푼다. গঠন_ছবি 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 অমনোনীত_মান EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD নথির_নাম 구성·কারনেল_মান 체크섬 검사와 물리 বোর্ড 부팅 검증은 별개다. MMU 사용 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 부팅 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 বাংলা API 사용

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/ফাইলনমুনা.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int শুরু_ব্যবহারকারী_অ্যাপ(int)`이다. ব্যবহারকারী C++는 FP/SIMD를 사용할 수 있다. কারনেল_মান C/Java AOT는 일반 레지스터만 사용하므로 ব্যতিক্রম প্রসেসর_মান_ভুক্তি 중 ব্যবহারকারী FP 상태를 건드리지 않는다. ব্যবহারকারী ভুক্তি_বিন্দু_মান 시 FP 상태를 초기화하고 কারনেল_মান 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int শুরু_ব্যবহারকারী_অ্যাপ(int) {
    int নথির_নাম = খোলা_ফাইল("인사.txt", পঠন_লিখন | 없으면만들기 | 내용비우기, 0600);
    if (নথির_নাম < 0) return 1;
    const char সামগ্রি_মান[] = "안녕하세요";
    int পরিমাপ = লেখা_ফাইল_ডাটা(নথির_নাম, সামগ্রি_মান, sizeof(সামগ্রি_মান) - 1);
    বন্ধ_ফাইল(নথির_নাম);
    return পরিমাপ == sizeof(সামগ্রি_মান) - 1 ? 0 : 2;
}
```

[নথির_নাম 예제](ব্যবহারকারী/ফাইলনমুনা.cpp)와 [통신 예제](ব্যবহারকারী/통신예제.cpp)가 প্রকৃত_ডাটা 부팅 시험 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 নথির_নাম প্রসেসর_মান_ভুক্তি 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 소켓 함수는 현재 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 কারনেল_মান 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 পরবর্তী_দফা 도구를 사용하면 **새 QEMU를 부팅해 업로드한 প্রকৃত_ডাটা 바이트를 재확인한 ফিরে_যান_মান 게스트에서 কার্যকর_করুন_আদেশ**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 সরঞ্জামগুলি/কার্যকর_করুন_ফাইল.py build/jkoros-native-sdk/demo.elf
python3 সরঞ্জামগুলি/কার্যকর_করুন_ফাইল.py 예제/Hello.java "한글 আর্গুমেন্ট_তালিকা"
python3 সরঞ্জামগুলি/কার্যকর_করুন_ফাইল.py 예제/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 কারনেল_মান 묶음에 포함되어 이 নথির_নাম 한도를 적용받지 않는다. **C++ 컴파일러는 হোস্ট SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 লাইব্রেরি, PT_TLS, PT_INTERP, PT_DYNAMIC, কার্যকর_করুন_আদেশ·লেখা 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 সূচি·ইমেইল ক্লিপ·오류는 [ব্যবহারকারী ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `파일저장확정`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 অনুমতি_মান·dup/fcntl은 없다. 디렉터리와 পিয়ার_মান/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, 수신 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. ব্যবহারকারী প্রস্থান_অ্যাপ 시 열린 নথির_নাম 서술자와 소켓을 회수한다.

## বৈধ_করুন পরিমাপ

`make test-jvm`은 9개 프로그램을 OpenJDK와 প্রকৃত_ডাটা নিজ 커널에서 실행해 결과를 비교한다. `make test`에도 포함된다. 별도 `সরঞ্জামগুলি/부팅시험.py`는 Java 사각형 API의 প্রকৃত_ডাটা 화면 픽셀까지 검사한다. `make test-shell`, `make test-desktop`은 새 셸과 প্রকৃত_ডাটা VNC 입력·한글 আদেশ_ব্যাখ্যাকারী 화면을 검사하며 `make test`에도 포함된다.

`make test-windows`, `make test-swing`, `make test-stream`, `make test-coding`도 제공하며 `make test`에 포함된다.

`make test`는 OpenJDK와 AOT অপারেশন_মান পরিমাপ 비교, 런타임 ত্রুটি 중단, 미지원 Java 거부와 함께 별도 QEMU VM에서 다음을 검사한다.

- 기존 Java কারনেল_মান 계산·UTF-8·C++ 직접 호출·협력식 작업 및 프레임버퍼.
- 손상/잘못된 ABI/ইমেইল 초과/겹친 페이지/W+X 등 ELF প্রত্যাখ্যান_মান 사례 22개.
- EL0 C++ 생성자·RAII·실수 অপারেশন_মান·নথির_নাম·힙 및 잘못된 시스템 호출 নির্দেশক.
- কারনেল_মান/কোড_মান/MMIO লেখা·অ্যাক্সেস_ভুক্তি, NX 스택·NULL কার্যকর_করুন_আদেশ, guard page, 특권 আদেশ 차단.
- SVC를 호출하지 않는 무한 반복을 타이머로 종료한 후 정상 অ্যাপ_f5044b9b 재실행.
- পুনরুক্তি_মান কার্যকর_করুন_আদেশ 시 নথির_নাম/소켓 누수 방지, UDP 왕복·보낸 ইমেইল·잘린 수신·큐 포화·빈 전문·미지원 통신 ত্রুটি.
- শেল সম্পাদন_মান·বাতিল_অপারেশন·16진수 업로드/다운로드·ব্যবহারকারী ELF 실행과 잘못된 ELF প্রত্যাখ্যান_মান.
- 게스트 Java → OpenJDK `-Xverify:all`, OpenJDK → 게스트 JVM 교차 কার্যকর_করুন_আদেশ, 한글 শ্রেণী_মান·변수·ফাইল_নাম_পাঠ.
- 여러 উইন্ডো·vi ভাণ্ডার_মান·সম্পাদন_মান·되돌림·ব্যবহারকারী অবস্হা_মান 중단/재개, Swing 한글 입력·이벤트·X বন্ধ_করুন, 연결형 루프백, C/C++ 한글 SDK 예제.

## Java와 Python의 정확한 ক্লিপ

নিজ `javac`는 버전 49 `.class`를 생성하며 JVM은 সমর্থন_মান 명령으로 구성된 버전 45–52 클래스를 실행한다. স্থির_মান ফাংশন_মান·재귀·int/boolean/char/String·শর্ত/পুনরুক্তি_মান·স্ট্রিং_মান 결합과 일부 নথির_নাম 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/조합 자모 식별자를 처리한다. Unicode সনাক্তকারী_মান 전체 লুকআপ_সারণি·Unicode উত্স_ট্রী 이스케이프는 구현하지 않았다. 게스트 উত্স_ট্রী 컴파일러는 일반 বস্তু_মান·ব্যতিক্রম·Thread 구문을 아직 컴파일하지 못한다. হোস্ট `javac --release 8`로 만든 সমর্থন_মান 부분집합 클래스는 নিজ JVM 0.4의 বস্তু_মান·ব্যতিক্রম·Thread·UDP와 বাংলা API를 사용할 수 있다. Swing은 문서화한 নিজ API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [নিজ JVM 설명](자바실행환경.md)이 기준이다. 상세 ভাষা 범위는 [공유 Java সরঞ্জামগুলি 설명](../../문서/자바개발환경.md)을 참고하되, 그 문서의 x86 শেল/ভাণ্ডার_মান/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 উত্স_ট্রী**를 নিজ AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 ফাংশন_মান·শ্রেণী_মান·ব্যতিক্রম·리스트/অভিধান·Unicode·GC·가변 정밀도 정수를 제공한다. 현재 구성은 পূর্ণসংখ্যা 빌드로 `float`, `complex`, `math`가 없으며 CPython 전체 표준 লাইব্রেরি, pip, subprocess, threading, 일반 socket과 অমনোনীত_মান `open()` নথির_নাম 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 বস্তু_মান·모듈은 প্রস্থান_অ্যাপ 시 회수되고 RAM 파일만 পরবর্তী_দফা 실행에 남는다.

`import jkoros`로 পরবর্তী_দফা 시스템 연결을 쓴다. 모두 SVC를 통해 নিজ Java 커널에 접근한다.

| ফাংশন_মান | কাজ |
|---|---|
| `stdin(limit)` | 현재 표준 입력에서 최대 limit바이트(0…16384)를 bytes로 읽음; EOF는 빈 bytes, UART ডাটা 없음은 OSError(11) |
| `read(name)` | পিয়ার_মান/절대 RAM 경로의 নথির_নাম 전체를 bytes로 읽음 |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 ভাণ্ডার_মান, 쓴 বাইট_মান 수 반환 |
| `remove(name)` | RAM নথির_নাম 삭제 |
| `rect(x, y, w, h, color)` | 선택한 প্রকৃত_ডাটা 화면 আকার 안의 사각형 অঙ্কন_মান; 기존 보드의 RGB32 মান |
| `ticks_ms()` | 부팅 후 밀리초, 32비트 চক্র_মান |
| `udp_open(port)` | 127.0.0.1의 UDP 소켓 খুলুন/묶기; 0은 자동 হার্ডওয়্যার_পোর্ট |
| `udp_send(fd, port, data)` | 루프백 গন্তব্য_মান 포트에 str/bytes 버퍼 স্থানান্তর_মান |
| `udp_recv(fd)` | `(bytes, 보낸포트)` 반환; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | 소켓 বন্ধ_করুন |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```

이식 কোড_মান: [python/](파이썬연결/), [ব্যবহারকারী Java সংযোগ_স্থাপনা](ব্যবহারকারী/자바연결.c). 공식 [MicroPython 이식 স্বনিবন্ধ_eb81d7d9](https://docs.micropython.org/en/latest/develop/porting.html)를 참고했다. উত্স_ট্রী URL·হ্যাশ_ফাইল·라이선스는 [vendor স্বনিবন্ধ_eb81d7d9](vendor/README.md)에 기록했다.

## বাংলা C ডেটা_ধরণ·Python ত্রুটি·পাঁজা ইনস্টল_করুন_মান

C 네트워크 API는 `struct 인터넷통신주소`, enum 상수와 প্রকৃত_ডাটা বাংলা 함수로
구현한다. ম্যাক্রো_মান 별칭을 사용하지 않으며 이전 pk_* ABI도 유지한다.
Python 예제는 `সিস্টেম_ত্রুটি`, `ত্রুটি.সূচি`, `ত্রুটি.설명`을 사용한다.

`python3 সরঞ্জামগুলি/কার্যকর_করুন_আদেশ.py --desktop --network --pip`로 시작하면 게스트에서
`pip install micropython-bisect==3.3.3`을 사용할 수 있다. 현재는 হোস্ট 중계를
이용하는 제한형 MicroPython উত্স_ট্রী 설치기이며 CPython pip·자동 의존성 해결·C 확장은
미지원이다. 설치한 `/lib` 자료는 RAM이다. [사용법과 제한](파이썬꾸러미.md).

## 화면 আকার বাছাই_মান

`python3 সরঞ্জামগুলি/কার্যকর_করুন_আদেশ.py --desktop --network --resolution 1920x1080`으로 Full HD 화면을 사용한다. 기본값은 640×480이며 1280×720도 가능하다. আদেশ_ব্যাখ্যাকারী অপসারণ_করা_মান, Swing 가운데 লিংক_লেআউট, Java·C·Python 그리기도 প্রকৃত_ডাটা 크기를 따른다. SD 영상은 `make image RESOLUTION=1920x1080`으로 만든다. [সেটিংস·বাংলা API·বৈধ_করুন স্বনিবন্ধ_eb81d7d9](화면해상도.md).

## বাংলা 직접 API와 화면 রিফ্রেশ

`example/java`는 `실행할일`, `동작받이`, `동작알림`, `বোতাম`, `ঘটনা_সারিবদ্ধ`,
`작업가닥`, `চালনা()`을 사용할 수 있다. বাংলা GUI/가닥을 নিজ JVM에 직접
