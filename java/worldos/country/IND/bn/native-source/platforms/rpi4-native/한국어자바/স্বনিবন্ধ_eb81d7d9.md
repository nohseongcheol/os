# বাংলা Java 통신·ইনপুট_আউটপুট·ব্যতিক্রম API

패키지는 `বাংলা.নিজ`다. হোস্ট `javac --release 8`로 컴파일한 class를
নিজ ARM64 커널의 JVM에서 실행한다. 통신·নথির_নাম·ব্যতিক্রম API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 থ্রেড_মান API는 নিজ JVM 전용이다.
기존 표준 Java লাইব্রেরি 전체의 বাংলা 번역판은 아니다.

```java
import বাংলা.নিজ.*;

public class নেটওয়ার্ক_9b2e3222 {
    public static void main(String[] আর্গুমেন্ট_তালিকা) throws ইনপুট_আউটপুট_ব্যতিক্রম {
        সংযোগ সংযোগ_স্থাপনা = সংযোগ.খুলুন("10.0.2.2", 9000);
        try {
            সংযোগ_স্থাপনা.টাইমআউট(700);
            সংযোগ_স্থাপনা.নির্গম().লেখা(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = সংযোগ_স্থাপনা.입력();
            নির্গম.수쓰기(입력.পড়া());
        } catch (অপেক্ষা_টাইমআউট_ব্যতিক্রম ত্রুটি) {
            নির্গম.লেখা_লাইন(ত্রুটি.설명());
        } finally {
            সংযোগ_স্থাপনা.বন্ধ_করুন();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
ব্যবহারকারী 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 স্ট্রিং_মান 리터럴에 사용하는 표준 클래스다. নিজ 실행기는 `public static void চালনা()`도 진입점으로 받는다.

## 통신과 প্রবাহ_মান

| শ্রেণী_মান | বাংলা 호출 |
|---|---|
| সংযোগ | `খুলুন(ইমেইল, পোর্ট_নম্বর)`, `입력()`, `নির্গম()`, `টাইমআউট(밀리초)`, `পোর্ট_নম্বর()`, `স্থানীয়_পোর্ট_নম্বর()`, `연결됨()`, `닫힘()`, `বন্ধ_করুন()` |
| 수신창구 | `খুলুন(পোর্ট_নম্বর)`, `받기()`, `পোর্ট_নম্বর()`, `টাইমআউট(밀리초)`, `닫힘()`, `বন্ধ_করুন()` |
| 입력흐름 | `পড়া()`, `পড়া(byte[])`, `পড়া(byte[], চালনা, দৈর্ঘ্য_মান)`, `বন্ধ_করুন()` |
| 출력흐름 | `লেখা(int)`, `লেখা(byte[])`, `লেখা(byte[], চালনা, দৈর্ঘ্য_মান)`, `내보내기()`, `বন্ধ_করুন()` |
| 전문통로 | `খুলুন(পোর্ট_নম্বর)`, `পাঠান(ইমেইল, পোর্ট_নম্বর, পাঠ)`, `받기()`, `টাইমআউট(밀리초)`, `পোর্ট_নম্বর()`, `닫힘()`, `বন্ধ_করুন()` |
| 연결통신 | `খুলুন(...)`, `수신열기(...)`는 위 বাংলা 객체를 반환 |
| 검사 | `참인지(শর্ত, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`পড়া()`의 নথির_নাম 끝은 -1, অ্যারে_মান 읽기의 반환값은 প্রকৃত_ডাটা 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. পোর্ট_নম্বর 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 নিজ 커널에서 512바이트까지 받으며, 주소는 সংখ্যা_মান IPv4를 사용한다.
`localhost` 루프백 외의 নাম 풀이(DNS)는 নিজ 커널에 아직 없다.

기존 `연결통신.সংযোগ_স্থাপনা/듣기/받기`, `통신.খুলুন/পাঠান/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `সংযোগ`, `수신창구`, `전문통로`를 쓴다.

## বাংলা ব্যতিক্রম

모든 아래 클래스는 অমনোনীত_মান 생성자, `새예외("설명")` 형태의 স্ট্রিং_মান 생성자와
`설명()`을 제공한다. প্রকৃত_ডাটা সৃষ্টি_করুন 문법은 `new অপেক্ষা_টাইমআউট_ব্যতিক্রম("অপেক্ষা_অবস্হা 끝")`이다.

| বাংলা ব্যতিক্রম | 상위 শ্রেণী_মান / 용도 |
|---|---|
| ব্যতিক্রম | `java.lang.Exception`, 직접 던지는 일반 검사 ব্যতিক্রম |
| 실행예외 | `java.lang.RuntimeException` |
| ইনপুট_আউটপুট_ব্যতিক্রম | `java.io.IOException`, বাংলা নথির_নাম·통신 API의 검사 ব্যতিক্রম |
| অপেক্ষা_টাইমআউট_ব্যতিক্রম | `ইনপুট_আউটপুট_ব্যতিক্রম`, 통신 টাইমআউট 초과 |
| ইমেইল_লুকআপ_ব্যতিক্রম | `ইনপুট_আউটপুট_ব্যতিক্রম`, ইমেইল যাচাই_করা বিফলতা_মান |
| 파일없음예외 | `ইনপুট_আউটপুট_ব্যতিক্রম`, নথির_নাম খুলুন বিফলতা_মান |
| 통신예외 | `ইনপুট_আউটপুট_ব্যতিক্রম`, 표준 SocketException 변환 |
| অবৈধ_যুক্তি_ব্যতিক্রম | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `অবৈধ_যুক্তি_ব্যতিক্রম` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| নাল_প্রসঙ্গ_ব্যতিক্রম | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| অবস্হা_ব্যতিক্রম | `java.lang.IllegalStateException` |
| টাইপ_করুন_কাস্ট_ব্যতিক্রম | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| অ্যারে_ভাণ্ডার_বিফলতা | `java.lang.ArrayStoreException` |
| থ্রেড_অবস্হা_ব্যতিক্রম | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 অপেক্ষা_মান 중단 |

`ব্যতিক্রম`와 `실행예외`는 모든 বাংলা 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, নথির_নাম·통신 전체를 잡으려면 `catch (ইনপুট_আউটপুট_ব্যতিক্রম ত্রুটি)`를 쓴다.
বাংলা API가 표준 ইনপুট_আউটপুট 오류를 বাংলা 예외로 변환한다.
기존 বাংলা 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`অপেক্ষা_টাইমআউট_ব্যতিক্রম`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
ব্যতিক্রম 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 নিজ JVM에 이 20종을 추가했다. 임의의 ব্যবহারকারী Throwable 하위 শ্রেণী_মান 전체를
지원하도록 확장했다는 뜻은 아니다.

## গঠন_উত্স·কার্যকর_করুন_আদেশ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make গঠন_সিস্টেম
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 সরঞ্জামগুলি/কার্যকর_করুন_ফাইল.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 ব্যবহারকারী JVM ELF 안에 탑재된다. `.jar`는 হোস্ট javac의
শ্রেণী_মান 경로로 사용한다. উত্স_ট্রী 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 বাংলা 예외의 `throws` 선언과 그 import를 인식한다.
নিজ JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·বস্তু_মান·소켓 예제 전체의 উত্স_ট্রী 컴파일은 হোস্ট javac를 사용한다.
`/example/java/ফাইলনমুনা.java`는 게스트 javac로도 컴파일할 수 있다.

প্রকৃত_ডাটা TCP/UDP 예제는 [নেটওয়ার্ক.java](../../../example/java/নেটওয়ার্ক.java),
কার্যকর_করুন_আদেশ 절차는 [example স্বনিবন্ধ_eb81d7d9](../../../example/README.md),
উত্স_ট্রী 명명 원칙은 [명명 স্বনিবন্ধ_eb81d7d9](../명명/স্বনিবন্ধ_eb81d7d9.md)에 있다.

## Swing উইন্ডো 예제

`/example/java/জানালানমুনা.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` পরবর্তী_দফা `java জানালানমুনা`로 연다. নাম 입력, 인사하기 버튼,
인사말과 ক্লিক_করা_মান 횟수 রিফ্রেশ, X 닫기를 지원한다.

| 기능 | বাংলা 직접 API |
|---|---|
| Runnable / run | `실행할일.চালানো()` |
| ActionListener / actionPerformed | `동작받이.동작받기(동작알림 알림)` |
| ActionEvent | `동작알림.আদেশ_পাঠ()`, `ঘটনা_উত্স()`, `সূচি()` |
| JFrame | `উইন্ডো(উইন্ডো_শিরোনাম, 폭, 높이)`, `যোগ_করা_উপাদান(화면구성요소)`, `শো_উইন্ডো()`, `বন্ধ_করুন()`, `보이는가()` |
| JButton | `বোতাম(পাঠ, 가로, উল্লম্ব_পদ, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `লেবেল(...)`, `পাঠ্য_ক্ষেত্র(...)` |
| 공통 화면 উপাদান_মান | `화면구성요소.글읽기()`, `লেখা_পাঠ(পাঠ)`, `자리정하기(가로, উল্লম্ব_পদ, 폭, 높이)` |
| SwingUtilities.invokeLater | `ঘটনা_সারিবদ্ধ.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `শুরু_কার্য()`, `기다리기()`, `살아있는가()`, `স্থগিত_করুন_কার্য()` |
| 명령행 | `চালনা()`, `실행인수.개수()`, `실행인수.পাঠ(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
নিজ JVM의 `한국어화면호출`, `প্রসেসর_থ্রেড`가 বাংলা শ্রেণী_মান·পদ্ধতি_মান·서술자를
해석해 화면 요소와 কার্যকর_করুন_আদেশ 가닥을 직접 만든다. কাজ 알림도 নিজ 객체이며
콜백으로 `চালানো`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 কার্যকর_করুন_আদেশ 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 নিজ JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 হোস্ট JVM에서 무동작 객체가 생기지 않도록 하는 প্রত্যাখ্যান_মান 경로다.
নিজ JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. হোস্ট javac로 컴파일한 ফিরে_যান_মান নিজ JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import বাংলা.নিজ.*;
public class 가닥예제 implements 실행할일 {
    public void চালানো() { নির্গম.লেখা_লাইন("বাংলা 작업 কার্যকর_করুন_আদেশ"); }
    public static void চালনা() throws 대기중단예외 {
        작업가닥 থ্রেড_মান = 작업.চালনা(new 가닥예제());
        작업.기다리기(থ্রেড_মান);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
অ্যারে_মান আর্গুমেন্ট_তালিকা 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
নিজ 실행기는 আর্গুমেন্ট_তালিকা 없는 `চালনা()`을 우선한다.
기존 বাংলা 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.চালনা(Runnable)`을 사용하던 코드는 새 বাংলা 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API সমর্থন_মান 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 শ্রেণী_মান·পদ্ধতি_মান 이름과 서술자가 남는다.
বাংলা নাম 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·পদ্ধতি_মান 재정의, native সংযোগ_স্থাপনা, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS সনাক্তকারী_মান](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS পদ্ধতি_মান প্রসঙ্গ](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
