# JIndOS 구조

아래는 বস্তু_মান 기반 관리 কারনেল_মান 전체의 লক্ষ্য_বস্তু 구조다. 현재 প্রকৃত_ডাটা 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 অপারেটিং_সিস্টেম স্বনিবন্ধ_eb81d7d9](../os/স্বনিবন্ধ_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·প্রসঙ্গ_মান সুইচ_মোড·ফাইল_পদ্ধতি 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 স্তর_মান
  ↓
Java AOT 실행기와 বস্তু_মান·অ্যারে_মান·GC 런타임
  ↓
হার্ডওয়্যার_মান 경계
  ↓
Java 관리 কারনেল_মান
  ├─ 기억공간/쪽관리/COW
  ├─ প্রসেসর_মান/배정/wait
  ├─ ফাইল_পদ্ধতি/ELF/POSIX
  └─ 입력/স্টোরেজ_ডিভাইস/নেটওয়ার্ক_গাদা
```

OpenJDK 자체는 이미 운영체제가 제공하는 নথির_নাম, 스레드, 가상 기억공간을 전제로 한다. 따라서 কারনেল_মান 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, প্রসঙ্গ_মান 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
