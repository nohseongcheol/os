# 전체 સપોર્ટ_મૂલ્ય 요청의 현재 સ્થિતિ_મૂલ્ય_e10195a1

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 વાસ્તવિક_ડેટા C POSIX 일부 기능, ગુજરાતી API/સ્રોત નામ, IDE ફાઈલ 보존, 게스트 Java ફાઈલ 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/રીડમી_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 અમલ_કરો_આદેશ 가능한 ક્લિપ | 전체 지원에 필요한 작업 |
|---|---|---|
| Java બિલ્ડ_કરો_સ્રોત·અમલ_કરો_આદેશ | 게스트 제한형 javac/JVM, સ્થિર_મૂલ્ય 단일 클래스와 일부 표준 ઑબ્જેક્ટ_મૂલ્ય | 일반 ઑબ્જેક્ટ_મૂલ્ય·વર્ગ_મૂલ્ય સંપર્ક_કરો·예외·GC·스레드, 완전한 javac와 표준 વર્ગ_મૂલ્ય લાઇબ્રેરી |
| ફાઈલ | POSIX 서술자, Java 단일 બાઇટ_મૂલ્ય ફાઈલ સ્ટ્રીમ_મૂલ્ય, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·અનુમતિ_મૂલ્ય·잠금·일반 ફાઇલ_સિસ્ટમ·એક્સ્ટેંશન_મૂલ્ય 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP હોસ્ટ 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 ઇવેંટ·ફૉન્ટ_મૂલ્ય·વિંડો ઑપરેટિંગ_સિસ્ટમ_મૂલ્ય, AWT 네이티브 연결과 Swing અમલ_કરો_આદેશ 기반 |
| POSIX | 문서화한 ફાઈલ·단말·UDP 부분 | પ્રક્રિયા_મૂલ્ય·exec/fork·스레드·시그널·સમય_મૂલ્ય·mmap·poll·파이프 등과 적합성 માન્ય_કરો |
| 언어별 નામ | ગુજરાતી 46개 대응 પ્રવેશ_મૂલ્ય, વાસ્તવિક_ડેટા C/Java/ફાઈલ નામ 적용 | લક્ષ્ય ભાષા 확정, 언어별 용례·역사 근거와 해당 સ્રોત·도구의 માન્ય_કરો |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 અમલ_કરો_આદેશ 환경을 추가하는 방식은 별도의 કર્નેલ_મૂલ્ય·루트 ફાઇલ_સિસ્ટમ·OpenJDK·그래픽 સર્વર_મૂલ્ય·영구 સંગ્રહ_કરવો_મૂલ્ય 구성을 가진 અમલ_કરો_આદેશ 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

અમલ_કરો_આદેશ 기반과 추가 લક્ષ્ય 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
