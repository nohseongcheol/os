# 자체 ARM64 JVM 0.4와 ಕನ್ನಡ ಲೈಬ್ರರಿ

ಕನ್ನಡ 통신·ವಿನಾಯಿತಿ 사용법은 [ಕನ್ನಡ Java API](한국어자바/README_ಫೈಲ್_eb81d7d9.md), ಕಾರ್ಯ_ಮೌಲ್ಯ·변수·ಕಡತ 이름의 변경과 어원 근거는 [명명 README_ಫೈಲ್_eb81d7d9](명명/README_ಫೈಲ್_eb81d7d9.md)를 참고한다.

JAR ಪೂರೈಸು_ಆದೇಶ, 외부 IPv4 TCP/UDP, 별도 ಸ್ಥಾಯಿ_ಮೌಲ್ಯ 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 ಆಬ್ಜೆಕ್ಟ್_ಮೌಲ್ಯ·Thread·Swing은 JVM 경로의 기능이며 AOT ಬೆಂಬಲ_ಮೌಲ್ಯ 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 ಪೂರೈಸು_ಆದೇಶ**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK ವರ್ಗ_ಮೌಲ್ಯ_55654bf1 ಲೈಬ್ರರಿ 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 ವರ್ಗ_ಮೌಲ್ಯ_55654bf1·ಸ್ಥಾಯಿ_ಮೌಲ್ಯ ವಿಧಾನ_ಮೌಲ್ಯ 중심이던 실행기를 ಆಬ್ಜೆಕ್ಟ್_ಮೌಲ್ಯ·ಲೈಬ್ರರಿ ಪೂರೈಸು_ಆದೇಶ 기반으로 넓힌 것이다.

## 실행과 ಸಂಕಲಿಸು_ಮೂಲ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# 자체 ಕರ್ನಲ್_ಮೌಲ್ಯ 안에서 ಮೂಲ_ವೃಕ್ಷ ಸಂಕಲಿಸು_ಮೂಲ → class ಪೂರೈಸು_ಆದೇಶ, ಕನ್ನಡ API 호출
python3 ಪರಿಕರಗಳು/ಪೂರೈಸು_ಫೈಲ್.py 시험/자바/한글소스.java

# ಆಬ್ಜೆಕ್ಟ್_ಮೌಲ್ಯ·ವಿನಾಯಿತಿ 등은 ಹೋಸ್ಟ್ JDK로 Java 8 class를 만든 후 자체 커널에서 ಪೂರೈಸು_ಆದೇಶ
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 ಪರಿಕರಗಳು/ಪೂರೈಸು_ಫೈಲ್.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 ವರ್ಗಾವಣೆ_ಮೌಲ್ಯ
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 ಪರಿಕರಗಳು/ಪೂರೈಸು_ಫೈಲ್.py build/my-java/객체시험.class \
  --include build/my-java/ಹಿನ್ನೆಲೆ_ಮೌಲ್ಯ.class --include build/my-java/ಶಾಖೆ_ಮೌಲ್ಯ.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.ವರ್ಗ_ಮೌಲ್ಯ_55654bf1.class`라는 RAM ಕಡತ 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.ವರ್ಗ_ಮೌಲ್ಯ_55654bf1`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.ವರ್ಗ_ಮೌಲ್ಯ_55654bf1`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar ಕಡತ.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 ಕನ್ನಡ 클래스만 찾는다. 배포 ಕನ್ನಡ ಲೈಬ್ರರಿ JAR는 ಹೋಸ್ಟ್ javac의 classpath로 사용하며, 같은 클래스가 ಬಳಕೆದಾರ JVM ELF에도 ಓದು 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 ಸ್ಥಾಯಿ_ಮೌಲ್ಯ ವಿಧಾನ_ಮೌಲ್ಯ, int/boolean/char/String, ಸ್ಥಿತಿ·ಸ್ಪ್ರಿಂಟ್_ಮೌಲ್ಯ, ಸ್ಟ್ರಿಂಗ್_ಮೌಲ್ಯ 결합, 일부 ಕಡತ 스트림 등의 **자체 부분집합 컴파일러**다. ಆಬ್ಜೆಕ್ಟ್_ಮೌಲ್ಯ ದೃಢೀಕರಣ·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 자체 JVM에서 실행한다. ಕನ್ನಡ API 중 ಔಟ್_ಪುಟ್·문자 스칼라 ಕಾರ್ಯ_ಮೌಲ್ಯ·ಕಡತ ಓದು/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] 인수) throws Exception {
        ಕನ್ನಡ.자체.ಔಟ್_ಪುಟ್.ಬರೆ_ಸಾಲು("안녕하세요😀");
        ಕನ್ನಡ.자체.ಔಟ್_ಪುಟ್.수쓰기(ಕನ್ನಡ.자체.문자.코드포인트수("한글😀"));
        ಕನ್ನಡ.자체.ಕಡತ.ಬರೆ("인사.txt", "한글 ಕಡತ😀");
        ಕನ್ನಡ.자체.ಔಟ್_ಪುಟ್.ಬರೆ_ಸಾಲು(ಕನ್ನಡ.자체.ಕಡತ.ಓದು("인사.txt"));
    }
}
```

## ಕನ್ನಡ API

독립 패키지 **`ಕನ್ನಡ.자체`**를 사용한다. Linux판 `ಕನ್ನಡ.자바`가 요구하는 NIO/Swing/HTTP API를 자체 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 ವರ್ಗ_ಮೌಲ್ಯ_55654bf1 ಹೆಸರು·ವಿಧಾನ_ಮೌಲ್ಯ·인수·ಕ್ಷೇತ್ರ_ಮೌಲ್ಯ·ಕಡತ 이름에 한국어를 사용한다. 표준 Java ವರ್ಗ_ಮೌಲ್ಯ_55654bf1 이름은 호환성을 위해 보존한다.

## ಪೂರೈಸು_ಆದೇಶ 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(ಕನ್ನಡ ವರ್ಗ_ಮೌಲ್ಯ_55654bf1 포함), class당 16 KiB·ಸ್ಧಿರ_ಮೌಲ್ಯ 풀 511항목, 전체 ವಿಧಾನ_ಮೌಲ್ಯ/ಕ್ಷೇತ್ರ_ಮೌಲ್ಯ 각각 512개. ವಿಧಾನ_ಮೌಲ್ಯ ಕೋಡ್_ಮೌಲ್ಯ 8 KiB, ಸ್ಥಳೀಯ_ವ್ಯಾಪ್ತಿ 변수·피연산자 스택 각각 128슬롯, 인수 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 ಪೂರೈಸು_ಆದೇಶ 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- ಆಬ್ಜೆಕ್ಟ್_ಮೌಲ್ಯ 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 ನಿಜವಾದ_ಡೇಟಾ 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 ಕಡತ·대형 ಸ್ಟ್ರಿಂಗ್_ಮೌಲ್ಯ·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 ಆಜ್ಞೆ 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 ವಿಂಡೋ ಸ್ವಿಚ್_ಮಾಡಿ_ಮೋಡ್ 시 중단·재개한다. 일반 ಸರ್ವರ್_ಮೌಲ್ಯ·계산의 무제한 실행은 아직 없다. 미지원 ಆಜ್ಞೆ·ಸಂಪನ್ಮೂಲ_ಮೌಲ್ಯ 부족은 명시적인 오류로 종료한다.
- RAM ಕಡತ 최대 64개, 파일당 16384바이트, ಮಾರ್ಗ UTF-8 63바이트. RAM 디렉터리와 ಪೀರ್_ಮೌಲ್ಯ/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 ಕನ್ನಡ class는 RAM ಕಡತ 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 현재 경로에서 ಮೂಲ_ವೃಕ್ಷ·ವರ್ಗ_ಮೌಲ್ಯ_55654bf1·ಡೇಟಾ 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 외부 IPv4를 제공한다. ನಿಜವಾದ_ಡೇಟಾ GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. 전문 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 ಪೂರೈಸು_ಆದೇಶ 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 ಅರೇ_ಮೌಲ್ಯ, 완전한 ಅರೇ_ಮೌಲ್ಯ 공변성·인터페이스 ಪದರ_ಮೌಲ್ಯ 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/ಎನ್_ಕ್ರಿಪ್ಟ್_ಡೇಟಾ/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 ಬೆಂಬಲ_ಮೌಲ್ಯ 부분집합은 아래 및 개발 매뉴얼을 참고한다. ವರ್ಗ_ಮೌಲ್ಯ_55654bf1 ಕಡತ 전체 검증기·ಪ್ರವೇಶ_ನಮೂದು ಅನುಮತಿ_ಮೌಲ್ಯ/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 ರಕ್ಷಿಸಿ_ಮೌಲ್ಯ 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM ಮೌಲ್ಯ/ಸಕ್ರಮೀಕರಿಸು/ವರ್ಗ_ಮೌಲ್ಯ_55654bf1 로더와 ವಿನಾಯಿತಿ 모델 → 영속 VFS·mmap·ಗಡಿಯಾರ·원자 ಆಪರೇಶನ್_ಮೌಲ್ಯ·ನಿಜವಾದ_ಡೇಟಾ 스레드/ಸಿಂಕ್_ಮಾಡು ABI → OpenJDK java.base 및 native ಲೈಬ್ರರಿ 이식 → ಸಾಧನ_ಮೌಲ್ಯ 네트워크·TCP/IP → ವಿಂಡೋ 시스템/ಫಾಂಟ್_ಮೌಲ್ಯ/입력기·java.desktop → Java SE 호환성 시험. 현재 자체 JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## ಸಕ್ರಮೀಕರಿಸು

`ಪರಿಕರಗಳು/자바가상기계시험.py`는 같은 Java 8 class 파일의 출력을 ಹೋಸ್ಟ್ OpenJDK `-Xverify:all`과 QEMU raspi4b 자체 커널에서 비교한다. ಆಬ್ಜೆಕ್ಟ್_ಮೌಲ್ಯ/상속/인터페이스·switch·ಅರೇ_ಮೌಲ್ಯ, ವಿನಾಯಿತಿ/finally, 컬렉션/GC, Thread/잠금, ಕನ್ನಡ UTF-8/ಕಡತ/컬렉션, ನಿಜವಾದ_ಡೇಟಾ UDP 루프백/ಸಮಯ_ಮೌಲ್ಯ 초과, 게스트 한글 ಮೂಲ_ವೃಕ್ಷ ಸಂಕಲಿಸು_ಮೂಲ, ಅರೇ_ಮೌಲ್ಯ ಪ್ರಕಾರ_ಮೌಲ್ಯ/ನಕಲಿಸು_ಮೌಲ್ಯ/ಕಡತ 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 ಕಡತ ನಿರಾಕರಿಸು_ಮೌಲ್ಯ 시험을 실행한다. UDP ಬಿಂಬಿಸು_ಮೂಲ 실행에는 ಹೋಸ್ಟ್ 루프백 소켓 권한이 필요하다.

`ಪರಿಕರಗಳು/부팅시험.py`는 ಕರ್ನಲ್_ಮೌಲ್ಯ ರಕ್ಷಿಸಿ_ಮೌಲ್ಯ/회귀 시험과 별도로 ಕನ್ನಡ Java 화면 API가 ನಿಜವಾದ_ಡೇಟಾ 픽셀을 그렸는지도 QMP 화면 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. ನಿಜವಾದ_ಡೇಟಾ Pi4 하드웨어 부팅 시험과 전체 JDK 호환성 시험 결과는 아니다.


## JVM 0.3: 네트워크와 GUI ವಿಸ್ತರಣೆ_ಮೌಲ್ಯ

`Socket`/`ServerSocket` ರಚಿಸಿ·ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು·accept·양방향 InputStream/OutputStream·close·EOF·ಸಮಯ_ಮೌಲ್ಯ 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 외부 ಅಂಕೆ_ಮೌಲ್ಯ IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 ಅಂತ್ಯಗೊಳಿಸು_ಬಿಂದು 16개, Java 루프백 버퍼 1024바이트, 외부 TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. ಸಂವಾದಕ 이벤트 대기는 ಪೂರೈಸು_ಆದೇಶ 기한을 갱신하고 ಟರ್ಮಿನಲ್ ಸ್ವಿಚ್_ಮಾಡಿ_ಮೋಡ್ 시 프로세스 상태를 ಸ್ಟೋರ್_ಮೌಲ್ಯ·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

ಕನ್ನಡ `ವಿಂಡೋ`, `ವಿಜೆಟ್`, `연결통신` 클래스를 배포 JAR와 자체 JVM 내장 자원에 추가했다. 상세 ವಿಧಾನ_ಮೌಲ್ಯ·제한·ಮೂಲ_ವೃಕ್ಷ·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## ಕನ್ನಡ 객체의 직접 ಪೂರೈಸು_ಆದೇಶ

`ವಿಂಡೋ`, `ಲೇಬಲ್`, `ಪಠ್ಯ_ಕ್ಷೇತ್ರ`, `ಬಟನ್`, `ಸಂಗತಿ_ಸರದಿ`, `동작알림`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. 자체 JVM의 ಆಬ್ಜೆಕ್ಟ್_ಮೌಲ್ಯ ರಚಿಸಿ,
ಸ್ವರೂಪ_ಮೌಲ್ಯ 검사, 화면 호출, ಸಂಗತಿ 큐, ಎಳೆ_ಮೌಲ್ಯ 스케줄러에 ಕನ್ನಡ 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 ಪೂರೈಸು_ಆದೇಶ 경로도 유지한다.
ಕನ್ನಡ 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

자체 실행기의 ಕನ್ನಡ 진입점은 `public static void ಚಲಾಯಿಸು_2()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 ಕನ್ನಡ 진입점을 우선한다.
명령행 인수는 `실행인수.개수()`와 `실행인수.ಪಠ್ಯ(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. ಸ್ಥಾಯಿ_ಮೌಲ್ಯ ಕಡತ 예제는 게스트
javac로도 컴파일하며, GUI/ಎಳೆ_ಮೌಲ್ಯ 소스는 ಹೋಸ್ಟ್ `javac --release 8`을 사용한다.
직접 GUI/ಎಳೆ_ಮೌಲ್ಯ API는 자체 JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
ಕನ್ನಡ 가닥의 ಪೂರೈಸು_ಆದೇಶ·ನಿರೀಕ್ಷಣೆ_ಮೌಲ್ಯ·중복 ಚಲಾಯಿಸು_2 ನಿರಾಕರಿಸು_ಮೌಲ್ಯ, GUI ಸಂಗತಿ 출처·ಪದಸೂಚಿ·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

ವಿಧಾನ_ಮೌಲ್ಯ 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
ಕನ್ನಡ 클래스도 실행되지만, ಸ್ಟ್ರಿಂಗ್_ಮೌಲ್ಯ 리터럴·표준 ಲೈಬ್ರರಿ 재정의·native
ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 예제](한국어자바/README_ಫೈಲ್_eb81d7d9.md)를 참고한다.

## ಟರ್ಮಿನಲ್ 부분 ತಾಜಾಮಾಡು

ಸರಿಸು_ಮೌಲ್ಯ·ಗಾತ್ರ 변경은 새 ವಿಂಡೋ 영역과 이전 자리에서 드러난 띠만 합성한다.
1920×32 ಪೆಲ್(240 KiB)의 임시 그림에서 배경·겹친 ವಿಂಡೋ·ಅಕ್ಷರ_ಮೌಲ್ಯ·GUI를 먼저
완성하고, 현재 ಶೋ_ಮೌಲ್ಯ 메모리와 비교하여 달라진 화소만 기록한다.
32줄보다 큰 영역은 여러 띠로 처리하므로 전체 프레임을 원자적으로
교체하거나 수직 동기에 맞추는 방식은 아니다. 전체 배경을 먼저 지우는
중간 화면은 표시하지 않는다. 좌표가 같으면 다시 그리지 않는다.

`make test-redraw`는 ನಿಜವಾದ_ಡೇಟಾ C 그리기 코드를 호스트의 ಮೆಮೊರಿ_ಡೇಟಾ 화면에 연결해
ಸರಿಸು_ಮೌಲ್ಯ 80회·ಗಾತ್ರ ಬದಲಿಸು_ಮೌಲ್ಯ 40회·겹친 ವಿಂಡೋ 4개를 전체 합성 결과와 ಪೆಲ್ 단위로 대조한다.
영역 밖 ಬಳಕೆದಾರ ಚಿತ್ರರಚನೆ_ಮೌಲ್ಯ, 동일 ಪೆಲ್ 무기록, ಸೂಚಕ 밑그림, ನಿಜವಾದ_ಡೇಟಾ 화면 ಸಾಲು 간격을
검사한다. 이 시험의 시간은 ಹೋಸ್ಟ್ CPU 측정이며 Pi 4/QEMU 속도로 해석하지 않는다.
`make test-resize`는 QEMU/VNC의 640×480 및 1920×1080에서 왼쪽 모서리 ಜಗ್ಗು_ಮೌಲ್ಯ,
한글 입력·vi 미저장 ವಿಷಯ_ಮೌಲ್ಯ·독립 ವಿಂಡೋ 크기를 검사한다.
