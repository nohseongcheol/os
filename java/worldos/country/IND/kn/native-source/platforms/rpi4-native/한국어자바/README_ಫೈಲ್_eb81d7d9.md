# ಕನ್ನಡ Java 통신·ಇನ್_ಪುಟ್_ಔಟ್_ಪುಟ್·ವಿನಾಯಿತಿ API

패키지는 `ಕನ್ನಡ.자체`다. ಹೋಸ್ಟ್ `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·ಕಡತ·ವಿನಾಯಿತಿ API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 ಎಳೆ_ಮೌಲ್ಯ API는 자체 JVM 전용이다.
기존 표준 Java ಲೈಬ್ರರಿ 전체의 ಕನ್ನಡ 번역판은 아니다.

```java
import ಕನ್ನಡ.자체.*;

public class ನೆಟ್_ವರ್ಕ್ {
    public static void main(String[] 인수) throws ಇನ್_ಪುಟ್_ಔಟ್_ಪುಟ್_ವಿನಾಯಿತಿ {
        ಸಂಪರ್ಕ ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು = ಸಂಪರ್ಕ.ತೆರೆ("10.0.2.2", 9000);
        try {
            ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು.대기시간(700);
            ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು.ಔಟ್_ಪುಟ್().ಬರೆ(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು.입력();
            ಔಟ್_ಪುಟ್.수쓰기(입력.ಓದು());
        } catch (대기시간초과예외 ದೋಷ) {
            ಔಟ್_ಪುಟ್.ಬರೆ_ಸಾಲು(ದೋಷ.설명());
        } finally {
            ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು.ಮುಚ್ಚು();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
ಬಳಕೆದಾರ 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 ಸ್ಟ್ರಿಂಗ್_ಮೌಲ್ಯ 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void ಚಲಾಯಿಸು_2()`도 진입점으로 받는다.

네트워크 흐름을 닫으면 연결도 닫힌다. ಪೋರ್ಟ್_ಸಂಖ್ಯೆ 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 자체 커널에서 512바이트까지 받으며, 주소는 ಅಂಕೆ_ಮೌಲ್ಯ IPv4를 사용한다.
`localhost` 루프백 외의 ಹೆಸರು 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು/듣기/받기`, `통신.ತೆರೆ/ಕಳುಹಿಸಿ/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `ಸಂಪರ್ಕ`, `수신창구`, `전문통로`를 쓴다.

모든 아래 클래스는 ಅಕ್ಷಮ_ಬೆಲೆ 생성자, `새예외("설명")` 형태의 ಸ್ಟ್ರಿಂಗ್_ಮೌಲ್ಯ 생성자와

`ವಿನಾಯಿತಿ`와 `실행예외`는 모든 ಕನ್ನಡ 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, ಕಡತ·통신 전체를 잡으려면 `catch (ಇನ್_ಪುಟ್_ಔಟ್_ಪುಟ್_ವಿನಾಯಿತಿ ದೋಷ)`를 쓴다.
ಕನ್ನಡ API가 표준 ಇನ್_ಪುಟ್_ಔಟ್_ಪುಟ್ 오류를 ಕನ್ನಡ 예외로 변환한다.
기존 ಕನ್ನಡ 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
ವಿನಾಯಿತಿ 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 자체 JVM에 이 20종을 추가했다. 임의의 ಬಳಕೆದಾರ Throwable 하위 ವರ್ಗ_ಮೌಲ್ಯ_55654bf1 전체를
지원하도록 확장했다는 뜻은 아니다.

## Swing ವಿಂಡೋ 예제

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` ಮುಂದೆ_ಅಂಶ `java 창예제`로 연다. ಹೆಸರು 입력, 인사하기 버튼,
인사말과 ಕ್ಲಿಕ್_ಮಾಡಿ_ಮೌಲ್ಯ 횟수 ತಾಜಾಮಾಡು, X 닫기를 지원한다.

|---|---|
| Runnable / run | `실행할일.ಚಲಾಯಿಸು()` |
| ActionListener / actionPerformed | `동작받이.동작받기(동작알림 알림)` |
| ActionEvent | `동작알림.ಆದೇಶ_ಪಠ್ಯ()`, `ಸಂಗತಿ_ಮೂಲ()`, `ಪದಸೂಚಿ()` |

| Thread | `작업가닥(실행할일)`, `ಆರಂಭಿಸು_ಕಾರ್ಯ()`, `기다리기()`, `살아있는가()`, `ಸ್ಥಗಿತಗೊಳಿಸಲಾಗಿದೆ_ಕಾರ್ಯ()` |
| 명령행 | `ಚಲಾಯಿಸು_2()`, `실행인수.개수()`, `실행인수.ಪಠ್ಯ(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `ಪ್ರಕ್ರಿಯೆ_ಎಳೆ`가 ಕನ್ನಡ ವರ್ಗ_ಮೌಲ್ಯ_55654bf1·ವಿಧಾನ_ಮೌಲ್ಯ·서술자를
해석해 화면 요소와 ಪೂರೈಸು_ಆದೇಶ 가닥을 직접 만든다. ಹಕ್ರಿಯೆ 알림도 자체 객체이며
콜백으로 `ಚಲಾಯಿಸು`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 ಪೂರೈಸು_ಆದೇಶ 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 ಹೋಸ್ಟ್ JVM에서 무동작 객체가 생기지 않도록 하는 ನಿರಾಕರಿಸು_ಮೌಲ್ಯ 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. ಹೋಸ್ಟ್ javac로 컴파일한 ಹಿಂದೆ_ಮೌಲ್ಯ 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import ಕನ್ನಡ.자체.*;
public class 가닥예제 implements 실행할일 {
    public void ಚಲಾಯಿಸು() { ಔಟ್_ಪುಟ್.ಬರೆ_ಸಾಲು("ಕನ್ನಡ 작업 ಪೂರೈಸು_ಆದೇಶ"); }
    public static void ಚಲಾಯಿಸು_2() throws 대기중단예외 {
        작업가닥 ಎಳೆ_ಮೌಲ್ಯ = 작업.ಚಲಾಯಿಸು_2(new 가닥예제());
        작업.기다리기(ಎಳೆ_ಮೌಲ್ಯ);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
ಅರೇ_ಮೌಲ್ಯ 인수 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 인수 없는 `ಚಲಾಯಿಸು_2()`을 우선한다.
기존 ಕನ್ನಡ 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.ಚಲಾಯಿಸು_2(Runnable)`을 사용하던 코드는 새 ಕನ್ನಡ 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API ಬೆಂಬಲ_ಮೌಲ್ಯ 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 ವರ್ಗ_ಮೌಲ್ಯ_55654bf1·ವಿಧಾನ_ಮೌಲ್ಯ 이름과 서술자가 남는다.
ಕನ್ನಡ ಹೆಸರು 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·ವಿಧಾನ_ಮೌಲ್ಯ 재정의, native ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS ಗುರುತಿಸುವಿಕೆ_ಮೌಲ್ಯ](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS ವಿಧಾನ_ಮೌಲ್ಯ ಉಲ್ಲೇಖ](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
