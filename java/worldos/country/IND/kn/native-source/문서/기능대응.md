# engos 기능 대응표

이 표는 기존 `ಲೆಗಸಿ_ಮೂಲ/`의 ಆಬ್ಜೆಕ್ಟ್_ಮೌಲ್ಯ 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [ನಿಜವಾದ_ಡೇಟಾ 부팅 기능과 한계](../os/README_ಫೈಲ್_eb81d7d9.md)를 따로 기록한다.

## Java 관리 ಪದರ_ಮೌಲ್ಯ 구현 완료

| engos 영역 | JIndOS 구현 |
|---|---|
| memorymanager, phymem | `ಮೆಮೊರಿ_ವ್ಯವಸ್ಥಾಪಕ` ಒಗ್ಗೂಡಿಸಿ_ಮೌಲ್ಯ ವಿತರಿಸು_ಸಂಗ್ರಹ·ಬಿಡುಗಡೆ_ಸಂಗ್ರಹ·병합 |
| paging, virtmem | `ಪುಟ_ವ್ಯವಸ್ಥಾಪಕ` ಇಮೇಲ್ 공간·ಪುಟ_ಮೌಲ್ಯ ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು·COW·개인 ಬರೆ |
| gdt, tss | `전역서술자표`, `ಕಾರ್ಯ_ಸ್ಥಿತಿ_ಸೆಗ್_ಮೆಂಟ್` |
| interrupt | `ತಡೆಗಟ್ಟು_ವ್ಯವಸ್ಥಾಪಕ` ನೋಂದಾಯಿಸು_ನಮೂದು·ಆನ್_ಮಾಡು·ವಿತರಿಸು_ಮೌಲ್ಯ |
| process, scheduler, thread | `ಪ್ರಕ್ರಿಯೆ_ಮೌಲ್ಯ`, `ಶೆಡ್ಯೂಲರ್` PID·fork·wait·ಸ್ಥಿತಿ_ಮೌಲ್ಯ ಸ್ವಿಚ್_ಮಾಡಿ_ಮೋಡ್ |
| systemcall/POSIX 1단계 | ಓದು·ಬರೆ·ತೆರೆ·ಮುಚ್ಚು·seek·dup·fcntl·ಪ್ರವೇಶ_ನಮೂದು·작업목록·ಬಳಕೆದಾರ/무리 ID·ಸಿಂಕ್_ಮಾಡು·brk·fork·wait·exec·stat·uname 의미 |
| ATA | `고급기술결합장치` 512바이트 ವಿಭಾಗ_ಮೌಲ್ಯ ಓದು·ಬರೆ |
| MSDOS partition | `기본분할영역표` MBR 검증과 네 ನಮೂದು_ಮೌಲ್ಯ ಪಾರ್ಸ್_ಮಾಡಿ_ಮೌಲ್ಯ |
| FAT 공개 ಕಡತ ಪದರ_ಮೌಲ್ಯ | `ಫೈಲ್_ಸಿಸ್ಟಂ`, `파일서술자표` ಓದು 전용 파일과 과정별 FD |
| ELF | ELF32 검사, ವಿಭಾಗ_ಮೌಲ್ಯ ಕ್ಲಿಪ್ 검사, 적재, NOBITS 영 ಆರಂಭಗೊಳಿಸು, ಚಲಾಯಿಸು_2 ಇಮೇಲ್·ಪ್ಯಾರಾಮೀಟರ್_ವಾದ·환경 반영 |
| keyboard, mouse | `입력관리자`의 손실 계수 포함 ಸಂಗತಿ 대기열 |
| timer | `ಗಡಿಯಾರ` 틱과 ಸಮಯ_ಮೌಲ್ಯ 변환 |
| PCI | `ಉಪಕರಣ_ಬಸ್_ವ್ಯವಸ್ಥಾಪಕ` 검색 결과와 ಸಾಧನ_ಮೌಲ್ಯ ಆಯ್ಕೆ_ಮೌಲ್ಯ |
| VGA/text mode | `ಅಕ್ಷರ_ಪ್ರದರ್ಶನ` 80x25 출력과 스크롤 |
| Ethernet/ARP/IPv4/ICMP/UDP/TCP | `ನೆಟ್_ವರ್ಕ್_ಪರಿಕರಗಳು`, `ನೆಟ್_ವರ್ಕ್_ಪದರ` ಫ್ರೇಮ್_ಪದಸೂಚಿ 검사·검사합·ಕೆಲಸ_ಮೌಲ್ಯ/포트 ವಿತರಿಸು_ಮೌಲ್ಯ |

## 기존 ಆಬ್ಜೆಕ್ಟ್_ಮೌಲ್ಯ 기반 관리 ಕರ್ನಲ್_ಮೌಲ್ಯ 전체를 부팅하기 위해 남은 ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು

ಮುಂದೆ_ಅಂಶ 항목은 Java 문법만으로 실행할 수 없는 CPU/ಸಾಧನ_ಮೌಲ್ಯ 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot ನಮೂದು_ಬಿಂದು_ಮೌಲ್ಯ, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 ಸಂದರ್ಭ_ಮೌಲ್ಯ ಸ್ಟೋರ್_ಮೌಲ್ಯ
- ನಿಜವಾದ_ಡೇಟಾ PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA ಲೂಪ್_ಮೌಲ್ಯ
- Java ಆಬ್ಜೆಕ್ಟ್_ಮೌಲ್ಯ·ಅರೇ_ಮೌಲ್ಯ ಜೋಡಣೆ_ಲೇಔಟ್, ವಿನಾಯಿತಿ, ಸ್ಥಾಯಿ_ಮೌಲ್ಯ ಆರಂಭಗೊಳಿಸು, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT ಹಂತ_ಮೌಲ್ಯ
- FAT 디스크 구역을 ನಿಜವಾದ_ಡೇಟಾ ATA 장치와 연결하는 ಇನ್_ಪುಟ್_ಔಟ್_ಪುಟ್ 접착 ಪದರ_ಮೌಲ್ಯ

위 관리 계층은 engos 기능의 Java 관리 구현과 ಹೋಸ್ಟ್ 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot ನಮೂದು_ಬಿಂದು_ಮೌಲ್ಯ, ಸ್ಥಾಯಿ_ಮೌಲ್ಯ ಆರಂಭಗೊಳಿಸು·ಪೂರ್ಣಸಂಖ್ಯೆ ಅರೇ_ಮೌಲ್ಯ, VGA/직렬/PS2, 명령해석기, ಬಳಕೆದಾರ ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 ಹೋಸ್ಟ್ 루프백 패킷 왕복을 검증했다. 위 표의 ಆಬ್ಜೆಕ್ಟ್_ಮೌಲ್ಯ 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
