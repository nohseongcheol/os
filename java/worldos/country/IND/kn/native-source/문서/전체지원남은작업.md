# 전체 ಬೆಂಬಲ_ಮೌಲ್ಯ 요청의 현재 ಸ್ಥಿತಿ_ಮೌಲ್ಯ

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 ನಿಜವಾದ_ಡೇಟಾ C POSIX 일부 기능, ಕನ್ನಡ API/ಮೂಲ ಹೆಸರು, IDE ಕಡತ 보존, 게스트 Java ಕಡತ 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/README_ಫೈಲ್_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 ಪೂರೈಸು_ಆದೇಶ 가능한 ಕ್ಲಿಪ್ | 전체 지원에 필요한 작업 |
|---|---|---|
| Java ಸಂಕಲಿಸು_ಮೂಲ·ಪೂರೈಸು_ಆದೇಶ | 게스트 제한형 javac/JVM, ಸ್ಥಾಯಿ_ಮೌಲ್ಯ 단일 클래스와 일부 표준 ಆಬ್ಜೆಕ್ಟ್_ಮೌಲ್ಯ | 일반 ಆಬ್ಜೆಕ್ಟ್_ಮೌಲ್ಯ·ವರ್ಗ_ಮೌಲ್ಯ_55654bf1 ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು·ವಿನಾಯಿತಿ·GC·스레드, 완전한 javac와 표준 ವರ್ಗ_ಮೌಲ್ಯ_55654bf1 ಲೈಬ್ರರಿ |
| ಕಡತ | POSIX 서술자, Java 단일 ಬೈಟ್_ಮೌಲ್ಯ ಕಡತ ಸ್ಟ್ರೀಮ್_ಮೌಲ್ಯ, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·ಅನುಮತಿ_ಮೌಲ್ಯ·잠금·일반 ಫೈಲ್_ಸಿಸ್ಟಂ·ವಿಸ್ತರಣೆ_ಮೌಲ್ಯ 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP ಹೋಸ್ಟ್ 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 ಪೂರೈಸು_ಆದೇಶ 환경을 추가하는 방식은 별도의 ಕರ್ನಲ್_ಮೌಲ್ಯ·루트 ಫೈಲ್_ಸಿಸ್ಟಂ·OpenJDK·그래픽 ಸರ್ವರ್_ಮೌಲ್ಯ·영구 ಸ್ಟೋರ್_ಮೌಲ್ಯ 구성을 가진 ಪೂರೈಸು_ಆದೇಶ 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

ಪೂರೈಸು_ಆದೇಶ 기반과 추가 ಲಕ್ಷ್ಯ 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
