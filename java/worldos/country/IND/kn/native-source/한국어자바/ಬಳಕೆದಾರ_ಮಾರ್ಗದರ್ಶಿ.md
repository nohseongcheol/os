# jkoros ಕನ್ನಡ ಲೈಬ್ರರಿ ಬಳಕೆದಾರ_ಮಾರ್ಗದರ್ಶಿ

확인일: 2026-09-27. 대상은 `platforms/rpi4`의 **ARM64 Linux + OpenJDK 실행판**이며, QEMU에서도 같은 Java 라이브러리를 사용한다. `os/`의 자체 x86 ಕರ್ನಲ್_ಮೌಲ್ಯ 및 `ಲೆಗಸಿ_ಮೂಲ/`의 관리 ಕರ್ನಲ್_ಮೌಲ್ಯ 모형과 구분한다.

## 1. 현재 제공하는 ಲೈಬ್ರರಿ

패키지는 `ಕನ್ನಡ.자바`, ಆಪರೇಟಿಂಗ್_ಸಿಸ್ಟಂ 안의 JAR 경로는 `/opt/jkoros/lib/한국어자바.jar`다. **도우미 ವರ್ಗ_ಮೌಲ್ಯ_55654bf1 5개, 공개 ಸ್ಥಾಯಿ_ಮೌಲ್ಯ ವಿಧಾನ_ಮೌಲ್ಯ 22개, 별도 GUI 프로그램인 ಕಾರ್ಯಸ್ಥಳ 1개**가 있다. JAR는 Java 11 이상을 대상으로 빌드하며 현재 ARM64 배포판에는 OpenJDK 25가 포함돼 있다.

| `ಕಡತ` | 9 | UTF-8 텍스트·ಬೈಟ್_ಮೌಲ್ಯ ಕಡತ, ಡೈರೆಕ್ಟರಿ_ಮೌಲ್ಯ, ನಮೂದು_ಪಟ್ಟಿ | [ಕಡತ.java](ಮೂಲ/ಕನ್ನಡ/자바/ಕಡತ.java) |

표준 JDK 전체를 한국어로 번역한 라이브러리는 아니다. Java 키워드와 `String`, `Path`, `Socket`, `JFrame`, `IOException` 같은 표준 ಡೇಟಾ_ಪ್ರಕಾರ·예외를 함께 사용한다. 이 도우미에 없는 기능은 OpenJDK의 표준 API 또는 별도 라이브러리로 구현한다. 예를 들어 HTTP POST, UDP, Swing ಬಟನ್·메뉴에는 각각 표준 Java API를 사용한다.

## 2. Java에서 ಆರಂಭಿಸು_ಕಾರ್ಯ

게스트 운영체제의 작업 폴더에서 `사용예.java`를 작성한다.

```java
import ಕನ್ನಡ.자바.*;
import java.nio.file.Path;

public class 사용예 {
    public static void main(String[] 인수) throws Exception {
        Path ಡೈರೆಕ್ಟರಿ_ಮೌಲ್ಯ = ಕಡತ.ರಚಿಸು_ಡೈರೆಕ್ಟರಿ(ಕಡತ.ಮಾರ್ಗ("사용예자료"));
        Path 문서 = ಡೈರೆಕ್ಟರಿ_ಮೌಲ್ಯ.resolve("인사.txt");
        ಕಡತ.ಬರೆ(문서, "한글 😀");
        String ವಿಷಯ_ಮೌಲ್ಯ = ಕಡತ.ಓದು(문서);
        System.out.println(ವಿಷಯ_ಮೌಲ್ಯ);
        System.out.println(문자.코드포인트수(ವಿಷಯ_ಮೌಲ್ಯ)); // 한, ಪಠ್ಯ, 공백, 😀 → 4
        Thread ಕೆಲಸದ_ಸ್ಥಳ_ಮೌಲ್ಯ = 작업.ಚಲಾಯಿಸು_2("인사 작업", () -> System.out.println("작업 ಪೂರೈಸು_ಆದೇಶ"));
        작업.기다리기(ಕೆಲಸದ_ಸ್ಥಳ_ಮೌಲ್ಯ);
    }
}
```

```sh
javac -encoding UTF-8 -cp /opt/jkoros/lib/한국어자바.jar 사용예.java
java -cp .:/opt/jkoros/lib/한국어자바.jar 사용예
```

로그인 환경에 ಅಕ್ಷಮ_ಬೆಲೆ `CLASSPATH`도 설정돼 있지만, 명시적인 `-cp`는 다른 ಪೂರೈಸು_ಆದೇಶ 환경에서도 경로를 분명하게 한다. 사용자가 `-cp`를 지정하면 필요한 JAR와 ವರ್ಗ_ಮೌಲ್ಯ_55654bf1 폴더를 모두 그 값에 포함해야 한다.

ಹೋಸ್ಟ್ 저장소에서는 다음처럼 ಬಿಲ್ಡ್_ಸಿಸ್ಟಂ·실행한다. ಹೋಸ್ಟ್ 경로와 게스트의 `/opt/...` 경로는 서로 다르다.

```sh
cd /home/user/jkoros/한국어자바
make
javac -encoding UTF-8 -cp build/한국어자바.jar 예제/인사.java
java -cp build/한국어자바.jar:예제 인사
```

## 3. 전체 도우미 API

아래 메서드는 모두 `public static`이며, 객체를 만들지 않고 `ಕಡತ.ಓದು(...)`처럼 호출한다. 표의 이름은 ನಿಜವಾದ_ಡೇಟಾ ಮೂಲ_ವೃಕ್ಷ 및 JAR의 `javap -public` 결과와 대조했다. 선언된 검사 ವಿನಾಯಿತಿ 외에도 잘못된 인수 등에 대한 표준 Java ಪೂರೈಸು_ಆದೇಶ 시 예외가 발생할 수 있다.

### ಕಡತ: `ಕನ್ನಡ.자바.ಕಡತ`

`Path`는 `java.nio.file.Path`, `List`는 `java.util.List`다.

| ವಿಧಾನ_ಮೌಲ್ಯ | 반환형 | ಹಕ್ರಿಯೆ·ಸ್ಥಿತಿ |
|---|---|---|
| `ಮಾರ್ಗ(String ಹೆಸರು)` | `Path` | 이름을 ಮಾರ್ಗ 객체로 변환. ನಿಜವಾದ_ಡೇಟಾ 파일을 만들지는 않음 |
| `ಓದು(Path ಮಾರ್ಗ)` | `String` | ಕಡತ 전체를 UTF-8 텍스트로 읽음 |
| `ಬರೆ(Path ಮಾರ್ಗ, String ವಿಷಯ_ಮೌಲ್ಯ)` | `Path` | UTF-8 ಸ್ಟೋರ್_ಮೌಲ್ಯ. 파일이 없으면 생성하고, 있으면 기존 내용을 비움 |
| `바이트읽기(Path ಮಾರ್ಗ)` | `byte[]` | ಕಡತ 전체를 ಬೈಟ್_ಮೌಲ್ಯ 배열로 읽음 |
| `ಬರೆ_ಬೈಟ್_ಮೌಲ್ಯ(Path ಮಾರ್ಗ, byte[] ವಿಷಯ_ಮೌಲ್ಯ)` | `Path` | ಬೈಟ್_ಮೌಲ್ಯ ಸ್ಟೋರ್_ಮೌಲ್ಯ. 없으면 생성하고, 있으면 기존 내용을 비움 |
| `ರಚಿಸು_ಡೈರೆಕ್ಟರಿ(Path ಮಾರ್ಗ)` | `Path` | 필요한 상위 폴더까지 ರಚಿಸಿ |
| `있는가(Path ಮಾರ್ಗ)` | `boolean` | 존재 여부 ಖಚಿತಪಡಿಸಿಕೊಳ್ಳು. 확인할 수 없는 경우도 `false`ಕೆಲಸದ_ಸ್ಥಳ_ಮೌಲ್ಯ 수 있음 |
| `ಅಳಿಸು_ನಮೂದು(Path ಮಾರ್ಗ)` | `boolean` | 삭제했으면 `true`, 없으면 `false`. 폴더의 재귀 삭제는 아님 |
| `ನಮೂದು_ಪಟ್ಟಿ(Path ಮಾರ್ಗ)` | `List<Path>` | 바로 아래 항목을 ಮಾರ್ಗ ಒಗ್ಗೂಡಿಸಿ_ಮೌಲ್ಯ 순서로 반환. 재귀 탐색은 아님 |

`ಮಾರ್ಗ`, `있는가`를 제외한 위 메서드는 `IOException`을 선언한다. `ಬರೆ`와 `ಬರೆ_ಬೈಟ್_ಮೌಲ್ಯ`는 상위 폴더를 자동으로 만들거나 내용을 이어 쓰지 않는다. 필요한 폴더는 먼저 생성한다. 큰 파일은 전체 내용을 메모리에 담는 대신 표준 Java 스트림·ಚಾನಲ್_ಮೌಲ್ಯ API를 사용하는 방식으로 작성할 수 있다.

### 문자: `ಕನ್ನಡ.자바.문자`

| ವಿಧಾನ_ಮೌಲ್ಯ | 반환형 | ಹಕ್ರಿಯೆ·ಸ್ಥಿತಿ |
|---|---|---|
| `부호화(String ವಿಷಯ_ಮೌಲ್ಯ)` | `byte[]` | 문자열을 UTF-8 바이트로 변환 |
| `ಡೀಕ್ರಿಪ್ಟ್_ಮಾಡಿ_ಡೇಟಾ(byte[] ವಿಷಯ_ಮೌಲ್ಯ)` | `String` | UTF-8 바이트를 문자열로 변환. 잘못된 입력은 대체 문자로 ಪ್ರಕ್ರಿಯೆ_ಮೌಲ್ಯ_ನಮೂದು |
| `ಸಮಾನೀಕರಿಸು_ಮೌಲ್ಯ(String ವಿಷಯ_ಮೌಲ್ಯ)` | `String` | ಯುನಿಕೋಡ್_ಮೌಲ್ಯ NFC ಸಮಾನೀಕರಿಸು_ಮೌಲ್ಯ. 예: 조합 자모 `ᄀ` + `ᅡ` → `가` |
| `코드포인트수(String ವಿಷಯ_ಮೌಲ್ಯ)` | `int` | UTF-16 ಕೋಡ್_ಮೌಲ್ಯ 단위가 아닌 ಯುನಿಕೋಡ್_ಮೌಲ್ಯ ಕೋಡ್_ಮೌಲ್ಯ 포인트 수 |
| `낱말(String ವಿಷಯ_ಮೌಲ್ಯ, Locale ಭಾಷೆ)` | `List<String>` | ನಿಯೋಜಿಸು_ಮೌಲ್ಯ 언어의 `BreakIterator` 낱말 경계로 나눈 구간 |

`낱말`은 공백·문장부호 구간도 반환한다. 자연어 형태소 분석기나 공백을 제거한 ಪದ_ಮೌಲ್ಯ ನಮೂದು_ಪಟ್ಟಿ API는 아니다. `ಸಮಾನೀಕರಿಸು_ಮೌಲ್ಯ`는 입력기나 ಅನುವಾದಿಸು_ಮೂಲ 기능이 아니다. ಕೋಡ್_ಮೌಲ್ಯ 포인트 수 역시 사람이 보는 ಅಕ್ಷರ_ಮೌಲ್ಯ 수와 항상 같지는 않다. 여러 ಕೋಡ್_ಮೌಲ್ಯ 포인트로 이루어진 결합 문자·가족 이모지 등을 구분해야 한다.

### 통신: `ಕನ್ನಡ.자바.통신`

| ವಿಧಾನ_ಮೌಲ್ಯ | 반환형 | ಹಕ್ರಿಯೆ·ಸ್ಥಿತಿ |
|---|---|---|
| `가져오기(URI ಇಮೇಲ್, Duration ಸಮಯ_ಮಿತಿ)` | `HttpResponse<String>` | HTTP(S) GET. ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು 및 요청 ಸಮಯ_ಮಿತಿ ಸಿದ್ಧತೆಗಳು. ಪ್ರತ್ಯುತ್ತರ 본문을 UTF-8로 ಪಾರ್ಸ್_ಮಾಡಿ_ಮೌಲ್ಯ |
| `연결하기(String ಇಮೇಲ್, int 포트, int 제한밀리초)` | `Socket` | TCP ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು 후 같은 값으로 ಓದು 제한시간도 ಸಿದ್ಧತೆಗಳು |

`가져오기`는 `IOException`, `InterruptedException`을 선언한다. 제한시간은 양수다. 404·500 같은 HTTP ದೋಷ 상태도 응답으로 반환하므로 `statusCode()`로 판단하고 `body()`로 본문을 읽는다. 현재 구현은 호출마다 HTTP 클라이언트를 만들며 자동 리다이렉트 설정을 추가하지 않는다.

`연결하기`는 `IOException`을 선언한다. 연결된 소켓은 호출자가 `close()` 또는 try-with-resources로 닫아야 한다. 제한밀리초의 0은 제한 없음이며, ಬರೆ 전체의 마감 시간을 보장하는 옵션은 아니다.

```java
var ಪ್ರತ್ಯುತ್ತರ = 통신.가져오기(
    java.net.URI.create("http://127.0.0.1:8000/"),
    java.time.Duration.ofSeconds(5));
System.out.println(ಪ್ರತ್ಯುತ್ತರ.statusCode());
System.out.println(ಪ್ರತ್ಯುತ್ತರ.body());
```

위 조각은 ವಿಧಾನ_ಮೌಲ್ಯ 안에서 실행하며 별도로 해당 주소의 서버를 실행해야 한다. Java ವಿನಾಯಿತಿ 처리가 필요하다.

### 작업: `ಕನ್ನಡ.자바.작업`

| ವಿಧಾನ_ಮೌಲ್ಯ | 반환형 | ಹಕ್ರಿಯೆ·ಸ್ಥಿತಿ |
|---|---|---|
| `ಚಲಾಯಿಸು_2(String ಹೆಸರು, Runnable ಹಕ್ರಿಯೆ)` | `Thread` | 이름을 지정한 스레드를 만들고 즉시 ಚಲಾಯಿಸು_2 |
| `기다리기(Thread ಎಳೆ_ಮೌಲ್ಯ)` | `void` | 해당 스레드가 종료할 때까지 `join()` |
| `쉬기(long 밀리초)` | `void` | 호출한 스레드를 ನಿಯೋಜಿಸು_ಮೌಲ್ಯ ಸಮಯ_ಮೌಲ್ಯ 동안 `sleep()` |
| `작업대(int 가닥수)` | `ExecutorService` | 고정 ಗಾತ್ರ 작업 ಅಪ್ಲಿ_ಲಾಂಚರ್ ರಚಿಸಿ. 가닥수는 양수 |

`기다리기`, `쉬기`는 `InterruptedException`을 선언한다. 작업 실행기는 사용 후 `shutdown()`으로 종료하고 필요하면 `awaitTermination(...)`으로 완료를 기다린다. Swing 이벤트 ಪ್ರಕ್ರಿಯೆ_ಮೌಲ್ಯ_ನಮೂದು 가닥에서 긴 작업이나 `기다리기`를 실행하면 화면이 멈출 수 있다.

### 화면: `ಕನ್ನಡ.자바.화면`

| ವಿಧಾನ_ಮೌಲ್ಯ | 반환형 | ಹಕ್ರಿಯೆ·ಸ್ಥಿತಿ |
|---|---|---|
| `나중에(Runnable ಹಕ್ರಿಯೆ)` | `void` | Swing 이벤트 ಪ್ರಕ್ರಿಯೆ_ಮೌಲ್ಯ_ನಮೂದು 가닥에 실행을 예약하고 반환 |
| `ವಿಂಡೋ(String ವಿಂಡೋ_ಶೀರ್ಷಿಕೆ, JComponent ವಿಷಯ_ಮೌಲ್ಯ, int 너비, int 높이)` | `JFrame` | ವಿಷಯ_ಮೌಲ್ಯ·크기를 지정한 창을 생성해 ಶೋ_ಮೌಲ್ಯ |

`ವಿಂಡೋ`을 Swing 이벤트 ಪ್ರಕ್ರಿಯೆ_ಮೌಲ್ಯ_ನಮೂದು ಎಳೆ_ಮೌಲ್ಯ 밖에서 부르면 `IllegalStateException`이 발생한다. 그래픽 세션도 필요하다. QEMU에서는 VNC 데스크톱의 터미널에서 실행한다.

```java
화면.나중에(() -> 화면.ವಿಂಡೋ(
    "ಕನ್ನಡ 화면", new javax.swing.JLabel("안녕하세요"), 500, 180));
```

반환된 `JFrame`에 표준 Swing API를 추가로 사용할 수 있다. 창의 ಮುಚ್ಚು 동작은 `DISPOSE_ON_CLOSE`다. `화면.나중에`가 반환됐다고 ವಿಂಡೋ 생성이 이미 끝난 것은 아니다.

### ಕಾರ್ಯಸ್ಥಳ: ಸಂಪಾದನೆ_ಮೌಲ್ಯ·ಸಂಕಲಿಸು_ಮೂಲ GUI

```sh
java -cp /opt/jkoros/lib/한국어자바.jar ಕನ್ನಡ.자바.ಕಾರ್ಯಸ್ಥಳ
```

`~/workspace`의 원문을 ತೆರೆ·저장하고, `javac`로 컴파일해 `java`로 실행한다. ಪೂರೈಸು_ಆದೇಶ ಕಡತ 만들기는 `jclassc --target openjdk` 경로를 사용한다. 작업마당은 개발용 프로그램이며 별도의 ಕಡತ·문자 API 클래스가 아니다. 생성하는 ಪೂರೈಸು_ಆದೇಶ ಕಡತ 방식은 [컴파일러 설명](../compiler/OpenJDK-실행파일.md)을 따른다.

## 4. Python과 C++에서 사용할 수 있는가?

| ವಿಧಾನ_ಮೋಡ್ | 현재 포함 ಸ್ಥಿತಿ_ಮೌಲ್ಯ | 호출 가능 ಕ್ಲಿಪ್ |
|---|---|---|
| Java → ಕನ್ನಡ JAR | ಅಕ್ಷಮ_ಬೆಲೆ 포함 | 위 22개 메서드와 ಕಾರ್ಯಸ್ಥಳ |
| Python → `java` ಮಗು_ಮೌಲ್ಯ 프로세스 | Python·Java ಅಕ್ಷಮ_ಬೆಲೆ 포함 | 작은 Java 진입점을 통해 호출하고 표준 ಔಟ್_ಪುಟ್·ಕಡತ 등으로 ಮಾಪನ ಮುಂದೆ_ಮೌಲ್ಯ_24592b8a |
| Python → JPype → JVM | JPype는 ಅಕ್ಷಮ_ಬೆಲೆ 배포에 없음 | 별도 ಸ್ಥಾಪಿಸು_ಮೌಲ್ಯ 후 Java ವರ್ಗ_ಮೌಲ್ಯ_55654bf1·ವಿಧಾನ_ಮೌಲ್ಯ 호출 가능. 이 배포판의 ARM64/musl/Python 3.14 조합은 추가 ಸಕ್ರಮೀಕರಿಸು 필요 |
| C++ → JNI → JVM | `g++`, JNI 헤더, `libjvm.so` 포함 | JVM을 생성하고 ಕನ್ನಡ ವರ್ಗ_ಮೌಲ್ಯ_55654bf1·메서드를 직접 호출할 수 있음 |
| Python용 독립 ಕನ್ನಡ ಲೈಬ್ರರಿ | 현재 ಅಕ್ಷಮ_ಬೆಲೆ 제공 없음 | 필요하면 Python 표준 라이브러리를 감싸는 ಕನ್ನಡ 모듈을 별도로 작성 |
| C/C++용 독립 ಕನ್ನಡ ಲೈಬ್ರರಿ | 자체 x86 `posix-kor`와 자체 ARM64 커널용 초기 RAM ಕಡತ 연결이 별도로 존재 | 둘 다 이 Linux/OpenJDK 실행판의 libc 라이브러리는 아님 |

Python의 일반 `import`나 `ctypes.CDLL`로 JAR를 바로 읽을 수는 없다. C++의 `#include`나 일반 네이티브 링커만으로 Java 메서드를 연결할 수도 없다. JVM 프로세스 또는 JVM ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು 계층을 거쳐야 한다.

### Python: 추가 패키지 없이 호출

ಪೂರೈಸು_ಆದೇಶ 가능한 예제 원문은 [문자명령.java](예제/다른언어/문자명령.java), [파이썬호출.py](예제/다른언어/파이썬호출.py)다. Python이 Java 진입점을 실행하고 `문자.코드포인트수`의 ಪೂರ್ಣಸಂಖ್ಯೆ 결과를 받는다. 인수 목록을 사용하며 ಶೆಲ್ ಆಜ್ಞೆ 문자열을 조립하지 않는다. `subprocess.run`의 프로세스 ಪೂರೈಸು_ಆದೇಶ·ನಿರ್ಗಮನ_ಅಪ್ಲಿ ಕೋಡ್_ಮೌಲ್ಯ·ಔಟ್_ಪುಟ್ ಪ್ರಕ್ರಿಯೆ_ಮೌಲ್ಯ_ನಮೂದು 방식은 [Python 공식 문서](https://docs.python.org/3/library/subprocess.html)를 따른다.

두 예제 파일을 게스트의 같은 폴더에 복사한 ಹಿಂದೆ_ಮೌಲ್ಯ 그 폴더에서 실행한다. 예제 ಕಡತ 자체는 ಅಕ್ಷಮ_ಬೆಲೆ 시스템 이미지에 자동 설치돼 있지 않다.

```sh
mkdir -p classes
javac -encoding UTF-8 -cp /opt/jkoros/lib/한국어자바.jar -d classes 문자명령.java
python3 파이썬호출.py --text '한글 😀'
```

ಔಟ್_ಪುಟ್: `Python → ಕನ್ನಡ.자바.문자.코드포인트수: 4`

이 예제의 Python ಕಾರ್ಯ_ಮೌಲ್ಯ `코드포인트수`는 이번 문서의 ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು 예제이며 기존에 설치된 Python 라이브러리는 아니다. 현재 예제는 호출할 때마다 JVM 프로세스를 시작한다. Java ಆಬ್ಜೆಕ್ಟ್_ಮೌಲ್ಯ 자체를 Python으로 가져오는 방식은 아니며, 다른 메서드를 사용하려면 진입점의 인수·ಮಾಪನ 형식을 확장한다.

### Python: JPype로 같은 프로세스에서 호출

JPype를 별도 설치한 환경에서는 ಮುಂದೆ_ಅಂಶ 형태로 연결할 수 있다. **아래는 ಆಯ್ಕೆ_ಮೌಲ್ಯ 가능한 ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು 방법이며, 현재 배포판에 JPype가 설치돼 있거나 ಪೂರೈಸು_ಆದೇಶ 검증됐다는 뜻은 아니다.** JVM 시작과 `JClass`를 통한 ವರ್ಗ_ಮೌಲ್ಯ_55654bf1 접근은 [JPype 공식 설명](https://jpype.readthedocs.io/en/latest/userguide.html)을 참고한다.

```python
import jpype

jpype.startJVM(
    "/usr/lib/jvm/java-25-openjdk/lib/server/libjvm.so",
    classpath=["/opt/jkoros/lib/한국어자바.jar"])
try:
    문자 = jpype.JClass("ಕನ್ನಡ.자바.문자")
    print(문자.코드포인트수(jpype.JString("한글 😀")))
finally:
    jpype.shutdownJVM()
```

Python·JVM·ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು 모듈의 CPU 아키텍처가 맞아야 한다. 이 실행판은 ARM64 + musl이므로 일반 x86_64/glibc용 바이너리를 그대로 설치하는 방식은 맞지 않는다. JPype ಸ್ಥಾಪಿಸು_ಮೌಲ್ಯ·패키지 빌드는 이번 문서 작업에서 수행하지 않았다.

### C++: JNI로 직접 호출

[자바호출.cpp](예제/다른언어/자바호출.cpp)는 ನಿಜವಾದ_ಡೇಟಾ ಪೂರೈಸು_ಆದೇಶ 가능한 예제다. JVM을 작업 스레드에서 생성하고 ಮುಂದೆ_ಅಂಶ 메서드를 찾는다.

```cpp
jclass type = env->FindClass("ಕನ್ನಡ/자바/문자");
jmethodID method = env->GetStaticMethodID(
    type, "코드포인트수", "(Ljava/lang/String;)I");
```

JVM ರಚಿಸಿ·종료와 스레드 연결은 [JNI Invocation API](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/invocation.html)의 방식이다. `JNIEnv*`는 ರಚಿಸಿ·연결된 스레드에서 사용해야 한다. 예제는 Java 예외를 확인하고 JVM 종료까지 처리한다.

게스트에 `자바호출.cpp`를 복사한 ಹಿಂದೆ_ಮೌಲ್ಯ 컴파일한다. 로그인 환경의 `JAVA_HOME`은 `/usr/lib/jvm/java-25-openjdk`다.

```sh
g++ -std=c++11 -Wall -Wextra -pthread \
  -I"$JAVA_HOME/include" -I"$JAVA_HOME/include/linux" \
  자바호출.cpp -L"$JAVA_HOME/lib/server" \
  -Wl,-rpath,"$JAVA_HOME/lib/server" -ljvm -o 자바호출
./자바호출 /opt/jkoros/lib/한국어자바.jar
```

ಔಟ್_ಪುಟ್: `C++ → ಕನ್ನಡ.자바.문자.코드포인트수: 4`

예제는 `한글 😀`을 UTF-16으로 만들어 `NewString`에 전달한다. `NewStringUTF`가 받는 modified UTF-8은 일반 UTF-8과 차이가 있으므로, 일반 UTF-8 이모지 바이트를 그대로 넘기는 예제로 작성하지 않았다. [JNI ಸ್ಟ್ರಿಂಗ್_ಮೌಲ್ಯ ಸ್ವರೂಪ_ಮೌಲ್ಯ](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/types.html#modified-utf-8-strings)

다른 ಕನ್ನಡ 메서드도 JNI 서명과 인수 자료형을 맞춰 호출할 수 있다. 예를 들어 `Path`를 받는 ಕಡತ API는 먼저 `ಕಡತ.ಮಾರ್ಗ`로 Java ಮಾರ್ಗ 객체를 얻어 전달한다. Swing 호출에는 그래픽 세션과 이벤트 ಪ್ರಕ್ರಿಯೆ_ಮೌಲ್ಯ_ನಮೂದು ಎಳೆ_ಮೌಲ್ಯ 규칙도 그대로 적용된다. JNI는 Java 실행을 기계어로 대체하는 기능이 아니며 JVM이 계속 필요하다.

### 기존 posix-kor와의 관계

추가된 [자체 ARM64 ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು](../posix-kor/arm64-native/README_ಫೈಲ್_eb81d7d9.md)은 C++에서 AOT Java 커널의 RAM ಕಡತ API를 직접 호출하며, 별도 EL0 ಬಳಕೆದಾರ 라이브러리로 ಕಡತ/UDP 루프백 SVC 호출도 제공한다. JNI를 사용하지 않는다. 이 문서의 ARM64 **Linux** 및 ಕನ್ನಡ Java JAR와는 다른 ಪೂರೈಸು_ಆದೇಶ 기반이며 자체 커널은 별도 제한형 Java 컴파일러/JVM과 MicroPython 1.24.1을 실행한다. MicroPython의 `import jkoros`로 Java ಕರ್ನಲ್_ಮೌಲ್ಯ ಕಡತ·UDP 루프백·사각형 호출이 가능하지만 이 문서의 JAR를 가져오는 기능은 아니다. 자체 커널의 전체 OpenJDK/JRE/CPython 이식은 아직 미완성이다.

[posix-kor](../posix-kor/README_ಫೈಲ್_eb81d7d9.md)에는 `ರಚಿಸು_ಫೈಲ್`, `파일자료읽기`, `ಬರೆ_ಫೈಲ್_ಡೇಟಾ`, `ಮುಚ್ಚು_ಫೈಲ್`, `통신종단점만들기`, `자료전문보내기` 등의 ಕನ್ನಡ C 별칭이 있다. 그러나 구현은 **자체 jkoros i386 커널의 `int 0x80` 호출 규약용**이다.

이 `libposix-kor.a`와 자체 `sys/stat.h` 등의 헤더는 현재 ARM64 Linux 실행판의 libc/C++용 라이브러리가 아니다. 해당 헤더·바이너리를 ARM64 Linux 프로그램에 그대로 연결해서는 ABI가 맞지 않는다. C++용 ಕನ್ನಡ ವರ್ಗ_ಮೌಲ್ಯ_55654bf1 라이브러리나 Python용 바인딩을 ಅಕ್ಷಮ_ಬೆಲೆ 제공하는 상태도 아니다. 현재 Linux 실행판에서 그와 같은 독립 API를 제공하려면 Linux 표준 라이브러리를 대상으로 별도로 구현·빌드해야 한다.

## 5. ಖಚಿತಪಡಿಸಿಕೊಳ್ಳು 범위와 재현

패키지 포함 여부는 [배포 패키지 ನಮೂದು_ಪಟ್ಟಿ](../platforms/rpi4/dist/packages.lock.json) 및 ಬಿಲ್ಡ್_ಸಿಸ್ಟಂ 루트의 ನಿಜವಾದ_ಡೇಟಾ 파일로 확인했다. JNI 헤더는 JDK의 `include/jni.h`, `include/linux/jni_md.h`, JVM 라이브러리는 `lib/server/libjvm.so`에 있다. 사용자가 이후 별도로 설치한 패키지는 이 ಅಕ್ಷಮ_ಬೆಲೆ 배포 목록과 다를 수 있다.

이번에 **ಹೋಸ್ಟ್ x86_64/OpenJDK 11에서** Python ಮಗು_ಮೌಲ್ಯ 프로세스 호출과 C++ JNI 직접 호출을 ಸಂಕಲಿಸು_ಮೂಲ·실행해 각각 ಮಾಪನ 4를 확인했다. JAR 공개 메서드도 소스와 대조했다. Python ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು 예제는 추가 패키지를 설치하지 않는다.

문서의 Java 사용 예제도 ಸಂಕಲಿಸು_ಮೂಲ·실행했고, 22개 메서드의 문서 포함 여부와 로컬 문서 링크를 확인했다. [예제 ಸಕ್ರಮೀಕರಿಸು ಲಾಗ್_ದಾಖಲೆ](build/다른언어/ದೃಢೀಕರಣ_ವರದಿ.json)

기존 ARM64 QEMU에서는 Java의 ಕಡತ·ಯುನಿಕೋಡ್_ಮೌಲ್ಯ·스레드·HTTP 및 Swing 시험 결과가 있다. 이번 Python/C++ ಸಂಪರ್ಕ_ಕಲ್ಪಿಸು 예제의 **ARM64 게스트 실행과 JPype 설치는 별도 검증하지 않았다.** 이미지와 ಪೂರೈಸು_ಆದೇಶ 중인 ಬಳಕೆದಾರ 환경은 이 문서 작업에서 변경하지 않았다. [기존 ಆಪರೇಟಿಂಗ್_ಸಿಸ್ಟಂ ಸಕ್ರಮೀಕರಿಸು ಲಾಗ್_ದಾಖಲೆ](../platforms/rpi4/VERIFICATION.md)

호스트에서 Python 예제를 재현하려면:

```sh
cd /home/user/jkoros/한국어자바
make
mkdir -p build/다른언어
javac -encoding UTF-8 --release 11 -cp build/한국어자바.jar \
  -d build/다른언어 예제/다른언어/문자명령.java
python3 예제/다른언어/파이썬호출.py \
  --jar build/한국어자바.jar --classes build/다른언어
```

ಹೋಸ್ಟ್ C++ 예제는 위 JNI ಸಂಕಲಿಸು_ಮೂಲ 명령의 JDK 경로를 **ಹೋಸ್ಟ್ JDK ಮಾರ್ಗ**로 바꾸고, ಮೂಲ `예제/다른언어/자바호출.cpp`와 JAR `build/한국어자바.jar`를 지정한다. ARM64 게스트 JDK의 헤더·ಲೈಬ್ರರಿ 경로를 ಹೋಸ್ಟ್ x86_64 링크 명령에 섞지 않는다.
