# 한국어 Java 통신·I_O·예외 API

패키지는 `한국어.자체`다. येजमान `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·फायल·예외 API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 थ्रॅड_मोल API는 자체 JVM 전용이다.
기존 표준 Java लायब्ररी 전체의 한국어 번역판은 아니다.

```java
import 한국어.자체.*;

public class नॅटवर्क {
    public static void main(String[] 인수) throws 입출력예외 {
        कनॅक्शन कनॅक्ट = कनॅक्शन.उगडचें("10.0.2.2", 9000);
        try {
            कनॅक्ट.कालबाह्य(700);
            कनॅक्ट.출력().बरोवचें(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = कनॅक्ट.입력();
            출력.수쓰기(입력.읽기());
        } catch (대기시간초과예외 चूक) {
            출력.बरोवचें_रेग(चूक.설명());
        } finally {
            कनॅक्ट.शेवट();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
उपेगकर्तो 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 स्ट्रिंग_मोल 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void चलोवप()`도 진입점으로 받는다.

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`읽기()`의 फायल 끝은 -1, क्रम_मोल_ed437109 읽기의 반환값은 प्रत्यक्ष_डेटा 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. 접속번호 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 자체 커널에서 512바이트까지 받으며, 주소는 अंक_मोल IPv4를 사용한다.
`localhost` 루프백 외의 नांव 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.कनॅक्ट/듣기/받기`, `통신.उगडचें/धाडचें/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `कनॅक्शन`, `수신창구`, `전문통로`를 쓴다.

## 한국어 예외

모든 아래 클래스는 डिफॉल्ट_मोल 생성자, `새예외("설명")` 형태의 स्ट्रिंग_मोल 생성자와
`설명()`을 제공한다. प्रत्यक्ष_डेटा तयार_करचें 문법은 `new 대기시간초과예외("기다림 끝")`이다.

| 한국어 예외 | 상위 वर्ग_मोल_55654bf1 / 용도 |
|---|---|
| 예외 | `java.lang.Exception`, 직접 던지는 일반 검사 예외 |
| 실행예외 | `java.lang.RuntimeException` |
| 입출력예외 | `java.io.IOException`, 한국어 फायल·통신 API의 검사 예외 |
| 대기시간초과예외 | `입출력예외`, 통신 कालबाह्य 초과 |
| 주소확인예외 | `입출력예외`, नामो पुनर्तपासणी_करची अपेस_मोल |
| 파일없음예외 | `입출력예외`, फायल उगडचें अपेस_मोल |
| 통신예외 | `입출력예외`, 표준 SocketException CONVERT_मोल |
| 잘못된인수예외 | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `잘못된인수예외` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| 빈참조예외 | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| 상태예외 | `java.lang.IllegalStateException` |
| 형변환예외 | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| क्रम_Store_अपेस | `java.lang.ArrayStoreException` |
| 가닥상태예외 | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 대기 중단 |

`예외`와 `실행예외`는 모든 한국어 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, फायल·통신 전체를 잡으려면 `catch (입출력예외 चूक)`를 쓴다.
한국어 API가 표준 I_O 오류를 한국어 예외로 변환한다.
기존 한국어 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
예외 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 자체 JVM에 이 20종을 추가했다. 임의의 उपेगकर्तो Throwable 하위 वर्ग_मोल_55654bf1 전체를
지원하도록 확장했다는 뜻은 아니다.

## दाळचे_स्त्रोत·पाळो_दिवचो_आदेश

```sh
cd /home/user/jkoros/platforms/rpi4-native
make दाळचे_प्रणाली
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 साधनां/पाळो_दिवचो_फायल.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 उपेगकर्तो JVM ELF 안에 탑재된다. `.jar`는 येजमान javac의
वर्ग_मोल_55654bf1 경로로 사용한다. स्त्रोत_ट्री 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 한국어 예외의 `throws` 선언과 그 import를 인식한다.
자체 JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·ऑब्जॅक्ट_मोल·소켓 예제 전체의 स्त्रोत_ट्री 컴파일은 येजमान javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 수 있다.

प्रत्यक्ष_डेटा TCP/UDP 예제는 [네트워크예제.java](../../../example/java/네트워크예제.java),
पाळो_दिवचो_आदेश 절차는 [example README_eb81d7d9](../../../example/README.md),
स्त्रोत_ट्री 명명 원칙은 [명명 README_eb81d7d9](../명명/README_eb81d7d9.md)에 있다.

## Swing विंडो 예제

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` फुडलें_आयटम `java 창예제`로 연다. नांव 입력, 인사하기 버튼,
인사말과 क्लिक_करचें_मोल 횟수 परतून_ताजें_करचें, X 닫기를 지원한다.

| 기능 | 한국어 직접 API |
|---|---|
| Runnable / run | `실행할일.पाळो_दिवचो_कार्य()` |
| ActionListener / actionPerformed | `동작받이.동작받기(동작알림 알림)` |
| ActionEvent | `동작알림.आदेश_SMS()`, `प्रसंग_स्त्रोत()`, `INDEX()` |
| JFrame | `विंडो(विंडो_शीर्षक, 폭, 높이)`, `संयोजन_करचें_मूलतत्व(화면구성요소)`, `शो_विंडो()`, `शेवट()`, `보이는가()` |
| JButton | `बटन(SMS, 가로, उबें_स्थिती, 폭, 높이, 받이)`, `동작맡기기(받이)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `प्रक्रिया_थ्रॅड`가 한국어 वर्ग_मोल_55654bf1·पद्दत_मोल·서술자를
해석해 화면 요소와 पाळो_दिवचो_आदेश 가닥을 직접 만든다. कृती 알림도 자체 객체이며
콜백으로 `पाळो_दिवचो_कार्य`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 पाळो_दिवचो_आदेश 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 येजमान JVM에서 무동작 객체가 생기지 않도록 하는 거부 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. येजमान javac로 컴파일한 फाटीं_मोल 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import 한국어.자체.*;
public class 가닥예제 implements 실행할일 {
    public void पाळो_दिवचो_कार्य() { 출력.बरोवचें_रेग("한국어 작업 पाळो_दिवचो_आदेश"); }
    public static void चलोवप() throws 대기중단예외 {
        작업가닥 थ्रॅड_मोल = 작업.चलोवप(new 가닥예제());
        작업.기다리기(थ्रॅड_मोल);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
क्रम_मोल_ed437109 인수 대신 `실행인수`, 길이는 `문자.बायट_COUNT`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 인수 없는 `चलोवप()`을 우선한다.
기존 한국어 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.चलोवप(Runnable)`을 사용하던 코드는 새 한국어 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API तेंको_मोल 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 वर्ग_मोल_55654bf1·पद्दत_मोल 이름과 서술자가 남는다.
한국어 नांव 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·पद्दत_मोल 재정의, native कनॅक्ट, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS वळखुपी_मोल](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS पद्दत_मोल संदर्भ](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
