# engos 기능 대응표

이 표는 기존 `लिगसी_स्त्रोत/`의 ऑब्जॅक्ट_मोल 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [प्रत्यक्ष_डेटा 부팅 기능과 한계](../os/README_eb81d7d9.md)를 따로 기록한다.

## 기존 ऑब्जॅक्ट_मोल 기반 관리 कर्नेल_मोल 전체를 부팅하기 위해 남은 कनॅक्ट

फुडलें_आयटम 항목은 Java 문법만으로 실행할 수 없는 CPU/मोबायल_मोल 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot प्रवेश_पॉयंट_मोल, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 मजकूर_मोल Store_मोल
- प्रत्यक्ष_डेटा PIC/PIT/PS2/ATA/PCI हार्डवॅर_पोर्ट 및 AMD PCnet DMA लूप_मोल
- Java ऑब्जॅक्ट_मोल·क्रम_मोल_ed437109 लिंक_रचणाय, 예외, थीर_मोल प्रारंभ_करचें, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT पांवडो_मोल
- FAT 디스크 구역을 प्रत्यक्ष_डेटा ATA 장치와 연결하는 I_O 접착 थर_मोल

위 관리 계층은 engos 기능의 Java 관리 구현과 येजमान 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot प्रवेश_पॉयंट_मोल, थीर_मोल प्रारंभ_करचें·पुर्णांक क्रम_मोल_ed437109, VGA/직렬/PS2, 명령해석기, उपेगकर्तो ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 येजमान 루프백 패킷 왕복을 검증했다. 위 표의 ऑब्जॅक्ट_मोल 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
