# 전체 तेंको_मोल 요청의 현재 स्थिती_मोल_e10195a1

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 प्रत्यक्ष_डेटा C POSIX 일부 기능, 한국어 API/स्त्रोत नांव, IDE फायल 보존, 게스트 Java फायल 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/README_eb81d7d9.md)를 기준으로 판단한다.

|---|---|---|
| Java दाळचे_स्त्रोत·पाळो_दिवचो_आदेश | 게스트 제한형 javac/JVM, थीर_मोल 단일 클래스와 일부 표준 ऑब्जॅक्ट_मोल | 일반 ऑब्जॅक्ट_मोल·वर्ग_मोल_55654bf1 कनॅक्ट·예외·GC·스레드, 완전한 javac와 표준 वर्ग_मोल_55654bf1 लायब्ररी |
| फायल | POSIX 서술자, Java 단일 बायट_मोल फायल Stream_मोल, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·अनुमती_मोल·잠금·일반 फायल_प्रणाली·विस्तार_मोल 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP येजमान 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 पाळो_दिवचो_आदेश 환경을 추가하는 방식은 별도의 कर्नेल_मोल·루트 फायल_प्रणाली·OpenJDK·그래픽 सर्वर_मोल·영구 Store_मोल 구성을 가진 पाळो_दिवचो_आदेश 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

पाळो_दिवचो_आदेश 기반과 추가 लक्ष्य 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
