# 자체 ARM64 കെര്_ണല്_മൂല്യം: FTP, C, JAR와 AOT നടപ്പാക്കുക_കമാന്_ഡ്

대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT കെര്_ണല്_മൂല്യം**이다. CPU·മൊബൈൽ_മൂല്യം 경계는 C/어셈블리, ഫയല് 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 ഹോസ്റ്റ് JVM으로 대신 실행하지 않는다.

## 먼저 알아둘 പിന്തുണ_മൂല്യം 경계

| HTTP_അപേക്ഷ | 이번 구현 | 남은 ക്ലിപ്പ് |
|---|---|---|
| JAR를 നടപ്പാക്കുക_കമാന്_ഡ് 파일처럼 നടപ്പാക്കുക_കമാന്_ഡ് | `java -jar ഫയല്.jar`, `./ഫയല്.jar 인수`; Main-Class와 സ്_റ്റോർ_മൂല്യം/DEFLATE ZIP, CRC 검사 | 전체 Java SE, 임의의 모든 JAR 호환성 |
| 게스트 AOT | `jaot ഫയല്.class -o ഫയല്.elf`, `jaot ഫയല്.jar -o ഫയല്.elf`; വാസ്തവമായ_ഡാറ്റാ ARM64 기계어 സൃഷ്_ടിക്കുക | ഓബ്ജക്റ്റ്_മൂല്യം·ഒഴിവാക്കൽ·Thread·Swing·Socket의 AOT 변환, 여러 애플리케이션 ക്ലാസ്_മൂല്യം കണക്ടു്_ചെയ്യുക |

| FTP | 게스트 서비스, 패시브 കൈമാറുക_മൂല്യം_630ba093, UTF-8 പേരു്, STOR/RETR/SIZE/LIST/NLST/MLSD/DELE | TLS·사용자별 അനുമതി_മൂല്യം·하위 디렉터리·영속 സ്_റ്റോർ_മൂല്യം |

JVM은 ക്ലാസ്_മൂല്യം 버전 45…52의 문서화한 부분집합이다. `java`는 바이트코드 실행기이고, `jaot`가 별도의 네이티브 നടപ്പാക്കുക_കമാന്_ഡ് 파일을 만든다. **JAR ശേഖരം_മൂല്യം 해제나 JVM을 함께 묶는 것을 AOT라고 표시하지 않는다.** 지원하지 않는 바이트코드/API는 `jaot`가 진단하고 출력을 만들지 않는다. 기존 ഫലം ELF도 കംപൈല്_ചെയ്യുക_ഉറവിടം പരാജയം_മൂല്യം 때 보존한다.

Android의 Dalvik/ART는 일반 JVM ക്ലാസ്_മൂല്യം/JAR가 아닌 **DEX**를 실행한다. ART의 AOT에는 GC, ക്ലാസ്_മൂല്യം 로딩, JNI 등 നടപ്പാക്കുക_കമാന്_ഡ് 기반도 필요하다. 따라서 ART처럼 기계어로 바꾸는 기능만으로 임의의 OpenJDK JAR 및 Swing이 자동 호환되지는 않는다. [Android 공식 런타임 설명](https://source.android.com/docs/core/runtime)

FTP는 루트 RAM 파일만 공개한다. 익명 로그인이며 비밀번호로 권한을 구분하지 않는다. സ്ഥിരസ്ഥിതി_മൂല്യം ഹോസ്റ്റ് 바인딩은 `127.0.0.1`이고, നിയന്ത്രണം_മൂല്യം 포트는 2121, 데이터 포트는 50000…50007이다. `--ftp-port 2122`로 നിയന്ത്രണം_മൂല്യം 포트를 바꿀 수 있다. 동시에 한 FTP 세션을 제공하며 명령이 없는 세션은 60초 후 닫는다. TYPE A도 바이트를 변경하지 않으므로 프로그램은 바이너리 전송한다.

파일은 **64개, 각각 16 KiB**, 경로는 UTF-8 63바이트이다. 부팅 시 준비되는 `/example`도 이 한도를 공유한다. 초과/끊어진 STOR는 기존 파일에 반영하지 않는다. FTP 업로드는 RAM에만 저장되며 재부팅하면 사라진다. 이 제한 때문에 일반적인 대형 JAR 배포판을 그대로 올릴 수 없다.

QEMU의 raspi4b에는 GENET Ethernet 장치가 없다. 따라서 `network_bridge.py`가 QEMU NAT의 Ethernet과 보조 UART의 SLIP를 변환한다. **TCP കണക്ടു്_ചെയ്യുക പ്രോസസ്_മൂല്യം_എന്_ട്രി·체크섬·재전송·FTP 명령과 ഫയല് 저장은 게스트 안에서 수행한다.** ഹോസ്റ്റ് 브리지는 FTP 서버가 아니다. [QEMU 공식 മൊബൈൽ_മൂല്യം പിന്തുണ_മൂല്യം എന്_ട്രി_ലിസ്റ്റ്](https://www.qemu.org/docs/master/system/arm/raspi.html)

이 경로는 QEMU에서 검증했다. 보조 UART의 വാസ്തവമായ_ഡാറ്റാ Pi 4 핀/클럭 설정과 내장 RJ45 GENET 드라이버는 구현·검증하지 않았으므로, SD 이미지에 커널이 포함되어 있다는 사실을 വാസ്തവമായ_ഡാറ്റാ 보드의 LAN/FTP നടപടി 보장으로 해석하면 안 된다.

## 한국어 Java를 게스트에서 컴파일하고 AOT നടപ്പാക്കുക_കമാന്_ഡ്

게스트 `vi 빛.java`로 അടുത്തത്_ഇനം 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] 인수) throws Exception {
        int 합 = 0;
        int 수 = 1;
        while (수 <= 10) {
            합 = 합 + 수;
            수 = 수 + 1;
        }
        한국어.자체.ഫലം.수쓰기(합);
        한국어.자체.ഫയല്.എഴുത്തു്("aot.txt", "한글 AOT ഫയല് 😀");
        한국어.자체.ഫലം.റൈറ്റ്_ചെയ്യുക_ലൈൻ(한국어.자체.ഫയല്.വായന("aot.txt"));
    }
}
```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 സൃഷ്_ടിക്കുക·연결한다. നടപ്പാക്കുക_കമാന്_ഡ് 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 പിന്തുണ_മൂല്യം 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 സ്ഥിരമായ_മൂല്യം విధానం_മൂല്യം/മണ്ഡലം_മൂല്യം, int 계열, പൂര്_ണ്ണസംഖ്യ 배열과 റഫറൻസ്, 인수 അരേ_മൂല്യം, അവസ്ഥ·ശാഖ·ആവര്_ത്തനം_മൂല്യം, സ്ട്രിംഗ്_മൂല്യം 리터럴, `System.out.print/println`의 int/String, 한국어 ഫലം·ഫയല് വായന/쓰기로 제한된다. ക്ലാസ്_മൂല്യം/విధానం_മൂല്യം 수와 스택 등에도 고정 상한이 있다. Java ഒഴിവാക്കൽ പ്രോസസ്_മൂല്യം_എന്_ട്രി, ഓബ്ജക്റ്റ്_മൂല്യം സൃഷ്_ടിക്കുക, 가상 విధానం_മൂല്യം 일반, switch/wide, long/float/double, invokedynamic, സ്ട്രിംഗ്_മൂല്യം 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 അരേ_മൂല്യം ആക്സസ്_എന്_ട്രി/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java ഒഴിവാക്കൽ 객체로 전달하지 않는다.

입력 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 വിന്യസിക്കുക_മൂല്യം 때문에 짧은 클래스도 이 한도를 넘을 수 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 ഓബ്ജക്റ്റ്_മൂല്യം·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 പിന്തുണ_മൂല്യം ക്ലിപ്പ് 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 개발 매뉴얼](개발안내.md)을 참고한다.

JAR는 하나의 애플리케이션 ക്ലാസ്_മൂല്യം 경로다. 내부 പേരു് `ബണ്ടിൽ/പ്രോഗ്രാം_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 한국어 클래스를 추가로 찾지만 현재 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·ഗൂഢഭാഷയാക്കുക_ഡാറ്റാ ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 수/VM സമൂഹം_മൂല്യം 제한은 그대로 적용된다.

## C에서 한국어 POSIX 호출

게스트에서 `vi 인사.c`로 작성하거나 FTP로 소스를 업로드한다.

```c
#include <파일규약.h>

int main(void) {
    const char 인사말[] = "자체 ARM64 C에서 한글 POSIX 호출\n";
    int 문서 = തുറക്കുക_ഫയല്("인사.txt", വായനാ_റൈറ്റ് | 없으면만들기 | 내용비우기, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = റൈറ്റ്_ചെയ്യുക_ഫയല്_ഡാറ്റാ(문서, 인사말, sizeof(인사말) - 1);
    അടയ്ക്കുക_ഫയല്(문서);
    റൈറ്റ്_ചെയ്യുക_ഫയല്_ഡാറ്റാ(1, 인사말, sizeof(인사말) - 1);
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

```text
cc 인사.c -o 인사.elf
run 인사.elf
cat 인사.txt
```

TinyCC의 표준 C എന്_ട്രി_പോയിന്_റ് `main`을 사용한다. 기존 ഹോസ്റ്റ് C/C++ SDK의 `ആരംഭം_ഉപയോക്താവ്_പ്രോഗ്രാം(int)` 진입점과 구분한다. 포함 ഫയല്·നടപ്പിലാക്കുക ഓബ്ജക്റ്റ്_മൂല്യം·`libposix-kor-user.a`는 컴파일러 내부의 വായന 전용 SDK에 들어 있다. C 전처리기/구조체/കാര്യപ്രവര്_ത്തനം_മൂല്യം/재귀/പോയിന്_റര്/부동소수점 സൃഷ്_ടിക്കുക 등을 사용하되 **일반 libc/libstdc++를 제공한다는 뜻은 아니다**. 제공하지 않는 함수는 കണക്ടു്_ചെയ്യുക 오류가 난다. 컴파일러 자체의 문자/അക്കം_മൂല്യം 변환 지원도 완전한 libc 대체품이 아니다.

`തുറക്കുക_ഫയല്` 등은 별도의 모의 호출이 아닌 기존 `pk_open` 등의 한국어 매크로이며, ELF의 SVC를 통해 വാസ്തവമായ_ഡാറ്റാ Java ഫയല് 체계에 도달한다. ഫയല്/소켓 호출 목록은 [ഉപയോക്താവ് ABI](사용자호출규약.md)에 있다. C/C++ ഹോസ്റ്റ് SDK നടപ്പാക്കുക_കമാന്_ഡ് 파일도 FTP로 업로드 후 `run` 또는 `./ഫയല്`로 실행하며 확장자는 필요 없다. Linux ARM64 സ്ഥിരമായ_മൂല്യം ELF에는 별도의 제한된 호환 വഴി `run --linux ഫയല്`을 추가했다. [ELF·Linux ABI 매뉴얼](실행파일규약.md)에 정확한 ఫార్మాట్_മൂല്യം·시스템 호출·ഇമെയിൽ 제한을 정리했다.

## 한국어 네트워크·작업·화면 API

| ക്ലാസ്_മൂല്യം | 호출 예 | നടപ്പാക്കുക_കമാന്_ഡ് വഴി |
|---|---|---|
| `ഫലം` | `റൈറ്റ്_ചെയ്യുക_ലൈൻ("안녕")`, `수쓰기(42)` | JVM 및 제한형 AOT |
| `ഫയല്` | `എഴുത്തു്("문서.txt", "ഉള്ളടക്കം_മൂല്യം")`, `വായന("문서.txt")` | JVM 및 제한형 AOT |
| `통신` | `തുറക്കുക(0)`, `അയയ്ക്കുക(അവസാനബിന്ദു, "10.0.2.2", 9000, "한글")`, `받기(അവസാനബിന്ദു)` | JVM의 UDP |
| `연결통신` | `കണക്ടു്_ചെയ്യുക("10.0.2.2", 9000)`, `ശ്രദ്ധിക്കുക_അവസാനബിന്ദു(9000)`, `받기(സെര്_വര്_മൂല്യം)` | JVM의 Socket/ServerSocket |
| `작업` | `നടപ്പിലാക്കുക(Runnable)`, `기다리기(Thread)`, `താല്_ക്കാലികമായി_നിര്_ത്തുക_ചുമതല()` | JVM의 협력식 ത്രെഡ്_മൂല്യം |
| `ജാലകം`, `വിജറ്റ്` | ജാലകം·버튼·പ്രതീകം_മൂല്യം·പാഠ_മണ്ഡലം·ഇവന്റ് കണക്ടു്_ചെയ്യുക | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 한국어 호출 계층을 추가한다. `통신(通信)`, `കണക്ടു്_ചെയ്യുക(連結)`, `ഫലം(出力)`은 기존 단어의 뜻을 사용한다. `작업 ത്രെഡ്_മൂല്യം`은 한 നടപ്പാക്കുക_കമാന്_ഡ് 흐름을 가닥에 빗댄 기술 표현, `പോര്_ട്ട്_മൂല്യം`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

외부 주소는 അക്കം_മൂല്യം IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 자체 ABI이며 JVM이 제한된 കാക്കുക_മൂല്യം/재시도를 제공한다. TCP connect 대기는 최대 1초, ഉപയോക്താവ് പ്രോഗ്രാം_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 നടപ്പാക്കുക_കമാന്_ഡ് ഉപയോക്താവ് 서버와 pthread는 아직 없다. FTP는 ഉപയോക്താവ് പ്രോഗ്രാം_f5044b9b 기한과 별개인 കെര്_ണല്_മൂല്യം 서비스다.

게스트의 ഉപയോക്താവ് TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 ഉപകരണങ്ങൾ/നടപ്പാക്കുക_കമാന്_ഡ്.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 സ്ഥിരസ്ഥിതി_മൂല്യം നിയന്ത്രണം_മൂല്യം/데이터 포트와 겹치면 നടപ്പാക്കുക_കമാന്_ഡ് 전에 거부한다.

## 시험과 ബിൽഡ്_సిస్టమ్ 재현

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test-ftp
make test
make image
```

`build/verification/ftp/report.json`은 വാസ്തവമായ_ഡാറ്റാ FTP കൈമാറുക_മൂല്യം_630ba093, 한글 ഫയല്, വലിപ്പം 초과 보존, ശേഖരം_മൂല്യം JAR നടപ്പാക്കുക_കമാന്_ഡ്, 게스트 C കംപൈല്_ചെയ്യുക_ഉറവിടം/ELF 재업로드, 외부 Java TCP/UDP, 게스트 javac/AOT 실행을 기록한다. `serial.log`에서 게스트 명령과 결과를 확인할 수 있다. 보고서의 കെര്_ണല്_മൂല്യം SHA-256과 배포 이미지의 커널을 비교한다.

빌드는 기존 JDK/Clang/AArch64 binutils와 함께 `../rpi4/build/rootfs`의 ARM64 SDK പ്രസ്താവം 헤더와 libgcc 산술 보조 함수를 사용한다(`make rpi-prepare`). **musl libc, Linux കെര്_ണല്_മൂല്യം, 동적 로더를 게스트에 링크하지 않는다.** TinyCC/lwIP/uzlib 원본과 라이선스·버전 정보는 `vendor/`, 이식 코드는 `ccompiler/`, `network/`, `ഉപയോക്താവ്/ബണ്ടിൽ.c`에 있다.

전체 JDK/AOT JVM으로 확장하려면 타입 സാധൂകരിക്കുക·ഓബ്ജക്റ്റ്_മൂല്യം/ഒഴിവാക്കൽ/GC·동적 로딩·JNI, 영속 ഫയല് ഓപ്പറേറ്റിംഗ്_സിസ്റ്റം_മൂല്യം·mmap/TLS/시그널·스레드 ABI, OpenJDK native లైబ్రరీ, GUI peer/폰트/입력기, GENET 및 실물 മൊബൈൽ_മൂല്യം 검증이 더 필요하다. 이 문서의 നടപ്പാക്കുക_കമാന്_ഡ് 시험은 그 전체 이식을 대신하지 않는다.
