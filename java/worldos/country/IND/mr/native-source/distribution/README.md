# बाह्य_मूल्य 배포용 압축과 복원

Ubuntu x86_64에서 프로젝트 루트의 `./pack.sh`를 실행한다.
`dist/jkoros-source.tar.xz`, 체크섬 फाइल, 독립 आज्ञा_कार्यवाही_करा 가능한 `dist/unpack.sh`पहिले_संकार्य 생성된다.
मूळ 캐시, स्रोत_ट्री, प्रयोक्ता 디스크는 삭제하거나 변경하지 않는다. 압축파일은 2 GB를
넘으면 생성에 실패한다. आउटपुट 경로는 `./pack.sh /मार्ग/jkoros-source.tar.xz`로 지정한다.

다른 Ubuntu PC에 압축파일, `.sha256`, `unpack.sh`를 함께 전달한 मागे_मूल्य 실행한다.

```sh
./unpack.sh jkoros-source.tar.xz /원하는/새/मार्ग/jkoros
make -C /원하는/새/मार्ग/jkoros all korean-java iso
make -C /원하는/새/मार्ग/jkoros rpi-native-image
make -C /원하는/새/मार्ग/jkoros rpi-image
```

डिफॉल्ट_मूल्य 동작은 संग्रह_मूल्य संग्रह_रिलीज नंतर_राज्य अवलंबने 자동 다운로드와 준비까지다. Ubuntu सिस्टम_बांधणी 도구가
없으면 `sudo apt-get`으로 설치하며 व्यवस्थापक_मूल्य 암호가 필요할 संख्या 있다. बाह्य_मूल्य 소스의
SHA-256을 확인하고 ARM64 SDK/Linux आज्ञा_कार्यवाही_करा पर्यावरण, होस्ट 도구와 JRE를 준비한다.
새 폴더의 위치를 기준으로 실행하므로 `/home/user` 경로를 만들 필요가 없다.

स्वकीय ARM64 커널만 개발한다면 `--profile native`로 GUI/Linux आज्ञा_कार्यवाही_करा पर्यावरण 준비를
생략할 संख्या 있다. सिस्टम_बांधणी 도구가 이미 설치되어 있으면 `--no-host-install`을 추가한다.
`--no-prepare`는 다운로드하지 않고 소스만 검사할 때 쓰는 명시적 선택이다.

तयार_करणे 도중 네트워크 오류가 나면 풀린 폴더에서 `./unpack.sh --prepare`를 पुनःप्रयत्न_मूल्य 실행한다.
기존 आउटपुट निर्देशिका_मूल्य 위에는 압축을 풀지 않는다. 개인 सुधारा_मूल्य 파일을 덮어쓰지 않으며,
복원 लक्ष्य 파일의 내용이 अपेक्षित_मूल्ये 해시와 다르면 중단한다.

압축에서 `build`, `dist`, `मोजमाप`, `.vbox`, Python 캐시, लॉग_मूल्य, प्रयोक्ता 디스크와
कनेक्शन_e05f319b 키를 제외한다. Alpine 패키지 캐시는 외부에서 필요한 패키지만 पुनःप्रयत्न_मूल्य 받는다.
libassh, BearSSL, lwIP, uzlib, MicroPython 중 고정 URL/해시로 복구할 संख्या 있는 원본은
제외하지만 로컬 सुधारा_मूल्य 파일은 포함한다. 정확한 재다운로드 주소를 고정하지 못한
TinyCC 스냅샷, स्वकीय फॉन्ट_मूल्य, 프로젝트 소스와 라이선스 고지는 포함한다.

인터넷과 Ubuntu 패키지 भांडार_मूळ 및 Alpine 3.24 भांडार_मूळ 접근이 필요하다.
Alpine 저장소의 वापर_मूल्य 가능한 패키지 버전을 받아 वास्तविक_डेटा 버전을 कुलूप_मूल्य 파일에 기록한다.
패키지 다운로드 후의 पारपाडा_कार्य 폴더와 सिस्टम_बांधणी 산출물은 2 GB를 넘을 संख्या 있다.
OpenJDK स्वकीय 소스의 별도 실험 빌드는 기존 संकलक 안내에 따라 소스를 준비한다.

`PORTABLE_DOWNLOAD_CACHE=/캐시/निर्देशिका_मूल्य`를 지정하면 SHA-256을 파일명으로 하는
검증된 다운로드 파일을 먼저 사용한다. 캐시에 없는 항목은 자동 다운로드한다.
वगळा_मूल्य 목록과 संग्रह_मूल्य 크기는 `dist/jkoros-source.tar.xz.report.json`에 기록된다.
