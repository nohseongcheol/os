# Java 네이티브 संचालनप्रणाली

이 문서는 기존 **x86 गाभा_मूल्य**을 설명한다. Raspberry Pi 4의 स्वकीय ARM64 प्रारंभिक_राज्य 이식은 [별도 वापरमार्गदर्शिका_eb81d7d9](../platforms/rpi4-native/README.md)를 참고한다. तळ_मूल्य x86 प्रयोक्ता ELF·네트워크·IDE साठवणे_मूल्य 기능이 ARM64에 सर्व_बांधणी 이식된 상태는 아니다.

Java 원문을 स्वकीय AOT 후단으로 x86 기계어로 컴파일해 부팅하는 작은 운영체제다. 커널과 별도로 स्वकीय 제한형 Java संकलक·JVM ELF를 प्रयोक्ता 모드에 적재할 संख्या 있다. Linux, engos, koros4와 बाह्य_मूल्य OpenJDK는 게스트에 적재하지 않는다. प्रणालीप्रारंभ 진입과 हार्डवेअर_पॉर्ट/물리 स्मृती_प्रदेश 접근은 어셈블리이며, वर्ण टर्मिनल_आदानप्रदान·आदान_मूल्य प्रक्रिया_मूल्य_प्रविष्टी·आदेश मूल्य_पार्स_करा·पारपाडा_कार्य विभाग_मूल्य 관리는 `स्रोत/*.java`에 있다.

## 게스트 Java विकास

`javac Hello.java`, `java Hello`로 부팅된 संचालनप्रणाली 안에서 स्रोत_बांधणी·실행한다. `edit FILE.java`와 `.save`로 소스를 작성하며 `ls`, `cat`, `rm`을 제공한다. RAM 파일은 कमाल_मूल्य 8개, 각각 16KiB이다. 전용 IDE 매체를 연결하면 `sync`로 보존할 संख्या 있다. 이 기능은 स्वकीय 제한형 구현이며 전체 OpenJDK/JDK 호환은 아니다. 사용법·समर्थन_मूल्य 문법·फाइल 적재·교차 시험은 [Java विकास पर्यावरण](../मार्गदर्शिका/जावा_विकास_पर्यावरण.md)에 있다. `make test-java`로 검증한다.

## 빌드와 आज्ञा_कार्यवाही_करा

`compiler/`पहिले_संकार्य 요구하는 도구에 더해 ISO 생성에는 `grub-file`, `grub-mkrescue`, GRUB BIOS मॉड्यूल_मूल्य, `xorriso`पहिले_संकार्य 필요하다. 실행에는 QEMU 또는 VirtualBox가 필요하다. सध्याचे_आयटम 설치된 도구만 사용한다. `make run-store`는 새 전용 가상 साठवणे_मूल्य 매체를 만들어 연결한다. VirtualBox 실행기는 이 프로젝트가 만든 전용 VM만 설정하고 다른 VM은 변경하지 않는다. 가상 메모리는 डिफॉल्ट_मूल्य 64MiB이며 किमान_मूल्य 16MiB가 필요하다.

```sh
cd /home/user/jkoros/os
make                 # build/kernel.elf
make iso             # build/kernel.iso (प्रयोक्ता ELF समूह_मूल्य घोषणाशीर्षे)
make run             # ELF 직접 प्रणालीप्रारंभ, अनुक्रमिक_मूल्य टर्मिनल_आदानप्रदान
make run-gui         # GRUB ISO प्रणालीप्रारंभ, VGA 창과 PS/2 자판
make vbox            # 상위 폴더의 실행기로 전용 VirtualBox VM आज्ञा_कार्यवाही_करा
make vbox-status     # 전용 VirtualBox VM राज्य_मूल्य पडताळा
make test            # ELF와 ISO 두 경로의 वास्तविक_डेटा प्रणालीप्रारंभ/आदान_मूल्य चाचण्या
make apps            # प्रयोक्ता 프로그램만 सिस्टम_बांधणी
make test-network    # प्रयोक्ता आज्ञा_कार्यवाही_करा/UDP/संरक्षण_मूल्य चाचण्या
```

`make run`은 QEMU의 अनुक्रमिक_मूल्य 표준 입출력을 쓴다. `Ctrl+A`를 누른 मागे_मूल्य `X`로 QEMU를 종료할 संख्या 있다. `halt`는 게스트 CPU만 정지시키므로 QEMU विंडो/프로세스는 별도로 닫는다. 폴링 방식이라 प्रतीक्षा_करा_मूल्य 중에도 होस्ट CPU를 사용할 संख्या 있다.

VirtualBox는 `make vbox`로 실행한다. 새 전용 VM을 स्मृती_डेटा 64MiB, BIOS, 광학 드라이브 부팅으로 자동 설정하며 디스크는 आवश्यक_मूल्य 없다. वास्तविक_डेटा VirtualBox 5.2.42에서 प्रणालीप्रारंभ, Java स्वकीय चाचण्या, शेल आदान_मूल्य, `run hello vbox`의 ring 3 실행과 आहे_सामान्य 종료를 확인했다. सध्याचे_आयटम संचार 드라이버는 QEMU의 RTL8139 전용이며 VirtualBox의 PCnet/E1000에서는 네트워크를 사용할 संख्या 없어 네트워크 장치를 비활성화한다. साठवणे_मूल्य राज्य_मूल्य 재개와 새 सिस्टम_बांधणी 반영 방법은 [VirtualBox आज्ञा_कार्यवाही_करा वापरमार्गदर्शिका_eb81d7d9](../मार्गदर्शिका/व्हर्च्युअल_पेटी_निष्पादन.md)에 있다.

## 셸에서 प्रयोक्ता अनुप्रयोग_f5044b9b आज्ञा_कार्यवाही_करा 및 네트워크 आवाहन

독립 ELF32 आज्ञा_कार्यवाही_करा 파일을 적재해 **ring 3**에서 실행한다. `int 0x80` 시스템 호출을 통해 टर्मिनल_आदानप्रदान आउटपुट, बाबी क्वेरी_मूल्य, UDP उघडा·पाठवा·स्वीकारा·닫기를 제공한다. प्रयोक्ता 코드를 गाभा_मूल्य 함수로 직접 호출하는 구조가 아니다.

```text
jkoros> apps
jkoros> run hello first second
jkoros> net
jkoros> run netcheck
jkoros> run udp 10.0.2.2 9000 hello
```

शेवटचे_आयटम 명령의 응답을 받으려면 호스트의 별도 터미널에서 `python3 /home/user/jkoros/os/साधने/प्रतिध्वनी_डेटा.py --port 9000`을 먼저 실행한다. 상세 API, अनुप्रयोग_f5044b9b शेवटीजोडा_प्रविष्टी, पत्ता 공간과 제한은 [प्रयोक्ता आज्ञा_कार्यवाही_करा·네트워크 वापरमार्गदर्शिका_eb81d7d9](प्रयोक्ता/वापरमार्गदर्शिका_eb81d7d9.md)에 있다.

प्रणालीप्रारंभ पडताळा शब्दसमूह_मूल्य:

```text
JKOROS NATIVE JAVA
जावा 기계어 गाभा_मूल्य सुरू_करा
JAVA SELFTEST PASS
USER ELF: ring 3 / paging / int 0x80
help | info | mem | alloc | free N | echo TEXT | clear | test | halt
apps | run NAME [ARGS] | net
READY
jkoros>
```

## 구현한 기능

- GRUB Multiboot 1 ELF प्रणालीप्रारंभ, x86 संरक्षण_मूल्य मोड_मूल्य GDT, BSS आरंभ_करा, 64KiB संकार्य_स्टॅक.
- Java फलन_मूल्य वास्तविक_डेटा 실행과 प्रणालीप्रारंभ सिस्टम_माहिती खूण_मूल्य पडताळा.
- COM1 अनुक्रमिक_मूल्य इनपुट_आउटपुट, VGA वर्ण पडदा·कर्सर_मूल्य·스크롤·पुसा_प्रविष्टी.
- PS/2 डिफॉल्ट_मूल्य 자판, 좌우 Shift, Enter, Backspace. एक्सटेंशन_मूल्य कळ_मूल्य/마우스 자료는 आदेश 입력으로 쓰지 않는다.
- लांबी_मूल्य 128의 आदेश आदान_मूल्य 버퍼, ओवरफ्लो_मूल्य 방지, CR/LF प्रक्रिया_मूल्य_प्रविष्टी.
- `help`, `info`, `mem`, `alloc`, `free N`, `echo TEXT`, `clear`, `test`, `halt`.
- 4KiB पारपाडा_कार्य विभाग_मूल्य 8개의 संग्रह_वाटप_करा·परतकरा_मोजमाप·재사용과 중복 परतकरा_मोजमाप 방지.
- Java ऍरे_मूल्य 256KiB 영역의 आकार·उपलिपी_मूल्य 검사와 런타임 त्रुटी 중단.
- वाचन 전용 JKAP आज्ञा_कार्यवाही_करा समूह_मूल्य, ELF32 विभाग_मूल्य/प्रविष्टी_गुण प्रमाणित, प्रयोक्ता मोड_मूल्य·बाबी·निर्गमन_करा_अनुप्रयोग संहिता_मूल्य.
- गाभा_मूल्य/प्रयोक्ता 페이지 परवानगी_मूल्य 분리, TSS, IDT, PIT 100Hz, प्रयोक्ता CPU अपवाद प्रक्रिया_मूल्य_प्रविष्टी 및 आज्ञा_कार्यवाही_करा वेळ_मूल्य 상한.
- PCI RTL8139 폴링 드라이버, ARP, स्थिर_मूल्य IPv4, UDP चेकसम·송수신·प्रतीक्षा_करा_मूल्य मर्यादा_मूल्य.

`mem`의 Upper memory는 Multiboot의 1MiB वरचे_बाजू दाट_स्विच_प्रकरणे स्मृती_डेटा आकार(KiB)이며, 전체 स्मृती_डेटा 지도 분석이나 자유 물리 स्मृती_डेटा 수치가 아니다. `alloc`은 이미 확보한 पूर्णांक ऍरे_मूल्य 안의 पारपाडा_कार्य विभाग_मूल्य 번호를 반환한다. 일반 물리 पृष्ठ_मूल्य संग्रह_वाटप_करा, पत्ता पत्ता_प्रदेश 또는 प्रयोक्ता प्रक्रिया_मूल्य स्मृती_डेटा 관리가 아니다.

## 명시적인 सीमा_मर्यादा

이 커널은 **प्रयोक्ता 프로그램을 한 번에 एक_मूल्य 실행하는 प्रारंभिक_राज्य गाभा_मूल्य**이다. PIT IRQ0만 사용하며 키보드와 NIC는 폴링한다. प्रयोक्ता CPU 예외는 해당 프로그램을 끝내고 셸로 복귀시키지만 गाभा_मूल्य 예외는 중단한다. आज्ञा_कार्यवाही_करा 시간은 약 3초로 제한한다. 완전한 선점 다중 प्रक्रिया_मूल्य 스케줄러, FAT/ext 등 일반 디스크 फाइल_सिस्टम, TCP·DNS·DHCP·IPv6·HTTP, 전체 POSIX, 일반 ऑब्जेक्ट_मूल्य 모델/GC는 아직 없다. 전용 IDE फाइल 보존과 POSIX फाइल/UDP 일부 기능은 구현했다. JVM은 RAM 파일의 단일 클래스를 आज्ञा_कार्यवाही_करा 시 적재하며 일반 ClassLoader나 JAR 로딩은 지원하지 않는다. 네이티브 आज्ञा_कार्यवाही_करा 파일은 सिस्टम_बांधणी 시 वाचन 전용 묶음에 넣으며, 일반 Linux ELF를 실행하는 환경이 아니다. 기존 `../लेगसी_स्रोत/`의 JVM 관리 गाभा_मूल्य 전체를 이식한 것도 아니다.

Java 식별자는 한국어다. अनुक्रमिक_मूल्य 출력은 이 프로젝트의 हांगुल_मजकूर(BMP वर्ण)을 UTF-8로 표시한다. VGA는 डिफॉल्ट_मूल्य ASCII 글꼴만 사용하므로 हांगुल_मजकूर 자리에 `?`पहिले_संकार्य 나온다. आदेश 입력도 सध्याचे_आयटम ASCII만 지원하며 हांगुल_मजकूर फॉन्ट_मूल्य·입력기 및 सहायक_मूल्य 평면 वर्ण 출력은 후속 작업이다. `test`는 작은 배열을 새로 할당하고 GC가 없으므로 무한 반복하지 않는다.

## 자동 चाचण्या

`चाचण्या/प्रणालीप्रारंभ_चाचणी.py`는 디스크 없는 독립 QEMU를 생성해 다음을 검증하고 종료한다.

- ELF 직접 प्रणालीप्रारंभ 및 GRUB ISO प्रणालीप्रारंभ.
- Java स्वकीय 시험과 UTF-8 अनुक्रमिक_मूल्य शब्दसमूह_मूल्य.
- आदेश मदत_शो·सिस्टम_माहिती·स्मृती_डेटा·आउटपुट·त्रुटी आदान_मूल्य·पडदा पुसा_प्रविष्टी.
- पारपाडा_कार्य विभाग_मूल्य 8개 संग्रह_वाटप_करा, 부족 प्रक्रिया_मूल्य_प्रविष्टी, परतकरा_मोजमाप/중복 परतकरा_मोजमाप/재할당.
- अनुक्रमिक_मूल्य नवीओळ·백스페이스·긴 आदान_मूल्य प्रक्रिया_मूल्य_प्रविष्टी.
- QEMU PS/2 कळ_मूल्य 입력으로 `info` आज्ञा_कार्यवाही_करा, `halt` थांबवा_निष्पादन.

यश_मूल्य 로그는 `build/प्रणालीप्रारंभ_चाचणी.json`에 남는다. 로컬 Unix 소켓을 금지하는 샌드박스에서는 चाचण्या 도구에 해당 권한이 필요하다. चाचण्या 도중 새로 만든 QEMU만 종료하며 기존 VM과 वास्तविक_डेटा 디스크는 건드리지 않는다.

`चाचण्या/प्रयोक्ता_संचारजाळे_चाचणी.py`는 ELF/ISO 각각에서 प्रयोक्ता ELF, वास्तविक_डेटा ring 3, बाबी, होस्ट 루프백 UDP 왕복, 1,023/1,024바이트 24회 दाट_स्विच_प्रकरणे 왕복, वेळ_मूल्य 초과, NIC अनुपस्थित_पद्धत, स्मृती_डेटा/हार्डवेअर_पॉर्ट ऍक्सेस_प्रविष्टी 차단, CPU अपवाद, 무한 पुनरावृत्ती_मूल्य, 잘못된 ELF를 시험한다. `build/प्रयोक्ता_संचारजाळे_चाचणी.json`에 게스트 기록과 호스트가 받은 데이터의 लांबी_मूल्य·해시를 저장한다. `चाचण्या/पॅकेट_चाचणी.py`는 वास्तविक_डेटा Java काम_मूल्य 처리기에 손상된 패킷을 넣어 2,201개 सीमा_मूल्य/चेकसम 조건을 검사한다. होस्ट 루프백 외 बाह्य_मूल्य 서버에는 चाचण्या 트래픽을 보내지 않는다.

부트 경계는 GNU의 [Multiboot विनिर्देश](https://www.gnu.org/software/grub/manual/multiboot/multiboot.html)를 따른다.

새 संचिका_विवरणक·C ABI·IDE साठवणे_मूल्य·Java फाइल 흐름의 범위와 मराठी नामकरण 대응은 [posix-kor वापरमार्गदर्शिका_eb81d7d9](../posix-kor/वापरमार्गदर्शिका_eb81d7d9.md)에 있다. `make test-posix`로 ELF/ISO 실행과 재부팅 보존을 검증한다.
