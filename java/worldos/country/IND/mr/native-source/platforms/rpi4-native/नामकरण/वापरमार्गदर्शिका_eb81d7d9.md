# स्वकीय 커널과 번역기의 मराठी नाव

대상은 `platforms/rpi4-native`의 स्वकीय Java गाभा_मूल्य, प्रयोक्ता JVM, C मशीन जोडा,
TCP/UDP·FTP, C संकलक_साधन 이식부, MicroPython 이식부, सिस्टम_बांधणी·आज्ञा_कार्यवाही_करा·चाचण्या 도구다.
`golang/worldos/देश_मूल्य/KOR/स्रोत`의 원칙처럼 기능을 먼저 구분하고 이름을 정한다.
x86 Java 커널과 공용 x86·ARM64 미리 번역기의 स्वकीय 선언도 नामकरण 검사에 포함한다.
Linux 실행판의 होस्ट साधने, OpenJDK सहायक_मूल्य साधने 및 बाह्य_मूल्य वितरण_मूल्य स्रोत_ट्री 전체를
한국어로 पुनःप्रयत्न_मूल्य 작성했다는 뜻은 아니다.

## नामकरण 원칙과 말의 근거

- 명사는 자료의 역할을 나타낸다: `संचिका_हाताळा`, `समकक्ष_पोर्ट_नंबर`, `गतिमानस्मृतिराशी_संग्रह`, `कीबोर्ड`.
- 함수는 행위를 나타낸다: `वाचन`, `लेखन`, `उघडा`, `बंद_करा`, `जाळे_बाइंड_करा`, `रन_अनुप्रयोग`.
- TCP의 이어진 बाइट_मूल्य 흐름과 UDP의 सीमा_मूल्य 있는 자료를 `कनेक्शन`와 `स्वतंत्रसंदेश_चॅनल`로 구별한다.
- 짧은 영어 변수도 쓰임에 따라 `लांबी_मूल्य`, `डेटा_स्थान`, `लुकअप_अनुक्रमणिका`, `परतलेले_मूल्य`으로 풀어 쓴다.
  क्रमांक_अनुक्रमणिका·तात्पुरते_मूल्य 산술값처럼 여러 역할에 재사용되는 변수는 `क्रमांक_अनुक्रमणिका`, `पहिले_मूल्य`, `दुसरे_मूल्य`으로 구별한다.
- 이름이 같아도 बाह्य_मूल्य 구조체의 필드와 स्वकीय 변수는 별도로 분석한다.

`चॅनल_प्रविष्टी(通路)`는 이동이나 교류가 이루어지는 길이라는 기존 의미를 संचार 연결에
적용했다. `पॉर्ट_मूल्य(窓口)`의 주고받는 접점이라는 의미를 연결을 받는 곳에 적용했다.
이는 국립국어원 한국어기초사전의 [चॅनल_प्रविष्टी](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=49310),
[पॉर्ट_मूल्य](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=24898)의 뜻에 근거한다.

`स्वतंत्रसंदेश(電文)`은 전보에 담는 글이라는 기존 संचार 어휘에서 가져와, UDP 자료의
경계가 보존된다는 특징을 드러내는 데 쓴다. 근거는
[한국어기초사전 स्वतंत्रसंदेश](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=74335)이다.
`प्रवाह_मूल्य`, `कार्यसूत्र_मूल्य_5b72a632`, `쌓임`은 우리말의 움직임·आहे_पुढीलक्रम·쌓이는 모양을 빌린 표현이다.
`आदान_प्रवाह`, `कार्यसूत्र`, `स्टॅक_संग्रह` 같은 복합 이름은 이 프로젝트의 기능별 조어다.
이 शब्दकोश 근거를 특정 중세 문헌의 최초 출현이나 공인 전산 번역으로 확대하지 않는다.
공인 표준 भाषांतर_करा_स्रोत·국어사 स्वतंत्रसंदेश 감수를 마쳤다는 뜻도 아니다.

| 기능 | 채택한 नाव | कारण_मूल्य |
|---|---|---|
| TCP Socket | कनेक्शन | 상대와 연결되어 क्रम_मूल्य 있는 바이트를 주고받음 |
| ServerSocket | पॉर्ट_स्वीकारा | 새 연결이 들어오는 접점 |
| DatagramSocket | स्वतंत्रसंदेश_चॅनल | 각 자료의 경계를 보존하는 संचार |
| InputStream / OutputStream | आदान_प्रवाह / प्रदान_प्रवाह | 들어오고 나가는 바이트의 क्रम_मूल्य |
| heap / stack | गतिमानस्मृतिराशी_संग्रह / स्टॅक_संग्रह | संग्रह_वाटप_करा 방식과 쌓고 꺼내는 वास्तुरचना |
| thread / keyboard | कार्यसूत्र / कीबोर्ड | 이어지는 실행과 글쇠의 ऍरे_मूल्य |
| exception / timeout | अपवाद / प्रतीक्षा_करा_प्रतीक्षामर्यादा_अपवाद | आहे_सामान्य 처리에서 벗어남과 그 구체적 कारण_मूल्य |

## 보존하는 प्रमाणित_व्याख्या नाव

`public`, `class`, `int`는 예약어다. `String`, `main`, 배열의 `length`는 예약어가 아니다.
सध्याचे_आयटम 다섯 Java 예제는 `सुरू_करा()`·`वितर्क`·मराठी पडदा/कार्यसूत्र_मूल्य_5b72a632 API를 사용해
राखीव_शब्द·리터럴 외의 식별자를 한국어로 작성한다. पडदा/가닥은 표준 객체를
감싸지 않고 स्वकीय JVM에 직접 구현했다. 자세한 계약은 [मराठी Java API](../स्वकीय_जावा/वापरमार्गदर्शिका_eb81d7d9.md)를 본다.

표준 javac는 स्ट्रींग_मूल्य 리터럴에 `java.lang.String`, स्ट्रींग_मूल्य 결합에 `StringBuilder`
같은 이름을 생성한다. 이들은 मराठी 소스에서도 바이트코드에 남을 संख्या 있다.
기존 표준 class를 실행하는 JVM의 प्रतिचित्रण_मूल्य स्ट्रींग_मूल्य, 아직 표준 라이브러리를 쓰는
संचार·फाइल 연결부까지 सर्व_बांधणी 한국어로 재구현한 것은 아니다. 이름만 일괄 치환하면
विवरणक_प्रविष्टी·재정의·native 연결이 달라져 호환성이 깨진다.

C 표준 फलन_मूल्य·पूर्णांक_टाइप_करा·POSIX ABI, CPU रजिस्टर_मूल्य नाव, 어셈블리 आदेश, 링커 절 नाव,
TinyCC·lwIP·MicroPython이 요구하는 संयोजना 매크로와 헤더 이름도 보존한다.
예: `main`, `memcpy`, `pk_bind`, `mpconfigport.h`, `lwipopts.h`, `stdint.h`.
स्वकीय C 함수의 स्रोत_ट्री 이름은 한국어이며, [मशीन_लिंक_नावे.h](मशीन_लिंक_नावे.h)पहिले_संकार्य
기존 AOT·어셈블리·SDK에 공개한 मशीन 심볼과 연결한다.
Python의 `__init__`, `setUp`, `handle`, 표준 मॉड्यूल_मूल्य गुणधर्म_मूल्य, 명령행 옵션과 JSON 키도
बाह्य_मूल्य 계약이다. `build/`, वितरण_मूल्य 바이너리 이름과 `/sdk`는 기존 आज्ञा_कार्यवाही_करा 경로를 유지한다.
बाह्य_मूल्य 원본은 `vendor/`에서 이용허락·해시와 함께 관리한다.

## 검사와 재실행

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 साधने/नामकरण_तपासा.py
make सिस्टम_बांधणी
make चाचण्या
make test-examples test-ftp test-elf
python3 साधने/आज्ञा_कार्यवाही_करा.py --desktop --network
```

`साधने/विश्लेषणकरा_सी_नावे.py`는 libclang 6으로 C 선언과 참조를 검사한다.
`साधने/*이름반영.py`는 बदल_करा_मूल्य आधी_मूल्य स्रोत_ट्री·분석표를 필요로 하는 일회성 이행 도구다.
이미 변경된 소스에 पुनःप्रयत्न_मूल्य 적용하여 대응표를 덮어쓰지 않는다.

## C संचार 구조체와 Python त्रुटी

C 통신에서 `갈래`는 पत्ता 체계를 구분하고 `पोर्ट_नंबर`는 port, `पत्ता_मूल्य`은
IPv4 주소의 32비트 값을 나타낸다. `स्वतंत्रसंदेश_प्रोटोकॉल`은 앞서 설명한 स्वतंत्रसंदेश(電文)과
काम_मूल्य(規約)을 결합해 UDP의 기능을 드러낸 프로젝트 이름이다.

| 표준 표현 | मराठी 직접 अंमलबजावणी |
|---|---|
| AF_INET / SOCK_DGRAM / IPPROTO_UDP | enum의 क्लाउड_कुटुंब / स्वतंत्रसंदेश_संचारद्वार / स्वतंत्रसंदेश_प्रोटोकॉल |
| struct pk_sockaddr_in | struct क्लाउड_संचारद्वार_पत्ता |
| sin_family / sin_port | पत्ता_कुटुंब / पोर्ट_नंबर |
| sin_addr.s_addr | इंटरनेट_पत्ता.पत्ता_मूल्य |
| OSError / त्रुटी.args[0] | सिस्टम_त्रुटी / त्रुटी.अनुक्रमणिका |

मराठी 구조체는 `#define` 치환이나 फील्ड_मूल्य 별칭이 아닌 별개 자료형이다.
표준 구조체와 같은 16바이트 배치를 선언하며 गाभा_मूल्य SVC에서 बाइट_मूल्य 복사로
검사한다. `संचारटोक_तयार_करा`·`स्वतंत्रसंदेश_डेटा_पाठवा`와 फाइल 함수는 स्थिर_मूल्य 라이브러리에
वास्तविक_डेटा मराठी 이름의 फलन_मूल्य 심볼을 갖는다. 기존 pk_* 심볼도 유지한다.
मागील_आयटम 코드에서 मराठी संचार 함수에 pk_sockaddr*를 전달했다면 मराठी 구조체로
옮기거나, 표준 구조체와 pk_* 함수의 짝을 유지한다.

Python의 `सिस्टम_त्रुटी`는 OSError의 मराठी 하위 클래스이며 연결부에서
त्रुटी 번호를 보존하여 변환한다. 일반 Python 문법과 बाह्य_मूल्य 패키지의 API는 유지한다.

## 직접 GUI 이름의 뜻과 검토 क्लिप

`चालवण्यायोग्य_कार्य`은 수행할 내용을, `कार्यान्वित_करा`는 그 수행을 나타낸다.
`क्रिया_ग्राहक`는 동작이 발생했다는 알림을 받는 역할, `क्रिया_सूचना`은 전달되는 사건이다.
`बटण`는 눌러 동작시키는 조작부, `लेबल`는 वापरमार्गदर्शिका_eb81d7d9 글의 स्थान_अनुक्रमणिका,
`मजकूर_फील्_ड`은 글을 적는 स्थान_अनुक्रमणिका, `कार्यसूत्र`은 이어지는 आज्ञा_कार्यवाही_करा 흐름을 뜻한다.
`आज्ञा_कार्यवाही_करा(實行)`·`कृती(動作)`의 기존 뜻과 `받다`·`알리다`·`कार्यसूत्र_मूल्य_5b72a632`의 기능을
결합한 프로젝트 이름이다. 새 복합어가 역사 문헌에 그대로 있었다거나
특정 시대에 प्रारंभिक_आयटम 쓰였다고 주장하지 않는다.

전체 저장소는 `python3 साधने/स्रोत_पुनरावलोकन.py`로 검토한다.
결과는 `build/verification/naming/source-review.json`이며 파일별 हॅश_संचिका,
ASCII 파일명과 Python의 영어 घोषणा 위치를 기록한다.
공용 ARM64·x86 번역기의 구현은 `compiler/जावा_साधने/आगाऊ_संबंधित_वेळ_संकलक.java`로 전환했다. `compiler/आगाऊ_संबंधित_वेळ_संकलक.py`는 호환 진입점이다.
`compiler/arm64.py`는 मागील_आयटम 경로와 `ARM64(...).generate(...)` 호출을 पुढीलक्रम_मूल्य 주는
호환 진입점이다. `compiler/classfile.py`, OpenJDK सहायक_मूल्य साधने, Linux आवृत्ती_मूल्य 도구와
기존 호환 진입점에는 영어 이름이 남아 있다. 따라서 전체 저장소가
राखीव_शब्द 외 100% 한국어라고 판정하지 않는다.
`साधने/नामकरण_तपासा.py --सी_भाषा`는 सक्रिय ARM64 소스의 घोषणा, C 의미 विश्लेषणकरा_मूल्य,
x86 Java 커널과 공용 번역기의 स्वकीय घोषणा, Java उदाहरणे 전체 आयडेंटिफायर_मूल्य,
ARM64 Python 예제와 직접 GUI/가닥에 표준 래퍼가 없는지를 별도로 검사한다.

## सध्याचे_आयटम 기능을 기준으로 보완한 नाव

번역은 글자를 음역하는 대신 자료의 역할과 함수의 행동을 구분한다.
동일한 영어 이름도 문맥이 다르면 मराठी 이름을 달리 정한다.
फाइल 이름은 주된 기능을 나타내고, फलन_मूल्य 이름은 행동을, चल_मूल्य 이름은 담는 자료를 나타낸다.
राखीव_शब्द, 표준 API 및 बाह्य_मूल्य जोडा 규약은 따로 기록한다.

| मागील_आयटम नाव | 적용한 नाव | सध्याचे_आयटम 기능 |
|---|---|---|
| `arm64.py`의 अंमलबजावणी | `compiler/जावा_साधने/आगाऊ_संबंधित_वेळ_संकलक.java` | Java 바이트코드를 독립 실행용 C 원문으로 미리 भाषांतर_करा_स्रोत |
| `ARM64`, `generate` | `मशीन_संहिता_संकलक`, `तयार_करा` | भाषांतर_करा_स्रोत 상태를 담는 객체와 C स्रोत तयार_करा वर्तन_मूल्य |

### 말의 뿌리와 새로운 복합 नाव

`स्मृती_मूल्य(記憶)`과 `लुकअप_अनुक्रमणिका(索引)`은 기존 한자어를 쓴다.
기억은 자료를 간직하는 기능에, 색인은 क्रम_मूल्य 있는 항목을 찾아 지정하는 기능에 적용한다.
शब्दकोश 근거는 국립국어원 한국어기초사전의
[स्मृती_मूल्य](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=38812&nation=eng),
[लुकअप_अनुक्रमणिका](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=63787)이다.

`स्टॅक_संग्रह`, `राशीवरठेवा_मूल्य`, `पोस्ट_ऑफिस_प्रोटोकॉल_मूल्य`는 자료를 포개고 शेवटचे_आयटम 자료부터 꺼내는 आज्ञा_कार्यवाही_करा 구조를 드러낸다.
`쌓다`의 기존 뜻에 근거한 기능별 조어이며, 사전의
[쌓다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62095)를 참고한다.
`आगाऊ_संबंधित_वेळ`은 आज्ञा_कार्यवाही_करा 전에 번역한다는 기능을 직접 나타낸다.
`मशीन_शब्द`은 처리기의 डेटा 단위를 가리키며, 언어의 일반 낱말과 구별하도록 `मशीन`를 붙였다.
`आगाऊ_संबंधित_वेळ_संकलक`, `गतिमानस्मृतिराशी_शब्द_गणना` 같은 복합 이름은 सध्याचे_आयटम 기능에 맞게 만든 프로젝트 용어다.
이 복합어가 옛 문헌에 그대로 있었다거나 특정 시대에 प्रारंभिक_आयटम 나타났다는 뜻은 아니다.
확인되지 않은 중세 형태나 최초 वापर_मूल्य 연대는 어원 근거로 적지 않는다.

생성되는 C의 내부 डेटा_टाइप·ऍरे_मूल्य·फलन_मूल्य·स्थानिक_संधी चल_मूल्य·शाखा 이름도 한국어로 바꾼다.
직접 हांगुल_मजकूर 식별자를 읽지 못하는 예전 GCC를 위해 호환 API는 같은 मराठी 이름을
표준 C 범용 वर्ण 표기로 출력한다. वास्तविक_डेटा ARM64 빌드는 Clang으로 읽을 संख्या 있는 हांगुल_मजकूर 원문을 사용한다.
स्ट्रींग_मूल्य, C 표준 फलन_मूल्य, `java_entry` 같은 공개 जोडा 이름은 바꾸지 않는다.

셸의 사용법·문법 त्रुटी·फाइल 및 स्मृती_मूल्य पत्ता_प्रदेश 안내도 한국어로 보완했다.
`READY`, `PASS`, `HEX BEGIN`처럼 चाचण्या·फाइल स्थानांतर_मूल्य 도구가 읽는 खूण_मूल्य,
명령행 옵션과 기존 निर्देश_मूल्य, JVM वर्ग_मूल्य नाव·फाइल स्वरूप_मूल्य·मोबाइल_मूल्य 이름은 호환 표기로 남는다.
x86 VGA वर्ण 화면은 한글을 표시하지 못하므로 मराठी 문구는 UTF-8 अनुक्रमिक_मूल्य 단말에서 확인한다.
