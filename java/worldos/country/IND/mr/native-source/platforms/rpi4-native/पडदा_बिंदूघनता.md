# स्वकीय ARM64 커널의 पडदा बिंदूघनता_मूल्य

QEMU आज्ञा_कार्यवाही_करा 위치는 `jkoros/platforms/rpi4-native`तिसरे_संकार्य. 커널을 빌드한 मागे_मूल्य 다음과 같이 실행한다.

```bash
make build
python3 साधने/आज्ञा_कार्यवाही_करा.py --desktop --network --resolution 1920x1080
```

Remmina의 **VNC** जोडा 주소는 `127.0.0.1:5902`तिसरे_संकार्य. 이미 आज्ञा_कार्यवाही_करा 중인 VM은 종료하고 새 옵션으로 पुनःप्रयत्न_मूल्य 시작한다. पडदा 전체가 보이지 않으면 Remmina에서 पडदा संरेखन_करावे_सीमा 또는 전체 화면을 선택한다. 이 옵션은 게스트의 वास्तविक_डेटा पिक्सेल 수를 바꾼다.

`--resolution`은 일반 UART आज्ञा_कार्यवाही_करा, `--desktop`, `--vnc`, `--display`에서 동일하게 적용된다. `--network`와 함께 사용할 संख्या 있다. रुंदी_मूल्य 640~1920, उंची_मूल्य 480~1080을 허용하며 기본값은 640×480이다. 1280×720과 1920×1080도 선택할 संख्या 있다.

```bash
make desktop RESOLUTION=1920x1080
python3 साधने/आज्ञा_कार्यवाही_करा.py --resolution 1280x720 --vnc 127.0.0.1:2
```

प्रणालीप्रारंभ 로그는 वास्तविक_डेटा 할당된 크기를 표시한다.

```text
FRAMEBUFFER PASS 1920x1080 RGB32 (drawing only)
```

टर्मिनल 바탕과 वरचे_बाजू 막대는 पडदा 전체를 채운다. 터미널은 उजवे 아래까지 끌어서 이동하고 X로 닫을 संख्या 있다. टर्मिनल विंडो आकार(568×360)와 फॉन्ट_मूल्य 크기는 유지되므로 넓어진 화면에 여러 창을 배치할 संख्या 있다. Swing 부분집합의 `setLocationRelativeTo(null)`도 वास्तविक_डेटा पडदा 가운데를 사용한다. प्रणालीप्रारंभ मागे_मूल्य 해상도를 바꾸는 기능은 제공하지 않는다.

## 프로그램에서 पडदा आकार वाचन

| भाषा | मराठी आवाहन |
|---|---|
| Java | `मराठी.स्वकीय.पडदा.रुंदी_मूल्य()`, `पडदा.उंची_मूल्य()`, `पडदा.पुसा_प्रविष्टी(रंग_मूल्य)` |
| C | `<पडदा_द्विमानजोडणी.h>`의 `पडदा_रुंदी()`, `पडदा_उंची()`, `आयत_आरेखित_करा(...)` |
| C++ SDK | `आवाहन.h`의 `पडदा_रुंदी_वाचा()`, `पडदा_उंची_वाचा()`, `पडदा_आयत(...)` |
| Python | `from मराठी import पडदा_आकारा, आयत_आरेखित_करा`; `रुंदी_मूल्य, उंची_मूल्य = पडदा_आकारा()` |

C 함수는 मॅक्रो_मूल्य 별칭이 아닌 वास्तविक_डेटा 함수다. प्रयोक्ता आवाहन 22로 크기를 조회하며, पेंट_पडदा आवाहन 13과 GUI आवाहन 20은 वास्तविक_डेटा पडदा 경계를 검사한다. 프레임버퍼 주소는 प्रयोक्ता 프로그램에 노출하지 않는다. पडदा 밖의 요청은 오류를 반환한다.

게스트 `javac`에서는 `मराठी.स्वकीय.पडदा.रुंदी_मूल्य()`처럼 전체 이름으로 호출한다. 지원하는 स्रोत_ट्री 문법에 맞춰 पिक्सेल_रंग 상수는 십진수로 쓴다. तळ_मूल्य 호출은 प्रणालीप्रारंभ 해상도와 관계없이 शेवटचे_आयटम 화소를 그린다.

```java
int रुंदी_मूल्य = मराठी.स्वकीय.पडदा.रुंदी_मूल्य();
int उंची_मूल्य = मराठी.स्वकीय.पडदा.उंची_मूल्य();
मराठी.स्वकीय.पडदा.आयत(रुंदी_मूल्य - 1, उंची_मूल्य - 1, 1, 1, 255);
```

`पडदा` 클래스의 프레임버퍼 호출은 स्वकीय JVM 전용이다. 이 API의 अपवाद प्रक्रिया_मूल्य_प्रविष्टी 시험은 होस्ट `javac --release 8`로 컴파일한 class를 स्वकीय JVM에서 실행한다. 게스트 컴파일러의 일반적인 `try/catch` 문법 지원을 추가한 것은 아니다.

## Raspberry Pi 4 SD प्रणालीप्रारंभ

```bash
make image RESOLUTION=1920x1080
```

생성되는 `dist/jkoros-native-rpi4.img`와 `dist/jkoros-native-rpi4-boot.zip`에 1080p 설정이 들어간다. SD चित्र_मूल्य 생성은 640×480, 1280×720, 1920×1080을 지원한다. 이미 펼친 प्रणालीप्रारंभ 파일을 수정할 경우 `config.txt`의 `[pi4]`에 तळ_मूल्य 값을 사용한다.

```ini
max_framebuffer_width=1920
max_framebuffer_height=1080
framebuffer_width=1920
framebuffer_height=1080
hdmi_group=1
hdmi_mode=16
```

커널은 [Raspberry Pi मेलबॉक्स काम_मूल्य](https://github.com/raspberrypi/firmware/wiki/Mailbox-property-interface)의 सध्याचे_आयटम पडदा आकार 조회와 पडदा संग्रह_वाटप_करा 응답을 사용한다. 응답의 आकार·RGB32 स्वरूप_मूल्य·한 줄의 बाइट_मूल्य संख्या·संग्रह_वाटप_करा 용량을 확인하고, 반환된 ओळ 간격으로 그린다. प्रारंभिक_राज्य 조회에 실패하거나 समर्थन_मूल्य 범위를 벗어나면 640×480을 요청한다. HDMI 설정은 [공식 펌웨어 पडदा संयोजना मार्गदर्शिका](https://www.raspberrypi.com/documentation/computers/legacy_config_txt.html)를 따른다. वास्तविक_डेटा Pi 4와 모니터 조합에서의 HDMI 부팅은 아직 검증하지 않았다.

## प्रमाणित

```bash
make test-resolution
```

시험은 각 해상도에서 वास्तविक_डेटा VNC पडदा 크기와 픽셀, टर्मिनल ओढा_मूल्य·बंद_करा, C/Java 게스트 स्रोत_बांधणी, Python आज्ञा_कार्यवाही_करा, उजवे तळ_मूल्य 픽셀과 पडदा सीमा_मूल्य त्रुटी, Swing मध्य लिंक_लेआउट·बटण·बंद_करा, GUI와 FTP 동시 사용을 확인한다. 결과와 पडदा 캡처는 `build/verification/resolution/`에 저장한다.
