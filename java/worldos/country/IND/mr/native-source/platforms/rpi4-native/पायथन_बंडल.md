# स्वकीय 커널의 Python बंडल स्थापित_करा_मूल्य

स्वकीय ARM64 커널의 `python`은 **MicroPython 1.24.1 पूर्णांक सिस्टम_बांधणी**तिसरे_संकार्य.
`pip`와 `python -m pip`는 이 환경을 위한 제한형 स्रोत_ट्री स्थापित_करा_मूल्य 명령이다.
PyPA pip 전체나 CPython을 이식한 것은 아니다.

호스트에서 실행한다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
python3 साधने/आज्ञा_कार्यवाही_करा.py --desktop --network --pip
```

게스트 셸에서 설치하고 사용한다.

```text
pip install micropython-bisect==3.3.3
pip list
python -c 'from bisect import insort as 순서대로넣기; मूल्य=[1,5]; 순서대로넣기(मूल्य,3); print(मूल्य)'
python -m pip list
pip uninstall micropython-bisect
```

आहे_सामान्य आज्ञा_कार्यवाही_करा 결과는 `[1, 3, 5]`तिसरे_संकार्य. 예시 वितरण_मूल्य 파일은
[PyPI의 micropython-bisect 3.3.3](https://pypi.org/project/micropython-bisect/3.3.3/)이며
SHA-256은 `b8d09d0bb4b2add706078dfa3f306e22fad1f4b5340b87d13f2c852507d720c8`이다.
`bisect`는 स्थापित_करा_मूल्य आधी_मूल्य 내장되어 있지 않다. 내려받은 `.py`를 स्वकीय 커널의 EL0
MicroPython이 import하여 실행한다.

## स्थापित_करा_मूल्य 경로와 역할

호스트의 [बंडल_संदेशमध्यस्थ.py](साधने/बंडल_संदेशमध्यस्थ.py)는 PyPI HTTPS 다운로드, 인증서 पडताळा,
वितरण_मूल्य फाइल SHA-256 검증과 संग्रह_मूल्य 해제를 맡는다. 호스트에서 `setup.py`दुसरे_संकार्य 내려받은
Python 코드를 실행하지 않는다. होस्ट pip 설치도 आवश्यक_मूल्य 없다.
중계는 `127.0.0.1:8027`에만 열리며 게스트는 QEMU NAT의 `10.0.2.2:8027`로 연결한다.
게스트 자체에 DNS·TLS·PyPI संग्रह_मूल्य संग्रह_रिलीज 기능을 추가했다는 뜻은 아니다.

게스트의 [बंडल.py](पायथन_ब्रिज/लायब्ररी/बंडल.py)는 TCP로 받은 파일의 SHA-256과
मार्ग·आकार·문법을 검사한 मागे_मूल्य `/lib`에 설치하고 `/lib/.pip.json`에 목록을 기록한다.
`/lib`와 आज्ञा_कार्यवाही_करा लिपी_मूल्य 폴더를 मॉड्यूल_मूल्य 검색 경로에 추가했으므로 पारपाडा_कार्य 폴더가 달라도
설치한 모듈을 import할 संख्या 있다. 패키지 폴더와 समकक्ष_मूल्य import도 지원한다.

स्थापित_करा_मूल्य 도중 पत्ता_प्रदेश 부족 등 오류가 발생하면 새 파일과 폴더를 지우고 기존 목록을
복원한다. 이미 있는 प्रयोक्ता 파일을 덮어쓰지 않는다. 동일 버전 재설치 요청은
फाइल 지문을 확인하고 유지한다. 다른 버전은 प्रविष्टी_काढणे नंतर_राज्य 설치한다. प्रविष्टी_काढणे 시 사용자가
수정한 파일이 발견되면 보존하고 오류를 알린다. 빈 패키지 폴더는 남을 संख्या 있다.

**`/lib`도 RAM 파일이다. 재부팅하면 설치한 패키지가 사라진다.**
होस्ट `build/pip-cache`에는 वितरण_मूल्य 파일과 उगम_मूल्य·지문이 남으므로 पुढील_आयटम 부팅에서 पुनःप्रयत्न_मूल्य
설치할 संख्या 있다. 버전을 지정하면 같은 वितरण_मूल्य 파일을 재사용한다.

```sh
# होस्ट: 인터넷이 있을 때 वितरण_मूल्य 파일만 तयार_करणे
python3 साधने/बंडल_संदेशमध्यस्थ.py --fetch micropython-bisect==3.3.3
# पुढील_आयटम आज्ञा_कार्यवाही_करा: PyPI जोडा 없이 캐시 वापर_मूल्य
python3 साधने/आज्ञा_कार्यवाही_करा.py --network --pip --pip-offline
```

다른 포트는 होस्ट `--pip-port 8028`, 게스트
`pip install micropython-bisect==3.3.3 --port 8028`로 맞춘다.
होस्ट 중계는 `python3 साधने/बंडल_संदेशमध्यस्थ.py --port 8027`로 별도 실행할 수도 있다.
QEMU를 종료하거나 संदेशमध्यस्थ_मूल्य 실행을 끝내면 이 서비스도 닫힌다.

## समर्थन_मूल्य क्लिप

- अवलंबने 없는 순수 Python wheel(`*-none-any.whl`, `Root-Is-Purelib: true`).
- 구형 `micropython-*` स्रोत_ट्री 배포형의 `.py`와 `PKG-INFO`.
- 꾸러미당 स्रोत_ट्री 16개, एकूण_मूल्य 64 KiB, 파일당 16 KiB, 절대 मार्ग UTF-8 63바이트 이하.
  전체 RAM फाइल 64개·निर्देशिका_मूल्य 16개의 남은 공간과 Python गतिमानस्मृतिराशी_मूल्य 256 KiB 한도도 적용된다.
- `install`, `list`, `uninstall`, `--help`, `--version`.
- SHA-256, JSON, स्मृती_डेटा `io.StringIO`/`BytesIO`를 실행기에 추가했다.
  일반 फाइल ऑब्जेक्ट_मूल्य `open()`은 미지원이며 `मराठी.संचिका_वाचा/संचिका_लिहा` 또는
  `jkoros.read/write`를 사용한다.

C एक्सटेंशन_मूल्य·플랫폼 전용 wheel, 일반 sdist सिस्टम_बांधणी, 자동 अवलंबने 해결, extras, VCS/임의 URL,
NumPy 같은 CPython 전용 패키지는 지원하지 않는다. 순수 Python 패키지도
MicroPython의 문법·표준 मॉड्यूल_मूल्य·पूर्णांक 전용 환경과 맞아야 실제로 실행할 संख्या 있다.
स्थापित_करा_मूल्य 시 문법을 검사하지만 모든 आज्ञा_कार्यवाही_करा 경로의 호환성을 증명하지는 않는다.
वास्तविक_डेटा Raspberry Pi 4의 LAN을 통한 설치는 검증하지 않았으며 सध्याचे_आयटम 중계는 QEMU용이다.

MicroPython 자체의 패키지 체계와 CPython pip의 차이는
[MicroPython 패키지 मार्गदर्शिका](https://docs.micropython.org/en/v1.24.0/reference/packages.html),
wheel 형식은 [PyPA वितरण_मूल्य स्वरूप_मूल्य प्रमाणित_व्याख्या](https://packaging.python.org/en/latest/specifications/binary-distribution-format/)을 참고한다.

```sh
make test-pip
```

प्रमाणित 기록은 `build/verification/pip/report.json`과 `serial.log`에 저장한다.
वास्तविक_डेटा PyPI बंडल 시험과 별도로 시험용 wheel로 패키지 निर्देशिका_मूल्य, 구문 त्रुटी,
पत्ता_प्रदेश 부족 되돌림을 확인한다.
