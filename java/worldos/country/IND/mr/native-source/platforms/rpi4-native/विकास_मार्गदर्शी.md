# स्वकीय 커널에서 vi·여러 टर्मिनल·हांगुल_मजकूर 프로그래밍 사용하기

मराठी संचार·अपवाद 사용법은 [मराठी Java API](स्वकीय_जावा/वापरमार्गदर्शिका_eb81d7d9.md), फलन_मूल्य·चल_मूल्य·फाइल 이름의 변경과 어원 근거는 [नामकरण वापरमार्गदर्शिका_eb81d7d9](नामकरण/वापरमार्गदर्शिका_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 स्वकीय AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 तळ_मूल्य समर्थन_मूल्य 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 आज्ञा_कार्यवाही_करा, बाह्य_मूल्य TCP/UDP와 FTP는 [새 आज्ञा_कार्यवाही_करा 매뉴얼](संचिका_स्थानांतर_आणि_संकलन.md)을 참고한다.

## GUI와 여러 टर्मिनल

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, पत्ता **127.0.0.1:5902**로 연결한다. पडदा वरचे_मूल्य **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. कमाल_मूल्य 네 개다. वरचे_बाजू टर्मिनल 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **उजवे वरचे_मूल्य X**를 클릭하면 닫힌다. शेवटचे_आयटम 창을 닫아도 वरचे_बाजू आज्ञा_कार्यवाही_करा 버튼으로 पुनःप्रयत्न_मूल्य स्तंभ_मूल्य संख्या 있다. 기존 `terminal`, `exit`, F12도 사용할 संख्या 있다.

창마다 सध्याचे_आयटम 디렉터리, शेल चल_मूल्य, आदेश लॉग_नोंद, आदान_मूल्य 중인 명령과 अनुप्रयोग_f5044b9b आज्ञा_कार्यवाही_करा 상태를 보관한다. फाइल 저장소는 공유한다. vi와 Swing의 이벤트 प्रतीक्षा_करा_मूल्य 중에 다른 터미널로 전환하면 प्रयोक्ता स्मृती_डेटा·레지스터·फाइल/संचारद्वार_मूल्य 연결을 보존했다가 돌아올 때 재개한다. **सध्याचे_आयटम 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** गणना 중인 프로그램은 पुढील_आयटम आदान_मूल्य प्रतीक्षा_करा_मूल्य 또는 기존 आज्ञा_कार्यवाही_करा 기한까지 전환이 지연될 संख्या 있다.

X로 터미널을 닫으면 그 터미널의 आज्ञा_कार्यवाही_करा 중인 프로그램도 종료하며 विवरणक_प्रविष्टी·소켓을 회수한다. 저장하지 않은 संपादन_मूल्य 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. सध्याचे_आयटम 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 विंडो 판단은 게스트 커널이 처리한다. QEMU आज्ञा_कार्यवाही_करा 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. वास्तविक_डेटा Pi4 USB 입력기와 भौतिक_हार्डवेअर 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI साधने 종료는 होस्ट 터미널의 Ctrl+C다.

## vi वापर_मूल्य

```text
mkdir पारपाडा_कार्य
cd पारपाडा_कार्य
vi अभिवादन_ae353e94.py
```

`vi`는 새로 구현한 **vi आदेश 부분집합** 편집기다. 내장 `build/user/vi.elf`를 보호된 प्रयोक्ता 영역에 적재한다. फाइल 크기는 UTF-8 बाइट_मूल्य प्रोजेक्ट_मूळ 16 KiB, 경로는 63바이트까지다. 디스크에 설치한 Vim/Neovim 바이너리를 실행하는 것이 아니다.

| कळ_मूल्य/आदेश | कृती |
|---|---|
| `i`, `a`, `I`, `A` | सध्याचे_आयटम/पुढील_आयटम जागा 또는 ओळ प्रारंभिक_आयटम/끝에서 आदान_मूल्य |
| `o`, `O` | तळ_मूल्य/위에 새 줄을 만들고 आदान_मूल्य |
| Esc | 일반 मोड_मूल्य |
| `h j k l`, 방향키 | UTF-8 वर्ण/ओळ हलवा_मूल्य |
| `0`, `$`, Home, End | ओळ प्रारंभिक_आयटम/शेवट |
| `gg`, `G`, `:अनुक्रमणिका` | फाइल प्रारंभिक_आयटम/शेवटचे_आयटम ओळ/नेमा_मूल्य ओळ |
| PgUp, PgDn | पडदा एकक_मूल्य हलवा_मूल्य |
| `x`, Delete | सध्याचे_आयटम वर्ण 삭제 |
| `dd`, `yy`, `p` | ओळ 삭제/इन्स्टन्स_मूल्य/चिकटवा_मजकूर |
| `u` | शेवटचे_आयटम 편집을 परतकरा_ब्रिज; 한 टप्पा_मूल्य 토글 |
| `/स्ट्रींग_मूल्य`, `n` | 단순 स्ट्रींग_मूल्य 검색/पुढील_आयटम आहे_समान; 정규식 अनुपस्थित_पद्धत |
| `:w`, `:w 다른이름` | RAM फाइल साठवणे_मूल्य/다른 경로로 साठवणे_मूल्य |
| `:q` | 변경이 없을 때 निर्गमन_करा_अनुप्रयोग |
| `:q!` | 변경을 버리고 निर्गमन_करा_अनुप्रयोग |
| `:wq`, `ZZ` | 저장하고 निर्गमन_करा_अनुप्रयोग |

붙여 넣은 한글을 वर्ण 경계에 맞춰 हलवा_मूल्य·삭제한다. 일반 vi의 수량 접두사, मॅक्रो_मूल्य, संयोजना फाइल, 플러그인, 정규식, 여러 버퍼/분할 विंडो, 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/शून्य_संकार्य 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 विंडो विंडो_शीर्षक `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 आदेश**으로 실행한다. 파이프·리다이렉션·लिपी_मूल्य·`;`/`&&`/`||`로 연결한 실행에서 परस्परसंवादी 대기를 시작하면 거부한다. आदान_मूल्य 대기는 약 2초 CPU 기한을 갱신하지만 आदान_मूल्य प्रतीक्षा_करा_मूल्य 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## हांगुल_मजकूर Java

vi에서 다음을 `अभिवादन_ae353e94.java`에 입력하고 Esc → `:wq`로 저장한다.

```java
public class अभिवादन_ae353e94 {
    static int जोडा_मूल्ये(int पहिले_क्रमांक, int दुसरे_क्रमांक) { return पहिले_क्रमांक + दुसरे_क्रमांक; }
    public static void main(String[] बाबी) {
        int एकूण_मूल्य = जोडा_मूल्ये(20, 22);
        System.out.println("안녕하세요 · एकूण_मूल्य=" + एकूण_मूल्य);
    }
}
```

게스트 셸에서 실행한다.

```text
javac अभिवादन_ae353e94.java
java अभिवादन_ae353e94
```

हांगुल_मजकूर संचिका_नाव_मजकूर·वर्ग_नाव·पद्धत_नाव_मजकूर·변수명·문자열을 사용할 संख्या 있다. **게스트 javac는 स्थिर_मूल्य Java 부분집합**이다. ऑब्जेक्ट_मूल्य·리스너·Swing·소켓을 사용하는 소스는 सध्याचे_आयटम होस्ट JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 स्वकीय JVM에 class를 올린다. स्वकीय JVM에서 지원하는 बाइटसंहिता/API 범위는 [जावा_सामान्य_भाषा_रनटाइम_पर्यावरण.md](जावा_सामान्य_भाषा_रनटाइम_पर्यावरण.md)를 따른다.

```sh
# होस्ट
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java चाचण्या/जावा/स्विंग_चाचणी_da272923.java
python3 साधने/अपलोड_करा_संचिका.py build/my-java/स्विंग_चाचणी_da272923.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. आउटपुट 전체를 GUI 터미널에 보내면 업로드한다. 업로드 नंतर_राज्य **별도로** `java स्विंग_चाचणी_da272923`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.वर्ग_मूल्य.class` 형식이다. 내장 मराठी 라이브러리는 별도 업로드가 आवश्यक_मूल्य 없다. मराठी विंडो API의 예제는 [हांगुल_विंडो_चाचणी.java](चाचण्या/जावा/हांगुल_विंडो_चाचणी.java)이며 같은 방법으로 स्रोत_बांधणी·업로드해 `java हांगुल_विंडो_चाचणी`으로 실행한다.

GUI가 आवश्यक_मूल्य 없는 단일 स्रोत_ट्री/클래스는 호스트의 `python3 साधने/संचिका_कार्यवाही_करा.py मार्ग/अभिवादन_ae353e94.java`로 별도 QEMU에 업로드·आज्ञा_कार्यवाही_करा·종료할 संख्या 있다. परस्परसंवादी Swing에는 आज्ञा_कार्यवाही_करा नंतर_राज्य प्रयोक्ता 입력을 유지하는 `make desktop`을 사용한다.

## स्वकीय JVM의 Swing क्लिप

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 स्वकीय Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | कृती |
|---|---|
| `JFrame` | विंडो_शीर्षक, आकार·जागा, विंडो_शो, बंद_करा 정책, dispose |
| `JPanel` | उपघटक_मूल्य 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 स्ट्रींग_मूल्य मूल्य_शो·बदल_करा_मूल्य |
| `JButton` | 버튼과 ActionListener क्लिक_करा_मूल्य प्रक्रिया_मूल्य_प्रविष्टी |
| `JTextField` | 한 ओळ UTF-8 आदान_मूल्य, 삭제, getText/setText, Enter 이벤트 |
| सामायिक_मूल्य | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 वर्ण 조판은 아직 없다. 이벤트 콜백은 स्वकीय JVM의 단일 이벤트 आज्ञा_कार्यवाही_करा 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. विंडो·요소는 आज्ञा_कार्यवाही_करा 하나당 एकूण_मूल्य 32개, घटक_मूल्य 글자는 कमाल_मूल्य 127 코드포인트다. डिफॉल्ट_मूल्य 서체와 색은 커널이 제공한다.

[स्विंग_चाचणी_da272923.java](चाचण्या/जावा/स्विंग_चाचणी_da272923.java)는 विंडो·हांगुल_मजकूर टॅग_मूल्य·मजकूर_फील्_ड·버튼·이벤트 처리의 आज्ञा_कार्यवाही_करा 가능한 예제다. [स्वकीय Swing पडदा](build/verification/swing/native-swing.png)을 참고한다.

मराठी 라이브러리에는 다음을 추가했다. होस्ट स्रोत_बांधणी 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `मराठी.स्वकीय.विंडो`: `जोडा_घटक`, `विंडो_शो`, `बंद_करा`.
- `मराठी.स्वकीय.विजेट`: `टॅग_मूल्य`, `बटण`, `मजकूर_फील्_ड` तयार_करा.
- `मराठी.स्वकीय.कनेक्शन_वाहतूक`: `जोडा`, `ऐका_संचारटोक`, `स्वीकारा`.
- 기존 `आउटपुट`, `वर्ण`, `फाइल`, `पारपाडा_कार्य`, `प्रविष्टी_यादी`, `शब्दकोश`, `संचार`, `पडदा`, `गाभा_मूल्य`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **गाभा_मूल्य 내부 연결형 बाइट_मूल्य प्रवाह_मूल्य**을 추가했다. फाइल/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket सर्व्हर_मूल्य = new java.net.ServerSocket(9250);
java.net.Socket अतिथी_मूल्य = new java.net.Socket("localhost", 9250);
java.net.Socket जोडा = सर्व्हर_मूल्य.accept();
अतिथी_मूल्य.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] स्वीकारलेले_आयटम = new byte[64];
int लांबी_मूल्य = जोडा.getInputStream().read(स्वीकारलेले_आयटम);
जोडा.close(); अतिथी_मूल्य.close(); सर्व्हर_मूल्य.close();
```

तयार_करा·जोडा·accept·양방향 बाइट_मूल्य/ऍरे_मूल्य इनपुट_आउटपुट·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 शेवट_करा_गुण 16개, मूल्य_स्वीकारा 버퍼당 1024바이트, प्रतीक्षा_करा_मूल्य जोडा कमाल_मूल्य 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. डिफॉल्ट_मूल्य वेळ_मूल्य मर्यादा_मूल्य 0은 별도 संचारद्वार_मूल्य 기한을 설정하지 않지만 JVM आदेश संख्या/गाभा_मूल्य आज्ञा_कार्यवाही_करा 기한은 여전히 적용된다.

बाह्य_मूल्य अंक_मूल्य IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. वास्तविक_डेटा Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP लायब्ररी 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [प्रवाह_चाचणी.java](चाचण्या/जावा/प्रवाह_चाचणी.java)는 वास्तविक_डेटा 송수신·EOF·기한·जोडा 회수의 चाचण्या 예제다.

## हांगुल_मजकूर Python

게스트 vi에서 हांगुल_मजकूर 이름을 사용해 작성한다.

```python
मूल्य = 21

def 두배(अंक_मूल्य):
    return अंक_मूल्य * 2

print("मोजमाप:", 두배(मूल्य))
```

साठवणे_मूल्य नंतर_राज्य `python अभिवादन_ae353e94.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 फलन_मूल्य·चल_मूल्य·फाइल 이름과 문자열을 한글로 쓴다.

[मराठी.py](उदाहरणे/हांगुल_संकेतन/मराठी.py)를 같은 디렉터리에 두면 पुढील_आयटम 별칭을 사용할 संख्या 있다.

```python
import मराठी
मराठी.संचिका_लिहा("अभिवादन_ae353e94.txt", "안녕하세요")
मराठी.आउटपुट(मराठी.संचिका_वाचा("अभिवादन_ae353e94.txt").decode())
```

आउटपुट·फाइल वाचन/लेखन/삭제·표준 आदान_मूल्य·आयत·वेळ_मूल्य·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 अंक_मूल्य IPv4 पत्ता 전송이다. `wait_key()`는 화면을 확인할 때 परस्परसंवादी 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor स्थिर_मूल्य 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 एक्सटेंशन_मूल्य 모듈은 아직 없다. 제한형 `pip`의 स्रोत_ट्री 설치는 [Python बंडल वापरमार्गदर्शिका_eb81d7d9](पायथन_बंडल.md)를 따른다. [तीन_मूल्य 언어의 वास्तविक_डेटा उदाहरणे](../../example/README.md).

## C·C++에서 posix-kor आवाहन

두 भाषा सर्व_बांधणी मराठी 헤더와 फलन_मूल्य 이름을 직접 사용한다. [अभिवादन_ae353e94.c](उदाहरणे/हांगुल_संकेतन/अभिवादन_ae353e94.c), [अभिवादन_ae353e94.cpp](उदाहरणे/हांगुल_संकेतन/अभिवादन_ae353e94.cpp)पहिले_संकार्य वास्तविक_डेटा EL0 आज्ञा_कार्यवाही_करा चाचण्या 대상이다.

```c
#include "संचिका_द्विमानजोडणी.h"
#ifdef __cplusplus
extern "C"
#endif
int प्रारंभ_प्रयोक्ता_अनुप्रयोग(int बाबी) {
    (void)बाबी;
    const char अभिवादन[] = "안녕하세요\n";
    int मार्गदर्शिका = संचिका_उघडा("अभिवादन_ae353e94.txt", वाचणे_लिहिणे | जर_अनुपस्थित_तयार_करा | छाटूनरिकामेकरा_सामुग्री, 0600);
    if (मार्गदर्शिका < 0) return 1;
    आदानप्रदान_मोजमाप_टाइप_करा नोंदवलेले_संख्या = संचिका_डेटा_लिहा(मार्गदर्शिका, अभिवादन, sizeof(अभिवादन) - 1);
    संचिका_मिटवा(मार्गदर्शिका);
    संचिका_डेटा_लिहा(1, अभिवादन, sizeof(अभिवादन) - 1); /* सध्याचे_आयटम टर्मिनल stdout */
    return नोंदवलेले_संख्या == sizeof(अभिवादन) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 संख्या 있다. C는 게스트 `cc` 또는 होस्ट SDK, C++는 होस्ट SDK의 Clang++로 컴파일한다. तळ_मूल्य 예제는 기존 होस्ट SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh
# 호스트에서 SDK तयार_करा·बाहेर_काढा
make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/अभिवादन_ae353e94.c -o अभिवादन_ae353e94-c.elf
python3 compile.py examples/अभिवादन_ae353e94.cpp -o अभिवादन_ae353e94-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 वास्तविक_डेटा आज्ञा_कार्यवाही_करा
cd /home/user/jkoros/platforms/rpi4-native
python3 साधने/संचिका_कार्यवाही_करा.py build/sdk-work/jkoros-native-sdk/अभिवादन_ae353e94-c.elf
python3 साधने/संचिका_कार्यवाही_करा.py build/sdk-work/jkoros-native-sdk/अभिवादन_ae353e94-cpp.elf
```

सध्याचे_आयटम GUI VM에서 실행하려면 `python3 साधने/अपलोड_करा_संचिका.py मार्ग/अभिवादन_ae353e94-c.elf`의 출력을 게스트에 보내고 `run अभिवादन_ae353e94-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex संचिका_नाव_मजकूर`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 संख्या 있다. 호스트와 게스트의 फाइल 시스템은 별개다.

| मराठी नाव | C चिन्ह | क्लिप |
|---|---|---|
| संचिका_उघडा/संचिका_मिटवा | pk_open/pk_close | RAM फाइल, समकक्ष_मूल्य/절대 मार्ग |
| संचिका_डेटा_वाचा/संचिका_डेटा_लिहा | pk_read/pk_write | फाइल, fd 0/1/2 표준 इनपुट_आउटपुट, 연결형 संचारद्वार_मूल्य |
| शोधा_संचिका | pk_lseek | पासून_आरंभ/सध्याचे_मूळ/शेवट_करा_उगम |
| संचिका_आकारा/संचिका_लांबी_संच | pk_size/pk_ftruncate | लांबी_मूल्य क्वेरी_मूल्य/बदल_करा_मूल्य |
| संचिका_प्रविष्टी_नाव_काढणे | pk_unlink | फाइल नाव 삭제 |
| स्थिरकरा_फाईल_संग्रहण | pk_fsync | RAM이므로 -1, त्रुटी_संख्या=ENOSYS |
| संचारटोक_तयार_करा/बाइंड_करा_पत्ता | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |
| स्वतंत्रसंदेश_डेटा_पाठवा/स्वतंत्रसंदेश_डेटा_स्वीकारा | pk_sendto/pk_recvfrom | UDP 루프백 |
| कनेक्ट_संचारजाळे | pk_connect | 연결형 루프백 |
| प्रतीक्षा_करा_साठी_नेटवर्क_कनेक्शन | pk_listen | प्रतीक्षा_करा_मूल्य जोडा कमाल_मूल्य 4개 |
| स्वीकारा_नेटवर्क_कनेक्शन | pk_accept | सध्याचे_आयटम पत्ता 인수는 NULL/NULL만 समर्थन_मूल्य |
| संचारद्वार_पत्ता_वाचा | pk_getsockname | 로컬 पत्ता/पॉर्ट_मूल्य |

`संचारजाळे_द्विमानजोडणी.h`의 स्वकीय `pk_sockaddr_in`을 사용하며 पॉर्ट_मूल्य·주소는 `संचारजाळे_लघु`/`संचारजाळे_पूर्णांक`로 변환한다. C संचारद्वार_मूल्य 호출은 비차단이며 डेटा/연결이 없으면 -1과 `त्रुटी_संख्या=11`(EAGAIN)을 반환한다. 양수 इनपुट_आउटपुट 결과가 요청보다 작을 संख्या 있으므로 पुनरावृत्ती_मूल्य 처리한다. बिघाड_मूल्य 후에만 오류번호를 확인한다.

[प्रवाह_मूल्य.c](उदाहरणे/हांगुल_संकेतन/प्रवाह_मूल्य.c)는 C에서 मराठी 이름으로 जोडा·accept·उपभाग_मूल्य वाचन/लेखन·큐 포화·EOF를 처리하는 आज्ञा_कार्यवाही_करा 예제다. SDK의 `examples/प्रवाह_मूल्य.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. आवाहन 흐름은 C/C++ → वास्तविक_डेटा मराठी C फलन_मूल्य 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·निर्देशक पडताळण्या → Java RAM फाइल/루프백 또는 बाह्य_मूल्य lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 गाभा_मूल्य 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 जोडा, 표준 C printf, libstdc++/STL, अपवाद·RTTI는 제공하지 않으며 C++의 स्थिर_मूल्य 생성자·स्थानिक_संधी ऑब्जेक्ट_मूल्य 소멸자는 지원한다. 상세 अनुक्रमणिका·स्मृती_डेटा 범위는 [प्रयोक्ता_कॉल_द्विमानजोडणी.md](प्रयोक्ता_कॉल_द्विमानजोडणी.md)를 참고한다.

अंमलबजावणी 시 참고한 표준 API: [Socket](https://docs.oracle.com/javase/8/docs/api/java/net/Socket.html), [JFrame](https://docs.oracle.com/javase/8/docs/api/javax/swing/JFrame.html), [JButton](https://docs.oracle.com/javase/8/docs/api/javax/swing/JButton.html). 이 문서의 अंमलबजावणी 범위가 वरचे_मूल्य 표준 전체를 지원한다는 뜻은 아니다.

## मराठी 이름으로 직접 작성하는 창과 कार्यसूत्र_मूल्य_5b72a632

`example/java/खिडकीउदाहरण.java`는 `चालवण्यायोग्य_कार्य.कार्यान्वित_करा`,
`क्रिया_ग्राहक.क्रिया_स्वीकारा(क्रिया_सूचना)`, `बटण`, `इव्हेंट_रांग.नंतर_आवाहन`, `सुरू_करा()`을 쓴다.
स्वकीय JVM에 이 이름들의 ऑब्जेक्ट_मूल्य·पद्धत_मूल्य·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `कार्यसूत्र`도 स्वकीय 스케줄러와 직접 연결된다.
세부 메서드와 기존 मराठी API에서의 변경은 [मराठी API मार्गदर्शिका](स्वकीय_जावा/वापरमार्गदर्शिका_eb81d7d9.md)를 본다.

होस्ट javac는 वितरण_मूल्य JAR를 वर्ग_मूल्य 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/खिडकीउदाहरण.java
python3 साधने/आज्ञा_कार्यवाही_करा.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java खिडकीउदाहरण
```

직접 पडदा/कार्यसूत्र_मूल्य_5b72a632 API와 `सुरू_करा()` 진입점은 स्वकीय JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 पुढेचालूकरा_प्रक्रियाकरण 실행할 संख्या 있다.
