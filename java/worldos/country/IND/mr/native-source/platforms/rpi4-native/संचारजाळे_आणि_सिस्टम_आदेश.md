# स्वकीय 커널의 네트워크와 ऑपरेटिंग_सिस्टम_मूल्य आदेश

게스트 SSH·VNC, LAN 공개 आज्ञा_कार्यवाही_करा, Pi4 GENET·DHCP 추가분은 [बाह्य_मूल्य कनेक्शन_e05f319b वापरमार्गदर्शिका_eb81d7d9](बाह्य_कनेक्शन_मार्गदर्शी.md)를 먼저 참고한다. QEMU는 `sl0`, भौतिक_हार्डवेअर GENET은 `en0`를 사용한다. भौतिक_हार्डवेअर 드라이버는 아직 보드에서 검증하지 않았다.

이 문서는 `platforms/rpi4-native`의 स्वकीय ARM64 Java 커널용이다. Linux/OpenJDK 실행환경의 명령어와 구분한다. 새 커널을 빌드하고 पुनःप्रयत्न_मूल्य 부팅해야 적용된다.

셸과 Java의 वास्तविक_डेटा CPU परवानगी_मूल्य, `ps`/`top`에 표시되는 एकक_मूल्य, होस्ट·बाह्य_मूल्य PC जोडा 방법은
[आज्ञा_कार्यवाही_करा 계층과 बाह्य_मूल्य संचार तपासा_राज्य](सामान्य_भाषा_रनटाइम_आणि_बाह्य_संचारजाळे_पडताळण्या.md)에 정리했다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop ARGS=--network RESOLUTION=1920x1080
# अनुक्रमिक_मूल्य 셸만 사용할 때
make run ARGS=--network
```

게스트에서 `help`, `help system` 또는 `मदत_शो system`을 입력한다. तळ_मूल्य 두 이름은 같은 동작을 하며 현지어 이름도 Tab으로 완성할 संख्या 있다.

## IP 설정과 संचार पडताळा

```sh
ipconfig
ip addr show
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2
아이피설정 set 10.0.2.20 255.255.255.0 10.0.2.2
ping -c 4 -W 1 10.0.2.2
प्रतिसाद_चाचणी -c 4 10.0.2.2
ip route show
ip link set dev sl0 down
ip link set dev sl0 up
netstat
```

초깃값은 `sl0`, `10.0.2.15/24`, गेटवे_मूल्य `10.0.2.2`तिसरे_संकार्य. पत्ता 설정은 재부팅 전까지 유지된다. TCP/UDP 끝점이 열려 있으면 `error -16`으로 변경을 거부한다. 먼저 `ftpd stop` 등으로 서비스를 닫고 프로그램의 소켓을 닫는다. 잘못된 पत्ता·비연속 넷마스크·다른 망의 관문은 적용하지 않는다.

`ip`는 वरचे_मूल्य 구문의 부분집합이며 Linux iproute2 전체 문법을 구현하지 않는다. `ping`은 IPv4 अंक_मूल्य पत्ता, `-c 1..100`, `-W 1..10`초를 지원한다. नाव मूल्य_पार्स_करा·IPv6는 미지원이며 GENET의 DHCP는 बाह्य_मूल्य कनेक्शन_e05f319b 구현에 추가했다. 응답이 없으면 निर्गमन_करा_संहिता 1, 잘못된 인수는 2, प्रयोक्ता 취소는 130이다. `ping ...; echo $?`로 확인한다.

QEMU बाह्य_मूल्य 통신은 UART SLIP→NAT 연결을 사용한다. `--network` 없이도 स्वकीय पत्ता क्वेरी_मूल्य·설정은 가능하지만 बाह्य_मूल्य 응답은 오지 않는다. डिफॉल्ट_मूल्य NAT는 `10.0.2.0/24`तिसरे_संकार्य. भौतिक_हार्डवेअर Pi의 GENET 드라이버는 별도로 추가했으며 बोर्ड 검증이 필요하다. Wi-Fi는 미지원이다.

주소를 `.20`으로 바꾼 मागे_मूल्य FTP 등 **외부에서 들어오는 जोडा**पर्यंत 사용할 때는 आज्ञा_कार्यवाही_करा 시 फॉरवर्ड_मूल्य 대상도 지정한다.

```sh
make desktop ARGS="--network --guest-ip 10.0.2.20"
# 부팅한 게스트 안에서
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2
ftpd start
```

`--guest-ip`는 NAT फॉरवर्ड_मूल्य 대상이며 게스트의 주소를 자동 설정하지 않는다. FTP नियंत्रण_मूल्य 포트는 होस्ट `127.0.0.1:2121`, 수동 데이터 포트는 50000~50007이다. 여러 VM을 함께 띄울 때는 `--network-host 127.0.0.2 --port 5903`처럼 होस्ट 루프백 주소와 VNC 포트를 구분한다. FTP와 Java/C 소켓은 변경된 वास्तविक_डेटा 게스트 IP를 사용한다.

## राज्य_मूल्य 조회의 의미

`ps`는 गाभा_मूल्य/शेल, 살아 있는 협력 पारपाडा_कार्य, कमाल_मूल्य 4개의 EL0 प्रयोक्ता 세션을 표시한다. 다른 터미널에 열린 `vi` 등을 `SUSPENDED` 상태로 볼 संख्या 있다. `MAPPED_KiB`는 वास्तविक_डेटा 페이지 प्रतिचित्रित_मूल्य, `RUN_ms`는 해당 세션이 선택된 동안의 경과 वेळ_मूल्य(시스템 आवाहन घोषणाशीर्षे)이며 정밀 CPU 사용률이 아니다. `top -n 1`은 한 번, `top -n 2`는 두 번 표시한다. 리다이렉션된 `top`의 기본값은 한 번이다.

`free`의 AOT गतिमानस्मृतिराशी_मूल्य 사용량은 할당기에서 읽는다. 힙은 गाभा_मूल्य BSS에 포함되므로 각 줄을 सर्व_बांधणी 더하면 중복된다. 고정 예약 영역과 प्रयोक्ता 페이지 매핑을 표시하며 Linux의 가용 RAM 계산이나 होस्ट स्मृती_डेटा 통계를 꾸며서 표시하지 않는다.

`df`는 RAM 파일시스템의 फाइल 64칸 × 16 KiB를 표시한다. फाइल 하나는 논리 크기와 별도로 16 KiB 칸을 예약한다. `Data`는 वास्तविक_डेटा डेटा लांबी_मूल्य एकूण_मूल्य, `Reserved`는 वापर_मूल्य 중인 खाच_प्रविष्टी 용량이다. 삭제 후에도 열린 파일은 शेवटचे_आयटम 참조를 닫을 때까지 계산한다. SD/영구 디스크 사용량은 아직 지원하지 않는다.

## 종료와 प्रमाणित

게스트에서 `poweroff` 또는 `पॉवर_बंद`를 입력한다. FTP·संचारद्वार_मूल्य·प्रयोक्ता 세션을 닫은 मागे_मूल्य BCM PM निर्गमन_करा_अनुप्रयोग 절차를 실행한다. RAM 파일은 재부팅 नंतर_राज्य 보존되지 않는다. QEMU에서는 게스트의 `SHUTDOWN / guest-shutdown` 이벤트와 आहे_सामान्य 종료를 검증한다. भौतिक_हार्डवेअर Pi 4 전원 회로 동작은 아직 시험하지 않았다.

अंमलबजावणी 근거: [Linux BCM watchdog의 power-off 절차](https://github.com/torvalds/linux/blob/master/drivers/watchdog/bcm2835_wdt.c), [QEMU BCM PM मोबाइल_मूल्य](https://github.com/qemu/qemu/blob/master/hw/misc/bcm2835_powermgt.c).

```sh
make test-system
# मोजमाप: build/verification/system-tools/report.json 및 serial.log
```

이 시험은 잘못된 IP अस्वीकृत_करा_मूल्य, वास्तविक_डेटा ICMP यश_मूल्य·시간초과, जोडा up/down, IP बदल_करा_मूल्य नंतर_राज्य FTP 송수신, df तयार_करा·삭제, गतिमानस्मृतिराशी_मूल्य गणना, 다른 터미널의 vi PID·स्मृती_डेटा, top ताजे_करा·निर्गमन_करा_अनुप्रयोग, हांगुल_मजकूर आदेश·Tab, 게스트 poweroff를 검사한다.

`java/worldos/देश_मूल्य/국가코드` 판에는 같은 기능과 국가별 आदेश 대응표 `native-commands.json`이 들어간다. 표준 명령은 모든 판에서 유지한다. 새 현지어 이름은 기능 중심 제안이며 현지 화자·어원 검토를 완료한 표준 용어는 아니다. 미번역 항목은 대응표의 `pending`에 명시한다.
