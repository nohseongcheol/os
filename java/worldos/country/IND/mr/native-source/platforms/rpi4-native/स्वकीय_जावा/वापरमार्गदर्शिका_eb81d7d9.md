# मराठी Java संचार·इनपुट_आउटपुट·अपवाद API

패키지는 `मराठी.स्वकीय`तिसरे_संकार्य. होस्ट `javac --release 8`로 컴파일한 class를
स्वकीय ARM64 커널의 JVM에서 실행한다. संचार·फाइल·अपवाद API는 OpenJDK와 대조한다. 아래의 직접 구현한 पडदा·पारपाडा_कार्य कार्यसूत्र_मूल्य_5b72a632 API는 स्वकीय JVM 전용이다.
기존 표준 Java लायब्ररी 전체의 मराठी 번역판은 아니다.

```java
import मराठी.स्वकीय.*;

public class संचारजाळे {
    public static void main(String[] बाबी) throws इनपुट_आउटपुट_अपवाद {
        कनेक्शन जोडा = कनेक्शन.उघडा("10.0.2.2", 9000);
        try {
            जोडा.प्रतीक्षामर्यादा(700);
            जोडा.आउटपुट().लेखन(वर्ण.संकेतन("안녕하세요\n"));
            आदान_प्रवाह आदान_मूल्य = जोडा.आदान_मूल्य();
            आउटपुट.संख्या_लिहा(आदान_मूल्य.वाचन());
        } catch (प्रतीक्षा_करा_प्रतीक्षामर्यादा_अपवाद त्रुटी) {
            आउटपुट.ओळ_लिहा(त्रुटी.वर्णन());
        } finally {
            जोडा.बंद_करा();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
प्रयोक्ता 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 स्ट्रींग_मूल्य 리터럴에 사용하는 표준 클래스다. स्वकीय 실행기는 `public static void सुरू_करा()`도 진입점으로 받는다.

## 통신과 प्रवाह_मूल्य

| वर्ग_मूल्य | मराठी आवाहन |
|---|---|
| कनेक्शन | `उघडा(पत्ता, पोर्ट_नंबर)`, `आदान_मूल्य()`, `आउटपुट()`, `प्रतीक्षामर्यादा(मिलिसेकंद)`, `पोर्ट_नंबर()`, `स्थानिक_पोर्ट_नंबर()`, `जोडलेले()`, `आहे_बंदकेलेले()`, `बंद_करा()` |
| पॉर्ट_स्वीकारा | `उघडा(पोर्ट_नंबर)`, `स्वीकारा()`, `पोर्ट_नंबर()`, `प्रतीक्षामर्यादा(मिलिसेकंद)`, `आहे_बंदकेलेले()`, `बंद_करा()` |
| आदान_प्रवाह | `वाचन()`, `वाचन(byte[])`, `वाचन(byte[], सुरू_करा, लांबी_मूल्य)`, `बंद_करा()` |
| प्रदान_प्रवाह | `लेखन(int)`, `लेखन(byte[])`, `लेखन(byte[], सुरू_करा, लांबी_मूल्य)`, `निर्गमितकरा_मूल्य()`, `बंद_करा()` |
| स्वतंत्रसंदेश_चॅनल | `उघडा(पोर्ट_नंबर)`, `पाठवा(पत्ता, पोर्ट_नंबर, पाठ्य)`, `स्वीकारा()`, `प्रतीक्षामर्यादा(मिलिसेकंद)`, `पोर्ट_नंबर()`, `आहे_बंदकेलेले()`, `बंद_करा()` |
| कनेक्शन_वाहतूक | `उघडा(...)`, `ग्राहक_उघडा(...)`는 वरचे_मूल्य मराठी 객체를 परतकरा_मोजमाप |
| पडताळण्या | `आवश्यकतापडताळा(सशर्त, कारण_मूल्य_bfc35dae)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`वाचन()`의 फाइल 끝은 -1, ऍरे_मूल्य 읽기의 반환값은 वास्तविक_डेटा 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. पोर्ट_नंबर 0은 빈 번호를 자동 배정한다.
UDP 전문은 सध्याचे_आयटम स्वकीय 커널에서 512바이트까지 받으며, 주소는 अंक_मूल्य IPv4를 사용한다.
`localhost` 루프백 외의 नाव 풀이(DNS)는 स्वकीय 커널에 아직 없다.

기존 `कनेक्शन_वाहतूक.जोडा/ऐका_संचारटोक/स्वीकारा`, `संचार.उघडा/पाठवा/स्वीकारा`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `कनेक्शन`, `पॉर्ट_स्वीकारा`, `स्वतंत्रसंदेश_चॅनल`를 쓴다.

## मराठी अपवाद

모든 तळ_मूल्य 클래스는 डिफॉल्ट_मूल्य 생성자, `새예외("वर्णन")` 형태의 स्ट्रींग_मूल्य 생성자와
`वर्णन()`을 제공한다. वास्तविक_डेटा तयार_करा 문법은 `new प्रतीक्षा_करा_प्रतीक्षामर्यादा_अपवाद("प्रतीक्षा_करा_राज्य शेवट")`이다.

| मराठी अपवाद | 상위 वर्ग_मूल्य / 용도 |
|---|---|
| अपवाद | `java.lang.Exception`, 직접 던지는 일반 पडताळण्या अपवाद |
| निष्पादन_अपवाद | `java.lang.RuntimeException` |
| इनपुट_आउटपुट_अपवाद | `java.io.IOException`, मराठी फाइल·संचार API의 पडताळण्या अपवाद |
| प्रतीक्षा_करा_प्रतीक्षामर्यादा_अपवाद | `इनपुट_आउटपुट_अपवाद`, संचार प्रतीक्षामर्यादा 초과 |
| पत्ता_लुकअप_अपवाद | `इनपुट_आउटपुट_अपवाद`, पत्ता पडताळा बिघाड_मूल्य |
| अनुपस्थित_संचिका_अपवाद | `इनपुट_आउटपुट_अपवाद`, फाइल उघडा बिघाड_मूल्य |
| संचार_अपवाद | `इनपुट_आउटपुट_अपवाद`, 표준 SocketException रूपांतरकरा_मूल्य |
| अवैध_वितर्क_अपवाद | `java.lang.IllegalArgumentException` |
| संख्या_स्वरूप_बिघाड | `अवैध_वितर्क_अपवाद` |
| सीमा_अपवाद | `java.lang.IndexOutOfBoundsException` |
| ऍरे_सीमा_अपवाद / स्ट्रींग_सीमा_अपवाद | `सीमा_अपवाद` |
| नल_संदर्भ_अपवाद | `java.lang.NullPointerException` |
| अंकगणिती_बिघाड | `java.lang.ArithmeticException` |
| राज्य_अपवाद | `java.lang.IllegalStateException` |
| टाइप_करा_कास्ट_अपवाद | `java.lang.ClassCastException` |
| ऋण_ऍरे_आकारा_बिघाड | `java.lang.NegativeArraySizeException` |
| ऍरे_साठवणे_बिघाड | `java.lang.ArrayStoreException` |
| कार्यसूत्र_राज्य_अपवाद | `java.lang.IllegalThreadStateException` |
| प्रतीक्षा_करा_खंडित_अपवाद | `java.lang.InterruptedException`, `पारपाडा_कार्य.प्रतीक्षाकरा`의 प्रतीक्षा_करा_मूल्य 중단 |

`अपवाद`와 `निष्पादन_अपवाद`는 모든 मराठी 예외의 सामायिक_मूल्य 부모가 아니다. वरचे_मूल्य 상속 관계를
사용하며, फाइल·संचार 전체를 잡으려면 `catch (इनपुट_आउटपुट_अपवाद त्रुटी)`를 쓴다.
मराठी API가 표준 इनपुट_आउटपुट 오류를 मराठी 예외로 변환한다.
기존 मराठी संचार 호출에서 `SocketTimeoutException`을 잡던 코드는
`प्रतीक्षा_करा_प्रतीक्षामर्यादा_अपवाद`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
अपवाद 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
सध्याचे_आयटम स्वकीय JVM에 이 20종을 추가했다. 임의의 प्रयोक्ता Throwable 하위 वर्ग_मूल्य 전체를
지원하도록 확장했다는 뜻은 아니다.

## स्रोत_बांधणी·आज्ञा_कार्यवाही_करा

```sh
cd /home/user/jkoros/platforms/rpi4-native
make सिस्टम_बांधणी
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 चाचण्या/जावा/कोरियन_संचारजाळे_चाचणी.java
python3 साधने/संचिका_कार्यवाही_करा.py build/한국어사용/कोरियन_संचारजाळे_चाचणी.class
make test-jvm
```

내장 라이브러리는 प्रयोक्ता JVM ELF 안에 탑재된다. `.jar`는 होस्ट javac의
वर्ग_मूल्य 경로로 사용한다. स्रोत_ट्री 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 मराठी 예외의 `throws` 선언과 그 import를 인식한다.
स्वकीय JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·ऑब्जेक्ट_मूल्य·संचारद्वार_मूल्य उदाहरणे 전체의 स्रोत_ट्री 컴파일은 होस्ट javac를 사용한다.
`/example/java/संचिका_उदाहरण.java`는 게스트 javac로도 컴파일할 संख्या 있다.

वास्तविक_डेटा TCP/UDP 예제는 [जाळेउदाहरण.java](../../../example/java/जाळेउदाहरण.java),
आज्ञा_कार्यवाही_करा 절차는 [example वापरमार्गदर्शिका_eb81d7d9](../../../example/README.md),
स्रोत_ट्री नामकरण 원칙은 [नामकरण वापरमार्गदर्शिका_eb81d7d9](../नामकरण/वापरमार्गदर्शिका_eb81d7d9.md)에 있다.

## Swing विंडो उदाहरणे

`/example/java/खिडकीउदाहरण.java`와 컴파일된 `.class`पहिले_संकार्य प्रणालीप्रारंभ 시 준비된다.
`cd /example/java` पुढील_आयटम `java खिडकीउदाहरण`로 연다. नाव आदान_मूल्य, अभिवादनकरा 버튼,
인사말과 क्लिक_करा_मूल्य पुनरावृत्ती_संख्या ताजे_करा, X 닫기를 지원한다.

| 기능 | मराठी 직접 API |
|---|---|
| Runnable / run | `चालवण्यायोग्य_कार्य.कार्यान्वित_करा()` |
| ActionListener / actionPerformed | `क्रिया_ग्राहक.क्रिया_स्वीकारा(क्रिया_सूचना सूचना)` |
| ActionEvent | `क्रिया_सूचना.आज्ञा_मजकूर()`, `इव्हेंट_स्रोत()`, `अनुक्रमणिका()` |
| JFrame | `विंडो(विंडो_शीर्षक, रुंदी_विस्तार, उंची_मूल्य)`, `जोडा_घटक(पडदा_घटक)`, `विंडो_शो()`, `बंद_करा()`, `आहे_दृश्य()` |
| JButton | `बटण(पाठ्य, आडवे_स्थान, अनुलंब_स्थान, रुंदी_विस्तार, उंची_मूल्य, ग्राहक_मूल्य)`, `क्रिया_ग्राहक_संच(ग्राहक_मूल्य)` |
| JLabel / JTextField | `लेबल(...)`, `मजकूर_फील्_ड(...)` |
| सामायिक_मूल्य पडदा घटक_मूल्य | `पडदा_घटक.मजकूर_वाचा()`, `मजकूर_लिहा(पाठ्य)`, `सीमा_संच(आडवे_स्थान, अनुलंब_स्थान, रुंदी_विस्तार, उंची_मूल्य)` |
| SwingUtilities.invokeLater | `इव्हेंट_रांग.नंतर_आवाहन(चालवण्यायोग्य_कार्य)`, `आहे_इव्हेंट_वितरण()` |
| Thread | `कार्यसूत्र(चालवण्यायोग्य_कार्य)`, `प्रारंभ_कार्य()`, `प्रतीक्षाकरा()`, `आहे_कार्यरत()`, `निलंबित_करा_कार्य()` |
| 명령행 | `सुरू_करा()`, `वितर्क.आयटम_संख्या()`, `वितर्क.पाठ्य(क्रमांक_अनुक्रमणिका)` |

वरचे_मूल्य 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
स्वकीय JVM의 `कोरियन_पडदा_आवाहन`, `प्रक्रिया_कार्यसूत्र`पहिले_संकार्य मराठी वर्ग_मूल्य·पद्धत_मूल्य·서술자를
해석해 पडदा 요소와 आज्ञा_कार्यवाही_करा 가닥을 직접 만든다. कृती 알림도 स्वकीय 객체이며
콜백으로 `कार्यान्वित_करा`와 `क्रिया_स्वीकारा`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 आज्ञा_कार्यवाही_करा 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 स्वकीय JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 होस्ट JVM에서 무동작 객체가 생기지 않도록 하는 अस्वीकृत_करा_मूल्य 경로다.
स्वकीय JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 अंमलबजावणी API를
실행할 संख्या 없다. होस्ट javac로 컴파일한 मागे_मूल्य स्वकीय JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, पडदा 큐 기능은 `SwingUtilities`에 해당한다.

```java
import मराठी.स्वकीय.*;
public class 가닥예제 implements चालवण्यायोग्य_कार्य {
    public void कार्यान्वित_करा() { आउटपुट.ओळ_लिहा("मराठी पारपाडा_कार्य आज्ञा_कार्यवाही_करा"); }
    public static void सुरू_करा() throws प्रतीक्षा_करा_खंडित_अपवाद {
        कार्यसूत्र कार्यसूत्र_मूल्य_5b72a632 = पारपाडा_कार्य.सुरू_करा(new 가닥예제());
        पारपाडा_कार्य.प्रतीक्षाकरा(कार्यसूत्र_मूल्य_5b72a632);
    }
}
```

`example/java`의 다섯 소스는 राखीव_शब्द·리터럴 외 식별자를 한국어로 작성한다.
ऍरे_मूल्य बाबी 대신 `वितर्क`, 길이는 `वर्ण.बाइट_संख्या`를 사용한다.
표준 Java의 `main(String[])`도 पुढेचालूकरा_प्रक्रियाकरण 지원한다. दोन_मूल्य तिसरे_संकार्य 정의되어 있으면
स्वकीय 실행기는 बाबी 없는 `सुरू_करा()`을 우선한다.
기존 मराठी पडदा 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`पारपाडा_कार्य.सुरू_करा(Runnable)`을 사용하던 코드는 새 मराठी 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API समर्थन_मूल्य 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 वर्ग_मूल्य·पद्धत_मूल्य 이름과 서술자가 남는다.
मराठी नाव 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 उपभाग_मूल्य,
