# वितरण_मूल्य चित्र_बांधणी प्रमाणित लॉग_नोंद

검증일: 2026-09-27 (Asia/Seoul)

लक्ष्य: `jkoros-rpi4-aarch64-349b52891a471c8e782da597`

이번 배포는 Raspberry Pi 4용 **ARM64 Linux 실행판**이다. 기존 स्वकीय x86 커널을 ARM으로 이식한 결과가 아니다. वास्तविक_डेटा Pi 보드는 연결되어 있지 않아 हार्डवेअर_मूल्य प्रणालीप्रारंभ 성공을 확인하지 못했다.

## अंमलबजावणी 범위와 남은 प्रमाणित

### QEMU 그래픽 आज्ञा_कार्यवाही_करा 보완

टर्मिनल 전용 실행에서 `अभिवादन_ae353e94.java`पहिले_संकार्य Swing 창을 만들 때 발생한 `HeadlessException`을 해결하기 위해 `make run`과 `make run-console`을 추가했다. 그래픽 실행은 bochs 가상 GPU, USB 키보드·태블릿, Xorg, 로컬 VNC를 사용한다. QEMU 전용 initramfs가 필요한 드라이버를 기존 루트 파일시스템에서 로딩한다. वितरण_मूल्य 시스템 이미지와 base-id는 변경하지 않아 기존 प्रयोक्ता डेटा 이미지를 पुढेचालूकरा_प्रक्रियाकरण 사용할 संख्या 있다.

वास्तविक_डेटा Xorg/VNC 화면에서 मराठी Java वर्कस्पेस, Swing चाचण्या विंडो, 기존 이미지의 `अभिवादन_ae353e94.java` 창을 표시했다. VNC를 통한 USB 마우스 클릭과 키보드 입력이 Swing 이벤트로 전달되는 것도 확인했다. निर्गमन_करा_अनुप्रयोग 시 시스템 OverlayFS와 डेटा 파일시스템의 वाचन 전용 전환을 확인했다. 이번 시험은 Xvfb를 사용하지 않는다.

स्रोत 예제에는 `GraphicsEnvironment.isHeadless()` 분기를 추가했다. 화면이 없는 환경에서는 फाइल·वर्ण·스레드 기능을 실행하고 안내를 출력한다. प्रयोक्ता 홈의 기존 원문을 자동 교체하지는 않는다. 향후 चित्र_बांधणी 빌드에는 udev의 `add` 이벤트를 명시적으로 발생시키는 수정도 반영된다.

### हांगुल_मजकूर आदान_मूल्य·फॉन्ट_मूल्य 보완

`make test-korean`으로 वास्तविक_डेटा Xorg/VNC 화면의 Swing 입력창과 xterm에서 Ctrl+Space स्विच_मोड 및 두벌식 कळ_मूल्य 입력을 시험했다. 양쪽에서 `हांगुल_मजकूर आदान_मूल्य`을 조합했고 UTF-8 파일의 내용과 일치했다. 시험은 별도 प्रयोक्ता डेटा 이미지에서 실행했으며 आहे_सामान्य निर्गमन_करा_अनुप्रयोग 시 두 파일시스템의 वाचन 전용 전환을 확인했다.

टर्मिनल फॉन्ट_मूल्य 진단에서 영문 DejaVu Sans Mono와 हांगुल_मजकूर Noto Sans Mono CJK KR의 वास्तविक_डेटा फाइल 로딩을 확인했다. 한글용으로 요청한 글꼴이 영문 전용 글꼴로 대체되던 Fontconfig 규칙의 우선순위도 수정했다. पडदा 캡처에서 हांगुल_मजकूर·영문 मूल्य_शो, Java 작업마당의 확대된 글꼴과 안티앨리어싱을 확인했다.

수정은 QEMU 전용 initramfs를 통해 प्रयोक्ता 시스템 변경분에 적용하며 वितरण_मूल्य डिफॉल्ट_मूल्य 이미지와 base-id는 유지한다. 기존 फाइल 백업, 동일 수정의 पुनरावृत्ती_मूल्य 적용 방지, 손상된 सुधारा_मूल्य फाइल 및 다른 base-id अस्वीकृत_करा_मूल्य, प्रयोक्ता 입력기 संयोजना 병합에 대한 होस्ट चाचण्या 4개도 통과했다. 원래 प्रयोक्ता डेटा चित्र_बांधणी `build/manual-user.img`는 시험에 사용하지 않았다.

### 남은 क्लिप

- 새 स्रोत_बांधणी लक्ष्य `openjdk`는 **네이티브 अनुप्रयोग_चालक + JVM/JRE** 방식이다. 모든 Java 바이트코드를 JVM 없이 기계어로 변환하는 범용 AOT 컴파일러는 구현하지 않았다. 기존 x86 AOT의 समर्थन_मूल्य 범위는 여전히 제한적이다.
- आज्ञा_कार्यवाही_करा 프로그램에는 main प्रविष्टी_गुण, 호환 वर्ग_मूल्य 버전과 의존 JAR/JNI가 필요하다. 개별 상용 अनुप्रयोग_f5044b9b, 모든 Java मॉड्यूल_मूल्य, 모든 문자권을 시험한 것은 아니다.
- मराठी Java 라이브러리는 फाइल·वर्ण·संचार·스레드·Swing을 위한 सहायक_मूल्य API이며 JDK 전체 API의 मराठी 번역판은 아니다.
- Pi 4 전용 펌웨어·गाभा_मूल्य·मोबाइल_मूल्य 트리는 이미지에 들어 있지만 वास्तविक_डेटा SD प्रणालीप्रारंभ, HDMI/KMS, USB, Wi-Fi, 물리 키보드의 हांगुल_मजकूर 입력은 실기 확인이 남아 있다. QEMU는 Pi 장치를 에뮬레이션하는 시험이 아니다.
- प्रयोक्ता निर्देशिका_मूल्य 이동은 동일 시스템 चित्र_बांधणी आयडेंटिफायर_मूल्य, ARM64, `/home/user`, UID 1000을 전제로 한다. निर्गमन_करा_अनुप्रयोग नंतर_राज्य 소유권·परवानगी_मूल्य·링크·एक्सटेंशन_मूल्य गुणधर्म_मूल्य·삭제 정보를 보존하여 복사해야 한다. 다른 OS 버전으로의 자동 이관은 제공하지 않는다.

स्थापित_करा_मूल्य·इन्स्टन्स_मूल्य 절차는 [README.md](README.md), स्रोत_बांधणी 방식은 [OpenJDK आज्ञा_कार्यवाही_करा फाइल वापरमार्गदर्शिका_eb81d7d9](../../compiler/OpenJDK-निष्पादनीय_संचिका.md)를 따른다. चित्र_बांधणी 파일만 생성했으며 वास्तविक_डेटा SD 카드나 USB 디스크에 기록하지 않았다.
