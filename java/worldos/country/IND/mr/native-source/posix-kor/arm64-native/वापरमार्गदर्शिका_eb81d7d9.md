# स्वकीय ARM64 Java 커널의 C/C++ फाइल·루프백 जोडा

이 디렉터리는 `platforms/rpi4-native` स्वकीय गाभा_मूल्य 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`घोषणाशीर्षे/संचिका_द्विमानजोडणी.h`는 मराठी 함수명과 `extern "C"` ABI를 제공한다. `जोडा.c`는 गाभा_मूल्य 안에서 AOT Java फाइल 메서드에 직접 연결하고, `प्रयोक्ता_ब्रिज.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. वास्तविक_डेटा फाइल 처리는 `स्मृती_संचिका.java`, 루프백 स्वतंत्रसंदेश 처리는 `स्वपरतावा_संचारजाळे.java`, 연결형 흐름은 `प्रवाह_संचारजाळे.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 गाभा_मूल्य 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`तिसरे_संकार्य. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·तरंगता_गुण_मूल्य क्रिया_मूल्य·फाइल·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

समर्थन_मूल्य: `संचिका_उघडा`, `संचिका_डेटा_वाचा`, `संचिका_डेटा_लिहा`, `संचिका_मिटवा`, `शोधा_संचिका`, `संचिका_प्रविष्टी_नाव_काढणे`, `संचिका_लांबी_संच`, सहायक_मूल्य फलन_मूल्य `संचिका_आकारा`. त्रुटी 시 -1과 작업별 `त्रुटी_संख्या`를 반환한다. `स्थिरकरा_फाईल_संग्रहण`은 RAM 파일이므로 ENOSYS를 반환한다. फाइल 16개, 각 16384바이트, नाव 63바이트, विवरणक_प्रविष्टी 16개이며 RAM 디렉터리·समकक्ष_मूल्य/절대 경로를 제공한다. परवानगी_मूल्य/영속 저장은 없다.

사용자용 `घोषणाशीर्षे/संचारजाळे_द्विमानजोडणी.h`는 वास्तविक_डेटा मराठी 함수와 독립 구조체를 선언한다.
`संचारटोक_तयार_करा`, `बाइंड_करा_पत्ता`, `स्वतंत्रसंदेश_डेटा_पाठवा/स्वीकारा`, `कनेक्ट_संचारजाळे/प्रतीक्षाकरा/स्वीकारा`는
`प्रयोक्ता_ब्रिज.c`에서 SVC를 호출하며 मॅक्रो_मूल्य 별칭이 아니다. `struct क्लाउड_संचारद्वार_पत्ता`의
`पत्ता_कुटुंब`, `पोर्ट_नंबर`, `इंटरनेट_पत्ता.पत्ता_मूल्य`을 사용한다. 상수는 enum의
`क्लाउड_कुटुंब`, `स्वतंत्रसंदेश_संचारद्वार`, `स्वतंत्रसंदेश_प्रोटोकॉल`, `प्रवाह_संचारजाळे`, `प्रवाह_वाहतूक_प्रोटोकॉल`이다.
मराठी·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. बाह्य_मूल्य 통신은 स्वकीय 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. वास्तविक_डेटा Pi 4 GENET 드라이버는 미지원이다.
소켓도 वास्तविक_डेटा फलन_मूल्य `संचिका_मिटवा`로 닫는다.
