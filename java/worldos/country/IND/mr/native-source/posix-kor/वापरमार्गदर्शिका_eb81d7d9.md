# jkoros posix-kor

**स्वकीय ARM64 Java 커널용 C++ जोडा**은 [arm64-native](arm64-native/वापरमार्गदर्शिका_eb81d7d9.md)에 있다. गाभा_मूल्य 내부 직접 फाइल 호출과 EL0 प्रयोक्ता 프로그램의 फाइल/UDP 루프백 SVC 호출을 별도 라이브러리로 제공한다. तळ_मूल्य i386 लायब्ररी 및 ARM64 Linux libc와는 लक्ष्य·ABI가 다르다.

स्वकीय jkoros 커널에서 실행되는 i386 C 라이브러리와 मराठी API다. होस्ट libc를 연결하지 않고 `int 0x80`으로 वास्तविक_डेटा 커널의 संचिका_विवरणक·टर्मिनल_आदानप्रदान·UDP·साठवणे_मूल्य 계층을 호출한다. `लेगसी_स्रोत/`의 होस्ट JVM 모형과 별개다.

**현재는 POSIX의 일부 기능을 제공하는 호환 계층이며, POSIX 인증·전체 libc·전체 OpenJDK를 뜻하지 않는다.** अंमलबजावणी 범위와 제한을 아래에 명시한다. 한국어를 먼저 적용했다. 다른 국가·언어의 번역판은 아직 만들지 않았다.

## 빌드와 आज्ञा_कार्यवाही_करा

```sh
cd /home/user/jkoros
make posix-kor
make iso
make test-posix
make -C os run-store
```

`run-store`는 `os/build/files.img`पहिले_संकार्य 없을 때만 새 전용 파일을 만들고 QEMU IDE पहिले_आयटम 장치로 연결한다. 기존 파일을 덮어써서 초기화하지 않는다. 일반 `make run`은 디스크 없이 실행된다. VirtualBox 실행기의 디스크 연결은 변경하지 않았다.

부팅된 jkoros에서:

```text
run posixcheck check
run posixstore
cat stored.txt
edit note.txt
hello from jkoros
.save
sync
```

`Sync: 0`은 연결된 전용 매체에 저장했다는 뜻이다. 디스크가 없거나 नेमा_मूल्य 형식이 아니면 `Sync: -19`तिसरे_संकार्य. 같은 `files.img`로 पुनःप्रयत्न_मूल्य 부팅하면 शेवटचे_आयटम समन्वय_साधा 상태를 복원한다. Java 소스와 `.class`도 같은 साठवणे_मूल्य 대상이다. `close`दुसरे_संकार्य 편집기의 `.save`만으로 재부팅 보존을 보장하지 않으므로 निर्गमन_करा_अनुप्रयोग 전에 `sync`를 실행한다.

## 한국어로 C अनुप्रयोग_f5044b9b 작성

```c
#include <संचिका_द्विमानजोडणी.h>

int main(int वितर्क_संख्या_e5e1cf1c, char **वितर्क_यादी) {
    (void)वितर्क_संख्या_e5e1cf1c;
    (void)वितर्क_यादी;
    int संचिका_विवरणक = संचिका_उघडा("note.txt", वाचणे_लिहिणे | जर_अनुपस्थित_तयार_करा, 0600);
    if (संचिका_विवरणक < 0) return त्रुटी_संख्या;
    if (संचिका_डेटा_लिहा(संचिका_विवरणक, "hello\n", 6) != 6) return 1;
    if (स्थिरकरा_फाईल_संग्रहण(संचिका_विवरणक) < 0) return त्रुटी_संख्या;
    return संचिका_मिटवा(संचिका_विवरणक);
}
```

작성 원문은 한글을 그대로 유지한다. `साधने/आयडेंटिफायर_रुपांतरण.py`पहिले_संकार्य सिस्टम_बांधणी 복사본의 식별자만 C 표준 UCN 표기로 바꾸어 GCC 7에서도 컴파일되게 한다. स्ट्रींग_मूल्य, 주석, `#include` 경로는 변환하지 않는다. 이 도구는 C의 모든 पूर्वप्रक्रियाकरा_स्रोत 표기법을 해석하는 전처리기가 아니며, 프로젝트가 사용하는 일반 토큰과 include 문법을 대상으로 한다.

라이브러리는 `build/libposix-kor.a`, सुरू_करा 코드는 `build/प्रारंभ_प्रयोक्ता_अनुप्रयोग.o`, तयार_करा 헤더는 `build/स्रोत/घोषणाशीर्षे/`이다. सिस्टम_बांधणी 옵션과 जोडा 명령은 [Makefile](Makefile), वास्तविक_डेटा 예제는 [संचिका_द्विमानजोडणी_चाचणी.c](स्रोत/चाचण्या/संचिका_द्विमानजोडणी_चाचणी.c)와 [स्वतंत्रसंदेश_चाचणी.c](स्रोत/चाचण्या/स्वतंत्रसंदेश_चाचणी.c)에 있다. 새 ELF를 OS에 포함하려면 `os/Makefile`의 प्रयोक्ता आज्ञा_कार्यवाही_करा 묶음에 명시적으로 등록한다. 게스트 안에서 C를 컴파일하는 도구는 제공하지 않는다.

표준 C/POSIX बाह्य_मूल्य नाव `open`, `read`, `write`, `socket`, `errno`, `main`과 헤더 경로는 유지한다. मराठी 별칭은 같은 함수를 가리킨다. 변수와 अंमलबजावणी 파일에는 의미를 드러내는 मराठी 이름을 사용한다. भाषांतर_करा_स्रोत 근거는 [नामकरण 원칙](नामकरण_तत्त्वे.md), वास्तविक_डेटा 대응은 [용어 대응표](परिभाषा_प्रतिचित्रण.tsv)에 기록했다.

## 제공하는 기능

|---|---|---|
| फाइल | open/creat/read/write/close/lseek/unlink/ftruncate/fstat/fsync | 루트의 단일 नाव, ASCII 63바이트, 8개 फाइल, 파일당 16KiB |
| विवरणक_प्रविष्टी | dup/dup2, F_DUPFD/F_DUPFD_CLOEXEC/F_GETFD/F_SETFD/F_GETFL/F_SETFL | प्रक्रिया_मूल्य एक_मूल्य, कमाल_मूल्य 32개; कुलूप_मूल्य·exec 미구현 |
| इनपुट_आउटपुट संयोजना | O_RDONLY/O_WRONLY/O_RDWR/O_CREAT/O_EXCL/O_TRUNC/O_APPEND/O_NONBLOCK/O_CLOEXEC | 그 밖의 비트는 ENOTSUP; वास्तविक_डेटा प्रयोक्ता·그룹 ऍक्सेस_प्रविष्टी परवानगी_मूल्य 검사는 अनुपस्थित_पद्धत |
| 표준 टर्मिनल_आदानप्रदान | 0 वाचन, 1·2 लेखन, बाइट_मूल्य एकक_मूल्य आदान_मूल्य | टर्मिनल संपादन_मूल्य·termios·시그널 अनुपस्थित_पद्धत, हांगुल_मजकूर फॉन्ट_मूल्य/입력기 अनुपस्थित_पद्धत |
| UDP | socket/bind/sendto/recvfrom/getsockname, SO_RCVTIMEO | IPv4 UDP만, 묶인 संचारटोक_मूल्य 4개, 전문당 1,024바이트, मूल्य_स्वीकारा प्रतीक्षा_करा_मूल्य संयोजना कमाल_मूल्य 2초 |
| पत्ता | htons/ntohs/htonl/ntohl/inet_pton/inet_ntop | IPv4 अंक_मूल्य 주소만; DNS/IPv6 अनुपस्थित_पद्धत |
| 작은 C समर्थन_मूल्य | strlen/strcmp/memcpy/memset/memcmp/puts/putchar | 전체 libc·stdio FILE·malloc अनुपस्थित_पद्धत |
| साठवणे_मूल्य | JKSTORE1 전용 IDE साठवणे_मूल्य, 두 보존본과 चेकसम | FAT/ext फाइल_सिस्टम·디렉터리·하드 링크·심볼릭 링크 अनुपस्थित_पद्धत |
| 게스트 Java | FileInputStream(String).read()/close(), FileOutputStream(String[, boolean]).write(int)/close() | ऍरे_मूल्य इनपुट_आउटपुट·일반 java.io·अपवाद प्रक्रिया_मूल्य_प्रविष्टी अनुपस्थित_पद्धत |

`dup`으로 복제한 서술자는 फाइल 위치와 शेवटीजोडा_पुढीलक्रम 설정을 공유한다. `FD_CLOEXEC`는 서술자마다 저장한다. `unlink`는 이름만 제거하며, 열린 파일의 내용은 शेवटचे_आयटम 참조가 닫힐 때까지 접근할 संख्या 있다. 빈 위치를 건너뛰어 쓰거나 길이를 늘린 영역은 0으로 읽힌다. संचिका_विवरणक 부족으로 실패한 `open`은 파일을 생성하거나 비우지 않는다. C आवाहन 실패는 `-1`과 `errno`, 내부 गाभा_मूल्य 호출은 ऋण_मूल्य त्रुटी 번호를 반환한다.

`fstat`는 이 프로젝트 전용 48바이트 구조체에 प्रकार_मूल्य·आकार·링크 संख्या·अनुमती_परवानगी बिट_मूल्य 등을 반환한다. POSIX의 전체 वेळ_मूल्य 속성은 아직 제공하지 않는다. 다른 운영체제의 `struct stat` 또는 Linux 바이너리 ABI와 호환되지 않는다. `O_CLOEXEC`는 기록할 संख्या 있지만 सध्याचे_आयटम exec 기능은 없다. 성공하는 फलन_मूल्य 이름만으로 전체 POSIX 의미가 구현되었다고 간주하면 안 된다.

UDP는 QEMU RTL8139의 वास्तविक_डेटा होस्ट 왕복을 지원한다. 짧은 मूल्य_स्वीकारा 버퍼에는 앞부분을 복사하고 बाकी_मूल्य 전문을 버린다. 빈 전문도 송수신한다. `SO_RCVTIMEO` 또는 비차단 수신의 डेटा 없음은 `EAGAIN`이다. TCP를 요청하면 `EPROTONOSUPPORT`를 반환한다. 루프백·브로드캐스트·멀티캐스트·연결형 संचारद्वार_मूल्य·listen/accept는 아직 없다. 기존 AOT Java UDP 손잡이는 이 POSIX 서술자와 별개이므로 서로 섞어 닫지 않는다.

모든 प्रयोक्ता 프로그램에는 기존 약 3초 आज्ञा_कार्यवाही_करा 상한이 적용된다. `errno`는 सध्याचे_आयटम 단일 प्रक्रिया_मूल्य·단일 스레드 변수다. JDK 전체, Swing/AWT/JavaFX, TCP/DNS/HTTP/TLS, 스레드·GC·JIT·동적 연결은 아직 구현하지 않았다. 전체 Java SE आज्ञा_कार्यवाही_करा 환경을 만들려면 해당 गाभा_मूल्य 기반과 런타임 이식을 पुढेचालूकरा_प्रक्रियाकरण 진행하거나 별도 Linux पाया आज्ञा_कार्यवाही_करा 방식을 결정해야 한다.

## साठवणे_मूल्य 형식과 प्रमाणित

매체는 512바이트 विभाग_मूल्य 2,048개(1MiB)तिसरे_संकार्य. विभाग_मूल्य 0의 `JKSTORE1` आयडेंटिफायर_मूल्य·आकार·स्वरूप_मूल्य 번호가 सर्व_बांधणी 맞는 장치만 लेखन 대상으로 삼는다. विभाग_मूल्य 1과 260에서 각각 259구역짜리 보존본이 시작한다. 각 보존본은 आहे_पूर्ण शीर्ष_मूल्य 1구역, फाइल लुकअप_सारणी 2구역, फाइल डेटा 256구역으로 구성된다.

`fsync`와 `sync`는 이름이 남아 있는 모든 파일의 सध्याचे_आयटम 상태를 저장한다. 반대편 보존본을 무효화한 मागे_मूल्य फाइल 표와 자료를 쓰고 ATA 캐시 비우기를 실행한다. 마지막에 पिढी_मूल्य 번호와 FNV-1a 검사합을 가진 आहे_पूर्ण 머리를 기록하고 पुनःप्रयत्न_मूल्य 캐시를 비운다. प्रणालीप्रारंभ 시 검사합과 표가 유효한 가장 अलीकडे_मूल्य 세대를 선택한다. 검사합은 우발적인 손상을 प्रविष्टी_शोधा 위한 것이며 암호학적 무결성 검증은 아니다. वास्तविक_डेटा मोबाइल_मूल्य 전원 차단 시험은 하지 않았다.

복원된 फाइल 목록은 प्रणालीप्रारंभ 이미지의 डिफॉल्ट_मूल्य उदाहरणे/`JAVA_FILES` 목록을 대체한다. 새 예제를 이미지에 추가해도 기존 साठवणे_मूल्य 매체를 연결하면 저장된 목록이 우선한다. 동기화하지 않은 변경은 재부팅 नंतर_राज्य 사라진다.

`make test-posix`는 मराठी आयडेंटिफायर_मूल्य रूपांतरकरा_मूल्य, ELF/ISO의 वास्तविक_डेटा C ABI आवाहन, 공유 जागा, 삭제된 파일의 수명, फाइल/विवरणक_प्रविष्टी 고갈, निर्देशक त्रुटी, 표준 आदान_मूल्य, UDP, `fsync`, 재부팅, 손상된 नवीनतम_मूल्य 보존본의 회피, 다른 형식의 माध्यमे_मूल्य 비변경, 게스트 Java फाइल 처리와 OpenJDK 교차 실행을 확인한다. 기록은 `os/build/काम_चाचणी_7b38e7e1.json`, `जतन_चाचणी.json`, `जावा_संचिका_चाचणी.json`이다.
