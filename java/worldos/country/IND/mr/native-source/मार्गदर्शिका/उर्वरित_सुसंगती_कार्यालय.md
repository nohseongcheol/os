# 전체 समर्थन_मूल्य 요청의 सध्याचे_आयटम राज्य_मूल्य

विनंती 전체는 아직 완료되지 않았다. सध्याचे_आयटम ISO는 स्वकीय Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 वास्तविक_डेटा C POSIX 일부 기능, मराठी API/स्रोत नाव, IDE फाइल 보존, 게스트 Java फाइल 흐름을 구현하고 시험했다. [구현과 सीमा_मर्यादा](../posix-kor/वापरमार्गदर्शिका_eb81d7d9.md)를 기준으로 판단한다.

| विनंती 분야 | सध्याचे_आयटम आज्ञा_कार्यवाही_करा 가능한 क्लिप | 전체 지원에 필요한 पारपाडा_कार्य |
|---|---|---|
| Java स्रोत_बांधणी·आज्ञा_कार्यवाही_करा | 게스트 제한형 javac/JVM, स्थिर_मूल्य 단일 클래스와 일부 표준 ऑब्जेक्ट_मूल्य | 일반 ऑब्जेक्ट_मूल्य·वर्ग_मूल्य जोडा·अपवाद·GC·스레드, 완전한 javac와 표준 वर्ग_मूल्य लायब्ररी |
| फाइल | POSIX विवरणक_प्रविष्टी, Java 단일 बाइट_मूल्य फाइल प्रवाह_मूल्य, 전용 माध्यमे_मूल्य 보존 | 일반 java.io/nio, 디렉터리·परवानगी_मूल्य·कुलूप_मूल्य·일반 फाइल_सिस्टम·एक्सटेंशन_मूल्य 가능한 धारणक्षमता_मूल्य |

| GUI·Swing | VGA वर्ण टर्मिनल_आदानप्रदान | 프레임버퍼·आदान_मूल्य इव्हेंट·फॉन्ट_मूल्य·विंडो ऑपरेटिंग_सिस्टम_मूल्य, AWT 네이티브 연결과 Swing आज्ञा_कार्यवाही_करा पाया |
| POSIX | 문서화한 फाइल·टर्मिनल_आदानप्रदान·UDP उपभाग_मूल्य | प्रक्रिया_मूल्य·exec/fork·스레드·시그널·वेळ_मूल्य·mmap·poll·파이프 등과 적합성 प्रमाणित |
| 언어별 नाव | मराठी 46개 प्रतिचित्रण_मूल्य प्रविष्टी_मूल्य, वास्तविक_डेटा C/Java/फाइल नाव 적용 | लक्ष्य भाषा स्थिरकरा_मूल्य, 언어별 용례·역사 근거와 해당 स्रोत·도구의 प्रमाणित |

स्वकीय 커널을 유지하면 वरचे_मूल्य पाया 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux पाया आज्ञा_कार्यवाही_करा 환경을 추가하는 방식은 별도의 गाभा_मूल्य·루트 फाइल_सिस्टम·OpenJDK·그래픽 सर्व्हर_मूल्य·영구 साठवणे_मूल्य 구성을 가진 आज्ञा_कार्यवाही_करा 경로가 된다. 후자는 기존 स्वकीय 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

आज्ञा_कार्यवाही_करा 기반과 शेवटीजोडा_प्रविष्टी लक्ष्य 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. सध्याचे_आयटम 원문과 चाचण्या 결과를 후속 구현의 출발점으로 보존한다.
