# engos 기능 대응표

이 표는 기존 `लेगसी_स्रोत/`의 ऑब्जेक्ट_मूल्य पाया JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [वास्तविक_डेटा प्रणालीप्रारंभ 기능과 सीमा_मर्यादा](../os/वापरमार्गदर्शिका_eb81d7d9.md)를 따로 기록한다.

## 기존 ऑब्जेक्ट_मूल्य पाया 관리 गाभा_मूल्य 전체를 부팅하기 위해 남은 जोडा

पुढील_आयटम 항목은 Java 문법만으로 실행할 संख्या 없는 CPU/मोबाइल_मूल्य 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot प्रविष्टी_गुण_मूल्य, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 संदर्भ_मूल्य साठवणे_मूल्य
- वास्तविक_डेटा PIC/PIT/PS2/ATA/PCI हार्डवेअर_पॉर्ट 및 AMD PCnet DMA लूप_मूल्य
- Java ऑब्जेक्ट_मूल्य·ऍरे_मूल्य लिंक_लेआउट, अपवाद, स्थिर_मूल्य आरंभ_करा, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT टप्पा_मूल्य
- FAT 디스크 구역을 वास्तविक_डेटा ATA 장치와 연결하는 इनपुट_आउटपुट 접착 थर_मूल्य

वरचे_मूल्य 관리 계층은 engos 기능의 Java 관리 구현과 होस्ट 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot प्रविष्टी_गुण_मूल्य, स्थिर_मूल्य आरंभ_करा·पूर्णांक ऍरे_मूल्य, VGA/अनुक्रमिक_मूल्य/PS2, आज्ञा_अर्थविश्लेषक, प्रयोक्ता ELF/ring 3/시스템 आवाहन, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 होस्ट 루프백 패킷 왕복을 검증했다. वरचे_मूल्य 표의 ऑब्जेक्ट_मूल्य पाया 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
