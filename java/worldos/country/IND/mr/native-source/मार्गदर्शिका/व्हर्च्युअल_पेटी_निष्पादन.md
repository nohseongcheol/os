# VirtualBox आज्ञा_कार्यवाही_करा

```sh
cd ~/jkoros
make vbox
```

별도로 VM을 만들거나 ISO를 연결할 필요가 없다. प्रारंभिक_आयटम 실행하면 `os/build/kernel.iso`를 빌드하고 `jkoros operating system`이라는 전용 VM을 만들어 VirtualBox 창으로 부팅한다. `jkoros/os` 안에서도 `make vbox`를 사용할 संख्या 있다.

게스트의 `jkoros>` 프롬프트에서 पुढील_आयटम 명령을 입력한다.

```text
help
apps
run hello vbox
```

शेवटचे_आयटम 명령은 별도 Java ELF를 실행한다. `USER MODE ring 3`, `arg: vbox`, `Exit: 0` आउटपुट नंतर_राज्य 셸로 돌아오면 정상이다. VGA 화면은 सध्याचे_आयटम ASCII 글꼴만 지원하므로 한글은 `?`로 보이며, हांगुल_मजकूर 원문은 अनुक्रमिक_मूल्य 기록에서 확인할 संख्या 있다.

## राज्य_मूल्य 확인과 पुनःप्रयत्न_मूल्य आज्ञा_कार्यवाही_करा

```sh
make vbox-status
```

이 명령은 VM राज्य_मूल्य, ISO와 अनुक्रमिक_मूल्य 기록의 절대 경로를 JSON으로 출력한다.

| सध्याचे_आयटम राज्य_मूल्य | `make vbox` कृती |
| --- | --- |
| 아직 생성하지 않음 | ISO सिस्टम_बांधणी → 전용 VM तयार_करा → प्रणालीप्रारंभ |
| आहे_बाहेरपडलेले (`poweroff`, `aborted`) | ISO सिस्टम_बांधणी → 광학 माध्यमे_मूल्य ताजे_करा → 새로 प्रणालीप्रारंभ |
| आज्ञा_कार्यवाही_करा 중 (`running`) | 재빌드·재부팅 없이 सध्याचे_आयटम VM राखा_मूल्य |
| 일시정지 (`paused`) | 기존 VM पुन्हाचालूकरा_निष्पादन |
| 저장됨 (`saved`) | मागील_आयटम अनुक्रमिक_मूल्य 기록을 복사해 보관하고 साठवणे_मूल्य राज्य_मूल्य पुन्हाचालूकरा_निष्पादन |
| साठवणे_मूल्य·सुरू_करा 등 स्विच_मोड 중 | 변경하지 않고 पारपाडा_कार्य आहे_पूर्ण नंतर_राज्य 재실행하도록 वापरमार्गदर्शिका_eb81d7d9 |

स्रोत_ट्री 변경을 반영하려면 VM을 종료한 पुढील_आयटम पुनःप्रयत्न_मूल्य `make vbox`를 실행한다. **साठवणे_मूल्य 상태를 재개하면 मागील_आयटम 커널이 पुढेचालूकरा_प्रक्रियाकरण 실행되므로 새 빌드를 반영하지 않는다.** 실행기는 강제 종료하거나 साठवणे_मूल्य 상태를 폐기하지 않는다. VirtualBox 창을 닫을 때 사용자가 전원 끄기를 선택하면 स्मृती_डेटा 상태가 사라지므로 보존할 작업이 없는지 먼저 확인한다. 게스트의 `halt`는 CPU만 멈추며 VirtualBox의 전원을 끄는 명령은 아니다.

विंडो 없는 실행이 필요하면 VM이 꺼져 있을 때 사용한다.

```sh
make vbox VBOX_TYPE=headless
```

आज्ञा_कार्यवाही_करा 중인 VM에 पुनःप्रयत्न_मूल्य 명령을 내려도 GUI/headless 방식은 바뀌지 않는다. डिफॉल्ट_मूल्य नाव 대신 다른 이름이 필요하면 **최초 तयार_करा 시에만** `VBOX_NAME="원하는 नाव"`을 지정하고 이후에도 같은 값을 사용한다.

## 설정과 डेटा 보존

- डिफॉल्ट_मूल्य 설정은 BIOS, स्मृती_डेटा 64MiB, CPU 1개, VGA स्मृती_डेटा 16MiB, IDE 광학 부팅이다. 가상 하드디스크를 만들지 않는다.
- VM 설정은 `.vbox/machines/`, सामुग्री_मूल्य 검사합별 ISO 사본은 `.vbox/media/`, अनुक्रमिक_मूल्य 기록은 `.vbox/logs/`에 보관한다. `.vbox/state.json`은 전용 VM의 UUID와 मालक_मूल्य 표식을 저장한다.
- 꺼진 VM을 부팅할 때 새 अनुक्रमिक_मूल्य 기록을 만든다. साठवणे_मूल्य राज्य_मूल्य पुन्हाचालूकरा_निष्पादन 전의 기록은 `before-resume-*.log`로 복사한다. साठवणे_मूल्य राज्य_मूल्य 자체는 삭제하지 않고 VirtualBox가 그대로 재개한다.
- 같은 이름의 다른 VM을 인수하지 않는다. UUID·संयोजना मार्ग·मालक_मूल्य 표식을 검사하며, 사용자가 별도로 연결한 디스크나 광학 매체를 자동 교체하지 않는다.
- 기존 ISO 사본과 기록은 자동 삭제하지 않는다. `.vbox`는 Git वगळा_मूल्य 대상이다. 용량을 정리할 때도 आज्ञा_कार्यवाही_करा·साठवणे_मूल्य 상태의 VM이 참조하는 파일과 관리 정보를 임의로 삭제하지 않는다.
- VirtualBox 또는 होस्ट 드라이버가 없으면 오류를 안내한다. 자동 स्थापित_करा_मूल्य, व्यवस्थापक_मूल्य परवानगी_मूल्य आज्ञा_कार्यवाही_करा, मोबाइल_मूल्य परवानगी_मूल्य 변경은 하지 않는다.

## 네트워크 मर्यादा_मूल्य

सध्याचे_आयटम 커널의 RTL8139 드라이버는 QEMU에서 사용한다. VirtualBox의 PCnet/E1000 드라이버는 아직 구현하지 않아 이 실행기는 네트워크 장치를 비활성화한다. 셸과 प्रयोक्ता 프로그램은 실행되지만 UDP 열기는 `-19`로 실패한다. UDP 왕복은 `make run`과 [प्रयोक्ता आज्ञा_कार्यवाही_करा·네트워크 वापरमार्गदर्शिका_eb81d7d9](../os/प्रयोक्ता/वापरमार्गदर्शिका_eb81d7d9.md)의 절차로 시험한다.

## प्रमाणित

`make test-vbox`는 가짜 VirtualBox 응답을 사용하여 새 VM तयार_करा, आज्ञा_कार्यवाही_करा·साठवणे_मूल्य·일시정지·स्विच_मोड राज्य_मूल्य, नाव 충돌, 소유권 불일치, प्रयोक्ता माध्यमे_मूल्य संरक्षण_मूल्य, सिस्टम_बांधणी बिघाड_मूल्य, 중단된 तयार_करा पुनर्प्राप्त_करा_राज्य, ISO बदल_करा_मूल्य 감지, मार्ग संरक्षण_मूल्य 등을 검사한다. वास्तविक_डेटा VM을 만들거나 변경하지 않는다.

2026-09-13에 अनुप्रयोग_चालक एकक_मूल्य चाचण्या 16개가 통과했다. 별도로 वास्तविक_डेटा VirtualBox 5.2.42에서 `make vbox`의 VM तयार_करा·GUI प्रणालीप्रारंभ, `JAVA SELFTEST PASS`, 셸의 `run hello vbox` 실행과 `Exit: 0`, आज्ञा_कार्यवाही_करा 중 재호출 시 재부팅하지 않는 कृती 및 `make vbox-status`를 확인했다. साठवणे_मूल्य·일시정지 분기는 एकक_मूल्य 시험으로 검증했다.
