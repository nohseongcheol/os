# JIndOS

सध्याचे_आयटम स्वकीय ARM64 배포판은 [LICENSE](LICENSE)의 COSL 상업 조건을 유지한다. 제3자 라이선스의 권리는 별도로 보장하며, वितरण_मूल्य 시 स्रोत_ट्री·पुन्हाजोडा_संचारटोक 자료를 포함하는 절차는 [COSL वितरण_मूल्य वापरमार्गदर्शिका_eb81d7d9](platforms/rpi4-native/सीओएसएल_वितरण_मार्गदर्शी.md)에 있다.

स्वकीय ARM64 판의 `ipconfig`/`ip`, `ping`, `ps`/`top`, `free`/`df`, `poweroff`와 मराठी 명령은 [네트워크·ऑपरेटिंग_सिस्टम_मूल्य आदेश वापरमार्गदर्शिका_eb81d7d9](platforms/rpi4-native/संचारजाळे_आणि_सिस्टम_आदेश.md)를 참고한다. 새 커널을 부팅한 मागे_मूल्य `help system`으로 볼 संख्या 있다.

Raspberry Pi 4 **स्वकीय Java ARM64 गाभा_मूल्य**은 [स्वकीय Pi4 वापरमार्गदर्शिका_eb81d7d9](platforms/rpi4-native/वापरमार्गदर्शिका_eb81d7d9.md)에 있다. Linux 없이 부팅하며 GUI टर्मिनल·vi, स्वकीय JVM의 Swing 일부 API, TCP/UDP·FTP, 게스트 TinyCC·MicroPython, C/C++의 posix-kor 호출을 제공한다. [मराठी Java संचार·अपवाद API](platforms/rpi4-native/स्वकीय_जावा/वापरमार्गदर्शिका_eb81d7d9.md)와 [मराठी स्रोत_ट्री नामकरण](platforms/rpi4-native/नामकरण/वापरमार्गदर्शिका_eb81d7d9.md)을 지원한다. [स्वकीय SSH·VNC 및 GENET 드라이버](platforms/rpi4-native/बाह्य_कनेक्शन_मार्गदर्शी.md)를 포함하며, 네트워크는 QEMU의 UART SLIP 경로로 검증했다. वास्तविक_डेटा Pi 4 GENET 동작은 미검증이고, USB आदान_मूल्य·영속 저장과 전체 OpenJDK·Swing은 아직 समर्थन_मूल्य क्लिप 밖이다.

Raspberry Pi 4용 Linux·OpenJDK 실행판과 प्रयोक्ता पर्यावरण हलवा_मूल्य 기능은 [라즈베리파이 실행판](platforms/rpi4/README.md)에 있다. वास्तविक_डेटा ARM64 JDK/JRE와 시스템·प्रयोक्ता चित्र_बांधणी सिस्टम_बांधणी 경로를 제공한다. 기존 स्वकीय x86 커널과는 별도 आज्ञा_कार्यवाही_करा 기반이다. 일반 Java `.class`/JAR의 आज्ञा_कार्यवाही_करा फाइल 생성은 [OpenJDK आज्ञा_कार्यवाही_करा फाइल](compiler/OpenJDK-निष्पादनीय_संचिका.md), मराठी API는 [मराठी Java लायब्ररी](स्वकीय_जावा/वापरमार्गदर्शिका_eb81d7d9.md)를 참고한다.

`jkoros`는 `engos`의 기능을 Java 관리 커널로 옮기는 프로젝트다. 프로젝트가 소유하는 Java फलन_मूल्य, चल_मूल्य, स्वरूप_मूल्य 및 Java फाइल 이름은 한국어로 작성한다. 표준 Java 실행기의 `main`, Java 표준 लायब्ररी स्वरूप_मूल्य, x86 부트 ABI 등 बाह्य_मूल्य 계약은 보존한다. स्वकीय ARM64 실행기는 मराठी `सुरू_करा()`도 진입점으로 지원하며, मराठी GUI·पारपाडा_कार्य 가닥을 JVM에 직접 구현했다. स्वकीय ARM64 C 연결부·Python 도구와 공용 x86·ARM64 AOT 번역기의 स्वकीय 이름도 한국어로 작성한다. मागील_आयटम 경로의 호환 प्रविष्टी_गुण, OpenJDK सहायक_मूल्य 도구와 Linux आवृत्ती_मूल्य 도구에는 영어 이름이 남아 있고 [नामकरण 원칙·말의 근거·전체 स्रोत 검토 क्लिप](platforms/rpi4-native/नामकरण/वापरमार्गदर्शिका_eb81d7d9.md)를 별도로 기록한다.

## सध्याचे_आयटम अंमलबजावणी

तळ_मूल्य 목록은 기존 `लेगसी_स्रोत/`의 JVM 관리 커널에 대한 것이다. वास्तविक_डेटा 네이티브 커널의 범위는 `os/वापरमार्गदर्शिका_eb81d7d9.md`에서 별도로 설명한다.

- संरेखन_करावे_मूल्य 할당과 해제를 지원하는 स्मृती_प्रदेश व्यवस्थापक_मूल्य
- पत्ता पत्ता_प्रदेश, पृष्ठ_मूल्य जोडा, लेखन 시 इन्स्टन्स_मूल्य(COW)
- प्रक्रिया_मूल्य आयडेंटिफायर_मूल्य, तयार_करणे 대기열, fork/wait राज्य_मूल्य
- 과정별 फाइल विवरणक_प्रविष्टी, open/read/seek/dup/close
- ELF32 ओळखा_मूल्य 및 विभाग_मूल्य पडताळण्या
- 키보드·마우스 आदान_मूल्य इव्हेंट 대기열
- अनुक्रमिक_मूल्य 단말과 네이티브 हार्डवेअर_मूल्य सीमा_मूल्य
- 관리 गाभा_मूल्य 전체 자동 चाचण्या

세부 प्रतिचित्रण_मूल्य 범위와 아직 필요한 네이티브 연결은 [기능 대응표](मार्गदर्शिका/वैशिष्ट्य_प्रतिचित्रण.md)에 기록한다.

## 빌드와 चाचण्या

새 네이티브 구현은 `compiler/`와 `os/`에 있다. 기존 `लेगसी_स्रोत/`의 JVM 관리 커널은 그대로 보존하며, 두 구현의 시험과 기능 범위는 서로 다르다.

```sh
cd /home/user/jkoros
make                 # 네이티브 गणना उदाहरणे + Java गाभा_मूल्य ELF
make iso             # os/build/kernel.iso
make run             # QEMU अनुक्रमिक_मूल्य टर्मिनल_आदानप्रदान; help आदान_मूल्य (종료는 Ctrl+A, X)
make run-gui         # ISO를 QEMU पडदा/PS2 키보드로 आज्ञा_कार्यवाही_करा
make vbox            # 전용 VirtualBox VM 자동 तयार_करा·आज्ञा_कार्यवाही_करा (GUI)
make vbox-status     # VirtualBox राज्य_मूल्य·ISO·अनुक्रमिक_मूल्य लॉग_नोंद मार्ग पडताळा
make test-vbox       # VirtualBox अनुप्रयोग_चालक राज्य_मूल्य प्रक्रिया_मूल्य_प्रविष्टी चाचण्या (वास्तविक_डेटा VM बदल_करा_मूल्य अनुपस्थित_पद्धत)
make test            # संकलक चाचण्या + ELF/ISO प्रणालीप्रारंभ 및 आदेश आदान_मूल्य चाचण्या
make apps            # 독립 प्रयोक्ता ELF अनुप्रयोग_f5044b9b सिस्टम_बांधणी
make test-network    # प्रयोक्ता मोड_मूल्य·UDP 왕복·स्मृती_डेटा संरक्षण_मूल्य चाचण्या
make test-java       # 게스트 javac/JVM + OpenJDK 양방향 교차 आज्ञा_कार्यवाही_करा चाचण्या
make posix-kor       # मराठी C 헤더와 वास्तविक_डेटा गाभा_मूल्य आवाहन लायब्ररी
make test-posix      # फाइल/UDP/साठवणे_मूल्य/Java फाइल इनपुट_आउटपुट चाचण्या
make -C os run-store # 전용 साठवणे_मूल्य 매체로 QEMU प्रणालीप्रारंभ
make legacy-test     # तळ_मूल्य 기존 JVM 관리 커널의 47개 चाचण्या
```

`compiler/`는 호스트의 `javac`를 문법·टाइप_करा_मूल्य पडताळण्या 전단으로 사용하고 स्वकीय बाइटसंहिता→x86 변환기로 ELF32 기계어를 만든다. 빌드할 때는 JDK가 필요하지만 생성된 커널과 ELF는 बाह्य_मूल्य JVM 없이 실행된다. 전체 Java, ऑब्जेक्ट_मूल्य 모델, 표준 라이브러리와 기존 관리 गाभा_मूल्य 전체의 AOT 변환은 아직 지원하지 않는다. 자세한 समर्थन_मूल्य 문법과 명령은 [संकलक वापरमार्गदर्शिका_eb81d7d9](compiler/वापरमार्गदर्शिका_eb81d7d9.md), वास्तविक_डेटा प्रणालीप्रारंभ 기능과 한계는 [네이티브 संचालनप्रणाली वापरमार्गदर्शिका_eb81d7d9](os/वापरमार्गदर्शिका_eb81d7d9.md)를 참고한다.

네이티브 셸에 स्वकीय 제한형 `javac`와 `java`를 추가했다. `edit Demo.java`로 소스를 입력하고 `.save`로 저장한 मागे_मूल्य `javac Demo.java`, `java Demo`로 **게스트 내부에서 컴파일하고 आज्ञा_कार्यवाही_करा**할 संख्या 있다. डिफॉल्ट_मूल्य 예제는 `javac Hello.java`, `java Hello`तिसरे_संकार्य. 파일은 RAM에서 동작하며, 전용 साठवणे_मूल्य 매체를 연결하면 `sync`로 재부팅 후에도 보존할 संख्या 있다. **OpenJDK/JDK 전체 이식은 아니며**, 단일 वर्ग_मूल्य·स्थिर_मूल्य फलन_मूल्य·पूर्णांक·स्ट्रींग_मूल्य·सशर्त/반복문과 일부 표준 호출을 지원한다. समर्थन_मूल्य क्लिप, बाह्य_मूल्य फाइल 적재와 시험은 [Java विकास पर्यावरण वापरमार्गदर्शिका_eb81d7d9](मार्गदर्शिका/जावा_विकास_पर्यावरण.md)에 있다.

네이티브 셸에서 `apps`, `run hello first second`, `net`, `run netcheck`를 사용할 संख्या 있다. 독립 ELF를 ring 3에 적재하고 `int 0x80` 호출을 통해 आउटपुट·बाबी·UDP 네트워크를 제공한다. 별도 होस्ट 터미널에서 `python3 os/साधने/प्रतिध्वनी_डेटा.py --port 9000`을 실행한 मागे_मूल्य 게스트에서 `run udp 10.0.2.2 9000 hello`로 वास्तविक_डेटा 왕복을 확인한다. 새 अनुप्रयोग_f5044b9b रजिस्टर_प्रविष्टी, API 및 제한은 [प्रयोक्ता आज्ञा_कार्यवाही_करा·네트워크 वापरमार्गदर्शिका_eb81d7d9](os/प्रयोक्ता/वापरमार्गदर्शिका_eb81d7d9.md)를 참고한다. सध्याचे_आयटम QEMU RTL8139·स्थिर_मूल्य IPv4·UDP 전용이며 TCP/DNS는 미지원이며, 전용 IDE साठवणे_मूल्य 형식과 POSIX फाइल/UDP 일부 기능을 추가했다.

`make vbox`는 `jkoros operating system` 전용 VM을 만들고 디스크 없이 ISO로 부팅한다. आज्ञा_कार्यवाही_करा 중이면 유지하고, साठवणे_मूल्य·일시정지 상태이면 재개하며, 꺼져 있을 때만 새 ISO를 빌드해 연결한다. VirtualBox에서 부팅과 셸의 प्रयोक्ता अनुप्रयोग_f5044b9b 실행을 확인했다. 다만 सध्याचे_आयटम VirtualBox용 네트워크 드라이버는 없어 네트워크 장치를 비활성화한다. UDP 시험에는 `make run`을 사용한다. 상태별 동작과 새 सिस्टम_बांधणी 반영 방법은 [VirtualBox आज्ञा_कार्यवाही_करा वापरमार्गदर्शिका_eb81d7d9](मार्गदर्शिका/व्हर्च्युअल_पेटी_निष्पादन.md)에 있다.

기존 관리 커널만 시험하려면:

```sh
cd /home/user/jkoros
make -f प्रविष्टी_तयार_करा.mk पडताळण्या
make -f प्रविष्टी_तयार_करा.mk होस्ट
```

`होस्ट`는 여전히 JVM 관리 계층의 कृती 시험이다. `make -f प्रविष्टी_तयार_करा.mk चित्र_बांधणी`는 새 `os/`의 제한형 네이티브 गाभा_मूल्य ISO를 만든다. 기존 `लेगसी_स्रोत/`의 फाइल_सिस्टम·प्रक्रिया_मूल्य·संचारजाळे_स्टॅक अंमलबजावणी 전체를 이 ISO에 이식했다는 의미는 아니다.

मराठी फलन_मूल्य·चल_मूल्य·फाइल 이름과 वास्तविक_डेटा C API는 [posix-kor](posix-kor/वापरमार्गदर्शिका_eb81d7d9.md)에 있다. 게스트 Java에서는 `FileInputStream`·`FileOutputStream`의 단일 बाइट_मूल्य 입출력도 지원한다. 전체 POSIX·OpenJDK·Swing 지원으로 확대된 것은 아니다.

बाह्य_मूल्य 배포용 `pack.sh` / `unpack.sh`와 자동 अवलंबने 복원은 [वितरण_मूल्य वापरमार्गदर्शिका_eb81d7d9](distribution/README.md)를 참고하세요.
