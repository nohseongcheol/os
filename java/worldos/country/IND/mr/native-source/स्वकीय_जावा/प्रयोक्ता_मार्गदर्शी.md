# jkoros मराठी लायब्ररी प्रयोक्ता_मार्गदर्शी

확인일: 2026-09-27. 대상은 `platforms/rpi4`의 **ARM64 Linux + OpenJDK 실행판**이며, QEMU에서도 같은 Java 라이브러리를 사용한다. `os/`의 स्वकीय x86 गाभा_मूल्य 및 `लेगसी_स्रोत/`의 관리 गाभा_मूल्य 모형과 구분한다.

## 1. सध्याचे_आयटम 제공하는 लायब्ररी

패키지는 `मराठी.जावा`, संचालनप्रणाली 안의 JAR 경로는 `/opt/jkoros/lib/स्वकीय_जावा.jar`तिसरे_संकार्य. **सहायक_मूल्य_44c0808f वर्ग_मूल्य 5개, 공개 स्थिर_मूल्य पद्धत_मूल्य 22개, 별도 GUI 프로그램인 वर्कस्पेस 1개**पहिले_संकार्य 있다. JAR는 Java 11 이상을 대상으로 빌드하며 सध्याचे_आयटम ARM64 배포판에는 OpenJDK 25가 포함돼 있다.

## 2. Java에서 प्रारंभ_कार्य

게스트 운영체제의 पारपाडा_कार्य 폴더에서 `사용예.java`를 작성한다.

```java
import मराठी.जावा.*;
import java.nio.file.Path;

public class 사용예 {
    public static void main(String[] बाबी) throws Exception {
        Path निर्देशिका_मूल्य = फाइल.निर्देशिका_तयार_करा(फाइल.मार्ग("사용예자료"));
        Path मार्गदर्शिका = निर्देशिका_मूल्य.resolve("अभिवादन_ae353e94.txt");
        फाइल.लेखन(मार्गदर्शिका, "हांगुल_मजकूर 😀");
        String सामुग्री_मूल्य = फाइल.वाचन(मार्गदर्शिका);
        System.out.println(सामुग्री_मूल्य);
        System.out.println(वर्ण.वर्ण_कोड_संख्या(सामुग्री_मूल्य)); // 한, पाठ्य, 공백, 😀 → 4
        Thread कार्यालय_मूल्य = पारपाडा_कार्य.सुरू_करा("अभिवादन_ae353e94 पारपाडा_कार्य", () -> System.out.println("पारपाडा_कार्य आज्ञा_कार्यवाही_करा"));
        पारपाडा_कार्य.प्रतीक्षाकरा(कार्यालय_मूल्य);
    }
}
```

```sh
javac -encoding UTF-8 -cp /opt/jkoros/lib/स्वकीय_जावा.jar 사용예.java
java -cp .:/opt/jkoros/lib/स्वकीय_जावा.jar 사용예
```

로그인 환경에 डिफॉल्ट_मूल्य `CLASSPATH`도 설정돼 있지만, 명시적인 `-cp`는 다른 आज्ञा_कार्यवाही_करा 환경에서도 경로를 분명하게 한다. 사용자가 `-cp`를 지정하면 필요한 JAR와 वर्ग_मूल्य 폴더를 सर्व_बांधणी 그 값에 포함해야 한다.

होस्ट 저장소에서는 다음처럼 सिस्टम_बांधणी·실행한다. होस्ट 경로와 게스트의 `/opt/...` 경로는 서로 다르다.

```sh
cd /home/user/jkoros/स्वकीय_जावा
make
javac -encoding UTF-8 -cp build/स्वकीय_जावा.jar उदाहरणे/अभिवादन_ae353e94.java
java -cp build/स्वकीय_जावा.jar:उदाहरणे अभिवादन_ae353e94
```

## 3. 전체 सहायक_मूल्य_44c0808f API

तळ_मूल्य 메서드는 सर्व_बांधणी `public static`이며, 객체를 만들지 않고 `फाइल.वाचन(...)`처럼 호출한다. 표의 이름은 वास्तविक_डेटा स्रोत_ट्री 및 JAR의 `javap -public` 결과와 대조했다. 선언된 पडताळण्या अपवाद 외에도 잘못된 बाबी 등에 대한 표준 Java आज्ञा_कार्यवाही_करा 시 예외가 발생할 संख्या 있다.

### फाइल: `मराठी.जावा.फाइल`

`Path`는 `java.nio.file.Path`, `List`는 `java.util.List`तिसरे_संकार्य.

| पद्धत_मूल्य | परतकरा_टाइप_करा | कृती·सशर्त |
|---|---|---|
| `मार्ग(String नाव)` | `Path` | 이름을 मार्ग 객체로 रूपांतरकरा_मूल्य. वास्तविक_डेटा 파일을 만들지는 않음 |
| `वाचन(Path मार्ग)` | `String` | फाइल 전체를 UTF-8 텍스트로 मोजमाप_वाचा |
| `लेखन(Path मार्ग, String सामुग्री_मूल्य)` | `Path` | UTF-8 साठवणे_मूल्य. 파일이 없으면 생성하고, 있으면 기존 내용을 비움 |
| `बाइट_मूल्य_वाचा(Path मार्ग)` | `byte[]` | फाइल 전체를 बाइट_मूल्य 배열로 मोजमाप_वाचा |
| `बाइट_मूल्य_लिहा(Path मार्ग, byte[] सामुग्री_मूल्य)` | `Path` | बाइट_मूल्य साठवणे_मूल्य. 없으면 생성하고, 있으면 기존 내용을 비움 |
| `निर्देशिका_तयार_करा(Path मार्ग)` | `Path` | 필요한 상위 폴더까지 तयार_करा |
| `करते_अस्तित्व(Path मार्ग)` | `boolean` | 존재 여부 पडताळा. 확인할 संख्या 없는 경우도 `false`कार्यालय_मूल्य संख्या 있음 |
| `पुसा_प्रविष्टी(Path मार्ग)` | `boolean` | 삭제했으면 `true`, 없으면 `false`. 폴더의 재귀 삭제는 아님 |
| `प्रविष्टी_यादी(Path मार्ग)` | `List<Path>` | 바로 तळ_मूल्य 항목을 मार्ग संरेखन_करावे_मूल्य 순서로 परतकरा_मोजमाप. 재귀 탐색은 아님 |

`मार्ग`, `करते_अस्तित्व`를 제외한 वरचे_मूल्य 메서드는 `IOException`을 선언한다. `लेखन`와 `बाइट_मूल्य_लिहा`는 상위 폴더를 자동으로 만들거나 내용을 पुढीलक्रम_मूल्य 쓰지 않는다. 필요한 폴더는 먼저 생성한다. 큰 파일은 전체 내용을 메모리에 담는 대신 표준 Java 스트림·चॅनल_मूल्य API를 사용하는 방식으로 작성할 संख्या 있다.

### वर्ण: `मराठी.जावा.वर्ण`

| पद्धत_मूल्य | परतकरा_टाइप_करा | कृती·सशर्त |
|---|---|---|
| `संकेतन(String सामुग्री_मूल्य)` | `byte[]` | 문자열을 UTF-8 바이트로 रूपांतरकरा_मूल्य |
| `डिक्रिप्ट_करा_डेटा(byte[] सामुग्री_मूल्य)` | `String` | UTF-8 바이트를 문자열로 रूपांतरकरा_मूल्य. 잘못된 입력은 대체 문자로 प्रक्रिया_मूल्य_प्रविष्टी |
| `सामान्यीकरण_करा_मूल्य(String सामुग्री_मूल्य)` | `String` | युनिकोड_मूल्य NFC सामान्यीकरण_करा_मूल्य. 예: संयोजन_मूल्य हांगुलवर्णघटक_मूल्य `ᄀ` + `ᅡ` → `पहिले_संकार्य` |
| `वर्ण_कोड_संख्या(String सामुग्री_मूल्य)` | `int` | UTF-16 संहिता_मूल्य 단위가 아닌 युनिकोड_मूल्य संहिता_मूल्य 포인트 संख्या |
| `शाब्दिक_शब्द(String सामुग्री_मूल्य, Locale भाषा)` | `List<String>` | नेमा_मूल्य 언어의 `BreakIterator` शाब्दिक_शब्द 경계로 나눈 मजकूर_व्याप्ती |

`शाब्दिक_शब्द`은 공백·문장부호 구간도 반환한다. 자연어 형태소 분석기나 공백을 제거한 शब्द_मूल्य प्रविष्टी_यादी API는 아니다. `सामान्यीकरण_करा_मूल्य`는 입력기나 भाषांतर_करा_स्रोत 기능이 아니다. संहिता_मूल्य 포인트 संख्या 역시 사람이 보는 वर्ण_मूल्य 수와 항상 같지는 않다. 여러 संहिता_मूल्य 포인트로 이루어진 एकत्र_मूल्ये वर्ण·가족 이모지 등을 구분해야 한다.

### संचार: `मराठी.जावा.संचार`

| पद्धत_मूल्य | परतकरा_टाइप_करा | कृती·सशर्त |
|---|---|---|
| `घ्या_मूल्य(URI पत्ता, Duration वेळ_मर्यादा)` | `HttpResponse<String>` | HTTP(S) GET. जोडा 및 विनंती वेळ_मर्यादा संयोजना. प्रत्युत्तर_द्या 본문을 UTF-8로 मूल्य_पार्स_करा |
| `कनेक्ट_संचारटोक(String पत्ता, int हार्डवेअर_पॉर्ट, int मर्यादा_मिलिसेकंद)` | `Socket` | TCP जोडा नंतर_राज्य 같은 값으로 वाचन 제한시간도 संयोजना |

`घ्या_मूल्य`는 `IOException`, `InterruptedException`을 선언한다. 제한시간은 양수다. 404·500 같은 HTTP त्रुटी 상태도 응답으로 반환하므로 `statusCode()`로 판단하고 `body()`로 본문을 읽는다. सध्याचे_आयटम 구현은 호출마다 HTTP 클라이언트를 만들며 자동 리다이렉트 설정을 추가하지 않는다.

`कनेक्ट_संचारटोक`는 `IOException`을 선언한다. 연결된 소켓은 호출자가 `close()` 또는 try-with-resources로 닫아야 한다. 제한밀리초의 0은 मर्यादा_मूल्य 없음이며, लेखन 전체의 अंतिमवेळ_मूल्य 시간을 보장하는 옵션은 아니다.

```java
var प्रत्युत्तर_द्या = संचार.घ्या_मूल्य(
    java.net.URI.create("http://127.0.0.1:8000/"),
    java.time.Duration.ofSeconds(5));
System.out.println(प्रत्युत्तर_द्या.statusCode());
System.out.println(प्रत्युत्तर_द्या.body());
```

वरचे_मूल्य 조각은 पद्धत_मूल्य 안에서 실행하며 별도로 해당 주소의 서버를 실행해야 한다. Java अपवाद 처리가 필요하다.

### पारपाडा_कार्य: `मराठी.जावा.पारपाडा_कार्य`

| पद्धत_मूल्य | परतकरा_टाइप_करा | कृती·सशर्त |
|---|---|---|
| `सुरू_करा(String नाव, Runnable कृती)` | `Thread` | 이름을 지정한 스레드를 만들고 즉시 सुरू_करा |
| `प्रतीक्षाकरा(Thread कार्यसूत्र_मूल्य_5b72a632)` | `void` | 해당 스레드가 종료할 때까지 `join()` |
| `उर्वरित_क्षणभर(long मिलिसेकंद)` | `void` | 호출한 스레드를 नेमा_मूल्य वेळ_मूल्य 동안 `sleep()` |
| `कार्यपीठ_मूल्य(int कार्यसूत्र_संख्या)` | `ExecutorService` | 고정 आकार पारपाडा_कार्य अनुप्रयोग_चालक तयार_करा. 가닥수는 양수 |

`प्रतीक्षाकरा`, `उर्वरित_क्षणभर`는 `InterruptedException`을 선언한다. पारपाडा_कार्य 실행기는 वापर_मूल्य नंतर_राज्य `shutdown()`으로 종료하고 필요하면 `awaitTermination(...)`으로 완료를 기다린다. Swing 이벤트 प्रक्रिया_मूल्य_प्रविष्टी 가닥에서 긴 작업이나 `प्रतीक्षाकरा`를 실행하면 화면이 멈출 संख्या 있다.

### पडदा: `मराठी.जावा.पडदा`

| पद्धत_मूल्य | परतकरा_टाइप_करा | कृती·सशर्त |
|---|---|---|
| `नंतर_मूल्य(Runnable कृती)` | `void` | Swing 이벤트 प्रक्रिया_मूल्य_प्रविष्टी 가닥에 실행을 예약하고 परतकरा_मोजमाप |
| `विंडो(String विंडो_शीर्षक, JComponent सामुग्री_मूल्य, int रुंदी_मूल्य, int उंची_मूल्य)` | `JFrame` | सामुग्री_मूल्य·크기를 지정한 창을 생성해 मूल्य_शो |

`विंडो`을 Swing 이벤트 प्रक्रिया_मूल्य_प्रविष्टी कार्यसूत्र_मूल्य_5b72a632 밖에서 부르면 `IllegalStateException`이 발생한다. 그래픽 세션도 필요하다. QEMU에서는 VNC 데스크톱의 터미널에서 실행한다.

```java
पडदा.नंतर_मूल्य(() -> पडदा.विंडो(
    "मराठी पडदा", new javax.swing.JLabel("안녕하세요"), 500, 180));
```

반환된 `JFrame`에 표준 Swing API를 추가로 사용할 संख्या 있다. 창의 बंद_करा 동작은 `DISPOSE_ON_CLOSE`तिसरे_संकार्य. `पडदा.नंतर_मूल्य`पहिले_संकार्य 반환됐다고 विंडो 생성이 이미 끝난 것은 아니다.

### वर्कस्पेस: संपादन_मूल्य·स्रोत_बांधणी GUI

```sh
java -cp /opt/jkoros/lib/स्वकीय_जावा.jar मराठी.जावा.वर्कस्पेस
```

`~/workspace`의 원문을 उघडा·저장하고, `javac`로 컴파일해 `java`로 실행한다. आज्ञा_कार्यवाही_करा फाइल 만들기는 `jclassc --target openjdk` 경로를 사용한다. 작업마당은 개발용 프로그램이며 별도의 फाइल·वर्ण API 클래스가 아니다. 생성하는 आज्ञा_कार्यवाही_करा फाइल 방식은 [संकलक वर्णन](../compiler/OpenJDK-निष्पादनीय_संचिका.md)을 따른다.

| पद्धत_मोड | सध्याचे_आयटम घोषणाशीर्षे राज्य_मूल्य | आवाहन 가능 क्लिप |
|---|---|---|
| Java → मराठी JAR | डिफॉल्ट_मूल्य घोषणाशीर्षे | वरचे_मूल्य 22개 메서드와 वर्कस्पेस |
| Python → `java` उपघटक_मूल्य 프로세스 | Python·Java डिफॉल्ट_मूल्य घोषणाशीर्षे | 작은 Java 진입점을 통해 호출하고 표준 आउटपुट·फाइल 등으로 मोजमाप फॉरवर्ड_मूल्य |
| Python → JPype → JVM | JPype는 डिफॉल्ट_मूल्य 배포에 अनुपस्थित_पद्धत | 별도 स्थापित_करा_मूल्य नंतर_राज्य Java वर्ग_मूल्य·पद्धत_मूल्य आवाहन 가능. 이 배포판의 ARM64/musl/Python 3.14 조합은 शेवटीजोडा_प्रविष्टी प्रमाणित आवश्यक_मूल्य |
| C++ → JNI → JVM | `g++`, JNI 헤더, `libjvm.so` घोषणाशीर्षे | JVM을 생성하고 मराठी वर्ग_मूल्य·메서드를 직접 호출할 संख्या 있음 |
| Python용 독립 मराठी लायब्ररी | सध्याचे_आयटम डिफॉल्ट_मूल्य 제공 अनुपस्थित_पद्धत | 필요하면 Python 표준 라이브러리를 감싸는 मराठी 모듈을 별도로 작성 |
| C/C++용 독립 मराठी लायब्ररी | स्वकीय x86 `posix-kor`와 स्वकीय ARM64 커널용 प्रारंभिक_राज्य RAM फाइल 연결이 별도로 존재 | दोन_मूल्य तिसरे_संकार्य 이 Linux/OpenJDK 실행판의 libc 라이브러리는 아님 |

Python의 일반 `import`दुसरे_संकार्य `ctypes.CDLL`로 JAR를 바로 읽을 수는 없다. C++의 `#include`दुसरे_संकार्य 일반 네이티브 링커만으로 Java 메서드를 연결할 수도 없다. JVM 프로세스 또는 JVM जोडा 계층을 거쳐야 한다.

### Python: शेवटीजोडा_प्रविष्टी 패키지 없이 आवाहन

आज्ञा_कार्यवाही_करा 가능한 उदाहरणे 원문은 [मजकूर_आदेश.java](उदाहरणे/दुसरे_भाषा/मजकूर_आदेश.java), [पायथन_कॉल्स.py](उदाहरणे/दुसरे_भाषा/पायथन_कॉल्स.py)तिसरे_संकार्य. Python이 Java 진입점을 실행하고 `वर्ण.वर्ण_कोड_संख्या`의 पूर्णांक 결과를 받는다. बाबी 목록을 사용하며 शेल आदेश 문자열을 조립하지 않는다. `subprocess.run`의 프로세스 आज्ञा_कार्यवाही_करा·निर्गमन_करा_अनुप्रयोग संहिता_मूल्य·आउटपुट प्रक्रिया_मूल्य_प्रविष्टी 방식은 [Python 공식 मार्गदर्शिका](https://docs.python.org/3/library/subprocess.html)를 따른다.

두 उदाहरणे 파일을 게스트의 같은 폴더에 복사한 मागे_मूल्य 그 폴더에서 실행한다. उदाहरणे फाइल 자체는 डिफॉल्ट_मूल्य 시스템 이미지에 자동 설치돼 있지 않다.

```sh
mkdir -p classes
javac -encoding UTF-8 -cp /opt/jkoros/lib/स्वकीय_जावा.jar -d classes मजकूर_आदेश.java
python3 पायथन_कॉल्स.py --text 'हांगुल_मजकूर 😀'
```

आउटपुट: `Python → मराठी.जावा.वर्ण.वर्ण_कोड_संख्या: 4`

이 예제의 Python फलन_मूल्य `वर्ण_कोड_संख्या`는 이번 문서의 जोडा 예제이며 기존에 설치된 Python 라이브러리는 아니다. सध्याचे_आयटम 예제는 호출할 때마다 JVM 프로세스를 시작한다. Java ऑब्जेक्ट_मूल्य 자체를 Python으로 가져오는 방식은 아니며, 다른 메서드를 사용하려면 진입점의 बाबी·मोजमाप 형식을 확장한다.

### Python: JPype로 같은 프로세스에서 आवाहन

JPype를 별도 설치한 환경에서는 पुढील_आयटम 형태로 연결할 संख्या 있다. **아래는 निवड_मूल्य 가능한 जोडा 방법이며, सध्याचे_आयटम 배포판에 JPype가 설치돼 있거나 आज्ञा_कार्यवाही_करा 검증됐다는 뜻은 아니다.** JVM 시작과 `JClass`를 통한 वर्ग_मूल्य 접근은 [JPype 공식 वर्णन](https://jpype.readthedocs.io/en/latest/userguide.html)을 참고한다.

```python
import jpype

jpype.startJVM(
    "/usr/lib/jvm/java-25-openjdk/lib/server/libjvm.so",
    classpath=["/opt/jkoros/lib/स्वकीय_जावा.jar"])
try:
    वर्ण = jpype.JClass("मराठी.जावा.वर्ण")
    print(वर्ण.वर्ण_कोड_संख्या(jpype.JString("हांगुल_मजकूर 😀")))
finally:
    jpype.shutdownJVM()
```

Python·JVM·जोडा 모듈의 CPU 아키텍처가 맞아야 한다. 이 실행판은 ARM64 + musl이므로 일반 x86_64/glibc용 바이너리를 그대로 설치하는 방식은 맞지 않는다. JPype स्थापित_करा_मूल्य·패키지 빌드는 이번 मार्गदर्शिका 작업에서 수행하지 않았다.

### C++: JNI로 직접 आवाहन

[जावा_कॉल्स.cpp](उदाहरणे/दुसरे_भाषा/जावा_कॉल्स.cpp)는 वास्तविक_डेटा आज्ञा_कार्यवाही_करा 가능한 예제다. JVM을 पारपाडा_कार्य 스레드에서 생성하고 पुढील_आयटम 메서드를 찾는다.

```cpp
jclass type = env->FindClass("मराठी/जावा/वर्ण");
jmethodID method = env->GetStaticMethodID(
    type, "वर्ण_कोड_संख्या", "(Ljava/lang/String;)I");
```

JVM तयार_करा·종료와 스레드 연결은 [JNI Invocation API](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/invocation.html)의 방식이다. `JNIEnv*`는 तयार_करा·연결된 스레드에서 사용해야 한다. 예제는 Java 예외를 확인하고 JVM 종료까지 처리한다.

게스트에 `जावा_कॉल्स.cpp`를 복사한 मागे_मूल्य 컴파일한다. 로그인 환경의 `JAVA_HOME`은 `/usr/lib/jvm/java-25-openjdk`तिसरे_संकार्य.

```sh
g++ -std=c++11 -Wall -Wextra -pthread \
  -I"$JAVA_HOME/include" -I"$JAVA_HOME/include/linux" \
  जावा_कॉल्स.cpp -L"$JAVA_HOME/lib/server" \
  -Wl,-rpath,"$JAVA_HOME/lib/server" -ljvm -o जावा_कॉल्स
./जावा_कॉल्स /opt/jkoros/lib/स्वकीय_जावा.jar
```

आउटपुट: `C++ → मराठी.जावा.वर्ण.वर्ण_कोड_संख्या: 4`

예제는 `हांगुल_मजकूर 😀`을 UTF-16으로 만들어 `NewString`에 전달한다. `NewStringUTF`पहिले_संकार्य 받는 modified UTF-8은 일반 UTF-8과 차이가 있으므로, 일반 UTF-8 이모지 바이트를 그대로 넘기는 예제로 작성하지 않았다. [JNI स्ट्रींग_मूल्य स्वरूप_मूल्य](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/types.html#modified-utf-8-strings)

다른 मराठी 메서드도 JNI 서명과 बाबी 자료형을 맞춰 호출할 संख्या 있다. 예를 들어 `Path`를 받는 फाइल API는 먼저 `फाइल.मार्ग`로 Java मार्ग 객체를 얻어 전달한다. Swing 호출에는 그래픽 세션과 이벤트 प्रक्रिया_मूल्य_प्रविष्टी कार्यसूत्र_मूल्य_5b72a632 규칙도 그대로 적용된다. JNI는 Java 실행을 기계어로 대체하는 기능이 아니며 JVM이 पुढेचालूकरा_प्रक्रियाकरण 필요하다.

### 기존 posix-kor와의 관계

추가된 [स्वकीय ARM64 जोडा](../posix-kor/arm64-native/वापरमार्गदर्शिका_eb81d7d9.md)은 C++에서 AOT Java 커널의 RAM फाइल API를 직접 호출하며, 별도 EL0 प्रयोक्ता 라이브러리로 फाइल/UDP 루프백 SVC 호출도 제공한다. JNI를 사용하지 않는다. 이 문서의 ARM64 **Linux** 및 मराठी Java JAR와는 다른 आज्ञा_कार्यवाही_करा 기반이며 स्वकीय 커널은 별도 제한형 Java संकलक/JVM과 MicroPython 1.24.1을 실행한다. MicroPython의 `import jkoros`로 Java गाभा_मूल्य फाइल·UDP 루프백·आयत 호출이 가능하지만 이 문서의 JAR를 가져오는 기능은 아니다. स्वकीय 커널의 전체 OpenJDK/JRE/CPython 이식은 아직 미완성이다.

[posix-kor](../posix-kor/वापरमार्गदर्शिका_eb81d7d9.md)에는 `संचिका_उघडा`, `संचिका_डेटा_वाचा`, `संचिका_डेटा_लिहा`, `संचिका_मिटवा`, `संचारटोक_तयार_करा`, `स्वतंत्रसंदेश_डेटा_पाठवा` 등의 मराठी C 별칭이 있다. 그러나 구현은 **स्वकीय jkoros i386 커널의 `int 0x80` आवाहन 규약용**이다.

이 `libposix-kor.a`와 स्वकीय `sys/stat.h` 등의 헤더는 सध्याचे_आयटम ARM64 Linux 실행판의 libc/C++용 라이브러리가 아니다. 해당 헤더·바이너리를 ARM64 Linux 프로그램에 그대로 연결해서는 ABI가 맞지 않는다. C++용 मराठी वर्ग_मूल्य 라이브러리나 Python용 바인딩을 डिफॉल्ट_मूल्य 제공하는 상태도 아니다. सध्याचे_आयटम Linux 실행판에서 그와 같은 독립 API를 제공하려면 Linux 표준 라이브러리를 대상으로 별도로 अंमलबजावणी·빌드해야 한다.

## 5. पडताळा 범위와 재현

패키지 घोषणाशीर्षे 여부는 [वितरण_मूल्य 패키지 प्रविष्टी_यादी](../platforms/rpi4/dist/packages.lock.json) 및 सिस्टम_बांधणी 루트의 वास्तविक_डेटा 파일로 확인했다. JNI 헤더는 JDK의 `include/jni.h`, `include/linux/jni_md.h`, JVM 라이브러리는 `lib/server/libjvm.so`에 있다. 사용자가 नंतर_मूल्य_ee1d8655 별도로 설치한 패키지는 이 डिफॉल्ट_मूल्य वितरण_मूल्य 목록과 다를 संख्या 있다.

이번에 **होस्ट x86_64/OpenJDK 11에서** Python उपघटक_मूल्य 프로세스 호출과 C++ JNI 직접 호출을 स्रोत_बांधणी·실행해 각각 मोजमाप 4를 확인했다. JAR 공개 메서드도 소스와 대조했다. Python जोडा 예제는 शेवटीजोडा_प्रविष्टी 패키지를 설치하지 않는다.

문서의 Java वापर_मूल्य 예제도 स्रोत_बांधणी·실행했고, 22개 메서드의 मार्गदर्शिका घोषणाशीर्षे 여부와 로컬 मार्गदर्शिका 링크를 확인했다. [उदाहरणे प्रमाणित लॉग_नोंद](build/दुसरे_भाषा/पडताळणी_अहवाल.json)

기존 ARM64 QEMU에서는 Java의 फाइल·युनिकोड_मूल्य·스레드·HTTP 및 Swing चाचण्या 결과가 있다. 이번 Python/C++ जोडा 예제의 **ARM64 게스트 실행과 JPype 설치는 별도 검증하지 않았다.** 이미지와 आज्ञा_कार्यवाही_करा 중인 प्रयोक्ता 환경은 이 मार्गदर्शिका 작업에서 변경하지 않았다. [기존 संचालनप्रणाली प्रमाणित लॉग_नोंद](../platforms/rpi4/VERIFICATION.md)

호스트에서 Python 예제를 재현하려면:

```sh
cd /home/user/jkoros/स्वकीय_जावा
make
mkdir -p build/दुसरे_भाषा
javac -encoding UTF-8 --release 11 -cp build/स्वकीय_जावा.jar \
  -d build/दुसरे_भाषा उदाहरणे/दुसरे_भाषा/मजकूर_आदेश.java
python3 उदाहरणे/दुसरे_भाषा/पायथन_कॉल्स.py \
  --jar build/स्वकीय_जावा.jar --classes build/दुसरे_भाषा
```

होस्ट C++ 예제는 वरचे_मूल्य JNI स्रोत_बांधणी 명령의 JDK 경로를 **होस्ट JDK मार्ग**로 바꾸고, स्रोत `उदाहरणे/दुसरे_भाषा/जावा_कॉल्स.cpp`와 JAR `build/स्वकीय_जावा.jar`를 지정한다. ARM64 게스트 JDK의 헤더·लायब्ररी 경로를 होस्ट x86_64 링크 명령에 섞지 않는다.
