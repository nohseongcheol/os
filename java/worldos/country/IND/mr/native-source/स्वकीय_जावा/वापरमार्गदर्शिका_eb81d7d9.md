# मराठी Java सहायक_मूल्य_44c0808f लायब्ररी

OpenJDK 11 이상과 함께 쓰는 프로젝트 मालक_मूल्य API다. 표준 Java लायब्ररी 전체의 번역판을 뜻하지 않는다. 기존 Java API·키워드·अपवाद·자료형은 그대로 함께 쓴다.

전체 22개 सहायक_मूल्य_44c0808f 메서드의 बाबी·परतलेले_मूल्य·제약, संचालनप्रणाली 안의 사용법, Python·C++ आवाहन 방법은 **[मराठी लायब्ररी प्रयोक्ता_मार्गदर्शी](प्रयोक्ता_मार्गदर्शी.md)**에 정리했다. [Python आवाहन उदाहरणे](उदाहरणे/दुसरे_भाषा/पायथन_कॉल्स.py)와 [C++ JNI आवाहन उदाहरणे](उदाहरणे/दुसरे_भाषा/जावा_कॉल्स.cpp)도 제공한다.

`make`로 `build/स्वकीय_जावा.jar`를 만든다. `javac -encoding UTF-8 -cp build/स्वकीय_जावा.jar उदाहरणे/अभिवादन_ae353e94.java`로 예제를 컴파일한다. 실행은 `java -cp build/स्वकीय_जावा.jar:उदाहरणे अभिवादन_ae353e94`तिसरे_संकार्य.

`अभिवादन_ae353e94` 예제는 그래픽 화면이 없으면 फाइल·वर्ण·스레드 결과와 안내만 출력한다. Swing 창은 그래픽 세션에서 실행해야 한다. QEMU에서는 [그래픽 आज्ञा_कार्यवाही_करा वापरमार्गदर्शिका_eb81d7d9](../platforms/rpi4/README.md)의 `make run`으로 부팅한 मागे_मूल्य VNC 데스크톱의 터미널을 사용한다.

| वर्ग_मूल्य | 제공 기능 |
|---|---|
| फाइल | UTF-8 텍스트·बाइट_मूल्य वाचन/लेखन, 디렉터리·प्रविष्टी_यादी |
| वर्ण | UTF-8 रूपांतरकरा_मूल्य, NFC सामान्यीकरण_करा_मूल्य, संहिता_मूल्य 포인트 संख्या, 언어별 शाब्दिक_शब्द सीमा_मूल्य |
| संचार | HTTP(S) विनंती, 제한시간을 가진 TCP जोडा |
| पारपाडा_कार्य | 스레드 सुरू_करा·합류·प्रतीक्षा_करा_मूल्य, पारपाडा_कार्य अनुप्रयोग_चालक |
| पडदा | Swing 이벤트 처리와 विंडो तयार_करा |
| वर्कस्पेस | स्रोत संपादन_मूल्य·स्रोत_बांधणी·आज्ञा_कार्यवाही_करा·आज्ञा_कार्यवाही_करा फाइल तयार_करा पडदा |

`char`는 UTF-16 संहिता_मूल्य 단위이므로 이모지 등을 한 글자로 처리할 때 संहिता_मूल्य 포인트 또는 वर्ण सीमा_मूल्य API를 사용한다. 파일은 UTF-8로 저장한다. OpenJDK의 모든 Java2D/फॉन्ट_मूल्य/입력기 조합을 각각 검증한 것은 아니다.

이름은 सध्याचे_आयटम 의미가 분명한 मराठी 용례를 사용했다. 개별 명칭의 역사적 어원 검토를 완료했다고 주장하지 않는다. संसाधन_मूल्य 종료와 अपवाद 처리는 표준 API의 계약을 따른다.
