# निज ARM64 JVM 0.4와 नेपाली पुस्तकालय

नेपाली 통신·예외 사용법은 [नेपाली Java API](한국어자바/readme_फाइल_eb81d7d9.md), प्रकार्य_मान·변수·फाइल 이름의 변경과 어원 근거는 [명명 readme_फाइल_eb81d7d9](명명/readme_फाइल_eb81d7d9.md)를 참고한다.

JAR कार्यान्वयन_गर्नुहोस्_आदेश, 외부 IPv4 TCP/UDP, 별도 तथ्याङ्कित_मान 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 वस्तु_मान·Thread·Swing은 JVM 경로의 기능이며 AOT समर्थन_मान 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 कार्यान्वयन_गर्नुहोस्_आदेश**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK वर्ग_मान पुस्तकालय 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 वर्ग_मान·तथ्याङ्कित_मान तरिका_मान 중심이던 실행기를 वस्तु_मान·पुस्तकालय कार्यान्वयन_गर्नुहोस्_आदेश 기반으로 넓힌 것이다.

## 실행과 बनाउनुहोस्_स्रोत

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# निज कर्णेल_मान 안에서 स्रोत_वृक्ष बनाउनुहोस्_स्रोत → class कार्यान्वयन_गर्नुहोस्_आदेश, नेपाली API 호출
python3 उपकरणहरू/कार्यान्वयन_गर्नुहोस्_फाइल.py 시험/자바/한글소스.java

# वस्तु_मान·예외 등은 होस्ट JDK로 Java 8 class를 만든 후 निज 커널에서 कार्यान्वयन_गर्नुहोस्_आदेश
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 उपकरणहरू/कार्यान्वयन_गर्नुहोस्_फाइल.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 ट्रान्सफर_मान
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 उपकरणहरू/कार्यान्वयन_गर्नुहोस्_फाइल.py build/my-java/객체시험.class \
  --include build/my-java/वालपेपर_मान.class --include build/my-java/शाखा_मान.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.वर्ग_मान.class`라는 RAM फाइल 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.वर्ग_मान`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.वर्ग_मान`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar फाइल.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 नेपाली 클래스만 찾는다. 배포 नेपाली पुस्तकालय JAR는 होस्ट javac의 classpath로 사용하며, 같은 클래스가 प्रयोगकर्ता JVM ELF에도 पढनुहोस् 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 तथ्याङ्कित_मान तरिका_मान, int/boolean/char/String, सर्त·दोहर्_याउनु_मान, स्ट्रिङ_मान 결합, 일부 फाइल 스트림 등의 **निज 부분집합 컴파일러**다. वस्तु_मान 선언·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 निज JVM에서 실행한다. नेपाली API 중 출력·문자 스칼라 प्रकार्य_मान·फाइल पढनुहोस्/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] तर्क) throws Exception {
        नेपाली.निज.출력.लेख्नुहोस्_रेखा("안녕하세요😀");
        नेपाली.निज.출력.수쓰기(नेपाली.निज.문자.코드포인트수("한글😀"));
        नेपाली.निज.फाइल.लेख्नुहोस्("인사.txt", "한글 फाइल😀");
        नेपाली.निज.출력.लेख्नुहोस्_रेखा(नेपाली.निज.फाइल.पढनुहोस्("인사.txt"));
    }
}
```

컬렉션은 지정한 메서드만 제공하며 iterator/stream/पङ्_क्तिबद्ध_गर्नुहोस्_मान·प्रयोगकर्ता परिभाषा_मान equals/hashCode 콜백은 없다. 사전의 열쇠는 String/Integer/null 사용을 시험했다. UTF-16 코드 단위와 Unicode 코드 포인트 수는 구분한다. 한글 입력 조합·सामान्यकरण_गर्नुहोस्_मान·아랍어 조판·GUI 다국어 글꼴은 이 स्ट्रिङ_मान 지원과 별개다.

예외는 Throwable/Exception/RuntimeException, ArithmeticException, NullPointerException, IndexOutOfBoundsException/ArrayIndexOutOfBoundsException/StringIndexOutOfBoundsException, IllegalArgumentException/NumberFormatException/IllegalThreadStateException, IOException/FileNotFoundException, IllegalStateException, ClassCastException, NegativeArraySizeException, ArrayStoreException, UnknownHostException, SocketTimeoutException의 제한된 सिर्जना_गर्नुहोस्·कोटि_मान·처리를 제공한다. प्रयोगकर्ता परिभाषा_मान Throwable 상속, stack trace/cause/suppressed 예외, try-with-resources의 addSuppressed, 완전한 आरम्भिक त्रुटि 포장은 아직 없다. 잡히지 않은 예외는 현재 전체 Java 실행을 실패로 끝낸다.

## नेपाली API

독립 패키지 **`नेपाली.निज`**를 사용한다. Linux판 `नेपाली.자바`가 요구하는 NIO/Swing/HTTP API를 निज 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 वर्ग_मान नाम·तरिका_मान·तर्क·फाँट_मान·फाइल 이름에 한국어를 사용한다. 표준 Java वर्ग_मान 이름은 호환성을 위해 보존한다.

| वर्ग_मान | 공개 기능 | 이름의 의미 |
|---|---|---|
| 출력 | लेख्नुहोस्, लेख्नुहोस्_रेखा, 수쓰기 | 출력(出力): 내용을 바깥으로 내보냄 |
| 문자 | लम्बाइ_मान, 같음, टाँस्नुहोस्_पाठ, टुक्राउने_मान, पदच्छेद_गर्नुहोस्_पूर्ण_सङ्ख्या/लेख्नुहोस्_पूर्ण_सङ्ख्या_मान, 코드포인트수, 부호화/गुप्तलेखन_उल्टाउनुहोस्_लगत | 문자(文字), एनकोडिङ_मान(符號): 글의 단위와 그 값을 바이트로 나타내는 नियम_मान |
| फाइल | पढनुहोस्/लेख्नुहोस्(String नाम), 바이트읽기/लेख्नुहोस्_बाइट_मान | 널리 쓰는 प्रयोगकर्ता 용어를 보존; RAM 자료의 नाम |
| प्रविष्टि_सूची | 더하기, पढनुहोस्, बदल्नुहोस्_मान, 지우기, आकार, 비었는가, खाली_गर्नुहोस्_टिओसी | प्रविष्टि_सूची(目錄): 순서가 있는 प्रविष्टि_मान 모음 |
| शब्दकोष | 넣기, खोज_गर्नुहोस्_प्रविष्टि, 있는가, 지우기, आकार, खाली_गर्नुहोस्_टिओसी | शब्दकोष(辭典): 찾는 말인 열쇠에 값을 대응 |
| 작업 | चलाउनुहोस्(실행할일), 기다리기(작업가닥), स्थगन_गर्नुहोस्_कार्य, 살아있는가 | 작업 धागो_मान: 한 अनुप्रयोग_f5044b9b 안의 कार्यान्वयन_गर्नुहोस्_आदेश प्रवाह_मान |
| 통신 | खोल्नुहोस्, पठाउनुहोस्, 받기, समय_सकियो, बन्दगर्नुहोस् | 통신(通信), 전문(電文), पोर्ट_मान: लगत 교환·메시지·포트의 역할 |
| 화면 | 사각형, 지우기 | 화면(畫面): वास्तविक_लगत 그림을 표시하는 면 |
| कर्णेल_मान | 밀리초, 사각형 | निज JVM의 고정 native जडान; 일반 JNI는 아님 |

이 명명은 현재 기능을 설명하는 용어 선택이다. 기존 한국어에 없던 역사적 어원을 만들어 주장하지 않는다. फाइल_नाम_पाठ·식별자는 UTF-8 소스로 보관한다. `문자.गुप्तलेखन_उल्टाउनुहोस्_लगत`는 잘못된 UTF-8에 IllegalArgumentException을 던지며, `부호화`는 짝이 없는 서로게이트를 `?`로 바꾼다. `फाइल.पढनुहोस्`는 엄격한 UTF-8 복호화를 적용한다. 화면 색은 `빨강 | (초록 << 8) | (파랑 << 16)` 형식이다.

## कार्यान्वयन_गर्नुहोस्_आदेश 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(नेपाली वर्ग_मान 포함), class당 16 KiB·अचल_मान 풀 511항목, 전체 तरिका_मान/फाँट_मान 각각 512개. तरिका_मान 코드 8 KiB, स्थानीय_क्षेत्र 변수·피연산자 스택 각각 128슬롯, तर्क 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 कार्यान्वयन_गर्नुहोस्_आदेश 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- वस्तु_मान 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 वास्तविक_लगत 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 फाइल·대형 स्ट्रिङ_मान·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 आदेश 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 सन्झ्याल परिवर्तन_मोड 시 중단·재개한다. 일반 सर्भर_मान·계산의 무제한 실행은 아직 없다. 미지원 आदेश·स्रोत_मान 부족은 명시적인 오류로 종료한다.
- RAM फाइल 최대 64개, 파일당 16384바이트, मार्ग UTF-8 63바이트. RAM 디렉터리와 समान_मान/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 नेपाली class는 RAM फाइल 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 현재 경로에서 स्रोत_वृक्ष·वर्ग_मान·लगत 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 외부 IPv4를 제공한다. वास्तविक_लगत GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. 전문 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 कार्यान्वयन_गर्नुहोस्_आदेश 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 विन्यास_मान, 완전한 विन्यास_मान 공변성·인터페이스 तह_मान 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/गुप्तलेखन_लेख्नुहोस्_लगत/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 समर्थन_मान 부분집합은 아래 및 개발 매뉴얼을 참고한다. वर्ग_मान फाइल 전체 검증기·पहुँच_प्रविष्टि अनुमति_मान/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 सुरक्षित_गर्नुहोस्_मान 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM मान/वैध_गर्नुहोस्/वर्ग_मान 로더와 예외 모델 → 영속 VFS·mmap·घडी·원자 सञ्चालन_मान·वास्तविक_लगत 스레드/समक्रमित ABI → OpenJDK java.base 및 native पुस्तकालय 이식 → मोबाइल_मान 네트워크·TCP/IP → सन्झ्याल 시스템/फन्ट_मान/입력기·java.desktop → Java SE 호환성 시험. 현재 निज JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## वैध_गर्नुहोस्

`उपकरणहरू/자바가상기계시험.py`는 같은 Java 8 class 파일의 출력을 होस्ट OpenJDK `-Xverify:all`과 QEMU raspi4b निज 커널에서 비교한다. वस्तु_मान/상속/인터페이스·switch·विन्यास_मान, 예외/finally, 컬렉션/GC, Thread/잠금, नेपाली UTF-8/फाइल/컬렉션, वास्तविक_लगत UDP 루프백/시간 초과, 게스트 한글 स्रोत_वृक्ष बनाउनुहोस्_स्रोत, विन्यास_मान प्रकार_मान/उद्धरण_मान_37b3d3b1/फाइल 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 फाइल 거부 시험을 실행한다. UDP परियोजना_रूट 실행에는 होस्ट 루프백 소켓 권한이 필요하다.

`उपकरणहरू/부팅시험.py`는 कर्णेल_मान सुरक्षित_गर्नुहोस्_मान/회귀 시험과 별도로 नेपाली Java 화면 API가 वास्तविक_लगत 픽셀을 그렸는지도 QMP 화면 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. वास्तविक_लगत Pi4 हार्डवेयर_मान 부팅 시험과 전체 JDK 호환성 시험 결과는 아니다.


## JVM 0.3: 네트워크와 GUI विस्तार_मान

`Socket`/`ServerSocket` सिर्जना_गर्नुहोस्·जडान·accept·양방향 InputStream/OutputStream·close·EOF·시간 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 외부 अङ्क_मान IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 समाप्त_गर्नुहोस्_अंक 16개, Java 루프백 버퍼 1024바이트, 외부 TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. अन्तरक्रियाशील 이벤트 대기는 कार्यान्वयन_गर्नुहोस्_आदेश 기한을 갱신하고 टर्मिनल परिवर्तन_मोड 시 프로세스 상태를 भण्डार_गर्नुहोस्_मान·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

नेपाली `सन्झ्याल`, `विजेट`, `연결통신` 클래스를 배포 JAR와 निज JVM 내장 자원에 추가했다. 상세 तरिका_मान·제한·स्रोत_वृक्ष·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## नेपाली 객체의 직접 कार्यान्वयन_गर्नुहोस्_आदेश

`सन्झ्याल`, `लेबुल`, `पाठ_क्षेत्र`, `बटन`, `घटना_लाइन`, `동작알림`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. निज JVM의 वस्तु_मान सिर्जना_गर्नुहोस्,
ढाँचा_मान 검사, 화면 호출, घटना 큐, धागो_मान 스케줄러에 नेपाली 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 कार्यान्वयन_गर्नुहोस्_आदेश 경로도 유지한다.
नेपाली 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

निज 실행기의 नेपाली 진입점은 `public static void चलाउनुहोस्()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 नेपाली 진입점을 우선한다.
명령행 인수는 `실행인수.개수()`와 `실행인수.पाठ(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. तथ्याङ्कित_मान फाइल 예제는 게스트
javac로도 컴파일하며, GUI/धागो_मान 소스는 होस्ट `javac --release 8`을 사용한다.
직접 GUI/धागो_मान API는 निज JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
नेपाली 가닥의 कार्यान्वयन_गर्नुहोस्_आदेश·대기·중복 चलाउनुहोस् 거부, GUI घटना 출처·अनुक्रमणिका·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

तरिका_मान 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
नेपाली 클래스도 실행되지만, स्ट्रिङ_मान 리터럴·표준 पुस्तकालय 재정의·native
जडान·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 예제](한국어자바/readme_फाइल_eb81d7d9.md)를 참고한다.

## टर्मिनल 부분 ताजा_गर्नुहोस्

लैजानुहोस्_मान·आकार 변경은 새 सन्झ्याल 영역과 이전 자리에서 드러난 띠만 합성한다.
1920×32 पेल(240 KiB)의 임시 그림에서 배경·겹친 सन्झ्याल·वर्ण_मान·GUI를 먼저
완성하고, 현재 शो_मान 메모리와 비교하여 달라진 화소만 기록한다.
32줄보다 큰 영역은 여러 띠로 처리하므로 전체 프레임을 원자적으로
교체하거나 수직 동기에 맞추는 방식은 아니다. 전체 배경을 먼저 지우는
중간 화면은 표시하지 않는다. 좌표가 같으면 다시 그리지 않는다.

`make test-redraw`는 वास्तविक_लगत C 그리기 코드를 호스트의 मेमोरी_लगत 화면에 연결해
लैजानुहोस्_मान 80회·आकार परिवर्तन_मान 40회·겹친 सन्झ्याल 4개를 전체 합성 결과와 पेल 단위로 대조한다.
영역 밖 प्रयोगकर्ता चित्रकारी_मान, 동일 पेल 무기록, पोइन्टर 밑그림, वास्तविक_लगत 화면 रेखा 간격을
검사한다. 이 시험의 시간은 होस्ट CPU 측정이며 Pi 4/QEMU 속도로 해석하지 않는다.
`make test-resize`는 QEMU/VNC의 640×480 및 1920×1080에서 왼쪽 모서리 तान्नुहोस्_मान,
한글 입력·vi 미저장 सामग्री_मान·독립 सन्झ्याल 크기를 검사한다.
