# Raspberry Pi 4 자체 Java କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ — ଉପଭୋକ୍ତା ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 기반

현재 자체 코드의 COSL 상업 ସର୍ତ୍ତ, 제3자 고지 및 LGPL 재연결 자료는 [COSL 배포 ମତେପଢନ୍ତୁ_eb81d7d9](COSL배포안내.md)를 참고한다. ସୁଇଚ୍_ମୋଡ୍ 전 GPL 구성의 판단은 [이전 라이선스 검토](ଲାଇସେନ୍ସ_କରିବା_ସମୀକ୍ଷା.md)에 기록했다.

한국어 통신·ବ୍ୟତିକ୍ରମ 사용법은 [한국어 Java API](한국어자바/ମତେପଢନ୍ତୁ_eb81d7d9.md), Excel_ଟେବଲ୍_ମୂଲ୍ୟ·변수·ଫାଇଲ 이름의 변경과 어원 근거는 [명명 ମତେପଢନ୍ତୁ_eb81d7d9](명명/ମତେପଢନ୍ତୁ_eb81d7d9.md)를 참고한다.

Linux 없이 부팅하는 자체 AArch64 커널이다. Java AOT କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ 위에 **ନିର୍ଦ୍ଦେଶ_ରେଖା ଖୋଳ, 게스트 Java 컴파일러·JVM, MicroPython, EL0 C++ ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ, ଫାଇଲ·UDP 루프백 시스템 호출, 여러 한글 GUI ଟର୍ମିନାଲ·vi ସଂପାଦକ·Swing 부분집합**을 제공한다. 커널의 ଫାଇଲ ଡାଟା/정책·루프백 ସ୍ଥାନାନ୍ତର_ମୂଲ୍ୟ·ଖୋଳ 상태는 Java, 화면 합성·ପିକ୍ସେଲ୍ ପରିବର୍ତ୍ତନ_ମୂଲ୍ୟ·ପଏଣ୍ଟର୍·클리핑도 Java로 구현하며, CPU/MMU/ଡିଭାଇସ_ମୂଲ୍ୟ 경계와 ଟର୍ମିନାଲ·ବର୍ଣ୍ଣ_ମୂଲ୍ୟ 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 자체 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 ତାରଯୁକ୍ତ_ମୂଲ୍ୟ 송수신은 아직 미검증이다.** ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ·ସଂଯୋଗ_e05f319b·ପାସ୍_ୱାର୍ଡ୍_ମୂଲ୍ୟ 확인은 [외부 ସଂଯୋଗ_e05f319b ମତେପଢନ୍ତୁ_eb81d7d9](외부접속안내.md)에 정리했다.

셸은 EL1 କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ, `java` 등 ଉପଭୋକ୍ତା ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ·ସଂଯୋଗ_e05f319b 방법 및 ପ୍ରକୃତ_ଡାଟା 검증은
[ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 계층과 외부 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 ପ୍ରକୃତ_ଡାଟା ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 ସ୍ଥିର_ମୂଲ୍ୟ ELF는 `run --linux ଫାଇଲ୍_ନାମ_ପାଠ`으로 실행한다. [ELF·Linux ABI ସମର୍ଥନ_ମୂଲ୍ୟ 범위와 동일 바이너리 시험](실행파일규약.md).

GUI와 네트워크는 `python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ.py --desktop --network`로 함께 사용한다. Java·C·Python의 한국어 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 부팅 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 수 있다. Remmina에서 **F9/Shift+Space/한·영 କୀ_ମୂଲ୍ୟ**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·ପ୍ରକୃତ_ଡାଟା TCP/UDP·ଫାଇଲ ବାଇଟ୍_ମୂଲ୍ୟ·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java 창예제`로 한국어 Swing 예제를 실행한다. ଟର୍ମିନାଲ 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 현재 ସ୍ତମ୍ଭ_ମୂଲ୍ୟ·ଧାଡ଼ି_ମୂଲ୍ୟ 수를 보여 준다.

ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 버튼 화면은 5×7 영문 글꼴을 쓰며, ଟର୍ମିନାଲ 창은 Noto CJK/DejaVu에서 생성한 한글·Unicode 비트맵 글꼴을 쓴다. UART와 ପ୍ରକୃତ_ଡାଟା 프레임버퍼의 한글 표시를 시험한다. 루프백은 동일 କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ 내부의 전문 전달이며 IP 패킷을 Ethernet으로 내보내는 드라이버가 아니다. 바깥 IPv4는 lwIP TCP/UDP 스택으로 보조 UART SLIP 경로를 사용한다. `python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ.py --network`로 QEMU NAT를 연결하고 `ftpd start`로 서비스를 시작한다.

Java의 정확한 API·문법·ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 제한과 한국어 사용법은 [자체 JVM과 한국어 ଲାଇବ୍ରେରୀ](자바실행환경.md)에 정리했다. ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1 ଫାଇଲ/JAR 배포는 [한국어자바](한국어자바) 소스에서 재현한다. 기존 Linux판 `한국어.자바`와 별도인 `한국어.자체` 패키지다.

**vi·여러 ଓ୍ୱିଣ୍ଡୋ·Swing·한글 Java/Python/C/C++·posix-kor 예제는 [한글 개발 매뉴얼](개발안내.md)에 정리했다.**

GUI ଟର୍ମିନାଲ ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ·단축키·ଖୋଳ ନିର୍ଦ୍ଦେଶ·제한은 [셸과 ଟର୍ମିନାଲ 사용법](셸과터미널.md)에 정리했다.

## 현재 컴퓨터에서 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

ପ୍ରସ୍ଥାନ_ଅନୁପ୍ରୟୋଗ: **Ctrl+A ପରବର୍ତ୍ତୀ_ଆଇଟମ୍ X**. 게스트 C/AOT ଉପକରଣସମୂହ 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. ଆୟୋଜକ 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. 컴파일러 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/ପଥ/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` ସମର୍ଥନ_ମୂଲ୍ୟ 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ**한다. 기존 한 ବର୍ଣ୍ଣ_ମୂଲ୍ୟ 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 인수 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

| ନିର୍ଦ୍ଦେଶ | କାମ |
|---|---|
| `help` / `info` | ନିର୍ଦ୍ଦେଶ·ପ୍ରକୃତ_ଡାଟା 구현 ସ୍ଥିତି_ମୂଲ୍ୟ_e10195a1 |
| `ls` / `cat FILE` / `rm FILE` | RAM ଫାଇଲ ଏଣ୍ଟ୍ରି_ତାଲିକା·ବିଷୟ_ମୂଲ୍ୟ·삭제 |
| `vi FILE` | ଉପଭୋକ୍ତା 영역 vi 부분집합, 한글 ସଂପାଦନା_ମୂଲ୍ୟ·ସଞ୍ଚୟ_କରିବା_ମୂଲ୍ୟ·검색·되돌리기 |
| `edit FILE` | ଫାଇଲ 전체를 새로 입력; 단독 `.` 줄로 ସଞ୍ଚୟ_କରିବା_ମୂଲ୍ୟ, Ctrl-C로 ବାତିଲ୍_ସଂଚାଳନ |

| `gui` / `terminal` | ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 화면 / 한글 GUI ଟର୍ମିନାଲ; F12로 ଟର୍ମିନାଲ ଖୋଲନ୍ତୁ·ବନ୍ଦ_କରନ୍ତୁ |

예를 들어 `edit 인사.java`를 입력한 ପରବର୍ତ୍ତୀ_ଆଇଟମ୍ 아래 소스를 입력한다.

```java
public class 인사 { public static void main(String[] args) { int ମୂଲ୍ୟ = 7; System.out.println("한글=" + ମୂଲ୍ୟ); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 인사.java`, `java 인사`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. ବାତିଲ୍_ସଂଚାଳନ·잘못된 16진수·용량 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 ନିର୍ଦ୍ଦେଶ 인수는 최대 32개다. କ୍ୟୁଏଟ୍·백슬래시·ଖୋଳ 변수·파이프·리다이렉션 범위는 [ଖୋଳ 설명](셸과터미널.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, ଠିକଣା **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode 입력·명시적 ଲେପନ_କରିବା_ମୂଲ୍ୟ·ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ.py --desktop --network
# 다른 ହାର୍ଡୱେର୍_ପୋର୍ଟ: python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ.py --desktop --port 5903
```

종료는 실행한 ଆୟୋଜକ 터미널에서 Ctrl+C다. 기존 `python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. ପ୍ରକୃତ_ଡାଟା Pi4 USB 입력기는 아직 없으며, VNC ସଂଯୋଗ_କରନ୍ତୁ 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 ପ୍ରକୃତ_ଡାଟା C++/UDP ELF ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ, `Hello.java` ସଙ୍କଳନ_ଉତ୍ସ 후 JVM ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ, `hello.py` ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ, GUI ଟର୍ମିନାଲ 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 ଆଦାନ_ପ୍ରଦାନ_ଯୋଗ୍ୟ 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 ମୋମରୀ_ଡାଟା·CPU 문맥을 보관한다. ଖୋଳ·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

```sh
make image   # କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ, SD ବିଲ୍ଡ୍_ଚିତ୍ର, 부팅 ZIP, 사용자용 SDK
```

이미지는 확인된 공식 Pi 부팅 묶음에서 `start4.elf`, `fixup4.dat`, Pi4 DTB와 disable-bt overlay를 가져온다. Linux kernel/initramfs/rootfs는 넣지 않는다. 펌웨어·MicroPython·ଟର୍ମିନାଲ ଫଣ୍ଟ_ମୂଲ୍ୟ 라이선스와 ଫଣ୍ଟ_ମୂଲ୍ୟ 출처 해시도 동봉한다. ଫାଇଲ ସୃଷ୍ଟି_କରିବା 스크립트는 물리 디스크에 기록하지 않는다.

예비 microSD에 ବିଲ୍ଡ୍_ଚିତ୍ର ଲଗ୍_ଧାଡ଼ି 도구로 `.img`를 기록하거나 FAT32 부팅 파티션 최상위에 ZIP 내용을 푼다. ବିଲ୍ଡ୍_ଚିତ୍ର 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 ଡିଫଲ୍ଟ_ମାନ EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD ଫାଇଲ 구성·କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ 체크섬 검사와 물리 ବୋର୍ଡ୍ 부팅 검증은 별개다. MMU 사용 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 부팅 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 한국어 API 사용

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/파일예제.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int ଆରମ୍ଭ_ଉପଭୋକ୍ତା_ଅନୁପ୍ରୟୋଗ(int)`이다. ଉପଭୋକ୍ତା C++는 FP/SIMD를 사용할 수 있다. କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ C/Java AOT는 일반 레지스터만 사용하므로 ବ୍ୟତିକ୍ରମ ପ୍ରୋସେସ୍_ମୂଲ୍ୟ_ଏଣ୍ଟ୍ରି 중 ଉପଭୋକ୍ତା FP 상태를 건드리지 않는다. ଉପଭୋକ୍ତା ଏଣ୍ଟ୍ରି_ପଏଣ୍ଟ୍_ମୂଲ୍ୟ 시 FP 상태를 초기화하고 କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int ଆରମ୍ଭ_ଉପଭୋକ୍ତା_ଅନୁପ୍ରୟୋଗ(int) {
    int ଫାଇଲ = ଖୋଲିବା_ଫାଇଲ୍("인사.txt", ପଢିବା_ଲେଖିବା | 없으면만들기 | 내용비우기, 0600);
    if (ଫାଇଲ < 0) return 1;
    const char ବିଷୟ_ମୂଲ୍ୟ[] = "안녕하세요";
    int ମାପ = ଲିଖନ_ଫାଇଲ୍_ଡାଟା(ଫାଇଲ, ବିଷୟ_ମୂଲ୍ୟ, sizeof(ବିଷୟ_ମୂଲ୍ୟ) - 1);
    ବନ୍ଦ_ଫାଇଲ୍(ଫାଇଲ);
    return ମାପ == sizeof(ବିଷୟ_ମୂଲ୍ୟ) - 1 ? 0 : 2;
}
```

[ଫାଇଲ 예제](ଉପଭୋକ୍ତା/파일예제.cpp)와 [통신 예제](ଉପଭୋକ୍ତା/통신예제.cpp)가 ପ୍ରକୃତ_ଡାଟା 부팅 시험 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 ଫାଇଲ ପ୍ରୋସେସ୍_ମୂଲ୍ୟ_ଏଣ୍ଟ୍ରି 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 소켓 함수는 현재 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 ପରବର୍ତ୍ତୀ_ଆଇଟମ୍ 도구를 사용하면 **새 QEMU를 부팅해 업로드한 ପ୍ରକୃତ_ଡାଟା 바이트를 재확인한 ପଛ_ମୂଲ୍ୟ 게스트에서 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ଫାଇଲ୍.py build/jkoros-native-sdk/demo.elf
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ 묶음에 포함되어 이 ଫାଇଲ 한도를 적용받지 않는다. **C++ 컴파일러는 ଆୟୋଜକ SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 ଲାଇବ୍ରେରୀ, PT_TLS, PT_INTERP, PT_DYNAMIC, ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ·ଲେଖନ୍ତୁ 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 ଅନୁକ୍ରମଣିକା·ଠିକଣା କ୍ଲିପ୍·오류는 [ଉପଭୋକ୍ତା ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `파일저장확정`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 ଅନୁମତି_ମୂଲ୍ୟ·dup/fcntl은 없다. 디렉터리와 ସମକକ୍ଷ_ମୂଲ୍ୟ/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, 수신 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. ଉପଭୋକ୍ତା ପ୍ରସ୍ଥାନ_ଅନୁପ୍ରୟୋଗ 시 열린 ଫାଇଲ 서술자와 소켓을 회수한다.

## Java와 Python의 정확한 କ୍ଲିପ୍

자체 `javac`는 버전 49 `.class`를 생성하며 JVM은 ସମର୍ଥନ_ମୂଲ୍ୟ 명령으로 구성된 버전 45–52 클래스를 실행한다. ସ୍ଥିର_ମୂଲ୍ୟ Excel_ଟେବଲ୍_ମୂଲ୍ୟ·재귀·int/boolean/char/String·ସର୍ତ୍ତ/ବାରମ୍ବାର_ମୂଲ୍ୟ·ଷ୍ଟ୍ରିଂ_ମୂଲ୍ୟ 결합과 일부 ଫାଇଲ 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/조합 자모 식별자를 처리한다. Unicode ପରିଚାୟକ_ମୂଲ୍ୟ 전체 ଦୃଷ୍ଟିପାତ_ସାରଣୀ·Unicode ଉତ୍ସ_ବୃକ୍ଷ 이스케이프는 구현하지 않았다. 게스트 ଉତ୍ସ_ବୃକ୍ଷ 컴파일러는 일반 ଅବଜେକ୍ଟ_ମୂଲ୍ୟ·ବ୍ୟତିକ୍ରମ·Thread 구문을 아직 컴파일하지 못한다. ଆୟୋଜକ `javac --release 8`로 만든 ସମର୍ଥନ_ମୂଲ୍ୟ 부분집합 클래스는 자체 JVM 0.4의 ଅବଜେକ୍ଟ_ମୂଲ୍ୟ·ବ୍ୟତିକ୍ରମ·Thread·UDP와 한국어 API를 사용할 수 있다. Swing은 문서화한 자체 API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [자체 JVM 설명](자바실행환경.md)이 기준이다. 상세 ଭାଷା 범위는 [공유 Java ଉପକରଣସମୂହ 설명](../../문서/자바개발환경.md)을 참고하되, 그 문서의 x86 ଖୋଳ/ସଞ୍ଚୟ_କରିବା_ମୂଲ୍ୟ/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 ଉତ୍ସ_ବୃକ୍ଷ**를 자체 AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 Excel_ଟେବଲ୍_ମୂଲ୍ୟ·ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1·ବ୍ୟତିକ୍ରମ·리스트/ଅଭିଧାନ·Unicode·GC·가변 정밀도 정수를 제공한다. 현재 구성은 ଇଣ୍ଟିଜର 빌드로 `float`, `complex`, `math`가 없으며 CPython 전체 표준 ଲାଇବ୍ରେରୀ, pip, subprocess, threading, 일반 socket과 ଡିଫଲ୍ଟ_ମାନ `open()` ଫାଇଲ 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 ଅବଜେକ୍ଟ_ମୂଲ୍ୟ·모듈은 ପ୍ରସ୍ଥାନ_ଅନୁପ୍ରୟୋଗ 시 회수되고 RAM 파일만 ପରବର୍ତ୍ତୀ_ଆଇଟମ୍ 실행에 남는다.

`import jkoros`로 ପରବର୍ତ୍ତୀ_ଆଇଟମ୍ 시스템 연결을 쓴다. 모두 SVC를 통해 자체 Java 커널에 접근한다.

| Excel_ଟେବଲ୍_ମୂଲ୍ୟ | କାମ |
|---|---|
| `stdin(limit)` | 현재 표준 입력에서 최대 limit바이트(0…16384)를 bytes로 읽음; EOF는 빈 bytes, UART ଡାଟା 없음은 OSError(11) |
| `read(name)` | ସମକକ୍ଷ_ମୂଲ୍ୟ/절대 RAM 경로의 ଫାଇଲ 전체를 bytes로 읽음 |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 ସଞ୍ଚୟ_କରିବା_ମୂଲ୍ୟ, 쓴 ବାଇଟ୍_ମୂଲ୍ୟ 수 반환 |
| `remove(name)` | RAM ଫାଇଲ 삭제 |
| `rect(x, y, w, h, color)` | 선택한 ପ୍ରକୃତ_ଡାଟା 화면 ଆକାର 안의 사각형 ଅଙ୍କନ_ମୂଲ୍ୟ; 기존 보드의 RGB32 ମୂଲ୍ୟ |
| `ticks_ms()` | 부팅 후 밀리초, 32비트 ଚକ୍ରାକାର_ମୂଲ୍ୟ |
| `udp_open(port)` | 127.0.0.1의 UDP 소켓 ଖୋଲନ୍ତୁ/묶기; 0은 자동 ହାର୍ଡୱେର୍_ପୋର୍ଟ |
| `udp_send(fd, port, data)` | 루프백 ଲକ୍ଷସ୍ଥଳ_ମୂଲ୍ୟ 포트에 str/bytes 버퍼 ସ୍ଥାନାନ୍ତର_ମୂଲ୍ୟ |
| `udp_recv(fd)` | `(bytes, 보낸포트)` 반환; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | 소켓 ବନ୍ଦ_କରନ୍ତୁ |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```

이식 코드: [python/](파이썬연결/), [ଉପଭୋକ୍ତା Java ସଂଯୋଗ_କରନ୍ତୁ](ଉପଭୋକ୍ତା/자바연결.c). 공식 [MicroPython 이식 ମତେପଢନ୍ତୁ_eb81d7d9](https://docs.micropython.org/en/latest/develop/porting.html)를 참고했다. ଉତ୍ସ_ବୃକ୍ଷ URL·ହାସ୍_ଫାଇଲ୍·라이선스는 [vendor ମତେପଢନ୍ତୁ_eb81d7d9](vendor/README.md)에 기록했다.

| CPython | 해당 libc와 OS API 대상으로 이식·교차 빌드하고 ଫାଇଲ/Unicode/스레드/소켓 시험 |
| OpenJDK/JRE | HotSpot OS ସ୍ତର_ମୂଲ୍ୟ, GC/JIT/스레드/신호/동적 연결과 Java 네이티브 ଲାଇବ୍ରେରୀ 이식; javac/java ପ୍ରକୃତ_ଡାଟା ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ |
| 외부 네트워크 | 추가한 GENET/PHY·DHCP 드라이버의 ପ୍ରକୃତ_ଡାଟା ବୋର୍ଡ୍ 송수신 ବୈଧକରଣ, DNS·Wi-Fi |
| GUI ଏକ୍ସଟେନସନ୍_ମୂଲ୍ୟ | USB HID, 게스트 입력기·문자 조판, Swing ଓ୍ୱିଣ୍ଡୋ ଆକାର 조절·클리핑 ଏକ୍ସଟେନସନ୍_ମୂଲ୍ୟ, 전체 AWT/Swing 이식 |

## 한국어 C ଡାଟା_ପ୍ରକାର·Python ତ୍ରୁଟି·ବଣ୍ଡଲ୍ ସଂସ୍ଥାପନ_ମୂଲ୍ୟ

C 네트워크 API는 `struct 인터넷통신주소`, enum 상수와 ପ୍ରକୃତ_ଡାଟା 한국어 함수로
구현한다. ମାକ୍ରୋ_ମୂଲ୍ୟ 별칭을 사용하지 않으며 이전 pk_* ABI도 유지한다.
Python 예제는 `ସିଷ୍ଟମ_ତ୍ରୁଟି`, `ତ୍ରୁଟି.ଅନୁକ୍ରମଣିକା`, `ତ୍ରୁଟି.설명`을 사용한다.

`python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ.py --desktop --network --pip`로 시작하면 게스트에서
`pip install micropython-bisect==3.3.3`을 사용할 수 있다. 현재는 ଆୟୋଜକ 중계를
이용하는 제한형 MicroPython ଉତ୍ସ_ବୃକ୍ଷ 설치기이며 CPython pip·자동 의존성 해결·C 확장은
미지원이다. 설치한 `/lib` 자료는 RAM이다. [사용법과 제한](파이썬꾸러미.md).

## 화면 ଆକାର ଚୟନ_ମୂଲ୍ୟ

`python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ.py --desktop --network --resolution 1920x1080`으로 Full HD 화면을 사용한다. 기본값은 640×480이며 1280×720도 가능하다. ଟର୍ମିନାଲ ଘୁଞ୍ଚାଇବା_ମୂଲ୍ୟ, Swing 가운데 ଲିଙ୍କ୍_ଲେଆଉଟ୍, Java·C·Python 그리기도 ପ୍ରକୃତ_ଡାଟା 크기를 따른다. SD 영상은 `make image RESOLUTION=1920x1080`으로 만든다. [ବିନ୍ଯାସ·한국어 API·ବୈଧକରଣ ମତେପଢନ୍ତୁ_eb81d7d9](화면해상도.md).

## 한국어 직접 API와 화면 ସତେଜ_କରନ୍ତୁ

`example/java`는 `실행할일`, `동작받이`, `동작알림`, `ବଟନ୍`, `ଘଟଣା_ପ୍ରତିଧାଡ଼ି`,
`작업가닥`, `ଚଳାନ୍ତୁ()`을 사용할 수 있다. 한국어 GUI/가닥을 자체 JVM에 직접
연결했으며, 표준 Swing/Thread를 감싸지 않는다. ଷ୍ଟ୍ରିଂ_ମୂଲ୍ୟ 등 javac의 표준
계약과 전체 ଉତ୍ସ_ବୃକ୍ଷ 검토 범위는 [명명 ମତେପଢନ୍ତୁ_eb81d7d9](명명/ମତେପଢନ୍ତୁ_eb81d7d9.md), 사용법과 호환성 변경은
[한국어 Java API](한국어자바/ମତେପଢନ୍ତୁ_eb81d7d9.md)를 본다.

ଟର୍ମିନାଲ ଘୁଞ୍ଚାଇବା_ମୂଲ୍ୟ·ଆକାର 변경은 바뀐 영역만 합성하고 달라진 화소만 표시한다.
[화면 ସତେଜ_କରନ୍ତୁ 설명](자바실행환경.md#ଟର୍ମିନାଲ-부분-ସତେଜ_କରନ୍ତୁ),
