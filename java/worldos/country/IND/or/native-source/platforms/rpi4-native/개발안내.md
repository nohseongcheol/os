# 자체 커널에서 vi·여러 ଟର୍ମିନାଲ·한글 프로그래밍 사용하기

한국어 통신·ବ୍ୟତିକ୍ରମ 사용법은 [한국어 Java API](한국어자바/ମତେପଢନ୍ତୁ_eb81d7d9.md), Excel_ଟେବଲ୍_ମୂଲ୍ୟ·변수·ଫାଇଲ 이름의 변경과 어원 근거는 [명명 ମତେପଢନ୍ତୁ_eb81d7d9](명명/ମତେପଢନ୍ତୁ_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 자체 AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 ସମର୍ଥନ_ମୂଲ୍ୟ 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ, 외부 TCP/UDP와 FTP는 [새 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 ଟର୍ମିନାଲ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, ଠିକଣା **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 ଟର୍ମିନାଲ 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **오른쪽 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 버튼으로 다시 ସ୍ତମ୍ଭ_ମୂଲ୍ୟ 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 현재 디렉터리, ଖୋଳ 변수, ନିର୍ଦ୍ଦେଶ ଲଗ୍_ଧାଡ଼ି, 입력 중인 명령과 ଅନୁପ୍ରୟୋଗ_f5044b9b ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 상태를 보관한다. ଫାଇଲ 저장소는 공유한다. vi와 Swing의 이벤트 ଅପେକ୍ଷା_ମୂଲ୍ୟ 중에 다른 터미널로 전환하면 ଉପଭୋକ୍ତା ମୋମରୀ_ଡାଟା·레지스터·ଫାଇଲ/소켓 연결을 보존했다가 돌아올 때 재개한다. **현재 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 ପରବର୍ତ୍ତୀ_ଆଇଟମ୍ 입력 ଅପେକ୍ଷା_ମୂଲ୍ୟ 또는 기존 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 ସଂପାଦନା_ମୂଲ୍ୟ 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. 현재 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 ଓ୍ୱିଣ୍ଡୋ 판단은 게스트 커널이 처리한다. QEMU ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. ପ୍ରକୃତ_ଡାଟା Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI ଉପକରଣସମୂହ 종료는 ଆୟୋଜକ 터미널의 Ctrl+C다.

## vi 사용

```text
mkdir 작업
cd 작업
vi 인사.py
```

`vi`는 새로 구현한 **vi ନିର୍ଦ୍ଦେଶ 부분집합** 편집기다. 내장 `build/user/vi.elf`를 보호된 ଉପଭୋକ୍ତା 영역에 적재한다. ଫାଇଲ 크기는 UTF-8 ବାଇଟ୍_ମୂଲ୍ୟ ପ୍ରୋଜେକ୍ଟ୍_ରୁଟ୍ 16 KiB, 경로는 63바이트까지다. 디스크에 설치한 Vim/Neovim 바이너리를 실행하는 것이 아니다.

| କୀ_ମୂଲ୍ୟ/ନିର୍ଦ୍ଦେଶ | କାମ |
|---|---|
| `i`, `a`, `I`, `A` | 현재/ପରବର୍ତ୍ତୀ_ଆଇଟମ୍ ଅବସ୍ଥାନ 또는 ରେଖା 처음/끝에서 입력 |
| `o`, `O` | 아래/위에 새 줄을 만들고 입력 |
| Esc | 일반 ମୋଡ୍_ମୂଲ୍ୟ |
| `h j k l`, 방향키 | UTF-8 문자/ରେଖା ଘୁଞ୍ଚାଇବା_ମୂଲ୍ୟ |
| `0`, `$`, Home, End | ରେଖା 처음/끝 |
| `gg`, `G`, `:ଅନୁକ୍ରମଣିକା` | ଫାଇଲ 처음/마지막 ରେଖା/ନ୍ୟସ୍ତ_କରିବା_ମୂଲ୍ୟ ରେଖା |
| PgUp, PgDn | 화면 ଶିକ୍ଷା_ମୂଲ୍ୟ ଘୁଞ୍ଚାଇବା_ମୂଲ୍ୟ |
| `x`, Delete | 현재 문자 삭제 |
| `dd`, `yy`, `p` | ରେଖା 삭제/କପି_ମୂଲ୍ୟ/ଲେପନ_କରିବା_ପାଠ |
| `u` | 마지막 편집을 되돌림; 한 ଷ୍ଟେଜ୍_ମୂଲ୍ୟ 토글 |
| `/ଷ୍ଟ୍ରିଂ_ମୂଲ୍ୟ`, `n` | 단순 ଷ୍ଟ୍ରିଂ_ମୂଲ୍ୟ 검색/ପରବର୍ତ୍ତୀ_ଆଇଟମ୍ 일치; 정규식 없음 |
| `:w`, `:w 다른이름` | RAM ଫାଇଲ ସଞ୍ଚୟ_କରିବା_ମୂଲ୍ୟ/다른 경로로 ସଞ୍ଚୟ_କରିବା_ମୂଲ୍ୟ |
| `:q` | 변경이 없을 때 ପ୍ରସ୍ଥାନ_ଅନୁପ୍ରୟୋଗ |
| `:q!` | 변경을 버리고 ପ୍ରସ୍ଥାନ_ଅନୁପ୍ରୟୋଗ |
| `:wq`, `ZZ` | 저장하고 ପ୍ରସ୍ଥାନ_ଅନୁପ୍ରୟୋଗ |

붙여 넣은 한글을 문자 경계에 맞춰 ଘୁଞ୍ଚାଇବା_ମୂଲ୍ୟ·삭제한다. 일반 vi의 수량 접두사, ମାକ୍ରୋ_ମୂଲ୍ୟ, ବିନ୍ଯାସ ଫାଇଲ, 플러그인, 정규식, 여러 버퍼/분할 ଓ୍ୱିଣ୍ଡୋ, 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/영 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 ଓ୍ୱିଣ୍ଡୋ ଓ୍ୱିଣ୍ଡୋ_ଟାଇଟେଲ୍ `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 ନିର୍ଦ୍ଦେଶ**으로 실행한다. 파이프·리다이렉션·ସ୍କ୍ରିପ୍ଟ_ମୂଲ୍ୟ·`;`/`&&`/`||`로 연결한 실행에서 ଆଦାନ_ପ୍ରଦାନ_ଯୋଗ୍ୟ 대기를 시작하면 거부한다. 입력 대기는 약 2초 CPU 기한을 갱신하지만 입력 ଅପେକ୍ଷା_ମୂଲ୍ୟ 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## 한글 Java

vi에서 다음을 `인사.java`에 입력하고 Esc → `:wq`로 저장한다.

```java
public class 인사 {
    static int 더하기(int 첫째, int 둘째) { return 첫째 + 둘째; }
    public static void main(String[] 인수) {
        int 합계 = 더하기(20, 22);
        System.out.println("안녕하세요 · 합계=" + 합계);
    }
}
```

게스트 셸에서 실행한다.

```text
javac 인사.java
java 인사
```

한글 ଫାଇଲ୍_ନାମ_ପାଠ·ଶ୍ରେଣୀ_ନାମ·ପଦ୍ଧତି_ନାମ_ପାଠ·변수명·문자열을 사용할 수 있다. **게스트 javac는 ସ୍ଥିର_ମୂଲ୍ୟ Java 부분집합**이다. ଅବଜେକ୍ଟ_ମୂଲ୍ୟ·리스너·Swing·소켓을 사용하는 소스는 현재 ଆୟୋଜକ JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 자체 JVM에 class를 올린다. 자체 JVM에서 지원하는 바이트코드/API 범위는 [자바실행환경.md](자바실행환경.md)를 따른다.

```sh
# ଆୟୋଜକ
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/스윙시험.java
python3 ଉପକରଣସମୂହ/ଅପଲୋଡ୍_ଫାଇଲ୍_ଗୁଡିକ.py build/my-java/스윙시험.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. ନିର୍ଗମ 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1.class` 형식이다. 내장 한국어 라이브러리는 별도 업로드가 필요 없다. 한국어 ଓ୍ୱିଣ୍ଡୋ API의 예제는 [한글창시험.java](시험/자바/한글창시험.java)이며 같은 방법으로 ସଙ୍କଳନ_ଉତ୍ସ·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 ଉତ୍ସ_ବୃକ୍ଷ/클래스는 호스트의 `python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ଫାଇଲ୍.py ପଥ/인사.java`로 별도 QEMU에 업로드·ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ·종료할 수 있다. ଆଦାନ_ପ୍ରଦାନ_ଯୋଗ୍ୟ Swing에는 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 후 ଉପଭୋକ୍ତା 입력을 유지하는 `make desktop`을 사용한다.

## 자체 JVM의 Swing କ୍ଲିପ୍

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 자체 Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | କାମ |
|---|---|
| `JFrame` | ଓ୍ୱିଣ୍ଡୋ_ଟାଇଟେଲ୍, ଆକାର·ଅବସ୍ଥାନ, ପ୍ରଦର୍ଶନ_କରିବା_ଓ୍ୱିଣ୍ଡୋ, ବନ୍ଦ_କରନ୍ତୁ 정책, dispose |
| `JPanel` | ଶିଶୁ_ମୂଲ୍ୟ 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 ଷ୍ଟ୍ରିଂ_ମୂଲ୍ୟ ପ୍ରଦର୍ଶନ_କରିବା_ମୂଲ୍ୟ·ପରିବର୍ତ୍ତନ_ମୂଲ୍ୟ |
| `JButton` | 버튼과 ActionListener କ୍ଲିକ୍_କରିବା_ମୂଲ୍ୟ ପ୍ରୋସେସ୍_ମୂଲ୍ୟ_ଏଣ୍ଟ୍ରି |
| `JTextField` | 한 ରେଖା UTF-8 입력, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 자체 JVM의 단일 이벤트 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. ଓ୍ୱିଣ୍ଡୋ·요소는 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 하나당 합계 32개, ଉପାଦାନ_ମୂଲ୍ୟ 글자는 최대 127 코드포인트다. ଡିଫଲ୍ଟ_ମାନ 서체와 색은 커널이 제공한다.

[스윙시험.java](시험/자바/스윙시험.java)는 ଓ୍ୱିଣ୍ଡୋ·한글 ଟ୍ୟାଗ୍_ମୂଲ୍ୟ·ପାଠ୍ୟ_କ୍ଷେତ୍ର·버튼·이벤트 처리의 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 가능한 예제다. [자체 Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

한국어 라이브러리에는 다음을 추가했다. ଆୟୋଜକ ସଙ୍କଳନ_ଉତ୍ସ 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `한국어.자체.ଓ୍ୱିଣ୍ଡୋ`: `ଯୋଡ଼ିବା_ଉପାଦାନ`, `ପ୍ରଦର୍ଶନ_କରିବା_ଓ୍ୱିଣ୍ଡୋ`, `ବନ୍ଦ_କରନ୍ତୁ`.
- `한국어.자체.ୱିଜାର୍ଡ୍`: `ଟ୍ୟାଗ୍_ମୂଲ୍ୟ`, `ବଟନ୍`, `ପାଠ୍ୟ_କ୍ଷେତ୍ର` ସୃଷ୍ଟି_କରିବା.
- `한국어.자체.연결통신`: `ସଂଯୋଗ_କରନ୍ତୁ`, `듣기`, `받기`.
- 기존 `ନିର୍ଗମ`, `문자`, `ଫାଇଲ`, `작업`, `ଏଣ୍ଟ୍ରି_ତାଲିକା`, `ଅଭିଧାନ`, `통신`, `화면`, `କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ 내부 연결형 ବାଇଟ୍_ମୂଲ୍ୟ ଷ୍ଟ୍ରିମ୍_ମୂଲ୍ୟ**을 추가했다. ଫାଇଲ/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket ସର୍ଭର୍_ମୂଲ୍ୟ = new java.net.ServerSocket(9250);
java.net.Socket ଅତିଥି_ମୂଲ୍ୟ = new java.net.Socket("localhost", 9250);
java.net.Socket ସଂଯୋଗ_କରନ୍ତୁ = ସର୍ଭର୍_ମୂଲ୍ୟ.accept();
ଅତିଥି_ମୂଲ୍ୟ.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int ଦୈର୍ଘ୍ୟ_ମୂଲ୍ୟ = ସଂଯୋଗ_କରନ୍ତୁ.getInputStream().read(받은것);
ସଂଯୋଗ_କରନ୍ତୁ.close(); ଅତିଥି_ମୂଲ୍ୟ.close(); ସର୍ଭର୍_ମୂଲ୍ୟ.close();
```

ସୃଷ୍ଟି_କରିବା·ସଂଯୋଗ_କରନ୍ତୁ·accept·양방향 ବାଇଟ୍_ମୂଲ୍ୟ/ଆରେ_ମୂଲ୍ୟ ଇନପୁଟ୍_ଆଉଟପୁଟ୍·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 ଶେଷ_କରନ୍ତୁ_ପଏଣ୍ଟ୍ 16개, 수신 버퍼당 1024바이트, ଅପେକ୍ଷା_ମୂଲ୍ୟ ସଂଯୋଗ_କରନ୍ତୁ 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. ଡିଫଲ୍ଟ_ମାନ ସମୟ_ମୂଲ୍ୟ 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM ନିର୍ଦ୍ଦେଶ 수/କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 기한은 여전히 적용된다.

외부 ଅଙ୍କ_ମୂଲ୍ୟ IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. ପ୍ରକୃତ_ଡାଟା Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP ଲାଇବ୍ରେରୀ 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 ପ୍ରକୃତ_ଡାଟା 송수신·EOF·기한·ସଂଯୋଗ_କରନ୍ତୁ 회수의 시험 예제다.

## 한글 Python

게스트 vi에서 한글 이름을 사용해 작성한다.

```python
ମୂଲ୍ୟ = 21

def 두배(ଅଙ୍କ_ମୂଲ୍ୟ):
    return ଅଙ୍କ_ମୂଲ୍ୟ * 2

print("ମାପ:", 두배(ମୂଲ୍ୟ))
```

ସଞ୍ଚୟ_କରିବା_ମୂଲ୍ୟ 후 `python 인사.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 Excel_ଟେବଲ୍_ମୂଲ୍ୟ·변수·ଫାଇଲ 이름과 문자열을 한글로 쓴다.

[한국어.py](예제/한글코딩/한국어.py)를 같은 디렉터리에 두면 ପରବର୍ତ୍ତୀ_ଆଇଟମ୍ 별칭을 사용할 수 있다.

```python
import 한국어
한국어.ଲିଖନ_ଫାଇଲ୍("인사.txt", "안녕하세요")
한국어.ନିର୍ଗମ(한국어.파일읽기("인사.txt").decode())
```

ନିର୍ଗମ·ଫାଇଲ ପଢନ୍ତୁ/ଲେଖନ୍ତୁ/삭제·표준 입력·사각형·ସମୟ_ମୂଲ୍ୟ·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 ଅଙ୍କ_ମୂଲ୍ୟ IPv4 ଠିକଣା 전송이다. `wait_key()`는 화면을 확인할 때 ଆଦାନ_ପ୍ରଦାନ_ଯୋଗ୍ୟ 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor ସ୍ଥିର_ମୂଲ୍ୟ 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 ଏକ୍ସଟେନସନ୍_ମୂଲ୍ୟ 모듈은 아직 없다. 제한형 `pip`의 ଉତ୍ସ_ବୃକ୍ଷ 설치는 [Python ବଣ୍ଡଲ୍ ମତେପଢନ୍ତୁ_eb81d7d9](파이썬꾸러미.md)를 따른다. [세 언어의 ପ୍ରକୃତ_ଡାଟା 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 ଭାଷା 모두 한국어 헤더와 Excel_ଟେବଲ୍_ମୂଲ୍ୟ 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 ପ୍ରକୃତ_ଡାଟା EL0 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 시험 대상이다.

```c
#include "파일규약.h"
#ifdef __cplusplus
extern "C"
#endif
int ଆରମ୍ଭ_ଉପଭୋକ୍ତା_ଅନୁପ୍ରୟୋଗ(int 인수) {
    (void)인수;
    const char 인사말[] = "안녕하세요\n";
    int 문서 = ଖୋଲିବା_ଫାଇଲ୍("인사.txt", ପଢିବା_ଲେଖିବା | 없으면만들기 | 내용비우기, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = ଲିଖନ_ଫାଇଲ୍_ଡାଟା(문서, 인사말, sizeof(인사말) - 1);
    ବନ୍ଦ_ଫାଇଲ୍(문서);
    ଲିଖନ_ଫାଇଲ୍_ଡାଟା(1, 인사말, sizeof(인사말) - 1); /* 현재 ଟର୍ମିନାଲ stdout */
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 수 있다. C는 게스트 `cc` 또는 ଆୟୋଜକ SDK, C++는 ଆୟୋଜକ SDK의 Clang++로 컴파일한다. 아래 예제는 기존 ଆୟୋଜକ SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh
# 호스트에서 SDK ସୃଷ୍ଟି_କରିବା·ବାହାର_କରିବା
make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/인사.c -o 인사-c.elf
python3 compile.py examples/인사.cpp -o 인사-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 ପ୍ରକୃତ_ଡାଟା ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ
cd /home/user/jkoros/platforms/rpi4-native
python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ଫାଇଲ୍.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ଫାଇଲ୍.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

현재 GUI VM에서 실행하려면 `python3 ଉପକରଣସମୂହ/ଅପଲୋଡ୍_ଫାଇଲ୍_ଗୁଡିକ.py ପଥ/인사-c.elf`의 출력을 게스트에 보내고 `run 인사-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex ଫାଇଲ୍_ନାମ_ପାଠ`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 수 있다. 호스트와 게스트의 ଫାଇଲ 시스템은 별개다.

| 한국어 ନାମ | C ସଙ୍କେତ | କ୍ଲିପ୍ |
|---|---|---|
| ଖୋଲିବା_ଫାଇଲ୍/ବନ୍ଦ_ଫାଇଲ୍ | pk_open/pk_close | RAM ଫାଇଲ, ସମକକ୍ଷ_ମୂଲ୍ୟ/절대 ପଥ |
| 파일자료읽기/ଲିଖନ_ଫାଇଲ୍_ଡାଟା | pk_read/pk_write | ଫାଇଲ, fd 0/1/2 표준 ଇନପୁଟ୍_ଆଉଟପୁଟ୍, 연결형 소켓 |
| ସୀକ୍_ଫାଇଲ୍ | pk_lseek | 처음기준/현재기준/끝기준 |
| ଫାଇଲ୍_ଅକାର/ସେଟ୍_ଫାଇଲ୍_ଦୈର୍ଘ୍ୟ | pk_size/pk_ftruncate | ଦୈର୍ଘ୍ୟ_ମୂଲ୍ୟ ଜିଜ୍ଞାସା_ମୂଲ୍ୟ/ପରିବର୍ତ୍ତନ_ମୂଲ୍ୟ |
| ଅପସାରଣ_କରିବା_ଫାଇଲ୍_ଏଣ୍ଟ୍ରି_ନାମ | pk_unlink | ଫାଇଲ ନାମ 삭제 |
| 파일저장확정 | pk_fsync | RAM이므로 -1, 오류번호=ENOSYS |
| 통신종단점만들기/ବନ୍ଧନ_ଠିକଣା | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |
| 자료전문보내기/자료전문받기 | pk_sendto/pk_recvfrom | UDP 루프백 |
| ସଂଯୋଗ_ନେଟ୍_ୱାର୍କ୍ | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | ଅପେକ୍ଷା_ମୂଲ୍ୟ ସଂଯୋଗ_କରନ୍ତୁ 최대 4개 |
| ସ୍ୱୀକାର_କରିବା_ନେଟ୍_ୱାର୍କ_ସଂଯୋଜନ | pk_accept | 현재 ଠିକଣା 인수는 NULL/NULL만 ସମର୍ଥନ_ମୂଲ୍ୟ |
| 통신주소읽기 | pk_getsockname | 로컬 ଠିକଣା/ପୋର୍ଟ_ମୂଲ୍ୟ |

`통신규약.h`의 자체 `pk_sockaddr_in`을 사용하며 ପୋର୍ଟ_ମୂଲ୍ୟ·주소는 `망차례짧은수`/`ନେଟ୍_ୱାର୍କ୍_ଇଣ୍ଟିଜର`로 변환한다. C 소켓 호출은 비차단이며 ଡାଟା/연결이 없으면 -1과 `오류번호=11`(EAGAIN)을 반환한다. 양수 ଇନପୁଟ୍_ଆଉଟପୁଟ୍ 결과가 요청보다 작을 수 있으므로 ବାରମ୍ବାର_ମୂଲ୍ୟ 처리한다. ବିଫଳତା_ମୂଲ୍ୟ 후에만 오류번호를 확인한다.

[ଷ୍ଟ୍ରିମ୍_ମୂଲ୍ୟ.c](예제/한글코딩/ଷ୍ଟ୍ରିମ୍_ମୂଲ୍ୟ.c)는 C에서 한국어 이름으로 ସଂଯୋଗ_କରନ୍ତୁ·accept·부분 ପଢନ୍ତୁ/ଲେଖନ୍ତୁ·큐 포화·EOF를 처리하는 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 예제다. SDK의 `examples/ଷ୍ଟ୍ରିମ୍_ମୂଲ୍ୟ.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → ପ୍ରକୃତ_ଡାଟା 한국어 C Excel_ଟେବଲ୍_ମୂଲ୍ୟ 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·ପଏଣ୍ଟର୍ 검사 → Java RAM ଫାଇଲ/루프백 또는 외부 lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 ସଂଯୋଗ_କରନ୍ତୁ, 표준 C printf, libstdc++/STL, ବ୍ୟତିକ୍ରମ·RTTI는 제공하지 않으며 C++의 ସ୍ଥିର_ମୂଲ୍ୟ 생성자·ସ୍ଥାନୀୟ_ପରିସର ଅବଜେକ୍ଟ_ମୂଲ୍ୟ 소멸자는 지원한다. 상세 ଅନୁକ୍ରମଣିକା·ମୋମରୀ_ଡାଟା 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## 한국어 이름으로 직접 작성하는 창과 ଧାରା_ମୂଲ୍ୟ

`example/java/창예제.java`는 `실행할일.ନିଷ୍ପାଦନ_କରନ୍ତୁ`,
`동작받이.동작받기(동작알림)`, `ବଟନ୍`, `ଘଟଣା_ପ୍ରତିଧାଡ଼ି.나중에실행`, `ଚଳାନ୍ତୁ()`을 쓴다.
자체 JVM에 이 이름들의 ଅବଜେକ୍ଟ_ମୂଲ୍ୟ·ପଦ୍ଧତି_ମୂଲ୍ୟ·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `작업가닥`도 자체 스케줄러와 직접 연결된다.
세부 메서드와 기존 한국어 API에서의 변경은 [한국어 API 문서](한국어자바/ମତେପଢନ୍ତୁ_eb81d7d9.md)를 본다.

ଆୟୋଜକ javac는 배포 JAR를 ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/창예제.java
python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java 창예제
```

직접 화면/ଧାରା_ମୂଲ୍ୟ API와 `ଚଳାନ୍ତୁ()` 진입점은 자체 JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
