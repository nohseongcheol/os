# 자체 ARM64 JVM 0.4와 한국어 ଲାଇବ୍ରେରୀ

한국어 통신·ବ୍ୟତିକ୍ରମ 사용법은 [한국어 Java API](한국어자바/ମତେପଢନ୍ତୁ_eb81d7d9.md), Excel_ଟେବଲ୍_ମୂଲ୍ୟ·변수·ଫାଇଲ 이름의 변경과 어원 근거는 [명명 ମତେପଢନ୍ତୁ_eb81d7d9](명명/ମତେପଢନ୍ତୁ_eb81d7d9.md)를 참고한다.

JAR ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ, 외부 IPv4 TCP/UDP, 별도 ସ୍ଥିର_ମୂଲ୍ୟ 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 ଅବଜେକ୍ଟ_ମୂଲ୍ୟ·Thread·Swing은 JVM 경로의 기능이며 AOT ସମର୍ଥନ_ମୂଲ୍ୟ 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1 ଲାଇବ୍ରେରୀ 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1·ସ୍ଥିର_ମୂଲ୍ୟ ପଦ୍ଧତି_ମୂଲ୍ୟ 중심이던 실행기를 ଅବଜେକ୍ଟ_ମୂଲ୍ୟ·ଲାଇବ୍ରେରୀ ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 기반으로 넓힌 것이다.

## 실행과 ସଙ୍କଳନ_ଉତ୍ସ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# 자체 କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ 안에서 ଉତ୍ସ_ବୃକ୍ଷ ସଙ୍କଳନ_ଉତ୍ସ → class ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ, 한국어 API 호출
python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ଫାଇଲ୍.py 시험/자바/한글소스.java

# ଅବଜେକ୍ଟ_ମୂଲ୍ୟ·ବ୍ୟତିକ୍ରମ 등은 ଆୟୋଜକ JDK로 Java 8 class를 만든 후 자체 커널에서 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ଫାଇଲ୍.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 ସ୍ଥାନାନ୍ତର_ମୂଲ୍ୟ
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ଫାଇଲ୍.py build/my-java/객체시험.class \
  --include build/my-java/ପୃଷ୍ଠପଟ_ମୂଲ୍ୟ.class --include build/my-java/ଶାଖା_ମୂଲ୍ୟ.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1.class`라는 RAM ଫାଇଲ 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar ଫାଇଲ.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 한국어 클래스만 찾는다. 배포 한국어 ଲାଇବ୍ରେରୀ JAR는 ଆୟୋଜକ javac의 classpath로 사용하며, 같은 클래스가 ଉପଭୋକ୍ତା JVM ELF에도 ପଢନ୍ତୁ 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 ସ୍ଥିର_ମୂଲ୍ୟ ପଦ୍ଧତି_ମୂଲ୍ୟ, int/boolean/char/String, ସର୍ତ୍ତ·ବାରମ୍ବାର_ମୂଲ୍ୟ, ଷ୍ଟ୍ରିଂ_ମୂଲ୍ୟ 결합, 일부 ଫାଇଲ 스트림 등의 **자체 부분집합 컴파일러**다. ଅବଜେକ୍ଟ_ମୂଲ୍ୟ 선언·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 자체 JVM에서 실행한다. 한국어 API 중 ନିର୍ଗମ·문자 스칼라 Excel_ଟେବଲ୍_ମୂଲ୍ୟ·ଫାଇଲ ପଢନ୍ତୁ/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] 인수) throws Exception {
        한국어.자체.ନିର୍ଗମ.ଲିଖନ_ରେଖା("안녕하세요😀");
        한국어.자체.ନିର୍ଗମ.수쓰기(한국어.자체.문자.코드포인트수("한글😀"));
        한국어.자체.ଫାଇଲ.ଲେଖନ୍ତୁ("인사.txt", "한글 ଫାଇଲ😀");
        한국어.자체.ନିର୍ଗମ.ଲିଖନ_ରେଖା(한국어.자체.ଫାଇଲ.ପଢନ୍ତୁ("인사.txt"));
    }
}
```

## 한국어 API

독립 패키지 **`한국어.자체`**를 사용한다. Linux판 `한국어.자바`가 요구하는 NIO/Swing/HTTP API를 자체 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1 ନାମ·ପଦ୍ଧତି_ମୂଲ୍ୟ·인수·ଫିଲ୍ଡ_ମୂଲ୍ୟ·ଫାଇଲ 이름에 한국어를 사용한다. 표준 Java ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1 이름은 호환성을 위해 보존한다.

## ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(한국어 ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1 포함), class당 16 KiB·ସ୍ଥିରାଙ୍କ_ମୂଲ୍ୟ 풀 511항목, 전체 ପଦ୍ଧତି_ମୂଲ୍ୟ/ଫିଲ୍ଡ_ମୂଲ୍ୟ 각각 512개. ପଦ୍ଧତି_ମୂଲ୍ୟ 코드 8 KiB, ସ୍ଥାନୀୟ_ପରିସର 변수·피연산자 스택 각각 128슬롯, 인수 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- ଅବଜେକ୍ଟ_ମୂଲ୍ୟ 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 ପ୍ରକୃତ_ଡାଟା 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 ଫାଇଲ·대형 ଷ୍ଟ୍ରିଂ_ମୂଲ୍ୟ·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 ନିର୍ଦ୍ଦେଶ 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 ଓ୍ୱିଣ୍ଡୋ ସୁଇଚ୍_ମୋଡ୍ 시 중단·재개한다. 일반 ସର୍ଭର୍_ମୂଲ୍ୟ·계산의 무제한 실행은 아직 없다. 미지원 ନିର୍ଦ୍ଦେଶ·ଉତ୍ସ_ମୂଲ୍ୟ 부족은 명시적인 오류로 종료한다.
- RAM ଫାଇଲ 최대 64개, 파일당 16384바이트, ପଥ UTF-8 63바이트. RAM 디렉터리와 ସମକକ୍ଷ_ମୂଲ୍ୟ/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 한국어 class는 RAM ଫାଇଲ 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 현재 경로에서 ଉତ୍ସ_ବୃକ୍ଷ·ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1·ଡାଟା 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 외부 IPv4를 제공한다. ପ୍ରକୃତ_ଡାଟା GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. 전문 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 ଆରେ_ମୂଲ୍ୟ, 완전한 ଆରେ_ମୂଲ୍ୟ 공변성·인터페이스 ସ୍ତର_ମୂଲ୍ୟ 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/ଏନକ୍ରିପ୍ଟ_ଡାଟା/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 ସମର୍ଥନ_ମୂଲ୍ୟ 부분집합은 아래 및 개발 매뉴얼을 참고한다. ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1 ଫାଇଲ 전체 검증기·ପ୍ରବେଶ_ଏଣ୍ଟ୍ରି ଅନୁମତି_ମୂଲ୍ୟ/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 ପ୍ରତିରୋଧ_ମୂଲ୍ୟ 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM ମୂଲ୍ୟ/ବୈଧକରଣ/ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1 로더와 ବ୍ୟତିକ୍ରମ 모델 → 영속 VFS·mmap·ଘଣ୍ଟା·원자 ସଂଚାଳନ_ମୂଲ୍ୟ·ପ୍ରକୃତ_ଡାଟା 스레드/ସିଂକ୍ରୋନାଇଜ୍_କରନ୍ତୁ ABI → OpenJDK java.base 및 native ଲାଇବ୍ରେରୀ 이식 → ଡିଭାଇସ_ମୂଲ୍ୟ 네트워크·TCP/IP → ଓ୍ୱିଣ୍ଡୋ 시스템/ଫଣ୍ଟ_ମୂଲ୍ୟ/입력기·java.desktop → Java SE 호환성 시험. 현재 자체 JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

`ଉପକରଣସମୂହ/자바가상기계시험.py`는 같은 Java 8 class 파일의 출력을 ଆୟୋଜକ OpenJDK `-Xverify:all`과 QEMU raspi4b 자체 커널에서 비교한다. ଅବଜେକ୍ଟ_ମୂଲ୍ୟ/상속/인터페이스·switch·ଆରେ_ମୂଲ୍ୟ, ବ୍ୟତିକ୍ରମ/finally, 컬렉션/GC, Thread/잠금, 한국어 UTF-8/ଫାଇଲ/컬렉션, ପ୍ରକୃତ_ଡାଟା UDP 루프백/ସମୟ_ମୂଲ୍ୟ 초과, 게스트 한글 ଉତ୍ସ_ବୃକ୍ଷ ସଙ୍କଳନ_ଉତ୍ସ, ଆରେ_ମୂଲ୍ୟ ଟାଇପ୍_କରିବା_ମୂଲ୍ୟ/କପି_ମୂଲ୍ୟ/ଫାଇଲ 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 ଫାଇଲ ପ୍ରତ୍ୟାକ୍ଷାନ_ମୂଲ୍ୟ 시험을 실행한다. UDP ପ୍ରୋଜେକ୍ଟ୍_ରୁଟ୍ 실행에는 ଆୟୋଜକ 루프백 소켓 권한이 필요하다.

## JVM 0.3: 네트워크와 GUI ଏକ୍ସଟେନସନ୍_ମୂଲ୍ୟ

`Socket`/`ServerSocket` ସୃଷ୍ଟି_କରିବା·ସଂଯୋଗ_କରନ୍ତୁ·accept·양방향 InputStream/OutputStream·close·EOF·ସମୟ_ମୂଲ୍ୟ 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 외부 ଅଙ୍କ_ମୂଲ୍ୟ IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 ଶେଷ_କରନ୍ତୁ_ପଏଣ୍ଟ୍ 16개, Java 루프백 버퍼 1024바이트, 외부 TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. ଆଦାନ_ପ୍ରଦାନ_ଯୋଗ୍ୟ 이벤트 대기는 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 기한을 갱신하고 ଟର୍ମିନାଲ ସୁଇଚ୍_ମୋଡ୍ 시 프로세스 상태를 ସଞ୍ଚୟ_କରିବା_ମୂଲ୍ୟ·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

한국어 `ଓ୍ୱିଣ୍ଡୋ`, `ୱିଜାର୍ଡ୍`, `연결통신` 클래스를 배포 JAR와 자체 JVM 내장 자원에 추가했다. 상세 ପଦ୍ଧତି_ମୂଲ୍ୟ·제한·ଉତ୍ସ_ବୃକ୍ଷ·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## 한국어 객체의 직접 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ

`ଓ୍ୱିଣ୍ଡୋ`, `ସୂଚକ`, `ପାଠ୍ୟ_କ୍ଷେତ୍ର`, `ବଟନ୍`, `ଘଟଣା_ପ୍ରତିଧାଡ଼ି`, `동작알림`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. 자체 JVM의 ଅବଜେକ୍ଟ_ମୂଲ୍ୟ ସୃଷ୍ଟି_କରିବା,
ଫର୍ମାଟ୍_ମୂଲ୍ୟ 검사, 화면 호출, ଘଟଣା 큐, ଧାରା_ମୂଲ୍ୟ 스케줄러에 한국어 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 경로도 유지한다.
한국어 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

자체 실행기의 한국어 진입점은 `public static void ଚଳାନ୍ତୁ()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 한국어 진입점을 우선한다.
명령행 인수는 `실행인수.개수()`와 `실행인수.ପାଠ୍ଯ(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. ସ୍ଥିର_ମୂଲ୍ୟ ଫାଇଲ 예제는 게스트
javac로도 컴파일하며, GUI/ଧାରା_ମୂଲ୍ୟ 소스는 ଆୟୋଜକ `javac --release 8`을 사용한다.
직접 GUI/ଧାରା_ମୂଲ୍ୟ API는 자체 JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
한국어 가닥의 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ·ଅପେକ୍ଷା_ମୂଲ୍ୟ·중복 ଚଳାନ୍ତୁ ପ୍ରତ୍ୟାକ୍ଷାନ_ମୂଲ୍ୟ, GUI ଘଟଣା 출처·ଅନୁକ୍ରମଣିକା·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

ପଦ୍ଧତି_ମୂଲ୍ୟ 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
한국어 클래스도 실행되지만, ଷ୍ଟ୍ରିଂ_ମୂଲ୍ୟ 리터럴·표준 ଲାଇବ୍ରେରୀ 재정의·native
ସଂଯୋଗ_କରନ୍ତୁ·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 예제](한국어자바/ମତେପଢନ୍ତୁ_eb81d7d9.md)를 참고한다.
