# 한국어 Java 통신·ଇନପୁଟ୍_ଆଉଟପୁଟ୍·ବ୍ୟତିକ୍ରମ API

패키지는 `한국어.자체`다. ଆୟୋଜକ `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·ଫାଇଲ·ବ୍ୟତିକ୍ରମ API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 ଧାରା_ମୂଲ୍ୟ API는 자체 JVM 전용이다.
기존 표준 Java ଲାଇବ୍ରେରୀ 전체의 한국어 번역판은 아니다.

```java
import 한국어.자체.*;

public class ନେଟ୍_ୱାର୍କ୍ {
    public static void main(String[] 인수) throws ଇନପୁଟ୍_ଆଉଟପୁଟ୍_ବ୍ୟତିକ୍ରମ {
        ସଂଯୋଗ ସଂଯୋଗ_କରନ୍ତୁ = ସଂଯୋଗ.ଖୋଲନ୍ତୁ("10.0.2.2", 9000);
        try {
            ସଂଯୋଗ_କରନ୍ତୁ.대기시간(700);
            ସଂଯୋଗ_କରନ୍ତୁ.ନିର୍ଗମ().ଲେଖନ୍ତୁ(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = ସଂଯୋଗ_କରନ୍ତୁ.입력();
            ନିର୍ଗମ.수쓰기(입력.ପଢନ୍ତୁ());
        } catch (대기시간초과예외 ତ୍ରୁଟି) {
            ନିର୍ଗମ.ଲିଖନ_ରେଖା(ତ୍ରୁଟି.설명());
        } finally {
            ସଂଯୋଗ_କରନ୍ତୁ.ବନ୍ଦ_କରନ୍ତୁ();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
ଉପଭୋକ୍ତା 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 ଷ୍ଟ୍ରିଂ_ମୂଲ୍ୟ 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void ଚଳାନ୍ତୁ()`도 진입점으로 받는다.

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`ପଢନ୍ତୁ()`의 ଫାଇଲ 끝은 -1, ଆରେ_ମୂଲ୍ୟ 읽기의 반환값은 ପ୍ରକୃତ_ଡାଟା 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. ପୋର୍ଟ୍_ନମ୍ଵର୍ 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 자체 커널에서 512바이트까지 받으며, 주소는 ଅଙ୍କ_ମୂଲ୍ୟ IPv4를 사용한다.
`localhost` 루프백 외의 ନାମ 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.ସଂଯୋଗ_କରନ୍ତୁ/듣기/받기`, `통신.ଖୋଲନ୍ତୁ/ପଠାନ୍ତୁ/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `ସଂଯୋଗ`, `수신창구`, `전문통로`를 쓴다.

모든 아래 클래스는 ଡିଫଲ୍ଟ_ମାନ 생성자, `새예외("설명")` 형태의 ଷ୍ଟ୍ରିଂ_ମୂଲ୍ୟ 생성자와
`설명()`을 제공한다. ପ୍ରକୃତ_ଡାଟା ସୃଷ୍ଟି_କରିବା 문법은 `new 대기시간초과예외("ଅପେକ୍ଷା_ସ୍ଥିତି 끝")`이다.

`ବ୍ୟତିକ୍ରମ`와 `실행예외`는 모든 한국어 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, ଫାଇଲ·통신 전체를 잡으려면 `catch (ଇନପୁଟ୍_ଆଉଟପୁଟ୍_ବ୍ୟତିକ୍ରମ ତ୍ରୁଟି)`를 쓴다.
한국어 API가 표준 ଇନପୁଟ୍_ଆଉଟପୁଟ୍ 오류를 한국어 예외로 변환한다.
기존 한국어 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
ବ୍ୟତିକ୍ରମ 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 자체 JVM에 이 20종을 추가했다. 임의의 ଉପଭୋକ୍ତା Throwable 하위 ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1 전체를
지원하도록 확장했다는 뜻은 아니다.

## ସଙ୍କଳନ_ଉତ୍ସ·ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make ବିଲ୍ଡ୍_ସିଷ୍ଟମ
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 ଉପକରଣସମୂହ/ନିର୍ବାହ_କରିବା_ଫାଇଲ୍.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 ଉପଭୋକ୍ତା JVM ELF 안에 탑재된다. `.jar`는 ଆୟୋଜକ javac의
ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1 경로로 사용한다. ଉତ୍ସ_ବୃକ୍ଷ 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 한국어 예외의 `throws` 선언과 그 import를 인식한다.
자체 JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·ଅବଜେକ୍ଟ_ମୂଲ୍ୟ·소켓 예제 전체의 ଉତ୍ସ_ବୃକ୍ଷ 컴파일은 ଆୟୋଜକ javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 수 있다.

ପ୍ରକୃତ_ଡାଟା TCP/UDP 예제는 [네트워크예제.java](../../../example/java/네트워크예제.java),
ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 절차는 [example ମତେପଢନ୍ତୁ_eb81d7d9](../../../example/README.md),
ଉତ୍ସ_ବୃକ୍ଷ 명명 원칙은 [명명 ମତେପଢନ୍ତୁ_eb81d7d9](../명명/ମତେପଢନ୍ତୁ_eb81d7d9.md)에 있다.

인사말과 କ୍ଲିକ୍_କରିବା_ମୂଲ୍ୟ 횟수 ସତେଜ_କରନ୍ତୁ, X 닫기를 지원한다.

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `ପ୍ରୋସେସ୍_ଧାରା`가 한국어 ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1·ପଦ୍ଧତି_ମୂଲ୍ୟ·서술자를
해석해 화면 요소와 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 가닥을 직접 만든다. କାମ 알림도 자체 객체이며
콜백으로 `ନିଷ୍ପାଦନ_କରନ୍ତୁ`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 ଆୟୋଜକ JVM에서 무동작 객체가 생기지 않도록 하는 ପ୍ରତ୍ୟାକ୍ଷାନ_ମୂଲ୍ୟ 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. ଆୟୋଜକ javac로 컴파일한 ପଛ_ମୂଲ୍ୟ 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import 한국어.자체.*;
public class 가닥예제 implements 실행할일 {
    public void ନିଷ୍ପାଦନ_କରନ୍ତୁ() { ନିର୍ଗମ.ଲିଖନ_ରେଖା("한국어 작업 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ"); }
    public static void ଚଳାନ୍ତୁ() throws 대기중단예외 {
        작업가닥 ଧାରା_ମୂଲ୍ୟ = 작업.ଚଳାନ୍ତୁ(new 가닥예제());
        작업.기다리기(ଧାରା_ମୂଲ୍ୟ);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
ଆରେ_ମୂଲ୍ୟ 인수 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 인수 없는 `ଚଳାନ୍ତୁ()`을 우선한다.
기존 한국어 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.ଚଳାନ୍ତୁ(Runnable)`을 사용하던 코드는 새 한국어 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API ସମର୍ଥନ_ମୂଲ୍ୟ 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 ଶ୍ରେଣୀ_ମୂଲ୍ୟ_55654bf1·ପଦ୍ଧତି_ମୂଲ୍ୟ 이름과 서술자가 남는다.
한국어 ନାମ 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·ପଦ୍ଧତି_ମୂଲ୍ୟ 재정의, native ସଂଯୋଗ_କରନ୍ତୁ, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS ପରିଚାୟକ_ମୂଲ୍ୟ](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS ପଦ୍ଧତି_ମୂଲ୍ୟ ପ୍ରସଙ୍ଗ](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
