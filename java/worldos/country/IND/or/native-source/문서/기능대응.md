# engos 기능 대응표

이 표는 기존 `ଲିଗାସୀ_ଉତ୍ସ/`의 ଅବଜେକ୍ଟ_ମୂଲ୍ୟ 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [ପ୍ରକୃତ_ଡାଟା 부팅 기능과 한계](../os/ମତେପଢନ୍ତୁ_eb81d7d9.md)를 따로 기록한다.

## 기존 ଅବଜେକ୍ଟ_ମୂଲ୍ୟ 기반 관리 କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ 전체를 부팅하기 위해 남은 ସଂଯୋଗ_କରନ୍ତୁ

ପରବର୍ତ୍ତୀ_ଆଇଟମ୍ 항목은 Java 문법만으로 실행할 수 없는 CPU/ଡିଭାଇସ_ମୂଲ୍ୟ 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot ଏଣ୍ଟ୍ରି_ପଏଣ୍ଟ୍_ମୂଲ୍ୟ, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 ପ୍ରସଙ୍ଗ_ମୂଲ୍ୟ ସଞ୍ଚୟ_କରିବା_ମୂଲ୍ୟ
- ପ୍ରକୃତ_ଡାଟା PIC/PIT/PS2/ATA/PCI ହାର୍ଡୱେର୍_ପୋର୍ଟ 및 AMD PCnet DMA ଲୁପ୍_ମୂଲ୍ୟ
- Java ଅବଜେକ୍ଟ_ମୂଲ୍ୟ·ଆରେ_ମୂଲ୍ୟ ଲିଙ୍କ୍_ଲେଆଉଟ୍, ବ୍ୟତିକ୍ରମ, ସ୍ଥିର_ମୂଲ୍ୟ ପ୍ରାରମ୍ଭିକରଣ, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT ଷ୍ଟେଜ୍_ମୂଲ୍ୟ
- FAT 디스크 구역을 ପ୍ରକୃତ_ଡାଟା ATA 장치와 연결하는 ଇନପୁଟ୍_ଆଉଟପୁଟ୍ 접착 ସ୍ତର_ମୂଲ୍ୟ

위 관리 계층은 engos 기능의 Java 관리 구현과 ଆୟୋଜକ 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot ଏଣ୍ଟ୍ରି_ପଏଣ୍ଟ୍_ମୂଲ୍ୟ, ସ୍ଥିର_ମୂଲ୍ୟ ପ୍ରାରମ୍ଭିକରଣ·ଇଣ୍ଟିଜର ଆରେ_ମୂଲ୍ୟ, VGA/직렬/PS2, 명령해석기, ଉପଭୋକ୍ତା ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 ଆୟୋଜକ 루프백 패킷 왕복을 검증했다. 위 표의 ଅବଜେକ୍ଟ_ମୂଲ୍ୟ 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
