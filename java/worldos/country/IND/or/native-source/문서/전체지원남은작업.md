# 전체 ସମର୍ଥନ_ମୂଲ୍ୟ 요청의 현재 ସ୍ଥିତି_ମୂଲ୍ୟ_e10195a1

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 ପ୍ରକୃତ_ଡାଟା C POSIX 일부 기능, 한국어 API/ଉତ୍ସ ନାମ, IDE ଫାଇଲ 보존, 게스트 Java ଫାଇଲ 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/ମତେପଢନ୍ତୁ_eb81d7d9.md)를 기준으로 판단한다.

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 환경을 추가하는 방식은 별도의 କେନ୍ଦ୍ରିକ_ମୂଲ୍ୟ·루트 ଫାଇଲ୍_ସିଷ୍ଟମ୍·OpenJDK·그래픽 ସର୍ଭର୍_ମୂଲ୍ୟ·영구 ସଞ୍ଚୟ_କରିବା_ମୂଲ୍ୟ 구성을 가진 ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

ନିର୍ବାହ_କରିବା_ନିର୍ଦ୍ଦେଶ 기반과 추가 ଲକ୍ଷ୍ୟସ୍ଥଳ 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
