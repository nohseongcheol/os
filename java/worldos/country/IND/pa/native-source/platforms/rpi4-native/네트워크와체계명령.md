# 자체 커널의 네트워크와 ਸਿਸਟਮ_ਚਲਾਉਣਾ_ਕੀਮਤ ਕਮਾਂਡ

게스트 SSH·VNC, LAN 공개 ਅਮਲ_ਕਰੋ_ਆਦੇਸ਼, Pi4 GENET·DHCP 추가분은 [외부 ਸਬੰਧ_e05f319b ਫਈਲ_ਮੈਨੂੰ_ਪੜਨ_ਦਿਉ_eb81d7d9](외부접속안내.md)를 먼저 참고한다. QEMU는 `sl0`, 실물 GENET은 `en0`를 사용한다. 실물 드라이버는 아직 보드에서 검증하지 않았다.

이 문서는 `platforms/rpi4-native`의 자체 ARM64 Java 커널용이다. Linux/OpenJDK 실행환경의 명령어와 구분한다. 새 커널을 빌드하고 다시 부팅해야 적용된다.

셸과 Java의 ਅਸਲ_ਸਮੱਗਰੀ CPU ਆਗਿਆ_ਕੀਮਤ, `ps`/`top`에 표시되는 ਪਾਠ_ਕੀਮਤ, ਹੋਸਟ·외부 PC ਕੁਨੈਕਸ਼ਨ_ਕਰੋ 방법은
[ਅਮਲ_ਕਰੋ_ਆਦੇਸ਼ 계층과 외부 통신 점검](실행계층과외부통신점검.md)에 정리했다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop ARGS=--network RESOLUTION=1920x1080
# 직렬 셸만 사용할 때
make run ARGS=--network
```

게스트에서 `help`, `help system` 또는 `ਸ਼ੋਅ_ਮਦਦ system`을 입력한다. 아래 두 이름은 같은 동작을 하며 현지어 이름도 Tab으로 완성할 수 있다.

## IP 설정과 통신 ਤਸਦੀਕ

```sh
ipconfig
ip addr show
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2
아이피설정 set 10.0.2.20 255.255.255.0 10.0.2.2
ping -c 4 -W 1 10.0.2.2
응답시험 -c 4 10.0.2.2
ip route show
ip link set dev sl0 down
ip link set dev sl0 up
netstat
```

초깃값은 `sl0`, `10.0.2.15/24`, ਗੇਟਵੇ_ਕੀਮਤ `10.0.2.2`다. ਪਤਾ 설정은 재부팅 전까지 유지된다. TCP/UDP 끝점이 열려 있으면 `error -16`으로 변경을 거부한다. 먼저 `ftpd stop` 등으로 서비스를 닫고 프로그램의 소켓을 닫는다. 잘못된 ਪਤਾ·비연속 넷마스크·다른 망의 관문은 적용하지 않는다.

`ip`는 위 구문의 부분집합이며 Linux iproute2 전체 문법을 구현하지 않는다. `ping`은 IPv4 ਅੰਕ_ਕੀਮਤ ਪਤਾ, `-c 1..100`, `-W 1..10`초를 지원한다. ਨਾਂ ਪਦ_ਵਿਆਖਿਆ_ਕਰੋ_ਕੀਮਤ·IPv6는 미지원이며 GENET의 DHCP는 외부 ਸਬੰਧ_e05f319b 구현에 추가했다. 응답이 없으면 종료값 1, 잘못된 인수는 2, ਉਪਭੋਗਤਾ 취소는 130이다. `ping ...; echo $?`로 확인한다.

QEMU 외부 통신은 UART SLIP→NAT 연결을 사용한다. `--network` 없이도 자체 ਪਤਾ ਪੜਤਾਲ_ਕੀਮਤ·설정은 가능하지만 외부 응답은 오지 않는다. ਡਿਫੌਲਟ_ਵੈਲਯੂ NAT는 `10.0.2.0/24`다. 실물 Pi의 GENET 드라이버는 별도로 추가했으며 ਬੋਰਡ 검증이 필요하다. Wi-Fi는 미지원이다.

주소를 `.20`으로 바꾼 ਪਿਛਲਾ_ਕੀਮਤ FTP 등 **외부에서 들어오는 ਕੁਨੈਕਸ਼ਨ_ਕਰੋ**까지 사용할 때는 ਅਮਲ_ਕਰੋ_ਆਦੇਸ਼ 시 ਫਾਰਵਰਡ_ਕੀਮਤ 대상도 지정한다.

```sh
make desktop ARGS="--network --guest-ip 10.0.2.20"
# 부팅한 게스트 안에서
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2
ftpd start
```

`--guest-ip`는 NAT ਫਾਰਵਰਡ_ਕੀਮਤ 대상이며 게스트의 주소를 자동 설정하지 않는다. FTP ਨਿਯੰਤਰਣ_ਕੀਮਤ 포트는 ਹੋਸਟ `127.0.0.1:2121`, 수동 데이터 포트는 50000~50007이다. 여러 VM을 함께 띄울 때는 `--network-host 127.0.0.2 --port 5903`처럼 ਹੋਸਟ 루프백 주소와 VNC 포트를 구분한다. FTP와 Java/C 소켓은 변경된 ਅਸਲ_ਸਮੱਗਰੀ 게스트 IP를 사용한다.

## ਸਥਿਤੀ_ਕੀਮਤ 조회의 의미

`ps`는 ਪੱਕੇ_ਹੋਣਾ_ਕੀਮਤ/ਸ਼ੈਲ, 살아 있는 협력 작업, 최대 4개의 EL0 ਉਪਭੋਗਤਾ 세션을 표시한다. 다른 터미널에 열린 `vi` 등을 `SUSPENDED` 상태로 볼 수 있다. `MAPPED_KiB`는 ਅਸਲ_ਸਮੱਗਰੀ 페이지 매핑, `RUN_ms`는 해당 세션이 선택된 동안의 경과 시간(시스템 호출 포함)이며 정밀 CPU 사용률이 아니다. `top -n 1`은 한 번, `top -n 2`는 두 번 표시한다. 리다이렉션된 `top`의 기본값은 한 번이다.

`free`의 AOT 힙 사용량은 할당기에서 읽는다. 힙은 ਪੱਕੇ_ਹੋਣਾ_ਕੀਮਤ BSS에 포함되므로 각 줄을 모두 더하면 중복된다. 고정 예약 영역과 ਉਪਭੋਗਤਾ 페이지 매핑을 표시하며 Linux의 가용 RAM 계산이나 ਹੋਸਟ ਮੈਮਰੀ_ਸਮੱਗਰੀ 통계를 꾸며서 표시하지 않는다.

`df`는 RAM 파일시스템의 ਫਾਇਲ 64칸 × 16 KiB를 표시한다. ਫਾਇਲ 하나는 논리 크기와 별도로 16 KiB 칸을 예약한다. `Data`는 ਅਸਲ_ਸਮੱਗਰੀ ਸਮੱਗਰੀ ਲੰਬਾਈ_ਕੀਮਤ 합계, `Reserved`는 사용 중인 ਸਲੌਟ_ਦਾਖਲਾ 용량이다. 삭제 후에도 열린 파일은 마지막 참조를 닫을 때까지 계산한다. SD/영구 디스크 사용량은 아직 지원하지 않는다.

## 종료와 ਪ੍ਰਮਾਣਿਤ

게스트에서 `poweroff` 또는 `전원끄기`를 입력한다. FTP·소켓·ਉਪਭੋਗਤਾ 세션을 닫은 ਪਿਛਲਾ_ਕੀਮਤ BCM PM ਨਿਕਾਸ_ਐਪਲੀਕੇਸ਼ 절차를 실행한다. RAM 파일은 재부팅 후 보존되지 않는다. QEMU에서는 게스트의 `SHUTDOWN / guest-shutdown` 이벤트와 정상 종료를 검증한다. 실물 Pi 4 전원 회로 동작은 아직 시험하지 않았다.

구현 근거: [Linux BCM watchdog의 power-off 절차](https://github.com/torvalds/linux/blob/master/drivers/watchdog/bcm2835_wdt.c), [QEMU BCM PM ਤਜਵੀਜ_ਕੀਮਤ](https://github.com/qemu/qemu/blob/master/hw/misc/bcm2835_powermgt.c).

```sh
make test-system
# ਮਾਪ: build/verification/system-tools/report.json 및 serial.log
```

이 시험은 잘못된 IP 거부, ਅਸਲ_ਸਮੱਗਰੀ ICMP 성공·시간초과, ਕੁਨੈਕਸ਼ਨ_ਕਰੋ up/down, IP ਬਦਲੋ_ਕੀਮਤ 후 FTP 송수신, df ਜਨਰੇਟ_ਕਰੋ·삭제, 힙 계산, 다른 터미널의 vi PID·ਮੈਮਰੀ_ਸਮੱਗਰੀ, top ਤਾਜ਼ਾ_ਕਰੋ·ਨਿਕਾਸ_ਐਪਲੀਕੇਸ਼, 한글 ਕਮਾਂਡ·Tab, 게스트 poweroff를 검사한다.

`java/worldos/나라/국가코드` 판에는 같은 기능과 국가별 ਕਮਾਂਡ 대응표 `native-commands.json`이 들어간다. 표준 명령은 모든 판에서 유지한다. 새 현지어 이름은 기능 중심 제안이며 현지 화자·어원 검토를 완료한 표준 용어는 아니다. 미번역 항목은 대응표의 `pending`에 명시한다.
