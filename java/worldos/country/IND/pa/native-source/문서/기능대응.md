# engos 기능 대응표

이 표는 기존 `ਲੀਗੇਸੀ_ਸਰੋਤ/`의 ਔਬਜੈਕਟ_ਕੀਮਤ 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [ਅਸਲ_ਸਮੱਗਰੀ 부팅 기능과 한계](../os/ਫਈਲ_ਮੈਨੂੰ_ਪੜਨ_ਦਿਉ_eb81d7d9.md)를 따로 기록한다.

## Java 관리 ਲੇਅਰ_ਕੀਮਤ 구현 완료

| engos 영역 | JIndOS 구현 |
|---|---|
| memorymanager, phymem | `ਮੈਮਰੀ_ਪ੍ਰਬੰਧਕ` ਸੇਧਬੰਦ_ਕਰੋ_ਕੀਮਤ ਨਿਰਧਾਰਿਤ_ਕਰੋ_ਸਟੋਰੇਜ·ਰਿਲੀਜ_ਸਟੋਰੇਜ·병합 |
| paging, virtmem | `ਪੰਨਾ_ਪ੍ਰਬੰਧਕ` ਪਤਾ 공간·ਪੰਨਾ_ਕੀਮਤ ਕੁਨੈਕਸ਼ਨ_ਕਰੋ·COW·개인 ਲਿਖਣ |
| gdt, tss | `전역서술자표`, `ਕਾਰਜ_ਸਥਿਤੀ_ਖੰਡ` |
| interrupt | `ਰੋਕ_ਪ੍ਰਬੰਧਕ` ਰਜਿਸਟਰ_ਕਰੋ_ਦਾਖਲਾ·ਚਾਲੂ_ਕਰੋ·ਵੰਡਣਾ_ਕੀਮਤ |
| process, scheduler, thread | `ਕਾਰਵਾਈ_ਕੀਮਤ`, `ਸ਼ੈਡਿਊਲਰ` PID·fork·wait·ਸਥਿਤੀ_ਕੀਮਤ ਸਵਿੱਚ_ਮੋਡ |
| systemcall/POSIX 1단계 | ਪੜ੍ਹਨ·ਲਿਖਣ·ਖੋਲ੍ਹੋ·ਬੰਦ_ਕਰੋ·seek·dup·fcntl·ਐਕਸੈਸ_ਦਾਖਲਾ·작업목록·ਉਪਭੋਗਤਾ/무리 ID·ਸਿੰਕ_ਕਰੋ·brk·fork·wait·exec·stat·uname 의미 |
| ATA | `고급기술결합장치` 512바이트 ਵਿਭਾਗ_ਕੀਮਤ ਪੜ੍ਹਨ·ਲਿਖਣ |
| MSDOS partition | `기본분할영역표` MBR 검증과 네 ਦਾਖਲਾ_ਕੀਮਤ ਪਦ_ਵਿਆਖਿਆ_ਕਰੋ_ਕੀਮਤ |
| FAT 공개 ਫਾਇਲ ਲੇਅਰ_ਕੀਮਤ | `ਫਾਈਲ_ਸਿਸਟਮ`, `파일서술자표` ਪੜ੍ਹਨ 전용 파일과 과정별 FD |
| ELF | ELF32 검사, ਵਿਭਾਗ_ਕੀਮਤ ਕਲਿਪ 검사, 적재, NOBITS 영 ਅਰੰਭ_ਕਰੋ, ਚਲਾਓ_2 ਪਤਾ·인자·환경 반영 |
| keyboard, mouse | `입력관리자`의 손실 계수 포함 ਇਵੈਂਟ 대기열 |
| timer | `ਘੜੀ` 틱과 시간 변환 |
| PCI | `ਪੈਰੀਫਰਲ_ਬਸ_ਪ੍ਰਬੰਧਕ` 검색 결과와 ਤਜਵੀਜ_ਕੀਮਤ ਚੋਣ_ਕੀਮਤ |
| VGA/text mode | `ਵਰਣ_ਪ੍ਰਦਰਸ਼ਨ` 80x25 출력과 스크롤 |
| Ethernet/ARP/IPv4/ICMP/UDP/TCP | `ਨੈਟਵਰਕ_ਸਾਧਨ`, `ਨੈਟਵਰਕ_ਲੇਅਰ` ਖਾਕਾ_ਅਨੁਕ੍ਰਮਣਿਕਾ 검사·검사합·ਕੰਮ_ਕੀਮਤ/포트 ਵੰਡਣਾ_ਕੀਮਤ |

## 기존 ਔਬਜੈਕਟ_ਕੀਮਤ 기반 관리 ਪੱਕੇ_ਹੋਣਾ_ਕੀਮਤ 전체를 부팅하기 위해 남은 ਕੁਨੈਕਸ਼ਨ_ਕਰੋ

ਅਗਲਾ_ਆਇਟਮ 항목은 Java 문법만으로 실행할 수 없는 CPU/ਤਜਵੀਜ_ਕੀਮਤ 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot ਦਾਖਲਾ_ਪੌਇੰਟ_ਕੀਮਤ, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 ਸੰਦਰਭ_ਕੀਮਤ ਸੰਭਾਲੋ_ਕੀਮਤ
- ਅਸਲ_ਸਮੱਗਰੀ PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA ਲੂਪ_ਕੀਮਤ
- Java ਔਬਜੈਕਟ_ਕੀਮਤ·ਤਰਤੀਬ_ਦੇਣਾ_ਕੀਮਤ ਲਿੰਕ_ਖਾਕਾ, 예외, ਸਥਾਈ_ਕੀਮਤ ਅਰੰਭ_ਕਰੋ, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT ਪੜਾਅ_ਕੀਮਤ
- FAT 디스크 구역을 ਅਸਲ_ਸਮੱਗਰੀ ATA 장치와 연결하는 ਦਾਖਲ_ਹੋਣਾ_ਬਾਹਰ_ਆਉਣਾ 접착 ਲੇਅਰ_ਕੀਮਤ

위 관리 계층은 engos 기능의 Java 관리 구현과 ਹੋਸਟ 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot ਦਾਖਲਾ_ਪੌਇੰਟ_ਕੀਮਤ, ਸਥਾਈ_ਕੀਮਤ ਅਰੰਭ_ਕਰੋ·ਪੂਰਣ_ਅੰਕ ਤਰਤੀਬ_ਦੇਣਾ_ਕੀਮਤ, VGA/직렬/PS2, 명령해석기, ਉਪਭੋਗਤਾ ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 ਹੋਸਟ 루프백 패킷 왕복을 검증했다. 위 표의 ਔਬਜੈਕਟ_ਕੀਮਤ 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
