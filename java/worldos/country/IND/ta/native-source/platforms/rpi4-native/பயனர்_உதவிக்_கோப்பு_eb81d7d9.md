# Raspberry Pi 4 자체 Java கரு_மதிப்பு — பயனர் இயக்கு_கட்டளை 기반

현재 자체 코드의 COSL 상업 நிபந்தனை, 제3자 고지 및 LGPL 재연결 자료는 [COSL 배포 பயனர்_உதவிக்_கோப்பு_eb81d7d9](COSL배포안내.md)를 참고한다. சுவிட்ச்_பயன்முறை 전 GPL 구성의 판단은 [이전 라이선스 검토](உரிமம்_மதிப்பாய்வு.md)에 기록했다.

தமிழ் 통신·விதிவிலக்கு 사용법은 [தமிழ் Java API](한국어자바/பயனர்_உதவிக்_கோப்பு_eb81d7d9.md), செயல்பாடு_மதிப்பு·변수·கோப்பின்_பெயர் 이름의 변경과 어원 근거는 [명명 பயனர்_உதவிக்_கோப்பு_eb81d7d9](명명/பயனர்_உதவிக்_கோப்பு_eb81d7d9.md)를 참고한다.

Linux 없이 부팅하는 자체 AArch64 커널이다. Java AOT கரு_மதிப்பு 위에 **கட்டளை_வரி கூடு, 게스트 Java 컴파일러·JVM, MicroPython, EL0 C++ இயக்கு_கட்டளை, கோப்பின்_பெயர்·UDP 루프백 시스템 호출, 여러 한글 GUI கட்டளை_விளக்கி·vi திருத்தி·Swing 부분집합**을 제공한다. 커널의 கோப்பின்_பெயர் தரவு/정책·루프백 இடமாற்று_மதிப்பு·கூடு 상태는 Java, 화면 합성·படக்_கூறு மாற்று_மதிப்பு_16f64fe4·குறிப்பான்·클리핑도 Java로 구현하며, CPU/MMU/சாதனம்_மதிப்பு 경계와 கட்டளை_விளக்கி·எழுத்துக்குறி_மதிப்பு 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 자체 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 இயக்கு_கட்டளை, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 கம்பியிலான_மதிப்பு 송수신은 아직 미검증이다.** இயக்கு_கட்டளை·இணைப்பு_e05f319b·கடவுச்சொல்_மதிப்பு 확인은 [외부 இணைப்பு_e05f319b பயனர்_உதவிக்_கோப்பு_eb81d7d9](외부접속안내.md)에 정리했다.

셸은 EL1 கரு_மதிப்பு, `java` 등 பயனர் இயக்கு_கட்டளை 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 இயக்கு_கட்டளை·இணைப்பு_e05f319b 방법 및 அசல்_தரவு 검증은
[இயக்கு_கட்டளை 계층과 외부 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 அசல்_தரவு இயக்கு_கட்டளை 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 மாறா_மதிப்பு ELF는 `run --linux கோப்பு_பெயர்_உரை`으로 실행한다. [ELF·Linux ABI ஆதரவு_மதிப்பு 범위와 동일 바이너리 시험](실행파일규약.md).

GUI와 네트워크는 `python3 கருவிகள்/இயக்கு_கட்டளை.py --desktop --network`로 함께 사용한다. Java·C·Python의 தமிழ் 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 부팅 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 수 있다. Remmina에서 **F9/Shift+Space/한·영 சாவி_மதிப்பு**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·அசல்_தரவு TCP/UDP·கோப்பின்_பெயர் பைட்_மதிப்பு·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java 창예제`로 தமிழ் Swing 예제를 실행한다. கட்டளை_விளக்கி 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 현재 நெடுவரிசை_மதிப்பு·வரிசை_மதிப்பு_fc48bc81 수를 보여 준다.

இயக்கு_கட்டளை 버튼 화면은 5×7 영문 글꼴을 쓰며, கட்டளை_விளக்கி 창은 Noto CJK/DejaVu에서 생성한 한글·Unicode 비트맵 글꼴을 쓴다. UART와 அசல்_தரவு 프레임버퍼의 한글 표시를 시험한다. 루프백은 동일 கரு_மதிப்பு 내부의 전문 전달이며 IP 패킷을 Ethernet으로 내보내는 드라이버가 아니다. 바깥 IPv4는 lwIP TCP/UDP 스택으로 보조 UART SLIP 경로를 사용한다. `python3 கருவிகள்/இயக்கு_கட்டளை.py --network`로 QEMU NAT를 연결하고 `ftpd start`로 서비스를 시작한다.

Java의 정확한 API·문법·இயக்கு_கட்டளை 제한과 தமிழ் 사용법은 [자체 JVM과 தமிழ் நூலகம்](자바실행환경.md)에 정리했다. பிரிவு_மதிப்பு_55654bf1 கோப்பின்_பெயர்/JAR 배포는 [한국어자바](한국어자바) 소스에서 재현한다. 기존 Linux판 `தமிழ்.자바`와 별도인 `தமிழ்.자체` 패키지다.

**vi·여러 சாளரம்·Swing·한글 Java/Python/C/C++·posix-kor 예제는 [한글 개발 매뉴얼](개발안내.md)에 정리했다.**

GUI கட்டளை_விளக்கி இயக்கு_கட்டளை·단축키·கூடு கட்டளை·제한은 [셸과 கட்டளை_விளக்கி 사용법](셸과터미널.md)에 정리했다.

## 현재 컴퓨터에서 இயக்கு_கட்டளை

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

முடிவு_நிரல்: **Ctrl+A அடுத்து_உருப்படி X**. 게스트 C/AOT கருவிகள் 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. ஓம்பு 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. 컴파일러 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/பாதை_2/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` ஆதரவு_மதிப்பு 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 இயக்கு_கட்டளை**한다. 기존 한 எழுத்துக்குறி_மதிப்பு 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 செயலுருபுகள் 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

```java
public class 인사 { public static void main(String[] args) { int மதிப்பு = 7; System.out.println("한글=" + மதிப்பு); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 인사.java`, `java 인사`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. ரத்து_இயக்கம்·잘못된 16진수·용량 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, இயக்கு_கட்டளை 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 கட்டளை 인수는 최대 32개다. மேற்கோள்_cbe2c532·백슬래시·கூடு 변수·파이프·리다이렉션 범위는 [கூடு 설명](셸과터미널.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, முகவரி **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode 입력·명시적 ஒட்டு_மதிப்பு·இயக்கு_கட்டளை 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 கருவிகள்/இயக்கு_கட்டளை.py --desktop --network
# 다른 포트: python3 கருவிகள்/இயக்கு_கட்டளை.py --desktop --port 5903
```

종료는 실행한 ஓம்பு 터미널에서 Ctrl+C다. 기존 `python3 கருவிகள்/இயக்கு_கட்டளை.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. அசல்_தரவு Pi4 USB 입력기는 아직 없으며, VNC இணைக்க 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 அசல்_தரவு C++/UDP ELF இயக்கு_கட்டளை, `Hello.java` தொகு_மூலம் 후 JVM இயக்கு_கட்டளை, `hello.py` இயக்கு_கட்டளை, GUI கட்டளை_விளக்கி 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 ஊடாடு 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 நினைவகம்_தரவு·CPU 문맥을 보관한다. கூடு·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD கோப்பின்_பெயர் 구성·கரு_மதிப்பு 체크섬 검사와 물리 போர்டு 부팅 검증은 별개다. MMU 사용 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 부팅 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 தமிழ் API 사용

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/파일예제.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int தொடங்கு_பயனர்_நிரல்(int)`이다. பயனர் C++는 FP/SIMD를 사용할 수 있다. கரு_மதிப்பு C/Java AOT는 일반 레지스터만 사용하므로 விதிவிலக்கு செயலகம்_மதிப்பு_உள்ளீடு 중 பயனர் FP 상태를 건드리지 않는다. பயனர் நுழைவுப்_புள்ளி_மதிப்பு 시 FP 상태를 초기화하고 கரு_மதிப்பு 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int தொடங்கு_பயனர்_நிரல்(int) {
    int கோப்பின்_பெயர் = திற_கோப்பு("인사.txt", படிக்க_எழுத | 없으면만들기 | 내용비우기, 0600);
    if (கோப்பின்_பெயர் < 0) return 1;
    const char உள்ளடக்கம்_மதிப்பு[] = "안녕하세요";
    int அளவிடக்கூடியது = எழுது_கோப்பு_தரவு(கோப்பின்_பெயர், உள்ளடக்கம்_மதிப்பு, sizeof(உள்ளடக்கம்_மதிப்பு) - 1);
    மூடு_கோப்பு(கோப்பின்_பெயர்);
    return அளவிடக்கூடியது == sizeof(உள்ளடக்கம்_மதிப்பு) - 1 ? 0 : 2;
}
```

[கோப்பின்_பெயர் 예제](பயனர்/파일예제.cpp)와 [통신 예제](பயனர்/통신예제.cpp)가 அசல்_தரவு 부팅 시험 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 கோப்பின்_பெயர் செயலகம்_மதிப்பு_உள்ளீடு 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 소켓 함수는 현재 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 கரு_மதிப்பு 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 அடுத்து_உருப்படி 도구를 사용하면 **새 QEMU를 부팅해 업로드한 அசல்_தரவு 바이트를 재확인한 பின்_மதிப்பு 게스트에서 இயக்கு_கட்டளை**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 கருவிகள்/இயக்கு_கோப்பு.py build/jkoros-native-sdk/demo.elf
python3 கருவிகள்/இயக்கு_கோப்பு.py 예제/Hello.java "한글 செயலுருபுகள்"
python3 கருவிகள்/இயக்கு_கோப்பு.py 예제/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 கரு_மதிப்பு 묶음에 포함되어 이 கோப்பின்_பெயர் 한도를 적용받지 않는다. **C++ 컴파일러는 ஓம்பு SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 நூலகம், PT_TLS, PT_INTERP, PT_DYNAMIC, இயக்கு_கட்டளை·எழுது 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 அடைவு·முகவரி கிளிப்·오류는 [பயனர் ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `파일저장확정`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 அனுமதி_மதிப்பு·dup/fcntl은 없다. 디렉터리와 பியர்_மதிப்பு/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, 수신 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. பயனர் முடிவு_நிரல் 시 열린 கோப்பின்_பெயர் 서술자와 소켓을 회수한다.

## Java와 Python의 정확한 கிளிப்

자체 `javac`는 버전 49 `.class`를 생성하며 JVM은 ஆதரவு_மதிப்பு 명령으로 구성된 버전 45–52 클래스를 실행한다. மாறா_மதிப்பு செயல்பாடு_மதிப்பு·재귀·int/boolean/char/String·நிபந்தனை/மீள்செயல்_மதிப்பு·சரம்_மதிப்பு 결합과 일부 கோப்பின்_பெயர் 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/조합 자모 식별자를 처리한다. Unicode அடையாளங்காட்டி_மதிப்பு 전체 தேடுதல்_அட்டவணை·Unicode மூலம்_மரம் 이스케이프는 구현하지 않았다. 게스트 மூலம்_மரம் 컴파일러는 일반 பொருள்_மதிப்பு·விதிவிலக்கு·Thread 구문을 아직 컴파일하지 못한다. ஓம்பு `javac --release 8`로 만든 ஆதரவு_மதிப்பு 부분집합 클래스는 자체 JVM 0.4의 பொருள்_மதிப்பு·விதிவிலக்கு·Thread·UDP와 தமிழ் API를 사용할 수 있다. Swing은 문서화한 자체 API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [자체 JVM 설명](자바실행환경.md)이 기준이다. 상세 மொழி 범위는 [공유 Java கருவிகள் 설명](../../문서/자바개발환경.md)을 참고하되, 그 문서의 x86 கூடு/சேகரி_மதிப்பு/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 மூலம்_மரம்**를 자체 AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 செயல்பாடு_மதிப்பு·பிரிவு_மதிப்பு_55654bf1·விதிவிலக்கு·리스트/அகராதி·Unicode·GC·가변 정밀도 정수를 제공한다. 현재 구성은 முழு_எண் 빌드로 `float`, `complex`, `math`가 없으며 CPython 전체 표준 நூலகம், pip, subprocess, threading, 일반 socket과 இயல்புநிலை_மதிப்பு `open()` கோப்பின்_பெயர் 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 பொருள்_மதிப்பு·모듈은 முடிவு_நிரல் 시 회수되고 RAM 파일만 அடுத்து_உருப்படி 실행에 남는다.

`import jkoros`로 அடுத்து_உருப்படி 시스템 연결을 쓴다. 모두 SVC를 통해 자체 Java 커널에 접근한다.

| செயல்பாடு_மதிப்பு | செயல் |
|---|---|
| `stdin(limit)` | 현재 표준 입력에서 최대 limit바이트(0…16384)를 bytes로 읽음; EOF는 빈 bytes, UART தரவு 없음은 OSError(11) |
| `read(name)` | பியர்_மதிப்பு/절대 RAM 경로의 கோப்பின்_பெயர் 전체를 bytes로 읽음 |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 சேகரி_மதிப்பு, 쓴 பைட்_மதிப்பு 수 반환 |
| `remove(name)` | RAM கோப்பின்_பெயர் 삭제 |
| `rect(x, y, w, h, color)` | 선택한 அசல்_தரவு 화면 அளவு 안의 사각형 வரைதல்_மதிப்பு; 기존 보드의 RGB32 மதிப்பு |
| `ticks_ms()` | 부팅 후 밀리초, 32비트 சுற்று_மதிப்பு |
| `udp_open(port)` | 127.0.0.1의 UDP 소켓 திற/கட்டு_முடிவுப்_புள்ளி; 0은 자동 포트 |
| `udp_send(fd, port, data)` | 루프백 இலக்கு_மதிப்பு 포트에 str/bytes 버퍼 இடமாற்று_மதிப்பு |
| `udp_recv(fd)` | `(bytes, 보낸포트)` 반환; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | 소켓 மூடு |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```

이식 குறியீடு_மதிப்பு: [python/](파이썬연결/), [பயனர் Java இணைக்க](பயனர்/자바연결.c). 공식 [MicroPython 이식 பயனர்_உதவிக்_கோப்பு_eb81d7d9](https://docs.micropython.org/en/latest/develop/porting.html)를 참고했다. மூலம்_மரம் URL·ஹாஷ்_கோப்பு·라이선스는 [vendor பயனர்_உதவிக்_கோப்பு_eb81d7d9](vendor/README.md)에 기록했다.

## தமிழ் C தரவு_வகை·Python பிழை·மூட்டை நிறுவு_மதிப்பு

C 네트워크 API는 `struct 인터넷통신주소`, enum 상수와 அசல்_தரவு தமிழ் 함수로
구현한다. மேக்ரோ_மதிப்பு 별칭을 사용하지 않으며 이전 pk_* ABI도 유지한다.
Python 예제는 `முறைமை_பிழை`, `பிழை.அடைவு`, `பிழை.설명`을 사용한다.

`python3 கருவிகள்/இயக்கு_கட்டளை.py --desktop --network --pip`로 시작하면 게스트에서
`pip install micropython-bisect==3.3.3`을 사용할 수 있다. 현재는 ஓம்பு 중계를
이용하는 제한형 MicroPython மூலம்_மரம் 설치기이며 CPython pip·자동 의존성 해결·C 확장은
미지원이다. 설치한 `/lib` 자료는 RAM이다. [사용법과 제한](파이썬꾸러미.md).

## 화면 அளவு தேர்வு_மதிப்பு

`python3 கருவிகள்/இயக்கு_கட்டளை.py --desktop --network --resolution 1920x1080`으로 Full HD 화면을 사용한다. 기본값은 640×480이며 1280×720도 가능하다. கட்டளை_விளக்கி நகர்த்து_மதிப்பு, Swing 가운데 இணை_லேஅவுட், Java·C·Python 그리기도 அசல்_தரவு 크기를 따른다. SD 영상은 `make image RESOLUTION=1920x1080`으로 만든다. [அமைப்புகள்·தமிழ் API·சரிபார்_5fb2b747 பயனர்_உதவிக்_கோப்பு_eb81d7d9](화면해상도.md).

## தமிழ் 직접 API와 화면 புதுப்பி

`example/java`는 `실행할일`, `동작받이`, `동작알림`, `பொத்தான்`, `நிகழ்வு_சாரை`,
