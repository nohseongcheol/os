# JIndOS 구조

아래는 பொருள்_மதிப்பு 기반 관리 கரு_மதிப்பு 전체의 இலக்கு_பொருள் 구조다. 현재 அசல்_தரவு 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 இயக்க_முறைமை பயனர்_உதவிக்_கோப்பு_eb81d7d9](../os/பயனர்_உதவிக்_கோப்பு_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·சூழல்_மதிப்பு சுவிட்ச்_பயன்முறை·கோப்பு_முறைமை 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 அடுக்கு_மதிப்பு
  ↓
Java AOT 실행기와 பொருள்_மதிப்பு·கோவை_மதிப்பு_ed437109·GC 런타임
  ↓
하드웨어 경계
  ↓
Java 관리 கரு_மதிப்பு
  ├─ 기억공간/쪽관리/COW
  ├─ செயலகம்_மதிப்பு/배정/wait
  ├─ கோப்பு_முறைமை/ELF/POSIX
  └─ 입력/சேமிப்பகம்_சாதனம்/பிணையம்_அடுக்கு_49fba3da
```

OpenJDK 자체는 이미 운영체제가 제공하는 கோப்பின்_பெயர், 스레드, 가상 기억공간을 전제로 한다. 따라서 கரு_மதிப்பு 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, சூழல்_மதிப்பு 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
