# 자체 ARM64 JVM 0.4와 한국어 లైబ్రరీ

한국어 통신·మినహాయింపు 사용법은 [한국어 Java API](한국어자바/మార్గదర్శక_సమాచారం_eb81d7d9.md), కార్యం_మూల్యం·변수·దస్త్రం 이름의 변경과 어원 근거는 [명명 మార్గదర్శక_సమాచారం_eb81d7d9](명명/మార్గదర్శక_సమాచారం_eb81d7d9.md)를 참고한다.

JAR అమలు_చేయి_ఆదేశం, 외부 IPv4 TCP/UDP, 별도 నిశ్చల_మూల్యం 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 అంశం_మూల్యం·Thread·Swing은 JVM 경로의 기능이며 AOT మద్దతు_మూల్యం 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 అమలు_చేయి_ఆదేశం**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK తరగతి_మూల్యం లైబ్రరీ 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 తరగతి_మూల్యం·నిశ్చల_మూల్యం విధానం_మూల్యం_ba7ce9bf 중심이던 실행기를 అంశం_మూల్యం·లైబ్రరీ అమలు_చేయి_ఆదేశం 기반으로 넓힌 것이다.

## 실행과 నిర్మించు_మూలం

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# 자체 కెర్నల్_మూల్యం 안에서 మూలం_వృక్షాకృతి నిర్మించు_మూలం → class అమలు_చేయి_ఆదేశం, 한국어 API 호출
python3 ఉపకరణాలు/అమలు_చేయి_ఫైలు.py 시험/자바/한글소스.java

# అంశం_మూల్యం·మినహాయింపు 등은 హోస్ట్ JDK로 Java 8 class를 만든 후 자체 커널에서 అమలు_చేయి_ఆదేశం
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 ఉపకరణాలు/అమలు_చేయి_ఫైలు.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 బదిలీ_మూల్యం
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 ఉపకరణాలు/అమలు_చేయి_ఫైలు.py build/my-java/객체시험.class \
  --include build/my-java/నేపథ్యం_మూల్యం.class --include build/my-java/శాఖ_మూల్యం.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.తరగతి_మూల్యం.class`라는 RAM దస్త్రం 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.తరగతి_మూల్యం`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.తరగతి_మూల్యం`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar దస్త్రం.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 한국어 클래스만 찾는다. 배포 한국어 లైబ్రరీ JAR는 హోస్ట్ javac의 classpath로 사용하며, 같은 클래스가 వినియోగదారు JVM ELF에도 చదువు 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 నిశ్చల_మూల్యం విధానం_మూల్యం_ba7ce9bf, int/boolean/char/String, నిబంధన·పునరావృతం_మూల్యం, అక్షరసరం_మూల్యం 결합, 일부 దస్త్రం 스트림 등의 **자체 부분집합 컴파일러**다. అంశం_మూల్యం ప్రకటన·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 자체 JVM에서 실행한다. 한국어 API 중 అవుట్పుట్·문자 스칼라 కార్యం_మూల్యం·దస్త్రం చదువు/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] 인수) throws Exception {
        한국어.자체.అవుట్పుట్.వ్రాయి_పంక్తి("안녕하세요😀");
        한국어.자체.అవుట్పుట్.수쓰기(한국어.자체.문자.코드포인트수("한글😀"));
        한국어.자체.దస్త్రం.వ్రాయుము("인사.txt", "한글 దస్త్రం😀");
        한국어.자체.అవుట్పుట్.వ్రాయి_పంక్తి(한국어.자체.దస్త్రం.చదువు("인사.txt"));
    }
}
```

예외는 Throwable/Exception/RuntimeException, ArithmeticException, NullPointerException, IndexOutOfBoundsException/ArrayIndexOutOfBoundsException/StringIndexOutOfBoundsException, IllegalArgumentException/NumberFormatException/IllegalThreadStateException, IOException/FileNotFoundException, IllegalStateException, ClassCastException, NegativeArraySizeException, ArrayStoreException, UnknownHostException, SocketTimeoutException의 제한된 రూపొందించు·వర్గం_మూల్యం·처리를 제공한다. వినియోగదారు నిర్వచనం_మూల్యం Throwable 상속, stack trace/cause/suppressed మినహాయింపు, try-with-resources의 addSuppressed, 완전한 సంకల్పించు దోషం 포장은 아직 없다. 잡히지 않은 예외는 현재 전체 Java 실행을 실패로 끝낸다.

## 한국어 API

독립 패키지 **`한국어.자체`**를 사용한다. Linux판 `한국어.자바`가 요구하는 NIO/Swing/HTTP API를 자체 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 తరగతి_మూల్యం పేరు·విధానం_మూల్యం_ba7ce9bf·인수·ఫీల్డ్_మూల్యం·దస్త్రం 이름에 한국어를 사용한다. 표준 Java తరగతి_మూల్యం 이름은 호환성을 위해 보존한다.

| తరగతి_మూల్యం | 공개 기능 | 이름의 의미 |
|---|---|---|
| అవుట్పుట్ | వ్రాయుము, వ్రాయి_పంక్తి, 수쓰기 | అవుట్పుట్(出力): 내용을 바깥으로 내보냄 |
| 문자 | పొడవు_మూల్యం, 같음, అతికించు_పాఠం, కత్తిరించు_మూల్యం, పార్స్_పూర్ణాంకం/వ్రాయి_పూర్ణాంకం_మూల్యం, 코드포인트수, 부호화/వ్యక్తపరుచు_డేటా | 문자(文字), సంకేతీకరణం_మూల్యం(符號): 글의 단위와 그 값을 바이트로 나타내는 నియమం_మూల్యం |
| దస్త్రం | చదువు/వ్రాయుము(String పేరు), 바이트읽기/వ్రాయి_బైట్_మూల్యం | 널리 쓰는 వినియోగదారు 용어를 보존; RAM 자료의 పేరు |
| ప్రవేశం_జాబితా | 더하기, చదువు, మళ్లీ_పెట్టు_మూల్యం, తుడిచివేయి_ప్రవేశం, పరిమాణం, సమాచార_టెక్నాలజీ_ఖాళీ_మూల్యం, క్లియర్_చేయి_విషయసూచీ | ప్రవేశం_జాబితా(目錄): 순서가 있는 ప్రవేశం_మూల్యం 모음 |
| నిఘంటువు | 넣기, వెతుకు_ప్రవేశం, 있는가, తుడిచివేయి_ప్రవేశం, పరిమాణం, క్లియర్_చేయి_విషయసూచీ | నిఘంటువు(辭典): 찾는 말인 열쇠에 값을 대응 |
| 작업 | నడుపుము(실행할일), 기다리기(작업가닥), తాత్కాలికంగా_నిలిపివేయి_విధి, 살아있는가 | 작업 థ్రెడ్_మూల్యం: 한 అనువర్తనం_f5044b9b 안의 అమలు_చేయి_ఆదేశం ధార_మూల్యం |
| 통신 | తెరువు, పంపు, 받기, 대기시간, మూసివేయి | 통신(通信), 전문(電文), పోర్టు_మూల్యం: డేటా 교환·메시지·포트의 역할 |
| 화면 | 사각형, తుడిచివేయి_ప్రవేశం | 화면(畫面): వాస్తవ_డేటా 그림을 표시하는 면 |
| కెర్నల్_మూల్యం | 밀리초, 사각형 | 자체 JVM의 고정 native కనెక్టుచేయి; 일반 JNI는 아님 |

이 명명은 현재 기능을 설명하는 용어 선택이다. 기존 한국어에 없던 역사적 어원을 만들어 주장하지 않는다. ఫైలు_పేరు_పాఠం·식별자는 UTF-8 소스로 보관한다. `문자.వ్యక్తపరుచు_డేటా`는 잘못된 UTF-8에 IllegalArgumentException을 던지며, `부호화`는 짝이 없는 서로게이트를 `?`로 바꾼다. `దస్త్రం.చదువు`는 엄격한 UTF-8 복호화를 적용한다. 화면 색은 `빨강 | (초록 << 8) | (파랑 << 16)` 형식이다.

## అమలు_చేయి_ఆదేశం 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(한국어 తరగతి_మూల్యం 포함), class당 16 KiB·స్థిర_మూల్యం 풀 511항목, 전체 విధానం_మూల్యం_ba7ce9bf/ఫీల్డ్_మూల్యం 각각 512개. విధానం_మూల్యం_ba7ce9bf కోడ్_మూల్యం 8 KiB, స్థానిక_పరిధి 변수·피연산자 스택 각각 128슬롯, 인수 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 అమలు_చేయి_ఆదేశం 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- అంశం_మూల్యం 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 వాస్తవ_డేటా 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 దస్త్రం·대형 అక్షరసరం_మూల్యం·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 ఆదేశము 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 విండో మారు_మోడ్ 시 중단·재개한다. 일반 సర్వర్_మూల్యం·계산의 무제한 실행은 아직 없다. 미지원 ఆదేశము·వనరు_మూల్యం 부족은 명시적인 오류로 종료한다.
- RAM దస్త్రం 최대 64개, 파일당 16384바이트, పాత్ UTF-8 63바이트. RAM 디렉터리와 పియర్_మూల్యం/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 한국어 class는 RAM దస్త్రం 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 현재 경로에서 మూలం_వృక్షాకృతి·తరగతి_మూల్యం·డేటా 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 외부 IPv4를 제공한다. వాస్తవ_డేటా GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. 전문 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 అమలు_చేయి_ఆదేశం 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 శ్రేణి_మూల్యం, 완전한 శ్రేణి_మూల్యం 공변성·인터페이스 పొర_మూల్యం 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/గుప్తీకరి౦చు_డేటా/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 మద్దతు_మూల్యం 부분집합은 아래 및 개발 매뉴얼을 참고한다. తరగతి_మూల్యం దస్త్రం 전체 검증기·ప్రాప్తి_ప్రవేశం అనుమతి_మూల్యం/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 రక్షించు_మూల్యం 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM మూల్యం/నిర్థారీకరించు/తరగతి_మూల్యం 로더와 మినహాయింపు 모델 → 영속 VFS·mmap·గడియారం·원자 ఆపరేషన్_మూల్యం·వాస్తవ_డేటా 스레드/సింక్ ABI → OpenJDK java.base 및 native లైబ్రరీ 이식 → పరికరం_మూల్యం 네트워크·TCP/IP → విండో 시스템/అక్షరాకృతి_మూల్యం/입력기·java.desktop → Java SE 호환성 시험. 현재 자체 JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## నిర్థారీకరించు

`ఉపకరణాలు/자바가상기계시험.py`는 같은 Java 8 class 파일의 출력을 హోస్ట్ OpenJDK `-Xverify:all`과 QEMU raspi4b 자체 커널에서 비교한다. అంశం_మూల్యం/상속/인터페이스·switch·శ్రేణి_మూల్యం, మినహాయింపు/finally, 컬렉션/GC, Thread/잠금, 한국어 UTF-8/దస్త్రం/컬렉션, వాస్తవ_డేటా UDP 루프백/సమయం_మూల్యం 초과, 게스트 한글 మూలం_వృక్షాకృతి నిర్మించు_మూలం, శ్రేణి_మూల్యం టైప్_చేయండి_మూల్యం/కాపీ_మూల్యం/దస్త్రం 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 దస్త్రం తిరస్కరించు_మూల్యం 시험을 실행한다. UDP ప్రొజెక్ట్_మూలం 실행에는 హోస్ట్ 루프백 소켓 권한이 필요하다.

`ఉపకరణాలు/부팅시험.py`는 కెర్నల్_మూల్యం రక్షించు_మూల్యం/회귀 시험과 별도로 한국어 Java 화면 API가 వాస్తవ_డేటా 픽셀을 그렸는지도 QMP 화면 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. వాస్తవ_డేటా Pi4 하드웨어 부팅 시험과 전체 JDK 호환성 시험 결과는 아니다.


## JVM 0.3: 네트워크와 GUI పొడిగింపు_మూల్యం

`Socket`/`ServerSocket` రూపొందించు·కనెక్టుచేయి·accept·양방향 InputStream/OutputStream·close·EOF·సమయం_మూల్యం 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 외부 అంకె_మూల్యం IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 ముగించు_పాయింట్ 16개, Java 루프백 버퍼 1024바이트, 외부 TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. పరస్పర 이벤트 대기는 అమలు_చేయి_ఆదేశం 기한을 갱신하고 టెర్మినల్ మారు_మోడ్ 시 프로세스 상태를 నిల్వ_మూల్యం·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

한국어 `విండో`, `విడ్జెట్`, `연결통신` 클래스를 배포 JAR와 자체 JVM 내장 자원에 추가했다. 상세 విధానం_మూల్యం_ba7ce9bf·제한·మూలం_వృక్షాకృతి·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## 한국어 객체의 직접 అమలు_చేయి_ఆదేశం

`విండో`, `లేబుల్`, `పాఠం_ఫీల్డ్`, `బటన్`, `ఈవెంట్_నిరీక్షణ_క్రమం`, `동작알림`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. 자체 JVM의 అంశం_మూల్యం రూపొందించు,
ఆకృతి_మూల్యం 검사, 화면 호출, ఈవెంట్ 큐, థ్రెడ్_మూల్యం 스케줄러에 한국어 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 అమలు_చేయి_ఆదేశం 경로도 유지한다.
한국어 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

자체 실행기의 한국어 진입점은 `public static void నడుపుము()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 한국어 진입점을 우선한다.
명령행 인수는 `실행인수.개수()`와 `실행인수.పాఠ్యము(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. నిశ్చల_మూల్యం దస్త్రం 예제는 게스트
javac로도 컴파일하며, GUI/థ్రెడ్_మూల్యం 소스는 హోస్ట్ `javac --release 8`을 사용한다.
직접 GUI/థ్రెడ్_మూల్యం API는 자체 JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
한국어 가닥의 అమలు_చేయి_ఆదేశం·వేచియుండు_మూల్యం·중복 నడుపుము తిరస్కరించు_మూల్యం, GUI ఈవెంట్ 출처·సూచీ·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

విధానం_మూల్యం_ba7ce9bf 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
한국어 클래스도 실행되지만, అక్షరసరం_మూల్యం 리터럴·표준 లైబ్రరీ 재정의·native
కనెక్టుచేయి·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 예제](한국어자바/మార్గదర్శక_సమాచారం_eb81d7d9.md)를 참고한다.

## టెర్మినల్ 부분 పునశ్చరించు

తరలించు_మూల్యం·పరిమాణం 변경은 새 విండో 영역과 이전 자리에서 드러난 띠만 합성한다.
1920×32 పెల్(240 KiB)의 임시 그림에서 배경·겹친 విండో·అక్షరం_మూల్యం·GUI를 먼저
완성하고, 현재 చూపించు_మూల్యం 메모리와 비교하여 달라진 화소만 기록한다.
32줄보다 큰 영역은 여러 띠로 처리하므로 전체 프레임을 원자적으로
교체하거나 수직 동기에 맞추는 방식은 아니다. 전체 배경을 먼저 지우는
중간 화면은 표시하지 않는다. 좌표가 같으면 다시 그리지 않는다.

`make test-redraw`는 వాస్తవ_డేటా C 그리기 코드를 호스트의 మెమరీ_డేటా 화면에 연결해
తరలించు_మూల్యం 80회·పరిమాణం మార్చు_మూల్యం 40회·겹친 విండో 4개를 전체 합성 결과와 పెల్ 단위로 대조한다.
영역 밖 వినియోగదారు రేఖాచిత్రణ_మూల్యం, 동일 పెల్ 무기록, పాయింటర్ 밑그림, వాస్తవ_డేటా 화면 పంక్తి 간격을
검사한다. 이 시험의 시간은 హోస్ట్ CPU 측정이며 Pi 4/QEMU 속도로 해석하지 않는다.
`make test-resize`는 QEMU/VNC의 640×480 및 1920×1080에서 왼쪽 모서리 లాగు_మూల్యం,
한글 입력·vi 미저장 విషయం_మూల్యం·독립 విండో 크기를 검사한다.
