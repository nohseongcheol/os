# 한국어 Java 통신·మూ_ఫ·మినహాయింపు API

패키지는 `한국어.자체`다. హోస్ట్ `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·దస్త్రం·మినహాయింపు API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 థ్రెడ్_మూల్యం API는 자체 JVM 전용이다.
기존 표준 Java లైబ్రరీ 전체의 한국어 번역판은 아니다.

```java
import 한국어.자체.*;

public class నెట్_వర్క్ {
    public static void main(String[] 인수) throws మూ_ఫ_మినహాయింపు {
        కనెక్షన్ కనెక్టుచేయి = కనెక్షన్.తెరువు("10.0.2.2", 9000);
        try {
            కనెక్టుచేయి.대기시간(700);
            కనెక్టుచేయి.అవుట్పుట్().వ్రాయుము(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = కనెక్టుచేయి.입력();
            అవుట్పుట్.수쓰기(입력.చదువు());
        } catch (대기시간초과예외 దోషం) {
            అవుట్పుట్.వ్రాయి_పంక్తి(దోషం.설명());
        } finally {
            కనెక్టుచేయి.మూసివేయి();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
వినియోగదారు 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 అక్షరసరం_మూల్యం 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void నడుపుము()`도 진입점으로 받는다.

## 통신과 ధార_మూల్యం

| తరగతి_మూల్యం | 한국어 호출 |
|---|---|
| కనెక్షన్ | `తెరువు(ఇమెయిల్, పోర్ట్_సంఖ్య)`, `입력()`, `అవుట్పుట్()`, `대기시간(밀리초)`, `పోర్ట్_సంఖ్య()`, `స్థానిక_పోర్ట్_సంఖ్య()`, `연결됨()`, `닫힘()`, `మూసివేయి()` |
| 수신창구 | `తెరువు(పోర్ట్_సంఖ్య)`, `받기()`, `పోర్ట్_సంఖ్య()`, `대기시간(밀리초)`, `닫힘()`, `మూసివేయి()` |
| 입력흐름 | `చదువు()`, `చదువు(byte[])`, `చదువు(byte[], నడుపుము, పొడవు_మూల్యం)`, `మూసివేయి()` |
| 출력흐름 | `వ్రాయుము(int)`, `వ్రాయుము(byte[])`, `వ్రాయుము(byte[], నడుపుము, పొడవు_మూల్యం)`, `내보내기()`, `మూసివేయి()` |
| 전문통로 | `తెరువు(పోర్ట్_సంఖ్య)`, `పంపు(ఇమెయిల్, పోర్ట్_సంఖ్య, పాఠ్యము)`, `받기()`, `대기시간(밀리초)`, `పోర్ట్_సంఖ్య()`, `닫힘()`, `మూసివేయి()` |
| 연결통신 | `తెరువు(...)`, `수신열기(...)`는 위 한국어 객체를 반환 |
| 검사 | `참인지(నిబంధన, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`చదువు()`의 దస్త్రం 끝은 -1, శ్రేణి_మూల్యం 읽기의 반환값은 వాస్తవ_డేటా 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. పోర్ట్_సంఖ్య 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 자체 커널에서 512바이트까지 받으며, 주소는 అంకె_మూల్యం IPv4를 사용한다.
`localhost` 루프백 외의 పేరు 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.కనెక్టుచేయి/듣기/받기`, `통신.తెరువు/పంపు/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `కనెక్షన్`, `수신창구`, `전문통로`를 쓴다.

## 한국어 మినహాయింపు

모든 아래 클래스는 స్వయంసిద్ధ_విలువ 생성자, `새예외("설명")` 형태의 అక్షరసరం_మూల్యం 생성자와
`설명()`을 제공한다. వాస్తవ_డేటా రూపొందించు 문법은 `new 대기시간초과예외("వేచియుండు_స్థితి 끝")`이다.

| 한국어 మినహాయింపు | 상위 తరగతి_మూల్యం / 용도 |
|---|---|
| మినహాయింపు | `java.lang.Exception`, 직접 던지는 일반 검사 మినహాయింపు |
| 실행예외 | `java.lang.RuntimeException` |
| మూ_ఫ_మినహాయింపు | `java.io.IOException`, 한국어 దస్త్రం·통신 API의 검사 మినహాయింపు |
| 대기시간초과예외 | `మూ_ఫ_మినహాయింపు`, 통신 대기시간 초과 |
| ఇమెయిల్_అంశం_శోధన_మినహాయింపు | `మూ_ఫ_మినహాయింపు`, ఇమెయిల్ సరిచూడు వైఫల్యం_మూల్యం |
| 파일없음예외 | `మూ_ఫ_మినహాయింపు`, దస్త్రం తెరువు వైఫల్యం_మూల్యం |
| 통신예외 | `మూ_ఫ_మినహాయింపు`, 표준 SocketException 변환 |
| చెల్లని_కారకం_మినహాయింపు | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `చెల్లని_కారకం_మినహాయింపు` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| శూన్య_సూచన_మినహాయింపు | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| స్థితి_మినహాయింపు | `java.lang.IllegalStateException` |
| టైప్_చేయండి_ప్రసారం_మినహాయింపు | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| శ్రేణి_నిల్వ_వైఫల్యం | `java.lang.ArrayStoreException` |
| థ్రెడ్_స్థితి_మినహాయింపు | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 వేచియుండు_మూల్యం 중단 |

`మినహాయింపు`와 `실행예외`는 모든 한국어 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, దస్త్రం·통신 전체를 잡으려면 `catch (మూ_ఫ_మినహాయింపు దోషం)`를 쓴다.
한국어 API가 표준 మూ_ఫ 오류를 한국어 예외로 변환한다.
기존 한국어 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
మినహాయింపు 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 자체 JVM에 이 20종을 추가했다. 임의의 వినియోగదారు Throwable 하위 తరగతి_మూల్యం 전체를
지원하도록 확장했다는 뜻은 아니다.

## నిర్మించు_మూలం·అమలు_చేయి_ఆదేశం

```sh
cd /home/user/jkoros/platforms/rpi4-native
make బిల్డ్_సిస్టం
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 ఉపకరణాలు/అమలు_చేయి_ఫైలు.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 వినియోగదారు JVM ELF 안에 탑재된다. `.jar`는 హోస్ట్ javac의
తరగతి_మూల్యం 경로로 사용한다. మూలం_వృక్షాకృతి 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 한국어 예외의 `throws` 선언과 그 import를 인식한다.
자체 JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·అంశం_మూల్యం·소켓 예제 전체의 మూలం_వృక్షాకృతి 컴파일은 హోస్ట్ javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 수 있다.

వాస్తవ_డేటా TCP/UDP 예제는 [네트워크예제.java](../../../example/java/네트워크예제.java),
అమలు_చేయి_ఆదేశం 절차는 [example మార్గదర్శక_సమాచారం_eb81d7d9](../../../example/README.md),
మూలం_వృక్షాకృతి 명명 원칙은 [명명 మార్గదర్శక_సమాచారం_eb81d7d9](../명명/మార్గదర్శక_సమాచారం_eb81d7d9.md)에 있다.

## Swing విండో 예제

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` తదుపరి_అంశం `java 창예제`로 연다. పేరు 입력, 인사하기 버튼,
인사말과 క్లిక్_చెయండి_మూల్యం 횟수 పునశ్చరించు, X 닫기를 지원한다.

| 기능 | 한국어 직접 API |
|---|---|
| Runnable / run | `실행할일.అమలుపరుచు()` |
| ActionListener / actionPerformed | `동작받이.동작받기(동작알림 알림)` |
| ActionEvent | `동작알림.ఆదేశం_పాఠం()`, `ఈవెంట్_మూలం()`, `సూచీ()` |
| JFrame | `విండో(గవాక్షం_శీర్షిక, 폭, 높이)`, `జోడించు_మూలకం(화면구성요소)`, `చూపించు_గవాక్షం()`, `మూసివేయి()`, `보이는가()` |
| JButton | `బటన్(పాఠ్యము, 가로, నిలువు_స్థాయి, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `లేబుల్(...)`, `పాఠం_ఫీల్డ్(...)` |
| 공통 화면 మూలకం_మూల్యం | `화면구성요소.글읽기()`, `వ్రాయి_పాఠం(పాఠ్యము)`, `자리정하기(가로, నిలువు_స్థాయి, 폭, 높이)` |
| SwingUtilities.invokeLater | `ఈవెంట్_నిరీక్షణ_క్రమం.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `ప్రారంభం_విధి()`, `기다리기()`, `살아있는가()`, `తాత్కాలికంగా_నిలిపివేయి_విధి()` |
| 명령행 | `నడుపుము()`, `실행인수.개수()`, `실행인수.పాఠ్యము(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `విధానం_థ్రెడ్`가 한국어 తరగతి_మూల్యం·విధానం_మూల్యం_ba7ce9bf·서술자를
해석해 화면 요소와 అమలు_చేయి_ఆదేశం 가닥을 직접 만든다. చర్య 알림도 자체 객체이며
콜백으로 `అమలుపరుచు`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 అమలు_చేయి_ఆదేశం 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 హోస్ట్ JVM에서 무동작 객체가 생기지 않도록 하는 తిరస్కరించు_మూల్యం 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. హోస్ట్ javac로 컴파일한 వెనుకకు_మూల్యం 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import 한국어.자체.*;
public class 가닥예제 implements 실행할일 {
    public void అమలుపరుచు() { అవుట్పుట్.వ్రాయి_పంక్తి("한국어 작업 అమలు_చేయి_ఆదేశం"); }
    public static void నడుపుము() throws 대기중단예외 {
        작업가닥 థ్రెడ్_మూల్యం = 작업.నడుపుము(new 가닥예제());
        작업.기다리기(థ్రెడ్_మూల్యం);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
శ్రేణి_మూల్యం 인수 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 인수 없는 `నడుపుము()`을 우선한다.
기존 한국어 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.నడుపుము(Runnable)`을 사용하던 코드는 새 한국어 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API మద్దతు_మూల్యం 또는 모든 JDK 소스의 번역을 뜻하지 않는다.
