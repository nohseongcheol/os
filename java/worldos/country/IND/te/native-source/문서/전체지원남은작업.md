# 전체 మద్దతు_మూల్యం 요청의 현재 స్థితి_మూల్యం

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 వాస్తవ_డేటా C POSIX 일부 기능, 한국어 API/వనరు పేరు, IDE దస్త్రం 보존, 게스트 Java దస్త్రం 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/మార్గదర్శక_సమాచారం_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 అమలు_చేయి_ఆదేశం 가능한 క్లిప్ | 전체 지원에 필요한 작업 |
|---|---|---|
| Java నిర్మించు_మూలం·అమలు_చేయి_ఆదేశం | 게스트 제한형 javac/JVM, నిశ్చల_మూల్యం 단일 클래스와 일부 표준 అంశం_మూల్యం | 일반 అంశం_మూల్యం·తరగతి_మూల్యం కనెక్టుచేయి·మినహాయింపు·GC·스레드, 완전한 javac와 표준 తరగతి_మూల్యం లైబ్రరీ |
| దస్త్రం | POSIX 서술자, Java 단일 బైట్_మూల్యం దస్త్రం ధార_మూల్యం, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·అనుమతి_మూల్యం·잠금·일반 ఫైల్_వ్యవస్థ·పొడిగింపు_మూల్యం 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP హోస్ట్ 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 ఈవెంట్·అక్షరాకృతి_మూల్యం·విండో నిర్వహణా_వ్యవస్థ_మూల్యం, AWT 네이티브 연결과 Swing అమలు_చేయి_ఆదేశం 기반 |
| POSIX | 문서화한 దస్త్రం·단말·UDP 부분 | విధానం_మూల్యం·exec/fork·스레드·시그널·సమయం_మూల్యం·mmap·poll·파이프 등과 적합성 నిర్థారీకరించు |
| 언어별 పేరు | 한국어 46개 대응 ప్రవేశం_మూల్యం, వాస్తవ_డేటా C/Java/దస్త్రం పేరు 적용 | లక్ష్యం భాష 확정, 언어별 용례·역사 근거와 해당 వనరు·도구의 నిర్థారీకరించు |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 అమలు_చేయి_ఆదేశం 환경을 추가하는 방식은 별도의 కెర్నల్_మూల్యం·루트 ఫైల్_వ్యవస్థ·OpenJDK·그래픽 సర్వర్_మూల్యం·영구 నిల్వ_మూల్యం 구성을 가진 అమలు_చేయి_ఆదేశం 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

అమలు_చేయి_ఆదేశం 기반과 추가 లక్ష్యం 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
