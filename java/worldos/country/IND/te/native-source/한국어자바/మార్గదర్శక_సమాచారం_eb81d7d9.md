# 한국어 Java 도우미 లైబ్రరీ

OpenJDK 11 이상과 함께 쓰는 프로젝트 యజమాని_మూల్యం API다. 표준 Java లైబ్రరీ 전체의 번역판을 뜻하지 않는다. 기존 Java API·키워드·మినహాయింపు·자료형은 그대로 함께 쓴다.

전체 22개 도우미 메서드의 인수·반환값·제약, నిర్వహణా_వ్యవస్థ 안의 사용법, Python·C++ 호출 방법은 **[한국어 లైబ్రరీ వినియోగదారు_గైడ్](వినియోగదారు_గైడ్.md)**에 정리했다. [Python 호출 예제](예제/다른언어/파이썬호출.py)와 [C++ JNI 호출 예제](예제/다른언어/자바호출.cpp)도 제공한다.

`make`로 `build/한국어자바.jar`를 만든다. `javac -encoding UTF-8 -cp build/한국어자바.jar 예제/인사.java`로 예제를 컴파일한다. 실행은 `java -cp build/한국어자바.jar:예제 인사`다.

`인사` 예제는 그래픽 화면이 없으면 దస్త్రం·문자·스레드 결과와 안내만 출력한다. Swing 창은 그래픽 세션에서 실행해야 한다. QEMU에서는 [그래픽 అమలు_చేయి_ఆదేశం మార్గదర్శక_సమాచారం_eb81d7d9](../platforms/rpi4/README.md)의 `make run`으로 부팅한 వెనుకకు_మూల్యం VNC 데스크톱의 터미널을 사용한다.

| తరగతి_మూల్యం | 제공 기능 |
|---|---|
| దస్త్రం | UTF-8 텍스트·బైట్_మూల్యం చదువు/వ్రాయుము, 디렉터리·ప్రవేశం_జాబితా |
| 문자 | UTF-8 변환, NFC సాధారణీకరించు_మూల్యం, కోడ్_మూల్యం 포인트 수, 언어별 낱말 경계 |
| 통신 | HTTP(S) 요청, 제한시간을 가진 TCP కనెక్టుచేయి |
| 작업 | 스레드 నడుపుము·합류·వేచియుండు_మూల్యం, 작업 అనువర్తనం_లాంచర్ |
| 화면 | Swing 이벤트 처리와 విండో రూపొందించు |
| కార్యస్థలం | వనరు సంకలనంచేయు_మూల్యం·నిర్మించు_మూలం·అమలు_చేయి_ఆదేశం·అమలు_చేయి_ఆదేశం దస్త్రం రూపొందించు 화면 |

`char`는 UTF-16 కోడ్_మూల్యం 단위이므로 이모지 등을 한 글자로 처리할 때 కోడ్_మూల్యం 포인트 또는 문자 경계 API를 사용한다. 파일은 UTF-8로 저장한다. OpenJDK의 모든 Java2D/అక్షరాకృతి_మూల్యం/입력기 조합을 각각 검증한 것은 아니다.

이름은 현재 의미가 분명한 한국어 용례를 사용했다. 개별 명칭의 역사적 어원 검토를 완료했다고 주장하지 않는다. వనరు_మూల్యం 종료와 మినహాయింపు 처리는 표준 API의 계약을 따른다.
