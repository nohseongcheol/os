# engos 기능 대응표

이 표는 기존 `جێماو_ژێدەر/`의 شت_نرخ 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [ڕاستەکی_دەیتا 부팅 기능과 한계](../os/رێخۆشکەر_eb81d7d9.md)를 따로 기록한다.

## 기존 شت_نرخ 기반 관리 کوورەک_نرخ 전체를 부팅하기 위해 남은 لكاندن

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/ئامێر_نرخ 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot تێنووسین_خاڵ_نرخ, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 ریزکردنی_سیاق_نرخ Store_نرخ
- ڕاستەکی_دەیتا PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA گێژەن_نرخ
- Java شت_نرخ·ڕیزی_داتا_نرخ لینك_ڕیزبەست, 예외, ستاتیک_نرخ ئامادە_کردن, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT قۆناغ_نرخ
- FAT 디스크 구역을 ڕاستەکی_دەیتا ATA 장치와 연결하는 I_O 접착 چین_نرخ

위 관리 계층은 engos 기능의 Java 관리 구현과 جێدەر 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot تێنووسین_خاڵ_نرخ, ستاتیک_نرخ ئامادە_کردن·ژمارەی_سروشتی ڕیزی_داتا_نرخ, VGA/직렬/PS2, 명령해석기, بەکارهێنەر ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 جێدەر 루프백 패킷 왕복을 검증했다. 위 표의 شت_نرخ 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
