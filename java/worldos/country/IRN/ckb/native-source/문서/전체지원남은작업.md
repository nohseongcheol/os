# 전체 پشتیوانی_نرخ 요청의 현재 دۆخ_نرخ

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 ڕاستەکی_دەیتا C POSIX 일부 기능, 한국어 API/ژێدەر ناو, IDE فایل 보존, 게스트 Java فایل 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/رێخۆشکەر_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 جێبەجێکردن_فەرمان 가능한 کلیپ | 전체 지원에 필요한 작업 |
|---|---|---|
| Java دروست_کردن_ژێدەر·جێبەجێکردن_فەرمان | 게스트 제한형 javac/JVM, ستاتیک_نرخ 단일 클래스와 일부 표준 شت_نرخ | 일반 شت_نرخ·کلاس_نرخ لكاندن·예외·GC·스레드, 완전한 javac와 표준 کلاس_نرخ کتێبخانە |
| فایل | POSIX 서술자, Java 단일 بایت_نرخ فایل Stream_نرخ, 전용 میدیا_نرخ 보존 | 일반 java.io/nio, 디렉터리·ڕێپێدان_نرخ·잠금·일반 سیستمی_فایل·پاشبەند_نرخ 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP جێدەر 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 پێشهات·جۆرەپیت_نرخ·پەنجەرە سیستەمی_کارپێکردن_نرخ, AWT 네이티브 연결과 Swing جێبەجێکردن_فەرمان 기반 |
| POSIX | 문서화한 فایل·단말·UDP 부분 | پرۆسە_نرخ·exec/fork·스레드·시그널·کات_نرخ·mmap·poll·파이프 등과 적합성 ڕەوایی |
| 언어별 ناو | 한국어 46개 대응 تێنووسین_نرخ, ڕاستەکی_دەیتا C/Java/فایل ناو 적용 | مەبەست زمان 확정, 언어별 용례·역사 근거와 해당 ژێدەر·도구의 ڕەوایی |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 جێبەجێکردن_فەرمان 환경을 추가하는 방식은 별도의 کوورەک_نرخ·루트 سیستمی_فایل·OpenJDK·그래픽 ڕاژەکار_نرخ·영구 Store_نرخ 구성을 가진 جێبەجێکردن_فەرمان 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

جێبەجێکردن_فەرمان 기반과 추가 مەبەست 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
