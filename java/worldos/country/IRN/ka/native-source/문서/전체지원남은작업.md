# 전체 მხარდაჭერა_მნიშვნელობა 요청의 현재 სტატუსი_მნიშვნელობა

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 რეალური_მონაცემები C POSIX 일부 기능, 한국어 API/წყარო სახელი, IDE ფაილი 보존, 게스트 Java ფაილი 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/წასაკითხი_ფაილი_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 შესრულება_ბრძანება 가능한 კლიპი | 전체 지원에 필요한 작업 |
|---|---|---|
| Java აწყობა_წყარო·შესრულება_ბრძანება | 게스트 제한형 javac/JVM, სტატიკური_მნიშვნელობა 단일 클래스와 일부 표준 ობიექტი_მნიშვნელობა | 일반 ობიექტი_მნიშვნელობა·კლასი_მნიშვნელობა დაკავშირება·예외·GC·스레드, 완전한 javac와 표준 კლასი_მნიშვნელობა ბიბლიოთეკა |
| ფაილი | POSIX 서술자, Java 단일 ბაიტი_მნიშვნელობა ფაილი ნაკადი_მნიშვნელობა, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·ნებართვა_მნიშვნელობა·잠금·일반 ფაილური_სისტემა·გაფართოება_მნიშვნელობა 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP მასპინძელი 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 მოვლენა·შრიფტი_მნიშვნელობა·ფანჯარა ოპერაციული_სისტემა_მნიშვნელობა, AWT 네이티브 연결과 Swing შესრულება_ბრძანება 기반 |
| POSIX | 문서화한 ფაილი·단말·UDP 부분 | პროცესი_მნიშვნელობა·exec/fork·스레드·시그널·დრო_მნიშვნელობა·mmap·poll·파이프 등과 적합성 შემოწმება |
| 언어별 სახელი | 한국어 46개 대응 შენატანი_მნიშვნელობა, რეალური_მონაცემები C/Java/ფაილი სახელი 적용 | მიზანი ენა 확정, 언어별 용례·역사 근거와 해당 წყარო·도구의 შემოწმება |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 შესრულება_ბრძანება 환경을 추가하는 방식은 별도의 ბირთვი_მნიშვნელობა·루트 ფაილური_სისტემა·OpenJDK·그래픽 სერვერი_მნიშვნელობა·영구 შენახვა_მნიშვნელობა 구성을 가진 შესრულება_ბრძანება 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

შესრულება_ბრძანება 기반과 추가 მიზანი 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
