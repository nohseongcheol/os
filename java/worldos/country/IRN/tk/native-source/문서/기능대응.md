## 기존 obýekt_baha 기반 관리 ýadro_baha 전체를 부팅하기 위해 남은 Birikme

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/enjam_baha 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot girizmeklik_utuk_baha, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 Kontekst_baha Store_baha
- hakyky_maglumat PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA sikl_baha
- Java obýekt_baha·ARRAY_baha Bag_Ýerleşiş, 예외, statiki_baha ulanyşa_taýýarla, 가비지 수집기

- FAT 디스크 구역을 hakyky_maglumat ATA 장치와 연결하는 I_O 접착 dereje_baha

위 관리 계층은 engos 기능의 Java 관리 구현과 esasy 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot girizmeklik_utuk_baha, statiki_baha ulanyşa_taýýarla·bitin ARRAY_baha, VGA/직렬/PS2, 명령해석기, ulanyjy ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 esasy 루프백 패킷 왕복을 검증했다. 위 표의 obýekt_baha 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
