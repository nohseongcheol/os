# Raspberry Pi 4 بومی Java هسته_مقدار — کاربر اجرا_فرمان 기반

현재 بومی 코드의 COSL 상업 شرط, 제3자 고지 및 LGPL 재연결 자료는 [COSL 배포 مرا_بخوان_eb81d7d9](COSL배포안내.md)를 참고한다. جابجایی_حالت 전 GPL 구성의 판단은 [이전 라이선스 검토](مجوز_بررسی_5f09b7c9.md)에 기록했다.

فارسی 통신·استثنا 사용법은 [فارسی Java API](한국어자바/مرا_بخوان_eb81d7d9.md), عملکرد_مقدار·변수·پرونده 이름의 변경과 어원 근거는 [명명 مرا_بخوان_eb81d7d9](명명/مرا_بخوان_eb81d7d9.md)를 참고한다.

Linux 없이 부팅하는 بومی AArch64 커널이다. Java AOT هسته_مقدار 위에 **خط_فرمان واسط, 게스트 Java 컴파일러·JVM, MicroPython, EL0 C++ اجرا_فرمان, پرونده·UDP 루프백 시스템 호출, 여러 한글 GUI پایانه·vi ویرایشگر·Swing 부분집합**을 제공한다. 커널의 پرونده داده_ها/정책·루프백 انتقال_مقدار_630ba093·واسط 상태는 Java, 화면 합성·پیکسل تغییر_مقدار·اشاره_گر·클리핑도 Java로 구현하며, CPU/MMU/دستگاه_مقدار 경계와 پایانه·نویسه_مقدار 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 بومی 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 اجرا_فرمان, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 سیم_دار_مقدار 송수신은 아직 미검증이다.** اجرا_فرمان·اتصال_e05f319b·رمز_عبور_مقدار 확인은 [외부 اتصال_e05f319b مرا_بخوان_eb81d7d9](외부접속안내.md)에 정리했다.

셸은 EL1 هسته_مقدار, `java` 등 کاربر اجرا_فرمان 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 اجرا_فرمان·اتصال_e05f319b 방법 및 واقعی_داده_ها 검증은
[اجرا_فرمان 계층과 외부 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 واقعی_داده_ها اجرا_فرمان 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 ایستا_مقدار ELF는 `run --linux فایل_نام_متن`으로 실행한다. [ELF·Linux ABI پشتیبان_مقدار 범위와 동일 바이너리 시험](실행파일규약.md).

GUI와 네트워크는 `python3 ابزارها/اجرا_فرمان.py --desktop --network`로 함께 사용한다. Java·C·Python의 فارسی 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 부팅 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 수 있다. Remmina에서 **F9/Shift+Space/한·영 کلید_مقدار**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·واقعی_داده_ها TCP/UDP·پرونده بایت_مقدار·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java نمونهپنجره`로 فارسی Swing 예제를 실행한다. پایانه 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 현재 ستون_مقدار·ردیف_مقدار 수를 보여 준다.

اجرا_فرمان 버튼 화면은 5×7 영문 글꼴을 쓰며, پایانه 창은 Noto CJK/DejaVu에서 생성한 한글·Unicode 비트맵 글꼴을 쓴다. UART와 واقعی_داده_ها 프레임버퍼의 한글 표시를 시험한다. 루프백은 동일 هسته_مقدار 내부의 전문 전달이며 IP 패킷을 Ethernet으로 내보내는 드라이버가 아니다. 바깥 IPv4는 lwIP TCP/UDP 스택으로 보조 UART SLIP 경로를 사용한다. `python3 ابزارها/اجرا_فرمان.py --network`로 QEMU NAT를 연결하고 `ftpd start`로 서비스를 시작한다.

Java의 정확한 API·문법·اجرا_فرمان 제한과 فارسی 사용법은 [بومی JVM과 فارسی کتابخانه](자바실행환경.md)에 정리했다. کلاس_مقدار پرونده/JAR 배포는 [한국어자바](한국어자바) 소스에서 재현한다. 기존 Linux판 `فارسی.자바`와 별도인 `فارسی.بومی` 패키지다.

**vi·여러 پنجره·Swing·한글 Java/Python/C/C++·posix-kor 예제는 [한글 개발 매뉴얼](개발안내.md)에 정리했다.**

GUI پایانه اجرا_فرمان·단축키·واسط فرمان·제한은 [셸과 پایانه 사용법](셸과터미널.md)에 정리했다.

## 현재 컴퓨터에서 اجرا_فرمان

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

خروج_برنامه: **Ctrl+A بعدی_مورد X**. 게스트 C/AOT ابزارها 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. میزبان 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. 컴파일러 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/مسیر/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` پشتیبان_مقدار 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 اجرا_فرمان**한다. 기존 한 نویسه_مقدار 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 نشانوندها 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

| فرمان | کنش |
|---|---|
| `help` / `info` | فرمان·واقعی_داده_ها 구현 وضعیت_مقدار |
| `ls` / `cat FILE` / `rm FILE` | RAM پرونده ورودی_لیست·محتوا_مقدار·삭제 |
| `vi FILE` | کاربر 영역 vi 부분집합, 한글 ویرایش_مقدار·ذخیره_مقدار·검색·되돌리기 |
| `edit FILE` | پرونده 전체를 새로 입력; 단독 `.` 줄로 ذخیره_مقدار, Ctrl-C로 لغو_عملیات |
| `javac FILE.java` / `java CLASS [ARGS]` | بومی 제한형 Java ساختن_منبع·اجرا_فرمان |
| `python FILE.py [ARGS]` / `python -c 'CODE'` | MicroPython ساختن_منبع·اجرا_فرمان |
| `load FILE` / `hex FILE` | 16진수 바이너리 입력/خروجی; 입력은 단독 `.` 줄로 ذخیره_مقدار |
| `run FILE.elf [ARGS]` / `run cpp` | 업로드한 بومی ABI ELF / 내장 C++ 예제 |
| `net test` / `tasks` / `selftest` | UDP 루프백 / 협력식 작업 / EL0 حفاظت_کردن_مقدار 시험 |
| `gui` / `terminal` | اجرا_فرمان 화면 / 한글 GUI پایانه; F12로 پایانه باز_کردن·بستن |
| `samples` | 삭제한 مقدار_پیش_فرض 예제 بازیابی_وضعیت; 기존 파일은 보존 |

예를 들어 `edit 인사.java`를 입력한 بعدی_مورد 아래 소스를 입력한다.

```java
public class 인사 { public static void main(String[] args) { int مقدار = 7; System.out.println("한글=" + مقدار); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 인사.java`, `java 인사`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. لغو_عملیات·잘못된 16진수·용량 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, اجرا_فرمان 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 فرمان 인수는 최대 32개다. نقل_قول·백슬래시·واسط 변수·파이프·리다이렉션 범위는 [واسط 설명](셸과터미널.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, آدرس **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode 입력·명시적 جای_گذاری_مقدار·اجرا_فرمان 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 ابزارها/اجرا_فرمان.py --desktop --network
# 다른 포트: python3 ابزارها/اجرا_فرمان.py --desktop --port 5903
```

종료는 실행한 میزبان 터미널에서 Ctrl+C다. 기존 `python3 ابزارها/اجرا_فرمان.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. واقعی_داده_ها Pi4 USB 입력기는 아직 없으며, VNC اتصال 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 واقعی_داده_ها C++/UDP ELF اجرا_فرمان, `Hello.java` ساختن_منبع 후 JVM اجرا_فرمان, `hello.py` اجرا_فرمان, GUI پایانه 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 محاوره_ای 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 حافظه_داده_ها·CPU 문맥을 보관한다. واسط·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

| `dist/jkoros-native-aarch64-sdk.tar.gz` | 사용자용 헤더·اجرا_2 کد_مقدار·کتابخانه·링커 اسکریپت_مقدار·예제 |
| `dist/manifest.json`, `build/build.json` | SHA256과 واقعی_داده_ها پشتیبان_مقدار وضعیت_مقدار |

이미지는 확인된 공식 Pi 부팅 묶음에서 `start4.elf`, `fixup4.dat`, Pi4 DTB와 disable-bt overlay를 가져온다. Linux kernel/initramfs/rootfs는 넣지 않는다. 펌웨어·MicroPython·پایانه قلم_مقدار 라이선스와 قلم_مقدار 출처 해시도 동봉한다. پرونده ایجاد 스크립트는 물리 디스크에 기록하지 않는다.

예비 microSD에 ساخت_عکس واقعه_نگار_ردیف 도구로 `.img`를 기록하거나 FAT32 부팅 파티션 최상위에 ZIP 내용을 푼다. ساخت_عکس 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 مقدار_پیش_فرض EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD پرونده 구성·هسته_مقدار 체크섬 검사와 물리 تخته_ای 부팅 검증은 별개다. MMU 사용 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 부팅 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 فارسی API 사용

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/نمونهپرونده.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int شروع_کاربر_برنامه(int)`이다. کاربر C++는 FP/SIMD를 사용할 수 있다. هسته_مقدار C/Java AOT는 일반 레지스터만 사용하므로 استثنا فرآیند_مقدار_ورودی 중 کاربر FP 상태를 건드리지 않는다. کاربر ورودی_نقطه_مقدار 시 FP 상태를 초기화하고 هسته_مقدار 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int شروع_کاربر_برنامه(int) {
    int پرونده = ایجاد_فایل("인사.txt", خواندن_نوشتن | 없으면만들기 | 내용비우기, 0600);
    if (پرونده < 0) return 1;
    const char محتوا_مقدار[] = "안녕하세요";
    int سنجش = نوشتن_فایل_داده_ها(پرونده, محتوا_مقدار, sizeof(محتوا_مقدار) - 1);
    بستن_فایل(پرونده);
    return سنجش == sizeof(محتوا_مقدار) - 1 ? 0 : 2;
}
```

[پرونده 예제](کاربر/نمونهپرونده.cpp)와 [통신 예제](کاربر/통신예제.cpp)가 واقعی_داده_ها 부팅 시험 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 پرونده فرآیند_مقدار_ورودی 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 소켓 함수는 현재 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 هسته_مقدار 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 بعدی_مورد 도구를 사용하면 **새 QEMU를 부팅해 업로드한 واقعی_داده_ها 바이트를 재확인한 برگشت_مقدار 게스트에서 اجرا_فرمان**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 ابزارها/اجرا_فایل.py build/jkoros-native-sdk/demo.elf
python3 ابزارها/اجرا_فایل.py 예제/Hello.java "한글 نشانوندها"
python3 ابزارها/اجرا_فایل.py 예제/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 هسته_مقدار 묶음에 포함되어 이 پرونده 한도를 적용받지 않는다. **C++ 컴파일러는 میزبان SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 کتابخانه, PT_TLS, PT_INTERP, PT_DYNAMIC, اجرا_فرمان·نوشتن 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 فهرست·آدرس کلیپ·오류는 [کاربر ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `파일저장확정`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 مجوز_مقدار·dup/fcntl은 없다. 디렉터리와 مشابه_مقدار/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, 수신 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. کاربر خروج_برنامه 시 열린 پرونده 서술자와 소켓을 회수한다.

## Java와 Python의 정확한 کلیپ

بومی `javac`는 버전 49 `.class`를 생성하며 JVM은 پشتیبان_مقدار 명령으로 구성된 버전 45–52 클래스를 실행한다. ایستا_مقدار عملکرد_مقدار·재귀·int/boolean/char/String·شرط/تکرار_مقدار·رشته_مقدار_6ca8363c 결합과 일부 پرونده 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/조합 자모 식별자를 처리한다. Unicode شناسه_مقدار 전체 جستجو_جدول·Unicode منبع_درخت 이스케이프는 구현하지 않았다. 게스트 منبع_درخت 컴파일러는 일반 شئ_مقدار·استثنا·Thread 구문을 아직 컴파일하지 못한다. میزبان `javac --release 8`로 만든 پشتیبان_مقدار 부분집합 클래스는 بومی JVM 0.4의 شئ_مقدار·استثنا·Thread·UDP와 فارسی API를 사용할 수 있다. Swing은 문서화한 بومی API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [بومی JVM 설명](자바실행환경.md)이 기준이다. 상세 زبان 범위는 [공유 Java ابزارها 설명](../../문서/자바개발환경.md)을 참고하되, 그 문서의 x86 واسط/ذخیره_مقدار/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 منبع_درخت**를 بومی AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 عملکرد_مقدار·کلاس_مقدار·استثنا·리스트/لغت_نامه·Unicode·GC·가변 정밀도 정수를 제공한다. 현재 구성은 عدد_صحیح 빌드로 `float`, `complex`, `math`가 없으며 CPython 전체 표준 کتابخانه, pip, subprocess, threading, 일반 socket과 مقدار_پیش_فرض `open()` پرونده 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 شئ_مقدار·모듈은 خروج_برنامه 시 회수되고 RAM 파일만 بعدی_مورد 실행에 남는다.

`import jkoros`로 بعدی_مورد 시스템 연결을 쓴다. 모두 SVC를 통해 بومی Java 커널에 접근한다.

| عملکرد_مقدار | کنش |
|---|---|
| `stdin(limit)` | 현재 표준 입력에서 최대 limit바이트(0…16384)를 bytes로 읽음; EOF는 빈 bytes, UART داده_ها 없음은 OSError(11) |
| `read(name)` | مشابه_مقدار/절대 RAM 경로의 پرونده 전체를 bytes로 읽음 |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 ذخیره_مقدار, 쓴 بایت_مقدار 수 بازگرداندن_سنجش |
| `remove(name)` | RAM پرونده 삭제 |
| `rect(x, y, w, h, color)` | 선택한 واقعی_داده_ها 화면 اندازه 안의 사각형 نقاشی_مقدار; 기존 보드의 RGB32 مقدار |
| `ticks_ms()` | 부팅 후 밀리초, 32비트 چرخه_مقدار |
| `udp_open(port)` | 127.0.0.1의 UDP 소켓 باز_کردن/묶기; 0은 자동 포트 |
| `udp_send(fd, port, data)` | 루프백 مقصد_مقدار 포트에 str/bytes 버퍼 انتقال_مقدار_630ba093 |
| `udp_recv(fd)` | `(bytes, 보낸포트)` بازگرداندن_سنجش; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | 소켓 بستن |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```

이식 کد_مقدار: [python/](파이썬연결/), [کاربر Java اتصال](کاربر/자바연결.c). 공식 [MicroPython 이식 مرا_بخوان_eb81d7d9](https://docs.micropython.org/en/latest/develop/porting.html)를 참고했다. منبع_درخت URL·هاشور_فایل·라이선스는 [vendor مرا_بخوان_eb81d7d9](vendor/README.md)에 기록했다.

## فارسی C نوع_داده_ها·Python خطا·دسته_کردن نصب_مقدار

C 네트워크 API는 `struct 인터넷통신주소`, enum 상수와 واقعی_داده_ها فارسی 함수로
구현한다. ماکرو_مقدار 별칭을 사용하지 않으며 이전 pk_* ABI도 유지한다.
Python 예제는 `سیستم_خطا`, `خطا.فهرست`, `خطا.설명`을 사용한다.

`python3 ابزارها/اجرا_فرمان.py --desktop --network --pip`로 시작하면 게스트에서
`pip install micropython-bisect==3.3.3`을 사용할 수 있다. 현재는 میزبان 중계를
이용하는 제한형 MicroPython منبع_درخت 설치기이며 CPython pip·자동 의존성 해결·C 확장은
미지원이다. 설치한 `/lib` 자료는 RAM이다. [사용법과 제한](파이썬꾸러미.md).

## 화면 اندازه مورد_انتخابی_مقدار

`python3 ابزارها/اجرا_فرمان.py --desktop --network --resolution 1920x1080`으로 Full HD 화면을 사용한다. 기본값은 640×480이며 1280×720도 가능하다. پایانه انتقال_مقدار, Swing 가운데 پیوند_پیمایش, Java·C·Python 그리기도 واقعی_داده_ها 크기를 따른다. SD 영상은 `make image RESOLUTION=1920x1080`으로 만든다. [تنظیمات·فارسی API·ارزیابی_کردن مرا_بخوان_eb81d7d9](화면해상도.md).

## فارسی 직접 API와 화면 تازه_کردن

`example/java`는 `실행할일`, `동작받이`, `동작알림`, `دکمه`, `رویداد_صف`,
`작업가닥`, `اجرا_2()`을 사용할 수 있다. فارسی GUI/가닥을 بومی JVM에 직접
연결했으며, 표준 Swing/Thread를 감싸지 않는다. رشته_مقدار_6ca8363c 등 javac의 표준
계약과 전체 منبع_درخت 검토 범위는 [명명 مرا_بخوان_eb81d7d9](명명/مرا_بخوان_eb81d7d9.md), 사용법과 호환성 변경은
[فارسی Java API](한국어자바/مرا_بخوان_eb81d7d9.md)를 본다.

پایانه انتقال_مقدار·اندازه 변경은 바뀐 영역만 합성하고 달라진 화소만 표시한다.
[화면 تازه_کردن 설명](자바실행환경.md#پایانه-부분-تازه_کردن),
