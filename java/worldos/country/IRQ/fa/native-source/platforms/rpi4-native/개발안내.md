# بومی 커널에서 vi·여러 پایانه·한글 프로그래밍 사용하기

فارسی 통신·استثنا 사용법은 [فارسی Java API](한국어자바/مرا_بخوان_eb81d7d9.md), عملکرد_مقدار·변수·پرونده 이름의 변경과 어원 근거는 [명명 مرا_بخوان_eb81d7d9](명명/مرا_بخوان_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 بومی AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 پشتیبان_مقدار 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 اجرا_فرمان, 외부 TCP/UDP와 FTP는 [새 اجرا_فرمان 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 پایانه

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, آدرس **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 پایانه 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **오른쪽 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 اجرا_فرمان 버튼으로 다시 ستون_مقدار 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 현재 디렉터리, واسط 변수, فرمان واقعه_نگار_ردیف, 입력 중인 명령과 برنامه_f5044b9b اجرا_فرمان 상태를 보관한다. پرونده 저장소는 공유한다. vi와 Swing의 이벤트 منتظر_ماندن_مقدار 중에 다른 터미널로 전환하면 کاربر حافظه_داده_ها·레지스터·پرونده/소켓 연결을 보존했다가 돌아올 때 재개한다. **현재 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 بعدی_مورد 입력 منتظر_ماندن_مقدار 또는 기존 اجرا_فرمان 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 اجرا_فرمان 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 ویرایش_مقدار 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. 현재 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 پنجره 판단은 게스트 커널이 처리한다. QEMU اجرا_فرمان 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. واقعی_داده_ها Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI ابزارها 종료는 میزبان 터미널의 Ctrl+C다.

## vi 사용

```text
mkdir 작업
cd 작업
vi 인사.py
```

`vi`는 새로 구현한 **vi فرمان 부분집합** 편집기다. 내장 `build/user/vi.elf`를 보호된 کاربر 영역에 적재한다. پرونده 크기는 UTF-8 بایت_مقدار نمایش_دادن_جذر 16 KiB, 경로는 63바이트까지다. 디스크에 설치한 Vim/Neovim 바이너리를 실행하는 것이 아니다.

| کلید_مقدار/فرمان | کنش |
|---|---|
| `i`, `a`, `I`, `A` | 현재/بعدی_مورد مرتب_کردن 또는 خط 처음/끝에서 입력 |
| `o`, `O` | 아래/위에 새 줄을 만들고 입력 |
| Esc | 일반 حالت_مقدار |
| `h j k l`, 방향키 | UTF-8 문자/خط انتقال_مقدار |
| `0`, `$`, Home, End | خط 처음/끝 |
| `gg`, `G`, `:فهرست` | پرونده 처음/마지막 خط/اختصاص_مقدار خط |
| PgUp, PgDn | 화면 درس_مقدار انتقال_مقدار |
| `x`, Delete | 현재 문자 삭제 |
| `dd`, `yy`, `p` | خط 삭제/کپی_مقدار/جای_گذاری_متن |
| `u` | 마지막 편집을 بازگرداندن_پل; 한 مرحله_مقدار 토글 |
| `/رشته_مقدار_6ca8363c`, `n` | 단순 رشته_مقدار_6ca8363c 검색/بعدی_مورد 일치; 정규식 없음 |
| `:w`, `:w 다른이름` | RAM پرونده ذخیره_مقدار/다른 경로로 ذخیره_مقدار |
| `:q` | 변경이 없을 때 خروج_برنامه |
| `:q!` | 변경을 버리고 خروج_برنامه |
| `:wq`, `ZZ` | 저장하고 خروج_برنامه |

붙여 넣은 한글을 문자 경계에 맞춰 انتقال_مقدار·삭제한다. 일반 vi의 수량 접두사, ماکرو_مقدار, تنظیمات پرونده, 플러그인, 정규식, 여러 버퍼/분할 پنجره, 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/영 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 پنجره پنجره_عنوان `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 فرمان**으로 실행한다. 파이프·리다이렉션·اسکریپت_مقدار·`;`/`&&`/`||`로 연결한 실행에서 محاوره_ای 대기를 시작하면 거부한다. 입력 대기는 약 2초 CPU 기한을 갱신하지만 입력 منتظر_ماندن_مقدار 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## 한글 Java

vi에서 다음을 `인사.java`에 입력하고 Esc → `:wq`로 저장한다.

```java
public class 인사 {
    static int 더하기(int 첫째, int 둘째) { return 첫째 + 둘째; }
    public static void main(String[] نشانوندها) {
        int 합계 = 더하기(20, 22);
        System.out.println("안녕하세요 · 합계=" + 합계);
    }
}
```

게스트 셸에서 실행한다.

```text
javac 인사.java
java 인사
```

한글 فایل_نام_متن·کلاس_نام·روش_نام_متن·변수명·문자열을 사용할 수 있다. **게스트 javac는 ایستا_مقدار Java 부분집합**이다. شئ_مقدار·리스너·Swing·소켓을 사용하는 소스는 현재 میزبان JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 بومی JVM에 class를 올린다. بومی JVM에서 지원하는 바이트코드/API 범위는 [자바실행환경.md](자바실행환경.md)를 따른다.

```sh
# میزبان
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/스윙시험.java
python3 ابزارها/آپلود_فایل.py build/my-java/스윙시험.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. خروجی 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.کلاس_مقدار.class` 형식이다. 내장 فارسی 라이브러리는 별도 업로드가 필요 없다. فارسی پنجره API의 예제는 [한글창시험.java](시험/자바/한글창시험.java)이며 같은 방법으로 ساختن_منبع·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 منبع_درخت/클래스는 호스트의 `python3 ابزارها/اجرا_فایل.py مسیر/인사.java`로 별도 QEMU에 업로드·اجرا_فرمان·종료할 수 있다. محاوره_ای Swing에는 اجرا_فرمان 후 کاربر 입력을 유지하는 `make desktop`을 사용한다.

## بومی JVM의 Swing کلیپ

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 بومی Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | کنش |
|---|---|
| `JFrame` | پنجره_عنوان, اندازه·مرتب_کردن, نمایش_پنجره, بستن 정책, dispose |
| `JPanel` | فرزند_مقدار 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 رشته_مقدار_6ca8363c نمایش_مقدار·تغییر_مقدار |
| `JButton` | 버튼과 ActionListener کلیک_مقدار فرآیند_مقدار_ورودی |
| `JTextField` | 한 خط UTF-8 입력, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 بومی JVM의 단일 이벤트 اجرا_فرمان 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. پنجره·요소는 اجرا_فرمان 하나당 합계 32개, عنصر_مقدار 글자는 최대 127 코드포인트다. مقدار_پیش_فرض 서체와 색은 커널이 제공한다.

[스윙시험.java](시험/자바/스윙시험.java)는 پنجره·한글 برچسب_مقدار·متن_فیلد·버튼·이벤트 처리의 اجرا_فرمان 가능한 예제다. [بومی Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

فارسی 라이브러리에는 다음을 추가했다. میزبان ساختن_منبع 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `فارسی.بومی.پنجره`: `افزودن_عنصر`, `نمایش_پنجره`, `بستن`.
- `فارسی.بومی.ویجت`: `برچسب_مقدار`, `دکمه`, `متن_فیلد` ایجاد.
- `فارسی.بومی.연결통신`: `اتصال`, `듣기`, `받기`.
- 기존 `خروجی`, `문자`, `پرونده`, `작업`, `ورودی_لیست`, `لغت_نامه`, `통신`, `화면`, `هسته_مقدار`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **هسته_مقدار 내부 연결형 بایت_مقدار جریان_مقدار**을 추가했다. پرونده/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket سرور_مقدار = new java.net.ServerSocket(9250);
java.net.Socket مهمان_مقدار = new java.net.Socket("localhost", 9250);
java.net.Socket اتصال = سرور_مقدار.accept();
مهمان_مقدار.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int طول_مقدار = اتصال.getInputStream().read(받은것);
اتصال.close(); مهمان_مقدار.close(); سرور_مقدار.close();
```

ایجاد·اتصال·accept·양방향 بایت_مقدار/آرايه_مقدار ورودی_خروجی·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 پایان_دادن_نقطه 16개, 수신 버퍼당 1024바이트, منتظر_ماندن_مقدار اتصال 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. مقدار_پیش_فرض زمان_مقدار 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM فرمان 수/هسته_مقدار اجرا_فرمان 기한은 여전히 적용된다.

외부 رقم_مقدار IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. واقعی_داده_ها Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP کتابخانه 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 واقعی_داده_ها 송수신·EOF·기한·اتصال 회수의 시험 예제다.

## 한글 Python

게스트 vi에서 한글 이름을 사용해 작성한다.

```python
مقدار = 21

def 두배(رقم_مقدار):
    return رقم_مقدار * 2

print("سنجش:", 두배(مقدار))
```

ذخیره_مقدار 후 `python 인사.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 عملکرد_مقدار·변수·پرونده 이름과 문자열을 한글로 쓴다.

[فارسی.py](예제/한글코딩/فارسی.py)를 같은 디렉터리에 두면 بعدی_مورد 별칭을 사용할 수 있다.

```python
import فارسی
فارسی.نوشتن_فایل("인사.txt", "안녕하세요")
فارسی.خروجی(فارسی.파일읽기("인사.txt").decode())
```

خروجی·پرونده خواندن/نوشتن/삭제·표준 입력·사각형·زمان_مقدار·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 رقم_مقدار IPv4 آدرس 전송이다. `wait_key()`는 화면을 확인할 때 محاوره_ای 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor ایستا_مقدار 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 تمدید_مقدار 모듈은 아직 없다. 제한형 `pip`의 منبع_درخت 설치는 [Python دسته_کردن مرا_بخوان_eb81d7d9](파이썬꾸러미.md)를 따른다. [세 언어의 واقعی_داده_ها 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 زبان 모두 فارسی 헤더와 عملکرد_مقدار 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 واقعی_داده_ها EL0 اجرا_فرمان 시험 대상이다.

```c
#include "파일규약.h"
#ifdef __cplusplus
extern "C"
#endif
int شروع_کاربر_برنامه(int نشانوندها) {
    (void)نشانوندها;
    const char 인사말[] = "안녕하세요\n";
    int 문서 = ایجاد_فایل("인사.txt", خواندن_نوشتن | 없으면만들기 | 내용비우기, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = نوشتن_فایل_داده_ها(문서, 인사말, sizeof(인사말) - 1);
    بستن_فایل(문서);
    نوشتن_فایل_داده_ها(1, 인사말, sizeof(인사말) - 1); /* 현재 پایانه stdout */
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 수 있다. C는 게스트 `cc` 또는 میزبان SDK, C++는 میزبان SDK의 Clang++로 컴파일한다. 아래 예제는 기존 میزبان SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh

make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/인사.c -o 인사-c.elf
python3 compile.py examples/인사.cpp -o 인사-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 واقعی_داده_ها اجرا_فرمان
cd /home/user/jkoros/platforms/rpi4-native
python3 ابزارها/اجرا_فایل.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 ابزارها/اجرا_فایل.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

현재 GUI VM에서 실행하려면 `python3 ابزارها/آپلود_فایل.py مسیر/인사-c.elf`의 출력을 게스트에 보내고 `run 인사-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex فایل_نام_متن`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 수 있다. 호스트와 게스트의 پرونده 시스템은 별개다.

| فارسی نام | C نماد | کلیپ |
|---|---|---|
| ایجاد_فایل/بستن_فایل | pk_open/pk_close | RAM پرونده, مشابه_مقدار/절대 مسیر |
| 파일자료읽기/نوشتن_فایل_داده_ها | pk_read/pk_write | پرونده, fd 0/1/2 표준 ورودی_خروجی, 연결형 소켓 |
| جستجو_کردن_فایل | pk_lseek | 처음기준/현재기준/끝기준 |
| فایل_اندازه_کردن/مجموعه_فایل_طول | pk_size/pk_ftruncate | طول_مقدار جستار_مقدار/تغییر_مقدار |
| حذف_فایل_ورودی_نام | pk_unlink | پرونده نام 삭제 |
| 파일저장확정 | pk_fsync | RAM이므로 -1, 오류번호=ENOSYS |
| 통신종단점만들기/مرتبط_سازی_آدرس | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |
| 자료전문보내기/자료전문받기 | pk_sendto/pk_recvfrom | UDP 루프백 |
| اتصال_شبکه | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | منتظر_ماندن_مقدار اتصال 최대 4개 |
| پذیرش_اتصال_شبکه | pk_accept | 현재 آدرس 인수는 NULL/NULL만 پشتیبان_مقدار |
| 통신주소읽기 | pk_getsockname | 로컬 آدرس/تبدیل_مقدار |

`통신규약.h`의 بومی `pk_sockaddr_in`을 사용하며 تبدیل_مقدار·주소는 `망차례짧은수`/`شبکه_عدد_صحیح`로 변환한다. C 소켓 호출은 비차단이며 داده_ها/연결이 없으면 -1과 `오류번호=11`(EAGAIN)을 반환한다. 양수 ورودی_خروجی 결과가 요청보다 작을 수 있으므로 تکرار_مقدار 처리한다. عدم_موفقیت_مقدار 후에만 오류번호를 확인한다.

[جریان_مقدار.c](예제/한글코딩/جریان_مقدار.c)는 C에서 فارسی 이름으로 اتصال·accept·부분 خواندن/نوشتن·큐 포화·EOF를 처리하는 اجرا_فرمان 예제다. SDK의 `examples/جریان_مقدار.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → واقعی_داده_ها فارسی C عملکرد_مقدار 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·اشاره_گر 검사 → Java RAM پرونده/루프백 또는 외부 lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 هسته_مقدار 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 اتصال, 표준 C printf, libstdc++/STL, استثنا·RTTI는 제공하지 않으며 C++의 ایستا_مقدار 생성자·محلی_محدوده شئ_مقدار 소멸자는 지원한다. 상세 فهرست·حافظه_داده_ها 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## ارزیابی_کردن

`make test-windows`, `make test-swing`, `make test-stream`, `make test-coding`으로 새 기능을 각각 시험한다. `make test`는 기존 واسط·VNC·JVM·AOT·هسته_مقدار حفاظت_کردن_مقدار 시험까지 포함한다. واقعی_داده_ها تخته_ای 대신 QEMU raspi4b에서 수행한다. 결과는 [이전 GUI تمدید_مقدار ارزیابی_کردن واقعه_نگار_ردیف](build/verification/release.json)과 [현재 زمان_اجرای_زبان_مشترک ارزیابی_کردن واقعه_نگار_ردیف](build/verification/native-runtime-summary.json), [여러 پایانه 화면](build/verification/windows/four-terminals.png), [Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

구현 시 참고한 표준 API: [Socket](https://docs.oracle.com/javase/8/docs/api/java/net/Socket.html), [JFrame](https://docs.oracle.com/javase/8/docs/api/javax/swing/JFrame.html), [JButton](https://docs.oracle.com/javase/8/docs/api/javax/swing/JButton.html). 이 문서의 구현 범위가 위 표준 전체를 지원한다는 뜻은 아니다.

## فارسی 이름으로 직접 작성하는 창과 رشته_مقدار

`example/java/نمونهپنجره.java`는 `실행할일.اجرا`,
`동작받이.동작받기(동작알림)`, `دکمه`, `رویداد_صف.나중에실행`, `اجرا_2()`을 쓴다.
بومی JVM에 이 이름들의 شئ_مقدار·روش_مقدار·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `작업가닥`도 بومی 스케줄러와 직접 연결된다.
세부 메서드와 기존 فارسی API에서의 변경은 [فارسی API 문서](한국어자바/مرا_بخوان_eb81d7d9.md)를 본다.

میزبان javac는 배포 JAR를 کلاس_مقدار 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/نمونهپنجره.java
python3 ابزارها/اجرا_فرمان.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java نمونهپنجره
```

직접 화면/رشته_مقدار API와 `اجرا_2()` 진입점은 بومی JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
