# 전체 پشتیبان_مقدار 요청의 현재 وضعیت_مقدار

요청 전체는 아직 완료되지 않았다. 현재 ISO는 بومی Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 واقعی_داده_ها C POSIX 일부 기능, فارسی API/مبداء نام, IDE پرونده 보존, 게스트 Java پرونده 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/مرا_بخوان_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 اجرا_فرمان 가능한 کلیپ | 전체 지원에 필요한 작업 |
|---|---|---|
| Java ساختن_منبع·اجرا_فرمان | 게스트 제한형 javac/JVM, ایستا_مقدار 단일 클래스와 일부 표준 شئ_مقدار | 일반 شئ_مقدار·کلاس_مقدار اتصال·استثنا·GC·스레드, 완전한 javac와 표준 کلاس_مقدار کتابخانه |
| پرونده | POSIX 서술자, Java 단일 بایت_مقدار پرونده جریان_مقدار, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·مجوز_مقدار·잠금·일반 سیستم_پرونده·تمدید_مقدار 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP میزبان 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 رویداد·قلم_مقدار·پنجره سیستم_عامل_مقدار, AWT 네이티브 연결과 Swing اجرا_فرمان 기반 |
| POSIX | 문서화한 پرونده·단말·UDP 부분 | فرآیند_مقدار·exec/fork·스레드·시그널·زمان_مقدار·mmap·poll·파이프 등과 적합성 ارزیابی_کردن |
| 언어별 نام | فارسی 46개 대응 ورودی_مقدار, واقعی_داده_ها C/Java/پرونده نام 적용 | هدف زبان 확정, 언어별 용례·역사 근거와 해당 مبداء·도구의 ارزیابی_کردن |

بومی 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 اجرا_فرمان 환경을 추가하는 방식은 별도의 هسته_مقدار·루트 سیستم_پرونده·OpenJDK·그래픽 سرور_مقدار·영구 ذخیره_مقدار 구성을 가진 اجرا_فرمان 경로가 된다. 후자는 기존 بومی 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

اجرا_فرمان 기반과 추가 هدف 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
