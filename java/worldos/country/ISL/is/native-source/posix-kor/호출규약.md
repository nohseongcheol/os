대상은 jkoros i386 ELF32다. Linux i386의 호출 번호와 바이너리 호환이 아니다. C의 cdecl 인수를 `vél/stýrikerfi_Símtöl.s`에서 EAX(INDEX), EBX·ECX·EDX·ESI·EDI(첫째~다섯째 Viðföng)로 변환한다. EBX·ESI·EDI·EBP를 보존하며 결과는 EAX다. kjarni_VALUE 실패는 음수 Villa INDEX, C safn 실패는 -1과 양수 errno다.

커널은 0x04000000 이상, 0x04400000 미만의 notandi 영역 안에 자료의 전체 길이가 들어가는지 확인한다. 단순 널 검사가 아니다. C gögn 주소는 bæti_VALUE 주소이며, 기존 Java AOT `int[]` 포인터와 혼용하지 않는다. Java Skrá 흐름의 어셈블리 경계가 별도 bæti_VALUE 버퍼를 마련하여 같은 호출을 사용한다.
