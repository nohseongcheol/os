## keyra_skipun 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(Íslenska klasi_VALUE 포함), class당 16 KiB·fasti_VALUE 풀 511항목, 전체 aðferð_VALUE/reitur_VALUE 각각 512개. aðferð_VALUE CODE_VALUE 8 KiB, staðbundið_umfang 변수·피연산자 스택 각각 128슬롯, Viðföng 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 keyra_skipun 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- hlutur_VALUE 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 raun_gögn 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 Skrá·대형 strengur_VALUE·객체가 이 제한을 넘을 númer 있다.
- 실행은 50만 바이트코드 Skipun 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 Gluggi SWITCH_MODE 시 중단·재개한다. 일반 þjónn_VALUE·계산의 무제한 실행은 아직 없다. 미지원 Skipun·tilfang_VALUE 부족은 명시적인 오류로 종료한다.
