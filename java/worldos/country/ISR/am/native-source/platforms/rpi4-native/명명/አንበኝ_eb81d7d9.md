# 자체 커널과 번역기의 አማርኛ ስም

대상은 `platforms/rpi4-native`의 자체 Java ዓንኳር_እሴት, ተጠቃሚ JVM, C ማሽን መገናኛ,
TCP/UDP·FTP, C 번역기 이식부, MicroPython 이식부, ግንብ_ስርዓት·ፈጽም_ትእዛዝ·시험 도구다.
`golang/worldos/나라/KOR/ምንጭ`의 원칙처럼 기능을 먼저 구분하고 이름을 정한다.
x86 Java 커널과 공용 x86·ARM64 미리 번역기의 자체 선언도 명명 검사에 포함한다.
Linux 실행판의 አዘጋጅ_b78e430d መሳሪያዎች, OpenJDK 보조 መሳሪያዎች 및 외부 배포 ምንጭ_ዛፍ 전체를
한국어로 다시 작성했다는 뜻은 아니다.

## 명명 원칙과 말의 근거

- 명사는 자료의 역할을 나타낸다: `ፋይል_እጀታ`, `አቻ_የወደብ_ቁጥር`, `동적기억공간`, `የቁልፍ_ሰሌዳ`.
- 함수는 행위를 나타낸다: `ማንበቢያ`, `መጻፊያ`, `መክፈቻ`, `መዝጊያ`, `망주소묶기`, `አሂድ_ፕሮግራም`.
- TCP의 이어진 ባይት_እሴት 흐름과 UDP의 경계 있는 자료를 `ግንኙነት`와 `전문통로`로 구별한다.
- 짧은 영어 변수도 쓰임에 따라 `ርዝመት_እሴት`, `ውሂብ_በቦታ_አስቀመጠ`, `ፍለጋ_መረጃ_ጠቆመ`, `반환값`으로 풀어 쓴다.
  순번·임시 산술값처럼 여러 역할에 재사용되는 변수는 `순번`, `첫째값`, `둘째값`으로 구별한다.
- 이름이 같아도 외부 구조체의 필드와 자체 변수는 별도로 분석한다.

`ሰርጥ_ምዝግብ(通路)`는 이동이나 교류가 이루어지는 길이라는 기존 의미를 통신 연결에
적용했다. `ወደብ_እሴት(窓口)`의 주고받는 접점이라는 의미를 연결을 받는 곳에 적용했다.
이는 국립국어원 한국어기초사전의 [ሰርጥ_ምዝግብ](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=49310),
[ወደብ_እሴት](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=24898)의 뜻에 근거한다.

`전문(電文)`은 전보에 담는 글이라는 기존 통신 어휘에서 가져와, UDP 자료의
경계가 보존된다는 특징을 드러내는 데 쓴다. 근거는
[한국어기초사전 전문](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=74335)이다.
`ልቀቅ_እሴት`, `ክር_እሴት`, `쌓임`은 우리말의 움직임·이어짐·쌓이는 모양을 빌린 표현이다.
`입력흐름`, `작업가닥`, `ክምር_ማከማቻ` 같은 복합 이름은 이 프로젝트의 기능별 조어다.
이 መዝገበ_ቃላት 근거를 특정 중세 문헌의 최초 출현이나 공인 전산 번역으로 확대하지 않는다.
공인 표준 ተርጉም_ምንጭ·국어사 전문 감수를 마쳤다는 뜻도 아니다.

| 기능 | 채택한 ስም | 이유 |
|---|---|---|
| TCP Socket | ግንኙነት | 상대와 연결되어 ቅደም_ተከተል_እሴት 있는 바이트를 주고받음 |
| ServerSocket | 수신창구 | 새 연결이 들어오는 접점 |
| DatagramSocket | 전문통로 | 각 자료의 경계를 보존하는 통신 |
| InputStream / OutputStream | 입력흐름 / 출력흐름 | 들어오고 나가는 바이트의 ቅደም_ተከተል_እሴት |
| heap / stack | 동적기억공간 / ክምር_ማከማቻ | መደብ_ማከማቻ 방식과 쌓고 꺼내는 구조 |
| thread / keyboard | 작업가닥 / የቁልፍ_ሰሌዳ | 이어지는 실행과 글쇠의 ድርድር_እሴት |
| exception / timeout | ልዩነት / 대기시간초과예외 | 정상 처리에서 벗어남과 그 구체적 이유 |

## 보존하는 규격 ስም

`public`, `class`, `int`는 예약어다. `String`, `main`, 배열의 `length`는 예약어가 아니다.
현재 다섯 Java 예제는 `ማስኬጃ()`·`실행인수`·አማርኛ 화면/ክር_እሴት API를 사용해
예약어·리터럴 외의 식별자를 한국어로 작성한다. 화면/가닥은 표준 객체를
감싸지 않고 자체 JVM에 직접 구현했다. 자세한 계약은 [አማርኛ Java API](../한국어자바/አንበኝ_eb81d7d9.md)를 본다.

표준 javac는 ኅብረቁምፊ_እሴት 리터럴에 `java.lang.String`, ኅብረቁምፊ_እሴት 결합에 `StringBuilder`
같은 이름을 생성한다. 이들은 አማርኛ 소스에서도 바이트코드에 남을 수 있다.
기존 표준 class를 실행하는 JVM의 대응 ኅብረቁምፊ_እሴት, 아직 표준 라이브러리를 쓰는
통신·ፋይል 연결부까지 모두 한국어로 재구현한 것은 아니다. 이름만 일괄 치환하면
서술자·재정의·native 연결이 달라져 호환성이 깨진다.

C 표준 ተግባር_እሴት·ኢንተጀር_ተይብ·POSIX ABI, CPU መዝግብ_እሴት ስም, 어셈블리 ትእዛዝ, 링커 절 ስም,
TinyCC·lwIP·MicroPython이 요구하는 ማሰናጃዎች 매크로와 헤더 이름도 보존한다.
예: `main`, `memcpy`, `pk_bind`, `mpconfigport.h`, `lwipopts.h`, `stdint.h`.
자체 C 함수의 ምንጭ_ዛፍ 이름은 한국어이며, [기계연결이름.h](기계연결이름.h)가
기존 AOT·어셈블리·SDK에 공개한 ማሽን 심볼과 연결한다.
Python의 `__init__`, `setUp`, `handle`, 표준 ሞጁል_እሴት ዓይነታ_እሴት, 명령행 옵션과 JSON 키도
외부 계약이다. `build/`, 배포 바이너리 이름과 `/sdk`는 기존 ፈጽም_ትእዛዝ 경로를 유지한다.
외부 원본은 `vendor/`에서 이용허락·해시와 함께 관리한다.

## 검사와 재실행

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 መሳሪያዎች/명명검사.py
make ግንብ_ስርዓት
make 시험
make test-examples test-ftp test-elf
python3 መሳሪያዎች/ፈጽም_ትእዛዝ.py --desktop --network
```

`መሳሪያዎች/시언어이름분석.py`는 libclang 6으로 C 선언과 참조를 검사한다.
`መሳሪያዎች/*이름반영.py`는 ለውጥ_እሴት 전 ምንጭ_ዛፍ·분석표를 필요로 하는 일회성 이행 도구다.
이미 변경된 소스에 다시 적용하여 대응표를 덮어쓰지 않는다.

## C 통신 구조체와 Python ስህተት

C 통신에서 `갈래`는 አድራሻ 체계를 구분하고 `የወደብ_ቁጥር`는 port, `አድራሻ_እሴት`은
IPv4 주소의 32비트 값을 나타낸다. `전문전송규약`은 앞서 설명한 전문(電文)과
ስራ_እሴት_102996da(規約)을 결합해 UDP의 기능을 드러낸 프로젝트 이름이다.

| 표준 표현 | አማርኛ 직접 구현 |
|---|---|
| AF_INET / SOCK_DGRAM / IPPROTO_UDP | enum의 ክላውድ_ቤተሰብ / 전문통신 / 전문전송규약 |
| struct pk_sockaddr_in | struct 인터넷통신주소 |
| sin_family / sin_port | አድራሻ_ቤተሰብ / የወደብ_ቁጥር |
| sin_addr.s_addr | የበይነመረብ_አድራሻ.አድራሻ_እሴት |
| OSError / ስህተት.args[0] | ስርዓት_ስህተት / ስህተት.መረጃ_ጠቆመ |

አማርኛ 구조체는 `#define` 치환이나 መስክ_እሴት 별칭이 아닌 별개 자료형이다.
표준 구조체와 같은 16바이트 배치를 선언하며 ዓንኳር_እሴት SVC에서 ባይት_እሴት 복사로
검사한다. `통신종단점만들기`·`자료전문보내기`와 ፋይል 함수는 አይንቀሳቀሴ_እሴት 라이브러리에
ትክክለኛ_ውሂብ አማርኛ 이름의 ተግባር_እሴት 심볼을 갖는다. 기존 pk_* 심볼도 유지한다.
이전 코드에서 አማርኛ 통신 함수에 pk_sockaddr*를 전달했다면 አማርኛ 구조체로
옮기거나, 표준 구조체와 pk_* 함수의 짝을 유지한다.

Python의 `ስርዓት_ስህተት`는 OSError의 አማርኛ 하위 클래스이며 연결부에서
ስህተት 번호를 보존하여 변환한다. 일반 Python 문법과 외부 패키지의 API는 유지한다.

## 직접 GUI 이름의 뜻과 검토 ቅንጥብ

`실행할일`은 수행할 내용을, `መፈጸሚያ`는 그 수행을 나타낸다.
`동작받이`는 동작이 발생했다는 알림을 받는 역할, `동작알림`은 전달되는 사건이다.
`አዝራር`는 눌러 동작시키는 조작부, `ምልክት`는 አንበኝ_eb81d7d9 글의 በቦታ_አስቀመጠ_መረጃ_ጠቆመ,
`ጽሁፍ_መስክ`은 글을 적는 በቦታ_አስቀመጠ_መረጃ_ጠቆመ, `작업가닥`은 이어지는 ፈጽም_ትእዛዝ 흐름을 뜻한다.
`ፈጽም_ትእዛዝ(實行)`·`ተግባር(動作)`의 기존 뜻과 `받다`·`알리다`·`ክር_እሴት`의 기능을
결합한 프로젝트 이름이다. 새 복합어가 역사 문헌에 그대로 있었다거나
특정 시대에 처음 쓰였다고 주장하지 않는다.

전체 저장소는 `python3 መሳሪያዎች/ምንጭ_ክለሳ.py`로 검토한다.
결과는 `build/verification/naming/source-review.json`이며 파일별 ሃሽ_ፋይል,
ASCII 파일명과 Python의 영어 እወጃ 위치를 기록한다.
공용 ARM64·x86 번역기의 구현은 `compiler/자바도구/기계어미리번역.java`로 전환했다. `compiler/기계어미리번역.py`는 호환 진입점이다.
`compiler/arm64.py`는 이전 경로와 `ARM64(...).generate(...)` 호출을 이어 주는
호환 진입점이다. `compiler/classfile.py`, OpenJDK 보조 መሳሪያዎች, Linux ስሪት_እሴት 도구와
기존 호환 진입점에는 영어 이름이 남아 있다. 따라서 전체 저장소가
예약어 외 100% 한국어라고 판정하지 않는다.
`መሳሪያዎች/명명검사.py --시언어`는 ንቁ ARM64 소스의 እወጃ, C 의미 분석,
x86 Java 커널과 공용 번역기의 자체 እወጃ, Java 예제 전체 መለያ_እሴት_5b7b8b77,
ARM64 Python 예제와 직접 GUI/가닥에 표준 래퍼가 없는지를 별도로 검사한다.

## 현재 기능을 기준으로 보완한 ስም

번역은 글자를 음역하는 대신 자료의 역할과 함수의 행동을 구분한다.
동일한 영어 이름도 문맥이 다르면 አማርኛ 이름을 달리 정한다.
ፋይል 이름은 주된 기능을 나타내고, ተግባር_እሴት 이름은 행동을, 변수 이름은 담는 자료를 나타낸다.
예약어, 표준 API 및 외부 መገናኛ 규약은 따로 기록한다.

| 이전 ስም | 적용한 ስም | 현재 기능 |
|---|---|---|

### 말의 뿌리와 새로운 복합 ስም

`ማስቀመጫ_እሴት(記憶)`과 `ፍለጋ_መረጃ_ጠቆመ(索引)`은 기존 한자어를 쓴다.
기억은 자료를 간직하는 기능에, 색인은 ቅደም_ተከተል_እሴት 있는 항목을 찾아 지정하는 기능에 적용한다.
መዝገበ_ቃላት 근거는 국립국어원 한국어기초사전의
[ማስቀመጫ_እሴት](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=38812&nation=eng),
[ፍለጋ_መረጃ_ጠቆመ](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=63787)이다.

`ክምር_ማከማቻ`, `쌓기`, `꺼내기`는 자료를 포개고 마지막 자료부터 꺼내는 ፈጽም_ትእዛዝ 구조를 드러낸다.
`쌓다`의 기존 뜻에 근거한 기능별 조어이며, 사전의
[쌓다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62095)를 참고한다.
`미리번역`은 ፈጽም_ትእዛዝ 전에 번역한다는 기능을 직접 나타낸다.
`ማሽን_ቃል`은 처리기의 ውሂብ 단위를 가리키며, 언어의 일반 낱말과 구별하도록 `ማሽን`를 붙였다.
`기계어미리번역`, `동적기억낱말수` 같은 복합 이름은 현재 기능에 맞게 만든 프로젝트 용어다.
이 복합어가 옛 문헌에 그대로 있었다거나 특정 시대에 처음 나타났다는 뜻은 아니다.
확인되지 않은 중세 형태나 최초 사용 연대는 어원 근거로 적지 않는다.

생성되는 C의 내부 የውሂብ_ዓይነት·ድርድር_እሴት·ተግባር_እሴት·የአካባቢ_ስፋት 변수·ቅርንጫፍ 이름도 한국어로 바꾼다.
직접 한글 식별자를 읽지 못하는 예전 GCC를 위해 호환 API는 같은 አማርኛ 이름을
표준 C 범용 문자 표기로 출력한다. ትክክለኛ_ውሂብ ARM64 빌드는 Clang으로 읽을 수 있는 한글 원문을 사용한다.
ኅብረቁምፊ_እሴት, C 표준 ተግባር_እሴት, `java_entry` 같은 공개 መገናኛ 이름은 바꾸지 않는다.

셸의 사용법·문법 ስህተት·ፋይል 및 ማስቀመጫ_እሴት 공간 안내도 한국어로 보완했다.
`READY`, `PASS`, `HEX BEGIN`처럼 시험·ፋይል ትልልፍ_እሴት 도구가 읽는 표식,
명령행 옵션과 기존 መምሪያ_እሴት, JVM መደብ_እሴት ስም·ፋይል ቅርጸት_እሴት·መሳሪያ_እሴት 이름은 호환 표기로 남는다.
x86 VGA 문자 화면은 한글을 표시하지 못하므로 አማርኛ 문구는 UTF-8 직렬 단말에서 확인한다.
