# አማርኛ Java 통신·ግቤት_ውጤት·ልዩነት API

패키지는 `አማርኛ.자체`다. አዘጋጅ_b78e430d `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·ፋይል·ልዩነት API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 ክር_እሴት API는 자체 JVM 전용이다.
기존 표준 Java ማከማቻ_ስፍራ 전체의 አማርኛ 번역판은 아니다.

```java
import አማርኛ.자체.*;

public class መረብ {
    public static void main(String[] 인수) throws ግቤት_ውጤት_ልዩነት {
        ግንኙነት መገናኛ = ግንኙነት.መክፈቻ("10.0.2.2", 9000);
        try {
            መገናኛ.대기시간(700);
            መገናኛ.ውጤት().መጻፊያ(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = መገናኛ.입력();
            ውጤት.수쓰기(입력.ማንበቢያ());
        } catch (대기시간초과예외 ስህተት) {
            ውጤት.ጻፍ_መስመር(ስህተት.설명());
        } finally {
            መገናኛ.መዝጊያ();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
ተጠቃሚ 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 ኅብረቁምፊ_እሴት 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void ማስኬጃ()`도 진입점으로 받는다.

## 통신과 ልቀቅ_እሴት

| መደብ_እሴት | አማርኛ 호출 |
|---|---|
| ግንኙነት | `መክፈቻ(አድራሻ, የወደብ_ቁጥር)`, `입력()`, `ውጤት()`, `대기시간(밀리초)`, `የወደብ_ቁጥር()`, `የአካባቢ_የወደብ_ቁጥር()`, `연결됨()`, `닫힘()`, `መዝጊያ()` |
| 수신창구 | `መክፈቻ(የወደብ_ቁጥር)`, `받기()`, `የወደብ_ቁጥር()`, `대기시간(밀리초)`, `닫힘()`, `መዝጊያ()` |
| 입력흐름 | `ማንበቢያ()`, `ማንበቢያ(byte[])`, `ማንበቢያ(byte[], ማስኬጃ, ርዝመት_እሴት)`, `መዝጊያ()` |
| 출력흐름 | `መጻፊያ(int)`, `መጻፊያ(byte[])`, `መጻፊያ(byte[], ማስኬጃ, ርዝመት_እሴት)`, `내보내기()`, `መዝጊያ()` |
| 전문통로 | `መክፈቻ(የወደብ_ቁጥር)`, `ላክ(አድራሻ, የወደብ_ቁጥር, ጽሁፍ)`, `받기()`, `대기시간(밀리초)`, `የወደብ_ቁጥር()`, `닫힘()`, `መዝጊያ()` |
| 연결통신 | `መክፈቻ(...)`, `수신열기(...)`는 위 አማርኛ 객체를 반환 |
| 검사 | `참인지(ሁኔታ, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`ማንበቢያ()`의 ፋይል 끝은 -1, ድርድር_እሴት 읽기의 반환값은 ትክክለኛ_ውሂብ 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. የወደብ_ቁጥር 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 자체 커널에서 512바이트까지 받으며, 주소는 숫자 IPv4를 사용한다.
`localhost` 루프백 외의 ስም 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.መገናኛ/듣기/받기`, `통신.መክፈቻ/ላክ/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `ግንኙነት`, `수신창구`, `전문통로`를 쓴다.

## አማርኛ ልዩነት

모든 아래 클래스는 ነባሪ_እሴት 생성자, `새예외("설명")` 형태의 ኅብረቁምፊ_እሴት 생성자와
`설명()`을 제공한다. ትክክለኛ_ውሂብ አዘጋጅ 문법은 `new 대기시간초과예외("መጠበቅ_ዞን 끝")`이다.

| አማርኛ ልዩነት | 상위 መደብ_እሴት / 용도 |
|---|---|
| ልዩነት | `java.lang.Exception`, 직접 던지는 일반 검사 ልዩነት |
| 실행예외 | `java.lang.RuntimeException` |
| ግቤት_ውጤት_ልዩነት | `java.io.IOException`, አማርኛ ፋይል·통신 API의 검사 ልዩነት |
| 대기시간초과예외 | `ግቤት_ውጤት_ልዩነት`, 통신 대기시간 초과 |
| አድራሻ_ፍለጋ_ልዩነት | `ግቤት_ውጤት_ልዩነት`, አድራሻ አረጋግጥ ተስኖት_እሴት |
| 파일없음예외 | `ግቤት_ውጤት_ልዩነት`, ፋይል መክፈቻ ተስኖት_እሴት |
| 통신예외 | `ግቤት_ውጤት_ልዩነት`, 표준 SocketException 변환 |
| ልክ_ያልኾነ_ነጋሪ_እሴት_ልዩነት | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `ልክ_ያልኾነ_ነጋሪ_እሴት_ልዩነት` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| አልቦ_ማጣቀሻ_ልዩነት | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| ዞን_ልዩነት | `java.lang.IllegalStateException` |
| ተይብ_ካስት_ልዩነት | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| ድርድር_ማከማቻ_ተስኖት | `java.lang.ArrayStoreException` |
| ክር_ዞን_ልዩነት | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 መጠበቅ_እሴት 중단 |

`ልዩነት`와 `실행예외`는 모든 አማርኛ 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, ፋይል·통신 전체를 잡으려면 `catch (ግቤት_ውጤት_ልዩነት ስህተት)`를 쓴다.
አማርኛ API가 표준 ግቤት_ውጤት 오류를 አማርኛ 예외로 변환한다.
기존 አማርኛ 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
ልዩነት 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 자체 JVM에 이 20종을 추가했다. 임의의 ተጠቃሚ Throwable 하위 መደብ_እሴት 전체를
지원하도록 확장했다는 뜻은 아니다.

## መገንባት_ምንጭ·ፈጽም_ትእዛዝ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make ግንብ_ስርዓት
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 መሳሪያዎች/ፈጽም_ፋይል.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 ተጠቃሚ JVM ELF 안에 탑재된다. `.jar`는 አዘጋጅ_b78e430d javac의
መደብ_እሴት 경로로 사용한다. ምንጭ_ዛፍ 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 አማርኛ 예외의 `throws` 선언과 그 import를 인식한다.
자체 JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·ነገር_እሴት·소켓 예제 전체의 ምንጭ_ዛፍ 컴파일은 አዘጋጅ_b78e430d javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 수 있다.

ትክክለኛ_ውሂብ TCP/UDP 예제는 [네트워크예제.java](../../../example/java/네트워크예제.java),
ፈጽም_ትእዛዝ 절차는 [example አንበኝ_eb81d7d9](../../../example/README.md),
ምንጭ_ዛፍ 명명 원칙은 [명명 አንበኝ_eb81d7d9](../명명/አንበኝ_eb81d7d9.md)에 있다.

## Swing መስኮት 예제

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` ቀጣይ_ንጥል_ነገር `java 창예제`로 연다. ስም 입력, 인사하기 버튼,
인사말과 ጠቅ_አድርግ_እሴት 횟수 አድስ, X 닫기를 지원한다.

| 기능 | አማርኛ 직접 API |
|---|---|
| Runnable / run | `실행할일.መፈጸሚያ()` |
| ActionListener / actionPerformed | `동작받이.동작받기(동작알림 알림)` |
| ActionEvent | `동작알림.ትእዛዝ_ጽሁፍ()`, `ፍጻሜ_ምንጭ()`, `መረጃ_ጠቆመ()` |
| JFrame | `መስኮት(መስኮት_ርዕስ, 폭, 높이)`, `አክል_አባል(화면구성요소)`, `አሳይ_መስኮት()`, `መዝጊያ()`, `보이는가()` |
| JButton | `አዝራር(ጽሁፍ, 가로, ቋሚ_በቦታ_አስቀመጠ, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `ምልክት(...)`, `ጽሁፍ_መስክ(...)` |
| 공통 화면 አባል_እሴት | `화면구성요소.글읽기()`, `ጻፍ_ጽሁፍ(ጽሁፍ)`, `자리정하기(가로, ቋሚ_በቦታ_አስቀመጠ, 폭, 높이)` |
| SwingUtilities.invokeLater | `ፍጻሜ_ሰልፍ.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `ጀምር_ተግባር()`, `기다리기()`, `살아있는가()`, `አግድ_ተግባር()` |
| 명령행 | `ማስኬጃ()`, `실행인수.개수()`, `실행인수.ጽሁፍ(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `ሂደት_ክር`가 አማርኛ መደብ_እሴት·ስልት_እሴት·서술자를
해석해 화면 요소와 ፈጽም_ትእዛዝ 가닥을 직접 만든다. ተግባር 알림도 자체 객체이며
콜백으로 `መፈጸሚያ`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 ፈጽም_ትእዛዝ 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 አዘጋጅ_b78e430d JVM에서 무동작 객체가 생기지 않도록 하는 አትቀበል_እሴት 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. አዘጋጅ_b78e430d javac로 컴파일한 ተመለስ_እሴት 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import አማርኛ.자체.*;
public class 가닥예제 implements 실행할일 {
    public void መፈጸሚያ() { ውጤት.ጻፍ_መስመር("አማርኛ 작업 ፈጽም_ትእዛዝ"); }
    public static void ማስኬጃ() throws 대기중단예외 {
        작업가닥 ክር_እሴት = 작업.ማስኬጃ(new 가닥예제());
        작업.기다리기(ክር_እሴት);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
ድርድር_እሴት 인수 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 인수 없는 `ማስኬጃ()`을 우선한다.
기존 አማርኛ 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.ማስኬጃ(Runnable)`을 사용하던 코드는 새 አማርኛ 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API ድገፍ_እሴት 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 መደብ_እሴት·ስልት_እሴት 이름과 서술자가 남는다.
አማርኛ ስም 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
