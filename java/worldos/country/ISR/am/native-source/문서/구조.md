# JIsrOS 구조

아래는 ነገር_እሴት 기반 관리 ዓንኳር_እሴት 전체의 ዒላማ_ነገር 구조다. 현재 ትክክለኛ_ውሂብ 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 ስርዓተ_ክወና አንበኝ_eb81d7d9](../os/አንበኝ_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·አገባበ_ነገር_እሴት ቀይር_ሁነታ·የፋይል_ስርዓት 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 ንብርብር_እሴት
  ↓
Java AOT 실행기와 ነገር_እሴት·ድርድር_እሴት·GC 런타임
  ↓
하드웨어 경계
  ↓
Java 관리 ዓንኳር_እሴት
  ├─ 기억공간/쪽관리/COW
  ├─ ሂደት_እሴት/배정/wait
  ├─ የፋይል_ስርዓት/ELF/POSIX
  └─ 입력/ማከማቻ_መሳሪያ/መረብ_ክምር
```

OpenJDK 자체는 이미 운영체제가 제공하는 ፋይል, 스레드, 가상 기억공간을 전제로 한다. 따라서 ዓንኳር_እሴት 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, አገባበ_ነገር_እሴት 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
