# engos 기능 대응표

이 표는 기존 `ነባር_ምንጭ/`의 ነገር_እሴት 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [ትክክለኛ_ውሂብ 부팅 기능과 한계](../os/አንበኝ_eb81d7d9.md)를 따로 기록한다.

## 기존 ነገር_እሴት 기반 관리 ዓንኳር_እሴት 전체를 부팅하기 위해 남은 መገናኛ

ቀጣይ_ንጥል_ነገር 항목은 Java 문법만으로 실행할 수 없는 CPU/መሳሪያ_እሴት 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot ምዝግብ_ቦታ_እሴት, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 አገባበ_ነገር_እሴት ማከማቻ_እሴት
- ትክክለኛ_ውሂብ PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA ድግግሞሽ_እሴት
- Java ነገር_እሴት·ድርድር_እሴት አገናኝ_አሰሳ, ልዩነት, አይንቀሳቀሴ_እሴት ጀምር, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT ደረጃ_እሴት
- FAT 디스크 구역을 ትክክለኛ_ውሂብ ATA 장치와 연결하는 ግቤት_ውጤት 접착 ንብርብር_እሴት

위 관리 계층은 engos 기능의 Java 관리 구현과 አዘጋጅ_b78e430d 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot ምዝግብ_ቦታ_እሴት, አይንቀሳቀሴ_እሴት ጀምር·ኢንተጀር ድርድር_እሴት, VGA/직렬/PS2, 명령해석기, ተጠቃሚ ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 አዘጋጅ_b78e430d 루프백 패킷 왕복을 검증했다. 위 표의 ነገር_እሴት 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
