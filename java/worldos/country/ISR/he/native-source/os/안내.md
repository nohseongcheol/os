# Java 네이티브 מערכת_הפעלה

이 문서는 기존 **x86 ליבה_ערך**을 설명한다. Raspberry Pi 4의 עצמי ARM64 מצב_התחלתי 이식은 [별도 안내](../platforms/rpi4-native/README.md)를 참고한다. 아래 x86 משתמש ELF·네트워크·IDE מאגר_ערך 기능이 ARM64에 모두 이식된 상태는 아니다.

Java 원문을 עצמי AOT 후단으로 x86 기계어로 컴파일해 부팅하는 작은 운영체제다. 커널과 별도로 עצמי 제한형 Java מהדר·JVM ELF를 משתמש 모드에 적재할 수 있다. Linux, engos, koros4와 חיצוני_ערך OpenJDK는 게스트에 적재하지 않는다. 부팅 진입과 חומרה_הסב/물리 זיכרון_אזור 접근은 어셈블리이며, 문자 단말·קלט_ערך תהליך_ערך_ערך·פקודה ניתוח_מבנה_טקסט_ערך·작업 מקטע_ערך 관리는 `קודמקור/*.java`에 있다.

## 게스트 Java 개발

`javac Hello.java`, `java Hello`로 부팅된 מערכת_הפעלה 안에서 בנה_מקור·실행한다. `edit FILE.java`와 `.save`로 소스를 작성하며 `ls`, `cat`, `rm`을 제공한다. RAM 파일은 최대 8개, 각각 16KiB이다. 전용 IDE 매체를 연결하면 `sync`로 보존할 수 있다. 이 기능은 עצמי 제한형 구현이며 전체 OpenJDK/JDK 호환은 아니다. 사용법·תמך_ערך 문법·קובץ 적재·교차 시험은 [Java 개발 סביבה](../문서/자바개발환경.md)에 있다. `make test-java`로 검증한다.

## 빌드와 לבצע_פקודה

`compiler/`가 요구하는 도구에 더해 ISO 생성에는 `grub-file`, `grub-mkrescue`, GRUB BIOS מודול_ערך, `xorriso`가 필요하다. 실행에는 QEMU 또는 VirtualBox가 필요하다. נוכחי_פריט 설치된 도구만 사용한다. `make run-store`는 새 전용 가상 מאגר_ערך 매체를 만들어 연결한다. VirtualBox 실행기는 이 프로젝트가 만든 전용 VM만 설정하고 다른 VM은 변경하지 않는다. 가상 메모리는 ערך_ברירת_מחדל 64MiB이며 최소 16MiB가 필요하다.

```sh
cd /home/user/jkoros/os
make                 # build/kernel.elf
make iso             # build/kernel.iso (משתמש ELF לקבץ_ערך 포함)
make run             # ELF 직접 부팅, 직렬 단말
make run-gui         # GRUB ISO 부팅, VGA 창과 PS/2 자판
make vbox            # 상위 폴더의 실행기로 전용 VirtualBox VM לבצע_פקודה
make vbox-status     # 전용 VirtualBox VM מצב_ערך ודא_אמת
make test            # ELF와 ISO 두 경로의 בפועל_נתונים 부팅/קלט_ערך 시험
make apps            # משתמש 프로그램만 בנייה
make test-network    # משתמש לבצע_פקודה/UDP/הגן_ערך 시험
```

`make run`은 QEMU의 직렬 표준 입출력을 쓴다. `Ctrl+A`를 누른 הקודם_ערך `X`로 QEMU를 종료할 수 있다. `halt`는 게스트 CPU만 정지시키므로 QEMU חלון/프로세스는 별도로 닫는다. 폴링 방식이라 רק_רגע_ערך 중에도 ארח CPU를 사용할 수 있다.

VirtualBox는 `make vbox`로 실행한다. 새 전용 VM을 זיכרון_נתונים 64MiB, BIOS, 광학 드라이브 부팅으로 자동 설정하며 디스크는 필요 없다. בפועל_נתונים VirtualBox 5.2.42에서 부팅, Java עצמי 시험, מעטפת קלט_ערך, `run hello vbox`의 ring 3 실행과 מערכות_מידע_רגיל 종료를 확인했다. נוכחי_פריט 통신 드라이버는 QEMU의 RTL8139 전용이며 VirtualBox의 PCnet/E1000에서는 네트워크를 사용할 수 없어 네트워크 장치를 비활성화한다. מאגר_ערך מצב_ערך 재개와 새 בנייה 반영 방법은 [VirtualBox לבצע_פקודה 안내](../문서/가상상자실행.md)에 있다.

## 셸에서 משתמש תוכנית_f5044b9b לבצע_פקודה 및 네트워크 호출

독립 ELF32 לבצע_פקודה 파일을 적재해 **ring 3**에서 실행한다. `int 0x80` 시스템 호출을 통해 단말 פלטטקסט, ארגומנטים שאילתה_ערך, UDP פתח·שלח·לקבל·닫기를 제공한다. משתמש 코드를 ליבה_ערך 함수로 직접 호출하는 구조가 아니다.

```text
jkoros> apps
jkoros> run hello first second
jkoros> net
jkoros> run netcheck
jkoros> run udp 10.0.2.2 9000 hello
```

마지막 명령의 응답을 받으려면 호스트의 별도 터미널에서 `python3 /home/user/jkoros/os/כלים/הד_נתונים.py --port 9000`을 먼저 실행한다. 상세 API, תוכנית_f5044b9b צירוף_ערך_b73accca, למען 공간과 제한은 [משתמש לבצע_פקודה·네트워크 안내](משתמש/안내.md)에 있다.

부팅 ודא_אמת 문구:

```text
JKOROS NATIVE JAVA
자바 기계어 ליבה_ערך הפעלה
JAVA SELFTEST PASS
USER ELF: ring 3 / paging / int 0x80
help | info | mem | alloc | free N | echo TEXT | clear | test | halt
apps | run NAME [ARGS] | net
READY
jkoros>
```

## 구현한 기능

- GRUB Multiboot 1 ELF 부팅, x86 הגן_ערך מצב_ערך_a83655ea GDT, BSS אתחול, 64KiB אופרנד_רמז.
- Java פונקציה_ערך בפועל_נתונים 실행과 부팅 מידע_מערכת סמן_ערך ודא_אמת.
- COM1 직렬 קלט_פלט, VGA 문자 화면·סמן_ערך_04ee3e20·스크롤·מחק_ערך.
- PS/2 ערך_ברירת_מחדל 자판, 좌우 Shift, Enter, Backspace. הרחבה_ערך מקש_ערך/마우스 자료는 פקודה 입력으로 쓰지 않는다.
- 길이 128의 פקודה קלט_ערך 버퍼, גלישה_ערך 방지, CR/LF תהליך_ערך_ערך.
- `help`, `info`, `mem`, `alloc`, `free N`, `echo TEXT`, `clear`, `test`, `halt`.
- 4KiB 작업 מקטע_ערך 8개의 הקצה_אחסון·החזר_תוצאה·재사용과 중복 החזר_תוצאה 방지.
- Java מערך_ערך 256KiB 영역의 גודל·כתב_תחתי_ערך 검사와 런타임 שגיאה 중단.
- קרא 전용 JKAP לבצע_פקודה לקבץ_ערך, ELF32 מקטע_ערך/נקודת_כניסה לאמת, משתמש מצב_ערך_a83655ea·ארגומנטים·יציאה_תוכנית קוד_ערך.
- ליבה_ערך/משתמש 페이지 הרשאה_ערך 분리, TSS, IDT, PIT 100Hz, משתמש CPU חריגה תהליך_ערך_ערך 및 לבצע_פקודה ערך_זמן 상한.
- PCI RTL8139 폴링 드라이버, ARP, סטטי_ערך IPv4, UDP בדיקת_סיכום·송수신·רק_רגע_ערך 제한.

`mem`의 Upper memory는 Multiboot의 1MiB 위쪽 연속 זיכרון_נתונים גודל(KiB)이며, 전체 זיכרון_נתונים 지도 분석이나 자유 물리 זיכרון_נתונים 수치가 아니다. `alloc`은 이미 확보한 מספר_שלם מערך_ערך 안의 작업 מקטע_ערך 번호를 반환한다. 일반 물리 דף_ערך הקצה_אחסון, למען למען_אזור 또는 משתמש תהליך_ערך זיכרון_נתונים 관리가 아니다.

## 명시적인 한계

이 커널은 **משתמש 프로그램을 한 번에 하나 실행하는 מצב_התחלתי ליבה_ערך**이다. PIT IRQ0만 사용하며 키보드와 NIC는 폴링한다. משתמש CPU 예외는 해당 프로그램을 끝내고 셸로 복귀시키지만 ליבה_ערך 예외는 중단한다. לבצע_פקודה 시간은 약 3초로 제한한다. 완전한 선점 다중 תהליך_ערך 스케줄러, FAT/ext 등 일반 디스크 מערכת_קבצים, TCP·DNS·DHCP·IPv6·HTTP, 전체 POSIX, 일반 אובייקט_ערך 모델/GC는 아직 없다. 전용 IDE קובץ 보존과 POSIX קובץ/UDP 일부 기능은 구현했다. JVM은 RAM 파일의 단일 클래스를 לבצע_פקודה 시 적재하며 일반 ClassLoader나 JAR 로딩은 지원하지 않는다. 네이티브 לבצע_פקודה 파일은 בנייה 시 קרא 전용 묶음에 넣으며, 일반 Linux ELF를 실행하는 환경이 아니다. 기존 `../דור_קודם_מקור/`의 JVM 관리 ליבה_ערך 전체를 이식한 것도 아니다.

Java 식별자는 한국어다. 직렬 출력은 이 프로젝트의 한글(BMP 문자)을 UTF-8로 표시한다. VGA는 ערך_ברירת_מחדל ASCII 글꼴만 사용하므로 한글 자리에 `?`가 나온다. פקודה 입력도 נוכחי_פריט ASCII만 지원하며 한글 גופן_ערך·입력기 및 보조 평면 문자 출력은 후속 작업이다. `test`는 작은 배열을 새로 할당하고 GC가 없으므로 무한 반복하지 않는다.

## 자동 시험

`시험/부팅시험.py`는 디스크 없는 독립 QEMU를 생성해 다음을 검증하고 종료한다.

- ELF 직접 부팅 및 GRUB ISO 부팅.
- Java עצמי 시험과 UTF-8 직렬 문구.
- פקודה הופעה_עזרה·מידע_מערכת·זיכרון_נתונים·פלטטקסט·שגיאה קלט_ערך·화면 מחק_ערך.
- 작업 מקטע_ערך 8개 הקצה_אחסון, 부족 תהליך_ערך_ערך, החזר_תוצאה/중복 החזר_תוצאה/재할당.
- 직렬 줄바꿈·백스페이스·긴 קלט_ערך תהליך_ערך_ערך.
- QEMU PS/2 מקש_ערך 입력으로 `info` לבצע_פקודה, `halt` 정지.

성공 로그는 `build/부팅시험.json`에 남는다. 로컬 Unix 소켓을 금지하는 샌드박스에서는 시험 도구에 해당 권한이 필요하다. 시험 도중 새로 만든 QEMU만 종료하며 기존 VM과 בפועל_נתונים 디스크는 건드리지 않는다.

`시험/נסה_משתמש_רשת.py`는 ELF/ISO 각각에서 משתמש ELF, בפועל_נתונים ring 3, ארגומנטים, ארח 루프백 UDP 왕복, 1,023/1,024바이트 24회 연속 왕복, ערך_זמן 초과, NIC 없음, זיכרון_נתונים/חומרה_הסב גישה_ערך_68aed533 차단, CPU חריגה, 무한 סבב_ערך, 잘못된 ELF를 시험한다. `build/נסה_משתמש_רשת.json`에 게스트 기록과 호스트가 받은 데이터의 길이·해시를 저장한다. `시험/מנה_נסה.py`는 בפועל_נתונים Java ערך_חוזה 처리기에 손상된 패킷을 넣어 2,201개 경계/בדיקת_סיכום 조건을 검사한다. ארח 루프백 외 חיצוני_ערך 서버에는 시험 트래픽을 보내지 않는다.

부트 경계는 GNU의 [Multiboot מפרט](https://www.gnu.org/software/grub/manual/multiboot/multiboot.html)를 따른다.

새 파일서술자·C ABI·IDE מאגר_ערך·Java קובץ 흐름의 범위와 עברית 명명 대응은 [posix-kor 안내](../posix-kor/안내.md)에 있다. `make test-posix`로 ELF/ISO 실행과 재부팅 보존을 검증한다.
