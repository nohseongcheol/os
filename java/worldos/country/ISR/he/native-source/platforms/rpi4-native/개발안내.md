# עצמי 커널에서 vi·여러 מסוף·한글 프로그래밍 사용하기

עברית 통신·חריגה 사용법은 [עברית Java API](한국어자바/안내.md), פונקציה_ערך·משתנה_ערך_541034c4·קובץ 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

대상은 `platforms/rpi4-native`의 עצמי AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 תמך_ערך 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 לבצע_פקודה, חיצוני_ערך TCP/UDP와 FTP는 [새 לבצע_פקודה 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 מסוף

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, למען **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 מסוף 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **זכות 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 לבצע_פקודה 버튼으로 נסה_שנית_ערך עמודה_ערך 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 נוכחי_פריט 디렉터리, מעטפת משתנה_ערך_541034c4, פקודה לרשום_שיא, קלט_ערך 중인 명령과 תוכנית_f5044b9b לבצע_פקודה 상태를 보관한다. קובץ 저장소는 공유한다. vi와 Swing의 이벤트 רק_רגע_ערך 중에 다른 터미널로 전환하면 משתמש זיכרון_נתונים·레지스터·קובץ/소켓 연결을 보존했다가 돌아올 때 재개한다. **נוכחי_פריט 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 הבא_פריט קלט_ערך רק_רגע_ערך 또는 기존 לבצע_פקודה 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 לבצע_פקודה 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 ערוך_ערך 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. נוכחי_פריט 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 חלון 판단은 게스트 커널이 처리한다. QEMU לבצע_פקודה 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. בפועל_נתונים Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI כלים 종료는 ארח 터미널의 Ctrl+C다.

## vi שימוש_ערך

```text
mkdir 작업
cd 작업
vi 인사.py
```

`vi`는 새로 구현한 **vi פקודה 부분집합** 편집기다. 내장 `build/user/vi.elf`를 보호된 משתמש 영역에 적재한다. קובץ 크기는 UTF-8 בית_ערך לשקף_בסיס 16 KiB, 경로는 63바이트까지다. 디스크에 설치한 Vim/Neovim 바이너리를 실행하는 것이 아니다.

| מקש_ערך/פקודה | פעולה |
|---|---|
| `i`, `a`, `I`, `A` | נוכחי_פריט/הבא_פריט מיקום 또는 שורה 처음/끝에서 קלט_ערך |
| `o`, `O` | 아래/위에 새 줄을 만들고 קלט_ערך |
| Esc | 일반 מצב_ערך_a83655ea |
| `h j k l`, 방향키 | UTF-8 문자/שורה להעביר_ערך |
| `0`, `$`, Home, End | שורה 처음/끝 |
| `gg`, `G`, `:מדד` | קובץ 처음/마지막 שורה/הקצה_ערך שורה |
| PgUp, PgDn | 화면 יחידה_ערך להעביר_ערך |
| `x`, Delete | נוכחי_פריט 문자 삭제 |
| `dd`, `yy`, `p` | שורה 삭제/מופע_ערך/הדבק_טקסט |
| `u` | 마지막 편집을 החזר_גשר; 한 במה_ערך 토글 |
| `/מחרוזת_ערך`, `n` | 단순 מחרוזת_ערך 검색/הבא_פריט 일치; 정규식 없음 |
| `:w`, `:w 다른이름` | RAM קובץ מאגר_ערך/다른 경로로 מאגר_ערך |
| `:q` | 변경이 없을 때 יציאה_תוכנית |
| `:q!` | 변경을 버리고 יציאה_תוכנית |
| `:wq`, `ZZ` | 저장하고 יציאה_תוכנית |

붙여 넣은 한글을 문자 경계에 맞춰 להעביר_ערך·삭제한다. 일반 vi의 수량 접두사, מאקרו_ערך, הגדרות קובץ, 플러그인, 정규식, 여러 버퍼/분할 חלון, 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/אפס_אופרנד 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 חלון חלון_כותר `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 פקודה**으로 실행한다. 파이프·리다이렉션·תסריט_ערך·`;`/`&&`/`||`로 연결한 실행에서 אינטראקטיבי 대기를 시작하면 거부한다. קלט_ערך 대기는 약 2초 CPU 기한을 갱신하지만 קלט_ערך רק_רגע_ערך 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## 한글 Java

vi에서 다음을 `인사.java`에 입력하고 Esc → `:wq`로 저장한다.

```java
public class 인사 {
    static int 더하기(int 첫째, int 둘째) { return 첫째 + 둘째; }
    public static void main(String[] ארגומנטים) {
        int סך_הכל_ערך = 더하기(20, 22);
        System.out.println("안녕하세요 · סך_הכל_ערך=" + סך_הכל_ערך);
    }
}
```

게스트 셸에서 실행한다.

```text
javac 인사.java
java 인사
```

한글 שם_קובץ_טקסט·שם_מחלקה·פעולת_שירות_שם_טקסט·변수명·문자열을 사용할 수 있다. **게스트 javac는 סטטי_ערך Java 부분집합**이다. אובייקט_ערך·리스너·Swing·소켓을 사용하는 소스는 נוכחי_פריט ארח JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 עצמי JVM에 class를 올린다. עצמי JVM에서 지원하는 바이트코드/API 범위는 [자바실행환경.md](자바실행환경.md)를 따른다.

```sh
# ארח
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/מוסיקת_סווינג_נסה.java
python3 כלים/העלה_קבצים.py build/my-java/מוסיקת_סווינג_נסה.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. פלטטקסט 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java מוסיקת_סווינג_נסה`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.כיתה_ערך.class` 형식이다. 내장 עברית 라이브러리는 별도 업로드가 필요 없다. עברית חלון API의 예제는 [한글창시험.java](시험/자바/한글창시험.java)이며 같은 방법으로 בנה_מקור·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 מקור_עץ/클래스는 호스트의 `python3 כלים/לבצע_קובץ.py נתיב/인사.java`로 별도 QEMU에 업로드·לבצע_פקודה·종료할 수 있다. אינטראקטיבי Swing에는 לבצע_פקודה 후 משתמש 입력을 유지하는 `make desktop`을 사용한다.

## עצמי JVM의 Swing לגזור

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 עצמי Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | פעולה |
|---|---|
| `JFrame` | חלון_כותר, גודל·מיקום, הופעה_חלון, סגירה 정책, dispose |
| `JPanel` | ילד_ערך 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 מחרוזת_ערך הופעה_ערך·שנה_ערך |
| `JButton` | 버튼과 ActionListener לחץ_ערך תהליך_ערך_ערך |
| `JTextField` | 한 שורה UTF-8 קלט_ערך, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 עצמי JVM의 단일 이벤트 לבצע_פקודה 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. חלון·요소는 לבצע_פקודה 하나당 סך_הכל_ערך 32개, רכיב_ערך 글자는 최대 127 코드포인트다. ערך_ברירת_מחדל 서체와 색은 커널이 제공한다.

[מוסיקת_סווינג_נסה.java](시험/자바/מוסיקת_סווינג_נסה.java)는 חלון·한글 תג_ערך·שדה_טקסט·버튼·이벤트 처리의 לבצע_פקודה 가능한 예제다. [עצמי Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

עברית 라이브러리에는 다음을 추가했다. ארח בנה_מקור 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `עברית.עצמי.חלון`: `הוסף_רכיב`, `הופעה_חלון`, `סגירה`.
- `עברית.עצמי.רכיב_גרפי`: `תג_ערך`, `לחצן`, `שדה_טקסט` יצר.
- `עברית.עצמי.קשר_הובלה`: `חיבור`, `להאזין_משתתף`, `לקבל`.
- 기존 `פלטטקסט`, `문자`, `קובץ`, `작업`, `ערך_רשימה`, `מילון`, `통신`, `화면`, `ליבה_ערך`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **ליבה_ערך 내부 연결형 בית_ערך זרם_ערך**을 추가했다. קובץ/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket שרת_ערך = new java.net.ServerSocket(9250);
java.net.Socket אורח_ערך = new java.net.Socket("localhost", 9250);
java.net.Socket חיבור = שרת_ערך.accept();
אורח_ערך.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int 길이 = חיבור.getInputStream().read(받은것);
חיבור.close(); אורח_ערך.close(); שרת_ערך.close();
```

יצר·חיבור·accept·양방향 בית_ערך/מערך_ערך קלט_פלט·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 סיים_שיחה_נקודה 16개, לקבל_ערך_cef4d8ab 버퍼당 1024바이트, רק_רגע_ערך חיבור 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. ערך_ברירת_מחדל ערך_זמן 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM פקודה 수/ליבה_ערך לבצע_פקודה 기한은 여전히 적용된다.

חיצוני_ערך ספרה_ערך IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. בפועל_נתונים Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP ספריה 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [נסה_זרם.java](시험/자바/נסה_זרם.java)는 בפועל_נתונים 송수신·EOF·기한·חיבור 회수의 시험 예제다.

## 한글 Python

게스트 vi에서 한글 이름을 사용해 작성한다.

```python
ערך = 21

def 두배(ספרה_ערך):
    return ספרה_ערך * 2

print("תוצאה:", 두배(ערך))
```

מאגר_ערך 후 `python 인사.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 פונקציה_ערך·משתנה_ערך_541034c4·קובץ 이름과 문자열을 한글로 쓴다.

[עברית.py](예제/한글코딩/עברית.py)를 같은 디렉터리에 두면 הבא_פריט 별칭을 사용할 수 있다.

```python
import עברית
עברית.כתיבה_קובץ("인사.txt", "안녕하세요")
עברית.פלטטקסט(עברית.파일읽기("인사.txt").decode())
```

פלטטקסט·קובץ קרא/כתוב/삭제·표준 קלט_ערך·מלבן·ערך_זמן·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 ספרה_ערך IPv4 למען 전송이다. `wait_key()`는 화면을 확인할 때 אינטראקטיבי 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor סטטי_ערך 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 הרחבה_ערך 모듈은 아직 없다. 제한형 `pip`의 מקור_עץ 설치는 [Python חבילה 안내](파이썬꾸러미.md)를 따른다. [세 언어의 בפועל_נתונים 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 שפה 모두 עברית 헤더와 פונקציה_ערך 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 בפועל_נתונים EL0 לבצע_פקודה 시험 대상이다.

```c
#include "파일규약.h"
#ifdef __cplusplus
extern "C"
#endif
int התחל_משתמש_תוכנית(int ארגומנטים) {
    (void)ארגומנטים;
    const char 인사말[] = "안녕하세요\n";
    int 문서 = פתח_קובץ("인사.txt", קריאה_כתיבה | 없으면만들기 | 내용비우기, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = כתיבה_קובץ_נתונים(문서, 인사말, sizeof(인사말) - 1);
    סגור_קובץ(문서);
    כתיבה_קובץ_נתונים(1, 인사말, sizeof(인사말) - 1); /* נוכחי_פריט מסוף stdout */
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 수 있다. C는 게스트 `cc` 또는 ארח SDK, C++는 ארח SDK의 Clang++로 컴파일한다. 아래 예제는 기존 ארח SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh
# 호스트에서 SDK יצר·חלץ
make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/인사.c -o 인사-c.elf
python3 compile.py examples/인사.cpp -o 인사-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 בפועל_נתונים לבצע_פקודה
cd /home/user/jkoros/platforms/rpi4-native
python3 כלים/לבצע_קובץ.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 כלים/לבצע_קובץ.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

נוכחי_פריט GUI VM에서 실행하려면 `python3 כלים/העלה_קבצים.py נתיב/인사-c.elf`의 출력을 게스트에 보내고 `run 인사-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex שם_קובץ_טקסט`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 수 있다. 호스트와 게스트의 קובץ 시스템은 별개다.

| עברית שם | C סימן | לגזור |
|---|---|---|
| פתח_קובץ/סגור_קובץ | pk_open/pk_close | RAM קובץ, עמית_ערך/절대 נתיב |
| 파일자료읽기/כתיבה_קובץ_נתונים | pk_read/pk_write | קובץ, fd 0/1/2 표준 קלט_פלט, 연결형 소켓 |
| חפש_קובץ | pk_lseek | 처음기준/נוכחי_בסיס/סיים_שיחה_מקור |
| גודל_קובץ/파일길이정하기 | pk_size/pk_ftruncate | 길이 שאילתה_ערך/שנה_ערך |
| הסר_קובץ_ערך_שם | pk_unlink | קובץ שם 삭제 |
| 파일저장확정 | pk_fsync | RAM이므로 -1, מספר_שגיאה=ENOSYS |
| ליצור_משתתף/לאגד_למען | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |
| שלח_יחידת_נתונים_נתונים/לקבל_יחידת_נתונים_נתונים | pk_sendto/pk_recvfrom | UDP 루프백 |
| לקשר_רשת | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | רק_רגע_ערך חיבור 최대 4개 |
| לקבל_חיבור_רשת | pk_accept | נוכחי_פריט למען 인수는 NULL/NULL만 תמך_ערך |
| 통신주소읽기 | pk_getsockname | 로컬 למען/הסב_ערך |

`통신규약.h`의 עצמי `pk_sockaddr_in`을 사용하며 הסב_ערך·주소는 `망차례짧은수`/`רשת_מספר_שלם`로 변환한다. C 소켓 호출은 비차단이며 נתונים/연결이 없으면 -1과 `מספר_שגיאה=11`(EAGAIN)을 반환한다. 양수 קלט_פלט 결과가 요청보다 작을 수 있으므로 סבב_ערך 처리한다. כשל_ערך 후에만 오류번호를 확인한다.

[זרם_ערך.c](예제/한글코딩/זרם_ערך.c)는 C에서 עברית 이름으로 חיבור·accept·부분 קרא/כתוב·큐 포화·EOF를 처리하는 לבצע_פקודה 예제다. SDK의 `examples/זרם_ערך.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → בפועל_נתונים עברית C פונקציה_ערך 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·מצביע 검사 → Java RAM קובץ/루프백 또는 חיצוני_ערך lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 ליבה_ערך 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 חיבור, 표준 C printf, libstdc++/STL, חריגה·RTTI는 제공하지 않으며 C++의 סטטי_ערך 생성자·מקומי_היקף אובייקט_ערך 소멸자는 지원한다. 상세 מדד·זיכרון_נתונים 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## עברית 이름으로 직접 작성하는 창과 שרשור_ערך

`example/java/דוגמתחלון.java`는 `실행할일.בצע`,
`동작받이.לקבל_המלצה(המלצה_הודעה)`, `לחצן`, `אירוע_תור.나중에실행`, `הפעלה()`을 쓴다.
עצמי JVM에 이 이름들의 אובייקט_ערך·פעולת_שירות_ערך·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `משימתרקע`도 עצמי 스케줄러와 직접 연결된다.
세부 메서드와 기존 עברית API에서의 변경은 [עברית API 문서](한국어자바/안내.md)를 본다.

ארח javac는 הפצה_ערך JAR를 כיתה_ערך 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/דוגמתחלון.java
python3 כלים/לבצע_פקודה.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java דוגמתחלון
```

직접 화면/שרשור_ערך API와 `הפעלה()` 진입점은 עצמי JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
