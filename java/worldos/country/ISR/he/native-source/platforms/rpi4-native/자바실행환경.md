# עצמי ARM64 JVM 0.4와 עברית ספריה

עברית 통신·חריגה 사용법은 [עברית Java API](한국어자바/안내.md), פונקציה_ערך·משתנה_ערך_541034c4·קובץ 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

JAR לבצע_פקודה, חיצוני_ערך IPv4 TCP/UDP, 별도 סטטי_ערך 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 אובייקט_ערך·Thread·Swing은 JVM 경로의 기능이며 AOT תמך_ערך 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 לבצע_פקודה**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK כיתה_ערך ספריה 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 כיתה_ערך·סטטי_ערך פעולת_שירות_ערך 중심이던 실행기를 אובייקט_ערך·ספריה לבצע_פקודה 기반으로 넓힌 것이다.

## 실행과 בנה_מקור

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# עצמי ליבה_ערך 안에서 מקור_עץ בנה_מקור → class לבצע_פקודה, עברית API 호출
python3 כלים/לבצע_קובץ.py 시험/자바/한글소스.java

# אובייקט_ערך·חריגה 등은 ארח JDK로 Java 8 class를 만든 후 עצמי 커널에서 לבצע_פקודה
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 כלים/לבצע_קובץ.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 העבר_ערך
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 כלים/לבצע_קובץ.py build/my-java/객체시험.class \
  --include build/my-java/טפט_ערך.class --include build/my-java/ענף_ערך.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.כיתה_ערך.class`라는 RAM קובץ 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.כיתה_ערך`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.כיתה_ערך`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar קובץ.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 עברית 클래스만 찾는다. הפצה_ערך עברית ספריה JAR는 ארח javac의 classpath로 사용하며, 같은 클래스가 משתמש JVM ELF에도 קרא 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 סטטי_ערך פעולת_שירות_ערך, int/boolean/char/String, תנאי·סבב_ערך, מחרוזת_ערך 결합, 일부 קובץ 스트림 등의 **עצמי 부분집합 מהדר**다. אובייקט_ערך הצהרה·상속·try/catch·Thread שימוש_ערך 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 עצמי JVM에서 실행한다. עברית API 중 פלטטקסט·문자 스칼라 פונקציה_ערך·קובץ קרא/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] ארגומנטים) throws Exception {
        עברית.עצמי.פלטטקסט.כתיבה_קו("안녕하세요😀");
        עברית.עצמי.פלטטקסט.수쓰기(עברית.עצמי.문자.코드포인트수("한글😀"));
        עברית.עצמי.קובץ.כתוב("인사.txt", "한글 קובץ😀");
        עברית.עצמי.פלטטקסט.כתיבה_קו(עברית.עצמי.קובץ.קרא("인사.txt"));
    }
}
```

## עברית API

독립 패키지 **`עברית.עצמי`**를 사용한다. Linux판 `עברית.자바`가 요구하는 NIO/Swing/HTTP API를 עצמי 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 כיתה_ערך שם·פעולת_שירות_ערך·ארגומנטים·ערך_שדה·קובץ 이름에 한국어를 사용한다. 표준 Java כיתה_ערך 이름은 호환성을 위해 보존한다.

| כיתה_ערך | 공개 기능 | 이름의 의미 |
|---|---|---|
| פלטטקסט | כתוב, כתיבה_קו, 수쓰기 | פלטטקסט(出力): 내용을 바깥으로 내보냄 |
| 문자 | 길이, 같음, הדבק_טקסט, לגזור_ערך_4601577b, ניתוח_מבנה_טקסט_מספר_שלם/כתיבה_מספר_שלם_ערך, 코드포인트수, לקדד/פענח_נתונים | 문자(文字), קידוד_ערך(符號): 글의 단위와 그 값을 바이트로 나타내는 כלל_ערך |
| קובץ | קרא/כתוב(String שם), 바이트읽기/כתיבה_בית_ערך | 널리 쓰는 משתמש 용어를 보존; RAM 자료의 שם |
| ערך_רשימה | 더하기, קרא, 바꾸기, מחק_ערך, גודל, מערכות_מידע_ריק_ערך, נקה_תוכן | ערך_רשימה(目錄): 순서가 있는 ערך_ערך 모음 |
| מילון | 넣기, חפש_ערך_832f7474, 있는가, מחק_ערך, גודל, נקה_תוכן | מילון(辭典): 찾는 말인 열쇠에 값을 대응 |
| 작업 | הפעלה(실행할일), 기다리기(משימתרקע), רווח_משימה, 살아있는가 | 작업 שרשור_ערך: 한 תוכנית_f5044b9b 안의 לבצע_פקודה זרם_ערך |
| 통신 | פתח, שלח, לקבל, פסק_זמן, סגירה | 통신(通信), יחידת_נתונים(電文), הסב_ערך: נתונים 교환·메시지·포트의 역할 |
| 화면 | מלבן, מחק_ערך | 화면(畫面): בפועל_נתונים 그림을 표시하는 면 |
| ליבה_ערך | 밀리초, מלבן | עצמי JVM의 고정 native חיבור; 일반 JNI는 아님 |

이 명명은 נוכחי_פריט 기능을 설명하는 용어 선택이다. 기존 한국어에 없던 역사적 어원을 만들어 주장하지 않는다. שם_קובץ_טקסט·식별자는 UTF-8 소스로 보관한다. `문자.פענח_נתונים`는 잘못된 UTF-8에 IllegalArgumentException을 던지며, `לקדד`는 짝이 없는 서로게이트를 `?`로 바꾼다. `קובץ.קרא`는 엄격한 UTF-8 복호화를 적용한다. 화면 색은 `빨강 | (초록 << 8) | (파랑 << 16)` 형식이다.

## לבצע_פקודה 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(עברית כיתה_ערך 포함), class당 16 KiB·קבוע_ערך 풀 511항목, 전체 פעולת_שירות_ערך/ערך_שדה 각각 512개. פעולת_שירות_ערך קוד_ערך 8 KiB, מקומי_היקף משתנה_ערך_541034c4·피연산자 אופרנד_רמז 각각 128슬롯, ארגומנטים 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 לבצע_פקודה 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- אובייקט_ערך 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 בפועל_נתונים 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 קובץ·대형 מחרוזת_ערך·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 פקודה 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 קלט_ערך 대기는 기한을 갱신하고 חלון מתג_מצב 시 중단·재개한다. 일반 שרת_ערך·계산의 무제한 실행은 아직 없다. 미지원 פקודה·משאב_ערך 부족은 명시적인 오류로 종료한다.
- RAM קובץ 최대 64개, 파일당 16384바이트, נתיב UTF-8 63바이트. RAM 디렉터리와 עמית_ערך/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 עברית class는 RAM קובץ 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 נוכחי_פריט 경로에서 מקור_עץ·כיתה_ערך·נתונים 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 חיצוני_ערך IPv4를 제공한다. בפועל_נתונים GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. יחידת_נתונים 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 לבצע_פקודה 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 מערך_ערך, 완전한 מערך_ערך 공변성·인터페이스 שכבה_ערך 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/הצפן_נתונים/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 תמך_ערך 부분집합은 아래 및 개발 매뉴얼을 참고한다. כיתה_ערך קובץ 전체 검증기·גישה_ערך_68aed533 הרשאה_ערך/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 הגן_ערך 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM ערך/לאמת/כיתה_ערך 로더와 חריגה 모델 → 영속 VFS·mmap·שעון·원자 ניתוח_ערך·בפועל_נתונים 스레드/סנכרן ABI → OpenJDK java.base 및 native ספריה 이식 → התקן_ערך_e13f0cd9 네트워크·TCP/IP → חלון 시스템/גופן_ערך/입력기·java.desktop → Java SE 호환성 시험. נוכחי_פריט עצמי JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## לאמת

`כלים/נסה_מחשב_וירטואלי_java.py`는 같은 Java 8 class 파일의 출력을 ארח OpenJDK `-Xverify:all`과 QEMU raspi4b עצמי 커널에서 비교한다. אובייקט_ערך/상속/인터페이스·switch·מערך_ערך, חריגה/finally, 컬렉션/GC, Thread/נעל_ערך, עברית UTF-8/קובץ/컬렉션, בפועל_נתונים UDP 루프백/ערך_זמן 초과, 게스트 한글 מקור_עץ בנה_מקור, מערך_ערך כתב_ערך/מופע_ערך/קובץ 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 קובץ דחייה_ערך 시험을 실행한다. UDP לשקף_בסיס 실행에는 ארח 루프백 소켓 권한이 필요하다.

`כלים/부팅시험.py`는 ליבה_ערך הגן_ערך/회귀 시험과 별도로 עברית Java 화면 API가 בפועל_נתונים 픽셀을 그렸는지도 QMP 화면 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. בפועל_נתונים Pi4 חומרה_ערך_9591fb0a 부팅 시험과 전체 JDK 호환성 시험 결과는 아니다.


## JVM 0.3: 네트워크와 GUI הרחבה_ערך

`Socket`/`ServerSocket` יצר·חיבור·accept·양방향 InputStream/OutputStream·close·EOF·ערך_זמן 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 חיצוני_ערך ספרה_ערך IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 סיים_שיחה_נקודה 16개, Java 루프백 버퍼 1024바이트, חיצוני_ערך TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. אינטראקטיבי 이벤트 대기는 לבצע_פקודה 기한을 갱신하고 מסוף מתג_מצב 시 프로세스 상태를 מאגר_ערך·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

עברית `חלון`, `רכיב_גרפי`, `קשר_הובלה` 클래스를 הפצה_ערך JAR와 עצמי JVM 내장 자원에 추가했다. 상세 פעולת_שירות_ערך·제한·מקור_עץ·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## עברית 객체의 직접 לבצע_פקודה

`חלון`, `תווית`, `שדה_טקסט`, `לחצן`, `אירוע_תור`, `המלצה_הודעה`, `משימתרקע`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. עצמי JVM의 אובייקט_ערך יצר,
לעצב_ערך 검사, 화면 호출, אירוע 큐, שרשור_ערך 스케줄러에 עברית 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 לבצע_פקודה 경로도 유지한다.
עברית 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

עצמי 실행기의 עברית 진입점은 `public static void הפעלה()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 עברית 진입점을 우선한다.
명령행 인수는 `실행인수.개수()`와 `실행인수.טקסט(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. סטטי_ערך קובץ 예제는 게스트
javac로도 컴파일하며, GUI/שרשור_ערך 소스는 ארח `javac --release 8`을 사용한다.
직접 GUI/שרשור_ערך API는 עצמי JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
עברית 가닥의 לבצע_פקודה·רק_רגע_ערך·중복 הפעלה דחייה_ערך, GUI אירוע מקור_ערך·מדד·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

פעולת_שירות_ערך 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
עברית 클래스도 실행되지만, מחרוזת_ערך 리터럴·표준 ספריה 재정의·native
חיבור·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 예제](한국어자바/안내.md)를 참고한다.

## מסוף 부분 רענן

להעביר_ערך·גודל 변경은 새 חלון 영역과 이전 자리에서 드러난 띠만 합성한다.
1920×32 פיקסל(240 KiB)의 임시 그림에서 배경·겹친 חלון·תו_ערך·GUI를 먼저
완성하고, נוכחי_פריט הופעה_ערך 메모리와 비교하여 달라진 화소만 기록한다.
32줄보다 큰 영역은 여러 띠로 처리하므로 전체 프레임을 원자적으로
교체하거나 수직 동기에 맞추는 방식은 아니다. 전체 배경을 먼저 지우는
중간 화면은 표시하지 않는다. 좌표가 같으면 נסה_שנית_ערך 그리지 않는다.

`make test-redraw`는 בפועל_נתונים C 그리기 코드를 호스트의 זיכרון_נתונים 화면에 연결해
להעביר_ערך 80회·גודל שנה_ערך 40회·겹친 חלון 4개를 전체 합성 결과와 פיקסל 단위로 대조한다.
אזור_ערך_0e9a97ab 밖 משתמש ציור_ערך, 동일 פיקסל 무기록, מצביע 밑그림, בפועל_נתונים 화면 שורה 간격을
검사한다. 이 시험의 시간은 ארח CPU 측정이며 Pi 4/QEMU 속도로 해석하지 않는다.
`make test-resize`는 QEMU/VNC의 640×480 및 1920×1080에서 왼쪽 모서리 גרור_ערך,
한글 קלט_ערך·vi 미저장 תוכן_ערך·독립 חלון 크기를 검사한다.
