# עצמי ARM64 Java 커널의 C/C++ קובץ·루프백 חיבור

이 디렉터리는 `platforms/rpi4-native` עצמי ליבה_ערך 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 עברית 함수명과 `extern "C"` ABI를 제공한다. `חיבור.c`는 ליבה_ערך 안에서 AOT Java קובץ 메서드에 직접 연결하고, `משתמש_גשר.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. בפועל_נתונים קובץ 처리는 `קבציםבזיכרון.java`, 루프백 יחידת_נתונים 처리는 `לולאה_חוזרת_Loopback_רשת.java`, 연결형 흐름은 `זרם_רשת.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 ליבה_ערך 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·צף_נקודה_ערך ניתוח_ערך·קובץ·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

תמך_ערך: `פתח_קובץ`, `파일자료읽기`, `כתיבה_קובץ_נתונים`, `סגור_קובץ`, `חפש_קובץ`, `הסר_קובץ_ערך_שם`, `파일길이정하기`, 보조 פונקציה_ערך `גודל_קובץ`. שגיאה 시 -1과 작업별 `מספר_שגיאה`를 반환한다. `파일저장확정`은 RAM 파일이므로 ENOSYS를 반환한다. קובץ 16개, 각 16384바이트, שם 63바이트, 서술자 16개이며 RAM 디렉터리·עמית_ערך/절대 경로를 제공한다. הרשאה_ערך/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 בפועל_נתונים עברית 함수와 독립 구조체를 선언한다.
`ליצור_משתתף`, `לאגד_למען`, `שלח_יחידת_נתונים_נתונים/לקבל`, `לקשר_רשת/기다리기/לקבל`는
`משתמש_גשר.c`에서 SVC를 호출하며 מאקרו_ערך 별칭이 아니다. `struct 인터넷통신주소`의
`למען_משפחה`, `מספר_יציאה`, `כתובת_אינטרנט.למען_ערך`을 사용한다. 상수는 enum의
`ענן_משפחה`, `Socket_של_יחידת_נתונים`, `יחידת_נתונים_פרוטוקול`, `זרם_רשת`, `זרם_פרוטוקול_תעבורה`이다.
עברית·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. חיצוני_ערך 통신은 עצמי 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. בפועל_נתונים Pi 4 GENET 드라이버는 미지원이다.
소켓도 בפועל_נתונים פונקציה_ערך `סגור_קובץ`로 닫는다.
