# משתמש 호출 경계

대상은 jkoros i386 ELF32다. Linux i386의 호출 번호와 바이너리 호환이 아니다. C의 cdecl 인수를 `מחשב/מערכת_הפעלה_שיחות_טלפון.s`에서 EAX(מדד), EBX·ECX·EDX·ESI·EDI(첫째~다섯째 ארגומנטים)로 변환한다. EBX·ESI·EDI·EBP를 보존하며 결과는 EAX다. ליבה_ערך 실패는 음수 שגיאה מדד, C ספריה 실패는 -1과 양수 errno다.

커널은 0x04000000 이상, 0x04400000 미만의 משתמש אזור_ערך_0e9a97ab 안에 자료의 전체 길이가 들어가는지 확인한다. 단순 널 검사가 아니다. C נתונים 주소는 בית_ערך 주소이며, 기존 Java AOT `int[]` 포인터와 혼용하지 않는다. Java קובץ 흐름의 어셈블리 경계가 별도 בית_ערך 버퍼를 마련하여 같은 호출을 사용한다.

|---|---|---|
| 30 | פתח_קובץ | NUL 끝 שם למען, הגדרות, 허가 |
| 31 | 파일자료읽기 | 서술자, נתונים למען, בית_ערך 수 |
| 32 | כתיבה_קובץ_נתונים | 서술자, נתונים למען, בית_ערך 수 |
| 33 | סגור_קובץ | 서술자 |
| 34 | חפש_קובץ | 서술자, קידוד_ערך 있는 היסט_ערך, לשקף_בסיס |
| 35 | 파일서술자복제 | 서술자 |
| 36 | 파일서술자지정복제 | 서술자, 새 서술자 |

| 44 | לקבל_יחידת_נתונים_נתונים | 서술자, נתונים למען, 길이, הגדרות, בקשה למען |

| 46 | ערכה_לקבל_פסק_זמן | 서술자, 0~2000 밀리초 |
| 47 | 파일저장확정 | 서술자 |

43번 요청은 32비트 주소와 32비트 길이의 두 칸이다. 44번 요청은 32비트 주소와 길이를 담은 32비트 값의 למען 두 칸이다. לקבל_ערך_cef4d8ab 주소가 NULL이면 עמית_ערך למען 기록을 생략한다. sockaddr_in은 16바이트이며 למען 체계는 התקן_ערך_e13f0cd9 בית_ערך רצף_ערך, 접속번호와 IP 주소는 네트워크 בית_ערך 차례다. 축소된 למען 버퍼에도 들어가는 앞부분을 쓰고 전체 למען גודל 16을 반환한다.

0~22번의 기존 Java AOT 호출은 유지한다. 0은 יציאה_תוכנית, 2·3은 기존 ארגומנטים 조회다. נוכחי_פריט 커널의 ארגומנטים 목록이 לבצע_פקודה 이름을 제외하므로 C 진입기는 argv[0]에 고정 מחרוזת_ערך `jkoros-app`을 넣고 이후 인수를 전달한다. argv 끝에는 NULL이 있다. 이 제한도 일반 UNIX תהליך_ערך ABI와 다른 점이다.

표준 헤더의 מספר_שלם גודל, 플래그 ערך, stat ערך_שדה 순서는 `קודמקור/포함/`에 정의한다. 동적 חיבור·다중 תהליך_ערך·스레드가 추가되면 שגיאה מדד 저장과 משאב_ערך 수명, 호출 경계도 함께 검토해야 한다.
