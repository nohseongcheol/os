# JIsrOS

נוכחי_פריט עצמי ARM64 배포판은 [LICENSE](LICENSE)의 COSL 상업 조건을 유지한다. 제3자 라이선스의 권리는 별도로 보장하며, הפצה_ערך 시 מקור_עץ·재연결 자료를 포함하는 절차는 [COSL הפצה_ערך 안내](platforms/rpi4-native/COSL배포안내.md)에 있다.

עצמי ARM64 판의 `ipconfig`/`ip`, `ping`, `ps`/`top`, `free`/`df`, `poweroff`와 עברית 명령은 [네트워크·מערכת_הפעלה_ערך פקודה 안내](platforms/rpi4-native/네트워크와체계명령.md)를 참고한다. 새 커널을 부팅한 הקודם_ערך `help system`으로 볼 수 있다.

Raspberry Pi 4 **עצמי Java ARM64 ליבה_ערך**은 [עצמי Pi4 안내](platforms/rpi4-native/안내.md)에 있다. Linux 없이 부팅하며 GUI מסוף·vi, עצמי JVM의 Swing 일부 API, TCP/UDP·FTP, 게스트 TinyCC·MicroPython, C/C++의 posix-kor 호출을 제공한다. [עברית Java 통신·חריגה API](platforms/rpi4-native/한국어자바/안내.md)와 [עברית מקור_עץ 명명](platforms/rpi4-native/명명/안내.md)을 지원한다. [עצמי SSH·VNC 및 GENET 드라이버](platforms/rpi4-native/חיצוני_קשר_מדריך.md)를 포함하며, 네트워크는 QEMU의 UART SLIP 경로로 검증했다. בפועל_נתונים Pi 4 GENET 동작은 미검증이고, USB קלט_ערך·영속 저장과 전체 OpenJDK·Swing은 아직 תמך_ערך לגזור 밖이다.

Raspberry Pi 4용 Linux·OpenJDK 실행판과 משתמש סביבה להעביר_ערך 기능은 [라즈베리파이 실행판](platforms/rpi4/README.md)에 있다. בפועל_נתונים ARM64 JDK/JRE와 시스템·משתמש בנה_תמונה בנייה 경로를 제공한다. 기존 עצמי x86 커널과는 별도 לבצע_פקודה 기반이다. 일반 Java `.class`/JAR의 לבצע_פקודה קובץ 생성은 [OpenJDK לבצע_פקודה קובץ](compiler/OpenJDK-실행파일.md), עברית API는 [עברית Java ספריה](한국어자바/안내.md)를 참고한다.

`jkoros`는 `engos`의 기능을 Java 관리 커널로 옮기는 프로젝트다. 프로젝트가 소유하는 Java פונקציה_ערך, משתנה_ערך_541034c4, לעצב_ערך 및 Java קובץ 이름은 한국어로 작성한다. 표준 Java 실행기의 `main`, Java 표준 ספריה לעצב_ערך, x86 부트 ABI 등 חיצוני_ערך 계약은 보존한다. עצמי ARM64 실행기는 עברית `הפעלה()`도 진입점으로 지원하며, עברית GUI·작업 가닥을 JVM에 직접 구현했다. עצמי ARM64 C 연결부·Python 도구와 공용 x86·ARM64 AOT 번역기의 עצמי 이름도 한국어로 작성한다. 이전 경로의 호환 נקודת_כניסה, OpenJDK 보조 도구와 Linux גירסה_ערך 도구에는 영어 이름이 남아 있고 [명명 원칙·말의 근거·전체 קודמקור 검토 לגזור](platforms/rpi4-native/명명/안내.md)를 별도로 기록한다.

## נוכחי_פריט 구현

아래 목록은 기존 `דור_קודם_מקור/`의 JVM 관리 커널에 대한 것이다. בפועל_נתונים 네이티브 커널의 범위는 `os/안내.md`에서 별도로 설명한다.

- ליישר_ערך 할당과 해제를 지원하는 זיכרון_אזור מנהל_ערך
- למען למען_אזור, דף_ערך חיבור, כתוב 시 מופע_ערך(COW)
- תהליך_ערך מזהה_ערך, להכין 대기열, fork/wait מצב_ערך
- 과정별 קובץ 서술자, open/read/seek/dup/close
- ELF32 식별 및 מקטע_ערך 검사
- 키보드·마우스 קלט_ערך אירוע 대기열
- 직렬 단말과 네이티브 חומרה_ערך_9591fb0a 경계
- 관리 ליבה_ערך 전체 자동 시험

세부 대응 범위와 아직 필요한 네이티브 연결은 [기능 대응표](문서/기능대응.md)에 기록한다.

## 빌드와 시험

새 네이티브 구현은 `compiler/`와 `os/`에 있다. 기존 `דור_קודם_מקור/`의 JVM 관리 커널은 그대로 보존하며, 두 구현의 시험과 기능 범위는 서로 다르다.

```sh
cd /home/user/jkoros
make                 # 네이티브 계산 예제 + Java ליבה_ערך ELF
make iso             # os/build/kernel.iso
make run             # QEMU 직렬 단말; help קלט_ערך (종료는 Ctrl+A, X)
make run-gui         # ISO를 QEMU 화면/PS2 키보드로 לבצע_פקודה
make vbox            # 전용 VirtualBox VM 자동 יצר·לבצע_פקודה (GUI)
make vbox-status     # VirtualBox מצב_ערך·ISO·직렬 לרשום_שיא נתיב ודא_אמת
make test-vbox       # VirtualBox תוכנית_מפעיל מצב_ערך תהליך_ערך_ערך 시험 (בפועל_נתונים VM שנה_ערך 없음)
make test            # מהדר 시험 + ELF/ISO 부팅 및 פקודה קלט_ערך 시험
make apps            # 독립 משתמש ELF תוכנית_f5044b9b בנייה
make test-network    # משתמש מצב_ערך_a83655ea·UDP 왕복·זיכרון_נתונים הגן_ערך 시험
make test-java       # 게스트 javac/JVM + OpenJDK 양방향 교차 לבצע_פקודה 시험
make posix-kor       # עברית C 헤더와 בפועל_נתונים ליבה_ערך 호출 ספריה
make test-posix      # קובץ/UDP/מאגר_ערך/Java קובץ קלט_פלט 시험
make -C os run-store # 전용 מאגר_ערך 매체로 QEMU 부팅
make legacy-test     # 아래 기존 JVM 관리 커널의 47개 시험
```

`compiler/`는 호스트의 `javac`를 문법·כתב_ערך 검사 전단으로 사용하고 עצמי 바이트코드→x86 변환기로 ELF32 기계어를 만든다. 빌드할 때는 JDK가 필요하지만 생성된 커널과 ELF는 חיצוני_ערך JVM 없이 실행된다. 전체 Java, אובייקט_ערך 모델, 표준 라이브러리와 기존 관리 ליבה_ערך 전체의 AOT 변환은 아직 지원하지 않는다. 자세한 תמך_ערך 문법과 명령은 [מהדר 안내](compiler/안내.md), בפועל_נתונים 부팅 기능과 한계는 [네이티브 מערכת_הפעלה 안내](os/안내.md)를 참고한다.

네이티브 셸에 עצמי 제한형 `javac`와 `java`를 추가했다. `edit Demo.java`로 소스를 입력하고 `.save`로 저장한 הקודם_ערך `javac Demo.java`, `java Demo`로 **게스트 내부에서 컴파일하고 לבצע_פקודה**할 수 있다. ערך_ברירת_מחדל 예제는 `javac Hello.java`, `java Hello`다. 파일은 RAM에서 동작하며, 전용 מאגר_ערך 매체를 연결하면 `sync`로 재부팅 후에도 보존할 수 있다. **OpenJDK/JDK 전체 이식은 아니며**, 단일 כיתה_ערך·סטטי_ערך פונקציה_ערך·מספר_שלם·מחרוזת_ערך·תנאי/반복문과 일부 표준 호출을 지원한다. תמך_ערך לגזור, חיצוני_ערך קובץ 적재와 시험은 [Java 개발 סביבה 안내](문서/자바개발환경.md)에 있다.

네이티브 셸에서 `apps`, `run hello first second`, `net`, `run netcheck`를 사용할 수 있다. 독립 ELF를 ring 3에 적재하고 `int 0x80` 호출을 통해 פלטטקסט·ארגומנטים·UDP 네트워크를 제공한다. 별도 ארח 터미널에서 `python3 os/כלים/הד_נתונים.py --port 9000`을 실행한 הקודם_ערך 게스트에서 `run udp 10.0.2.2 9000 hello`로 בפועל_נתונים 왕복을 확인한다. 새 תוכנית_f5044b9b אוגר_ערך_bb216f10, API 및 제한은 [משתמש לבצע_פקודה·네트워크 안내](os/משתמש/안내.md)를 참고한다. נוכחי_פריט QEMU RTL8139·סטטי_ערך IPv4·UDP 전용이며 TCP/DNS는 미지원이며, 전용 IDE מאגר_ערך 형식과 POSIX קובץ/UDP 일부 기능을 추가했다.

`make vbox`는 `jkoros operating system` 전용 VM을 만들고 디스크 없이 ISO로 부팅한다. לבצע_פקודה 중이면 유지하고, מאגר_ערך·일시정지 상태이면 재개하며, 꺼져 있을 때만 새 ISO를 빌드해 연결한다. VirtualBox에서 부팅과 셸의 משתמש תוכנית_f5044b9b 실행을 확인했다. 다만 נוכחי_פריט VirtualBox용 네트워크 드라이버는 없어 네트워크 장치를 비활성화한다. UDP 시험에는 `make run`을 사용한다. 상태별 동작과 새 בנייה 반영 방법은 [VirtualBox לבצע_פקודה 안내](문서/가상상자실행.md)에 있다.

기존 관리 커널만 시험하려면:

```sh
cd /home/user/jkoros
make -f ליצור_ערך.mk 검사
make -f ליצור_ערך.mk ארח
```

`ארח`는 여전히 JVM 관리 계층의 פעולה 시험이다. `make -f ליצור_ערך.mk בנה_תמונה`는 새 `os/`의 제한형 네이티브 ליבה_ערך ISO를 만든다. 기존 `דור_קודם_מקור/`의 מערכת_קבצים·תהליך_ערך·רשת_רמז 구현 전체를 이 ISO에 이식했다는 의미는 아니다.

עברית פונקציה_ערך·משתנה_ערך_541034c4·קובץ 이름과 בפועל_נתונים C API는 [posix-kor](posix-kor/안내.md)에 있다. 게스트 Java에서는 `FileInputStream`·`FileOutputStream`의 단일 בית_ערך 입출력도 지원한다. 전체 POSIX·OpenJDK·Swing 지원으로 확대된 것은 아니다.

חיצוני_ערך 배포용 `pack.sh` / `unpack.sh`와 자동 의존성 복원은 [הפצה_ערך 안내](distribution/README.md)를 참고하세요.
