# propriu ARM64 JVM 0.4와 Română bibliotecă

Română 통신·excepție 사용법은 [Română Java API](한국어자바/안내.md), funcție_VALUE·variabilă_VALUE·Fișier 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

JAR executa_comandă, extern_VALUE IPv4 TCP/UDP, 별도 정적 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 obiect_VALUE·Thread·Swing은 JVM 경로의 기능이며 AOT suport_VALUE 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 executa_comandă**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK Clasă_VALUE bibliotecă 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 Clasă_VALUE·정적 metodă_VALUE 중심이던 실행기를 obiect_VALUE·bibliotecă executa_comandă 기반으로 넓힌 것이다.

## 실행과 compilare_sursă

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# propriu nucleu_VALUE 안에서 sursă_arborescență compilare_sursă → class executa_comandă, Română API 호출
python3 Instrumente/executa_Fișier.py 시험/자바/한글소스.java

# obiect_VALUE·excepție 등은 gazdă JDK로 Java 8 class를 만든 후 propriu 커널에서 executa_comandă
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 Instrumente/executa_Fișier.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 Transfer_VALUE
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 Instrumente/executa_Fișier.py build/my-java/객체시험.class \
  --include build/my-java/tapet_VALUE.class --include build/my-java/ramură_VALUE.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.Clasă_VALUE.class`라는 RAM Fișier 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.Clasă_VALUE`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.Clasă_VALUE`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar Fișier.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 Română 클래스만 찾는다. 배포 Română bibliotecă JAR는 gazdă javac의 classpath로 사용하며, 같은 클래스가 utilizator JVM ELF에도 Citire 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 정적 metodă_VALUE, int/boolean/char/String, condiție·sprint_VALUE, șir_VALUE 결합, 일부 Fișier 스트림 등의 **propriu 부분집합 compilator**다. obiect_VALUE declarație·상속·try/catch·Thread utiliza_VALUE 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 propriu JVM에서 실행한다. Română API 중 Rezultat·문자 스칼라 funcție_VALUE·Fișier Citire/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] Argumente) throws Exception {
        Română.propriu.Rezultat.scriere_linie("안녕하세요😀");
        Română.propriu.Rezultat.수쓰기(Română.propriu.문자.cod_caracter_COUNT("한글😀"));
        Română.propriu.Fișier.Scriere("인사.txt", "한글 Fișier😀");
        Română.propriu.Rezultat.scriere_linie(Română.propriu.Fișier.Citire("인사.txt"));
    }
}
```

## Română API

독립 패키지 **`Română.propriu`**를 사용한다. Linux판 `Română.자바`가 요구하는 NIO/Swing/HTTP API를 propriu 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 Clasă_VALUE Nume·metodă_VALUE·Argumente·valoare_câmp·Fișier 이름에 한국어를 사용한다. 표준 Java Clasă_VALUE 이름은 호환성을 위해 보존한다.

| Clasă_VALUE | 공개 기능 | 이름의 의미 |
|---|---|---|
| Rezultat | Scriere, scriere_linie, 수쓰기 | Rezultat(出力): 내용을 바깥으로 내보냄 |
| 문자 | lungime_VALUE, 같음, lipi_SMS, decupa_VALUE, analiza_întreg/scriere_întreg_VALUE, cod_caracter_COUNT, codifica/decripta_date | 문자(文字), codificare_VALUE(符號): 글의 단위와 그 값을 바이트로 나타내는 filtru_VALUE |
| Fișier | Citire/Scriere(String Nume), 바이트읽기/scriere_byte_VALUE | 널리 쓰는 utilizator 용어를 보존; RAM 자료의 Nume |
| intrare_Listă | 더하기, Citire, REPLACE_VALUE, șterge_intrare, Mărime, 비었는가, goli_TOC | intrare_Listă(目錄): 순서가 있는 intrare_VALUE 모음 |

| 작업 | Pornește(실행할일), 기다리기(작업가닥), YIELD_sarcină, 살아있는가 | 작업 fir_VALUE: 한 program_f5044b9b 안의 executa_comandă flux_VALUE |

## executa_comandă 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(Română Clasă_VALUE 포함), class당 16 KiB·constantă_VALUE 풀 511항목, 전체 metodă_VALUE/valoare_câmp 각각 512개. metodă_VALUE cod_VALUE 8 KiB, local_gamă variabilă_VALUE·피연산자 operand_Teanc 각각 128슬롯, Argumente 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 executa_comandă 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- obiect_VALUE 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 real_date 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 Fișier·대형 șir_VALUE·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 Comandă 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 Fereastră SWITCH_mod 시 중단·재개한다. 일반 server_VALUE·계산의 무제한 실행은 아직 없다. 미지원 Comandă·resursă_VALUE 부족은 명시적인 오류로 종료한다.
- RAM Fișier 최대 64개, 파일당 16384바이트, Cale UTF-8 63바이트. RAM 디렉터리와 pereche_VALUE/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 Română class는 RAM Fișier 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 curent_element 경로에서 sursă_arborescență·Clasă_VALUE·date 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 extern_VALUE IPv4를 제공한다. real_date GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. diagramă_informații 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 executa_comandă 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 ARRAY_VALUE, 완전한 ARRAY_VALUE 공변성·인터페이스 strat_VALUE 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/cripta_date/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 suport_VALUE 부분집합은 아래 및 개발 매뉴얼을 참고한다. Clasă_VALUE Fișier 전체 검증기·acces_intrare permisiune_VALUE/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 proteja_VALUE 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM VALUE/valida/Clasă_VALUE 로더와 excepție 모델 → 영속 VFS·mmap·Ceas·원자 operație_VALUE·real_date 스레드/sincroniz ABI → OpenJDK java.base 및 native bibliotecă 이식 → mobil_VALUE 네트워크·TCP/IP → Fereastră 시스템/font_VALUE/입력기·java.desktop → Java SE 호환성 시험. curent_element propriu JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## JVM 0.3: 네트워크와 GUI extensie_VALUE

`Socket`/`ServerSocket` genera·Conectează·accept·양방향 InputStream/OutputStream·close·EOF·oră_VALUE 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 extern_VALUE cifră_VALUE IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 termina_un_apel_p 16개, Java 루프백 버퍼 1024바이트, extern_VALUE TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. 대화형 이벤트 대기는 executa_comandă 기한을 갱신하고 Terminal SWITCH_mod 시 프로세스 상태를 Store_VALUE·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

Română `Fereastră`, `widget`, `연결통신` 클래스를 배포 JAR와 propriu JVM 내장 자원에 추가했다. 상세 metodă_VALUE·제한·sursă_arborescență·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## Română 객체의 직접 executa_comandă

`Fereastră`, `Etichetă`, `câmp_text`, `buton`, `eveniment_coadă`, `Acțiune_înștiințare`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. propriu JVM의 obiect_VALUE genera,
format_VALUE 검사, 화면 호출, Eveniment 큐, fir_VALUE 스케줄러에 Română 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 executa_comandă 경로도 유지한다.
Română 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

propriu 실행기의 Română 진입점은 `public static void Pornește()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 Română 진입점을 우선한다.
명령행 인수는 `실행인수.element_COUNT()`와 `실행인수.SMS(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. 정적 Fișier 예제는 게스트
javac로도 컴파일하며, GUI/fir_VALUE 소스는 gazdă `javac --release 8`을 사용한다.
직접 GUI/fir_VALUE API는 propriu JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
Română 가닥의 executa_comandă·대기·중복 Pornește respinge_VALUE, GUI Eveniment 출처·INDEX·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.
