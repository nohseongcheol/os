# свой 커널의 네트워크와 операционная_система_ЗНАЧЕН команда

[실행 계층과 внешний_ЗНАЧЕН коммуникация 점검](실행계층과외부통신점검.md)에 정리했다.

## IP 설정과 коммуникация проверять

```sh
ipconfig
ip addr show
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2
아이피설정 set 10.0.2.20 255.255.255.0 10.0.2.2
ping -c 4 -W 1 10.0.2.2
тест_ответ -c 4 10.0.2.2
ip route show
ip link set dev sl0 down
ip link set dev sl0 up
netstat
```

초깃값은 `sl0`, `10.0.2.15/24`, шлюз_ЗНАЧЕН `10.0.2.2`다. АДРЕС 설정은 재부팅 전까지 유지된다. TCP/UDP 끝점이 열려 있으면 `error -16`으로 변경을 거부한다. 먼저 `ftpd stop` 등으로 서비스를 닫고 프로그램의 소켓을 닫는다. 잘못된 АДРЕС·비연속 넷마스크·다른 망의 관문은 적용하지 않는다.

`ip`는 위 구문의 부분집합이며 Linux iproute2 전체 문법을 구현하지 않는다. `ping`은 IPv4 цифра_ЗНАЧЕН АДРЕС, `-c 1..100`, `-W 1..10`초를 지원한다. Название анализировать_ЗНАЧЕН·IPv6는 미지원이며 GENET의 DHCP는 внешний_ЗНАЧЕН контакт_e05f319b 구현에 추가했다. 응답이 없으면 код_выхода 1, 잘못된 인수는 2, пространство_пользователя 취소는 130이다. `ping ...; echo $?`로 확인한다.

QEMU внешний_ЗНАЧЕН 통신은 UART SLIP→NAT 연결을 사용한다. `--network` 없이도 свой АДРЕС запрос_ЗНАЧЕН·설정은 가능하지만 внешний_ЗНАЧЕН 응답은 오지 않는다. значение_по_умолчанию NAT는 `10.0.2.0/24`다. 실물 Pi의 GENET 드라이버는 별도로 추가했으며 Доска 검증이 필요하다. Wi-Fi는 미지원이다.

주소를 `.20`으로 바꾼 BACK_ЗНАЧЕН FTP 등 **외부에서 들어오는 Подключить**까지 사용할 때는 실행 시 вперед_ЗНАЧЕН 대상도 지정한다.

```sh
make desktop ARGS="--network --guest-ip 10.0.2.20"
# 부팅한 게스트 안에서
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2
ftpd start
```

`--guest-ip`는 NAT вперед_ЗНАЧЕН 대상이며 게스트의 주소를 자동 설정하지 않는다. FTP управление_ЗНАЧЕН 포트는 узел `127.0.0.1:2121`, 수동 데이터 포트는 50000~50007이다. 여러 VM을 함께 띄울 때는 `--network-host 127.0.0.2 --port 5903`처럼 узел 루프백 주소와 VNC 포트를 구분한다. FTP와 Java/C 소켓은 변경된 фактический_данные 게스트 IP를 사용한다.

## Состояние_ЗНАЧЕН 조회의 의미

`ps`는 ядро_ЗНАЧЕН/оболочка, 살아 있는 협력 작업, 최대 4개의 EL0 пространство_пользователя 세션을 표시한다. 다른 터미널에 열린 `vi` 등을 `SUSPENDED` 상태로 볼 수 있다. `MAPPED_KiB`는 фактический_данные 페이지 매핑, `RUN_ms`는 해당 세션이 선택된 동안의 경과 значение_времени(시스템 호출 объявления)이며 정밀 CPU 사용률이 아니다. `top -n 1`은 한 번, `top -n 2`는 두 번 표시한다. 리다이렉션된 `top`의 기본값은 한 번이다.

`free`의 AOT куча_ЗНАЧЕН 사용량은 할당기에서 읽는다. 힙은 ядро_ЗНАЧЕН BSS에 포함되므로 각 줄을 모두 더하면 중복된다. 고정 예약 영역과 пространство_пользователя 페이지 매핑을 표시하며 Linux의 가용 RAM 계산이나 узел Память_данные 통계를 꾸며서 표시하지 않는다.

`df`는 RAM 파일시스템의 файл 64칸 × 16 KiB를 표시한다. файл 하나는 논리 크기와 별도로 16 KiB 칸을 예약한다. `Data`는 фактический_данные данные длина_ЗНАЧЕН итог_ЗНАЧЕН, `Reserved`는 использовать_ЗНАЧЕН 중인 слот_ввод 용량이다. 삭제 후에도 열린 파일은 마지막 참조를 닫을 때까지 계산한다. SD/영구 디스크 사용량은 아직 지원하지 않는다.

## 종료와 проверить

게스트에서 `poweroff` 또는 `전원끄기`를 입력한다. FTP·сокет_ЗНАЧЕН·пространство_пользователя 세션을 닫은 BACK_ЗНАЧЕН BCM PM Выход_программа 절차를 실행한다. RAM 파일은 재부팅 후 보존되지 않는다. QEMU에서는 게스트의 `SHUTDOWN / guest-shutdown` 이벤트와 ИТ_службы_обычный 종료를 검증한다. 실물 Pi 4 전원 회로 동작은 아직 시험하지 않았다.

реализация 근거: [Linux BCM watchdog의 power-off 절차](https://github.com/torvalds/linux/blob/master/drivers/watchdog/bcm2835_wdt.c), [QEMU BCM PM устройство_ЗНАЧЕН](https://github.com/qemu/qemu/blob/master/hw/misc/bcm2835_powermgt.c).

```sh
make test-system
# результат: build/verification/system-tools/report.json 및 serial.log
```

이 시험은 잘못된 IP отклонить_ЗНАЧЕН, фактический_данные ICMP 성공·시간초과, Подключить up/down, IP изменить_ЗНАЧЕН 후 FTP 송수신, df генерировать·삭제, куча_ЗНАЧЕН 계산, 다른 터미널의 vi PID·Память_данные, top обновить·Выход_программа, 한글 команда·Tab, 게스트 poweroff를 검사한다.

`java/worldos/кантри_ЗНАЧЕН/국가코드` 판에는 같은 기능과 국가별 команда 대응표 `native-commands.json`이 들어간다. 표준 명령은 모든 판에서 유지한다. 새 현지어 이름은 기능 중심 제안이며 현지 화자·어원 검토를 완료한 표준 용어는 아니다. 미번역 항목은 대응표의 `pending`에 명시한다.
