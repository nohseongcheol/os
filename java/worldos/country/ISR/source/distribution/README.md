# חיצוני_ערך 배포용 압축과 복원

Ubuntu x86_64에서 프로젝트 루트의 `./pack.sh`를 실행한다.
`dist/jkoros-source.tar.xz`, 체크섬 קובץ, 독립 לבצע_פקודה 가능한 `dist/unpack.sh`가 생성된다.
원본 캐시, מקור_עץ, משתמש 디스크는 삭제하거나 변경하지 않는다. 압축파일은 2 GB를
넘으면 생성에 실패한다. פלטטקסט 경로는 `./pack.sh /נתיב/jkoros-source.tar.xz`로 지정한다.

다른 Ubuntu PC에 압축파일, `.sha256`, `unpack.sh`를 함께 전달한 הקודם_ערך 실행한다.

```sh
./unpack.sh jkoros-source.tar.xz /원하는/새/נתיב/jkoros
make -C /원하는/새/נתיב/jkoros all korean-java iso
make -C /원하는/새/נתיב/jkoros rpi-native-image
make -C /원하는/새/נתיב/jkoros rpi-image
```

ערך_ברירת_מחדל 동작은 ארכיון_ערך לשחרר_אחסון 후 의존성 자동 다운로드와 준비까지다. Ubuntu בנייה 도구가
없으면 `sudo apt-get`으로 설치하며 מנהל_ערך 암호가 필요할 수 있다. חיצוני_ערך 소스의
SHA-256을 확인하고 ARM64 SDK/Linux לבצע_פקודה סביבה, ארח 도구와 JRE를 준비한다.
새 폴더의 위치를 기준으로 실행하므로 `/home/user` 경로를 만들 필요가 없다.

עצמי ARM64 커널만 개발한다면 `--profile native`로 GUI/Linux לבצע_פקודה סביבה 준비를
생략할 수 있다. בנייה 도구가 이미 설치되어 있으면 `--no-host-install`을 추가한다.
`--no-prepare`는 다운로드하지 않고 소스만 검사할 때 쓰는 명시적 선택이다.

להכין 도중 네트워크 오류가 나면 풀린 폴더에서 `./unpack.sh --prepare`를 נסה_שנית_ערך 실행한다.
기존 פלטטקסט מדריך_ערך 위에는 압축을 풀지 않는다. 개인 수정 파일을 덮어쓰지 않으며,
복원 יעד 파일의 내용이 예상 해시와 다르면 중단한다.

압축에서 `build`, `dist`, `תוצאה`, `.vbox`, Python 캐시, לרשום_ערך, משתמש 디스크와
קשר_e05f319b 키를 제외한다. Alpine 패키지 캐시는 외부에서 필요한 패키지만 נסה_שנית_ערך 받는다.
libassh, BearSSL, lwIP, uzlib, MicroPython 중 고정 URL/해시로 복구할 수 있는 원본은
제외하지만 로컬 수정 파일은 포함한다. 정확한 재다운로드 주소를 고정하지 못한
TinyCC 스냅샷, עצמי גופן_ערך, 프로젝트 소스와 라이선스 고지는 포함한다.

인터넷과 Ubuntu 패키지 מאגר_בסיס 및 Alpine 3.24 מאגר_בסיס 접근이 필요하다.
Alpine 저장소의 שימוש_ערך 가능한 패키지 버전을 받아 בפועל_נתונים 버전을 נעל_ערך 파일에 기록한다.
패키지 다운로드 후의 작업 폴더와 בנייה 산출물은 2 GB를 넘을 수 있다.
OpenJDK עצמי 소스의 별도 실험 빌드는 기존 מהדר 안내에 따라 소스를 준비한다.

`PORTABLE_DOWNLOAD_CACHE=/캐시/מדריך_ערך`를 지정하면 SHA-256을 파일명으로 하는
검증된 다운로드 파일을 먼저 사용한다. 캐시에 없는 항목은 자동 다운로드한다.
제외 목록과 ארכיון_ערך 크기는 `dist/jkoros-source.tar.xz.report.json`에 기록된다.
