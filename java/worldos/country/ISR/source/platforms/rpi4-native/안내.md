# Raspberry Pi 4 עצמי Java ליבה_ערך — משתמש לבצע_פקודה 기반

נוכחי_פריט עצמי 코드의 COSL 상업 תנאי, 제3자 고지 및 LGPL 재연결 자료는 [COSL הפצה_ערך 안내](COSL배포안내.md)를 참고한다. מתג_מצב 전 GPL 구성의 판단은 [이전 라이선스 검토](רשיון_סקירה.md)에 기록했다.

עברית 통신·חריגה 사용법은 [עברית Java API](한국어자바/안내.md), פונקציה_ערך·משתנה_ערך_541034c4·קובץ 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

Linux 없이 부팅하는 עצמי AArch64 커널이다. Java AOT ליבה_ערך 위에 **שורת_פקודה מעטפת, 게스트 Java מהדר·JVM, MicroPython, EL0 C++ לבצע_פקודה, קובץ·UDP 루프백 시스템 호출, 여러 한글 GUI מסוף·vi עורך·Swing 부분집합**을 제공한다. 커널의 קובץ נתונים/정책·루프백 העבר_ערך·מעטפת 상태는 Java, 화면 합성·פיקסל שנה_ערך·מצביע·클리핑도 Java로 구현하며, CPU/MMU/התקן_ערך_e13f0cd9 경계와 מסוף·תו_ערך 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 עצמי 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 לבצע_פקודה, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 קווי_ערך 송수신은 아직 미검증이다.** לבצע_פקודה·קשר_e05f319b·סיסמה_ערך 확인은 [חיצוני_ערך קשר_e05f319b 안내](חיצוני_קשר_מדריך.md)에 정리했다.

셸은 EL1 ליבה_ערך, `java` 등 משתמש לבצע_פקודה 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 לבצע_פקודה·קשר_e05f319b 방법 및 בפועל_נתונים 검증은
[לבצע_פקודה 계층과 חיצוני_ערך 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 בפועל_נתונים לבצע_פקודה 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 סטטי_ערך ELF는 `run --linux שם_קובץ_טקסט`으로 실행한다. [ELF·Linux ABI תמך_ערך 범위와 동일 바이너리 시험](실행파일규약.md).

GUI와 네트워크는 `python3 כלים/לבצע_פקודה.py --desktop --network`로 함께 사용한다. Java·C·Python의 עברית 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 부팅 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 수 있다. Remmina에서 **F9/Shift+Space/한·אפס_אופרנד מקש_ערך**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·בפועל_נתונים TCP/UDP·קובץ בית_ערך·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java דוגמתחלון`로 עברית Swing 예제를 실행한다. מסוף 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 נוכחי_פריט עמודה_ערך·שורה_ערך 수를 보여 준다.

לבצע_פקודה 버튼 화면은 5×7 영문 글꼴을 쓰며, מסוף 창은 Noto CJK/DejaVu에서 생성한 한글·Unicode 비트맵 글꼴을 쓴다. UART와 בפועל_נתונים 프레임버퍼의 한글 표시를 시험한다. 루프백은 동일 ליבה_ערך 내부의 יחידת_נתונים 전달이며 IP 패킷을 Ethernet으로 내보내는 드라이버가 아니다. 바깥 IPv4는 lwIP TCP/UDP 스택으로 보조 UART SLIP 경로를 사용한다. `python3 כלים/לבצע_פקודה.py --network`로 QEMU NAT를 연결하고 `ftpd start`로 서비스를 시작한다.

Java의 정확한 API·문법·לבצע_פקודה 제한과 עברית 사용법은 [עצמי JVM과 עברית ספריה](자바실행환경.md)에 정리했다. כיתה_ערך קובץ/JAR 배포는 [한국어자바](한국어자바) 소스에서 재현한다. 기존 Linux판 `עברית.자바`와 별도인 `עברית.עצמי` 패키지다.

**vi·여러 חלון·Swing·한글 Java/Python/C/C++·posix-kor 예제는 [한글 개발 매뉴얼](개발안내.md)에 정리했다.**

GUI מסוף לבצע_פקודה·단축키·מעטפת פקודה·제한은 [셸과 מסוף 사용법](מעטפת_פעולת_גם_מסוף.md)에 정리했다.

## נוכחי_פריט 컴퓨터에서 לבצע_פקודה

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

יציאה_תוכנית: **Ctrl+A הבא_פריט X**. 게스트 C/AOT כלים 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. ארח 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. מהדר 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/נתיב/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` תמך_ערך 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 לבצע_פקודה**한다. 기존 한 תו_ערך 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 ארגומנטים 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

| פקודה | פעולה |
|---|---|
| `help` / `info` | פקודה·בפועל_נתונים 구현 מצב_ערך |
| `ls` / `cat FILE` / `rm FILE` | RAM קובץ ערך_רשימה·תוכן_ערך·삭제 |
| `vi FILE` | משתמש אזור_ערך_0e9a97ab vi 부분집합, 한글 ערוך_ערך·מאגר_ערך·검색·되돌리기 |
| `edit FILE` | קובץ 전체를 새로 קלט_ערך; 단독 `.` 줄로 מאגר_ערך, Ctrl-C로 לבטל_ניתוח |
| `javac FILE.java` / `java CLASS [ARGS]` | עצמי 제한형 Java בנה_מקור·לבצע_פקודה |
| `python FILE.py [ARGS]` / `python -c 'CODE'` | MicroPython בנה_מקור·לבצע_פקודה |
| `load FILE` / `hex FILE` | 16진수 바이너리 קלט_ערך/פלטטקסט; 입력은 단독 `.` 줄로 מאגר_ערך |
| `run FILE.elf [ARGS]` / `run cpp` | 업로드한 עצמי ABI ELF / 내장 C++ 예제 |
| `net test` / `tasks` / `selftest` | UDP 루프백 / 협력식 작업 / EL0 הגן_ערך 시험 |
| `gui` / `terminal` | לבצע_פקודה 화면 / 한글 GUI מסוף; F12로 מסוף פתח·סגירה |
| `samples` | 삭제한 ערך_ברירת_מחדל 예제 לשחזר_מצב; 기존 파일은 보존 |

예를 들어 `edit 인사.java`를 입력한 הבא_פריט 아래 소스를 입력한다.

```java
public class 인사 { public static void main(String[] args) { int ערך = 7; System.out.println("한글=" + ערך); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 인사.java`, `java 인사`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. לבטל_ניתוח·잘못된 16진수·קיבולת_ערך 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, לבצע_פקודה 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 פקודה 인수는 최대 32개다. ציטוט·백슬래시·מעטפת משתנה_ערך_541034c4·파이프·리다이렉션 범위는 [מעטפת 설명](מעטפת_פעולת_גם_מסוף.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, למען **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode קלט_ערך·명시적 הדבק_ערך·לבצע_פקודה 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 כלים/לבצע_פקודה.py --desktop --network
# 다른 חומרה_הסב: python3 כלים/לבצע_פקודה.py --desktop --port 5903
```

종료는 실행한 ארח 터미널에서 Ctrl+C다. 기존 `python3 כלים/לבצע_פקודה.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. בפועל_נתונים Pi4 USB 입력기는 아직 없으며, VNC חיבור 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 בפועל_נתונים C++/UDP ELF לבצע_פקודה, `Hello.java` בנה_מקור 후 JVM לבצע_פקודה, `hello.py` לבצע_פקודה, GUI מסוף 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 אינטראקטיבי 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 זיכרון_נתונים·CPU 문맥을 보관한다. מעטפת·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

| `build/libposix-kor-arm64.a` | **ליבה_ערך 내부**에서 Java קובץ 구현을 직접 부르는 기존 חיבור |
| `build/libposix-kor-user.a` | **EL0 משתמש תוכנית_f5044b9b**에서 SVC로 קובץ/루프백을 호출하는 새 חיבור |
| `dist/jkoros-native-rpi4.img` | 128 MiB MBR/FAT32 SD בנה_תמונה |
| `dist/jkoros-native-rpi4-boot.zip` | FAT32 부팅 파티션에 복사할 קובץ לקבץ_ערך |
| `dist/jkoros-native-aarch64-sdk.tar.gz` | 사용자용 헤더·הפעלה קוד_ערך·ספריה·링커 תסריט_ערך·예제 |
| `dist/manifest.json`, `build/build.json` | SHA256과 בפועל_נתונים תמך_ערך מצב_ערך |

이미지는 확인된 공식 Pi 부팅 묶음에서 `start4.elf`, `fixup4.dat`, Pi4 DTB와 disable-bt overlay를 가져온다. Linux kernel/initramfs/rootfs는 넣지 않는다. 펌웨어·MicroPython·מסוף גופן_ערך 라이선스와 גופן_ערך מקור_ערך 해시도 동봉한다. קובץ יצר 스크립트는 물리 디스크에 기록하지 않는다.

예비 microSD에 בנה_תמונה לרשום_שיא 도구로 `.img`를 기록하거나 FAT32 부팅 파티션 최상위에 ZIP 내용을 푼다. בנה_תמונה 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 ערך_ברירת_מחדל EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD קובץ 구성·ליבה_ערך 체크섬 검사와 물리 לוח 부팅 검증은 별개다. MMU שימוש_ערך 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 부팅 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 עברית API שימוש_ערך

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/דוגמתקובץ.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int התחל_משתמש_תוכנית(int)`이다. משתמש C++는 FP/SIMD를 사용할 수 있다. ליבה_ערך C/Java AOT는 일반 레지스터만 사용하므로 חריגה תהליך_ערך_ערך 중 משתמש FP 상태를 건드리지 않는다. משתמש נקודת_כניסה_ערך 시 FP 상태를 초기화하고 ליבה_ערך 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int התחל_משתמש_תוכנית(int) {
    int קובץ = פתח_קובץ("인사.txt", קריאה_כתיבה | 없으면만들기 | 내용비우기, 0600);
    if (קובץ < 0) return 1;
    const char תוכן_ערך[] = "안녕하세요";
    int תוצאה = כתיבה_קובץ_נתונים(קובץ, תוכן_ערך, sizeof(תוכן_ערך) - 1);
    סגור_קובץ(קובץ);
    return תוצאה == sizeof(תוכן_ערך) - 1 ? 0 : 2;
}
```

[קובץ 예제](משתמש/דוגמתקובץ.cpp)와 [통신 예제](משתמש/통신예제.cpp)가 בפועל_נתונים 부팅 시험 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 קובץ תהליך_ערך_ערך 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 소켓 함수는 נוכחי_פריט 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 ליבה_ערך 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 הבא_פריט 도구를 사용하면 **새 QEMU를 부팅해 업로드한 בפועל_נתונים 바이트를 재확인한 הקודם_ערך 게스트에서 לבצע_פקודה**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 כלים/לבצע_קובץ.py build/jkoros-native-sdk/demo.elf
python3 כלים/לבצע_קובץ.py 예제/Hello.java "한글 ארגומנטים"
python3 כלים/לבצע_קובץ.py 예제/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 ליבה_ערך 묶음에 포함되어 이 קובץ 한도를 적용받지 않는다. **C++ 컴파일러는 ארח SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 ספריה, PT_TLS, PT_INTERP, PT_DYNAMIC, לבצע_פקודה·כתוב 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 מדד·למען לגזור·오류는 [משתמש ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `파일저장확정`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 הרשאה_ערך·dup/fcntl은 없다. 디렉터리와 עמית_ערך/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, לקבל_ערך_cef4d8ab 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. משתמש יציאה_תוכנית 시 열린 קובץ 서술자와 소켓을 회수한다.

## Java와 Python의 정확한 לגזור

עצמי `javac`는 버전 49 `.class`를 생성하며 JVM은 תמך_ערך 명령으로 구성된 버전 45–52 클래스를 실행한다. סטטי_ערך פונקציה_ערך·재귀·int/boolean/char/String·תנאי/סבב_ערך·מחרוזת_ערך 결합과 일부 קובץ 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/조합 자모 식별자를 처리한다. Unicode מזהה_ערך 전체 טבלת_בדיקת_מידע·Unicode מקור_עץ 이스케이프는 구현하지 않았다. 게스트 מקור_עץ 컴파일러는 일반 אובייקט_ערך·חריגה·Thread 구문을 아직 컴파일하지 못한다. ארח `javac --release 8`로 만든 תמך_ערך 부분집합 클래스는 עצמי JVM 0.4의 אובייקט_ערך·חריגה·Thread·UDP와 עברית API를 사용할 수 있다. Swing은 문서화한 עצמי API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [עצמי JVM 설명](자바실행환경.md)이 기준이다. 상세 שפה 범위는 [공유 Java כלים 설명](../../문서/자바개발환경.md)을 참고하되, 그 문서의 x86 מעטפת/מאגר_ערך/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 מקור_עץ**를 עצמי AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 פונקציה_ערך·כיתה_ערך·חריגה·리스트/מילון·Unicode·GC·가변 דיוק_ערך 정수를 제공한다. נוכחי_פריט 구성은 מספר_שלם 빌드로 `float`, `complex`, `math`가 없으며 CPython 전체 표준 ספריה, pip, subprocess, threading, 일반 socket과 ערך_ברירת_מחדל `open()` קובץ 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 אובייקט_ערך·모듈은 יציאה_תוכנית 시 회수되고 RAM 파일만 הבא_פריט 실행에 남는다.

`import jkoros`로 הבא_פריט 시스템 연결을 쓴다. 모두 SVC를 통해 עצמי Java 커널에 접근한다.

| פונקציה_ערך | פעולה |
|---|---|
| `stdin(limit)` | נוכחי_פריט 표준 입력에서 최대 limit바이트(0…16384)를 bytes로 읽음; EOF는 빈 bytes, UART נתונים 없음은 OSError(11) |
| `read(name)` | עמית_ערך/절대 RAM 경로의 קובץ 전체를 bytes로 읽음 |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 מאגר_ערך, 쓴 בית_ערך 수 החזר_תוצאה |
| `remove(name)` | RAM קובץ 삭제 |
| `rect(x, y, w, h, color)` | 선택한 בפועל_נתונים 화면 גודל 안의 מלבן ציור_ערך; 기존 보드의 RGB32 ערך |
| `ticks_ms()` | 부팅 후 밀리초, 32비트 מחזור_ערך |
| `udp_open(port)` | 127.0.0.1의 UDP 소켓 פתח/לאגד_משתתף; 0은 자동 חומרה_הסב |
| `udp_send(fd, port, data)` | 루프백 יעד_ערך 포트에 str/bytes 버퍼 העבר_ערך |
| `udp_recv(fd)` | `(bytes, 보낸포트)` החזר_תוצאה; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | 소켓 סגירה |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```

이식 קוד_ערך: [python/](파이썬연결/), [משתמש Java חיבור](משתמש/자바연결.c). 공식 [MicroPython 이식 안내](https://docs.micropython.org/en/latest/develop/porting.html)를 참고했다. מקור_עץ URL·קוד_Hash_קובץ·라이선스는 [vendor 안내](vendor/README.md)에 기록했다.

| חיצוני_ערך 네트워크 | 추가한 GENET/PHY·DHCP 드라이버의 בפועל_נתונים לוח 송수신 לאמת, DNS·Wi-Fi |
| GUI הרחבה_ערך | USB HID, 게스트 입력기·문자 조판, Swing חלון גודל 조절·클리핑 הרחבה_ערך, 전체 AWT/Swing 이식 |

이 표는 남은 작업이며 구현 완료 목록이 아니다. QEMU Pi4 모델에는 GENET Ethernet과 PCIe root port가 없어 חיצוני_ערך 네트워크 드라이버는 실물 검증도 필요하다. [QEMU התקן_ערך_e13f0cd9 지원표](https://www.qemu.org/docs/master/system/arm/raspi.html)

## עברית C סוג_נתונים·Python שגיאה·חבילה התקן_ערך

C 네트워크 API는 `struct 인터넷통신주소`, enum 상수와 בפועל_נתונים עברית 함수로
구현한다. מאקרו_ערך 별칭을 사용하지 않으며 이전 pk_* ABI도 유지한다.
Python 예제는 `שגיאת_מערכת`, `שגיאה.מדד`, `שגיאה.설명`을 사용한다.

`python3 כלים/לבצע_פקודה.py --desktop --network --pip`로 시작하면 게스트에서
`pip install micropython-bisect==3.3.3`을 사용할 수 있다. 현재는 ארח 중계를
이용하는 제한형 MicroPython מקור_עץ 설치기이며 CPython pip·자동 의존성 해결·C 확장은
미지원이다. 설치한 `/lib` 자료는 RAM이다. [사용법과 제한](파이썬꾸러미.md).

## 화면 גודל קטע_נבחר_ערך

`python3 כלים/לבצע_פקודה.py --desktop --network --resolution 1920x1080`으로 Full HD 화면을 사용한다. 기본값은 640×480이며 1280×720도 가능하다. מסוף להעביר_ערך, Swing 가운데 לקשר_ניווט, Java·C·Python 그리기도 בפועל_נתונים 크기를 따른다. SD 영상은 `make image RESOLUTION=1920x1080`으로 만든다. [הגדרות·עברית API·לאמת 안내](רזולוציית_מסך.md).

## עברית 직접 API와 화면 רענן

`example/java`는 `실행할일`, `동작받이`, `המלצה_הודעה`, `לחצן`, `אירוע_תור`,
`משימתרקע`, `הפעלה()`을 사용할 수 있다. עברית GUI/가닥을 עצמי JVM에 직접
연결했으며, 표준 Swing/Thread를 감싸지 않는다. מחרוזת_ערך 등 javac의 표준
계약과 전체 מקור_עץ 검토 범위는 [명명 안내](명명/안내.md), 사용법과 호환성 변경은
[עברית Java API](한국어자바/안내.md)를 본다.

מסוף להעביר_ערך·גודל 변경은 바뀐 영역만 합성하고 달라진 화소만 표시한다.
[화면 רענן 설명](자바실행환경.md#מסוף-부분-רענן),
[부분 רענן 검사](build/verification/redraw/report.json)를 참고한다.
