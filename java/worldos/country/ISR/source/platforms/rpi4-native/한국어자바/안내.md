# עברית Java 통신·קלט_פלט·חריגה API

패키지는 `עברית.עצמי`다. ארח `javac --release 8`로 컴파일한 class를
עצמי ARM64 커널의 JVM에서 실행한다. 통신·קובץ·חריגה API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 שרשור_ערך API는 עצמי JVM 전용이다.
기존 표준 Java ספריה 전체의 עברית 번역판은 아니다.

```java
import עברית.עצמי.*;

public class רשת {
    public static void main(String[] ארגומנטים) throws קלט_פלט_חריגה {
        קשר חיבור = קשר.פתח("10.0.2.2", 9000);
        try {
            חיבור.פסק_זמן(700);
            חיבור.פלטטקסט().כתוב(문자.לקדד("안녕하세요\n"));
            זרימת_קלט קלט_ערך = חיבור.קלט_ערך();
            פלטטקסט.수쓰기(קלט_ערך.קרא());
        } catch (רק_רגע_פסק_זמן_חריגה שגיאה) {
            פלטטקסט.כתיבה_קו(שגיאה.설명());
        } finally {
            חיבור.סגירה();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
משתמש 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 מחרוזת_ערך 리터럴에 사용하는 표준 클래스다. עצמי 실행기는 `public static void הפעלה()`도 진입점으로 받는다.

## 통신과 זרם_ערך

| כיתה_ערך | עברית 호출 |
|---|---|
| קשר | `פתח(למען, מספר_יציאה)`, `קלט_ערך()`, `פלטטקסט()`, `פסק_זמן(밀리초)`, `מספר_יציאה()`, `מקומי_מספר_יציאה()`, `연결됨()`, `מערכות_מידע_נסגר()`, `סגירה()` |
| לקבל_הסב | `פתח(מספר_יציאה)`, `לקבל()`, `מספר_יציאה()`, `פסק_זמן(밀리초)`, `מערכות_מידע_נסגר()`, `סגירה()` |
| זרימת_קלט | `קרא()`, `קרא(byte[])`, `קרא(byte[], הפעלה, 길이)`, `סגירה()` |
| זרימת_פלט | `כתוב(int)`, `כתוב(byte[])`, `כתוב(byte[], הפעלה, 길이)`, `내보내기()`, `סגירה()` |
| יחידת_נתונים_ערוץ | `פתח(מספר_יציאה)`, `שלח(למען, מספר_יציאה, טקסט)`, `לקבל()`, `פסק_זמן(밀리초)`, `מספר_יציאה()`, `מערכות_מידע_נסגר()`, `סגירה()` |
| קשר_הובלה | `פתח(...)`, `수신열기(...)`는 위 עברית 객체를 החזר_תוצאה |
| 검사 | `참인지(תנאי, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`קרא()`의 קובץ 끝은 -1, מערך_ערך 읽기의 반환값은 בפועל_נתונים 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. מספר_יציאה 0은 빈 번호를 자동 배정한다.
UDP 전문은 נוכחי_פריט עצמי 커널에서 512바이트까지 받으며, 주소는 ספרה_ערך IPv4를 사용한다.
`localhost` 루프백 외의 שם 풀이(DNS)는 עצמי 커널에 아직 없다.

기존 `קשר_הובלה.חיבור/להאזין_משתתף/לקבל`, `통신.פתח/שלח/לקבל`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `קשר`, `לקבל_הסב`, `יחידת_נתונים_ערוץ`를 쓴다.

## עברית חריגה

모든 아래 클래스는 ערך_ברירת_מחדל 생성자, `새예외("설명")` 형태의 מחרוזת_ערך 생성자와
`설명()`을 제공한다. בפועל_נתונים יצר 문법은 `new רק_רגע_פסק_זמן_חריגה("מצב_המתנה 끝")`이다.

| עברית חריגה | 상위 כיתה_ערך / 용도 |
|---|---|
| חריגה | `java.lang.Exception`, 직접 던지는 일반 검사 חריגה |
| 실행예외 | `java.lang.RuntimeException` |
| קלט_פלט_חריגה | `java.io.IOException`, עברית קובץ·통신 API의 검사 חריגה |
| רק_רגע_פסק_זמן_חריגה | `קלט_פלט_חריגה`, 통신 פסק_זמן 초과 |
| למען_חפושׂ_חריגה | `קלט_פלט_חריגה`, למען ודא_אמת כשל_ערך |
| 파일없음예외 | `קלט_פלט_חריגה`, קובץ פתח כשל_ערך |
| 통신예외 | `קלט_פלט_חריגה`, 표준 SocketException המר_ערך |
| לא_חוקי_ארגומנט_חריגה | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `לא_חוקי_ארגומנט_חריגה` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| הפניה_חסרת_אובייקט_חריגה | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| מצב_חריגה | `java.lang.IllegalStateException` |
| כתב_לשדר_חריגה | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| מערך_מאגר_כשל | `java.lang.ArrayStoreException` |
| שרשור_מצב_חריגה | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 רק_רגע_ערך 중단 |

`חריגה`와 `실행예외`는 모든 עברית 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, קובץ·통신 전체를 잡으려면 `catch (קלט_פלט_חריגה שגיאה)`를 쓴다.
עברית API가 표준 קלט_פלט 오류를 עברית 예외로 변환한다.
기존 עברית 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`רק_רגע_פסק_זמן_חריגה`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
חריגה 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
נוכחי_פריט עצמי JVM에 이 20종을 추가했다. 임의의 משתמש Throwable 하위 כיתה_ערך 전체를
지원하도록 확장했다는 뜻은 아니다.

## בנה_מקור·לבצע_פקודה

```sh
cd /home/user/jkoros/platforms/rpi4-native
make בנייה
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 כלים/לבצע_קובץ.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 משתמש JVM ELF 안에 탑재된다. `.jar`는 ארח javac의
כיתה_ערך 경로로 사용한다. מקור_עץ 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 עברית 예외의 `throws` 선언과 그 import를 인식한다.
עצמי JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·אובייקט_ערך·소켓 예제 전체의 מקור_עץ 컴파일은 ארח javac를 사용한다.
`/example/java/דוגמתקובץ.java`는 게스트 javac로도 컴파일할 수 있다.

בפועל_נתונים TCP/UDP 예제는 [דוגמתרשת.java](../../../example/java/דוגמתרשת.java),
לבצע_פקודה 절차는 [example 안내](../../../example/README.md),
מקור_עץ 명명 원칙은 [명명 안내](../명명/안내.md)에 있다.

## Swing חלון 예제

`/example/java/דוגמתחלון.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` הבא_פריט `java דוגמתחלון`로 연다. שם קלט_ערך, 인사하기 버튼,
인사말과 לחץ_ערך 횟수 רענן, X 닫기를 지원한다.

| 기능 | עברית 직접 API |
|---|---|
| Runnable / run | `실행할일.בצע()` |
| ActionListener / actionPerformed | `동작받이.לקבל_המלצה(המלצה_הודעה הודעה)` |
| ActionEvent | `המלצה_הודעה.פקודה_טקסט()`, `מקור_אירוע()`, `מדד()` |
| JFrame | `חלון(חלון_כותר, 폭, גובה_ערך)`, `הוסף_רכיב(화면구성요소)`, `הופעה_חלון()`, `סגירה()`, `보이는가()` |
| JButton | `לחצן(טקסט, 가로, אנכי_עמדה, 폭, גובה_ערך, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `תווית(...)`, `שדה_טקסט(...)` |
| 공통 화면 רכיב_ערך | `화면구성요소.글읽기()`, `כתיבה_טקסט(טקסט)`, `자리정하기(가로, אנכי_עמדה, 폭, גובה_ערך)` |
| SwingUtilities.invokeLater | `אירוע_תור.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `משימתרקע(실행할일)`, `התחל_משימה()`, `기다리기()`, `살아있는가()`, `רווח_משימה()` |
| 명령행 | `הפעלה()`, `실행인수.개수()`, `실행인수.טקסט(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
עצמי JVM의 `한국어화면호출`, `תהליך_שרשור`가 עברית כיתה_ערך·פעולת_שירות_ערך·서술자를
해석해 화면 요소와 לבצע_פקודה 가닥을 직접 만든다. פעולה 알림도 עצמי 객체이며
콜백으로 `בצע`와 `לקבל_המלצה`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 לבצע_פקודה 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 עצמי JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 ארח JVM에서 무동작 객체가 생기지 않도록 하는 דחייה_ערך 경로다.
עצמי JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. ארח javac로 컴파일한 הקודם_ערך עצמי JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import עברית.עצמי.*;
public class 가닥예제 implements 실행할일 {
    public void בצע() { פלטטקסט.כתיבה_קו("עברית 작업 לבצע_פקודה"); }
    public static void הפעלה() throws 대기중단예외 {
        משימתרקע שרשור_ערך = 작업.הפעלה(new 가닥예제());
        작업.기다리기(שרשור_ערך);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
מערך_ערך ארגומנטים 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
עצמי 실행기는 ארגומנטים 없는 `הפעלה()`을 우선한다.
기존 עברית 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.הפעלה(Runnable)`을 사용하던 코드는 새 עברית 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API תמך_ערך 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 כיתה_ערך·פעולת_שירות_ערך 이름과 서술자가 남는다.
עברית שם 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·פעולת_שירות_ערך 재정의, native חיבור, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS מזהה_ערך](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS פעולת_שירות_ערך הפנה](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
