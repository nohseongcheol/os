# JIsrOS ארכיטקטורה

아래는 אובייקט_ערך 기반 관리 ליבה_ערך 전체의 יעד_אובייקט 구조다. נוכחי_פריט בפועל_נתונים 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 מערכת_הפעלה 안내](../os/안내.md)에 구현 범위를 명시한다. 아래의 GC·הקשר_ערך מתג_מצב·מערכת_קבצים 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 שכבה_ערך
  ↓
Java AOT 실행기와 אובייקט_ערך·מערך_ערך·GC 런타임
  ↓
חומרה_ערך_9591fb0a 경계
  ↓
Java 관리 ליבה_ערך
  ├─ זיכרון_אזור/쪽관리/COW
  ├─ תהליך_ערך/배정/wait
  ├─ מערכת_קבצים/ELF/POSIX
  └─ קלט_ערך/התקן_אחסון/רשת_רמז
```

OpenJDK 자체는 이미 운영체제가 제공하는 קובץ, 스레드, 가상 기억공간을 전제로 한다. 따라서 ליבה_ערך 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, הקשר_ערך 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
