## 기존 אובייקט_ערך 기반 관리 ליבה_ערך 전체를 부팅하기 위해 남은 חיבור

הבא_פריט 항목은 Java 문법만으로 실행할 수 없는 CPU/התקן_ערך_e13f0cd9 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot נקודת_כניסה_ערך, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 הקשר_ערך מאגר_ערך
- בפועל_נתונים PIC/PIT/PS2/ATA/PCI חומרה_הסב 및 AMD PCnet DMA לולאה_ערך
- Java אובייקט_ערך·מערך_ערך לקשר_ניווט, חריגה, סטטי_ערך אתחול, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT במה_ערך
- FAT 디스크 구역을 בפועל_נתונים ATA 장치와 연결하는 קלט_פלט 접착 שכבה_ערך

위 관리 계층은 engos 기능의 Java 관리 구현과 ארח 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot נקודת_כניסה_ערך, סטטי_ערך אתחול·מספר_שלם מערך_ערך, VGA/직렬/PS2, מפרשפקודות, משתמש ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 ארח 루프백 패킷 왕복을 검증했다. 위 표의 אובייקט_ערך 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
