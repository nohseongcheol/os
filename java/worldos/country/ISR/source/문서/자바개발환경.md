# jkoros 안에서 Java בנה_מקור·לבצע_פקודה

이 문서의 부팅·מעטפת·מאגר_ערך 명령은 **x86 גירסה_ערך** 기준이다. 공유 Java מהדר/JVM은 [עצמי ARM64 Pi4 גירסה_ערך](../platforms/rpi4-native/README.md)에도 연결되어 있다. ARM64에서는 UTF-8 UART קלט_ערך·한글 שם_קובץ_טקסט, `edit`의 단독 `.` מאגר_ערך, 16개 RAM קובץ, 약 2초 לבצע_פקודה 제한을 사용한다.

`javac FILE.java`와 `java CLASS [ARGS]`를 네이티브 jkoros 셸에서 실행한다. 컴파일러와 JVM은 각각 독립 ELF로 적재되어 ring 3에서 동작한다. 소스를 게스트에서 읽어 בפועל_נתונים JVM `.class` 파일을 만들고, 그 파일의 바이트코드를 게스트 JVM이 해석한다. ארח בנה_מקור 서버나 Linux 게스트는 사용하지 않는다.

**נוכחי_פריט 구현은 עצמי 제한형 מהדר·JVM이다. OpenJDK/JDK 전체를 이식하거나 설치한 것이 아니며 Java SE 호환 환경도 아니다.** 표준 라이브러리는 아래의 일부 호출을 구현한 것이다. `java -version`과 `javac -version`에도 이 범위를 표시한다. 일반 JAR, Maven/Gradle, 임의의 Java תוכנית_f5044b9b 실행은 아직 지원하지 않는다.

## 바로 לבצע_פקודה

호스트에서:

```sh
cd /home/user/jkoros
make iso
make run
```

게스트에서:

```text
jkoros> javac -version
jkoros> java -version
jkoros> ls
jkoros> cat Hello.java
jkoros> javac Hello.java
Compiled: Hello.class (JVM class version 49)
Exit: 0
jkoros> java Hello
Hello from jkoros JVM!
55
Exit: 0
```

ISO는 `os/build/kernel.iso`다. 기존 VirtualBox 실행기도 같은 ISO를 사용한다. לבצע_פקודה 중이거나 저장된 VM에는 새 ISO가 자동 반영되지 않는다. 새 부팅 절차는 [VirtualBox לבצע_פקודה 안내](가상상자실행.md)를 따른다. 이 변경의 Java 자동 시험은 QEMU에서 수행했다.

## 직접 작성

`edit`는 קובץ 전체를 새 내용으로 작성한다. 기존 내용의 שורה ערוך_ערך 기능은 아니다. `.save`로 저장하고 `.cancel`로 취소한다.

```text
jkoros> edit Demo.java
...> public class Demo {
...>  public static int square(int n) { return n * n; }
...>  public static void main(String[] args) {
...>   int n = Integer.parseInt(args[0]);
...>   System.out.println("square=" + square(n));
...>  }
...> }
...> .save
jkoros> javac Demo.java
jkoros> java Demo 12
square=144
Exit: 0
```

- `ls`: 파일과 בית_ערך 수 הופעה_ערך.
- `cat FILE`: קובץ תוכן_ערך הופעה_ערך. 텍스트 소스에 사용한다.
- `rm FILE`: זיכרון_נתונים קובץ 삭제.
- `edit FILE`: 전체 내용을 새로 קלט_ערך. 빈 파일도 저장할 수 있다.
- 구문·כתב_ערך 검사 כשל_ערך 시 기존 `.class`는 유지된다. 소스를 고친 הקודם_ערך 컴파일이 실패했다면 이전 לבצע_פקודה 파일이 남아 있으므로 בנה_מקור 성공 여부를 확인한다.

파일은 RAM에서 동작한다. 전용 מאגר_ערך 매체가 없거나 `sync`하지 않은 내용은 재부팅하면 사라진다. `make -C os run-store`로 연결한 매체에는 `sync`로 מקור_עץ·כיתה_ערך·נתונים 파일을 보존할 수 있다. 최대 8개, 파일마다 16KiB, קובץ 이름은 ASCII 1~63자다. מקור_עץ 이름은 `.class` 확장자 למען_אזור 때문에 최대 62자다. ערוך_ערך 입력은 ASCII이고 한 שורה 최대 128자다. שורה 또는 קובץ 한도를 넘긴 편집은 `.save`에서 거부하여 기존 파일을 보존한다. ליבה_ערך/מהדר/JVM 구현의 Java 식별자는 한국어이며, נוכחי_פריט 게스트 קלט_ערך 제한 때문에 משתמש 예제 이름은 ASCII로 작성한다.

## חיצוני_ערך קובץ 적재

호스트에서 만든 소스나 תמך_ערך לגזור 안의 `.class`를 부팅 이미지에 포함할 수 있다. `JAVA_FILES`는 `게스트이름=호스트경로` 목록이다. 아래의 경로는 예시이며 בפועל_נתונים 파일의 절대 경로로 바꾼다. 공백 없는 경로를 사용한다.

```sh
# ארח JDK로 컴파일한 클래스도 사용할 수 있다.
javac --release 8 /tmp/Demo.java
make -C /home/user/jkoros iso \
  JAVA_FILES='Demo.java=/tmp/Demo.java Demo.class=/tmp/Demo.class'
make -C /home/user/jkoros run \
  JAVA_FILES='Demo.java=/tmp/Demo.java Demo.class=/tmp/Demo.class'
```

새 부팅 후 `java Demo 12`를 실행한다. 소스만 넣었으면 게스트에서 `javac Demo.java`부터 실행한다. `JAVA_FILES`를 생략한 הבא_פריט 빌드에서는 צירוף_ערך_b73accca 파일을 포함하지 않는다. קובץ תוכן_ערך 변경과 ערך_רשימה 제거도 הבא_פריט 빌드에 반영된다. 원본 ארח 파일에는 쓰지 않는다. ערך_ברירת_מחדל `Hello.java`까지 합해 8개이며, 같은 이름을 명시하면 ערך_ברירת_מחדל 예제를 대체한다. 새 `.class`를 저장할 빈 슬롯도 남겨 둔다.

`--release 8`은 כיתה_ערך קובץ 버전을 맞추는 옵션이다. 사용하는 문법·바이트코드·라이브러리도 아래 תמך_ערך לגזור 안에 있어야 한다.

## תמך_ערך לגזור

| 기능 | 게스트 javac | 게스트 JVM |
| --- | --- | --- |
| כיתה_ערך | 패키지 없는 단일 כיתה_ערך, סטטי_ערך פונקציה_ערך, 재귀, ארגומנטים/החזר_תוצאה | 실행마다 단일 כיתה_ערך 적재, public static main(String[]) |
| ערך_ברירת_מחדל ערך | int, boolean, char, String, main의 String[] ארגומנטים | מספר_שלם·הפנה אופרנד_רמז, String, int[], String[], 내부 StringBuilder |
| דוח_ערך | 초기값 있는 מקומי_היקף הצהרה, מטלה_ערך, `+=`, `-=`, `*=`, `/=`, `%=`, 후위 ++/--, 블록, if/else, while, for, return | 해당 מספר_שלם·הפנה 바이트코드와 תנאי ענף |
| ביטוי_ערך | 십진 מספר_שלם, UTF-8 소스의 מחרוזת_ערך/문자, + - * / %, 비교, ==/!=, !/&&/\|\|, מחרוזת_ערך 결합 | מספר_שלם ניתוח_ערך·ביט_ערך ניתוח_ערך·כתב_ערך המר_ערך, 단락 평가, מערך_ערך גישה_ערך_68aed533 |
| קובץ | FileInputStream(String), FileOutputStream(String[, boolean]), read()/write(int)/close() | בפועל_נתונים ליבה_ערך 파일서술자와 חיבור, יצר·נקה_תוכן·이어쓰기·EOF |
| פלטטקסט | System.out.print/println: int/boolean/char/String, println() | 동일 |
| מחרוזת_ערך/ארגומנטים | String.length(), args.length, args[index], Integer.parseInt | 추가로 String.charAt(), מחרוזת_ערך 상수의 modified UTF-8 해독 |

선언은 지원하는 문법만 허용한다. 여러 변수를 한 선언에 나열하기, 초기값 없는 מקומי_היקף הצהרה, 오버로드, 임의 כתב_ערך המר_ערך, מערך_ערך יצר קודמקור, 8/16진 리터럴, Unicode מקור_עץ 이스케이프 등은 미지원이다. `char`는 문자 리터럴로 초기화하며 일반 JDK의 모든 קבוע_ערך 축소 변환을 구현하지 않는다. חיצוני_ערך `.class`의 `int[]` יצר/קרא/쓰기는 지원하므로 ארח `javac --release 8`로 만든 מערך_ערך 예제는 실행할 수 있다.

אובייקט_ערך ערך_שדה·일반 אובייקט_ערך יצר·상속·인터페이스·여러 כיתה_ערך חיבור, long/float/double, חריגה תהליך_ערך_ערך, 스레드·모니터, 리플렉션, JNI, JIT, GC, 위 표에 없는 `java.io`와 `java.nio`/`java.net` 일반 API, 컬렉션, JAR와 클래스패스는 미지원이다. 런타임 오류는 Java חריגה 객체를 던지지 않고 진단 후 נוכחי_פריט 프로그램을 종료한다. 객체와 מחרוזת_ערך מאגר_ערך 공간은 לבצע_פקודה יציאה_תוכנית 시 משתמש אזור_ערך_0e9a97ab 전체와 함께 회수한다. 지속 לבצע_פקודה 중 GC는 없다.

## לבצע_פקודה 한도와 שגיאה

| משאב_ערך | 한도 |
| --- | --- |
| מקור_עץ/כיתה_ערך קובץ | 각각 16KiB |
| מהדר | אסימון_ערך 2,047개, יצר קוד_ערך 4KiB, קבוע_ערך 풀 4KiB |
| פונקציה_ערך/ארגומנטים | 클래스당 32함수, 함수당 16인수 |
| JVM קבוע_ערך | 511개 |
| JVM פונקציה_ערך קוד_ערך | 함수당 8KiB |
| JVM 호출/אופרנד_רמז/מקומי_היקף משתנה_ערך_541034c4 | 32프레임, 프레임당 אופרנד_רמז 128칸·מקומי_היקף 128칸 |
| JVM אובייקט_ערך מאגר_ערך למען_אזור | 8,192개 32비트 חריץ_ערך, 헤더 포함 약 32KiB |
| לבצע_פקודה | 최대 500,000 פקודה, 기존 커널의 약 3초 CPU לבצע_פקודה 상한도 적용 |

게스트 컴파일러는 버전 49.0 `.class`를 생성하며 JVM은 45.0~52.0 중 תמך_ערך 명령으로 구성된 파일을 읽는다. 스택맵을 이용한 완전한 JVM מילון 검증기를 구현한 것은 아니다. קובץ/ערך_תכונה 길이, קבוע_ערך הפנה, פקודה·ענף 경계를 검사하고, לבצע_פקודה 중 אופרנד_רמז לעצב_ערך·מקומי_היקף אתחול·מערך_ערך כתב_תחתי_ערך·אובייקט_ערך 참조를 검사한다. משתמש 코드의 페이지·חומרה_הסב 접근은 기존 ring 3 경계로 보호한다.

일반 성공은 `Exit: 0`, בנה_מקור·JVM 오류는 `Exit: 1`, פקודה ארגומנטים 오류는 `Exit: 2`다. CPU ערך_זמן 상한은 기존 `Exit: 124`이며, משתמש ELF 자체의 CPU/런타임 오류는 기존 יציאה_תוכנית 코드를 따른다. כשל_ערך 후 셸에서 다른 프로그램을 계속 실행할 수 있다.

## 구현 위치와 시험

- `os/משתמש/자바/자바컴파일러.java`: 게스트 어휘·구문·כתב_ערך 검사, קבוע_ערך 풀 및 바이트코드 יצר.
- `os/משתמש/자바/자바가상기계.java`: כיתה_ערך 적재, אופרנד_רמז·프레임·אובייקט_ערך מאגר_ערך, פקודה 해석과 제한된 표준 호출.
- `os/קודמקור/זיכרון_מערכת_קבצים.java`: זיכרון_נתונים מערכת_קבצים, ערוך_ערך, 부팅 קובץ 적재.
- `os/קודמקור/체계호출.java`, `compiler/התחל_משתמש_תוכנית.s`: קובץ/문자 פלטטקסט API와 משתמש מצביע 검사.
- `os/כלים/자바파일묶기.py`: ארח קלט_ערך קובץ לאמת·부팅 לקבץ_ערך יצר.

```sh
make test-java
make test
```

`os/시험/자바시험.py`는 ELF/ISO 부팅, 게스트 בנה_מקור·לבצע_פקודה, משתמש קלט_ערך, 재귀·반복문·מספר_שלם 극값·מחרוזת_ערך 결합·단락 평가, 재실행, מקור_עץ שגיאה 후 기존 כיתה_ערך 보존, מערך_ערך/수 해독 שגיאה, 무한 סבב_ערך 제한, ערוך_ערך 넘침과 קובץ 부족을 검사한다. 게스트 יצר 클래스의 바이트를 QEMU 메모리에서 꺼내 OpenJDK `java -Xverify:all`로 실행하고 결과를 대조한다. 반대 방향으로 ארח OpenJDK의 כיתה_ערך, מספר_שלם 배열과 한글 상수를 게스트에 적재하며, 손상된 קובץ סמן_ערך·버전·קבוע_ערך 수·ענף·스택을 거부하는지도 검사한다. 기록은 `os/build/자바시험.json`에 남는다. 디스크 없는 별도 시험 VM만 생성하고 종료한다.

구현 형식의 참고 נתונים: Oracle [JVM כיתה_ערך קובץ מפרט](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-4.html), [JVM פקודה מפרט](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-6.html).

## Java קובץ קלט_פלט

[FileDemo.java](../posix-kor/자바예제/FileDemo.java)는 일반 Java 표준 כיתה_ערך 이름을 사용한다. 소스를 `edit FileDemo.java`로 입력하거나 `JAVA_FILES`로 부팅 이미지에 넣은 הקודם_ערך `javac FileDemo.java`, `java FileDemo`를 실행한다. 결과는 `65`, `255`, `66`, `-1`, `JAVA FILE IO PASS`다. `write(int)`는 하위 8비트를 쓰고 `read()`는 0~255 또는 EOF -1을 반환한다. ערך_ברירת_מחדל פלטטקסט 생성자는 내용을 비우고, boolean 인수가 true이면 이어쓴다.

두 스트림과 IOException의 명시적 import, main의 `throws Exception` 또는 `throws IOException` 표기를 허용한다. חריגה אובייקט_ערך·try/catch·try-with-resources는 지원하지 않으며 קובץ 오류를 진단하고 프로그램을 종료한다. מערך_ערך קלט_פלט, InputStream/OutputStream으로의 다형성, Reader/Writer, getFD, 일반 קובץ 메타데이터 API는 아직 없다. close는 열린 서술자를 닫고, 재부팅 보존에는 מעטפת `sync`가 필요하다. 예제의 קובץ 이름은 נוכחי_פריט 셸과 파일체계에 맞춰 ASCII로 쓴다.

`os/시험/자바파일시험.py`는 בפועל_נתונים 게스트 בנה_מקור 결과를 OpenJDK `-Xverify:all`로 נסה_שנית_ערך 실행해 קובץ 바이트와 출력을 대조한다. 범위와 מאגר_ערך מדיה_ערך 사용법은 [posix-kor 안내](../posix-kor/안내.md)를 참고한다. 참고한 표준 API는 Oracle [FileOutputStream](https://docs.oracle.com/javase/8/docs/api/java/io/FileOutputStream.html)이다.
