# 전체 תמך_ערך 요청의 נוכחי_פריט מצב_ערך

בקשה 전체는 아직 완료되지 않았다. נוכחי_פריט ISO는 עצמי Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 בפועל_נתונים C POSIX 일부 기능, עברית API/קודמקור שם, IDE קובץ 보존, 게스트 Java קובץ 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/안내.md)를 기준으로 판단한다.

| בקשה 분야 | נוכחי_פריט לבצע_פקודה 가능한 לגזור | 전체 지원에 필요한 작업 |
|---|---|---|
| Java בנה_מקור·לבצע_פקודה | 게스트 제한형 javac/JVM, סטטי_ערך 단일 클래스와 일부 표준 אובייקט_ערך | 일반 אובייקט_ערך·כיתה_ערך חיבור·חריגה·GC·스레드, 완전한 javac와 표준 כיתה_ערך ספריה |
| קובץ | POSIX 서술자, Java 단일 בית_ערך קובץ זרם_ערך, 전용 מדיה_ערך 보존 | 일반 java.io/nio, 디렉터리·הרשאה_ערך·נעל_ערך·일반 מערכת_קבצים·הרחבה_ערך 가능한 קיבולת_ערך |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP ארח 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, צירוף_ערך_b73accca NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·קלט_ערך אירוע·גופן_ערך·חלון מערכת_הפעלה_ערך, AWT 네이티브 연결과 Swing לבצע_פקודה 기반 |
| POSIX | 문서화한 קובץ·단말·UDP 부분 | תהליך_ערך·exec/fork·스레드·시그널·ערך_זמן·mmap·poll·파이프 등과 적합성 לאמת |
| 언어별 שם | עברית 46개 대응 ערך_ערך, בפועל_נתונים C/Java/קובץ שם 적용 | יעד שפה 확정, 언어별 용례·역사 근거와 해당 קודמקור·도구의 לאמת |

עצמי 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 לבצע_פקודה 환경을 추가하는 방식은 별도의 ליבה_ערך·루트 מערכת_קבצים·OpenJDK·그래픽 שרת_ערך·영구 מאגר_ערך 구성을 가진 לבצע_פקודה 경로가 된다. 후자는 기존 עצמי 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

לבצע_פקודה 기반과 צירוף_ערך_b73accca יעד 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. נוכחי_פריט 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
