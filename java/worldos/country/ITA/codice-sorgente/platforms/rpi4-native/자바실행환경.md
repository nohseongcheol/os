# nativo ARM64 JVM 0.4와 Italiano Catalogo

Italiano comunicazione·eccezione 사용법은 [Italiano Java API](한국어자바/README_eb81d7d9.md), FUNZIONE_VALORE·variabile_VALORE·file 이름의 변경과 어원 근거는 [명명 README_eb81d7d9](명명/README_eb81d7d9.md)를 참고한다.

JAR Esegui_comando, esterno_VALORE IPv4 TCP/UDP, 별도 statico_VALORE 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 oggetto_VALORE·Thread·Swing은 JVM 경로의 기능이며 AOT Supporto_VALORE 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 Esegui_comando**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK Corso_VALORE Catalogo 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 Corso_VALORE·statico_VALORE metodo_VALORE 중심이던 실행기를 oggetto_VALORE·Catalogo Esegui_comando 기반으로 넓힌 것이다.

## 실행과 compilare_fonte

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# nativo kernel_VALORE 안에서 fonte_albero compilare_fonte → class Esegui_comando, Italiano API 호출
python3 strumenti/Esegui_File.py prove/자바/한글소스.java

# oggetto_VALORE·eccezione 등은 host JDK로 Java 8 class를 만든 후 nativo 커널에서 Esegui_comando
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java prove/자바/한글시험.java
python3 strumenti/Esegui_File.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 trasferire_VALORE
javac --release 8 -encoding UTF-8 -d build/my-java prove/자바/객체시험.java
python3 strumenti/Esegui_File.py build/my-java/객체시험.class \
  --include build/my-java/sfondo_VALORE.class --include build/my-java/ramo_VALORE.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.Corso_VALORE.class`라는 RAM file 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.Corso_VALORE`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.Corso_VALORE`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar file.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 Italiano 클래스만 찾는다. distribuzione_VALORE Italiano Catalogo JAR는 host javac의 classpath로 사용하며, 같은 클래스가 spazio_utente JVM ELF에도 Lettura 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 statico_VALORE metodo_VALORE, int/boolean/char/String, condizione·sprint_VALORE, stringa_VALORE 결합, 일부 file 스트림 등의 **nativo 부분집합 compilatore**다. oggetto_VALORE dichiarazione·상속·try/catch·Thread usare_VALORE 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 nativo JVM에서 실행한다. Italiano API 중 uscitaTesto·문자 스칼라 FUNZIONE_VALORE·file Lettura/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class messaggio_di_saluto_ae353e94 {
    public static void main(String[] argomenti) throws Exception {
        Italiano.nativo.uscitaTesto.scrivere_riga("안녕하세요😀");
        Italiano.nativo.uscitaTesto.scrivere_numero(Italiano.nativo.문자.punto_di_codice_CONTA_NUMERI("한글😀"));
        Italiano.nativo.file.Scrittura("messaggio_di_saluto_ae353e94.txt", "한글 file😀");
        Italiano.nativo.uscitaTesto.scrivere_riga(Italiano.nativo.file.Lettura("messaggio_di_saluto_ae353e94.txt"));
    }
}
```

## Italiano API

독립 패키지 **`Italiano.nativo`**를 사용한다. Linux판 `Italiano.자바`가 요구하는 NIO/Swing/HTTP API를 nativo 커널에서 실행할 numero 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 Corso_VALORE Nome·metodo_VALORE·argomenti·valore_del_campo·file 이름에 한국어를 사용한다. 표준 Java Corso_VALORE 이름은 호환성을 위해 보존한다.

| Corso_VALORE | 공개 기능 | 이름의 의미 |
|---|---|---|
| uscitaTesto | Scrittura, scrivere_riga, scrivere_numero | uscitaTesto(出力): 내용을 바깥으로 내보냄 |
| 문자 | durata_VALORE, 같음, incollare_SMS, tagliare_VALORE, analizzare_intero/scrivere_intero_VALORE, punto_di_codice_CONTA_NUMERI, codificare/decifrare_dati | 문자(文字), Codifica_VALORE(符號): 글의 단위와 그 값을 바이트로 나타내는 riga_VALORE_c689d407 |
| file | Lettura/Scrittura(String Nome), 바이트읽기/scrivere_byte_VALORE | 널리 쓰는 spazio_utente 용어를 보존; RAM 자료의 Nome |
| voce_elenco | 더하기, Lettura, RIMPIAZZA_VALORE, cancellare_voce, Dimensione, reparto_IT_vuota_VALORE, liquidare_Sommario | voce_elenco(目錄): 순서가 있는 voce_VALORE 모음 |
| dizionario | 넣기, TROVA_voce, 있는가, cancellare_voce, Dimensione, liquidare_Sommario | dizionario(辭典): 찾는 말인 열쇠에 값을 mapping_VALORE |
| 작업 | avvia(실행할일), 기다리기(esecutoreAsincrono), REND_task, 살아있는가 | 작업 thread_VALORE: 한 app_f5044b9b 안의 Esegui_comando Stream_VALORE |
| comunicazione | Apri, inviare, ricevere, TIMEOUT, Chiudi | comunicazione(通信), datagramma(電文), porta_VALORE: dati 교환·메시지·포트의 역할 |

## Esegui_comando 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(Italiano Corso_VALORE dichiarazioni), class당 16 KiB·costante_VALORE 풀 511항목, 전체 metodo_VALORE/valore_del_campo 각각 512개. metodo_VALORE CODICE_VALORE 8 KiB, locale_Scope variabile_VALORE·피연산자 operando_Pila 각각 128슬롯, argomenti 최대 16개(this dichiarazioni).
- VM 가닥은 main dichiarazioni **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 Esegui_comando 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- oggetto_VALORE 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 effettivo_dati 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 file·대형 stringa_VALORE·객체가 이 제한을 넘을 numero 있다.
- 실행은 50만 바이트코드 comando 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 input_VALORE 대기는 기한을 갱신하고 Finestra SWITCH_MODA 시 중단·재개한다. 일반 server_VALORE·계산의 무제한 실행은 아직 없다. 미지원 comando·risorsa_VALORE 부족은 명시적인 오류로 종료한다.
- RAM file 최대 64개, 파일당 16384바이트, percorso UTF-8 63바이트. RAM 디렉터리와 peer_VALORE/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 Italiano class는 RAM file 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 Regolari_articolo 경로에서 fonte_albero·Corso_VALORE·dati 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 esterno_VALORE IPv4를 제공한다. effettivo_dati GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. datagramma 512바이트, socket_VALORE 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 Esegui_comando 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 array_VALORE, 완전한 array_VALORE 공변성·인터페이스 layer_VALORE 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/Crittografa_dati/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 Supporto_VALORE 부분집합은 아래 및 sviluppo 매뉴얼을 참고한다. Corso_VALORE file 전체 검증기·accesso_voce privilegio_VALORE/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 proteggere_VALORE limite_VALORE 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 implementazione 단계다: 완전한 JVM VALORE/convalidare/Corso_VALORE 로더와 eccezione 모델 → 영속 VFS·mmap·clock·원자 operazione_VALORE·effettivo_dati 스레드/sincronizzare ABI → OpenJDK java.base 및 native Catalogo 이식 → cellulare_VALORE 네트워크·TCP/IP → Finestra 시스템/tipo_di_carattere_VALORE/입력기·java.desktop → Java SE 호환성 prove. Regolari_articolo nativo JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## JVM 0.3: 네트워크와 GUI estensione_VALORE

`Socket`/`ServerSocket` generare·Connetti·accept·양방향 InputStream/OutputStream·close·EOF·valore 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 esterno_VALORE cifra_VALORE IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 chiudere_p 16개, Java 루프백 버퍼 1024바이트, esterno_VALORE TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. interattivo 이벤트 대기는 Esegui_comando 기한을 갱신하고 terminale SWITCH_MODA 시 프로세스 상태를 Store_VALORE·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

Italiano `Finestra`, `elemento_grafico`, `connessione_trasporto` 클래스를 distribuzione_VALORE JAR와 nativo JVM 내장 자원에 추가했다. 상세 metodo_VALORE·제한·fonte_albero·업로드 방법: [한글 sviluppo 매뉴얼](sviluppo_guida.md).

## Italiano 객체의 직접 Esegui_comando

`Finestra`, `Etichetta`, `campo_di_testo`, `pulsante`, `evento_coda`, `Action_informativa`, `esecutoreAsincrono`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. nativo JVM의 oggetto_VALORE generare,
formato_VALORE 검사, schermata 호출, Evento 큐, thread_VALORE 스케줄러에 Italiano 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 Esegui_comando 경로도 유지한다.
Italiano 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

nativo 실행기의 Italiano 진입점은 `public static void avvia()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 Italiano 진입점을 우선한다.
명령행 인수는 `실행인수.articolo_CONTA_NUMERI()`와 `실행인수.testo(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. statico_VALORE file 예제는 게스트
javac로도 컴파일하며, GUI/thread_VALORE 소스는 host `javac --release 8`을 사용한다.
직접 GUI/thread_VALORE API는 nativo JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
Italiano 가닥의 Esegui_comando·aspetta_VALORE·중복 avvia rifiutare_VALORE, GUI Evento origine_VALORE·INDICE·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

## terminale 부분 aggiornare

spostare_VALORE·Dimensione 변경은 새 Finestra 영역과 Indietro_articolo 자리에서 드러난 띠만 합성한다.
1920×32 pixel(240 KiB)의 임시 그림에서 배경·겹친 Finestra·carattere_VALORE·GUI를 먼저
완성하고, Regolari_articolo mostrare_VALORE 메모리와 비교하여 달라진 화소만 기록한다.
32줄보다 큰 영역은 여러 띠로 처리하므로 전체 프레임을 원자적으로
교체하거나 수직 동기에 맞추는 방식은 아니다. 전체 배경을 먼저 지우는
중간 화면은 표시하지 않는다. 좌표가 같으면 retry_VALORE 그리지 않는다.

`make test-redraw`는 effettivo_dati C Paint_schermata 코드를 호스트의 Memoria_dati 화면에 연결해
spostare_VALORE 80회·Dimensione cambiare_VALORE 40회·겹친 Finestra 4개를 전체 합성 결과와 pixel 단위로 대조한다.
area_VALORE 밖 spazio_utente disegno_VALORE, 동일 pixel 무기록, puntatore 밑그림, effettivo_dati schermata riga_di_ingresso 간격을
검사한다. 이 시험의 시간은 host CPU 측정이며 Pi 4/QEMU 속도로 해석하지 않는다.
`make test-resize`는 QEMU/VNC의 640×480 및 1920×1080에서 왼쪽 모서리 trascinare_VALORE,
한글 input_VALORE·vi 미저장 Contenuto_VALORE·독립 Finestra 크기를 검사한다.
