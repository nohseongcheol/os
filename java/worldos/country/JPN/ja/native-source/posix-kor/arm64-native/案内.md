# 内蔵 ARM64 Java 커널의 C/C++ ファイル·루프백 接続

이 디렉터리는 `platforms/rpi4-native` 内蔵 中核値 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`ヘッダー/ファイルABI.h`는 日本語 함수명과 `extern "C"` ABI를 제공한다. `接続.c`는 中核値 안에서 AOT Java ファイル 메서드에 직접 연결하고, `利用者橋渡し.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. 実際データ ファイル 처리는 `記憶ファイル群.java`, 루프백 データグラム 처리는 `折返し通信網.java`, 연결형 흐름은 `ストリーム通信網.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 中核値 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`第三被演算子. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·浮動点値 操作値·ファイル·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

支援値: `ファイル開放`, `ファイルデータ読取`, `ファイルデータ書込`, `ファイル閉鎖`, `ファイル位置移動`, `ファイル入口名前除去`, `ファイル長さ設定`, 補助値 関数 `ファイル容量`. エラー 시 -1과 작업별 `エラー番号`를 반환한다. `確定ファイル記憶装置`은 RAM 파일이므로 ENOSYS를 반환한다. ファイル 16개, 각 16384바이트, 名前 63바이트, 記述子入口 16개이며 RAM 디렉터리·通信相手値/절대 경로를 제공한다. 許可値/영속 저장은 없다.

사용자용 `ヘッダー/通信網ABI.h`는 実際データ 日本語 함수와 독립 구조체를 선언한다.
`通信端点作成`, `番地結合`, `データグラムデータ送信/受取`, `通信網接続/待機/受取`는
`利用者橋渡し.c`에서 SVC를 호출하며 マクロ値 별칭이 아니다. `struct インターネットソケット番地`의
`番地体系`, `ポート番号`, `インターネット番地.番地値`을 사용한다. 상수는 enum의
`インターネット体系`, `データグラムソケット`, `データグラム通信規約`, `ストリーム通信網`, `ストリーム輸送通信規約`이다.
日本語·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. 外部値 통신은 内蔵 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. 実際データ Pi 4 GENET 드라이버는 미지원이다.
소켓도 実際データ 関数 `ファイル閉鎖`로 닫는다.
