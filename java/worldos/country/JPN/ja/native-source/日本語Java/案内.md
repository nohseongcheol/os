# 日本語 Java 補助器値 ライブラリ

OpenJDK 11 이상과 함께 쓰는 프로젝트 所有者値 API다. 표준 Java ライブラリ 전체의 번역판을 뜻하지 않는다. 기존 Java API·키워드·例外·자료형은 그대로 함께 쓴다.

전체 22개 補助器値 메서드의 引数·返却済み値·제약, 稼働システム 안의 사용법, Python·C++ 呼出 방법은 **[日本語 ライブラリ 利用者手引](利用者手引.md)**에 정리했다. [Python 呼出 用例](用例/他言語/Python呼出.py)와 [C++ JNI 呼出 用例](用例/他言語/Java呼出.cpp)도 제공한다.

`make`로 `build/日本語Java.jar`를 만든다. `javac -encoding UTF-8 -cp build/日本語Java.jar 用例/挨拶例.java`로 예제를 컴파일한다. 실행은 `java -cp build/日本語Java.jar:用例 挨拶例`第三被演算子.

`挨拶例` 예제는 그래픽 화면이 없으면 ファイル·文字·스레드 결과와 안내만 출력한다. Swing 창은 그래픽 세션에서 실행해야 한다. QEMU에서는 [그래픽 命令実行 案内](../platforms/rpi4/README.md)의 `make run`으로 부팅한 後端値 VNC 데스크톱의 터미널을 사용한다.

| クラス値 | 제공 기능 |
|---|---|
| ファイル | UTF-8 텍스트·バイト値 読取/書込, 디렉터리·入口一覧 |
| 文字 | UTF-8 値変換, NFC 値正規化, コード値 포인트 数, 언어별 字句用語 境界位置値 |
| 通信 | HTTP(S) 要求, 제한시간을 가진 TCP 接続 |
| 作業 | 스레드 起動処理·합류·値待合, 作業 プログラム実行器 |
| 画面 | Swing 이벤트 처리와 窓 生成 |
| 作業場 | ソース 編集値·ソースコンパイル·命令実行·命令実行 ファイル 生成 画面 |

`char`는 UTF-16 コード値 단위이므로 이모지 등을 한 글자로 처리할 때 コード値 포인트 또는 文字 境界位置値 API를 사용한다. 파일은 UTF-8로 저장한다. OpenJDK의 모든 Java2D/書体値/입력기 조합을 각각 검증한 것은 아니다.

이름은 現在項目 의미가 분명한 日本語 용례를 사용했다. 개별 명칭의 역사적 어원 검토를 완료했다고 주장하지 않는다. 資源値 종료와 例外 처리는 표준 API의 계약을 따른다.
