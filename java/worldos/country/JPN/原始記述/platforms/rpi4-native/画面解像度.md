# 内蔵 ARM64 커널의 画面 解像度値

QEMU 命令実行 위치는 `jkoros/platforms/rpi4-native`第三被演算子. 커널을 빌드한 後端値 다음과 같이 실행한다.

```bash
make build
python3 道具/命令実行.py --desktop --network --resolution 1920x1080
```

Remmina의 **VNC** 接続 주소는 `127.0.0.1:5902`第三被演算子. 이미 命令実行 중인 VM은 종료하고 새 옵션으로 再試行処理値 시작한다. 画面 전체가 보이지 않으면 Remmina에서 画面 整列境界位置 또는 전체 화면을 선택한다. 이 옵션은 게스트의 実際データ 画素 수를 바꾼다.

`--resolution`은 일반 UART 命令実行, `--desktop`, `--vnc`, `--display`에서 동일하게 적용된다. `--network`와 함께 사용할 数 있다. 幅値 640~1920, 高さ値 480~1080을 허용하며 기본값은 640×480이다. 1280×720과 1920×1080도 선택할 数 있다.

```bash
make desktop RESOLUTION=1920x1080
python3 道具/命令実行.py --resolution 1280x720 --vnc 127.0.0.1:2
```

起動 로그는 実際データ 할당된 크기를 표시한다.

```text
FRAMEBUFFER PASS 1920x1080 RGB32 (drawing only)
```

端末 바탕과 上限側側面 막대는 画面 전체를 채운다. 터미널은 右 아래까지 끌어서 이동하고 X로 닫을 数 있다. 端末 窓 容量(568×360)와 書体値 크기는 유지되므로 넓어진 화면에 여러 창을 배치할 数 있다. Swing 부분집합의 `setLocationRelativeTo(null)`도 実際データ 画面 가운데를 사용한다. 起動 後端値 해상도를 바꾸는 기능은 제공하지 않는다.

## 프로그램에서 画面 容量 読取

| 言語 | 日本語 呼出 |
|---|---|
| Java | `日本語.内蔵.画面.幅値()`, `画面.高さ値()`, `画面.入口消去処理(色値)` |
| C | `<画面ABI.h>`의 `画面幅()`, `画面高さ()`, `矩形描画処理(...)` |
| C++ SDK | `呼出.h`의 `画面幅読取()`, `画面高さ読取()`, `画面矩形(...)` |
| Python | `from 日本語 import 画面容量, 矩形描画処理`; `幅値, 高さ値 = 画面容量()` |

C 함수는 マクロ値 별칭이 아닌 実際データ 함수다. 利用者 呼出 22로 크기를 조회하며, 塗装画面 呼出 13과 GUI 呼出 20은 実際データ 画面 경계를 검사한다. 프레임버퍼 주소는 利用者 프로그램에 노출하지 않는다. 画面 밖의 요청은 오류를 반환한다.

게스트 `javac`에서는 `日本語.内蔵.画面.幅値()`처럼 전체 이름으로 호출한다. 지원하는 ソース木 문법에 맞춰 画素色 상수는 십진수로 쓴다. 下端値 호출은 起動 해상도와 관계없이 末尾項目 화소를 그린다.

```java
int 幅値 = 日本語.内蔵.画面.幅値();
int 高さ値 = 日本語.内蔵.画面.高さ値();
日本語.内蔵.画面.矩形(幅値 - 1, 高さ値 - 1, 1, 1, 255);
```

`画面` 클래스의 프레임버퍼 호출은 内蔵 JVM 전용이다. 이 API의 例外 プロセス値入口 시험은 ホスト `javac --release 8`로 컴파일한 class를 内蔵 JVM에서 실행한다. 게스트 컴파일러의 일반적인 `try/catch` 문법 지원을 추가한 것은 아니다.

## Raspberry Pi 4 SD 起動

```bash
make image RESOLUTION=1920x1080
```

생성되는 `dist/jkoros-native-rpi4.img`와 `dist/jkoros-native-rpi4-boot.zip`에 1080p 설정이 들어간다. SD イメージ値 생성은 640×480, 1280×720, 1920×1080을 지원한다. 이미 펼친 起動 파일을 수정할 경우 `config.txt`의 `[pi4]`에 下端値 값을 사용한다.

```ini
max_framebuffer_width=1920
max_framebuffer_height=1080
framebuffer_width=1920
framebuffer_height=1080
hdmi_group=1
hdmi_mode=16
```

커널은 [Raspberry Pi 受信箱 契約値](https://github.com/raspberrypi/firmware/wiki/Mailbox-property-interface)의 現在項目 画面 容量 조회와 画面 記憶装置確保 응답을 사용한다. 응답의 容量·RGB32 書式値·한 줄의 バイト値 数·記憶装置確保 용량을 확인하고, 반환된 行 간격으로 그린다. 初期状況 조회에 실패하거나 支援値 범위를 벗어나면 640×480을 요청한다. HDMI 설정은 [공식 펌웨어 画面 設定値 文書](https://www.raspberrypi.com/documentation/computers/legacy_config_txt.html)를 따른다. 実際データ Pi 4와 모니터 조합에서의 HDMI 부팅은 아직 검증하지 않았다.

## 妥当性検査

```bash
make test-resolution
```

시험은 각 해상도에서 実際データ VNC 画面 크기와 픽셀, 端末 引摺り値·閉鎖, C/Java 게스트 ソースコンパイル, Python 命令実行, 右 下端値 픽셀과 画面 境界位置値 エラー, Swing 中間 連結配置·ボタン·閉鎖, GUI와 FTP 동시 사용을 확인한다. 결과와 画面 캡처는 `build/verification/resolution/`에 저장한다.
