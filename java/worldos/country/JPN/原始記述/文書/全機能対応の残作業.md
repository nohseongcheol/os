# 전체 支援値 요청의 現在項目 状況値

要求 전체는 아직 완료되지 않았다. 現在項目 ISO는 内蔵 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 実際データ C POSIX 일부 기능, 日本語 API/ソース 名前, IDE ファイル 보존, 게스트 Java ファイル 흐름을 구현하고 시험했다. [구현과 境界位置上限](../posix-kor/案内.md)를 기준으로 판단한다.

| 要求 분야 | 現在項目 命令実行 가능한 切抜き | 전체 지원에 필요한 作業 |
|---|---|---|
| Java ソースコンパイル·命令実行 | 게스트 제한형 javac/JVM, 静的値 단일 클래스와 일부 표준 オブジェクト値 | 일반 オブジェクト値·クラス値 接続·例外·GC·스레드, 완전한 javac와 표준 クラス値 ライブラリ |
| ファイル | POSIX 記述子入口, Java 단일 バイト値 ファイル ストリーム値, 전용 媒体値 보존 | 일반 java.io/nio, 디렉터리·許可値·錠値·일반 ファイルシステム·拡張子値 가능한 容積値 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP ホスト 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 入口追記 NIC |
| GUI·Swing | VGA 文字 端末入出力 | 프레임버퍼·入力値 イベント·書体値·窓 稼働システム値, AWT 네이티브 연결과 Swing 命令実行 基盤 |
| POSIX | 문서화한 ファイル·端末入出力·UDP 部分要素値 | プロセス値·exec/fork·스레드·시그널·時間値·mmap·poll·파이프 등과 적합성 妥当性検査 |
| 언어별 名前 | 日本語 46개 対応付け値 入口値, 実際データ C/Java/ファイル 名前 적용 | 対象値 言語 確定値, 언어별 용례·역사 근거와 해당 ソース·도구의 妥当性検査 |

内蔵 커널을 유지하면 上端値 基盤 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 基盤 命令実行 환경을 추가하는 방식은 별도의 中核値·루트 ファイルシステム·OpenJDK·그래픽 サーバー値·영구 格納値 구성을 가진 命令実行 경로가 된다. 후자는 기존 内蔵 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

命令実行 기반과 入口追記 対象値 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 現在項目 원문과 試験 결과를 후속 구현의 출발점으로 보존한다.
