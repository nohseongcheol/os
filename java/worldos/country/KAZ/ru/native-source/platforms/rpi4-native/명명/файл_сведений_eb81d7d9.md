- 명사는 자료의 역할을 나타낸다: `дескриптор_файла`, `одноранговый_номер_порта`, `динамическая_память`, `клавиатура`.

## 보존하는 SD Название

`public`, `class`, `int`는 예약어다. `String`, `main`, 배열의 `length`는 예약어가 아니다.
текущий_товар 다섯 Java 예제는 `запустить()`·`실행인수`·русский экран/поток_ЗНАЧЕН_5b72a632 API를 사용해
예약어·리터럴 외의 식별자를 한국어로 작성한다. экран/가닥은 표준 객체를
감싸지 않고 свой JVM에 직접 구현했다. 자세한 계약은 [русский Java API](../한국어자바/файл_сведений_eb81d7d9.md)를 본다.

표준 javac는 строка_ЗНАЧЕН 리터럴에 `java.lang.String`, строка_ЗНАЧЕН 결합에 `StringBuilder`
같은 이름을 생성한다. 이들은 русский 소스에서도 바이트코드에 남을 수 있다.
기존 표준 class를 실행하는 JVM의 сопоставление_ЗНАЧЕН строка_ЗНАЧЕН, 아직 표준 라이브러리를 쓰는
коммуникация·файл 연결부까지 모두 한국어로 재구현한 것은 아니다. 이름만 일괄 치환하면
дескриптор_ввод·재정의·native 연결이 달라져 호환성이 깨진다.

C 표준 ФУНКЦИЯ_ЗНАЧЕН·целое_число_ТИП·POSIX ABI, CPU регистр Название, 어셈블리 команда, 링커 절 Название,

## C коммуникация 구조체와 Python ошибка

C 통신에서 `갈래`는 АДРЕС 체계를 구분하고 `номер_порта`는 port, `АДРЕС_ЗНАЧЕН`은
IPv4 주소의 32비트 값을 나타낸다. `датаграмма_протокол`은 앞서 설명한 датаграмма(電文)과
сумма_контракта(規約)을 결합해 UDP의 기능을 드러낸 프로젝트 이름이다.

| 표준 표현 | русский 직접 реализация |
|---|---|
| AF_INET / SOCK_DGRAM / IPPROTO_UDP | enum의 облако_Семья / сокет_датаграмм / датаграмма_протокол |
| struct pk_sockaddr_in | struct облако_сокет_АДРЕС |
| sin_family / sin_port | АДРЕС_Семья / номер_порта |
| sin_addr.s_addr | адрес_в_Интернете.АДРЕС_ЗНАЧЕН |
| OSError / ошибка.args[0] | системная_ошибка / ошибка.ИНДЕКС |

русский 구조체는 `#define` 치환이나 значение_поля 별칭이 아닌 별개 자료형이다.
표준 구조체와 같은 16바이트 배치를 선언하며 ядро_ЗНАЧЕН SVC에서 байт_ЗНАЧЕН 복사로
검사한다. `Create_участник`·`написать_датаграмма_данные`와 файл 함수는 статический_ЗНАЧЕН 라이브러리에
фактический_данные русский 이름의 ФУНКЦИЯ_ЗНАЧЕН 심볼을 갖는다. 기존 pk_* 심볼도 유지한다.
Назад_товар 코드에서 русский коммуникация 함수에 pk_sockaddr*를 전달했다면 русский 구조체로
옮기거나, 표준 구조체와 pk_* 함수의 짝을 유지한다.

Python의 `системная_ошибка`는 OSError의 русский 하위 클래스이며 연결부에서
ошибка 번호를 보존하여 변환한다. 일반 Python 문법과 внешний_ЗНАЧЕН 패키지의 API는 유지한다.

### 말의 뿌리와 새로운 복합 Название

`Память_ЗНАЧЕН(記憶)`과 `Поиск_ИНДЕКС(索引)`은 기존 한자어를 쓴다.
기억은 자료를 간직하는 기능에, 색인은 заказ_ЗНАЧЕН 있는 항목을 찾아 지정하는 기능에 적용한다.
