## 실행 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(русский Класс_ЗНАЧЕН объявления), class당 16 KiB·константа_ЗНАЧЕН 풀 511항목, 전체 метод_ЗНАЧЕН/значение_поля 각각 512개. метод_ЗНАЧЕН кодовое_значение 8 KiB, локальный_Scope переменная_ЗНАЧЕН·피연산자 операнд_стек 각각 128슬롯, аргументы 최대 16개(this объявления).
- VM 가닥은 main объявления **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 실행 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- объект_ЗНАЧЕН 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 фактический_данные 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 файл·대형 строка_ЗНАЧЕН·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 команда 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 входные_данные_ЗНАЧЕН 대기는 기한을 갱신하고 Окно перейти_МОДА 시 중단·재개한다. 일반 сервер_ЗНАЧЕН·계산의 무제한 실행은 아직 없다. 미지원 команда·ресурс_ЗНАЧЕН 부족은 명시적인 오류로 종료한다.

- long/float/double, invokedynamic/람다, enum/annotation, 다차원 МАССИВ_ЗНАЧЕН, 완전한 МАССИВ_ЗНАЧЕН 공변성·인터페이스 слой_ЗНАЧЕН 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/шифровать_данные/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다.
