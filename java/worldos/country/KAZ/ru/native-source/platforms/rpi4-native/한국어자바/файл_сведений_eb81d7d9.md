# русский Java коммуникация·входные_данные_выход·исключение API

패키지는 `русский.свой`다. узел `javac --release 8`로 컴파일한 class를
свой ARM64 커널의 JVM에서 실행한다. коммуникация·файл·исключение API는 OpenJDK와 대조한다. 아래의 직접 구현한 экран·작업 поток_ЗНАЧЕН_5b72a632 API는 свой JVM 전용이다.
기존 표준 Java библиотека 전체의 русский 번역판은 아니다.

```java
import русский.свой.*;

public class сеть {
    public static void main(String[] аргументы) throws входные_данные_выход_исключение {
        контакт Подключить = контакт.Открыть("10.0.2.2", 9000);
        try {
            Подключить.ТАЙМАУТ(700);
            Подключить.текстовыйВывод().Запись(문자.кодировать("안녕하세요\n"));
            входной_поток входные_данные_ЗНАЧЕН = Подключить.входные_данные_ЗНАЧЕН();
            текстовыйВывод.수쓰기(входные_данные_ЗНАЧЕН.Чтение());
        } catch (минутку_ТАЙМАУТ_исключение ошибка) {
            текстовыйВывод.запись_линия(ошибка.описание());
        } finally {
            Подключить.Закрыть();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
пространство_пользователя 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 строка_ЗНАЧЕН 리터럴에 사용하는 표준 클래스다. свой 실행기는 `public static void запустить()`도 진입점으로 받는다.

`Чтение()`의 файл 끝은 -1, МАССИВ_ЗНАЧЕН 읽기의 반환값은 фактический_данные 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. номер_порта 0은 빈 번호를 자동 배정한다.
UDP 전문은 текущий_товар свой 커널에서 512바이트까지 받으며, 주소는 цифра_ЗНАЧЕН IPv4를 사용한다.
`localhost` 루프백 외의 Название 풀이(DNS)는 свой 커널에 아직 없다.

기존 `контакт_транспортировка.Подключить/ожидать_передачи_данных_участник/получить`, `коммуникация.Открыть/написать/получить`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `контакт`, `порт_получения`, `датаграмма_канал`를 쓴다.

## русский исключение

모든 아래 클래스는 значение_по_умолчанию 생성자, `새예외("описание")` 형태의 строка_ЗНАЧЕН 생성자와
`описание()`을 제공한다. фактический_данные генерировать 문법은 `new минутку_ТАЙМАУТ_исключение("состояние_ожидания 끝")`이다.

| русский исключение | 상위 Класс_ЗНАЧЕН / 용도 |
|---|---|
| исключение | `java.lang.Exception`, 직접 던지는 일반 검사 исключение |
| выполнение_исключение | `java.lang.RuntimeException` |
| входные_данные_выход_исключение | `java.io.IOException`, русский файл·коммуникация API의 검사 исключение |
| минутку_ТАЙМАУТ_исключение | `входные_данные_выход_исключение`, коммуникация ТАЙМАУТ 초과 |
| АДРЕС_Поиск_исключение | `входные_данные_выход_исключение`, АДРЕС проверять сбой_ЗНАЧЕН |
| 파일없음예외 | `входные_данные_выход_исключение`, файл Открыть сбой_ЗНАЧЕН |
| коммуникация_исключение | `входные_данные_выход_исключение`, 표준 SocketException ПРЕОБР_ЗНАЧЕН |
| неверный_аргумент_исключение | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `неверный_аргумент_исключение` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| границы_массива_исключение / 문자열범위예외 | `범위예외` |
| пустая_ссылка_исключение | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| Состояние_исключение | `java.lang.IllegalStateException` |
| ТИП_приводить_исключение | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| МАССИВ_Store_сбой | `java.lang.ArrayStoreException` |
| поток_Состояние_исключение | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 минутку_ЗНАЧЕН 중단 |

`исключение`와 `выполнение_исключение`는 모든 русский 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, файл·коммуникация 전체를 잡으려면 `catch (входные_данные_выход_исключение ошибка)`를 쓴다.
русский API가 표준 входные_данные_выход 오류를 русский 예외로 변환한다.
기존 русский коммуникация 호출에서 `SocketTimeoutException`을 잡던 코드는
`минутку_ТАЙМАУТ_исключение`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
исключение 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
текущий_товар свой JVM에 이 20종을 추가했다. 임의의 пространство_пользователя Throwable 하위 Класс_ЗНАЧЕН 전체를
지원하도록 확장했다는 뜻은 아니다.

## компилировать_источник·실행

```sh
cd /home/user/jkoros/platforms/rpi4-native

javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 испытания/자바/한국어통신시험.java

```

내장 라이브러리는 пространство_пользователя JVM ELF 안에 탑재된다. `.jar`는 узел javac의
Класс_ЗНАЧЕН 경로로 사용한다. источник_дерево 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 русский 예외의 `throws` 선언과 그 import를 인식한다.
свой JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·объект_ЗНАЧЕН·сокет_ЗНАЧЕН 예제 전체의 источник_дерево 컴파일은 узел javac를 사용한다.
`/example/java/ПримерФайла.java`는 게스트 javac로도 컴파일할 수 있다.

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
свой JVM의 `한국어화면호출`, `Процесс_поток`가 русский Класс_ЗНАЧЕН·метод_ЗНАЧЕН·서술자를
해석해 экран 요소와 실행 가닥을 직접 만든다. Действие 알림도 свой 객체이며
콜백으로 `Выполнить`와 `получить_задача`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 실행 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 свой JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 узел JVM에서 무동작 객체가 생기지 않도록 하는 отклонить_ЗНАЧЕН 경로다.
свой JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 реализация API를
실행할 수 없다. узел javac로 컴파일한 BACK_ЗНАЧЕН свой JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, экран 큐 기능은 `SwingUtilities`에 해당한다.

```java
import русский.свой.*;
public class 가닥예제 implements 실행할일 {
    public void Выполнить() { текстовыйВывод.запись_линия("русский 작업 실행"); }
    public static void запустить() throws 대기중단예외 {
        фоноваяЗадача поток_ЗНАЧЕН_5b72a632 = 작업.запустить(new 가닥예제());
        작업.기다리기(поток_ЗНАЧЕН_5b72a632);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
МАССИВ_ЗНАЧЕН аргументы 대신 `실행인수`, 길이는 `문자.байт_СЧЁТ`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
свой 실행기는 аргументы 없는 `запустить()`을 우선한다.
기존 русский экран 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.запустить(Runnable)`을 사용하던 코드는 새 русский 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API опора_ЗНАЧЕН 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 Класс_ЗНАЧЕН·метод_ЗНАЧЕН 이름과 서술자가 남는다.
русский Название 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·метод_ЗНАЧЕН 재정의, native Подключить, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS идентификатор_ЗНАЧЕН](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS метод_ЗНАЧЕН ссылка](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
