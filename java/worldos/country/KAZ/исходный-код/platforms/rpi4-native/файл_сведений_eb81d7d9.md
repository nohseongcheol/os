# Raspberry Pi 4 свой Java ядро_ЗНАЧЕН — пространство_пользователя 실행 기반

текущий_товар свой 코드의 COSL 상업 условие, 제3자 고지 및 LGPL 재연결 자료는 [COSL распределение_ЗНАЧЕН файл_сведений_eb81d7d9](COSL배포안내.md)를 참고한다. перейти_МОДА 전 GPL 구성의 판단은 [Назад_товар 라이선스 검토](лицензия_отзыв.md)에 기록했다.

русский коммуникация·исключение 사용법은 [русский Java API](한국어자바/файл_сведений_eb81d7d9.md), ФУНКЦИЯ_ЗНАЧЕН·переменная_ЗНАЧЕН·файл 이름의 변경과 어원 근거는 [명명 файл_сведений_eb81d7d9](명명/файл_сведений_eb81d7d9.md)를 참고한다.

Linux 없이 부팅하는 свой AArch64 커널이다. Java AOT ядро_ЗНАЧЕН 위에 **командная_строка оболочка, 게스트 Java компилятор·JVM, MicroPython, EL0 C++ 실행, файл·UDP 루프백 시스템 호출, 여러 한글 GUI терминал·vi Редактор·Swing 부분집합**을 제공한다. 커널의 файл данные/정책·루프백 передать_ЗНАЧЕН_630ba093·оболочка 상태는 Java, экран 합성·пиксель изменить_ЗНАЧЕН·указатель·클리핑도 Java로 구현하며, CPU/MMU/устройство_ЗНАЧЕН 경계와 терминал·знак_ЗНАЧЕН Paint_экран 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 свой 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 실행, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 проводной_ЗНАЧЕН 송수신은 아직 미검증이다.** 실행·контакт_e05f319b·пароль_ЗНАЧЕН 확인은 [внешний_ЗНАЧЕН контакт_e05f319b файл_сведений_eb81d7d9](внешний_контакт_гид.md)에 정리했다.

셸은 EL1 ядро_ЗНАЧЕН, `java` 등 пространство_пользователя 실행 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 실행·контакт_e05f319b 방법 및 фактический_данные 검증은
[실행 계층과 внешний_ЗНАЧЕН коммуникация 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 фактический_данные 실행 형식으로 검사한다. `./приветствие_ae353e94`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 статический_ЗНАЧЕН ELF는 `run --linux имя_файла_SMS`으로 실행한다. [ELF·Linux ABI опора_ЗНАЧЕН 범위와 동일 바이너리 испытания](исполняемый_ABI.md).

GUI와 네트워크는 `python3 инструменты/실행.py --desktop --network`로 함께 사용한다. Java·C·Python의 русский 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 запуск_машины 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 수 있다. Remmina에서 **F9/Shift+Space/한·нуль_операнд Ключ_ЗНАЧЕН**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·фактический_данные TCP/UDP·файл байт_ЗНАЧЕН·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java ПримерОкна`로 русский Swing 예제를 실행한다. терминал 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 текущий_товар СТОЛБЕЦ_ЗНАЧЕН·СТРОКА_ЗНАЧЕН 수를 보여 준다.

## текущий_товар 컴퓨터에서 실행

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

Выход_программа: **Ctrl+A Далее_товар X**. 게스트 C/AOT инструменты 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. узел 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. компилятор 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/путь/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` опора_ЗНАЧЕН 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 실행**한다. 기존 한 знак_ЗНАЧЕН 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 аргументы 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

예를 들어 `edit приветствие_ae353e94.java`를 입력한 Далее_товар 아래 소스를 입력한다.

```java
public class приветствие_ae353e94 { public static void main(String[] args) { int ЗНАЧЕН = 7; System.out.println("한글=" + ЗНАЧЕН); } }
```

그다음 단독 `.` 줄로 저장하고 `javac приветствие_ae353e94.java`, `java приветствие_ae353e94`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. Close_операция·잘못된 16진수·емкость_ЗНАЧЕН 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, 실행 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 команда 인수는 최대 32개다. Цитата·백슬래시·оболочка переменная_ЗНАЧЕН·파이프·리다이렉션 범위는 [оболочка описание](оболочка_И_Терминал.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, АДРЕС **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode входные_данные_ЗНАЧЕН·명시적 вставить_ЗНАЧЕН·실행 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 инструменты/실행.py --desktop --network
# 다른 аппаратный_порт: python3 инструменты/실행.py --desktop --port 5903
```

종료는 실행한 узел 터미널에서 Ctrl+C다. 기존 `python3 инструменты/실행.py --vnc 127.0.0.1:2`는 экран 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. фактический_данные Pi4 USB 입력기는 아직 없으며, VNC Подключить 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 фактический_данные C++/UDP ELF 실행, `Hello.java` компилировать_источник 후 JVM 실행, `hello.py` 실행, GUI терминал 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 интерактивный 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 Память_данные·CPU 문맥을 보관한다. оболочка·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD файл 구성·ядро_ЗНАЧЕН 체크섬 검사와 물리 Доска запуск_машины 검증은 별개다. MMU использовать_ЗНАЧЕН 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 запуск_машины 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## Java와 Python의 정확한 клип

свой `javac`는 버전 49 `.class`를 생성하며 JVM은 опора_ЗНАЧЕН 명령으로 구성된 버전 45–52 클래스를 실행한다. статический_ЗНАЧЕН ФУНКЦИЯ_ЗНАЧЕН·재귀·int/boolean/char/String·условие/спринт_ЗНАЧЕН·строка_ЗНАЧЕН 결합과 일부 файл 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/состав_ЗНАЧЕН 자모 식별자를 처리한다. Unicode идентификатор_ЗНАЧЕН 전체 таблица_подстановки·Unicode источник_дерево 이스케이프는 구현하지 않았다. 게스트 источник_дерево 컴파일러는 일반 объект_ЗНАЧЕН·исключение·Thread 구문을 아직 컴파일하지 못한다. узел `javac --release 8`로 만든 опора_ЗНАЧЕН 부분집합 클래스는 свой JVM 0.4의 объект_ЗНАЧЕН·исключение·Thread·UDP와 русский API를 사용할 수 있다.
