# engos 기능 대응표

이 표는 기존 `мурасталган_башат/`의 объект_маани 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [актуалдуу_берилмелер 부팅 기능과 한계](../os/readme_файл_eb81d7d9.md)를 따로 기록한다.

## 기존 объект_маани 기반 관리 өзөк_маани 전체를 부팅하기 위해 남은 Туташуу

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/түзмөк_маани 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot киргизме_жазуу_упай_маани, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 Контекст_маани сактагыч_маани
- актуалдуу_берилмелер PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA цикл_маани
- Java объект_маани·МАССИВ_маани Шилтеме_түзүлүш, 예외, статикалык_маани иштетүү, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT стадия_маани
- FAT 디스크 구역을 актуалдуу_берилмелер ATA 장치와 연결하는 киргизүү_чыгаруу 접착 катмар_маани

위 관리 계층은 engos 기능의 Java 관리 구현과 кабылдоо 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot киргизме_жазуу_упай_маани, статикалык_маани иштетүү·бүтүн_сан МАССИВ_маани, VGA/직렬/PS2, 명령해석기, колдонуучу ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 кабылдоо 루프백 패킷 왕복을 검증했다. 위 표의 объект_маани 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
