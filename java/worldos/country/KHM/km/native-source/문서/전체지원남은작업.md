# 전체 ទម្រ_តំលៃ 요청의 현재 ភាព_តំលៃ

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 ដែលពិត_ទិន្នន័យ C POSIX 일부 기능, 한국어 API/ប្រភព ឈ្មោះ, IDE ឯកសារ 보존, 게스트 Java ឯកសារ 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/អានខ្ញុំ_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 អនុវត្ត_ពាក្យបញ្ជា 가능한 មេឌៀខ្លីៗ | 전체 지원에 필요한 작업 |
|---|---|---|
| Java ចងក្រង_ប្រភព·អនុវត្ត_ពាក្យបញ្ជា | 게스트 제한형 javac/JVM, នឹង_តំលៃ 단일 클래스와 일부 표준 វត្ថុ_តំលៃ | 일반 វត្ថុ_តំលៃ·ថ្នាក់_តំលៃ ភ្ជាប់·ការលើកលែង·GC·스레드, 완전한 javac와 표준 ថ្នាក់_តំលៃ បណ្ណាល័យ |
| ឯកសារ | POSIX 서술자, Java 단일 បៃ_តំលៃ ឯកសារ ស្ទ្រីម_តំលៃ, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·ការអនុញ្ញាត_តំលៃ·잠금·일반 ឯកសារនៃប្រព័ន្ធ·ម៉ូឌុល_តំលៃ 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP ហូស 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 ព្រឹត្តិការណ៍·ពុម្ពអក្សរ_តំលៃ·វីនដូ ប្រព័ន្ធប្រតិបត្តិការណ៏_តំលៃ, AWT 네이티브 연결과 Swing អនុវត្ត_ពាក្យបញ្ជា 기반 |
| POSIX | 문서화한 ឯកសារ·단말·UDP 부분 | ដំណើរការ_តំលៃ·exec/fork·스레드·시그널·ពេល_វេលា_តំលៃ·mmap·poll·파이프 등과 적합성 ធ្វើអោយមានសុពលភាព |
| 언어별 ឈ្មោះ | 한국어 46개 대응 ការបញ្ចូល_តំលៃ, ដែលពិត_ទិន្នន័យ C/Java/ឯកសារ ឈ្មោះ 적용 | គោលដៅ ភាសា 확정, 언어별 용례·역사 근거와 해당 ប្រភព·도구의 ធ្វើអោយមានសុពលភាព |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 អនុវត្ត_ពាក្យបញ្ជា 환경을 추가하는 방식은 별도의 ខឺណេល_តំលៃ·루트 ឯកសារនៃប្រព័ន្ធ·OpenJDK·그래픽 ម៉ាស៊ីនមេ_តំលៃ·영구 ផ្ទុក_តំលៃ 구성을 가진 អនុវត្ត_ពាក្យបញ្ជា 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

អនុវត្ត_ពាក្យបញ្ជា 기반과 추가 គោលដៅ 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
