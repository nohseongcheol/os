# 한국어 Java 통신·ចូល_ចេញ·ការលើកលែង API

패키지는 `한국어.자체`다. ហូស `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·ឯកសារ·ការលើកលែង API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 ស្រេត_តំលៃ API는 자체 JVM 전용이다.
기존 표준 Java បណ្ណាល័យ 전체의 한국어 번역판은 아니다.

```java
import 한국어.자체.*;

public class ណិតវឺក {
    public static void main(String[] អាគុយម៉ង់) throws ចូល_ចេញ_ការលើកលែង {
        ការភ្ជាប់ ភ្ជាប់ = ការភ្ជាប់.បើក("10.0.2.2", 9000);
        try {
            ភ្ជាប់.អស់ម៉ោង(700);
            ភ្ជាប់.លទ្ធផល().សរសេរ(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = ភ្ជាប់.입력();
            លទ្ធផល.수쓰기(입력.អាន());
        } catch (រង់ចាំ_អស់ម៉ោង_ការលើកលែង កំហុស) {
            លទ្ធផល.សរសេរ_បណ្ដាញ(កំហុស.설명());
        } finally {
            ភ្ជាប់.បិទ();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
អ្នកប្រើ 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 សំនុំអក្សរ_តំលៃ 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void រត់()`도 진입점으로 받는다.

## 통신과 ស្ទ្រីម_តំលៃ

| ថ្នាក់_តំលៃ | 한국어 호출 |
|---|---|
| ការភ្ជាប់ | `បើក(អ៊ីម៉ែល, លេខរន្ធ)`, `입력()`, `លទ្ធផល()`, `អស់ម៉ោង(밀리초)`, `លេខរន្ធ()`, `ក្នុងតំបន់_លេខរន្ធ()`, `연결됨()`, `닫힘()`, `បិទ()` |
| 수신창구 | `បើក(លេខរន្ធ)`, `받기()`, `លេខរន្ធ()`, `អស់ម៉ោង(밀리초)`, `닫힘()`, `បិទ()` |
| 입력흐름 | `អាន()`, `អាន(byte[])`, `អាន(byte[], រត់, ប្រវែង_តំលៃ)`, `បិទ()` |
| 출력흐름 | `សរសេរ(int)`, `សរសេរ(byte[])`, `សរសេរ(byte[], រត់, ប្រវែង_តំលៃ)`, `내보내기()`, `បិទ()` |
| 전문통로 | `បើក(លេខរន្ធ)`, `ផ្ញើ(អ៊ីម៉ែល, លេខរន្ធ, អត្ថបទ)`, `받기()`, `អស់ម៉ោង(밀리초)`, `លេខរន្ធ()`, `닫힘()`, `បិទ()` |
| 연결통신 | `បើក(...)`, `수신열기(...)`는 위 한국어 객체를 반환 |
| 검사 | `참인지(លក្ខខណ្ឌ, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`អាន()`의 ឯកសារ 끝은 -1, អារេ_តំលៃ 읽기의 반환값은 ដែលពិត_ទិន្នន័យ 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. លេខរន្ធ 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 자체 커널에서 512바이트까지 받으며, 주소는 숫자 IPv4를 사용한다.
`localhost` 루프백 외의 ឈ្មោះ 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.ភ្ជាប់/듣기/받기`, `통신.បើក/ផ្ញើ/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `ការភ្ជាប់`, `수신창구`, `전문통로`를 쓴다.

## 한국어 ការលើកលែង

모든 아래 클래스는 តំលៃស្វ័យប្រវត្តិ 생성자, `새예외("설명")` 형태의 សំនុំអក្សរ_តំលៃ 생성자와
`설명()`을 제공한다. ដែលពិត_ទិន្នន័យ បង្កើត 문법은 `new រង់ចាំ_អស់ម៉ោង_ការលើកលែង("រង់ចាំ_ភាព 끝")`이다.

| 한국어 ការលើកលែង | 상위 ថ្នាក់_តំលៃ / 용도 |
|---|---|
| ការលើកលែង | `java.lang.Exception`, 직접 던지는 일반 검사 ការលើកលែង |
| 실행예외 | `java.lang.RuntimeException` |
| ចូល_ចេញ_ការលើកលែង | `java.io.IOException`, 한국어 ឯកសារ·통신 API의 검사 ការលើកលែង |
| រង់ចាំ_អស់ម៉ោង_ការលើកលែង | `ចូល_ចេញ_ការលើកលែង`, 통신 អស់ម៉ោង 초과 |
| អ៊ីម៉ែល_រុករក_ការលើកលែង | `ចូល_ចេញ_ការលើកលែង`, អ៊ីម៉ែល ផ្ទៀងផ្ទាត់ បរាជ័យ_តំលៃ |
| 파일없음예외 | `ចូល_ចេញ_ការលើកលែង`, ឯកសារ បើក បរាជ័យ_តំលៃ |
| 통신예외 | `ចូល_ចេញ_ការលើកលែង`, 표준 SocketException 변환 |
| មិនត្រឹមត្រូវ_អាគុយម៉ង់_ការលើកលែង | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `មិនត្រឹមត្រូវ_អាគុយម៉ង់_ការលើកលែង` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| ទទេ_យោង_ការលើកលែង | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| ភាព_ការលើកលែង | `java.lang.IllegalStateException` |
| វាយបញ្ចូល_បញ្ជូន_ការលើកលែង | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| អារេ_ផ្ទុក_បរាជ័យ | `java.lang.ArrayStoreException` |
| ស្រេត_ភាព_ការលើកលែង | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 រង់ចាំ_តំលៃ 중단 |

`ការលើកលែង`와 `실행예외`는 모든 한국어 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, ឯកសារ·통신 전체를 잡으려면 `catch (ចូល_ចេញ_ការលើកលែង កំហុស)`를 쓴다.
한국어 API가 표준 ចូល_ចេញ 오류를 한국어 예외로 변환한다.
기존 한국어 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`រង់ចាំ_អស់ម៉ោង_ការលើកលែង`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
ការលើកលែង 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 자체 JVM에 이 20종을 추가했다. 임의의 អ្នកប្រើ Throwable 하위 ថ្នាក់_តំលៃ 전체를
지원하도록 확장했다는 뜻은 아니다.

## ចងក្រង_ប្រភព·អនុវត្ត_ពាក្យបញ្ជា

```sh
cd /home/user/jkoros/platforms/rpi4-native
make ចងក្រង_ប្រព័ន្ធ
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 ឧបករណ៍/អនុវត្ត_ឯកសារ.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 អ្នកប្រើ JVM ELF 안에 탑재된다. `.jar`는 ហូស javac의
ថ្នាក់_តំលៃ 경로로 사용한다. ប្រភព_មែកធាង 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 한국어 예외의 `throws` 선언과 그 import를 인식한다.
자체 JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·វត្ថុ_តំលៃ·소켓 예제 전체의 ប្រភព_មែកធាង 컴파일은 ហូស javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 수 있다.

ដែលពិត_ទិន្នន័យ TCP/UDP 예제는 [네트워크예제.java](../../../example/java/네트워크예제.java),
អនុវត្ត_ពាក្យបញ្ជា 절차는 [example អានខ្ញុំ_eb81d7d9](../../../example/README.md),
ប្រភព_មែកធាង 명명 원칙은 [명명 អានខ្ញុំ_eb81d7d9](../명명/អានខ្ញុំ_eb81d7d9.md)에 있다.

## Swing វីនដូ 예제

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` បន្ទាប់_ធាតុ `java 창예제`로 연다. ឈ្មោះ 입력, 인사하기 버튼,
인사말과 ចុច_តំលៃ 횟수 ផ្ទុក_ឡើង_វិញ, X 닫기를 지원한다.

| 기능 | 한국어 직접 API |
|---|---|
| Runnable / run | `실행할일.ប្រតិបត្តិ()` |
| ActionListener / actionPerformed | `동작받이.동작받기(동작알림 알림)` |
| ActionEvent | `동작알림.ពាក្យបញ្ជា_អត្ថបទ()`, `ព្រឹត្តិការណ៍_ប្រភព()`, `សន្ទស្សន៏()` |
| JFrame | `វីនដូ(វីនដូ_ចំណងជើង, 폭, 높이)`, `បន្ថែម_ធាតុ(화면구성요소)`, `បង្ហាញ_វីនដូ()`, `បិទ()`, `보이는가()` |
| JButton | `ប៊ូតុង(អត្ថបទ, 가로, បញ្ឈរ_កំណត់ទីតាំង, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `ស្លាក(...)`, `អត្ថបទ_កន្លែង_បញ្ចូល(...)` |
| 공통 화면 ធាតុ_តំលៃ | `화면구성요소.글읽기()`, `សរសេរ_អត្ថបទ(អត្ថបទ)`, `자리정하기(가로, បញ្ឈរ_កំណត់ទីតាំង, 폭, 높이)` |
| SwingUtilities.invokeLater | `ព្រឹត្តិការណ៍_ជួរ.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `ផ្តើម_ធូឌូ()`, `기다리기()`, `살아있는가()`, `ផ្អាក_ធូឌូ()` |
| 명령행 | `រត់()`, `실행인수.개수()`, `실행인수.អត្ថបទ(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `ដំណើរការ_ស្រេត`가 한국어 ថ្នាក់_តំលៃ·វិធីសាស្រ្ត_តំលៃ·서술자를
해석해 화면 요소와 អនុវត្ត_ពាក្យបញ្ជា 가닥을 직접 만든다. អំពើ 알림도 자체 객체이며
콜백으로 `ប្រតិបត្តិ`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 អនុវត្ត_ពាក្យបញ្ជា 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 ហូស JVM에서 무동작 객체가 생기지 않도록 하는 បដិសេធ_តំលៃ 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. ហូស javac로 컴파일한 ការថយ_តំលៃ 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import 한국어.자체.*;
public class 가닥예제 implements 실행할일 {
    public void ប្រតិបត្តិ() { លទ្ធផល.សរសេរ_បណ្ដាញ("한국어 작업 អនុវត្ត_ពាក្យបញ្ជា"); }
    public static void រត់() throws 대기중단예외 {
        작업가닥 ស្រេត_តំលៃ = 작업.រត់(new 가닥예제());
        작업.기다리기(ស្រេត_តំលៃ);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
អារេ_តំលៃ អាគុយម៉ង់ 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 អាគុយម៉ង់ 없는 `រត់()`을 우선한다.
기존 한국어 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.រត់(Runnable)`을 사용하던 코드는 새 한국어 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API ទម្រ_តំលៃ 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 ថ្នាក់_តំលៃ·វិធីសាស្រ្ត_តំលៃ 이름과 서술자가 남는다.
한국어 ឈ្មោះ 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·វិធីសាស្រ្ត_តំលៃ 재정의, native ភ្ជាប់, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS អង្គសម្គាល់_តំលៃ](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS វិធីសាស្រ្ត_តំលៃ យោង](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
