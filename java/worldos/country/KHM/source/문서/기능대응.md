# engos 기능 대응표

이 표는 기존 `តាមច្បាប់_ប្រភព/`의 វត្ថុ_តំលៃ 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [ដែលពិត_ទិន្នន័យ 부팅 기능과 한계](../os/អានខ្ញុំ_eb81d7d9.md)를 따로 기록한다.

## 기존 វត្ថុ_តំលៃ 기반 관리 ខឺណេល_តំលៃ 전체를 부팅하기 위해 남은 ភ្ជាប់

បន្ទាប់_ធាតុ 항목은 Java 문법만으로 실행할 수 없는 CPU/ឧបករណ៍_តំលៃ 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot ការបញ្ចូល_ចំនុច_តំលៃ, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 បរិបទ_តំលៃ ផ្ទុក_តំលៃ
- ដែលពិត_ទិន្នន័យ PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA រង្វិលជុំ_តំលៃ
- Java វត្ថុ_តំលៃ·អារេ_តំលៃ តំណ_ប្លង់, ការលើកលែង, នឹង_តំលៃ ចាប់ផ្តើម, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT ឆាក_តំលៃ
- FAT 디스크 구역을 ដែលពិត_ទិន្នន័យ ATA 장치와 연결하는 ចូល_ចេញ 접착 ស្រទាប់_តំលៃ

위 관리 계층은 engos 기능의 Java 관리 구현과 ហូស 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot ការបញ្ចូល_ចំនុច_តំលៃ, នឹង_តំលៃ ចាប់ផ្តើម·ចំនួនគត់ អារេ_តំលៃ, VGA/직렬/PS2, 명령해석기, អ្នកប្រើ ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 ហូស 루프백 패킷 왕복을 검증했다. 위 표의 វត្ថុ_តំលៃ 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
