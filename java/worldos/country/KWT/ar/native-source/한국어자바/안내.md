# العربية Java مساعد_قيمة مكتبة

OpenJDK 11 이상과 함께 쓰는 프로젝트 مالك_قيمة API다. 표준 Java مكتبة 전체의 번역판을 뜻하지 않는다. 기존 Java API·키워드·استثناء·자료형은 그대로 함께 쓴다.

전체 22개 مساعد_قيمة 메서드의 وسائط·반환값·제약, نظام_تشغيل 안의 사용법, Python·C++ 호출 방법은 **[العربية مكتبة مستخدم_دليل](مستخدم_دليل.md)**에 정리했다. [Python 호출 예제](예제/다른언어/파이썬호출.py)와 [C++ JNI 호출 예제](예제/다른언어/자바호출.cpp)도 제공한다.

`make`로 `build/한국어자바.jar`를 만든다. `javac -encoding UTF-8 -cp build/한국어자바.jar 예제/인사.java`로 예제를 컴파일한다. 실행은 `java -cp build/한국어자바.jar:예제 인사`다.

`인사` 예제는 그래픽 화면이 없으면 ملف·문자·스레드 결과와 안내만 출력한다. Swing 창은 그래픽 세션에서 실행해야 한다. QEMU에서는 [그래픽 ينفذ_أمر 안내](../platforms/rpi4/README.md)의 `make run`으로 부팅한 عودة_قيمة VNC 데스크톱의 터미널을 사용한다.

| فئة_قيمة_55654bf1 | 제공 기능 |
|---|---|
| ملف | UTF-8 텍스트·بايت_قيمة قراءة/كتابة, 디렉터리·إدخال_قائمة_f07b3200 |
| 문자 | UTF-8 تحويل_قيمة, NFC يقلل_التكرار_قيمة, رمز_قيمة_f3cd31ee 포인트 رقم, 언어별 낱말 경계 |
| 통신 | HTTP(S) طلب, 제한시간을 가진 TCP اتصال |
| 작업 | 스레드 تشغيل·합류·انتظر_قيمة, 작업 تطبيق_مشغّل |
| 화면 | Swing 이벤트 처리와 نافذة إنشاء |
| مساحة_عمل | مصدر يحرر_قيمة·يحول_برمجياً_مصدر·ينفذ_أمر·ينفذ_أمر ملف إنشاء 화면 |

`char`는 UTF-16 رمز_قيمة_f3cd31ee 단위이므로 이모지 등을 한 글자로 처리할 때 رمز_قيمة_f3cd31ee 포인트 또는 문자 경계 API를 사용한다. 파일은 UTF-8로 저장한다. OpenJDK의 모든 Java2D/خط_قيمة/입력기 조합을 각각 검증한 것은 아니다.

이름은 حديث_عنصر 의미가 분명한 العربية 용례를 사용했다. 개별 명칭의 역사적 어원 검토를 완료했다고 주장하지 않는다. مصدر_قيمة 종료와 استثناء 처리는 표준 API의 계약을 따른다.
