# 셸에서 실행하는 ຜູ້ໃຊ້ 프로그램과 UDP

게스트에서 일반적인 `main(String[] args)` 형식의 소스를 직접 작성하고 컴파일하려면 [제한형 Java 개발 환경 ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9](../../문서/자바개발환경.md)를 참고한다. 아래의 네이티브 ELF 개발과 별도로 `javac FILE.java`, `java CLASS`를 제공한다.

## 바로 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ

ໂຮສ ເທີມີນໍ 1:

```sh
cd /home/user/jkoros
python3 os/ເຄື່ອງມື/자료되돌리기.py --port 9000
```

이 서버는 `127.0.0.1`에만 바인딩한다. 외부 연결을 받도록 방화벽이나 포트 전달을 변경하지 않는다. Ctrl+C로 종료한다.

ໂຮສ ເທີມີນໍ 2:

```sh
cd /home/user/jkoros
make run
```

게스트의 `jkoros>` 프롬프트에 입력:

```text
apps
run hello first second
net
run netcheck
run udp 10.0.2.2 9000 hello
run stress 9000
```

- `hello`: 독립 Java ELF 실행과 ຕົວ_ຈິງ_ຂໍ້ມູນ CPU ການອະນຸຍາດ_ຄ່າ `ring 3`, 인수 출력.
- `netcheck`: ຜອດ_ຄ່າ 중복, 잘못된 ຈັດ_ການ_ຄ່າ/ລູກສອນເມົ້າ/ຄວາມຍາວ_ຄ່າ, 비차단 받기와 ເວລາ_ຄ່າ 초과 확인.
- `udp`: IPv4 ອີເມວ·ປາຍທາງ_ຄ່າ ຜອດ_ຄ່າ·한 ຄໍາ_ເວົ້າ_ຄ່າ 메시지를 받아 UDP로 보내고 같은 응답을 확인. `UDP ECHO PASS`, `Exit: 0`이면 성공.
- `stress`: ໂຮສ `10.0.2.2`의 ມອບຫມາຍ_ຄ່າ 창구와 1,023/1,024바이트 데이터그램을 24회 왕복. 수신 ຫ່ວງ_ຄ່າ 경계를 여러 번 지난다.

`make run`/`run-gui`는 `-netdev user,id=net0 -device rtl8139,netdev=net0`을 사용한다. 현재 주소는 게스트 `10.0.2.15/24`, ເກດເວ_ຄ່າ `10.0.2.2`로 고정돼 있다. QEMU ຜູ້ໃຊ້ 네트워크의 ໂຮສ ເຂົ້າຫາ_ເຂົ້າໃນ 주소를 사용한 예제다. 다른 네트워크 설정에는 맞춰 수정해야 하며 자동 DHCP는 없다. NIC 없이 실행하려면 `make -C os run NET_ARGS='-net none'`을 사용한다. 이때 ແອັບ_f5044b9b 실행은 되지만 UDP 열기는 `-19`로 실패한다.

## 새 Java ແອັບ_f5044b9b 추가

`예제/내프로그램.java`를 ຕໍ່ໄປ_ລາຍການ 형식으로 만든다. 진입점은 인수 없는 `static int` 또는 `static void` 함수다. 인수는 ຜູ້ໃຊ້ API로 조회한다.

```java
public final class 내프로그램 {
    public static int ແລ່ນ() {
        ຜູ້ໃຊ້.ຂຽນ("My program is running in user mode.\n");
        return 0;
    }
}
```

`os/ຜູ້ໃຊ້/ແອັບ_f5044b9b.mk`에 추가한다.

```make
APP_NAMES += mine
APP_SOURCE_mine := ຜູ້ໃຊ້/예제/내프로그램.java
APP_ENTRY_mine := 내프로그램.ແລ່ນ
```

여러 Java 파일을 쓰면 `APP_SOURCE_mine`에 공백으로 모두 나열한다. `ຜູ້ໃຊ້/ການປະກາດ/ຜູ້ໃຊ້.java`는 자동으로 함께 컴파일한다.

```sh
cd /home/user/jkoros
make iso
make run
```

새로 부팅한 셸에서 `run mine`을 실행한다. 이미 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 중인 VM에는 ສ້າງ_ລະບົບ 결과가 자동 반영되지 않는다. ແອັບ_f5044b9b 이름은 현재 셸의 ASCII 입력 제한에 맞춘 1~15자의 소문자 이름이며 Java ປະເພດສິ່ງຂອງ_ຄ່າ·ຟັງ_ຄ໌_ຊັນ_ຄ່າ·변수에는 한국어를 쓴다. 최대 32개 ແອັບ_f5044b9b, 한 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 파일은 최대 2MiB다.

독립 ELF만 컴파일할 수도 있다.

```sh
cd /home/user/jkoros
python3 compiler/컴파일러.py --target user --entry 인사.ແລ່ນ \
    -o os/build/apps/hello.elf os/ຜູ້ໃຊ້/ການປະກາດ/ຜູ້ໃຊ້.java os/ຜູ້ໃຊ້/예제/인사.java
```

`--target user`는 **jkoros 전용 ABI**다. Linux 대상과 시스템 호출 번호가 다르므로 ໂຮສ 터미널에서 직접 실행하면 안 된다. `.class`는 별도 `java CLASS` 명령의 ການຮອງຮັບ_ຄ່າ ຄ_ລິບ 안에서 실행한다. `.jar`와 일반 Linux ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 파일은 지원하지 않는다.

## ຜູ້ໃຊ້ 네트워크 API

선언은 `ການປະກາດ/ຜູ້ໃຊ້.java`에 있다. `ສົ່ງ_ຂໍ້ມູນ`/`자료받기`의 `int[]` ລາຍການ_ອົງປະກອບ 한 개는 ໄບ_ຄ່າ 하나(0~255)를 나타낸다. 한 데이터그램의 최대 ຂໍ້ມູນ 길이는 1,024바이트다.

```java
int ຈັດ_ການ_ຄ່າ = ຜູ້ໃຊ້.ສ້າງ_ເຄືອຂ່າຍ(0); // 0: 임시 ໃນເຄື່ອງ_ຂອບ_ເຂດ UDP ຜອດ_ຄ່າ 자동 ການ_ເລືອກ_ຄ່າ
int[] ຂໍ້ມູນ = new int[32];
ຂໍ້ມູນ[0] = 'H'; ຂໍ້ມູນ[1] = 'i';
int 보낸길이 = ຜູ້ໃຊ້.ສົ່ງ_ຂໍ້ມູນ(ຈັດ_ການ_ຄ່າ, 0x0a000202, 9000, ຂໍ້ມູນ, 2);
int 받은길이 = ຜູ້ໃຊ້.자료받기(ຈັດ_ການ_ຄ່າ, ຂໍ້ມູນ, 1500);
ຜູ້ໃຊ້.ປິດ_ເຄືອຂ່າຍ(ຈັດ_ການ_ຄ່າ);
```

ຕົວ_ຈິງ_ຂໍ້ມູນ 프로그램에서는 ສ້າງ·ສົ່ງ·받기의 음수 반환값을 각각 검사한다. 완성된 예제는 `예제/자료통신.java`에 있다. `자료받기`의 ລໍຖ້າ_ຄ່າ 시간은 0~2,000밀리초이며 0은 즉시 반환이다. 받은 데이터그램이 배열보다 크면 해당 데이터그램을 버리고 `-90`을 반환한다. 창구당 수신 대기열은 한 개뿐이므로 추가 도착분은 버린다. `보낸주소`와 `보낸창구`로 마지막으로 받은 상대를 조회한다.

| 반환값 | 의미 |
| --- | --- |
| 0 이상 | ຈັດ_ການ_ຄ່າ·ຂະ_ບວນ_ການ_ຄ່າ_ເຂົ້າໃນ ຄວາມຍາວ_ຄ່າ·성공 등 해당 함수의 ມາດຕະການ |
| -5 | ມືຖື_ຄ່າ ສົ່ງ_ຄ່າ ຫຼົ້ມເຫຼວ_ຄ່າ |
| -9 | 잘못되었거나 닫힌 통신 ຈັດ_ການ_ຄ່າ |
| -11 | 비차단 받기에서 도착한 ຂໍ້ມູນ 없음 |
| -14 | ຜູ້ໃຊ້ ລູກສອນເມົ້າ/ການຈັດຄ່າຮອບວຽນ_ຄ່າ ຄ_ລິບ ຂໍ້ຜິດພາດ |
| -19 | ການຮອງຮັບ_ຄ່າ NIC 없음 |
| -22 | ຜອດ_ຄ່າ/ລໍຖ້າ_ຄ່າ ເວລາ_ຄ່າ/인수 ຄ່າ ຂໍ້ຜິດພາດ |
| -24 | 열린 ເຄືອຂ່າຍ_ຜອດ 4개 한도 |
| -38 | 알 수 없는 시스템 호출 |
| -90 | ຂໍ້ມູນ 또는 수신 ການຈັດຄ່າຮອບວຽນ_ຄ່າ ຂະ_ຫນາດ 문제 |
| -98 | ໃນເຄື່ອງ_ຂອບ_ເຂດ ຜອດ_ຄ່າ ດັດຊະນີ 중복 |
| -101 | 지원하지 않는 ປາຍທາງ_ຄ່າ ອີເມວ |
| -110 | ARP·ມືຖື_ຄ່າ·수신 ເວລາ_ຄ່າ 초과 |

IP 주소는 상위 바이트부터 표기한 32비트 값이다. `10.0.2.2`는 `0x0a000202`이다. 주소를 반환하는 함수는 ເຂົ້າລະຫັດ_ຄ່າ 있는 Java `int`의 ບິດ_ຄ່າ 패턴을 사용하므로 상위 비트가 1인 정상 IP 주소가 음수로 보일 수 있다. 단순히 모든 API 반환값의 부호를 오류로 판단하면 안 된다.

## ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 경계와 시스템 호출

```text
ເຊລ run → JKAP에서 ELF ຮັບ_ຮອງ·적재 → ring 3 ຜູ້ໃຊ້ ແອັບ_f5044b9b
                                 ↓ int 0x80
                      ລູກສອນເມົ້າ 검사 → Java ແກນກາງ_ຄ່າ API → RTL8139/UDP
                                 ↓ ອອກ_ແອັບ·ຂໍ້ຍົກເວັ້ນ·ເວລາ_ຄ່າ 초과
                                ເຊລ 복귀
```

시스템 호출 레지스터는 `EAX=ດັດຊະນີ`, `EBX,ECX,EDX,ESI,EDI=인수`, `EAX=ມາດຕະການ`다. Java 호출 스택 ABI는 컴파일러가 ຜູ້ໃຊ້ 스텁에서 이 형식으로 바꾼다. C의 POSIX/JNI ABI가 아니다.

| ດັດຊະນີ | 호출 |
| --- | --- |
| 0 | ອອກ_ແອັບ(ສະຖານະ_ຄ່າ ລະຫັດ_ຄ່າ) — ແລ່ນ/ຂໍ້ຜິດພາດ 런타임에서 사용 |
| 1 | ສະຕຣິງ_ຄ່າ ຂຽນ |
| 2 / 3 | 인수 개수 / 인수 ສະຕຣິງ_ຄ່າ ອີເມວ |
| 10 | UDP ສ້າງ |
| 11 | UDP ສົ່ງ(ຈັດ_ການ_ຄ່າ, IP, ປາຍທາງ_ຄ່າ ຜອດ_ຄ່າ, ການຈັດຄ່າຮອບວຽນ_ຄ່າ ອີເມວ, ຄວາມຍາວ_ຄ່າ) |
| 12 | UDP 받기(ຈັດ_ການ_ຄ່າ, ການຈັດຄ່າຮອບວຽນ_ຄ່າ ອີເມວ, 제한 밀리초) |
| 13 | UDP ປິດ |
| 14 | ໃນເຄື່ອງ_ຂອບ_ເຂດ IP ອີເມວ |
| 15 / 16 | 마지막 ລຸ້ນດຽວກັນ_ຄ່າ IP / UDP ຜອດ_ຄ່າ |
| 20 | RAM ຟາຍ 읽기(ຊື່ int[] ອີເມວ, 출력 int[] ອີເມວ) |
| 21 | RAM ຟາຍ ຂຽນ(ຊື່ int[] ອີເມວ, 입력 int[] ອີເມວ, ໄບ_ຄ່າ ຄວາມຍາວ_ຄ່າ) |
| 22 | UTF-16 ລະຫັດ_ຄ່າ ບົດຮຽນ_ຄ່າ 문자 출력(0~65535) |

ຟາຍ API는 `ຜູ້ໃຊ້.파일읽기(int[] ຊື່, int[] ຂໍ້ມູນ)`와 `ຜູ້ໃຊ້.ຂຽນ_ຟາຍ(int[] ຊື່, int[] ຂໍ້ມູນ, int ຄວາມຍາວ_ຄ່າ)`다. 이름은 ASCII ລະຫັດ_ຄ່າ ການຈັດຄ່າຮອບວຽນ_ຄ່າ(최대 64칸, 0 ອອກ_ແອັບ 또는 ການຈັດຄ່າຮອບວຽນ_ຄ່າ 끝), ຂໍ້ມູນ ລາຍການ_ອົງປະກອບ 하나는 한 바이트다. 반환값은 읽거나 쓴 길이이며 ຟາຍ 없음 `-2`, ລູກສອນເມົ້າ ຂໍ້ຜິດພາດ `-14`, ຊື່/ຄວາມຍາວ_ຄ່າ ຂໍ້ຜິດພາດ `-22`, ຟາຍ ຊ່ອງ_ຄ່າ 부족 `-28`, ຂະ_ຫນາດ 초과 `-90`을 반환한다. 쓰기는 ຮັບ_ຮອງ 후 ຟາຍ 전체를 대체한다. `ຜູ້ໃຊ້.ຂຽນ_ຕົວອັກສອນ_ຄ່າ(int)`는 문자를 단말에 출력한다. Java 프로그램의 일반 `java.io` 구현은 아니다.

`실행권한()`은 시스템 호출이 아니라 ຜູ້ໃຊ້ 모드에서 CS의 하위 비트를 직접 읽으므로 ຕົວ_ຈິງ_ຂໍ້ມູນ ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 권한을 확인한다. ແກນກາງ_ຄ່າ 포트 접근용 `ມືຖື_ຄ່າ` native 함수는 ຜູ້ໃຊ້ ເປົ້າ_ຫມາຍ 컴파일에서 거부한다. ELF에 직접 특권 명령을 넣더라도 CPU가 차단한다.

## 범위와 제한

- 한 번에 한 프로그램만 실행하며 완료 후 셸로 돌아온다. 백그라운드 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ, 파이프, 프로세스 간 통신은 없다. ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 파일은 커널의 읽기 전용 JKAP 묶음에서 적재한다. ຂໍ້ມູນ 파일에는 주기억 파일체계와 전용 IDE 보존 형식이 있다.
- ຜູ້ໃຊ້ 가상 ອີເມວ `0x04000000..0x043fffff`를 물리 8~12MiB에 연결한다. ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 영상은 ດ້ານຫນ້າ_ຄ່າ 2MiB, 인수는 `0x04300000`부터, 스택은 영역 끝에서 시작한다. ແກນກາງ_ຄ່າ identity 페이지는 supervisor 전용이다.
- 실행마다 4MiB ຜູ້ໃຊ້ 영역을 비우고 ຟາຍ 구역을 복사해 BSS·ການຈັດຄ່າຮອບວຽນ_ຄ່າ 영역을 초기화한다. ຜູ້ໃຊ້ GC는 없지만 ອອກ_ແອັບ 후 ຕໍ່ໄປ_ລາຍການ ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 때 영역을 재사용한다. 인수는 공백으로 분리한 최대 16개이며 ອ້າງອີງ/이스케이프 파싱은 없다.
- ຜູ້ໃຊ້ 페이지의 ລະຫັດ_ຄ່າ/ຂໍ້ມູນ 분리 읽기 전용 ການຕັ້ງຄ່າ, NX, 스택 guard, ASLR은 아직 없다. 커널과 ຜູ້ໃຊ້ ຄວາມຈໍາ_ຂໍ້ມູນ·포트 ການອະນຸຍາດ_ຄ່າ 경계를 구현한 초기판이지 보안 인증된 샌드박스는 아니다.
- PIT 100Hz로 약 3초 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 상한을 두며 ເວລາ_ຄ່າ 초과는 `Exit: 124`다. ຜູ້ໃຊ້ CPU 예외는 `128 + ຂໍ້ຍົກເວັ້ນ ດັດຊະນີ`(페이지 ຂໍ້ຜິດພາດ 142, 특권 위반 141), Java ການຈັດຄ່າຮອບວຽນ_ຄ່າ/계산 오류는 101~105다. ແກນກາງ_ຄ່າ 오류까지 복구하는 구조는 아니다.
- 네트워크는 PCI bus 0/function 0의 RTL8139, ກໍານົດເອງ_ຄ່າ IPv4, ARP, UDP만 지원한다. NIC는 폴링하고 송신은 동기식이다. IPv4 단편 재조립·TCP·DNS·DHCP·IPv6·HTTP·TLS·일반 `java.net`은 미지원이다. IPv4 UDP 검사합 0은 규약에 따라 허용하고, 그 외 UDP/IP 검사합과 길이는 검증한다.
- ຜູ້ໃຊ້ ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ·네트워크·ປົກປ້ອງ_ຄ່າ 경계 전체 시험은 QEMU에서 수행했다. VirtualBox에서도 `make vbox`로 부팅과 `run hello vbox`의 ring 3 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ·정상 종료를 확인했다. VirtualBox PCnet/E1000용 드라이버는 없어 그 환경의 네트워크는 지원하지 않는다.

## ຮັບ_ຮອງ 근거

`make test`는 컴파일러 14개 시험, Java 패킷 ເງື່ອນໄຂ 2,201개 검사, 기존 ເຊລ ELF/ISO 부팅 시험, ຜູ້ໃຊ້ ELF/ຕົວ_ຈິງ_ຂໍ້ມູນ UDP/ປົກປ້ອງ_ຄ່າ 경계 시험을 실행한다. 네트워크 시험은 루프백 서버가 받은 자료의 ຄວາມຍາວ_ຄ່າ·해시까지 `os/build/사용자통신시험.json`에 기록한다. 시험용 손상된 ELF·특권 ຄໍາສັ່ງ_1f12b8e2·무한 ສະປຣິນ_ຄ່າ 프로그램은 임시 묶음에만 넣으며 배포용 `apps` 목록에는 넣지 않는다.
