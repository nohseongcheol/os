# 자체 ARM64 ແກນກາງ_ຄ່າ: FTP, C, JAR와 AOT ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ

대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT ແກນກາງ_ຄ່າ**이다. CPU·ມືຖື_ຄ່າ 경계는 C/어셈블리, ຟາຍ 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 ໂຮສ JVM으로 대신 실행하지 않는다.

## 먼저 알아둘 ການຮອງຮັບ_ຄ່າ 경계

| 요청 | 이번 구현 | 남은 ຄ_ລິບ |
|---|---|---|
| JAR를 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 파일처럼 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ | `java -jar ຟາຍ.jar`, `./ຟາຍ.jar 인수`; Main-Class와 ຮ້ານຄ້າ_ຄ່າ/DEFLATE ZIP, CRC 검사 | 전체 Java SE, 임의의 모든 JAR 호환성 |
| 게스트 AOT | `jaot ຟາຍ.class -o ຟາຍ.elf`, `jaot ຟາຍ.jar -o ຟາຍ.elf`; ຕົວ_ຈິງ_ຂໍ້ມູນ ARM64 기계어 ສ້າງ_167eff27 | ວັດ_ຖຸ_ຄ່າ·ຂໍ້ຍົກເວັ້ນ·Thread·Swing·Socket의 AOT 변환, 여러 애플리케이션 ປະເພດສິ່ງຂອງ_ຄ່າ ເຊື່ອມຕໍ່ |

| FTP | 게스트 서비스, 패시브 ໂອນ_ຄ່າ, UTF-8 ຊື່, STOR/RETR/SIZE/LIST/NLST/MLSD/DELE | TLS·사용자별 ການອະນຸຍາດ_ຄ່າ·하위 디렉터리·영속 ຮ້ານຄ້າ_ຄ່າ |

JVM은 ປະເພດສິ່ງຂອງ_ຄ່າ 버전 45…52의 문서화한 부분집합이다. `java`는 바이트코드 실행기이고, `jaot`가 별도의 네이티브 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 파일을 만든다. **JAR ການສໍາເນົາ_ຄ່າ 해제나 JVM을 함께 묶는 것을 AOT라고 표시하지 않는다.** 지원하지 않는 바이트코드/API는 `jaot`가 진단하고 출력을 만들지 않는다. 기존 출력 ELF도 ສ້າງ_ແຫຼ່ງທີ່ມາ ຫຼົ້ມເຫຼວ_ຄ່າ 때 보존한다.

Android의 Dalvik/ART는 일반 JVM ປະເພດສິ່ງຂອງ_ຄ່າ/JAR가 아닌 **DEX**를 실행한다. ART의 AOT에는 GC, ປະເພດສິ່ງຂອງ_ຄ່າ 로딩, JNI 등 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 기반도 필요하다. 따라서 ART처럼 기계어로 바꾸는 기능만으로 임의의 OpenJDK JAR 및 Swing이 자동 호환되지는 않는다. [Android 공식 런타임 설명](https://source.android.com/docs/core/runtime)

FTP는 루트 RAM 파일만 공개한다. 익명 로그인이며 비밀번호로 권한을 구분하지 않는다. ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ ໂຮສ 바인딩은 `127.0.0.1`이고, ຄວບຄຸມ_ຄ່າ 포트는 2121, 데이터 포트는 50000…50007이다. `--ftp-port 2122`로 ຄວບຄຸມ_ຄ່າ 포트를 바꿀 수 있다. 동시에 한 FTP 세션을 제공하며 명령이 없는 세션은 60초 후 닫는다. TYPE A도 바이트를 변경하지 않으므로 프로그램은 바이너리 전송한다.

파일은 **64개, 각각 16 KiB**, 경로는 UTF-8 63바이트이다. 부팅 시 준비되는 `/example`도 이 한도를 공유한다. 초과/끊어진 STOR는 기존 파일에 반영하지 않는다. FTP 업로드는 RAM에만 저장되며 재부팅하면 사라진다. 이 제한 때문에 일반적인 대형 JAR 배포판을 그대로 올릴 수 없다.

QEMU의 raspi4b에는 GENET Ethernet 장치가 없다. 따라서 `network_bridge.py`가 QEMU NAT의 Ethernet과 보조 UART의 SLIP를 변환한다. **TCP ເຊື່ອມຕໍ່ ຂະ_ບວນ_ການ_ຄ່າ_ເຂົ້າໃນ·체크섬·재전송·FTP 명령과 ຟາຍ 저장은 게스트 안에서 수행한다.** ໂຮສ 브리지는 FTP 서버가 아니다. [QEMU 공식 ມືຖື_ຄ່າ ການຮອງຮັບ_ຄ່າ ເຂົ້າໃນ_ລາຍຊື່](https://www.qemu.org/docs/master/system/arm/raspi.html)

이 경로는 QEMU에서 검증했다. 보조 UART의 ຕົວ_ຈິງ_ຂໍ້ມູນ Pi 4 핀/클럭 설정과 내장 RJ45 GENET 드라이버는 구현·검증하지 않았으므로, SD 이미지에 커널이 포함되어 있다는 사실을 ຕົວ_ຈິງ_ຂໍ້ມູນ 보드의 LAN/FTP ຄໍາສັ່ງ 보장으로 해석하면 안 된다.

## 한국어 Java를 게스트에서 컴파일하고 AOT ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ

게스트 `vi 빛.java`로 ຕໍ່ໄປ_ລາຍການ 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] 인수) throws Exception {
        int 합 = 0;
        int 수 = 1;
        while (수 <= 10) {
            합 = 합 + 수;
            수 = 수 + 1;
        }
        한국어.자체.출력.수쓰기(합);
        한국어.자체.ຟາຍ.ຂຽນ("aot.txt", "한글 AOT ຟາຍ 😀");
        한국어.자체.출력.ຂຽນ_ສາຍ(한국어.자체.ຟາຍ.읽기("aot.txt"));
    }
}
```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 ສ້າງ_167eff27·연결한다. ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 ການຮອງຮັບ_ຄ່າ 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 ກໍານົດເອງ_ຄ່າ ວິ_ທີ_ຄ່າ/ຊ່ອງຂໍ້ມູນ_ຄ່າ, int 계열, ຕົວເລກຈໍານວນເຕັມ 배열과 ການ_ອ້າງ_ອີງ, 인수 ການຈັດຄ່າຮອບວຽນ_ຄ່າ, ເງື່ອນໄຂ·ສາຂາ·ສະປຣິນ_ຄ່າ, ສະຕຣິງ_ຄ່າ 리터럴, `System.out.print/println`의 int/String, 한국어 출력·ຟາຍ 읽기/쓰기로 제한된다. ປະເພດສິ່ງຂອງ_ຄ່າ/ວິ_ທີ_ຄ່າ 수와 스택 등에도 고정 상한이 있다. Java ຂໍ້ຍົກເວັ້ນ ຂະ_ບວນ_ການ_ຄ່າ_ເຂົ້າໃນ, ວັດ_ຖຸ_ຄ່າ ສ້າງ_167eff27, 가상 ວິ_ທີ_ຄ່າ 일반, switch/wide, long/float/double, invokedynamic, ສະຕຣິງ_ຄ່າ 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 ການຈັດຄ່າຮອບວຽນ_ຄ່າ ເຂົ້າຫາ_ເຂົ້າໃນ/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java ຂໍ້ຍົກເວັ້ນ 객체로 전달하지 않는다.

입력 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 ຈັດແຖວ_ຄ່າ 때문에 짧은 클래스도 이 한도를 넘을 수 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 ວັດ_ຖຸ_ຄ່າ·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 ການຮອງຮັບ_ຄ່າ ຄ_ລິບ 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 개발 매뉴얼](개발안내.md)을 참고한다.

JAR는 하나의 애플리케이션 ປະເພດສິ່ງຂອງ_ຄ່າ 경로다. 내부 ຊື່ `ຊຸດ/ແອັບ_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 한국어 클래스를 추가로 찾지만 현재 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·ກົດລັບ_ຂໍ້ມູນ ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 수/VM 힙 제한은 그대로 적용된다.

## C에서 한국어 POSIX 호출

게스트에서 `vi 인사.c`로 작성하거나 FTP로 소스를 업로드한다.

```c
#include <파일규약.h>

int main(void) {
    const char 인사말[] = "자체 ARM64 C에서 한글 POSIX 호출\n";
    int 문서 = ສ້າງ_ຟາຍ("인사.txt", ອ່ານ_ຂຽນ | 없으면만들기 | 내용비우기, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = ຂຽນ_ຟາຍ_ຂໍ້ມູນ(문서, 인사말, sizeof(인사말) - 1);
    ປິດ_ຟາຍ(문서);
    ຂຽນ_ຟາຍ_ຂໍ້ມູນ(1, 인사말, sizeof(인사말) - 1);
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

```text
cc 인사.c -o 인사.elf
run 인사.elf
cat 인사.txt
```

TinyCC의 표준 C ເຂົ້າໃນ_ຈຸດ `main`을 사용한다. 기존 ໂຮສ C/C++ SDK의 `ເລີ່ມ_ຜູ້ໃຊ້_ແອັບ(int)` 진입점과 구분한다. 포함 ຟາຍ·ແລ່ນ ວັດ_ຖຸ_ຄ່າ·`libposix-kor-user.a`는 컴파일러 내부의 읽기 전용 SDK에 들어 있다. C 전처리기/구조체/ຟັງ_ຄ໌_ຊັນ_ຄ່າ/재귀/ລູກສອນເມົ້າ/부동소수점 ສ້າງ_167eff27 등을 사용하되 **일반 libc/libstdc++를 제공한다는 뜻은 아니다**. 제공하지 않는 함수는 ເຊື່ອມຕໍ່ 오류가 난다. 컴파일러 자체의 문자/ຕົວເລກ_ຄ່າ 변환 지원도 완전한 libc 대체품이 아니다.

`ສ້າງ_ຟາຍ` 등은 별도의 모의 호출이 아닌 기존 `pk_open` 등의 한국어 매크로이며, ELF의 SVC를 통해 ຕົວ_ຈິງ_ຂໍ້ມູນ Java ຟາຍ 체계에 도달한다. ຟາຍ/소켓 호출 목록은 [ຜູ້ໃຊ້ ABI](사용자호출규약.md)에 있다. C/C++ ໂຮສ SDK ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 파일도 FTP로 업로드 후 `run` 또는 `./ຟາຍ`로 실행하며 확장자는 필요 없다. Linux ARM64 ກໍານົດເອງ_ຄ່າ ELF에는 별도의 제한된 호환 ທາງໂຄຈອນ `run --linux ຟາຍ`을 추가했다. [ELF·Linux ABI 매뉴얼](실행파일규약.md)에 정확한 ຮູບແບບ_ຄ່າ_d1a42ea5·시스템 호출·ອີເມວ 제한을 정리했다.

## 한국어 네트워크·작업·화면 API

| ປະເພດສິ່ງຂອງ_ຄ່າ | 호출 예 | ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ ທາງໂຄຈອນ |
|---|---|---|
| `출력` | `ຂຽນ_ສາຍ("안녕")`, `수쓰기(42)` | JVM 및 제한형 AOT |
| `ຟາຍ` | `ຂຽນ("문서.txt", "ເນື້ອໃນ_ຄ່າ_cb0f2404")`, `읽기("문서.txt")` | JVM 및 제한형 AOT |
| `통신` | `ສ້າງ(0)`, `ສົ່ງ(종단, "10.0.2.2", 9000, "한글")`, `받기(종단)` | JVM의 UDP |
| `연결통신` | `ເຊື່ອມຕໍ່("10.0.2.2", 9000)`, `듣기(9000)`, `받기(서버)` | JVM의 Socket/ServerSocket |
| `작업` | `ແລ່ນ(Runnable)`, `기다리기(Thread)`, `ລະງັບ_ຫນ້າວຽກ()` | JVM의 협력식 ສອດຕໍ່_ຄ່າ |
| `ວິນໂດ`, `ວິດເຈັດ` | ວິນໂດ·버튼·ຕົວອັກສອນ_ຄ່າ·ຂໍ້ຄວາມ_ຊ່ອງຂໍ້ມູນ·ງານ ເຊື່ອມຕໍ່ | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 한국어 호출 계층을 추가한다. `통신(通信)`, `ເຊື່ອມຕໍ່(連結)`, `출력(出力)`은 기존 단어의 뜻을 사용한다. `작업 ສອດຕໍ່_ຄ່າ`은 한 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 흐름을 가닥에 빗댄 기술 표현, `ຜອດ_ຄ່າ`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

외부 주소는 ຕົວເລກ_ຄ່າ IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 자체 ABI이며 JVM이 제한된 ລໍຖ້າ_ຄ່າ/재시도를 제공한다. TCP connect 대기는 최대 1초, ຜູ້ໃຊ້ ແອັບ_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ ຜູ້ໃຊ້ 서버와 pthread는 아직 없다. FTP는 ຜູ້ໃຊ້ ແອັບ_f5044b9b 기한과 별개인 ແກນກາງ_ຄ່າ 서비스다.

게스트의 ຜູ້ໃຊ້ TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 ເຄື່ອງມື/ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ ຄວບຄຸມ_ຄ່າ/데이터 포트와 겹치면 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 전에 거부한다.

## 시험과 ສ້າງ_ລະບົບ 재현

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test-ftp
make test
make image
```

`build/verification/ftp/report.json`은 ຕົວ_ຈິງ_ຂໍ້ມູນ FTP ໂອນ_ຄ່າ, 한글 ຟາຍ, ຂະ_ຫນາດ 초과 보존, ການສໍາເນົາ_ຄ່າ JAR ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ, 게스트 C ສ້າງ_ແຫຼ່ງທີ່ມາ/ELF 재업로드, 외부 Java TCP/UDP, 게스트 javac/AOT 실행을 기록한다. `serial.log`에서 게스트 명령과 결과를 확인할 수 있다. 보고서의 ແກນກາງ_ຄ່າ SHA-256과 배포 이미지의 커널을 비교한다.

빌드는 기존 JDK/Clang/AArch64 binutils와 함께 `../rpi4/build/rootfs`의 ARM64 SDK ການປະກາດ 헤더와 libgcc 산술 보조 함수를 사용한다(`make rpi-prepare`). **musl libc, Linux ແກນກາງ_ຄ່າ, 동적 로더를 게스트에 링크하지 않는다.** TinyCC/lwIP/uzlib 원본과 라이선스·버전 정보는 `vendor/`, 이식 코드는 `ccompiler/`, `network/`, `ຜູ້ໃຊ້/ຊຸດ.c`에 있다.

전체 JDK/AOT JVM으로 확장하려면 타입 ຮັບ_ຮອງ·ວັດ_ຖຸ_ຄ່າ/ຂໍ້ຍົກເວັ້ນ/GC·동적 로딩·JNI, 영속 ຟາຍ ລະບົບປະຕິບັດການ_ຄ່າ·mmap/TLS/시그널·스레드 ABI, OpenJDK native ຫໍສະຫມຸດ, GUI peer/폰트/입력기, GENET 및 실물 ມືຖື_ຄ່າ 검증이 더 필요하다. 이 문서의 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 시험은 그 전체 이식을 대신하지 않는다.
