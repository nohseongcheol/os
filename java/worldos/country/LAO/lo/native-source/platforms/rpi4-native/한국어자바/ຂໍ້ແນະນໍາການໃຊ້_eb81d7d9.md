# 한국어 Java 통신·ໄອ_ໂອ·ຂໍ້ຍົກເວັ້ນ API

패키지는 `한국어.자체`다. ໂຮສ `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·ຟາຍ·ຂໍ້ຍົກເວັ້ນ API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 ສອດຕໍ່_ຄ່າ API는 자체 JVM 전용이다.
기존 표준 Java ຫໍສະຫມຸດ 전체의 한국어 번역판은 아니다.

```java
import 한국어.자체.*;

public class ເຄືອຂ່າຍ {
    public static void main(String[] 인수) throws ໄອ_ໂອ_ຂໍ້ຍົກເວັ້ນ {
        ການເຊື່ອມຕໍ່ ເຊື່ອມຕໍ່ = ການເຊື່ອມຕໍ່.ສ້າງ("10.0.2.2", 9000);
        try {
            ເຊື່ອມຕໍ່.대기시간(700);
            ເຊື່ອມຕໍ່.출력().ຂຽນ(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = ເຊື່ອມຕໍ່.입력();
            출력.수쓰기(입력.읽기());
        } catch (대기시간초과예외 ຂໍ້ຜິດພາດ) {
            출력.ຂຽນ_ສາຍ(ຂໍ້ຜິດພາດ.설명());
        } finally {
            ເຊື່ອມຕໍ່.ປິດ();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
ຜູ້ໃຊ້ 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 ສະຕຣິງ_ຄ່າ 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void ແລ່ນ()`도 진입점으로 받는다.

## 통신과 ສະຕຣີມ_ຄ່າ

| ປະເພດສິ່ງຂອງ_ຄ່າ | 한국어 호출 |
|---|---|
| ການເຊື່ອມຕໍ່ | `ສ້າງ(ອີເມວ, ຫມາຍເລກພອດ)`, `입력()`, `출력()`, `대기시간(밀리초)`, `ຫມາຍເລກພອດ()`, `ໃນເຄື່ອງ_ຫມາຍເລກພອດ()`, `연결됨()`, `닫힘()`, `ປິດ()` |
| 수신창구 | `ສ້າງ(ຫມາຍເລກພອດ)`, `받기()`, `ຫມາຍເລກພອດ()`, `대기시간(밀리초)`, `닫힘()`, `ປິດ()` |
| 입력흐름 | `읽기()`, `읽기(byte[])`, `읽기(byte[], ແລ່ນ, ຄວາມຍາວ_ຄ່າ)`, `ປິດ()` |
| 출력흐름 | `ຂຽນ(int)`, `ຂຽນ(byte[])`, `ຂຽນ(byte[], ແລ່ນ, ຄວາມຍາວ_ຄ່າ)`, `내보내기()`, `ປິດ()` |
| 전문통로 | `ສ້າງ(ຫມາຍເລກພອດ)`, `ສົ່ງ(ອີເມວ, ຫມາຍເລກພອດ, ຂໍ້ຄວາມ)`, `받기()`, `대기시간(밀리초)`, `ຫມາຍເລກພອດ()`, `닫힘()`, `ປິດ()` |
| 연결통신 | `ສ້າງ(...)`, `수신열기(...)`는 위 한국어 객체를 반환 |
| 검사 | `참인지(ເງື່ອນໄຂ, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`읽기()`의 ຟາຍ 끝은 -1, ການຈັດຄ່າຮອບວຽນ_ຄ່າ 읽기의 반환값은 ຕົວ_ຈິງ_ຂໍ້ມູນ 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. ຫມາຍເລກພອດ 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 자체 커널에서 512바이트까지 받으며, 주소는 ຕົວເລກ_ຄ່າ IPv4를 사용한다.
`localhost` 루프백 외의 ຊື່ 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.ເຊື່ອມຕໍ່/듣기/받기`, `통신.ສ້າງ/ສົ່ງ/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `ການເຊື່ອມຕໍ່`, `수신창구`, `전문통로`를 쓴다.

## 한국어 ຂໍ້ຍົກເວັ້ນ

모든 아래 클래스는 ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ 생성자, `새예외("설명")` 형태의 ສະຕຣິງ_ຄ່າ 생성자와
`설명()`을 제공한다. ຕົວ_ຈິງ_ຂໍ້ມູນ ສ້າງ_167eff27 문법은 `new 대기시간초과예외("ລໍຖ້າ_ສະຖານະ 끝")`이다.

| 한국어 ຂໍ້ຍົກເວັ້ນ | 상위 ປະເພດສິ່ງຂອງ_ຄ່າ / 용도 |
|---|---|
| ຂໍ້ຍົກເວັ້ນ | `java.lang.Exception`, 직접 던지는 일반 검사 ຂໍ້ຍົກເວັ້ນ |
| 실행예외 | `java.lang.RuntimeException` |
| ໄອ_ໂອ_ຂໍ້ຍົກເວັ້ນ | `java.io.IOException`, 한국어 ຟາຍ·통신 API의 검사 ຂໍ້ຍົກເວັ້ນ |
| 대기시간초과예외 | `ໄອ_ໂອ_ຂໍ້ຍົກເວັ້ນ`, 통신 대기시간 초과 |
| ອີເມວ_ຄົ້ນຫາ_ຂໍ້ຍົກເວັ້ນ | `ໄອ_ໂອ_ຂໍ້ຍົກເວັ້ນ`, ອີເມວ 확인 ຫຼົ້ມເຫຼວ_ຄ່າ |
| 파일없음예외 | `ໄອ_ໂອ_ຂໍ້ຍົກເວັ້ນ`, ຟາຍ ສ້າງ ຫຼົ້ມເຫຼວ_ຄ່າ |
| 통신예외 | `ໄອ_ໂອ_ຂໍ້ຍົກເວັ້ນ`, 표준 SocketException 변환 |
| ໃຊ້ບໍ່ໄດ້_ຂໍ້ພິສູດ_ຂໍ້ຍົກເວັ້ນ | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `ໃຊ້ບໍ່ໄດ້_ຂໍ້ພິສູດ_ຂໍ້ຍົກເວັ້ນ` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| ບໍ່ມີຄ່າ_ການ_ອ້າງ_ອີງ_ຂໍ້ຍົກເວັ້ນ | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| ສະຖານະ_ຂໍ້ຍົກເວັ້ນ | `java.lang.IllegalStateException` |
| ພິມ_ສົ່ງສັນຍານ_ຂໍ້ຍົກເວັ້ນ | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| ການຈັດຄ່າຮອບວຽນ_ຮ້ານຄ້າ_ຫຼົ້ມເຫຼວ | `java.lang.ArrayStoreException` |
| ສອດຕໍ່_ສະຖານະ_ຂໍ້ຍົກເວັ້ນ | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 ລໍຖ້າ_ຄ່າ 중단 |

`ຂໍ້ຍົກເວັ້ນ`와 `실행예외`는 모든 한국어 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, ຟາຍ·통신 전체를 잡으려면 `catch (ໄອ_ໂອ_ຂໍ້ຍົກເວັ້ນ ຂໍ້ຜິດພາດ)`를 쓴다.
한국어 API가 표준 ໄອ_ໂອ 오류를 한국어 예외로 변환한다.
기존 한국어 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
ຂໍ້ຍົກເວັ້ນ 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 자체 JVM에 이 20종을 추가했다. 임의의 ຜູ້ໃຊ້ Throwable 하위 ປະເພດສິ່ງຂອງ_ຄ່າ 전체를
지원하도록 확장했다는 뜻은 아니다.

## ສ້າງ_ແຫຼ່ງທີ່ມາ·ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make ສ້າງ_ລະບົບ
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 ເຄື່ອງມື/ປະ_ຕິ_ບັດ_ຟາຍ.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 ຜູ້ໃຊ້ JVM ELF 안에 탑재된다. `.jar`는 ໂຮສ javac의
ປະເພດສິ່ງຂອງ_ຄ່າ 경로로 사용한다. ແຫຼ່ງທີ່ມາ_ຕົ້ນໄມ້ 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 한국어 예외의 `throws` 선언과 그 import를 인식한다.
자체 JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·ວັດ_ຖຸ_ຄ່າ·소켓 예제 전체의 ແຫຼ່ງທີ່ມາ_ຕົ້ນໄມ້ 컴파일은 ໂຮສ javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 수 있다.

ຕົວ_ຈິງ_ຂໍ້ມູນ TCP/UDP 예제는 [네트워크예제.java](../../../example/java/네트워크예제.java),
ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 절차는 [example ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9](../../../example/README.md),
ແຫຼ່ງທີ່ມາ_ຕົ້ນໄມ້ 명명 원칙은 [명명 ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9](../명명/ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9.md)에 있다.

## Swing ວິນໂດ 예제

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` ຕໍ່ໄປ_ລາຍການ `java 창예제`로 연다. ຊື່ 입력, 인사하기 버튼,
인사말과 ກົດ_ຄ່າ 횟수 ລຶ້ມຄືນໃຫມ່, X 닫기를 지원한다.

| 기능 | 한국어 직접 API |
|---|---|
| Runnable / run | `실행할일.ປະ_ຕິ_ບັດ_ຫນ້າວຽກ()` |

| ActionEvent | `동작알림.ຄໍາສັ່ງ_ຂໍ້ຄວາມ()`, `ງານ_ແຫຼ່ງທີ່ມາ()`, `ດັດຊະນີ()` |
| JFrame | `ວິນໂດ(ວິນໂດ_ຊື່, 폭, 높이)`, `ເພີ່ມ_ອົງປະກອບ(화면구성요소)`, `ລາຍການ_ວິນໂດ()`, `ປິດ()`, `보이는가()` |
| JButton | `ປຸ່ມ(ຂໍ້ຄວາມ, 가로, ລວງຕັ້ງ_ຈັດຕໍາແຫນ່ງ, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `ປ້າຍ(...)`, `ຂໍ້ຄວາມ_ຊ່ອງຂໍ້ມູນ(...)` |
| 공통 화면 ອົງປະກອບ_ຄ່າ | `화면구성요소.글읽기()`, `ຂຽນ_ຂໍ້ຄວາມ(ຂໍ້ຄວາມ)`, `자리정하기(가로, ລວງຕັ້ງ_ຈັດຕໍາແຫນ່ງ, 폭, 높이)` |
| SwingUtilities.invokeLater | `ງານ_ຄິວ.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `ເລີ່ມ_ຫນ້າວຽກ()`, `기다리기()`, `살아있는가()`, `ລະງັບ_ຫນ້າວຽກ()` |
| 명령행 | `ແລ່ນ()`, `실행인수.개수()`, `실행인수.ຂໍ້ຄວາມ(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `ຂະ_ບວນ_ການ_ສອດຕໍ່`가 한국어 ປະເພດສິ່ງຂອງ_ຄ່າ·ວິ_ທີ_ຄ່າ·서술자를
해석해 화면 요소와 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 가닥을 직접 만든다. ຄໍາສັ່ງ 알림도 자체 객체이며
콜백으로 `ປະ_ຕິ_ບັດ_ຫນ້າວຽກ`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 ໂຮສ JVM에서 무동작 객체가 생기지 않도록 하는 ປະຕິເສດ_ຄ່າ 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. ໂຮສ javac로 컴파일한 ກັບ_ຄືນ_ຄ່າ 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import 한국어.자체.*;
public class 가닥예제 implements 실행할일 {
    public void ປະ_ຕິ_ບັດ_ຫນ້າວຽກ() { 출력.ຂຽນ_ສາຍ("한국어 작업 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ"); }
    public static void ແລ່ນ() throws 대기중단예외 {
        작업가닥 ສອດຕໍ່_ຄ່າ = 작업.ແລ່ນ(new 가닥예제());
        작업.기다리기(ສອດຕໍ່_ຄ່າ);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
ການຈັດຄ່າຮອບວຽນ_ຄ່າ 인수 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 인수 없는 `ແລ່ນ()`을 우선한다.
기존 한국어 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.ແລ່ນ(Runnable)`을 사용하던 코드는 새 한국어 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API ການຮອງຮັບ_ຄ່າ 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 ປະເພດສິ່ງຂອງ_ຄ່າ·ວິ_ທີ_ຄ່າ 이름과 서술자가 남는다.
한국어 ຊື່ 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·ວິ_ທີ_ຄ່າ 재정의, native ເຊື່ອມຕໍ່, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS ຕົວ_ກໍາ_ນົດ_ຄ່າ](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS ວິ_ທີ_ຄ່າ ການ_ອ້າງ_ອີງ](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
