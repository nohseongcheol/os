# jkoros 안에서 Java ສ້າງ_ແຫຼ່ງທີ່ມາ·ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ

이 문서의 부팅·ເຊລ·ຮ້ານຄ້າ_ຄ່າ 명령은 **x86 판** 기준이다. 공유 Java 컴파일러/JVM은 [자체 ARM64 Pi4 판](../platforms/rpi4-native/README.md)에도 연결되어 있다. ARM64에서는 UTF-8 UART 입력·한글 ຟາຍ_ຊື່_ຂໍ້ຄວາມ, `edit`의 단독 `.` ຮ້ານຄ້າ_ຄ່າ, 16개 RAM ຟາຍ, 약 2초 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 제한을 사용한다.

`javac FILE.java`와 `java CLASS [ARGS]`를 네이티브 jkoros 셸에서 실행한다. 컴파일러와 JVM은 각각 독립 ELF로 적재되어 ring 3에서 동작한다. 소스를 게스트에서 읽어 ຕົວ_ຈິງ_ຂໍ້ມູນ JVM `.class` 파일을 만들고, 그 파일의 바이트코드를 게스트 JVM이 해석한다. ໂຮສ ສ້າງ_ແຫຼ່ງທີ່ມາ 서버나 Linux 게스트는 사용하지 않는다.

**현재 구현은 자체 제한형 컴파일러·JVM이다. OpenJDK/JDK 전체를 이식하거나 설치한 것이 아니며 Java SE 호환 환경도 아니다.** 표준 라이브러리는 아래의 일부 호출을 구현한 것이다. `java -version`과 `javac -version`에도 이 범위를 표시한다. 일반 JAR, Maven/Gradle, 임의의 Java ແອັບ_f5044b9b 실행은 아직 지원하지 않는다.

## 바로 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ

호스트에서:

```sh
cd /home/user/jkoros
make iso
make run
```

게스트에서:

```text
jkoros> javac -version
jkoros> java -version
jkoros> ls
jkoros> cat Hello.java
jkoros> javac Hello.java
Compiled: Hello.class (JVM class version 49)
Exit: 0
jkoros> java Hello
Hello from jkoros JVM!
55
Exit: 0
```

ISO는 `os/build/kernel.iso`다. 기존 VirtualBox 실행기도 같은 ISO를 사용한다. ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 중이거나 저장된 VM에는 새 ISO가 자동 반영되지 않는다. 새 부팅 절차는 [VirtualBox ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9](가상상자실행.md)를 따른다. 이 변경의 Java 자동 시험은 QEMU에서 수행했다.

## 직접 작성

`edit`는 ຟາຍ 전체를 새 내용으로 작성한다. 기존 내용의 ສາຍ ແກ້ໄຂ_ຄ່າ 기능은 아니다. `.save`로 저장하고 `.cancel`로 취소한다.

```text
jkoros> edit Demo.java
...> public class Demo {
...>  public static int square(int n) { return n * n; }
...>  public static void main(String[] args) {
...>   int n = Integer.parseInt(args[0]);
...>   System.out.println("square=" + square(n));
...>  }
...> }
...> .save
jkoros> javac Demo.java
jkoros> java Demo 12
square=144
Exit: 0
```

- `ls`: 파일과 ໄບ_ຄ່າ 수 ລາຍການ_ຄ່າ.
- `cat FILE`: ຟາຍ ເນື້ອໃນ_ຄ່າ_cb0f2404 ລາຍການ_ຄ່າ. 텍스트 소스에 사용한다.
- `rm FILE`: ຄວາມຈໍາ_ຂໍ້ມູນ ຟາຍ 삭제.
- `edit FILE`: 전체 내용을 새로 입력. 빈 파일도 저장할 수 있다.
- 구문·ພິມ_ຄ່າ 검사 ຫຼົ້ມເຫຼວ_ຄ່າ 시 기존 `.class`는 유지된다. 소스를 고친 ກັບ_ຄືນ_ຄ່າ 컴파일이 실패했다면 이전 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 파일이 남아 있으므로 ສ້າງ_ແຫຼ່ງທີ່ມາ 성공 여부를 확인한다.

파일은 RAM에서 동작한다. 전용 ຮ້ານຄ້າ_ຄ່າ 매체가 없거나 `sync`하지 않은 내용은 재부팅하면 사라진다. `make -C os run-store`로 연결한 매체에는 `sync`로 ແຫຼ່ງທີ່ມາ_ຕົ້ນໄມ້·ປະເພດສິ່ງຂອງ_ຄ່າ·ຂໍ້ມູນ 파일을 보존할 수 있다. 최대 8개, 파일마다 16KiB, ຟາຍ 이름은 ASCII 1~63자다. ແຫຼ່ງທີ່ມາ_ຕົ້ນໄມ້ 이름은 `.class` 확장자 공간 때문에 최대 62자다. ແກ້ໄຂ_ຄ່າ 입력은 ASCII이고 한 ສາຍ 최대 128자다. ສາຍ 또는 ຟາຍ 한도를 넘긴 편집은 `.save`에서 거부하여 기존 파일을 보존한다. ແກນກາງ_ຄ່າ/컴파일러/JVM 구현의 Java 식별자는 한국어이며, 현재 게스트 입력 제한 때문에 ຜູ້ໃຊ້ 예제 이름은 ASCII로 작성한다.

## 외부 ຟາຍ 적재

호스트에서 만든 소스나 ການຮອງຮັບ_ຄ່າ ຄ_ລິບ 안의 `.class`를 부팅 이미지에 포함할 수 있다. `JAVA_FILES`는 `게스트이름=호스트경로` 목록이다. 아래의 경로는 예시이며 ຕົວ_ຈິງ_ຂໍ້ມູນ 파일의 절대 경로로 바꾼다. 공백 없는 경로를 사용한다.

```sh
# ໂຮສ JDK로 컴파일한 클래스도 사용할 수 있다.
javac --release 8 /tmp/Demo.java
make -C /home/user/jkoros iso \
  JAVA_FILES='Demo.java=/tmp/Demo.java Demo.class=/tmp/Demo.class'
make -C /home/user/jkoros run \
  JAVA_FILES='Demo.java=/tmp/Demo.java Demo.class=/tmp/Demo.class'
```

새 부팅 후 `java Demo 12`를 실행한다. 소스만 넣었으면 게스트에서 `javac Demo.java`부터 실행한다. `JAVA_FILES`를 생략한 ຕໍ່ໄປ_ລາຍການ 빌드에서는 추가 파일을 포함하지 않는다. ຟາຍ ເນື້ອໃນ_ຄ່າ_cb0f2404 변경과 ເຂົ້າໃນ_ລາຍຊື່ 제거도 ຕໍ່ໄປ_ລາຍການ 빌드에 반영된다. 원본 ໂຮສ 파일에는 쓰지 않는다. ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ `Hello.java`까지 합해 8개이며, 같은 이름을 명시하면 ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ 예제를 대체한다. 새 `.class`를 저장할 빈 슬롯도 남겨 둔다.

`--release 8`은 ປະເພດສິ່ງຂອງ_ຄ່າ ຟາຍ 버전을 맞추는 옵션이다. 사용하는 문법·바이트코드·라이브러리도 아래 ການຮອງຮັບ_ຄ່າ ຄ_ລິບ 안에 있어야 한다.

## ການຮອງຮັບ_ຄ່າ ຄ_ລິບ

| 기능 | 게스트 javac | 게스트 JVM |
| --- | --- | --- |
| ປະເພດສິ່ງຂອງ_ຄ່າ | 패키지 없는 단일 ປະເພດສິ່ງຂອງ_ຄ່າ, ກໍານົດເອງ_ຄ່າ ຟັງ_ຄ໌_ຊັນ_ຄ່າ, 재귀, 인수/반환 | 실행마다 단일 ປະເພດສິ່ງຂອງ_ຄ່າ 적재, public static main(String[]) |
| ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ ຄ່າ | int, boolean, char, String, main의 String[] 인수 | ຕົວເລກຈໍານວນເຕັມ·ການ_ອ້າງ_ອີງ 스택, String, int[], String[], 내부 StringBuilder |
| ຄໍາສັ່ງ_ຄ່າ | 초기값 있는 ໃນເຄື່ອງ_ຂອບ_ເຂດ ການປະກາດ, ວຽກ_ມອບ_ຫມາຍ_ຄ່າ, `+=`, `-=`, `*=`, `/=`, `%=`, 후위 ++/--, 블록, if/else, while, for, return | 해당 ຕົວເລກຈໍານວນເຕັມ·ການ_ອ້າງ_ອີງ 바이트코드와 ເງື່ອນໄຂ ສາຂາ |
| ສະແດງສົມຜົນ_ຄ່າ | 십진 ຕົວເລກຈໍານວນເຕັມ, UTF-8 소스의 ສະຕຣິງ_ຄ່າ/문자, + - * / %, 비교, ==/!=, !/&&/\|\|, ສະຕຣິງ_ຄ່າ 결합 | ຕົວເລກຈໍານວນເຕັມ ການຄໍານວນ_ຄ່າ·ບິດ_ຄ່າ ການຄໍານວນ_ຄ່າ·ພິມ_ຄ່າ 변환, 단락 평가, ການຈັດຄ່າຮອບວຽນ_ຄ່າ ເຂົ້າຫາ_ເຂົ້າໃນ |
| ຟາຍ | FileInputStream(String), FileOutputStream(String[, boolean]), read()/write(int)/close() | ຕົວ_ຈິງ_ຂໍ້ມູນ ແກນກາງ_ຄ່າ 파일서술자와 ເຊື່ອມຕໍ່, ສ້າງ_167eff27·ລ້າງ_ສາລະບານ·이어쓰기·EOF |
| 출력 | System.out.print/println: int/boolean/char/String, println() | 동일 |
| ສະຕຣິງ_ຄ່າ/인수 | String.length(), args.length, args[index], Integer.parseInt | 추가로 String.charAt(), ສະຕຣິງ_ຄ່າ 상수의 modified UTF-8 해독 |

선언은 지원하는 문법만 허용한다. 여러 변수를 한 선언에 나열하기, 초기값 없는 ໃນເຄື່ອງ_ຂອບ_ເຂດ ການປະກາດ, 오버로드, 임의 ພິມ_ຄ່າ 변환, ການຈັດຄ່າຮອບວຽນ_ຄ່າ ສ້າງ_167eff27 ແຫຼ່ງທີ່ມາ, 8/16진 리터럴, Unicode ແຫຼ່ງທີ່ມາ_ຕົ້ນໄມ້ 이스케이프 등은 미지원이다. `char`는 문자 리터럴로 초기화하며 일반 JDK의 모든 ຄ່າຄົງທີ່_ຄ່າ 축소 변환을 구현하지 않는다. 외부 `.class`의 `int[]` ສ້າງ_167eff27/읽기/쓰기는 지원하므로 ໂຮສ `javac --release 8`로 만든 ການຈັດຄ່າຮອບວຽນ_ຄ່າ 예제는 실행할 수 있다.

ວັດ_ຖຸ_ຄ່າ ຊ່ອງຂໍ້ມູນ_ຄ່າ·일반 ວັດ_ຖຸ_ຄ່າ ສ້າງ_167eff27·상속·인터페이스·여러 ປະເພດສິ່ງຂອງ_ຄ່າ ເຊື່ອມຕໍ່, long/float/double, ຂໍ້ຍົກເວັ້ນ ຂະ_ບວນ_ການ_ຄ່າ_ເຂົ້າໃນ, 스레드·모니터, 리플렉션, JNI, JIT, GC, 위 표에 없는 `java.io`와 `java.nio`/`java.net` 일반 API, 컬렉션, JAR와 클래스패스는 미지원이다. 런타임 오류는 Java ຂໍ້ຍົກເວັ້ນ 객체를 던지지 않고 진단 후 현재 프로그램을 종료한다. 객체와 ສະຕຣິງ_ຄ່າ ຮ້ານຄ້າ_ຄ່າ 공간은 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ ອອກ_ແອັບ 시 ຜູ້ໃຊ້ 영역 전체와 함께 회수한다. 지속 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 중 GC는 없다.

## ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 한도와 ຂໍ້ຜິດພາດ

| ແຫຼ່ງ_ຄ່າ | 한도 |
| --- | --- |
| ແຫຼ່ງທີ່ມາ_ຕົ້ນໄມ້/ປະເພດສິ່ງຂອງ_ຄ່າ ຟາຍ | 각각 16KiB |
| 컴파일러 | ໂທເຄນ_ຄ່າ 2,047개, ສ້າງ_167eff27 ລະຫັດ_ຄ່າ 4KiB, ຄ່າຄົງທີ່_ຄ່າ 풀 4KiB |
| ຟັງ_ຄ໌_ຊັນ_ຄ່າ/인수 | 클래스당 32함수, 함수당 16인수 |
| JVM ຄ່າຄົງທີ່_ຄ່າ | 511개 |
| JVM ຟັງ_ຄ໌_ຊັນ_ຄ່າ ລະຫັດ_ຄ່າ | 함수당 8KiB |
| JVM 호출/스택/ໃນເຄື່ອງ_ຂອບ_ເຂດ 변수 | 32프레임, 프레임당 스택 128칸·ໃນເຄື່ອງ_ຂອບ_ເຂດ 128칸 |
| JVM ວັດ_ຖຸ_ຄ່າ ຮ້ານຄ້າ_ຄ່າ 공간 | 8,192개 32비트 ຊ່ອງ_ເຂົ້າໃນ, 헤더 포함 약 32KiB |
| ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ | 최대 500,000 ຄໍາສັ່ງ_1f12b8e2, 기존 커널의 약 3초 CPU ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 상한도 적용 |

게스트 컴파일러는 버전 49.0 `.class`를 생성하며 JVM은 45.0~52.0 중 ການຮອງຮັບ_ຄ່າ 명령으로 구성된 파일을 읽는다. 스택맵을 이용한 완전한 JVM ວັດ_ຈະ_ນາ_ນຸ_ກົມ 검증기를 구현한 것은 아니다. ຟາຍ/ຄຸນສົມບັດ_ຄ່າ ຄວາມຍາວ_ຄ່າ, ຄ່າຄົງທີ່_ຄ່າ ການ_ອ້າງ_ອີງ, ຄໍາສັ່ງ_1f12b8e2·ສາຂາ 경계를 검사하고, ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 중 스택 ຮູບແບບ_ຄ່າ_d1a42ea5·ໃນເຄື່ອງ_ຂອບ_ເຂດ ລິເລີ່ມ·ການຈັດຄ່າຮອບວຽນ_ຄ່າ ຕົວ_ຫ້ອຍ_ຄ່າ·ວັດ_ຖຸ_ຄ່າ 참조를 검사한다. ຜູ້ໃຊ້ 코드의 페이지·포트 접근은 기존 ring 3 경계로 보호한다.

일반 성공은 `Exit: 0`, ສ້າງ_ແຫຼ່ງທີ່ມາ·JVM 오류는 `Exit: 1`, ຄໍາສັ່ງ_1f12b8e2 인수 오류는 `Exit: 2`다. CPU ເວລາ_ຄ່າ 상한은 기존 `Exit: 124`이며, ຜູ້ໃຊ້ ELF 자체의 CPU/런타임 오류는 기존 ອອກ_ແອັບ 코드를 따른다. ຫຼົ້ມເຫຼວ_ຄ່າ 후 셸에서 다른 프로그램을 계속 실행할 수 있다.

## 구현 위치와 시험

- `os/ຜູ້ໃຊ້/자바/자바컴파일러.java`: 게스트 어휘·구문·ພິມ_ຄ່າ 검사, ຄ່າຄົງທີ່_ຄ່າ 풀 및 바이트코드 ສ້າງ_167eff27.
- `os/ຜູ້ໃຊ້/자바/자바가상기계.java`: ປະເພດສິ່ງຂອງ_ຄ່າ 적재, 스택·프레임·ວັດ_ຖຸ_ຄ່າ ຮ້ານຄ້າ_ຄ່າ, ຄໍາສັ່ງ_1f12b8e2 해석과 제한된 표준 호출.
- `os/ແຫຼ່ງທີ່ມາ/ຄວາມຈໍາ_ລະບົບຟາຍ.java`: ຄວາມຈໍາ_ຂໍ້ມູນ ລະບົບຟາຍ, ແກ້ໄຂ_ຄ່າ, 부팅 ຟາຍ 적재.
- `os/ແຫຼ່ງທີ່ມາ/체계호출.java`, `compiler/ເລີ່ມ_ຜູ້ໃຊ້_ແອັບ.s`: ຟາຍ/문자 출력 API와 ຜູ້ໃຊ້ ລູກສອນເມົ້າ 검사.
- `os/ເຄື່ອງມື/자바파일묶기.py`: ໂຮສ 입력 ຟາຍ ຮັບ_ຮອງ·부팅 ກຸ່ມ_ຄ່າ ສ້າງ_167eff27.

```sh
make test-java
make test
```

`os/시험/자바시험.py`는 ELF/ISO 부팅, 게스트 ສ້າງ_ແຫຼ່ງທີ່ມາ·ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ, ຜູ້ໃຊ້ 입력, 재귀·반복문·ຕົວເລກຈໍານວນເຕັມ 극값·ສະຕຣິງ_ຄ່າ 결합·단락 평가, 재실행, ແຫຼ່ງທີ່ມາ_ຕົ້ນໄມ້ ຂໍ້ຜິດພາດ 후 기존 ປະເພດສິ່ງຂອງ_ຄ່າ 보존, ການຈັດຄ່າຮອບວຽນ_ຄ່າ/수 해독 ຂໍ້ຜິດພາດ, 무한 ສະປຣິນ_ຄ່າ 제한, ແກ້ໄຂ_ຄ່າ 넘침과 ຟາຍ 부족을 검사한다. 게스트 ສ້າງ_167eff27 클래스의 바이트를 QEMU 메모리에서 꺼내 OpenJDK `java -Xverify:all`로 실행하고 결과를 대조한다. 반대 방향으로 ໂຮສ OpenJDK의 ປະເພດສິ່ງຂອງ_ຄ່າ, ຕົວເລກຈໍານວນເຕັມ 배열과 한글 상수를 게스트에 적재하며, 손상된 ຟາຍ 표식·버전·ຄ່າຄົງທີ່_ຄ່າ 수·ສາຂາ·스택을 거부하는지도 검사한다. 기록은 `os/build/자바시험.json`에 남는다. 디스크 없는 별도 시험 VM만 생성하고 종료한다.

구현 형식의 참고 ຂໍ້ມູນ: Oracle [JVM ປະເພດສິ່ງຂອງ_ຄ່າ ຟາຍ 명세](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-4.html), [JVM ຄໍາສັ່ງ_1f12b8e2 명세](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-6.html).

## Java ຟາຍ ໄອ_ໂອ

[FileDemo.java](../posix-kor/자바예제/FileDemo.java)는 일반 Java 표준 ປະເພດສິ່ງຂອງ_ຄ່າ 이름을 사용한다. 소스를 `edit FileDemo.java`로 입력하거나 `JAVA_FILES`로 부팅 이미지에 넣은 ກັບ_ຄືນ_ຄ່າ `javac FileDemo.java`, `java FileDemo`를 실행한다. 결과는 `65`, `255`, `66`, `-1`, `JAVA FILE IO PASS`다. `write(int)`는 하위 8비트를 쓰고 `read()`는 0~255 또는 EOF -1을 반환한다. ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ 출력 생성자는 내용을 비우고, boolean 인수가 true이면 이어쓴다.

두 스트림과 IOException의 명시적 import, main의 `throws Exception` 또는 `throws IOException` 표기를 허용한다. ຂໍ້ຍົກເວັ້ນ ວັດ_ຖຸ_ຄ່າ·try/catch·try-with-resources는 지원하지 않으며 ຟາຍ 오류를 진단하고 프로그램을 종료한다. ການຈັດຄ່າຮອບວຽນ_ຄ່າ ໄອ_ໂອ, InputStream/OutputStream으로의 다형성, Reader/Writer, getFD, 일반 ຟາຍ 메타데이터 API는 아직 없다. close는 열린 서술자를 닫고, 재부팅 보존에는 ເຊລ `sync`가 필요하다. 예제의 ຟາຍ 이름은 현재 셸과 파일체계에 맞춰 ASCII로 쓴다.

`os/시험/자바파일시험.py`는 ຕົວ_ຈິງ_ຂໍ້ມູນ 게스트 ສ້າງ_ແຫຼ່ງທີ່ມາ 결과를 OpenJDK `-Xverify:all`로 다시 실행해 ຟາຍ 바이트와 출력을 대조한다. 범위와 ຮ້ານຄ້າ_ຄ່າ ມີເດຍ_ຄ່າ 사용법은 [posix-kor ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9](../posix-kor/ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9.md)를 참고한다. 참고한 표준 API는 Oracle [FileOutputStream](https://docs.oracle.com/javase/8/docs/api/java/io/FileOutputStream.html)이다.
