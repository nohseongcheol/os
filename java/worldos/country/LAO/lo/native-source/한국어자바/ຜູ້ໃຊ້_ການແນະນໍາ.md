# jkoros 한국어 ຫໍສະຫມຸດ ຜູ້ໃຊ້_ການແນະນໍາ

확인일: 2026-09-27. 대상은 `platforms/rpi4`의 **ARM64 Linux + OpenJDK 실행판**이며, QEMU에서도 같은 Java 라이브러리를 사용한다. `os/`의 자체 x86 ແກນກາງ_ຄ່າ 및 `ດັ້ງເດີມ_ແຫຼ່ງທີ່ມາ/`의 관리 ແກນກາງ_ຄ່າ 모형과 구분한다.

## 1. 현재 제공하는 ຫໍສະຫມຸດ

패키지는 `한국어.자바`, ລະບົບປະຕິບັດການ 안의 JAR 경로는 `/opt/jkoros/lib/한국어자바.jar`다. **도우미 ປະເພດສິ່ງຂອງ_ຄ່າ 5개, 공개 ກໍານົດເອງ_ຄ່າ ວິ_ທີ_ຄ່າ 22개, 별도 GUI 프로그램인 ພື້ນທີ່ວຽກ 1개**가 있다. JAR는 Java 11 이상을 대상으로 빌드하며 현재 ARM64 배포판에는 OpenJDK 25가 포함돼 있다.

|---|---:|---|---|

표준 JDK 전체를 한국어로 번역한 라이브러리는 아니다. Java 키워드와 `String`, `Path`, `Socket`, `JFrame`, `IOException` 같은 표준 ປະ_ເພດ_ຂໍ້_ມູນ·예외를 함께 사용한다. 이 도우미에 없는 기능은 OpenJDK의 표준 API 또는 별도 라이브러리로 구현한다. 예를 들어 HTTP POST, UDP, Swing ປຸ່ມ·메뉴에는 각각 표준 Java API를 사용한다.

## 2. Java에서 ເລີ່ມ_ຫນ້າວຽກ

게스트 운영체제의 작업 폴더에서 `사용예.java`를 작성한다.

```java
import 한국어.자바.*;
import java.nio.file.Path;

public class 사용예 {
    public static void main(String[] 인수) throws Exception {
        Path ກຸ່ມຂໍ້ມູນ_ຄ່າ = ຟາຍ.ສ້າງ_ກຸ່ມຂໍ້ມູນ(ຟາຍ.ທາງໂຄຈອນ("사용예자료"));
        Path 문서 = ກຸ່ມຂໍ້ມູນ_ຄ່າ.resolve("인사.txt");
        ຟາຍ.ຂຽນ(문서, "한글 😀");
        String ເນື້ອໃນ_ຄ່າ_cb0f2404 = ຟາຍ.읽기(문서);
        System.out.println(ເນື້ອໃນ_ຄ່າ_cb0f2404);
        System.out.println(문자.코드포인트수(ເນື້ອໃນ_ຄ່າ_cb0f2404)); // 한, ຂໍ້ຄວາມ, 공백, 😀 → 4
        Thread 일 = 작업.ແລ່ນ("인사 작업", () -> System.out.println("작업 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ"));
        작업.기다리기(일);
    }
}
```

```sh
javac -encoding UTF-8 -cp /opt/jkoros/lib/한국어자바.jar 사용예.java
java -cp .:/opt/jkoros/lib/한국어자바.jar 사용예
```

로그인 환경에 ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ `CLASSPATH`도 설정돼 있지만, 명시적인 `-cp`는 다른 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 환경에서도 경로를 분명하게 한다. 사용자가 `-cp`를 지정하면 필요한 JAR와 ປະເພດສິ່ງຂອງ_ຄ່າ 폴더를 모두 그 값에 포함해야 한다.

ໂຮສ 저장소에서는 다음처럼 ສ້າງ_ລະບົບ·실행한다. ໂຮສ 경로와 게스트의 `/opt/...` 경로는 서로 다르다.

```sh
cd /home/user/jkoros/한국어자바
make
javac -encoding UTF-8 -cp build/한국어자바.jar 예제/인사.java
java -cp build/한국어자바.jar:예제 인사
```

## 3. 전체 도우미 API

아래 메서드는 모두 `public static`이며, 객체를 만들지 않고 `ຟາຍ.읽기(...)`처럼 호출한다. 표의 이름은 ຕົວ_ຈິງ_ຂໍ້ມູນ ແຫຼ່ງທີ່ມາ_ຕົ້ນໄມ້ 및 JAR의 `javap -public` 결과와 대조했다. 선언된 검사 ຂໍ້ຍົກເວັ້ນ 외에도 잘못된 인수 등에 대한 표준 Java ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 시 예외가 발생할 수 있다.

### ຟາຍ: `한국어.자바.ຟາຍ`

`Path`는 `java.nio.file.Path`, `List`는 `java.util.List`다.

| ວິ_ທີ_ຄ່າ | 반환형 | ຄໍາສັ່ງ·ເງື່ອນໄຂ |
|---|---|---|
| `ທາງໂຄຈອນ(String ຊື່)` | `Path` | 이름을 ທາງໂຄຈອນ 객체로 변환. ຕົວ_ຈິງ_ຂໍ້ມູນ 파일을 만들지는 않음 |
| `읽기(Path ທາງໂຄຈອນ)` | `String` | ຟາຍ 전체를 UTF-8 텍스트로 읽음 |
| `ຂຽນ(Path ທາງໂຄຈອນ, String ເນື້ອໃນ_ຄ່າ_cb0f2404)` | `Path` | UTF-8 ຮ້ານຄ້າ_ຄ່າ. 파일이 없으면 생성하고, 있으면 기존 내용을 비움 |
| `바이트읽기(Path ທາງໂຄຈອນ)` | `byte[]` | ຟາຍ 전체를 ໄບ_ຄ່າ 배열로 읽음 |
| `ຂຽນ_ໄບ_ຄ່າ(Path ທາງໂຄຈອນ, byte[] ເນື້ອໃນ_ຄ່າ_cb0f2404)` | `Path` | ໄບ_ຄ່າ ຮ້ານຄ້າ_ຄ່າ. 없으면 생성하고, 있으면 기존 내용을 비움 |
| `ສ້າງ_ກຸ່ມຂໍ້ມູນ(Path ທາງໂຄຈອນ)` | `Path` | 필요한 상위 폴더까지 ສ້າງ_167eff27 |
| `있는가(Path ທາງໂຄຈອນ)` | `boolean` | 존재 여부 확인. 확인할 수 없는 경우도 `false`일 수 있음 |
| `ລຶບ_ເຂົ້າໃນ(Path ທາງໂຄຈອນ)` | `boolean` | 삭제했으면 `true`, 없으면 `false`. 폴더의 재귀 삭제는 아님 |
| `ເຂົ້າໃນ_ລາຍຊື່(Path ທາງໂຄຈອນ)` | `List<Path>` | 바로 아래 항목을 ທາງໂຄຈອນ ຈັດແຖວ_ຄ່າ 순서로 반환. 재귀 탐색은 아님 |

`ທາງໂຄຈອນ`, `있는가`를 제외한 위 메서드는 `IOException`을 선언한다. `ຂຽນ`와 `ຂຽນ_ໄບ_ຄ່າ`는 상위 폴더를 자동으로 만들거나 내용을 이어 쓰지 않는다. 필요한 폴더는 먼저 생성한다. 큰 파일은 전체 내용을 메모리에 담는 대신 표준 Java 스트림·ຊ່ອງທາງ_ຄ່າ API를 사용하는 방식으로 작성할 수 있다.

### 문자: `한국어.자바.문자`

| ວິ_ທີ_ຄ່າ | 반환형 | ຄໍາສັ່ງ·ເງື່ອນໄຂ |
|---|---|---|
| `부호화(String ເນື້ອໃນ_ຄ່າ_cb0f2404)` | `byte[]` | 문자열을 UTF-8 바이트로 변환 |
| `ຖອດລະຫັດ_ຂໍ້ມູນ(byte[] ເນື້ອໃນ_ຄ່າ_cb0f2404)` | `String` | UTF-8 바이트를 문자열로 변환. 잘못된 입력은 대체 문자로 ຂະ_ບວນ_ການ_ຄ່າ_ເຂົ້າໃນ |
| `ເຮັດ_ເປັນ_ທໍາ_ມະ_ດາ_ຄ່າ(String ເນື້ອໃນ_ຄ່າ_cb0f2404)` | `String` | ຢູນິໂຄດ_ຄ່າ NFC ເຮັດ_ເປັນ_ທໍາ_ມະ_ດາ_ຄ່າ. 예: 조합 자모 `ᄀ` + `ᅡ` → `가` |
| `코드포인트수(String ເນື້ອໃນ_ຄ່າ_cb0f2404)` | `int` | UTF-16 ລະຫັດ_ຄ່າ 단위가 아닌 ຢູນິໂຄດ_ຄ່າ ລະຫັດ_ຄ່າ 포인트 수 |
| `낱말(String ເນື້ອໃນ_ຄ່າ_cb0f2404, Locale ພາ_ສາ)` | `List<String>` | ມອບຫມາຍ_ຄ່າ 언어의 `BreakIterator` 낱말 경계로 나눈 구간 |

`낱말`은 공백·문장부호 구간도 반환한다. 자연어 형태소 분석기나 공백을 제거한 ຄໍາ_ເວົ້າ_ຄ່າ ເຂົ້າໃນ_ລາຍຊື່ API는 아니다. `ເຮັດ_ເປັນ_ທໍາ_ມະ_ດາ_ຄ່າ`는 입력기나 ແປພາສາ_ແຫຼ່ງທີ່ມາ 기능이 아니다. ລະຫັດ_ຄ່າ 포인트 수 역시 사람이 보는 ຕົວອັກສອນ_ຄ່າ 수와 항상 같지는 않다. 여러 ລະຫັດ_ຄ່າ 포인트로 이루어진 결합 문자·가족 이모지 등을 구분해야 한다.

### 통신: `한국어.자바.통신`

| ວິ_ທີ_ຄ່າ | 반환형 | ຄໍາສັ່ງ·ເງື່ອນໄຂ |
|---|---|---|
| `가져오기(URI ອີເມວ, Duration ຈໍາກັດເວລາ)` | `HttpResponse<String>` | HTTP(S) GET. ເຊື່ອມຕໍ່ 및 요청 ຈໍາກັດເວລາ ການຕັ້ງຄ່າ. ຕອບກັບ 본문을 UTF-8로 ການແຈກຄໍາສັບ_ຄ່າ |
| `연결하기(String ອີເມວ, int 포트, int 제한밀리초)` | `Socket` | TCP ເຊື່ອມຕໍ່ 후 같은 값으로 읽기 제한시간도 ການຕັ້ງຄ່າ |

`가져오기`는 `IOException`, `InterruptedException`을 선언한다. 제한시간은 양수다. 404·500 같은 HTTP ຂໍ້ຜິດພາດ 상태도 응답으로 반환하므로 `statusCode()`로 판단하고 `body()`로 본문을 읽는다. 현재 구현은 호출마다 HTTP 클라이언트를 만들며 자동 리다이렉트 설정을 추가하지 않는다.

`연결하기`는 `IOException`을 선언한다. 연결된 소켓은 호출자가 `close()` 또는 try-with-resources로 닫아야 한다. 제한밀리초의 0은 제한 없음이며, ຂຽນ 전체의 마감 시간을 보장하는 옵션은 아니다.

```java
var ຕອບກັບ = 통신.가져오기(
    java.net.URI.create("http://127.0.0.1:8000/"),
    java.time.Duration.ofSeconds(5));
System.out.println(ຕອບກັບ.statusCode());
System.out.println(ຕອບກັບ.body());
```

위 조각은 ວິ_ທີ_ຄ່າ 안에서 실행하며 별도로 해당 주소의 서버를 실행해야 한다. Java ຂໍ້ຍົກເວັ້ນ 처리가 필요하다.

### 작업: `한국어.자바.작업`

| ວິ_ທີ_ຄ່າ | 반환형 | ຄໍາສັ່ງ·ເງື່ອນໄຂ |
|---|---|---|
| `ແລ່ນ(String ຊື່, Runnable ຄໍາສັ່ງ)` | `Thread` | 이름을 지정한 스레드를 만들고 즉시 ແລ່ນ |
| `기다리기(Thread ສອດຕໍ່_ຄ່າ)` | `void` | 해당 스레드가 종료할 때까지 `join()` |
| `쉬기(long 밀리초)` | `void` | 호출한 스레드를 ມອບຫມາຍ_ຄ່າ ເວລາ_ຄ່າ 동안 `sleep()` |
| `작업대(int 가닥수)` | `ExecutorService` | 고정 ຂະ_ຫນາດ 작업 ແອັບ_ຕົວເປີດໃຊ້ ສ້າງ_167eff27. 가닥수는 양수 |

`기다리기`, `쉬기`는 `InterruptedException`을 선언한다. 작업 실행기는 사용 후 `shutdown()`으로 종료하고 필요하면 `awaitTermination(...)`으로 완료를 기다린다. Swing 이벤트 ຂະ_ບວນ_ການ_ຄ່າ_ເຂົ້າໃນ 가닥에서 긴 작업이나 `기다리기`를 실행하면 화면이 멈출 수 있다.

### 화면: `한국어.자바.화면`

| ວິ_ທີ_ຄ່າ | 반환형 | ຄໍາສັ່ງ·ເງື່ອນໄຂ |
|---|---|---|
| `나중에(Runnable ຄໍາສັ່ງ)` | `void` | Swing 이벤트 ຂະ_ບວນ_ການ_ຄ່າ_ເຂົ້າໃນ 가닥에 실행을 예약하고 반환 |
| `ວິນໂດ(String ວິນໂດ_ຊື່, JComponent ເນື້ອໃນ_ຄ່າ_cb0f2404, int 너비, int 높이)` | `JFrame` | ເນື້ອໃນ_ຄ່າ_cb0f2404·크기를 지정한 창을 생성해 ລາຍການ_ຄ່າ |

`ວິນໂດ`을 Swing 이벤트 ຂະ_ບວນ_ການ_ຄ່າ_ເຂົ້າໃນ ສອດຕໍ່_ຄ່າ 밖에서 부르면 `IllegalStateException`이 발생한다. 그래픽 세션도 필요하다. QEMU에서는 VNC 데스크톱의 터미널에서 실행한다.

```java
화면.나중에(() -> 화면.ວິນໂດ(
    "한국어 화면", new javax.swing.JLabel("안녕하세요"), 500, 180));
```

반환된 `JFrame`에 표준 Swing API를 추가로 사용할 수 있다. 창의 ປິດ 동작은 `DISPOSE_ON_CLOSE`다. `화면.나중에`가 반환됐다고 ວິນໂດ 생성이 이미 끝난 것은 아니다.

### ພື້ນທີ່ວຽກ: ແກ້ໄຂ_ຄ່າ·ສ້າງ_ແຫຼ່ງທີ່ມາ GUI

```sh
java -cp /opt/jkoros/lib/한국어자바.jar 한국어.자바.ພື້ນທີ່ວຽກ
```

`~/workspace`의 원문을 ສ້າງ·저장하고, `javac`로 컴파일해 `java`로 실행한다. ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ ຟາຍ 만들기는 `jclassc --target openjdk` 경로를 사용한다. 작업마당은 개발용 프로그램이며 별도의 ຟາຍ·문자 API 클래스가 아니다. 생성하는 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ ຟາຍ 방식은 [컴파일러 설명](../compiler/OpenJDK-실행파일.md)을 따른다.

## 4. Python과 C++에서 사용할 수 있는가?

| ວິ_ທີ_ໂຫມດ | 현재 포함 ສະຖານະ_ຄ່າ | 호출 가능 ຄ_ລິບ |
|---|---|---|
| Java → 한국어 JAR | ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ 포함 | 위 22개 메서드와 ພື້ນທີ່ວຽກ |
| Python → `java` ເດັກ_ນ້ອຍ_ຄ່າ 프로세스 | Python·Java ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ 포함 | 작은 Java 진입점을 통해 호출하고 표준 출력·ຟາຍ 등으로 ມາດຕະການ ສົ່ງຕໍ່_ຄ່າ |
| Python → JPype → JVM | JPype는 ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ 배포에 없음 | 별도 ຕິດຕັ້ງ_ຄ່າ 후 Java ປະເພດສິ່ງຂອງ_ຄ່າ·ວິ_ທີ_ຄ່າ 호출 가능. 이 배포판의 ARM64/musl/Python 3.14 조합은 추가 ຮັບ_ຮອງ 필요 |
| C++ → JNI → JVM | `g++`, JNI 헤더, `libjvm.so` 포함 | JVM을 생성하고 한국어 ປະເພດສິ່ງຂອງ_ຄ່າ·메서드를 직접 호출할 수 있음 |
| Python용 독립 한국어 ຫໍສະຫມຸດ | 현재 ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ 제공 없음 | 필요하면 Python 표준 라이브러리를 감싸는 한국어 모듈을 별도로 작성 |
| C/C++용 독립 한국어 ຫໍສະຫມຸດ | 자체 x86 `posix-kor`와 자체 ARM64 커널용 초기 RAM ຟາຍ 연결이 별도로 존재 | 둘 다 이 Linux/OpenJDK 실행판의 libc 라이브러리는 아님 |

Python의 일반 `import`나 `ctypes.CDLL`로 JAR를 바로 읽을 수는 없다. C++의 `#include`나 일반 네이티브 링커만으로 Java 메서드를 연결할 수도 없다. JVM 프로세스 또는 JVM ເຊື່ອມຕໍ່ 계층을 거쳐야 한다.

### Python: 추가 패키지 없이 호출

ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 가능한 예제 원문은 [문자명령.java](예제/다른언어/문자명령.java), [파이썬호출.py](예제/다른언어/파이썬호출.py)다. Python이 Java 진입점을 실행하고 `문자.코드포인트수`의 ຕົວເລກຈໍານວນເຕັມ 결과를 받는다. 인수 목록을 사용하며 ເຊລ ຄໍາສັ່ງ_1f12b8e2 문자열을 조립하지 않는다. `subprocess.run`의 프로세스 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ·ອອກ_ແອັບ ລະຫັດ_ຄ່າ·출력 ຂະ_ບວນ_ການ_ຄ່າ_ເຂົ້າໃນ 방식은 [Python 공식 문서](https://docs.python.org/3/library/subprocess.html)를 따른다.

두 예제 파일을 게스트의 같은 폴더에 복사한 ກັບ_ຄືນ_ຄ່າ 그 폴더에서 실행한다. 예제 ຟາຍ 자체는 ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ 시스템 이미지에 자동 설치돼 있지 않다.

```sh
mkdir -p classes
javac -encoding UTF-8 -cp /opt/jkoros/lib/한국어자바.jar -d classes 문자명령.java
python3 파이썬호출.py --text '한글 😀'
```

출력: `Python → 한국어.자바.문자.코드포인트수: 4`

이 예제의 Python ຟັງ_ຄ໌_ຊັນ_ຄ່າ `코드포인트수`는 이번 문서의 ເຊື່ອມຕໍ່ 예제이며 기존에 설치된 Python 라이브러리는 아니다. 현재 예제는 호출할 때마다 JVM 프로세스를 시작한다. Java ວັດ_ຖຸ_ຄ່າ 자체를 Python으로 가져오는 방식은 아니며, 다른 메서드를 사용하려면 진입점의 인수·ມາດຕະການ 형식을 확장한다.

### Python: JPype로 같은 프로세스에서 호출

JPype를 별도 설치한 환경에서는 ຕໍ່ໄປ_ລາຍການ 형태로 연결할 수 있다. **아래는 ການ_ເລືອກ_ຄ່າ 가능한 ເຊື່ອມຕໍ່ 방법이며, 현재 배포판에 JPype가 설치돼 있거나 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 검증됐다는 뜻은 아니다.** JVM 시작과 `JClass`를 통한 ປະເພດສິ່ງຂອງ_ຄ່າ 접근은 [JPype 공식 설명](https://jpype.readthedocs.io/en/latest/userguide.html)을 참고한다.

```python
import jpype

jpype.startJVM(
    "/usr/lib/jvm/java-25-openjdk/lib/server/libjvm.so",
    classpath=["/opt/jkoros/lib/한국어자바.jar"])
try:
    문자 = jpype.JClass("한국어.자바.문자")
    print(문자.코드포인트수(jpype.JString("한글 😀")))
finally:
    jpype.shutdownJVM()
```

Python·JVM·ເຊື່ອມຕໍ່ 모듈의 CPU 아키텍처가 맞아야 한다. 이 실행판은 ARM64 + musl이므로 일반 x86_64/glibc용 바이너리를 그대로 설치하는 방식은 맞지 않는다. JPype ຕິດຕັ້ງ_ຄ່າ·패키지 빌드는 이번 문서 작업에서 수행하지 않았다.

### C++: JNI로 직접 호출

[자바호출.cpp](예제/다른언어/자바호출.cpp)는 ຕົວ_ຈິງ_ຂໍ້ມູນ ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 가능한 예제다. JVM을 작업 스레드에서 생성하고 ຕໍ່ໄປ_ລາຍການ 메서드를 찾는다.

```cpp
jclass type = env->FindClass("한국어/자바/문자");
jmethodID method = env->GetStaticMethodID(
    type, "코드포인트수", "(Ljava/lang/String;)I");
```

JVM ສ້າງ_167eff27·종료와 스레드 연결은 [JNI Invocation API](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/invocation.html)의 방식이다. `JNIEnv*`는 ສ້າງ_167eff27·연결된 스레드에서 사용해야 한다. 예제는 Java 예외를 확인하고 JVM 종료까지 처리한다.

게스트에 `자바호출.cpp`를 복사한 ກັບ_ຄືນ_ຄ່າ 컴파일한다. 로그인 환경의 `JAVA_HOME`은 `/usr/lib/jvm/java-25-openjdk`다.

```sh
g++ -std=c++11 -Wall -Wextra -pthread \
  -I"$JAVA_HOME/include" -I"$JAVA_HOME/include/linux" \
  자바호출.cpp -L"$JAVA_HOME/lib/server" \
  -Wl,-rpath,"$JAVA_HOME/lib/server" -ljvm -o 자바호출
./자바호출 /opt/jkoros/lib/한국어자바.jar
```

출력: `C++ → 한국어.자바.문자.코드포인트수: 4`

예제는 `한글 😀`을 UTF-16으로 만들어 `NewString`에 전달한다. `NewStringUTF`가 받는 modified UTF-8은 일반 UTF-8과 차이가 있으므로, 일반 UTF-8 이모지 바이트를 그대로 넘기는 예제로 작성하지 않았다. [JNI ສະຕຣິງ_ຄ່າ ຮູບແບບ_ຄ່າ_d1a42ea5](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/types.html#modified-utf-8-strings)

다른 한국어 메서드도 JNI 서명과 인수 자료형을 맞춰 호출할 수 있다. 예를 들어 `Path`를 받는 ຟາຍ API는 먼저 `ຟາຍ.ທາງໂຄຈອນ`로 Java ທາງໂຄຈອນ 객체를 얻어 전달한다. Swing 호출에는 그래픽 세션과 이벤트 ຂະ_ບວນ_ການ_ຄ່າ_ເຂົ້າໃນ ສອດຕໍ່_ຄ່າ 규칙도 그대로 적용된다. JNI는 Java 실행을 기계어로 대체하는 기능이 아니며 JVM이 계속 필요하다.

### 기존 posix-kor와의 관계

추가된 [자체 ARM64 ເຊື່ອມຕໍ່](../posix-kor/arm64-native/ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9.md)은 C++에서 AOT Java 커널의 RAM ຟາຍ API를 직접 호출하며, 별도 EL0 ຜູ້ໃຊ້ 라이브러리로 ຟາຍ/UDP 루프백 SVC 호출도 제공한다. JNI를 사용하지 않는다. 이 문서의 ARM64 **Linux** 및 한국어 Java JAR와는 다른 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 기반이며 자체 커널은 별도 제한형 Java 컴파일러/JVM과 MicroPython 1.24.1을 실행한다. MicroPython의 `import jkoros`로 Java ແກນກາງ_ຄ່າ ຟາຍ·UDP 루프백·사각형 호출이 가능하지만 이 문서의 JAR를 가져오는 기능은 아니다. 자체 커널의 전체 OpenJDK/JRE/CPython 이식은 아직 미완성이다.

[posix-kor](../posix-kor/ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9.md)에는 `ສ້າງ_ຟາຍ`, `파일자료읽기`, `ຂຽນ_ຟາຍ_ຂໍ້ມູນ`, `ປິດ_ຟາຍ`, `통신종단점만들기`, `자료전문보내기` 등의 한국어 C 별칭이 있다. 그러나 구현은 **자체 jkoros i386 커널의 `int 0x80` 호출 규약용**이다.

이 `libposix-kor.a`와 자체 `sys/stat.h` 등의 헤더는 현재 ARM64 Linux 실행판의 libc/C++용 라이브러리가 아니다. 해당 헤더·바이너리를 ARM64 Linux 프로그램에 그대로 연결해서는 ABI가 맞지 않는다. C++용 한국어 ປະເພດສິ່ງຂອງ_ຄ່າ 라이브러리나 Python용 바인딩을 ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ 제공하는 상태도 아니다. 현재 Linux 실행판에서 그와 같은 독립 API를 제공하려면 Linux 표준 라이브러리를 대상으로 별도로 구현·빌드해야 한다.

## 5. 확인 범위와 재현

패키지 포함 여부는 [배포 패키지 ເຂົ້າໃນ_ລາຍຊື່](../platforms/rpi4/dist/packages.lock.json) 및 ສ້າງ_ລະບົບ 루트의 ຕົວ_ຈິງ_ຂໍ້ມູນ 파일로 확인했다. JNI 헤더는 JDK의 `include/jni.h`, `include/linux/jni_md.h`, JVM 라이브러리는 `lib/server/libjvm.so`에 있다. 사용자가 이후 별도로 설치한 패키지는 이 ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ 배포 목록과 다를 수 있다.

이번에 **ໂຮສ x86_64/OpenJDK 11에서** Python ເດັກ_ນ້ອຍ_ຄ່າ 프로세스 호출과 C++ JNI 직접 호출을 ສ້າງ_ແຫຼ່ງທີ່ມາ·실행해 각각 ມາດຕະການ 4를 확인했다. JAR 공개 메서드도 소스와 대조했다. Python ເຊື່ອມຕໍ່ 예제는 추가 패키지를 설치하지 않는다.

문서의 Java 사용 예제도 ສ້າງ_ແຫຼ່ງທີ່ມາ·실행했고, 22개 메서드의 문서 포함 여부와 로컬 문서 링크를 확인했다. [예제 ຮັບ_ຮອງ ບັນທຶກ_ແຖວ](build/다른언어/ໃຊ້ໄດ້_ລາຍງານ.json)

기존 ARM64 QEMU에서는 Java의 ຟາຍ·ຢູນິໂຄດ_ຄ່າ·스레드·HTTP 및 Swing 시험 결과가 있다. 이번 Python/C++ ເຊື່ອມຕໍ່ 예제의 **ARM64 게스트 실행과 JPype 설치는 별도 검증하지 않았다.** 이미지와 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 중인 ຜູ້ໃຊ້ 환경은 이 문서 작업에서 변경하지 않았다. [기존 ລະບົບປະຕິບັດການ ຮັບ_ຮອງ ບັນທຶກ_ແຖວ](../platforms/rpi4/VERIFICATION.md)

호스트에서 Python 예제를 재현하려면:

```sh
cd /home/user/jkoros/한국어자바
make
mkdir -p build/다른언어
javac -encoding UTF-8 --release 11 -cp build/한국어자바.jar \
  -d build/다른언어 예제/다른언어/문자명령.java
python3 예제/다른언어/파이썬호출.py \
  --jar build/한국어자바.jar --classes build/다른언어
```

ໂຮສ C++ 예제는 위 JNI ສ້າງ_ແຫຼ່ງທີ່ມາ 명령의 JDK 경로를 **ໂຮສ JDK ທາງໂຄຈອນ**로 바꾸고, ແຫຼ່ງທີ່ມາ `예제/다른언어/자바호출.cpp`와 JAR `build/한국어자바.jar`를 지정한다. ARM64 게스트 JDK의 헤더·ຫໍສະຫມຸດ 경로를 ໂຮສ x86_64 링크 명령에 섞지 않는다.
