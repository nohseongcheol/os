# 외부 배포용 압축과 복원

Ubuntu x86_64에서 프로젝트 루트의 `./pack.sh`를 실행한다.
`dist/jkoros-source.tar.xz`, 체크섬 ຟາຍ, 독립 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 가능한 `dist/unpack.sh`가 생성된다.
원본 캐시, ແຫຼ່ງທີ່ມາ_ຕົ້ນໄມ້, ຜູ້ໃຊ້ 디스크는 삭제하거나 변경하지 않는다. 압축파일은 2 GB를
넘으면 생성에 실패한다. 출력 경로는 `./pack.sh /ທາງໂຄຈອນ/jkoros-source.tar.xz`로 지정한다.

다른 Ubuntu PC에 압축파일, `.sha256`, `unpack.sh`를 함께 전달한 ກັບ_ຄືນ_ຄ່າ 실행한다.

```sh
./unpack.sh jkoros-source.tar.xz /원하는/새/ທາງໂຄຈອນ/jkoros
make -C /원하는/새/ທາງໂຄຈອນ/jkoros all korean-java iso
make -C /원하는/새/ທາງໂຄຈອນ/jkoros rpi-native-image
make -C /원하는/새/ທາງໂຄຈອນ/jkoros rpi-image
```

ຄ່າທີ່ກໍານົດໄວ້ແລ້ວ 동작은 ການສໍາເນົາ_ຄ່າ ເວີຊັນ_ບ່ອນເກັບຂໍ້ມູນ 후 의존성 자동 다운로드와 준비까지다. Ubuntu ສ້າງ_ລະບົບ 도구가
없으면 `sudo apt-get`으로 설치하며 관리자 암호가 필요할 수 있다. 외부 소스의
SHA-256을 확인하고 ARM64 SDK/Linux ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 환경, ໂຮສ 도구와 JRE를 준비한다.
새 폴더의 위치를 기준으로 실행하므로 `/home/user` 경로를 만들 필요가 없다.

자체 ARM64 커널만 개발한다면 `--profile native`로 GUI/Linux ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 환경 준비를
생략할 수 있다. ສ້າງ_ລະບົບ 도구가 이미 설치되어 있으면 `--no-host-install`을 추가한다.
`--no-prepare`는 다운로드하지 않고 소스만 검사할 때 쓰는 명시적 선택이다.

ກະ_ກຽມ 도중 네트워크 오류가 나면 풀린 폴더에서 `./unpack.sh --prepare`를 다시 실행한다.
기존 출력 ກຸ່ມຂໍ້ມູນ_ຄ່າ 위에는 압축을 풀지 않는다. 개인 수정 파일을 덮어쓰지 않으며,
복원 ເປົ້າ_ຫມາຍ 파일의 내용이 예상 해시와 다르면 중단한다.

압축에서 `build`, `dist`, `ມາດຕະການ`, `.vbox`, Python 캐시, ບັນທຶກ_ຄ່າ, ຜູ້ໃຊ້ 디스크와
ການເຊື່ອມຕໍ່_e05f319b 키를 제외한다. Alpine 패키지 캐시는 외부에서 필요한 패키지만 다시 받는다.
libassh, BearSSL, lwIP, uzlib, MicroPython 중 고정 URL/해시로 복구할 수 있는 원본은
제외하지만 로컬 수정 파일은 포함한다. 정확한 재다운로드 주소를 고정하지 못한
TinyCC 스냅샷, 자체 ຮູບແບບຕົວຫນັງສື_ຄ່າ, 프로젝트 소스와 라이선스 고지는 포함한다.

인터넷과 Ubuntu 패키지 ຣີໂພຊິທໍຣີ_ເລກຮາກ 및 Alpine 3.24 ຣີໂພຊິທໍຣີ_ເລກຮາກ 접근이 필요하다.
Alpine 저장소의 사용 가능한 패키지 버전을 받아 ຕົວ_ຈິງ_ຂໍ້ມູນ 버전을 잠금 파일에 기록한다.
패키지 다운로드 후의 작업 폴더와 ສ້າງ_ລະບົບ 산출물은 2 GB를 넘을 수 있다.
OpenJDK 자체 소스의 별도 실험 빌드는 기존 컴파일러 안내에 따라 소스를 준비한다.

`PORTABLE_DOWNLOAD_CACHE=/캐시/ກຸ່ມຂໍ້ມູນ_ຄ່າ`를 지정하면 SHA-256을 파일명으로 하는
검증된 다운로드 파일을 먼저 사용한다. 캐시에 없는 항목은 자동 다운로드한다.
제외 목록과 ການສໍາເນົາ_ຄ່າ 크기는 `dist/jkoros-source.tar.xz.report.json`에 기록된다.
