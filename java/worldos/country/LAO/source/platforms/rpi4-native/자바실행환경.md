# 자체 ARM64 JVM 0.4와 한국어 ຫໍສະຫມຸດ

한국어 통신·ຂໍ້ຍົກເວັ້ນ 사용법은 [한국어 Java API](한국어자바/ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9.md), ຟັງ_ຄ໌_ຊັນ_ຄ່າ·변수·ຟາຍ 이름의 변경과 어원 근거는 [명명 ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9](명명/ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9.md)를 참고한다.

JAR ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ, 외부 IPv4 TCP/UDP, 별도 ກໍານົດເອງ_ຄ່າ 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 ວັດ_ຖຸ_ຄ່າ·Thread·Swing은 JVM 경로의 기능이며 AOT ການຮອງຮັບ_ຄ່າ 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK ປະເພດສິ່ງຂອງ_ຄ່າ ຫໍສະຫມຸດ 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 ປະເພດສິ່ງຂອງ_ຄ່າ·ກໍານົດເອງ_ຄ່າ ວິ_ທີ_ຄ່າ 중심이던 실행기를 ວັດ_ຖຸ_ຄ່າ·ຫໍສະຫມຸດ ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 기반으로 넓힌 것이다.

## 실행과 ສ້າງ_ແຫຼ່ງທີ່ມາ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# 자체 ແກນກາງ_ຄ່າ 안에서 ແຫຼ່ງທີ່ມາ_ຕົ້ນໄມ້ ສ້າງ_ແຫຼ່ງທີ່ມາ → class ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ, 한국어 API 호출
python3 ເຄື່ອງມື/ປະ_ຕິ_ບັດ_ຟາຍ.py 시험/자바/한글소스.java

# ວັດ_ຖຸ_ຄ່າ·ຂໍ້ຍົກເວັ້ນ 등은 ໂຮສ JDK로 Java 8 class를 만든 후 자체 커널에서 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 ເຄື່ອງມື/ປະ_ຕິ_ບັດ_ຟາຍ.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 ໂອນ_ຄ່າ
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 ເຄື່ອງມື/ປະ_ຕິ_ບັດ_ຟາຍ.py build/my-java/객체시험.class \
  --include build/my-java/ພື້ນຫຼັງ_ຄ່າ.class --include build/my-java/ສາຂາ_ຄ່າ.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.ປະເພດສິ່ງຂອງ_ຄ່າ.class`라는 RAM ຟາຍ 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.ປະເພດສິ່ງຂອງ_ຄ່າ`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.ປະເພດສິ່ງຂອງ_ຄ່າ`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar ຟາຍ.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 한국어 클래스만 찾는다. 배포 한국어 ຫໍສະຫມຸດ JAR는 ໂຮສ javac의 classpath로 사용하며, 같은 클래스가 ຜູ້ໃຊ້ JVM ELF에도 읽기 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 ກໍານົດເອງ_ຄ່າ ວິ_ທີ_ຄ່າ, int/boolean/char/String, ເງື່ອນໄຂ·ສະປຣິນ_ຄ່າ, ສະຕຣິງ_ຄ່າ 결합, 일부 ຟາຍ 스트림 등의 **자체 부분집합 컴파일러**다. ວັດ_ຖຸ_ຄ່າ ການປະກາດ·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 자체 JVM에서 실행한다. 한국어 API 중 출력·문자 스칼라 ຟັງ_ຄ໌_ຊັນ_ຄ່າ·ຟາຍ 읽기/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] 인수) throws Exception {
        한국어.자체.출력.ຂຽນ_ສາຍ("안녕하세요😀");
        한국어.자체.출력.수쓰기(한국어.자체.문자.코드포인트수("한글😀"));
        한국어.자체.ຟາຍ.ຂຽນ("인사.txt", "한글 ຟາຍ😀");
        한국어.자체.출력.ຂຽນ_ສາຍ(한국어.자체.ຟາຍ.읽기("인사.txt"));
    }
}
```

## 한국어 API

독립 패키지 **`한국어.자체`**를 사용한다. Linux판 `한국어.자바`가 요구하는 NIO/Swing/HTTP API를 자체 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 ປະເພດສິ່ງຂອງ_ຄ່າ ຊື່·ວິ_ທີ_ຄ່າ·인수·ຊ່ອງຂໍ້ມູນ_ຄ່າ·ຟາຍ 이름에 한국어를 사용한다. 표준 Java ປະເພດສິ່ງຂອງ_ຄ່າ 이름은 호환성을 위해 보존한다.

|---|---|---|
| 출력 | ຂຽນ, ຂຽນ_ສາຍ, 수쓰기 | 출력(出力): 내용을 바깥으로 내보냄 |
| 문자 | ຄວາມຍາວ_ຄ່າ, 같음, ວາງ_ຂໍ້ຄວາມ, ຕັດ_ຄ່າ, ການແຈກຄໍາສັບ_ຕົວເລກຈໍານວນເຕັມ/ຂຽນ_ຕົວເລກຈໍານວນເຕັມ_ຄ່າ, 코드포인트수, 부호화/ຖອດລະຫັດ_ຂໍ້ມູນ | 문자(文字), ເຂົ້າລະຫັດ_ຄ່າ(符號): 글의 단위와 그 값을 바이트로 나타내는 ລະບຽບ_ຄ່າ |

| ເຂົ້າໃນ_ລາຍຊື່ | 더하기, 읽기, 바꾸기, ລຶບ_ເຂົ້າໃນ, ຂະ_ຫນາດ, ເທັກໂນໂລຢີຂໍ້ມູນຂ່າວສານ_ຫວ່າງ_ເປົ່າ_ຄ່າ, ລ້າງ_ສາລະບານ | ເຂົ້າໃນ_ລາຍຊື່(目錄): 순서가 있는 ເຂົ້າໃນ_ຄ່າ 모음 |

| ແກນກາງ_ຄ່າ | 밀리초, 사각형 | 자체 JVM의 고정 native ເຊື່ອມຕໍ່; 일반 JNI는 아님 |

이 명명은 현재 기능을 설명하는 용어 선택이다. 기존 한국어에 없던 역사적 어원을 만들어 주장하지 않는다. ຟາຍ_ຊື່_ຂໍ້ຄວາມ·식별자는 UTF-8 소스로 보관한다. `문자.ຖອດລະຫັດ_ຂໍ້ມູນ`는 잘못된 UTF-8에 IllegalArgumentException을 던지며, `부호화`는 짝이 없는 서로게이트를 `?`로 바꾼다. `ຟາຍ.읽기`는 엄격한 UTF-8 복호화를 적용한다. 화면 색은 `빨강 | (초록 << 8) | (파랑 << 16)` 형식이다.

## ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(한국어 ປະເພດສິ່ງຂອງ_ຄ່າ 포함), class당 16 KiB·ຄ່າຄົງທີ່_ຄ່າ 풀 511항목, 전체 ວິ_ທີ_ຄ່າ/ຊ່ອງຂໍ້ມູນ_ຄ່າ 각각 512개. ວິ_ທີ_ຄ່າ ລະຫັດ_ຄ່າ 8 KiB, ໃນເຄື່ອງ_ຂອບ_ເຂດ 변수·피연산자 스택 각각 128슬롯, 인수 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- ວັດ_ຖຸ_ຄ່າ 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 ຕົວ_ຈິງ_ຂໍ້ມູນ 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 ຟາຍ·대형 ສະຕຣິງ_ຄ່າ·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 ຄໍາສັ່ງ_1f12b8e2 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 ວິນໂດ ສະວິດ_ໂຫມດ 시 중단·재개한다. 일반 서버·계산의 무제한 실행은 아직 없다. 미지원 ຄໍາສັ່ງ_1f12b8e2·ແຫຼ່ງ_ຄ່າ 부족은 명시적인 오류로 종료한다.
- RAM ຟາຍ 최대 64개, 파일당 16384바이트, ທາງໂຄຈອນ UTF-8 63바이트. RAM 디렉터리와 ລຸ້ນດຽວກັນ_ຄ່າ/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 한국어 class는 RAM ຟາຍ 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 현재 경로에서 ແຫຼ່ງທີ່ມາ_ຕົ້ນໄມ້·ປະເພດສິ່ງຂອງ_ຄ່າ·ຂໍ້ມູນ 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 외부 IPv4를 제공한다. ຕົວ_ຈິງ_ຂໍ້ມູນ GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. 전문 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 ການຈັດຄ່າຮອບວຽນ_ຄ່າ, 완전한 ການຈັດຄ່າຮອບວຽນ_ຄ່າ 공변성·인터페이스 ຊັ້ນ_ຄ່າ 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/ກົດລັບ_ຂໍ້ມູນ/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 ການຮອງຮັບ_ຄ່າ 부분집합은 아래 및 개발 매뉴얼을 참고한다. ປະເພດສິ່ງຂອງ_ຄ່າ ຟາຍ 전체 검증기·ເຂົ້າຫາ_ເຂົ້າໃນ ການອະນຸຍາດ_ຄ່າ/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 ປົກປ້ອງ_ຄ່າ 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM ຄ່າ/ຮັບ_ຮອງ/ປະເພດສິ່ງຂອງ_ຄ່າ 로더와 ຂໍ້ຍົກເວັ້ນ 모델 → 영속 VFS·mmap·ໂມງ·원자 ການຄໍານວນ_ຄ່າ·ຕົວ_ຈິງ_ຂໍ້ມູນ 스레드/ຊິງໂຄຣໄນ ABI → OpenJDK java.base 및 native ຫໍສະຫມຸດ 이식 → ມືຖື_ຄ່າ 네트워크·TCP/IP → ວິນໂດ 시스템/ຮູບແບບຕົວຫນັງສື_ຄ່າ/입력기·java.desktop → Java SE 호환성 시험. 현재 자체 JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## ຮັບ_ຮອງ

`ເຄື່ອງມື/자바가상기계시험.py`는 같은 Java 8 class 파일의 출력을 ໂຮສ OpenJDK `-Xverify:all`과 QEMU raspi4b 자체 커널에서 비교한다. ວັດ_ຖຸ_ຄ່າ/상속/인터페이스·switch·ການຈັດຄ່າຮອບວຽນ_ຄ່າ, ຂໍ້ຍົກເວັ້ນ/finally, 컬렉션/GC, Thread/잠금, 한국어 UTF-8/ຟາຍ/컬렉션, ຕົວ_ຈິງ_ຂໍ້ມູນ UDP 루프백/ເວລາ_ຄ່າ 초과, 게스트 한글 ແຫຼ່ງທີ່ມາ_ຕົ້ນໄມ້ ສ້າງ_ແຫຼ່ງທີ່ມາ, ການຈັດຄ່າຮອບວຽນ_ຄ່າ ພິມ_ຄ່າ/ກ່າຍ_ຄ່າ/ຟາຍ 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 ຟາຍ ປະຕິເສດ_ຄ່າ 시험을 실행한다. UDP ໂຄງ_ການ_ເລກຮາກ 실행에는 ໂຮສ 루프백 소켓 권한이 필요하다.

`ເຄື່ອງມື/부팅시험.py`는 ແກນກາງ_ຄ່າ ປົກປ້ອງ_ຄ່າ/회귀 시험과 별도로 한국어 Java 화면 API가 ຕົວ_ຈິງ_ຂໍ້ມູນ 픽셀을 그렸는지도 QMP 화면 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. ຕົວ_ຈິງ_ຂໍ້ມູນ Pi4 하드웨어 부팅 시험과 전체 JDK 호환성 시험 결과는 아니다.


## JVM 0.3: 네트워크와 GUI ສ່ວນຂະຫຍາຍ_ຄ່າ

`Socket`/`ServerSocket` ສ້າງ_167eff27·ເຊື່ອມຕໍ່·accept·양방향 InputStream/OutputStream·close·EOF·ເວລາ_ຄ່າ 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 외부 ຕົວເລກ_ຄ່າ IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 ຈົບ_ຈຸດ 16개, Java 루프백 버퍼 1024바이트, 외부 TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. ແບບໂຕ້ຕອບ 이벤트 대기는 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 기한을 갱신하고 ເທີມີນໍ ສະວິດ_ໂຫມດ 시 프로세스 상태를 ຮ້ານຄ້າ_ຄ່າ·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

한국어 `ວິນໂດ`, `ວິດເຈັດ`, `연결통신` 클래스를 배포 JAR와 자체 JVM 내장 자원에 추가했다. 상세 ວິ_ທີ_ຄ່າ·제한·ແຫຼ່ງທີ່ມາ_ຕົ້ນໄມ້·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## 한국어 객체의 직접 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ

`ວິນໂດ`, `ປ້າຍ`, `ຂໍ້ຄວາມ_ຊ່ອງຂໍ້ມູນ`, `ປຸ່ມ`, `ງານ_ຄິວ`, `동작알림`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. 자체 JVM의 ວັດ_ຖຸ_ຄ່າ ສ້າງ_167eff27,
ຮູບແບບ_ຄ່າ_d1a42ea5 검사, 화면 호출, ງານ 큐, ສອດຕໍ່_ຄ່າ 스케줄러에 한국어 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 경로도 유지한다.
한국어 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

자체 실행기의 한국어 진입점은 `public static void ແລ່ນ()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 한국어 진입점을 우선한다.
명령행 인수는 `실행인수.개수()`와 `실행인수.ຂໍ້ຄວາມ(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. ກໍານົດເອງ_ຄ່າ ຟາຍ 예제는 게스트
javac로도 컴파일하며, GUI/ສອດຕໍ່_ຄ່າ 소스는 ໂຮສ `javac --release 8`을 사용한다.
직접 GUI/ສອດຕໍ່_ຄ່າ API는 자체 JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
한국어 가닥의 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ·ລໍຖ້າ_ຄ່າ·중복 ແລ່ນ ປະຕິເສດ_ຄ່າ, GUI ງານ 출처·ດັດຊະນີ·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

ວິ_ທີ_ຄ່າ 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
한국어 클래스도 실행되지만, ສະຕຣິງ_ຄ່າ 리터럴·표준 ຫໍສະຫມຸດ 재정의·native
ເຊື່ອມຕໍ່·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 예제](한국어자바/ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9.md)를 참고한다.

## ເທີມີນໍ 부분 ລຶ້ມຄືນໃຫມ່

이동·ຂະ_ຫນາດ 변경은 새 ວິນໂດ 영역과 이전 자리에서 드러난 띠만 합성한다.
1920×32 ເປ_ລ(240 KiB)의 임시 그림에서 배경·겹친 ວິນໂດ·ຕົວອັກສອນ_ຄ່າ·GUI를 먼저
완성하고, 현재 ລາຍການ_ຄ່າ 메모리와 비교하여 달라진 화소만 기록한다.
32줄보다 큰 영역은 여러 띠로 처리하므로 전체 프레임을 원자적으로
교체하거나 수직 동기에 맞추는 방식은 아니다. 전체 배경을 먼저 지우는
중간 화면은 표시하지 않는다. 좌표가 같으면 다시 그리지 않는다.

`make test-redraw`는 ຕົວ_ຈິງ_ຂໍ້ມູນ C 그리기 코드를 호스트의 ຄວາມຈໍາ_ຂໍ້ມູນ 화면에 연결해
이동 80회·ຂະ_ຫນາດ ປ່ຽນ_ແປງ_ຄ່າ 40회·겹친 ວິນໂດ 4개를 전체 합성 결과와 ເປ_ລ 단위로 대조한다.
영역 밖 ຜູ້ໃຊ້ ການ_ແຕ້ມ_ຄ່າ, 동일 ເປ_ລ 무기록, ລູກສອນເມົ້າ 밑그림, ຕົວ_ຈິງ_ຂໍ້ມູນ 화면 ສາຍ 간격을
검사한다. 이 시험의 시간은 ໂຮສ CPU 측정이며 Pi 4/QEMU 속도로 해석하지 않는다.
`make test-resize`는 QEMU/VNC의 640×480 및 1920×1080에서 왼쪽 모서리 ລາກ_ຄ່າ,
한글 입력·vi 미저장 ເນື້ອໃນ_ຄ່າ_cb0f2404·독립 ວິນໂດ 크기를 검사한다.
