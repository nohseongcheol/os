# engos 기능 대응표

이 표는 기존 `ດັ້ງເດີມ_ແຫຼ່ງທີ່ມາ/`의 ວັດ_ຖຸ_ຄ່າ 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [ຕົວ_ຈິງ_ຂໍ້ມູນ 부팅 기능과 한계](../os/ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9.md)를 따로 기록한다.

## Java 관리 ຊັ້ນ_ຄ່າ 구현 완료

## 기존 ວັດ_ຖຸ_ຄ່າ 기반 관리 ແກນກາງ_ຄ່າ 전체를 부팅하기 위해 남은 ເຊື່ອມຕໍ່

ຕໍ່ໄປ_ລາຍການ 항목은 Java 문법만으로 실행할 수 없는 CPU/ມືຖື_ຄ່າ 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot ເຂົ້າໃນ_ຈຸດ_ຄ່າ, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 ສະ_ພາບ_ເນື້ອ_ໃນ_ຄ່າ ຮ້ານຄ້າ_ຄ່າ
- ຕົວ_ຈິງ_ຂໍ້ມູນ PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA ຫ່ວງ_ຄ່າ
- Java ວັດ_ຖຸ_ຄ່າ·ການຈັດຄ່າຮອບວຽນ_ຄ່າ ລິ້ງ_ຮູບແບບ, ຂໍ້ຍົກເວັ້ນ, ກໍານົດເອງ_ຄ່າ ລິເລີ່ມ, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT ສາກ_ຄ່າ
- FAT 디스크 구역을 ຕົວ_ຈິງ_ຂໍ້ມູນ ATA 장치와 연결하는 ໄອ_ໂອ 접착 ຊັ້ນ_ຄ່າ

위 관리 계층은 engos 기능의 Java 관리 구현과 ໂຮສ 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot ເຂົ້າໃນ_ຈຸດ_ຄ່າ, ກໍານົດເອງ_ຄ່າ ລິເລີ່ມ·ຕົວເລກຈໍານວນເຕັມ ການຈັດຄ່າຮອບວຽນ_ຄ່າ, VGA/직렬/PS2, 명령해석기, ຜູ້ໃຊ້ ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 ໂຮສ 루프백 패킷 왕복을 검증했다. 위 표의 ວັດ_ຖຸ_ຄ່າ 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
