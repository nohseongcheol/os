# 전체 ການຮອງຮັບ_ຄ່າ 요청의 현재 ສະຖານະ_ຄ່າ

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 ຕົວ_ຈິງ_ຂໍ້ມູນ C POSIX 일부 기능, 한국어 API/ແຫຼ່ງທີ່ມາ ຊື່, IDE ຟາຍ 보존, 게스트 Java ຟາຍ 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/ຂໍ້ແນະນໍາການໃຊ້_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 가능한 ຄ_ລິບ | 전체 지원에 필요한 작업 |
|---|---|---|
| Java ສ້າງ_ແຫຼ່ງທີ່ມາ·ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ | 게스트 제한형 javac/JVM, ກໍານົດເອງ_ຄ່າ 단일 클래스와 일부 표준 ວັດ_ຖຸ_ຄ່າ | 일반 ວັດ_ຖຸ_ຄ່າ·ປະເພດສິ່ງຂອງ_ຄ່າ ເຊື່ອມຕໍ່·ຂໍ້ຍົກເວັ້ນ·GC·스레드, 완전한 javac와 표준 ປະເພດສິ່ງຂອງ_ຄ່າ ຫໍສະຫມຸດ |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 환경을 추가하는 방식은 별도의 ແກນກາງ_ຄ່າ·루트 ລະບົບຟາຍ·OpenJDK·그래픽 서버·영구 ຮ້ານຄ້າ_ຄ່າ 구성을 가진 ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

ປະ_ຕິ_ບັດ_ຄໍາສັ່ງ 기반과 추가 ເປົ້າ_ຫມາຍ 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
