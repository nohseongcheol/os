# خارجي_قيمة 배포용 압축과 복원

Ubuntu x86_64에서 프로젝트 루트의 `./pack.sh`를 실행한다.
`dist/jkoros-source.tar.xz`, 체크섬 ملف, 독립 ينفذ_أمر 가능한 `dist/unpack.sh`가 생성된다.
원본 캐시, مصدر_شجرة, فضاء_المستخدم 디스크는 삭제하거나 변경하지 않는다. 압축파일은 2 GB를
넘으면 생성에 실패한다. مخرجات 경로는 `./pack.sh /مسار/jkoros-source.tar.xz`로 지정한다.

다른 Ubuntu PC에 압축파일, `.sha256`, `unpack.sh`를 함께 전달한 عودة_قيمة 실행한다.

```sh
./unpack.sh jkoros-source.tar.xz /원하는/새/مسار/jkoros
make -C /원하는/새/مسار/jkoros all korean-java iso
make -C /원하는/새/مسار/jkoros rpi-native-image
make -C /원하는/새/مسار/jkoros rpi-image
```

قيمة_افتراضية 동작은 أرشيف_قيمة إصدار_تخزين 후 의존성 자동 다운로드와 준비까지다. Ubuntu بنية_نظام 도구가
없으면 `sudo apt-get`으로 설치하며 مدير_قيمة 암호가 필요할 رقم 있다. خارجي_قيمة 소스의
SHA-256을 확인하고 ARM64 SDK/Linux ينفذ_أمر بيئة_التشغيل, مضيف 도구와 JRE를 준비한다.
새 폴더의 위치를 기준으로 실행하므로 `/home/user` 경로를 만들 필요가 없다.

ذاتي ARM64 커널만 개발한다면 `--profile native`로 GUI/Linux ينفذ_أمر بيئة_التشغيل 준비를
생략할 رقم 있다. بنية_نظام 도구가 이미 설치되어 있으면 `--no-host-install`을 추가한다.
`--no-prepare`는 다운로드하지 않고 소스만 검사할 때 쓰는 명시적 선택이다.

إعداد 도중 네트워크 오류가 나면 풀린 폴더에서 `./unpack.sh --prepare`를 إعادة_محاولة_قيمة 실행한다.
기존 مخرجات دليل_قيمة 위에는 압축을 풀지 않는다. 개인 수정 파일을 덮어쓰지 않으며,
복원 الهدف 파일의 내용이 예상 해시와 다르면 중단한다.

압축에서 `build`, `dist`, `نتيجة`, `.vbox`, Python 캐시, سجل_قيمة, فضاء_المستخدم 디스크와
صديق_e05f319b 키를 제외한다. Alpine 패키지 캐시는 외부에서 필요한 패키지만 إعادة_محاولة_قيمة 받는다.
libassh, BearSSL, lwIP, uzlib, MicroPython 중 고정 URL/해시로 복구할 رقم 있는 원본은
제외하지만 로컬 수정 파일은 포함한다. 정확한 재다운로드 주소를 고정하지 못한
TinyCC 스냅샷, ذاتي خط_قيمة, 프로젝트 소스와 라이선스 고지는 포함한다.

인터넷과 Ubuntu 패키지 مستودع_جذر 및 Alpine 3.24 مستودع_جذر 접근이 필요하다.
Alpine 저장소의 يستخدم_قيمة 가능한 패키지 버전을 받아 الفعلي_بيانات 버전을 قفل_قيمة 파일에 기록한다.
패키지 다운로드 후의 작업 폴더와 بنية_نظام 산출물은 2 GB를 넘을 رقم 있다.
OpenJDK ذاتي 소스의 별도 실험 빌드는 기존 محول_برمجي 안내에 따라 소스를 준비한다.

`PORTABLE_DOWNLOAD_CACHE=/캐시/دليل_قيمة`를 지정하면 SHA-256을 파일명으로 하는
검증된 다운로드 파일을 먼저 사용한다. 캐시에 없는 항목은 자동 다운로드한다.
제외 목록과 أرشيف_قيمة 크기는 `dist/jkoros-source.tar.xz.report.json`에 기록된다.
