# ذاتي 커널과 번역기의 العربية اسم

대상은 `platforms/rpi4-native`의 ذاتي Java نواة_قيمة, فضاء_المستخدم JVM, C جهاز اتصال,
TCP/UDP·FTP, C محول_برمجي_أداة 이식부, MicroPython 이식부, بنية_نظام·ينفذ_أمر·اختبارات 도구다.
`golang/worldos/나라/KOR/مصدر`의 원칙처럼 기능을 먼저 구분하고 이름을 정한다.
x86 Java 커널과 공용 x86·ARM64 미리 번역기의 ذاتي 선언도 명명 검사에 포함한다.
Linux 실행판의 مضيف أدوات, OpenJDK 보조 أدوات 및 خارجي_قيمة توزيع_قيمة مصدر_شجرة 전체를
한국어로 إعادة_محاولة_قيمة 작성했다는 뜻은 아니다.

## 명명 원칙과 말의 근거

- 명사는 자료의 역할을 나타낸다: `ملف_مؤشر`, `نظير_رقم_المنفذ`, `ذاكرة_ديناميكية`, `لوحة_المفاتيح`.
- 함수는 행위를 나타낸다: `قراءة`, `كتابة`, `فتح`, `إغلاق`, `صافي_يربط`, `يشغّل_تطبيق`.
- TCP의 이어진 بايت_قيمة 흐름과 UDP의 경계 있는 자료를 `صديق`와 `مخطط_بيانات_قناة`로 구별한다.
- 짧은 영어 변수도 쓰임에 따라 `길이`, `بيانات_منصب`, `البحث_فهرس`, `반환값`으로 풀어 쓴다.
  순번·임시 산술값처럼 여러 역할에 재사용되는 변수는 `순번`, `첫째값`, `둘째값`으로 구별한다.
- 이름이 같아도 خارجي_قيمة 구조체의 필드와 ذاتي 변수는 별도로 분석한다.

`قناة_إدخال(通路)`는 이동이나 교류가 이루어지는 길이라는 기존 의미를 통신 연결에
적용했다. `منفذ_قيمة(窓口)`의 주고받는 접점이라는 의미를 연결을 받는 곳에 적용했다.
이는 국립국어원 한국어기초사전의 [قناة_إدخال](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=49310),
[منفذ_قيمة](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=24898)의 뜻에 근거한다.

`رزمةمستقلة(電文)`은 전보에 담는 글이라는 기존 통신 어휘에서 가져와, UDP 자료의
경계가 보존된다는 특징을 드러내는 데 쓴다. 근거는
[한국어기초사전 رزمةمستقلة](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=74335)이다.
`بث_قيمة`, `محادثة_قيمة`, `쌓임`은 우리말의 움직임·이어짐·쌓이는 모양을 빌린 표현이다.
`تدفق_المدخلات`, `خيطالعمل`, `ذاكرة_مكدس` 같은 복합 이름은 이 프로젝트의 기능별 조어다.
이 قاموس 근거를 특정 중세 문헌의 최초 출현이나 공인 전산 번역으로 확대하지 않는다.
공인 표준 تحويل_مصدر·국어사 رزمةمستقلة 감수를 마쳤다는 뜻도 아니다.

| 기능 | 채택한 اسم | 이유 |
|---|---|---|
| TCP Socket | صديق | 상대와 연결되어 أمر_قيمة 있는 바이트를 주고받음 |
| ServerSocket | يستلم_منفذ | 새 연결이 들어오는 접점 |
| DatagramSocket | مخطط_بيانات_قناة | 각 자료의 경계를 보존하는 통신 |
| InputStream / OutputStream | تدفق_المدخلات / تدفق_الإنتاج | 들어오고 나가는 바이트의 أمر_قيمة |
| heap / stack | ذاكرة_ديناميكية / ذاكرة_مكدس | يخصص_تخزين 방식과 쌓고 꺼내는 تصميم |
| thread / keyboard | خيطالعمل / لوحة_المفاتيح | 이어지는 실행과 글쇠의 صفيف_قيمة |
| exception / timeout | استثناء / 대기시간초과예외 | أنظمة_المعلومات_عادي 처리에서 벗어남과 그 구체적 이유 |

호환 진입점이며 구현을 두 벌 유지하지 않는다.

## 보존하는 قياسي_تعريف اسم

`public`, `class`, `int`는 예약어다. `String`, `main`, 배열의 `length`는 예약어가 아니다.
حديث_عنصر 다섯 Java 예제는 `تشغيل()`·`실행인수`·العربية 화면/محادثة_قيمة API를 사용해
예약어·리터럴 외의 식별자를 한국어로 작성한다. 화면/가닥은 표준 객체를
감싸지 않고 ذاتي JVM에 직접 구현했다. 자세한 계약은 [العربية Java API](../한국어자바/안내.md)를 본다.

표준 javac는 سلسلة_قيمة 리터럴에 `java.lang.String`, سلسلة_قيمة 결합에 `StringBuilder`
같은 이름을 생성한다. 이들은 العربية 소스에서도 바이트코드에 남을 رقم 있다.
기존 표준 class를 실행하는 JVM의 대응 سلسلة_قيمة, 아직 표준 라이브러리를 쓰는
통신·ملف 연결부까지 모두 한국어로 재구현한 것은 아니다. 이름만 일괄 치환하면
서술자·재정의·native 연결이 달라져 호환성이 깨진다.

C 표준 دالة_قيمة·عدد_صحيح_نوع·POSIX ABI, CPU مسجل اسم, 어셈블리 أمر, 링커 절 اسم,
TinyCC·lwIP·MicroPython이 요구하는 إعدادات 매크로와 헤더 이름도 보존한다.
예: `main`, `memcpy`, `pk_bind`, `mpconfigport.h`, `lwipopts.h`, `stdint.h`.
ذاتي C 함수의 مصدر_شجرة 이름은 한국어이며, [기계연결이름.h](기계연결이름.h)가
기존 AOT·어셈블리·SDK에 공개한 جهاز 심볼과 연결한다.
Python의 `__init__`, `setUp`, `handle`, 표준 وحدة_نمطية_قيمة قيمة_السمة, 명령행 옵션과 JSON 키도
خارجي_قيمة 계약이다. `build/`, توزيع_قيمة 바이너리 이름과 `/sdk`는 기존 ينفذ_أمر 경로를 유지한다.
خارجي_قيمة 원본은 `vendor/`에서 이용허락·해시와 함께 관리한다.

## 검사와 재실행

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 أدوات/명명검사.py
make بنية_نظام
make اختبارات
make test-examples test-ftp test-elf
python3 أدوات/ينفذ_أمر.py --desktop --network
```

`أدوات/시언어이름분석.py`는 libclang 6으로 C 선언과 참조를 검사한다.
`أدوات/*이름반영.py`는 يغيّر_قيمة 전 مصدر_شجرة·분석표를 필요로 하는 일회성 이행 도구다.
이미 변경된 소스에 إعادة_محاولة_قيمة 적용하여 대응표를 덮어쓰지 않는다.

## C 통신 구조체와 Python خطأ

C 통신에서 `갈래`는 عنوان 체계를 구분하고 `رقم_المنفذ`는 port, `عنوان_قيمة`은
IPv4 주소의 32비트 값을 나타낸다. `مخطط_بيانات_بروتوكول`은 앞서 설명한 رزمةمستقلة(電文)과
قيمة_العقد(規約)을 결합해 UDP의 기능을 드러낸 프로젝트 이름이다.

| 표준 표현 | العربية 직접 구현 |
|---|---|
| AF_INET / SOCK_DGRAM / IPPROTO_UDP | enum의 سحابة_عائلة / مأخذ_مخطط_البيانات / مخطط_بيانات_بروتوكول |
| struct pk_sockaddr_in | struct سحابة_مأخذ_التوصيل_عنوان |
| sin_family / sin_port | عنوان_عائلة / رقم_المنفذ |
| sin_addr.s_addr | عنوان_الإنترنت.عنوان_قيمة |
| OSError / خطأ.args[0] | فشل_النظام / خطأ.فهرس |

العربية 구조체는 `#define` 치환이나 قيمة_الحقل 별칭이 아닌 별개 자료형이다.
표준 구조체와 같은 16바이트 배치를 선언하며 نواة_قيمة SVC에서 بايت_قيمة 복사로
검사한다. `فتح_المشارك`·`يرسل_مخطط_بيانات_بيانات`와 ملف 함수는 ثابت_قيمة_f430d3f5 라이브러리에
الفعلي_بيانات العربية 이름의 دالة_قيمة 심볼을 갖는다. 기존 pk_* 심볼도 유지한다.
이전 코드에서 العربية 통신 함수에 pk_sockaddr*를 전달했다면 العربية 구조체로
옮기거나, 표준 구조체와 pk_* 함수의 짝을 유지한다.

Python의 `فشل_النظام`는 OSError의 العربية 하위 클래스이며 연결부에서
خطأ 번호를 보존하여 변환한다. 일반 Python 문법과 خارجي_قيمة 패키지의 API는 유지한다.

## 직접 GUI 이름의 뜻과 검토 يقص

`실행할일`은 수행할 내용을, `تنفيذ`는 그 수행을 나타낸다.
`동작받이`는 동작이 발생했다는 알림을 받는 역할, `إجراء_إشعار`은 전달되는 사건이다.
`زر`는 눌러 동작시키는 조작부, `تسمية`는 안내 글의 منصب_فهرس,
`حقل_نصي`은 글을 적는 منصب_فهرس, `خيطالعمل`은 이어지는 ينفذ_أمر 흐름을 뜻한다.
`ينفذ_أمر(實行)`·`إجراء(動作)`의 기존 뜻과 `받다`·`알리다`·`محادثة_قيمة`의 기능을
결합한 프로젝트 이름이다. 새 복합어가 역사 문헌에 그대로 있었다거나
특정 시대에 처음 쓰였다고 주장하지 않는다.

전체 저장소는 `python3 أدوات/مصدر_تقييم.py`로 검토한다.
결과는 `build/verification/naming/source-review.json`이며 파일별 تجزئة_ملف,
ASCII 파일명과 Python의 영어 إعلان 위치를 기록한다.
공용 ARM64·x86 번역기의 구현은 `compiler/أدواتجافا/مترجممسبق.java`로 전환했다. `compiler/مترجممسبق.py`는 호환 진입점이다.
`compiler/arm64.py`는 이전 경로와 `ARM64(...).generate(...)` 호출을 이어 주는
호환 진입점이다. `compiler/classfile.py`, OpenJDK 보조 أدوات, Linux إصدار_قيمة 도구와
기존 호환 진입점에는 영어 이름이 남아 있다. 따라서 전체 저장소가
예약어 외 100% 한국어라고 판정하지 않는다.
`أدوات/명명검사.py --الرمز_البريدي_لغة`는 نشط ARM64 소스의 إعلان, C 의미 تحليل_قيمة,
x86 Java 커널과 공용 번역기의 ذاتي إعلان, Java 예제 전체 معرف_قيمة,
ARM64 Python 예제와 직접 GUI/가닥에 표준 래퍼가 없는지를 별도로 검사한다.

## حديث_عنصر 기능을 기준으로 보완한 اسم

번역은 글자를 음역하는 대신 자료의 역할과 함수의 행동을 구분한다.
동일한 영어 이름도 문맥이 다르면 العربية 이름을 달리 정한다.
ملف 이름은 주된 기능을 나타내고, دالة_قيمة 이름은 행동을, متغيّر_قيمة 이름은 담는 자료를 나타낸다.
예약어, 표준 API 및 خارجي_قيمة اتصال 규약은 따로 기록한다.

| 이전 اسم | 적용한 اسم | حديث_عنصر 기능 |
|---|---|---|
| `arm64.py`의 구현 | `compiler/أدواتجافا/مترجممسبق.java` | Java 바이트코드를 독립 실행용 C 원문으로 미리 تحويل_مصدر |
| `ARM64`, `generate` | `جهاز_رمز_محول_برمجي`, `إنشاء` | تحويل_مصدر 상태를 담는 객체와 C مصدر إنشاء 행동 |
| `prototype`, `method` | `أسلوب_نموذج_أولي`, `أسلوب_نص_أساسي` | 함수의 ينسق_قيمة 선언과 الفعلي_بيانات أمر مصدر |
| `profile`, `heap_words` | `실행대상`, `كومة_ذاكرة_مؤقتة_عدد_الكلمات` | نواة_قيمة·فضاء_المستخدم 구분과 يخصص_تخزين ذاكرة_قيمة 공간의 جهاز 낱말 رقم |
| `pc`, `op` | `أمر_منصب`, `명령번호` | 바이트코드에서의 위치와 수행할 명령의 فهرس |
| `x`, `y`, `w`, `h` | `الإحداثي_س`, `الزر_Y_إحداثيات`, `영역너비`, `منطقة_ارتفاع` | بعيد_قيمة 화면의 위치와 직사각형 حجم |
| `p`, `n`, `i`, `j` | `بيانات_منصب`, `قيمة`, `순번`, `안쪽순번` | بعيد_قيمة 화면 بيانات·رقم_قيمة·تكرار_قيمة منصب_فهرس; 파일별 기능을 확인해 적용 |
| `aot_heap_info`, `__stack_top` | `شجرة_مكونات_البرنامج_ذاكرة_البحث`, `커널쌓임공간끝` | جهاز اتصال 규약을 유지하면서 ذاتي 소스에서 사용하는 اسم |
| `앞캐리지` | `앞줄복귀` | 앞서 받은 문자가 줄복귀였는지 기억하여 중복 줄바꿈을 막음 |

[공용번역기이름대응.tsv](공용번역기이름대응.tsv)에 محول_برمجي_أداة 참조의 الفعلي_بيانات يغيّر_قيمة 기록을 남겼다.
추가로 보존한 C·POSIX/lwIP/libassh 이름의 이유는
[قياسي_اسم_دليل.json](قياسي_اسم_دليل.json)에 기록한다.
`الرمز_البريدي_محول_برمجي/محول_برمجي_أداة.c`는 TinyCC خارجي_قيمة 원문을 포함하는 اتصال 파일로 ذاتي 선언이 없어서
C ذاتي إعلان 분석에서는 제외한다. الفعلي_بيانات نواة_قيمة 빌드에서는 계속 컴파일한다.

### 말의 뿌리와 새로운 복합 اسم

`ذاكرة_قيمة(記憶)`과 `البحث_فهرس(索引)`은 기존 한자어를 쓴다.
기억은 자료를 간직하는 기능에, 색인은 أمر_قيمة 있는 항목을 찾아 지정하는 기능에 적용한다.
قاموس 근거는 국립국어원 한국어기초사전의
[ذاكرة_قيمة](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=38812&nation=eng),
[البحث_فهرس](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=63787)이다.

`ذاكرة_مكدس`, `دفع_قيمة`, `꺼내기`는 자료를 포개고 마지막 자료부터 꺼내는 ينفذ_أمر 구조를 드러낸다.
`쌓다`의 기존 뜻에 근거한 기능별 조어이며, 사전의
[쌓다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62095)를 참고한다.
`미리번역`은 ينفذ_أمر 전에 번역한다는 기능을 직접 나타낸다.
`جهاز_الكلمات`은 처리기의 بيانات 단위를 가리키며, 언어의 일반 낱말과 구별하도록 `جهاز`를 붙였다.
`مترجممسبق`, `كومة_ذاكرة_مؤقتة_عدد_الكلمات` 같은 복합 이름은 حديث_عنصر 기능에 맞게 만든 프로젝트 용어다.
이 복합어가 옛 문헌에 그대로 있었다거나 특정 시대에 처음 나타났다는 뜻은 아니다.
확인되지 않은 중세 형태나 최초 يستخدم_قيمة 연대는 어원 근거로 적지 않는다.

생성되는 C의 내부 نوع_البيانات·صفيف_قيمة·دالة_قيمة·محلي_نطاق متغيّر_قيمة·فرع 이름도 한국어로 바꾼다.
직접 한글 식별자를 읽지 못하는 예전 GCC를 위해 호환 API는 같은 العربية 이름을
표준 C 범용 문자 표기로 출력한다. الفعلي_بيانات ARM64 빌드는 Clang으로 읽을 رقم 있는 한글 원문을 사용한다.
سلسلة_قيمة, C 표준 دالة_قيمة, `java_entry` 같은 공개 اتصال 이름은 바꾸지 않는다.

셸의 사용법·문법 خطأ·ملف 및 ذاكرة_قيمة عنوان_منطقة 안내도 한국어로 보완했다.
`READY`, `PASS`, `HEX BEGIN`처럼 اختبارات·ملف نقل_قيمة_630ba093 도구가 읽는 علامة_قيمة_7e8f90bd,
명령행 옵션과 기존 تعليمة_قيمة, JVM فئة_قيمة_55654bf1 اسم·ملف ينسق_قيمة·جهاز_قيمة 이름은 호환 표기로 남는다.
x86 VGA 문자 화면은 한글을 표시하지 못하므로 العربية 문구는 UTF-8 직렬 단말에서 확인한다.
