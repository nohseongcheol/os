# Java 네이티브 මෙහෙයුම්_පද්ධතිය

이 문서는 기존 **x86 කර්නලය_අගය**을 설명한다. Raspberry Pi 4의 자체 ARM64 초기 이식은 [별도 README_ගොනුව_eb81d7d9](../platforms/rpi4-native/README.md)를 참고한다. 아래 x86 පරිශීලක ELF·네트워크·IDE ගබඩා_කරන්න_අගය 기능이 ARM64에 모두 이식된 상태는 아니다.

Java 원문을 자체 AOT 후단으로 x86 기계어로 컴파일해 부팅하는 작은 운영체제다. 커널과 별도로 자체 제한형 Java 컴파일러·JVM ELF를 පරිශීලක 모드에 적재할 수 있다. Linux, engos, koros4와 외부 OpenJDK는 게스트에 적재하지 않는다. 부팅 진입과 포트/물리 기억공간 접근은 어셈블리이며, 문자 단말·입력 ක්_රියාවලිය_අගය_පිවිසුම·විධානය විශ්ලේෂණය_කරන්න_අගය·작업 අංශය_අගය 관리는 `මූලය/*.java`에 있다.

## 게스트 Java 개발

`javac Hello.java`, `java Hello`로 부팅된 මෙහෙයුම්_පද්ධතිය 안에서 සාදන්න_මූලය·실행한다. `edit FILE.java`와 `.save`로 소스를 작성하며 `ls`, `cat`, `rm`을 제공한다. RAM 파일은 최대 8개, 각각 16KiB이다. 전용 IDE 매체를 연결하면 `sync`로 보존할 수 있다. 이 기능은 자체 제한형 구현이며 전체 OpenJDK/JDK 호환은 아니다. 사용법·සහාය_අගය 문법·ගොනු 적재·교차 시험은 [Java 개발 환경](../문서/자바개발환경.md)에 있다. `make test-java`로 검증한다.

## 빌드와 ක්_රියාත්මක_කරන්න_විධානය

`compiler/`가 요구하는 도구에 더해 ISO 생성에는 `grub-file`, `grub-mkrescue`, GRUB BIOS 모듈, `xorriso`가 필요하다. 실행에는 QEMU 또는 VirtualBox가 필요하다. 현재 설치된 도구만 사용한다. `make run-store`는 새 전용 가상 ගබඩා_කරන්න_අගය 매체를 만들어 연결한다. VirtualBox 실행기는 이 프로젝트가 만든 전용 VM만 설정하고 다른 VM은 변경하지 않는다. 가상 메모리는 පෙරනිමි_අගය 64MiB이며 최소 16MiB가 필요하다.

```sh
cd /home/user/jkoros/os
make                 # build/kernel.elf
make iso             # build/kernel.iso (පරිශීලක ELF සමූහය_අගය 포함)
make run             # ELF 직접 부팅, 직렬 단말
make run-gui         # GRUB ISO 부팅, VGA 창과 PS/2 자판
make vbox            # 상위 폴더의 실행기로 전용 VirtualBox VM ක්_රියාත්මක_කරන්න_විධානය
make vbox-status     # 전용 VirtualBox VM තත්වය_අගය තහවුරු_කරන්න
make test            # ELF와 ISO 두 경로의 තථ්_ය_දත්ත 부팅/입력 시험
make apps            # පරිශීලක 프로그램만 තැනුම_පද්ධතිය
make test-network    # පරිශීලක ක්_රියාත්මක_කරන්න_විධානය/UDP/ආරක්ෂා_කරන්න_අගය 시험
```

`make run`은 QEMU의 직렬 표준 입출력을 쓴다. `Ctrl+A`를 누른 ආපසු_අගය `X`로 QEMU를 종료할 수 있다. `halt`는 게스트 CPU만 정지시키므로 QEMU කවුළුව/프로세스는 별도로 닫는다. 폴링 방식이라 대기 중에도 ධාරකය CPU를 사용할 수 있다.

VirtualBox는 `make vbox`로 실행한다. 새 전용 VM을 මතකය_දත්ත 64MiB, BIOS, 광학 드라이브 부팅으로 자동 설정하며 디스크는 필요 없다. තථ්_ය_දත්ත VirtualBox 5.2.42에서 부팅, Java 자체 시험, කවචය 입력, `run hello vbox`의 ring 3 실행과 정상 종료를 확인했다. 현재 통신 드라이버는 QEMU의 RTL8139 전용이며 VirtualBox의 PCnet/E1000에서는 네트워크를 사용할 수 없어 네트워크 장치를 비활성화한다. ගබඩා_කරන්න_අගය තත්වය_අගය 재개와 새 තැනුම_පද්ධතිය 반영 방법은 [VirtualBox ක්_රියාත්මක_කරන්න_විධානය README_ගොනුව_eb81d7d9](../문서/가상상자실행.md)에 있다.

## 셸에서 පරිශීලක යෙදු_f5044b9b ක්_රියාත්මක_කරන්න_විධානය 및 네트워크 호출

독립 ELF32 ක්_රියාත්මක_කරන්න_විධානය 파일을 적재해 **ring 3**에서 실행한다. `int 0x80` 시스템 호출을 통해 단말 출력, විස්තාරක විමසුම_අගය, UDP විවෘත_කරන්න·ඊමේල්·받기·닫기를 제공한다. පරිශීලක 코드를 කර්නලය_අගය 함수로 직접 호출하는 구조가 아니다.

```text
jkoros> apps
jkoros> run hello first second
jkoros> net
jkoros> run netcheck
jkoros> run udp 10.0.2.2 9000 hello
```

마지막 명령의 응답을 받으려면 호스트의 별도 터미널에서 `python3 /home/user/jkoros/os/මෙවලම්/자료되돌리기.py --port 9000`을 먼저 실행한다. 상세 API, යෙදු_f5044b9b 추가, යොමුව 공간과 제한은 [පරිශීලක ක්_රියාත්මක_කරන්න_විධානය·네트워크 README_ගොනුව_eb81d7d9](පරිශීලක/README_ගොනුව_eb81d7d9.md)에 있다.

## 구현한 기능

- GRUB Multiboot 1 ELF 부팅, x86 ආරක්ෂා_කරන්න_අගය ප්_රකාරය_අගය GDT, BSS මුලපුරන්න, 64KiB 스택.
- Java ශ්_රිතය_අගය තථ්_ය_දත්ත 실행과 부팅 පද්ධති_තොරතුරු 표식 තහවුරු_කරන්න.
- COM1 직렬 ආදාන_ප්_රතිදාන, VGA 문자 화면·කර්සරය_අගය·스크롤·지우기.
- PS/2 පෙරනිමි_අගය 자판, 좌우 Shift, Enter, Backspace. දිගුව_අගය යතුර_අගය/마우스 자료는 විධානය 입력으로 쓰지 않는다.
- දිග_අගය 128의 විධානය 입력 버퍼, පිටාරය_අගය 방지, CR/LF ක්_රියාවලිය_අගය_පිවිසුම.
- `help`, `info`, `mem`, `alloc`, `free N`, `echo TEXT`, `clear`, `test`, `halt`.
- 4KiB 작업 අංශය_අගය 8개의 විබෙදන්න_ගබඩාව·반환·재사용과 중복 반환 방지.
- Java ආරා_ව_අගය 256KiB 영역의 ප්_රමාණය·යටිලකුණ_අගය 검사와 런타임 දෝෂය 중단.
- කියවීම 전용 JKAP ක්_රියාත්මක_කරන්න_විධානය සමූහය_අගය, ELF32 අංශය_අගය/පිවිසුම_ලකුණ වලංගු_කරන්න, පරිශීලක ප්_රකාරය_අගය·විස්තාරක·පිටවීම_යෙදු 코드.
- කර්නලය_අගය/පරිශීලක 페이지 අවසරය_අගය 분리, TSS, IDT, PIT 100Hz, පරිශීලක CPU 예외 ක්_රියාවලිය_අගය_පිවිසුම 및 ක්_රියාත්මක_කරන්න_විධානය 시간 상한.
- PCI RTL8139 폴링 드라이버, ARP, ස්ථිතික_අගය IPv4, UDP 검사합·송수신·대기 제한.

`mem`의 Upper memory는 Multiboot의 1MiB 위쪽 연속 මතකය_දත්ත ප්_රමාණය(KiB)이며, 전체 මතකය_දත්ත 지도 분석이나 자유 물리 මතකය_දත්ත 수치가 아니다. `alloc`은 이미 확보한 පූර්ණාංකය ආරා_ව_අගය 안의 작업 අංශය_අගය 번호를 반환한다. 일반 물리 පිටුව_අගය විබෙදන්න_ගබඩාව, යොමුව 공간 또는 පරිශීලක ක්_රියාවලිය_අගය මතකය_දත්ත 관리가 아니다.

## 명시적인 한계

이 커널은 **පරිශීලක 프로그램을 한 번에 하나 실행하는 초기 කර්නලය_අගය**이다. PIT IRQ0만 사용하며 키보드와 NIC는 폴링한다. පරිශීලක CPU 예외는 해당 프로그램을 끝내고 셸로 복귀시키지만 කර්නලය_අගය 예외는 중단한다. ක්_රියාත්මක_කරන්න_විධානය 시간은 약 3초로 제한한다. 완전한 선점 다중 ක්_රියාවලිය_අගය 스케줄러, FAT/ext 등 일반 디스크 ගොනු_පද්ධතිය, TCP·DNS·DHCP·IPv6·HTTP, 전체 POSIX, 일반 වස්තුව_අගය 모델/GC는 아직 없다. 전용 IDE ගොනු 보존과 POSIX ගොනු/UDP 일부 기능은 구현했다. JVM은 RAM 파일의 단일 클래스를 ක්_රියාත්මක_කරන්න_විධානය 시 적재하며 일반 ClassLoader나 JAR 로딩은 지원하지 않는다. 네이티브 ක්_රියාත්මක_කරන්න_විධානය 파일은 තැනුම_පද්ධතිය 시 කියවීම 전용 묶음에 넣으며, 일반 Linux ELF를 실행하는 환경이 아니다. 기존 `../පැවත_එන_මූලය/`의 JVM 관리 කර්නලය_අගය 전체를 이식한 것도 아니다.

Java 식별자는 한국어다. 직렬 출력은 이 프로젝트의 한글(BMP 문자)을 UTF-8로 표시한다. VGA는 පෙරනිමි_අගය ASCII 글꼴만 사용하므로 한글 자리에 `?`가 나온다. විධානය 입력도 현재 ASCII만 지원하며 한글 ෆොන්ටය_අගය·입력기 및 보조 평면 문자 출력은 후속 작업이다. `test`는 작은 배열을 새로 할당하고 GC가 없으므로 무한 반복하지 않는다.

## 자동 시험

`시험/부팅시험.py`는 디스크 없는 독립 QEMU를 생성해 다음을 검증하고 종료한다.

- ELF 직접 부팅 및 GRUB ISO 부팅.
- Java 자체 시험과 UTF-8 직렬 문구.
- විධානය දර්ශනය_උදව්ව·පද්ධති_තොරතුරු·මතකය_දත්ත·출력·දෝෂය 입력·화면 지우기.
- 작업 අංශය_අගය 8개 විබෙදන්න_ගබඩාව, 부족 ක්_රියාවලිය_අගය_පිවිසුම, 반환/중복 반환/재할당.
- 직렬 줄바꿈·백스페이스·긴 입력 ක්_රියාවලිය_අගය_පිවිසුම.
- QEMU PS/2 යතුර_අගය 입력으로 `info` ක්_රියාත්මක_කරන්න_විධානය, `halt` 정지.

성공 로그는 `build/부팅시험.json`에 남는다. 로컬 Unix 소켓을 금지하는 샌드박스에서는 시험 도구에 해당 권한이 필요하다. 시험 도중 새로 만든 QEMU만 종료하며 기존 VM과 තථ්_ය_දත්ත 디스크는 건드리지 않는다.

`시험/사용자통신시험.py`는 ELF/ISO 각각에서 පරිශීලක ELF, තථ්_ය_දත්ත ring 3, විස්තාරක, ධාරකය 루프백 UDP 왕복, 1,023/1,024바이트 24회 연속 왕복, 시간 초과, NIC 없음, මතකය_දත්ත/포트 ප්_රවේශය_පිවිසුම 차단, CPU 예외, 무한 පුනර්කරණය_අගය, 잘못된 ELF를 시험한다. `build/사용자통신시험.json`에 게스트 기록과 호스트가 받은 데이터의 දිග_අගය·해시를 저장한다. `시험/패킷시험.py`는 තථ්_ය_දත්ත Java කාරණය_අගය 처리기에 손상된 패킷을 넣어 2,201개 경계/검사합 조건을 검사한다. ධාරකය 루프백 외 외부 서버에는 시험 트래픽을 보내지 않는다.

부트 경계는 GNU의 [Multiboot 명세](https://www.gnu.org/software/grub/manual/multiboot/multiboot.html)를 따른다.
