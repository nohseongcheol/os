# 자체 ARM64 JVM 0.4와 한국어 ලේඛාගාරය

한국어 통신·예외 사용법은 [한국어 Java API](한국어자바/README_ගොනුව_eb81d7d9.md), ශ්_රිතය_අගය·변수·ගොනු 이름의 변경과 어원 근거는 [명명 README_ගොනුව_eb81d7d9](명명/README_ගොනුව_eb81d7d9.md)를 참고한다.

JAR ක්_රියාත්මක_කරන්න_විධානය, 외부 IPv4 TCP/UDP, 별도 ස්ථිතික_අගය 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 වස්තුව_අගය·Thread·Swing은 JVM 경로의 기능이며 AOT සහාය_අගය 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 ක්_රියාත්මක_කරන්න_විධානය**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK පන්තිය_අගය ලේඛාගාරය 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 පන්තිය_අගය·ස්ථිතික_අගය ක්_රමය_අගය 중심이던 실행기를 වස්තුව_අගය·ලේඛාගාරය ක්_රියාත්මක_කරන්න_විධානය 기반으로 넓힌 것이다.

## 실행과 සාදන්න_මූලය

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# 자체 කර්නලය_අගය 안에서 මූලය_රුක සාදන්න_මූලය → class ක්_රියාත්මක_කරන්න_විධානය, 한국어 API 호출
python3 මෙවලම්/ක්_රියාත්මක_කරන්න_ගොනුව.py 시험/자바/한글소스.java

# වස්තුව_අගය·예외 등은 ධාරකය JDK로 Java 8 class를 만든 후 자체 커널에서 ක්_රියාත්මක_කරන්න_විධානය
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 මෙවලම්/ක්_රියාත්මක_කරන්න_ගොනුව.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 මාරුව_අගය
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 මෙවලම්/ක්_රියාත්මක_කරන්න_ගොනුව.py build/my-java/객체시험.class \
  --include build/my-java/පසුබිම_අගය.class --include build/my-java/ශාඛාව_අගය.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.පන්තිය_අගය.class`라는 RAM ගොනු 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.පන්තිය_අගය`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.පන්තිය_අගය`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar ගොනු.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 한국어 클래스만 찾는다. 배포 한국어 ලේඛාගාරය JAR는 ධාරකය javac의 classpath로 사용하며, 같은 클래스가 පරිශීලක JVM ELF에도 කියවීම 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 ස්ථිතික_අගය ක්_රමය_අගය, int/boolean/char/String, තත්වය·පුනර්කරණය_අගය, අනුලකුණු_වැල_අගය 결합, 일부 ගොනු 스트림 등의 **자체 부분집합 컴파일러**다. වස්තුව_අගය 선언·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 자체 JVM에서 실행한다. 한국어 API 중 출력·문자 스칼라 ශ්_රිතය_අගය·ගොනු කියවීම/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] විස්තාරක) throws Exception {
        한국어.자체.출력.ලියන්න_පේළිය("안녕하세요😀");
        한국어.자체.출력.수쓰기(한국어.자체.문자.코드포인트수("한글😀"));
        한국어.자체.ගොනු.ලිවීම("인사.txt", "한글 ගොනු😀");
        한국어.자체.출력.ලියන්න_පේළිය(한국어.자체.ගොනු.කියවීම("인사.txt"));
    }
}
```

컬렉션은 지정한 메서드만 제공하며 iterator/stream/පෙළ_ගස්වන්න_අගය·පරිශීලක නිර්වචනය_අගය equals/hashCode 콜백은 없다. 사전의 열쇠는 String/Integer/null 사용을 시험했다. UTF-16 코드 단위와 Unicode 코드 포인트 수는 구분한다. 한글 입력 조합·ප්_රමත_කරන්න_අගය·아랍어 조판·GUI 다국어 글꼴은 이 අනුලකුණු_වැල_අගය 지원과 별개다.

예외는 Throwable/Exception/RuntimeException, ArithmeticException, NullPointerException, IndexOutOfBoundsException/ArrayIndexOutOfBoundsException/StringIndexOutOfBoundsException, IllegalArgumentException/NumberFormatException/IllegalThreadStateException, IOException/FileNotFoundException, IllegalStateException, ClassCastException, NegativeArraySizeException, ArrayStoreException, UnknownHostException, SocketTimeoutException의 제한된 생성·ප්_රවර්ගය_අගය·처리를 제공한다. පරිශීලක නිර්වචනය_අගය Throwable 상속, stack trace/cause/suppressed 예외, try-with-resources의 addSuppressed, 완전한 මුලපුරන්න දෝෂය 포장은 아직 없다. 잡히지 않은 예외는 현재 전체 Java 실행을 실패로 끝낸다.

## 한국어 API

독립 패키지 **`한국어.자체`**를 사용한다. Linux판 `한국어.자바`가 요구하는 NIO/Swing/HTTP API를 자체 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 පන්තිය_අගය නම·ක්_රමය_අගය·විස්තාරක·ක්_ෂේත්_රය_අගය·ගොනු 이름에 한국어를 사용한다. 표준 Java පන්තිය_අගය 이름은 호환성을 위해 보존한다.

| පන්තිය_අගය | 공개 기능 | 이름의 의미 |
|---|---|---|
| 출력 | ලිවීම, ලියන්න_පේළිය, 수쓰기 | 출력(出力): 내용을 바깥으로 내보냄 |
| 문자 | දිග_අගය, 같음, අලවන්න_පෙළ, කපන්න_අගය, විශ්ලේෂණය_කරන්න_පූර්ණාංකය/ලියන්න_පූර්ණාංකය_අගය, 코드포인트수, 부호화/විගුප්ත_කේතනය_කරන්න_දත්ත | 문자(文字), සංකේතනය_අගය(符號): 글의 단위와 그 값을 바이트로 나타내는 පෙරහන_අගය |
| ගොනු | කියවීම/ලිවීම(String නම), 바이트읽기/ලියන්න_බයිටය_අගය | 널리 쓰는 පරිශීලක 용어를 보존; RAM 자료의 නම |

## ක්_රියාත්මක_කරන්න_විධානය 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(한국어 පන්තිය_අගය 포함), class당 16 KiB·නියතය_අගය 풀 511항목, 전체 ක්_රමය_අගය/ක්_ෂේත්_රය_අගය 각각 512개. ක්_රමය_අගය 코드 8 KiB, ස්ව_විෂය_පථය 변수·피연산자 스택 각각 128슬롯, විස්තාරක 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 ක්_රියාත්මක_කරන්න_විධානය 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- වස්තුව_අගය 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 තථ්_ය_දත්ත 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 ගොනු·대형 අනුලකුණු_වැල_අගය·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 විධානය 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 කවුළුව මාරු_වන්න_ප්_රකාරය 시 중단·재개한다. 일반 සේවාදායකය_අගය·계산의 무제한 실행은 아직 없다. 미지원 විධානය·සම්පත_අගය 부족은 명시적인 오류로 종료한다.
- RAM ගොනු 최대 64개, 파일당 16384바이트, මාර්_ගය UTF-8 63바이트. RAM 디렉터리와 සමානයා_අගය/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 한국어 class는 RAM ගොනු 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 현재 경로에서 මූලය_රුක·පන්තිය_අගය·දත්ත 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 외부 IPv4를 제공한다. තථ්_ය_දත්ත GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. 전문 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 ක්_රියාත්මක_කරන්න_විධානය 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 ආරා_ව_අගය, 완전한 ආරා_ව_අගය 공변성·인터페이스 ස්තරය_අගය 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/ගුප්ත_කේතනය_කරන්න_දත්ත/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 සහාය_අගය 부분집합은 아래 및 개발 매뉴얼을 참고한다. පන්තිය_අගය ගොනු 전체 검증기·ප්_රවේශය_පිවිසුම අවසරය_අගය/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 ආරක්ෂා_කරන්න_අගය 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM අගය/වලංගු_කරන්න/පන්තිය_අගය 로더와 예외 모델 → 영속 VFS·mmap·ඝටිකා_ව·원자 මෙහෙයුම_අගය·තථ්_ය_දත්ත 스레드/සමමු ABI → OpenJDK java.base 및 native ලේඛාගාරය 이식 → ජංගම_අගය 네트워크·TCP/IP → කවුළුව 시스템/ෆොන්ටය_අගය/입력기·java.desktop → Java SE 호환성 시험. 현재 자체 JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## වලංගු_කරන්න

`මෙවලම්/자바가상기계시험.py`는 같은 Java 8 class 파일의 출력을 ධාරකය OpenJDK `-Xverify:all`과 QEMU raspi4b 자체 커널에서 비교한다. වස්තුව_අගය/상속/인터페이스·switch·ආරා_ව_අගය, 예외/finally, 컬렉션/GC, Thread/잠금, 한국어 UTF-8/ගොනු/컬렉션, තථ්_ය_දත්ත UDP 루프백/시간 초과, 게스트 한글 මූලය_රුක සාදන්න_මූලය, ආරා_ව_අගය ටයිප්_කරන්න_අගය/ප්_රස්තාව_අගය/ගොනු 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 ගොනු 거부 시험을 실행한다. UDP 기준 실행에는 ධාරකය 루프백 소켓 권한이 필요하다.

`මෙවලම්/부팅시험.py`는 කර්නලය_අගය ආරක්ෂා_කරන්න_අගය/회귀 시험과 별도로 한국어 Java 화면 API가 තථ්_ය_දත්ත 픽셀을 그렸는지도 QMP 화면 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. තථ්_ය_දත්ත Pi4 하드웨어 부팅 시험과 전체 JDK 호환성 시험 결과는 아니다.


## JVM 0.3: 네트워크와 GUI දිගුව_අගය

`Socket`/`ServerSocket` 생성·සම්බන්ද_වන්න·accept·양방향 InputStream/OutputStream·close·EOF·시간 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 외부 සංඛ්_යාංකය_අගය IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 නිමා_කරන්න_ලකුණ 16개, Java 루프백 버퍼 1024바이트, 외부 TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. අන්තර්ක්_රියාකාරී 이벤트 대기는 ක්_රියාත්මක_කරන්න_විධානය 기한을 갱신하고 අග්_රය මාරු_වන්න_ප්_රකාරය 시 프로세스 상태를 ගබඩා_කරන්න_අගය·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

한국어 `කවුළුව`, `විජෙට්ටුව`, `연결통신` 클래스를 배포 JAR와 자체 JVM 내장 자원에 추가했다. 상세 ක්_රමය_අගය·제한·මූලය_රුක·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## 한국어 객체의 직접 ක්_රියාත්මක_කරන්න_විධානය

`කවුළුව`, `ලේබලය`, `පෙළ_ක්ෂේත්_රය`, `බොත්තම`, `සිද්ධිය_පෙළගැස්ම`, `동작알림`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. 자체 JVM의 වස්තුව_අගය 생성,
හැඩතලය_අගය 검사, 화면 호출, සිදුවීම 큐, පොට_අගය 스케줄러에 한국어 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 ක්_රියාත්මක_කරන්න_විධානය 경로도 유지한다.
한국어 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

자체 실행기의 한국어 진입점은 `public static void ක්_රියාත්මක_කරන්න_2()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 한국어 진입점을 우선한다.
명령행 인수는 `실행인수.개수()`와 `실행인수.පෙළ(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. ස්ථිතික_අගය ගොනු 예제는 게스트
javac로도 컴파일하며, GUI/පොට_අගය 소스는 ධාරකය `javac --release 8`을 사용한다.
직접 GUI/පොට_අගය API는 자체 JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
한국어 가닥의 ක්_රියාත්මක_කරන්න_විධානය·대기·중복 ක්_රියාත්මක_කරන්න_2 거부, GUI සිදුවීම 출처·සූචිය·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

ක්_රමය_අගය 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
한국어 클래스도 실행되지만, අනුලකුණු_වැල_අගය 리터럴·표준 ලේඛාගාරය 재정의·native
සම්බන්ද_වන්න·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.

## අග්_රය 부분 නැවුම්_කරන්න

ගෙනයන්න_අගය·ප්_රමාණය 변경은 새 කවුළුව 영역과 이전 자리에서 드러난 띠만 합성한다.
1920×32 පික්සලය(240 KiB)의 임시 그림에서 배경·겹친 කවුළුව·අනුලකුණ_අගය·GUI를 먼저
완성하고, 현재 දර්ශනය_අගය 메모리와 비교하여 달라진 화소만 기록한다.
32줄보다 큰 영역은 여러 띠로 처리하므로 전체 프레임을 원자적으로
교체하거나 수직 동기에 맞추는 방식은 아니다. 전체 배경을 먼저 지우는
중간 화면은 표시하지 않는다. 좌표가 같으면 다시 그리지 않는다.

`make test-redraw`는 තථ්_ය_දත්ත C 그리기 코드를 호스트의 මතකය_දත්ත 화면에 연결해
ගෙනයන්න_අගය 80회·ප්_රමාණය වෙනස්_කරන්න_අගය 40회·겹친 කවුළුව 4개를 전체 합성 결과와 පික්සලය 단위로 대조한다.
영역 밖 පරිශීලක චිත්_රය_අගය, 동일 පික්සලය 무기록, පොයින්ටරය 밑그림, තථ්_ය_දත්ත 화면 පේළිය 간격을
검사한다. 이 시험의 시간은 ධාරකය CPU 측정이며 Pi 4/QEMU 속도로 해석하지 않는다.
`make test-resize`는 QEMU/VNC의 640×480 및 1920×1080에서 왼쪽 모서리 ඇදගෙන_ඒම_අගය,
한글 입력·vi 미저장 අන්තර්ගතය_අගය·독립 කවුළුව 크기를 검사한다.
