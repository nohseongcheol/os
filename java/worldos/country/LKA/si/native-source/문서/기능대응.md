# engos 기능 대응표

이 표는 기존 `පැවත_එන_මූලය/`의 වස්තුව_අගය 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [තථ්_ය_දත්ත 부팅 기능과 한계](../os/README_ගොනුව_eb81d7d9.md)를 따로 기록한다.

## 기존 වස්තුව_අගය 기반 관리 කර්නලය_අගය 전체를 부팅하기 위해 남은 සම්බන්ද_වන්න

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/ජංගම_අගය 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot පිවිසුම_ලකුණ_අගය, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 සන්දර්භය_අගය ගබඩා_කරන්න_අගය
- තථ්_ය_දත්ත PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA ලූපය_අගය
- Java වස්තුව_අගය·ආරා_ව_අගය සබැඳිය_සැකැස්ම, 예외, ස්ථිතික_අගය මුලපුරන්න, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT අදියර_අගය
- FAT 디스크 구역을 තථ්_ය_දත්ත ATA 장치와 연결하는 ආදාන_ප්_රතිදාන 접착 ස්තරය_අගය

위 관리 계층은 engos 기능의 Java 관리 구현과 ධාරකය 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot පිවිසුම_ලකුණ_අගය, ස්ථිතික_අගය මුලපුරන්න·පූර්ණාංකය ආරා_ව_අගය, VGA/직렬/PS2, 명령해석기, පරිශීලක ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 ධාරකය 루프백 패킷 왕복을 검증했다. 위 표의 වස්තුව_අගය 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
