## 기존 into_inani 기반 관리 ikhenela_inani 전체를 부팅하기 위해 남은 Xhumanisa

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/idivayisi_inani 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot okufakwayo_iphoyinti_inani, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 Umongo_inani Store_inani
- ulwazi_ngokwenzekile_imininingwane PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA iluphu_inani
- Java into_inani·AMALUNGU_AFANAYO_inani xhuma_I_layout, 예외, ngaguquki_inani qalisa, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT isigaba_inani_29ee1bb7
- FAT 디스크 구역을 ulwazi_ngokwenzekile_imininingwane ATA 장치와 연결하는 i_I_O 접착 ugqinsi_inani

위 관리 계층은 engos 기능의 Java 관리 구현과 singatha 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot okufakwayo_iphoyinti_inani, ngaguquki_inani qalisa·inamba AMALUNGU_AFANAYO_inani, VGA/직렬/PS2, 명령해석기, umsebenzisi ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 singatha 루프백 패킷 왕복을 검증했다. 위 표의 into_inani 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
