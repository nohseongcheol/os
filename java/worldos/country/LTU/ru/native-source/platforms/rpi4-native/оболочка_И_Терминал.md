# свой 커널의 GUI 터미널과 оболочка

이 터미널은 свой Java 커널의 셸을 프레임버퍼 창과 UART에서 사용한다. команда Процесс_ЗНАЧЕН_ввод·RAM файл·파이프는 Java ядро_ЗНАЧЕН, 화면의 знак_ЗНАЧЕН 그리기는 freestanding C에서 수행한다. Linux·X11·Bash 없이 동작하며, свой JVM의 Swing опора_ЗНАЧЕН 부분집합도 같은 Окно 시스템을 이용한다. 자세한 vi·다중 Окно·코딩 사용법은 [개발 매뉴얼](개발안내.md)을 참고한다.

## текущий_товар 컴퓨터에서 실행

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, АДРЕС **127.0.0.1:5902**로 연결한다. терминал 창은 자동으로 열린다. 연결한 VNC 창에 키를 입력하면 свой 커널의 셸로 전달된다. 종료하려면 `make desktop`을 실행한 узел 터미널에서 Ctrl+C를 누른다. 포트를 바꾸려면 сборка 후 `python3 инструменты/실행.py --desktop --port 5903`을 사용한다. 서버는 localhost에만 바인드하며 동시에 한 클라이언트가 제어한다.

일반 UART 셸은 `make run`으로 시작한다. QEMU 종료는 Ctrl+A Далее_товар X이다. 같은 VM의 UART에서 `terminal` 또는 F12로 GUI 터미널을 СТОЛБЕЦ_ЗНАЧЕН 수 있다. `gui` 실행 화면에서는 다섯 번째 **OPEN TERMINAL** 버튼, цифра_ЗНАЧЕН 5 또는 T로 연다. `--vnc 127.0.0.1:2`만 사용한 기존 실행 방식은 экран 보기용이며, VNC 키보드를 연결하려면 `--desktop`을 사용한다.

FTP와 внешний_ЗНАЧЕН 네트워크도 함께 쓰려면 `python3 инструменты/실행.py --desktop --network`로
실행한다. Remmina VNC는 `127.0.0.1:5902`, 게스트에서 `ftpd start` 후 FTP는
`127.0.0.1:2121`이다. `--port`, `--ftp-port`, `--forward`를 함께 지정할 수 있다.
한 VM의 보조 UART로 SLIP를 전송하고 주 UART로 GUI 입력을 전달한다.

QEMU 실행 도구가 VNC 키보드/마우스를 UART 입력으로 변환한다. фактический_данные Pi4의 USB 키보드·마우스 드라이버를 구현한 것은 아니다. фактический_данные 보드에서는 текущий_товар UART 입력이 필요하며 실물 부팅은 아직 미검증이다.

## 창과 входные_данные_ЗНАЧЕН

- 640×480~1920×1080 화면에서 최대 네 개 терминал Окно, значение_по_умолчанию 568×360(68열 × 19행)과 Что_нового_ЗНАЧЕН 160행 보관, значение_по_умолчанию ANSI 색상·курсор_ЗНАЧЕН·удалить_ввод_c8dbc399 Процесс_ЗНАЧЕН_ввод.

- F12/заголовок право 버튼/`exit`: Окно Закрыть. 빈 입력에서 Ctrl+D도 창을 닫는다. VM을 종료하는 명령은 아니다.

`--desktop`의 VNC входные_данные_ЗНАЧЕН 연결에 **두벌식 한글 состав_ЗНАЧЕН**을 제공한다. 접속한 PC의
입력기를 영어로 두고 **F9**, **Shift+Space**, **한/нуль_операнд Ключ_ЗНАЧЕН** 중 하나를 누르면

`dkssudgktpdy` → `안녕하세요`. 같은 키로 영어로 돌아간다.
겹받침·복합 모음과 состав_ЗНАЧЕН 단계별 Backspace를 지원한다. курсор_ЗНАЧЕН переместить_ЗНАЧЕН·마우스 клик_ЗНАЧЕН·
단축키·вставить_ЗНАЧЕН·Enter 때 조합을 확정한다. PC가 Shift+Space나 한/нуль_операнд 키를
свой 처리하면 **F9**를 사용한다. Alt 단독은 перейти_МОДА 키가 아니다.

이 조합기는 QEMU의 VNC→UART входные_данные_ЗНАЧЕН 연결에서 실행된다. 일반 직렬 접속과
실물 Pi의 USB 키보드 입력기에 추가된 기능은 아니다. 이미 완성된 Unicode
한글 키도 그대로 전달한다. 클립보드 공유가 활성화되어 표준 VNC ClientCutText가
도착하면 Ctrl+Shift+V로 붙여 넣는다. 클립보드 동기화만으로 명령을 실행하지 않는다.
줄바꿈을 포함해 명시적으로 붙여 넣으면 해당 줄이 실행된다.

게스트에서 `help` 또는 `help ko`를 입력하면 한글 входные_данные_ЗНАЧЕН 안내를 볼 수 있다.
`help`와 `help ko`에는 한/нуль_операнд Ключ_ЗНАЧЕН·Shift+Space·F9 및 `[EN]`/`[KO]` 안내를 표시한다.
긴 도움말은 PgUp/PgDn으로 스크롤한다.

터미널에서 Java·Python·C++ 실행 결과를 바로 볼 수 있다. 프로그램이 직접 프레임버퍼에 그림을 그린 경우 Выход_программа 후 терминал 창을 복원한다. vi/Swing минутку_ЗНАЧЕН 중 다른 창으로 전환하면 해당 EL0 프로그램의 Память_данные·레지스터를 보관하고 돌아올 때 재개한다. выделение_ЗНАЧЕН экземпляр_ЗНАЧЕН·PTY·전체 VT100/xterm 호환과 임의 프로그램의 동시 병렬 실행은 제공하지 않는다. X로 닫으면 해당 창의 프로그램도 종료되므로 vi에서 저장하지 않은 내용은 사라진다.

## 문법과 제한

작은따옴표·큰따옴표·백슬래시, `$NAME`/`${NAME}`/`$?`, Word_ЗНАЧЕН лицевая_камера_ЗНАЧЕН `~`, строка_ввода 주석 `#`, 순차 실행 `;`, условие 실행 `&&`/`||`, 파이프 `|`, входные_данные_ЗНАЧЕН `<`, 새 текстовыйВывод `>`, добавить_ввод текстовыйВывод `>>`를 제공한다. переменная_ЗНАЧЕН 확장은 аргументы 안에서 수행하며 расширение_ЗНАЧЕН 결과를 공백으로 повторить_попытку_ЗНАЧЕН 나누지 않는다. `export`의 값은 оболочка 안에서만 공유하며 пространство_пользователя ELF의 envp/getenv 환경은 아직 없다.

파이프는 각 단계를 순서대로 실행하고 최대 **16384바이트**를 Далее_товар 단계로 넘긴다. 여러 프로세스가 동시에 읽고 쓰는 POSIX 파이프가 아니다. емкость_ЗНАЧЕН 초과는 ошибка 28과 сбой_ЗНАЧЕН 상태를 반환하고 해당 실행을 중단한다. `<`는 EOF를 제공하며 `>`/`>>`는 stdout만 바꾼다. EL0 fd 2는 экран/UART로 출력된다. `2>` 등 번호를 붙인 리다이렉션은 거부한다. 일부 내장 명령의 진단은 stdout을 사용한다. 연결한 프로그램의 `exit N` 진단은 데이터에 섞이지 않도록 생략한다.

`vi`, `edit`, `load`, `gui`, `terminal`, `sh`, `source`에는 파이프와 리다이렉션을 적용할 수 없다. 리다이렉션 파일을 열지 못하거나 파이프 용량을 초과하면 текущий_товар 명령줄을 중단하며, 그 줄의 뒤쪽 `||` 명령도 실행하지 않는다. скрипт_ЗНАЧЕН 파일을 입력할 때 멀티라인 Цитата·이어 쓰기는 제공하지 않는다. `if`/`for`/`while`, ФУНКЦИЯ_ЗНАЧЕН, команда 치환, glob, слово_для_замены_имя, 백그라운드 `&`, jobs/fg/bg, 일반 프로세스·신호·PTY는 아직 없다. Bash/POSIX sh 전체 호환으로 표시하지 않는다.

файл 64개 × 각 16384바이트, 루트 외 디렉터리 15개, файл дескриптор_ввод 16개, путь 최대 UTF-8 63바이트다. одноранговый_ЗНАЧЕН/절대 경로와 `.`/`..`를 정규화하지만 Полномочие_ЗНАЧЕН·심볼릭 링크·마운트·디스크 영속 저장은 없다. **файл·디렉터리·переменная_ЗНАЧЕН·기록의 수정 내용은 재부팅하면 사라진다.** пространство_пользователя 실행도 текущий_товар оболочка 경로를 사용한다. Java/Python/C++의 файл API는 같은 RAM 저장소를 본다. `/example`의 세 Язык 예제와 설명서는 부팅할 때 원본으로 준비된다.

한 명령줄은 4096바이트, 구문 токен_ЗНАЧЕН 128개, 실행 аргументы 32개, 변수는 16개(Название 31바이트·ЗНАЧЕН 255바이트)까지다. пространство_пользователя 프로그램에 전달하는 인수는 기존 ABI대로 최대 8개·각 255바이트다. команда 기록은 1024바이트 이하 줄을 Что_нового_ЗНАЧЕН 16개까지 저장한다.

## 마우스로 Размер изменить_ЗНАЧЕН

네 모서리의 안쪽 8픽셀에 마우스를 대면 방향에 맞는 대각선 양방향 포인터가
나타난다. **왼쪽 버튼을 누른 채 끌고 놓는다.** право 버튼으로는 크기가 바뀌지 않는다.
окно_право 표시줄의 나머지 부분은 переместить_ЗНАЧЕН, право 위 X는 닫기다.
최소 크기는 360×216이며 최대 크기는 текущий_товар экран 안에 제한된다.
각 창의 знак_ЗНАЧЕН 칸은 `(폭-24)/8`СТОЛБЕЦ_ЗНАЧЕН, `(높이-56)/16`행이다. `terminal size`로 조회한다.
