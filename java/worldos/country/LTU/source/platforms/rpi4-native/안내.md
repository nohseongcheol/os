# Raspberry Pi 4 savas Java branduolys_VALUE — naudotojas Vykdyti_komanda 기반

dabartinis_prekė savas 코드의 COSL 상업 sąlyga, 제3자 고지 및 LGPL 재연결 자료는 [COSL paskirstymas_VALUE 안내](COSL배포안내.md)를 참고한다. SWITCH_MODE 전 GPL 구성의 판단은 [이전 라이선스 검토](licencija_atsiliepimas.md)에 기록했다.

Lietuvių 통신·išimtis 사용법은 [Lietuvių Java API](한국어자바/안내.md), FUNCTION_VALUE·kintamasis_VALUE·Failas 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

Linux 없이 부팅하는 savas AArch64 커널이다. Java AOT branduolys_VALUE 위에 **komandų_eilutė apvalkalas, 게스트 Java kompiliatorius·JVM, MicroPython, EL0 C++ Vykdyti_komanda, Failas·UDP 루프백 시스템 호출, 여러 한글 GUI Terminalas·vi Redaktorius·Swing 부분집합**을 제공한다. 커널의 Failas duomenys/정책·루프백 perduoti_VALUE_630ba093·apvalkalas 상태는 Java, 화면 합성·pikselis keisti_VALUE·rodyklė·클리핑도 Java로 구현하며, CPU/MMU/įrenginys_VALUE 경계와 Terminalas·simbolis_VALUE_068c2631 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 savas 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 Vykdyti_komanda, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 laidinis_VALUE 송수신은 아직 미검증이다.** Vykdyti_komanda·ryšys_e05f319b·slaptažodis_VALUE 확인은 [išorinis_VALUE ryšys_e05f319b 안내](išorinis_ryšys_orientyras.md)에 정리했다.

셸은 EL1 branduolys_VALUE, `java` 등 naudotojas Vykdyti_komanda 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 Vykdyti_komanda·ryšys_e05f319b 방법 및 faktinis_duomenys 검증은
[Vykdyti_komanda 계층과 išorinis_VALUE 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 faktinis_duomenys Vykdyti_komanda 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 정적 ELF는 `run --linux failo_vardas_SMS`으로 실행한다. [ELF·Linux ABI pagalba_VALUE 범위와 동일 바이너리 시험](실행파일규약.md).

GUI와 네트워크는 `python3 Įrankiai/Vykdyti_komanda.py --desktop --network`로 함께 사용한다. Java·C·Python의 Lietuvių 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 부팅 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 numeris 있다. Remmina에서 **F9/Shift+Space/한·nulis_operandas Raktas_VALUE**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·faktinis_duomenys TCP/UDP·Failas baitas_VALUE·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java LangoPavyzdys`로 Lietuvių Swing 예제를 실행한다. Terminalas 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 dabartinis_prekė COLUMN_VALUE·ROW_VALUE 수를 보여 준다.

이미지는 확인된 공식 Pi 부팅 묶음에서 `start4.elf`, `fixup4.dat`, Pi4 DTB와 disable-bt overlay를 가져온다. Linux kernel/initramfs/rootfs는 넣지 않는다. 펌웨어·MicroPython·Terminalas šriftas_VALUE 라이선스와 šriftas_VALUE 출처 해시도 동봉한다. Failas generuoti 스크립트는 물리 디스크에 기록하지 않는다.

예비 microSD에 kompiliuoti_IMAGE LOG_RECORD 도구로 `.img`를 기록하거나 FAT32 부팅 파티션 최상위에 ZIP 내용을 푼다. kompiliuoti_IMAGE 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 numatytoji_reikšmė EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD Failas 구성·branduolys_VALUE 체크섬 검사와 물리 Lenta 부팅 검증은 별개다. MMU naudoti_VALUE 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 부팅 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 Lietuvių API naudoti_VALUE

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/FailoPavyzdys.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int Start_naudotojas_programa(int)`이다. naudotojas C++는 FP/SIMD를 사용할 numeris 있다. branduolys_VALUE C/Java AOT는 일반 레지스터만 사용하므로 išimtis Procesas_VALUE_įrašas 중 naudotojas FP 상태를 건드리지 않는다. naudotojas įrašas_p_VALUE 시 FP 상태를 초기화하고 branduolys_VALUE 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int Start_naudotojas_programa(int) {
    int Failas = kurti_Failas("인사.txt", 읽고쓰기 | 없으면만들기 | trumpinti_Turinys, 0600);
    if (Failas < 0) return 1;
    const char Turinys_VALUE[] = "안녕하세요";
    int REZULTATAS = rašymas_Failas_duomenys(Failas, Turinys_VALUE, sizeof(Turinys_VALUE) - 1);
    Uždaryti_Failas(Failas);
    return REZULTATAS == sizeof(Turinys_VALUE) - 1 ? 0 : 2;
}
```

[Failas 예제](naudotojas/FailoPavyzdys.cpp)와 [통신 예제](naudotojas/통신예제.cpp)가 faktinis_duomenys 부팅 시험 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 Failas Procesas_VALUE_įrašas 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 소켓 함수는 dabartinis_prekė 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 branduolys_VALUE 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 toliau_prekė 도구를 사용하면 **새 QEMU를 부팅해 업로드한 faktinis_duomenys 바이트를 재확인한 ATGAL_VALUE 게스트에서 Vykdyti_komanda**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 Įrankiai/Vykdyti_Failas.py build/jkoros-native-sdk/demo.elf
python3 Įrankiai/Vykdyti_Failas.py 예제/Hello.java "한글 Argumentai"
python3 Įrankiai/Vykdyti_Failas.py 예제/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 branduolys_VALUE 묶음에 포함되어 이 Failas 한도를 적용받지 않는다. **C++ 컴파일러는 organizuoti SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 biblioteka, PT_TLS, PT_INTERP, PT_DYNAMIC, Vykdyti_komanda·Rašymas 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 INDEX·ADDRESS klipas·오류는 [naudotojas ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `vykdymas_failų_saugykla`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 teisė_VALUE·dup/fcntl은 없다. 디렉터리와 lygiavertis_mazgas_VALUE/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, gauti_VALUE_cef4d8ab 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. naudotojas Baigti_programa_086bb533 시 열린 Failas 서술자와 소켓을 회수한다.

## Java와 Python의 정확한 klipas

savas `javac`는 버전 49 `.class`를 생성하며 JVM은 pagalba_VALUE 명령으로 구성된 버전 45–52 클래스를 실행한다. 정적 FUNCTION_VALUE·재귀·int/boolean/char/String·sąlyga/sprintas_VALUE·eilutė_VALUE 결합과 일부 Failas 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/struktūra_VALUE 자모 식별자를 처리한다. Unicode identifikatorius_VALUE 전체 LOOKUP_lentelė·Unicode šaltinis_medis 이스케이프는 구현하지 않았다. 게스트 šaltinis_medis 컴파일러는 일반 objektas_VALUE·išimtis·Thread 구문을 아직 컴파일하지 못한다. organizuoti `javac --release 8`로 만든 pagalba_VALUE 부분집합 클래스는 savas JVM 0.4의 objektas_VALUE·išimtis·Thread·UDP와 Lietuvių API를 사용할 numeris 있다. Swing은 문서화한 savas API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [savas JVM aprašas](자바실행환경.md)이 기준이다. 상세 Kalba 범위는 [공유 Java Įrankiai aprašas](../../문서/자바개발환경.md)을 참고하되, 그 문서의 x86 apvalkalas/Store_VALUE/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 šaltinis_medis**를 savas AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 FUNCTION_VALUE·klasė_VALUE·išimtis·리스트/žodynas·Unicode·GC·가변 tikslumas_VALUE 정수를 제공한다. dabartinis_prekė 구성은 sveikasis_skaičius 빌드로 `float`, `complex`, `math`가 없으며 CPython 전체 표준 biblioteka, pip, subprocess, threading, 일반 socket과 numatytoji_reikšmė `open()` Failas 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 objektas_VALUE·모듈은 Baigti_programa_086bb533 시 회수되고 RAM 파일만 toliau_prekė 실행에 남는다.

`import jkoros`로 toliau_prekė 시스템 연결을 쓴다. 모두 SVC를 통해 savas Java 커널에 접근한다.
