# savas ARM64 JVM 0.4와 Lietuvių biblioteka

Lietuvių 통신·išimtis 사용법은 [Lietuvių Java API](한국어자바/안내.md), FUNCTION_VALUE·kintamasis_VALUE·Failas 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

JAR Vykdyti_komanda, išorinis_VALUE IPv4 TCP/UDP, 별도 정적 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 objektas_VALUE·Thread·Swing은 JVM 경로의 기능이며 AOT pagalba_VALUE 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 Vykdyti_komanda**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK klasė_VALUE biblioteka 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 klasė_VALUE·정적 metodas_VALUE 중심이던 실행기를 objektas_VALUE·biblioteka Vykdyti_komanda 기반으로 넓힌 것이다.

JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar Failas.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 Lietuvių 클래스만 찾는다. paskirstymas_VALUE Lietuvių biblioteka JAR는 organizuoti javac의 classpath로 사용하며, 같은 클래스가 naudotojas JVM ELF에도 Skaitymas 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 정적 metodas_VALUE, int/boolean/char/String, sąlyga·sprintas_VALUE, eilutė_VALUE 결합, 일부 Failas 스트림 등의 **savas 부분집합 kompiliatorius**다. objektas_VALUE deklaracija·상속·try/catch·Thread naudoti_VALUE 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 savas JVM에서 실행한다. Lietuvių API 중 Išvestis·문자 스칼라 FUNCTION_VALUE·Failas Skaitymas/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.


## Vykdyti_komanda 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(Lietuvių klasė_VALUE 포함), class당 16 KiB·konstanta_VALUE 풀 511항목, 전체 metodas_VALUE/lauko_reikšmė 각각 512개. metodas_VALUE CODE_VALUE 8 KiB, vietinis_Aprėptis kintamasis_VALUE·피연산자 operandas_eilė 각각 128슬롯, Argumentai 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 Vykdyti_komanda 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- objektas_VALUE 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 faktinis_duomenys 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 Failas·대형 eilutė_VALUE·객체가 이 제한을 넘을 numeris 있다.
- 실행은 50만 바이트코드 Komanda 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 Langas SWITCH_MODE 시 중단·재개한다. 일반 serveris_VALUE·계산의 무제한 실행은 아직 없다. 미지원 Komanda·ištekliai_VALUE 부족은 명시적인 오류로 종료한다.
- RAM Failas 최대 64개, 파일당 16384바이트, KELIAS UTF-8 63바이트. RAM 디렉터리와 lygiavertis_mazgas_VALUE/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 Lietuvių class는 RAM Failas 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 dabartinis_prekė 경로에서 šaltinis_medis·klasė_VALUE·duomenys 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 išorinis_VALUE IPv4를 제공한다. faktinis_duomenys GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. paketų_kelio_schema 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 Vykdyti_komanda 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 ARRAY_VALUE, 완전한 ARRAY_VALUE 공변성·인터페이스 sluoksnis_VALUE 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/Šifruoti_duomenys/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 pagalba_VALUE 부분집합은 아래 및 개발 매뉴얼을 참고한다. klasė_VALUE Failas 전체 검증기·prieiga_įrašas teisė_VALUE/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 apsaugoti_VALUE 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM VALUE/tikrinti/klasė_VALUE 로더와 išimtis 모델 → 영속 VFS·mmap·laikrodis·원자 operacija_VALUE·faktinis_duomenys 스레드/sinchronizuoti ABI → OpenJDK java.base 및 native biblioteka 이식 → įrenginys_VALUE 네트워크·TCP/IP → Langas 시스템/šriftas_VALUE/입력기·java.desktop → Java SE 호환성 시험. dabartinis_prekė savas JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## JVM 0.3: 네트워크와 GUI plėtinys_VALUE

`Socket`/`ServerSocket` generuoti·Prisijungti·accept·양방향 InputStream/OutputStream·close·EOF·TIME_VALUE 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 išorinis_VALUE skaitmuo_VALUE IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 baigti_pokalbį_p 16개, Java 루프백 버퍼 1024바이트, išorinis_VALUE TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. 대화형 이벤트 대기는 Vykdyti_komanda 기한을 갱신하고 Terminalas SWITCH_MODE 시 프로세스 상태를 Store_VALUE·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

Lietuvių `Langas`, `valdiklis`, `ryšys_transportavimas` 클래스를 paskirstymas_VALUE JAR와 savas JVM 내장 자원에 추가했다. 상세 metodas_VALUE·제한·šaltinis_medis·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## Lietuvių 객체의 직접 Vykdyti_komanda

`Langas`, `Pavadinimas`, `teksto_laukas`, `mygtukas`, `įvykis_eilė`, `gavinys_pranešimas`, `darbininkas`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. savas JVM의 objektas_VALUE generuoti,
formatas_VALUE 검사, 화면 호출, Įvykis 큐, gija_VALUE 스케줄러에 Lietuvių 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 Vykdyti_komanda 경로도 유지한다.
Lietuvių 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

savas 실행기의 Lietuvių 진입점은 `public static void Paleisti()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 Lietuvių 진입점을 우선한다.
명령행 인수는 `실행인수.prekė_COUNT()`와 `실행인수.Tekstas(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. 정적 Failas 예제는 게스트
javac로도 컴파일하며, GUI/gija_VALUE 소스는 organizuoti `javac --release 8`을 사용한다.
직접 GUI/gija_VALUE API는 savas JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
Lietuvių 가닥의 Vykdyti_komanda·Palauk_VALUE·중복 Paleisti atmesti_VALUE, GUI Įvykis 출처·INDEX·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

metodas_VALUE 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
Lietuvių 클래스도 실행되지만, eilutė_VALUE 리터럴·표준 biblioteka 재정의·native
Prisijungti·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 예제](한국어자바/안내.md)를 참고한다.

judėti_VALUE·Dydis 변경은 새 Langas 영역과 이전 자리에서 드러난 띠만 합성한다.
