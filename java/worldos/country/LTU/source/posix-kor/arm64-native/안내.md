# savas ARM64 Java 커널의 C/C++ Failas·루프백 Prisijungti

이 디렉터리는 `platforms/rpi4-native` savas branduolys_VALUE 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 Lietuvių 함수명과 `extern "C"` ABI를 제공한다. `Prisijungti.c`는 branduolys_VALUE 안에서 AOT Java Failas 메서드에 직접 연결하고, `naudotojas_tiltas.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. faktinis_duomenys Failas 처리는 `atmintis_Failai.java`, 루프백 paketų_kelio_schema 처리는 `ciklinis_testas_tinklas.java`, 연결형 흐름은 `Stream_tinklas.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 branduolys_VALUE 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·slankiojantis_p_VALUE operacija_VALUE·Failas·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

pagalba_VALUE: `kurti_Failas`, `파일자료읽기`, `rašymas_Failas_duomenys`, `Uždaryti_Failas`, `ieškoti_Failas`, `pašalinti_Failas_įrašas_pavadinimas`, `파일길이정하기`, 보조 FUNCTION_VALUE `failo_dydis`. KLAIDA 시 -1과 작업별 `klaidos_numeris`를 반환한다. `vykdymas_failų_saugykla`은 RAM 파일이므로 ENOSYS를 반환한다. Failas 16개, 각 16384바이트, Pavadinimas_2 63바이트, 서술자 16개이며 RAM 디렉터리·lygiavertis_mazgas_VALUE/절대 경로를 제공한다. teisė_VALUE/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 faktinis_duomenys Lietuvių 함수와 독립 구조체를 선언한다.
`kurti_dalyvis`, `BIND_ADDRESS`, `siųsti_paketų_kelio_schema_duomenys/gauti`, `ryšys_tinklas/기다리기/gauti`는
`naudotojas_tiltas.c`에서 SVC를 호출하며 makrokomanda_VALUE 별칭이 아니다. `struct 인터넷통신주소`의
`ADDRESS_Šeima`, `prievado_numeris`, `interneto_adresas.ADDRESS_VALUE`을 사용한다. 상수는 enum의
`debesis_Šeima`, `paketų_maršruto_schemos_jungtis`, `paketų_kelio_schema_protokolas`, `Stream_tinklas`, `Stream_transportavimo_protokolas`이다.
Lietuvių·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. išorinis_VALUE 통신은 savas 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. faktinis_duomenys Pi 4 GENET 드라이버는 미지원이다.
소켓도 faktinis_duomenys FUNCTION_VALUE `Uždaryti_Failas`로 닫는다.
