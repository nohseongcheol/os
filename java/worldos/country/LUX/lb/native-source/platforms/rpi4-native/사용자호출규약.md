# 자체 ARM64 Benotzer ausféieren_Befeel ABI v1

이 ABI는 `platforms/rpi4-native`의 제한된 freestanding ausféieren_Befeel 환경이다. Linux AArch64 ABI나 POSIX 전체 구현이 아니다. **OpenJDK/JRE, CPython, libc, libstdc++는 아직 이식되지 않았다.**

ELF 로더는 Fichier 확장자 대신 aktuell_Daten ELF 헤더를 검사한다. 아래 자체 ABI와 별도로 `run --linux FILE`에 제한된 Linux ARM64 statesch_VALUE ausféieren_Befeel Fichier 경로를 추가했다. 두 시스템 호출 번호표를 혼합하지 않는다. [ELF·Linux ABI 매뉴얼](실행파일규약.md).

- 한 번에 한 Benotzer 프로그램이 CPU에서 실행된다. 네 터미널에 각 하나씩 interaktiv 프로그램을 일시 정지해 보관할 수 있다. 정상 Schluss_App·예외·TIME_VALUE 초과 시 커널에 복귀하고 열린 Fichier/소켓을 닫으며 Benotzer 페이지 권한을 제거한다.
- statesch_VALUE 생성자와 자동 객체의 RAII 소멸자를 시험했다. `__cxa_atexit`, 표준 C++ 예외/RTTI/STL, 일반적인 전역 Objet_VALUE Schluss_App 등록은 제공하지 않는다.

자체 JVM의 Klass_VALUE·Objet_VALUE 자료를 수용하도록 Benotzer 창을 16 MiB로 확장했다. App_f5044b9b 헤더의 Erlaben_VALUE Clip, 페이지 Geneemegung_VALUE 검사, SDK 링커 Skript_VALUE 및 schützen_VALUE 시험이 같은 배치를 사용한다. 기존에 brk Laf 주소를 상수로 가정한 프로그램은 새 SDK로 다시 빌드한다. 일반 프로그램은 호출 8로 현재 brk를 조회한다.

ausféieren_Befeel 코드는 EL0 읽기/실행만, Daten·힙·스택은 EL0 읽기/쓰기만 허용한다. 나머지 Kernel_VALUE RAM·Mobil_VALUE MMIO에는 EL0 권한을 주지 않는다. 이번 W^X 보장은 **Benotzer 페이지에 대한 것**이다. kernel identity map의 전체 Geneemegung_VALUE 분할이나 다중 프로세스 Adress 공간 전환을 구현했다고 의미하지 않는다.

커널은 `-mgeneral-regs-only`로 빌드한다. Benotzer C/C++는 FP/SIMD를 허용하고, Benotzer Agab_Punkt_VALUE 시 Vecteur_VALUE 레지스터와 FPCR/FPSR를 초기화한다. Kernel_VALUE 복귀용 callee-saved FP 상태를 보관한다. syscall/IRQ의 C 처리부는 FP 레지스터를 사용하지 않는다. 향후 여러 Benotzer 스레드를 전환할 때에는 각 스레드의 전체 FP Kontext_VALUE 보존을 별도로 구현해야 한다.

GIC-400의 물리 타이머 IRQ로 약 2초의 ausféieren_Befeel 기한을 적용한다. SVC 없는 무한 반복도 종료한다. 시스템 호출 Laf 시 기한을 검사하지만 EL1 Prozess_VALUE_Agab 중에는 IRQ를 마스킹하므로 긴 출력/그리기 호출의 종료는 지연될 수 있다. 이것은 App_f5044b9b ausféieren_Befeel 기한이며 일반 선점 스케줄러가 아니다.

## UDP 루프백의 계약

바깥 IPv4는 lwIP/SLIP로 확장했다. 기존 fd/구조체/Uweiser 검사 규약을 유지하며 0.0.0.0 또는 10.0.2.15에 bind한 끝점을 바깥 통신에 연결한다. 127.0.0.1에 명시적으로 bind한 UDP는 루프백에 한정한다. 외부 TCP connect는 비차단 -EINPROGRESS(-115)를 반환할 수 있으므로 같은 주소로 재시도하여 완료를 확인한다. [ausféieren_Befeel/제한](파일전송과번역.md).

`Cloud_Famill`, `전문통신`, Transfer_Protokoll 0/`전문전송규약`을 허용한다. `struct 인터넷통신주소`는 16바이트이며 주소갈래는 Mobil_VALUE SEQUENCE_VALUE, 접속번호와 Internetsadress.주소값은 Reseau_VALUE 차례다. 호환용 pk_sockaddr_in도 같은 배치지만 독립 자료형이다. 한국어 함수는 직접 SVC를 호출하는 aktuell_Daten 함수이며 표준 이름으로 치환하는 매크로가 아니다. Host Linux 헤더를 섞지 않는다.

- 목적지는 127.0.0.1만 Erlaben_VALUE. bind는 0.0.0.0 또는 127.0.0.1, port=0이면 49152…65535에서 빈 창구를 고른다.
- 미바인드 소켓의 첫 전송은 임시 창구를 바인드한다. 같은 창구의 중복 bind는 EADDRINUSE.
- 최대 8개 소켓, 각 큐 4개, 전문은 0…512바이트. 빈 전문도 소비된다.
- 수신 버퍼가 작으면 복사할 부분만 반환하고 전문의 나머지는 버린다. peer Adress/창구를 반환한다.
- flags는 현재 0만 Support_VALUE. 비차단 수신의 빈 큐 및 mailen_VALUE Zil 큐 포화는 EAGAIN이다.
- Zil Port_VALUE 없음은 ECONNREFUSED, 512바이트 초과는 EMSGSIZE, 루프백에 명시적으로 바인드한 UDP의 외부 IP는 ENETUNREACH, UDP 소켓에 잘못된 규약을 지정하면 EPROTONOSUPPORT. SOCK_STREAM은 별도 연결형 루프백에서 제공한다.
- 외부 IPv4 TCP/UDP 헤더·체크섬·재전송은 lwIP가 처리한다. aktuell_Daten GENET/Wi-Fi NIC, poll/select, setsockopt는 아직 없다. 연결형 루프백의 connect/listen/accept는 아래 Extensioun_VALUE ABI로 제공한다.

## 여러 터미널의 Benotzer Kontext_VALUE

interaktiv tty/GUI 대기를 명시적으로 시작한 프로그램은 입력 대기에서 약 2초 기한을 갱신한다. Waart_VALUE 없이 무한 반복하면 타이머로 종료한다. 파이프/리다이렉션/복합 Befeel/스크립트에서 interaktiv 시작은 -ENOTSUP로 거부한다. vi와 Swing의 이벤트 루프가 이 API를 사용한다.

다른 창으로 전환하면 Weider_Element Waart_VALUE SVC에서 EL0 문맥을 저장하고 해당 SVC를 재실행할 위치에서 재개한다. x0…x30, SP/PC/PSTATE, v0…v31, FPCR/FPSR, 매핑·힙·ausféieren_Befeel 인수·Fichier/소켓 소유권을 보관한다. 스냅샷은 Kernel_VALUE 전용 물리 Adress 0x04000000…0x07ffffff(네 Slot_VALUE ×16 MiB)에 저장한다. 현재 aktiv EL0 Adress 창은 종전 0x02000000…0x02ffffff를 사용한다. 스냅샷 저장소는 EL0에서 접근할 수 없다. fork/exec/wait, SMP 또는 일반 선점형 프로세스 스케줄러의 구현은 아니다.

SVC 40은 소유한 연결형 소켓의 Peer_VALUE 포트 번호를 반환한다(자체 JVM용 Ganzzuel Requête_VALUE).

연결형 루프백 fd는 40…55, UDP fd는 32…39다. Schluss_App/Terminal X 닫기에서 해당 프로그램의 Fichier·소켓을 회수한다. 연결형 읽기의 Daten 없음은 -EAGAIN, 상대가 닫고 버퍼도 비면 0, 상대가 닫힌 Zeréck_VALUE 쓰기는 -EPIPE다. 쓰기는 짧게 완료될 수 있다. 큐 용량은 끝점마다 1024바이트이고 한 시스템 호출은 최대 512바이트를 옮긴다. 부모 리스너를 닫으면 아직 accept하지 않은 연결도 회수한다. 외부 연결은 lwIP TCP를 사용하며 외부 수신 버퍼는 4096바이트다. aktuell_Daten GENET NIC 드라이버는 없다.

협력 Waart_VALUE(17)는 일반 선점형 sleep/scheduler 구현이 아니다. 호출마다 최대 100 ms 동안 통신을 처리하고 Benotzer ausféieren_Befeel 기한을 갱신한다. Bëndel 설치기의 비차단 TCP 대기에 사용한다.
