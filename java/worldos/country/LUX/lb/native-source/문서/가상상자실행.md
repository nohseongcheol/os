# VirtualBox ausféieren_Befeel

```sh
cd ~/jkoros
make vbox
```

별도로 VM을 만들거나 ISO를 연결할 필요가 없다. 처음 실행하면 `os/build/kernel.iso`를 빌드하고 `jkoros operating system`이라는 전용 VM을 만들어 VirtualBox 창으로 부팅한다. `jkoros/os` 안에서도 `make vbox`를 사용할 수 있다.

게스트의 `jkoros>` 프롬프트에서 Weider_Element 명령을 입력한다.

```text
help
apps
run hello vbox
```

마지막 명령은 별도 Java ELF를 실행한다. `USER MODE ring 3`, `arg: vbox`, `Exit: 0` 출력 후 셸로 돌아오면 정상이다. VGA 화면은 현재 ASCII 글꼴만 지원하므로 한글은 `?`로 보이며, 한글 원문은 직렬 기록에서 확인할 수 있다.

## Status_VALUE 확인과 다시 ausféieren_Befeel

```sh
make vbox-status
```

이 명령은 VM Status_VALUE, ISO와 직렬 기록의 절대 경로를 JSON으로 출력한다.

| 현재 Status_VALUE | `make vbox` Aktioun |
| --- | --- |
| 아직 생성하지 않음 | ISO Build_System → 전용 VM generéieren → 부팅 |
| 종료됨 (`poweroff`, `aborted`) | ISO Build_System → 광학 매체 aktualiséieren → 새로 부팅 |
| ausféieren_Befeel 중 (`running`) | 재빌드·재부팅 없이 현재 VM 유지 |
| 일시정지 (`paused`) | 기존 VM 재개 |
| 저장됨 (`saved`) | 이전 직렬 기록을 복사해 보관하고 Store_VALUE Status_VALUE 재개 |
| Store_VALUE·Laf 등 SWITCH_MODE 중 | 변경하지 않고 작업 완료 후 재실행하도록 LIESMECH_eb81d7d9 |

Quell_Bamstruktur 변경을 반영하려면 VM을 종료한 Weider_Element 다시 `make vbox`를 실행한다. **Store_VALUE 상태를 재개하면 이전 커널이 계속 실행되므로 새 빌드를 반영하지 않는다.** 실행기는 강제 종료하거나 Store_VALUE 상태를 폐기하지 않는다. VirtualBox 창을 닫을 때 사용자가 전원 끄기를 선택하면 Späicher_Daten 상태가 사라지므로 보존할 작업이 없는지 먼저 확인한다. 게스트의 `halt`는 CPU만 멈추며 VirtualBox의 전원을 끄는 명령은 아니다.

Fënster 없는 실행이 필요하면 VM이 꺼져 있을 때 사용한다.

```sh
make vbox VBOX_TYPE=headless
```

ausféieren_Befeel 중인 VM에 다시 명령을 내려도 GUI/headless 방식은 바뀌지 않는다. Standardwäert Numm 대신 다른 이름이 필요하면 **최초 generéieren 시에만** `VBOX_NAME="원하는 Numm"`을 지정하고 이후에도 같은 값을 사용한다.

## 설정과 Daten 보존

- Standardwäert 설정은 BIOS, Späicher_Daten 64MiB, CPU 1개, VGA Späicher_Daten 16MiB, IDE 광학 부팅이다. 가상 하드디스크를 만들지 않는다.
- VM 설정은 `.vbox/machines/`, Inhalt_VALUE 검사합별 ISO 사본은 `.vbox/media/`, 직렬 기록은 `.vbox/logs/`에 보관한다. `.vbox/state.json`은 전용 VM의 UUID와 Besëtzer_VALUE 표식을 저장한다.
- 꺼진 VM을 부팅할 때 새 직렬 기록을 만든다. Store_VALUE Status_VALUE 재개 전의 기록은 `before-resume-*.log`로 복사한다. Store_VALUE Status_VALUE 자체는 삭제하지 않고 VirtualBox가 그대로 재개한다.
- 같은 이름의 다른 VM을 인수하지 않는다. UUID·Astellungen Wee·Besëtzer_VALUE 표식을 검사하며, 사용자가 별도로 연결한 디스크나 광학 매체를 자동 교체하지 않는다.
- 기존 ISO 사본과 기록은 자동 삭제하지 않는다. `.vbox`는 Git 제외 대상이다. 용량을 정리할 때도 ausféieren_Befeel·Store_VALUE 상태의 VM이 참조하는 파일과 관리 정보를 임의로 삭제하지 않는다.
- VirtualBox 또는 Host 드라이버가 없으면 오류를 안내한다. 자동 installéieren_VALUE, Manager_VALUE Geneemegung_VALUE ausféieren_Befeel, Mobil_VALUE Geneemegung_VALUE 변경은 하지 않는다.

## 네트워크 제한

현재 커널의 RTL8139 드라이버는 QEMU에서 사용한다. VirtualBox의 PCnet/E1000 드라이버는 아직 구현하지 않아 이 실행기는 네트워크 장치를 비활성화한다. 셸과 Benotzer 프로그램은 실행되지만 UDP 열기는 `-19`로 실패한다. UDP 왕복은 `make run`과 [Benotzer ausféieren_Befeel·네트워크 LIESMECH_eb81d7d9](../os/Benotzer/LIESMECH_eb81d7d9.md)의 절차로 시험한다.
