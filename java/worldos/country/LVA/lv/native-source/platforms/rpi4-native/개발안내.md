# savs 커널에서 vi·여러 Terminālis·한글 프로그래밍 사용하기

Latviešu 통신·izņēmums 사용법은 [Latviešu Java API](한국어자바/fails_Lasi_mani_eb81d7d9.md), FUNCTION_VALUE·mainīgais_VALUE·Fails 이름의 변경과 어원 근거는 [명명 fails_Lasi_mani_eb81d7d9](명명/fails_Lasi_mani_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 savs AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 Atbalsts_VALUE 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 Izpildīt_komanda, ārējs_VALUE TCP/UDP와 FTP는 [새 Izpildīt_komanda 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 Terminālis

```sh

```

창마다 pašreizējais_krājums 디렉터리, čaula mainīgais_VALUE, Komanda LOG_RECORD, 입력 중인 명령과 programma_f5044b9b Izpildīt_komanda 상태를 보관한다. Fails 저장소는 공유한다. vi와 Swing의 이벤트 pagaidi_VALUE 중에 다른 터미널로 전환하면 lietotājs atmiņa_dati·레지스터·Fails/소켓 연결을 보존했다가 돌아올 때 재개한다. **pašreizējais_krājums 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 Tālāk_krājums 입력 pagaidi_VALUE 또는 기존 Izpildīt_komanda 기한까지 전환이 지연될 numurs 있다.

X로 터미널을 닫으면 그 터미널의 Izpildīt_komanda 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 Rediģēt_VALUE 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. pašreizējais_krājums 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 Logs 판단은 게스트 커널이 처리한다. QEMU Izpildīt_komanda 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. faktisks_dati Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI Rīki 종료는 viesot 터미널의 Ctrl+C다.
