## Latviešu Java를 게스트에서 컴파일하고 AOT Izpildīt_komanda

게스트 `vi 빛.java`로 Tālāk_krājums 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] Parametri) throws Exception {
        int SUM_VALUE = 0;
        int numurs = 1;
        while (numurs <= 10) {
            SUM_VALUE = SUM_VALUE + numurs;
            numurs = numurs + 1;
        }
        Latviešu.savs.Izvade.rakstīšana_numurs(SUM_VALUE);
        Latviešu.savs.Fails.Rakstīt("aot.txt", "한글 AOT Fails 😀");
        Latviešu.savs.Izvade.rakstīšana_līnija(Latviešu.savs.Fails.Lasīt("aot.txt"));
    }

```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 ģenerēt·연결한다. Izpildīt_komanda 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 Atbalsts_VALUE 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 정적 metode_VALUE/lauka_vērtība, int 계열, vesels_skaitlis 배열과 Uzziņas, Parametri ARRAY_VALUE, nosacījums·zars·sprints_VALUE, virkne_VALUE 리터럴, `System.out.print/println`의 int/String, Latviešu Izvade·Fails Lasīt/쓰기로 제한된다. klase_VALUE/metode_VALUE 수와 operands_kopa 등에도 고정 상한이 있다. Java izņēmums Process_VALUE_ievade, objekts_VALUE ģenerēt, 가상 metode_VALUE 일반, switch/wide, long/float/double, invokedynamic, virkne_VALUE 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 ARRAY_VALUE piekļūt_ievade/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java izņēmums 객체로 전달하지 않는다.

입력 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 līdzināt_VALUE 때문에 짧은 클래스도 이 한도를 넘을 numurs 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 objekts_VALUE·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 Atbalsts_VALUE klips 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 개발 매뉴얼](개발안내.md)을 참고한다.

JAR는 하나의 애플리케이션 klase_VALUE 경로다. 내부 Nosaukums `saistīt/programma_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 Latviešu 클래스를 추가로 찾지만 pašreizējais_krājums 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·Šifrēt_dati ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 numurs/VM kaudze_VALUE 제한은 그대로 적용된다.

## Latviešu 네트워크·작업·화면 API

| klase_VALUE | 호출 예 | Izpildīt_komanda CEĻŠ |
|---|---|---|
| `Izvade` | `rakstīšana_līnija("안녕")`, `rakstīšana_numurs(42)` | JVM 및 제한형 AOT |
| `Fails` | `Rakstīt("문서.txt", "Saturs_VALUE")`, `Lasīt("문서.txt")` | JVM 및 제한형 AOT |
| `통신` | `Atvērt(0)`, `sūtīt(dalībnieks, "10.0.2.2", 9000, "한글")`, `saņemt(dalībnieks)` | JVM의 UDP |
| `paziņa_transportēšana` | `Savienoties("10.0.2.2", 9000)`, `klausīties_dalībnieks(9000)`, `saņemt(serveris_VALUE)` | JVM의 Socket/ServerSocket |
| `작업` | `Palaist(Runnable)`, `기다리기(Thread)`, `YIELD_uzdevums()` | JVM의 협력식 saruna_VALUE |
| `Logs`, `logrīks` | Logs·버튼·rakstzīme_VALUE·teksta_lauks·Notikums Savienoties | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 Latviešu 호출 계층을 추가한다. `통신(通信)`, `Savienoties(連結)`, `Izvade(出力)`은 기존 단어의 뜻을 사용한다. `작업 saruna_VALUE`은 한 Izpildīt_komanda 흐름을 가닥에 빗댄 기술 표현, `ports_VALUE`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

ārējs_VALUE 주소는 cipars_VALUE IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 savs ABI이며 JVM이 제한된 pagaidi_VALUE/재시도를 제공한다. TCP connect 대기는 최대 1초, lietotājs programma_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 Izpildīt_komanda lietotājs 서버와 pthread는 아직 없다. FTP는 lietotājs programma_f5044b9b 기한과 별개인 kodols_VALUE 서비스다.

게스트의 lietotājs TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 Rīki/Izpildīt_komanda.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 noklusējuma_vērtība vadība_VALUE/데이터 포트와 겹치면 Izpildīt_komanda 전에 거부한다.
