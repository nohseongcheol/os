# 전체 Atbalsts_VALUE 요청의 pašreizējais_krājums Statuss_VALUE

pieprasījums 전체는 아직 완료되지 않았다. pašreizējais_krājums ISO는 savs Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 faktisks_dati C POSIX 일부 기능, Latviešu API/AVOTS Nosaukums, IDE Fails 보존, 게스트 Java Fails 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/fails_Lasi_mani_eb81d7d9.md)를 기준으로 판단한다.

| pieprasījums 분야 | pašreizējais_krājums Izpildīt_komanda 가능한 klips | 전체 지원에 필요한 작업 |
|---|---|---|
| Java kompilēt_avots·Izpildīt_komanda | 게스트 제한형 javac/JVM, 정적 단일 클래스와 일부 표준 objekts_VALUE | 일반 objekts_VALUE·klase_VALUE Savienoties·izņēmums·GC·스레드, 완전한 javac와 표준 klase_VALUE bibliotēka |
| Fails | POSIX 서술자, Java 단일 byte_VALUE Fails Stream_VALUE, 전용 datu_nesējs_VALUE 보존 | 일반 java.io/nio, 디렉터리·atļauja_VALUE·bloķēt_VALUE·일반 failu_sistēma·paplašinājums_VALUE 가능한 noslodze_VALUE |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP viesot 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, Pievienot_ievade NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 Notikums·fonts_VALUE·Logs operētājsistēma_VALUE, AWT 네이티브 연결과 Swing Izpildīt_komanda 기반 |
| POSIX | 문서화한 Fails·단말·UDP 부분 | Process_VALUE·exec/fork·스레드·시그널·TIME_VALUE·mmap·poll·파이프 등과 적합성 validēt |
| 언어별 Nosaukums | Latviešu 46개 kartēšana_VALUE ievade_VALUE, faktisks_dati C/Java/Fails Nosaukums 적용 | mērķis Valodas izpilde_VALUE, 언어별 용례·역사 근거와 해당 AVOTS·도구의 validēt |

savs 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 Izpildīt_komanda 환경을 추가하는 방식은 별도의 kodols_VALUE·루트 failu_sistēma·OpenJDK·그래픽 serveris_VALUE·영구 Store_VALUE 구성을 가진 Izpildīt_komanda 경로가 된다. 후자는 기존 savs 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

Izpildīt_komanda 기반과 Pievienot_ievade mērķis 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. pašreizējais_krājums 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
