# jkoros 안에서 Java kompilēt_avots·Izpildīt_komanda

이 문서의 부팅·čaula·Store_VALUE 명령은 **x86 versija_VALUE** 기준이다. 공유 Java kompilators/JVM은 [savs ARM64 Pi4 versija_VALUE](../platforms/rpi4-native/README.md)에도 연결되어 있다. ARM64에서는 UTF-8 UART 입력·한글 faila_nosaukums_SMS, `edit`의 단독 `.` Store_VALUE, 16개 RAM Fails, 약 2초 Izpildīt_komanda 제한을 사용한다.

`javac FILE.java`와 `java CLASS [ARGS]`를 네이티브 jkoros 셸에서 실행한다. 컴파일러와 JVM은 각각 독립 ELF로 적재되어 ring 3에서 동작한다. 소스를 게스트에서 읽어 faktisks_dati JVM `.class` 파일을 만들고, 그 파일의 바이트코드를 게스트 JVM이 해석한다. viesot kompilēt_avots 서버나 Linux 게스트는 사용하지 않는다.

**pašreizējais_krājums 구현은 savs 제한형 kompilators·JVM이다. OpenJDK/JDK 전체를 이식하거나 설치한 것이 아니며 Java SE 호환 환경도 아니다.** 표준 라이브러리는 아래의 일부 호출을 구현한 것이다. `java -version`과 `javac -version`에도 이 범위를 표시한다. 일반 JAR, Maven/Gradle, 임의의 Java programma_f5044b9b 실행은 아직 지원하지 않는다.

## 바로 Izpildīt_komanda

호스트에서:

```sh
cd /home/user/jkoros
make iso
make run
```

게스트에서:

```text
jkoros> javac -version
jkoros> java -version
jkoros> ls
jkoros> cat Hello.java
jkoros> javac Hello.java
Compiled: Hello.class (JVM class version 49)
Exit: 0
jkoros> java Hello
Hello from jkoros JVM!
55
Exit: 0
```

ISO는 `os/build/kernel.iso`다. 기존 VirtualBox 실행기도 같은 ISO를 사용한다. Izpildīt_komanda 중이거나 저장된 VM에는 새 ISO가 자동 반영되지 않는다. 새 부팅 절차는 [VirtualBox Izpildīt_komanda fails_Lasi_mani_eb81d7d9](가상상자실행.md)를 따른다. 이 변경의 Java 자동 시험은 QEMU에서 수행했다.

## 직접 작성

`edit`는 Fails 전체를 새 내용으로 작성한다. 기존 내용의 Līniju Rediģēt_VALUE 기능은 아니다. `.save`로 저장하고 `.cancel`로 취소한다.

```text
jkoros> edit Demo.java
...> public class Demo {
...>  public static int square(int n) { return n * n; }
...>  public static void main(String[] args) {
...>   int n = Integer.parseInt(args[0]);
...>   System.out.println("square=" + square(n));
...>  }
...> }
...> .save
jkoros> javac Demo.java
jkoros> java Demo 12
square=144
Exit: 0
```

- `ls`: 파일과 byte_VALUE numurs rādīt_VALUE.
- `cat FILE`: Fails Saturs_VALUE rādīt_VALUE. 텍스트 소스에 사용한다.
- `rm FILE`: atmiņa_dati Fails 삭제.
- `edit FILE`: 전체 내용을 새로 입력. 빈 파일도 저장할 numurs 있다.
- 구문·TYPE_VALUE 검사 kļūme_VALUE 시 기존 `.class`는 유지된다. 소스를 고친 ATPAKAĻ_VALUE 컴파일이 실패했다면 이전 Izpildīt_komanda 파일이 남아 있으므로 kompilēt_avots 성공 여부를 확인한다.

파일은 RAM에서 동작한다. 전용 Store_VALUE 매체가 없거나 `sync`하지 않은 내용은 재부팅하면 사라진다. `make -C os run-store`로 연결한 매체에는 `sync`로 avots_koks·klase_VALUE·dati 파일을 보존할 numurs 있다. 최대 8개, 파일마다 16KiB, Fails 이름은 ASCII 1~63자다. avots_koks 이름은 `.class` 확장자 adrese_reģions 때문에 최대 62자다. Rediģēt_VALUE 입력은 ASCII이고 한 Līniju 최대 128자다. Līniju 또는 Fails 한도를 넘긴 편집은 `.save`에서 거부하여 기존 파일을 보존한다. kodols_VALUE/kompilators/JVM 구현의 Java 식별자는 한국어이며, pašreizējais_krājums 게스트 입력 제한 때문에 lietotājs 예제 이름은 ASCII로 작성한다.

## ārējs_VALUE Fails 적재

호스트에서 만든 소스나 Atbalsts_VALUE klips 안의 `.class`를 부팅 이미지에 포함할 numurs 있다. `JAVA_FILES`는 `게스트이름=호스트경로` 목록이다. 아래의 경로는 예시이며 faktisks_dati 파일의 절대 경로로 바꾼다. 공백 없는 경로를 사용한다.

```sh
# viesot JDK로 컴파일한 클래스도 사용할 numurs 있다.
javac --release 8 /tmp/Demo.java
make -C /home/user/jkoros iso \
  JAVA_FILES='Demo.java=/tmp/Demo.java Demo.class=/tmp/Demo.class'
make -C /home/user/jkoros run \
  JAVA_FILES='Demo.java=/tmp/Demo.java Demo.class=/tmp/Demo.class'
```

새 부팅 후 `java Demo 12`를 실행한다. 소스만 넣었으면 게스트에서 `javac Demo.java`부터 실행한다. `JAVA_FILES`를 생략한 Tālāk_krājums 빌드에서는 Pievienot_ievade 파일을 포함하지 않는다. Fails Saturs_VALUE 변경과 ievade_Saraksts 제거도 Tālāk_krājums 빌드에 반영된다. 원본 viesot 파일에는 쓰지 않는다. noklusējuma_vērtība `Hello.java`까지 합해 8개이며, 같은 이름을 명시하면 noklusējuma_vērtība 예제를 대체한다. 새 `.class`를 저장할 빈 슬롯도 남겨 둔다.

`--release 8`은 klase_VALUE Fails 버전을 맞추는 옵션이다. 사용하는 문법·바이트코드·라이브러리도 아래 Atbalsts_VALUE klips 안에 있어야 한다.

## Atbalsts_VALUE klips

| 기능 | 게스트 javac | 게스트 JVM |
| --- | --- | --- |
| klase_VALUE | 패키지 없는 단일 klase_VALUE, 정적 FUNCTION_VALUE, 재귀, Parametri/atdot_mērs | 실행마다 단일 klase_VALUE 적재, public static main(String[]) |
| noklusējuma_vērtība VALUE | int, boolean, char, String, main의 String[] Parametri | vesels_skaitlis·Uzziņas operands_kopa, String, int[], String[], 내부 StringBuilder |
| pārskats_VALUE | 초기값 있는 vietējs_Tvērums deklarācija, piešķire_VALUE, `+=`, `-=`, `*=`, `/=`, `%=`, 후위 ++/--, 블록, if/else, while, for, return | 해당 vesels_skaitlis·Uzziņas 바이트코드와 nosacījums zars |
| izteiksme_VALUE | 십진 vesels_skaitlis, UTF-8 소스의 virkne_VALUE/문자, + - * / %, 비교, ==/!=, !/&&/\|\|, virkne_VALUE 결합 | vesels_skaitlis operācija_VALUE·bit_VALUE operācija_VALUE·TYPE_VALUE CONVERT_VALUE, 단락 평가, ARRAY_VALUE piekļūt_ievade |
| Fails | FileInputStream(String), FileOutputStream(String[, boolean]), read()/write(int)/close() | faktisks_dati kodols_VALUE 파일서술자와 Savienoties, ģenerēt·nodzēst_Satura_rādītājs·이어쓰기·EOF |
| Izvade | System.out.print/println: int/boolean/char/String, println() | 동일 |
| virkne_VALUE/Parametri | String.length(), args.length, args[index], Integer.parseInt | 추가로 String.charAt(), virkne_VALUE 상수의 modified UTF-8 해독 |

선언은 지원하는 문법만 허용한다. 여러 변수를 한 선언에 나열하기, 초기값 없는 vietējs_Tvērums deklarācija, 오버로드, 임의 TYPE_VALUE CONVERT_VALUE, ARRAY_VALUE ģenerēt AVOTS, 8/16진 리터럴, Unicode avots_koks 이스케이프 등은 미지원이다. `char`는 문자 리터럴로 초기화하며 일반 JDK의 모든 konstante_VALUE 축소 변환을 구현하지 않는다. ārējs_VALUE `.class`의 `int[]` ģenerēt/Lasīt/쓰기는 지원하므로 viesot `javac --release 8`로 만든 ARRAY_VALUE 예제는 실행할 numurs 있다.

objekts_VALUE lauka_vērtība·일반 objekts_VALUE ģenerēt·상속·인터페이스·여러 klase_VALUE Savienoties, long/float/double, izņēmums Process_VALUE_ievade, 스레드·모니터, 리플렉션, JNI, JIT, GC, 위 표에 없는 `java.io`와 `java.nio`/`java.net` 일반 API, 컬렉션, JAR와 클래스패스는 미지원이다. 런타임 오류는 Java izņēmums 객체를 던지지 않고 진단 후 pašreizējais_krājums 프로그램을 종료한다. 객체와 virkne_VALUE Store_VALUE 공간은 Izpildīt_komanda Iziet_programma 시 lietotājs reģions_VALUE 전체와 함께 회수한다. 지속 Izpildīt_komanda 중 GC는 없다.

## Izpildīt_komanda 한도와 Kļūda

| resurss_VALUE | 한도 |
| --- | --- |
| avots_koks/klase_VALUE Fails | 각각 16KiB |
| kompilators | daļiņa_VALUE 2,047개, ģenerēt CODE_VALUE 4KiB, konstante_VALUE 풀 4KiB |
| FUNCTION_VALUE/Parametri | 클래스당 32함수, 함수당 16인수 |
| JVM konstante_VALUE | 511개 |
| JVM FUNCTION_VALUE CODE_VALUE | 함수당 8KiB |
| JVM 호출/operands_kopa/vietējs_Tvērums mainīgais_VALUE | 32프레임, 프레임당 operands_kopa 128칸·vietējs_Tvērums 128칸 |
| JVM objekts_VALUE Store_VALUE adrese_reģions | 8,192개 32비트 칸, 헤더 포함 약 32KiB |
| Izpildīt_komanda | 최대 500,000 Komanda, 기존 커널의 약 3초 CPU Izpildīt_komanda 상한도 적용 |

게스트 컴파일러는 버전 49.0 `.class`를 생성하며 JVM은 45.0~52.0 중 Atbalsts_VALUE 명령으로 구성된 파일을 읽는다. 스택맵을 이용한 완전한 JVM vārdnīca 검증기를 구현한 것은 아니다. Fails/atribūts_VALUE 길이, konstante_VALUE Uzziņas, Komanda·zars 경계를 검사하고, Izpildīt_komanda 중 operands_kopa formāts_VALUE·vietējs_Tvērums 초기화·ARRAY_VALUE apakšraksts_VALUE·objekts_VALUE 참조를 검사한다. lietotājs 코드의 페이지·포트 접근은 기존 ring 3 경계로 보호한다.

일반 성공은 `Exit: 0`, kompilēt_avots·JVM 오류는 `Exit: 1`, Komanda Parametri 오류는 `Exit: 2`다. CPU TIME_VALUE 상한은 기존 `Exit: 124`이며, lietotājs ELF 자체의 CPU/런타임 오류는 기존 Iziet_programma 코드를 따른다. kļūme_VALUE 후 셸에서 다른 프로그램을 계속 실행할 numurs 있다.

- `os/AVOTS/atmiņa_failu_sistēma.java`: atmiņa_dati failu_sistēma, Rediģēt_VALUE, 부팅 Fails 적재.

`os/시험/자바시험.py`는 ELF/ISO 부팅, 게스트 kompilēt_avots·Izpildīt_komanda, lietotājs 입력, 재귀·반복문·vesels_skaitlis 극값·virkne_VALUE 결합·단락 평가, 재실행, avots_koks Kļūda 후 기존 klase_VALUE 보존, ARRAY_VALUE/numurs 해독 Kļūda, 무한 sprints_VALUE 제한, Rediģēt_VALUE 넘침과 Fails 부족을 검사한다. 게스트 ģenerēt 클래스의 바이트를 QEMU 메모리에서 꺼내 OpenJDK `java -Xverify:all`로 실행하고 결과를 대조한다. 반대 방향으로 viesot OpenJDK의 klase_VALUE, vesels_skaitlis 배열과 한글 상수를 게스트에 적재하며, 손상된 Fails marķieris_VALUE·버전·konstante_VALUE numurs·zars·스택을 거부하는지도 검사한다. 기록은 `os/build/자바시험.json`에 남는다. 디스크 없는 별도 시험 VM만 생성하고 종료한다.

## Java Fails ievadizvade

[FileDemo.java](../posix-kor/자바예제/FileDemo.java)는 일반 Java 표준 klase_VALUE 이름을 사용한다. 소스를 `edit FileDemo.java`로 입력하거나 `JAVA_FILES`로 부팅 이미지에 넣은 ATPAKAĻ_VALUE `javac FileDemo.java`, `java FileDemo`를 실행한다. 결과는 `65`, `255`, `66`, `-1`, `JAVA FILE IO PASS`다. `write(int)`는 하위 8비트를 쓰고 `read()`는 0~255 또는 EOF -1을 반환한다. noklusējuma_vērtība Izvade 생성자는 내용을 비우고, boolean 인수가 true이면 이어쓴다.

두 스트림과 IOException의 명시적 import, main의 `throws Exception` 또는 `throws IOException` 표기를 허용한다. izņēmums objekts_VALUE·try/catch·try-with-resources는 지원하지 않으며 Fails 오류를 진단하고 프로그램을 종료한다. ARRAY_VALUE ievadizvade, InputStream/OutputStream으로의 다형성, Reader/Writer, getFD, 일반 Fails 메타데이터 API는 아직 없다. close는 열린 서술자를 닫고, 재부팅 보존에는 čaula `sync`가 필요하다. 예제의 Fails 이름은 pašreizējais_krājums 셸과 파일체계에 맞춰 ASCII로 쓴다.

`os/시험/자바파일시험.py`는 faktisks_dati 게스트 kompilēt_avots 결과를 OpenJDK `-Xverify:all`로 mēģināt_vēlreiz_VALUE 실행해 Fails 바이트와 출력을 대조한다. 범위와 Store_VALUE datu_nesējs_VALUE 사용법은 [posix-kor fails_Lasi_mani_eb81d7d9](../posix-kor/fails_Lasi_mani_eb81d7d9.md)를 참고한다. 참고한 표준 API는 Oracle [FileOutputStream](https://docs.oracle.com/javase/8/docs/api/java/io/FileOutputStream.html)이다.
