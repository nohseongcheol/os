# 전체 支持值 요청의 当前项目 状态值

申请 전체는 아직 완료되지 않았다. 当前项目 ISO는 内置 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 实际数据 C POSIX 일부 기능, 中文 API/源代码 名称, IDE 文件 보존, 게스트 Java 文件 흐름을 구현하고 시험했다. [구현과 边界位置限制](../posix-kor/指南.md)를 기준으로 판단한다.

| 申请 분야 | 当前项目 执行命令 가능한 裁剪 | 전체 지원에 필요한 任务 |
|---|---|---|
| Java 编译源代码·执行命令 | 게스트 제한형 javac/JVM, 静态值 단일 클래스와 일부 표준 对象值 | 일반 对象值·类值 连接·异常·GC·스레드, 완전한 javac와 표준 类值 库 |
| 文件 | POSIX 描述符条目, Java 단일 字节值 文件 流值, 전용 介质值 보존 | 일반 java.io/nio, 디렉터리·权限值·锁值·일반 文件系统·扩展名值 가능한 容量值 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP 宿主 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 追加条目 NIC |
| GUI·Swing | VGA 字符 终端输入输出 | 프레임버퍼·输入值 事件·字体值·窗口 运行系统值, AWT 네이티브 연결과 Swing 执行命令 基础 |
| POSIX | 문서화한 文件·终端输入输出·UDP 子部分值 | 进程值·exec/fork·스레드·시그널·时间值·mmap·poll·파이프 등과 적합성 有效性校验 |
| 언어별 名称 | 中文 46개 映射值 条目值, 实际数据 C/Java/文件 名称 적용 | 目标值 语言 提交值, 언어별 용례·역사 근거와 해당 源代码·도구의 有效性校验 |

内置 커널을 유지하면 顶端值 基础 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 基础 执行命令 환경을 추가하는 방식은 별도의 内核值·루트 文件系统·OpenJDK·그래픽 服务器值·영구 存储值 구성을 가진 执行命令 경로가 된다. 후자는 기존 内置 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

执行命令 기반과 追加条目 目标值 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 当前项目 원문과 测试 결과를 후속 구현의 출발점으로 보존한다.
