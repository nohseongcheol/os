# ذاتي 커널에서 vi·여러 طرفية·한글 프로그래밍 사용하기

العربية 통신·استثناء 사용법은 [العربية Java API](한국어자바/안내.md), دالة_قيمة·متغيّر_قيمة·ملف 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

대상은 `platforms/rpi4-native`의 ذاتي AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 دعم_قيمة 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 ينفذ_أمر, خارجي_قيمة TCP/UDP와 FTP는 [새 ينفذ_أمر 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 طرفية

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, عنوان **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 طرفية 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **حق 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 ينفذ_أمر 버튼으로 إعادة_محاولة_قيمة عمود_قيمة رقم 있다. 기존 `terminal`, `exit`, F12도 사용할 رقم 있다.

창마다 حديث_عنصر 디렉터리, 셸 متغيّر_قيمة, أمر سجل_سجل, إدخال_قيمة 중인 명령과 تطبيق_f5044b9b ينفذ_أمر 상태를 보관한다. ملف 저장소는 공유한다. vi와 Swing의 이벤트 انتظر_قيمة 중에 다른 터미널로 전환하면 فضاء_المستخدم ذاكرة_بيانات·레지스터·ملف/مأخذ_التوصيل_قيمة 연결을 보존했다가 돌아올 때 재개한다. **حديث_عنصر 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 التالي_عنصر إدخال_قيمة انتظر_قيمة 또는 기존 ينفذ_أمر 기한까지 전환이 지연될 رقم 있다.

X로 터미널을 닫으면 그 터미널의 ينفذ_أمر 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 يحرر_قيمة 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. حديث_عنصر 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 نافذة 판단은 게스트 커널이 처리한다. QEMU ينفذ_أمر 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. الفعلي_بيانات Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI أدوات 종료는 مضيف 터미널의 Ctrl+C다.

## vi يستخدم_قيمة

```text
mkdir 작업
cd 작업
vi 인사.py
```

`vi`는 새로 구현한 **vi أمر 부분집합** 편집기다. 내장 `build/user/vi.elf`를 보호된 فضاء_المستخدم 영역에 적재한다. ملف 크기는 UTF-8 بايت_قيمة يعرض_جذر 16 KiB, 경로는 63바이트까지다. 디스크에 설치한 Vim/Neovim 바이너리를 실행하는 것이 아니다.

| مفتاح_قيمة/أمر | إجراء |
|---|---|
| `i`, `a`, `I`, `A` | حديث_عنصر/التالي_عنصر موضع 또는 سطر 처음/끝에서 إدخال_قيمة |
| `o`, `O` | 아래/위에 새 줄을 만들고 إدخال_قيمة |
| Esc | 일반 الوضع_قيمة |
| `h j k l`, 방향키 | UTF-8 문자/سطر نقل_قيمة |
| `0`, `$`, Home, End | سطر 처음/끝 |
| `gg`, `G`, `:فهرس` | ملف 처음/마지막 سطر/تعيين_قيمة سطر |
| PgUp, PgDn | 화면 درس_قيمة نقل_قيمة |
| `x`, Delete | حديث_عنصر 문자 삭제 |
| `dd`, `yy`, `p` | سطر 삭제/مثيل_قيمة/لصق_نص |
| `u` | 마지막 편집을 إرجاع_جسر; 한 لوحة_قيمة 토글 |
| `/سلسلة_قيمة`, `n` | 단순 سلسلة_قيمة 검색/التالي_عنصر 일치; 정규식 없음 |
| `:w`, `:w 다른이름` | RAM ملف مخزن_قيمة/다른 경로로 مخزن_قيمة |
| `:q` | 변경이 없을 때 خروج_تطبيق |
| `:q!` | 변경을 버리고 خروج_تطبيق |
| `:wq`, `ZZ` | 저장하고 خروج_تطبيق |

붙여 넣은 한글을 문자 경계에 맞춰 نقل_قيمة·삭제한다. 일반 vi의 수량 접두사, ماكرو_قيمة, إعدادات ملف, 플러그인, 정규식, 여러 버퍼/분할 نافذة, 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/صفر_مُعامل 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 نافذة نافذة_عنوان `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 أمر**으로 실행한다. 파이프·리다이렉션·نص_قيمة·`;`/`&&`/`||`로 연결한 실행에서 تفاعلي 대기를 시작하면 거부한다. إدخال_قيمة 대기는 약 2초 CPU 기한을 갱신하지만 إدخال_قيمة انتظر_قيمة 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

vi에서 다음을 `인사.java`에 입력하고 Esc → `:wq`로 저장한다.

게스트 셸에서 실행한다.

```sh
# مضيف

javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java اختبارات/자바/스윙시험.java
python3 أدوات/تحميل_الملفات.py build/my-java/스윙시험.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. مخرجات 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.فئة_قيمة_55654bf1.class` 형식이다. 내장 العربية 라이브러리는 별도 업로드가 필요 없다. العربية نافذة API의 예제는 [한글창시험.java](اختبارات/자바/한글창시험.java)이며 같은 방법으로 يحول_برمجياً_مصدر·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 مصدر_شجرة/클래스는 호스트의 `python3 أدوات/ينفذ_ملف.py مسار/인사.java`로 별도 QEMU에 업로드·ينفذ_أمر·종료할 رقم 있다. تفاعلي Swing에는 ينفذ_أمر 후 فضاء_المستخدم 입력을 유지하는 `make desktop`을 사용한다.

## ذاتي JVM의 Swing يقص

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 ذاتي Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | إجراء |
|---|---|
| `JFrame` | نافذة_عنوان, حجم·موضع, عرض_نافذة, إغلاق 정책, dispose |
| `JPanel` | طفل_قيمة 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 سلسلة_قيمة عرض_قيمة_487749b8·يغيّر_قيمة |
| `JButton` | 버튼과 ActionListener نقرة_قيمة عملية_قيمة_إدخال |
| `JTextField` | 한 سطر UTF-8 إدخال_قيمة, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 ذاتي JVM의 단일 이벤트 ينفذ_أمر 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. نافذة·요소는 ينفذ_أمر 하나당 إجمالي_قيمة 32개, عنصر_قيمة 글자는 최대 127 코드포인트다. قيمة_افتراضية 서체와 색은 커널이 제공한다.

[스윙시험.java](اختبارات/자바/스윙시험.java)는 نافذة·한글 علامة_قيمة·حقل_نصي·버튼·이벤트 처리의 ينفذ_أمر 가능한 예제다. [ذاتي Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

العربية 라이브러리에는 다음을 추가했다. مضيف يحول_برمجياً_مصدر 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `العربية.ذاتي.نافذة`: `يضيف_عنصر`, `عرض_نافذة`, `إغلاق`.
- `العربية.ذاتي.عنصر_شاشة`: `علامة_قيمة`, `زر`, `حقل_نصي` إنشاء.
- `العربية.ذاتي.صديق_نقل`: `اتصال`, `انصات_المشارك`, `يستلم`.
- 기존 `مخرجات`, `문자`, `ملف`, `작업`, `إدخال_قائمة_f07b3200`, `قاموس`, `통신`, `화면`, `نواة_قيمة`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **نواة_قيمة 내부 연결형 بايت_قيمة بث_قيمة**을 추가했다. ملف/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket خادم_قيمة = new java.net.ServerSocket(9250);
java.net.Socket ضيف_قيمة = new java.net.Socket("localhost", 9250);
java.net.Socket اتصال = خادم_قيمة.accept();
ضيف_قيمة.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int 길이 = اتصال.getInputStream().read(받은것);
اتصال.close(); ضيف_قيمة.close(); خادم_قيمة.close();
```

إنشاء·اتصال·accept·양방향 بايت_قيمة/صفيف_قيمة إدخال_إخراج·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 إنهاء_مكالمة_نقطة 16개, يستلم_قيمة 버퍼당 1024바이트, انتظر_قيمة اتصال 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. قيمة_افتراضية قيمة_الوقت 제한 0은 별도 مأخذ_التوصيل_قيمة 기한을 설정하지 않지만 JVM أمر رقم/نواة_قيمة ينفذ_أمر 기한은 여전히 적용된다.

خارجي_قيمة رقم_قيمة IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. الفعلي_بيانات Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP مكتبة 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [يختبر_بث.java](اختبارات/자바/يختبر_بث.java)는 الفعلي_بيانات 송수신·EOF·기한·اتصال 회수의 اختبارات 예제다.

## 한글 Python

게스트 vi에서 한글 이름을 사용해 작성한다.

```python
قيمة = 21

def 두배(رقم_قيمة):
    return رقم_قيمة * 2

print("نتيجة:", 두배(قيمة))
```

مخزن_قيمة 후 `python 인사.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 دالة_قيمة·متغيّر_قيمة·ملف 이름과 문자열을 한글로 쓴다.

[العربية.py](예제/한글코딩/العربية.py)를 같은 디렉터리에 두면 التالي_عنصر 별칭을 사용할 رقم 있다.

```python
import العربية
العربية.كتابة_ملف("인사.txt", "안녕하세요")
العربية.مخرجات(العربية.يقرأ_ملف("인사.txt").decode())
```

مخرجات·ملف قراءة/كتابة/삭제·표준 إدخال_قيمة·مستطيل·قيمة_الوقت·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 رقم_قيمة IPv4 عنوان 전송이다. `wait_key()`는 화면을 확인할 때 تفاعلي 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor ثابت_قيمة_f430d3f5 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 ملحق_قيمة 모듈은 아직 없다. 제한형 `pip`의 مصدر_شجرة 설치는 [Python يُجمع 안내](파이썬꾸러미.md)를 따른다. [세 언어의 الفعلي_بيانات 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 لغة 모두 العربية 헤더와 دالة_قيمة 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 الفعلي_بيانات EL0 ينفذ_أمر اختبارات 대상이다.

```c
#include "파일규약.h"
#ifdef __cplusplus
extern "C"
#endif
int بدء_مستخدم_تطبيق(int وسائط) {
    (void)وسائط;
    const char 인사말[] = "안녕하세요\n";
    int 문서 = فتح_ملف("인사.txt", مقروء_مكتوب | 없으면만들기 | يقتطع_المحتويات, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = كتابة_ملف_بيانات(문서, 인사말, sizeof(인사말) - 1);
    يغلق_ملف(문서);
    كتابة_ملف_بيانات(1, 인사말, sizeof(인사말) - 1); /* حديث_عنصر طرفية stdout */
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 رقم 있다. C는 게스트 `cc` 또는 مضيف SDK, C++는 مضيف SDK의 Clang++로 컴파일한다. 아래 예제는 기존 مضيف SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh

mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/인사.c -o 인사-c.elf
python3 compile.py examples/인사.cpp -o 인사-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 الفعلي_بيانات ينفذ_أمر

python3 أدوات/ينفذ_ملف.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 أدوات/ينفذ_ملف.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

حديث_عنصر GUI VM에서 실행하려면 `python3 أدوات/تحميل_الملفات.py مسار/인사-c.elf`의 출력을 게스트에 보내고 `run 인사-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex اسم_الملف_نص`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 رقم 있다. 호스트와 게스트의 ملف 시스템은 별개다.

| العربية اسم | C رمز | يقص |
|---|---|---|
| فتح_ملف/يغلق_ملف | pk_open/pk_close | RAM ملف, نظير_قيمة/절대 مسار |
| يقرأ_ملف_بيانات/كتابة_ملف_بيانات | pk_read/pk_write | ملف, fd 0/1/2 표준 إدخال_إخراج, 연결형 مأخذ_التوصيل_قيمة |
| يبحث_ملف | pk_lseek | 처음기준/حديث_جذر/إنهاء_مكالمة_نقطة_الأصل |
| حجم_الملف/파일길이정하기 | pk_size/pk_ftruncate | 길이 يستعلم_قيمة/يغيّر_قيمة |
| يزيل_ملف_إدخال_اسم | pk_unlink | ملف اسم 삭제 |
| تثبيت_تخزين_الملفات | pk_fsync | RAM이므로 -1, رقم_الخطأ=ENOSYS |
| فتح_المشارك/يربط_عنوان | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |
| يرسل_مخطط_بيانات_بيانات/يستلم_مخطط_بيانات_بيانات | pk_sendto/pk_recvfrom | UDP 루프백 |
| يتصل_شبكة | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | انتظر_قيمة اتصال 최대 4개 |
| قبول_اتصال_الشبكة | pk_accept | حديث_عنصر عنوان 인수는 NULL/NULL만 دعم_قيمة |
| يقرأ_مأخذ_التوصيل_عنوان | pk_getsockname | 로컬 عنوان/منفذ_قيمة |

`통신규약.h`의 ذاتي `pk_sockaddr_in`을 사용하며 منفذ_قيمة·주소는 `망차례짧은수`/`شبكة_عدد_صحيح`로 변환한다. C مأخذ_التوصيل_قيمة 호출은 비차단이며 بيانات/연결이 없으면 -1과 `رقم_الخطأ=11`(EAGAIN)을 반환한다. 양수 إدخال_إخراج 결과가 요청보다 작을 رقم 있으므로 تكرار_قيمة 처리한다. فشل_قيمة 후에만 오류번호를 확인한다.

[بث_قيمة.c](예제/한글코딩/بث_قيمة.c)는 C에서 العربية 이름으로 اتصال·accept·부분 قراءة/كتابة·큐 포화·EOF를 처리하는 ينفذ_أمر 예제다. SDK의 `examples/بث_قيمة.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → الفعلي_بيانات العربية C دالة_قيمة 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·مؤشر 검사 → Java RAM ملف/루프백 또는 خارجي_قيمة lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 نواة_قيمة 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 اتصال, 표준 C printf, libstdc++/STL, استثناء·RTTI는 제공하지 않으며 C++의 ثابت_قيمة_f430d3f5 생성자·محلي_نطاق عنصر_قيمة_2ed200e9 소멸자는 지원한다. 상세 فهرس·ذاكرة_بيانات 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## التحقق_من_صحة

`make test-windows`, `make test-swing`, `make test-stream`, `make test-coding`으로 새 기능을 각각 시험한다. `make test`는 기존 셸·VNC·JVM·AOT·نواة_قيمة يحمي_قيمة 시험까지 포함한다. الفعلي_بيانات لوحة 대신 QEMU raspi4b에서 수행한다. 결과는 [이전 GUI ملحق_قيمة التحقق_من_صحة سجل_سجل](build/verification/release.json)과 [حديث_عنصر وقت_التشغيل التحقق_من_صحة سجل_سجل](build/verification/native-runtime-summary.json), [여러 طرفية 화면](build/verification/windows/four-terminals.png), [Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

구현 시 참고한 표준 API: [Socket](https://docs.oracle.com/javase/8/docs/api/java/net/Socket.html), [JFrame](https://docs.oracle.com/javase/8/docs/api/javax/swing/JFrame.html), [JButton](https://docs.oracle.com/javase/8/docs/api/javax/swing/JButton.html). 이 문서의 구현 범위가 위 표준 전체를 지원한다는 뜻은 아니다.

## العربية 이름으로 직접 작성하는 창과 محادثة_قيمة

`example/java/مثالنافذة.java`는 `실행할일.تنفيذ`,
`동작받이.يستلم_إجراء(إجراء_إشعار)`, `زر`, `حدث_يدرج.나중에실행`, `تشغيل()`을 쓴다.
ذاتي JVM에 이 이름들의 عنصر_قيمة_2ed200e9·أسلوب_قيمة·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `خيطالعمل`도 ذاتي 스케줄러와 직접 연결된다.
세부 메서드와 기존 العربية API에서의 변경은 [العربية API 문서](한국어자바/안내.md)를 본다.

مضيف javac는 توزيع_قيمة JAR를 فئة_قيمة_55654bf1 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/مثالنافذة.java
python3 أدوات/ينفذ_أمر.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java مثالنافذة
```

직접 화면/محادثة_قيمة API와 `تشغيل()` 진입점은 ذاتي JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 رقم 있다.
