## Română Java를 게스트에서 컴파일하고 AOT executa_comandă

게스트 `vi 빛.java`로 Următorul_element 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] Argumente) throws Exception {
        int SUM_VALUE = 0;
        int 수 = 1;
        while (수 <= 10) {
            SUM_VALUE = SUM_VALUE + 수;
            수 = 수 + 1;
        }
        Română.propriu.Rezultat.수쓰기(SUM_VALUE);
        Română.propriu.Fișier.Scriere("aot.txt", "한글 AOT Fișier 😀");
        Română.propriu.Rezultat.scriere_linie(Română.propriu.Fișier.Citire("aot.txt"));
    }
}
```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 genera·연결한다. executa_comandă 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 suport_VALUE 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 정적 metodă_VALUE/valoare_câmp, int 계열, întreg 배열과 referință, Argumente ARRAY_VALUE, condiție·ramură·sprint_VALUE, șir_VALUE 리터럴, `System.out.print/println`의 int/String, Română Rezultat·Fișier Citire/쓰기로 제한된다. Clasă_VALUE/metodă_VALUE 수와 operand_Teanc 등에도 고정 상한이 있다. Java excepție Proces_VALUE_intrare, obiect_VALUE genera, 가상 metodă_VALUE 일반, switch/wide, long/float/double, invokedynamic, șir_VALUE 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 ARRAY_VALUE acces_intrare/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java excepție 객체로 전달하지 않는다.

입력 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 alinia_VALUE 때문에 짧은 클래스도 이 한도를 넘을 수 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 obiect_VALUE·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 suport_VALUE clip 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 개발 매뉴얼](개발안내.md)을 참고한다.

JAR는 하나의 애플리케이션 Clasă_VALUE 경로다. 내부 Nume `set/program_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 Română 클래스를 추가로 찾지만 curent_element 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·cripta_date ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 수/VM 힙 제한은 그대로 적용된다.

## Română 네트워크·작업·화면 API

| Clasă_VALUE | 호출 예 | executa_comandă Cale |
|---|---|---|
| `Rezultat` | `scriere_linie("안녕")`, `수쓰기(42)` | JVM 및 제한형 AOT |
| `Fișier` | `Scriere("문서.txt", "Conținut_VALUE")`, `Citire("문서.txt")` | JVM 및 제한형 AOT |
| `통신` | `Deschide(0)`, `trimite(participant, "10.0.2.2", 9000, "한글")`, `primi(participant)` | JVM의 UDP |
| `연결통신` | `Conectează("10.0.2.2", 9000)`, `asculta_participant(9000)`, `primi(server_VALUE)` | JVM의 Socket/ServerSocket |
| `작업` | `Pornește(Runnable)`, `기다리기(Thread)`, `YIELD_sarcină()` | JVM의 협력식 fir_VALUE |
| `Fereastră`, `widget` | Fereastră·버튼·caracter_VALUE·câmp_text·Eveniment Conectează | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 Română 호출 계층을 추가한다. `통신(通信)`, `Conectează(連結)`, `Rezultat(出力)`은 기존 단어의 뜻을 사용한다. `작업 fir_VALUE`은 한 executa_comandă 흐름을 가닥에 빗댄 기술 표현, `muta_VALUE`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

extern_VALUE 주소는 cifră_VALUE IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 propriu ABI이며 JVM이 제한된 대기/재시도를 제공한다. TCP connect 대기는 최대 1초, utilizator program_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 executa_comandă utilizator 서버와 pthread는 아직 없다. FTP는 utilizator program_f5044b9b 기한과 별개인 nucleu_VALUE 서비스다.

게스트의 utilizator TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 Instrumente/executa_comandă.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 valoare_implicită control_VALUE/데이터 포트와 겹치면 executa_comandă 전에 거부한다.
