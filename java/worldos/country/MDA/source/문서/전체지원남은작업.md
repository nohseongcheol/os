# 전체 suport_VALUE 요청의 curent_element Stare_VALUE

cerere 전체는 아직 완료되지 않았다. curent_element ISO는 propriu Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 real_date C POSIX 일부 기능, Română API/SURSĂ Nume, IDE Fișier 보존, 게스트 Java Fișier 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/안내.md)를 기준으로 판단한다.

| cerere 분야 | curent_element executa_comandă 가능한 clip | 전체 지원에 필요한 작업 |
|---|---|---|
| Java compilare_sursă·executa_comandă | 게스트 제한형 javac/JVM, 정적 단일 클래스와 일부 표준 obiect_VALUE | 일반 obiect_VALUE·Clasă_VALUE Conectează·excepție·GC·스레드, 완전한 javac와 표준 Clasă_VALUE bibliotecă |
| Fișier | POSIX 서술자, Java 단일 byte_VALUE Fișier flux_VALUE, 전용 suport_fizic_VALUE 보존 | 일반 java.io/nio, 디렉터리·permisiune_VALUE·blocare_VALUE·일반 sistem_de_fișiere·extensie_VALUE 가능한 capacitate_VALUE |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP gazdă 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, adăuga_intrare NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 Eveniment·font_VALUE·Fereastră sistem_de_operare_VALUE, AWT 네이티브 연결과 Swing executa_comandă 기반 |
| POSIX | 문서화한 Fișier·단말·UDP 부분 | Proces_VALUE·exec/fork·스레드·시그널·oră_VALUE·mmap·poll·파이프 등과 적합성 valida |
| 언어별 Nume | Română 46개 mapare_VALUE intrare_VALUE, real_date C/Java/Fișier Nume 적용 | țintă Limbi_străine comitere_VALUE, 언어별 용례·역사 근거와 해당 SURSĂ·도구의 valida |

propriu 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 executa_comandă 환경을 추가하는 방식은 별도의 nucleu_VALUE·루트 sistem_de_fișiere·OpenJDK·그래픽 server_VALUE·영구 Store_VALUE 구성을 가진 executa_comandă 경로가 된다. 후자는 기존 propriu 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

executa_comandă 기반과 adăuga_intrare țintă 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. curent_element 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
