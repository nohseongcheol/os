# зовнішній_значення 배포용 압축과 복원

Ubuntu x86_64에서 프로젝트 루트의 `./pack.sh`를 실행한다.
`dist/jkoros-source.tar.xz`, 체크섬 файл, 독립 Виконати_команда 가능한 `dist/unpack.sh`가 생성된다.
원본 캐시, джерело_дерево, простір_користувача 디스크는 삭제하거나 변경하지 않는다. 압축파일은 2 GB를
넘으면 생성에 실패한다. Вивід 경로는 `./pack.sh /шлях/jkoros-source.tar.xz`로 지정한다.

다른 Ubuntu PC에 압축파일, `.sha256`, `unpack.sh`를 함께 전달한 НАЗАД_значення 실행한다.

```sh
./unpack.sh jkoros-source.tar.xz /원하는/새/шлях/jkoros
make -C /원하는/새/шлях/jkoros all korean-java iso
make -C /원하는/새/шлях/jkoros rpi-native-image
make -C /원하는/새/шлях/jkoros rpi-image
```

стандартне_значення 동작은 Архів_значення випуск_місце 후 의존성 자동 다운로드와 준비까지다. Ubuntu збирання 도구가
없으면 `sudo apt-get`으로 설치하며 관리자 암호가 필요할 수 있다. зовнішній_значення 소스의
SHA-256을 확인하고 ARM64 SDK/Linux Виконати_команда середовище, хост 도구와 JRE를 준비한다.
새 폴더의 위치를 기준으로 실행하므로 `/home/user` 경로를 만들 필요가 없다.

своє ARM64 커널만 개발한다면 `--profile native`로 GUI/Linux Виконати_команда середовище 준비를
생략할 수 있다. збирання 도구가 이미 설치되어 있으면 `--no-host-install`을 추가한다.
`--no-prepare`는 다운로드하지 않고 소스만 검사할 때 쓰는 명시적 선택이다.

Готувати 도중 네트워크 오류가 나면 풀린 폴더에서 `./unpack.sh --prepare`를 пробувати_знову_значення 실행한다.
기존 Вивід Каталог_значення 위에는 압축을 풀지 않는다. 개인 수정 파일을 덮어쓰지 않으며,
복원 мета 파일의 내용이 예상 해시와 다르면 중단한다.

압축에서 `build`, `dist`, `результат`, `.vbox`, Python 캐시, журнал_значення, простір_користувача 디스크와
зв_язок_e05f319b 키를 제외한다. Alpine 패키지 캐시는 외부에서 필요한 패키지만 пробувати_знову_значення 받는다.
libassh, BearSSL, lwIP, uzlib, MicroPython 중 고정 URL/해시로 복구할 수 있는 원본은
제외하지만 로컬 수정 파일은 포함한다. 정확한 재다운로드 주소를 고정하지 못한
TinyCC 스냅샷, своє шрифт_значення, 프로젝트 소스와 라이선스 고지는 포함한다.

인터넷과 Ubuntu 패키지 репозиторій_корінь 및 Alpine 3.24 репозиторій_корінь 접근이 필요하다.
Alpine 저장소의 використання_значення 가능한 패키지 버전을 받아 фактично_дані 버전을 блокувати_значення 파일에 기록한다.
패키지 다운로드 후의 작업 폴더와 збирання 산출물은 2 GB를 넘을 수 있다.
OpenJDK своє 소스의 별도 실험 빌드는 기존 компілятор 안내에 따라 소스를 준비한다.

`PORTABLE_DOWNLOAD_CACHE=/캐시/Каталог_значення`를 지정하면 SHA-256을 파일명으로 하는
검증된 다운로드 파일을 먼저 사용한다. 캐시에 없는 항목은 자동 다운로드한다.
제외 목록과 Архів_значення 크기는 `dist/jkoros-source.tar.xz.report.json`에 기록된다.
