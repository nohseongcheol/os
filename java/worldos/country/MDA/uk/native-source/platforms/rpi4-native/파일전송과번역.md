# своє ARM64 ядро_значення: FTP, C, JAR와 AOT Виконати_команда

대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT ядро_значення**이다. CPU·пристрій_значення 경계는 C/어셈블리, файл 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 хост JVM으로 대신 실행하지 않는다.

## 먼저 알아둘 опора_значення 경계

| запит | 이번 реалізація | 남은 кліп |
|---|---|---|
| JAR를 Виконати_команда 파일처럼 Виконати_команда | `java -jar файл.jar`, `./файл.jar аргументи`; Main-Class와 сховище_значення/DEFLATE ZIP, CRC 검사 | 전체 Java SE, 임의의 모든 JAR 호환성 |
| 게스트 AOT | `jaot файл.class -o файл.elf`, `jaot файл.jar -o файл.elf`; фактично_дані ARM64 기계어 генерувати | об_єкт_значення·виняток·Thread·Swing·Socket의 AOT перетворити_значення, 여러 애플리케이션 Клас_значення З_єднання |
| C компілювати_джерело | 게스트 `cc`/`tcc`, TinyCC C 전처리기·ARM64 생성기·링커; українська 식별자와 posix-kor | 전체 libc, 일반 Linux Виконати_команда файл, 게스트 C++ компілятор |
| 업로드한 ELF Виконати_команда | ELF64/AArch64 헤더 검사, 확장자 없는 `./файл`; своє ABI 및 명시적인 제한형 Linux ABI | 일반 Linux 바이너리 호환, 동적 링커, 공유 бібліотека |
| зовнішній_значення TCP/UDP | 게스트 lwIP IPv4 операнд_Стіс, POSIX 소켓과 JVM의 цифра_значення IPv4 Адреса | GENET/Wi-Fi 드라이버, DHCP·DNS·TLS, 실물 Дошка 네트워크 випробування |
| FTP | 게스트 서비스, 패시브 передача_значення, UTF-8 Назва, STOR/RETR/SIZE/LIST/NLST/MLSD/DELE | TLS·사용자별 дозвіл_значення·하위 디렉터리·영속 сховище_значення |
| 한글 Java | 기존 `українська.своє` 클래스와 зовнішній_значення Адреса UDP 오버로드 | 전체 JDK의 일대일 українська зіставлення_значення API |

JVM은 Клас_значення 버전 45…52의 문서화한 부분집합이다. `java`는 바이트코드 실행기이고, `jaot`가 별도의 네이티브 Виконати_команда 파일을 만든다. **JAR Архів_значення 해제나 JVM을 함께 묶는 것을 AOT라고 표시하지 않는다.** 지원하지 않는 바이트코드/API는 `jaot`가 진단하고 출력을 만들지 않는다. 기존 Вивід ELF도 компілювати_джерело неполадка_значення 때 보존한다.

Android의 Dalvik/ART는 일반 JVM Клас_значення/JAR가 아닌 **DEX**를 실행한다. ART의 AOT에는 GC, Клас_значення 로딩, JNI 등 Виконати_команда 기반도 필요하다. 따라서 ART처럼 기계어로 바꾸는 기능만으로 임의의 OpenJDK JAR 및 Swing이 자동 호환되지는 않는다. [Android 공식 런타임 설명](https://source.android.com/docs/core/runtime)

QEMU의 raspi4b에는 GENET Ethernet 장치가 없다. 따라서 `network_bridge.py`가 QEMU NAT의 Ethernet과 보조 UART의 SLIP를 변환한다. **TCP З_єднання процес_значення_запис·체크섬·재전송·FTP 명령과 файл 저장은 게스트 안에서 수행한다.** хост 브리지는 FTP 서버가 아니다. [QEMU 공식 пристрій_значення опора_значення запис_список](https://www.qemu.org/docs/master/system/arm/raspi.html)

이 경로는 QEMU에서 검증했다. 보조 UART의 фактично_дані Pi 4 핀/클럭 설정과 내장 RJ45 GENET 드라이버는 реалізація·검증하지 않았으므로, SD 이미지에 커널이 포함되어 있다는 사실을 фактично_дані 보드의 LAN/FTP Дія 보장으로 해석하면 안 된다.

## українська Java를 게스트에서 컴파일하고 AOT Виконати_команда

게스트 `vi 빛.java`로 Далі_елемент 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] аргументи) throws Exception {
        int 합 = 0;
        int 수 = 1;
        while (수 <= 10) {
            합 = 합 + 수;
            수 = 수 + 1;
        }
        українська.своє.Вивід.수쓰기(합);
        українська.своє.файл.Запис("aot.txt", "한글 AOT файл 😀");
        українська.своє.Вивід.записування_рядок(українська.своє.файл.Читання("aot.txt"));
    }
}
```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 генерувати·연결한다. Виконати_команда 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 опора_значення 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 정적 метод_значення/значення_поля, int 계열, ціле_число 배열과 довідка, аргументи масив_значення, умова·гілка·спринт_значення, рядок_значення 리터럴, `System.out.print/println`의 int/String, українська Вивід·файл Читання/쓰기로 제한된다. Клас_значення/метод_значення 수와 операнд_Стіс 등에도 고정 상한이 있다. Java виняток процес_значення_запис, об_єкт_значення генерувати, 가상 метод_значення 일반, switch/wide, long/float/double, invokedynamic, рядок_значення 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 масив_значення доступ_запис/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java виняток 객체로 전달하지 않는다.

입력 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 вирівняти_значення 때문에 짧은 클래스도 이 한도를 넘을 수 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 об_єкт_значення·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 опора_значення кліп 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 개발 매뉴얼](개발안내.md)을 참고한다.

JAR는 하나의 애플리케이션 Клас_значення 경로다. 내부 Назва `набір/програма_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 українська 클래스를 추가로 찾지만 чинний_елемент 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·шифрувати_дані ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 수/VM динамічна_пам_ять_значення 제한은 그대로 적용된다.

## C에서 українська POSIX 호출

게스트에서 `vi 인사.c`로 작성하거나 FTP로 소스를 업로드한다.

```c
#include <파일규약.h>

int main(void) {
    const char 인사말[] = "своє ARM64 C에서 한글 POSIX 호출\n";
    int 문서 = відкрито_Файл("인사.txt", 읽고쓰기 | 없으면만들기 | скорочувати_Зміст, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = записування_Файл_дані(문서, 인사말, sizeof(인사말) - 1);
    Закрити_Файл(문서);
    записування_Файл_дані(1, 인사말, sizeof(인사말) - 1);
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

```text
cc 인사.c -o 인사.elf
run 인사.elf
cat 인사.txt
```

TinyCC의 표준 C запис_бал `main`을 사용한다. 기존 хост C/C++ SDK의 `ПУСК_користувач_програма(int)` 진입점과 구분한다. оголошення файл·запустити об_єкт_значення·`libposix-kor-user.a`는 компілятор 내부의 Читання 전용 SDK에 들어 있다. C 전처리기/구조체/функція_значення/재귀/курсор/부동소수점 генерувати 등을 사용하되 **일반 libc/libstdc++를 제공한다는 뜻은 아니다**. 제공하지 않는 함수는 З_єднання 오류가 난다. компілятор 자체의 문자/цифра_значення перетворити_значення 지원도 완전한 libc 대체품이 아니다.

`відкрито_Файл` 등은 별도의 모의 호출이 아닌 기존 `pk_open` 등의 українська 매크로이며, ELF의 SVC를 통해 фактично_дані Java файл 체계에 도달한다. файл/сокет_значення 호출 목록은 [простір_користувача ABI](사용자호출규약.md)에 있다. C/C++ хост SDK Виконати_команда 파일도 FTP로 업로드 후 `run` 또는 `./файл`로 실행하며 확장자는 필요 없다. Linux ARM64 정적 ELF에는 별도의 제한된 호환 шлях `run --linux файл`을 추가했다. [ELF·Linux ABI 매뉴얼](실행파일규약.md)에 정확한 формат_значення·시스템 호출·Адреса 제한을 정리했다.

## українська 네트워크·작업·화면 API

| Клас_значення | 호출 예 | Виконати_команда шлях |
|---|---|---|
| `Вивід` | `записування_рядок("안녕")`, `수쓰기(42)` | JVM 및 제한형 AOT |
| `файл` | `Запис("문서.txt", "Вміст_значення")`, `Читання("문서.txt")` | JVM 및 제한형 AOT |
| `통신` | `Відкрити(0)`, `надсилати(учасник, "10.0.2.2", 9000, "한글")`, `отримувати(учасник)` | JVM의 UDP |
| `연결통신` | `З_єднання("10.0.2.2", 9000)`, `прослуховувати_учасник(9000)`, `отримувати(сервер_значення)` | JVM의 Socket/ServerSocket |
| `작업` | `запустити(Runnable)`, `기다리기(Thread)`, `призупиняти_справа()` | JVM의 협력식 потік_значення_5b72a632 |
| `Вікно`, `елемент_екрана` | Вікно·버튼·символ_значення_068c2631·текстове_поле·Подія З_єднання | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 українська 호출 계층을 추가한다. `통신(通信)`, `З_єднання(連結)`, `Вивід(出力)`은 기존 단어의 뜻을 사용한다. `작업 потік_значення_5b72a632`은 한 Виконати_команда 흐름을 가닥에 빗댄 기술 표현, `порт_значення`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

зовнішній_значення 주소는 цифра_значення IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 своє ABI이며 JVM이 제한된 хвилиноньку_панове_значення/재시도를 제공한다. TCP connect 대기는 최대 1초, простір_користувача програма_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 Виконати_команда простір_користувача 서버와 pthread는 아직 없다. FTP는 простір_користувача програма_f5044b9b 기한과 별개인 ядро_значення 서비스다.

게스트의 простір_користувача TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 інструменти/Виконати_команда.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 стандартне_значення керування_значення/데이터 포트와 겹치면 Виконати_команда 전에 거부한다.

`build/verification/ftp/report.json`은 фактично_дані FTP передача_значення, 한글 файл, Розмір 초과 보존, Архів_значення JAR Виконати_команда, 게스트 C компілювати_джерело/ELF 재업로드, зовнішній_значення Java TCP/UDP, 게스트 javac/AOT 실행을 기록한다. `serial.log`에서 게스트 명령과 결과를 확인할 수 있다. 보고서의 ядро_значення SHA-256과 배포 이미지의 커널을 비교한다.

빌드는 기존 JDK/Clang/AArch64 binutils와 함께 `../rpi4/build/rootfs`의 ARM64 SDK оголошення_4f4f026b 헤더와 libgcc 산술 보조 함수를 사용한다(`make rpi-prepare`). **musl libc, Linux ядро_значення, 동적 로더를 게스트에 링크하지 않는다.** TinyCC/lwIP/uzlib 원본과 라이선스·버전 정보는 `vendor/`, 이식 코드는 `ccompiler/`, `network/`, `простір_користувача/набір.c`에 있다.

전체 JDK/AOT JVM으로 확장하려면 타입 затвердити·об_єкт_значення/виняток/GC·동적 로딩·JNI, 영속 файл операційна_система_ОС_значення·mmap/TLS/시그널·스레드 ABI, OpenJDK native бібліотека, GUI peer/폰트/입력기, GENET 및 실물 пристрій_значення 검증이 더 필요하다. 이 문서의 Виконати_команда 시험은 그 전체 이식을 대신하지 않는다.
