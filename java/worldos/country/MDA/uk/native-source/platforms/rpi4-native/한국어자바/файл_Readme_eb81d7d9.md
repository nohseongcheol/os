# українська Java 통신·ввід_вивід·виняток API

패키지는 `українська.своє`다. хост `javac --release 8`로 컴파일한 class를
своє ARM64 커널의 JVM에서 실행한다. 통신·файл·виняток API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 потік_значення_5b72a632 API는 своє JVM 전용이다.
기존 표준 Java бібліотека 전체의 українська 번역판은 아니다.

```java
import українська.своє.*;

public class мережа {
    public static void main(String[] аргументи) throws ввід_вивід_виняток {
        зв_язок З_єднання = зв_язок.Відкрити("10.0.2.2", 9000);
        try {
            З_єднання.대기시간(700);
            З_єднання.Вивід().Запис(문자.кодувати("안녕하세요\n"));
            вхідний_потік 입력 = З_єднання.입력();
            Вивід.수쓰기(입력.Читання());
        } catch (대기시간초과예외 ПОМИЛКА) {
            Вивід.записування_рядок(ПОМИЛКА.설명());
        } finally {
            З_єднання.Закрити();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
простір_користувача 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 рядок_значення 리터럴에 사용하는 표준 클래스다. своє 실행기는 `public static void запустити()`도 진입점으로 받는다.

## 통신과 потік_значення

| Клас_значення | українська 호출 |
|---|---|
| зв_язок | `Відкрити(Адреса, номер_порту)`, `입력()`, `Вивід()`, `대기시간(밀리초)`, `номер_порту()`, `місцевий_номер_порту()`, `연결됨()`, `닫힘()`, `Закрити()` |
| отримувати_порт | `Відкрити(номер_порту)`, `отримувати()`, `номер_порту()`, `대기시간(밀리초)`, `닫힘()`, `Закрити()` |
| вхідний_потік | `Читання()`, `Читання(byte[])`, `Читання(byte[], запустити, 길이)`, `Закрити()` |
| вихідний_потік | `Запис(int)`, `Запис(byte[])`, `Запис(byte[], запустити, 길이)`, `내보내기()`, `Закрити()` |
| дейтаграма_Канал | `Відкрити(номер_порту)`, `надсилати(Адреса, номер_порту, текст)`, `отримувати()`, `대기시간(밀리초)`, `номер_порту()`, `닫힘()`, `Закрити()` |
| 연결통신 | `Відкрити(...)`, `수신열기(...)`는 위 українська 객체를 повернути_КР |
| 검사 | `참인지(умова, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`Читання()`의 файл 끝은 -1, масив_значення 읽기의 반환값은 фактично_дані 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. номер_порту 0은 빈 번호를 자동 배정한다.
UDP 전문은 чинний_елемент своє 커널에서 512바이트까지 받으며, 주소는 цифра_значення IPv4를 사용한다.
`localhost` 루프백 외의 Назва 풀이(DNS)는 своє 커널에 아직 없다.

기존 `연결통신.З_єднання/прослуховувати_учасник/отримувати`, `통신.Відкрити/надсилати/отримувати`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `зв_язок`, `отримувати_порт`, `дейтаграма_Канал`를 쓴다.

## українська виняток

모든 아래 클래스는 стандартне_значення 생성자, `새예외("설명")` 형태의 рядок_значення 생성자와
`설명()`을 제공한다. фактично_дані генерувати 문법은 `new 대기시간초과예외("стан_очікування 끝")`이다.

| українська виняток | 상위 Клас_значення / 용도 |
|---|---|
| виняток | `java.lang.Exception`, 직접 던지는 일반 검사 виняток |
| 실행예외 | `java.lang.RuntimeException` |
| ввід_вивід_виняток | `java.io.IOException`, українська файл·통신 API의 검사 виняток |
| 대기시간초과예외 | `ввід_вивід_виняток`, 통신 대기시간 초과 |
| адреса_Інформування_виняток | `ввід_вивід_виняток`, Адреса перевіряти неполадка_значення |
| 파일없음예외 | `ввід_вивід_виняток`, файл Відкрити неполадка_значення |
| 통신예외 | `ввід_вивід_виняток`, 표준 SocketException перетворити_значення |
| недійсний_аргумент_виняток | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `недійсний_аргумент_виняток` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| Null_значення_довідка_виняток | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| Стан_виняток | `java.lang.IllegalStateException` |
| Тип_приводити_виняток | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| масив_сховище_неполадка | `java.lang.ArrayStoreException` |
| потік_Стан_виняток | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 хвилиноньку_панове_значення 중단 |

`виняток`와 `실행예외`는 모든 українська 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, файл·통신 전체를 잡으려면 `catch (ввід_вивід_виняток ПОМИЛКА)`를 쓴다.
українська API가 표준 ввід_вивід 오류를 українська 예외로 변환한다.
기존 українська 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
виняток 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
чинний_елемент своє JVM에 이 20종을 추가했다. 임의의 простір_користувача Throwable 하위 Клас_значення 전체를
지원하도록 확장했다는 뜻은 아니다.

## компілювати_джерело·Виконати_команда

```sh
cd /home/user/jkoros/platforms/rpi4-native
make збирання
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 випробування/자바/한국어통신시험.java
python3 інструменти/Виконати_Файл.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 простір_користувача JVM ELF 안에 탑재된다. `.jar`는 хост javac의
Клас_значення 경로로 사용한다. джерело_дерево 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 українська 예외의 `throws` 선언과 그 import를 인식한다.
своє JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·об_єкт_значення·сокет_значення 예제 전체의 джерело_дерево 컴파일은 хост javac를 사용한다.
`/example/java/ПрикладФайлу.java`는 게스트 javac로도 컴파일할 수 있다.

фактично_дані TCP/UDP 예제는 [ПрикладМережі.java](../../../example/java/ПрикладМережі.java),
Виконати_команда 절차는 [example файл_Readme_eb81d7d9](../../../example/README.md),
джерело_дерево 명명 원칙은 [명명 файл_Readme_eb81d7d9](../명명/файл_Readme_eb81d7d9.md)에 있다.

## Swing Вікно 예제

`/example/java/ПрикладВікна.java`와 컴파일된 `.class`가 запуск_машини 시 준비된다.
`cd /example/java` Далі_елемент `java ПрикладВікна`로 연다. Назва 입력, 인사하기 버튼,
인사말과 клік_значення 횟수 оновлювати, X 닫기를 지원한다.

| 기능 | українська 직접 API |
|---|---|
| Runnable / run | `실행할일.Виконати()` |
| ActionListener / actionPerformed | `동작받이.отримувати_Дія(Дія_повідомлення повідомлення_12ddd6ca)` |
| ActionEvent | `Дія_повідомлення.команда_Текст()`, `джерело_події()`, `індекс()` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
своє JVM의 `한국어화면호출`, `процес_потік`가 українська Клас_значення·метод_значення·서술자를
해석해 화면 요소와 Виконати_команда 가닥을 직접 만든다. Дія 알림도 своє 객체이며
콜백으로 `Виконати`와 `отримувати_Дія`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 Виконати_команда 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 своє JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 хост JVM에서 무동작 객체가 생기지 않도록 하는 відхилити_значення 경로다.
своє JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 реалізація API를
실행할 수 없다. хост javac로 컴파일한 НАЗАД_значення своє JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import українська.своє.*;
public class 가닥예제 implements 실행할일 {
    public void Виконати() { Вивід.записування_рядок("українська 작업 Виконати_команда"); }
    public static void запустити() throws 대기중단예외 {
        фоноваЗадача потік_значення_5b72a632 = 작업.запустити(new 가닥예제());
        작업.기다리기(потік_значення_5b72a632);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
масив_значення аргументи 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
своє 실행기는 аргументи 없는 `запустити()`을 우선한다.
기존 українська 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.запустити(Runnable)`을 사용하던 코드는 새 українська 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API опора_значення 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 Клас_значення·метод_значення 이름과 서술자가 남는다.
українська Назва 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·метод_значення 재정의, native З_єднання, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS ідентифікатор_значення](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS метод_значення довідка](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
