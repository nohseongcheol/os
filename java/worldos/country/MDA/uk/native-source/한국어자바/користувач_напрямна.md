# jkoros українська бібліотека користувач_напрямна

확인일: 2026-09-27. 대상은 `platforms/rpi4`의 **ARM64 Linux + OpenJDK 실행판**이며, QEMU에서도 같은 Java 라이브러리를 사용한다. `os/`의 своє x86 ядро_значення 및 `застарілий_джерело/`의 관리 ядро_значення 모형과 구분한다.

## 1. чинний_елемент 제공하는 бібліотека

패키지는 `українська.자바`, операційна_система_ОС 안의 JAR 경로는 `/opt/jkoros/lib/한국어자바.jar`다. **도우미 Клас_значення 5개, 공개 정적 метод_значення 22개, 별도 GUI 프로그램인 робоча_область 1개**가 있다. JAR는 Java 11 이상을 대상으로 빌드하며 чинний_елемент ARM64 배포판에는 OpenJDK 25가 포함돼 있다.

| Клас_значення | метод_значення 수 | 기능 | вихіднийКод |
|---|---:|---|---|
| `файл` | 9 | UTF-8 텍스트·байт_значення файл, Каталог_значення, запис_список | [файл.java](вихіднийКод/українська/자바/файл.java) |
| `문자` | 5 | UTF-8 перетворити_значення, NFC нормалізувати_значення, код_значення 포인트, рядок_значення 경계 | [문자.java](вихіднийКод/українська/자바/문자.java) |
| `통신` | 2 | HTTP(S) GET, TCP З_єднання | [통신.java](вихіднийКод/українська/자바/통신.java) |
| `작업` | 4 | 스레드 Виконати_команда·хвилиноньку_панове_значення, 고정 Розмір 작업 програма_запускач | [작업.java](вихіднийКод/українська/자바/작업.java) |
| `화면` | 2 | Swing 이벤트 процес_значення_запис 가닥에 작업 예약, Вікно генерувати | [화면.java](вихіднийКод/українська/자바/화면.java) |
| `робоча_область` | запис_бал `main` | Java вихіднийКод правка_значення·сховище_значення·компілювати_джерело·Виконати_команда | [робоча_область.java](вихіднийКод/українська/자바/робоча_область.java) |

표준 JDK 전체를 한국어로 번역한 라이브러리는 아니다. Java 키워드와 `String`, `Path`, `Socket`, `JFrame`, `IOException` 같은 표준 тип_даних·예외를 함께 사용한다. 이 도우미에 없는 기능은 OpenJDK의 표준 API 또는 별도 라이브러리로 구현한다. 예를 들어 HTTP POST, UDP, Swing кнопка·메뉴에는 각각 표준 Java API를 사용한다.

## 2. Java에서 ПУСК_справа

게스트 운영체제의 작업 폴더에서 `사용예.java`를 작성한다.

```java
import українська.자바.*;
import java.nio.file.Path;

public class 사용예 {
    public static void main(String[] аргументи) throws Exception {
        Path Каталог_значення = файл.Створення_Каталог(файл.шлях("사용예자료"));
        Path 문서 = Каталог_значення.resolve("인사.txt");
        файл.Запис(문서, "한글 😀");
        String Вміст_значення = файл.Читання(문서);
        System.out.println(Вміст_значення);
        System.out.println(문자.코드포인트수(Вміст_значення)); // 한, текст, 공백, 😀 → 4
        Thread робота_значення = 작업.запустити("인사 작업", () -> System.out.println("작업 Виконати_команда"));
        작업.기다리기(робота_значення);
    }
}
```

```sh
javac -encoding UTF-8 -cp /opt/jkoros/lib/한국어자바.jar 사용예.java
java -cp .:/opt/jkoros/lib/한국어자바.jar 사용예
```

로그인 환경에 стандартне_значення `CLASSPATH`도 설정돼 있지만, 명시적인 `-cp`는 다른 Виконати_команда 환경에서도 경로를 분명하게 한다. 사용자가 `-cp`를 지정하면 필요한 JAR와 Клас_значення 폴더를 모두 그 값에 포함해야 한다.

хост 저장소에서는 다음처럼 збирання·실행한다. хост 경로와 게스트의 `/opt/...` 경로는 서로 다르다.

```sh
cd /home/user/jkoros/한국어자바
make
javac -encoding UTF-8 -cp build/한국어자바.jar 예제/인사.java
java -cp build/한국어자바.jar:예제 인사
```

## 3. 전체 도우미 API

아래 메서드는 모두 `public static`이며, 객체를 만들지 않고 `файл.Читання(...)`처럼 호출한다. 표의 이름은 фактично_дані джерело_дерево 및 JAR의 `javap -public` 결과와 대조했다. 선언된 검사 виняток 외에도 잘못된 аргументи 등에 대한 표준 Java Виконати_команда 시 예외가 발생할 수 있다.

### файл: `українська.자바.файл`

`Path`는 `java.nio.file.Path`, `List`는 `java.util.List`다.

| метод_значення | повернути_Тип | Дія·умова |
|---|---|---|
| `шлях(String Назва)` | `Path` | 이름을 шлях 객체로 перетворити_значення. фактично_дані 파일을 만들지는 않음 |
| `Читання(Path шлях)` | `String` | файл 전체를 UTF-8 텍스트로 읽음 |
| `Запис(Path шлях, String Вміст_значення)` | `Path` | UTF-8 сховище_значення. 파일이 없으면 생성하고, 있으면 기존 내용을 비움 |
| `바이트읽기(Path шлях)` | `byte[]` | файл 전체를 байт_значення 배열로 읽음 |
| `записування_байт_значення(Path шлях, byte[] Вміст_значення)` | `Path` | байт_значення сховище_значення. 없으면 생성하고, 있으면 기존 내용을 비움 |
| `Створення_Каталог(Path шлях)` | `Path` | 필요한 상위 폴더까지 генерувати |
| `있는가(Path шлях)` | `boolean` | 존재 여부 перевіряти. 확인할 수 없는 경우도 `false`робота_значення 수 있음 |
| `видаляти_запис(Path шлях)` | `boolean` | 삭제했으면 `true`, 없으면 `false`. 폴더의 재귀 삭제는 아님 |
| `запис_список(Path шлях)` | `List<Path>` | 바로 아래 항목을 шлях вирівняти_значення 순서로 повернути_КР. 재귀 탐색은 아님 |

`шлях`, `있는가`를 제외한 위 메서드는 `IOException`을 선언한다. `Запис`와 `записування_байт_значення`는 상위 폴더를 자동으로 만들거나 내용을 이어 쓰지 않는다. 필요한 폴더는 먼저 생성한다. 큰 파일은 전체 내용을 메모리에 담는 대신 표준 Java 스트림·Канал_значення API를 사용하는 방식으로 작성할 수 있다.

### 문자: `українська.자바.문자`

| метод_значення | повернути_Тип | Дія·умова |
|---|---|---|
| `кодувати(String Вміст_значення)` | `byte[]` | 문자열을 UTF-8 바이트로 перетворити_значення |
| `дешифрувати_дані(byte[] Вміст_значення)` | `String` | UTF-8 바이트를 문자열로 перетворити_значення. 잘못된 입력은 대체 문자로 процес_значення_запис |
| `нормалізувати_значення(String Вміст_значення)` | `String` | Юнікод_значення NFC нормалізувати_значення. 예: 조합 자모 `ᄀ` + `ᅡ` → `가` |
| `코드포인트수(String Вміст_значення)` | `int` | UTF-16 код_значення 단위가 아닌 Юнікод_значення код_значення 포인트 수 |
| `낱말(String Вміст_значення, Locale Мови)` | `List<String>` | Призначити_значення 언어의 `BreakIterator` 낱말 경계로 나눈 Текст_діапазон |

`낱말`은 공백·문장부호 구간도 반환한다. 자연어 형태소 분석기나 공백을 제거한 Ігри_в_слова_значення запис_список API는 아니다. `нормалізувати_значення`는 입력기나 Перекласти_джерело 기능이 아니다. код_значення 포인트 수 역시 사람이 보는 символ_значення_068c2631 수와 항상 같지는 않다. 여러 код_значення 포인트로 이루어진 결합 문자·가족 이모지 등을 구분해야 한다.

### 통신: `українська.자바.통신`

| метод_значення | повернути_Тип | Дія·умова |
|---|---|---|
| `가져오기(URI Адреса, Duration обмеження_часу)` | `HttpResponse<String>` | HTTP(S) GET. З_єднання 및 запит обмеження_часу Налаштування. відповідь 본문을 UTF-8로 аналізувати_значення |
| `зв_язок_учасник(String Адреса, int обладнання_порт, int 제한밀리초)` | `Socket` | TCP З_єднання 후 같은 값으로 Читання 제한시간도 Налаштування |

`가져오기`는 `IOException`, `InterruptedException`을 선언한다. 제한시간은 양수다. 404·500 같은 HTTP ПОМИЛКА 상태도 응답으로 반환하므로 `statusCode()`로 판단하고 `body()`로 본문을 읽는다. чинний_елемент 구현은 호출마다 HTTP 클라이언트를 만들며 자동 리다이렉트 설정을 추가하지 않는다.

`зв_язок_учасник`는 `IOException`을 선언한다. 연결된 소켓은 호출자가 `close()` 또는 try-with-resources로 닫아야 한다. 제한밀리초의 0은 제한 없음이며, Запис 전체의 крайнiй_термін_значення 시간을 보장하는 옵션은 아니다.

```java
var відповідь = 통신.가져오기(
    java.net.URI.create("http://127.0.0.1:8000/"),
    java.time.Duration.ofSeconds(5));
System.out.println(відповідь.statusCode());
System.out.println(відповідь.body());
```

위 조각은 метод_значення 안에서 실행하며 별도로 해당 주소의 서버를 실행해야 한다. Java виняток 처리가 필요하다.

### 작업: `українська.자바.작업`

| метод_значення | повернути_Тип | Дія·умова |
|---|---|---|
| `запустити(String Назва, Runnable Дія)` | `Thread` | 이름을 지정한 스레드를 만들고 즉시 запустити |
| `기다리기(Thread потік_значення_5b72a632)` | `void` | 해당 스레드가 종료할 때까지 `join()` |
| `쉬기(long 밀리초)` | `void` | 호출한 스레드를 Призначити_значення час_значення 동안 `sleep()` |
| `작업대(int 가닥수)` | `ExecutorService` | 고정 Розмір 작업 програма_запускач генерувати. 가닥수는 양수 |

`기다리기`, `쉬기`는 `InterruptedException`을 선언한다. 작업 실행기는 використання_значення 후 `shutdown()`으로 종료하고 필요하면 `awaitTermination(...)`으로 완료를 기다린다. Swing 이벤트 процес_значення_запис 가닥에서 긴 작업이나 `기다리기`를 실행하면 화면이 멈출 수 있다.

### 화면: `українська.자바.화면`

| метод_значення | повернути_Тип | Дія·умова |
|---|---|---|
| `나중에(Runnable Дія)` | `void` | Swing 이벤트 процес_значення_запис 가닥에 실행을 예약하고 повернути_КР |
| `Вікно(String вікно_Назва, JComponent Вміст_значення, int 너비, int 높이)` | `JFrame` | Вміст_значення·크기를 지정한 창을 생성해 показувати_значення |

`Вікно`을 Swing 이벤트 процес_значення_запис потік_значення_5b72a632 밖에서 부르면 `IllegalStateException`이 발생한다. 그래픽 세션도 필요하다. QEMU에서는 VNC 데스크톱의 터미널에서 실행한다.

```java
화면.나중에(() -> 화면.Вікно(
    "українська 화면", new javax.swing.JLabel("안녕하세요"), 500, 180));
```

반환된 `JFrame`에 표준 Swing API를 추가로 사용할 수 있다. 창의 Закрити 동작은 `DISPOSE_ON_CLOSE`다. `화면.나중에`가 반환됐다고 Вікно 생성이 이미 끝난 것은 아니다.

### робоча_область: правка_значення·компілювати_джерело GUI

```sh
java -cp /opt/jkoros/lib/한국어자바.jar українська.자바.робоча_область
```

`~/workspace`의 원문을 Відкрити·저장하고, `javac`로 컴파일해 `java`로 실행한다. Виконати_команда файл 만들기는 `jclassc --target openjdk` 경로를 사용한다. 작업마당은 개발용 프로그램이며 별도의 файл·문자 API 클래스가 아니다. 생성하는 Виконати_команда файл 방식은 [компілятор 설명](../compiler/OpenJDK-실행파일.md)을 따른다.

## 4. Python과 C++에서 사용할 수 있는가?

| метод_режим | чинний_елемент оголошення Стан_значення | 호출 가능 кліп |
|---|---|---|
| Java → українська JAR | стандартне_значення оголошення | 위 22개 메서드와 робоча_область |
| Python → `java` дитина_значення 프로세스 | Python·Java стандартне_значення оголошення | 작은 Java 진입점을 통해 호출하고 표준 Вивід·файл 등으로 результат Уперед_значення |
| Python → JPype → JVM | JPype는 стандартне_значення 배포에 없음 | 별도 інсталювати_значення 후 Java Клас_значення·метод_значення 호출 가능. 이 배포판의 ARM64/musl/Python 3.14 조합은 додавати_запис затвердити 필요 |
| C++ → JNI → JVM | `g++`, JNI 헤더, `libjvm.so` оголошення | JVM을 생성하고 українська Клас_значення·메서드를 직접 호출할 수 있음 |
| Python용 독립 українська бібліотека | чинний_елемент стандартне_значення 제공 없음 | 필요하면 Python 표준 라이브러리를 감싸는 українська 모듈을 별도로 작성 |
| C/C++용 독립 українська бібліотека | своє x86 `posix-kor`와 своє ARM64 커널용 початковий_стан RAM файл 연결이 별도로 존재 | 둘 다 이 Linux/OpenJDK 실행판의 libc 라이브러리는 아님 |

Python의 일반 `import`나 `ctypes.CDLL`로 JAR를 바로 읽을 수는 없다. C++의 `#include`나 일반 네이티브 링커만으로 Java 메서드를 연결할 수도 없다. JVM 프로세스 또는 JVM З_єднання 계층을 거쳐야 한다.

### Python: додавати_запис 패키지 없이 호출

Виконати_команда 가능한 예제 원문은 [문자명령.java](예제/다른언어/문자명령.java), [파이썬호출.py](예제/다른언어/파이썬호출.py)다. Python이 Java 진입점을 실행하고 `문자.코드포인트수`의 ціле_число 결과를 받는다. аргументи 목록을 사용하며 оболонка команда 문자열을 조립하지 않는다. `subprocess.run`의 프로세스 Виконати_команда·Вийти_програма код_значення·Вивід процес_значення_запис 방식은 [Python 공식 문서](https://docs.python.org/3/library/subprocess.html)를 따른다.

두 예제 파일을 게스트의 같은 폴더에 복사한 НАЗАД_значення 그 폴더에서 실행한다. 예제 файл 자체는 стандартне_значення 시스템 이미지에 자동 설치돼 있지 않다.

```sh
mkdir -p classes
javac -encoding UTF-8 -cp /opt/jkoros/lib/한국어자바.jar -d classes 문자명령.java
python3 파이썬호출.py --text '한글 😀'
```

Вивід: `Python → українська.자바.문자.코드포인트수: 4`

이 예제의 Python функція_значення `코드포인트수`는 이번 문서의 З_єднання 예제이며 기존에 설치된 Python 라이브러리는 아니다. чинний_елемент 예제는 호출할 때마다 JVM 프로세스를 시작한다. Java об_єкт_значення 자체를 Python으로 가져오는 방식은 아니며, 다른 메서드를 사용하려면 진입점의 аргументи·результат 형식을 확장한다.

### Python: JPype로 같은 프로세스에서 호출

JPype를 별도 설치한 환경에서는 Далі_елемент 형태로 연결할 수 있다. **아래는 вибране_значення 가능한 З_єднання 방법이며, чинний_елемент 배포판에 JPype가 설치돼 있거나 Виконати_команда 검증됐다는 뜻은 아니다.** JVM 시작과 `JClass`를 통한 Клас_значення 접근은 [JPype 공식 설명](https://jpype.readthedocs.io/en/latest/userguide.html)을 참고한다.

```python
import jpype

jpype.startJVM(
    "/usr/lib/jvm/java-25-openjdk/lib/server/libjvm.so",
    classpath=["/opt/jkoros/lib/한국어자바.jar"])
try:
    문자 = jpype.JClass("українська.자바.문자")
    print(문자.코드포인트수(jpype.JString("한글 😀")))
finally:
    jpype.shutdownJVM()
```

Python·JVM·З_єднання 모듈의 CPU 아키텍처가 맞아야 한다. 이 실행판은 ARM64 + musl이므로 일반 x86_64/glibc용 바이너리를 그대로 설치하는 방식은 맞지 않는다. JPype інсталювати_значення·패키지 빌드는 이번 문서 작업에서 수행하지 않았다.

### C++: JNI로 직접 호출

[자바호출.cpp](예제/다른언어/자바호출.cpp)는 фактично_дані Виконати_команда 가능한 예제다. JVM을 작업 스레드에서 생성하고 Далі_елемент 메서드를 찾는다.

```cpp
jclass type = env->FindClass("українська/자바/문자");
jmethodID method = env->GetStaticMethodID(
    type, "코드포인트수", "(Ljava/lang/String;)I");
```

JVM генерувати·종료와 스레드 연결은 [JNI Invocation API](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/invocation.html)의 방식이다. `JNIEnv*`는 генерувати·연결된 스레드에서 사용해야 한다. 예제는 Java 예외를 확인하고 JVM 종료까지 처리한다.

게스트에 `자바호출.cpp`를 복사한 НАЗАД_значення 컴파일한다. 로그인 환경의 `JAVA_HOME`은 `/usr/lib/jvm/java-25-openjdk`다.

```sh
g++ -std=c++11 -Wall -Wextra -pthread \
  -I"$JAVA_HOME/include" -I"$JAVA_HOME/include/linux" \
  자바호출.cpp -L"$JAVA_HOME/lib/server" \
  -Wl,-rpath,"$JAVA_HOME/lib/server" -ljvm -o 자바호출
./자바호출 /opt/jkoros/lib/한국어자바.jar
```

Вивід: `C++ → українська.자바.문자.코드포인트수: 4`

예제는 `한글 😀`을 UTF-16으로 만들어 `NewString`에 전달한다. `NewStringUTF`가 받는 modified UTF-8은 일반 UTF-8과 차이가 있으므로, 일반 UTF-8 이모지 바이트를 그대로 넘기는 예제로 작성하지 않았다. [JNI рядок_значення формат_значення](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/types.html#modified-utf-8-strings)

다른 українська 메서드도 JNI 서명과 аргументи 자료형을 맞춰 호출할 수 있다. 예를 들어 `Path`를 받는 файл API는 먼저 `файл.шлях`로 Java шлях 객체를 얻어 전달한다. Swing 호출에는 그래픽 세션과 이벤트 процес_значення_запис потік_значення_5b72a632 규칙도 그대로 적용된다. JNI는 Java 실행을 기계어로 대체하는 기능이 아니며 JVM이 계속 필요하다.

### 기존 posix-kor와의 관계

추가된 [своє ARM64 З_єднання](../posix-kor/arm64-native/файл_Readme_eb81d7d9.md)은 C++에서 AOT Java 커널의 RAM файл API를 직접 호출하며, 별도 EL0 простір_користувача 라이브러리로 файл/UDP 루프백 SVC 호출도 제공한다. JNI를 사용하지 않는다. 이 문서의 ARM64 **Linux** 및 українська Java JAR와는 다른 Виконати_команда 기반이며 своє 커널은 별도 제한형 Java компілятор/JVM과 MicroPython 1.24.1을 실행한다. MicroPython의 `import jkoros`로 Java ядро_значення файл·UDP 루프백·прямокутник 호출이 가능하지만 이 문서의 JAR를 가져오는 기능은 아니다. своє 커널의 전체 OpenJDK/JRE/CPython 이식은 아직 미완성이다.

[posix-kor](../posix-kor/файл_Readme_eb81d7d9.md)에는 `відкрито_Файл`, `파일자료읽기`, `записування_Файл_дані`, `Закрити_Файл`, `Створення_учасник`, `надсилати_дейтаграма_дані` 등의 українська C 별칭이 있다. 그러나 구현은 **своє jkoros i386 커널의 `int 0x80` 호출 규약용**이다.

이 `libposix-kor.a`와 своє `sys/stat.h` 등의 헤더는 чинний_елемент ARM64 Linux 실행판의 libc/C++용 라이브러리가 아니다. 해당 헤더·바이너리를 ARM64 Linux 프로그램에 그대로 연결해서는 ABI가 맞지 않는다. C++용 українська Клас_значення 라이브러리나 Python용 바인딩을 стандартне_значення 제공하는 상태도 아니다. чинний_елемент Linux 실행판에서 그와 같은 독립 API를 제공하려면 Linux 표준 라이브러리를 대상으로 별도로 реалізація·빌드해야 한다.

## 5. перевіряти 범위와 재현

패키지 оголошення 여부는 [배포 패키지 запис_список](../platforms/rpi4/dist/packages.lock.json) 및 збирання 루트의 фактично_дані 파일로 확인했다. JNI 헤더는 JDK의 `include/jni.h`, `include/linux/jni_md.h`, JVM 라이브러리는 `lib/server/libjvm.so`에 있다. 사용자가 이후 별도로 설치한 패키지는 이 стандартне_значення 배포 목록과 다를 수 있다.

이번에 **хост x86_64/OpenJDK 11에서** Python дитина_значення 프로세스 호출과 C++ JNI 직접 호출을 компілювати_джерело·실행해 각각 результат 4를 확인했다. JAR 공개 메서드도 소스와 대조했다. Python З_єднання 예제는 додавати_запис 패키지를 설치하지 않는다.

문서의 Java використання_значення 예제도 компілювати_джерело·실행했고, 22개 메서드의 문서 оголошення 여부와 로컬 문서 링크를 확인했다. [예제 затвердити журнал_запис](build/다른언어/перевірка_звіт.json)

기존 ARM64 QEMU에서는 Java의 файл·Юнікод_значення·스레드·HTTP 및 Swing випробування 결과가 있다. 이번 Python/C++ З_єднання 예제의 **ARM64 게스트 실행과 JPype 설치는 별도 검증하지 않았다.** 이미지와 Виконати_команда 중인 простір_користувача 환경은 이 문서 작업에서 변경하지 않았다. [기존 операційна_система_ОС затвердити журнал_запис](../platforms/rpi4/VERIFICATION.md)

호스트에서 Python 예제를 재현하려면:

```sh
cd /home/user/jkoros/한국어자바
make
mkdir -p build/다른언어
javac -encoding UTF-8 --release 11 -cp build/한국어자바.jar \
  -d build/다른언어 예제/다른언어/문자명령.java
python3 예제/다른언어/파이썬호출.py \
  --jar build/한국어자바.jar --classes build/다른언어
```

хост C++ 예제는 위 JNI компілювати_джерело 명령의 JDK 경로를 **хост JDK шлях**로 바꾸고, вихіднийКод `예제/다른언어/자바호출.cpp`와 JAR `build/한국어자바.jar`를 지정한다. ARM64 게스트 JDK의 헤더·бібліотека 경로를 хост x86_64 링크 명령에 섞지 않는다.
