# Македонски Java 통신·В_И·исклучок API

패키지는 `Македонски.자체`다. вдоми `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·Датотека·исклучок API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 нишка_VALUE API는 자체 JVM 전용이다.
기존 표준 Java библиотека 전체의 Македонски 번역판은 아니다.

```java
import Македонски.자체.*;

public class Мрежа {
    public static void main(String[] Аргументи) throws В_И_исклучок {
        врска Врзи_се = врска.Отвори("10.0.2.2", 9000);
        try {
            Врзи_се.TIMEOUT(700);
            Врзи_се.출력().Запиши(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = Врзи_се.입력();
            출력.수쓰기(입력.Читај());
        } catch (почекај_TIMEOUT_исклучок ГРЕШКА) {
            출력.запиши_ред(ГРЕШКА.설명());
        } finally {
            Врзи_се.Затвори();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
корисник 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 низа_VALUE_6ca8363c 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void Изврши_2()`도 진입점으로 받는다.

## 통신과 Stream_VALUE

| класа_VALUE | Македонски 호출 |
|---|---|
| врска | `Отвори(адреса, број_на_порта)`, `입력()`, `출력()`, `TIMEOUT(밀리초)`, `број_на_порта()`, `локален_број_на_порта()`, `연결됨()`, `닫힘()`, `Затвори()` |
| 수신창구 | `Отвори(број_на_порта)`, `받기()`, `број_на_порта()`, `TIMEOUT(밀리초)`, `닫힘()`, `Затвори()` |
| 입력흐름 | `Читај()`, `Читај(byte[])`, `Читај(byte[], Изврши_2, должина_VALUE)`, `Затвори()` |
| 출력흐름 | `Запиши(int)`, `Запиши(byte[])`, `Запиши(byte[], Изврши_2, должина_VALUE)`, `내보내기()`, `Затвори()` |
| 전문통로 | `Отвори(број_на_порта)`, `испрати(адреса, број_на_порта, Текст)`, `받기()`, `TIMEOUT(밀리초)`, `број_на_порта()`, `닫힘()`, `Затвори()` |
| 연결통신 | `Отвори(...)`, `수신열기(...)`는 위 Македонски 객체를 반환 |
| 검사 | `참인지(услов, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`Читај()`의 Датотека 끝은 -1, низа_VALUE 읽기의 반환값은 реален_податоци 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. број_на_порта 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 자체 커널에서 512바이트까지 받으며, 주소는 цифра_VALUE IPv4를 사용한다.
`localhost` 루프백 외의 Име 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.Врзи_се/듣기/받기`, `통신.Отвори/испрати/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `врска`, `수신창구`, `전문통로`를 쓴다.

## Македонски исклучок

모든 아래 클래스는 стандардна_вредност 생성자, `새예외("설명")` 형태의 низа_VALUE_6ca8363c 생성자와
`설명()`을 제공한다. реален_податоци генерира 문법은 `new почекај_TIMEOUT_исклучок("почекај_статус 끝")`이다.

| Македонски исклучок | 상위 класа_VALUE / 용도 |
|---|---|
| исклучок | `java.lang.Exception`, 직접 던지는 일반 검사 исклучок |
| 실행예외 | `java.lang.RuntimeException` |
| В_И_исклучок | `java.io.IOException`, Македонски Датотека·통신 API의 검사 исклучок |
| почекај_TIMEOUT_исклучок | `В_И_исклучок`, 통신 TIMEOUT 초과 |
| адреса_LOOKUP_исклучок | `В_И_исклучок`, адреса провери неуспех_VALUE |
| 파일없음예외 | `В_И_исклучок`, Датотека Отвори неуспех_VALUE |
| 통신예외 | `В_И_исклучок`, 표준 SocketException CONVERT_VALUE |
| неважечки_аргумент_исклучок | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `неважечки_аргумент_исклучок` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| NULL_Референци_исклучок | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| статус_исклучок | `java.lang.IllegalStateException` |
| TYPE_емитувај_исклучок | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| низа_Store_неуспех | `java.lang.ArrayStoreException` |
| нишка_статус_исклучок | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 почекај_VALUE 중단 |

`исклучок`와 `실행예외`는 모든 Македонски 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, Датотека·통신 전체를 잡으려면 `catch (В_И_исклучок ГРЕШКА)`를 쓴다.
Македонски API가 표준 В_И 오류를 Македонски 예외로 변환한다.
기존 Македонски 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`почекај_TIMEOUT_исклучок`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
исклучок 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 자체 JVM에 이 20종을 추가했다. 임의의 корисник Throwable 하위 класа_VALUE 전체를
지원하도록 확장했다는 뜻은 아니다.


내장 라이브러리는 корисник JVM ELF 안에 탑재된다. `.jar`는 вдоми javac의
класа_VALUE 경로로 사용한다. извор_дрво 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 Македонски 예외의 `throws` 선언과 그 import를 인식한다.
자체 JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·објект_VALUE·소켓 예제 전체의 извор_дрво 컴파일은 вдоми javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 수 있다.

`cd /example/java` Следно_ставка `java 창예제`로 연다. Име 입력, 인사하기 버튼,

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `Процес_нишка`가 Македонски класа_VALUE·метод_VALUE·서술자를
해석해 화면 요소와 Изврши_наредба 가닥을 직접 만든다. Дејство 알림도 자체 객체이며
콜백으로 `Изврши`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 Изврши_наредба 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 вдоми JVM에서 무동작 객체가 생기지 않도록 하는 одбива_VALUE 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. вдоми javac로 컴파일한 Назад_VALUE 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import Македонски.자체.*;
public class 가닥예제 implements 실행할일 {
    public void Изврши() { 출력.запиши_ред("Македонски 작업 Изврши_наредба"); }
    public static void Изврши_2() throws 대기중단예외 {
        작업가닥 нишка_VALUE = 작업.Изврши_2(new 가닥예제());
        작업.기다리기(нишка_VALUE);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
низа_VALUE Аргументи 대신 `실행인수`, 길이는 `문자.бајт_COUNT`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 Аргументи 없는 `Изврши_2()`을 우선한다.
기존 Македонски 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.Изврши_2(Runnable)`을 사용하던 코드는 새 Македонски 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API Поддршка_VALUE 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 класа_VALUE·метод_VALUE 이름과 서술자가 남는다.
Македонски Име 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·метод_VALUE 재정의, native Врзи_се, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS идентификатор_VALUE](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS метод_VALUE Референци](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
