# 자체 ARM64 JVM 0.4와 Македонски библиотека

Македонски 통신·исклучок 사용법은 [Македонски Java API](한국어자바/информации_пред_употреба_eb81d7d9.md), ФУНКЦИЈА_VALUE·변수·Датотека 이름의 변경과 어원 근거는 [명명 информации_пред_употреба_eb81d7d9](명명/информации_пред_употреба_eb81d7d9.md)를 참고한다.

JAR Изврши_наредба, 외부 IPv4 TCP/UDP, 별도 статичен_VALUE 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 објект_VALUE·Thread·Swing은 JVM 경로의 기능이며 AOT Поддршка_VALUE 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 Изврши_наредба**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK класа_VALUE библиотека 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 класа_VALUE·статичен_VALUE метод_VALUE 중심이던 실행기를 објект_VALUE·библиотека Изврши_наредба 기반으로 넓힌 것이다.

## Изврши_наредба 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(Македонски класа_VALUE 포함), class당 16 KiB·константа_VALUE 풀 511항목, 전체 метод_VALUE/поле_VALUE 각각 512개. метод_VALUE CODE_VALUE 8 KiB, локален_обем 변수·피연산자 스택 각각 128슬롯, Аргументи 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 Изврши_наредба 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- објект_VALUE 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 реален_податоци 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 Датотека·대형 низа_VALUE_6ca8363c·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 Команда 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 прозорец SWITCH_MODE 시 중단·재개한다. 일반 сервер_VALUE·계산의 무제한 실행은 아직 없다. 미지원 Команда·извор_VALUE 부족은 명시적인 오류로 종료한다.
- RAM Датотека 최대 64개, 파일당 16384바이트, ПАТЕКА UTF-8 63바이트. RAM 디렉터리와 рамноправен_уред_VALUE/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 Македонски class는 RAM Датотека 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 현재 경로에서 извор_дрво·класа_VALUE·податоци 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 외부 IPv4를 제공한다. реален_податоци GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. 전문 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 Изврши_наредба 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 низа_VALUE, 완전한 низа_VALUE 공변성·인터페이스 слој_VALUE_e65604ef 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/кодирај_податоци/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 Поддршка_VALUE 부분집합은 아래 및 개발 매뉴얼을 참고한다. класа_VALUE Датотека 전체 검증기·пристап_внес дозвола_VALUE/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 заштита_VALUE 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM VALUE/потврди/класа_VALUE 로더와 исклучок 모델 → 영속 VFS·mmap·Часовник·원자 операција_VALUE·реален_податоци 스레드/синхронизирај ABI → OpenJDK java.base 및 native библиотека 이식 → уред_VALUE 네트워크·TCP/IP → прозорец 시스템/фонт_VALUE/입력기·java.desktop → Java SE 호환성 시험. 현재 자체 JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## JVM 0.3: 네트워크와 GUI наставка_VALUE
