# JMliOS

حديث_عنصر ذاتي ARM64 배포판은 [LICENSE](LICENSE)의 COSL 상업 조건을 유지한다. 제3자 라이선스의 권리는 별도로 보장하며, توزيع_قيمة 시 مصدر_شجرة·재연결 자료를 포함하는 절차는 [COSL توزيع_قيمة 안내](platforms/rpi4-native/COSL배포안내.md)에 있다.

ذاتي ARM64 판의 `ipconfig`/`ip`, `ping`, `ps`/`top`, `free`/`df`, `poweroff`와 العربية 명령은 [네트워크·نظام_تشغيل_قيمة أمر 안내](platforms/rpi4-native/네트워크와체계명령.md)를 참고한다. 새 커널을 부팅한 عودة_قيمة `help system`으로 볼 رقم 있다.

Raspberry Pi 4 **ذاتي Java ARM64 نواة_قيمة**은 [ذاتي Pi4 안내](platforms/rpi4-native/안내.md)에 있다. Linux 없이 부팅하며 GUI طرفية·vi, ذاتي JVM의 Swing 일부 API, TCP/UDP·FTP, 게스트 TinyCC·MicroPython, C/C++의 posix-kor 호출을 제공한다. [العربية Java 통신·استثناء API](platforms/rpi4-native/한국어자바/안내.md)와 [العربية مصدر_شجرة 명명](platforms/rpi4-native/명명/안내.md)을 지원한다. [ذاتي SSH·VNC 및 GENET 드라이버](platforms/rpi4-native/خارجي_صديق_دليل.md)를 포함하며, 네트워크는 QEMU의 UART SLIP 경로로 검증했다. الفعلي_بيانات Pi 4 GENET 동작은 미검증이고, USB إدخال_قيمة·영속 저장과 전체 OpenJDK·Swing은 아직 دعم_قيمة يقص 밖이다.

Raspberry Pi 4용 Linux·OpenJDK 실행판과 فضاء_المستخدم بيئة_التشغيل نقل_قيمة 기능은 [라즈베리파이 실행판](platforms/rpi4/README.md)에 있다. الفعلي_بيانات ARM64 JDK/JRE와 시스템·فضاء_المستخدم بنية_صورة بنية_نظام 경로를 제공한다. 기존 ذاتي x86 커널과는 별도 ينفذ_أمر 기반이다. 일반 Java `.class`/JAR의 ينفذ_أمر ملف 생성은 [OpenJDK ينفذ_أمر ملف](compiler/OpenJDK-실행파일.md), العربية API는 [العربية Java مكتبة](한국어자바/안내.md)를 참고한다.

`jkoros`는 `engos`의 기능을 Java 관리 커널로 옮기는 프로젝트다. 프로젝트가 소유하는 Java دالة_قيمة, متغيّر_قيمة, ينسق_قيمة 및 Java ملف 이름은 한국어로 작성한다. 표준 Java 실행기의 `main`, Java 표준 مكتبة ينسق_قيمة, x86 부트 ABI 등 خارجي_قيمة 계약은 보존한다. ذاتي ARM64 실행기는 العربية `تشغيل()`도 진입점으로 지원하며, العربية GUI·작업 가닥을 JVM에 직접 구현했다. ذاتي ARM64 C 연결부·Python 도구와 공용 x86·ARM64 AOT 번역기의 ذاتي 이름도 한국어로 작성한다. 이전 경로의 호환 نقطة_الإدخال, OpenJDK 보조 도구와 Linux إصدار_قيمة 도구에는 영어 이름이 남아 있고 [명명 원칙·말의 근거·전체 مصدر 검토 يقص](platforms/rpi4-native/명명/안내.md)를 별도로 기록한다.

## حديث_عنصر 구현

아래 목록은 기존 `قديم_مصدر/`의 JVM 관리 커널에 대한 것이다. الفعلي_بيانات 네이티브 커널의 범위는 `os/안내.md`에서 별도로 설명한다.

- يحاذي_قيمة 할당과 해제를 지원하는 ذاكرة_منطقة مدير_قيمة
- عنوان عنوان_منطقة, صفحة_قيمة اتصال, كتابة 시 مثيل_قيمة(COW)
- عملية_قيمة معرف_قيمة, إعداد 대기열, fork/wait حالة_قيمة
- 과정별 ملف 서술자, open/read/seek/dup/close
- ELF32 식별 및 قسم_قيمة_366e0bfa 검사
- 키보드·마우스 إدخال_قيمة حدث 대기열
- 직렬 단말과 네이티브 أجهزة_قيمة 경계
- 관리 نواة_قيمة 전체 자동 اختبارات

세부 대응 범위와 아직 필요한 네이티브 연결은 [기능 대응표](문서/기능대응.md)에 기록한다.

## 빌드와 اختبارات

새 네이티브 구현은 `compiler/`와 `os/`에 있다. 기존 `قديم_مصدر/`의 JVM 관리 커널은 그대로 보존하며, 두 구현의 시험과 기능 범위는 서로 다르다.

```sh
cd /home/user/jkoros
make                 # 네이티브 계산 예제 + Java نواة_قيمة ELF
make iso             # os/build/kernel.iso
make run             # QEMU 직렬 단말; help إدخال_قيمة (종료는 Ctrl+A, X)
make run-gui         # ISO를 QEMU 화면/PS2 키보드로 ينفذ_أمر
make vbox            # 전용 VirtualBox VM 자동 إنشاء·ينفذ_أمر (GUI)
make vbox-status     # VirtualBox حالة_قيمة·ISO·직렬 سجل_سجل مسار يتحقق
make test-vbox       # VirtualBox تطبيق_مشغّل حالة_قيمة عملية_قيمة_إدخال اختبارات (الفعلي_بيانات VM يغيّر_قيمة 없음)
make test            # محول_برمجي اختبارات + ELF/ISO إقلاع_الآلة 및 أمر إدخال_قيمة اختبارات
make apps            # 독립 فضاء_المستخدم ELF تطبيق_f5044b9b بنية_نظام
make test-network    # فضاء_المستخدم الوضع_قيمة·UDP 왕복·ذاكرة_بيانات يحمي_قيمة اختبارات
make test-java       # 게스트 javac/JVM + OpenJDK 양방향 교차 ينفذ_أمر اختبارات
make posix-kor       # العربية C 헤더와 الفعلي_بيانات نواة_قيمة 호출 مكتبة
make test-posix      # ملف/UDP/مخزن_قيمة/Java ملف إدخال_إخراج اختبارات
make -C os run-store # 전용 مخزن_قيمة 매체로 QEMU إقلاع_الآلة
make legacy-test     # 아래 기존 JVM 관리 커널의 47개 اختبارات
```

`compiler/`는 호스트의 `javac`를 문법·نوع_قيمة 검사 전단으로 사용하고 ذاتي 바이트코드→x86 변환기로 ELF32 기계어를 만든다. 빌드할 때는 JDK가 필요하지만 생성된 커널과 ELF는 خارجي_قيمة JVM 없이 실행된다. 전체 Java, عنصر_قيمة_2ed200e9 모델, 표준 라이브러리와 기존 관리 نواة_قيمة 전체의 AOT 변환은 아직 지원하지 않는다. 자세한 دعم_قيمة 문법과 명령은 [محول_برمجي 안내](compiler/안내.md), الفعلي_بيانات إقلاع_الآلة 기능과 한계는 [네이티브 نظام_تشغيل 안내](os/안내.md)를 참고한다.

네이티브 셸에 ذاتي 제한형 `javac`와 `java`를 추가했다. `edit Demo.java`로 소스를 입력하고 `.save`로 저장한 عودة_قيمة `javac Demo.java`, `java Demo`로 **게스트 내부에서 컴파일하고 ينفذ_أمر**할 رقم 있다. قيمة_افتراضية 예제는 `javac Hello.java`, `java Hello`다. 파일은 RAM에서 동작하며, 전용 مخزن_قيمة 매체를 연결하면 `sync`로 재부팅 후에도 보존할 رقم 있다. **OpenJDK/JDK 전체 이식은 아니며**, 단일 فئة_قيمة_55654bf1·ثابت_قيمة_f430d3f5 دالة_قيمة·عدد_صحيح·سلسلة_قيمة·شرط/반복문과 일부 표준 호출을 지원한다. دعم_قيمة يقص, خارجي_قيمة ملف 적재와 시험은 [Java 개발 بيئة_التشغيل 안내](문서/자바개발환경.md)에 있다.

네이티브 셸에서 `apps`, `run hello first second`, `net`, `run netcheck`를 사용할 رقم 있다. 독립 ELF를 ring 3에 적재하고 `int 0x80` 호출을 통해 مخرجات·وسائط·UDP 네트워크를 제공한다. 별도 مضيف 터미널에서 `python3 os/أدوات/ارتداد_بيانات.py --port 9000`을 실행한 عودة_قيمة 게스트에서 `run udp 10.0.2.2 9000 hello`로 الفعلي_بيانات 왕복을 확인한다. 새 تطبيق_f5044b9b سجل_إدخال, API 및 제한은 [فضاء_المستخدم ينفذ_أمر·네트워크 안내](os/فضاء_المستخدم/안내.md)를 참고한다. حديث_عنصر QEMU RTL8139·ثابت_قيمة_f430d3f5 IPv4·UDP 전용이며 TCP/DNS는 미지원이며, 전용 IDE مخزن_قيمة 형식과 POSIX ملف/UDP 일부 기능을 추가했다.

`make vbox`는 `jkoros operating system` 전용 VM을 만들고 디스크 없이 ISO로 부팅한다. ينفذ_أمر 중이면 유지하고, مخزن_قيمة·일시정지 상태이면 재개하며, 꺼져 있을 때만 새 ISO를 빌드해 연결한다. VirtualBox에서 부팅과 셸의 فضاء_المستخدم تطبيق_f5044b9b 실행을 확인했다. 다만 حديث_عنصر VirtualBox용 네트워크 드라이버는 없어 네트워크 장치를 비활성화한다. UDP 시험에는 `make run`을 사용한다. 상태별 동작과 새 بنية_نظام 반영 방법은 [VirtualBox ينفذ_أمر 안내](문서/가상상자실행.md)에 있다.

기존 관리 커널만 시험하려면:

```sh
cd /home/user/jkoros
make -f فتح_إدخال.mk 검사
make -f فتح_إدخال.mk مضيف
```

`مضيف`는 여전히 JVM 관리 계층의 إجراء 시험이다. `make -f فتح_إدخال.mk بنية_صورة`는 새 `os/`의 제한형 네이티브 نواة_قيمة ISO를 만든다. 기존 `قديم_مصدر/`의 نظام_الملفات·عملية_قيمة·شبكة_رمز 구현 전체를 이 ISO에 이식했다는 의미는 아니다.

العربية دالة_قيمة·متغيّر_قيمة·ملف 이름과 الفعلي_بيانات C API는 [posix-kor](posix-kor/안내.md)에 있다. 게스트 Java에서는 `FileInputStream`·`FileOutputStream`의 단일 بايت_قيمة 입출력도 지원한다. 전체 POSIX·OpenJDK·Swing 지원으로 확대된 것은 아니다.

خارجي_قيمة 배포용 `pack.sh` / `unpack.sh`와 자동 의존성 복원은 [توزيع_قيمة 안내](distribution/README.md)를 참고하세요.
