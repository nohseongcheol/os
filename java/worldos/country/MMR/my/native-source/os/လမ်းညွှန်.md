# Java 네이티브 စက်စနစ်

이 문서는 기존 **x86 အူတိုင်တန်ဖိုး**을 설명한다. Raspberry Pi 4의 ကိုယ်ပိုင် ARM64 အစဦးအခြေအနေ 이식은 [별도 လမ်းညွှန်](../platforms/rpi4-native/README.md)를 참고한다. အောက်ဆုံးတန်ဖိုး x86 သုံးစွဲသူ ELF·ကွန်ရက်ဆက်·IDE သိုလှောင်တန်ဖိုး 기능이 ARM64에 အားလုံးတည်ဆောက် 이식된 상태는 아니다.

Java 원문을 ကိုယ်ပိုင် AOT 후단으로 x86 기계어로 컴파일해 부팅하는 작은 운영체제다. 커널과 별도로 ကိုယ်ပိုင် 제한형 Java ဘာသာပြန်စက်·JVM ELF를 သုံးစွဲသူ 모드에 적재할 ကိန်းတန်ဖိုး 있다. Linux, engos, koros4와 ပြင်ပတန်ဖိုး OpenJDK는 게스트에 적재하지 않는다. စက်တင် 진입과 စက်ပစ္စည်းဆက်သွယ်ပေါက်/물리 မှတ်ဉာဏ်နယ်ပယ် 접근은 어셈블리이며, အက္ခရာ အဆုံးသုံးစက်·ဝင်ဒေတာ လုပ်ငန်းစဉ်တန်ဖိုးအချက်·အမိန့် တန်ဖိုးသဒ္ဒါခွဲခြမ်း·အလုပ် ကဏ္ဍတန်ဖိုး 관리는 `မူရင်းကုဒ်/*.java`에 있다.

## 게스트 Java ဖွံ့ဖြိုးရေး

`javac Hello.java`, `java Hello`로 부팅된 စက်စနစ် 안에서 မူရင်းကုဒ်ဘာသာပြန်·실행한다. `edit FILE.java`와 `.save`로 소스를 작성하며 `ls`, `cat`, `rm`을 제공한다. RAM 파일은 အများဆုံးတန်ဖိုး 8개, 각각 16KiB이다. 전용 IDE 매체를 연결하면 `sync`로 보존할 ကိန်းတန်ဖိုး 있다. 이 기능은 ကိုယ်ပိုင် 제한형 구현이며 전체 OpenJDK/JDK 호환은 아니다. 사용법·ထောက်ပံ့မှုတန်ဖိုး 문법·ဖိုင် 적재·교차 시험은 [Java ဖွံ့ဖြိုးရေး ဝန်းကျင်](../စာတမ်း/Javaဖွံ့ဖြိုးဝန်းကျင်.md)에 있다. `make test-java`로 검증한다.

## 빌드와 စက်မောင်း

`compiler/`ပထမတွက်ချက်ခံ 요구하는 도구에 더해 ISO 생성에는 `grub-file`, `grub-mkrescue`, GRUB BIOS မော်ဂျူးတန်ဖိုး, `xorriso`ပထမတွက်ချက်ခံ 필요하다. 실행에는 QEMU 또는 VirtualBox가 필요하다. လက်ရှိအချက်အလက်တစ်ခု 설치된 도구만 사용한다. `make run-store`는 새 전용 가상 သိုလှောင်တန်ဖိုး 매체를 만들어 연결한다. VirtualBox 실행기는 이 프로젝트가 만든 전용 VM만 설정하고 다른 VM은 변경하지 않는다. 가상 메모리는 မူလသတ်မှတ်တန်ဖိုး 64MiB이며 အနည်းဆုံးတန်ဖိုး 16MiB가 필요하다.

```sh
cd /home/user/jkoros/os
make                 # build/kernel.elf
make iso             # build/kernel.iso (သုံးစွဲသူ ELF အုပ်စုတန်ဖိုး ခေါင်းစီးဖိုင်)
make run             # ELF 직접 စက်တင်, အစဉ်ဆက်တန်ဖိုး အဆုံးသုံးစက်
make run-gui         # GRUB ISO စက်တင်, VGA 창과 PS/2 자판
make vbox            # 상위 폴더의 실행기로 전용 VirtualBox VM စက်မောင်း
make vbox-status     # 전용 VirtualBox VM အခြေအနေတန်ဖိုး အတည်ပြု
make test            # ELF와 ISO 두 경로의 တကယ့်ဒေတာ စက်တင်/ဝင်ဒေတာ စမ်းသပ်မှု
make apps            # သုံးစွဲသူ 프로그램만 တည်ဆောက်
make test-network    # သုံးစွဲသူ စက်မောင်း/UDP/တန်ဖိုးကာကွယ် စမ်းသပ်မှု
```

`make run`은 QEMU의 အစဉ်ဆက်တန်ဖိုး 표준 입출력을 쓴다. `Ctrl+A`를 누른 နောက်တန်ဖိုး `X`로 QEMU를 종료할 ကိန်းတန်ဖိုး 있다. `halt`는 게스트 CPU만 정지시키므로 QEMU ဝင်း/프로세스는 별도로 닫는다. 폴링 방식이라 တန်ဖိုးစောင့် 중에도 အိမ်ရှင် CPU를 사용할 ကိန်းတန်ဖိုး 있다.

VirtualBox는 `make vbox`로 실행한다. 새 전용 VM을 မှတ်ဉာဏ်ဒေတာ 64MiB, BIOS, 광학 드라이브 부팅으로 자동 설정하며 디스크는 필요 없다. တကယ့်ဒေတာ VirtualBox 5.2.42에서 စက်တင်, Java ကိုယ်ပိုင် စမ်းသပ်မှု, အမိန့်ဝင်း ဝင်ဒေတာ, `run hello vbox`의 ring 3 실행과 ဖြစ်သောပုံမှန် 종료를 확인했다. လက်ရှိအချက်အလက်တစ်ခု ဆက်သွယ်မှု 드라이버는 QEMU의 RTL8139 전용이며 VirtualBox의 PCnet/E1000에서는 네트워크를 사용할 ကိန်းတန်ဖိုး 없어 ကွန်ရက်ဆက် 장치를 비활성화한다. သိုလှောင်တန်ဖိုး အခြေအနေတန်ဖိုး 재개와 새 တည်ဆောက် 반영 방법은 [VirtualBox စက်မောင်း လမ်းညွှန်](../စာတမ်း/VirtualBoxလုပ်ဆောင်.md)에 있다.

## 셸에서 သုံးစွဲသူ ပရိုဂရမ် စက်မောင်း 및 ကွန်ရက်ဆက် ခေါ်လုပ်

독립 ELF32 စက်မောင်း 파일을 적재해 **ring 3**에서 실행한다. `int 0x80` 시스템 호출을 통해 အဆုံးသုံးစက် အထွက်, အချက်များ 조회, UDP ဖွင့်·ပို့·လက်ခံ·닫기를 제공한다. သုံးစွဲသူ 코드를 အူတိုင်တန်ဖိုး 함수로 직접 호출하는 구조가 아니다.

```text
jkoros> apps
jkoros> run hello first second
jkoros> net
jkoros> run netcheck
jkoros> run udp 10.0.2.2 9000 hello
```

နောက်ဆုံးအချက်အလက်တစ်ခု 명령의 응답을 받으려면 호스트의 별도 터미널에서 `python3 /home/user/jkoros/os/ကိရိယာစု/ဒေတာပြန်ယူ.py --port 9000`을 먼저 실행한다. 상세 API, ပရိုဂရမ် အချက်နောက်တွဲ, လိပ်စာ 공간과 제한은 [သုံးစွဲသူ စက်မောင်း·ကွန်ရက်ဆက် လမ်းညွှန်](သုံးစွဲသူ/လမ်းညွှန်.md)에 있다.

စက်တင် အတည်ပြု စကားစု:

```text
JKOROS NATIVE JAVA
Java 기계어 အူတိုင်တန်ဖိုး လုပ်ဆောင်
JAVA SELFTEST PASS
USER ELF: ring 3 / paging / int 0x80
help | info | mem | alloc | free N | echo TEXT | clear | test | halt
apps | run NAME [ARGS] | net
READY
jkoros>
```

## 구현한 기능

- GRUB Multiboot 1 ELF စက်တင်, x86 တန်ဖိုးကာကွယ် နည်းစနစ်တန်ဖိုး GDT, BSS အစပြင်ဆင်, 64KiB တွက်ချက်ခံထပ်ဆင့်အစု.
- Java လုပ်ဆောင်ချက် တကယ့်ဒေတာ 실행과 စက်တင် စနစ်သတင်းအချက်အလက် အမှတ်အသား အတည်ပြု.
- COM1 အစဉ်ဆက်တန်ဖိုး အဝင်အထွက်, VGA အက္ခရာ မျက်နှာပြင်·စာညွှန်းတန်ဖိုး·스크롤·အချက်ဖျက်.
- PS/2 မူလသတ်မှတ်တန်ဖိုး 자판, 좌우 Shift, Enter, Backspace. တိုးချဲ့မှု သော့တန်ဖိုး/마우스 자료는 အမိန့် 입력으로 쓰지 않는다.
- အလျား 128의 အမိန့် ဝင်ဒေတာ 버퍼, လျှံကျတန်ဖိုး 방지, CR/LF လုပ်ငန်းစဉ်တန်ဖိုးအချက်.
- `help`, `info`, `mem`, `alloc`, `free N`, `echo TEXT`, `clear`, `test`, `halt`.
- 4KiB အလုပ် ကဏ္ဍတန်ဖိုး 8개의 သိုလှောင်ရာခွဲဝေ·ပြန်ပေးရလဒ်·재사용과 중복 ပြန်ပေးရလဒ် 방지.
- Java အခင်းအကျင်းတန်ဖိုး 256KiB 영역의 အရွယ်·အောက်ညွှန်း 검사와 런타임 အမှား 중단.
- ဖတ် 전용 JKAP စက်မောင်း အုပ်စုတန်ဖိုး, ELF32 ကဏ္ဍတန်ဖိုး/အချက်အမှတ်တစ်ခု မှန်ကန်ကြောင်းစစ်, သုံးစွဲသူ နည်းစနစ်တန်ဖိုး·အချက်များ·ထွက်ပရိုဂရမ် ကုဒ်တန်ဖိုး.
- အူတိုင်တန်ဖိုး/သုံးစွဲသူ 페이지 ခွင့်ပြုချက်တန်ဖိုး 분리, TSS, IDT, PIT 100Hz, သုံးစွဲသူ CPU ခြွင်းချက် လုပ်ငန်းစဉ်တန်ဖိုးအချက် 및 စက်မောင်း အချိန်တန်ဖိုး 상한.
- PCI RTL8139 폴링 드라이버, ARP, တည်ငြိမ်တန်ဖိုး IPv4, UDP စစ်ဆေးပေါင်းလဒ်·송수신·တန်ဖိုးစောင့် ကန့်သတ်ချက်တန်ဖိုး.

`mem`의 Upper memory는 Multiboot의 1MiB အပေါ်ဘက် 연속 မှတ်ဉာဏ်ဒေတာ အရွယ်(KiB)이며, 전체 မှတ်ဉာဏ်ဒေတာ 지도 분석이나 자유 물리 မှတ်ဉာဏ်ဒေတာ 수치가 아니다. `alloc`은 이미 확보한 ကိန်းပြည့် အခင်းအကျင်းတန်ဖိုး 안의 အလုပ် ကဏ္ဍတန်ဖိုး 번호를 반환한다. 일반 물리 စာမျက်နှာတန်ဖိုး သိုလှောင်ရာခွဲဝေ, လိပ်စာ သတ်မှတ်လိပ်စာနယ် 또는 သုံးစွဲသူ လုပ်ငန်းစဉ် မှတ်ဉာဏ်ဒေတာ 관리가 아니다.

## 명시적인 နယ်နိမိတ်ကန့်သတ်ချက်

이 커널은 **သုံးစွဲသူ 프로그램을 한 번에 တစ်တန်ဖိုး 실행하는 အစဦးအခြေအနေ အူတိုင်တန်ဖိုး**이다. PIT IRQ0만 사용하며 키보드와 NIC는 폴링한다. သုံးစွဲသူ CPU 예외는 해당 프로그램을 끝내고 셸로 복귀시키지만 အူတိုင်တန်ဖိုး 예외는 중단한다. စက်မောင်း 시간은 약 3초로 제한한다. 완전한 선점 다중 လုပ်ငန်းစဉ် 스케줄러, FAT/ext 등 일반 디스크 ဖိုင်စနစ်, TCP·DNS·DHCP·IPv6·HTTP, 전체 POSIX, 일반 အရာဝတ္ထုတန်ဖိုး 모델/GC는 아직 없다. 전용 IDE ဖိုင် 보존과 POSIX ဖိုင်/UDP 일부 기능은 구현했다. JVM은 RAM 파일의 단일 클래스를 စက်မောင်း 시 적재하며 일반 ClassLoader나 JAR 로딩은 지원하지 않는다. 네이티브 စက်မောင်း 파일은 တည်ဆောက် 시 ဖတ် 전용 묶음에 넣으며, 일반 Linux ELF를 실행하는 환경이 아니다. 기존 `../အခြေခံကုဒ်/`의 JVM 관리 အူတိုင်တန်ဖိုး 전체를 이식한 것도 아니다.

Java 식별자는 한국어다. အစဉ်ဆက်တန်ဖိုး 출력은 이 프로젝트의 ဟန်ဂုစာသား(BMP အက္ခရာ)을 UTF-8로 표시한다. VGA는 မူလသတ်မှတ်တန်ဖိုး ASCII 글꼴만 사용하므로 ဟန်ဂုစာသား 자리에 `?`ပထမတွက်ချက်ခံ 나온다. အမိန့် 입력도 လက်ရှိအချက်အလက်တစ်ခု ASCII만 지원하며 ဟန်ဂုစာသား စာလုံးပုံစံတန်ဖိုး·입력기 및 보조 평면 အက္ခရာ 출력은 후속 작업이다. `test`는 작은 배열을 새로 할당하고 GC가 없으므로 무한 반복하지 않는다.

## 자동 စမ်းသပ်မှု

`စမ်းသပ်မှု/စက်တင်စမ်းသပ်.py`는 디스크 없는 독립 QEMU를 생성해 다음을 검증하고 종료한다.

- ELF 직접 စက်တင် 및 GRUB ISO စက်တင်.
- Java ကိုယ်ပိုင် 시험과 UTF-8 အစဉ်ဆက်တန်ဖိုး စကားစု.
- အမိန့် အကူအညီပြသ·စနစ်သတင်းအချက်အလက်·မှတ်ဉာဏ်ဒေတာ·အထွက်·အမှား ဝင်ဒေတာ·မျက်နှာပြင် အချက်ဖျက်.
- အလုပ် ကဏ္ဍတန်ဖိုး 8개 သိုလှောင်ရာခွဲဝေ, 부족 လုပ်ငန်းစဉ်တန်ဖိုးအချက်, ပြန်ပေးရလဒ်/중복 ပြန်ပေးရလဒ်/재할당.
- အစဉ်ဆက်တန်ဖိုး စာကြောင်းသစ်·백스페이스·긴 ဝင်ဒေတာ လုပ်ငန်းစဉ်တန်ဖိုးအချက်.
- QEMU PS/2 သော့တန်ဖိုး 입력으로 `info` စက်မောင်း, `halt` လုပ်ဆောင်မှုရပ်.

အောင်မြင်မှုတန်ဖိုး 로그는 `build/စက်တင်စမ်းသပ်.json`에 남는다. 로컬 Unix 소켓을 금지하는 샌드박스에서는 စမ်းသပ်မှု 도구에 해당 권한이 필요하다. စမ်းသပ်မှု 도중 새로 만든 QEMU만 종료하며 기존 VM과 တကယ့်ဒေတာ 디스크는 건드리지 않는다.

`စမ်းသပ်မှု/သုံးစွဲဆက်သွယ်စမ်းသပ်.py`는 ELF/ISO 각각에서 သုံးစွဲသူ ELF, တကယ့်ဒေတာ ring 3, အချက်များ, အိမ်ရှင် 루프백 UDP 왕복, 1,023/1,024바이트 24회 연속 왕복, အချိန်တန်ဖိုး 초과, NIC 없음, မှတ်ဉာဏ်ဒေတာ/စက်ပစ္စည်းဆက်သွယ်ပေါက် ဝင်သုံးအချက် 차단, CPU ခြွင်းချက်, 무한 반복, 잘못된 ELF를 시험한다. `build/သုံးစွဲဆက်သွယ်စမ်းသပ်.json`에 게스트 기록과 호스트가 받은 데이터의 အလျား·해시를 저장한다. `စမ်းသပ်မှု/ဒေတာထုပ်စမ်းသပ်.py`는 တကယ့်ဒေတာ Java သဘောတူစည်းမျဉ်းတန်ဖိုး 처리기에 손상된 패킷을 넣어 2,201개 နယ်နိမိတ်တန်ဖိုး/စစ်ဆေးပေါင်းလဒ် 조건을 검사한다. အိမ်ရှင် 루프백 외 ပြင်ပတန်ဖိုး 서버에는 စမ်းသပ်မှု 트래픽을 보내지 않는다.

부트 경계는 GNU의 [Multiboot သတ်မှတ်စံ](https://www.gnu.org/software/grub/manual/multiboot/multiboot.html)를 따른다.

새 ဖိုင်အညွှန်း·C ABI·IDE သိုလှောင်တန်ဖိုး·Java ဖိုင် 흐름의 범위와 မြန်မာ 명명 대응은 [posix-kor လမ်းညွှန်](../posix-kor/လမ်းညွှန်.md)에 있다. `make test-posix`로 ELF/ISO 실행과 재부팅 보존을 검증한다.
