# ကိုယ်ပိုင် ARM64 JVM 0.4와 မြန်မာ စာကြည့်တိုက်

မြန်မာ ဆက်သွယ်မှု·ခြွင်းချက် 사용법은 [မြန်မာ Java API](မြန်မာJava/လမ်းညွှန်.md), လုပ်ဆောင်ချက်·ကိန်းရှင်တန်ဖိုး·ဖိုင် 이름의 변경과 어원 근거는 [명명 လမ်းညွှန်](명명/လမ်းညွှန်.md)를 참고한다.

JAR စက်မောင်း, ပြင်ပတန်ဖိုး IPv4 TCP/UDP, 별도 တည်ငြိမ်တန်ဖိုး 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](ဖိုင်လွှဲပြောင်းနှင့်ဘာသာပြန်မှု.md)에 설명한다. အောက်ဆုံးတန်ဖိုး အရာဝတ္ထုတန်ဖိုး·Thread·Swing은 JVM 경로의 기능이며 AOT ထောက်ပံ့မှုတန်ဖိုး 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 စက်မောင်း**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK အတန်းတန်ဖိုး စာကြည့်တိုက် 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 အတန်းတန်ဖိုး·တည်ငြိမ်တန်ဖိုး နည်းလမ်းတန်ဖိုး 중심이던 실행기를 အရာဝတ္ထုတန်ဖိုး·စာကြည့်တိုက် စက်မောင်း 기반으로 넓힌 것이다.

## 실행과 မူရင်းကုဒ်ဘာသာပြန်

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# ကိုယ်ပိုင် အူတိုင်တန်ဖိုး 안에서 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ မူရင်းကုဒ်ဘာသာပြန် → class စက်မောင်း, မြန်မာ API ခေါ်လုပ်
python3 ကိရိယာစု/ဖိုင်လုပ်ဆောင်.py စမ်းသပ်မှု/Java/ဟန်ဂုမူရင်းကုဒ်.java

# အရာဝတ္ထုတန်ဖိုး·ခြွင်းချက် 등은 အိမ်ရှင် JDK로 Java 8 class를 만든 후 ကိုယ်ပိုင် 커널에서 စက်မောင်း
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java စမ်းသပ်မှု/Java/ဟန်ဂုစမ်းသပ်.java
python3 ကိရိယာစု/ဖိုင်လုပ်ဆောင်.py build/my-java/ဟန်ဂုစမ်းသပ်.class

# 의존 class 파일은 --include로 함께 လွှဲပြောင်းတန်ဖိုး
javac --release 8 -encoding UTF-8 -d build/my-java စမ်းသပ်မှု/Java/အရာဝတ္ထုစမ်းသပ်.java
python3 ကိရိယာစု/ဖိုင်လုပ်ဆောင်.py build/my-java/အရာဝတ္ထုစမ်းသပ်.class \
  --include build/my-java/နောက်ခံတန်ဖိုး.class --include build/my-java/အခွဲတန်ဖိုး.class \
  --include build/my-java/နိုင်တွက်.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.အတန်းတန်ဖိုး.class`라는 RAM ဖိုင် 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.အတန်းတန်ဖိုး`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.အတန်းတန်ဖိုး`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar ဖိုင်.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 မြန်မာ 클래스만 찾는다. ဖြန့်ချိမှုတန်ဖိုး မြန်မာ စာကြည့်တိုက် JAR는 အိမ်ရှင် javac의 classpath로 사용하며, 같은 클래스가 သုံးစွဲသူ JVM ELF에도 ဖတ် 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 တည်ငြိမ်တန်ဖိုး နည်းလမ်းတန်ဖိုး, int/boolean/char/String, အခြေအနေစည်းကမ်း·반복, အက္ခရာစဉ် ပေါင်းစပ်တန်ဖိုးများ, 일부 ဖိုင် 스트림 등의 **ကိုယ်ပိုင် 부분집합 ဘာသာပြန်စက်**တတိယအော်ပရန်း. အရာဝတ္ထုတန်ဖိုး ကြေညာချက်·상속·try/catch·Thread သုံးစွဲမှု 소스를 게스트 javac가 အားလုံးတည်ဆောက် 컴파일하는 것은 아니다. ထိပ်တန်ဖိုး 기능은 `javac --release 8`로 만든 class를 ကိုယ်ပိုင် JVM에서 실행한다. မြန်မာ API 중 အထွက်·အက္ခရာ 스칼라 လုပ်ဆောင်ချက်·ဖိုင် ဖတ်/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class နှုတ်ဆက် {
    public static void main(String[] အချက်များ) throws Exception {
        မြန်မာ.ကိုယ်ပိုင်.အထွက်.စာကြောင်းထုတ်("안녕하세요😀");
        မြန်မာ.ကိုယ်ပိုင်.အထွက်.ကိန်းထုတ်(မြန်မာ.ကိုယ်ပိုင်.အက္ခရာ.ကုဒ်အမှတ်တစ်ခုအရေအတွက်("ဟန်ဂုစာသား😀"));
        မြန်မာ.ကိုယ်ပိုင်.ဖိုင်.ရေး("နှုတ်ဆက်.txt", "ဟန်ဂုစာသား ဖိုင်😀");
        မြန်မာ.ကိုယ်ပိုင်.အထွက်.စာကြောင်းထုတ်(မြန်မာ.ကိုယ်ပိုင်.ဖိုင်.ဖတ်("နှုတ်ဆက်.txt"));
    }
}
```

## ကိုယ်ပိုင် JVM에서 구현한 ဖြတ်နယ်ပယ်

| နယ်ပယ်တန်ဖိုး | 제공 ဖြတ်နယ်ပယ် |
|---|---|
| အတန်းတန်ဖိုး | class 버전 45…52, 여러 အတန်းတန်ဖိုး 로딩, 인스턴스/တည်ငြိမ်တန်ဖိုး အကွက်တန်ဖိုး, 생성자, 상속, 가상 ခေါ်လုပ်, 인터페이스 ခေါ်လုပ်, တည်ငြိမ်တန်ဖိုး အစပြင်ဆင် |
| တန်ဖိုး·အမိန့် | 32비트 int 계열, boolean/byte/char/short, ကိုးကားချက်, 1차원 အခင်းအကျင်းတန်ဖိုး, အခွဲ·switch·wide, instanceof/checkcast, category-1 တွက်ချက်ခံထပ်ဆင့်အစု အမိန့် |
| ခြွင်းချက် | 지원하는 표준 ခြွင်းချက် ထုတ်လုပ်·throw·catch·finally, နည်းလမ်းတန်ဖိုး 경계를 넘는 ဆက်ပို့တန်ဖိုး, getMessage; အောက်ဆုံးတန်ဖိုး ကန့်သတ်ချက်တန်ဖိုး ကိုးကားချက် |
| မှတ်ဉာဏ်ဒေတာ | 비이동 mark/sweep GC, 빈 နယ်ပယ်တန်ဖိုး 병합, တွက်ချက်ခံထပ်ဆင့်အစု·တည်ငြိမ်တန်ဖိုး အကွက်တန်ဖိုး·컬렉션·အလုပ်ကြိုးတန်ဖိုး·모니터·အက္ခရာစဉ် 상수의 ကိုးကားချက် 유지 |
| အက္ခရာစဉ် | UTF-16, length/charAt/equals/isEmpty/substring/concat/hashCode/toString, String.valueOf(int), StringBuilder의 မူလသတ်မှတ်တန်ဖိုး ထုတ်လုပ်·append(int/boolean/char/String)·toString |
| ကိန်းတန်ဖိုး | Integer.parseInt/valueOf/intValue/toString, 작은 Integer 캐시, Math.abs/min/max(int) |
| 표준 အထွက် | System.out/err, PrintStream.print/println의 int/boolean/char/String 및 빈 println |
| အခင်းအကျင်းတန်ဖိုး | int/byte/boolean/char/short/ကိုးကားချက် အခင်းအကျင်းတန်ဖိုး, အလျား·ဖြတ်နယ်ပယ် စစ်ဆေးချက်, ကိုးကားချက် အခင်းအကျင်းတန်ဖိုး အချက်အလက်တစ်ခုအင်္ဂါရပ် အမျိုးပုံစံတန်ဖိုး စစ်ဆေးချက်, System.arraycopy의 ထပ်နေသလား/ဖြတ်နယ်ပယ်/အချက်အလက်တစ်ခုအင်္ဂါရပ် အမျိုးပုံစံတန်ဖိုး စစ်ဆေးချက် |
| ဖိုင် | FileInputStream(String), FileOutputStream(String[,boolean]); read()/read(byte[][,offset,len]), write(int)/write(byte[][,offset,len]), close, အထွက် flush. EOF는 -1 |
| 컬렉션 | ArrayList/List: add(E), get, set, remove(int), size, isEmpty, clear. HashMap/Map: put/get/remove/containsKey/size/isEmpty/clear |
| အလုပ်ကြိုးတန်ဖိုး | Thread(), Thread(Runnable), Thread 상속, start/join/isAlive/currentThread/yield; synchronized နည်းလမ်းတန်ဖိုး·블록의 재진입·경합·ခြွင်းချက် 시 သိုလှောင်ရာလွှတ်ပေး |
| UDP | DatagramSocket의 မူလသတ်မှတ်တန်ဖိုး/စက်ပစ္စည်းဆက်သွယ်ပေါက် 생성자, send/receive/close/getLocalPort/setSoTimeout; DatagramPacket의 byte[]/အလျား ထုတ်လုပ် 및 လိပ်စာ·စက်ပစ္စည်းဆက်သွယ်ပေါက် ခေါင်းစီးဖိုင် ထုတ်လုပ်, getData/getLength/getAddress/getPort/setLength |
| လိပ်စာ | InetAddress.getByName은 localhost/ဂဏန်းတန်ဖိုး IPv4 (DNS 미지원), getLoopbackAddress/getHostAddress |
| ပုံဆွဲမှု | မြန်မာ မျက်နှာပြင် API가 EL0 SVC를 통해 프레임버퍼에 사각형을 ပုံဆွဲမှု; ဖြတ်နယ်ပယ် စစ်ဆေးချက် |

컬렉션은 지정한 메서드만 제공하며 iterator/stream/ညှိတန်ဖိုး·သုံးစွဲသူ 정의 equals/hashCode 콜백은 없다. 사전의 열쇠는 String/Integer/null 사용을 시험했다. UTF-16 ကုဒ်တန်ဖိုး 단위와 Unicode ကုဒ်တန်ဖိုး 포인트 수는 구분한다. ဟန်ဂုစာသား ဝင်ဒေတာ ပေါင်းစပ်မှု·စံပုံစံပြောင်း·아랍어 조판·GUI 다국어 글꼴은 이 အက္ခရာစဉ် 지원과 별개다.

예외는 Throwable/Exception/RuntimeException, ArithmeticException, NullPointerException, IndexOutOfBoundsException/ArrayIndexOutOfBoundsException/StringIndexOutOfBoundsException, IllegalArgumentException/NumberFormatException/IllegalThreadStateException, IOException/FileNotFoundException, IllegalStateException, ClassCastException, NegativeArraySizeException, ArrayStoreException, UnknownHostException, SocketTimeoutException의 제한된 ထုတ်လုပ်·분류·처리를 제공한다. သုံးစွဲသူ 정의 Throwable 상속, stack trace/cause/suppressed ခြွင်းချက်, try-with-resources의 addSuppressed, 완전한 အစပြင်ဆင် အမှား 포장은 아직 없다. 잡히지 않은 예외는 လက်ရှိအချက်အလက်တစ်ခု 전체 Java 실행을 실패로 끝낸다.

## မြန်မာ API

독립 패키지 **`မြန်မာ.ကိုယ်ပိုင်`**를 사용한다. Linux판 `မြန်မာ.Java`ပထမတွက်ချက်ခံ 요구하는 NIO/Swing/HTTP API를 ကိုယ်ပိုင် 커널에서 실행할 ကိန်းတန်ဖိုး 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 အတန်းတန်ဖိုး အမည်·နည်းလမ်းတန်ဖိုး·အချက်များ·အကွက်တန်ဖိုး·ဖိုင် 이름에 한국어를 사용한다. 표준 Java အတန်းတန်ဖိုး 이름은 호환성을 위해 보존한다.

| အတန်းတန်ဖိုး | 공개 기능 | 이름의 의미 |
|---|---|---|
| အထွက် | ရေး, စာကြောင်းထုတ်, ကိန်းထုတ် | အထွက်(出力): 내용을 바깥으로 ထုတ်ပေးတန်ဖိုး |
| အက္ခရာ | အလျား, ညီစာသား, စာသားကူးထည့်, တန်ဖိုးဖြတ်, ကိန်းပြည့်သဒ္ဒါခွဲခြမ်း/ကိန်းပြည့်တန်ဖိုးရေး, ကုဒ်အမှတ်တစ်ခုအရေအတွက်, ကုဒ်သွင်း/လျှို့ဝှက်ကုဒ်ဖြည် | အက္ခရာ(文字), ကုဒ်သွင်းစနစ်တန်ဖိုး(符號): 글의 단위와 그 값을 바이트로 나타내는 စည်းမျဉ်းတန်ဖိုး |
| ဖိုင် | ဖတ်/ရေး(String အမည်), ဘိုက်တန်ဖိုးဖတ်/ဘိုက်တန်ဖိုးရေး | 널리 쓰는 သုံးစွဲသူ 용어를 보존; RAM 자료의 အမည် |
| အချက်စာရင်း | တန်ဖိုးများထည့်, ဖတ်, တန်ဖိုးအစားထိုး, အချက်ဖျက်, အရွယ်, ဖြစ်သောအလွတ်တန်ဖိုး, အကြောင်းအရာရှင်း | အချက်စာရင်း(目錄): 순서가 있는 အချက်တန်ဖိုး 모음 |
| အဘိဓာန် | တန်ဖိုးထား, အချက်ရှာ, ရှိသလား, အချက်ဖျက်, အရွယ်, အကြောင်းအရာရှင်း | အဘိဓာန်(辭典): 찾는 말인 열쇠에 값을 ချိတ်ဆက်ပုံတန်ဖိုး |
| အလုပ် | လုပ်ဆောင်(လုပ်ဆောင်ရန်အလုပ်), စောင့်(အလုပ်သမား), အလုပ်အလှည့်ပေး, လည်ပတ်ဆဲလား | အလုပ် အလုပ်ကြိုးတန်ဖိုး: 한 ပရိုဂရမ် 안의 စက်မောင်း စီးကြောင်းတန်ဖိုး |
| ဆက်သွယ်မှု | ဖွင့်, ပို့, လက်ခံ, စောင့်ချိန်, ပိတ် | ဆက်သွယ်မှု(通信), ဒေတာစာ(電文), ဆက်သွယ်ပေါက်တန်ဖိုး: ဒေတာ 교환·메시지·포트의 역할 |
| မျက်နှာပြင် | စတုဂံ, အချက်ဖျက် | မျက်နှာပြင်(畫面): တကယ့်ဒေတာ 그림을 표시하는 면 |
| အူတိုင်တန်ဖိုး | မီလီစက္ကန့်, စတုဂံ | ကိုယ်ပိုင် JVM의 고정 native ချိတ်ဆက်; 일반 JNI는 아님 |

이 명명은 လက်ရှိအချက်အလက်တစ်ခု 기능을 설명하는 용어 선택이다. 기존 한국어에 없던 역사적 어원을 만들어 주장하지 않는다. ဖိုင်အမည်စာသား·식별자는 UTF-8 소스로 보관한다. `အက္ခရာ.လျှို့ဝှက်ကုဒ်ဖြည်`는 잘못된 UTF-8에 IllegalArgumentException을 던지며, `ကုဒ်သွင်း`는 짝이 없는 서로게이트를 `?`로 바꾼다. `ဖိုင်.ဖတ်`는 엄격한 UTF-8 복호화를 적용한다. မျက်နှာပြင် 색은 `빨강 | (초록 << 8) | (파랑 << 16)` 형식이다.

## စက်မောင်း 제한과 남은 အလုပ်

- 동시에 적재하는 class အများဆုံးတန်ဖိုး 16개(မြန်မာ အတန်းတန်ဖိုး ခေါင်းစီးဖိုင်), class당 16 KiB·ကိန်းသေတန်ဖိုး 풀 511항목, 전체 နည်းလမ်းတန်ဖိုး/အကွက်တန်ဖိုး 각각 512개. နည်းလမ်းတန်ဖိုး ကုဒ်တန်ဖိုး 8 KiB, ဒေသတွင်းနယ်ပယ်ကန့်သတ် ကိန်းရှင်တန်ဖိုး·피연산자 တွက်ချက်ခံထပ်ဆင့်အစု 각각 128슬롯, အချက်များ အများဆုံးတန်ဖိုး 16개(this ခေါင်းစီးဖိုင်).
- VM 가닥은 main ခေါင်းစီးဖိုင် **실행당 အများဆုံးတန်ဖိုး 4개**, 가닥당 ခေါ်လုပ် အနက်တန်ဖိုး 32. 100개 명령마다 စက်မောင်း 대상을 바꾼다. 네이티브 ခေါ်လုပ် 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- အရာဝတ္ထုတန်ဖိုး 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 တကယ့်ဒေတာ 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 ဖိုင်·대형 အက္ခရာစဉ်·객체가 이 제한을 넘을 ကိန်းတန်ဖိုး 있다.
- 실행은 50만 ဘိုက်ကုဒ် အမိန့် 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 ဝင်ဒေတာ 대기는 기한을 갱신하고 ဝင်း အလှည့်ပြောင်းနည်းစနစ် 시 중단·재개한다. 일반 ဝန်ဆောင်စက်တန်ဖိုး·계산의 무제한 실행은 아직 없다. 미지원 အမိန့်·အရင်းအမြစ်တန်ဖိုး 부족은 명시적인 오류로 종료한다.
- RAM ဖိုင် အများဆုံးတန်ဖိုး 64개, 파일당 16384바이트, လမ်း UTF-8 63바이트. RAM 디렉터리와 တစ်ဖက်တန်ဖိုး/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 မြန်မာ class는 RAM ဖိုင် 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 လက်ရှိအချက်အလက်တစ်ခု 경로에서 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ·အတန်းတန်ဖိုး·ဒေတာ 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 ပြင်ပတန်ဖိုး IPv4를 제공한다. တကယ့်ဒေတာ GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. ဒေတာစာ 512바이트, ကွန်ရက်ပေါက်တန်ဖိုး 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 စက်မောင်း 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 အခင်းအကျင်းတန်ဖိုး, 완전한 အခင်းအကျင်းတန်ဖိုး 공변성·인터페이스 အလွှာတန်ဖိုး စစ်ဆေးချက်, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/암호화/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 ထောက်ပံ့မှုတန်ဖိုး 부분집합은 အောက်ဆုံးတန်ဖိုး 및 ဖွံ့ဖြိုးရေး 매뉴얼을 참고한다. အတန်းတန်ဖိုး ဖိုင် 전체 검증기·ဝင်သုံးအချက် ခွင့်ပြုချက်တန်ဖိုး/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 တန်ဖိုးကာကွယ် နယ်နိမိတ်တန်ဖိုး 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 အကောင်အထည်ဖော်မှု 단계다: 완전한 JVM တန်ဖိုး/မှန်ကန်ကြောင်းစစ်/အတန်းတန်ဖိုး 로더와 ခြွင်းချက် 모델 → 영속 VFS·mmap·နာရီ·원자 တွက်ချက်လုပ်ဆောင်မှု·တကယ့်ဒေတာ 스레드/တစ်ပြေးညီလုပ် ABI → OpenJDK java.base 및 native စာကြည့်တိုက် 이식 → ကိရိယာ ကွန်ရက်ဆက်·TCP/IP → ဝင်း 시스템/စာလုံးပုံစံတန်ဖိုး/입력기·java.desktop → Java SE 호환성 စမ်းသပ်မှု. လက်ရှိအချက်အလက်တစ်ခု ကိုယ်ပိုင် JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## မှန်ကန်ကြောင်းစစ်

`ကိရိယာစု/JVMစမ်းသပ်.py`는 같은 Java 8 class 파일의 출력을 အိမ်ရှင် OpenJDK `-Xverify:all`과 QEMU raspi4b ကိုယ်ပိုင် 커널에서 비교한다. အရာဝတ္ထုတန်ဖိုး/상속/인터페이스·switch·အခင်းအကျင်းတန်ဖိုး, ခြွင်းချက်/finally, 컬렉션/GC, Thread/သော့ခတ်တန်ဖိုး, မြန်မာ UTF-8/ဖိုင်/컬렉션, တကယ့်ဒေတာ UDP 루프백/အချိန်တန်ဖိုး 초과, 게스트 ဟန်ဂုစာသား မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ မူရင်းကုဒ်ဘာသာပြန်, အခင်းအကျင်းတန်ဖိုး အမျိုးပုံစံတန်ဖိုး/တန်ဖိုးမိတ္တူကူး/ဖိုင် နယ်နိမိတ်တန်ဖိုး·ဟန်ဂုစာသား 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 ဖိုင် တန်ဖိုးငြင်းပယ် 시험을 실행한다. UDP စီမံကိန်းအမြစ် 실행에는 အိမ်ရှင် 루프백 ကွန်ရက်ပေါက်တန်ဖိုး 권한이 필요하다.

`ကိရိယာစု/စက်တင်စမ်းသပ်.py`는 အူတိုင်တန်ဖိုး တန်ဖိုးကာကွယ်/회귀 시험과 별도로 မြန်မာ Java မျက်နှာပြင် API가 တကယ့်ဒေတာ 픽셀을 그렸는지도 QMP မျက်နှာပြင် 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. တကယ့်ဒေတာ Pi4 စက်ပစ္စည်း စက်တင် 시험과 전체 JDK 호환성 စမ်းသပ်မှု 결과는 아니다.


## JVM 0.3: 네트워크와 GUI တိုးချဲ့မှု

`Socket`/`ServerSocket` ထုတ်လုပ်·ချိတ်ဆက်·accept·양방향 InputStream/OutputStream·close·EOF·အချိန်တန်ဖိုး 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 ပြင်ပတန်ဖိုး ဂဏန်းတန်ဖိုး IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 အဆုံးမှတ် 16개, Java 루프백 버퍼 1024바이트, ပြင်ပတန်ဖိုး TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. အပြန်အလှန် 이벤트 대기는 စက်မောင်း 기한을 갱신하고 အဆုံးသုံးမျက်နှာပြင် အလှည့်ပြောင်းနည်းစနစ် 시 프로세스 상태를 သိုလှောင်တန်ဖိုး·복원한다. 이벤트 콜백 자체는 기존 ဘိုက်ကုဒ်/CPU 기한을 따른다.

မြန်မာ `ဝင်း`, `မြင်ကွင်းအစိတ်အပိုင်း`, `ချိတ်ဆက်သယ်ပို့` 클래스를 ဖြန့်ချိမှုတန်ဖိုး JAR와 ကိုယ်ပိုင် JVM 내장 자원에 추가했다. 상세 နည်းလမ်းတန်ဖိုး·ကန့်သတ်ချက်တန်ဖိုး·မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ·업로드 방법: [ဟန်ဂုစာသား ဖွံ့ဖြိုးရေး 매뉴얼](ဖွံ့ဖြိုးရေးလမ်းညွှန်.md).

## မြန်မာ 객체의 직접 စက်မောင်း

`ဝင်း`, `အညွှန်းစာ`, `စာသားအကွက်`, `ခလုတ်`, `ဖြစ်ရပ်တန်းစီရာ`, `လှုပ်ရှားမှုအသိပေးချက်`, `အလုပ်သမား`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. ကိုယ်ပိုင် JVM의 အရာဝတ္ထုတန်ဖိုး ထုတ်လုပ်,
ပုံစံတန်ဖိုး စစ်ဆေးချက်, မျက်နှာပြင် ခေါ်လုပ်, ဖြစ်ရပ် 큐, အလုပ်ကြိုးတန်ဖိုး 스케줄러에 မြန်မာ 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 စက်မောင်း 경로도 유지한다.
မြန်မာ 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

ကိုယ်ပိုင် 실행기의 မြန်မာ 진입점은 `public static void လုပ်ဆောင်()`이다.
표준 `main(String[])`도 지원하며 နှစ်တန်ဖိုး တတိယအော်ပရန်း 있으면 မြန်မာ 진입점을 우선한다.
명령행 인수는 `လုပ်ဆောင်အချက်များ.အရေအတွက်()`와 `လုပ်ဆောင်အချက်များ.စာသား(အစဉ်အမှတ်)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. တည်ငြိမ်တန်ဖိုး ဖိုင် 예제는 게스트
javac로도 컴파일하며, GUI/အလုပ်ကြိုးတန်ဖိုး 소스는 အိမ်ရှင် `javac --release 8`을 사용한다.
직접 GUI/အလုပ်ကြိုးတန်ဖိုး API는 ကိုယ်ပိုင် JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
မြန်မာ 가닥의 စက်မောင်း·တန်ဖိုးစောင့်·중복 လုပ်ဆောင် တန်ဖိုးငြင်းပယ်, GUI ဖြစ်ရပ် 출처·နံပါတ်·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

နည်းလမ်းတန်ဖိုး 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
မြန်မာ 클래스도 실행되지만, အက္ခရာစဉ် 리터럴·표준 စာကြည့်တိုက် 재정의·native
ချိတ်ဆက်·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 ဥပမာ](မြန်မာJava/လမ်းညွှန်.md)를 참고한다.

## အဆုံးသုံးမျက်နှာပြင် အစိတ်အပိုင်းတန်ဖိုး ပြန်လည်မွမ်းမံ

ရွှေ့တန်ဖိုး·အရွယ် 변경은 새 ဝင်း 영역과 ယခင်အချက်အလက်တစ်ခု 자리에서 드러난 띠만 합성한다.
1920×32 ပုံမှတ်(240 KiB)의 ယာယီတန်ဖိုး 그림에서 배경·겹친 ဝင်း·အက္ခရာတန်ဖိုး·GUI를 먼저
완성하고, လက်ရှိအချက်အလက်တစ်ခု တန်ဖိုးပြသ 메모리와 비교하여 달라진 화소만 기록한다.
32줄보다 큰 영역은 여러 띠로 처리하므로 전체 프레임을 원자적으로
교체하거나 수직 동기에 맞추는 방식은 아니다. 전체 배경을 먼저 지우는
중간 화면은 표시하지 않는다. 좌표가 같으면 ပြန်ကြိုးစား 그리지 않는다.

`make test-redraw`는 တကယ့်ဒေတာ C မျက်နှာပြင်ဆေးခြယ် 코드를 호스트의 မှတ်ဉာဏ်ဒေတာ 화면에 연결해
ရွှေ့တန်ဖိုး 80회·အရွယ် တန်ဖိုးပြောင်း 40회·겹친 ဝင်း 4개를 전체 합성 결과와 ပုံမှတ် 단위로 대조한다.
နယ်ပယ်တန်ဖိုး 밖 သုံးစွဲသူ ပုံဆွဲမှု, 동일 ပုံမှတ် 무기록, ညွှန်တံ 밑그림, တကယ့်ဒေတာ မျက်နှာပြင် စာကြောင်း 간격을
검사한다. 이 시험의 시간은 အိမ်ရှင် CPU 측정이며 Pi 4/QEMU 속도로 해석하지 않는다.
`make test-resize`는 QEMU/VNC의 640×480 및 1920×1080에서 ဘယ်ဘက် 모서리 끌기,
ဟန်ဂုစာသား ဝင်ဒေတာ·vi 미저장 အကြောင်းအရာတန်ဖိုး·독립 ဝင်း 크기를 검사한다.
