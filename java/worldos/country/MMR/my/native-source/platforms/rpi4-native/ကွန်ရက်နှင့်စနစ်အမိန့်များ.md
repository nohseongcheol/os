# ကိုယ်ပိုင် 커널의 네트워크와 လည်ပတ်မှုစနစ်တန်ဖိုး အမိန့်

게스트 SSH·VNC, LAN 공개 စက်မောင်း, Pi4 GENET·DHCP 추가분은 [ပြင်ပတန်ဖိုး ချိတ်ဆက်မှု လမ်းညွှန်](ပြင်ပချိတ်ဆက်မှုလမ်းညွှန်.md)를 먼저 참고한다. QEMU는 `sl0`, ရုပ်ပိုင်းစက်ပစ္စည်း GENET은 `en0`를 사용한다. ရုပ်ပိုင်းစက်ပစ္စည်း 드라이버는 아직 보드에서 검증하지 않았다.

이 문서는 `platforms/rpi4-native`의 ကိုယ်ပိုင် ARM64 Java 커널용이다. Linux/OpenJDK 실행환경의 명령어와 구분한다. 새 커널을 빌드하고 ပြန်ကြိုးစား 부팅해야 적용된다.

셸과 Java의 တကယ့်ဒေတာ CPU ခွင့်ပြုချက်တန်ဖိုး, `ps`/`top`에 표시되는 ယူနစ်တန်ဖိုး, အိမ်ရှင်·ပြင်ပတန်ဖိုး PC ချိတ်ဆက် 방법은
[စက်မောင်း 계층과 ပြင်ပတန်ဖိုး ဆက်သွယ်မှု 점검](실행계층과외부통신점검.md)에 정리했다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop ARGS=--network RESOLUTION=1920x1080
# အစဉ်ဆက်တန်ဖိုး 셸만 사용할 때
make run ARGS=--network
```

게스트에서 `help`, `help system` 또는 `အကူအညီပြသ system`을 입력한다. အောက်ဆုံးတန်ဖိုး 두 이름은 같은 동작을 하며 현지어 이름도 Tab으로 완성할 ကိန်းတန်ဖိုး 있다.

| 표준 အမိန့် | မြန်မာ အမိန့် | 기능 |
|---|---|---|
| ipconfig, ifconfig | 아이피설정 | တကယ့်ဒေတာ IPv4 လိပ်စာ·넷마스크·ကွန်ရက်တံခါးပေါက်·송수신 통계 |

| ping | တုံ့ပြန်စမ်းသပ် | တကယ့်ဒေတာ ICMPv4 အကြောင်းပြန်ချက်·손실률·왕복 အချိန်တန်ဖိုး |

## IP 설정과 ဆက်သွယ်မှု အတည်ပြု

```sh
ipconfig
ip addr show
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2
아이피설정 set 10.0.2.20 255.255.255.0 10.0.2.2
ping -c 4 -W 1 10.0.2.2
တုံ့ပြန်စမ်းသပ် -c 4 10.0.2.2
ip route show
ip link set dev sl0 down
ip link set dev sl0 up
netstat
```

초깃값은 `sl0`, `10.0.2.15/24`, ကွန်ရက်တံခါးပေါက် `10.0.2.2`တတိယအော်ပရန်း. လိပ်စာ 설정은 재부팅 전까지 유지된다. TCP/UDP 끝점이 열려 있으면 `error -16`으로 변경을 거부한다. 먼저 `ftpd stop` 등으로 서비스를 닫고 프로그램의 소켓을 닫는다. 잘못된 လိပ်စာ·비연속 넷마스크·다른 망의 관문은 적용하지 않는다.

`ip`는 ထိပ်တန်ဖိုး 구문의 부분집합이며 Linux iproute2 전체 문법을 구현하지 않는다. `ping`은 IPv4 ဂဏန်းတန်ဖိုး လိပ်စာ, `-c 1..100`, `-W 1..10`초를 지원한다. အမည် တန်ဖိုးသဒ္ဒါခွဲခြမ်း·IPv6는 미지원이며 GENET의 DHCP는 ပြင်ပတန်ဖိုး ချိတ်ဆက်မှု 구현에 추가했다. 응답이 없으면 ထွက်ကုဒ် 1, 잘못된 인수는 2, သုံးစွဲသူ 취소는 130이다. `ping ...; echo $?`로 확인한다.

QEMU ပြင်ပတန်ဖိုး 통신은 UART SLIP→NAT 연결을 사용한다. `--network` 없이도 ကိုယ်ပိုင် လိပ်စာ 조회·설정은 가능하지만 ပြင်ပတန်ဖိုး 응답은 오지 않는다. မူလသတ်မှတ်တန်ဖိုး NAT는 `10.0.2.0/24`တတိယအော်ပရန်း. ရုပ်ပိုင်းစက်ပစ္စည်း Pi의 GENET 드라이버는 별도로 추가했으며 ဆားကစ်ပြား 검증이 필요하다. Wi-Fi는 미지원이다.

주소를 `.20`으로 바꾼 နောက်တန်ဖိုး FTP 등 **외부에서 들어오는 ချိတ်ဆက်**까지 사용할 때는 စက်မောင်း 시 ဆက်ပို့တန်ဖိုး 대상도 지정한다.

```sh
make desktop ARGS="--network --guest-ip 10.0.2.20"
# 부팅한 게스트 안에서
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2
ftpd start
```

`--guest-ip`는 NAT ဆက်ပို့တန်ဖိုး 대상이며 게스트의 주소를 자동 설정하지 않는다. FTP ထိန်းချုပ်တန်ဖိုး 포트는 အိမ်ရှင် `127.0.0.1:2121`, 수동 데이터 포트는 50000~50007이다. 여러 VM을 함께 띄울 때는 `--network-host 127.0.0.2 --port 5903`처럼 အိမ်ရှင် 루프백 주소와 VNC 포트를 구분한다. FTP와 Java/C 소켓은 변경된 တကယ့်ဒေတာ 게스트 IP를 사용한다.

## အခြေအနေတန်ဖိုး 조회의 의미

`ps`는 အူတိုင်တန်ဖိုး/အမိန့်ဝင်း, 살아 있는 협력 အလုပ်, အများဆုံးတန်ဖိုး 4개의 EL0 သုံးစွဲသူ 세션을 표시한다. 다른 터미널에 열린 `vi` 등을 `SUSPENDED` 상태로 볼 ကိန်းတန်ဖိုး 있다. `MAPPED_KiB`는 တကယ့်ဒေတာ 페이지 ချိတ်ထားတန်ဖိုး, `RUN_ms`는 해당 세션이 선택된 동안의 경과 အချိန်တန်ဖိုး(시스템 ခေါ်လုပ် ခေါင်းစီးဖိုင်)이며 정밀 CPU 사용률이 아니다. `top -n 1`은 한 번, `top -n 2`는 두 번 표시한다. 리다이렉션된 `top`의 기본값은 한 번이다.

`free`의 AOT ပုံတင်မှတ်ဉာဏ်တန်ဖိုး 사용량은 할당기에서 읽는다. 힙은 အူတိုင်တန်ဖိုး BSS에 포함되므로 각 줄을 အားလုံးတည်ဆောက် 더하면 중복된다. 고정 예약 영역과 သုံးစွဲသူ 페이지 매핑을 표시하며 Linux의 가용 RAM 계산이나 အိမ်ရှင် မှတ်ဉာဏ်ဒေတာ 통계를 꾸며서 표시하지 않는다.

`df`는 RAM 파일시스템의 ဖိုင် 64칸 × 16 KiB를 표시한다. ဖိုင် 하나는 논리 크기와 별도로 16 KiB 칸을 예약한다. `Data`는 တကယ့်ဒေတာ ဒေတာ အလျား အကုန်စုစုပေါင်းတန်ဖိုး, `Reserved`는 သုံးစွဲမှု 중인 နေရာကွက်အချက် 용량이다. 삭제 후에도 열린 파일은 နောက်ဆုံးအချက်အလက်တစ်ခု 참조를 닫을 때까지 계산한다. SD/영구 디스크 사용량은 아직 지원하지 않는다.

## 종료와 မှန်ကန်ကြောင်းစစ်

게스트에서 `poweroff` 또는 `စက်ပိတ်`를 입력한다. FTP·ကွန်ရက်ပေါက်တန်ဖိုး·သုံးစွဲသူ 세션을 닫은 နောက်တန်ဖိုး BCM PM ထွက်ပရိုဂရမ် 절차를 실행한다. RAM 파일은 재부팅 후 보존되지 않는다. QEMU에서는 게스트의 `SHUTDOWN / guest-shutdown` 이벤트와 ဖြစ်သောပုံမှန် 종료를 검증한다. ရုပ်ပိုင်းစက်ပစ္စည်း Pi 4 전원 회로 동작은 아직 시험하지 않았다.

အကောင်အထည်ဖော်မှု 근거: [Linux BCM watchdog의 power-off 절차](https://github.com/torvalds/linux/blob/master/drivers/watchdog/bcm2835_wdt.c), [QEMU BCM PM ကိရိယာ](https://github.com/qemu/qemu/blob/master/hw/misc/bcm2835_powermgt.c).

```sh
make test-system
# ရလဒ်: build/verification/system-tools/report.json 및 serial.log
```

이 시험은 잘못된 IP တန်ဖိုးငြင်းပယ်, တကယ့်ဒေတာ ICMP အောင်မြင်မှုတန်ဖိုး·시간초과, ချိတ်ဆက် up/down, IP တန်ဖိုးပြောင်း 후 FTP 송수신, df ထုတ်လုပ်·삭제, ပုံတင်မှတ်ဉာဏ်တန်ဖိုး တွက်ချက်မှု, 다른 터미널의 vi PID·မှတ်ဉာဏ်ဒေတာ, top ပြန်လည်မွမ်းမံ·ထွက်ပရိုဂရမ်, ဟန်ဂုစာသား အမိန့်·Tab, 게스트 poweroff를 검사한다.

`java/worldos/နိုင်ငံတန်ဖိုး/국가코드` 판에는 같은 기능과 국가별 အမိန့် 대응표 `native-commands.json`이 들어간다. 표준 명령은 모든 판에서 유지한다. 새 현지어 이름은 기능 중심 제안이며 현지 화자·어원 검토를 완료한 표준 용어는 아니다. 미번역 항목은 대응표의 `pending`에 명시한다.
