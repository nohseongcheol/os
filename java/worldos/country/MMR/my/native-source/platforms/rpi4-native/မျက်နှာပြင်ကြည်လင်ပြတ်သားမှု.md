# ကိုယ်ပိုင် ARM64 커널의 မျက်နှာပြင် ကြည်လင်ပြတ်သားမှုတန်ဖိုး

QEMU စက်မောင်း 위치는 `jkoros/platforms/rpi4-native`တတိယအော်ပရန်း. 커널을 빌드한 နောက်တန်ဖိုး 다음과 같이 실행한다.

```bash
make build
python3 ကိရိယာစု/စက်မောင်း.py --desktop --network --resolution 1920x1080
```

Remmina의 **VNC** ချိတ်ဆက် 주소는 `127.0.0.1:5902`တတိယအော်ပရန်း. 이미 စက်မောင်း 중인 VM은 종료하고 새 옵션으로 ပြန်ကြိုးစား 시작한다. မျက်နှာပြင် 전체가 보이지 않으면 Remmina에서 မျက်နှာပြင် ညှိနယ်နိမိတ် 또는 전체 화면을 선택한다. 이 옵션은 게스트의 တကယ့်ဒေတာ ပုံမှတ် 수를 바꾼다.

`--resolution`은 일반 UART စက်မောင်း, `--desktop`, `--vnc`, `--display`에서 동일하게 적용된다. `--network`와 함께 사용할 ကိန်းတန်ဖိုး 있다. အနံတန်ဖိုး 640~1920, အမြင့်တန်ဖိုး 480~1080을 허용하며 기본값은 640×480이다. 1280×720과 1920×1080도 선택할 ကိန်းတန်ဖိုး 있다.

```bash
make desktop RESOLUTION=1920x1080
python3 ကိရိယာစု/စက်မောင်း.py --resolution 1280x720 --vnc 127.0.0.1:2
```

စက်တင် 로그는 တကယ့်ဒေတာ 할당된 크기를 표시한다.

```text
FRAMEBUFFER PASS 1920x1080 RGB32 (drawing only)
```

အဆုံးသုံးမျက်နှာပြင် 바탕과 အပေါ်ဘက် 막대는 မျက်နှာပြင် 전체를 채운다. 터미널은 ညာ 아래까지 끌어서 이동하고 X로 닫을 ကိန်းတန်ဖိုး 있다. အဆုံးသုံးမျက်နှာပြင် ဝင်း အရွယ်(568×360)와 စာလုံးပုံစံတန်ဖိုး 크기는 유지되므로 넓어진 화면에 여러 창을 배치할 ကိန်းတန်ဖိုး 있다. Swing 부분집합의 `setLocationRelativeTo(null)`도 တကယ့်ဒေတာ မျက်နှာပြင် 가운데를 사용한다. စက်တင် နောက်တန်ဖိုး 해상도를 바꾸는 기능은 제공하지 않는다.

## 프로그램에서 မျက်နှာပြင် အရွယ် ဖတ်

| ဘာသာစကား | မြန်မာ ခေါ်လုပ် |
|---|---|
| Java | `မြန်မာ.ကိုယ်ပိုင်.မျက်နှာပြင်.အနံတန်ဖိုး()`, `မျက်နှာပြင်.အမြင့်တန်ဖိုး()`, `မျက်နှာပြင်.အချက်ဖျက်(အရောင်တန်ဖိုး)` |
| C | `<화면규약.h>`의 `မျက်နှာပြင်အနံ()`, `မျက်နှာပြင်အမြင့်()`, `စတုဂံဆွဲ(...)` |
| C++ SDK | `ခေါ်လုပ်.h`의 `မျက်နှာပြင်အနံဖတ်()`, `မျက်နှာပြင်အမြင့်ဖတ်()`, `မျက်နှာပြင်စတုဂံ(...)` |
| Python | `from မြန်မာ import မျက်နှာပြင်အရွယ်, စတုဂံဆွဲ`; `အနံတန်ဖိုး, အမြင့်တန်ဖိုး = မျက်နှာပြင်အရွယ်()` |

C 함수는 매크로 별칭이 아닌 တကယ့်ဒေတာ 함수다. သုံးစွဲသူ ခေါ်လုပ် 22로 크기를 조회하며, မျက်နှာပြင်ဆေးခြယ် ခေါ်လုပ် 13과 GUI ခေါ်လုပ် 20은 တကယ့်ဒေတာ မျက်နှာပြင် 경계를 검사한다. 프레임버퍼 주소는 သုံးစွဲသူ 프로그램에 노출하지 않는다. မျက်နှာပြင် 밖의 요청은 오류를 반환한다.

게스트 `javac`에서는 `မြန်မာ.ကိုယ်ပိုင်.မျက်နှာပြင်.အနံတန်ဖိုး()`처럼 전체 이름으로 호출한다. 지원하는 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 문법에 맞춰 ပုံမှတ်အရောင် 상수는 십진수로 쓴다. အောက်ဆုံးတန်ဖိုး 호출은 စက်တင် 해상도와 관계없이 နောက်ဆုံးအချက်အလက်တစ်ခု 화소를 그린다.

```java
int အနံတန်ဖိုး = မြန်မာ.ကိုယ်ပိုင်.မျက်နှာပြင်.အနံတန်ဖိုး();
int အမြင့်တန်ဖိုး = မြန်မာ.ကိုယ်ပိုင်.မျက်နှာပြင်.အမြင့်တန်ဖိုး();
မြန်မာ.ကိုယ်ပိုင်.မျက်နှာပြင်.စတုဂံ(အနံတန်ဖိုး - 1, အမြင့်တန်ဖိုး - 1, 1, 1, 255);
```

`မျက်နှာပြင်` 클래스의 프레임버퍼 호출은 ကိုယ်ပိုင် JVM 전용이다. 이 API의 ခြွင်းချက် လုပ်ငန်းစဉ်တန်ဖိုးအချက် 시험은 အိမ်ရှင် `javac --release 8`로 컴파일한 class를 ကိုယ်ပိုင် JVM에서 실행한다. 게스트 컴파일러의 일반적인 `try/catch` 문법 지원을 추가한 것은 아니다.

## Raspberry Pi 4 SD စက်တင်

```bash
make image RESOLUTION=1920x1080
```

생성되는 `dist/jkoros-native-rpi4.img`와 `dist/jkoros-native-rpi4-boot.zip`에 1080p 설정이 들어간다. SD စက်ပုံရိပ်တန်ဖိုး 생성은 640×480, 1280×720, 1920×1080을 지원한다. 이미 펼친 စက်တင် 파일을 수정할 경우 `config.txt`의 `[pi4]`에 အောက်ဆုံးတန်ဖိုး 값을 사용한다.

```ini
max_framebuffer_width=1920
max_framebuffer_height=1080
framebuffer_width=1920
framebuffer_height=1080
hdmi_group=1
hdmi_mode=16
```

커널은 [Raspberry Pi စာတိုက်ပုံး သဘောတူစည်းမျဉ်းတန်ဖိုး](https://github.com/raspberrypi/firmware/wiki/Mailbox-property-interface)의 လက်ရှိအချက်အလက်တစ်ခု မျက်နှာပြင် အရွယ် 조회와 မျက်နှာပြင် သိုလှောင်ရာခွဲဝေ 응답을 사용한다. 응답의 အရွယ်·RGB32 ပုံစံတန်ဖိုး·한 줄의 ဘိုက်တန်ဖိုး ကိန်းတန်ဖိုး·သိုလှောင်ရာခွဲဝေ 용량을 확인하고, 반환된 စာကြောင်း 간격으로 그린다. အစဦးအခြေအနေ 조회에 실패하거나 ထောက်ပံ့မှုတန်ဖိုး 범위를 벗어나면 640×480을 요청한다. HDMI 설정은 [공식 펌웨어 မျက်နှာပြင် သတ်မှတ်ချက် စာတမ်း](https://www.raspberrypi.com/documentation/computers/legacy_config_txt.html)를 따른다. တကယ့်ဒေတာ Pi 4와 모니터 조합에서의 HDMI 부팅은 아직 검증하지 않았다.

## မှန်ကန်ကြောင်းစစ်

```bash
make test-resolution
```

시험은 각 해상도에서 တကယ့်ဒေတာ VNC မျက်နှာပြင် 크기와 픽셀, အဆုံးသုံးမျက်နှာပြင် 끌기·ပိတ်, C/Java 게스트 မူရင်းကုဒ်ဘာသာပြန်, Python စက်မောင်း, ညာ အောက်ဆုံးတန်ဖိုး 픽셀과 မျက်နှာပြင် နယ်နိမိတ်တန်ဖိုး အမှား, Swing အလယ် နေရာချထားပုံ·ခလုတ်·ပိတ်, GUI와 FTP 동시 사용을 확인한다. 결과와 မျက်နှာပြင် 캡처는 `build/verification/resolution/`에 저장한다.
