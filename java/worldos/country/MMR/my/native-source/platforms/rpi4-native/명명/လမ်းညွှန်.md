# ကိုယ်ပိုင် 커널과 번역기의 မြန်မာ အမည်

대상은 `platforms/rpi4-native`의 ကိုယ်ပိုင် Java အူတိုင်တန်ဖိုး, သုံးစွဲသူ JVM, C စက် ချိတ်ဆက်,
TCP/UDP·FTP, C ဘာသာပြန်စက်ကိရိယာတစ်ခု 이식부, MicroPython 이식부, တည်ဆောက်·စက်မောင်း·စမ်းသပ်မှု 도구다.
`golang/worldos/နိုင်ငံတန်ဖိုး/KOR/မူရင်းကုဒ်`의 원칙처럼 기능을 먼저 구분하고 이름을 정한다.
x86 Java 커널과 공용 x86·ARM64 미리 번역기의 ကိုယ်ပိုင် 선언도 명명 검사에 포함한다.
Linux 실행판의 အိမ်ရှင် ကိရိယာစု, OpenJDK 보조 ကိရိယာစု 및 ပြင်ပတန်ဖိုး ဖြန့်ချိမှုတန်ဖိုး မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 전체를
한국어로 ပြန်ကြိုးစား 작성했다는 뜻은 아니다.

## 명명 원칙과 말의 근거

- 명사는 자료의 역할을 나타낸다: `ဖိုင်ကိုင်တွယ်ရာ`, `တစ်ဖက်ဆက်သွယ်ပေါက်အမှတ်`, `ပုံတင်မှတ်ဉာဏ်သိုလှောင်ရာ`, `လက်ကွက်`.
- 함수는 행위를 나타낸다: `ဖတ်`, `ရေး`, `ဖွင့်`, `ပိတ်`, `망주소묶기`, `ပရိုဂရမ်စက်မောင်း`.
- TCP의 이어진 ဘိုက်တန်ဖိုး 흐름과 UDP의 နယ်နိမိတ်တန်ဖိုး 있는 자료를 `ဆက်သွယ်လမ်းကြောင်း`와 `ဒေတာပို့လမ်း`로 구별한다.
- 짧은 영어 변수도 쓰임에 따라 `အလျား`, `ဒေတာနေရာ`, `ရှာကြည့်အညွှန်းကိန်း`, `ပြန်ပေးတန်ဖိုး`으로 풀어 쓴다.
  အစဉ်အမှတ်·ယာယီတန်ဖိုး 산술값처럼 여러 역할에 재사용되는 변수는 `အစဉ်အမှတ်`, `ပထမတန်ဖိုး`, `ဒုတိယတန်ဖိုး`으로 구별한다.
- 이름이 같아도 ပြင်ပတန်ဖိုး 구조체의 필드와 ကိုယ်ပိုင် 변수는 별도로 분석한다.

`ချန်နယ်အချက်(通路)`는 이동이나 교류가 이루어지는 길이라는 기존 의미를 ဆက်သွယ်မှု 연결에
적용했다. `ဆက်သွယ်ပေါက်တန်ဖိုး(窓口)`의 주고받는 접점이라는 의미를 연결을 받는 곳에 적용했다.
이는 국립국어원 한국어기초사전의 [ချန်နယ်အချက်](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=49310),
[ဆက်သွယ်ပေါက်တန်ဖိုး](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=24898)의 뜻에 근거한다.

`ဒေတာစာ(電文)`은 전보에 담는 글이라는 기존 ဆက်သွယ်မှု 어휘에서 가져와, UDP 자료의
경계가 보존된다는 특징을 드러내는 데 쓴다. 근거는
[한국어기초사전 ဒေတာစာ](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=74335)이다.
`စီးကြောင်းတန်ဖိုး`, `အလုပ်ကြိုးတန်ဖိုး`, `ထပ်ဆင့်မှု`은 우리말의 움직임·이어짐·쌓이는 모양을 빌린 표현이다.
`ဝင်စီးကြောင်း`, `အလုပ်သမား`, `ထပ်ဆင့်သိုလှောင်ရာ` 같은 복합 이름은 이 프로젝트의 기능별 조어다.
이 အဘိဓာန် 근거를 특정 중세 문헌의 최초 출현이나 공인 전산 번역으로 확대하지 않는다.
공인 표준 မူရင်းကုဒ်ဘာသာပြန်ဆို·국어사 ဒေတာစာ 감수를 마쳤다는 뜻도 아니다.

| 기능 | 채택한 အမည် | အကြောင်းရင်း |
|---|---|---|
| TCP Socket | ဆက်သွယ်လမ်းကြောင်း | 상대와 연결되어 အစဉ်တန်ဖိုး 있는 바이트를 주고받음 |
| ServerSocket | ဆက်သွယ်ပေါက်လက်ခံရယူ | 새 연결이 들어오는 접점 |
| DatagramSocket | ဒေတာပို့လမ်း | 각 자료의 경계를 보존하는 ဆက်သွယ်မှု |
| InputStream / OutputStream | ဝင်စီးကြောင်း / ထွက်စီးကြောင်း | 들어오고 나가는 바이트의 အစဉ်တန်ဖိုး |
| heap / stack | ပုံတင်မှတ်ဉာဏ်သိုလှောင်ရာ / ထပ်ဆင့်သိုလှောင်ရာ | သိုလှောင်ရာခွဲဝေ 방식과 쌓고 꺼내는 ဖွဲ့စည်းပုံ |
| thread / keyboard | အလုပ်သမား / လက်ကွက် | 이어지는 실행과 글쇠의 အခင်းအကျင်းတန်ဖိုး |
| exception / timeout | ခြွင်းချက် / စောင့်အချိန်လွန်ခြွင်းချက် | ဖြစ်သောပုံမှန် 처리에서 벗어남과 그 구체적 အကြောင်းရင်း |

[Cအမည်ချိတ်ဆက်ပုံ.tsv](Cအမည်ချိတ်ဆက်ပုံ.tsv), [Pythonအမည်ချိတ်ဆက်ပုံ.tsv](Pythonအမည်ချိတ်ဆက်ပုံ.tsv)에

호환 진입점이며 구현을 두 벌 유지하지 않는다.

## 보존하는 규격 အမည်

`public`, `class`, `int`는 예약어다. `String`, `main`, 배열의 `length`는 예약어가 아니다.
လက်ရှိအချက်အလက်တစ်ခု 다섯 Java 예제는 `လုပ်ဆောင်()`·`လုပ်ဆောင်အချက်များ`·မြန်မာ မျက်နှာပြင်/အလုပ်ကြိုးတန်ဖိုး API를 사용해
သီးသန့်စကားလုံးများ·리터럴 외의 식별자를 한국어로 작성한다. မျက်နှာပြင်/가닥은 표준 객체를
감싸지 않고 ကိုယ်ပိုင် JVM에 직접 구현했다. 자세한 계약은 [မြန်မာ Java API](../မြန်မာJava/လမ်းညွှန်.md)를 본다.

표준 javac는 အက္ခရာစဉ် 리터럴에 `java.lang.String`, အက္ခရာစဉ် 결합에 `StringBuilder`
같은 이름을 생성한다. 이들은 မြန်မာ 소스에서도 바이트코드에 남을 ကိန်းတန်ဖိုး 있다.
기존 표준 class를 실행하는 JVM의 ချိတ်ဆက်ပုံတန်ဖိုး အက္ခရာစဉ်, 아직 표준 라이브러리를 쓰는
ဆက်သွယ်မှု·ဖိုင် 연결부까지 အားလုံးတည်ဆောက် 한국어로 재구현한 것은 아니다. 이름만 일괄 치환하면
အညွှန်း·재정의·native 연결이 달라져 호환성이 깨진다.

C 표준 လုပ်ဆောင်ချက်·ကိန်းပြည့်အမျိုးပုံစံ·POSIX ABI, CPU အမြန်မှတ်ကွက် အမည်, 어셈블리 အမိန့်, 링커 절 အမည်,
TinyCC·lwIP·MicroPython이 요구하는 သတ်မှတ်ချက် 매크로와 헤더 이름도 보존한다.
예: `main`, `memcpy`, `pk_bind`, `mpconfigport.h`, `lwipopts.h`, `stdint.h`.
ကိုယ်ပိုင် C 함수의 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 이름은 한국어이며, [စက်ချိတ်အမည်များ.h](စက်ချိတ်အမည်များ.h)ပထမတွက်ချက်ခံ
기존 AOT·어셈블리·SDK에 공개한 စက် 심볼과 연결한다.
Python의 `__init__`, `setUp`, `handle`, 표준 မော်ဂျူးတန်ဖိုး ဂုဏ်သတ္တိတန်ဖိုး, 명령행 옵션과 JSON 키도
ပြင်ပတန်ဖိုး 계약이다. `build/`, ဖြန့်ချိမှုတန်ဖိုး 바이너리 이름과 `/sdk`는 기존 စက်မောင်း 경로를 유지한다.
ပြင်ပတန်ဖိုး 원본은 `vendor/`에서 이용허락·해시와 함께 관리한다.

## 검사와 재실행

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 ကိရိယာစု/명명검사.py
make တည်ဆောက်
make စမ်းသပ်မှု
make test-examples test-ftp test-elf
python3 ကိရိယာစု/စက်မောင်း.py --desktop --network
```

`ကိရိယာစု/Cအမည်များခွဲခြမ်းစိတ်ဖြာ.py`는 libclang 6으로 C 선언과 참조를 검사한다.
`ကိရိယာစု/*이름반영.py`는 တန်ဖိုးပြောင်း 전 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ·분석표를 필요로 하는 일회성 이행 도구다.
이미 변경된 소스에 ပြန်ကြိုးစား 적용하여 대응표를 덮어쓰지 않는다.

## C ဆက်သွယ်မှု 구조체와 Python အမှား

C 통신에서 `갈래`는 လိပ်စာ 체계를 구분하고 `ဆက်သွယ်ပေါက်ကိန်း`는 port, `လိပ်စာတန်ဖိုး`은
IPv4 주소의 32비트 값을 나타낸다. `ဒေတာစာဆက်သွယ်စည်းမျဉ်း`은 앞서 설명한 ဒေတာစာ(電文)과
သဘောတူစည်းမျဉ်းတန်ဖိုး(規約)을 결합해 UDP의 기능을 드러낸 프로젝트 이름이다.

| 표준 표현 | မြန်မာ 직접 အကောင်အထည်ဖော်မှု |
|---|---|
| AF_INET / SOCK_DGRAM / IPPROTO_UDP | enum의 အင်တာနက်မျိုးစု / ဒေတာစာကွန်ရက်ပေါက် / ဒေတာစာဆက်သွယ်စည်းမျဉ်း |
| struct pk_sockaddr_in | struct အင်တာနက်ကွန်ရက်ပေါက်လိပ်စာ |
| sin_family / sin_port | လိပ်စာမျိုးစု / ဆက်သွယ်ပေါက်ကိန်း |
| sin_addr.s_addr | အင်တာနက်လိပ်စာ.လိပ်စာတန်ဖိုး |
| OSError / အမှား.args[0] | စနစ်အမှား / အမှား.နံပါတ် |

မြန်မာ 구조체는 `#define` 치환이나 အကွက်တန်ဖိုး 별칭이 아닌 별개 자료형이다.
표준 구조체와 같은 16바이트 배치를 선언하며 အူတိုင်တန်ဖိုး SVC에서 ဘိုက်တန်ဖိုး 복사로
검사한다. `အဆုံးမှတ်ဖန်တီး`·`ဒေတာစာဒေတာပို့`와 ဖိုင် 함수는 တည်ငြိမ်တန်ဖိုး 라이브러리에
တကယ့်ဒေတာ မြန်မာ 이름의 လုပ်ဆောင်ချက် 심볼을 갖는다. 기존 pk_* 심볼도 유지한다.
ယခင်အချက်အလက်တစ်ခု 코드에서 မြန်မာ ဆက်သွယ်မှု 함수에 pk_sockaddr*를 전달했다면 မြန်မာ 구조체로
옮기거나, 표준 구조체와 pk_* 함수의 짝을 유지한다.

Python의 `စနစ်အမှား`는 OSError의 မြန်မာ 하위 클래스이며 연결부에서
အမှား 번호를 보존하여 변환한다. 일반 Python 문법과 ပြင်ပတန်ဖိုး 패키지의 API는 유지한다.

## 직접 GUI 이름의 뜻과 검토 ဖြတ်နယ်ပယ်

`လုပ်ဆောင်ရန်အလုပ်`은 수행할 내용을, `အလုပ်လုပ်ဆောင်`는 그 수행을 나타낸다.
`လှုပ်ရှားမှုလက်ခံသူ`는 동작이 발생했다는 알림을 받는 역할, `လှုပ်ရှားမှုအသိပေးချက်`은 전달되는 사건이다.
`ခလုတ်`는 눌러 동작시키는 조작부, `အညွှန်းစာ`는 လမ်းညွှန် 글의 နေရာအညွှန်းကိန်း,
`စာသားအကွက်`은 글을 적는 နေရာအညွှန်းကိန်း, `အလုပ်သမား`은 이어지는 စက်မောင်း 흐름을 뜻한다.
`စက်မောင်း(實行)`·`လှုပ်ရှားမှု(動作)`의 기존 뜻과 `받다`·`알리다`·`အလုပ်ကြိုးတန်ဖိုး`의 기능을
결합한 프로젝트 이름이다. 새 복합어가 역사 문헌에 그대로 있었다거나
특정 시대에 အစဦးအချက်အလက်တစ်ခု 쓰였다고 주장하지 않는다.

전체 저장소는 `python3 ကိရိယာစု/မူရင်းကုဒ်သုံးသပ်.py`로 검토한다.
결과는 `build/verification/naming/source-review.json`이며 파일별 ဖိုင်ဟက်ရှ်တွက်,
ASCII 파일명과 Python의 영어 ကြေညာချက် 위치를 기록한다.
공용 ARM64·x86 번역기의 구현은 `compiler/Javaကိရိယာ/ကြိုတင်ဘာသာပြန်.java`로 전환했다. `compiler/ကြိုတင်ဘာသာပြန်.py`는 호환 진입점이다.
`compiler/arm64.py`는 ယခင်အချက်အလက်တစ်ခု 경로와 `ARM64(...).generate(...)` 호출을 ဆက်လက်တန်ဖိုး 주는
호환 진입점이다. `compiler/classfile.py`, OpenJDK 보조 ကိရိယာစု, Linux ထုတ်ဝေမှုတန်ဖိုး 도구와
기존 호환 진입점에는 영어 이름이 남아 있다. 따라서 전체 저장소가
သီးသန့်စကားလုံးများ 외 100% 한국어라고 판정하지 않는다.
`ကိရိယာစု/명명검사.py --Cဘာသာစကား`는 အလုပ်လုပ်နေ ARM64 소스의 ကြေညာချက်, C 의미 တန်ဖိုးခွဲခြမ်းစိတ်ဖြာ,
x86 Java 커널과 공용 번역기의 ကိုယ်ပိုင် ကြေညာချက်, Java ဥပမာ 전체 သတ်မှတ်နံပါတ်တန်ဖိုး,
ARM64 Python 예제와 직접 GUI/가닥에 표준 래퍼가 없는지를 별도로 검사한다.

## လက်ရှိအချက်အလက်တစ်ခု 기능을 기준으로 보완한 အမည်

번역은 글자를 음역하는 대신 자료의 역할과 함수의 행동을 구분한다.
동일한 영어 이름도 문맥이 다르면 မြန်မာ 이름을 달리 정한다.
ဖိုင် 이름은 주된 기능을 나타내고, လုပ်ဆောင်ချက် 이름은 행동을, ကိန်းရှင်တန်ဖိုး 이름은 담는 자료를 나타낸다.
သီးသန့်စကားလုံးများ, 표준 API 및 ပြင်ပတန်ဖိုး ချိတ်ဆက် 규약은 따로 기록한다.

| ယခင်အချက်အလက်တစ်ခု အမည် | 적용한 အမည် | လက်ရှိအချက်အလက်တစ်ခု 기능 |
|---|---|---|
| `arm64.py`의 အကောင်အထည်ဖော်မှု | `compiler/Javaကိရိယာ/ကြိုတင်ဘာသာပြန်.java` | Java 바이트코드를 독립 실행용 C 원문으로 미리 မူရင်းကုဒ်ဘာသာပြန်ဆို |
| `ARM64`, `generate` | `စက်ကုဒ်ဘာသာပြန်စက်`, `ထုတ်လုပ်` | မူရင်းကုဒ်ဘာသာပြန်ဆို 상태를 담는 객체와 C မူရင်းကုဒ် ထုတ်လုပ် အပြုအမူ |
| `prototype`, `method` | `လုပ်ဆောင်နည်းပုံစံ`, `နည်းလမ်းကိုယ်ထည်` | 함수의 ပုံစံတန်ဖိုး 선언과 တကယ့်ဒေတာ အမိန့် မူရင်းကုဒ် |
| `profile`, `heap_words` | `လုပ်ဆောင်မှုဦးတည်ချက်`, `ပုံတင်မှတ်ဉာဏ်စကားလုံးအရေအတွက်` | အူတိုင်တန်ဖိုး·သုံးစွဲသူ 구분과 သိုလှောင်ရာခွဲဝေ မှတ်ဉာဏ် 공간의 စက် ဝေါဟာရ ကိန်းတန်ဖိုး |
| `pc`, `op` | `အမိန့်နေရာ`, `명령번호` | 바이트코드에서의 위치와 수행할 명령의 နံပါတ် |
| `x`, `y`, `w`, `h` | `xတည်နေရာအမှတ်`, `yတည်နေရာအမှတ်`, `နယ်ပယ်အနံ`, `နယ်ပယ်အမြင့်` | အဝေးတန်ဖိုး 화면의 위치와 직사각형 အရွယ် |
| `p`, `n`, `i`, `j` | `ဒေတာနေရာ`, `တန်ဖိုး`, `အစဉ်အမှတ်`, `안쪽순번` | အဝေးတန်ဖိုး မျက်နှာပြင် ဒေတာ·ဂဏန်းတန်ဖိုး·반복 နေရာအညွှန်းကိန်း; 파일별 기능을 확인해 적용 |
| `aot_heap_info`, `__stack_top` | `ကြိုတင်ဘာသာပြန်မှတ်ဉာဏ်ရှာကြည့်`, `ထပ်ဆင့်အစုထိပ်` | စက် ချိတ်ဆက် 규약을 유지하면서 ကိုယ်ပိုင် 소스에서 사용하는 အမည် |
| `앞캐리지` | `ရှေ့စာကြောင်းပြန်` | 앞서 받은 문자가 줄복귀였는지 기억하여 중복 줄바꿈을 막음 |

[မျှဝေသုံးဘာသာပြန်စက်အမည်များ.tsv](မျှဝေသုံးဘာသာပြန်စက်အမည်များ.tsv)에 ဘာသာပြန်စက်ကိရိယာတစ်ခု 참조의 တကယ့်ဒေတာ တန်ဖိုးပြောင်း 기록을 남겼다.
추가로 보존한 C·POSIX/lwIP/libassh 이름의 이유는
[규격이름근거.json](규격이름근거.json)에 기록한다.
`Cဘာသာပြန်စက်/ဘာသာပြန်စက်ကိရိယာတစ်ခု.c`는 TinyCC ပြင်ပတန်ဖိုး 원문을 포함하는 ချိတ်ဆက် 파일로 ကိုယ်ပိုင် 선언이 없어서
C ကိုယ်ပိုင် ကြေညာချက် 분석에서는 제외한다. တကယ့်ဒေတာ အူတိုင်တန်ဖိုး 빌드에서는 ဆက်လုပ်လုပ်ငန်းစဉ်ဆောင်ရွက်မှု 컴파일한다.

### 말의 뿌리와 새로운 복합 အမည်

`မှတ်ဉာဏ်(記憶)`과 `ရှာကြည့်အညွှန်းကိန်း(索引)`은 기존 한자어를 쓴다.
기억은 자료를 간직하는 기능에, 색인은 အစဉ်တန်ဖိုး 있는 항목을 찾아 지정하는 기능에 적용한다.
အဘိဓာန် 근거는 국립국어원 한국어기초사전의
[မှတ်ဉာဏ်](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=38812&nation=eng),
[ရှာကြည့်အညွှန်းကိန်း](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=63787)이다.

`ထပ်ဆင့်သိုလှောင်ရာ`, `တန်ဖိုးထိပ်ထည့်`, `တန်ဖိုးထိပ်ထုတ်`는 자료를 포개고 နောက်ဆုံးအချက်အလက်တစ်ခု 자료부터 꺼내는 စက်မောင်း 구조를 드러낸다.
`쌓다`의 기존 뜻에 근거한 기능별 조어이며, 사전의
[쌓다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62095)를 참고한다.
`미리번역`은 စက်မောင်း 전에 번역한다는 기능을 직접 나타낸다.
`စက်စကားလုံး`은 처리기의 ဒေတာ 단위를 가리키며, 언어의 일반 낱말과 구별하도록 `စက်`를 붙였다.
`ကြိုတင်ဘာသာပြန်`, `ပုံတင်မှတ်ဉာဏ်စကားလုံးအရေအတွက်` 같은 복합 이름은 လက်ရှိအချက်အလက်တစ်ခု 기능에 맞게 만든 프로젝트 용어다.
이 복합어가 옛 문헌에 그대로 있었다거나 특정 시대에 အစဦးအချက်အလက်တစ်ခု 나타났다는 뜻은 아니다.
확인되지 않은 중세 형태나 최초 သုံးစွဲမှု 연대는 어원 근거로 적지 않는다.

생성되는 C의 내부 ဒေတာအမျိုးပုံစံ·အခင်းအကျင်းတန်ဖိုး·လုပ်ဆောင်ချက်·ဒေသတွင်းနယ်ပယ်ကန့်သတ် ကိန်းရှင်တန်ဖိုး·အခွဲ 이름도 한국어로 바꾼다.
직접 ဟန်ဂုစာသား 식별자를 읽지 못하는 예전 GCC를 위해 호환 API는 같은 မြန်မာ 이름을
표준 C 범용 အက္ခရာ 표기로 출력한다. တကယ့်ဒေတာ ARM64 빌드는 Clang으로 읽을 ကိန်းတန်ဖိုး 있는 ဟန်ဂုစာသား 원문을 사용한다.
အက္ခရာစဉ်, C 표준 လုပ်ဆောင်ချက်, `java_entry` 같은 공개 ချိတ်ဆက် 이름은 바꾸지 않는다.

셸의 사용법·문법 အမှား·ဖိုင် 및 မှတ်ဉာဏ် သတ်မှတ်လိပ်စာနယ် 안내도 한국어로 보완했다.
`READY`, `PASS`, `HEX BEGIN`처럼 စမ်းသပ်မှု·ဖိုင် လွှဲပြောင်းတန်ဖိုး 도구가 읽는 အမှတ်အသား,
명령행 옵션과 기존 စက်ညွှန်ကြားချက်တန်ဖိုး, JVM အတန်းတန်ဖိုး အမည်·ဖိုင် ပုံစံတန်ဖိုး·ကိရိယာ 이름은 호환 표기로 남는다.
x86 VGA အက္ခရာ 화면은 한글을 표시하지 못하므로 မြန်မာ 문구는 UTF-8 အစဉ်ဆက်တန်ဖိုး 단말에서 확인한다.
