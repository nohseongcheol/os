# ဖြန့်ချိမှုတန်ဖိုး စက်ပုံရိပ်တည်ဆောက် မှန်ကန်ကြောင်းစစ် မှတ်တမ်းမှတ်တမ်းတစ်ခု

검증일: 2026-09-27 (Asia/Seoul)

ဦးတည်ချက်တန်ဖိုး: `jkoros-rpi4-aarch64-349b52891a471c8e782da597`

이번 배포는 Raspberry Pi 4용 **ARM64 Linux 실행판**이다. 기존 ကိုယ်ပိုင် x86 커널을 ARM으로 이식한 결과가 아니다. တကယ့်ဒေတာ Pi 보드는 연결되어 있지 않아 စက်ပစ္စည်း စက်တင် 성공을 확인하지 못했다.

## အကောင်အထည်ဖော်မှု 범위와 남은 မှန်ကန်ကြောင်းစစ်

### QEMU 그래픽 စက်မောင်း 보완

အဆုံးသုံးမျက်နှာပြင် 전용 실행에서 `နှုတ်ဆက်.java`ပထမတွက်ချက်ခံ Swing 창을 만들 때 발생한 `HeadlessException`을 해결하기 위해 `make run`과 `make run-console`을 추가했다. 그래픽 실행은 bochs 가상 GPU, USB 키보드·태블릿, Xorg, 로컬 VNC를 사용한다. QEMU 전용 initramfs가 필요한 드라이버를 기존 루트 파일시스템에서 로딩한다. ဖြန့်ချိမှုတန်ဖိုး 시스템 이미지와 base-id는 변경하지 않아 기존 သုံးစွဲသူ ဒေတာ 이미지를 ဆက်လုပ်လုပ်ငန်းစဉ်ဆောင်ရွက်မှု 사용할 ကိန်းတန်ဖိုး 있다.

တကယ့်ဒေတာ Xorg/VNC 화면에서 မြန်မာ Java အလုပ်နယ်ပယ်, Swing စမ်းသပ်မှု ဝင်း, 기존 이미지의 `နှုတ်ဆက်.java` 창을 표시했다. VNC를 통한 USB 마우스 클릭과 키보드 입력이 Swing 이벤트로 전달되는 것도 확인했다. ထွက်ပရိုဂရမ် 시 시스템 OverlayFS와 ဒေတာ 파일시스템의 ဖတ် 전용 전환을 확인했다. 이번 시험은 Xvfb를 사용하지 않는다.

မူရင်းကုဒ် 예제에는 `GraphicsEnvironment.isHeadless()` 분기를 추가했다. 화면이 없는 환경에서는 ဖိုင်·အက္ခရာ·스레드 기능을 실행하고 안내를 출력한다. သုံးစွဲသူ 홈의 기존 원문을 자동 교체하지는 않는다. 향후 စက်ပုံရိပ်တည်ဆောက် 빌드에는 udev의 `add` 이벤트를 명시적으로 발생시키는 수정도 반영된다.

### ဟန်ဂုစာသား ဝင်ဒေတာ·စာလုံးပုံစံတန်ဖိုး 보완

`make test-korean`으로 တကယ့်ဒေတာ Xorg/VNC 화면의 Swing 입력창과 xterm에서 Ctrl+Space အလှည့်ပြောင်းနည်းစနစ် 및 두벌식 သော့တန်ဖိုး 입력을 시험했다. 양쪽에서 `ဟန်ဂုစာသား ဝင်ဒေတာ`을 조합했고 UTF-8 파일의 내용과 일치했다. 시험은 별도 သုံးစွဲသူ ဒေတာ 이미지에서 실행했으며 ဖြစ်သောပုံမှန် ထွက်ပရိုဂရမ် 시 두 파일시스템의 ဖတ် 전용 전환을 확인했다.

အဆုံးသုံးမျက်နှာပြင် စာလုံးပုံစံတန်ဖိုး 진단에서 영문 DejaVu Sans Mono와 ဟန်ဂုစာသား Noto Sans Mono CJK KR의 တကယ့်ဒေတာ ဖိုင် 로딩을 확인했다. 한글용으로 요청한 글꼴이 영문 전용 글꼴로 대체되던 Fontconfig 규칙의 우선순위도 수정했다. မျက်နှာပြင် 캡처에서 ဟန်ဂုစာသား·영문 တန်ဖိုးပြသ, Java 작업마당의 확대된 글꼴과 안티앨리어싱을 확인했다.

수정은 QEMU 전용 initramfs를 통해 သုံးစွဲသူ 시스템 변경분에 적용하며 ဖြန့်ချိမှုတန်ဖိုး မူလသတ်မှတ်တန်ဖိုး 이미지와 base-id는 유지한다. 기존 ဖိုင် 백업, 동일 수정의 반복 적용 방지, 손상된 수정 ဖိုင် 및 다른 base-id တန်ဖိုးငြင်းပယ်, သုံးစွဲသူ 입력기 သတ်မှတ်ချက် 병합에 대한 အိမ်ရှင် စမ်းသပ်မှု 4개도 통과했다. 원래 သုံးစွဲသူ ဒေတာ စက်ပုံရိပ်တည်ဆောက် `build/manual-user.img`는 시험에 사용하지 않았다.

### 남은 ဖြတ်နယ်ပယ်

- 새 မူရင်းကုဒ်ဘာသာပြန် ဦးတည်ချက်တန်ဖိုး `openjdk`는 **네이티브 ပရိုဂရမ်စက်နှိုးကိရိယာ + JVM/JRE** 방식이다. 모든 Java 바이트코드를 JVM 없이 기계어로 변환하는 범용 AOT 컴파일러는 구현하지 않았다. 기존 x86 AOT의 ထောက်ပံ့မှုတန်ဖိုး 범위는 여전히 제한적이다.
- စက်မောင်း 프로그램에는 main အချက်အမှတ်တစ်ခု, 호환 အတန်းတန်ဖိုး 버전과 의존 JAR/JNI가 필요하다. 개별 상용 ပရိုဂရမ်, 모든 Java မော်ဂျူးတန်ဖိုး, 모든 문자권을 시험한 것은 아니다.
- မြန်မာ Java 라이브러리는 ဖိုင်·အက္ခရာ·ဆက်သွယ်မှု·스레드·Swing을 위한 보조 API이며 JDK 전체 API의 မြန်မာ 번역판은 아니다.
- Pi 4 전용 펌웨어·အူတိုင်တန်ဖိုး·ကိရိယာ 트리는 이미지에 들어 있지만 တကယ့်ဒေတာ SD စက်တင်, HDMI/KMS, USB, Wi-Fi, 물리 키보드의 ဟန်ဂုစာသား 입력은 실기 확인이 남아 있다. QEMU는 Pi 장치를 에뮬레이션하는 시험이 아니다.
- သုံးစွဲသူ ဖိုင်တွဲတန်ဖိုး 이동은 동일 시스템 စက်ပုံရိပ်တည်ဆောက် သတ်မှတ်နံပါတ်တန်ဖိုး, ARM64, `/home/user`, UID 1000을 전제로 한다. ထွက်ပရိုဂရမ် 후 소유권·ခွင့်ပြုချက်တန်ဖိုး·링크·တိုးချဲ့မှု ဂုဏ်သတ္တိတန်ဖိုး·삭제 정보를 보존하여 복사해야 한다. 다른 OS 버전으로의 자동 이관은 제공하지 않는다.

တန်ဖိုးတပ်ဆင်·တန်ဖိုးမိတ္တူကူး 절차는 [README.md](README.md), မူရင်းကုဒ်ဘာသာပြန် 방식은 [OpenJDK စက်မောင်း ဖိုင် လမ်းညွှန်](../../compiler/OpenJDK-စက်ဖိုင်ဖိုင်.md)를 따른다. စက်ပုံရိပ်တည်ဆောက် 파일만 생성했으며 တကယ့်ဒေတာ SD 카드나 USB 디스크에 기록하지 않았다.
