# jkoros 안에서 Java မူရင်းကုဒ်ဘာသာပြန်·စက်မောင်း

이 문서의 စက်တင်·အမိန့်ဝင်း·သိုလှောင်တန်ဖိုး 명령은 **x86 ထုတ်ဝေမှုတန်ဖိုး** 기준이다. 공유 Java ဘာသာပြန်စက်/JVM은 [ကိုယ်ပိုင် ARM64 Pi4 ထုတ်ဝေမှုတန်ဖိုး](../platforms/rpi4-native/README.md)에도 연결되어 있다. ARM64에서는 UTF-8 UART ဝင်ဒေတာ·ဟန်ဂုစာသား ဖိုင်အမည်စာသား, `edit`의 단독 `.` သိုလှောင်တန်ဖိုး, 16개 RAM ဖိုင်, 약 2초 စက်မောင်း 제한을 사용한다.

`javac FILE.java`와 `java CLASS [ARGS]`를 네이티브 jkoros 셸에서 실행한다. 컴파일러와 JVM은 각각 독립 ELF로 적재되어 ring 3에서 동작한다. 소스를 게스트에서 읽어 တကယ့်ဒေတာ JVM `.class` 파일을 만들고, 그 파일의 바이트코드를 게스트 JVM이 해석한다. အိမ်ရှင် မူရင်းကုဒ်ဘာသာပြန် 서버나 Linux 게스트는 사용하지 않는다.

**လက်ရှိအချက်အလက်တစ်ခု 구현은 ကိုယ်ပိုင် 제한형 ဘာသာပြန်စက်·JVM이다. OpenJDK/JDK 전체를 이식하거나 설치한 것이 아니며 Java SE 호환 환경도 아니다.** 표준 라이브러리는 아래의 일부 호출을 구현한 것이다. `java -version`과 `javac -version`에도 이 범위를 표시한다. 일반 JAR, Maven/Gradle, 임의의 Java ပရိုဂရမ် 실행은 아직 지원하지 않는다.

## 바로 စက်မောင်း

호스트에서:

```sh
cd /home/user/jkoros
make iso
make run
```

게스트에서:

```text
jkoros> javac -version
jkoros> java -version
jkoros> ls
jkoros> cat Hello.java
jkoros> javac Hello.java
Compiled: Hello.class (JVM class version 49)
Exit: 0
jkoros> java Hello
Hello from jkoros JVM!
55
Exit: 0
```

ISO는 `os/build/kernel.iso`တတိယအော်ပရန်း. 기존 VirtualBox 실행기도 같은 ISO를 사용한다. စက်မောင်း 중이거나 저장된 VM에는 새 ISO가 자동 반영되지 않는다. 새 စက်တင် 절차는 [VirtualBox စက်မောင်း လမ်းညွှန်](VirtualBoxလုပ်ဆောင်.md)를 따른다. 이 변경의 Java 자동 시험은 QEMU에서 수행했다.

## 직접 작성

`edit`는 ဖိုင် 전체를 새 내용으로 작성한다. 기존 내용의 စာကြောင်း တည်းဖြတ်တန်ဖိုး 기능은 아니다. `.save`로 저장하고 `.cancel`로 취소한다.

```text
jkoros> edit Demo.java
...> public class Demo {
...>  public static int square(int n) { return n * n; }
...>  public static void main(String[] args) {
...>   int n = Integer.parseInt(args[0]);
...>   System.out.println("square=" + square(n));
...>  }
...> }
...> .save
jkoros> javac Demo.java
jkoros> java Demo 12
square=144
Exit: 0
```

- `ls`: 파일과 ဘိုက်တန်ဖိုး ကိန်းတန်ဖိုး တန်ဖိုးပြသ.
- `cat FILE`: ဖိုင် အကြောင်းအရာတန်ဖိုး တန်ဖိုးပြသ. 텍스트 소스에 사용한다.
- `rm FILE`: မှတ်ဉာဏ်ဒေတာ ဖိုင် 삭제.
- `edit FILE`: 전체 내용을 새로 ဝင်ဒေတာ. 빈 파일도 저장할 ကိန်းတန်ဖိုး 있다.
- 구문·အမျိုးပုံစံတန်ဖိုး စစ်ဆေးချက် မအောင်မြင်မှု 시 기존 `.class`는 유지된다. 소스를 고친 နောက်တန်ဖိုး 컴파일이 실패했다면 ယခင်အချက်အလက်တစ်ခု စက်မောင်း 파일이 남아 있으므로 မူရင်းကုဒ်ဘာသာပြန် အောင်မြင်မှုတန်ဖိုး 여부를 확인한다.

파일은 RAM에서 동작한다. 전용 သိုလှောင်တန်ဖိုး 매체가 없거나 `sync`하지 않은 내용은 재부팅하면 사라진다. `make -C os run-store`로 연결한 매체에는 `sync`로 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ·အတန်းတန်ဖိုး·ဒေတာ 파일을 보존할 ကိန်းတန်ဖိုး 있다. အများဆုံးတန်ဖိုး 8개, 파일마다 16KiB, ဖိုင် 이름은 ASCII 1~63자다. မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 이름은 `.class` 확장자 သတ်မှတ်လိပ်စာနယ် 때문에 အများဆုံးတန်ဖိုး 62자다. တည်းဖြတ်တန်ဖိုး 입력은 ASCII이고 한 စာကြောင်း အများဆုံးတန်ဖိုး 128자다. စာကြောင်း 또는 ဖိုင် 한도를 넘긴 편집은 `.save`에서 거부하여 기존 파일을 보존한다. အူတိုင်တန်ဖိုး/ဘာသာပြန်စက်/JVM 구현의 Java 식별자는 한국어이며, လက်ရှိအချက်အလက်တစ်ခု 게스트 ဝင်ဒေတာ ကန့်သတ်ချက်တန်ဖိုး 때문에 သုံးစွဲသူ ဥပမာ 이름은 ASCII로 작성한다.

## ပြင်ပတန်ဖိုး ဖိုင် 적재

호스트에서 만든 소스나 ထောက်ပံ့မှုတန်ဖိုး ဖြတ်နယ်ပယ် 안의 `.class`를 စက်တင် 이미지에 포함할 ကိန်းတန်ဖိုး 있다. `JAVA_FILES`는 `게스트이름=호스트경로` 목록이다. 아래의 경로는 예시이며 တကယ့်ဒေတာ 파일의 절대 경로로 바꾼다. 공백 없는 경로를 사용한다.

```sh
# အိမ်ရှင် JDK로 컴파일한 클래스도 사용할 ကိန်းတန်ဖိုး 있다.
javac --release 8 /tmp/Demo.java
make -C /home/user/jkoros iso \
  JAVA_FILES='Demo.java=/tmp/Demo.java Demo.class=/tmp/Demo.class'
make -C /home/user/jkoros run \
  JAVA_FILES='Demo.java=/tmp/Demo.java Demo.class=/tmp/Demo.class'
```

새 စက်တင် 후 `java Demo 12`를 실행한다. 소스만 넣었으면 게스트에서 `javac Demo.java`부터 실행한다. `JAVA_FILES`를 생략한 နောက်တစ်ခုအချက်အလက်တစ်ခု 빌드에서는 အချက်နောက်တွဲ 파일을 포함하지 않는다. ဖိုင် အကြောင်းအရာတန်ဖိုး 변경과 အချက်စာရင်း 제거도 နောက်တစ်ခုအချက်အလက်တစ်ခု 빌드에 반영된다. မူရင်း အိမ်ရှင် 파일에는 쓰지 않는다. မူလသတ်မှတ်တန်ဖိုး `Hello.java`까지 합해 8개이며, 같은 이름을 명시하면 မူလသတ်မှတ်တန်ဖိုး 예제를 대체한다. 새 `.class`를 저장할 빈 슬롯도 남겨 둔다.

`--release 8`은 အတန်းတန်ဖိုး ဖိုင် 버전을 맞추는 옵션이다. 사용하는 문법·ဘိုက်ကုဒ်·라이브러리도 အောက်ဆုံးတန်ဖိုး ထောက်ပံ့မှုတန်ဖိုး ဖြတ်နယ်ပယ် 안에 있어야 한다.

## ထောက်ပံ့မှုတန်ဖိုး ဖြတ်နယ်ပယ်

| 기능 | 게스트 javac | 게스트 JVM |
| --- | --- | --- |
| အတန်းတန်ဖိုး | 패키지 없는 단일 အတန်းတန်ဖိုး, တည်ငြိမ်တန်ဖိုး လုပ်ဆောင်ချက်, 재귀, အချက်များ/ပြန်ပေးရလဒ် | 실행마다 단일 အတန်းတန်ဖိုး 적재, public static main(String[]) |
| မူလသတ်မှတ်တန်ဖိုး တန်ဖိုး | int, boolean, char, String, main의 String[] အချက်များ | ကိန်းပြည့်·ကိုးကားချက် တွက်ချက်ခံထပ်ဆင့်အစု, String, int[], String[], 내부 StringBuilder |
| အမိန့်ကြောင်းတန်ဖိုး | အစဦးတန်ဖိုး 있는 ဒေသတွင်းနယ်ပယ်ကန့်သတ် ကြေညာချက်, တန်ဖိုးအပ်, `+=`, `-=`, `*=`, `/=`, `%=`, 후위 ++/--, 블록, if/else, while, for, return | 해당 ကိန်းပြည့်·ကိုးကားချက် 바이트코드와 အခြေအနေစည်းကမ်း အခွဲ |
| သင်္ချာစကားရပ်တန်ဖိုး | 십진 ကိန်းပြည့်, UTF-8 소스의 အက္ခရာစဉ်/အက္ခရာ, + - * / %, 비교, ==/!=, !/&&/\|\|, အက္ခရာစဉ် ပေါင်းစပ်တန်ဖိုးများ | ကိန်းပြည့် တွက်ချက်လုပ်ဆောင်မှု·ဘစ်တန်ဖိုး တွက်ချက်လုပ်ဆောင်မှု·အမျိုးပုံစံတန်ဖိုး တန်ဖိုးပြောင်းလဲ, 단락 평가, အခင်းအကျင်းတန်ဖိုး ဝင်သုံးအချက် |
| ဖိုင် | FileInputStream(String), FileOutputStream(String[, boolean]), read()/write(int)/close() | တကယ့်ဒေတာ အူတိုင်တန်ဖိုး 파일서술자와 ချိတ်ဆက်, ထုတ်လုပ်·အကြောင်းအရာရှင်း·ဆက်လက်ဖြည့်ရေး·EOF |
| အထွက် | System.out.print/println: int/boolean/char/String, println() | 동일 |
| အက္ခရာစဉ်/အချက်များ | String.length(), args.length, args[index], Integer.parseInt | 추가로 String.charAt(), အက္ခရာစဉ် 상수의 modified UTF-8 해독 |

선언은 지원하는 문법만 허용한다. 여러 변수를 한 선언에 나열하기, အစဦးတန်ဖိုး 없는 ဒေသတွင်းနယ်ပယ်ကန့်သတ် ကြေညာချက်, 오버로드, 임의 အမျိုးပုံစံတန်ဖိုး တန်ဖိုးပြောင်းလဲ, အခင်းအကျင်းတန်ဖိုး ထုတ်လုပ် မူရင်းကုဒ်, 8/16진 리터럴, Unicode မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 이스케이프 등은 미지원이다. `char`는 အက္ခရာ 리터럴로 초기화하며 일반 JDK의 모든 ကိန်းသေတန်ဖိုး 축소 변환을 구현하지 않는다. ပြင်ပတန်ဖိုး `.class`의 `int[]` ထုတ်လုပ်/ဖတ်/쓰기는 지원하므로 အိမ်ရှင် `javac --release 8`로 만든 အခင်းအကျင်းတန်ဖိုး 예제는 실행할 ကိန်းတန်ဖိုး 있다.

အရာဝတ္ထုတန်ဖိုး အကွက်တန်ဖိုး·일반 အရာဝတ္ထုတန်ဖိုး ထုတ်လုပ်·상속·인터페이스·여러 အတန်းတန်ဖိုး ချိတ်ဆက်, long/float/double, ခြွင်းချက် လုပ်ငန်းစဉ်တန်ဖိုးအချက်, 스레드·모니터, 리플렉션, JNI, JIT, GC, ထိပ်တန်ဖိုး 표에 없는 `java.io`와 `java.nio`/`java.net` 일반 API, 컬렉션, JAR와 클래스패스는 미지원이다. 런타임 오류는 Java ခြွင်းချက် 객체를 던지지 않고 진단 후 လက်ရှိအချက်အလက်တစ်ခု 프로그램을 종료한다. 객체와 အက္ခရာစဉ် သိုလှောင်တန်ဖိုး 공간은 စက်မောင်း ထွက်ပရိုဂရမ် 시 သုံးစွဲသူ နယ်ပယ်တန်ဖိုး 전체와 함께 회수한다. 지속 စက်မောင်း 중 GC는 없다.

## စက်မောင်း 한도와 အမှား

| အရင်းအမြစ်တန်ဖိုး | ဆံ့ပမာဏအကန့် |
| --- | --- |
| မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ/အတန်းတန်ဖိုး ဖိုင် | 각각 16KiB |
| ဘာသာပြန်စက် | သင်္ကေတစကားလုံးတန်ဖိုး 2,047개, ထုတ်လုပ် ကုဒ်တန်ဖိုး 4KiB, ကိန်းသေတန်ဖိုး 풀 4KiB |
| လုပ်ဆောင်ချက်/အချက်များ | 클래스당 32함수, 함수당 16인수 |
| JVM ကိန်းသေတန်ဖိုး | 511개 |
| JVM လုပ်ဆောင်ချက် ကုဒ်တန်ဖိုး | 함수당 8KiB |
| JVM ခေါ်လုပ်/တွက်ချက်ခံထပ်ဆင့်အစု/ဒေသတွင်းနယ်ပယ်ကန့်သတ် ကိန်းရှင်တန်ဖိုး | 32프레임, 프레임당 တွက်ချက်ခံထပ်ဆင့်အစု 128칸·ဒေသတွင်းနယ်ပယ်ကန့်သတ် 128칸 |
| JVM အရာဝတ္ထုတန်ဖိုး သိုလှောင်တန်ဖိုး သတ်မှတ်လိပ်စာနယ် | 8,192개 32비트 နေရာကွက်အချက်, 헤더 ခေါင်းစီးဖိုင် 약 32KiB |
| စက်မောင်း | အများဆုံးတန်ဖိုး 500,000 အမိန့်, 기존 커널의 약 3초 CPU စက်မောင်း 상한도 적용 |

게스트 컴파일러는 버전 49.0 `.class`를 생성하며 JVM은 45.0~52.0 중 ထောက်ပံ့မှုတန်ဖိုး 명령으로 구성된 파일을 읽는다. 스택맵을 이용한 완전한 JVM အဘိဓာန် 검증기를 구현한 것은 아니다. ဖိုင်/ဂုဏ်သတ္တိတန်ဖိုး အလျား, ကိန်းသေတန်ဖိုး ကိုးကားချက်, အမိန့်·အခွဲ 경계를 검사하고, စက်မောင်း 중 တွက်ချက်ခံထပ်ဆင့်အစု ပုံစံတန်ဖိုး·ဒေသတွင်းနယ်ပယ်ကန့်သတ် အစပြင်ဆင်·အခင်းအကျင်းတန်ဖိုး အောက်ညွှန်း·အရာဝတ္ထုတန်ဖိုး 참조를 검사한다. သုံးစွဲသူ 코드의 페이지·စက်ပစ္စည်းဆက်သွယ်ပေါက် 접근은 기존 ring 3 경계로 보호한다.

일반 성공은 `Exit: 0`, မူရင်းကုဒ်ဘာသာပြန်·JVM 오류는 `Exit: 1`, အမိန့် အချက်များ 오류는 `Exit: 2`တတိယအော်ပရန်း. CPU အချိန်တန်ဖိုး 상한은 기존 `Exit: 124`이며, သုံးစွဲသူ ELF 자체의 CPU/런타임 오류는 기존 ထွက်ပရိုဂရမ် 코드를 따른다. မအောင်မြင်မှု 후 셸에서 다른 프로그램을 ဆက်လုပ်လုပ်ငန်းစဉ်ဆောင်ရွက်မှု 실행할 ကိန်းတန်ဖိုး 있다.

## အကောင်အထည်ဖော်မှု 위치와 စမ်းသပ်မှု

- `os/သုံးစွဲသူ/Java/Javaဘာသာပြန်စက်.java`: 게스트 어휘·구문·အမျိုးပုံစံတန်ဖိုး စစ်ဆေးချက်, ကိန်းသေတန်ဖိုး 풀 및 ဘိုက်ကုဒ် ထုတ်လုပ်.
- `os/သုံးစွဲသူ/Java/Javaစက်တု.java`: အတန်းတန်ဖိုး 적재, တွက်ချက်ခံထပ်ဆင့်အစု·프레임·အရာဝတ္ထုတန်ဖိုး သိုလှောင်တန်ဖိုး, အမိန့် 해석과 제한된 표준 ခေါ်လုပ်.
- `os/မူရင်းကုဒ်/မှတ်ဉာဏ်ဖိုင်စနစ်.java`: မှတ်ဉာဏ်ဒေတာ ဖိုင်စနစ်, တည်းဖြတ်တန်ဖိုး, စက်တင် ဖိုင် 적재.
- `os/မူရင်းကုဒ်/စနစ်ခေါ်ဆိုမှု.java`, `compiler/သုံးစွဲသူပရိုဂရမ်စတင်.s`: ဖိုင်/အက္ခရာ အထွက် API와 သုံးစွဲသူ ညွှန်တံ စစ်ဆေးချက်.
- `os/ကိရိယာစု/Javaဖိုင်ထုပ်ပိုး.py`: အိမ်ရှင် ဝင်ဒေတာ ဖိုင် မှန်ကန်ကြောင်းစစ်·စက်တင် အုပ်စုတန်ဖိုး ထုတ်လုပ်.

```sh
make test-java
make test
```

`os/စမ်းသပ်မှု/Javaစမ်းသပ်.py`는 ELF/ISO စက်တင်, 게스트 မူရင်းကုဒ်ဘာသာပြန်·စက်မောင်း, သုံးစွဲသူ ဝင်ဒေတာ, 재귀·반복문·ကိန်းပြည့် 극값·အက္ခရာစဉ် ပေါင်းစပ်တန်ဖိုးများ·단락 평가, 재실행, မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ အမှား 후 기존 အတန်းတန်ဖိုး 보존, အခင်းအကျင်းတန်ဖိုး/ကိန်းတန်ဖိုး 해독 အမှား, 무한 반복 ကန့်သတ်ချက်တန်ဖိုး, တည်းဖြတ်တန်ဖိုး 넘침과 ဖိုင် 부족을 검사한다. 게스트 ထုတ်လုပ် 클래스의 바이트를 QEMU 메모리에서 꺼내 OpenJDK `java -Xverify:all`로 실행하고 결과를 대조한다. 반대 방향으로 အိမ်ရှင် OpenJDK의 အတန်းတန်ဖိုး, ကိန်းပြည့် 배열과 ဟန်ဂုစာသား 상수를 게스트에 적재하며, 손상된 ဖိုင် အမှတ်အသား·버전·ကိန်းသေတန်ဖိုး ကိန်းတန်ဖိုး·အခွဲ·스택을 거부하는지도 검사한다. 기록은 `os/build/Javaစမ်းသပ်.json`에 남는다. 디스크 없는 별도 စမ်းသပ်မှု VM만 생성하고 종료한다.

အကောင်အထည်ဖော်မှု 형식의 참고 ဒေတာ: Oracle [JVM အတန်းတန်ဖိုး ဖိုင် သတ်မှတ်စံ](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-4.html), [JVM အမိန့် သတ်မှတ်စံ](https://docs.oracle.com/javase/specs/jvms/se8/html/jvms-6.html).

## Java ဖိုင် အဝင်အထွက်

[FileDemo.java](../posix-kor/Javaဥပမာ/FileDemo.java)는 일반 Java 표준 အတန်းတန်ဖိုး 이름을 사용한다. 소스를 `edit FileDemo.java`로 입력하거나 `JAVA_FILES`로 စက်တင် 이미지에 넣은 နောက်တန်ဖိုး `javac FileDemo.java`, `java FileDemo`를 실행한다. 결과는 `65`, `255`, `66`, `-1`, `JAVA FILE IO PASS`တတိယအော်ပရန်း. `write(int)`는 하위 8비트를 쓰고 `read()`는 0~255 또는 EOF -1을 반환한다. မူလသတ်မှတ်တန်ဖိုး အထွက် 생성자는 내용을 비우고, boolean 인수가 true이면 이어쓴다.

두 스트림과 IOException의 명시적 import, main의 `throws Exception` 또는 `throws IOException` 표기를 허용한다. ခြွင်းချက် အရာဝတ္ထုတန်ဖိုး·try/catch·try-with-resources는 지원하지 않으며 ဖိုင် 오류를 진단하고 프로그램을 종료한다. အခင်းအကျင်းတန်ဖိုး အဝင်အထွက်, InputStream/OutputStream으로의 다형성, Reader/Writer, getFD, 일반 ဖိုင် 메타데이터 API는 아직 없다. close는 열린 서술자를 닫고, 재부팅 보존에는 အမိန့်ဝင်း `sync`ပထမတွက်ချက်ခံ 필요하다. 예제의 ဖိုင် 이름은 လက်ရှိအချက်အလက်တစ်ခု 셸과 파일체계에 맞춰 ASCII로 쓴다.

`os/စမ်းသပ်မှု/Javaဖိုင်စမ်းသပ်.py`는 တကယ့်ဒေတာ 게스트 မူရင်းကုဒ်ဘာသာပြန် 결과를 OpenJDK `-Xverify:all`로 ပြန်ကြိုးစား 실행해 ဖိုင် 바이트와 출력을 대조한다. 범위와 သိုလှောင်တန်ဖိုး 매체 사용법은 [posix-kor လမ်းညွှန်](../posix-kor/လမ်းညွှန်.md)를 참고한다. 참고한 표준 API는 Oracle [FileOutputStream](https://docs.oracle.com/javase/8/docs/api/java/io/FileOutputStream.html)이다.
