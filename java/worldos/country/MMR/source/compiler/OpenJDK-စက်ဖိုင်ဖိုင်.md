# 일반 Java 클래스의 စက်မောင်း ဖိုင် အချက်ဖန်တီး

OpenJDK 자체를 소스에서 만드는 기능은 [OpenJDK မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 빌드와 ကိုယ်ပိုင် အူတိုင်တန်ဖိုး 이식](OpenJDK-မူရင်းကုဒ်တည်ဆောက်နှင့်-ကိုယ်ပိုင်အူတိုင်-이식.md)의 `openjdk-build` 대상이다. အောက်ဆုံးတန်ဖိုး `openjdk` 대상은 Java 응용프로그램 포장 기능이다.

`--target openjdk`는 OpenJDK로 실행하는 네이티브 ELF 실행기와 `.app` ဒေတာ 폴더를 만든다. Java 바이트코드를 အားလုံးတည်ဆောက် 기계어로 미리 변환하는 AOT는 아니다. အရာဝတ္ထုတန်ဖိုး·상속·인터페이스·ခြွင်းချက်·스레드·리플렉션·람다·표준 라이브러리는 설치된 OpenJDK가 실행하며, 필요한 코드는 JVM의 JIT가 기계어로 컴파일한다.

```sh
python3 compiler/ဘာသာပြန်စက်.py --target openjdk --entry ဥပမာ.Main \
  -o build/ပရိုဂရမ် build/classes
./build/ပရိုဂရမ် "ဆက်ပို့တန်ဖိုး အချက်များ"
```

Pi 실행판에서는 같은 도구가 `jclassc` 명령으로 설치된다.

```sh
jclassc --target openjdk --entry Main -o ပရိုဂရမ် Main.java
jclassc --target openjdk --entry Main -o ပရိုဂရမ် Main.class
jclassc --target openjdk --entry Main --classpath helper.jar -o ပရိုဂရမ် app.jar
jclassc --target openjdk --entry Main --bundle-runtime /usr/lib/jvm/java-25-jre \
  -o ပရိုဂရမ် classes
```

입력은 `.java`, `.class`, `.jar`/`.zip`, 또는 컴파일된 클래스와 리소스가 있는 디렉터리다. အချက်နောက်တွဲ 의존성은 `--classpath`를 반복해서 지정한다. 개별 `.class` 입력은 ဖိုင် 내부의 အတန်းတန်ဖိုး 이름을 읽어 올바른 패키지 경로에 배치한다. 내부 အတန်းတန်ဖိုး·다른 အတန်းတန်ဖိုး·리소스까지 포함하려면 အတန်းတန်ဖိုး 디렉터리를 전달한다. မူရင်းကုဒ် 입력은 `javac`로 컴파일한 후 포함한다.

စက်မောင်း ဖိုင် `ပရိုဂရမ်`과 `ပရိုဂရမ်.app`를 **함께** 이동한다. လက်ရှိအချက်အလက်တစ်ခု အလုပ် 폴더와 관계없이 자신의 경로를 기준으로 자료를 찾는다. စက်စနစ်·CPU는 빌드한 실행기와 일치해야 한다. `--cc`로 C 컴파일러를 지정할 ကိန်းတန်ဖိုး 있으며, Pi에서는 မူလသတ်မှတ်တန်ဖိုး GCC가 ARM64 실행기를 만든다. 번들 런타임을 지정하지 않으면 `JAVA_HOME/bin/java` 또는 PATH의 `java`를 사용한다.

စက်မောင်း 가능한 응용프로그램은 `public static void main(String[])` အချက်အမှတ်တစ်ခုတန်ဖိုး 클래스가 필요하다. စာကြည့်တိုက်·인터페이스·`module-info.class` 하나만으로 စက်မောင်း 프로그램이 되지는 않는다. အတန်းတန်ဖိုး 버전을 지원하는 JDK, ပြင်ပတန်ဖိုး JAR, JNI 네이티브 စာကြည့်တိုက်, သုံးစွဲမှု 장치와 권한은 해당 프로그램의 요구사항에 맞춰 제공해야 한다. မော်ဂျူးတန်ဖိုး လမ်း·အချက်နောက်တွဲ JVM 설정이 필요한 응용프로그램은 별도 စက်မောင်း 설정이 필요하다. `JDK_JAVA_OPTIONS`로 JVM 옵션을 전달할 ကိန်းတန်ဖိုး 있다. 모든 ပြင်ပတန်ဖိုး Java 응용프로그램을 개별 검증했다는 뜻은 아니다.

기존 `linux`, `kernel`, `user` 대상은 제한형 x86 ELF32 AOT로 유지된다. 이 경로에도 `.class` 직접 입력을 추가했지만 지원하지 않는 အရာဝတ္ထုတန်ဖိုး·표준 라이브러리를 자동으로 네이티브 변환하지는 않는다. ARM64 Linux에서 사용할 때는 `openjdk` 대상을 선택한다.
