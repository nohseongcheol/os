# ပြင်ပတန်ဖိုး 배포용 압축과 복원

Ubuntu x86_64에서 프로젝트 루트의 `./pack.sh`를 실행한다.
`dist/jkoros-source.tar.xz`, 체크섬 ဖိုင်, 독립 စက်မောင်း 가능한 `dist/unpack.sh`ပထမတွက်ချက်ခံ 생성된다.
မူရင်း 캐시, မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ, သုံးစွဲသူ 디스크는 삭제하거나 변경하지 않는다. 압축파일은 2 GB를
넘으면 생성에 실패한다. အထွက် 경로는 `./pack.sh /လမ်း/jkoros-source.tar.xz`로 지정한다.

다른 Ubuntu PC에 압축파일, `.sha256`, `unpack.sh`를 함께 전달한 နောက်တန်ဖိုး 실행한다.

```sh
./unpack.sh jkoros-source.tar.xz /원하는/새/လမ်း/jkoros
make -C /원하는/새/လမ်း/jkoros all korean-java iso
make -C /원하는/새/လမ်း/jkoros rpi-native-image
make -C /원하는/새/လမ်း/jkoros rpi-image
```

မူလသတ်မှတ်တန်ဖိုး 동작은 မော်ကွန်းတန်ဖိုး သိုလှောင်ရာလွှတ်ပေး 후 의존성 자동 다운로드와 준비까지다. Ubuntu တည်ဆောက် 도구가
없으면 `sudo apt-get`으로 설치하며 စီမံသူတန်ဖိုး 암호가 필요할 ကိန်းတန်ဖိုး 있다. ပြင်ပတန်ဖိုး 소스의
SHA-256을 확인하고 ARM64 SDK/Linux စက်မောင်း ဝန်းကျင်, အိမ်ရှင် 도구와 JRE를 준비한다.
새 폴더의 위치를 기준으로 실행하므로 `/home/user` 경로를 만들 필요가 없다.

ကိုယ်ပိုင် ARM64 커널만 개발한다면 `--profile native`로 GUI/Linux စက်မောင်း ဝန်းကျင် 준비를
생략할 ကိန်းတန်ဖိုး 있다. တည်ဆောက် 도구가 이미 설치되어 있으면 `--no-host-install`을 추가한다.
`--no-prepare`는 다운로드하지 않고 소스만 검사할 때 쓰는 명시적 선택이다.

ပြင်ဆင် 도중 ကွန်ရက်ဆက် 오류가 나면 풀린 폴더에서 `./unpack.sh --prepare`를 ပြန်ကြိုးစား 실행한다.
기존 အထွက် ဖိုင်တွဲတန်ဖိုး 위에는 압축을 풀지 않는다. 개인 수정 파일을 덮어쓰지 않으며,
복원 ဦးတည်ချက်တန်ဖိုး 파일의 내용이 မျှော်မှန်းတန်ဖိုးများ 해시와 다르면 중단한다.

압축에서 `build`, `dist`, `ရလဒ်`, `.vbox`, Python 캐시, မှတ်တမ်းတန်ဖိုး, သုံးစွဲသူ 디스크와
ချိတ်ဆက်မှု 키를 제외한다. Alpine 패키지 캐시는 외부에서 필요한 패키지만 ပြန်ကြိုးစား 받는다.
libassh, BearSSL, lwIP, uzlib, MicroPython 중 고정 URL/해시로 복구할 ကိန်းတန်ဖိုး 있는 원본은
제외하지만 로컬 수정 파일은 포함한다. 정확한 재다운로드 주소를 고정하지 못한
TinyCC 스냅샷, ကိုယ်ပိုင် စာလုံးပုံစံတန်ဖိုး, 프로젝트 소스와 라이선스 고지는 포함한다.

인터넷과 Ubuntu 패키지 저장소 및 Alpine 3.24 저장소 접근이 필요하다.
Alpine 저장소의 သုံးစွဲမှု 가능한 패키지 버전을 받아 တကယ့်ဒေတာ 버전을 သော့ခတ်တန်ဖိုး 파일에 기록한다.
패키지 다운로드 후의 အလုပ် 폴더와 တည်ဆောက် 산출물은 2 GB를 넘을 ကိန်းတန်ဖိုး 있다.
OpenJDK ကိုယ်ပိုင် 소스의 별도 실험 빌드는 기존 ဘာသာပြန်စက် 안내에 따라 소스를 준비한다.

`PORTABLE_DOWNLOAD_CACHE=/캐시/ဖိုင်တွဲတန်ဖိုး`를 지정하면 SHA-256을 파일명으로 하는
검증된 다운로드 파일을 먼저 사용한다. 캐시에 없는 항목은 자동 다운로드한다.
제외 목록과 မော်ကွန်းတန်ဖိုး 크기는 `dist/jkoros-source.tar.xz.report.json`에 기록된다.
