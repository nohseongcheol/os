# မြန်မာ Java ဆက်သွယ်မှု·အဝင်အထွက်·ခြွင်းချက် API

패키지는 `မြန်မာ.ကိုယ်ပိုင်`တတိယအော်ပရန်း. အိမ်ရှင် `javac --release 8`로 컴파일한 class를
ကိုယ်ပိုင် ARM64 커널의 JVM에서 실행한다. ဆက်သွယ်မှု·ဖိုင်·ခြွင်းချက် API는 OpenJDK와 대조한다. 아래의 직접 구현한 မျက်နှာပြင်·အလုပ် အလုပ်ကြိုးတန်ဖိုး API는 ကိုယ်ပိုင် JVM 전용이다.
기존 표준 Java စာကြည့်တိုက် 전체의 မြန်မာ 번역판은 아니다.

```java
import မြန်မာ.ကိုယ်ပိုင်.*;

public class ကွန်ရက်သုံးမှု {
    public static void main(String[] အချက်များ) throws အဝင်အထွက်ခြွင်းချက် {
        ဆက်သွယ်လမ်းကြောင်း ချိတ်ဆက် = ဆက်သွယ်လမ်းကြောင်း.ဖွင့်("10.0.2.2", 9000);
        try {
            ချိတ်ဆက်.စောင့်ချိန်(700);
            ချိတ်ဆက်.အထွက်().ရေး(အက္ခရာ.ကုဒ်သွင်း("안녕하세요\n"));
            ဝင်စီးကြောင်း ဝင်ဒေတာ = ချိတ်ဆက်.ဝင်ဒေတာ();
            အထွက်.ကိန်းထုတ်(ဝင်ဒေတာ.ဖတ်());
        } catch (စောင့်အချိန်လွန်ခြွင်းချက် အမှား) {
            အထွက်.စာကြောင်းထုတ်(အမှား.ရှင်းလင်းချက်());
        } finally {
            ချိတ်ဆက်.ပိတ်();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
သုံးစွဲသူ 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 အက္ခရာစဉ် 리터럴에 사용하는 표준 클래스다. ကိုယ်ပိုင် 실행기는 `public static void လုပ်ဆောင်()`도 진입점으로 받는다.

## 통신과 စီးကြောင်းတန်ဖိုး

| အတန်းတန်ဖိုး | မြန်မာ ခေါ်လုပ် |
|---|---|
| ဆက်သွယ်လမ်းကြောင်း | `ဖွင့်(လိပ်စာ, ဆက်သွယ်ပေါက်ကိန်း)`, `ဝင်ဒေတာ()`, `အထွက်()`, `စောင့်ချိန်(မီလီစက္ကန့်)`, `ဆက်သွယ်ပေါက်ကိန်း()`, `ဒေသတွင်းဆက်သွယ်ပေါက်ကိန်း()`, `ချိတ်ဆက်ပြီး()`, `ပိတ်ပြီးသလား()`, `ပိတ်()` |
| ဆက်သွယ်ပေါက်လက်ခံရယူ | `ဖွင့်(ဆက်သွယ်ပေါက်ကိန်း)`, `လက်ခံ()`, `ဆက်သွယ်ပေါက်ကိန်း()`, `စောင့်ချိန်(မီလီစက္ကန့်)`, `ပိတ်ပြီးသလား()`, `ပိတ်()` |
| ဝင်စီးကြောင်း | `ဖတ်()`, `ဖတ်(byte[])`, `ဖတ်(byte[], လုပ်ဆောင်, အလျား)`, `ပိတ်()` |
| ထွက်စီးကြောင်း | `ရေး(int)`, `ရေး(byte[])`, `ရေး(byte[], လုပ်ဆောင်, အလျား)`, `တန်ဖိုးထုတ်လွှတ်()`, `ပိတ်()` |
| ဒေတာပို့လမ်း | `ဖွင့်(ဆက်သွယ်ပေါက်ကိန်း)`, `ပို့(လိပ်စာ, ဆက်သွယ်ပေါက်ကိန်း, စာသား)`, `လက်ခံ()`, `စောင့်ချိန်(မီလီစက္ကန့်)`, `ဆက်သွယ်ပေါက်ကိန်း()`, `ပိတ်ပြီးသလား()`, `ပိတ်()` |
| ချိတ်ဆက်သယ်ပို့ | `ဖွင့်(...)`, `လက်ခံသူဖွင့်(...)`는 ထိပ်တန်ဖိုး မြန်မာ 객체를 ပြန်ပေးရလဒ် |
| စစ်ဆေးချက် | `မှန်ကြောင်းစစ်(အခြေအနေစည်းကမ်း, မူလအကြောင်းရင်း)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`ဖတ်()`의 ဖိုင် 끝은 -1, အခင်းအကျင်းတန်ဖိုး 읽기의 반환값은 တကယ့်ဒေတာ 읽은 길이다.
ကွန်ရက်ဆက် 흐름을 닫으면 연결도 닫힌다. ဆက်သွယ်ပေါက်ကိန်း 0은 빈 번호를 자동 배정한다.
UDP 전문은 လက်ရှိအချက်အလက်တစ်ခု ကိုယ်ပိုင် 커널에서 512바이트까지 받으며, 주소는 ဂဏန်းတန်ဖိုး IPv4를 사용한다.
`localhost` 루프백 외의 အမည် 풀이(DNS)는 ကိုယ်ပိုင် 커널에 아직 없다.

기존 `ချိတ်ဆက်သယ်ပို့.ချိတ်ဆက်/အဆုံးမှတ်နားထောင်/လက်ခံ`, `ဆက်သွယ်မှု.ဖွင့်/ပို့/လက်ခံ`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `ဆက်သွယ်လမ်းကြောင်း`, `ဆက်သွယ်ပေါက်လက်ခံရယူ`, `ဒေတာပို့လမ်း`를 쓴다.

## မြန်မာ ခြွင်းချက်

모든 အောက်ဆုံးတန်ဖိုး 클래스는 မူလသတ်မှတ်တန်ဖိုး 생성자, `새예외("ရှင်းလင်းချက်")` 형태의 အက္ခရာစဉ် 생성자와
`ရှင်းလင်းချက်()`을 제공한다. တကယ့်ဒေတာ ထုတ်လုပ် 문법은 `new စောင့်အချိန်လွန်ခြွင်းချက်("အခြေအနေစောင့် အဆုံး")`이다.

| မြန်မာ ခြွင်းချက် | 상위 အတန်းတန်ဖိုး / 용도 |
|---|---|
| ခြွင်းချက် | `java.lang.Exception`, 직접 던지는 일반 စစ်ဆေးချက် ခြွင်းချက် |
| လုပ်ဆောင်မှုခြွင်းချက် | `java.lang.RuntimeException` |
| အဝင်အထွက်ခြွင်းချက် | `java.io.IOException`, မြန်မာ ဖိုင်·ဆက်သွယ်မှု API의 စစ်ဆေးချက် ခြွင်းချက် |
| စောင့်အချိန်လွန်ခြွင်းချက် | `အဝင်အထွက်ခြွင်းချက်`, ဆက်သွယ်မှု စောင့်ချိန် 초과 |
| လိပ်စာရှာကြည့်ခြွင်းချက် | `အဝင်အထွက်ခြွင်းချက်`, လိပ်စာ အတည်ပြု မအောင်မြင်မှု |
| ဖိုင်မရှိခြွင်းချက် | `အဝင်အထွက်ခြွင်းချက်`, ဖိုင် ဖွင့် မအောင်မြင်မှု |
| ဆက်သွယ်မှုခြွင်းချက် | `အဝင်အထွက်ခြွင်းချက်`, 표준 SocketException တန်ဖိုးပြောင်းလဲ |
| မမှန်ကန်ပေးအချက်ခြွင်းချက် | `java.lang.IllegalArgumentException` |
| ကိန်းပုံစံခြွင်းချက် | `မမှန်ကန်ပေးအချက်ခြွင်းချက်` |
| နယ်နိမိတ်ခြွင်းချက် | `java.lang.IndexOutOfBoundsException` |
| အခင်းအကန့်ခြွင်းချက် / စာသားအကန့်ခြွင်းချက် | `နယ်နိမိတ်ခြွင်းချက်` |
| အလွတ်ကိုးကားခြွင်းချက် | `java.lang.NullPointerException` |
| သင်္ချာခြွင်းချက် | `java.lang.ArithmeticException` |
| အခြေအနေခြွင်းချက် | `java.lang.IllegalStateException` |
| အမျိုးပြောင်းခြွင်းချက် | `java.lang.ClassCastException` |
| အနုတ်အခင်းအရွယ်ခြွင်းချက် | `java.lang.NegativeArraySizeException` |
| အခင်းသိုလှောင်ခြွင်းချက် | `java.lang.ArrayStoreException` |
| အလုပ်ကြိုးအခြေအနေခြွင်းချက် | `java.lang.IllegalThreadStateException` |
| စောင့်ဆိုင်းပြတ်ခြွင်းချက် | `java.lang.InterruptedException`, `အလုပ်.စောင့်`의 တန်ဖိုးစောင့် 중단 |

`ခြွင်းချက်`와 `လုပ်ဆောင်မှုခြွင်းချက်`는 모든 မြန်မာ 예외의 အများသုံးတန်ဖိုး 부모가 아니다. ထိပ်တန်ဖိုး 상속 관계를
사용하며, ဖိုင်·ဆက်သွယ်မှု 전체를 잡으려면 `catch (အဝင်အထွက်ခြွင်းချက် အမှား)`를 쓴다.
မြန်မာ API가 표준 အဝင်အထွက် 오류를 မြန်မာ 예외로 변환한다.
기존 မြန်မာ ဆက်သွယ်မှု 호출에서 `SocketTimeoutException`을 잡던 코드는
`စောင့်အချိန်လွန်ခြွင်းချက်`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
ခြွင်းချက် 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
လက်ရှိအချက်အလက်တစ်ခု ကိုယ်ပိုင် JVM에 이 20종을 추가했다. 임의의 သုံးစွဲသူ Throwable 하위 အတန်းတန်ဖိုး 전체를
지원하도록 확장했다는 뜻은 아니다.

## မူရင်းကုဒ်ဘာသာပြန်·စက်မောင်း

```sh
cd /home/user/jkoros/platforms/rpi4-native
make တည်ဆောက်
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 စမ်းသပ်မှု/Java/မြန်မာကွန်ရက်စမ်းသပ်.java
python3 ကိရိယာစု/ဖိုင်လုပ်ဆောင်.py build/한국어사용/မြန်မာကွန်ရက်စမ်းသပ်.class
make test-jvm
```

내장 라이브러리는 သုံးစွဲသူ JVM ELF 안에 탑재된다. `.jar`는 အိမ်ရှင် javac의
အတန်းတန်ဖိုး 경로로 사용한다. မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 မြန်မာ 예외의 `throws` 선언과 그 import를 인식한다.
ကိုယ်ပိုင် JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·အရာဝတ္ထုတန်ဖိုး·ကွန်ရက်ပေါက်တန်ဖိုး ဥပမာ 전체의 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 컴파일은 အိမ်ရှင် javac를 사용한다.
`/example/java/ဖိုင်ဥပမာ.java`는 게스트 javac로도 컴파일할 ကိန်းတန်ဖိုး 있다.

တကယ့်ဒေတာ TCP/UDP 예제는 [ကွန်ရက်ဥပမာ.java](../../../example/java/ကွန်ရက်ဥပမာ.java),
စက်မောင်း 절차는 [example လမ်းညွှန်](../../../example/README.md),
မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 명명 원칙은 [명명 လမ်းညွှန်](../명명/လမ်းညွှန်.md)에 있다.

## Swing ဝင်း ဥပမာ

`/example/java/ဝင်းဥပမာ.java`와 컴파일된 `.class`ပထမတွက်ချက်ခံ စက်တင် 시 준비된다.
`cd /example/java` နောက်တစ်ခုအချက်အလက်တစ်ခု `java ဝင်းဥပမာ`로 연다. အမည် ဝင်ဒေတာ, နှုတ်ဆက်လုပ်ဆောင် 버튼,
인사말과 클릭 အကြိမ်အရေအတွက် ပြန်လည်မွမ်းမံ, X 닫기를 지원한다.

| 기능 | မြန်မာ 직접 API |
|---|---|
| Runnable / run | `လုပ်ဆောင်ရန်အလုပ်.အလုပ်လုပ်ဆောင်()` |
| ActionListener / actionPerformed | `လှုပ်ရှားမှုလက်ခံသူ.လုပ်ဆောင်ချက်လက်ခံရယူ(လှုပ်ရှားမှုအသိပေးချက် အသိပေးချက်)` |
| ActionEvent | `လှုပ်ရှားမှုအသိပေးချက်.အမိန့်စာသား()`, `ဖြစ်ရပ်မူရင်းကုဒ်()`, `နံပါတ်()` |
| JFrame | `ဝင်း(ဝင်းခေါင်းစဉ်, အကျယ်အဝန်း, အမြင့်တန်ဖိုး)`, `ထည့်သွင်း(မျက်နှာပြင်အင်္ဂါရပ်)`, `ပြသ()`, `ပိတ်()`, `ဖြစ်သောမြင်နိုင်()` |
| JButton | `ခလုတ်(စာသား, အလျားတည်နေရာ, ဒေါင်လိုက်တည်နေရာ, အကျယ်အဝန်း, အမြင့်တန်ဖိုး, လက်ခံသူတန်ဖိုး)`, `လှုပ်ရှားမှုလက်ခံသူသတ်မှတ်(လက်ခံသူတန်ဖိုး)` |
| JLabel / JTextField | `အညွှန်းစာ(...)`, `စာသားအကွက်(...)` |
| အများသုံးတန်ဖိုး မျက်နှာပြင် အင်္ဂါရပ်တန်ဖိုး | `မျက်နှာပြင်အင်္ဂါရပ်.စာသားဖတ်()`, `စာသားရေး(စာသား)`, `နေရာအရွယ်သတ်မှတ်(အလျားတည်နေရာ, ဒေါင်လိုက်တည်နေရာ, အကျယ်အဝန်း, အမြင့်တန်ဖိုး)` |
| SwingUtilities.invokeLater | `ဖြစ်ရပ်တန်းစီရာ.နောက်မှလုပ်ဆောင်(လုပ်ဆောင်ရန်အလုပ်)`, `ဖြစ်ရပ်ဖြန့်ဝေနေသလား()` |
| Thread | `အလုပ်သမား(လုပ်ဆောင်ရန်အလုပ်)`, `အလုပ်စတင်()`, `စောင့်()`, `လည်ပတ်ဆဲလား()`, `အလုပ်အလှည့်ပေး()` |
| 명령행 | `လုပ်ဆောင်()`, `လုပ်ဆောင်အချက်များ.အရေအတွက်()`, `လုပ်ဆောင်အချက်များ.စာသား(အစဉ်အမှတ်)` |

ထိပ်တန်ဖိုး 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
ကိုယ်ပိုင် JVM의 `မြန်မာမျက်နှာပြင်ခေါ်`, `လုပ်ငန်းစဉ်အလုပ်ကြိုး`ပထမတွက်ချက်ခံ မြန်မာ အတန်းတန်ဖိုး·နည်းလမ်းတန်ဖိုး·서술자를
해석해 မျက်နှာပြင် 요소와 စက်မောင်း 가닥을 직접 만든다. လှုပ်ရှားမှု 알림도 ကိုယ်ပိုင် 객체이며
콜백으로 `အလုပ်လုပ်ဆောင်`와 `လုပ်ဆောင်ချက်လက်ခံရယူ`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 စက်မောင်း 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 ကိုယ်ပိုင် JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 အိမ်ရှင် JVM에서 무동작 객체가 생기지 않도록 하는 တန်ဖိုးငြင်းပယ် 경로다.
ကိုယ်ပိုင် JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 အကောင်အထည်ဖော်မှု API를
실행할 ကိန်းတန်ဖိုး 없다. အိမ်ရှင် javac로 컴파일한 နောက်တန်ဖိုး ကိုယ်ပိုင် JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, မျက်နှာပြင် 큐 기능은 `SwingUtilities`에 해당한다.

```java
import မြန်မာ.ကိုယ်ပိုင်.*;
public class 가닥예제 implements လုပ်ဆောင်ရန်အလုပ် {
    public void အလုပ်လုပ်ဆောင်() { အထွက်.စာကြောင်းထုတ်("မြန်မာ အလုပ် စက်မောင်း"); }
    public static void လုပ်ဆောင်() throws စောင့်ဆိုင်းပြတ်ခြွင်းချက် {
        အလုပ်သမား အလုပ်ကြိုးတန်ဖိုး = အလုပ်.လုပ်ဆောင်(new 가닥예제());
        အလုပ်.စောင့်(အလုပ်ကြိုးတန်ဖိုး);
    }
}
```

`example/java`의 다섯 소스는 သီးသန့်စကားလုံးများ·리터럴 외 식별자를 한국어로 작성한다.
အခင်းအကျင်းတန်ဖိုး အချက်များ 대신 `လုပ်ဆောင်အချက်များ`, 길이는 `အက္ခရာ.ဘိုက်အရေအတွက်`를 사용한다.
표준 Java의 `main(String[])`도 ဆက်လုပ်လုပ်ငန်းစဉ်ဆောင်ရွက်မှု 지원한다. နှစ်တန်ဖိုး တတိယအော်ပရန်း 정의되어 있으면
ကိုယ်ပိုင် 실행기는 အချက်များ 없는 `လုပ်ဆောင်()`을 우선한다.
기존 မြန်မာ မျက်နှာပြင် 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`အလုပ်.လုပ်ဆောင်(Runnable)`을 사용하던 코드는 새 မြန်မာ 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API ထောက်ပံ့မှုတန်ဖိုး 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 အတန်းတန်ဖိုး·နည်းလမ်းတန်ဖိုး 이름과 서술자가 남는다.
မြန်မာ အမည် 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 အစိတ်အပိုင်းတန်ဖိုး,
상속·နည်းလမ်းတန်ဖိုး 재정의, native ချိတ်ဆက်, 런처의 진입점도 함께 맞춰야 한다.

[JVMS နည်းလမ်းတန်ဖိုး ကိုးကားချက်](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)တတိယအော်ပရန်း.
