# Raspberry Pi 4 ကိုယ်ပိုင် Java အူတိုင်တန်ဖိုး — သုံးစွဲသူ စက်မောင်း 기반

လက်ရှိအချက်အလက်တစ်ခု ကိုယ်ပိုင် 코드의 COSL 상업 အခြေအနေစည်းကမ်း, 제3자 고지 및 LGPL 재연결 자료는 [COSL ဖြန့်ချိမှုတန်ဖိုး လမ်းညွှန်](COSL배포안내.md)를 참고한다. အလှည့်ပြောင်းနည်းစနစ် 전 GPL 구성의 판단은 [ယခင်အချက်အလက်တစ်ခု 라이선스 검토](라이선스검토.md)에 기록했다.

မြန်မာ ဆက်သွယ်မှု·ခြွင်းချက် 사용법은 [မြန်မာ Java API](မြန်မာJava/လမ်းညွှန်.md), လုပ်ဆောင်ချက်·ကိန်းရှင်တန်ဖိုး·ဖိုင် 이름의 변경과 어원 근거는 [명명 လမ်းညွှန်](명명/လမ်းညွှန်.md)를 참고한다.

Linux 없이 부팅하는 ကိုယ်ပိုင် AArch64 커널이다. Java AOT အူတိုင်တန်ဖိုး 위에 **အမိန့်စာကြောင်း အမိန့်ဝင်း, 게스트 Java ဘာသာပြန်စက်·JVM, MicroPython, EL0 C++ စက်မောင်း, ဖိုင်·UDP 루프백 시스템 ခေါ်လုပ်, 여러 ဟန်ဂုစာသား GUI အဆုံးသုံးမျက်နှာပြင်·vi တည်းဖြတ်စက်·Swing 부분집합**을 제공한다. 커널의 ဖိုင် ဒေတာ/정책·루프백 လွှဲပြောင်းတန်ဖိုး·အမိန့်ဝင်း 상태는 Java, မျက်နှာပြင် 합성·ပုံမှတ် တန်ဖိုးပြောင်း·ညွှန်တံ·클리핑도 Java로 구현하며, CPU/MMU/ကိရိယာ 경계와 အဆုံးသုံးမျက်နှာပြင်·အက္ခရာတန်ဖိုး မျက်နှာပြင်ဆေးခြယ် 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 ကိုယ်ပိုင် 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 စက်မောင်း, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](ဖိုင်လွှဲပြောင်းနှင့်ဘာသာပြန်မှု.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, ရုပ်ပိုင်းစက်ပစ္စည်း Pi4의 유선 송수신은 아직 미검증이다.** စက်မောင်း·ချိတ်ဆက်မှု·စကားဝှက်တန်ဖိုး 확인은 [ပြင်ပတန်ဖိုး ချိတ်ဆက်မှု လမ်းညွှန်](ပြင်ပချိတ်ဆက်မှုလမ်းညွှန်.md)에 정리했다.

셸은 EL1 အူတိုင်တန်ဖိုး, `java` 등 သုံးစွဲသူ စက်မောင်း 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 ကန့်သတ်ချက်တန်ဖိုး, QEMU ကွန်ရက်ဆက် စက်မောင်း·ချိတ်ဆက်မှု 방법 및 တကယ့်ဒေတာ 검증은
[စက်မောင်း 계층과 ပြင်ပတန်ဖိုး ဆက်သွယ်မှု 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 တကယ့်ဒေတာ စက်မောင်း 형식으로 검사한다. `./နှုတ်ဆက်`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 တည်ငြိမ်တန်ဖိုး ELF는 `run --linux ဖိုင်အမည်စာသား`으로 실행한다. [ELF·Linux ABI ထောက်ပံ့မှုတန်ဖိုး 범위와 동일 바이너리 စမ်းသပ်မှု](실행파일규약.md).

GUI와 네트워크는 `python3 ကိရိယာစု/စက်မောင်း.py --desktop --network`로 함께 사용한다. Java·C·Python의 မြန်မာ ဥပမာ 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 စက်တင် 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 ကိန်းတန်ဖိုး 있다. Remmina에서 **F9/Shift+Space/한·သုညတွက်ချက်ခံ သော့တန်ဖိုး**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·တကယ့်ဒေတာ TCP/UDP·ဖိုင် ဘိုက်တန်ဖိုး·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java ဝင်းဥပမာ`로 မြန်မာ Swing 예제를 실행한다. အဆုံးသုံးမျက်နှာပြင် 모서리에 마우스를 대고 **ဘယ်ဘက် 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 လက်ရှိအချက်အလက်တစ်ခု ကော်လံတန်ဖိုး·အတန်းလိုက်တန်ဖိုး 수를 보여 준다.

စက်မောင်း 버튼 화면은 5×7 영문 글꼴을 쓰며, အဆုံးသုံးမျက်နှာပြင် 창은 Noto CJK/DejaVu에서 생성한 ဟန်ဂုစာသား·Unicode 비트맵 글꼴을 쓴다. UART와 တကယ့်ဒေတာ 프레임버퍼의 ဟန်ဂုစာသား 표시를 시험한다. 루프백은 동일 အူတိုင်တန်ဖိုး 내부의 ဒေတာစာ 전달이며 IP 패킷을 Ethernet으로 내보내는 드라이버가 아니다. 바깥 IPv4는 lwIP TCP/UDP 스택으로 보조 UART SLIP 경로를 사용한다. `python3 ကိရိယာစု/စက်မောင်း.py --network`로 QEMU NAT를 연결하고 `ftpd start`로 서비스를 시작한다.

Java의 정확한 API·문법·စက်မောင်း 제한과 မြန်မာ 사용법은 [ကိုယ်ပိုင် JVM과 မြန်မာ စာကြည့်တိုက်](Javaလည်ပတ်ဝန်းကျင်.md)에 정리했다. အတန်းတန်ဖိုး ဖိုင်/JAR 배포는 [မြန်မာJava](မြန်မာJava) 소스에서 재현한다. 기존 Linux판 `မြန်မာ.Java`와 별도인 `မြန်မာ.ကိုယ်ပိုင်` 패키지다.

**vi·여러 ဝင်း·Swing·ဟန်ဂုစာသား Java/Python/C/C++·posix-kor 예제는 [ဟန်ဂုစာသား ဖွံ့ဖြိုးရေး 매뉴얼](ဖွံ့ဖြိုးရေးလမ်းညွှန်.md)에 정리했다.**

GUI အဆုံးသုံးမျက်နှာပြင် စက်မောင်း·단축키·အမိန့်ဝင်း အမိန့်·제한은 [셸과 အဆုံးသုံးမျက်နှာပြင် 사용법](အမိန့်ဝင်းနှင့်အဆုံးသုံးစက်.md)에 정리했다.

## လက်ရှိအချက်အလက်တစ်ခု 컴퓨터에서 စက်မောင်း

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

ထွက်ပရိုဂရမ်: **Ctrl+A နောက်တစ်ခုအချက်အလက်တစ်ခု X**. 게스트 C/AOT ကိရိယာစု 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc ဂဏန်းသင်္ချာတန်ဖိုး 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. အိမ်ရှင် 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. ဘာသာပြန်စက် 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/လမ်း/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` ထောက်ပံ့မှုတန်ဖိုး 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 စက်မောင်း**한다. 기존 한 အက္ခရာတန်ဖိုး 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "ဟန်ဂုစာသား အချက်များ 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

| အမိန့် | လှုပ်ရှားမှု |
|---|---|
| `help` / `info` | အမိန့်·တကယ့်ဒေတာ အကောင်အထည်ဖော်မှု အခြေအနေတန်ဖိုး |
| `ls` / `cat FILE` / `rm FILE` | RAM ဖိုင် အချက်စာရင်း·အကြောင်းအရာတန်ဖိုး·삭제 |
| `vi FILE` | သုံးစွဲသူ နယ်ပယ်တန်ဖိုး vi 부분집합, ဟန်ဂုစာသား တည်းဖြတ်တန်ဖိုး·သိုလှောင်တန်ဖိုး·검색·되돌리기 |
| `edit FILE` | ဖိုင် 전체를 새로 ဝင်ဒေတာ; 단독 `.` 줄로 သိုလှောင်တန်ဖိုး, Ctrl-C로 ပယ်ဖျက်လုပ်ငန်း |
| `javac FILE.java` / `java CLASS [ARGS]` | ကိုယ်ပိုင် 제한형 Java မူရင်းကုဒ်ဘာသာပြန်·စက်မောင်း |
| `python FILE.py [ARGS]` / `python -c 'CODE'` | MicroPython မူရင်းကုဒ်ဘာသာပြန်·စက်မောင်း |
| `load FILE` / `hex FILE` | 16진수 바이너리 ဝင်ဒေတာ/အထွက်; 입력은 단독 `.` 줄로 သိုလှောင်တန်ဖိုး |
| `run FILE.elf [ARGS]` / `run cpp` | 업로드한 ကိုယ်ပိုင် ABI ELF / 내장 C++ ဥပမာ |
| `net test` / `tasks` / `selftest` | UDP 루프백 / 협력식 အလုပ် / EL0 တန်ဖိုးကာကွယ် စမ်းသပ်မှု |
| `gui` / `terminal` | စက်မောင်း မျက်နှာပြင် / ဟန်ဂုစာသား GUI အဆုံးသုံးမျက်နှာပြင်; F12로 အဆုံးသုံးမျက်နှာပြင် ဖွင့်·ပိတ် |
| `samples` | 삭제한 မူလသတ်မှတ်တန်ဖိုး ဥပမာ အခြေအနေပြန်လည်ရယူ; 기존 파일은 보존 |

예를 들어 `edit နှုတ်ဆက်.java`를 입력한 နောက်တစ်ခုအချက်အလက်တစ်ခု အောက်ဆုံးတန်ဖိုး 소스를 입력한다.

```java
public class နှုတ်ဆက် { public static void main(String[] args) { int တန်ဖိုး = 7; System.out.println("ဟန်ဂုစာသား=" + တန်ဖိုး); } }
```

그다음 단독 `.` 줄로 저장하고 `javac နှုတ်ဆက်.java`, `java နှုတ်ဆက်`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. ပယ်ဖျက်လုပ်ငန်း·잘못된 16진수·ဆံ့ပမာဏ 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, စက်မောင်း 인수는 အများဆုံးတန်ဖိုး 8개·각각 UTF-8 255바이트다. 일반 အမိန့် 인수는 အများဆုံးတန်ဖိုး 32개다. ကိုးကားအမှတ်·백슬래시·အမိန့်ဝင်း ကိန်းရှင်တန်ဖိုး·파이프·리다이렉션 범위는 [အမိန့်ဝင်း ရှင်းလင်းချက်](အမိန့်ဝင်းနှင့်အဆုံးသုံးစက်.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, လိပ်စာ **127.0.0.1:5902**로 연결한다. 키보드·ဟန်ဂုစာသား Unicode ဝင်ဒေတာ·명시적 붙여넣기·စက်မောင်း 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + ကွန်ရက်ဆက်: python3 ကိရိယာစု/စက်မောင်း.py --desktop --network
# 다른 စက်ပစ္စည်းဆက်သွယ်ပေါက်: python3 ကိရိယာစု/စက်မောင်း.py --desktop --port 5903
```

종료는 실행한 အိမ်ရှင် 터미널에서 Ctrl+C다. 기존 `python3 ကိရိယာစု/စက်မောင်း.py --vnc 127.0.0.1:2`는 မျက်နှာပြင် 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. တကယ့်ဒေတာ Pi4 USB 입력기는 아직 없으며, VNC ချိတ်ဆက် 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 တကယ့်ဒေတာ C++/UDP ELF စက်မောင်း, `Hello.java` မူရင်းကုဒ်ဘာသာပြန် 후 JVM စက်မောင်း, `hello.py` စက်မောင်း, GUI အဆုံးသုံးမျက်နှာပြင် 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 အပြန်အလှန် 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 မှတ်ဉာဏ်ဒေတာ·CPU 문맥을 보관한다. အမိန့်ဝင်း·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

make image   # အူတိုင်တန်ဖိုး, SD စက်ပုံရိပ်တည်ဆောက်, စက်တင် ZIP, 사용자용 SDK

이미지는 확인된 공식 Pi စက်တင် 묶음에서 `start4.elf`, `fixup4.dat`, Pi4 DTB와 disable-bt overlay를 가져온다. Linux kernel/initramfs/rootfs는 넣지 않는다. 펌웨어·MicroPython·အဆုံးသုံးမျက်နှာပြင် စာလုံးပုံစံတန်ဖိုး 라이선스와 စာလုံးပုံစံတန်ဖိုး 출처 해시도 동봉한다. ဖိုင် ထုတ်လုပ် 스크립트는 물리 디스크에 기록하지 않는다.

예비 microSD에 စက်ပုံရိပ်တည်ဆောက် မှတ်တမ်းမှတ်တမ်းတစ်ခု 도구로 `.img`를 기록하거나 FAT32 စက်တင် 파티션 최상위에 ZIP 내용을 푼다. စက်ပုံရိပ်တည်ဆောက် 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 မူလသတ်မှတ်တန်ဖိုး EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**ရုပ်ပိုင်းစက်ပစ္စည်း Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD ဖိုင် 구성·အူတိုင်တန်ဖိုး 체크섬 검사와 물리 ဆားကစ်ပြား စက်တင် 검증은 별개다. MMU သုံးစွဲမှု 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 စက်တင် 조건을 전제로 한다. သုံးတန်ဖိုး 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 မြန်မာ API သုံးစွဲမှု

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/ဖိုင်ဥပမာ.cpp -o demo.elf
python3 compile.py examples/ဆက်သွယ်မှုဥပမာ.cpp -o network.elf
```

진입점은 `extern "C" int သုံးစွဲသူပရိုဂရမ်စတင်(int)`이다. သုံးစွဲသူ C++는 FP/SIMD를 사용할 ကိန်းတန်ဖိုး 있다. အူတိုင်တန်ဖိုး C/Java AOT는 일반 레지스터만 사용하므로 ခြွင်းချက် လုပ်ငန်းစဉ်တန်ဖိုးအချက် 중 သုံးစွဲသူ FP 상태를 건드리지 않는다. သုံးစွဲသူ အချက်အမှတ်တစ်ခုတန်ဖိုး 시 FP 상태를 초기화하고 အူတိုင်တန်ဖိုး 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int သုံးစွဲသူပရိုဂရမ်စတင်(int) {
    int ဖိုင် = ဖိုင်ဖွင့်("နှုတ်ဆက်.txt", ဖတ်ရေး | 없으면만들기 | 내용비우기, 0600);
    if (ဖိုင် < 0) return 1;
    const char အကြောင်းအရာတန်ဖိုး[] = "안녕하세요";
    int ရလဒ် = ဖိုင်ဒေတာရေး(ဖိုင်, အကြောင်းအရာတန်ဖိုး, sizeof(အကြောင်းအရာတန်ဖိုး) - 1);
    ဖိုင်ပိတ်(ဖိုင်);
    return ရလဒ် == sizeof(အကြောင်းအရာတန်ဖိုး) - 1 ? 0 : 2;
}
```

[ဖိုင် ဥပမာ](သုံးစွဲသူ/ဖိုင်ဥပမာ.cpp)와 [ဆက်သွယ်မှု ဥပမာ](သုံးစွဲသူ/ဆက်သွယ်မှုဥပမာ.cpp)ပထမတွက်ချက်ခံ တကယ့်ဒေတာ စက်တင် စမ်းသပ်မှု 대상이다. `파일규약.h`의 이름은 커널용/사용자용 အားလုံးတည်ဆောက် 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 ဖိုင် လုပ်ငန်းစဉ်တန်ဖိုးအချက် 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 ကွန်ရက်ပေါက်တန်ဖိုး 함수는 လက်ရှိအချက်အလက်တစ်ခု 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 အူတိုင်တန်ဖိုး 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 နောက်တစ်ခုအချက်အလက်တစ်ခု 도구를 사용하면 **새 QEMU를 부팅해 업로드한 တကယ့်ဒေတာ 바이트를 재확인한 နောက်တန်ဖိုး 게스트에서 စက်မောင်း**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 ကိရိယာစု/ဖိုင်လုပ်ဆောင်.py build/jkoros-native-sdk/demo.elf
python3 ကိရိယာစု/ဖိုင်လုပ်ဆောင်.py ဥပမာ/Hello.java "ဟန်ဂုစာသား အချက်များ"
python3 ကိရိယာစု/ဖိုင်လုပ်ဆောင်.py ဥပမာ/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 အူတိုင်တန်ဖိုး 묶음에 포함되어 이 ဖိုင် 한도를 적용받지 않는다. **C++ 컴파일러는 အိမ်ရှင် SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 စာကြည့်တိုက်, PT_TLS, PT_INTERP, PT_DYNAMIC, စက်မောင်း·ရေး 겸용 세그먼트는 로더가 거부한다. 구체적인 ခေါ်လုပ် နံပါတ်·လိပ်စာ ဖြတ်နယ်ပယ်·오류는 [သုံးစွဲသူ ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `ဖိုင်သိုလှောင်အတည်ပြု`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 ခွင့်ပြုချက်တန်ဖိုး·dup/fcntl은 없다. 디렉터리와 တစ်ဖက်တန်ဖိုး/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 အများဆုံးတန်ဖိုး 512바이트, 소켓은 8개, တန်ဖိုးလက်ခံရယူ 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. သုံးစွဲသူ ထွက်ပရိုဂရမ် 시 열린 ဖိုင် 서술자와 소켓을 회수한다.

## မှန်ကန်ကြောင်းစစ် ရလဒ်

`make test-jvm`은 9개 프로그램을 OpenJDK와 တကယ့်ဒေတာ ကိုယ်ပိုင် 커널에서 실행해 결과를 비교한다. `make test`에도 포함된다. 별도 `ကိရိယာစု/စက်တင်စမ်းသပ်.py`는 Java စတုဂံ API의 တကယ့်ဒေတာ မျက်နှာပြင် 픽셀까지 검사한다. `make test-shell`, `make test-desktop`은 새 셸과 တကယ့်ဒေတာ VNC ဝင်ဒေတာ·ဟန်ဂုစာသား အဆုံးသုံးမျက်နှာပြင် 화면을 검사하며 `make test`에도 포함된다.

`make test-windows`, `make test-swing`, `make test-stream`, `make test-coding`도 제공하며 `make test`에 포함된다.

`make test`는 OpenJDK와 AOT တွက်ချက်လုပ်ဆောင်မှု ရလဒ် 비교, 런타임 အမှား 중단, 미지원 Java 거부와 함께 별도 QEMU VM에서 다음을 검사한다.

- 기존 Java အူတိုင်တန်ဖိုး တွက်ချက်မှု·UTF-8·C++ 직접 ခေါ်လုပ်·협력식 အလုပ် 및 프레임버퍼.
- 손상/잘못된 ABI/လိပ်စာ 초과/겹친 페이지/W+X 등 ELF တန်ဖိုးငြင်းပယ် 사례 22개.
- EL0 C++ 생성자·RAII·실수 တွက်ချက်လုပ်ဆောင်မှု·ဖိုင်·ပုံတင်မှတ်ဉာဏ်တန်ဖိုး 및 잘못된 시스템 ခေါ်လုပ် ညွှန်တံ.
- အူတိုင်တန်ဖိုး/ကုဒ်တန်ဖိုး/MMIO ရေး·ဝင်သုံးအချက်, NX တွက်ချက်ခံထပ်ဆင့်အစု·NULL စက်မောင်း, guard page, 특권 အမိန့် 차단.
- SVC를 호출하지 않는 무한 반복을 타이머로 종료한 후 ဖြစ်သောပုံမှန် ပရိုဂရမ် 재실행.
- 반복 စက်မောင်း 시 ဖိုင်/ကွန်ရက်ပေါက်တန်ဖိုး 누수 방지, UDP 왕복·보낸 လိပ်စာ·잘린 တန်ဖိုးလက်ခံရယူ·큐 포화·빈 ဒေတာစာ·미지원 ဆက်သွယ်မှု အမှား.
- အမိန့်ဝင်း တည်းဖြတ်တန်ဖိုး·ပယ်ဖျက်လုပ်ငန်း·16진수 업로드/다운로드·သုံးစွဲသူ ELF 실행과 잘못된 ELF တန်ဖိုးငြင်းပယ်.
- 게스트 Java → OpenJDK `-Xverify:all`, OpenJDK → 게스트 JVM 교차 စက်မောင်း, ဟန်ဂုစာသား အတန်းတန်ဖိုး·ကိန်းရှင်တန်ဖိုး·ဖိုင်အမည်စာသား.
- 여러 ဝင်း·vi သိုလှောင်တန်ဖိုး·တည်းဖြတ်တန်ဖိုး·ပြန်ပေးတံတား·သုံးစွဲသူ အခြေအနေတန်ဖိုး 중단/လုပ်ဆောင်မှုပြန်စ, Swing ဟန်ဂုစာသား ဝင်ဒေတာ·이벤트·X ပိတ်, 연결형 루프백, C/C++ ဟန်ဂုစာသား SDK ဥပမာ.
- MicroPython Unicode·큰 ကိန်းပြည့်·အတန်းတန်ဖိုး·GC 반복·ဖိုင် import·ခြွင်းချက်·ဖိုင်·UDP 왕복·အချိန်တန်ဖိုး 초과 후 복귀.
- GUI ရွေးချယ်မှုတန်ဖိုး ရွှေ့တန်ဖိုး, C++/UDP/Java/MicroPython 버튼 စက်မောင်း, 콘솔 복귀 및 တကယ့်ဒေတာ 프레임버퍼 픽셀/စာလုံးပုံစံတန်ဖိုး.
- 디렉터리·ကိန်းရှင်တန်ဖိုး·အခြေအနေစည်းကမ်း·ဖိုင် အမိန့်·အမိန့်စာတမ်းတန်ဖိုး·순차 파이프·리다이렉션·ဆံ့ပမာဏ 초과 အခြေအနေပြန်လည်ရယူ, Python stdin/EOF와 Java/Python stdout.
- အမိန့် မှတ်တမ်းမှတ်တမ်းတစ်ခု·긴 ဟန်ဂုစာသား ဝင်ဒေတာ တည်းဖြတ်တန်ဖိုး·ပြီးစီးတန်ဖိုး·အဆုံးသုံးမျက်နှာပြင် 스크롤, 그래픽 ပရိုဂရမ် ထွက်ပရိုဂရမ် 후 ဝင်း 복원, တကယ့်ဒေတာ VNC Unicode သော့တန်ဖိုး·붙여넣기·마우스.

[အူတိုင်တန်ဖိုး စမ်းသပ်မှု မှတ်တမ်းမှတ်တမ်းတစ်ခု](build/verification/implementation-test.log), [အမိန့်ဝင်း စမ်းသပ်မှု](build/verification/shell/report.json), [VNC စမ်းသပ်မှု](build/verification/desktop/report.json), [စက် 판독 ရလဒ်](build/verification/report.json), [အစဉ်ဆက်တန်ဖိုး မှတ်တမ်းတန်ဖိုး](build/verification/serial.log), [GUI မျက်နှာပြင်](build/verification/gui-python.png)을 확인할 ကိန်းတန်ဖိုး 있다. [SDK 재컴파일 ရလဒ်](build/verification/sdk.json)는 두 예제의 အချက်အမှတ်တစ်ခု·적재 세그먼트·ABI note가 စက်တင် 시험한 ELF와 일치함을 확인한다. သင်္ကေတတန်ဖိုး 등 비적재 메타데이터를 포함한 ဖိုင် 전체의 SHA256까지 같다고 의미하지는 않는다.

## Java와 Python의 정확한 ဖြတ်နယ်ပယ်

ကိုယ်ပိုင် `javac`는 버전 49 `.class`를 생성하며 JVM은 ထောက်ပံ့မှုတန်ဖိုး 명령으로 구성된 버전 45–52 클래스를 실행한다. တည်ငြိမ်တန်ဖိုး လုပ်ဆောင်ချက်·재귀·int/boolean/char/String·အခြေအနေစည်းကမ်း/반복·အက္ခရာစဉ် 결합과 일부 ဖိုင် 스트림을 지원한다. UTF-8 문자열과 အက္ခရာ 리터럴, ASCII 및 현대 ဟန်ဂုစာသား 음절/ပေါင်းစပ်မှု 자모 식별자를 처리한다. Unicode သတ်မှတ်နံပါတ်တန်ဖိုး 전체 ဇယား·Unicode မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 이스케이프는 구현하지 않았다. 게스트 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 컴파일러는 일반 အရာဝတ္ထုတန်ဖိုး·ခြွင်းချက်·Thread 구문을 아직 컴파일하지 못한다. အိမ်ရှင် `javac --release 8`로 만든 ထောက်ပံ့မှုတန်ဖိုး 부분집합 클래스는 ကိုယ်ပိုင် JVM 0.4의 အရာဝတ္ထုတန်ဖိုး·ခြွင်းချက်·Thread·UDP와 မြန်မာ API를 사용할 ကိန်းတန်ဖိုး 있다. Swing은 문서화한 ကိုယ်ပိုင် API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [ကိုယ်ပိုင် JVM ရှင်းလင်းချက်](Javaလည်ပတ်ဝန်းကျင်.md)이 기준이다. 상세 ဘာသာစကား 범위는 [공유 Java ကိရိယာစု ရှင်းလင်းချက်](../../စာတမ်း/Javaဖွံ့ဖြိုးဝန်းကျင်.md)을 참고하되, 그 문서의 x86 အမိန့်ဝင်း/သိုလှောင်တန်ဖိုး/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ**를 ကိုယ်ပိုင် AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 လုပ်ဆောင်ချက်·အတန်းတန်ဖိုး·ခြွင်းချက်·리스트/အဘိဓာန်·Unicode·GC·가변 정밀도 정수를 제공한다. လက်ရှိအချက်အလက်တစ်ခု 구성은 ကိန်းပြည့် 빌드로 `float`, `complex`, `math`ပထမတွက်ချက်ခံ 없으며 CPython 전체 표준 စာကြည့်တိုက်, pip, subprocess, threading, 일반 socket과 မူလသတ်မှတ်တန်ဖိုး `open()` ဖိုင် 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 အရာဝတ္ထုတန်ဖိုး·모듈은 ထွက်ပရိုဂရမ် 시 회수되고 RAM 파일만 နောက်တစ်ခုအချက်အလက်တစ်ခု 실행에 남는다.

`import jkoros`로 နောက်တစ်ခုအချက်အလက်တစ်ခု 시스템 연결을 쓴다. အားလုံးတည်ဆောက် SVC를 통해 ကိုယ်ပိုင် Java 커널에 접근한다.

| လုပ်ဆောင်ချက် | လှုပ်ရှားမှု |
|---|---|
| `stdin(limit)` | လက်ရှိအချက်အလက်တစ်ခု 표준 입력에서 အများဆုံးတန်ဖိုး limit바이트(0…16384)를 bytes로 ရလဒ်ဖတ်; EOF는 빈 bytes, UART ဒေတာ 없음은 OSError(11) |
| `read(name)` | တစ်ဖက်တန်ဖိုး/절대 RAM 경로의 ဖိုင် 전체를 bytes로 ရလဒ်ဖတ် |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 သိုလှောင်တန်ဖိုး, 쓴 ဘိုက်တန်ဖိုး ကိန်းတန်ဖိုး ပြန်ပေးရလဒ် |
| `remove(name)` | RAM ဖိုင် 삭제 |
| `rect(x, y, w, h, color)` | 선택한 တကယ့်ဒေတာ မျက်နှာပြင် အရွယ် 안의 စတုဂံ ပုံဆွဲမှု; 기존 보드의 RGB32 တန်ဖိုး |
| `ticks_ms()` | စက်တင် 후 မီလီစက္ကန့်, 32비트 순환 |
| `udp_open(port)` | 127.0.0.1의 UDP ကွန်ရက်ပေါက်တန်ဖိုး ဖွင့်/စက်ဖိုင်ထုပ်ပိုး; 0은 자동 စက်ပစ္စည်းဆက်သွယ်ပေါက် |
| `udp_send(fd, port, data)` | 루프백 ဦးတည်ရာတန်ဖိုး 포트에 str/bytes 버퍼 လွှဲပြောင်းတန်ဖိုး |
| `udp_recv(fd)` | `(bytes, 보낸포트)` ပြန်ပေးရလဒ်; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | ကွန်ရက်ပေါက်တန်ဖိုး ပိတ် |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```

이식 ကုဒ်တန်ဖိုး: [python/](Pythonတံတား/), [သုံးစွဲသူ Java ချိတ်ဆက်](သုံးစွဲသူ/Javaတံတား.c). 공식 [MicroPython 이식 လမ်းညွှန်](https://docs.micropython.org/en/latest/develop/porting.html)를 참고했다. မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ URL·ဖိုင်ဟက်ရှ်တွက်·라이선스는 [vendor လမ်းညွှန်](vendor/README.md)에 기록했다.

| OpenJDK/JRE | HotSpot OS အလွှာတန်ဖိုး, GC/JIT/스레드/신호/동적 연결과 Java 네이티브 စာကြည့်တိုက် 이식; javac/java တကယ့်ဒေတာ စက်မောင်း |
| ပြင်ပတန်ဖိုး ကွန်ရက်ဆက် | 추가한 GENET/PHY·DHCP 드라이버의 တကယ့်ဒေတာ ဆားကစ်ပြား 송수신 မှန်ကန်ကြောင်းစစ်, DNS·Wi-Fi |
| GUI တိုးချဲ့မှု | USB HID, 게스트 입력기·အက္ခရာ 조판, Swing ဝင်း အရွယ် 조절·클리핑 တိုးချဲ့မှု, 전체 AWT/Swing 이식 |

이 표는 남은 작업이며 အကောင်အထည်ဖော်မှု ဖြစ်သောအပြည့်အစုံ 목록이 아니다. QEMU Pi4 모델에는 GENET Ethernet과 PCIe root port가 없어 ပြင်ပတန်ဖိုး ကွန်ရက်ဆက် 드라이버는 ရုပ်ပိုင်းစက်ပစ္စည်း 검증도 필요하다. [QEMU ကိရိယာ 지원표](https://www.qemu.org/docs/master/system/arm/raspi.html)

စက်ပစ္စည်း 및 ABI 참고: [BCM2711 အရံ](https://datasheets.raspberrypi.com/bcm2711/bcm2711-peripherals.pdf), [Pi4 GIC လိပ်စာ](https://github.com/raspberrypi/linux/blob/rpi-6.12.y/arch/arm/boot/dts/broadcom/bcm2711.dtsi), [mailbox သဘောတူစည်းမျဉ်းတန်ဖိုး](https://github.com/raspberrypi/firmware/wiki/Mailbox-property-interface), [Arm ELF64](https://github.com/ARM-software/abi-aa/blob/main/aaelf64/aaelf64.rst), [Arm FP ထိန်းချုပ်တန်ဖိုး 레지스터 정의](https://github.com/ARM-software/arm-trusted-firmware/blob/master/include/arch/aarch64/arch.h).


## မြန်မာ C ဒေတာအမျိုးပုံစံ·Python အမှား·အထုပ် တန်ဖိုးတပ်ဆင်

C ကွန်ရက်ဆက် API는 `struct အင်တာနက်ကွန်ရက်ပေါက်လိပ်စာ`, enum 상수와 တကယ့်ဒေတာ မြန်မာ 함수로
구현한다. 매크로 별칭을 사용하지 않으며 ယခင်အချက်အလက်တစ်ခု pk_* ABI도 유지한다.
Python 예제는 `စနစ်အမှား`, `အမှား.နံပါတ်`, `အမှား.ရှင်းလင်းချက်`을 사용한다.

`python3 ကိရိယာစု/စက်မောင်း.py --desktop --network --pip`로 시작하면 게스트에서
`pip install micropython-bisect==3.3.3`을 사용할 ကိန်းတန်ဖိုး 있다. 현재는 အိမ်ရှင် 중계를
이용하는 제한형 MicroPython မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 설치기이며 CPython pip·자동 의존성 해결·C 확장은
미지원이다. 설치한 `/lib` 자료는 RAM이다. [사용법과 ကန့်သတ်ချက်တန်ဖိုး](Pythonအထုပ်.md).

## မျက်နှာပြင် အရွယ် ရွေးချယ်မှုတန်ဖိုး

`python3 ကိရိယာစု/စက်မောင်း.py --desktop --network --resolution 1920x1080`으로 Full HD 화면을 사용한다. 기본값은 640×480이며 1280×720도 가능하다. အဆုံးသုံးမျက်နှာပြင် ရွှေ့တန်ဖိုး, Swing အလယ် နေရာချထားပုံ, Java·C·Python 그리기도 တကယ့်ဒေတာ 크기를 따른다. SD 영상은 `make image RESOLUTION=1920x1080`으로 만든다. [သတ်မှတ်ချက်·မြန်မာ API·မှန်ကန်ကြောင်းစစ် လမ်းညွှန်](မျက်နှာပြင်ကြည်လင်ပြတ်သားမှု.md).

## မြန်မာ 직접 API와 မျက်နှာပြင် ပြန်လည်မွမ်းမံ

`example/java`는 `လုပ်ဆောင်ရန်အလုပ်`, `လှုပ်ရှားမှုလက်ခံသူ`, `လှုပ်ရှားမှုအသိပေးချက်`, `ခလုတ်`, `ဖြစ်ရပ်တန်းစီရာ`,
`အလုပ်သမား`, `လုပ်ဆောင်()`을 사용할 ကိန်းတန်ဖိုး 있다. မြန်မာ GUI/가닥을 ကိုယ်ပိုင် JVM에 직접
연결했으며, 표준 Swing/Thread를 감싸지 않는다. အက္ခရာစဉ် 등 javac의 표준
계약과 전체 မူရင်းကုဒ်အပင်ဖွဲ့စည်းပုံ 검토 범위는 [명명 လမ်းညွှန်](명명/လမ်းညွှန်.md), 사용법과 호환성 변경은
[မြန်မာ Java API](မြန်မာJava/လမ်းညွှန်.md)를 본다.

အဆုံးသုံးမျက်နှာပြင် ရွှေ့တန်ဖိုး·အရွယ် 변경은 바뀐 영역만 합성하고 달라진 화소만 표시한다.

[အစိတ်အပိုင်းတန်ဖိုး ပြန်လည်မွမ်းမံ စစ်ဆေးချက်](build/verification/redraw/report.json)를 참고한다.
