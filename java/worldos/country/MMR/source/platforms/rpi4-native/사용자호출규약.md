# ကိုယ်ပိုင် ARM64 သုံးစွဲသူ စက်မောင်း ABI v1

이 ABI는 `platforms/rpi4-native`의 제한된 freestanding စက်မောင်း 환경이다. Linux AArch64 ABI나 POSIX 전체 구현이 아니다. **OpenJDK/JRE, CPython, libc, libstdc++는 아직 이식되지 않았다.**

ELF 로더는 ဖိုင် 확장자 대신 တကယ့်ဒေတာ ELF 헤더를 검사한다. အောက်ဆုံးတန်ဖိုး ကိုယ်ပိုင် ABI와 별도로 `run --linux FILE`에 제한된 Linux ARM64 တည်ငြိမ်တန်ဖိုး စက်မောင်း ဖိုင် 경로를 추가했다. 두 시스템 ခေါ်လုပ် 번호표를 혼합하지 않는다. [ELF·Linux ABI 매뉴얼](실행파일규약.md).

## ELF와 စက်မောင်း 수명

- ELF64 little endian, ET_EXEC, EM_AARCH64, 버전 1, e_flags=0.
- ပရိုဂရမ် 헤더 အများဆုံးတန်ဖိုး 16개. PT_LOAD는 ဖတ် 가능, 4 KiB ညှိတန်ဖိုး, 페이지 간 အဆင့်ဆင့်ထပ်မှု 없음, filesz≤memsz, စက်ပုံရိပ်တည်ဆောက် လိပ်စာ ဖြတ်နယ်ပယ် 안이어야 한다. W+X는 거부한다.
- 진입점은 ဖိုင် 내용이 있는 စက်မောင်း 세그먼트 안의 4바이트 ညှိတန်ဖိုး 주소다.
- PT_NOTE에 အမည် `JKOROS\0`(namesz=7), type=1, descsz=4, 버전 1의 little endian uint32가 필요하다. SDK의 `start.o`ပထမတွက်ချက်ခံ 넣는다.
- PT_DYNAMIC/PT_INTERP/PT_TLS 등은 거부한다. 동적 재배치·공유 စာကြည့်တိုက်·TLS 로더가 없다.
- 커널에 포함한 ELF 묶음을 검증하고 별도 သုံးစွဲသူ 메모리에 복사한 နောက်တန်ဖိုး EL0로 진입한다. 커널에 함수로 တည်ငြိမ်တန်ဖိုး 링크해 호출하는 ယခင်အချက်အလက်တစ်ခု `cpp_test`와 다르다.
- 내장 프로그램은 `demo.elf`, `fault.elf`의 8개 တန်ဖိုးကာကွယ် စမ်းသပ်မှု နည်းစနစ်တန်ဖိုး, `network.elf`, ကိုယ်ပိုင် Java ကိရိယာစု, MicroPython이다. 셸의 `load`/`run FILE`로 RAM의 16KiB 이하 ELF도 같은 မှန်ကန်ကြောင်းစစ် 경로로 실행한다.
- `_start`ပထမတွက်ချက်ခံ `user_start`를 호출하고 `.init_array` → `သုံးစွဲသူပရိုဂရမ်စတင်(int)` → `.fini_array` 순서로 실행한 နောက်တန်ဖိုး exit 호출을 수행한다. 인수는 ခေါ်လုပ် 15로 읽으며 표준 argc/argv/envp တွက်ချက်ခံထပ်ဆင့်အစု 배치는 없다.
- 한 번에 한 သုံးစွဲသူ 프로그램이 CPU에서 실행된다. 네 터미널에 각 하나씩 အပြန်အလှန် 프로그램을 일시 정지해 보관할 ကိန်းတန်ဖိုး 있다. ဖြစ်သောပုံမှန် ထွက်ပရိုဂရမ်·ခြွင်းချက်·အချိန်တန်ဖိုး 초과 시 커널에 복귀하고 열린 ဖိုင်/소켓을 닫으며 သုံးစွဲသူ 페이지 권한을 제거한다.
- တည်ငြိမ်တန်ဖိုး 생성자와 자동 객체의 RAII 소멸자를 시험했다. `__cxa_atexit`, 표준 C++ ခြွင်းချက်/RTTI/STL, 일반적인 전역 အရာဝတ္ထုတန်ဖိုး ထွက်ပရိုဂရမ် 등록은 제공하지 않는다.

## 주소와 တန်ဖိုးကာကွယ်

| 가상 လိပ်စာ ဖြတ်နယ်ပယ် | 용도 |
|---|---|
| 0x02000000–0x02bfffff | ELF စက်ပုံရိပ်တည်ဆောက်, အများဆုံးတန်ဖိုး 12 MiB |
| 0x02c00000–0x02ecffff | brk ပုံတင်မှတ်ဉာဏ်တန်ဖိုး, အများဆုံးတန်ဖိုး 2880 KiB |
| 0x02ed0000–0x02efffff | 미매핑 စာသားအပိုင်းအခြား/တွက်ချက်ခံထပ်ဆင့်အစု အောက်ဆုံးတန်ဖိုး တန်ဖိုးကာကွယ် စာသားအပိုင်းအခြား |
| 0x02f00000–0x02ffffff | 1 MiB သုံးစွဲသူ တွက်ချက်ခံထပ်ဆင့်အစု |

ကိုယ်ပိုင် JVM의 အတန်းတန်ဖိုး·အရာဝတ္ထုတန်ဖိုး 자료를 수용하도록 သုံးစွဲသူ 창을 16 MiB로 확장했다. ပရိုဂရမ် 헤더의 တန်ဖိုးခွင့်ပြု ဖြတ်နယ်ပယ်, 페이지 ခွင့်ပြုချက်တန်ဖိုး စစ်ဆေးချက်, SDK 링커 အမိန့်စာတမ်းတန်ဖိုး 및 တန်ဖိုးကာကွယ် 시험이 같은 배치를 사용한다. 기존에 brk လုပ်ဆောင် 주소를 상수로 가정한 프로그램은 새 SDK로 ပြန်ကြိုးစား 빌드한다. 일반 프로그램은 ခေါ်လုပ် 8로 လက်ရှိအချက်အလက်တစ်ခု brk를 조회한다.

စက်မောင်း 코드는 EL0 ဖတ်/실행만, ဒေတာ·ပုံတင်မှတ်ဉာဏ်တန်ဖိုး·스택은 EL0 ဖတ်/쓰기만 허용한다. 나머지 အူတိုင်တန်ဖိုး RAM·ကိရိယာ MMIO에는 EL0 권한을 주지 않는다. 이번 W^X 보장은 **သုံးစွဲသူ 페이지에 대한 것**이다. kernel identity map의 전체 ခွင့်ပြုချက်တန်ဖိုး 분할이나 다중 프로세스 လိပ်စာ သတ်မှတ်လိပ်စာနယ် 전환을 구현했다고 의미하지 않는다.

커널은 `-mgeneral-regs-only`로 빌드한다. သုံးစွဲသူ C/C++는 FP/SIMD를 허용하고, သုံးစွဲသူ အချက်အမှတ်တစ်ခုတန်ဖိုး 시 ဗက်တာတန်ဖိုး 레지스터와 FPCR/FPSR를 초기화한다. အူတိုင်တန်ဖိုး 복귀용 callee-saved FP 상태를 보관한다. syscall/IRQ의 C 처리부는 FP 레지스터를 사용하지 않는다. 향후 여러 သုံးစွဲသူ 스레드를 전환할 때에는 각 스레드의 전체 FP ပတ်ဝန်းကျင်အဓိပ္ပာယ်တန်ဖိုး 보존을 별도로 구현해야 한다.

GIC-400의 물리 타이머 IRQ로 약 2초의 စက်မောင်း 기한을 적용한다. SVC 없는 무한 반복도 종료한다. 시스템 ခေါ်လုပ် လုပ်ဆောင် 시 기한을 검사하지만 EL1 လုပ်ငန်းစဉ်တန်ဖိုးအချက် 중에는 IRQ를 마스킹하므로 긴 အထွက်/မျက်နှာပြင်ဆေးခြယ် 호출의 종료는 지연될 ကိန်းတန်ဖိုး 있다. 이것은 ပရိုဂရမ် စက်မောင်း 기한이며 일반 선점 스케줄러가 아니다.

## 시스템 ခေါ်လုပ်

`svc #0`, နံပါတ် x8, အချက်များ x0…x5, ရလဒ် x0. 실패는 အနုတ်တန်ဖိုး အမှား 번호다. `libposix-kor-user.a`는 이를 -1과 `အမှားကိန်း`로 바꾼다. သုံးစွဲသူ 프로그램의 errno는 လက်ရှိအချက်အလက်တစ်ခု 단일 စက်မောင်း 흐름용이며 pthread TLS가 아니다.

미지원 호출은 -ENOSYS이다. 모든 သုံးစွဲသူ 포인터와 해당 페이지의 ဖတ်/ရေး 권한을 확인한다. 파일은 3…18의 프로세스별 서술자를 အူတိုင်တန်ဖိုး 서술자로 변환한다. 0은 လက်ရှိအချက်အလက်တစ်ခု 셸의 표준 ဝင်ဒေတာ(UART 또는 리다이렉션/파이프), 1은 표준 အထွက်(UART/GUI 또는 리다이렉션/파이프), 2는 UART/GUI 진단 출력이다. UART에 읽을 자료가 없으면 -EAGAIN, ဖိုင်/파이프 ဝင်ဒေတာ 끝이면 read가 0을 반환한다. 출력은 ဖိုင်/파이프에서 LF를 그대로 유지하고 UART에서만 CRLF로 표시한다. 파이프는 16 KiB 순차 버퍼이며 프로세스 간 동시 파이프/PTY는 아니다. read/write 요청은 65536바이트 이하이며, RAM 파일은 အများဆုံးတန်ဖိုး 64개, 각각 16384바이트다. ဖိုင် 경로는 လက်ရှိအချက်အလက်တစ်ခု အမိန့်ဝင်း 경로에 대한 တစ်ဖက်တန်ဖိုး လမ်း 또는 `/`로 시작하는 절대 경로이며 UTF-8 63바이트까지다. 디렉터리 ထုတ်လုပ်·빈 ဖိုင်တွဲတန်ဖိုး အချက်ဖယ်ရှား·အမျိုးအစားတန်ဖိုး 조회는 ခေါ်လုပ် 18로도 제공한다. လက်ရှိအချက်အလက်တစ်ခု လမ်း 변경은 အမိန့်ဝင်း 내장 cd가 담당한다. 그래픽 요청은 ခေါ်လုပ် 22로 조회한 တကယ့်ဒေတာ မျက်နှာပြင် အရွယ် 안의 직사각형만 허용한다. 프레임버퍼 လိပ်စာ 자체는 사용자에게 노출하지 않는다.

힙의 페이지 ယူနစ်တန်ဖိုး 축소·재확장에서 ပြန်ကြိုးစား 노출하는 페이지는 0으로 만든다. 같은 페이지 안에서 brk만 줄였다 늘리는 경우에는 해당 페이지 내용이 남을 ကိန်းတန်ဖိုး 있다. malloc/free나 mmap/mprotect의 구현은 아니다.

인수는 အများဆုံးတန်ဖိုး 8개·각 255바이트다. 잘못된 번호는 -EINVAL, 작은 버퍼는 -ENAMETOOLONG, ရေး 불가능한 포인터는 -EFAULT다. `run FILE [ARGS]`는 파일명을 အချက်များ 0으로 포함한다. `javac`/`java`/`python`은 စက်ညွှန်ကြားချက်တန်ဖိုး 자체를 제외한 토큰을 전달한다. 인수는 အူတိုင်တန်ဖိုး တန်ဖိုးထိန်းသိမ်း 자료를 သုံးစွဲသူ 버퍼로 복사하며 အူတိုင်တန်ဖိုး 포인터를 반환하지 않는다.

## UDP 루프백의 계약

바깥 IPv4는 lwIP/SLIP로 확장했다. 기존 fd/구조체/ညွှန်တံ စစ်ဆေးချက် 규약을 유지하며 0.0.0.0 또는 10.0.2.15에 bind한 끝점을 바깥 통신에 연결한다. 127.0.0.1에 명시적으로 bind한 UDP는 루프백에 한정한다. ပြင်ပတန်ဖိုး TCP connect는 비차단 -EINPROGRESS(-115)를 반환할 ကိန်းတန်ဖိုး 있으므로 같은 주소로 재시도하여 완료를 확인한다. [စက်မောင်း/ကန့်သတ်ချက်တန်ဖိုး](ဖိုင်လွှဲပြောင်းနှင့်ဘာသာပြန်မှု.md).

`အင်တာနက်မျိုးစု`, `ဒေတာစာကွန်ရက်ပေါက်`, လွှဲပြောင်းဆက်သွယ်စည်းမျဉ်း 0/`ဒေတာစာဆက်သွယ်စည်းမျဉ်း`을 허용한다. `struct အင်တာနက်ကွန်ရက်ပေါက်လိပ်စာ`는 16바이트이며 주소갈래는 ကိရိယာ အစဉ်လိုက်တန်ဖိုး, 접속번호와 အင်တာနက်လိပ်စာ.주소값은 ကွန်ရက်တန်ဖိုး 차례다. 호환용 pk_sockaddr_in도 같은 배치지만 독립 자료형이다. မြန်မာ 함수는 직접 SVC를 호출하는 တကယ့်ဒေတာ 함수이며 표준 이름으로 치환하는 매크로가 아니다. အိမ်ရှင် Linux 헤더를 섞지 않는다.

- 목적지는 127.0.0.1만 တန်ဖိုးခွင့်ပြု. bind는 0.0.0.0 또는 127.0.0.1, port=0이면 49152…65535에서 빈 창구를 고른다.
- 미바인드 소켓의 ပထမအချက်အလက်တစ်ခု 전송은 ယာယီတန်ဖိုး 창구를 바인드한다. 같은 창구의 중복 bind는 EADDRINUSE.
- အများဆုံးတန်ဖိုး 8개 ကွန်ရက်ပေါက်တန်ဖိုး, 각 큐 4개, 전문은 0…512바이트. 빈 전문도 소비된다.
- တန်ဖိုးလက်ခံရယူ 버퍼가 작으면 복사할 부분만 반환하고 전문의 나머지는 버린다. peer လိပ်စာ/창구를 반환한다.
- flags는 လက်ရှိအချက်အလက်တစ်ခု 0만 ထောက်ပံ့မှုတန်ဖိုး. 비차단 수신의 빈 큐 및 တန်ဖိုးပို့ ဦးတည်ချက်တန်ဖိုး 큐 포화는 EAGAIN이다.
- ဦးတည်ချက်တန်ဖိုး ဆက်သွယ်ပေါက်တန်ဖိုး 없음은 ECONNREFUSED, 512바이트 초과는 EMSGSIZE, 루프백에 명시적으로 바인드한 UDP의 ပြင်ပတန်ဖိုး IP는 ENETUNREACH, UDP 소켓에 잘못된 규약을 지정하면 EPROTONOSUPPORT. SOCK_STREAM은 별도 연결형 루프백에서 제공한다.
- ပြင်ပတန်ဖိုး IPv4 TCP/UDP 헤더·체크섬·재전송은 lwIP가 처리한다. တကယ့်ဒေတာ GENET/Wi-Fi NIC, poll/select, setsockopt는 아직 없다. 연결형 루프백의 connect/listen/accept는 အောက်ဆုံးတန်ဖိုး တိုးချဲ့မှု ABI로 제공한다.

## 커널로 돌아오는 ရလဒ်

Java의 `ဆားကစ်ပြား.သုံးစွဲသူပရိုဂရမ်စက်မောင်း(index)`는 ဖြစ်သောပုံမှန် exit အခြေအနေတန်ဖိုး 0…255 또는 နောက်တစ်ခုအချက်အလက်တစ်ခု 값을 받는다. GUI는 실패를 표시하고 셸을 유지한다.

| တန်ဖိုး | 의미 |
|---:|---|
| -8 | ELF/ABI/လိပ်စာ/ခွင့်ပြုချက်တန်ဖိုး မှန်ကန်ကြောင်းစစ် မအောင်မြင်မှု |
| -16 | သုံးစွဲသူ ပရိုဂရမ် အဆင့်ဆင့်ထပ်မှု စက်မောင်း တန်ဖိုးငြင်းပယ် |
| -22 | 등록되지 않은 ပရိုဂရမ် နံပါတ် |
| -1001 | သုံးစွဲသူ ဒေတာ ဝင်သုံးအချက် ခြွင်းချက် |
| -1002 | သုံးစွဲသူ စက်ညွှန်ကြားချက်တန်ဖိုး ဝင်သုံးအချက် ခြွင်းချက် |
| -1003 | 특권/미지원 အမိန့် 등 သုံးစွဲသူ ခြွင်းချက် |
| -1004 | သုံးစွဲသူ စက်မောင်း 기한 초과 |
| -1005 | အပြန်အလှန် သုံးစွဲသူ ပရိုဂရမ် 일시 လုပ်ဆောင်မှုရပ်; အူတိုင်တန်ဖိုး အမိန့်ဝင်း 전용 ရလဒ် |

이는 완성된 POSIX signal/wait 상태가 아닌 လက်ရှိအချက်အလက်တစ်ခု ကိုယ်ပိုင် 실행기의 진단 규약이다.


## 여러 터미널의 သုံးစွဲသူ ပတ်ဝန်းကျင်အဓိပ္ပာယ်တန်ဖိုး

အပြန်အလှန် tty/GUI 대기를 명시적으로 시작한 프로그램은 ဝင်ဒေတာ 대기에서 약 2초 기한을 갱신한다. တန်ဖိုးစောင့် 없이 무한 반복하면 타이머로 종료한다. 파이프/리다이렉션/복합 အမိန့်/스크립트에서 အပြန်အလှန် 시작은 -ENOTSUP로 거부한다. vi와 Swing의 이벤트 루프가 이 API를 사용한다.

다른 창으로 전환하면 နောက်တစ်ခုအချက်အလက်တစ်ခု တန်ဖိုးစောင့် SVC에서 EL0 문맥을 저장하고 해당 SVC를 재실행할 위치에서 재개한다. x0…x30, SP/PC/PSTATE, v0…v31, FPCR/FPSR, ချိတ်ထားတန်ဖိုး·ပုံတင်မှတ်ဉာဏ်တန်ဖိုး·စက်မောင်း အချက်များ·ဖိုင်/ကွန်ရက်ပေါက်တန်ဖိုး 소유권을 보관한다. 스냅샷은 အူတိုင်တန်ဖိုး 전용 물리 လိပ်စာ 0x04000000…0x07ffffff(네 နေရာကွက်တန်ဖိုး ×16 MiB)에 저장한다. လက်ရှိအချက်အလက်တစ်ခု အလုပ်လုပ်နေ EL0 လိပ်စာ 창은 종전 0x02000000…0x02ffffff를 사용한다. 스냅샷 저장소는 EL0에서 접근할 ကိန်းတန်ဖိုး 없다. fork/exec/wait, SMP 또는 일반 선점형 프로세스 스케줄러의 구현은 아니다.

SVC 40은 소유한 연결형 소켓의 တစ်ဖက်တန်ဖိုး စက်ပစ္စည်းဆက်သွယ်ပေါက် 번호를 반환한다(ကိုယ်ပိုင် JVM용 ကိန်းပြည့် 조회).

연결형 루프백 fd는 40…55, UDP fd는 32…39다. ထွက်ပရိုဂရမ်/အဆုံးသုံးမျက်နှာပြင် X 닫기에서 해당 프로그램의 ဖိုင်·소켓을 회수한다. 연결형 읽기의 ဒေတာ 없음은 -EAGAIN, 상대가 닫고 버퍼도 비면 0, 상대가 닫힌 နောက်တန်ဖိုး 쓰기는 -EPIPE다. 쓰기는 짧게 완료될 ကိန်းတန်ဖိုး 있다. 큐 용량은 끝점마다 1024바이트이고 한 시스템 호출은 အများဆုံးတန်ဖိုး 512바이트를 옮긴다. မိဘတန်ဖိုး 리스너를 닫으면 아직 accept하지 않은 연결도 회수한다. ပြင်ပတန်ဖိုး 연결은 lwIP TCP를 사용하며 ပြင်ပတန်ဖိုး တန်ဖိုးလက်ခံရယူ 버퍼는 4096바이트다. တကယ့်ဒေတာ GENET NIC 드라이버는 없다.

협력 တန်ဖိုးစောင့်(17)는 일반 선점형 sleep/scheduler 구현이 아니다. 호출마다 အများဆုံးတန်ဖိုး 100 ms 동안 통신을 처리하고 သုံးစွဲသူ စက်မောင်း 기한을 갱신한다. အထုပ် 설치기의 비차단 TCP 대기에 사용한다.
