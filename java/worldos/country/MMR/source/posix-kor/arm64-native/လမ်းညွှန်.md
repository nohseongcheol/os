# ကိုယ်ပိုင် ARM64 Java 커널의 C/C++ ဖိုင်·루프백 ချိတ်ဆက်

이 디렉터리는 `platforms/rpi4-native` ကိုယ်ပိုင် အူတိုင်တန်ဖိုး 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`ခေါင်းစီးဖိုင်/파일규약.h`는 မြန်မာ 함수명과 `extern "C"` ABI를 제공한다. `ချိတ်ဆက်.c`는 အူတိုင်တန်ဖိုး 안에서 AOT Java ဖိုင် 메서드에 직접 연결하고, `သုံးစွဲသူတံတား.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. တကယ့်ဒေတာ ဖိုင် 처리는 `မှတ်ဉာဏ်ဖိုင်.java`, 루프백 ဒေတာစာ 처리는 `ပြန်လှည့်ကွန်ရက်.java`, 연결형 흐름은 `စီးကြောင်းဆက်သွယ်မှု.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 အူတိုင်တန်ဖိုး 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`တတိယအော်ပရန်း. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·실수 တွက်ချက်လုပ်ဆောင်မှု·ဖိုင်·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

ထောက်ပံ့မှုတန်ဖိုး: `ဖိုင်ဖွင့်`, `ဖိုင်ဒေတာဖတ်`, `ဖိုင်ဒေတာရေး`, `ဖိုင်ပိတ်`, `ဖိုင်နေရာရွှေ့`, `ဖိုင်အချက်အမည်ဖယ်ရှား`, `ဖိုင်အလျားသတ်မှတ်`, 보조 လုပ်ဆောင်ချက် `ဖိုင်အရွယ်`. အမှား 시 -1과 작업별 `အမှားကိန်း`를 반환한다. `ဖိုင်သိုလှောင်အတည်ပြု`은 RAM 파일이므로 ENOSYS를 반환한다. ဖိုင် 16개, 각 16384바이트, အမည် 63바이트, အညွှန်း 16개이며 RAM 디렉터리·တစ်ဖက်တန်ဖိုး/절대 경로를 제공한다. ခွင့်ပြုချက်တန်ဖိုး/영속 저장은 없다.

사용자용 `ခေါင်းစီးဖိုင်/통신규약.h`는 တကယ့်ဒေတာ မြန်မာ 함수와 독립 구조체를 선언한다.
`အဆုံးမှတ်ဖန်တီး`, `လိပ်စာချည်နှောင်`, `ဒေတာစာဒေတာပို့/လက်ခံ`, `ကွန်ရက်ချိတ်ဆက်/စောင့်/လက်ခံ`는
`သုံးစွဲသူတံတား.c`에서 SVC를 호출하며 매크로 별칭이 아니다. `struct အင်တာနက်ကွန်ရက်ပေါက်လိပ်စာ`의
`လိပ်စာမျိုးစု`, `ဆက်သွယ်ပေါက်ကိန်း`, `အင်တာနက်လိပ်စာ.လိပ်စာတန်ဖိုး`을 사용한다. 상수는 enum의
`အင်တာနက်မျိုးစု`, `ဒေတာစာကွန်ရက်ပေါက်`, `ဒေတာစာဆက်သွယ်စည်းမျဉ်း`, `စီးကြောင်းဆက်သွယ်မှု`, `흐름전송규약`이다.
မြန်မာ·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. ပြင်ပတန်ဖိုး 통신은 ကိုယ်ပိုင် 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. တကယ့်ဒေတာ Pi 4 GENET 드라이버는 미지원이다.
소켓도 တကယ့်ဒေတာ လုပ်ဆောင်ချက် `ဖိုင်ပိတ်`로 닫는다.
