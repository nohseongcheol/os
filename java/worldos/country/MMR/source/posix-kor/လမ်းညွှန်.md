# jkoros posix-kor

**ကိုယ်ပိုင် ARM64 Java 커널용 C++ ချိတ်ဆက်**은 [arm64-native](arm64-native/လမ်းညွှန်.md)에 있다. အူတိုင်တန်ဖိုး 내부 직접 ဖိုင် 호출과 EL0 သုံးစွဲသူ 프로그램의 ဖိုင်/UDP 루프백 SVC 호출을 별도 라이브러리로 제공한다. အောက်ဆုံးတန်ဖိုး i386 စာကြည့်တိုက် 및 ARM64 Linux libc와는 ဦးတည်ချက်တန်ဖိုး·ABI가 다르다.

ကိုယ်ပိုင် jkoros 커널에서 실행되는 i386 C 라이브러리와 မြန်မာ API다. အိမ်ရှင် libc를 연결하지 않고 `int 0x80`으로 တကယ့်ဒေတာ 커널의 ဖိုင်အညွှန်း·အဆုံးသုံးစက်·UDP·သိုလှောင်တန်ဖိုး 계층을 호출한다. `အခြေခံကုဒ်/`의 အိမ်ရှင် JVM 모형과 별개다.

**현재는 POSIX의 일부 기능을 제공하는 호환 계층이며, POSIX 인증·전체 libc·전체 OpenJDK를 뜻하지 않는다.** အကောင်အထည်ဖော်မှု 범위와 제한을 아래에 명시한다. 한국어를 먼저 적용했다. 다른 국가·언어의 번역판은 아직 만들지 않았다.

## 빌드와 စက်မောင်း

```sh
cd /home/user/jkoros
make posix-kor
make iso
make test-posix
make -C os run-store
```

`run-store`는 `os/build/files.img`ပထမတွက်ချက်ခံ 없을 때만 새 전용 파일을 만들고 QEMU IDE ပထမအချက်အလက်တစ်ခု 장치로 연결한다. 기존 파일을 덮어써서 초기화하지 않는다. 일반 `make run`은 디스크 없이 실행된다. VirtualBox 실행기의 디스크 연결은 변경하지 않았다.

부팅된 jkoros에서:

```text
run posixcheck check
run posixstore
cat stored.txt
edit note.txt
hello from jkoros
.save
sync
```

`Sync: 0`은 연결된 전용 매체에 저장했다는 뜻이다. 디스크가 없거나 သတ်မှတ်ပေးတန်ဖိုး 형식이 아니면 `Sync: -19`တတိယအော်ပရန်း. 같은 `files.img`로 ပြန်ကြိုးစား 부팅하면 နောက်ဆုံးအချက်အလက်တစ်ခု တစ်ပြေးညီလုပ် 상태를 복원한다. Java 소스와 `.class`도 같은 သိုလှောင်တန်ဖိုး 대상이다. `close`ဒုတိယတွက်ချက်ခံ 편집기의 `.save`만으로 재부팅 보존을 보장하지 않으므로 ထွက်ပရိုဂရမ် 전에 `sync`를 실행한다.

## 한국어로 C ပရိုဂရမ် 작성

```c
#include <파일규약.h>

int main(int ပေးအချက်များအရေအတွက်, char **ပေးအချက်စာရင်း) {
    (void)ပေးအချက်များအရေအတွက်;
    (void)ပေးအချက်စာရင်း;
    int ဖိုင်အညွှန်း = ဖိုင်ဖွင့်("note.txt", ဖတ်ရေး | 없으면만들기, 0600);
    if (ဖိုင်အညွှန်း < 0) return အမှားကိန်း;
    if (ဖိုင်ဒေတာရေး(ဖိုင်အညွှန်း, "hello\n", 6) != 6) return 1;
    if (ဖိုင်သိုလှောင်အတည်ပြု(ဖိုင်အညွှန်း) < 0) return အမှားကိန်း;
    return ဖိုင်ပိတ်(ဖိုင်အညွှန်း);
}
```

작성 원문은 한글을 그대로 유지한다. `ကိရိယာစု/식별자변환.py`ပထမတွက်ချက်ခံ တည်ဆောက် 복사본의 식별자만 C 표준 UCN 표기로 바꾸어 GCC 7에서도 컴파일되게 한다. အက္ခရာစဉ်, 주석, `#include` 경로는 변환하지 않는다. 이 도구는 C의 모든 전처리 표기법을 해석하는 전처리기가 아니며, 프로젝트가 사용하는 일반 토큰과 include 문법을 대상으로 한다.

라이브러리는 `build/libposix-kor.a`, လုပ်ဆောင် 코드는 `build/သုံးစွဲသူပရိုဂရမ်စတင်.o`, ထုတ်လုပ် 헤더는 `build/မူရင်းကုဒ်/ခေါင်းစီးဖိုင်/`이다. တည်ဆောက် 옵션과 ချိတ်ဆက် 명령은 [Makefile](Makefile), တကယ့်ဒေတာ 예제는 [파일규약시험.c](မူရင်းကုဒ်/စမ်းသပ်မှု/파일규약시험.c)와 [ဒေတာစာစမ်းသပ်.c](မူရင်းကုဒ်/စမ်းသပ်မှု/ဒေတာစာစမ်းသပ်.c)에 있다. 새 ELF를 OS에 포함하려면 `os/Makefile`의 သုံးစွဲသူ စက်မောင်း 묶음에 명시적으로 등록한다. 게스트 안에서 C를 컴파일하는 도구는 제공하지 않는다.

표준 C/POSIX ပြင်ပတန်ဖိုး အမည် `open`, `read`, `write`, `socket`, `errno`, `main`과 헤더 경로는 유지한다. မြန်မာ 별칭은 같은 함수를 가리킨다. 변수와 အကောင်အထည်ဖော်မှု 파일에는 의미를 드러내는 မြန်မာ 이름을 사용한다. မူရင်းကုဒ်ဘာသာပြန်ဆို 근거는 [명명 원칙](명명원칙.md), တကယ့်ဒေတာ 대응은 [용어 대응표](용어대응.tsv)에 기록했다.

## 제공하는 기능

| ဖြတ်နယ်ပယ် | အကောင်အထည်ဖော်မှု | လက်ရှိအချက်အလက်တစ်ခု ကန့်သတ်ချက်တန်ဖိုး |
|---|---|---|
| ဖိုင် | open/creat/read/write/close/lseek/unlink/ftruncate/fstat/fsync | 루트의 단일 အမည်, ASCII 63바이트, 8개 ဖိုင်, 파일당 16KiB |
| အညွှန်း | dup/dup2, F_DUPFD/F_DUPFD_CLOEXEC/F_GETFD/F_SETFD/F_GETFL/F_SETFL | လုပ်ငန်းစဉ် တစ်တန်ဖိုး, အများဆုံးတန်ဖိုး 32개; သော့ခတ်တန်ဖိုး·exec 미구현 |
| အဝင်အထွက် သတ်မှတ်ချက် | O_RDONLY/O_WRONLY/O_RDWR/O_CREAT/O_EXCL/O_TRUNC/O_APPEND/O_NONBLOCK/O_CLOEXEC | 그 밖의 비트는 ENOTSUP; တကယ့်ဒေတာ သုံးစွဲသူ·그룹 ဝင်သုံးအချက် ခွင့်ပြုချက်တန်ဖိုး 검사는 없음 |
| 표준 အဆုံးသုံးစက် | 0 ဖတ်, 1·2 ရေး, ဘိုက်တန်ဖိုး ယူနစ်တန်ဖိုး ဝင်ဒေတာ | အဆုံးသုံးမျက်နှာပြင် တည်းဖြတ်တန်ဖိုး·termios·시그널 없음, ဟန်ဂုစာသား စာလုံးပုံစံတန်ဖိုး/입력기 없음 |
| UDP | socket/bind/sendto/recvfrom/getsockname, SO_RCVTIMEO | IPv4 UDP만, 묶인 အဆုံးမှတ်တန်ဖိုး 4개, 전문당 1,024바이트, တန်ဖိုးလက်ခံရယူ တန်ဖိုးစောင့် သတ်မှတ်ချက် အများဆုံးတန်ဖိုး 2초 |
| လိပ်စာ | htons/ntohs/htonl/ntohl/inet_pton/inet_ntop | IPv4 ဂဏန်းတန်ဖိုး 주소만; DNS/IPv6 없음 |
| 작은 C ထောက်ပံ့မှုတန်ဖိုး | strlen/strcmp/memcpy/memset/memcmp/puts/putchar | 전체 libc·stdio FILE·malloc 없음 |
| သိုလှောင်တန်ဖိုး | JKSTORE1 전용 IDE သိုလှောင်တန်ဖိုး, 두 보존본과 စစ်ဆေးပေါင်းလဒ် | FAT/ext ဖိုင်စနစ်·디렉터리·하드 링크·심볼릭 링크 없음 |
| 게스트 Java | FileInputStream(String).read()/close(), FileOutputStream(String[, boolean]).write(int)/close() | အခင်းအကျင်းတန်ဖိုး အဝင်အထွက်·일반 java.io·ခြွင်းချက် လုပ်ငန်းစဉ်တန်ဖိုးအချက် 없음 |

`dup`으로 복제한 서술자는 ဖိုင် 위치와 ဆက်လက်ဖြည့်ရေး 설정을 공유한다. `FD_CLOEXEC`는 서술자마다 저장한다. `unlink`는 이름만 제거하며, 열린 파일의 내용은 နောက်ဆုံးအချက်အလက်တစ်ခု 참조가 닫힐 때까지 접근할 ကိန်းတန်ဖိုး 있다. 빈 위치를 건너뛰어 쓰거나 길이를 늘린 영역은 0으로 읽힌다. ဖိုင်အညွှန်း 부족으로 실패한 `open`은 파일을 생성하거나 비우지 않는다. C ခေါ်လုပ် 실패는 `-1`과 `errno`, 내부 အူတိုင်တန်ဖိုး 호출은 အနုတ်တန်ဖိုး အမှား 번호를 반환한다.

`fstat`는 이 프로젝트 전용 48바이트 구조체에 အမျိုးအစားတန်ဖိုး·အရွယ်·링크 ကိန်းတန်ဖိုး·ခွင့်ပြုပေး ဘစ်တန်ဖိုး 등을 반환한다. POSIX의 전체 အချိန်တန်ဖိုး 속성은 아직 제공하지 않는다. 다른 운영체제의 `struct stat` 또는 Linux 바이너리 ABI와 호환되지 않는다. `O_CLOEXEC`는 기록할 ကိန်းတန်ဖိုး 있지만 လက်ရှိအချက်အလက်တစ်ခု exec 기능은 없다. 성공하는 လုပ်ဆောင်ချက် 이름만으로 전체 POSIX 의미가 구현되었다고 간주하면 안 된다.

UDP는 QEMU RTL8139의 တကယ့်ဒေတာ အိမ်ရှင် 왕복을 지원한다. 짧은 တန်ဖိုးလက်ခံရယူ 버퍼에는 앞부분을 복사하고 나머지 전문을 버린다. 빈 전문도 송수신한다. `SO_RCVTIMEO` 또는 비차단 수신의 ဒေတာ 없음은 `EAGAIN`이다. TCP를 요청하면 `EPROTONOSUPPORT`를 반환한다. 루프백·브로드캐스트·멀티캐스트·연결형 ကွန်ရက်ပေါက်တန်ဖိုး·listen/accept는 아직 없다. 기존 AOT Java UDP 손잡이는 이 POSIX 서술자와 별개이므로 서로 섞어 닫지 않는다.

모든 သုံးစွဲသူ 프로그램에는 기존 약 3초 စက်မောင်း 상한이 적용된다. `errno`는 လက်ရှိအချက်အလက်တစ်ခု 단일 လုပ်ငန်းစဉ်·단일 스레드 변수다. JDK 전체, Swing/AWT/JavaFX, TCP/DNS/HTTP/TLS, 스레드·GC·JIT·동적 연결은 아직 구현하지 않았다. 전체 Java SE စက်မောင်း 환경을 만들려면 해당 အူတိုင်တန်ဖိုး 기반과 런타임 이식을 ဆက်လုပ်လုပ်ငန်းစဉ်ဆောင်ရွက်မှု 진행하거나 별도 Linux 기반 စက်မောင်း 방식을 결정해야 한다.

## သိုလှောင်တန်ဖိုး 형식과 မှန်ကန်ကြောင်းစစ်

매체는 512바이트 ကဏ္ဍတန်ဖိုး 2,048개(1MiB)တတိယအော်ပရန်း. ကဏ္ဍတန်ဖိုး 0의 `JKSTORE1` သတ်မှတ်နံပါတ်တန်ဖိုး·အရွယ်·ပုံစံတန်ဖိုး 번호가 အားလုံးတည်ဆောက် 맞는 장치만 ရေး 대상으로 삼는다. ကဏ္ဍတန်ဖိုး 1과 260에서 각각 259구역짜리 보존본이 시작한다. 각 보존본은 ဖြစ်သောအပြည့်အစုံ ဦးခေါင်းတန်ဖိုး 1구역, ဖိုင် ဇယား 2구역, ဖိုင် ဒေတာ 256구역으로 구성된다.

`fsync`와 `sync`는 이름이 남아 있는 모든 파일의 လက်ရှိအချက်အလက်တစ်ခု 상태를 저장한다. 반대편 보존본을 무효화한 နောက်တန်ဖိုး ဖိုင် 표와 자료를 쓰고 ATA 캐시 비우기를 실행한다. 마지막에 မျိုးဆက်တန်ဖိုး 번호와 FNV-1a 검사합을 가진 ဖြစ်သောအပြည့်အစုံ 머리를 기록하고 ပြန်ကြိုးစား 캐시를 비운다. စက်တင် 시 검사합과 표가 유효한 가장 မကြာသေးမီတန်ဖိုး 세대를 선택한다. 검사합은 우발적인 손상을 အချက်ရှာ 위한 것이며 암호학적 무결성 검증은 아니다. တကယ့်ဒေတာ ကိရိယာ 전원 차단 시험은 하지 않았다.

복원된 ဖိုင် 목록은 စက်တင် 이미지의 မူလသတ်မှတ်တန်ဖိုး ဥပမာ/`JAVA_FILES` 목록을 대체한다. 새 예제를 이미지에 추가해도 기존 သိုလှောင်တန်ဖိုး 매체를 연결하면 저장된 목록이 우선한다. 동기화하지 않은 변경은 재부팅 후 사라진다.

`make test-posix`는 မြန်မာ သတ်မှတ်နံပါတ်တန်ဖိုး တန်ဖိုးပြောင်းလဲ, ELF/ISO의 တကယ့်ဒေတာ C ABI ခေါ်လုပ်, 공유 နေရာ, 삭제된 파일의 수명, ဖိုင်/အညွှန်း 고갈, ညွှန်တံ အမှား, 표준 ဝင်ဒေတာ, UDP, `fsync`, 재부팅, 손상된 최신 보존본의 회피, 다른 형식의 매체 비변경, 게스트 Java ဖိုင် 처리와 OpenJDK 교차 실행을 확인한다. 기록은 `os/build/စည်းမျဉ်းစမ်းသပ်.json`, `ထိန်းသိမ်းမှုစမ်းသပ်.json`, `Javaဖိုင်စမ်းသပ်.json`이다.
