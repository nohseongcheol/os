# JMmrOS ဖွဲ့စည်းပုံ

아래는 အရာဝတ္ထုတန်ဖိုး 기반 관리 အူတိုင်တန်ဖိုး 전체의 ဦးတည်ချက်အရာဝတ္ထု 구조다. လက်ရှိအချက်အလက်တစ်ခု တကယ့်ဒေတာ စက်တင် 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 စက်စနစ် လမ်းညွှန်](../os/လမ်းညွှန်.md)에 အကောင်အထည်ဖော်မှု 범위를 명시한다. 아래의 GC·ပတ်ဝန်းကျင်အဓိပ္ပာယ်တန်ဖိုး အလှည့်ပြောင်းနည်းစနစ်·ဖိုင်စနစ် 등이 새 ISO에 အားလုံးတည်ဆောက် 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 အနည်းဆုံးတန်ဖိုး 부트·트랩 အလွှာတန်ဖိုး
  ↓
Java AOT 실행기와 အရာဝတ္ထုတန်ဖိုး·အခင်းအကျင်းတန်ဖိုး·GC 런타임
  ↓
စက်ပစ္စည်း နယ်နိမိတ်တန်ဖိုး
  ↓
Java 관리 အူတိုင်တန်ဖိုး
  ├─ မှတ်ဉာဏ်နယ်ပယ်/စာမျက်နှာစီမံမှု/COW
  ├─ လုပ်ငန်းစဉ်/배정/wait
  ├─ ဖိုင်စနစ်/ELF/POSIX
  └─ ဝင်ဒေတာ/သိုလှောင်ကိရိယာ/ကွန်ရက်အလွှာစု
```

OpenJDK 자체는 이미 운영체제가 제공하는 ဖိုင်, 스레드, 가상 기억공간을 전제로 한다. 따라서 အူတိုင်တန်ဖိုး 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java ဘိုက်ကုဒ် AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, ပတ်ဝန်းကျင်အဓိပ္ပာယ်တန်ဖိုး 저장처럼 Java로 표현할 ကိန်းတန်ဖိုး 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
