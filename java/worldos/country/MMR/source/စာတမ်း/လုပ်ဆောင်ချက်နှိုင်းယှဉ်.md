# engos 기능 대응표

이 표는 기존 `အခြေခံကုဒ်/`의 အရာဝတ္ထုတန်ဖိုး 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [တကယ့်ဒေတာ စက်တင် 기능과 နယ်နိမိတ်ကန့်သတ်ချက်](../os/လမ်းညွှန်.md)를 따로 기록한다.

## Java 관리 အလွှာတန်ဖိုး အကောင်အထည်ဖော်မှု ဖြစ်သောအပြည့်အစုံ

| engos နယ်ပယ်တန်ဖိုး | JMmrOS အကောင်အထည်ဖော်မှု |
|---|---|
| memorymanager, phymem | `မှတ်ဉာဏ်စီမံသူ` ညှိတန်ဖိုး သိုလှောင်ရာခွဲဝေ·သိုလှောင်ရာလွှတ်ပေး·병합 |
| paging, virtmem | `စာမျက်နှာစီမံသူ` လိပ်စာ သတ်မှတ်လိပ်စာနယ်·စာမျက်နှာတန်ဖိုး ချိတ်ဆက်·COW·개인 ရေး |
| gdt, tss | `အများသုံးအညွှန်းဇယား`, `အလုပ်အခြေအနေအပိုင်း` |
| interrupt | `ကြားဖြတ်စီမံသူ` ကိုင်တွယ်သူစာရင်းသွင်း·ဖွင့်သုံး·တန်ဖိုးဖြန့်ဝေ |
| process, scheduler, thread | `လုပ်ငန်းစဉ်`, `အလှည့်ခွဲဝေသူ` PID·fork·wait·အခြေအနေတန်ဖိုး အလှည့်ပြောင်းနည်းစနစ် |
| systemcall/POSIX 1단계 | ဖတ်·ရေး·ဖွင့်·ပိတ်·seek·dup·fcntl·ဝင်သုံးအချက်·작업목록·သုံးစွဲသူ/무리 ID·တစ်ပြေးညီလုပ်·brk·fork·wait·exec·stat·uname 의미 |
| ATA | `အဆင့်မြင့်သိုလှောင်ဆက်သွယ်ကိရိယာ` 512바이트 ကဏ္ဍတန်ဖိုး ဖတ်·ရေး |
| MSDOS partition | `အဓိကအပိုင်းခြားမှုဇယား` MBR 검증과 네 အချက်တန်ဖိုး တန်ဖိုးသဒ္ဒါခွဲခြမ်း |
| FAT 공개 ဖိုင် အလွှာတန်ဖိုး | `ဖိုင်စနစ်`, `ဖိုင်အညွှန်းဇယား` ဖတ် 전용 파일과 과정별 FD |
| ELF | ELF32 စစ်ဆေးချက်, ကဏ္ဍတန်ဖိုး ဖြတ်နယ်ပယ် စစ်ဆေးချက်, 적재, NOBITS သုညတွက်ချက်ခံ အစပြင်ဆင်, လုပ်ဆောင် လိပ်စာ·သတ်မှတ်အချက်ပေးအချက်·ဝန်းကျင် 반영 |
| keyboard, mouse | `အဝင်စီမံသူ`의 손실 계수 ခေါင်းစီးဖိုင် ဖြစ်ရပ် 대기열 |
| timer | `နာရီ` 틱과 အချိန်တန်ဖိုး တန်ဖိုးပြောင်းလဲ |
| PCI | `အရံဒေတာလမ်းစီမံသူ` 검색 결과와 ကိရိယာ ရွေးချယ်မှုတန်ဖိုး |
| VGA/text mode | `စာသားမျက်နှာပြင်` 80x25 출력과 스크롤 |
| Ethernet/ARP/IPv4/ICMP/UDP/TCP | `ကွန်ရက်ကိရိယာ`, `ကွန်ရက်အလွှာ` ဘောင်အညွှန်းကိန်း စစ်ဆေးချက်·စစ်ဆေးပေါင်းလဒ်·သဘောတူစည်းမျဉ်းတန်ဖိုး/စက်ပစ္စည်းဆက်သွယ်ပေါက် တန်ဖိုးဖြန့်ဝေ |

## 기존 အရာဝတ္ထုတန်ဖိုး 기반 관리 အူတိုင်တန်ဖိုး 전체를 부팅하기 위해 남은 ချိတ်ဆက်

နောက်တစ်ခုအချက်အလက်တစ်ခု 항목은 Java 문법만으로 실행할 ကိန်းတန်ဖိုး 없는 CPU/ကိရိယာ 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot အချက်အမှတ်တစ်ခုတန်ဖိုး, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 ပတ်ဝန်းကျင်အဓိပ္ပာယ်တန်ဖိုး သိုလှောင်တန်ဖိုး
- တကယ့်ဒေတာ PIC/PIT/PS2/ATA/PCI စက်ပစ္စည်းဆက်သွယ်ပေါက် 및 AMD PCnet DMA ထပ်ခါလည်ပတ်မှုတန်ဖိုး
- Java အရာဝတ္ထုတန်ဖိုး·အခင်းအကျင်းတန်ဖိုး နေရာချထားပုံ, ခြွင်းချက်, တည်ငြိမ်တန်ဖိုး အစပြင်ဆင်, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT အဆင့်ကာလတန်ဖိုး
- FAT 디스크 구역을 တကယ့်ဒေတာ ATA 장치와 연결하는 အဝင်အထွက် 접착 အလွှာတန်ဖိုး

ထိပ်တန်ဖိုး 관리 계층은 engos 기능의 Java 관리 구현과 အိမ်ရှင် 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot အချက်အမှတ်တစ်ခုတန်ဖိုး, တည်ငြိမ်တန်ဖိုး အစပြင်ဆင်·ကိန်းပြည့် အခင်းအကျင်းတန်ဖိုး, VGA/အစဉ်ဆက်တန်ဖိုး/PS2, အမိန့်အဓိပ္ပာယ်ဖော်, သုံးစွဲသူ ELF/ring 3/시스템 ခေါ်လုပ်, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 အိမ်ရှင် 루프백 패킷 왕복을 검증했다. ထိပ်တန်ဖိုး 표의 အရာဝတ္ထုတန်ဖိုး 기반 관리 기능 전체나 VirtualBox ကွန်ရက်ဆက် 실행까지 검증했다는 뜻은 아니다.
