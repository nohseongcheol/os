# 전체 ထောက်ပံ့မှုတန်ဖိုး 요청의 လက်ရှိအချက်အလက်တစ်ခု အခြေအနေတန်ဖိုး

တောင်းဆိုချက် 전체는 아직 완료되지 않았다. လက်ရှိအချက်အလက်တစ်ခု ISO는 ကိုယ်ပိုင် Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 တကယ့်ဒေတာ C POSIX 일부 기능, မြန်မာ API/မူရင်းကုဒ် အမည်, IDE ဖိုင် 보존, 게스트 Java ဖိုင် 흐름을 구현하고 시험했다. [구현과 နယ်နိမိတ်ကန့်သတ်ချက်](../posix-kor/လမ်းညွှန်.md)를 기준으로 판단한다.

| တောင်းဆိုချက် 분야 | လက်ရှိအချက်အလက်တစ်ခု စက်မောင်း 가능한 ဖြတ်နယ်ပယ် | 전체 지원에 필요한 အလုပ် |
|---|---|---|
| Java မူရင်းကုဒ်ဘာသာပြန်·စက်မောင်း | 게스트 제한형 javac/JVM, တည်ငြိမ်တန်ဖိုး 단일 클래스와 일부 표준 အရာဝတ္ထုတန်ဖိုး | 일반 အရာဝတ္ထုတန်ဖိုး·အတန်းတန်ဖိုး ချိတ်ဆက်·ခြွင်းချက်·GC·스레드, 완전한 javac와 표준 အတန်းတန်ဖိုး စာကြည့်တိုက် |
| ဖိုင် | POSIX အညွှန်း, Java 단일 ဘိုက်တန်ဖိုး ဖိုင် စီးကြောင်းတန်ဖိုး, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·ခွင့်ပြုချက်တန်ဖိုး·သော့ခတ်တန်ဖိုး·일반 ဖိုင်စနစ်·တိုးချဲ့မှု 가능한 ဆံ့ပမာဏ |
| ကွန်ရက်ဆက် | AOT Java와 POSIX C의 IPv4 UDP အိမ်ရှင် 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, အချက်နောက်တွဲ NIC |
| GUI·Swing | VGA အက္ခရာ အဆုံးသုံးစက် | 프레임버퍼·ဝင်ဒေတာ ဖြစ်ရပ်·စာလုံးပုံစံတန်ဖိုး·ဝင်း လည်ပတ်မှုစနစ်တန်ဖိုး, AWT 네이티브 연결과 Swing စက်မောင်း 기반 |
| POSIX | 문서화한 ဖိုင်·အဆုံးသုံးစက်·UDP အစိတ်အပိုင်းတန်ဖိုး | လုပ်ငန်းစဉ်·exec/fork·스레드·시그널·အချိန်တန်ဖိုး·mmap·poll·파이프 등과 적합성 မှန်ကန်ကြောင်းစစ် |
| 언어별 အမည် | မြန်မာ 46개 ချိတ်ဆက်ပုံတန်ဖိုး အချက်တန်ဖိုး, တကယ့်ဒေတာ C/Java/ဖိုင် အမည် 적용 | ဦးတည်ချက်တန်ဖိုး ဘာသာစကား 확정, 언어별 용례·역사 근거와 해당 မူရင်းကုဒ်·도구의 မှန်ကန်ကြောင်းစစ် |

ကိုယ်ပိုင် 커널을 유지하면 ထိပ်တန်ဖိုး 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 စက်မောင်း 환경을 추가하는 방식은 별도의 အူတိုင်တန်ဖိုး·루트 ဖိုင်စနစ်·OpenJDK·그래픽 ဝန်ဆောင်စက်တန်ဖိုး·영구 သိုလှောင်တန်ဖိုး 구성을 가진 စက်မောင်း 경로가 된다. 후자는 기존 ကိုယ်ပိုင် 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

စက်မောင်း 기반과 အချက်နောက်တွဲ ဦးတည်ချက်တန်ဖိုး 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. လက်ရှိအချက်အလက်တစ်ခု 원문과 စမ်းသပ်မှု 결과를 후속 구현의 출발점으로 보존한다.
