# Raspberry Pi 4 자체 Java jezgro_VALUE — korisnik Izvrši_komanda 기반

aktuelno_stavka 자체 코드의 COSL 상업 stanje, 제3자 고지 및 LGPL 재연결 자료는 [COSL 배포 안내](COSL배포안내.md)를 참고한다. SWITCH_MODE 전 GPL 구성의 판단은 [이전 라이선스 검토](licenca_komentar.md)에 기록했다.

한국어 통신·izuzetak 사용법은 [한국어 Java API](한국어자바/안내.md), FUNCTION_VALUE·promenljiva_VALUE·Datoteka 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

Linux 없이 부팅하는 자체 AArch64 커널이다. Java AOT jezgro_VALUE 위에 **komandna_linija ljuska, 게스트 Java kompajler·JVM, MicroPython, EL0 C++ Izvrši_komanda, Datoteka·UDP 루프백 시스템 호출, 여러 한글 GUI Terminal·vi Uređivač·Swing 부분집합**을 제공한다. 커널의 Datoteka podaci/정책·루프백 prenos_VALUE·ljuska 상태는 Java, 화면 합성·piksel promeniti_VALUE·pokazivač·클리핑도 Java로 구현하며, CPU/MMU/uređaj_VALUE 경계와 Terminal·znak_VALUE 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 자체 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 Izvrši_komanda, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 žični_VALUE 송수신은 아직 미검증이다.** Izvrši_komanda·veza_e05f319b·lozinka_VALUE 확인은 [spoljni_VALUE veza_e05f319b 안내](spoljni_veza_vodič.md)에 정리했다.

셸은 EL1 jezgro_VALUE, `java` 등 korisnik Izvrši_komanda 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 Izvrši_komanda·veza_e05f319b 방법 및 stvarni_podaci 검증은
[Izvrši_komanda 계층과 spoljni_VALUE 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 stvarni_podaci Izvrši_komanda 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 정적 ELF는 `run --linux ime_datoteke_SMS`으로 실행한다. [ELF·Linux ABI Podrška_VALUE 범위와 동일 바이너리 시험](실행파일규약.md).

GUI와 네트워크는 `python3 Alatke/Izvrši_komanda.py --desktop --network`로 함께 사용한다. Java·C·Python의 한국어 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 부팅 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 수 있다. Remmina에서 **F9/Shift+Space/한·nula_operand Ključ_VALUE**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·stvarni_podaci TCP/UDP·Datoteka bajt_VALUE·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java 창예제`로 한국어 Swing 예제를 실행한다. Terminal 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 aktuelno_stavka COLUMN_VALUE·ROW_VALUE 수를 보여 준다.

## aktuelno_stavka 컴퓨터에서 Izvrši_komanda

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

Izađi_program: **Ctrl+A Dalje_stavka X**. 게스트 C/AOT Alatke 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. host 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. kompajler 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/putanja/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` Podrška_VALUE 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 Izvrši_komanda**한다. 기존 한 znak_VALUE 명령도 Enter가 필요하다.

```text
javac Hello.java

ls

net test

```

```java
public class 인사 { public static void main(String[] args) { int VALUE = 7; System.out.println("한글=" + VALUE); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 인사.java`, `java 인사`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. Otkaži_operacija·잘못된 16진수·kapacitet_VALUE 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, Izvrši_komanda 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 komanda 인수는 최대 32개다. Citat·백슬래시·ljuska promenljiva_VALUE·파이프·리다이렉션 범위는 [ljuska 설명](ljuska_I_Terminal.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, adresa **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode 입력·명시적 nalepiti_VALUE·Izvrši_komanda 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 Alatke/Izvrši_komanda.py --desktop --network
# 다른 포트: python3 Alatke/Izvrši_komanda.py --desktop --port 5903
```

종료는 실행한 host 터미널에서 Ctrl+C다. 기존 `python3 Alatke/Izvrši_komanda.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. stvarni_podaci Pi4 USB 입력기는 아직 없으며, VNC veze 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 stvarni_podaci C++/UDP ELF Izvrši_komanda, `Hello.java` kompajlirati_izvor 후 JVM Izvrši_komanda, `hello.py` Izvrši_komanda, GUI Terminal 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 대화형 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 Memorija_podaci·CPU 문맥을 보관한다. ljuska·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

이미지는 확인된 공식 Pi 부팅 묶음에서 `start4.elf`, `fixup4.dat`, Pi4 DTB와 disable-bt overlay를 가져온다. Linux kernel/initramfs/rootfs는 넣지 않는다. 펌웨어·MicroPython·Terminal font_VALUE 라이선스와 font_VALUE 출처 해시도 동봉한다. Datoteka generisati 스크립트는 물리 디스크에 기록하지 않는다.

예비 microSD에 verzija_IMAGE LOG_snimi 도구로 `.img`를 기록하거나 FAT32 부팅 파티션 최상위에 ZIP 내용을 푼다. verzija_IMAGE 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 podrazumevana_vrednost EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD Datoteka 구성·jezgro_VALUE 체크섬 검사와 물리 Tabla 부팅 검증은 별개다. MMU koristiti_VALUE 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 부팅 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

```sh
python3 compile.py examples/파일예제.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int START_korisnik_program(int)`이다. korisnik C++는 FP/SIMD를 사용할 수 있다. jezgro_VALUE C/Java AOT는 일반 레지스터만 사용하므로 izuzetak Proces_VALUE_stavka 중 korisnik FP 상태를 건드리지 않는다. korisnik stavka_p_VALUE 시 FP 상태를 초기화하고 jezgro_VALUE 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int START_korisnik_program(int) {
    int Datoteka = otvoren_Datoteka("인사.txt", za_čitanje_pisanje | 없으면만들기 | 내용비우기, 0600);
    if (Datoteka < 0) return 1;
    const char Sadržaj_VALUE[] = "안녕하세요";
    int KR = 파일자료쓰기(Datoteka, Sadržaj_VALUE, sizeof(Sadržaj_VALUE) - 1);
    Zatvori_Datoteka(Datoteka);
    return KR == sizeof(Sadržaj_VALUE) - 1 ? 0 : 2;
}
```

[Datoteka 예제](korisnik/파일예제.cpp)와 [통신 예제](korisnik/통신예제.cpp)가 stvarni_podaci 부팅 시험 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 Datoteka Proces_VALUE_stavka 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 소켓 함수는 aktuelno_stavka 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 jezgro_VALUE 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 Dalje_stavka 도구를 사용하면 **새 QEMU를 부팅해 업로드한 stvarni_podaci 바이트를 재확인한 NAZAD_VALUE 게스트에서 Izvrši_komanda**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 Alatke/Izvrši_Datoteka.py build/jkoros-native-sdk/demo.elf
python3 Alatke/Izvrši_Datoteka.py 예제/Hello.java "한글 인수"
python3 Alatke/Izvrši_Datoteka.py 예제/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 jezgro_VALUE 묶음에 포함되어 이 Datoteka 한도를 적용받지 않는다. **C++ 컴파일러는 host SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 biblioteka, PT_TLS, PT_INTERP, PT_DYNAMIC, Izvrši_komanda·쓰기 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 INDEX·adresa klip·오류는 [korisnik ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `izvršavanje_skladište_datoteka`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 dozvola_VALUE·dup/fcntl은 없다. 디렉터리와 ravnopravni_uređaj_VALUE/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, primiti_VALUE 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. korisnik Izađi_program 시 열린 Datoteka 서술자와 소켓을 회수한다.

## Java와 Python의 정확한 klip

자체 `javac`는 버전 49 `.class`를 생성하며 JVM은 Podrška_VALUE 명령으로 구성된 버전 45–52 클래스를 실행한다. 정적 FUNCTION_VALUE·재귀·int/boolean/char/String·stanje/sprint_VALUE·niska_VALUE 결합과 일부 Datoteka 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/조합 자모 식별자를 처리한다. Unicode identifikator_VALUE 전체 LOOKUP_tabela·Unicode izvor_stablo 이스케이프는 구현하지 않았다. 게스트 izvor_stablo 컴파일러는 일반 objekat_VALUE·izuzetak·Thread 구문을 아직 컴파일하지 못한다. host `javac --release 8`로 만든 Podrška_VALUE 부분집합 클래스는 자체 JVM 0.4의 objekat_VALUE·izuzetak·Thread·UDP와 한국어 API를 사용할 수 있다. Swing은 문서화한 자체 API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [자체 JVM 설명](자바실행환경.md)이 기준이다. 상세 jezik 범위는 [공유 Java Alatke 설명](../../문서/자바개발환경.md)을 참고하되, 그 문서의 x86 ljuska/Store_VALUE/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 izvor_stablo**를 자체 AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 FUNCTION_VALUE·Razred_VALUE·izuzetak·리스트/rečnik·Unicode·GC·가변 preciznost_VALUE 정수를 제공한다. aktuelno_stavka 구성은 ceo_broj 빌드로 `float`, `complex`, `math`가 없으며 CPython 전체 표준 biblioteka, pip, subprocess, threading, 일반 socket과 podrazumevana_vrednost `open()` Datoteka 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 objekat_VALUE·모듈은 Izađi_program 시 회수되고 RAM 파일만 Dalje_stavka 실행에 남는다.

`import jkoros`로 Dalje_stavka 시스템 연결을 쓴다. 모두 SVC를 통해 자체 Java 커널에 접근한다.

| FUNCTION_VALUE | radnja |
|---|---|
| `stdin(limit)` | aktuelno_stavka 표준 입력에서 최대 limit바이트(0…16384)를 bytes로 읽음; EOF는 빈 bytes, UART podaci 없음은 OSError(11) |
| `read(name)` | ravnopravni_uređaj_VALUE/절대 RAM 경로의 Datoteka 전체를 bytes로 읽음 |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 Store_VALUE, 쓴 bajt_VALUE 수 vratiti_KR |
| `remove(name)` | RAM Datoteka 삭제 |
| `rect(x, y, w, h, color)` | 선택한 stvarni_podaci 화면 promeniti_veličinu 안의 사각형 crtež_VALUE; 기존 보드의 RGB32 VALUE |
| `ticks_ms()` | 부팅 후 밀리초, 32비트 Ciklus_VALUE |
| `udp_open(port)` | 127.0.0.1의 UDP 소켓 otvoren/povezati_učesnik; 0은 자동 포트 |
| `udp_send(fd, port, data)` | 루프백 odredište_VALUE 포트에 str/bytes 버퍼 prenos_VALUE |
| `udp_recv(fd)` | `(bytes, 보낸포트)` vratiti_KR; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | 소켓 Zatvori |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```
