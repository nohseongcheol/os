# 자체 ARM64 Java 커널의 C/C++ Datoteka·루프백 veze

이 디렉터리는 `platforms/rpi4-native` 자체 jezgro_VALUE 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 한국어 함수명과 `extern "C"` ABI를 제공한다. `veze.c`는 jezgro_VALUE 안에서 AOT Java Datoteka 메서드에 직접 연결하고, `korisnik_most.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. stvarni_podaci Datoteka 처리는 `Memorija_Datoteke.java`, 루프백 datagram 처리는 `kružni_tok_podataka_Mreža.java`, 연결형 흐름은 `tok_Mreža.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 jezgro_VALUE 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·plutajući_p_VALUE operacija_VALUE·Datoteka·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

Podrška_VALUE: `otvoren_Datoteka`, `파일자료읽기`, `파일자료쓰기`, `Zatvori_Datoteka`, `tražiti_Datoteka`, `ukloniti_Datoteka_stavka_ime`, `파일길이정하기`, 보조 FUNCTION_VALUE `veličina_datoteke`. greška 시 -1과 작업별 `broj_greške`를 반환한다. `izvršavanje_skladište_datoteka`은 RAM 파일이므로 ENOSYS를 반환한다. Datoteka 16개, 각 16384바이트, ime 63바이트, 서술자 16개이며 RAM 디렉터리·ravnopravni_uređaj_VALUE/절대 경로를 제공한다. dozvola_VALUE/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 stvarni_podaci 한국어 함수와 독립 구조체를 선언한다.
`Create_učesnik`, `povezati_adresa`, `poslati_datagram_podaci/primiti`, `veze_Mreža/기다리기/primiti`는
`korisnik_most.c`에서 SVC를 호출하며 makro_VALUE 별칭이 아니다. `struct 인터넷통신주소`의
`adresa_Porodica`, `broj_porta`, `Internet_adresa.adresa_VALUE`을 사용한다. 상수는 enum의
`oblak_Porodica`, `datagramski_priključak`, `datagram_protokol`, `tok_Mreža`, `tok_protokol_prenosa`이다.
한국어·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. spoljni_VALUE 통신은 자체 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. stvarni_podaci Pi 4 GENET 드라이버는 미지원이다.
소켓도 stvarni_podaci FUNCTION_VALUE `Zatvori_Datoteka`로 닫는다.
