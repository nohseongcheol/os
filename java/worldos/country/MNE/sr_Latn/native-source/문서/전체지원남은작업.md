# 전체 Podrška_VALUE 요청의 aktuelno_stavka Status_VALUE

zahtev 전체는 아직 완료되지 않았다. aktuelno_stavka ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 stvarni_podaci C POSIX 일부 기능, 한국어 API/izvor ime, IDE Datoteka 보존, 게스트 Java Datoteka 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/안내.md)를 기준으로 판단한다.

| zahtev 분야 | aktuelno_stavka Izvrši_komanda 가능한 klip | 전체 지원에 필요한 작업 |
|---|---|---|
| Java kompajlirati_izvor·Izvrši_komanda | 게스트 제한형 javac/JVM, 정적 단일 클래스와 일부 표준 objekat_VALUE | 일반 objekat_VALUE·Razred_VALUE veze·izuzetak·GC·스레드, 완전한 javac와 표준 Razred_VALUE biblioteka |
| Datoteka | POSIX 서술자, Java 단일 bajt_VALUE Datoteka tok_VALUE, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·dozvola_VALUE·zaključati_VALUE·일반 sistem_datoteka·ekstenzija_VALUE 가능한 kapacitet_VALUE |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP host 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, dodati_stavka NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 događaj·font_VALUE·prozor operativni_sistem_VALUE, AWT 네이티브 연결과 Swing Izvrši_komanda 기반 |
| POSIX | 문서화한 Datoteka·단말·UDP 부분 | Proces_VALUE·exec/fork·스레드·시그널·TIME_VALUE·mmap·poll·파이프 등과 적합성 potvrditi |
| 언어별 ime | 한국어 46개 mapiranje_VALUE stavka_VALUE, stvarni_podaci C/Java/Datoteka ime 적용 | cilj jezik izvršavanje_VALUE, 언어별 용례·역사 근거와 해당 izvor·도구의 potvrditi |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 Izvrši_komanda 환경을 추가하는 방식은 별도의 jezgro_VALUE·루트 sistem_datoteka·OpenJDK·그래픽 server_VALUE·영구 Store_VALUE 구성을 가진 Izvrši_komanda 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

Izvrši_komanda 기반과 dodati_stavka cilj 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. aktuelno_stavka 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
