# 전체 тусламж_утга 요청의 현재 төлөв_утга

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 бодит_өгөгдөл C POSIX 일부 기능, Монгол API/ЭХ Нэр, IDE Файл 보존, 게스트 Java Файл 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/заавал_унших_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 Гүйцэтгэх_команд 가능한 клип | 전체 지원에 필요한 작업 |
|---|---|---|
| Java хөрвүүлэх_эх·Гүйцэтгэх_команд | 게스트 제한형 javac/JVM, статик_утга 단일 클래스와 일부 표준 объект_утга | 일반 объект_утга·класс_утга Холбох·예외·GC·스레드, 완전한 javac와 표준 класс_утга сан |
| Файл | POSIX 서술자, Java 단일 байт_утга Файл урсгал_утга, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·зөвшөөрөл_утга·잠금·일반 файлын_систем·өргөтгөл_утга 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP хост 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 Гүйцэтгэх_команд 환경을 추가하는 방식은 별도의 кернел_утга·루트 файлын_систем·OpenJDK·그래픽 сервер_утга·영구 хадгалах_утга 구성을 가진 Гүйцэтгэх_команд 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

Гүйцэтгэх_команд 기반과 추가 зорилго 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
