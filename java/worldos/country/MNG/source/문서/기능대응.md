# engos 기능 대응표

## 기존 объект_утга 기반 관리 кернел_утга 전체를 부팅하기 위해 남은 Холбох

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/гар_утас_утга 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot оролт_цэг_утга, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 Хам_сэдэв_утга хадгалах_утга
- бодит_өгөгдөл PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA давтах_утга
- Java объект_утга·олонлог_утга Холбох_Бүдүүвч, 예외, статик_утга ажилд_бэлдэх, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT үе_шат_утга_29ee1bb7
- FAT 디스크 구역을 бодит_өгөгдөл ATA 장치와 연결하는 оролт_гаралт 접착 үе_шат_утга

위 관리 계층은 engos 기능의 Java 관리 구현과 хост 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot оролт_цэг_утга, статик_утга ажилд_бэлдэх·бүхэл_тоо олонлог_утга, VGA/직렬/PS2, 명령해석기, хэрэглэгч ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 хост 루프백 패킷 왕복을 검증했다. 위 표의 объект_утга 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
