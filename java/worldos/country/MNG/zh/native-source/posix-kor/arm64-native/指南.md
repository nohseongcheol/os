# 内置 ARM64 Java 커널의 C/C++ 文件·루프백 连接

이 디렉터리는 `platforms/rpi4-native` 内置 内核值 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`头文件/文件ABI.h`는 中文 함수명과 `extern "C"` ABI를 제공한다. `连接.c`는 内核值 안에서 AOT Java 文件 메서드에 직접 연결하고, `用户桥接.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. 实际数据 文件 처리는 `内存文件集.java`, 루프백 数据报 처리는 `环回网络.java`, 연결형 흐름은 `流网络.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 内核值 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`第三操作数. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·浮点型分值 操作值·文件·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

支持值: `打开文件`, `读取文件数据`, `写入文件数据`, `关闭文件`, `寻道文件`, `移除文件条目名称`, `设定文件长度`, 辅助值 函数 `文件大小`. 错误 시 -1과 작업별 `错误编号`를 반환한다. `提交文件存储装置`은 RAM 파일이므로 ENOSYS를 반환한다. 文件 16개, 각 16384바이트, 名称 63바이트, 描述符条目 16개이며 RAM 디렉터리·对端值/절대 경로를 제공한다. 权限值/영속 저장은 없다.

사용자용 `头文件/网络ABI.h`는 实际数据 中文 함수와 독립 구조체를 선언한다.
`创建端点`, `绑定地址`, `发送数据报数据/接收`, `连接网络/等待/接收`는
`用户桥接.c`에서 SVC를 호출하며 宏值 별칭이 아니다. `struct 互联网套接字地址`의
`地址族`, `端口编号`, `互联网地址.地址值`을 사용한다. 상수는 enum의
`互联网族`, `数据报套接字`, `数据报协议`, `流网络`, `流传输协议`이다.
中文·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. 外部值 통신은 内置 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. 实际数据 Pi 4 GENET 드라이버는 미지원이다.
소켓도 实际数据 函数 `关闭文件`로 닫는다.
