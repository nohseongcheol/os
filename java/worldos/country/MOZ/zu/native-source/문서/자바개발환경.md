# jkoros 안에서 Java akha_umthombo·yenza_umyalo

이 문서의 부팅·isihumushi_miyalelo·Store_inani 명령은 **x86 isibuyekezo_inani** 기준이다. 공유 Java 컴파일러/JVM은 [자체 ARM64 Pi4 isibuyekezo_inani](../platforms/rpi4-native/README.md)에도 연결되어 있다. ARM64에서는 UTF-8 UART 입력·한글 ifayela_igama_I_SMS, `edit`의 단독 `.` Store_inani, 16개 RAM Ihele, 약 2초 yenza_umyalo 제한을 사용한다.

`javac FILE.java`와 `java CLASS [ARGS]`를 네이티브 jkoros 셸에서 실행한다. 컴파일러와 JVM은 각각 독립 ELF로 적재되어 ring 3에서 동작한다. 소스를 게스트에서 읽어 ulwazi_ngokwenzekile_imininingwane JVM `.class` 파일을 만들고, 그 파일의 바이트코드를 게스트 JVM이 해석한다. singatha akha_umthombo 서버나 Linux 게스트는 사용하지 않는다.

**현재 구현은 자체 제한형 컴파일러·JVM이다. OpenJDK/JDK 전체를 이식하거나 설치한 것이 아니며 Java SE 호환 환경도 아니다.** 표준 라이브러리는 아래의 일부 호출을 구현한 것이다. `java -version`과 `javac -version`에도 이 범위를 표시한다. 일반 JAR, Maven/Gradle, 임의의 Java i_app_f5044b9b 실행은 아직 지원하지 않는다.

## 직접 작성

`edit`는 Ihele 전체를 새 내용으로 작성한다. 기존 내용의 umugqa hlela_inani 기능은 아니다. `.save`로 저장하고 `.cancel`로 취소한다.

```text
jkoros> edit Demo.java
...> public class Demo {
...>  public static int square(int n) { return n * n; }
...>  public static void main(String[] args) {
...>   int n = Integer.parseInt(args[0]);
...>   System.out.println("square=" + square(n));
...>  }
...> }
...> .save
jkoros> javac Demo.java
jkoros> java Demo 12
square=144
Exit: 0
```

- `ls`: 파일과 ibhayithi_inani 수 khombisa_inani.
- `cat FILE`: Ihele Okuqukethwe_inani khombisa_inani. 텍스트 소스에 사용한다.
- `rm FILE`: inkumbulo_imininingwane Ihele 삭제.
- `edit FILE`: 전체 내용을 새로 입력. 빈 파일도 저장할 수 있다.
- 구문·thayipha_inani 검사 ukwehluleka_inani 시 기존 `.class`는 유지된다. 소스를 고친 Impindamuva_inani 컴파일이 실패했다면 이전 yenza_umyalo 파일이 남아 있으므로 akha_umthombo 성공 여부를 확인한다.

파일은 RAM에서 동작한다. 전용 Store_inani 매체가 없거나 `sync`하지 않은 내용은 재부팅하면 사라진다. `make -C os run-store`로 연결한 매체에는 `sync`로 umthombo_isihlahla·uhlobo_inani·imininingwane 파일을 보존할 수 있다. 최대 8개, 파일마다 16KiB, Ihele 이름은 ASCII 1~63자다. umthombo_isihlahla 이름은 `.class` 확장자 공간 때문에 최대 62자다. hlela_inani 입력은 ASCII이고 한 umugqa 최대 128자다. umugqa 또는 Ihele 한도를 넘긴 편집은 `.save`에서 거부하여 기존 파일을 보존한다. ikhenela_inani/컴파일러/JVM 구현의 Java 식별자는 한국어이며, 현재 게스트 입력 제한 때문에 umsebenzisi 예제 이름은 ASCII로 작성한다.

## 외부 Ihele 적재

호스트에서 만든 소스나 uxhaso_inani isiqeshana 안의 `.class`를 부팅 이미지에 포함할 수 있다. `JAVA_FILES`는 `게스트이름=호스트경로` 목록이다. 아래의 경로는 예시이며 ulwazi_ngokwenzekile_imininingwane 파일의 절대 경로로 바꾼다. 공백 없는 경로를 사용한다.

```sh
# singatha JDK로 컴파일한 클래스도 사용할 수 있다.
javac --release 8 /tmp/Demo.java
make -C /home/user/jkoros iso \
  JAVA_FILES='Demo.java=/tmp/Demo.java Demo.class=/tmp/Demo.class'
make -C /home/user/jkoros run \
  JAVA_FILES='Demo.java=/tmp/Demo.java Demo.class=/tmp/Demo.class'
```

새 부팅 후 `java Demo 12`를 실행한다. 소스만 넣었으면 게스트에서 `javac Demo.java`부터 실행한다. `JAVA_FILES`를 생략한 다음 빌드에서는 추가 파일을 포함하지 않는다. Ihele Okuqukethwe_inani 변경과 okufakwayo_Uhlu 제거도 다음 빌드에 반영된다. 원본 singatha 파일에는 쓰지 않는다. inani_elimisiwe `Hello.java`까지 합해 8개이며, 같은 이름을 명시하면 inani_elimisiwe 예제를 대체한다. 새 `.class`를 저장할 빈 슬롯도 남겨 둔다.

`--release 8`은 uhlobo_inani Ihele 버전을 맞추는 옵션이다. 사용하는 문법·바이트코드·라이브러리도 아래 uxhaso_inani isiqeshana 안에 있어야 한다.

## Java Ihele i_I_O

[FileDemo.java](../posix-kor/자바예제/FileDemo.java)는 일반 Java 표준 uhlobo_inani 이름을 사용한다. 소스를 `edit FileDemo.java`로 입력하거나 `JAVA_FILES`로 부팅 이미지에 넣은 Impindamuva_inani `javac FileDemo.java`, `java FileDemo`를 실행한다. 결과는 `65`, `255`, `66`, `-1`, `JAVA FILE IO PASS`다. `write(int)`는 하위 8비트를 쓰고 `read()`는 0~255 또는 EOF -1을 반환한다. inani_elimisiwe 출력 생성자는 내용을 비우고, boolean 인수가 true이면 이어쓴다.

두 스트림과 IOException의 명시적 import, main의 `throws Exception` 또는 `throws IOException` 표기를 허용한다. 예외 into_inani·try/catch·try-with-resources는 지원하지 않으며 Ihele 오류를 진단하고 프로그램을 종료한다. AMALUNGU_AFANAYO_inani i_I_O, InputStream/OutputStream으로의 다형성, Reader/Writer, getFD, 일반 Ihele 메타데이터 API는 아직 없다. close는 열린 서술자를 닫고, 재부팅 보존에는 isihumushi_miyalelo `sync`가 필요하다. 예제의 Ihele 이름은 현재 셸과 파일체계에 맞춰 ASCII로 쓴다.

`os/시험/자바파일시험.py`는 ulwazi_ngokwenzekile_imininingwane 게스트 akha_umthombo 결과를 OpenJDK `-Xverify:all`로 다시 실행해 Ihele 바이트와 출력을 대조한다. 범위와 Store_inani imidiya_inani 사용법은 [posix-kor NGIFUNDE_eb81d7d9](../posix-kor/NGIFUNDE_eb81d7d9.md)를 참고한다. 참고한 표준 API는 Oracle [FileOutputStream](https://docs.oracle.com/javase/8/docs/api/java/io/FileOutputStream.html)이다.
