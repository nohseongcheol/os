## 기존 yëf_xëyma 기반 관리 xoox_xëyma 전체를 부팅하기 위해 남은 JOKKOO

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/toftal_xëyma 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot dugal_xabaar_Tomb_xëyma, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 péete_xëyma Store_xëyma
- liteew_mbir PIC/PIT/PS2/ATA/PCI jumtukaay_jël 및 AMD PCnet DMA wërngël_xëyma
- Java yëf_xëyma·TABLO_xëyma lëkkale_Tëralin, 예외, Soppeekoodi_xëyma doortal, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT pàcc_xëyma
- FAT 디스크 구역을 liteew_mbir ATA 장치와 연결하는 D_G 접착 déggoob_wet_xëyma

위 관리 계층은 engos 기능의 Java 관리 구현과 dalal 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot dugal_xabaar_Tomb_xëyma, Soppeekoodi_xëyma doortal·lëmm TABLO_xëyma, VGA/직렬/PS2, 명령해석기, kiy_jariñoo_internet ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 dalal 루프백 패킷 왕복을 검증했다. 위 표의 yëf_xëyma 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
