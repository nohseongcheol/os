# 자체 커널과 번역기의 தமிழ் பெயர்

대상은 `platforms/rpi4-native`의 자체 Java கரு_மதிப்பு, பயனர் JVM, C இயந்திரம் இணைக்க,
TCP/UDP·FTP, C 번역기 이식부, MicroPython 이식부, தொகு_முறைமை·இயக்கு_கட்டளை·시험 도구다.
`golang/worldos/나라/KOR/மூலக்_கோப்பு`의 원칙처럼 기능을 먼저 구분하고 이름을 정한다.
x86 Java 커널과 공용 x86·ARM64 미리 번역기의 자체 선언도 명명 검사에 포함한다.
Linux 실행판의 ஓம்பு கருவிகள், OpenJDK 보조 கருவிகள் 및 외부 배포 மூலம்_மரம் 전체를
한국어로 다시 작성했다는 뜻은 아니다.

## 명명 원칙과 말의 근거

- 명사는 자료의 역할을 나타낸다: `கோப்பு_நடத்தி`, `பியர்_முனைய_எண்`, `குவியல்_சேமிப்பகம்`, `விசைப்பலகை`.
- 함수는 행위를 나타낸다: `படி`, `எழுது`, `திற`, `மூடு`, `망주소묶기`, `இயக்கு_நிரல்`.
- TCP의 이어진 பைட்_மதிப்பு 흐름과 UDP의 경계 있는 자료를 `இணைப்பு`와 `전문통로`로 구별한다.
- 짧은 영어 변수도 쓰임에 따라 `நீளம்_மதிப்பு`, `தரவு_நிலை`, `தேடுதல்_அடைவு`, `반환값`으로 풀어 쓴다.
  순번·임시 산술값처럼 여러 역할에 재사용되는 변수는 `순번`, `첫째값`, `둘째값`으로 구별한다.
- 이름이 같아도 외부 구조체의 필드와 자체 변수는 별도로 분석한다.

`சேனல்_உள்ளீடு(通路)`는 이동이나 교류가 이루어지는 길이라는 기존 의미를 통신 연결에
적용했다. `முணையம்_மதிப்பு(窓口)`의 주고받는 접점이라는 의미를 연결을 받는 곳에 적용했다.
이는 국립국어원 한국어기초사전의 [சேனல்_உள்ளீடு](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=49310),
[முணையம்_மதிப்பு](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=24898)의 뜻에 근거한다.

`전문(電文)`은 전보에 담는 글이라는 기존 통신 어휘에서 가져와, UDP 자료의
경계가 보존된다는 특징을 드러내는 데 쓴다. 근거는
[한국어기초사전 전문](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=74335)이다.
`தொடரோடி_மதிப்பு`, `தொடரிழை_மதிப்பு`, `쌓임`은 우리말의 움직임·이어짐·쌓이는 모양을 빌린 표현이다.
`உள்ளீடு_ஓட்டம்`, `작업가닥`, `அடுக்கு_சேமிப்பகம்` 같은 복합 이름은 이 프로젝트의 기능별 조어다.
이 அகராதி 근거를 특정 중세 문헌의 최초 출현이나 공인 전산 번역으로 확대하지 않는다.
공인 표준 மொழியாக்கம்_மூலம்·국어사 전문 감수를 마쳤다는 뜻도 아니다.

| 기능 | 채택한 பெயர் | 이유 |
|---|---|---|
| TCP Socket | இணைப்பு | 상대와 연결되어 வரிசை_மதிப்பு 있는 바이트를 주고받음 |
| ServerSocket | 수신창구 | 새 연결이 들어오는 접점 |
| DatagramSocket | 전문통로 | 각 자료의 경계를 보존하는 통신 |
| InputStream / OutputStream | உள்ளீடு_ஓட்டம் / வெளியீடு_ஓட்டம் | 들어오고 나가는 바이트의 வரிசை_மதிப்பு |
| heap / stack | குவியல்_சேமிப்பகம் / அடுக்கு_சேமிப்பகம் | ஒதுக்கிடு_சேமிப்பகம் 방식과 쌓고 꺼내는 구조 |

## 보존하는 규격 பெயர்

`public`, `class`, `int`는 예약어다. `String`, `main`, 배열의 `length`는 예약어가 아니다.
현재 다섯 Java 예제는 `செயல்படுத்துக()`·`실행인수`·தமிழ் 화면/தொடரிழை_மதிப்பு API를 사용해
예약어·리터럴 외의 식별자를 한국어로 작성한다. 화면/가닥은 표준 객체를
감싸지 않고 자체 JVM에 직접 구현했다. 자세한 계약은 [தமிழ் Java API](../한국어자바/பயனர்_உதவிக்_கோப்பு_eb81d7d9.md)를 본다.

표준 javac는 சரம்_மதிப்பு 리터럴에 `java.lang.String`, சரம்_மதிப்பு 결합에 `StringBuilder`
같은 이름을 생성한다. 이들은 தமிழ் 소스에서도 바이트코드에 남을 수 있다.
기존 표준 class를 실행하는 JVM의 대응 சரம்_மதிப்பு, 아직 표준 라이브러리를 쓰는
통신·கோப்பின்_பெயர் 연결부까지 모두 한국어로 재구현한 것은 아니다. 이름만 일괄 치환하면
서술자·재정의·native 연결이 달라져 호환성이 깨진다.

C 표준 செயல்பாடு_மதிப்பு·முழு_எண்_வகை·POSIX ABI, CPU பதிவு_செய்_மதிப்பு பெயர், 어셈블리 கட்டளை, 링커 절 பெயர்,
TinyCC·lwIP·MicroPython이 요구하는 அமைப்புகள் 매크로와 헤더 이름도 보존한다.
예: `main`, `memcpy`, `pk_bind`, `mpconfigport.h`, `lwipopts.h`, `stdint.h`.
자체 C 함수의 மூலம்_மரம் 이름은 한국어이며, [기계연결이름.h](기계연결이름.h)가
기존 AOT·어셈블리·SDK에 공개한 இயந்திரம் 심볼과 연결한다.
Python의 `__init__`, `setUp`, `handle`, 표준 தொகுதி_மதிப்பு பண்புக்கூறு_மதிப்பு, 명령행 옵션과 JSON 키도
외부 계약이다. `build/`, 배포 바이너리 이름과 `/sdk`는 기존 இயக்கு_கட்டளை 경로를 유지한다.
외부 원본은 `vendor/`에서 이용허락·해시와 함께 관리한다.

## 검사와 재실행

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 கருவிகள்/명명검사.py
make தொகு_முறைமை
make 시험
make test-examples test-ftp test-elf
python3 கருவிகள்/இயக்கு_கட்டளை.py --desktop --network
```

`கருவிகள்/시언어이름분석.py`는 libclang 6으로 C 선언과 참조를 검사한다.
`கருவிகள்/*이름반영.py`는 மாற்று_மதிப்பு_16f64fe4 전 மூலம்_மரம்·분석표를 필요로 하는 일회성 이행 도구다.
이미 변경된 소스에 다시 적용하여 대응표를 덮어쓰지 않는다.

## C 통신 구조체와 Python பிழை

C 통신에서 `갈래`는 முகவரி 체계를 구분하고 `முனைய_எண்`는 port, `முகவரி_மதிப்பு`은
IPv4 주소의 32비트 값을 나타낸다. `전문전송규약`은 앞서 설명한 전문(電文)과
வேலை_மதிப்பு_102996da(規約)을 결합해 UDP의 기능을 드러낸 프로젝트 이름이다.

| 표준 표현 | தமிழ் 직접 구현 |
|---|---|
| AF_INET / SOCK_DGRAM / IPPROTO_UDP | enum의 இணையம்_குடும்பம் / 전문통신 / 전문전송규약 |
| struct pk_sockaddr_in | struct 인터넷통신주소 |
| sin_family / sin_port | முகவரி_குடும்பம் / முனைய_எண் |
| sin_addr.s_addr | இணைய_முகவரி.முகவரி_மதிப்பு |
| OSError / பிழை.args[0] | முறைமை_பிழை / பிழை.அடைவு |

தமிழ் 구조체는 `#define` 치환이나 புலம்_மதிப்பு 별칭이 아닌 별개 자료형이다.
표준 구조체와 같은 16바이트 배치를 선언하며 கரு_மதிப்பு SVC에서 பைட்_மதிப்பு 복사로
검사한다. `உருவாக்கு_முடிவுப்_புள்ளி`·`자료전문보내기`와 கோப்பின்_பெயர் 함수는 மாறா_மதிப்பு 라이브러리에
அசல்_தரவு தமிழ் 이름의 செயல்பாடு_மதிப்பு 심볼을 갖는다. 기존 pk_* 심볼도 유지한다.
이전 코드에서 தமிழ் 통신 함수에 pk_sockaddr*를 전달했다면 தமிழ் 구조체로
옮기거나, 표준 구조체와 pk_* 함수의 짝을 유지한다.

Python의 `முறைமை_பிழை`는 OSError의 தமிழ் 하위 클래스이며 연결부에서
பிழை 번호를 보존하여 변환한다. 일반 Python 문법과 외부 패키지의 API는 유지한다.

## 직접 GUI 이름의 뜻과 검토 கிளிப்

`실행할일`은 수행할 내용을, `செயற்படுத்துக`는 그 수행을 나타낸다.
`동작받이`는 동작이 발생했다는 알림을 받는 역할, `동작알림`은 전달되는 사건이다.
`பொத்தான்`는 눌러 동작시키는 조작부, `விளக்கச்சீட்டு`는 பயனர்_உதவிக்_கோப்பு_eb81d7d9 글의 நிலை_அடைவு,
`உரைப்_புலம்`은 글을 적는 நிலை_அடைவு, `작업가닥`은 이어지는 இயக்கு_கட்டளை 흐름을 뜻한다.
`இயக்கு_கட்டளை(實行)`·`செயல்(動作)`의 기존 뜻과 `받다`·`알리다`·`தொடரிழை_மதிப்பு`의 기능을
결합한 프로젝트 이름이다. 새 복합어가 역사 문헌에 그대로 있었다거나
특정 시대에 처음 쓰였다고 주장하지 않는다.

전체 저장소는 `python3 கருவிகள்/மூலம்_மதிப்பாய்வு.py`로 검토한다.
결과는 `build/verification/naming/source-review.json`이며 파일별 ஹாஷ்_கோப்பு,
ASCII 파일명과 Python의 영어 அறிவிப்பு 위치를 기록한다.
공용 ARM64·x86 번역기의 구현은 `compiler/자바도구/기계어미리번역.java`로 전환했다. `compiler/기계어미리번역.py`는 호환 진입점이다.
`compiler/arm64.py`는 이전 경로와 `ARM64(...).generate(...)` 호출을 이어 주는
호환 진입점이다. `compiler/classfile.py`, OpenJDK 보조 கருவிகள், Linux பதிப்பு_மதிப்பு 도구와
기존 호환 진입점에는 영어 이름이 남아 있다. 따라서 전체 저장소가
예약어 외 100% 한국어라고 판정하지 않는다.
`கருவிகள்/명명검사.py --시언어`는 இயக்க ARM64 소스의 அறிவிப்பு, C 의미 분석,
x86 Java 커널과 공용 번역기의 자체 அறிவிப்பு, Java 예제 전체 அடையாளங்காட்டி_மதிப்பு,
ARM64 Python 예제와 직접 GUI/가닥에 표준 래퍼가 없는지를 별도로 검사한다.

## 현재 기능을 기준으로 보완한 பெயர்

번역은 글자를 음역하는 대신 자료의 역할과 함수의 행동을 구분한다.
동일한 영어 이름도 문맥이 다르면 தமிழ் 이름을 달리 정한다.
கோப்பின்_பெயர் 이름은 주된 기능을 나타내고, செயல்பாடு_மதிப்பு 이름은 행동을, 변수 이름은 담는 자료를 나타낸다.
예약어, 표준 API 및 외부 இணைக்க 규약은 따로 기록한다.

| 이전 பெயர் | 적용한 பெயர் | 현재 기능 |
|---|---|---|
| `arm64.py`의 구현 | `compiler/자바도구/기계어미리번역.java` | Java 바이트코드를 독립 실행용 C 원문으로 미리 மொழியாக்கம்_மூலம் |

### 말의 뿌리와 새로운 복합 பெயர்

`நினைவகம்_மதிப்பு(記憶)`과 `தேடுதல்_அடைவு(索引)`은 기존 한자어를 쓴다.
기억은 자료를 간직하는 기능에, 색인은 வரிசை_மதிப்பு 있는 항목을 찾아 지정하는 기능에 적용한다.
அகராதி 근거는 국립국어원 한국어기초사전의
[நினைவகம்_மதிப்பு](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=38812&nation=eng),
[தேடுதல்_அடைவு](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=63787)이다.

`அடுக்கு_சேமிப்பகம்`, `쌓기`, `மேல்மீட்பு_மதிப்பு`는 자료를 포개고 마지막 자료부터 꺼내는 இயக்கு_கட்டளை 구조를 드러낸다.
`쌓다`의 기존 뜻에 근거한 기능별 조어이며, 사전의
[쌓다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62095)를 참고한다.
`미리번역`은 இயக்கு_கட்டளை 전에 번역한다는 기능을 직접 나타낸다.
`இயந்திரம்_சொல்`은 처리기의 தரவு 단위를 가리키며, 언어의 일반 낱말과 구별하도록 `இயந்திரம்`를 붙였다.
`기계어미리번역`, `குவியல்_சொல்_எண்ணிக்கை` 같은 복합 이름은 현재 기능에 맞게 만든 프로젝트 용어다.
이 복합어가 옛 문헌에 그대로 있었다거나 특정 시대에 처음 나타났다는 뜻은 아니다.
확인되지 않은 중세 형태나 최초 사용 연대는 어원 근거로 적지 않는다.

생성되는 C의 내부 தரவு_வகை·கோவை_மதிப்பு_ed437109·செயல்பாடு_மதிப்பு·தனி_நோக்கி 변수·கிளை 이름도 한국어로 바꾼다.

표준 C 범용 문자 표기로 출력한다. அசல்_தரவு ARM64 빌드는 Clang으로 읽을 수 있는 한글 원문을 사용한다.
