# தமிழ் Java 도우미 நூலகம்

OpenJDK 11 이상과 함께 쓰는 프로젝트 உரிமையாளர்_மதிப்பு API다. 표준 Java நூலகம் 전체의 번역판을 뜻하지 않는다. 기존 Java API·키워드·விதிவிலக்கு·자료형은 그대로 함께 쓴다.

전체 22개 도우미 메서드의 செயலுருபுகள்·반환값·제약, இயக்க_முறைமை 안의 사용법, Python·C++ 호출 방법은 **[தமிழ் நூலகம் பயனர்_வழிகாட்டி](பயனர்_வழிகாட்டி.md)**에 정리했다. [Python 호출 예제](예제/다른언어/파이썬호출.py)와 [C++ JNI 호출 예제](예제/다른언어/자바호출.cpp)도 제공한다.

`make`로 `build/한국어자바.jar`를 만든다. `javac -encoding UTF-8 -cp build/한국어자바.jar 예제/인사.java`로 예제를 컴파일한다. 실행은 `java -cp build/한국어자바.jar:예제 인사`다.

`인사` 예제는 그래픽 화면이 없으면 கோப்பின்_பெயர்·문자·스레드 결과와 안내만 출력한다. Swing 창은 그래픽 세션에서 실행해야 한다. QEMU에서는 [그래픽 இயக்கு_கட்டளை பயனர்_உதவிக்_கோப்பு_eb81d7d9](../platforms/rpi4/README.md)의 `make run`으로 부팅한 பின்_மதிப்பு VNC 데스크톱의 터미널을 사용한다.

| பிரிவு_மதிப்பு_55654bf1 | 제공 기능 |
|---|---|
| கோப்பின்_பெயர் | UTF-8 텍스트·பைட்_மதிப்பு படி/எழுது, 디렉터리·உள்ளீடு_பட்டியல் |
| 문자 | UTF-8 변환, NFC சீராக்கு_மதிப்பு, குறியீடு_மதிப்பு 포인트 수, 언어별 낱말 경계 |
| 통신 | HTTP(S) HTTP_வேண்டுதல், 제한시간을 가진 TCP இணைக்க |
| 작업 | 스레드 செயல்படுத்துக·합류·காத்திரு_மதிப்பு, 작업 நிரல்_துவக்குநர் |
| 화면 | Swing 이벤트 처리와 சாளரம் உருவாக்குக |
| பணியிடம் | மூலக்_கோப்பு திருத்து_மதிப்பு·தொகு_மூலம்·இயக்கு_கட்டளை·இயக்கு_கட்டளை கோப்பின்_பெயர் உருவாக்குக 화면 |

`char`는 UTF-16 குறியீடு_மதிப்பு 단위이므로 이모지 등을 한 글자로 처리할 때 குறியீடு_மதிப்பு 포인트 또는 문자 경계 API를 사용한다. 파일은 UTF-8로 저장한다. OpenJDK의 모든 Java2D/எழுத்துரு_மதிப்பு/입력기 조합을 각각 검증한 것은 아니다.

이름은 현재 의미가 분명한 தமிழ் 용례를 사용했다. 개별 명칭의 역사적 어원 검토를 완료했다고 주장하지 않는다. வளம்_மதிப்பு 종료와 விதிவிலக்கு 처리는 표준 API의 계약을 따른다.
