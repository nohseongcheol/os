# اپنا ARM64 Java 커널의 C/C++ فائل_کا_نام·루프백 متصل_ہوں

이 디렉터리는 `platforms/rpi4-native` اپنا کرنیل_قدر 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 اردو 함수명과 `extern "C"` ABI를 제공한다. `متصل_ہوں.c`는 کرنیل_قدر 안에서 AOT Java فائل_کا_نام 메서드에 직접 연결하고, `صارف_برج.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. اصل_کوائف فائل_کا_نام 처리는 `میموری_فائلیں.java`, 루프백 전문 처리는 `되돌림망.java`, 연결형 흐름은 `بہاؤ_نیٹ_ورک.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 کرنیل_قدر 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·실수 عملیہ_قدر·فائل_کا_نام·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

معاونت_قدر: `بنائیں_فائل`, `파일자료읽기`, `لکھیں_فائل_کوائف`, `بند_فائل`, `تلاش_کرنا_فائل`, `ہٹائیں_فائل_اندراج_نام`, `سیٹ_فائل_لمبا_ئی`, 보조 فعل_قدر `فائل_سائز_دیں`. غلطی 시 -1과 작업별 `오류번호`를 반환한다. `파일저장확정`은 RAM 파일이므로 ENOSYS를 반환한다. فائل_کا_نام 16개, 각 16384바이트, نام 63바이트, 서술자 16개이며 RAM 디렉터리·ساتھی_قدر/절대 경로를 제공한다. اجازت_قدر/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 اصل_کوائف اردو 함수와 독립 구조체를 선언한다.
`통신종단점만들기`, `باندھیں_پتہ`, `자료전문보내기/받기`, `جڑیں_نیٹ_ورک/기다리기/받기`는
`صارف_برج.c`에서 SVC를 호출하며 میکرو_قدر 별칭이 아니다. `struct 인터넷통신주소`의
`پتہ_خاندان`, `دہانہ_نمبر`, `انٹرنیٹ_پتہ.پتہ_قدر`을 사용한다. 상수는 enum의
`بادل_خاندان`, `전문통신`, `전문전송규약`, `بہاؤ_نیٹ_ورک`, `흐름전송규약`이다.
اردو·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. 외부 통신은 اپنا 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. اصل_کوائف Pi 4 GENET 드라이버는 미지원이다.
소켓도 اصل_کوائف فعل_قدر `بند_فائل`로 닫는다.
