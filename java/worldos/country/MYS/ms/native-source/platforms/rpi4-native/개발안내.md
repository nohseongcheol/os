# Asli 커널에서 vi·여러 Terminal·한글 프로그래밍 사용하기

Melayu 통신·pengecualian 사용법은 [Melayu Java API](한국어자바/README_eb81d7d9.md), fungsi_VALUE·pemboleh_ubah_VALUE·Fail 이름의 변경과 어원 근거는 [명명 README_eb81d7d9](명명/README_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 Asli AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 Sokongan_VALUE 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 laksanakan_perintah, 외부 TCP/UDP와 FTP는 [새 laksanakan_perintah 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 Terminal

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, e_mel **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 Terminal 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **RIGHT 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 laksanakan_perintah 버튼으로 다시 lajur_VALUE 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 현재 디렉터리, cangkerang pemboleh_ubah_VALUE, Perintah LOG_baris, 입력 중인 명령과 aplikasi_f5044b9b laksanakan_perintah 상태를 보관한다. Fail 저장소는 공유한다. vi와 Swing의 이벤트 tunggu_VALUE 중에 다른 터미널로 전환하면 ruang_pengguna Memori_data·레지스터·Fail/소켓 연결을 보존했다가 돌아올 때 재개한다. **현재 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 Seterusnya_item 입력 tunggu_VALUE 또는 기존 laksanakan_perintah 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 laksanakan_perintah 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 edit_VALUE 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. 현재 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 Tetingkap 판단은 게스트 커널이 처리한다. QEMU laksanakan_perintah 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. sebenar_data Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI alat 종료는 hos 터미널의 Ctrl+C다.

```sh

  -d build/my-java ujian/자바/스윙시험.java

```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. 출력 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.Kelas_VALUE.class` 형식이다. 내장 Melayu 라이브러리는 별도 업로드가 필요 없다. Melayu Tetingkap API의 예제는 [한글창시험.java](ujian/자바/한글창시험.java)이며 같은 방법으로 bina_sumber·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 sumber_pepohon/클래스는 호스트의 `python3 alat/laksanakan_fail.py LALUAN/인사.java`로 별도 QEMU에 업로드·laksanakan_perintah·종료할 수 있다. interaktif Swing에는 laksanakan_perintah 후 ruang_pengguna 입력을 유지하는 `make desktop`을 사용한다.

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 Asli Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

`setLayout(null)`과 `setBounds`로 배치한다. Tetingkap·요소는 laksanakan_perintah 하나당 합계 32개, unsur_VALUE 글자는 최대 127 코드포인트다. nilai_lalai 서체와 색은 커널이 제공한다.

[스윙시험.java](ujian/자바/스윙시험.java)는 Tetingkap·한글 tag_VALUE·medan_teks·버튼·이벤트 처리의 laksanakan_perintah 가능한 예제다. [Asli Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

- `Melayu.Asli.Tetingkap`: `tambah_unsur`, `tayang_tetingkap`, `Tutup`.
- `Melayu.Asli.unsur_skrin`: `tag_VALUE`, `Butang`, `medan_teks` jana.
- `Melayu.Asli.연결통신`: `Sambung`, `dengar_peserta`, `받기`.
- 기존 `출력`, `문자`, `Fail`, `작업`, `pemasukan_Senarai`, `kamus`, `통신`, `화면`, `kernel_VALUE`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **kernel_VALUE 내부 연결형 bait_VALUE strim_VALUE**을 추가했다. Fail/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket pelayan_VALUE = new java.net.ServerSocket(9250);
java.net.Socket tetamu_VALUE = new java.net.Socket("localhost", 9250);
java.net.Socket Sambung = pelayan_VALUE.accept();
tetamu_VALUE.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] RECEIVED_item = new byte[64];
int kepanjangan_VALUE = Sambung.getInputStream().read(RECEIVED_item);
Sambung.close(); tetamu_VALUE.close(); pelayan_VALUE.close();
```

jana·Sambung·accept·양방향 bait_VALUE/ARRAY_VALUE I_O·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 tamat_p 16개, 수신 버퍼당 1024바이트, tunggu_VALUE Sambung 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. nilai_lalai nilai_masa 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM Perintah 수/kernel_VALUE laksanakan_perintah 기한은 여전히 적용된다.

외부 digit_VALUE IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. sebenar_data Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP pustaka 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [ujian_strim.java](ujian/자바/ujian_strim.java)는 sebenar_data 송수신·EOF·기한·Sambung 회수의 ujian 예제다.

## C·C++에서 posix-kor 호출

두 Bahasa 모두 Melayu 헤더와 fungsi_VALUE 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 sebenar_data EL0 laksanakan_perintah ujian 대상이다.

`통신규약.h`의 Asli `pk_sockaddr_in`을 사용하며 port_VALUE·주소는 `망차례짧은수`/`rangkaian_integer`로 변환한다. C 소켓 호출은 비차단이며 data/연결이 없으면 -1과 `오류번호=11`(EAGAIN)을 반환한다. 양수 I_O 결과가 요청보다 작을 수 있으므로 lelaran_VALUE 처리한다. kegagalan_VALUE 후에만 오류번호를 확인한다.

[strim_VALUE.c](예제/한글코딩/strim_VALUE.c)는 C에서 Melayu 이름으로 Sambung·accept·부분 Baca/Tulis·큐 포화·EOF를 처리하는 laksanakan_perintah 예제다. SDK의 `examples/strim_VALUE.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → sebenar_data Melayu C fungsi_VALUE 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·penuding 검사 → Java RAM Fail/루프백 또는 외부 lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 kernel_VALUE 내부용이므로 EL0 프로그램에 링크하지 않는다. ## Melayu 이름으로 직접 작성하는 창과 urutan_VALUE

`example/java/ContohTetingkap.java`는 `실행할일.Lakukan`,
`동작받이.동작받기(동작알림)`, `Butang`, `acara_baris.나중에실행`, `Jalan()`을 쓴다.
Asli JVM에 이 이름들의 objek_VALUE·kaedah_VALUE·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `작업가닥`도 Asli 스케줄러와 직접 연결된다.
세부 메서드와 기존 Melayu API에서의 변경은 [Melayu API 문서](한국어자바/README_eb81d7d9.md)를 본다.

hos javac는 배포 JAR를 Kelas_VALUE 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/ContohTetingkap.java
python3 alat/laksanakan_perintah.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java ContohTetingkap
```

직접 화면/urutan_VALUE API와 `Jalan()` 진입점은 Asli JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
