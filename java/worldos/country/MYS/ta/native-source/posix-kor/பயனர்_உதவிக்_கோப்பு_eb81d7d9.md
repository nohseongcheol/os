# jkoros posix-kor

**자체 ARM64 Java 커널용 C++ இணைக்க**은 [arm64-native](arm64-native/பயனர்_உதவிக்_கோப்பு_eb81d7d9.md)에 있다. கரு_மதிப்பு 내부 직접 கோப்பின்_பெயர் 호출과 EL0 பயனர் 프로그램의 கோப்பின்_பெயர்/UDP 루프백 SVC 호출을 별도 라이브러리로 제공한다. 아래 i386 நூலகம் 및 ARM64 Linux libc와는 இலக்கு·ABI가 다르다.

자체 jkoros 커널에서 실행되는 i386 C 라이브러리와 தமிழ் API다. ஓம்பு libc를 연결하지 않고 `int 0x80`으로 அசல்_தரவு 커널의 파일서술자·단말·UDP·சேகரி_மதிப்பு 계층을 호출한다. `மரபுவழி_மூலம்/`의 ஓம்பு JVM 모형과 별개다.

**현재는 POSIX의 일부 기능을 제공하는 호환 계층이며, POSIX 인증·전체 libc·전체 OpenJDK를 뜻하지 않는다.** 구현 범위와 제한을 아래에 명시한다. 한국어를 먼저 적용했다. 다른 국가·언어의 번역판은 아직 만들지 않았다.

## 빌드와 இயக்கு_கட்டளை

```sh
cd /home/user/jkoros
make posix-kor
make iso
make test-posix
make -C os run-store
```

`run-store`는 `os/build/files.img`가 없을 때만 새 전용 파일을 만들고 QEMU IDE 첫 장치로 연결한다. 기존 파일을 덮어써서 초기화하지 않는다. 일반 `make run`은 디스크 없이 실행된다. VirtualBox 실행기의 디스크 연결은 변경하지 않았다.

부팅된 jkoros에서:

```text
run posixcheck check
run posixstore
cat stored.txt
edit note.txt
hello from jkoros
.save
sync
```

`Sync: 0`은 연결된 전용 매체에 저장했다는 뜻이다. 디스크가 없거나 ஒதுக்கு_மதிப்பு 형식이 아니면 `Sync: -19`다. 같은 `files.img`로 다시 부팅하면 마지막 ஒத்திசை 상태를 복원한다. Java 소스와 `.class`도 같은 சேகரி_மதிப்பு 대상이다. `close`나 편집기의 `.save`만으로 재부팅 보존을 보장하지 않으므로 முடிவு_நிரல் 전에 `sync`를 실행한다.

## 한국어로 C நிரல்_f5044b9b 작성

```c
#include <파일규약.h>

int main(int 인수개수, char **மதிப்புரு_பட்டியல்) {
    (void)인수개수;
    (void)மதிப்புரு_பட்டியல்;
    int 파일서술자 = திற_கோப்பு("note.txt", படிக்க_எழுத | 없으면만들기, 0600);
    if (파일서술자 < 0) return 오류번호;
    if (எழுது_கோப்பு_தரவு(파일서술자, "hello\n", 6) != 6) return 1;
    if (파일저장확정(파일서술자) < 0) return 오류번호;
    return மூடு_கோப்பு(파일서술자);
}
```

작성 원문은 한글을 그대로 유지한다. `கருவிகள்/அடையாளங்காட்டி_மாற்றம்.py`가 தொகு_முறைமை 복사본의 식별자만 C 표준 UCN 표기로 바꾸어 GCC 7에서도 컴파일되게 한다. சரம்_மதிப்பு, 주석, `#include` 경로는 변환하지 않는다. 이 도구는 C의 모든 전처리 표기법을 해석하는 전처리기가 아니며, 프로젝트가 사용하는 일반 토큰과 include 문법을 대상으로 한다.

라이브러리는 `build/libposix-kor.a`, செயல்படுத்துக 코드는 `build/தொடங்கு_பயனர்_நிரல்.o`, உருவாக்குக 헤더는 `build/மூலக்_கோப்பு/포함/`이다. தொகு_முறைமை 옵션과 இணைக்க 명령은 [Makefile](Makefile), அசல்_தரவு 예제는 [파일규약시험.c](மூலக்_கோப்பு/시험/파일규약시험.c)와 [자료전문시험.c](மூலக்_கோப்பு/시험/자료전문시험.c)에 있다. 새 ELF를 OS에 포함하려면 `os/Makefile`의 பயனர் இயக்கு_கட்டளை 묶음에 명시적으로 등록한다. 게스트 안에서 C를 컴파일하는 도구는 제공하지 않는다.

표준 C/POSIX 외부 பெயர் `open`, `read`, `write`, `socket`, `errno`, `main`과 헤더 경로는 유지한다. தமிழ் 별칭은 같은 함수를 가리킨다. 변수와 구현 파일에는 의미를 드러내는 தமிழ் 이름을 사용한다. மொழியாக்கம்_மூலம் 근거는 [명명 원칙](명명원칙.md), அசல்_தரவு 대응은 [용어 대응표](용어대응.tsv)에 기록했다.

`dup`으로 복제한 서술자는 கோப்பின்_பெயர் 위치와 이어쓰기 설정을 공유한다. `FD_CLOEXEC`는 서술자마다 저장한다. `unlink`는 이름만 제거하며, 열린 파일의 내용은 마지막 참조가 닫힐 때까지 접근할 수 있다. 빈 위치를 건너뛰어 쓰거나 길이를 늘린 영역은 0으로 읽힌다. 파일서술자 부족으로 실패한 `open`은 파일을 생성하거나 비우지 않는다. C 호출 실패는 `-1`과 `errno`, 내부 கரு_மதிப்பு 호출은 음수 பிழை 번호를 반환한다.

`fstat`는 이 프로젝트 전용 48바이트 구조체에 종류·அளவு·링크 수·허가 பிட்_மதிப்பு 등을 반환한다. POSIX의 전체 நேர_மதிப்பு 속성은 아직 제공하지 않는다. 다른 운영체제의 `struct stat` 또는 Linux 바이너리 ABI와 호환되지 않는다. `O_CLOEXEC`는 기록할 수 있지만 현재 exec 기능은 없다. 성공하는 செயல்பாடு_மதிப்பு 이름만으로 전체 POSIX 의미가 구현되었다고 간주하면 안 된다.

UDP는 QEMU RTL8139의 அசல்_தரவு ஓம்பு 왕복을 지원한다. 짧은 수신 버퍼에는 앞부분을 복사하고 나머지 전문을 버린다. 빈 전문도 송수신한다. `SO_RCVTIMEO` 또는 비차단 수신의 தரவு 없음은 `EAGAIN`이다. TCP를 요청하면 `EPROTONOSUPPORT`를 반환한다. 루프백·브로드캐스트·멀티캐스트·연결형 소켓·listen/accept는 아직 없다. 기존 AOT Java UDP 손잡이는 이 POSIX 서술자와 별개이므로 서로 섞어 닫지 않는다.

모든 பயனர் 프로그램에는 기존 약 3초 இயக்கு_கட்டளை 상한이 적용된다. `errno`는 현재 단일 செயலகம்_மதிப்பு·단일 스레드 변수다. JDK 전체, Swing/AWT/JavaFX, TCP/DNS/HTTP/TLS, 스레드·GC·JIT·동적 연결은 아직 구현하지 않았다. 전체 Java SE இயக்கு_கட்டளை 환경을 만들려면 해당 கரு_மதிப்பு 기반과 런타임 이식을 계속 진행하거나 별도 Linux 기반 இயக்கு_கட்டளை 방식을 결정해야 한다.

## சேகரி_மதிப்பு 형식과 சரிபார்_5fb2b747

매체는 512바이트 பிரிவு_மதிப்பு 2,048개(1MiB)다. பிரிவு_மதிப்பு 0의 `JKSTORE1` அடையாளங்காட்டி_மதிப்பு·அளவு·வடிவமை_மதிப்பு 번호가 모두 맞는 장치만 எழுது 대상으로 삼는다. பிரிவு_மதிப்பு 1과 260에서 각각 259구역짜리 보존본이 시작한다. 각 보존본은 완료 머리 1구역, கோப்பின்_பெயர் தேடுதல்_அட்டவணை 2구역, கோப்பின்_பெயர் தரவு 256구역으로 구성된다.

`fsync`와 `sync`는 이름이 남아 있는 모든 파일의 현재 상태를 저장한다. 반대편 보존본을 무효화한 பின்_மதிப்பு கோப்பின்_பெயர் 표와 자료를 쓰고 ATA 캐시 비우기를 실행한다. 마지막에 세대 번호와 FNV-1a 검사합을 가진 완료 머리를 기록하고 다시 캐시를 비운다. 부팅 시 검사합과 표가 유효한 가장 சமீபத்தியவை_மதிப்பு 세대를 선택한다. 검사합은 우발적인 손상을 கண்டறி_உள்ளீடு 위한 것이며 암호학적 무결성 검증은 아니다. அசல்_தரவு சாதனம்_மதிப்பு 전원 차단 시험은 하지 않았다.

복원된 கோப்பின்_பெயர் 목록은 부팅 이미지의 இயல்புநிலை_மதிப்பு 예제/`JAVA_FILES` 목록을 대체한다. 새 예제를 이미지에 추가해도 기존 சேகரி_மதிப்பு 매체를 연결하면 저장된 목록이 우선한다. 동기화하지 않은 변경은 재부팅 후 사라진다.

`make test-posix`는 தமிழ் அடையாளங்காட்டி_மதிப்பு 변환, ELF/ISO의 அசல்_தரவு C ABI 호출, 공유 இடம், 삭제된 파일의 수명, கோப்பின்_பெயர்/서술자 고갈, குறிப்பான் பிழை, 표준 입력, UDP, `fsync`, 재부팅, 손상된 최신 보존본의 회피, 다른 형식의 매체 비변경, 게스트 Java கோப்பின்_பெயர் 처리와 OpenJDK 교차 실행을 확인한다. 기록은 `os/build/규약시험.json`, `보존시험.json`, `자바파일시험.json`이다.
