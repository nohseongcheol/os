# JMysOS

当前项目 内置 ARM64 배포판은 [LICENSE](LICENSE)의 COSL 상업 조건을 유지한다. 제3자 라이선스의 권리는 별도로 보장하며, 分发值 시 源代码树·重新连接端点 자료를 포함하는 절차는 [COSL 分发值 指南](platforms/rpi4-native/COSL分发指南.md)에 있다.

内置 ARM64 판의 `ipconfig`/`ip`, `ping`, `ps`/`top`, `free`/`df`, `poweroff`와 中文 명령은 [네트워크·运行系统值 命令 指南](platforms/rpi4-native/网络与系统命令列.md)를 참고한다. 새 커널을 부팅한 后端值 `help system`으로 볼 数 있다.

Raspberry Pi 4 **内置 Java ARM64 内核值**은 [内置 Pi4 指南](platforms/rpi4-native/指南.md)에 있다. Linux 없이 부팅하며 GUI 终端·vi, 内置 JVM의 Swing 일부 API, TCP/UDP·FTP, 게스트 TinyCC·MicroPython, C/C++의 posix-kor 호출을 제공한다. [中文 Java 通信·异常 API](platforms/rpi4-native/中文Java/指南.md)와 [中文 源代码树 命名](platforms/rpi4-native/命名/指南.md)을 지원한다. [内置 SSH·VNC 및 GENET 드라이버](platforms/rpi4-native/外部连接状态指南.md)를 포함하며, 네트워크는 QEMU의 UART SLIP 경로로 검증했다. 实际数据 Pi 4 GENET 동작은 미검증이고, USB 输入值·영속 저장과 전체 OpenJDK·Swing은 아직 支持值 裁剪 밖이다.

Raspberry Pi 4용 Linux·OpenJDK 실행판과 用户 环境 移动值 기능은 [라즈베리파이 실행판](platforms/rpi4/README.md)에 있다. 实际数据 ARM64 JDK/JRE와 시스템·用户 构建映像 构建系统 경로를 제공한다. 기존 内置 x86 커널과는 별도 执行命令 기반이다. 일반 Java `.class`/JAR의 执行命令 文件 생성은 [OpenJDK 执行命令 文件](compiler/OpenJDK-可执行文件文件.md), 中文 API는 [中文 Java 库](中文Java/指南.md)를 참고한다.

`jkoros`는 `engos`의 기능을 Java 관리 커널로 옮기는 프로젝트다. 프로젝트가 소유하는 Java 函数, 变量值, 格式值 및 Java 文件 이름은 한국어로 작성한다. 표준 Java 실행기의 `main`, Java 표준 库 格式值, x86 부트 ABI 등 外部值 계약은 보존한다. 内置 ARM64 실행기는 中文 `运行()`도 진입점으로 지원하며, 中文 GUI·任务 가닥을 JVM에 직접 구현했다. 内置 ARM64 C 연결부·Python 도구와 공용 x86·ARM64 AOT 번역기의 内置 이름도 한국어로 작성한다. 上一个项目 경로의 호환 条目分, OpenJDK 辅助值 도구와 Linux 版本值 도구에는 영어 이름이 남아 있고 [命名 원칙·말의 근거·전체 源代码 검토 裁剪](platforms/rpi4-native/命名/指南.md)를 별도로 기록한다.

## 当前项目 实现

底端值 목록은 기존 `基础源代码/`의 JVM 관리 커널에 대한 것이다. 实际数据 네이티브 커널의 범위는 `os/指南.md`에서 별도로 설명한다.

- 对齐值 할당과 해제를 지원하는 内存空间 管理器值
- 地址 地址区域, 页值 连接, 写入 시 复制值(COW)
- 进程值 标识符值, 准备 대기열, fork/wait 状态值
- 과정별 文件 描述符条目, open/read/seek/dup/close
- ELF32 识别值 및 区段值 检查项
- 키보드·마우스 输入值 事件 대기열
- 串行值 단말과 네이티브 硬件值 边界位置值
- 관리 内核值 전체 자동 测试

세부 映射值 범위와 아직 필요한 네이티브 연결은 [기능 대응표](文档集/功能对应.md)에 기록한다.

## 빌드와 测试

새 네이티브 구현은 `compiler/`와 `os/`에 있다. 기존 `基础源代码/`의 JVM 관리 커널은 그대로 보존하며, 두 구현의 시험과 기능 범위는 서로 다르다.

```sh
cd /home/user/jkoros
make                 # 네이티브 计算结果 用例 + Java 内核值 ELF
make iso             # os/build/kernel.iso
make run             # QEMU 串行值 终端输入输出; help 输入值 (종료는 Ctrl+A, X)
make run-gui         # ISO를 QEMU 屏幕/PS2 키보드로 执行命令
make vbox            # 전용 VirtualBox VM 자동 生成·执行命令 (GUI)
make vbox-status     # VirtualBox 状态值·ISO·串行值 日志记录 路径 验证
make test-vbox       # VirtualBox 运行器 状态值 进程值条目 测试 (实际数据 VM 更改值 缺失方法)
make test            # 编译器 测试 + ELF/ISO 启动 및 命令 输入值 测试
make apps            # 독립 用户 ELF 程序 构建系统
make test-network    # 用户 模式值·UDP 왕복·内存数据 保护值 测试
make test-java       # 게스트 javac/JVM + OpenJDK 양방향 교차 执行命令 测试
make posix-kor       # 中文 C 헤더와 实际数据 内核值 调用 库
make test-posix      # 文件/UDP/存储值/Java 文件 输入输出 测试
make -C os run-store # 전용 存储值 매체로 QEMU 启动
make legacy-test     # 底端值 기존 JVM 관리 커널의 47개 测试
```

`compiler/`는 호스트의 `javac`를 문법·类型值 检查项 전단으로 사용하고 内置 字节码→x86 변환기로 ELF32 기계어를 만든다. 빌드할 때는 JDK가 필요하지만 생성된 커널과 ELF는 外部值 JVM 없이 실행된다. 전체 Java, 对象值 모델, 표준 라이브러리와 기존 관리 内核值 전체의 AOT 변환은 아직 지원하지 않는다. 자세한 支持值 문법과 명령은 [编译器 指南](compiler/指南.md), 实际数据 启动 기능과 한계는 [네이티브 操作系统 指南](os/指南.md)를 참고한다.

네이티브 셸에 内置 제한형 `javac`와 `java`를 추가했다. `edit Demo.java`로 소스를 입력하고 `.save`로 저장한 后端值 `javac Demo.java`, `java Demo`로 **게스트 내부에서 컴파일하고 执行命令**할 数 있다. 默认值 예제는 `javac Hello.java`, `java Hello`第三操作数. 파일은 RAM에서 동작하며, 전용 存储值 매체를 연결하면 `sync`로 재부팅 후에도 보존할 数 있다. **OpenJDK/JDK 전체 이식은 아니며**, 단일 类值·静态值 函数·整数·字符串·条件/반복문과 일부 표준 호출을 지원한다. 支持值 裁剪, 外部值 文件 적재와 시험은 [Java 开发 环境 指南](文档集/Java开发环境.md)에 있다.

네이티브 셸에서 `apps`, `run hello first second`, `net`, `run netcheck`를 사용할 数 있다. 독립 ELF를 ring 3에 적재하고 `int 0x80` 호출을 통해 输出·实参·UDP 네트워크를 제공한다. 별도 宿主 터미널에서 `python3 os/工具集/数据恢复.py --port 9000`을 실행한 后端值 게스트에서 `run udp 10.0.2.2 9000 hello`로 实际数据 왕복을 확인한다. 새 程序 登记, API 및 제한은 [用户 执行命令·네트워크 指南](os/用户/指南.md)를 참고한다. 当前项目 QEMU RTL8139·静态值 IPv4·UDP 전용이며 TCP/DNS는 미지원이며, 전용 IDE 存储值 형식과 POSIX 文件/UDP 일부 기능을 추가했다.

`make vbox`는 `jkoros operating system` 전용 VM을 만들고 디스크 없이 ISO로 부팅한다. 执行命令 중이면 유지하고, 存储值·일시정지 상태이면 재개하며, 꺼져 있을 때만 새 ISO를 빌드해 연결한다. VirtualBox에서 부팅과 셸의 用户 程序 실행을 확인했다. 다만 当前项目 VirtualBox용 네트워크 드라이버는 없어 네트워크 장치를 비활성화한다. UDP 시험에는 `make run`을 사용한다. 상태별 동작과 새 构建系统 반영 방법은 [VirtualBox 执行命令 指南](文档集/VirtualBox运行.md)에 있다.

기존 관리 커널만 시험하려면:

```sh
cd /home/user/jkoros
make -f 创建条目.mk 检查项
make -f 创建条目.mk 宿主
```

`宿主`는 여전히 JVM 관리 계층의 动作 시험이다. `make -f 创建条目.mk 构建映像`는 새 `os/`의 제한형 네이티브 内核值 ISO를 만든다. 기존 `基础源代码/`의 文件系统·进程值·通信网络 实现 전체를 이 ISO에 이식했다는 의미는 아니다.

中文 函数·变量值·文件 이름과 实际数据 C API는 [posix-kor](posix-kor/指南.md)에 있다. 게스트 Java에서는 `FileInputStream`·`FileOutputStream`의 단일 字节值 입출력도 지원한다. 전체 POSIX·OpenJDK·Swing 지원으로 확대된 것은 아니다.

外部值 배포용 `pack.sh` / `unpack.sh`와 자동 依赖项列 복원은 [分发值 指南](distribution/README.md)를 참고하세요.
