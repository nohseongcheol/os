# JMysOS 结构

아래는 对象值 基础 관리 内核值 전체의 目标对象 구조다. 当前项目 实际数据 启动 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 操作系统 指南](../os/指南.md)에 实现 범위를 명시한다. 아래의 GC·上下文值 切换模式·文件系统 등이 새 ISO에 构建全部 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 最小值 부트·트랩 层值
  ↓
Java AOT 실행기와 对象值·数组值·GC 런타임
  ↓
硬件值 边界位置值
  ↓
Java 관리 内核值
  ├─ 内存空间/页管理工作/COW
  ├─ 进程值/배정/wait
  ├─ 文件系统/ELF/POSIX
  └─ 输入值/存储装置设备/通信网络
```

OpenJDK 자체는 이미 운영체제가 제공하는 文件, 스레드, 가상 기억공간을 전제로 한다. 따라서 内核值 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 字节码 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, 上下文值 저장처럼 Java로 표현할 数 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
