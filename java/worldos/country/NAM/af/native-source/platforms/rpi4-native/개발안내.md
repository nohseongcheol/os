`통신규약.h`의 자체 `pk_sockaddr_in`을 사용하며 ombou_VALUE·주소는 `망차례짧은수`/`Netwerk_heelgetal`로 변환한다. C 소켓 호출은 비차단이며 data/연결이 없으면 -1과 `오류번호=11`(EAGAIN)을 반환한다. 양수 I_O 결과가 요청보다 작을 수 있으므로 sprint_VALUE 처리한다. faling_VALUE 후에만 오류번호를 확인한다.

[Stream_VALUE.c](예제/한글코딩/Stream_VALUE.c)는 C에서 한국어 이름으로 Koppel·accept·부분 Lees/Skryf·큐 포화·EOF를 처리하는 uitvoer_bevel 예제다. SDK의 `examples/Stream_VALUE.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → werklik_data 한국어 C funksie_VALUE 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·wyser 검사 → Java RAM Lêer/루프백 또는 외부 lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 kern_VALUE 내부용이므로 EL0 프로그램에 링크하지 않는다. ## 한국어 이름으로 직접 작성하는 창과 draad_VALUE

`example/java/창예제.java`는 `실행할일.Voer_uit`,
`동작받이.동작받기(동작알림)`, `knoppie`, `gebeurtenis_tou.나중에실행`, `Loop()`을 쓴다.
자체 JVM에 이 이름들의 objek_VALUE·metode_VALUE·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `작업가닥`도 자체 스케줄러와 직접 연결된다.
세부 메서드와 기존 한국어 API에서의 변경은 [한국어 API 문서](한국어자바/README_eb81d7d9.md)를 본다.

hou javac는 배포 JAR를 Klas_VALUE 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/창예제.java
python3 Nutsmiddels/uitvoer_bevel.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java 창예제
```

직접 화면/draad_VALUE API와 `Loop()` 진입점은 자체 JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
