# JNerOS 구조

아래는 abu_Daraja 기반 관리 Kwara_Daraja 전체의 tageti_abu 구조다. 현재 Na_hakika_Tarin_bayani 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 OS README_eb81d7d9](../os/README_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·Kwaryar_rubutu_Daraja Sauya_yanayin_aiki·tsarin_fayil_a_kwamfuta 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 Tsarkiya_Daraja
  ↓
Java AOT 실행기와 abu_Daraja·TSARI_Daraja·GC 런타임
  ↓
kayan_haɗi_na_kwamfuta_Daraja 경계
  ↓
Java 관리 Kwara_Daraja
  ├─ 기억공간/쪽관리/COW
  ├─ haryar_aikin_na_ura_Daraja/배정/wait
  ├─ tsarin_fayil_a_kwamfuta/ELF/POSIX
  └─ 입력/Wurin_adana_na_ura/Hanyar_sadarwa_tara
```

OpenJDK 자체는 이미 운영체제가 제공하는 Fayil, 스레드, 가상 기억공간을 전제로 한다. 따라서 Kwara_Daraja 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, Kwaryar_rubutu_Daraja 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
