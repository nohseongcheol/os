# 전체 taimako_Daraja 요청의 현재 Matsayi_Daraja

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 Na_hakika_Tarin_bayani C POSIX 일부 기능, 한국어 API/tushe Suna, IDE Fayil 보존, 게스트 Java Fayil 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/README_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 gudanar_Umarni 가능한 darfi | 전체 지원에 필요한 작업 |
|---|---|---|
| Java Gina_tushe·gudanar_Umarni | 게스트 제한형 javac/JVM, Tsaye_cik_Daraja 단일 클래스와 일부 표준 abu_Daraja | 일반 abu_Daraja·Aji_Daraja Haɗi·banbanchi·GC·스레드, 완전한 javac와 표준 Aji_Daraja laburare |
| Fayil | POSIX 서술자, Java 단일 bayit_Daraja Fayil watsuwa_Daraja, 전용 Midiya_Daraja 보존 | 일반 java.io/nio, 디렉터리·izini_Daraja·잠금·일반 tsarin_fayil_a_kwamfuta·faɗi_Daraja 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP sauka 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 Faruwa·salon_rubutu_Daraja·taga OS_Daraja, AWT 네이티브 연결과 Swing gudanar_Umarni 기반 |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 gudanar_Umarni 환경을 추가하는 방식은 별도의 Kwara_Daraja·루트 tsarin_fayil_a_kwamfuta·OpenJDK·그래픽 Saba_Daraja·영구 Ajiye_Daraja 구성을 가진 gudanar_Umarni 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

gudanar_Umarni 기반과 추가 tageti 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
