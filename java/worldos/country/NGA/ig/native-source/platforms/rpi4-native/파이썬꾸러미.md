호스트의 [꾸러미중계.py](Ngwaọrụ/꾸러미중계.py)는 PyPI HTTPS 다운로드, 인증서 nkwàdo_eziokwū,

wùbe_valuu 도중 공간 부족 등 오류가 발생하면 새 파일과 폴더를 지우고 기존 목록을

수정한 파일이 발견되면 보존하고 오류를 알린다. 빈 패키지 폴더는 남을 수 있다.

**`/lib`도 RAM 파일이다. 재부팅하면 설치한 패키지가 사라진다.**
usu `build/pip-cache`에는 배포 파일과 출처·지문이 남으므로 다음 부팅에서 다시
설치할 수 있다. 버전을 지정하면 같은 배포 파일을 재사용한다.


`pip install micropython-bisect==3.3.3 --port 8028`로 맞춘다.
usu 중계는 `python3 Ngwaọrụ/꾸러미중계.py --port 8027`로 별도 실행할 수도 있다.
QEMU를 종료하거나 중계 실행을 끝내면 이 서비스도 닫힌다.
