대상은 jkoros i386 ELF32다. Linux i386의 호출 번호와 바이너리 호환이 아니다. C의 cdecl 인수를 `ngwa_komputa/운영체제호출.s`에서 EAX(indèks), EBX·ECX·EDX·ESI·EDI(첫째~다섯째 인수)로 변환한다. EBX·ESI·EDI·EBP를 보존하며 결과는 EAX다. mkpụrụobī_kọmpùta_valuu 실패는 음수 mmejọ indèks, C ọbaakwụkwọ 실패는 -1과 양수 errno다.

커널은 0x04000000 이상, 0x04400000 미만의 òjìàrụ 영역 안에 자료의 전체 길이가 들어가는지 확인한다. 단순 널 검사가 아니다. C datà 주소는 baịtị_valuu 주소이며, 기존 Java AOT `int[]` 포인터와 혼용하지 않는다. Java Faịlụ 흐름의 어셈블리 경계가 별도 baịtị_valuu 버퍼를 마련하여 같은 호출을 사용한다.
