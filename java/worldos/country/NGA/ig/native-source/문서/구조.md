# JNgaOS 구조

아래는 ihe_valuu 기반 관리 mkpụrụobī_kọmpùta_valuu 전체의 ebenlereanya_ihe 구조다. 현재 ǹdịnezie_datà 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 OS GỤ̀ỌM_eb81d7d9](../os/GỤ̀ỌM_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·Ọnọdụ_valuu ngbanwụ_moòdù·sistèm_ọbọakwụkwo 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 òkpùkpù_valuu
  ↓
Java AOT 실행기와 ihe_valuu·MKPOKỌTA_valuu·GC 런타임
  ↓
ngwaike_valuu 경계
  ↓
Java 관리 mkpụrụobī_kọmpùta_valuu
  ├─ 기억공간/쪽관리/COW
  ├─ ùsòrò_valuu_6712bde7/배정/wait
  ├─ sistèm_ọbọakwụkwo/ELF/POSIX
  └─ 입력/Nchekwa_njìarụ/Netwọọkụ_ikpo
```

OpenJDK 자체는 이미 운영체제가 제공하는 Faịlụ, 스레드, 가상 기억공간을 전제로 한다. 따라서 mkpụrụobī_kọmpùta_valuu 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, Ọnọdụ_valuu 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
