## 기존 ihe_valuu 기반 관리 mkpụrụobī_kọmpùta_valuu 전체를 부팅하기 위해 남은 Banye

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/njìarụ_valuu 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot ndebà_akara_valuu, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 Ọnọdụ_valuu Store_valuu
- ǹdịnezie_datà PIC/PIT/PS2/ATA/PCI ngwaike_pọọt 및 AMD PCnet DMA memmenwè_valuu

- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT ebedielu_valuu
- FAT 디스크 구역을 ǹdịnezie_datà ATA 장치와 연결하는 I_O 접착 òkpùkpù_valuu

위 관리 계층은 engos 기능의 Java 관리 구현과 usu 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot ndebà_akara_valuu, adịmgbanwò_valuu kwàdo_mmàlite·ọnụọgụ_nzùrùòkè MKPOKỌTA_valuu, VGA/직렬/PS2, 명령해석기, òjìàrụ ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 usu 루프백 패킷 왕복을 검증했다. 위 표의 ihe_valuu 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
