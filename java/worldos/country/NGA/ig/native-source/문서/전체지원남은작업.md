자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 mee_nnyemiwu 환경을 추가하는 방식은 별도의 mkpụrụobī_kọmpùta_valuu·루트 sistèm_ọbọakwụkwo·OpenJDK·그래픽 savà_valuu·영구 Store_valuu 구성을 가진 mee_nnyemiwu 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

mee_nnyemiwu 기반과 추가 ebenlereanya 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
