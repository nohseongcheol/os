# aṣàmúlò 호출 경계

대상은 jkoros i386 ELF32다. Linux i386의 호출 번호와 바이너리 호환이 아니다. C의 cdecl 인수를 `maṣíìnì/운영체제호출.s`에서 EAX(wá_atọ̀ka_àkóónú), EBX·ECX·EDX·ESI·EDI(첫째~다섯째 인수)로 변환한다. EBX·ESI·EDI·EBP를 보존하며 결과는 EAX다. kánẹ́ẹ̀lì_iye 실패는 음수 àṣìṣe wá_atọ̀ka_àkóónú, C ibi_ìpamọ́ 실패는 -1과 양수 errno다.

커널은 0x04000000 이상, 0x04400000 미만의 aṣàmúlò 영역 안에 자료의 전체 길이가 들어가는지 확인한다. 단순 널 검사가 아니다. C détà 주소는 báìtì_iye 주소이며, 기존 Java AOT `int[]` 포인터와 혼용하지 않는다. Java Fáìlì 흐름의 어셈블리 경계가 별도 báìtì_iye 버퍼를 마련하여 같은 호출을 사용한다.

| 44 | 자료전문받기 | 서술자, détà àdírẹ́ẹ̀sì, gígùn_iye, Àwọn_ààtò, 요청 àdírẹ́ẹ̀sì |
| 45 | 통신주소읽기 | 서술자, sockaddr àdírẹ́ẹ̀sì, socklen_t àdírẹ́ẹ̀sì |
| 46 | 수신대기정하기 | 서술자, 0~2000 밀리초 |
| 47 | 파일저장확정 | 서술자 |

43번 요청은 32비트 주소와 32비트 길이의 두 칸이다. 44번 요청은 32비트 주소와 길이를 담은 32비트 값의 àdírẹ́ẹ̀sì 두 칸이다. 수신 주소가 NULL이면 ọ̀gbà_iye àdírẹ́ẹ̀sì 기록을 생략한다. sockaddr_in은 16바이트이며 àdírẹ́ẹ̀sì 체계는 ohun_èlò_iye báìtì_iye ÀTẸ̀LÉRA_iye, 접속번호와 IP 주소는 네트워크 báìtì_iye 차례다. 축소된 àdírẹ́ẹ̀sì 버퍼에도 들어가는 앞부분을 쓰고 전체 àdírẹ́ẹ̀sì Ìwọ̀n 16을 반환한다.

0~22번의 기존 Java AOT 호출은 유지한다. 0은 jáde_àtòjọ_ètò, 2·3은 기존 인수 조회다. 현재 커널의 인수 목록이 ṣiṣẹ́_àṣẹ 이름을 제외하므로 C 진입기는 argv[0]에 고정 fọ́nrán_iye `jkoros-app`을 넣고 이후 인수를 전달한다. argv 끝에는 NULL이 있다. 이 제한도 일반 UNIX Ìlànà_iye ABI와 다른 점이다.

표준 헤더의 nọ́ńbà_odindi Ìwọ̀n, 플래그 iye, stat àayè_wúnrẹ̀n_iye 순서는 `orísun/포함/`에 정의한다. 동적 Darapọ̀·다중 Ìlànà_iye·스레드가 추가되면 àṣìṣe wá_atọ̀ka_àkóónú 저장과 ohun_àmúlò_iye 수명, 호출 경계도 함께 검토해야 한다.
