# 전체 àtìlẹ́yìn_iye 요청의 현재 ipò_iye

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 gangan_détà C POSIX 일부 기능, 한국어 API/orísun Orúkọ, IDE Fáìlì 보존, 게스트 Java Fáìlì 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/KÀ_MÍ_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 ṣiṣẹ́_àṣẹ 가능한 ní_ṣókí | 전체 지원에 필요한 작업 |
|---|---|---|
| Java ṣàkójọ_ìtumò_èdè_kọ̀ǹpútà_orísun·ṣiṣẹ́_àṣẹ | 게스트 제한형 javac/JVM, ìdágún_iye 단일 클래스와 일부 표준 nǹkan_iye | 일반 nǹkan_iye·ọ̀wọ́_iye Darapọ̀·예외·GC·스레드, 완전한 javac와 표준 ọ̀wọ́_iye ibi_ìpamọ́ |
| Fáìlì | POSIX 서술자, Java 단일 báìtì_iye Fáìlì Stream_iye, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·Ìyànda_iye·잠금·일반 ìlànà_ètò_fáìlì·Àfikún_iye 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP olùpèsè 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 ìgbéṣẹ̀·ìrísí_lẹ́tà_iye·wínńdò OS_iye, AWT 네이티브 연결과 Swing ṣiṣẹ́_àṣẹ 기반 |
| POSIX | 문서화한 Fáìlì·단말·UDP 부분 | Ìlànà_iye·exec/fork·스레드·시그널·시간·mmap·poll·파이프 등과 적합성 ìfọwọ́síìwé |
| 언어별 Orúkọ | 한국어 46개 대응 ìgbéwọlé_iye, gangan_détà C/Java/Fáìlì Orúkọ 적용 | àfojúsùn Èdè 확정, 언어별 용례·역사 근거와 해당 orísun·도구의 ìfọwọ́síìwé |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 ṣiṣẹ́_àṣẹ 환경을 추가하는 방식은 별도의 kánẹ́ẹ̀lì_iye·루트 ìlànà_ètò_fáìlì·OpenJDK·그래픽 apèsè_iye·영구 Store_iye 구성을 가진 ṣiṣẹ́_àṣẹ 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

ṣiṣẹ́_àṣẹ 기반과 추가 àfojúsùn 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
