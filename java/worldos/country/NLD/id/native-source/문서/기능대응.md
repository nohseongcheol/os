## 기존 objek_VALUE 기반 관리 kernel_VALUE 전체를 부팅하기 위해 남은 Sambung

Berikutnya_item 항목은 Java 문법만으로 실행할 수 없는 CPU/Ponsel_VALUE 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot entri_p_VALUE, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 문맥 Store_VALUE
- aktual_data PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA Loop_VALUE
- Java objek_VALUE·ARRAY_VALUE tata_letak_penautan, pengecualian, statik_VALUE inisialisasi, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT tahap_VALUE
- FAT 디스크 구역을 aktual_data ATA 장치와 연결하는 I_O 접착 lapisan_VALUE

위 관리 계층은 engos 기능의 Java 관리 구현과 host 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot entri_p_VALUE, statik_VALUE inisialisasi·bilangan_bulat ARRAY_VALUE, VGA/직렬/PS2, PenafsirPerintah, ruang_pengguna ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 host 루프백 패킷 왕복을 검증했다. 위 표의 objek_VALUE 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
