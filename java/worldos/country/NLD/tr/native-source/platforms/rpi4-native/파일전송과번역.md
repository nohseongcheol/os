# Öz ARM64 çekirdek_değer: FTP, C, JAR와 AOT yürütmek_komut

대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT çekirdek_değer**이다. CPU·cihaz_değer 경계는 C/어셈블리, dosya 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 konak JVM으로 대신 실행하지 않는다.

## 먼저 알아둘 Destek_değer sınır_değer

| istek | 이번 gerçekleme | 남은 klip |
|---|---|---|
| JAR를 yürütmek_komut 파일처럼 yürütmek_komut | `java -jar dosya.jar`, `./dosya.jar bağımsız_değişkenler`; Main-Class와 depo_değer/DEFLATE ZIP, CRC 검사 | 전체 Java SE, 임의의 모든 JAR 호환성 |
| 게스트 AOT | `jaot dosya.class -o dosya.elf`, `jaot dosya.jar -o dosya.elf`; fiili_veri ARM64 기계어 oluşturmak | nesne_değer·özel_durum·Thread·Swing·Socket의 AOT ÇEVİR_değer, 여러 애플리케이션 Sınıf_değer Bağlan |
| C derlemek_kaynak | 게스트 `cc`/`tcc`, TinyCC C 전처리기·ARM64 생성기·링커; Türkçe 식별자와 posix-kor | 전체 libc, 일반 Linux yürütmek_komut dosya, 게스트 C++ derleyici |
| 업로드한 ELF yürütmek_komut | ELF64/AArch64 헤더 검사, 확장자 없는 `./dosya`; Öz ABI 및 명시적인 제한형 Linux ABI | 일반 Linux 바이너리 호환, 동적 링커, 공유 kitaplık |
| dış_değer TCP/UDP | 게스트 lwIP IPv4 işlenen_Yığın, POSIX 소켓과 JVM의 rakam_değer IPv4 ADRES | GENET/Wi-Fi 드라이버, DHCP·DNS·TLS, 실물 Pano 네트워크 sınamalar |
| FTP | 게스트 서비스, 패시브 devir_değer, UTF-8 İsim, STOR/RETR/SIZE/LIST/NLST/MLSD/DELE | TLS·사용자별 izin_değer·하위 디렉터리·영속 depo_değer |
| 한글 Java | 기존 `Türkçe.Öz` 클래스와 dış_değer ADRES UDP 오버로드 | 전체 JDK의 일대일 Türkçe eşleme_değer API |

JVM은 Sınıf_değer 버전 45…52의 문서화한 부분집합이다. `java`는 바이트코드 실행기이고, `jaot`가 별도의 네이티브 yürütmek_komut 파일을 만든다. **JAR Arşiv_değer 해제나 JVM을 함께 묶는 것을 AOT라고 표시하지 않는다.** 지원하지 않는 바이트코드/API는 `jaot`가 진단하고 출력을 만들지 않는다. 기존 metinÇıktısı ELF도 derlemek_kaynak hata_değer 때 보존한다.

Android의 Dalvik/ART는 일반 JVM Sınıf_değer/JAR가 아닌 **DEX**를 실행한다. ART의 AOT에는 GC, Sınıf_değer 로딩, JNI 등 yürütmek_komut 기반도 필요하다. 따라서 ART처럼 기계어로 바꾸는 기능만으로 임의의 OpenJDK JAR 및 Swing이 자동 호환되지는 않는다. [Android 공식 런타임 설명](https://source.android.com/docs/core/runtime)

FTP는 루트 RAM 파일만 공개한다. 익명 로그인이며 비밀번호로 권한을 구분하지 않는다. varsayılan_değer konak 바인딩은 `127.0.0.1`이고, denetim_değer 포트는 2121, 데이터 포트는 50000…50007이다. `--ftp-port 2122`로 denetim_değer 포트를 바꿀 수 있다. 동시에 한 FTP 세션을 제공하며 명령이 없는 세션은 60초 후 닫는다. TYPE A도 바이트를 변경하지 않으므로 프로그램은 바이너리 전송한다.

파일은 **64개, 각각 16 KiB**, 경로는 UTF-8 63바이트이다. makine_başlatma 시 준비되는 `/example`도 이 한도를 공유한다. 초과/끊어진 STOR는 기존 파일에 반영하지 않는다. FTP 업로드는 RAM에만 저장되며 재부팅하면 사라진다. 이 제한 때문에 일반적인 대형 JAR 배포판을 그대로 올릴 수 없다.

QEMU의 raspi4b에는 GENET Ethernet 장치가 없다. 따라서 `network_bridge.py`가 QEMU NAT의 Ethernet과 보조 UART의 SLIP를 변환한다. **TCP Bağlan işlem_değer_girdi·체크섬·재전송·FTP 명령과 dosya 저장은 게스트 안에서 수행한다.** konak 브리지는 FTP 서버가 아니다. [QEMU 공식 cihaz_değer Destek_değer girdi_Liste](https://www.qemu.org/docs/master/system/arm/raspi.html)

이 경로는 QEMU에서 검증했다. 보조 UART의 fiili_veri Pi 4 핀/클럭 설정과 내장 RJ45 GENET 드라이버는 gerçekleme·검증하지 않았으므로, SD 이미지에 커널이 포함되어 있다는 사실을 fiili_veri 보드의 LAN/FTP Eylem 보장으로 해석하면 안 된다.

## Türkçe Java를 게스트에서 컴파일하고 AOT yürütmek_komut

게스트 `vi 빛.java`로 Sonraki_öğe 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] bağımsız_değişkenler) throws Exception {
        int SUM_değer = 0;
        int 수 = 1;
        while (수 <= 10) {
            SUM_değer = SUM_değer + 수;
            수 = 수 + 1;
        }
        Türkçe.Öz.metinÇıktısı.수쓰기(SUM_değer);
        Türkçe.Öz.dosya.Yazma("aot.txt", "한글 AOT dosya 😀");
        Türkçe.Öz.metinÇıktısı.yazma_hat(Türkçe.Öz.dosya.Okuma("aot.txt"));
    }
}
```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 oluşturmak·연결한다. yürütmek_komut 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 Destek_değer 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 statik_değer metot_değer/alan_değeri, int 계열, bilgi 배열과 Başvuru, bağımsız_değişkenler DİZİ_değer, koşul·dal·öğe_değer_58902391, dize_değer 리터럴, `System.out.print/println`의 int/String, Türkçe metinÇıktısı·dosya Okuma/쓰기로 제한된다. Sınıf_değer/metot_değer 수와 işlenen_Yığın 등에도 고정 상한이 있다. Java özel_durum işlem_değer_girdi, nesne_değer oluşturmak, 가상 metot_değer 일반, switch/wide, long/float/double, invokedynamic, dize_değer 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 DİZİ_değer erişim_girdi/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java özel_durum 객체로 전달하지 않는다.

artış_değer 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 hizalamak_değer 때문에 짧은 클래스도 이 한도를 넘을 수 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 nesne_değer·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 Destek_değer klip 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 개발 매뉴얼](개발안내.md)을 참고한다.

JAR는 하나의 애플리케이션 Sınıf_değer 경로다. 내부 İsim `paket_iş/program_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 Türkçe 클래스를 추가로 찾지만 geçerli_öğe 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·Şifrele_veri ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 수/VM yığın_değer 제한은 그대로 적용된다.

## C에서 Türkçe POSIX 호출

게스트에서 `vi 인사.c`로 작성하거나 FTP로 소스를 업로드한다.

```c
#include <Dosya_ABI.h>

int main(void) {
    const char 인사말[] = "Öz ARM64 C에서 한글 POSIX 호출\n";
    int 문서 = açık_Dosya("인사.txt", R_W | 없으면만들기 | kesmek_içindekiler, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = yazma_Dosya_veri(문서, 인사말, sizeof(인사말) - 1);
    Kapat_Dosya(문서);
    yazma_Dosya_veri(1, 인사말, sizeof(인사말) - 1);
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

```text
cc 인사.c -o 인사.elf
run 인사.elf
cat 인사.txt
```

TinyCC의 표준 C giriş_noktası `main`을 사용한다. 기존 konak C/C++ SDK의 `Start_kullanıcı_program(int)` 진입점과 구분한다. bildirimler dosya·çalıştır nesne_değer·`libposix-kor-user.a`는 derleyici 내부의 Okuma 전용 SDK에 들어 있다. C 전처리기/구조체/işlev_değer/재귀/işaretçi/부동소수점 oluşturmak 등을 사용하되 **일반 libc/libstdc++를 제공한다는 뜻은 아니다**. 제공하지 않는 함수는 Bağlan 오류가 난다. derleyici 자체의 문자/rakam_değer ÇEVİR_değer 지원도 완전한 libc 대체품이 아니다.

`açık_Dosya` 등은 별도의 모의 호출이 아닌 기존 `pk_open` 등의 Türkçe 매크로이며, ELF의 SVC를 통해 fiili_veri Java dosya 체계에 도달한다. dosya/yuva_değer 호출 목록은 [kullanıcı_alanı ABI](kullanıcı_Ara_ABI.md)에 있다. C/C++ konak SDK yürütmek_komut 파일도 FTP로 업로드 후 `run` 또는 `./dosya`로 실행하며 확장자는 필요 없다. Linux ARM64 statik_değer ELF에는 별도의 제한된 호환 yol `run --linux dosya`을 추가했다. [ELF·Linux ABI 매뉴얼](yürütülebilir_ABI.md)에 정확한 biçim_değer·시스템 호출·ADRES 제한을 정리했다.

## Türkçe 네트워크·작업·화면 API

| Sınıf_değer | 호출 예 | yürütmek_komut yol |
|---|---|---|
| `metinÇıktısı` | `yazma_hat("안녕")`, `수쓰기(42)` | JVM 및 제한형 AOT |
| `dosya` | `Yazma("문서.txt", "içerik_değer")`, `Okuma("문서.txt")` | JVM 및 제한형 AOT |
| `iletişim` | `Aç(0)`, `göndermek(uç_nokta, "10.0.2.2", 9000, "한글")`, `almak(uç_nokta)` | JVM의 UDP |
| `cxn_taşıma` | `Bağlan("10.0.2.2", 9000)`, `dinlemek_uç_nokta(9000)`, `almak(sunucu_değer)` | JVM의 Socket/ServerSocket |
| `작업` | `çalıştır(Runnable)`, `기다리기(Thread)`, `ÖDEME_Görev()` | JVM의 협력식 yazışma_değer |
| `Pencere`, `ekran_öğesi` | Pencere·버튼·karakter_değer·metin_alanı·Olay Bağlan | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 Türkçe 호출 계층을 추가한다. `iletişim(通信)`, `Bağlan(連結)`, `metinÇıktısı(出力)`은 기존 단어의 뜻을 사용한다. `작업 yazışma_değer`은 한 yürütmek_komut 흐름을 가닥에 빗댄 tanımlayıcı_değer_a78cee47 표현, `taşımak_değer`는 포트의 접점을 설명하는 표현이다. 새 tanımlayıcı_değer_a78cee47 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

dış_değer 주소는 rakam_değer IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 Öz ABI이며 JVM이 제한된 bekle_değer/재시도를 제공한다. TCP connect 대기는 최대 1초, kullanıcı_alanı program_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 yürütmek_komut kullanıcı_alanı 서버와 pthread는 아직 없다. FTP는 kullanıcı_alanı program_f5044b9b 기한과 별개인 çekirdek_değer 서비스다.

게스트의 kullanıcı_alanı TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 araçlar/yürütmek_komut.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 varsayılan_değer denetim_değer/데이터 포트와 겹치면 yürütmek_komut 전에 거부한다.

`build/verification/ftp/report.json`은 fiili_veri FTP devir_değer, 한글 dosya, Boyut 초과 보존, Arşiv_değer JAR yürütmek_komut, 게스트 C derlemek_kaynak/ELF 재업로드, dış_değer Java TCP/UDP, 게스트 javac/AOT 실행을 기록한다. `serial.log`에서 게스트 명령과 결과를 확인할 수 있다. 보고서의 çekirdek_değer SHA-256과 dağıtım_değer 이미지의 커널을 비교한다.

빌드는 기존 JDK/Clang/AArch64 binutils와 함께 `../rpi4/build/rootfs`의 ARM64 SDK bildirim 헤더와 libgcc 산술 보조 함수를 사용한다(`make rpi-prepare`). **musl libc, Linux çekirdek_değer, 동적 로더를 게스트에 링크하지 않는다.** TinyCC/lwIP/uzlib 원본과 라이선스·버전 정보는 `vendor/`, 이식 코드는 `ccompiler/`, `network/`, `kullanıcı_alanı/paket_iş.c`에 있다.

전체 JDK/AOT JVM으로 확장하려면 타입 doğrulamak_5fb2b747·nesne_değer/özel_durum/GC·동적 로딩·JNI, 영속 dosya işletim_sistemi_değer·mmap/TLS/시그널·스레드 ABI, OpenJDK native kitaplık, GUI peer/폰트/입력기, GENET 및 실물 cihaz_değer 검증이 더 필요하다. 이 문서의 yürütmek_komut 시험은 그 전체 이식을 대신하지 않는다.
