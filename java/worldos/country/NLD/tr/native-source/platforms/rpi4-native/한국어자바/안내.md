# Türkçe Java iletişim·G_Ç·özel_durum API

패키지는 `Türkçe.Öz`다. konak `javac --release 8`로 컴파일한 class를
Öz ARM64 커널의 JVM에서 실행한다. iletişim·dosya·özel_durum API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 yazışma_değer API는 Öz JVM 전용이다.
기존 표준 Java kitaplık 전체의 Türkçe 번역판은 아니다.

```java
import Türkçe.Öz.*;

public class ağ {
    public static void main(String[] bağımsız_değişkenler) throws G_Ç_özel_durum {
        cxn Bağlan = cxn.Aç("10.0.2.2", 9000);
        try {
            Bağlan.ZAMANAŞIMI(700);
            Bağlan.metinÇıktısı().Yazma(문자.kodlamak("안녕하세요\n"));
            giriş_akışı artış_değer = Bağlan.artış_değer();
            metinÇıktısı.수쓰기(artış_değer.Okuma());
        } catch (bekle_ZAMANAŞIMI_özel_durum hata) {
            metinÇıktısı.yazma_hat(hata.설명());
        } finally {
            Bağlan.Kapat();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
kullanıcı_alanı 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 dize_değer 리터럴에 사용하는 표준 클래스다. Öz 실행기는 `public static void çalıştır()`도 진입점으로 받는다.

## 통신과 akış_değer

| Sınıf_değer | Türkçe 호출 |
|---|---|
| cxn | `Aç(ADRES, bağlantı_noktası_numarası)`, `artış_değer()`, `metinÇıktısı()`, `ZAMANAŞIMI(밀리초)`, `bağlantı_noktası_numarası()`, `yerel_bağlantı_noktası_numarası()`, `연결됨()`, `bilgi_teknolojisi_kapalı()`, `Kapat()` |
| almak_taşımak | `Aç(bağlantı_noktası_numarası)`, `almak()`, `bağlantı_noktası_numarası()`, `ZAMANAŞIMI(밀리초)`, `bilgi_teknolojisi_kapalı()`, `Kapat()` |
| giriş_akışı | `Okuma()`, `Okuma(byte[])`, `Okuma(byte[], çalıştır, süre_değer)`, `Kapat()` |
| çıkış_akışı | `Yazma(int)`, `Yazma(byte[])`, `Yazma(byte[], çalıştır, süre_değer)`, `내보내기()`, `Kapat()` |
| veri_birimi_Kanal | `Aç(bağlantı_noktası_numarası)`, `göndermek(ADRES, bağlantı_noktası_numarası, metin)`, `almak()`, `ZAMANAŞIMI(밀리초)`, `bağlantı_noktası_numarası()`, `bilgi_teknolojisi_kapalı()`, `Kapat()` |
| cxn_taşıma | `Aç(...)`, `수신열기(...)`는 위 Türkçe 객체를 İade_KR |
| 검사 | `참인지(koşul, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`Okuma()`의 dosya 끝은 -1, DİZİ_değer 읽기의 반환값은 fiili_veri 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. bağlantı_noktası_numarası 0은 빈 번호를 자동 배정한다.
UDP 전문은 geçerli_öğe Öz 커널에서 512바이트까지 받으며, 주소는 rakam_değer IPv4를 사용한다.
`localhost` 루프백 외의 İsim 풀이(DNS)는 Öz 커널에 아직 없다.

기존 `cxn_taşıma.Bağlan/dinlemek_uç_nokta/almak`, `iletişim.Aç/göndermek/almak`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `cxn`, `almak_taşımak`, `veri_birimi_Kanal`를 쓴다.

## Türkçe özel_durum

모든 아래 클래스는 varsayılan_değer 생성자, `새예외("설명")` 형태의 dize_değer 생성자와
`설명()`을 제공한다. fiili_veri oluşturmak 문법은 `new bekle_ZAMANAŞIMI_özel_durum("bekleme_durumu 끝")`이다.

| Türkçe özel_durum | 상위 Sınıf_değer / 용도 |
|---|---|
| özel_durum | `java.lang.Exception`, 직접 던지는 일반 검사 özel_durum |
| yürütme_özel_durum | `java.lang.RuntimeException` |
| G_Ç_özel_durum | `java.io.IOException`, Türkçe dosya·iletişim API의 검사 özel_durum |
| bekle_ZAMANAŞIMI_özel_durum | `G_Ç_özel_durum`, iletişim ZAMANAŞIMI 초과 |
| ADRES_ARA_özel_durum | `G_Ç_özel_durum`, ADRES doğrulamak hata_değer |
| 파일없음예외 | `G_Ç_özel_durum`, dosya Aç hata_değer |
| iletişim_özel_durum | `G_Ç_özel_durum`, 표준 SocketException ÇEVİR_değer |
| geçersiz_bağımsız_değişken_özel_durum | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `geçersiz_bağımsız_değişken_özel_durum` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| boş_referans_özel_durum | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| Durum_özel_durum | `java.lang.IllegalStateException` |
| TÜR_Yayın_özel_durum | `java.lang.ClassCastException` |
| Negatif_DİZİ_boyutlandırmak_hata | `java.lang.NegativeArraySizeException` |
| DİZİ_depo_hata | `java.lang.ArrayStoreException` |
| yazışma_Durum_özel_durum | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 bekle_değer 중단 |

`özel_durum`와 `yürütme_özel_durum`는 모든 Türkçe 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, dosya·iletişim 전체를 잡으려면 `catch (G_Ç_özel_durum hata)`를 쓴다.
Türkçe API가 표준 G_Ç 오류를 Türkçe 예외로 변환한다.
기존 Türkçe iletişim 호출에서 `SocketTimeoutException`을 잡던 코드는
`bekle_ZAMANAŞIMI_özel_durum`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
özel_durum 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
geçerli_öğe Öz JVM에 이 20종을 추가했다. 임의의 kullanıcı_alanı Throwable 하위 Sınıf_değer 전체를
지원하도록 확장했다는 뜻은 아니다.

## derlemek_kaynak·yürütmek_komut

```sh
cd /home/user/jkoros/platforms/rpi4-native
make oluştur
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 sınamalar/자바/한국어통신시험.java
python3 araçlar/yürütmek_Dosya.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 kullanıcı_alanı JVM ELF 안에 탑재된다. `.jar`는 konak javac의
Sınıf_değer 경로로 사용한다. kaynak_ağaç 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 Türkçe 예외의 `throws` 선언과 그 import를 인식한다.
Öz JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·nesne_değer·yuva_değer 예제 전체의 kaynak_ağaç 컴파일은 konak javac를 사용한다.
`/example/java/DosyaÖrneği.java`는 게스트 javac로도 컴파일할 수 있다.

fiili_veri TCP/UDP 예제는 [AğÖrneği.java](../../../example/java/AğÖrneği.java),
yürütmek_komut 절차는 [example 안내](../../../example/README.md),
kaynak_ağaç 명명 원칙은 [명명 안내](../명명/안내.md)에 있다.

## Swing Pencere 예제

`/example/java/PencereÖrneği.java`와 컴파일된 `.class`가 makine_başlatma 시 준비된다.
`cd /example/java` Sonraki_öğe `java PencereÖrneği`로 연다. İsim artış_değer, 인사하기 버튼,
인사말과 tık_değer 횟수 yenilemek, X 닫기를 지원한다.

| 기능 | Türkçe 직접 API |
|---|---|
| Runnable / run | `실행할일.Çalıştır()` |
| ActionListener / actionPerformed | `동작받이.almak_Eylem(Eylem_uyarı uyarı)` |
| ActionEvent | `Eylem_uyarı.komut_SMS()`, `olay_kaynağı()`, `Dizin()` |
| JFrame | `Pencere(pencere_Başlık, 폭, 높이)`, `Ekle_öğe(화면구성요소)`, `şov_pencere()`, `Kapat()`, `보이는가()` |
| JButton | `düğme(metin, 가로, Dikey_konum, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `Etiket(...)`, `metin_alanı(...)` |
| 공통 화면 öğe_değer | `화면구성요소.글읽기()`, `yazma_SMS(metin)`, `자리정하기(가로, Dikey_konum, 폭, 높이)` |
| SwingUtilities.invokeLater | `olay_sıra.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `arkaPlanGörevi(실행할일)`, `Start_Görev()`, `기다리기()`, `살아있는가()`, `ÖDEME_Görev()` |
| 명령행 | `çalıştır()`, `실행인수.öğe_BAĞ_DEĞ_SAY()`, `실행인수.metin(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
Öz JVM의 `한국어화면호출`, `işlem_yazışma`가 Türkçe Sınıf_değer·metot_değer·서술자를
해석해 화면 요소와 yürütmek_komut 가닥을 직접 만든다. Eylem 알림도 Öz 객체이며
콜백으로 `Çalıştır`와 `almak_Eylem`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 yürütmek_komut 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 Öz JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 konak JVM에서 무동작 객체가 생기지 않도록 하는 reddetmek_değer 경로다.
Öz JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 gerçekleme API를
실행할 수 없다. konak javac로 컴파일한 BACK_değer Öz JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import Türkçe.Öz.*;
public class 가닥예제 implements 실행할일 {
    public void Çalıştır() { metinÇıktısı.yazma_hat("Türkçe 작업 yürütmek_komut"); }
    public static void çalıştır() throws 대기중단예외 {
        arkaPlanGörevi yazışma_değer = 작업.çalıştır(new 가닥예제());
        작업.기다리기(yazışma_değer);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
DİZİ_değer bağımsız_değişkenler 대신 `실행인수`, 길이는 `문자.bayt_BAĞ_DEĞ_SAY`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
Öz 실행기는 bağımsız_değişkenler 없는 `çalıştır()`을 우선한다.
기존 Türkçe 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.çalıştır(Runnable)`을 사용하던 코드는 새 Türkçe 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API Destek_değer 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 Sınıf_değer·metot_değer 이름과 서술자가 남는다.
Türkçe İsim 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·metot_değer 재정의, native Bağlan, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS tanımlayıcı_değer](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS metot_değer Başvuru](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
