# 전체 støtte_VERDI 요청의 betalt_vare status_VERDI

forespørsel 전체는 아직 완료되지 않았다. betalt_vare ISO는 eget Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 faktisk_data C POSIX 일부 기능, norsk API/KILDE Navn, IDE Fil 보존, 게스트 Java Fil 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/Viktig_fil_eb81d7d9.md)를 기준으로 판단한다.

eget 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 Utfør_kommando 환경을 추가하는 방식은 별도의 kjerne_VERDI·루트 filsystem·OpenJDK·그래픽 server_VERDI·영구 Store_VERDI 구성을 가진 Utfør_kommando 경로가 된다. 후자는 기존 eget 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

Utfør_kommando 기반과 Tilføye_oppføring mål 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. betalt_vare 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
