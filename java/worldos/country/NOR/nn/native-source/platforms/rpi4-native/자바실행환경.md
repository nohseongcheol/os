# 자체 ARM64 JVM 0.4와 한국어 bibliotek

한국어 통신·unntak 사용법은 [한국어 Java API](한국어자바/Viktig_eb81d7d9.md), FUNCTION_VALUE·variabel_VALUE·Fil 이름의 변경과 어원 근거는 [명명 Viktig_eb81d7d9](명명/Viktig_eb81d7d9.md)를 참고한다.

JAR Utfør_kommando, ekstern_VALUE IPv4 TCP/UDP, 별도 statisk_VALUE 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 objekt_VALUE·Thread·Swing은 JVM 경로의 기능이며 AOT støtte_VALUE 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 Utfør_kommando**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK time_VALUE bibliotek 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 time_VALUE·statisk_VALUE metode_VALUE 중심이던 실행기를 objekt_VALUE·bibliotek Utfør_kommando 기반으로 넓힌 것이다.

## 실행과 byggje_kjelde

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# 자체 kjerne_VALUE 안에서 kjelde_tre byggje_kjelde → class Utfør_kommando, 한국어 API 호출
python3 Verktøy/Utfør_fil.py 시험/자바/한글소스.java

# objekt_VALUE·unntak 등은 vert JDK로 Java 8 class를 만든 후 자체 커널에서 Utfør_kommando
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 Verktøy/Utfør_fil.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 Overfør_VALUE
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 Verktøy/Utfør_fil.py build/my-java/객체시험.class \
  --include build/my-java/bakgrunn_VALUE.class --include build/my-java/grein_VALUE.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.time_VALUE.class`라는 RAM Fil 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.time_VALUE`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.time_VALUE`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar Fil.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 한국어 클래스만 찾는다. 배포 한국어 bibliotek JAR는 vert javac의 classpath로 사용하며, 같은 클래스가 brukar JVM ELF에도 Les 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 statisk_VALUE metode_VALUE, int/boolean/char/String, tilstand·gjentaking_VALUE, streng_VALUE 결합, 일부 Fil 스트림 등의 **자체 부분집합 컴파일러**다. objekt_VALUE erklæring·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 자체 JVM에서 실행한다. 한국어 API 중 Utdata·문자 스칼라 FUNCTION_VALUE·Fil Les/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] Argument) throws Exception {
        한국어.자체.Utdata.skrive_line("안녕하세요😀");
        한국어.자체.Utdata.수쓰기(한국어.자체.문자.teiknkode_COUNT("한글😀"));
        한국어.자체.Fil.Skriv("인사.txt", "한글 Fil😀");
        한국어.자체.Utdata.skrive_line(한국어.자체.Fil.Les("인사.txt"));
    }
}
```

## 한국어 API

독립 패키지 **`한국어.자체`**를 사용한다. Linux판 `한국어.자바`가 요구하는 NIO/Swing/HTTP API를 자체 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 time_VALUE Namn·metode_VALUE·Argument·felt_VALUE_0f39cf1c·Fil 이름에 한국어를 사용한다. 표준 Java time_VALUE 이름은 호환성을 위해 보존한다.

## Utfør_kommando 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(한국어 time_VALUE 포함), class당 16 KiB·konstant_VALUE 풀 511항목, 전체 metode_VALUE/felt_VALUE_0f39cf1c 각각 512개. metode_VALUE CODE_VALUE 8 KiB, lokal_område variabel_VALUE·피연산자 스택 각각 128슬롯, Argument 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 Utfør_kommando 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- objekt_VALUE 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 faktisk_data 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 Fil·대형 streng_VALUE·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 Kommando 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 vindauge byte_MODE 시 중단·재개한다. 일반 tenar_VALUE·계산의 무제한 실행은 아직 없다. 미지원 Kommando·ressurs_VALUE 부족은 명시적인 오류로 종료한다.
- RAM Fil 최대 64개, 파일당 16384바이트, STIGE UTF-8 63바이트. RAM 디렉터리와 node_VALUE_6a3b6fa7/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 한국어 class는 RAM Fil 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 betalt_vare 경로에서 kjelde_tre·time_VALUE·data 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 ekstern_VALUE IPv4를 제공한다. faktisk_data GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. 전문 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 Utfør_kommando 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 ARRAY_VALUE, 완전한 ARRAY_VALUE 공변성·인터페이스 lag_VALUE 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/kryptere_data/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 støtte_VALUE 부분집합은 아래 및 개발 매뉴얼을 참고한다. time_VALUE Fil 전체 검증기·tilgang_oppføring løyve_VALUE/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 verne_VALUE 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM VALUE/bekrefte/time_VALUE 로더와 unntak 모델 → 영속 VFS·mmap·Klokke·원자 operasjon_VALUE·faktisk_data 스레드/synkronisere ABI → OpenJDK java.base 및 native bibliotek 이식 → mobil_VALUE 네트워크·TCP/IP → vindauge 시스템/skrift_VALUE/입력기·java.desktop → Java SE 호환성 시험. betalt_vare 자체 JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## JVM 0.3: 네트워크와 GUI filtype_VALUE

`Socket`/`ServerSocket` generere·Kopla_til·accept·양방향 InputStream/OutputStream·close·EOF·TIME_VALUE 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 ekstern_VALUE siffer_VALUE IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 avslutte_p 16개, Java 루프백 버퍼 1024바이트, ekstern_VALUE TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. interaktiv 이벤트 대기는 Utfør_kommando 기한을 갱신하고 Terminal byte_MODE 시 프로세스 상태를 Store_VALUE·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

한국어 `vindauge`, `miniprogram`, `연결통신` 클래스를 배포 JAR와 자체 JVM 내장 자원에 추가했다. 상세 metode_VALUE·제한·kjelde_tre·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## 한국어 객체의 직접 Utfør_kommando

`vindauge`, `Etikett`, `SMS_felt`, `knapp`, `hending_kø`, `동작알림`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. 자체 JVM의 objekt_VALUE generere,
format_VALUE 검사, 화면 호출, Hending 큐, tråd_VALUE 스케줄러에 한국어 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 Utfør_kommando 경로도 유지한다.
한국어 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

자체 실행기의 한국어 진입점은 `public static void Køyr_2()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 한국어 진입점을 우선한다.
명령행 인수는 `실행인수.vare_COUNT()`와 `실행인수.Tekst(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. statisk_VALUE Fil 예제는 게스트
javac로도 컴파일하며, GUI/tråd_VALUE 소스는 vert `javac --release 8`을 사용한다.
직접 GUI/tråd_VALUE API는 자체 JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
한국어 가닥의 Utfør_kommando·vent_VALUE·중복 Køyr_2 avvise_VALUE, GUI Hending nullpunkt_VALUE·INDEX·콜백을 검사한다.
