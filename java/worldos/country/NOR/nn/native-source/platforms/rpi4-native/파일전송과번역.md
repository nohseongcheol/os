## 한국어 Java를 게스트에서 컴파일하고 AOT Utfør_kommando

게스트 `vi 빛.java`로 Neste_vare 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] Argument) throws Exception {
        int SUM_VALUE = 0;
        int 수 = 1;
        while (수 <= 10) {
            SUM_VALUE = SUM_VALUE + 수;
            수 = 수 + 1;
        }
        한국어.자체.Utdata.수쓰기(SUM_VALUE);
        한국어.자체.Fil.Skriv("aot.txt", "한글 AOT Fil 😀");
        한국어.자체.Utdata.skrive_line(한국어.자체.Fil.Les("aot.txt"));
    }
}
```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 generere·연결한다. Utfør_kommando 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 støtte_VALUE 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 statisk_VALUE metode_VALUE/felt_VALUE_0f39cf1c, int 계열, heiltal 배열과 Oppslagsverk, Argument ARRAY_VALUE, tilstand·grein·gjentaking_VALUE, streng_VALUE 리터럴, `System.out.print/println`의 int/String, 한국어 Utdata·Fil Les/쓰기로 제한된다. time_VALUE/metode_VALUE 수와 스택 등에도 고정 상한이 있다. Java unntak Prosess_VALUE_oppføring, objekt_VALUE generere, 가상 metode_VALUE 일반, switch/wide, long/float/double, invokedynamic, streng_VALUE 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 ARRAY_VALUE tilgang_oppføring/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java unntak 객체로 전달하지 않는다.

입력 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 justere_VALUE 때문에 짧은 클래스도 이 한도를 넘을 수 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 objekt_VALUE·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 støtte_VALUE klipp 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 개발 매뉴얼](개발안내.md)을 참고한다.

JAR는 하나의 애플리케이션 time_VALUE 경로다. 내부 Namn `bunt/app_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 한국어 클래스를 추가로 찾지만 betalt_vare 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·kryptere_data ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 수/VM 힙 제한은 그대로 적용된다.

## 한국어 네트워크·작업·화면 API

| time_VALUE | 호출 예 | Utfør_kommando STIGE |
|---|---|---|
| `Utdata` | `skrive_line("안녕")`, `수쓰기(42)` | JVM 및 제한형 AOT |
| `Fil` | `Skriv("문서.txt", "Innhald_VALUE")`, `Les("문서.txt")` | JVM 및 제한형 AOT |
| `통신` | `Opna(0)`, `sende(endepunkt, "10.0.2.2", 9000, "한글")`, `받기(endepunkt)` | JVM의 UDP |
| `연결통신` | `Kopla_til("10.0.2.2", 9000)`, `lytte_endepunkt(9000)`, `받기(tenar_VALUE)` | JVM의 Socket/ServerSocket |
| `작업` | `Køyr_2(Runnable)`, `기다리기(Thread)`, `YIELD_oppgåve()` | JVM의 협력식 tråd_VALUE |
| `vindauge`, `miniprogram` | vindauge·버튼·teikn_VALUE·SMS_felt·Hending Kopla_til | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 한국어 호출 계층을 추가한다. `통신(通信)`, `Kopla_til(連結)`, `Utdata(出力)`은 기존 단어의 뜻을 사용한다. `작업 tråd_VALUE`은 한 Utfør_kommando 흐름을 가닥에 빗댄 기술 표현, `port_VALUE`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

ekstern_VALUE 주소는 siffer_VALUE IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 자체 ABI이며 JVM이 제한된 vent_VALUE/재시도를 제공한다. TCP connect 대기는 최대 1초, brukar app_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 Utfør_kommando brukar 서버와 pthread는 아직 없다. FTP는 brukar app_f5044b9b 기한과 별개인 kjerne_VALUE 서비스다.

게스트의 brukar TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 Verktøy/Utfør_kommando.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 standardverdi styring_VALUE/데이터 포트와 겹치면 Utfør_kommando 전에 거부한다.
