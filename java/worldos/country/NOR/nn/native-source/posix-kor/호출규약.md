대상은 jkoros i386 ELF32다. Linux i386의 호출 번호와 바이너리 호환이 아니다. C의 cdecl 인수를 `maskin/operativsystem_Samtalar.s`에서 EAX(INDEX), EBX·ECX·EDX·ESI·EDI(첫째~다섯째 Argument)로 변환한다. EBX·ESI·EDI·EBP를 보존하며 결과는 EAX다. kjerne_VALUE 실패는 음수 FEIL INDEX, C bibliotek 실패는 -1과 양수 errno다.
