# JNplOS

현재 নিজ ARM64 배포판은 [LICENSE](LICENSE)의 COSL 상업 조건을 유지한다. 제3자 라이선스의 권리는 별도로 보장하며, 배포 시 উত্স_ট্রী·재연결 자료를 포함하는 절차는 [COSL 배포 স্বনিবন্ধ_eb81d7d9](platforms/rpi4-native/COSL배포안내.md)에 있다.

নিজ ARM64 판의 `ipconfig`/`ip`, `ping`, `ps`/`top`, `free`/`df`, `poweroff`와 বাংলা 명령은 [네트워크·অপারেটিং_সিস্টেম_মান আদেশ স্বনিবন্ধ_eb81d7d9](platforms/rpi4-native/네트워크와체계명령.md)를 참고한다. 새 커널을 부팅한 ফিরে_যান_মান `help system`으로 볼 수 있다.

Raspberry Pi 4 **নিজ Java ARM64 কারনেল_মান**은 [নিজ Pi4 স্বনিবন্ধ_eb81d7d9](platforms/rpi4-native/স্বনিবন্ধ_eb81d7d9.md)에 있다. Linux 없이 부팅하며 GUI আদেশ_ব্যাখ্যাকারী·vi, নিজ JVM의 Swing 일부 API, TCP/UDP·FTP, 게스트 TinyCC·MicroPython, C/C++의 posix-kor 호출을 제공한다. [বাংলা Java 통신·ব্যতিক্রম API](platforms/rpi4-native/한국어자바/স্বনিবন্ধ_eb81d7d9.md)와 [বাংলা উত্স_ট্রী 명명](platforms/rpi4-native/명명/স্বনিবন্ধ_eb81d7d9.md)을 지원한다. [নিজ SSH·VNC 및 GENET 드라이버](platforms/rpi4-native/외부접속안내.md)를 포함하며, 네트워크는 QEMU의 UART SLIP 경로로 검증했다. প্রকৃত_ডাটা Pi 4 GENET 동작은 미검증이고, USB 입력·영속 저장과 전체 OpenJDK·Swing은 아직 সমর্থন_মান ক্লিপ 밖이다.

Raspberry Pi 4용 Linux·OpenJDK 실행판과 ব্যবহারকারী 환경 অপসারণ_করা_মান 기능은 [라즈베리파이 실행판](platforms/rpi4/README.md)에 있다. প্রকৃত_ডাটা ARM64 JDK/JRE와 시스템·ব্যবহারকারী গঠন_ছবি গঠন_সিস্টেম 경로를 제공한다. 기존 নিজ x86 커널과는 별도 কার্যকর_করুন_আদেশ 기반이다. 일반 Java `.class`/JAR의 কার্যকর_করুন_আদেশ নথির_নাম 생성은 [OpenJDK কার্যকর_করুন_আদেশ নথির_নাম](compiler/OpenJDK-실행파일.md), বাংলা API는 [বাংলা Java লাইব্রেরি](한국어자바/স্বনিবন্ধ_eb81d7d9.md)를 참고한다.

`jkoros`는 `engos`의 기능을 Java 관리 커널로 옮기는 프로젝트다. 프로젝트가 소유하는 Java ফাংশন_মান, 변수, বিন্যাস_মান 및 Java নথির_নাম 이름은 한국어로 작성한다. 표준 Java 실행기의 `main`, Java 표준 লাইব্রেরি বিন্যাস_মান, x86 부트 ABI 등 외부 계약은 보존한다. নিজ ARM64 실행기는 বাংলা `চালনা()`도 진입점으로 지원하며, বাংলা GUI·작업 가닥을 JVM에 직접 구현했다. নিজ ARM64 C 연결부·Python 도구와 공용 x86·ARM64 AOT 번역기의 নিজ 이름도 한국어로 작성한다. 이전 경로의 호환 ভুক্তি_বিন্দু, OpenJDK 보조 도구와 Linux সংস্করণ_মান 도구에는 영어 이름이 남아 있고 [명명 원칙·말의 근거·전체 উৎস_নথি 검토 ক্লিপ](platforms/rpi4-native/명명/স্বনিবন্ধ_eb81d7d9.md)를 별도로 기록한다.

## 현재 구현

아래 목록은 기존 `ঐতিহ্য_উত্স/`의 JVM 관리 커널에 대한 것이다. প্রকৃত_ডাটা 네이티브 커널의 범위는 `os/স্বনিবন্ধ_eb81d7d9.md`에서 별도로 설명한다.

- সারিকরণ_করা_মান 할당과 해제를 지원하는 기억공간 ব্যবস্থাপক_মান
- ইমেইল 공간, পৃষ্ঠা_মান সংযোগ_স্থাপনা, লেখা 시 নজির_মান(COW)
- প্রসেসর_মান সনাক্তকারী_মান, প্রস্তুত_করুন 대기열, fork/wait অবস্হা_মান
- 과정별 নথির_নাম 서술자, open/read/seek/dup/close
- ELF32 식별 및 শাখা_মান_366e0bfa 검사
- 키보드·마우스 입력 ঘটনা 대기열
- 직렬 단말과 네이티브 হার্ডওয়্যার_মান 경계
- 관리 কারনেল_মান 전체 자동 시험

세부 대응 범위와 아직 필요한 네이티브 연결은 [기능 대응표](문서/기능대응.md)에 기록한다.

## 빌드와 시험

새 네이티브 구현은 `compiler/`와 `os/`에 있다. 기존 `ঐতিহ্য_উত্স/`의 JVM 관리 커널은 그대로 보존하며, 두 구현의 시험과 기능 범위는 서로 다르다.

```sh
cd /home/user/jkoros
make                 # 네이티브 계산 예제 + Java কারনেল_মান ELF
make iso             # os/build/kernel.iso
make run             # QEMU 직렬 단말; help 입력 (종료는 Ctrl+A, X)
make run-gui         # ISO를 QEMU 화면/PS2 키보드로 কার্যকর_করুন_আদেশ
make vbox            # 전용 VirtualBox VM 자동 সৃষ্টি_করুন·কার্যকর_করুন_আদেশ (GUI)
make vbox-status     # VirtualBox অবস্হা_মান·ISO·직렬 লগ_সারি পথ_2 যাচাই_করা
make test-vbox       # VirtualBox অ্যাপ_অ্যাপ_লঞ্চার অবস্হা_মান প্রসেসর_মান_ভুক্তি 시험 (প্রকৃত_ডাটা VM পরিবর্তন_করা_মান 없음)
make test            # 컴파일러 시험 + ELF/ISO 부팅 및 আদেশ 입력 시험
make apps            # 독립 ব্যবহারকারী ELF অ্যাপ_f5044b9b গঠন_সিস্টেম
make test-network    # ব্যবহারকারী মোড_মান·UDP 왕복·মেমরি_ডাটা রক্ষা_করুন_মান 시험
make test-java       # 게스트 javac/JVM + OpenJDK 양방향 교차 কার্যকর_করুন_আদেশ 시험
make posix-kor       # বাংলা C 헤더와 প্রকৃত_ডাটা কারনেল_মান 호출 লাইব্রেরি
make test-posix      # নথির_নাম/UDP/ভাণ্ডার_মান/Java নথির_নাম ইনপুট_আউটপুট 시험
make -C os run-store # 전용 ভাণ্ডার_মান 매체로 QEMU 부팅
make legacy-test     # 아래 기존 JVM 관리 커널의 47개 시험
```

`compiler/`는 호스트의 `javac`를 문법·টাইপ_করুন_মান 검사 전단으로 사용하고 নিজ 바이트코드→x86 변환기로 ELF32 기계어를 만든다. 빌드할 때는 JDK가 필요하지만 생성된 커널과 ELF는 외부 JVM 없이 실행된다. 전체 Java, বস্তু_মান 모델, 표준 라이브러리와 기존 관리 কারনেল_মান 전체의 AOT 변환은 아직 지원하지 않는다. 자세한 সমর্থন_মান 문법과 명령은 [컴파일러 স্বনিবন্ধ_eb81d7d9](compiler/স্বনিবন্ধ_eb81d7d9.md), প্রকৃত_ডাটা 부팅 기능과 한계는 [네이티브 অপারেটিং_সিস্টেম স্বনিবন্ধ_eb81d7d9](os/স্বনিবন্ধ_eb81d7d9.md)를 참고한다.

네이티브 셸에 নিজ 제한형 `javac`와 `java`를 추가했다. `edit Demo.java`로 소스를 입력하고 `.save`로 저장한 ফিরে_যান_মান `javac Demo.java`, `java Demo`로 **게스트 내부에서 컴파일하고 কার্যকর_করুন_আদেশ**할 수 있다. অমনোনীত_মান 예제는 `javac Hello.java`, `java Hello`다. 파일은 RAM에서 동작하며, 전용 ভাণ্ডার_মান 매체를 연결하면 `sync`로 재부팅 후에도 보존할 수 있다. **OpenJDK/JDK 전체 이식은 아니며**, 단일 শ্রেণী_মান·স্থির_মান ফাংশন_মান·পূর্ণসংখ্যা·স্ট্রিং_মান·শর্ত/반복문과 일부 표준 호출을 지원한다. সমর্থন_মান ক্লিপ, 외부 নথির_নাম 적재와 시험은 [Java 개발 환경 স্বনিবন্ধ_eb81d7d9](문서/자바개발환경.md)에 있다.

네이티브 셸에서 `apps`, `run hello first second`, `net`, `run netcheck`를 사용할 수 있다. 독립 ELF를 ring 3에 적재하고 `int 0x80` 호출을 통해 নির্গম·আর্গুমেন্ট_তালিকা·UDP 네트워크를 제공한다. 별도 হোস্ট 터미널에서 `python3 os/সরঞ্জামগুলি/자료되돌리기.py --port 9000`을 실행한 ফিরে_যান_মান 게스트에서 `run udp 10.0.2.2 9000 hello`로 প্রকৃত_ডাটা 왕복을 확인한다. 새 অ্যাপ_f5044b9b নিবন্ধন_করুন_ভুক্তি, API 및 제한은 [ব্যবহারকারী কার্যকর_করুন_আদেশ·네트워크 স্বনিবন্ধ_eb81d7d9](os/ব্যবহারকারী/স্বনিবন্ধ_eb81d7d9.md)를 참고한다. 현재 QEMU RTL8139·স্থির_মান IPv4·UDP 전용이며 TCP/DNS는 미지원이며, 전용 IDE ভাণ্ডার_মান 형식과 POSIX নথির_নাম/UDP 일부 기능을 추가했다.

`make vbox`는 `jkoros operating system` 전용 VM을 만들고 디스크 없이 ISO로 부팅한다. কার্যকর_করুন_আদেশ 중이면 유지하고, ভাণ্ডার_মান·일시정지 상태이면 재개하며, 꺼져 있을 때만 새 ISO를 빌드해 연결한다. VirtualBox에서 부팅과 셸의 ব্যবহারকারী অ্যাপ_f5044b9b 실행을 확인했다. 다만 현재 VirtualBox용 네트워크 드라이버는 없어 네트워크 장치를 비활성화한다. UDP 시험에는 `make run`을 사용한다. 상태별 동작과 새 গঠন_সিস্টেম 반영 방법은 [VirtualBox কার্যকর_করুন_আদেশ স্বনিবন্ধ_eb81d7d9](문서/가상상자실행.md)에 있다.

기존 관리 커널만 시험하려면:

```sh
cd /home/user/jkoros
make -f ক্রিয়েট_ভুক্তি.mk 검사
make -f ক্রিয়েট_ভুক্তি.mk হোস্ট
```

`হোস্ট`는 여전히 JVM 관리 계층의 কাজ 시험이다. `make -f ক্রিয়েট_ভুক্তি.mk গঠন_ছবি`는 새 `os/`의 제한형 네이티브 কারনেল_মান ISO를 만든다. 기존 `ঐতিহ্য_উত্স/`의 ফাইল_পদ্ধতি·প্রসেসর_মান·নেটওয়ার্ক_গাদা 구현 전체를 이 ISO에 이식했다는 의미는 아니다.

বাংলা ফাংশন_মান·변수·নথির_নাম 이름과 প্রকৃত_ডাটা C API는 [posix-kor](posix-kor/স্বনিবন্ধ_eb81d7d9.md)에 있다. 게스트 Java에서는 `FileInputStream`·`FileOutputStream`의 단일 বাইট_মান 입출력도 지원한다. 전체 POSIX·OpenJDK·Swing 지원으로 확대된 것은 아니다.

외부 배포용 `pack.sh` / `unpack.sh`와 자동 의존성 복원은 [배포 স্বনিবন্ধ_eb81d7d9](distribution/README.md)를 참고하세요.
