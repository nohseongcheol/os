# निज ARM64 JVM 0.4와 हिंदी लाइब्रेरी

हिंदी 통신·अपवाद 사용법은 [हिंदी Java API](한국어자바/ReadMe_फ़ाइल_eb81d7d9.md), फ़ंक्_शन_मान·चर_मान·संचिका 이름의 변경과 어원 근거는 [명명 ReadMe_फ़ाइल_eb81d7d9](명명/ReadMe_फ़ाइल_eb81d7d9.md)를 참고한다.

JAR निष्पादित_करें_आदेश, बाहरी_मान IPv4 TCP/UDP, 별도 정적 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 ऑब्जेक्ट_मान·Thread·Swing은 JVM 경로의 기능이며 AOT समर्थन_मान 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 निष्पादित_करें_आदेश**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK कक्षा_मान लाइब्रेरी 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 कक्षा_मान·정적 विधि_मान 중심이던 실행기를 ऑब्जेक्ट_मान·लाइब्रेरी निष्पादित_करें_आदेश 기반으로 넓힌 것이다.

## 실행과 कंपाइल_स्रोत

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# निज कर्नेल_मान 안에서 स्रोत_ट्री कंपाइल_स्रोत → class निष्पादित_करें_आदेश, हिंदी API 호출
python3 उपकरण/निष्पादित_करें_फ़ाइल.py 시험/자바/한글소스.java

# ऑब्जेक्ट_मान·अपवाद 등은 आयोजक JDK로 Java 8 class를 만든 후 निज 커널에서 निष्पादित_करें_आदेश
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 उपकरण/निष्पादित_करें_फ़ाइल.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 हस्तांतरण_मान
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 उपकरण/निष्पादित_करें_फ़ाइल.py build/my-java/객체시험.class \
  --include build/my-java/वॉलपेपर_मान.class --include build/my-java/शाखा_मान.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.कक्षा_मान.class`라는 RAM संचिका 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.कक्षा_मान`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.कक्षा_मान`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar संचिका.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 हिंदी 클래스만 찾는다. 배포 हिंदी लाइब्रेरी JAR는 आयोजक javac의 classpath로 사용하며, 같은 클래스가 उपयोगकर्ता JVM ELF에도 पढ़ें 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 정적 विधि_मान, int/boolean/char/String, शर्त·पुनरावृति_मान, स्ट्रिंग_मान 결합, 일부 संचिका 스트림 등의 **निज 부분집합 कंपाइलर**다. ऑब्जेक्ट_मान घोषणा·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 निज JVM에서 실행한다. हिंदी API 중 निर्गम·문자 스칼라 फ़ंक्_शन_मान·संचिका पढ़ें/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class अभिनन्दन_ae353e94 {
    public static void main(String[] तर्क) throws Exception {
        हिंदी.निज.निर्गम.लिखना_लाइन("안녕하세요😀");
        हिंदी.निज.निर्गम.수쓰기(हिंदी.निज.문자.코드포인트수("한글😀"));
        हिंदी.निज.संचिका.लिखें("अभिनन्दन_ae353e94.txt", "한글 संचिका😀");
        हिंदी.निज.निर्गम.लिखना_लाइन(हिंदी.निज.संचिका.पढ़ें("अभिनन्दन_ae353e94.txt"));
    }
}
```

컬렉션은 지정한 메서드만 제공하며 iterator/stream/संरेखित_करें_मान·उपयोगकर्ता परिभाषा_मान equals/hashCode 콜백은 없다. 사전의 열쇠는 String/Integer/null 사용을 시험했다. UTF-16 कोड_मान 단위와 Unicode कोड_मान 포인트 수는 구분한다. 한글 입력 조합·सामान्य_करें_मान·아랍어 조판·GUI 다국어 글꼴은 이 स्ट्रिंग_मान 지원과 별개다.

예외는 Throwable/Exception/RuntimeException, ArithmeticException, NullPointerException, IndexOutOfBoundsException/ArrayIndexOutOfBoundsException/StringIndexOutOfBoundsException, IllegalArgumentException/NumberFormatException/IllegalThreadStateException, IOException/FileNotFoundException, IllegalStateException, ClassCastException, NegativeArraySizeException, ArrayStoreException, UnknownHostException, SocketTimeoutException의 제한된 जनरेट_करें·श्रेणी_मान·처리를 제공한다. उपयोगकर्ता परिभाषा_मान Throwable 상속, stack trace/cause/suppressed अपवाद, try-with-resources의 addSuppressed, 완전한 आरंभ त्रुटि 포장은 아직 없다. 잡히지 않은 예외는 अद्यतित_आइटम 전체 Java 실행을 실패로 끝낸다.

## हिंदी API

독립 패키지 **`हिंदी.निज`**를 사용한다. Linux판 `हिंदी.자바`가 요구하는 NIO/Swing/HTTP API를 निज 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 कक्षा_मान नाम·विधि_मान·तर्क·फ़ील्ड_मान·संचिका 이름에 한국어를 사용한다. 표준 Java कक्षा_मान 이름은 호환성을 위해 보존한다.

| कक्षा_मान | 공개 기능 | 이름의 의미 |
|---|---|---|
| निर्गम | लिखें, लिखना_लाइन, 수쓰기 | निर्गम(出力): 내용을 바깥으로 내보냄 |
| 문자 | 길이, 같음, चिपकाएँ_पाठ, काटें_मान, पार्स_करें_पूर्णांक/लिखना_पूर्णांक_मान, 코드포인트수, 부호화/डिक्रिप्ट_करें_डेटा | 문자(文字), एन्कोडिंग_मान(符號): 글의 단위와 그 값을 바이트로 나타내는 नियम_मान |
| संचिका | पढ़ें/लिखें(String नाम), पढें_बाइट_मान/लिखना_बाइट_मान | 널리 쓰는 उपयोगकर्ता 용어를 보존; RAM 자료의 नाम |
| एन्ट्री_सूची | 더하기, पढ़ें, बदलें_मान, मिटाएँ_एन्ट्री, आकार, 비었는가, साफ_करें_सामग्री | एन्ट्री_सूची(目錄): 순서가 있는 एन्ट्री_मान 모음 |
| कोश | 넣기, खोजें_एन्ट्री, 있는가, मिटाएँ_एन्ट्री, आकार, साफ_करें_सामग्री | कोश(辭典): 찾는 말인 열쇠에 값을 대응 |
| 작업 | चलाएँ(실행할일), 기다리기(कार्यसूत्र), स्थगित_करें_कार्य, 살아있는가 | 작업 थ्रेड_मान: 한 ऐप_f5044b9b 안의 निष्पादित_करें_आदेश स्ट्रीम_मान |
| 통신 | खोलें, भेजें, 받기, 대기시간, बंदकरें | 통신(通信), स्वतंत्रसंदेश(電文), पोर्ट_मान: आँकड़े 교환·메시지·포트의 역할 |
| 화면 | रेक्_टेंगल, मिटाएँ_एन्ट्री | 화면(畫面): वास्तविक_डेटा 그림을 표시하는 면 |
| कर्नेल_मान | 밀리초, रेक्_टेंगल | निज JVM의 고정 native जोड़ना; 일반 JNI는 아님 |

이 명명은 अद्यतित_आइटम 기능을 설명하는 용어 선택이다. 기존 한국어에 없던 역사적 어원을 만들어 주장하지 않는다. फ़ाइल_नाम_पाठ·식별자는 UTF-8 소스로 보관한다. `문자.डिक्रिप्ट_करें_डेटा`는 잘못된 UTF-8에 IllegalArgumentException을 던지며, `부호화`는 짝이 없는 서로게이트를 `?`로 바꾼다. `संचिका.पढ़ें`는 엄격한 UTF-8 복호화를 적용한다. 화면 색은 `빨강 | (초록 << 8) | (파랑 << 16)` 형식이다.

## निष्पादित_करें_आदेश 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(हिंदी कक्षा_मान 포함), class당 16 KiB·अचर_मान 풀 511항목, 전체 विधि_मान/फ़ील्ड_मान 각각 512개. विधि_मान कोड_मान 8 KiB, स्थानीय_दायरा चर_मान·피연산자 ऑपरेंड_स्टैक 각각 128슬롯, तर्क 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 निष्पादित_करें_आदेश 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- ऑब्जेक्ट_मान 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 वास्तविक_डेटा 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 संचिका·대형 स्ट्रिंग_मान·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 आदेश 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 खिड़की स्विच_मोड 시 중단·재개한다. 일반 서버·계산의 무제한 실행은 아직 없다. 미지원 आदेश·संसाधन_मान 부족은 명시적인 오류로 종료한다.
- RAM संचिका 최대 64개, 파일당 16384바이트, पथ UTF-8 63바이트. RAM 디렉터리와 पीअर_मान/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 हिंदी class는 RAM संचिका 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 अद्यतित_आइटम 경로에서 स्रोत_ट्री·कक्षा_मान·आँकड़े 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 बाहरी_मान IPv4를 제공한다. वास्तविक_डेटा GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. स्वतंत्रसंदेश 512바이트, सॉकेट_मान 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 निष्पादित_करें_आदेश 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 सरणी_मान, 완전한 सरणी_मान 공변성·인터페이스 लेयर_मान 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/एन्क्रिप्ट_करें_डेटा/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 समर्थन_मान 부분집합은 아래 및 개발 매뉴얼을 참고한다. कक्षा_मान संचिका 전체 검증기·पहुँच_एन्ट्री अनुमति_मान/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 रक्षित_करें_मान 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM मान/मान्य_करें/कक्षा_मान 로더와 अपवाद 모델 → 영속 VFS·mmap·घड़ी·원자 ऑपरेशन_मान·वास्तविक_डेटा 스레드/सिंक्रनाइज़_करें ABI → OpenJDK java.base 및 native लाइब्रेरी 이식 → उपकरण_मान 네트워크·TCP/IP → खिड़की 시스템/फ़ॉन्ट_मान/입력기·java.desktop → Java SE 호환성 시험. अद्यतित_आइटम निज JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## मान्य_करें

`उपकरण/자바가상기계시험.py`는 같은 Java 8 class 파일의 출력을 आयोजक OpenJDK `-Xverify:all`과 QEMU raspi4b निज 커널에서 비교한다. ऑब्जेक्ट_मान/상속/인터페이스·switch·सरणी_मान, अपवाद/finally, 컬렉션/GC, Thread/लॉक_मान, हिंदी UTF-8/संचिका/컬렉션, वास्तविक_डेटा UDP 루프백/समय_उपयोगिता 초과, 게스트 한글 स्रोत_ट्री कंपाइल_स्रोत, सरणी_मान लिखें_मान/आवृत्ति_मान/संचिका 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 संचिका अस्वीकृत_करें_मान 시험을 실행한다. UDP प्रोजेक्ट_करें_मूल 실행에는 आयोजक 루프백 सॉकेट_मान 권한이 필요하다.

`उपकरण/부팅시험.py`는 कर्नेल_मान रक्षित_करें_मान/회귀 시험과 별도로 हिंदी Java 화면 API가 वास्तविक_डेटा 픽셀을 그렸는지도 QMP 화면 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. वास्तविक_डेटा Pi4 하드웨어 부팅 시험과 전체 JDK 호환성 시험 결과는 아니다.


## JVM 0.3: 네트워크와 GUI एक्सटेंशन_मान

`Socket`/`ServerSocket` जनरेट_करें·जोड़ना·accept·양방향 InputStream/OutputStream·close·EOF·समय_उपयोगिता 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 बाहरी_मान अंक_मान IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 समाप्त_करें_अंक 16개, Java 루프백 버퍼 1024바이트, बाहरी_मान TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. 대화형 이벤트 대기는 निष्पादित_करें_आदेश 기한을 갱신하고 आदेशपटल स्विच_मोड 시 프로세스 상태를 स्टोर_मान·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

हिंदी `खिड़की`, `विजेट`, `연결통신` 클래스를 배포 JAR와 निज JVM 내장 자원에 추가했다. 상세 विधि_मान·제한·स्रोत_ट्री·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## हिंदी 객체의 직접 निष्पादित_करें_आदेश

`खिड़की`, `लेबल`, `पाठ_फ़ील्ड`, `बटन`, `घटना_कतार`, `एक्शन_सूचना`, `कार्यसूत्र`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. निज JVM의 ऑब्जेक्ट_मान जनरेट_करें,
फॉर्मैट_मान 검사, 화면 호출, घटना 큐, थ्रेड_मान 스케줄러에 हिंदी 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 निष्पादित_करें_आदेश 경로도 유지한다.
हिंदी 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

निज 실행기의 हिंदी 진입점은 `public static void चलाएँ()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 हिंदी 진입점을 우선한다.
명령행 인수는 `실행인수.개수()`와 `실행인수.पाठ(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. 정적 संचिका 예제는 게스트
javac로도 컴파일하며, GUI/थ्रेड_मान 소스는 आयोजक `javac --release 8`을 사용한다.
직접 GUI/थ्रेड_मान API는 निज JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
हिंदी 가닥의 निष्पादित_करें_आदेश·प्रतीक्षा_करें_मान·중복 चलाएँ अस्वीकृत_करें_मान, GUI घटना 출처·इंडेक्स·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

विधि_मान 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
हिंदी 클래스도 실행되지만, स्ट्रिंग_मान 리터럴·표준 लाइब्रेरी 재정의·native
जोड़ना·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 예제](한국어자바/ReadMe_फ़ाइल_eb81d7d9.md)를 참고한다.

## आदेशपटल 부분 ताज़ा_करें

ले_जाएँ_मान·आकार 변경은 새 खिड़की 영역과 이전 자리에서 드러난 띠만 합성한다.
1920×32 पिक्सेल(240 KiB)의 임시 그림에서 배경·겹친 खिड़की·कैरेक्टर_मान·GUI를 먼저
완성하고, अद्यतित_आइटम शो_मान 메모리와 비교하여 달라진 화소만 기록한다.
32줄보다 큰 영역은 여러 띠로 처리하므로 전체 프레임을 원자적으로
교체하거나 수직 동기에 맞추는 방식은 아니다. 전체 배경을 먼저 지우는
중간 화면은 표시하지 않는다. 좌표가 같으면 다시 그리지 않는다.

`make test-redraw`는 वास्तविक_डेटा C 그리기 코드를 호스트의 मेमोरी_डेटा 화면에 연결해
ले_जाएँ_मान 80회·आकार परिवर्तित_करें_मान 40회·겹친 खिड़की 4개를 전체 합성 결과와 पिक्सेल 단위로 대조한다.
क्षेत्र_मान 밖 उपयोगकर्ता ड्रॉइंग_मान, 동일 पिक्सेल 무기록, सूचक 밑그림, वास्तविक_डेटा 화면 पंक्ति 간격을
검사한다. 이 시험의 시간은 आयोजक CPU 측정이며 Pi 4/QEMU 속도로 해석하지 않는다.
`make test-resize`는 QEMU/VNC의 640×480 및 1920×1080에서 왼쪽 모서리 खींचे_मान,
한글 입력·vi 미저장 सामग्री_मान·독립 खिड़की 크기를 검사한다.
