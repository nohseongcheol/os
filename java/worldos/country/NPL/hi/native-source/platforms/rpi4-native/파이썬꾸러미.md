# निज 커널의 Python बंडल इंस्टॉल_करें_मान

निज ARM64 커널의 `python`은 **MicroPython 1.24.1 पूर्णांक बिल्ड_सिस्टम**다.
`pip`와 `python -m pip`는 이 환경을 위한 제한형 स्रोत_ट्री इंस्टॉल_करें_मान 명령이다.
PyPA pip 전체나 CPython을 이식한 것은 아니다.

호스트에서 실행한다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
python3 उपकरण/निष्पादित_करें_आदेश.py --desktop --network --pip
```

게스트 셸에서 설치하고 사용한다.

```text
pip install micropython-bisect==3.3.3
pip list
python -c 'from bisect import insort as 순서대로넣기; मान=[1,5]; 순서대로넣기(मान,3); print(मान)'
python -m pip list
pip uninstall micropython-bisect
```

정상 निष्पादित_करें_आदेश 결과는 `[1, 3, 5]`다. 예시 배포 파일은
[PyPI의 micropython-bisect 3.3.3](https://pypi.org/project/micropython-bisect/3.3.3/)이며
SHA-256은 `b8d09d0bb4b2add706078dfa3f306e22fad1f4b5340b87d13f2c852507d720c8`이다.
`bisect`는 इंस्टॉल_करें_मान 전 내장되어 있지 않다. 내려받은 `.py`를 निज 커널의 EL0
MicroPython이 import하여 실행한다.

## इंस्टॉल_करें_मान 경로와 역할

호스트의 [꾸러미중계.py](उपकरण/꾸러미중계.py)는 PyPI HTTPS 다운로드, 인증서 सत्यापित_करें,
배포 संचिका SHA-256 검증과 संग्रह_मान 해제를 맡는다. 호스트에서 `setup.py`나 내려받은
Python 코드를 실행하지 않는다. आयोजक pip 설치도 필요 없다.
중계는 `127.0.0.1:8027`에만 열리며 게스트는 QEMU NAT의 `10.0.2.2:8027`로 연결한다.
게스트 자체에 DNS·TLS·PyPI संग्रह_मान रिलीज़_संग्रहण 기능을 추가했다는 뜻은 아니다.

게스트의 [बंडल.py](파이썬연결/लाइब्रेरी/बंडल.py)는 TCP로 받은 파일의 SHA-256과
पथ·आकार·문법을 검사한 वापस_मान `/lib`에 설치하고 `/lib/.pip.json`에 목록을 기록한다.
`/lib`와 निष्पादित_करें_आदेश स्क्रिप्ट_मान 폴더를 मॉड्यूल_मान 검색 경로에 추가했으므로 작업 폴더가 달라도
설치한 모듈을 import할 수 있다. 패키지 폴더와 पीअर_मान import도 지원한다.

इंस्टॉल_करें_मान 도중 पता_क्षेत्र 부족 등 오류가 발생하면 새 파일과 폴더를 지우고 기존 목록을
복원한다. 이미 있는 उपयोगकर्ता 파일을 덮어쓰지 않는다. 동일 버전 재설치 요청은
संचिका 지문을 확인하고 유지한다. 다른 버전은 निकालें_एन्ट्री 후 설치한다. निकालें_एन्ट्री 시 사용자가
수정한 파일이 발견되면 보존하고 오류를 알린다. 빈 패키지 폴더는 남을 수 있다.

**`/lib`도 RAM 파일이다. 재부팅하면 설치한 패키지가 사라진다.**
आयोजक `build/pip-cache`에는 배포 파일과 출처·지문이 남으므로 अगला_आइटम 부팅에서 다시
설치할 수 있다. 버전을 지정하면 같은 배포 파일을 재사용한다.

```sh
# आयोजक: 인터넷이 있을 때 배포 파일만 준비
python3 उपकरण/꾸러미중계.py --fetch micropython-bisect==3.3.3
# अगला_आइटम निष्पादित_करें_आदेश: PyPI जोड़ना 없이 캐시 사용
python3 उपकरण/निष्पादित_करें_आदेश.py --network --pip --pip-offline
```

다른 포트는 आयोजक `--pip-port 8028`, 게스트
`pip install micropython-bisect==3.3.3 --port 8028`로 맞춘다.
आयोजक 중계는 `python3 उपकरण/꾸러미중계.py --port 8027`로 별도 실행할 수도 있다.
QEMU를 종료하거나 중계 실행을 끝내면 이 서비스도 닫힌다.

## समर्थन_मान क्लिप

- 의존성 없는 순수 Python wheel(`*-none-any.whl`, `Root-Is-Purelib: true`).
- 구형 `micropython-*` स्रोत_ट्री 배포형의 `.py`와 `PKG-INFO`.
- 꾸러미당 स्रोत_ट्री 16개, 합계 64 KiB, 파일당 16 KiB, 절대 पथ UTF-8 63바이트 이하.
  전체 RAM संचिका 64개·डायरेक्टरी_मान 16개의 남은 공간과 Python ढ़ेर_मान 256 KiB 한도도 적용된다.
- `install`, `list`, `uninstall`, `--help`, `--version`.
- SHA-256, JSON, मेमोरी_डेटा `io.StringIO`/`BytesIO`를 실행기에 추가했다.
  일반 संचिका ऑब्जेक्ट_मान `open()`은 미지원이며 `हिंदी.पढें_फ़ाइल/लिखना_फ़ाइल` 또는
  `jkoros.read/write`를 사용한다.

C एक्सटेंशन_मान·플랫폼 전용 wheel, 일반 sdist बिल्ड_सिस्टम, 자동 의존성 해결, extras, VCS/임의 URL,
NumPy 같은 CPython 전용 패키지는 지원하지 않는다. 순수 Python 패키지도
MicroPython의 문법·표준 मॉड्यूल_मान·पूर्णांक 전용 환경과 맞아야 실제로 실행할 수 있다.
इंस्टॉल_करें_मान 시 문법을 검사하지만 모든 निष्पादित_करें_आदेश 경로의 호환성을 증명하지는 않는다.
वास्तविक_डेटा Raspberry Pi 4의 LAN을 통한 설치는 검증하지 않았으며 अद्यतित_आइटम 중계는 QEMU용이다.

MicroPython 자체의 패키지 체계와 CPython pip의 차이는
[MicroPython 패키지 문서](https://docs.micropython.org/en/v1.24.0/reference/packages.html),
wheel 형식은 [PyPA 배포 फॉर्मैट_मान 규격](https://packaging.python.org/en/latest/specifications/binary-distribution-format/)을 참고한다.

```sh
make test-pip
```

मान्य_करें 기록은 `build/verification/pip/report.json`과 `serial.log`에 저장한다.
वास्तविक_डेटा PyPI बंडल 시험과 별도로 시험용 wheel로 패키지 डायरेक्टरी_मान, 구문 त्रुटि,
पता_क्षेत्र 부족 되돌림을 확인한다.
