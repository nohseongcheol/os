# निज ARM64 Java 커널의 C/C++ संचिका·루프백 जोड़ना

이 디렉터리는 `platforms/rpi4-native` निज कर्नेल_मान 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 हिंदी 함수명과 `extern "C"` ABI를 제공한다. `जोड़ना.c`는 कर्नेल_मान 안에서 AOT Java संचिका 메서드에 직접 연결하고, `उपयोगकर्ता_ब्रिज.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. वास्तविक_डेटा संचिका 처리는 `मेमोरी_फ़ाइलें.java`, 루프백 स्वतंत्रसंदेश 처리는 `लूपबैक_नेटवर्क.java`, 연결형 흐름은 `स्ट्रीम_नेटवर्क.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 कर्नेल_मान 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·फ़्लोटिंग_अंक_मान ऑपरेशन_मान·संचिका·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

समर्थन_मान: `जारी_फ़ाइल`, `पढें_फ़ाइल_डेटा`, `लिखना_फ़ाइल_डेटा`, `बंद_फ़ाइल`, `खोजें_फ़ाइल`, `निकालें_फ़ाइल_एन्ट्री_नाम`, `파일길이정하기`, 보조 फ़ंक्_शन_मान `फ़ाइल_आकार`. त्रुटि 시 -1과 작업별 `त्रुटि_संख्या`를 반환한다. `कमिट_फ़ाइल_संग्रहण`은 RAM 파일이므로 ENOSYS를 반환한다. संचिका 16개, 각 16384바이트, नाम 63바이트, 서술자 16개이며 RAM 디렉터리·पीअर_मान/절대 경로를 제공한다. अनुमति_मान/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 वास्तविक_डेटा हिंदी 함수와 독립 구조체를 선언한다.
`बनाएँ_एंडपॉइंट`, `बाइंड_करें_पता`, `자료전문보내기/받기`, `कनेक्ट_नेटवर्क/기다리기/받기`는
`उपयोगकर्ता_ब्रिज.c`에서 SVC를 호출하며 मैक्रो_मान 별칭이 아니다. `struct क्लाउड_सॉकेट_पता`의
`पता_समूह`, `पोर्ट_संख्या`, `इंटरनेट_पता.पता_मान`을 사용한다. 상수는 enum의
`क्लाउड_समूह`, `전문통신`, `전문전송규약`, `स्ट्रीम_नेटवर्क`, `स्ट्रीम_ट्रांसपोर्ट_प्रोटोकॉल`이다.
हिंदी·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. बाहरी_मान 통신은 निज 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. वास्तविक_डेटा Pi 4 GENET 드라이버는 미지원이다.
소켓도 वास्तविक_डेटा फ़ंक्_शन_मान `बंद_फ़ाइल`로 닫는다.
