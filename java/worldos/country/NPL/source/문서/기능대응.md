# engos 기능 대응표

이 표는 기존 `बिरासत_स्रोत/`의 वस्तु_मान 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [वास्तविक_लगत 부팅 기능과 한계](../os/readme_फाइल_eb81d7d9.md)를 따로 기록한다.

## 기존 वस्तु_मान 기반 관리 कर्णेल_मान 전체를 부팅하기 위해 남은 जडान

अर्को_वस्तु 항목은 Java 문법만으로 실행할 수 없는 CPU/मोबाइल_मान 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot प्रविष्टि_अंक_मान, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 प्रसङ्ग_मान भण्डार_गर्नुहोस्_मान
- वास्तविक_लगत PIC/PIT/PS2/ATA/PCI हार्डवेयर_पोर्ट 및 AMD PCnet DMA लुप_मान
- Java वस्तु_मान·विन्यास_मान लिङ्क_लेआउट, 예외, तथ्याङ्कित_मान आरम्भिक, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT चरण_मान
- FAT 디스크 구역을 वास्तविक_लगत ATA 장치와 연결하는 आगत_लगत 접착 तह_मान

위 관리 계층은 engos 기능의 Java 관리 구현과 होस्ट 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot प्रविष्टि_अंक_मान, तथ्याङ्कित_मान आरम्भिक·पूर्ण_सङ्ख्या विन्यास_मान, VGA/직렬/PS2, 명령해석기, प्रयोगकर्ता ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 होस्ट 루프백 패킷 왕복을 검증했다. 위 표의 वस्तु_मान 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
