# 전체 समर्थन_मान 요청의 현재 स्थिति_मान

요청 전체는 아직 완료되지 않았다. 현재 ISO는 निज Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 वास्तविक_लगत C POSIX 일부 기능, नेपाली API/स्रोत नाम, IDE फाइल 보존, 게스트 Java फाइल 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/readme_फाइल_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 कार्यान्वयन_गर्नुहोस्_आदेश 가능한 क्लिप | 전체 지원에 필요한 작업 |
|---|---|---|
| Java बनाउनुहोस्_स्रोत·कार्यान्वयन_गर्नुहोस्_आदेश | 게스트 제한형 javac/JVM, तथ्याङ्कित_मान 단일 클래스와 일부 표준 वस्तु_मान | 일반 वस्तु_मान·वर्ग_मान जडान·예외·GC·스레드, 완전한 javac와 표준 वर्ग_मान पुस्तकालय |
| फाइल | POSIX 서술자, Java 단일 बाइट_मान फाइल प्रवाह_मान, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·अनुमति_मान·잠금·일반 फाइल_प्रणाली·विस्तार_मान 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP होस्ट 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 घटना·फन्ट_मान·सन्झ्याल सञ्चालनप्रणाली_मान, AWT 네이티브 연결과 Swing कार्यान्वयन_गर्नुहोस्_आदेश 기반 |
| POSIX | 문서화한 फाइल·단말·UDP 부분 | प्रक्रिया_मान·exec/fork·스레드·시그널·시간·mmap·poll·파이프 등과 적합성 वैध_गर्नुहोस् |
| 언어별 नाम | नेपाली 46개 대응 प्रविष्टि_मान, वास्तविक_लगत C/Java/फाइल नाम 적용 | लक्ष्य भाषा 확정, 언어별 용례·역사 근거와 해당 स्रोत·도구의 वैध_गर्नुहोस् |

निज 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 कार्यान्वयन_गर्नुहोस्_आदेश 환경을 추가하는 방식은 별도의 कर्णेल_मान·루트 फाइल_प्रणाली·OpenJDK·그래픽 सर्भर_मान·영구 भण्डार_गर्नुहोस्_मान 구성을 가진 कार्यान्वयन_गर्नुहोस्_आदेश 경로가 된다. 후자는 기존 निज 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

कार्यान्वयन_गर्नुहोस्_आदेश 기반과 추가 लक्ष्य 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
