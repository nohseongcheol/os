## 기존 ahanoa_uara 기반 관리 kākano_uara_0611a8a8 전체를 부팅하기 위해 남은 TŪHONO

Panuku_tuemi 항목은 Java 문법만으로 실행할 수 없는 CPU/pūkoro_uara 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot tāurunga_ira_uara, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 Horopaki_uara Store_uara
- tūturu_raraunga PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA Loop_uara
- Java ahanoa_uara·HUĀNGA_uara Hono_Tahora, 예외, pateko_uara arawhiti, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT atamira_uara
- FAT 디스크 구역을 tūturu_raraunga ATA 장치와 연결하는 I_O 접착 apa_uara

위 관리 계층은 engos 기능의 Java 관리 구현과 taurima 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot tāurunga_ira_uara, pateko_uara arawhiti·tau_tōpū HUĀNGA_uara, VGA/직렬/PS2, 명령해석기, kaiwhakamahi ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 taurima 루프백 패킷 왕복을 검증했다. 위 표의 ahanoa_uara 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
