# 전체 Tautoko_uara 요청의 현재 tūnga_uara

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 tūturu_raraunga C POSIX 일부 기능, Reo_Māori API/pūtake Ingoa, IDE Kōnae 보존, 게스트 Java Kōnae 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/PĀNUIMAI_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 kawe_tono 가능한 topenga | 전체 지원에 필요한 작업 |
|---|---|---|
| Java hanga_pūtake·kawe_tono | 게스트 제한형 javac/JVM, pateko_uara 단일 클래스와 일부 표준 ahanoa_uara | 일반 ahanoa_uara·tauaha_uara TŪHONO·예외·GC·스레드, 완전한 javac와 표준 tauaha_uara puna |
| Kōnae | POSIX 서술자, Java 단일 paita_uara Kōnae roma_uara, 전용 pāpāhotanga_uara 보존 | 일반 java.io/nio, 디렉터리·mana_uru_uara·잠금·일반 pūnaha_kōnae·toronga_uara 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP taurima 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 hui·momotuhi_uara·matapihi pūnaha_mahi_uara, AWT 네이티브 연결과 Swing kawe_tono 기반 |
| POSIX | 문서화한 Kōnae·단말·UDP 부분 | Hātepe_uara·exec/fork·스레드·시그널·TIME_uara·mmap·poll·파이프 등과 적합성 whakamana |
| 언어별 Ingoa | Reo_Māori 46개 대응 tāurunga_uara, tūturu_raraunga C/Java/Kōnae Ingoa 적용 | ūnga reo 확정, 언어별 용례·역사 근거와 해당 pūtake·도구의 whakamana |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 kawe_tono 환경을 추가하는 방식은 별도의 kākano_uara_0611a8a8·루트 pūnaha_kōnae·OpenJDK·그래픽 tūmau_uara·영구 Store_uara 구성을 가진 kawe_tono 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

kawe_tono 기반과 추가 ūnga 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
