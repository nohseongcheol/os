# Java 네이티브 محول_برمجي

OpenJDK ذاتي 소스를 빌드하는 **`--target openjdk-build`**와 ذاتي نواة_قيمة ABI 검사 도구를 추가했다.
이는 공식 javac/C/C++ 도구를 연결하는 별도 경로다. [بنية_نظام 방법·الفعلي_بيانات التحقق_من_صحة·نواة_قيمة 이식 يقص](OpenJDK-مصدر_بنية_و-أصلي_نواة-이식.md)를 참고한다.

x86 직접 변환과 ARM64 C إنشاء 후단은 모두 [مترجممسبق.java](أدواتجافا/مترجممسبق.java)로 구현한다. `sh 미리번역.sh`로 직접 실행하며, [مترجممسبق.py](مترجممسبق.py)와 `محول_برمجي.py`는 이전 أمر·API 및 OpenJDK 도구를 위한 호환 진입점이다. ذاتي Pi4 후단은 freestanding C를 거쳐 AArch64로 만든다. [arm64.py](arm64.py)는 이전 경로와 Python 호출을 위한 호환 진입점이다. دالة_قيمة·متغيّر_قيمة·إنشاء C 이름의 뜻과 예외는 [العربية 명명 안내](../platforms/rpi4-native/명명/안내.md)를 참고한다. [ARM64 بنية_نظام·دعم_قيمة يقص](../platforms/rpi4-native/안내.md)에 ينفذ_أمر 조건이 있다. 전체 OpenJDK나 일반 فئة_قيمة_55654bf1 실행기는 아니다.

ينفذ_أمر 시 JVM이 필요 없는 x86 32비트 ELF를 만든다. JDK 11 이상으로 실행하는 Java ذاتي AOT 후단이며, Java 전체를 새로 구현한 컴파일러는 아니다. Java 문법·يصل_إدخال تحكم_قيمة·نوع_قيمة 검사는 JDK의 `javac`에 맡기고, Java 8 فئة_قيمة_55654bf1 파일을 읽어 각 바이트코드를 x86 명령으로 직접 변환한다. C 코드로 우회하거나 바이트코드 해석기를 커널에 넣지 않는다.

```text
Java مصدر → javac의 문법·نوع_قيمة 검사 → 임시 .class
          → ذاتي x86 변환기 → GNU as/ld → 네이티브 ELF32
```

## 준비와 ينفذ_أمر

بنية_نظام مضيف: Linux, Python 3.6 이상, JDK 11 이상(`javac --release 8`), GNU binutils(`as`, `ld`), Make. حديث_عنصر 환경의 OpenJDK 11, Python 3.6, binutils 2.30으로 검증했다. خارجي_قيمة Python 패키지와 네트워크 다운로드는 사용하지 않는다.

```sh
cd /home/user/jkoros/compiler
make
./build/계산
echo $?                  # 0이면 예제 اختبارات 성공

python3 محول_برمجي.py --target linux --entry 계산.تشغيل \
    -o build/계산 예제/계산.java

make test
```

`linux` 대상은 Linux의 32비트 ينفذ_أمر 호환 기능이 필요하다. `int 0x80`을 차단하는 샌드박스에서는 `Bad system call`이 발생할 رقم 있다. أنظمة_المعلومات_عادي Linux مضيف 또는 해당 실행을 허용한 اختبارات 환경에서 실행한다. 시험의 비정상 종료를 통과로 처리하지 않는다.

진입점은 `static int تشغيل()` 또는 `static void تشغيل()`처럼 인수가 없어야 한다. `--entry 패키지.فئة_قيمة_55654bf1.دالة_قيمة`로 선택한다. `int` 반환값은 Linux 프로세스 خروج_تطبيق 코드가 되며 셸에는 하위 8비트가 보인다. 일반 `main(String[] args)` ينفذ_أمر 환경이나 표준 إدخال_إخراج 라이브러리는 제공하지 않는다.

`--target kernel`은 إقلاع_الآلة 코드와 연결할 재배치 ELF 오브젝트를 생성한다.

```sh
cd /home/user/jkoros
python3 compiler/محول_برمجي.py --target kernel --entry نواة.تشغيل \
    --export kernel_dispatch=نداء_النظام.عملية_قيمة_إدخال \
    -o os/build/java.o os/مصدر/*.java
```

`--target user`는 jkoros 셸에서 실행할 독립 ELF를 생성한다. `فضاء_المستخدم` 클래스의 제한된 native API는 `int 0x80` 시스템 호출로 연결하며 `جهاز_قيمة` 클래스의 أجهزة_قيمة 직접 접근은 거부한다. فضاء_المستخدم ELF는 Linux ينفذ_أمر ملف ABI와 다르므로 호스트에서 실행하지 않는다. إنشاء·سجل_إدخال 방법은 [فضاء_المستخدم ينفذ_أمر 안내](../os/فضاء_المستخدم/안내.md)에 있다. `--export 외부기호=فئة_قيمة_55654bf1.دالة_قيمة`는 오버로드되지 않은 ثابت_قيمة_f430d3f5 함수를 ذاتي مُعامل_رمز ABI로 노출한다. 커널의 시스템 호출 진입점에 사용한다.

Java 파일은 필요한 클래스들을 한꺼번에 전달한다. مخرجات 옆의 `.s`는 생성된 어셈블리, `.json`은 مصدر SHA-256 및 네이티브 رمز↔Java دالة_قيمة 대응표다. العربية 함수명은 원문과 대응표에 보존하고 ELF 내부에는 충돌 방지용 جهاز 기호를 쓴다. يحول_برمجياً_مصدر·يجمّع_قيمة·اتصال 중 실패하면 기존 نتيجة 파일을 덮어쓰지 않는다.

## دعم_قيمة يقص

- `int`, `boolean`, `byte`, `short`, `char`의 32비트 계산 및 نوع_قيمة تحويل_قيمة.
- ثابت_قيمة_f430d3f5 필드와 ثابت_قيمة_f430d3f5 دالة_قيمة, 매개변수·반환값, 재귀, 클래스별 지연 초기화와 تهيئة دورة_قيمة.
- 조건문, 반복문, 단락 평가, 삼항식, عدد_صحيح `switch`, 넓은 محلي_نطاق متغيّر_قيمة 인덱스.
- 덧셈·뺄셈·곱셈·나눗셈·나머지·بت_قيمة 연산과 نقل_قيمة. Java의 오버플로 및 `MIN_VALUE / -1` 동작을 유지한다.
- `int[]` إنشاء·초기값 0·길이·قراءة·كتابة·مرجع 비교. 256KiB 고정 صفيف_قيمة منطقة_قيمة, 널/منخفض_قيمة/حجم/عنوان_منطقة 검사.
- سلسلة_قيمة 리터럴과 `String` مرجع, `length()` 및 `charAt()`. 문자열은 UTF-16 رمز_قيمة_f3cd31ee 단위로 저장하고 같은 리터럴은 공유한다. NUL 및 대리쌍도 시험한다.
- العربية فئة_قيمة_55654bf1·دالة_قيمة·متغيّر_قيمة·ملف اسم.

`new Object`, 인스턴스 قيمة_الحقل/دالة_قيمة, 상속/인터페이스, `long/float/double` ينفذ_أمر تشغيل_قيمة, `int[]` 이외 صفيف_قيمة, سلسلة_قيمة 동적 결합, Java 표준 مكتبة, استثناء عملية_قيمة_إدخال, 스레드·تزامن·GC는 미지원이다. 실행에 필요한 미지원 바이트코드나 خارجي_قيمة 호출을 발견하면 실패한다. 사용되지 않는 قيمة_افتراضية 생성자는 ينفذ_أمر 코드로 만들지 않는다. Java 8 문법이어도 모든 프로그램을 컴파일할 رقم 있다는 뜻은 아니다.

استثناء عنصر_قيمة_2ed200e9 대신 런타임 خطأ 번호로 중단한다. Linux와 jkoros فضاء_المستخدم 대상에서는 `100 + فهرس`로 종료하고 نواة_قيمة 대상에서는 `JKOROS PANIC فهرس`를 출력하고 정지한다. فضاء_المستخدم 프로그램만 종료한 경우 셸은 계속 실행된다.

| فهرس | 원인 |
| --- | --- |
| 1 | 0으로 قسم_مقياس |
| 2 | 널 مرجع |
| 3 | صفيف_قيمة/سلسلة_قيمة منخفض_قيمة يقص 초과 |
| 4 | 음수 صفيف_قيمة حجم |
| 5 | صفيف_قيمة منطقة_قيمة 부족 |

صفيف_قيمة 영역은 증가식 할당이며 회수하지 않는다. 재귀 스택의 경계 검사도 아직 없으므로 무제한 재귀를 안전하게 처리하는 런타임은 아니다. 특권 نواة_قيمة 및 신뢰할 رقم 있는 작은 프로그램용 حالة_أولية 구현이다.

## native 경계와 ABI

نواة_قيمة 대상에서는 `os/مصدر/جهاز_قيمة.java`, فضاء_المستخدم 대상에서는 `os/فضاء_المستخدم/إعلان/فضاء_المستخدم.java`의 정확한 أسلوب_اسم_نص·서술만 허용한다. 임의의 `native` 함수와 Linux/فضاء_المستخدم 대상의 أجهزة_قيمة 접근은 거부한다. Java 인수를 왼쪽부터 32비트 한 칸씩 스택에 놓으며, 반환값은 EAX, EBP/ESP 이외 레지스터는 호출자가 보존한다고 가정하지 않는다. C의 cdecl/JNI ABI가 아니므로 C 함수와 바로 연결하면 안 된다.

Java مصدر 또는 `.class` 입력을 받는다. 전체 JVM 바이트코드 검증기는 제공하지 않는다. 어노테이션 처리는 비활성화하고 비어 있는 فئة_قيمة_55654bf1 مسار/مصدر 경로에서 명시한 소스만 컴파일한다.

## 검증과 구현 근거

`اختبارات/test_compiler.py`의 14개 시험에는 네이티브 ELF와 OpenJDK의 تشغيل_قيمة نتيجة 대조, فئة_قيمة_55654bf1 تهيئة, عدد_صحيح 극값, سلسلة_قيمة/صفيف_قيمة, 재귀·switch·wide, 런타임 오류와 미지원 기능 يرفض_قيمة, فشل_قيمة 시 مخرجات 보존, فضاء_المستخدم ELF/إذن_قيمة 경계 및 내보내기 검증이 포함된다. 이것은 Java 전체 적합성 시험은 아니다.

أمر 의미와 فئة_قيمة_55654bf1 ملف 형식은 Oracle의 [JVM أمر المواصفات](https://docs.oracle.com/javase/specs/jvms/se11/html/jvms-6.html), [فئة_قيمة_55654bf1 ملف المواصفات](https://docs.oracle.com/javase/specs/jvms/se11/html/jvms-4.html)를 참고했다.
