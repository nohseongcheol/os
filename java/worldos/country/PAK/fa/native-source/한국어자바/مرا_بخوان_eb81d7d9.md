# فارسی Java 도우미 کتابخانه

OpenJDK 11 이상과 함께 쓰는 프로젝트 مالک_مقدار API다. 표준 Java کتابخانه 전체의 번역판을 뜻하지 않는다. 기존 Java API·키워드·استثنا·자료형은 그대로 함께 쓴다.

전체 22개 도우미 메서드의 نشانوندها·반환값·제약, سیستم_عامل 안의 사용법, Python·C++ 호출 방법은 **[فارسی کتابخانه کاربر_راهنما](کاربر_راهنما.md)**에 정리했다. [Python 호출 예제](예제/다른언어/파이썬호출.py)와 [C++ JNI 호출 예제](예제/다른언어/자바호출.cpp)도 제공한다.

`make`로 `build/한국어자바.jar`를 만든다. `javac -encoding UTF-8 -cp build/한국어자바.jar 예제/인사.java`로 예제를 컴파일한다. 실행은 `java -cp build/한국어자바.jar:예제 인사`다.

`인사` 예제는 그래픽 화면이 없으면 پرونده·문자·스레드 결과와 안내만 출력한다. Swing 창은 그래픽 세션에서 실행해야 한다. QEMU에서는 [그래픽 اجرا_فرمان مرا_بخوان_eb81d7d9](../platforms/rpi4/README.md)의 `make run`으로 부팅한 برگشت_مقدار VNC 데스크톱의 터미널을 사용한다.

| کلاس_مقدار | 제공 기능 |
|---|---|
| پرونده | UTF-8 텍스트·بایت_مقدار خواندن/نوشتن, 디렉터리·ورودی_لیست |
| 문자 | UTF-8 변환, NFC بهنجار_کردن_مقدار, کد_مقدار 포인트 수, 언어별 낱말 경계 |
| 통신 | HTTP(S) 요청, 제한시간을 가진 TCP اتصال |
| 작업 | 스레드 اجرا_2·합류·منتظر_ماندن_مقدار, 작업 برنامه_راه_انداز |
| 화면 | Swing 이벤트 처리와 پنجره ایجاد |
| فضای_کار | مبداء ویرایش_مقدار·ساختن_منبع·اجرا_فرمان·اجرا_فرمان پرونده ایجاد 화면 |

`char`는 UTF-16 کد_مقدار 단위이므로 이모지 등을 한 글자로 처리할 때 کد_مقدار 포인트 또는 문자 경계 API를 사용한다. 파일은 UTF-8로 저장한다. OpenJDK의 모든 Java2D/قلم_مقدار/입력기 조합을 각각 검증한 것은 아니다.

이름은 현재 의미가 분명한 فارسی 용례를 사용했다. 개별 명칭의 역사적 어원 검토를 완료했다고 주장하지 않는다. منبع_مقدار 종료와 استثنا 처리는 표준 API의 계약을 따른다.
