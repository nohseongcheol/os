# 자체 ARM64 JVM 0.4와 한국어 لائبريري

한국어 통신·예외 사용법은 [한국어 Java API](한국어자바/پڙهو_فائل_eb81d7d9.md), فعل_قدر·변수·فائل 이름의 변경과 어원 근거는 [명명 پڙهو_فائل_eb81d7d9](명명/پڙهو_فائل_eb81d7d9.md)를 참고한다.

JAR تعميل_ڪرڻ_حڪم, 외부 IPv4 TCP/UDP, 별도 ساقط_قدر 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 عنصر_قدر_2ed200e9·Thread·Swing은 JVM 경로의 기능이며 AOT معاونت_قدر 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 تعميل_ڪرڻ_حڪم**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK درجو_قدر لائبريري 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 درجو_قدر·ساقط_قدر طريقو_قدر 중심이던 실행기를 عنصر_قدر_2ed200e9·لائبريري تعميل_ڪرڻ_حڪم 기반으로 넓힌 것이다.

## 실행과 گڏ_ڪريو_ماخذ

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# 자체 ڪرنل_قدر 안에서 ماخذ_شجرو گڏ_ڪريو_ماخذ → class تعميل_ڪرڻ_حڪم, 한국어 API 호출
python3 اوزار/تعميل_ڪرڻ_فائل.py 시험/자바/한글소스.java

# عنصر_قدر_2ed200e9·예외 등은 مهمان JDK로 Java 8 class를 만든 후 자체 커널에서 تعميل_ڪرڻ_حڪم
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 اوزار/تعميل_ڪرڻ_فائل.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 منتقلي_قدر
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 اوزار/تعميل_ڪرڻ_فائل.py build/my-java/객체시험.class \
  --include build/my-java/پس_منظر_قدر.class --include build/my-java/شاخ_قدر.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.درجو_قدر.class`라는 RAM فائل 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.درجو_قدر`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.درجو_قدر`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar فائل.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 한국어 클래스만 찾는다. 배포 한국어 لائبريري JAR는 مهمان javac의 classpath로 사용하며, 같은 클래스가 صارف JVM ELF에도 읽기 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 ساقط_قدر طريقو_قدر, int/boolean/char/String, حالت·دهرائڻ_قدر, اسٽرنگ_قدر 결합, 일부 فائل 스트림 등의 **자체 부분집합 컴파일러**다. عنصر_قدر_2ed200e9 선언·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 자체 JVM에서 실행한다. 한국어 API 중 출력·문자 스칼라 فعل_قدر·فائل 읽기/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] 인수) throws Exception {
        한국어.자체.출력.لکو_لڪير("안녕하세요😀");
        한국어.자체.출력.수쓰기(한국어.자체.문자.코드포인트수("한글😀"));
        한국어.자체.فائل.لکو("인사.txt", "한글 فائل😀");
        한국어.자체.출력.لکو_لڪير(한국어.자체.فائل.읽기("인사.txt"));
    }
}
```

## 한국어 API

독립 패키지 **`한국어.자체`**를 사용한다. Linux판 `한국어.자바`가 요구하는 NIO/Swing/HTTP API를 자체 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 درجو_قدر نالو·طريقو_قدر·인수·قطعه_قدر·فائل 이름에 한국어를 사용한다. 표준 Java درجو_قدر 이름은 호환성을 위해 보존한다.

| درجو_قدر | 공개 기능 | 이름의 의미 |
|---|---|---|
| 출력 | لکو, لکو_لڪير, 수쓰기 | 출력(出力): 내용을 바깥으로 내보냄 |
| 문자 | لمبائي_قدر, 같음, چپڪايو_متن, ڪٽيو_قدر, 정수읽기/لکو_عدد_صحيح_قدر, 코드포인트수, 부호화/طئي_ٿيل_ڪوائف | 문자(文字), ضابطه_ربائي_قدر(符號): 글의 단위와 그 값을 바이트로 나타내는 فلٽر_قدر |
| فائل | 읽기/لکو(String نالو), 바이트읽기/لکو_بائٽ_قدر | 널리 쓰는 صارف 용어를 보존; RAM 자료의 نالو |
| داخلا_فهرست | 더하기, 읽기, بدلو_قدر, 지우기, سائيز, 비었는가, صاف_ڪريو_موادَ | داخلا_فهرست(目錄): 순서가 있는 داخلا_قدر 모음 |
| ڊڪشنري | 넣기, ڳوليو_داخلا, 있는가, 지우기, سائيز, صاف_ڪريو_موادَ | ڊڪشنري(辭典): 찾는 말인 열쇠에 값을 대응 |
| 작업 | هلائڻ(실행할일), 기다리기(작업가닥), معطل_ڪريو_ٽاسڪ, 살아있는가 | 작업 لڙي_قدر: 한 ائپ_f5044b9b 안의 تعميل_ڪرڻ_حڪم اسٽريم_قدر |
| 통신 | ٺاھيو, اي_ميل, 받기, 대기시간, بند_ڪرڻ | 통신(通信), 전문(電文), پورٽ_قدر: ڪوائف 교환·메시지·포트의 역할 |
| 화면 | 사각형, 지우기 | 화면(畫面): اصلي_ڪوائف 그림을 표시하는 면 |
| ڪرنل_قدر | 밀리초, 사각형 | 자체 JVM의 고정 native ڪنيڪٽ; 일반 JNI는 아님 |

이 명명은 현재 기능을 설명하는 용어 선택이다. 기존 한국어에 없던 역사적 어원을 만들어 주장하지 않는다. فائل_نالو_متن·식별자는 UTF-8 소스로 보관한다. `문자.طئي_ٿيل_ڪوائف`는 잘못된 UTF-8에 IllegalArgumentException을 던지며, `부호화`는 짝이 없는 서로게이트를 `?`로 바꾼다. `فائل.읽기`는 엄격한 UTF-8 복호화를 적용한다. 화면 색은 `빨강 | (초록 << 8) | (파랑 << 16)` 형식이다.

## تعميل_ڪرڻ_حڪم 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(한국어 درجو_قدر 포함), class당 16 KiB·لاڳاتار_جزو_قدر 풀 511항목, 전체 طريقو_قدر/قطعه_قدر 각각 512개. طريقو_قدر 코드 8 KiB, مقامي_اسڪوپ 변수·피연산자 스택 각각 128슬롯, 인수 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 تعميل_ڪرڻ_حڪم 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- عنصر_قدر_2ed200e9 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 اصلي_ڪوائف 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 فائل·대형 اسٽرنگ_قدر·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 حڪم 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 دري سوئچ_موڊ 시 중단·재개한다. 일반 سرور_قدر·계산의 무제한 실행은 아직 없다. 미지원 حڪم·ذريعو_قدر 부족은 명시적인 오류로 종료한다.
- RAM فائل 최대 64개, 파일당 16384바이트, راههه UTF-8 63바이트. RAM 디렉터리와 همعصر_قدر/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 한국어 class는 RAM فائل 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 현재 경로에서 ماخذ_شجرو·درجو_قدر·ڪوائف 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 외부 IPv4를 제공한다. اصلي_ڪوائف GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. 전문 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 تعميل_ڪرڻ_حڪم 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 ترتيب_قدر_ed437109, 완전한 ترتيب_قدر_ed437109 공변성·인터페이스 پرت_قدر 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/ضابطه_ڪسائي_ڪوائف/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 معاونت_قدر 부분집합은 아래 및 개발 매뉴얼을 참고한다. درجو_قدر فائل 전체 검증기·پهچ_داخلا اجازت_قدر/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 حفاظت_ڪريو_قدر 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM قدر/ڪارگر_ڪريو/درجو_قدر 로더와 예외 모델 → 영속 VFS·mmap·گهڙي·원자 عمل_قدر_c96707fb·اصلي_ڪوائف 스레드/هم_وقت ABI → OpenJDK java.base 및 native لائبريري 이식 → آلو_قدر 네트워크·TCP/IP → دري 시스템/فانٽ_قدر/입력기·java.desktop → Java SE 호환성 시험. 현재 자체 JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## ڪارگر_ڪريو

`اوزار/자바가상기계시험.py`는 같은 Java 8 class 파일의 출력을 مهمان OpenJDK `-Xverify:all`과 QEMU raspi4b 자체 커널에서 비교한다. عنصر_قدر_2ed200e9/상속/인터페이스·switch·ترتيب_قدر_ed437109, 예외/finally, 컬렉션/GC, Thread/잠금, 한국어 UTF-8/فائل/컬렉션, اصلي_ڪوائف UDP 루프백/시간 초과, 게스트 한글 ماخذ_شجرو گڏ_ڪريو_ماخذ, ترتيب_قدر_ed437109 قسم_قدر/نقل_قدر/فائل 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 فائل 거부 시험을 실행한다. UDP 기준 실행에는 مهمان 루프백 소켓 권한이 필요하다.

`اوزار/부팅시험.py`는 ڪرنل_قدر حفاظت_ڪريو_قدر/회귀 시험과 별도로 한국어 Java 화면 API가 اصلي_ڪوائف 픽셀을 그렸는지도 QMP 화면 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. اصلي_ڪوائف Pi4 하드웨어 부팅 시험과 전체 JDK 호환성 시험 결과는 아니다.


## JVM 0.3: 네트워크와 GUI واڌ_قدر

`Socket`/`ServerSocket` 생성·ڪنيڪٽ·accept·양방향 InputStream/OutputStream·close·EOF·시간 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 외부 ڊجٽ_قدر IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 ختم_ڪريو_هنڌ 16개, Java 루프백 버퍼 1024바이트, 외부 TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. متعامل 이벤트 대기는 تعميل_ڪرڻ_حڪم 기한을 갱신하고 터미널 سوئچ_موڊ 시 프로세스 상태를 روڪيو_قدر·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

한국어 `دري`, `وجيٽ`, `연결통신` 클래스를 배포 JAR와 자체 JVM 내장 자원에 추가했다. 상세 طريقو_قدر·제한·ماخذ_شجرو·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## 한국어 객체의 직접 تعميل_ڪرڻ_حڪم

`دري`, `پرچي`, `متن_فيلڊ`, `بٽن`, `واقعو_قطار`, `동작알림`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. 자체 JVM의 عنصر_قدر_2ed200e9 생성,
وضع_قدر 검사, 화면 호출, واقعو 큐, لڙي_قدر 스케줄러에 한국어 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 تعميل_ڪرڻ_حڪم 경로도 유지한다.
한국어 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

자체 실행기의 한국어 진입점은 `public static void هلائڻ()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 한국어 진입점을 우선한다.
명령행 인수는 `실행인수.개수()`와 `실행인수.متن(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. ساقط_قدر فائل 예제는 게스트
javac로도 컴파일하며, GUI/لڙي_قدر 소스는 مهمان `javac --release 8`을 사용한다.
직접 GUI/لڙي_قدر API는 자체 JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
한국어 가닥의 تعميل_ڪرڻ_حڪم·대기·중복 هلائڻ 거부, GUI واقعو 출처·ابتدائي·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

طريقو_قدر 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
한국어 클래스도 실행되지만, اسٽرنگ_قدر 리터럴·표준 لائبريري 재정의·native
ڪنيڪٽ·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 예제](한국어자바/پڙهو_فائل_eb81d7d9.md)를 참고한다.
