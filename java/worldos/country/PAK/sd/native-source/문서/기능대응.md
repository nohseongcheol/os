## 기존 عنصر_قدر_2ed200e9 기반 관리 ڪرنل_قدر 전체를 부팅하기 위해 남은 ڪنيڪٽ

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/آلو_قدر 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot داخلا_هنڌ_قدر, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 مفهوم_قدر روڪيو_قدر
- اصلي_ڪوائف PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA لوپ_قدر
- Java عنصر_قدر_2ed200e9·ترتيب_قدر_ed437109 ڪڙي_لي_آئوٽ, 예외, ساقط_قدر شروع_ڪريو, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT اسٽيج_قدر
- FAT 디스크 구역을 اصلي_ڪوائف ATA 장치와 연결하는 입출력 접착 پرت_قدر

위 관리 계층은 engos 기능의 Java 관리 구현과 مهمان 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot داخلا_هنڌ_قدر, ساقط_قدر شروع_ڪريو·عدد_صحيح ترتيب_قدر_ed437109, VGA/직렬/PS2, 명령해석기, صارف ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 مهمان 루프백 패킷 왕복을 검증했다. 위 표의 عنصر_قدر_2ed200e9 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
