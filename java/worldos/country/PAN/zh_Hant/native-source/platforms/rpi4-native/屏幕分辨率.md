# 內建 ARM64 커널의 屏幕 分辨率值

QEMU 執行命令 위치는 `jkoros/platforms/rpi4-native`第三操作數. 커널을 빌드한 後端值 다음과 같이 실행한다.

```bash
make build
python3 工具集/執行命令.py --desktop --network --resolution 1920x1080
```

Remmina의 **VNC** 連接 주소는 `127.0.0.1:5902`第三操作數. 이미 執行命令 중인 VM은 종료하고 새 옵션으로 重試值 시작한다. 屏幕 전체가 보이지 않으면 Remmina에서 屏幕 對齊邊界位置 또는 전체 화면을 선택한다. 이 옵션은 게스트의 實際資料 像素 수를 바꾼다.

`--resolution`은 일반 UART 執行命令, `--desktop`, `--vnc`, `--display`에서 동일하게 적용된다. `--network`와 함께 사용할 數 있다. 寬度值 640~1920, 高度值 480~1080을 허용하며 기본값은 640×480이다. 1280×720과 1920×1080도 선택할 數 있다.

```bash
make desktop RESOLUTION=1920x1080
python3 工具集/執行命令.py --resolution 1280x720 --vnc 127.0.0.1:2
```

啓動 로그는 實際資料 할당된 크기를 표시한다.

```text
FRAMEBUFFER PASS 1920x1080 RGB32 (drawing only)
```

終端 바탕과 上位側側 막대는 屏幕 전체를 채운다. 터미널은 右 아래까지 끌어서 이동하고 X로 닫을 數 있다. 終端 窗口 大小(568×360)와 字體值 크기는 유지되므로 넓어진 화면에 여러 창을 배치할 數 있다. Swing 부분집합의 `setLocationRelativeTo(null)`도 實際資料 屏幕 가운데를 사용한다. 啓動 後端值 해상도를 바꾸는 기능은 제공하지 않는다.

## 프로그램에서 屏幕 大小 讀取

| 語言 | 中文 調用 |
|---|---|
| Java | `中文.內建.屏幕.寬度值()`, `屏幕.高度值()`, `屏幕.擦除條目(顏色值)` |
| C | `<屏幕ABI.h>`의 `屏幕寬度()`, `屏幕高度()`, `繪製矩形(...)` |
| C++ SDK | `調用.h`의 `讀取屏幕寬度()`, `讀取屏幕高度()`, `屏幕矩形(...)` |
| Python | `from 中文 import 屏幕大小, 繪製矩形`; `寬度值, 高度值 = 屏幕大小()` |

C 함수는 宏值 별칭이 아닌 實際資料 함수다. 使用者 調用 22로 크기를 조회하며, 畫圖屏幕 調用 13과 GUI 調用 20은 實際資料 屏幕 경계를 검사한다. 프레임버퍼 주소는 使用者 프로그램에 노출하지 않는다. 屏幕 밖의 요청은 오류를 반환한다.

게스트 `javac`에서는 `中文.內建.屏幕.寬度值()`처럼 전체 이름으로 호출한다. 지원하는 原始碼樹 문법에 맞춰 像素顏色 상수는 십진수로 쓴다. 底端值 호출은 啓動 해상도와 관계없이 最後項目 화소를 그린다.

```java
int 寬度值 = 中文.內建.屏幕.寬度值();
int 高度值 = 中文.內建.屏幕.高度值();
中文.內建.屏幕.矩形(寬度值 - 1, 高度值 - 1, 1, 1, 255);
```

`屏幕` 클래스의 프레임버퍼 호출은 內建 JVM 전용이다. 이 API의 異常 程序值條目 시험은 宿主 `javac --release 8`로 컴파일한 class를 內建 JVM에서 실행한다. 게스트 컴파일러의 일반적인 `try/catch` 문법 지원을 추가한 것은 아니다.

## Raspberry Pi 4 SD 啓動

```bash
make image RESOLUTION=1920x1080
```

생성되는 `dist/jkoros-native-rpi4.img`와 `dist/jkoros-native-rpi4-boot.zip`에 1080p 설정이 들어간다. SD 映像值 생성은 640×480, 1280×720, 1920×1080을 지원한다. 이미 펼친 啓動 파일을 수정할 경우 `config.txt`의 `[pi4]`에 底端值 값을 사용한다.

```ini
max_framebuffer_width=1920
max_framebuffer_height=1080
framebuffer_width=1920
framebuffer_height=1080
hdmi_group=1
hdmi_mode=16
```

커널은 [Raspberry Pi 郵箱 契約值](https://github.com/raspberrypi/firmware/wiki/Mailbox-property-interface)의 當前項目 屏幕 大小 조회와 屏幕 分配存儲裝置 응답을 사용한다. 응답의 大小·RGB32 格式值·한 줄의 位元組值 數·分配存儲裝置 용량을 확인하고, 반환된 行 간격으로 그린다. 初始狀態 조회에 실패하거나 支持值 범위를 벗어나면 640×480을 요청한다. HDMI 설정은 [공식 펌웨어 屏幕 設置 文檔集](https://www.raspberrypi.com/documentation/computers/legacy_config_txt.html)를 따른다. 實際資料 Pi 4와 모니터 조합에서의 HDMI 부팅은 아직 검증하지 않았다.

## 有效性校驗

```bash
make test-resolution
```

시험은 각 해상도에서 實際資料 VNC 屏幕 크기와 픽셀, 終端 拖動值·關閉, C/Java 게스트 編譯原始碼, Python 執行命令, 右 底端值 픽셀과 屏幕 邊界位置值 錯誤, Swing 中間 鏈接佈局·按鈕·關閉, GUI와 FTP 동시 사용을 확인한다. 결과와 屏幕 캡처는 `build/verification/resolution/`에 저장한다.
