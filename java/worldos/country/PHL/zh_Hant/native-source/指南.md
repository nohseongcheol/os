# JPhlOS

當前項目 內建 ARM64 배포판은 [LICENSE](LICENSE)의 COSL 상업 조건을 유지한다. 제3자 라이선스의 권리는 별도로 보장하며, 分發值 시 原始碼樹·重新連接端點 자료를 포함하는 절차는 [COSL 分發值 指南](platforms/rpi4-native/COSL分發指南.md)에 있다.

內建 ARM64 판의 `ipconfig`/`ip`, `ping`, `ps`/`top`, `free`/`df`, `poweroff`와 中文 명령은 [네트워크·運行系統值 命令 指南](platforms/rpi4-native/網路與系統命令列.md)를 참고한다. 새 커널을 부팅한 後端值 `help system`으로 볼 數 있다.

Raspberry Pi 4 **內建 Java ARM64 內核值**은 [內建 Pi4 指南](platforms/rpi4-native/指南.md)에 있다. Linux 없이 부팅하며 GUI 終端·vi, 內建 JVM의 Swing 일부 API, TCP/UDP·FTP, 게스트 TinyCC·MicroPython, C/C++의 posix-kor 호출을 제공한다. [中文 Java 通信·異常 API](platforms/rpi4-native/中文Java/指南.md)와 [中文 原始碼樹 命名](platforms/rpi4-native/命名/指南.md)을 지원한다. [內建 SSH·VNC 및 GENET 드라이버](platforms/rpi4-native/外部連接狀態指南.md)를 포함하며, 네트워크는 QEMU의 UART SLIP 경로로 검증했다. 實際資料 Pi 4 GENET 동작은 미검증이고, USB 輸入值·영속 저장과 전체 OpenJDK·Swing은 아직 支持值 裁剪 밖이다.

Raspberry Pi 4용 Linux·OpenJDK 실행판과 使用者 環境 移動值 기능은 [라즈베리파이 실행판](platforms/rpi4/README.md)에 있다. 實際資料 ARM64 JDK/JRE와 시스템·使用者 構建映像 構建系統 경로를 제공한다. 기존 內建 x86 커널과는 별도 執行命令 기반이다. 일반 Java `.class`/JAR의 執行命令 檔案 생성은 [OpenJDK 執行命令 檔案](compiler/OpenJDK-可執行文件檔案.md), 中文 API는 [中文 Java 庫](中文Java/指南.md)를 참고한다.

`jkoros`는 `engos`의 기능을 Java 관리 커널로 옮기는 프로젝트다. 프로젝트가 소유하는 Java 函數, 變量值, 格式值 및 Java 檔案 이름은 한국어로 작성한다. 표준 Java 실행기의 `main`, Java 표준 庫 格式值, x86 부트 ABI 등 外部值 계약은 보존한다. 內建 ARM64 실행기는 中文 `運行()`도 진입점으로 지원하며, 中文 GUI·任務 가닥을 JVM에 직접 구현했다. 內建 ARM64 C 연결부·Python 도구와 공용 x86·ARM64 AOT 번역기의 內建 이름도 한국어로 작성한다. 上一個項目 경로의 호환 條目分, OpenJDK 輔助值 도구와 Linux 版本值 도구에는 영어 이름이 남아 있고 [命名 원칙·말의 근거·전체 原始碼 검토 裁剪](platforms/rpi4-native/命名/指南.md)를 별도로 기록한다.

## 當前項目 實現

底端值 목록은 기존 `基礎原始碼/`의 JVM 관리 커널에 대한 것이다. 實際資料 네이티브 커널의 범위는 `os/指南.md`에서 별도로 설명한다.

- 對齊值 할당과 해제를 지원하는 記憶體空間 管理器值
- 地址 地址區域, 頁值 連接, 寫入 시 複製值(COW)
- 程序值 標識符值, 準備 대기열, fork/wait 狀態值
- 과정별 檔案 描述符條目, open/read/seek/dup/close
- ELF32 識別值 및 區段值 檢查項
- 키보드·마우스 輸入值 事件 대기열
- 串行值 단말과 네이티브 硬件值 邊界位置值
- 관리 內核值 전체 자동 測試

세부 映射值 범위와 아직 필요한 네이티브 연결은 [기능 대응표](文檔集/功能對應.md)에 기록한다.

## 빌드와 測試

새 네이티브 구현은 `compiler/`와 `os/`에 있다. 기존 `基礎原始碼/`의 JVM 관리 커널은 그대로 보존하며, 두 구현의 시험과 기능 범위는 서로 다르다.

```sh
cd /home/user/jkoros
make                 # 네이티브 計算結果 範例 + Java 內核值 ELF
make iso             # os/build/kernel.iso
make run             # QEMU 串行值 終端輸入輸出; help 輸入值 (종료는 Ctrl+A, X)
make run-gui         # ISO를 QEMU 屏幕/PS2 키보드로 執行命令
make vbox            # 전용 VirtualBox VM 자동 生成·執行命令 (GUI)
make vbox-status     # VirtualBox 狀態值·ISO·串行值 日誌記錄 路徑 驗證
make test-vbox       # VirtualBox 運行器 狀態值 程序值條目 測試 (實際資料 VM 更改值 缺失方法)
make test            # 編譯器 測試 + ELF/ISO 啓動 및 命令 輸入值 測試
make apps            # 독립 使用者 ELF 程式 構建系統
make test-network    # 使用者 模式值·UDP 왕복·記憶體資料 保護值 測試
make test-java       # 게스트 javac/JVM + OpenJDK 양방향 교차 執行命令 測試
make posix-kor       # 中文 C 헤더와 實際資料 內核值 調用 庫
make test-posix      # 檔案/UDP/存儲值/Java 檔案 輸入輸出 測試
make -C os run-store # 전용 存儲值 매체로 QEMU 啓動
make legacy-test     # 底端值 기존 JVM 관리 커널의 47개 測試
```

`compiler/`는 호스트의 `javac`를 문법·類型值 檢查項 전단으로 사용하고 內建 字節碼→x86 변환기로 ELF32 기계어를 만든다. 빌드할 때는 JDK가 필요하지만 생성된 커널과 ELF는 外部值 JVM 없이 실행된다. 전체 Java, 物件值 모델, 표준 라이브러리와 기존 관리 內核值 전체의 AOT 변환은 아직 지원하지 않는다. 자세한 支持值 문법과 명령은 [編譯器 指南](compiler/指南.md), 實際資料 啓動 기능과 한계는 [네이티브 操作系統 指南](os/指南.md)를 참고한다.

네이티브 셸에 內建 제한형 `javac`와 `java`를 추가했다. `edit Demo.java`로 소스를 입력하고 `.save`로 저장한 後端值 `javac Demo.java`, `java Demo`로 **게스트 내부에서 컴파일하고 執行命令**할 數 있다. 默認值 예제는 `javac Hello.java`, `java Hello`第三操作數. 파일은 RAM에서 동작하며, 전용 存儲值 매체를 연결하면 `sync`로 재부팅 후에도 보존할 數 있다. **OpenJDK/JDK 전체 이식은 아니며**, 단일 類別值·靜態值 函數·整數·字符串·條件/반복문과 일부 표준 호출을 지원한다. 支持值 裁剪, 外部值 檔案 적재와 시험은 [Java 開發 環境 指南](文檔集/Java開發環境.md)에 있다.

네이티브 셸에서 `apps`, `run hello first second`, `net`, `run netcheck`를 사용할 數 있다. 독립 ELF를 ring 3에 적재하고 `int 0x80` 호출을 통해 輸出·實參·UDP 네트워크를 제공한다. 별도 宿主 터미널에서 `python3 os/工具集/資料復原.py --port 9000`을 실행한 後端值 게스트에서 `run udp 10.0.2.2 9000 hello`로 實際資料 왕복을 확인한다. 새 程式 登記, API 및 제한은 [使用者 執行命令·네트워크 指南](os/使用者/指南.md)를 참고한다. 當前項目 QEMU RTL8139·靜態值 IPv4·UDP 전용이며 TCP/DNS는 미지원이며, 전용 IDE 存儲值 형식과 POSIX 檔案/UDP 일부 기능을 추가했다.

`make vbox`는 `jkoros operating system` 전용 VM을 만들고 디스크 없이 ISO로 부팅한다. 執行命令 중이면 유지하고, 存儲值·일시정지 상태이면 재개하며, 꺼져 있을 때만 새 ISO를 빌드해 연결한다. VirtualBox에서 부팅과 셸의 使用者 程式 실행을 확인했다. 다만 當前項目 VirtualBox용 네트워크 드라이버는 없어 네트워크 장치를 비활성화한다. UDP 시험에는 `make run`을 사용한다. 상태별 동작과 새 構建系統 반영 방법은 [VirtualBox 執行命令 指南](文檔集/VirtualBox運行.md)에 있다.

기존 관리 커널만 시험하려면:

```sh
cd /home/user/jkoros
make -f 創建條目.mk 檢查項
make -f 創建條目.mk 宿主
```

`宿主`는 여전히 JVM 관리 계층의 動作 시험이다. `make -f 創建條目.mk 構建映像`는 새 `os/`의 제한형 네이티브 內核值 ISO를 만든다. 기존 `基礎原始碼/`의 檔案系統·程序值·通信網絡 實現 전체를 이 ISO에 이식했다는 의미는 아니다.

中文 函數·變量值·檔案 이름과 實際資料 C API는 [posix-kor](posix-kor/指南.md)에 있다. 게스트 Java에서는 `FileInputStream`·`FileOutputStream`의 단일 位元組值 입출력도 지원한다. 전체 POSIX·OpenJDK·Swing 지원으로 확대된 것은 아니다.

外部值 배포용 `pack.sh` / `unpack.sh`와 자동 依賴項列 복원은 [分發值 指南](distribution/README.md)를 참고하세요.
