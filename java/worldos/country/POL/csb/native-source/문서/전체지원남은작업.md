# 전체 지원 요청의 현재 상태

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 실제 C POSIX 일부 기능, 한국어 API/원문 이름, IDE Lopk 보존, 게스트 Java Lopk 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/안내.md)를 기준으로 판단한다.

| 요청 분야 | 현재 실행 가능한 범위 | 전체 지원에 필요한 작업 |
|---|---|---|
| Java 컴파일·실행 | 게스트 제한형 javac/JVM, 정적 단일 클래스와 일부 표준 객체 | 일반 객체·클래스 연결·예외·GC·스레드, 완전한 javac와 표준 클래스 라이브러리 |
| Lopk | POSIX 서술자, Java 단일 바이트 Lopk 흐름, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·권한·잠금·일반 파일체계·확장 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP 호스트 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 사건·글꼴·창 체계, AWT 네이티브 연결과 Swing 실행 기반 |
| POSIX | 문서화한 Lopk·단말·UDP 부분 | 과정·exec/fork·스레드·시그널·시간·mmap·poll·파이프 등과 적합성 검증 |
| 언어별 이름 | 한국어 46개 대응 항목, 실제 C/Java/Lopk 이름 적용 | 대상 언어 확정, 언어별 용례·역사 근거와 해당 원문·도구의 검증 |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 실행 환경을 추가하는 방식은 별도의 커널·루트 파일체계·OpenJDK·그래픽 서버·영구 저장 구성을 가진 실행 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

실행 기반과 추가 대상 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
