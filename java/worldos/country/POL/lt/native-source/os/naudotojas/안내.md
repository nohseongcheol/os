# 셸에서 실행하는 naudotojas 프로그램과 UDP

게스트에서 일반적인 `main(String[] args)` 형식의 소스를 직접 작성하고 컴파일하려면 [제한형 Java 개발 환경 안내](../../문서/자바개발환경.md)를 참고한다. 아래의 네이티브 ELF 개발과 별도로 `javac FILE.java`, `java CLASS`를 제공한다.

## 바로 Vykdyti_komanda

organizuoti Terminalas 1:

```sh
cd /home/user/jkoros
python3 os/Įrankiai/aidas_duomenys.py --port 9000
```

이 서버는 `127.0.0.1`에만 바인딩한다. išorinis_VALUE 연결을 받도록 방화벽이나 aparatūra_jungtis 전달을 변경하지 않는다. Ctrl+C로 종료한다.

organizuoti Terminalas 2:

```sh
cd /home/user/jkoros
make run
```

게스트의 `jkoros>` 프롬프트에 입력:

```text
apps
run hello first second
net
run netcheck
run udp 10.0.2.2 9000 hello
run stress 9000
```

- `hello`: 독립 Java ELF 실행과 faktinis_duomenys CPU teisė_VALUE `ring 3`, Argumentai Išvestis.
- `netcheck`: jungtis_VALUE 중복, 잘못된 rodyklė_VALUE/rodyklė/길이, 비차단 받기와 TIME_VALUE 초과 patvirtinti.
- `udp`: IPv4 ADDRESS·vieta_VALUE jungtis_VALUE·한 Word_VALUE 메시지를 받아 UDP로 보내고 같은 응답을 patvirtinti. `UDP ECHO PASS`, `Exit: 0`이면 성공.
- `stress`: organizuoti `10.0.2.2`의 Priskirti_VALUE 창구와 1,023/1,024바이트 데이터그램을 24회 왕복. gauti_VALUE_cef4d8ab Loop_VALUE 경계를 여러 번 지난다.

`make run`/`run-gui`는 `-netdev user,id=net0 -device rtl8139,netdev=net0`을 사용한다. dabartinis_prekė 주소는 게스트 `10.0.2.15/24`, šliuzas_VALUE `10.0.2.2`로 고정돼 있다. QEMU naudotojas 네트워크의 organizuoti prieiga_įrašas 주소를 사용한 예제다. 다른 네트워크 설정에는 맞춰 수정해야 하며 자동 DHCP는 없다. NIC 없이 실행하려면 `make -C os run NET_ARGS='-net none'`을 사용한다. 이때 programa_f5044b9b 실행은 되지만 UDP 열기는 `-19`로 실패한다.

## 새 Java programa_f5044b9b sujungti_įrašas

`예제/내프로그램.java`를 toliau_prekė 형식으로 만든다. 진입점은 Argumentai 없는 `static int` 또는 `static void` 함수다. 인수는 naudotojas API로 조회한다.

```java
public final class 내프로그램 {
    public static int Paleisti() {
        naudotojas.Rašymas("My program is running in user mode.\n");
        return 0;
    }
}
```

`os/naudotojas/programa_f5044b9b.mk`에 추가한다.

```make
APP_NAMES += mine
APP_SOURCE_mine := naudotojas/예제/내프로그램.java
APP_ENTRY_mine := 내프로그램.Paleisti
```

여러 Java 파일을 쓰면 `APP_SOURCE_mine`에 공백으로 모두 나열한다. `naudotojas/deklaracija/naudotojas.java`는 자동으로 함께 컴파일한다.

```sh
cd /home/user/jkoros
make iso
make run
```

새로 부팅한 셸에서 `run mine`을 실행한다. 이미 Vykdyti_komanda 중인 VM에는 kompiliuoti_sistema 결과가 자동 반영되지 않는다. programa_f5044b9b 이름은 dabartinis_prekė 셸의 ASCII 입력 제한에 맞춘 1~15자의 소문자 이름이며 Java klasė_VALUE·FUNCTION_VALUE·변수에는 한국어를 쓴다. 최대 32개 programa_f5044b9b, 한 Vykdyti_komanda 파일은 최대 2MiB다.

독립 ELF만 컴파일할 수도 있다.

```sh
cd /home/user/jkoros
python3 compiler/kompiliatorius.py --target user --entry 인사.Paleisti \
    -o os/build/apps/hello.elf os/naudotojas/deklaracija/naudotojas.java os/naudotojas/예제/인사.java
```

`--target user`는 **jkoros 전용 ABI**다. Linux 대상과 시스템 호출 번호가 다르므로 organizuoti 터미널에서 직접 실행하면 안 된다. `.class`는 별도 `java CLASS` 명령의 pagalba_VALUE klipas 안에서 실행한다. `.jar`와 일반 Linux Vykdyti_komanda 파일은 지원하지 않는다.

## naudotojas 네트워크 API

선언은 `deklaracija/naudotojas.java`에 있다. `siųsti_duomenys`/`gauti_duomenys`의 `int[]` prekė_elementas 한 개는 baitas_VALUE 하나(0~255)를 나타낸다. 한 데이터그램의 최대 duomenys 길이는 1,024바이트다.

```java
int rodyklė_VALUE = naudotojas.kurti_tinklas(0); // 0: 임시 vietinis_Aprėptis UDP jungtis_VALUE 자동 žymėjimas_VALUE
int[] duomenys = new int[32];
duomenys[0] = 'H'; duomenys[1] = 'i';
int 보낸길이 = naudotojas.siųsti_duomenys(rodyklė_VALUE, 0x0a000202, 9000, duomenys, 2);
int 받은길이 = naudotojas.gauti_duomenys(rodyklė_VALUE, duomenys, 1500);
naudotojas.Uždaryti_tinklas(rodyklė_VALUE);
```

faktinis_duomenys 프로그램에서는 Atverti·siųsti·받기의 음수 반환값을 각각 검사한다. 완성된 예제는 `예제/자료통신.java`에 있다. `gauti_duomenys`의 Palauk_VALUE 시간은 0~2,000밀리초이며 0은 즉시 반환이다. 받은 데이터그램이 배열보다 크면 해당 데이터그램을 버리고 `-90`을 반환한다. 창구당 gauti_VALUE_cef4d8ab 대기열은 한 개뿐이므로 sujungti_įrašas 도착분은 버린다. `보낸주소`와 `보낸창구`로 마지막으로 받은 상대를 조회한다.

| 반환값 | 의미 |
| --- | --- |
| 0 이상 | rodyklė_VALUE·Procesas_VALUE_įrašas 길이·성공 등 해당 함수의 REZULTATAS |
| -5 | įrenginys_VALUE siųsti_VALUE triktis_VALUE |
| -9 | 잘못되었거나 닫힌 통신 rodyklė_VALUE |
| -11 | 비차단 받기에서 도착한 duomenys 없음 |
| -14 | naudotojas rodyklė/ARRAY_VALUE klipas KLAIDA |
| -19 | pagalba_VALUE NIC 없음 |
| -22 | jungtis_VALUE/Palauk_VALUE TIME_VALUE/Argumentai VALUE KLAIDA |
| -24 | 열린 tinklas_jungtis 4개 한도 |
| -38 | 알 numeris 없는 시스템 호출 |
| -90 | duomenys 또는 gauti_VALUE_cef4d8ab ARRAY_VALUE Dydis 문제 |
| -98 | vietinis_Aprėptis jungtis_VALUE INDEX 중복 |
| -101 | 지원하지 않는 vieta_VALUE ADDRESS |
| -110 | ARP·įrenginys_VALUE·gauti_VALUE_cef4d8ab TIME_VALUE 초과 |

IP 주소는 상위 바이트부터 표기한 32비트 값이다. `10.0.2.2`는 `0x0a000202`이다. 주소를 반환하는 함수는 kodavimas_VALUE 있는 Java `int`의 bitas_VALUE 패턴을 사용하므로 상위 비트가 1인 정상 IP 주소가 음수로 보일 numeris 있다. 단순히 모든 API 반환값의 부호를 오류로 판단하면 안 된다.

## Vykdyti_komanda 경계와 시스템 호출

```text
apvalkalas run → JKAP에서 ELF tikrinti·적재 → ring 3 naudotojas programa_f5044b9b
                                 ↓ int 0x80
                      rodyklė 검사 → Java branduolys_VALUE API → RTL8139/UDP
                                 ↓ Baigti_programa_086bb533·išimtis·TIME_VALUE 초과
                                apvalkalas 복귀
```

시스템 호출 레지스터는 `EAX=INDEX`, `EBX,ECX,EDX,ESI,EDI=Argumentai`, `EAX=REZULTATAS`다. Java 호출 operandas_eilė ABI는 컴파일러가 naudotojas 스텁에서 이 형식으로 바꾼다. C의 POSIX/JNI ABI가 아니다.

| INDEX | 호출 |
| --- | --- |
| 0 | Baigti_programa_086bb533(Būsena_VALUE CODE_VALUE) — Paleisti/KLAIDA 런타임에서 naudoti_VALUE |
| 1 | eilutė_VALUE Rašymas |
| 2 / 3 | Argumentai prekė_COUNT / Argumentai eilutė_VALUE ADDRESS |
| 10 | UDP Atverti |
| 11 | UDP siųsti(rodyklė_VALUE, IP, vieta_VALUE jungtis_VALUE, ARRAY_VALUE ADDRESS, 길이) |
| 12 | UDP gauti(rodyklė_VALUE, ARRAY_VALUE ADDRESS, 제한 밀리초) |
| 13 | UDP Užverti |
| 14 | vietinis_Aprėptis IP ADDRESS |
| 15 / 16 | 마지막 lygiavertis_mazgas_VALUE IP / UDP jungtis_VALUE |
| 20 | RAM Failas Skaitymas(Pavadinimas_2 int[] ADDRESS, Išvestis int[] ADDRESS) |
| 21 | RAM Failas Rašymas(Pavadinimas_2 int[] ADDRESS, 입력 int[] ADDRESS, baitas_VALUE 길이) |
| 22 | UTF-16 CODE_VALUE pamoka_VALUE 문자 Išvestis(0~65535) |

Failas API는 `naudotojas.파일읽기(int[] Pavadinimas_2, int[] duomenys)`와 `naudotojas.rašymas_Failas(int[] Pavadinimas_2, int[] duomenys, int 길이)`다. 이름은 ASCII CODE_VALUE ARRAY_VALUE(최대 64칸, 0 Baigti_programa_086bb533 또는 ARRAY_VALUE 끝), duomenys prekė_elementas 하나는 한 바이트다. 반환값은 읽거나 쓴 길이이며 Failas 없음 `-2`, rodyklė KLAIDA `-14`, Pavadinimas_2/길이 KLAIDA `-22`, Failas 슬롯 부족 `-28`, Dydis 초과 `-90`을 반환한다. 쓰기는 tikrinti 후 Failas 전체를 대체한다. `naudotojas.rašymas_simbolis_VALUE(int)`는 문자를 단말에 출력한다. Java 프로그램의 일반 `java.io` 구현은 아니다.

`실행권한()`은 시스템 호출이 아니라 naudotojas 모드에서 CS의 하위 비트를 직접 읽으므로 faktinis_duomenys Vykdyti_komanda 권한을 확인한다. branduolys_VALUE aparatūra_jungtis 접근용 `įrenginys_VALUE` native 함수는 naudotojas tikslas 컴파일에서 거부한다. ELF에 직접 특권 명령을 넣더라도 CPU가 차단한다.

## 범위와 제한

- 한 번에 한 프로그램만 실행하며 완료 후 셸로 돌아온다. 백그라운드 Vykdyti_komanda, 파이프, 프로세스 간 통신은 없다. Vykdyti_komanda 파일은 커널의 Skaitymas 전용 JKAP 묶음에서 적재한다. duomenys 파일에는 주기억 파일체계와 전용 IDE 보존 형식이 있다.
- naudotojas 가상 ADDRESS `0x04000000..0x043fffff`를 물리 8~12MiB에 연결한다. Vykdyti_komanda 영상은 priekinis_VALUE 2MiB, 인수는 `0x04300000`부터, 스택은 sritis_VALUE_0e9a97ab 끝에서 시작한다. branduolys_VALUE identity 페이지는 supervisor 전용이다.
- 실행마다 4MiB naudotojas 영역을 비우고 Failas 구역을 복사해 BSS·ARRAY_VALUE 영역을 초기화한다. naudotojas GC는 없지만 Baigti_programa_086bb533 후 toliau_prekė Vykdyti_komanda 때 영역을 재사용한다. 인수는 공백으로 분리한 최대 16개이며 Citavimas/이스케이프 파싱은 없다.
- naudotojas 페이지의 CODE_VALUE/duomenys 분리 Skaitymas 전용 Nustatymai, NX, operandas_eilė guard, ASLR은 아직 없다. 커널과 naudotojas atmintis_duomenys·aparatūra_jungtis teisė_VALUE 경계를 구현한 초기판이지 보안 인증된 샌드박스는 아니다.
- PIT 100Hz로 약 3초 Vykdyti_komanda 상한을 두며 TIME_VALUE 초과는 `Exit: 124`다. naudotojas CPU 예외는 `128 + išimtis INDEX`(페이지 KLAIDA 142, 특권 위반 141), Java ARRAY_VALUE/계산 오류는 101~105다. branduolys_VALUE 오류까지 복구하는 구조는 아니다.
- 네트워크는 PCI bus 0/function 0의 RTL8139, 정적 IPv4, ARP, UDP만 지원한다. NIC는 폴링하고 송신은 동기식이다. IPv4 단편 재조립·TCP·DNS·DHCP·IPv6·HTTP·TLS·일반 `java.net`은 미지원이다. IPv4 UDP kontrolinė_suma 0은 규약에 따라 허용하고, 그 외 UDP/IP 검사합과 길이는 검증한다.
- naudotojas Vykdyti_komanda·네트워크·apsaugoti_VALUE 경계 전체 시험은 QEMU에서 수행했다. VirtualBox에서도 `make vbox`로 부팅과 `run hello vbox`의 ring 3 Vykdyti_komanda·정상 종료를 확인했다. VirtualBox PCnet/E1000용 드라이버는 없어 그 환경의 네트워크는 지원하지 않는다.

## tikrinti 근거

`make test`는 kompiliatorius 14개 시험, Java 패킷 sąlyga 2,201개 검사, 기존 apvalkalas ELF/ISO 부팅 시험, naudotojas ELF/faktinis_duomenys UDP/apsaugoti_VALUE 경계 시험을 실행한다. 네트워크 시험은 루프백 서버가 받은 자료의 길이·해시까지 `os/build/사용자통신시험.json`에 기록한다. 시험용 손상된 ELF·특권 Komanda·무한 sprintas_VALUE 프로그램은 임시 묶음에만 넣으며 배포용 `apps` 목록에는 넣지 않는다.
