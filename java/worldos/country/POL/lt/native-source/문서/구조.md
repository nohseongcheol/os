# JPolOS 구조

아래는 objektas_VALUE 기반 관리 branduolys_VALUE 전체의 tikslas_objektas 구조다. dabartinis_prekė faktinis_duomenys 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 operacinė_sistema 안내](../os/안내.md)에 구현 범위를 명시한다. 아래의 GC·문맥 SWITCH_MODE·failų_sistema 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 sluoksnis_VALUE
  ↓
Java AOT 실행기와 objektas_VALUE·ARRAY_VALUE·GC 런타임
  ↓
aparatūra_VALUE 경계
  ↓
Java 관리 branduolys_VALUE
  ├─ atmintis_sritis/쪽관리/COW
  ├─ Procesas_VALUE/배정/wait
  ├─ failų_sistema/ELF/POSIX
  └─ 입력/saugojimo_įrenginys/tinklas_eilė
```

OpenJDK 자체는 이미 운영체제가 제공하는 Failas, 스레드, 가상 기억공간을 전제로 한다. 따라서 branduolys_VALUE 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, 문맥 저장처럼 Java로 표현할 numeris 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
