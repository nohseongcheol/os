# 전체 pagalba_VALUE 요청의 dabartinis_prekė Būsena_VALUE

užklausa 전체는 아직 완료되지 않았다. dabartinis_prekė ISO는 savas Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 faktinis_duomenys C POSIX 일부 기능, Lietuvių API/ŠALTINIS Pavadinimas_2, IDE Failas 보존, 게스트 Java Failas 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/안내.md)를 기준으로 판단한다.

| užklausa 분야 | dabartinis_prekė Vykdyti_komanda 가능한 klipas | 전체 지원에 필요한 작업 |
|---|---|---|
| Java kompiliuoti_šaltinis·Vykdyti_komanda | 게스트 제한형 javac/JVM, 정적 단일 클래스와 일부 표준 objektas_VALUE | 일반 objektas_VALUE·klasė_VALUE Prisijungti·išimtis·GC·스레드, 완전한 javac와 표준 klasė_VALUE biblioteka |
| Failas | POSIX 서술자, Java 단일 baitas_VALUE Failas Stream_VALUE, 전용 medija_VALUE 보존 | 일반 java.io/nio, 디렉터리·teisė_VALUE·užraktas_VALUE·일반 failų_sistema·plėtinys_VALUE 가능한 pajėgumas_VALUE |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP organizuoti 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, sujungti_įrašas NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 Įvykis·šriftas_VALUE·Langas operacinė_sistema_VALUE, AWT 네이티브 연결과 Swing Vykdyti_komanda 기반 |
| POSIX | 문서화한 Failas·단말·UDP 부분 | Procesas_VALUE·exec/fork·스레드·시그널·TIME_VALUE·mmap·poll·파이프 등과 적합성 tikrinti |
| 언어별 Pavadinimas_2 | Lietuvių 46개 susiejimas_VALUE įrašas_VALUE, faktinis_duomenys C/Java/Failas Pavadinimas_2 적용 | tikslas Kalba vykdymas_VALUE, 언어별 용례·역사 근거와 해당 ŠALTINIS·도구의 tikrinti |

savas 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 Vykdyti_komanda 환경을 추가하는 방식은 별도의 branduolys_VALUE·루트 failų_sistema·OpenJDK·그래픽 serveris_VALUE·영구 Store_VALUE 구성을 가진 Vykdyti_komanda 경로가 된다. 후자는 기존 savas 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

Vykdyti_komanda 기반과 sujungti_įrašas tikslas 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. dabartinis_prekė 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
