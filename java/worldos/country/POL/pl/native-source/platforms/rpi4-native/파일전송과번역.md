# własny ARM64 jądro_WARTOŚĆ: FTP, C, JAR와 AOT Wykonaj_polecenie

대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT jądro_WARTOŚĆ**이다. CPU·urządzenie_WARTOŚĆ 경계는 C/어셈블리, nazwa_pliku 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 host JVM으로 대신 실행하지 않는다.

JVM은 Klasa_WARTOŚĆ 버전 45…52의 문서화한 부분집합이다. `java`는 바이트코드 실행기이고, `jaot`가 별도의 네이티브 Wykonaj_polecenie 파일을 만든다. **JAR Archiwum_WARTOŚĆ 해제나 JVM을 함께 묶는 것을 AOT라고 표시하지 않는다.** 지원하지 않는 바이트코드/API는 `jaot`가 진단하고 출력을 만들지 않는다. 기존 pozycja_wyjścia ELF도 kompilować_źródło awaria_WARTOŚĆ 때 보존한다.

Android의 Dalvik/ART는 일반 JVM Klasa_WARTOŚĆ/JAR가 아닌 **DEX**를 실행한다. ART의 AOT에는 GC, Klasa_WARTOŚĆ 로딩, JNI 등 Wykonaj_polecenie 기반도 필요하다. 따라서 ART처럼 기계어로 바꾸는 기능만으로 임의의 OpenJDK JAR 및 Swing이 자동 호환되지는 않는다. [Android 공식 런타임 설명](https://source.android.com/docs/core/runtime)

명명에서는 표준 영어 API를 보존하고 polski 호출 계층을 추가한다. `komunikacja(通信)`, `Połącz(連結)`, `pozycja_wyjścia(出力)`은 기존 단어의 뜻을 사용한다. `작업 wątek_WARTOŚĆ`은 한 Wykonaj_polecenie 흐름을 가닥에 빗댄 deskryptor_WARTOŚĆ 표현, `port_WARTOŚĆ`는 포트의 접점을 설명하는 표현이다. 새 deskryptor_WARTOŚĆ 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

zewnętrzny_WARTOŚĆ 주소는 cyfra_WARTOŚĆ IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 własny ABI이며 JVM이 제한된 chwileczkę_WARTOŚĆ/재시도를 제공한다. TCP connect 대기는 최대 1초, przestrzeń_użytkownika program_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 Wykonaj_polecenie przestrzeń_użytkownika 서버와 pthread는 아직 없다. FTP는 przestrzeń_użytkownika program_f5044b9b 기한과 별개인 jądro_WARTOŚĆ 서비스다.

게스트의 przestrzeń_użytkownika TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 narzędzia/Wykonaj_polecenie.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 wartość_domyślna kontrola_WARTOŚĆ/데이터 포트와 겹치면 Wykonaj_polecenie 전에 거부한다.
