# ذاتي ARM64 نواة_قيمة: FTP, C, JAR와 AOT ينفذ_أمر

대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT نواة_قيمة**이다. CPU·جهاز_قيمة 경계는 C/어셈블리, ملف 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 مضيف JVM으로 대신 실행하지 않는다.

## 먼저 알아둘 دعم_قيمة 경계

| طلب | 이번 구현 | 남은 يقص |
|---|---|---|
| JAR를 ينفذ_أمر 파일처럼 ينفذ_أمر | `java -jar ملف.jar`, `./ملف.jar وسائط`; Main-Class와 مخزن_قيمة/DEFLATE ZIP, CRC 검사 | 전체 Java SE, 임의의 모든 JAR 호환성 |
| 게스트 AOT | `jaot ملف.class -o ملف.elf`, `jaot ملف.jar -o ملف.elf`; الفعلي_بيانات ARM64 기계어 إنشاء | عنصر_قيمة_2ed200e9·استثناء·Thread·Swing·Socket의 AOT تحويل_قيمة, 여러 애플리케이션 فئة_قيمة_55654bf1 اتصال |
| C يحول_برمجياً_مصدر | 게스트 `cc`/`tcc`, TinyCC C 전처리기·ARM64 생성기·링커; العربية 식별자와 posix-kor | 전체 libc, 일반 Linux ينفذ_أمر ملف, 게스트 C++ محول_برمجي |
| 업로드한 ELF ينفذ_أمر | ELF64/AArch64 헤더 검사, 확장자 없는 `./ملف`; ذاتي ABI 및 명시적인 제한형 Linux ABI | 일반 Linux 바이너리 호환, 동적 링커, 공유 مكتبة |
| خارجي_قيمة TCP/UDP | 게스트 lwIP IPv4 مُعامل_رمز, POSIX 소켓과 JVM의 رقم_قيمة IPv4 عنوان | GENET/Wi-Fi 드라이버, DHCP·DNS·TLS, 실물 لوحة 네트워크 اختبارات |
| FTP | 게스트 서비스, 패시브 نقل_قيمة_630ba093, UTF-8 اسم, STOR/RETR/SIZE/LIST/NLST/MLSD/DELE | TLS·사용자별 إذن_قيمة·하위 디렉터리·영속 مخزن_قيمة |
| 한글 Java | 기존 `العربية.ذاتي` 클래스와 خارجي_قيمة عنوان UDP 오버로드 | 전체 JDK의 일대일 العربية 대응 API |

JVM은 فئة_قيمة_55654bf1 버전 45…52의 문서화한 부분집합이다. `java`는 바이트코드 실행기이고, `jaot`가 별도의 네이티브 ينفذ_أمر 파일을 만든다. **JAR أرشيف_قيمة 해제나 JVM을 함께 묶는 것을 AOT라고 표시하지 않는다.** 지원하지 않는 바이트코드/API는 `jaot`가 진단하고 출력을 만들지 않는다. 기존 مخرجات ELF도 يحول_برمجياً_مصدر فشل_قيمة 때 보존한다.

Android의 Dalvik/ART는 일반 JVM فئة_قيمة_55654bf1/JAR가 아닌 **DEX**를 실행한다. ART의 AOT에는 GC, فئة_قيمة_55654bf1 로딩, JNI 등 ينفذ_أمر 기반도 필요하다. 따라서 ART처럼 기계어로 바꾸는 기능만으로 임의의 OpenJDK JAR 및 Swing이 자동 호환되지는 않는다. [Android 공식 런타임 설명](https://source.android.com/docs/core/runtime)

FTP는 루트 RAM 파일만 공개한다. 익명 로그인이며 비밀번호로 권한을 구분하지 않는다. قيمة_افتراضية مضيف 바인딩은 `127.0.0.1`이고, تحكم_قيمة 포트는 2121, 데이터 포트는 50000…50007이다. `--ftp-port 2122`로 تحكم_قيمة 포트를 바꿀 رقم 있다. 동시에 한 FTP 세션을 제공하며 명령이 없는 세션은 60초 후 닫는다. TYPE A도 바이트를 변경하지 않으므로 프로그램은 바이너리 전송한다.

파일은 **64개, 각각 16 KiB**, 경로는 UTF-8 63바이트이다. إقلاع_الآلة 시 준비되는 `/example`도 이 한도를 공유한다. 초과/끊어진 STOR는 기존 파일에 반영하지 않는다. FTP 업로드는 RAM에만 저장되며 재부팅하면 사라진다. 이 제한 때문에 일반적인 대형 JAR 배포판을 그대로 올릴 رقم 없다.

QEMU의 raspi4b에는 GENET Ethernet 장치가 없다. 따라서 `network_bridge.py`가 QEMU NAT의 Ethernet과 보조 UART의 SLIP를 변환한다. **TCP اتصال عملية_قيمة_إدخال·체크섬·재전송·FTP 명령과 ملف 저장은 게스트 안에서 수행한다.** مضيف 브리지는 FTP 서버가 아니다. [QEMU 공식 جهاز_قيمة دعم_قيمة إدخال_قائمة_f07b3200](https://www.qemu.org/docs/master/system/arm/raspi.html)

이 경로는 QEMU에서 검증했다. 보조 UART의 الفعلي_بيانات Pi 4 핀/클럭 설정과 내장 RJ45 GENET 드라이버는 구현·검증하지 않았으므로, SD 이미지에 커널이 포함되어 있다는 사실을 الفعلي_بيانات 보드의 LAN/FTP إجراء 보장으로 해석하면 안 된다.

## العربية Java를 게스트에서 컴파일하고 AOT ينفذ_أمر

게스트 `vi 빛.java`로 التالي_عنصر 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] وسائط) throws Exception {
        int 합 = 0;
        int رقم = 1;
        while (رقم <= 10) {
            합 = 합 + رقم;
            رقم = رقم + 1;
        }
        العربية.ذاتي.مخرجات.كتابة_رقم(합);
        العربية.ذاتي.ملف.كتابة("aot.txt", "한글 AOT ملف 😀");
        العربية.ذاتي.مخرجات.كتابة_خط(العربية.ذاتي.ملف.قراءة("aot.txt"));
    }
}
```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 إنشاء·연결한다. ينفذ_أمر 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 دعم_قيمة 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 ثابت_قيمة_f430d3f5 أسلوب_قيمة/قيمة_الحقل, int 계열, عدد_صحيح 배열과 مرجع, وسائط صفيف_قيمة, شرط·فرع·تكرار_قيمة, سلسلة_قيمة 리터럴, `System.out.print/println`의 int/String, العربية مخرجات·ملف قراءة/쓰기로 제한된다. فئة_قيمة_55654bf1/أسلوب_قيمة 수와 مُعامل_رمز 등에도 고정 상한이 있다. Java استثناء عملية_قيمة_إدخال, عنصر_قيمة_2ed200e9 إنشاء, 가상 أسلوب_قيمة 일반, switch/wide, long/float/double, invokedynamic, سلسلة_قيمة 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 صفيف_قيمة يصل_إدخال/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java استثناء 객체로 전달하지 않는다.

إدخال_قيمة 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 يحاذي_قيمة 때문에 짧은 클래스도 이 한도를 넘을 رقم 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 عنصر_قيمة_2ed200e9·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 دعم_قيمة يقص 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 개발 매뉴얼](개발안내.md)을 참고한다.

JAR는 하나의 애플리케이션 فئة_قيمة_55654bf1 경로다. 내부 اسم `يُجمع/تطبيق_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 العربية 클래스를 추가로 찾지만 حديث_عنصر 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·تشفير_بيانات ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 رقم/VM كومة_ذاكرة_مؤقتة_قيمة 제한은 그대로 적용된다.

## C에서 العربية POSIX 호출

게스트에서 `vi 인사.c`로 작성하거나 FTP로 소스를 업로드한다.

```c
#include <파일규약.h>

int main(void) {
    const char 인사말[] = "ذاتي ARM64 C에서 한글 POSIX 호출\n";
    int 문서 = فتح_ملف("인사.txt", مقروء_مكتوب | 없으면만들기 | يقتطع_المحتويات, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = كتابة_ملف_بيانات(문서, 인사말, sizeof(인사말) - 1);
    يغلق_ملف(문서);
    كتابة_ملف_بيانات(1, 인사말, sizeof(인사말) - 1);
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

```text
cc 인사.c -o 인사.elf
run 인사.elf
cat 인사.txt
```

TinyCC의 표준 C نقطة_الإدخال `main`을 사용한다. 기존 مضيف C/C++ SDK의 `بدء_مستخدم_تطبيق(int)` 진입점과 구분한다. تصريحات ملف·تشغيل عنصر_قيمة_2ed200e9·`libposix-kor-user.a`는 محول_برمجي 내부의 قراءة 전용 SDK에 들어 있다. C 전처리기/구조체/دالة_قيمة/재귀/مؤشر/부동소수점 إنشاء 등을 사용하되 **일반 libc/libstdc++를 제공한다는 뜻은 아니다**. 제공하지 않는 함수는 اتصال 오류가 난다. محول_برمجي 자체의 문자/رقم_قيمة تحويل_قيمة 지원도 완전한 libc 대체품이 아니다.

`فتح_ملف` 등은 별도의 모의 호출이 아닌 기존 `pk_open` 등의 العربية 매크로이며, ELF의 SVC를 통해 الفعلي_بيانات Java ملف 체계에 도달한다. ملف/مأخذ_التوصيل_قيمة 호출 목록은 [فضاء_المستخدم ABI](사용자호출규약.md)에 있다. C/C++ مضيف SDK ينفذ_أمر 파일도 FTP로 업로드 후 `run` 또는 `./ملف`로 실행하며 확장자는 필요 없다. Linux ARM64 ثابت_قيمة_f430d3f5 ELF에는 별도의 제한된 호환 مسار `run --linux ملف`을 추가했다. [ELF·Linux ABI 매뉴얼](실행파일규약.md)에 정확한 ينسق_قيمة·시스템 호출·عنوان 제한을 정리했다.

## العربية 네트워크·작업·화면 API

| فئة_قيمة_55654bf1 | 호출 예 | ينفذ_أمر مسار |
|---|---|---|
| `مخرجات` | `كتابة_خط("안녕")`, `كتابة_رقم(42)` | JVM 및 제한형 AOT |
| `ملف` | `كتابة("문서.txt", "محتوى_قيمة")`, `قراءة("문서.txt")` | JVM 및 제한형 AOT |
| `통신` | `فتح(0)`, `يرسل(المشارك, "10.0.2.2", 9000, "한글")`, `يستلم(المشارك)` | JVM의 UDP |
| `صديق_نقل` | `اتصال("10.0.2.2", 9000)`, `انصات_المشارك(9000)`, `يستلم(خادم_قيمة)` | JVM의 Socket/ServerSocket |
| `작업` | `تشغيل(Runnable)`, `기다리기(Thread)`, `العائد_مهمة()` | JVM의 협력식 محادثة_قيمة |
| `نافذة`, `عنصر_شاشة` | نافذة·버튼·حرف_قيمة·حقل_نصي·حدث اتصال | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 العربية 호출 계층을 추가한다. `통신(通信)`, `اتصال(連結)`, `مخرجات(出力)`은 기존 단어의 뜻을 사용한다. `작업 محادثة_قيمة`은 한 ينفذ_أمر 흐름을 가닥에 빗댄 기술 표현, `منفذ_قيمة`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

خارجي_قيمة 주소는 رقم_قيمة IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 ذاتي ABI이며 JVM이 제한된 انتظر_قيمة/재시도를 제공한다. TCP connect 대기는 최대 1초, فضاء_المستخدم تطبيق_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 ينفذ_أمر فضاء_المستخدم 서버와 pthread는 아직 없다. FTP는 فضاء_المستخدم تطبيق_f5044b9b 기한과 별개인 نواة_قيمة 서비스다.

게스트의 فضاء_المستخدم TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 أدوات/ينفذ_أمر.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 قيمة_افتراضية تحكم_قيمة/데이터 포트와 겹치면 ينفذ_أمر 전에 거부한다.
