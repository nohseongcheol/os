# ذاتي ARM64 Java 커널의 C/C++ ملف·루프백 اتصال

이 디렉터리는 `platforms/rpi4-native` ذاتي نواة_قيمة 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`تصريحات/파일규약.h`는 العربية 함수명과 `extern "C"` ABI를 제공한다. `اتصال.c`는 نواة_قيمة 안에서 AOT Java ملف 메서드에 직접 연결하고, `مستخدم_جسر.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. الفعلي_بيانات ملف 처리는 `ذاكرة_الملفات.java`, 루프백 رزمةمستقلة 처리는 `استرجاع_شبكة.java`, 연결형 흐름은 `بث_شبكة.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 نواة_قيمة 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·عائم_نقطة_قيمة تشغيل_قيمة·ملف·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

دعم_قيمة: `فتح_ملف`, `يقرأ_ملف_بيانات`, `كتابة_ملف_بيانات`, `يغلق_ملف`, `يبحث_ملف`, `يزيل_ملف_إدخال_اسم`, `파일길이정하기`, 보조 دالة_قيمة `حجم_الملف`. خطأ 시 -1과 작업별 `رقم_الخطأ`를 반환한다. `تثبيت_تخزين_الملفات`은 RAM 파일이므로 ENOSYS를 반환한다. ملف 16개, 각 16384바이트, اسم 63바이트, 서술자 16개이며 RAM 디렉터리·نظير_قيمة/절대 경로를 제공한다. إذن_قيمة/영속 저장은 없다.

사용자용 `تصريحات/통신규약.h`는 الفعلي_بيانات العربية 함수와 독립 구조체를 선언한다.
`فتح_المشارك`, `يربط_عنوان`, `يرسل_مخطط_بيانات_بيانات/يستلم`, `يتصل_شبكة/기다리기/يستلم`는
`مستخدم_جسر.c`에서 SVC를 호출하며 ماكرو_قيمة 별칭이 아니다. `struct سحابة_مأخذ_التوصيل_عنوان`의
`عنوان_عائلة`, `رقم_المنفذ`, `عنوان_الإنترنت.عنوان_قيمة`을 사용한다. 상수는 enum의
`سحابة_عائلة`, `مأخذ_مخطط_البيانات`, `مخطط_بيانات_بروتوكول`, `بث_شبكة`, `بث_بروتوكول_النقل`이다.
العربية·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. خارجي_قيمة 통신은 ذاتي 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. الفعلي_بيانات Pi 4 GENET 드라이버는 미지원이다.
소켓도 الفعلي_بيانات دالة_قيمة `يغلق_ملف`로 닫는다.
