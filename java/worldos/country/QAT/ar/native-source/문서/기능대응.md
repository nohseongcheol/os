## 기존 عنصر_قيمة_2ed200e9 기반 관리 نواة_قيمة 전체를 부팅하기 위해 남은 اتصال

التالي_عنصر 항목은 Java 문법만으로 실행할 رقم 없는 CPU/جهاز_قيمة 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot نقطة_الإدخال_قيمة, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 سياق_قيمة مخزن_قيمة
- الفعلي_بيانات PIC/PIT/PS2/ATA/PCI أجهزة_منفذ 및 AMD PCnet DMA يكرر_قيمة
- Java عنصر_قيمة_2ed200e9·صفيف_قيمة تخطيط_الربط, استثناء, ثابت_قيمة_f430d3f5 تهيئة, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT لوحة_قيمة
- FAT 디스크 구역을 الفعلي_بيانات ATA 장치와 연결하는 إدخال_إخراج 접착 طبقة_قيمة

위 관리 계층은 engos 기능의 Java 관리 구현과 مضيف 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot نقطة_الإدخال_قيمة, ثابت_قيمة_f430d3f5 تهيئة·عدد_صحيح صفيف_قيمة, VGA/직렬/PS2, مفسر_الأوامر, فضاء_المستخدم ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 مضيف 루프백 패킷 왕복을 검증했다. 위 표의 عنصر_قيمة_2ed200e9 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
