# engos 기능 대응표

이 표는 기존 `موروثی_منبع/`의 شئ_مقدار 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [واقعی_داده_ها 부팅 기능과 한계](../os/مرا_بخوان_eb81d7d9.md)를 따로 기록한다.

| process, scheduler, thread | `فرآیند_مقدار`, `زمان_بند` PID·fork·wait·وضعیت_مقدار جابجایی_حالت |
| systemcall/POSIX 1단계 | خواندن·نوشتن·باز_کردن·بستن·seek·dup·fcntl·دسترسی_ورودی·작업목록·کاربر/무리 ID·همگام_سازی·brk·fork·wait·exec·stat·uname 의미 |

## 기존 شئ_مقدار 기반 관리 هسته_مقدار 전체를 부팅하기 위해 남은 اتصال

بعدی_مورد 항목은 Java 문법만으로 실행할 수 없는 CPU/دستگاه_مقدار 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot ورودی_نقطه_مقدار, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 زمینه_مقدار ذخیره_مقدار
- واقعی_داده_ها PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA حلقه_مقدار
- Java شئ_مقدار·آرايه_مقدار پیوند_پیمایش, استثنا, ایستا_مقدار آماده_سازی, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT مرحله_مقدار
- FAT 디스크 구역을 واقعی_داده_ها ATA 장치와 연결하는 ورودی_خروجی 접착 لایه_مقدار

위 관리 계층은 engos 기능의 Java 관리 구현과 میزبان 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot ورودی_نقطه_مقدار, ایستا_مقدار آماده_سازی·عدد_صحیح آرايه_مقدار, VGA/직렬/PS2, 명령해석기, کاربر ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 میزبان 루프백 패킷 왕복을 검증했다. 위 표의 شئ_مقدار 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
