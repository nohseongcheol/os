# Български Java 통신·В_И·изключение API

패키지는 `Български.자체`다. хост `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·Файл·изключение API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 нишка_стойност API는 자체 JVM 전용이다.
기존 표준 Java библиотека 전체의 Български 번역판은 아니다.

```java
import Български.자체.*;

public class мрежа {
    public static void main(String[] Параметри) throws В_И_изключение {
        връзка Свързване = връзка.Отваряне("10.0.2.2", 9000);
        try {
            Свързване.време_на_изчакване(700);
            Свързване.Изход().Писане(문자.кодирам("안녕하세요\n"));
            входен_поток 입력 = Свързване.입력();
            Изход.수쓰기(입력.Четене());
        } catch (почакай_време_на_изчакване_изключение ГРЕШКА) {
            Изход.записване_ред(ГРЕШКА.설명());
        } finally {
            Свързване.Затворен();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
потребител 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 низ_стойност 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void Стартиране()`도 진입점으로 받는다.

## 통신과 поток_стойност

| Клас_стойност | Български 호출 |
|---|---|
| връзка | `Отваряне(адрес, номер_на_порт)`, `입력()`, `Изход()`, `време_на_изчакване(밀리초)`, `номер_на_порт()`, `локален_номер_на_порт()`, `연결됨()`, `닫힘()`, `Затворен()` |
| получавам_порт | `Отваряне(номер_на_порт)`, `получавам()`, `номер_на_порт()`, `време_на_изчакване(밀리초)`, `닫힘()`, `Затворен()` |
| входен_поток | `Четене()`, `Четене(byte[])`, `Четене(byte[], Стартиране, 길이)`, `Затворен()` |
| изходен_поток | `Писане(int)`, `Писане(byte[])`, `Писане(byte[], Стартиране, 길이)`, `내보내기()`, `Затворен()` |
| дейтаграма_Канал | `Отваряне(номер_на_порт)`, `изпращам(адрес, номер_на_порт, Текст)`, `получавам()`, `време_на_изчакване(밀리초)`, `номер_на_порт()`, `닫힘()`, `Затворен()` |
| 연결통신 | `Отваряне(...)`, `수신열기(...)`는 위 Български 객체를 връщам_мярка |
| 검사 | `참인지(условие, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`Четене()`의 Файл 끝은 -1, масив_стойност 읽기의 반환값은 действителен_данни 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. номер_на_порт 0은 빈 번호를 자동 배정한다.
UDP 전문은 в_срок_артикул 자체 커널에서 512바이트까지 받으며, 주소는 цифра_стойност IPv4를 사용한다.
`localhost` 루프백 외의 Име 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.Свързване/чакам_участник/получавам`, `통신.Отваряне/изпращам/получавам`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `връзка`, `получавам_порт`, `дейтаграма_Канал`를 쓴다.

## Български изключение

모든 아래 클래스는 стойност_по_подразбиране 생성자, `새예외("설명")` 형태의 низ_стойност 생성자와
`설명()`을 제공한다. действителен_данни генерирам 문법은 `new почакай_време_на_изчакване_изключение("състояние_на_изчакване 끝")`이다.

| Български изключение | 상위 Клас_стойност / 용도 |
|---|---|
| изключение | `java.lang.Exception`, 직접 던지는 일반 검사 изключение |
| 실행예외 | `java.lang.RuntimeException` |
| В_И_изключение | `java.io.IOException`, Български Файл·통신 API의 검사 изключение |
| почакай_време_на_изчакване_изключение | `В_И_изключение`, 통신 време_на_изчакване 초과 |
| адрес_Търсене_изключение | `В_И_изключение`, адрес проверявам отказ_стойност |
| 파일없음예외 | `В_И_изключение`, Файл Отваряне отказ_стойност |
| 통신예외 | `В_И_изключение`, 표준 SocketException преобразувам_стойност |
| невалиден_аргумент_изключение | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `невалиден_аргумент_изключение` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| 빈참조예외 | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| Състояние_изключение | `java.lang.IllegalStateException` |
| Тип_прехвърлям_изключение | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| масив_хранилище_отказ | `java.lang.ArrayStoreException` |
| нишка_Състояние_изключение | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 почакай_стойност 중단 |

`изключение`와 `실행예외`는 모든 Български 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, Файл·통신 전체를 잡으려면 `catch (В_И_изключение ГРЕШКА)`를 쓴다.
Български API가 표준 В_И 오류를 Български 예외로 변환한다.
기존 Български 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`почакай_време_на_изчакване_изключение`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
изключение 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
в_срок_артикул 자체 JVM에 이 20종을 추가했다. 임의의 потребител Throwable 하위 Клас_стойност 전체를
지원하도록 확장했다는 뜻은 아니다.

## компилирам_източник·изпълнявам_команда

```sh
cd /home/user/jkoros/platforms/rpi4-native
make компилация_система
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 Инструменти/изпълнявам_Файл.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 потребител JVM ELF 안에 탑재된다. `.jar`는 хост javac의
Клас_стойност 경로로 사용한다. източник_дърво 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 Български 예외의 `throws` 선언과 그 import를 인식한다.
자체 JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·обект_стойност·소켓 예제 전체의 източник_дърво 컴파일은 хост javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 수 있다.

действителен_данни TCP/UDP 예제는 [네트워크예제.java](../../../example/java/네트워크예제.java),
изпълнявам_команда 절차는 [example 안내](../../../example/README.md),
източник_дърво 명명 원칙은 [명명 안내](../명명/안내.md)에 있다.

## Swing Прозорец 예제

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` Следваща_артикул `java 창예제`로 연다. Име 입력, 인사하기 버튼,
인사말과 кликвам_стойност 횟수 обновявам, X 닫기를 지원한다.

| 기능 | Български 직접 API |
|---|---|
| Runnable / run | `실행할일.Изпълнение()` |
| ActionListener / actionPerformed | `동작받이.получавам_проект(проект_предупреждение предупреждение)` |

| 공통 화면 елемент_стойност | `화면구성요소.글읽기()`, `записване_Текст(Текст)`, `자리정하기(가로, вертикал_позиция, 폭, 높이)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `Процес_нишка`가 Български Клас_стойност·метод_стойност·서술자를
해석해 화면 요소와 изпълнявам_команда 가닥을 직접 만든다. Операция 알림도 자체 객체이며
콜백으로 `Изпълнение`와 `получавам_проект`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 изпълнявам_команда 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 хост JVM에서 무동작 객체가 생기지 않도록 하는 отхвърлям_стойност_e3ecc00b 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. хост javac로 컴파일한 НАЗАД_стойност 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import Български.자체.*;
public class 가닥예제 implements 실행할일 {
    public void Изпълнение() { Изход.записване_ред("Български 작업 изпълнявам_команда"); }
    public static void Стартиране() throws 대기중단예외 {
        작업가닥 нишка_стойност = 작업.Стартиране(new 가닥예제());
        작업.기다리기(нишка_стойност);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
масив_стойност Параметри 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 Параметри 없는 `Стартиране()`을 우선한다.
기존 Български 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.Стартиране(Runnable)`을 사용하던 코드는 새 Български 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API Поддръжка_стойност 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 Клас_стойност·метод_стойност 이름과 서술자가 남는다.
Български Име 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·метод_стойност 재정의, native Свързване, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS Идентификатор_стойност](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS метод_стойност препратка](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
