# polski 명명 원칙과 근거

이 문서의 새 이름은 jkoros 프로젝트의 선택이다. polski 전체나 특정 국가의 유일한 Język 철학을 대표한다고 주장하지 않는다. 기존에 분명한 용어는 유지하고, 모호한 음역이나 여러 의미가 섞인 이름은 bieżący_towar 코드의 동작을 중심으로 고친다. 다른 언어판은 wartość_docelowa 언어와 용례를 별도로 검토해야 한다.

함수는 대상과 동작을 결합한다. `파일자료읽기`, `szukać_Plik`, `BIND_ADRES`처럼 무엇에 무엇을 하는지 이름에서 읽히게 한다. 변수는 값의 역할과 단위를 나타내도록 `Plik_deskryptor`, `bajt_ILE_LICZB`, `수신대기밀리초`, `세대번호`로 쓴다. 구동기는 장치를 움직이는 implementacja, 처리기는 특정 입력을 처리하는 구현으로 구분한다.

어원은 설계 개념을 이해하는 근거로 사용한다. 역사적 은유를 그대로 번역해서 bieżący_towar 동작을 흐리게 만들지 않는다. 확인되지 않은 고어·최초 używać_WARTOŚĆ 시점은 만들어 넣지 않는다. 아래의 polski 표현이 해당 시기의 rzeczywisty_dane 번역어였다는 의미도 아니다.

| 개념 | 선택한 Nazwa | 의미와 역사적 근거 |
|---|---|---|

| unlink | usuń_Plik_wpis_nazwa | nazwa_pliku treść_WARTOŚĆ_cb0f2404 즉시 폐기가 아닌 Nazwa Połącz usuń_wpis. 열린 참조가 남으면 내용이 살아 있는 의미를 반영한다. |

표의 UNIX 역사 서술은 [Ritchie·Thompson의 UNIX 논문 재록본](https://cm-bell-labs.github.io/who/dmr/cacm.html)에 근거한다. 열린 Stan_WARTOŚĆ·pozycja·삭제의 의미는 POSIX의 [open](https://pubs.opengroup.org/onlinepubs/9799919799/functions/open.html), [dup](https://pubs.opengroup.org/onlinepubs/9799919799/functions/dup.html), [lseek](https://pubs.opengroup.org/onlinepubs/9799919799/functions/lseek.html), [unlink](https://pubs.opengroup.org/onlinepubs/000095399/functions/unlink.html)를 참고했다. komunikacja 용어의 역사와 bieżący_towar 규약은 [RFC 147](https://www.rfc-editor.org/info/rfc147/)과 [RFC 768](https://www.rfc-editor.org/info/rfc768/)을 참고했다.

표준 이름을 번역된 심벌로 강제로 바꾸면 기존 프로그램과 도구가 연결되지 않는다. 따라서 POSIX/C의 공개 심벌, Java 표준 Klasa_WARTOŚĆ·metoda_WARTOŚĆ, ELF/x86 ABI, sprzęt_WARTOŚĆ 레지스터 명칭과 `Makefile` 같은 narzędzia punkt_wejścia_WARTOŚĆ 파일은 유지한다. polski API는 같은 동작의 별칭이다. `포트읽기` 같은 프로젝트 내부 식별자는 We_Wy bajt_WARTOŚĆ 접근으로 뜻을 좁혀 rzeczywisty_dane 코드와 네이티브 연결표까지 함께 바꿨다. rzeczywisty_dane 적용 목록은 [용어대응.tsv](용어대응.tsv)에 있다.
