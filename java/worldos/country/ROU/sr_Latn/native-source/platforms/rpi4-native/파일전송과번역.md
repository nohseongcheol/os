대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT jezgro_VALUE**이다. CPU·uređaj_VALUE 경계는 C/어셈블리, Datoteka 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 host JVM으로 대신 실행하지 않는다.

## 한국어 Java를 게스트에서 컴파일하고 AOT Izvrši_komanda

게스트 `vi 빛.java`로 Dalje_stavka 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] 인수) throws Exception {
        int SUM_VALUE = 0;
        int 수 = 1;
        while (수 <= 10) {
            SUM_VALUE = SUM_VALUE + 수;
            수 = 수 + 1;
        }
        한국어.자체.출력.수쓰기(SUM_VALUE);
        한국어.자체.Datoteka.쓰기("aot.txt", "한글 AOT Datoteka 😀");
        한국어.자체.출력.줄쓰기(한국어.자체.Datoteka.읽기("aot.txt"));
    }
}
```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 generisati·연결한다. Izvrši_komanda 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 Podrška_VALUE 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 정적 metod_VALUE/vrednost_polja, int 계열, ceo_broj 배열과 referenca, 인수 niz_VALUE, stanje·grana·sprint_VALUE, niska_VALUE 리터럴, `System.out.print/println`의 int/String, 한국어 출력·Datoteka 읽기/쓰기로 제한된다. Razred_VALUE/metod_VALUE 수와 operand_stek 등에도 고정 상한이 있다. Java izuzetak Proces_VALUE_stavka, objekat_VALUE generisati, 가상 metod_VALUE 일반, switch/wide, long/float/double, invokedynamic, niska_VALUE 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 niz_VALUE pristup_stavka/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java izuzetak 객체로 전달하지 않는다.

입력 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 poravnati_VALUE 때문에 짧은 클래스도 이 한도를 넘을 수 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 objekat_VALUE·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 Podrška_VALUE klip 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 개발 매뉴얼](개발안내.md)을 참고한다.

JAR는 하나의 애플리케이션 Razred_VALUE 경로다. 내부 ime `komplet/program_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 한국어 클래스를 추가로 찾지만 aktuelno_stavka 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·šifrovati_podaci ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 수/VM 힙 제한은 그대로 적용된다.

## 한국어 네트워크·작업·화면 API

| Razred_VALUE | 호출 예 | Izvrši_komanda putanja |
|---|---|---|
| `출력` | `줄쓰기("안녕")`, `수쓰기(42)` | JVM 및 제한형 AOT |
| `Datoteka` | `쓰기("문서.txt", "Sadržaj_VALUE")`, `읽기("문서.txt")` | JVM 및 제한형 AOT |
| `통신` | `otvoren(0)`, `poslati(učesnik, "10.0.2.2", 9000, "한글")`, `primiti(učesnik)` | JVM의 UDP |
| `연결통신` | `veze("10.0.2.2", 9000)`, `slušati_učesnik(9000)`, `primiti(server_VALUE)` | JVM의 Socket/ServerSocket |
| `작업` | `koristiti(Runnable)`, `기다리기(Thread)`, `YIELD_obaveza()` | JVM의 협력식 nit_VALUE |
| `prozor`, `vidžet` | prozor·버튼·znak_VALUE·tekstualno_polje·događaj veze | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 한국어 호출 계층을 추가한다. `통신(通信)`, `veze(連結)`, `출력(出力)`은 기존 단어의 뜻을 사용한다. `작업 nit_VALUE`은 한 Izvrši_komanda 흐름을 가닥에 빗댄 기술 표현, `port_VALUE`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

spoljni_VALUE 주소는 cifra_VALUE IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 자체 ABI이며 JVM이 제한된 čekaj_VALUE/재시도를 제공한다. TCP connect 대기는 최대 1초, korisnik program_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 Izvrši_komanda korisnik 서버와 pthread는 아직 없다. FTP는 korisnik program_f5044b9b 기한과 별개인 jezgro_VALUE 서비스다.

게스트의 korisnik TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 Alatke/Izvrši_komanda.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 podrazumevana_vrednost kontrola_VALUE/데이터 포트와 겹치면 Izvrši_komanda 전에 거부한다.
