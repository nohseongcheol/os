# Java 네이티브 işletim_sistemi

이 문서는 기존 **x86 çekirdek_değer**을 설명한다. Raspberry Pi 4의 Öz ARM64 başlangıç_durumu 이식은 [별도 안내](../platforms/rpi4-native/README.md)를 참고한다. 아래 x86 kullanıcı_alanı ELF·네트워크·IDE depo_değer 기능이 ARM64에 모두 이식된 상태는 아니다.

Java 원문을 Öz AOT 후단으로 x86 기계어로 컴파일해 부팅하는 작은 운영체제다. 커널과 별도로 Öz 제한형 Java derleyici·JVM ELF를 kullanıcı_alanı 모드에 적재할 수 있다. Linux, engos, koros4와 dış_değer OpenJDK는 게스트에 적재하지 않는다. makine_başlatma 진입과 donanım_taşımak/물리 Bellek_bölge 접근은 어셈블리이며, 문자 단말·artış_değer işlem_değer_girdi·komut ayrıştırmak_değer·작업 bölüm_değer_366e0bfa 관리는 `kaynakKod/*.java`에 있다.

## 게스트 Java 개발

`javac Hello.java`, `java Hello`로 부팅된 işletim_sistemi 안에서 derlemek_kaynak·실행한다. `edit FILE.java`와 `.save`로 소스를 작성하며 `ls`, `cat`, `rm`을 제공한다. RAM 파일은 최대 8개, 각각 16KiB이다. 전용 IDE 매체를 연결하면 `sync`로 보존할 수 있다. 이 기능은 Öz 제한형 구현이며 전체 OpenJDK/JDK 호환은 아니다. 사용법·Destek_değer 문법·dosya 적재·교차 시험은 [Java 개발 ortam](../문서/Java_IDE.md)에 있다. `make test-java`로 검증한다.

## 빌드와 yürütmek_komut

`compiler/`가 요구하는 도구에 더해 ISO 생성에는 `grub-file`, `grub-mkrescue`, GRUB BIOS modül_değer, `xorriso`가 필요하다. 실행에는 QEMU 또는 VirtualBox가 필요하다. geçerli_öğe 설치된 도구만 사용한다. `make run-store`는 새 전용 가상 depo_değer 매체를 만들어 연결한다. VirtualBox 실행기는 이 프로젝트가 만든 전용 VM만 설정하고 다른 VM은 변경하지 않는다. 가상 메모리는 varsayılan_değer 64MiB이며 최소 16MiB가 필요하다.

```sh
cd /home/user/jkoros/os
make                 # build/kernel.elf
make iso             # build/kernel.iso (kullanıcı_alanı ELF Grup_değer bildirimler)
make run             # ELF 직접 makine_başlatma, 직렬 단말
make run-gui         # GRUB ISO makine_başlatma, VGA 창과 PS/2 자판
make vbox            # 상위 폴더의 실행기로 전용 VirtualBox VM yürütmek_komut
make vbox-status     # 전용 VirtualBox VM Durum_değer doğrulamak
make test            # ELF와 ISO 두 경로의 fiili_veri makine_başlatma/artış_değer sınamalar
make apps            # kullanıcı_alanı 프로그램만 oluştur
make test-network    # kullanıcı_alanı yürütmek_komut/UDP/korumak_değer sınamalar
```

`make run`은 QEMU의 직렬 표준 입출력을 쓴다. `Ctrl+A`를 누른 BACK_değer `X`로 QEMU를 종료할 수 있다. `halt`는 게스트 CPU만 정지시키므로 QEMU Pencere/프로세스는 별도로 닫는다. 폴링 방식이라 bekle_değer 중에도 konak CPU를 사용할 수 있다.

VirtualBox는 `make vbox`로 실행한다. 새 전용 VM을 Bellek_veri 64MiB, BIOS, 광학 드라이브 부팅으로 자동 설정하며 디스크는 필요 없다. fiili_veri VirtualBox 5.2.42에서 makine_başlatma, Java Öz sınamalar, kabuk artış_değer, `run hello vbox`의 ring 3 실행과 bilgi_teknolojisi_normal 종료를 확인했다. geçerli_öğe iletişim 드라이버는 QEMU의 RTL8139 전용이며 VirtualBox의 PCnet/E1000에서는 네트워크를 사용할 수 없어 네트워크 장치를 비활성화한다. depo_değer Durum_değer 재개와 새 oluştur 반영 방법은 [VirtualBox yürütmek_komut 안내](../문서/가상상자실행.md)에 있다.

## 셸에서 kullanıcı_alanı program_f5044b9b yürütmek_komut 및 네트워크 호출

독립 ELF32 yürütmek_komut 파일을 적재해 **ring 3**에서 실행한다. `int 0x80` 시스템 호출을 통해 단말 metinÇıktısı, bağımsız_değişkenler sorgu_değer, UDP Aç·göndermek·almak·닫기를 제공한다. kullanıcı_alanı 코드를 çekirdek_değer 함수로 직접 호출하는 구조가 아니다.

```text
jkoros> apps
jkoros> run hello first second
jkoros> net
jkoros> run netcheck
jkoros> run udp 10.0.2.2 9000 hello
```

마지막 명령의 응답을 받으려면 호스트의 별도 터미널에서 `python3 /home/user/jkoros/os/araçlar/yankı_veri.py --port 9000`을 먼저 실행한다. 상세 API, program_f5044b9b Ekleme_girdi, ADRES 공간과 제한은 [kullanıcı_alanı yürütmek_komut·네트워크 안내](kullanıcı_alanı/안내.md)에 있다.

makine_başlatma doğrulamak 문구:

```text
JKOROS NATIVE JAVA
자바 기계어 çekirdek_değer çalıştır
JAVA SELFTEST PASS
USER ELF: ring 3 / paging / int 0x80
help | info | mem | alloc | free N | echo TEXT | clear | test | halt
apps | run NAME [ARGS] | net
READY
jkoros>
```

## 구현한 기능

- GRUB Multiboot 1 ELF makine_başlatma, x86 korumak_değer mod_değer GDT, BSS başlat, 64KiB işlenen_Yığın.
- Java işlev_değer fiili_veri 실행과 makine_başlatma msinfo32_exe işaret_değer doğrulamak.
- COM1 직렬 G_Ç, VGA 문자 화면·imleç_değer·스크롤·silmek_girdi.
- PS/2 varsayılan_değer 자판, 좌우 Shift, Enter, Backspace. uzantı_değer tuş_değer/마우스 자료는 komut 입력으로 쓰지 않는다.
- süre_değer 128의 komut artış_değer 버퍼, Taşma_değer 방지, CR/LF işlem_değer_girdi.
- `help`, `info`, `mem`, `alloc`, `free N`, `echo TEXT`, `clear`, `test`, `halt`.
- 4KiB 작업 bölüm_değer_366e0bfa 8개의 ayırmak_Depolama·İade_KR·재사용과 중복 İade_KR 방지.
- Java DİZİ_değer 256KiB 영역의 Boyut·alt_simge_değer 검사와 런타임 hata 중단.
- Okuma 전용 JKAP yürütmek_komut Grup_değer, ELF32 bölüm_değer_366e0bfa/giriş_noktası doğrulamak_5fb2b747, kullanıcı_alanı mod_değer·bağımsız_değişkenler·Çıkış_program KOD_değer.
- çekirdek_değer/kullanıcı_alanı 페이지 izin_değer 분리, TSS, IDT, PIT 100Hz, kullanıcı_alanı CPU özel_durum işlem_değer_girdi 및 yürütmek_komut zaman_değeri 상한.
- PCI RTL8139 폴링 드라이버, ARP, statik_değer IPv4, UDP sağlama_toplamı·송수신·bekle_değer 제한.

`mem`의 Upper memory는 Multiboot의 1MiB 위쪽 연속 Bellek_veri Boyut(KiB)이며, 전체 Bellek_veri 지도 분석이나 자유 물리 Bellek_veri 수치가 아니다. `alloc`은 이미 확보한 bilgi DİZİ_değer 안의 작업 bölüm_değer_366e0bfa 번호를 반환한다. 일반 물리 sayfa_değer ayırmak_Depolama, ADRES ADRES_bölge 또는 kullanıcı_alanı işlem_değer Bellek_veri 관리가 아니다.

## 명시적인 한계

이 커널은 **kullanıcı_alanı 프로그램을 한 번에 하나 실행하는 başlangıç_durumu çekirdek_değer**이다. PIT IRQ0만 사용하며 키보드와 NIC는 폴링한다. kullanıcı_alanı CPU 예외는 해당 프로그램을 끝내고 셸로 복귀시키지만 çekirdek_değer 예외는 중단한다. yürütmek_komut 시간은 약 3초로 제한한다. 완전한 선점 다중 işlem_değer 스케줄러, FAT/ext 등 일반 디스크 dosya_sistemi, TCP·DNS·DHCP·IPv6·HTTP, 전체 POSIX, 일반 nesne_değer 모델/GC는 아직 없다. 전용 IDE dosya 보존과 POSIX dosya/UDP 일부 기능은 구현했다. JVM은 RAM 파일의 단일 클래스를 yürütmek_komut 시 적재하며 일반 ClassLoader나 JAR 로딩은 지원하지 않는다. 네이티브 yürütmek_komut 파일은 oluştur 시 Okuma 전용 묶음에 넣으며, 일반 Linux ELF를 실행하는 환경이 아니다. 기존 `../eski_kaynak/`의 JVM 관리 çekirdek_değer 전체를 이식한 것도 아니다.

Java 식별자는 한국어다. 직렬 출력은 이 프로젝트의 한글(BMP 문자)을 UTF-8로 표시한다. VGA는 varsayılan_değer ASCII 글꼴만 사용하므로 한글 자리에 `?`가 나온다. komut 입력도 geçerli_öğe ASCII만 지원하며 한글 yazı_tipi_değer·입력기 및 보조 평면 문자 출력은 후속 작업이다. `test`는 작은 배열을 새로 할당하고 GC가 없으므로 무한 반복하지 않는다.

## 자동 sınamalar

`sınamalar/부팅시험.py`는 디스크 없는 독립 QEMU를 생성해 다음을 검증하고 종료한다.

- ELF 직접 makine_başlatma 및 GRUB ISO makine_başlatma.
- Java Öz 시험과 UTF-8 직렬 문구.
- komut yardım_göster·msinfo32_exe·Bellek_veri·metinÇıktısı·hata artış_değer·화면 silmek_girdi.
- 작업 bölüm_değer_366e0bfa 8개 ayırmak_Depolama, 부족 işlem_değer_girdi, İade_KR/중복 İade_KR/재할당.
- 직렬 줄바꿈·백스페이스·긴 artış_değer işlem_değer_girdi.
- QEMU PS/2 tuş_değer 입력으로 `info` yürütmek_komut, `halt` 정지.

성공 로그는 `build/부팅시험.json`에 남는다. 로컬 Unix 소켓을 금지하는 샌드박스에서는 sınamalar 도구에 해당 권한이 필요하다. sınamalar 도중 새로 만든 QEMU만 종료하며 기존 VM과 fiili_veri 디스크는 건드리지 않는다.

`sınamalar/test_kullanıcı_ağ.py`는 ELF/ISO 각각에서 kullanıcı_alanı ELF, fiili_veri ring 3, bağımsız_değişkenler, konak 루프백 UDP 왕복, 1,023/1,024바이트 24회 연속 왕복, zaman_değeri 초과, NIC 없음, Bellek_veri/donanım_taşımak erişim_girdi 차단, CPU özel_durum, 무한 öğe_değer_58902391, 잘못된 ELF를 시험한다. `build/test_kullanıcı_ağ.json`에 게스트 기록과 호스트가 받은 데이터의 süre_değer·해시를 저장한다. `sınamalar/paket_test.py`는 fiili_veri Java sözleşme_değeri 처리기에 손상된 패킷을 넣어 2,201개 sınır_değer/sağlama_toplamı 조건을 검사한다. konak 루프백 외 dış_değer 서버에는 sınamalar 트래픽을 보내지 않는다.

부트 경계는 GNU의 [Multiboot 명세](https://www.gnu.org/software/grub/manual/multiboot/multiboot.html)를 따른다.

새 Dosya_tanımlayıcı·C ABI·IDE depo_değer·Java dosya 흐름의 범위와 Türkçe 명명 대응은 [posix-kor 안내](../posix-kor/안내.md)에 있다. `make test-posix`로 ELF/ISO 실행과 재부팅 보존을 검증한다.
