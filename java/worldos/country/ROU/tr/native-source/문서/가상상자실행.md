# VirtualBox yürütmek_komut

```sh
cd ~/jkoros
make vbox
```

별도로 VM을 만들거나 ISO를 연결할 필요가 없다. 처음 실행하면 `os/build/kernel.iso`를 빌드하고 `jkoros operating system`이라는 전용 VM을 만들어 VirtualBox 창으로 부팅한다. `jkoros/os` 안에서도 `make vbox`를 사용할 수 있다.

게스트의 `jkoros>` 프롬프트에서 Sonraki_öğe 명령을 입력한다.

```text
help
apps
run hello vbox
```

마지막 명령은 별도 Java ELF를 실행한다. `USER MODE ring 3`, `arg: vbox`, `Exit: 0` metinÇıktısı 후 셸로 돌아오면 정상이다. VGA 화면은 geçerli_öğe ASCII 글꼴만 지원하므로 한글은 `?`로 보이며, 한글 원문은 직렬 기록에서 확인할 수 있다.

## Durum_değer 확인과 yeniden_denemek_değer yürütmek_komut

```sh
make vbox-status
```

이 명령은 VM Durum_değer, ISO와 직렬 기록의 절대 경로를 JSON으로 출력한다.

| geçerli_öğe Durum_değer | `make vbox` Eylem |
| --- | --- |
| 아직 생성하지 않음 | ISO oluştur → 전용 VM oluşturmak → makine_başlatma |
| 종료됨 (`poweroff`, `aborted`) | ISO oluştur → 광학 Medya_değer yenilemek → 새로 makine_başlatma |
| yürütmek_komut 중 (`running`) | 재빌드·재부팅 없이 geçerli_öğe VM 유지 |
| 일시정지 (`paused`) | 기존 VM özgeçmiş_yürütme |
| 저장됨 (`saved`) | Önceki_öğe 직렬 기록을 복사해 보관하고 depo_değer Durum_değer özgeçmiş_yürütme |
| depo_değer·çalıştır 등 geçiş_mod 중 | 변경하지 않고 작업 완료 후 재실행하도록 안내 |

kaynak_ağaç 변경을 반영하려면 VM을 종료한 Sonraki_öğe yeniden_denemek_değer `make vbox`를 실행한다. **depo_değer 상태를 재개하면 Önceki_öğe 커널이 계속 실행되므로 새 빌드를 반영하지 않는다.** 실행기는 강제 종료하거나 depo_değer 상태를 폐기하지 않는다. VirtualBox 창을 닫을 때 사용자가 전원 끄기를 선택하면 Bellek_veri 상태가 사라지므로 보존할 작업이 없는지 먼저 확인한다. 게스트의 `halt`는 CPU만 멈추며 VirtualBox의 전원을 끄는 명령은 아니다.

Pencere 없는 실행이 필요하면 VM이 꺼져 있을 때 사용한다.

```sh
make vbox VBOX_TYPE=headless
```

yürütmek_komut 중인 VM에 yeniden_denemek_değer 명령을 내려도 GUI/headless 방식은 바뀌지 않는다. varsayılan_değer İsim 대신 다른 이름이 필요하면 **최초 oluşturmak 시에만** `VBOX_NAME="원하는 İsim"`을 지정하고 이후에도 같은 값을 사용한다.

## 설정과 veri 보존

- varsayılan_değer 설정은 BIOS, Bellek_veri 64MiB, CPU 1개, VGA Bellek_veri 16MiB, IDE 광학 부팅이다. 가상 하드디스크를 만들지 않는다.
- VM 설정은 `.vbox/machines/`, içerik_değer 검사합별 ISO 사본은 `.vbox/media/`, 직렬 기록은 `.vbox/logs/`에 보관한다. `.vbox/state.json`은 전용 VM의 UUID와 sahip_değer 표식을 저장한다.
- 꺼진 VM을 부팅할 때 새 직렬 기록을 만든다. depo_değer Durum_değer özgeçmiş_yürütme 전의 기록은 `before-resume-*.log`로 복사한다. depo_değer Durum_değer 자체는 삭제하지 않고 VirtualBox가 그대로 재개한다.
- 같은 이름의 다른 VM을 인수하지 않는다. UUID·Ayarlar yol·sahip_değer 표식을 검사하며, 사용자가 별도로 연결한 디스크나 광학 매체를 자동 교체하지 않는다.
- 기존 ISO 사본과 기록은 자동 삭제하지 않는다. `.vbox`는 Git 제외 대상이다. 용량을 정리할 때도 yürütmek_komut·depo_değer 상태의 VM이 참조하는 파일과 관리 정보를 임의로 삭제하지 않는다.
- VirtualBox 또는 konak 드라이버가 없으면 오류를 안내한다. 자동 yükle_değer, yönetici_değer izin_değer yürütmek_komut, cihaz_değer izin_değer 변경은 하지 않는다.

## 네트워크 제한

geçerli_öğe 커널의 RTL8139 드라이버는 QEMU에서 사용한다. VirtualBox의 PCnet/E1000 드라이버는 아직 구현하지 않아 이 실행기는 네트워크 장치를 비활성화한다. 셸과 kullanıcı_alanı 프로그램은 실행되지만 UDP 열기는 `-19`로 실패한다. UDP 왕복은 `make run`과 [kullanıcı_alanı yürütmek_komut·네트워크 안내](../os/kullanıcı_alanı/안내.md)의 절차로 시험한다.
