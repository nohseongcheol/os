# JRusOS 구조

아래는 objekti_ARVO 기반 관리 ydin_ARVO 전체의 kohde_objekti 구조다. nykyinen_kohde todellinen_data koneen_käynnistys 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 käyttöjärjestelmä Lueminut_eb81d7d9](../os/Lueminut_eb81d7d9.md)에 toteutus 범위를 명시한다. 아래의 GC·konteksti_ARVO MUUTA_tila·tiedostojärjestelmä 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 kerros_ARVO_e65604ef
  ↓
Java AOT 실행기와 objekti_ARVO·MATRIISI_ARVO·GC 런타임
  ↓
laitteisto_ARVO rajattu_alue_ARVO
  ↓
Java 관리 ydin_ARVO
  ├─ Muisti_alue/쪽관리/COW
  ├─ prosessi_ARVO/배정/wait
  ├─ tiedostojärjestelmä/ELF/POSIX
  └─ syöte_ARVO/tallennuslaite/verkko_Pino
```

OpenJDK 자체는 이미 운영체제가 제공하는 tiedoston_nimi, 스레드, 가상 기억공간을 전제로 한다. 따라서 ydin_ARVO 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, konteksti_ARVO 저장처럼 Java로 표현할 numero 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
