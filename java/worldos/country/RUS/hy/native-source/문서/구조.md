# JRusOS 구조

아래는 առարկա_արժեք 기반 관리 միջուկ_արժեք 전체의 թիրախ_առարկա 구조다. 현재 իրական_տվյալ 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 գործավար_համակարգ ԿԱՐԴԱ_ԻՆՁ_eb81d7d9](../os/ԿԱՐԴԱ_ԻՆՁ_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·Համատեքստ_արժեք փոխարկել_կերպ·նիշքային_համակարգ 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 շերտ_արժեք
  ↓
Java AOT 실행기와 առարկա_արժեք·ԶԱՆԳՎԱԾ_արժեք·GC 런타임
  ↓
하드웨어 경계
  ↓
Java 관리 միջուկ_արժեք
  ├─ 기억공간/쪽관리/COW
  ├─ Ընթացք_արժեք/배정/wait
  ├─ նիշքային_համակարգ/ELF/POSIX
  └─ 입력/Պահեստ_սարք/Ցանց_Շեղջ
```

OpenJDK 자체는 이미 운영체제가 제공하는 Ֆայլ, 스레드, 가상 기억공간을 전제로 한다. 따라서 միջուկ_արժեք 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, Համատեքստ_արժեք 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
