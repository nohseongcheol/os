# 자체 커널에서 vi·여러 Терминал·한글 프로그래밍 사용하기

Татарча 통신·예외 사용법은 [Татарча Java API](한국어자바/Белешмә_файлы_eb81d7d9.md), ФУНКЦИЯ_VALUE·변수·Birem 이름의 변경과 어원 근거는 [명명 Белешмә_файлы_eb81d7d9](명명/Белешмә_файлы_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 자체 AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 ярдәм_VALUE 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 үтәргә_команда, 외부 TCP/UDP와 FTP는 [새 үтәргә_команда 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 Терминал

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, адрес **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 Терминал 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **RIGHT 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 үтәргә_команда 버튼으로 다시 COLUMN_VALUE 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 현재 디렉터리, тышча 변수, команда LOG_юл, 입력 중인 명령과 кушымта_f5044b9b үтәргә_команда 상태를 보관한다. Birem 저장소는 공유한다. vi와 Swing의 이벤트 대기 중에 다른 터미널로 전환하면 кулланучы Хәтер_мәгълүмат·레지스터·Birem/소켓 연결을 보존했다가 돌아올 때 재개한다. **현재 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 Киләсе_элемент 입력 대기 또는 기존 үтәргә_команда 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 үтәргә_команда 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 төзәтү_VALUE 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. 현재 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 тәрәз 판단은 게스트 커널이 처리한다. QEMU үтәргә_команда 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. фактик_мәгълүмат Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI Кораллар 종료는 хост 터미널의 Ctrl+C다.

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. 출력 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.класс_VALUE.class` 형식이다. 내장 Татарча 라이브러리는 별도 업로드가 필요 없다. Татарча тәрәз API의 예제는 [한글창시험.java](시험/자바/한글창시험.java)이며 같은 방법으로 төзү_чыганак·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 чыганак_агач/클래스는 호스트의 `python3 Кораллар/үтәргә_файл.py Yul/인사.java`로 별도 QEMU에 업로드·үтәргә_команда·종료할 수 있다. интерактив Swing에는 үтәргә_команда 후 кулланучы 입력을 유지하는 `make desktop`을 사용한다.

- `Татарча.자체.виджет`: `тәг_VALUE`, `төймә`, `текст_кыры` булдыру.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **төш_VALUE 내부 연결형 байт_VALUE агым_VALUE**을 추가했다. Birem/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket сервер_VALUE = new java.net.ServerSocket(9250);
java.net.Socket кунак_VALUE = new java.net.Socket("localhost", 9250);
java.net.Socket ялгау = сервер_VALUE.accept();
кунак_VALUE.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] RECEIVED_элемент = new byte[64];
int озынлык_VALUE = ялгау.getInputStream().read(RECEIVED_элемент);
ялгау.close(); кунак_VALUE.close(); сервер_VALUE.close();
```

булдыру·ялгау·accept·양방향 байт_VALUE/МАССИВ_VALUE К_Ч·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 тәмамлау_балл 16개, 수신 버퍼당 1024바이트, 대기 ялгау 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. килешенгәнчә_кыйммәт TIME_VALUE 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM команда 수/төш_VALUE үтәргә_команда 기한은 여전히 적용된다.

외부 сан_VALUE IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. фактик_мәгълүмат Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP библиотека 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 фактик_мәгълүмат 송수신·EOF·기한·ялгау 회수의 시험 예제다.

Store_VALUE 후 `python 인사.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 ФУНКЦИЯ_VALUE·변수·Birem 이름과 문자열을 한글로 쓴다.

출력·Birem 읽기/язу/삭제·표준 입력·사각형·TIME_VALUE·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 сан_VALUE IPv4 адрес 전송이다. `wait_key()`는 화면을 확인할 때 интерактив 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor статик_VALUE 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 өстәмә_VALUE 모듈은 아직 없다. 제한형 `pip`의 чыганак_агач 설치는 [Python пакет Белешмә_файлы_eb81d7d9](PYTHON_пакет.md)를 따른다. [세 언어의 фактик_мәгълүмат 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 тел 모두 Татарча 헤더와 ФУНКЦИЯ_VALUE 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 фактик_мәгълүмат EL0 үтәргә_команда 시험 대상이다.

```c

#ifdef __cplusplus
extern "C"
#endif
int Start_кулланучы_кушымта(int 인수) {
    (void)인수;
    const char 인사말[] = "안녕하세요\n";
    int 문서 = ачу_файл("인사.txt", укымалы_язмалы | 없으면만들기 | 내용비우기, 0600);
```

`통신규약.h`의 자체 `pk_sockaddr_in`을 사용하며 порт_VALUE·주소는 `망차례짧은수`/`Челтәр_бөтен_сан`로 변환한다. C 소켓 호출은 비차단이며 мәгълүмат/연결이 없으면 -1과 `오류번호=11`(EAGAIN)을 반환한다. 양수 К_Ч 결과가 요청보다 작을 수 있으므로 итерация_VALUE 처리한다. эштән_туктау_VALUE 후에만 오류번호를 확인한다.

[агым_VALUE.c](예제/한글코딩/агым_VALUE.c)는 C에서 Татарча 이름으로 ялгау·accept·부분 읽기/язу·큐 포화·EOF를 처리하는 үтәргә_команда 예제다. SDK의 `examples/агым_VALUE.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → фактик_мәгълүмат Татарча C ФУНКЦИЯ_VALUE 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·күрсәткеч 검사 → Java RAM Birem/루프백 또는 외부 lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 төш_VALUE 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 ялгау, 표준 C printf, libstdc++/STL, 예외·RTTI는 제공하지 않으며 C++의 статик_VALUE 생성자·локаль_даирә объект_VALUE 소멸자는 지원한다. 상세 INDEX·Хәтер_мәгълүмат 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.
