# 전체 ярдәм_VALUE 요청의 현재 халәт_VALUE

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 фактик_мәгълүмат C POSIX 일부 기능, Татарча API/чыганак исем, IDE Birem 보존, 게스트 Java Birem 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/Белешмә_файлы_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 үтәргә_команда 가능한 клип | 전체 지원에 필요한 작업 |
|---|---|---|
| Java төзү_чыганак·үтәргә_команда | 게스트 제한형 javac/JVM, статик_VALUE 단일 클래스와 일부 표준 объект_VALUE | 일반 объект_VALUE·класс_VALUE ялгау·예외·GC·스레드, 완전한 javac와 표준 класс_VALUE библиотека |
| Birem | POSIX 서술자, Java 단일 байт_VALUE Birem агым_VALUE, 전용 туплагыч_VALUE 보존 | 일반 java.io/nio, 디렉터리·рөхсәт_VALUE·잠금·일반 файл_системасы·өстәмә_VALUE 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP хост 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 вакыйга·шрифт_VALUE·тәрәз операцион_система_VALUE, AWT 네이티브 연결과 Swing үтәргә_команда 기반 |
| POSIX | 문서화한 Birem·단말·UDP 부분 | Процесс_VALUE·exec/fork·스레드·시그널·TIME_VALUE·mmap·poll·파이프 등과 적합성 тикшерү |
| 언어별 исем | Татарча 46개 대응 кертү_VALUE, фактик_мәгълүмат C/Java/Birem исем 적용 | максат_кыйммәт тел 확정, 언어별 용례·역사 근거와 해당 чыганак·도구의 тикшерү |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 үтәргә_команда 환경을 추가하는 방식은 별도의 төш_VALUE·루트 файл_системасы·OpenJDK·그래픽 сервер_VALUE·영구 Store_VALUE 구성을 가진 үтәргә_команда 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

үтәргә_команда 기반과 추가 максат_кыйммәт 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
