# 자체 커널에서 vi·여러 ടെ_ര്മിനല്·한글 프로그래밍 사용하기

한국어 통신·ഒഴിവാക്കൽ 사용법은 [한국어 Java API](한국어자바/readme_ഫയല്_eb81d7d9.md), കാര്യപ്രവര്_ത്തനം_മൂല്യം·변수·ഫയല് 이름의 변경과 어원 근거는 [명명 readme_ഫയല്_eb81d7d9](명명/readme_ഫയല്_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 자체 AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 പിന്തുണ_മൂല്യം 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 നടപ്പാക്കുക_കമാന്_ഡ്, 외부 TCP/UDP와 FTP는 [새 നടപ്പാക്കുക_കമാന്_ഡ് 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 ടെ_ര്മിനല്

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, ഇമെയിൽ **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 ടെ_ര്മിനല് 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **오른쪽 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 നടപ്പാക്കുക_കമാന്_ഡ് 버튼으로 다시 നിര_മൂല്യം 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 현재 디렉터리, ഷെല് 변수, ആജ്ഞ ലോഗ്_രേഖ, 입력 중인 명령과 പ്രോഗ്രാം_f5044b9b നടപ്പാക്കുക_കമാന്_ഡ് 상태를 보관한다. ഫയല് 저장소는 공유한다. vi와 Swing의 이벤트 കാക്കുക_മൂല്യം 중에 다른 터미널로 전환하면 ഉപയോക്താവ് മെമ്മറി_ഡാറ്റാ·레지스터·ഫയല്/소켓 연결을 보존했다가 돌아올 때 재개한다. **현재 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 അടുത്തത്_ഇനം 입력 കാക്കുക_മൂല്യം 또는 기존 നടപ്പാക്കുക_കമാന്_ഡ് 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 നടപ്പാക്കുക_കമാന്_ഡ് 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 ചിട്ടപ്പെടുത്തല്_മൂല്യം 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. 현재 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 ജാലകം 판단은 게스트 커널이 처리한다. QEMU നടപ്പാക്കുക_കമാന്_ഡ് 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. വാസ്തവമായ_ഡാറ്റാ Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI ഉപകരണങ്ങൾ 종료는 ഹോസ്റ്റ് 터미널의 Ctrl+C다.

## vi 사용

```text
mkdir 작업
cd 작업
vi 인사.py
```

`vi`는 새로 구현한 **vi ആജ്ഞ 부분집합** 편집기다. 내장 `build/user/vi.elf`를 보호된 ഉപയോക്താവ് 영역에 적재한다. ഫയല് 크기는 UTF-8 బైట్_മൂല്യം പ്രൊജക്റ്റ്_ചെയ്യുക_വർഗ്ഗമൂലം 16 KiB, 경로는 63바이트까지다. 디스크에 설치한 Vim/Neovim 바이너리를 실행하는 것이 아니다.

| കീ_മൂല്യം/ആജ്ഞ | നടപടി |
|---|---|
| `i`, `a`, `I`, `A` | 현재/അടുത്തത്_ഇനം സ്ഥാനം 또는 ലൈൻ 처음/끝에서 입력 |
| `o`, `O` | 아래/위에 새 줄을 만들고 입력 |
| Esc | 일반 മോഡ്_മൂല്യം |
| `h j k l`, 방향키 | UTF-8 문자/ലൈൻ നീക്കുക_മൂല്യം |
| `0`, `$`, Home, End | ലൈൻ 처음/끝 |
| `gg`, `G`, `:സൂചിക` | ഫയല് 처음/마지막 ലൈൻ/അസൈൻ_ചെയ്യുക_മൂല്യം ലൈൻ |
| PgUp, PgDn | 화면 പഠനഭാഗം_മൂല്യം നീക്കുക_മൂല്യം |
| `x`, Delete | 현재 문자 삭제 |
| `dd`, `yy`, `p` | ലൈൻ 삭제/ദൃഷ്ടാന്തം_മൂല്യം/ഒട്ടിക്കുക_ലിഖിതം |
| `u` | 마지막 편집을 되돌림; 한 വേദി_മൂല്യം 토글 |
| `/സ്ട്രിംഗ്_മൂല്യം`, `n` | 단순 സ്ട്രിംഗ്_മൂല്യം 검색/അടുത്തത്_ഇനം 일치; 정규식 없음 |
| `:w`, `:w 다른이름` | RAM ഫയല് സ്_റ്റോർ_മൂല്യം/다른 경로로 സ്_റ്റോർ_മൂല്യം |
| `:q` | 변경이 없을 때 പുറത്തുകടക്കൽ_പ്രോഗ്രാം |
| `:q!` | 변경을 버리고 പുറത്തുകടക്കൽ_പ്രോഗ്രാം |
| `:wq`, `ZZ` | 저장하고 പുറത്തുകടക്കൽ_പ്രോഗ്രാം |

붙여 넣은 한글을 문자 경계에 맞춰 നീക്കുക_മൂല്യം·삭제한다. 일반 vi의 수량 접두사, മാക്രോ_മൂല്യം, സജ്ജീകരണം ഫയല്, 플러그인, 정규식, 여러 버퍼/분할 ജാലകം, 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/영 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 ജാലകം ജാലകം_ശീർഷകം `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 ആജ്ഞ**으로 실행한다. 파이프·리다이렉션·സ്ക്രിപ്റ്റ്_മൂല്യം·`;`/`&&`/`||`로 연결한 실행에서 ഇടപെടാനുതകുന്ന 대기를 시작하면 거부한다. 입력 대기는 약 2초 CPU 기한을 갱신하지만 입력 കാക്കുക_മൂല്യം 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## 한글 Java

vi에서 다음을 `인사.java`에 입력하고 Esc → `:wq`로 저장한다.

```java
public class 인사 {
    static int 더하기(int 첫째, int 둘째) { return 첫째 + 둘째; }
    public static void main(String[] 인수) {
        int 합계 = 더하기(20, 22);
        System.out.println("안녕하세요 · 합계=" + 합계);
    }
}
```

게스트 셸에서 실행한다.

```text
javac 인사.java
java 인사
```

한글 ഫയല്_നാ_മം_ലിഖിതം·ക്ലാസ്_നാ_മം·విధానం_നാ_മം_ലിഖിതം·변수명·문자열을 사용할 수 있다. **게스트 javac는 സ്ഥിരമായ_മൂല്യം Java 부분집합**이다. ഓബ്ജക്റ്റ്_മൂല്യം·리스너·Swing·소켓을 사용하는 소스는 현재 ഹോസ്റ്റ് JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 자체 JVM에 class를 올린다. 자체 JVM에서 지원하는 바이트코드/API 범위는 [자바실행환경.md](자바실행환경.md)를 따른다.

```sh
# ഹോസ്റ്റ്
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/스윙시험.java
python3 ഉപകരണങ്ങൾ/അപ്_ലോഡ്_ഫയലുകൾ.py build/my-java/스윙시험.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. ഫലം 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.ക്ലാസ്_മൂല്യം.class` 형식이다. 내장 한국어 라이브러리는 별도 업로드가 필요 없다. 한국어 ജാലകം API의 예제는 [한글창시험.java](시험/자바/한글창시험.java)이며 같은 방법으로 കംപൈല്_ചെയ്യുക_ഉറവിടം·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 ഉറവിടം_ശാഖി/클래스는 호스트의 `python3 ഉപകരണങ്ങൾ/നടപ്പാക്കുക_ഫയല്.py വഴി/인사.java`로 별도 QEMU에 업로드·നടപ്പാക്കുക_കമാന്_ഡ്·종료할 수 있다. ഇടപെടാനുതകുന്ന Swing에는 നടപ്പാക്കുക_കമാന്_ഡ് 후 ഉപയോക്താവ് 입력을 유지하는 `make desktop`을 사용한다.

## 자체 JVM의 Swing ക്ലിപ്പ്

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 자체 Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | നടപടി |
|---|---|
| `JFrame` | ജാലകം_ശീർഷകം, വലിപ്പം·സ്ഥാനം, പ്രദർശനം_ജാലകം, അടയ്ക്കു 정책, dispose |
| `JPanel` | കുട്ടി_മൂല്യം 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 സ്ട്രിംഗ്_മൂല്യം പ്രദർശനം_മൂല്യം·മാറ്റികൊടുക്കുക_മൂല്യം |
| `JButton` | 버튼과 ActionListener ക്ലിക്ക്_ചെയ്യുക_മൂല്യം പ്രോസസ്_മൂല്യം_എന്_ട്രി |
| `JTextField` | 한 ലൈൻ UTF-8 입력, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 자체 JVM의 단일 이벤트 നടപ്പാക്കുക_കമാന്_ഡ് 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. ജാലകം·요소는 നടപ്പാക്കുക_കമാന്_ഡ് 하나당 합계 32개, ഘടകാംശം_മൂല്യം 글자는 최대 127 코드포인트다. സ്ഥിരസ്ഥിതി_മൂല്യം 서체와 색은 커널이 제공한다.

[스윙시험.java](시험/자바/스윙시험.java)는 ജാലകം·한글 ടാഗ്_മൂല്യം·പാഠ_മണ്ഡലം·버튼·이벤트 처리의 നടപ്പാക്കുക_കമാന്_ഡ് 가능한 예제다. [자체 Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

한국어 라이브러리에는 다음을 추가했다. ഹോസ്റ്റ് കംപൈല്_ചെയ്യുക_ഉറവിടം 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `한국어.자체.ജാലകം`: `ചേ൪ക്കുക_ഘടകാംശം`, `പ്രദർശനം_ജാലകം`, `അടയ്ക്കു`.
- `한국어.자체.വിജറ്റ്`: `ടാഗ്_മൂല്യം`, `ബട്ടണ്`, `പാഠ_മണ്ഡലം` സൃഷ്_ടിക്കുക.
- `한국어.자체.연결통신`: `കണക്ടു്_ചെയ്യുക`, `ശ്രദ്ധിക്കുക_അവസാനബിന്ദു`, `받기`.
- 기존 `ഫലം`, `문자`, `ഫയല്`, `작업`, `എന്_ട്രി_ലിസ്റ്റ്`, `നിഘണ്ടു`, `통신`, `화면`, `കെര്_ണല്_മൂല്യം`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **കെര്_ണല്_മൂല്യം 내부 연결형 బైట్_മൂല്യം സ്ട്രീം_മൂല്യം**을 추가했다. ഫയല്/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket സെര്_വര്_മൂല്യം = new java.net.ServerSocket(9250);
java.net.Socket അതിഥി_മൂല്യം = new java.net.Socket("localhost", 9250);
java.net.Socket കണക്ടു്_ചെയ്യുക = സെര്_വര്_മൂല്യം.accept();
അതിഥി_മൂല്യം.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int ദൈര്_ഘ്യം_മൂല്യം = കണക്ടു്_ചെയ്യുക.getInputStream().read(받은것);
കണക്ടു്_ചെയ്യുക.close(); അതിഥി_മൂല്യം.close(); സെര്_വര്_മൂല്യം.close();
```

സൃഷ്_ടിക്കുക·കണക്ടു്_ചെയ്യുക·accept·양방향 బైట్_മൂല്യം/അരേ_മൂല്യം ഇന്_പുട്ട്_ഔട്ട്_പുട്ട്·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 അവസാനിപ്പിക്കുക_പോയിന്റ് 16개, 수신 버퍼당 1024바이트, കാക്കുക_മൂല്യം കണക്ടു്_ചെയ്യുക 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. സ്ഥിരസ്ഥിതി_മൂല്യം സമയ_മൂല്യം 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM ആജ്ഞ 수/കെര്_ണല്_മൂല്യം നടപ്പാക്കുക_കമാന്_ഡ് 기한은 여전히 적용된다.

외부 അക്കം_മൂല്യം IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. വാസ്തവമായ_ഡാറ്റാ Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP లైబ్రరీ 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 വാസ്തവമായ_ഡാറ്റാ 송수신·EOF·기한·കണക്ടു്_ചെയ്യുക 회수의 시험 예제다.

## 한글 Python

게스트 vi에서 한글 이름을 사용해 작성한다.

```python
മൂല്യം = 21

def 두배(അക്കം_മൂല്യം):
    return അക്കം_മൂല്യം * 2

print("അളവ്:", 두배(മൂല്യം))
```

സ്_റ്റോർ_മൂല്യം 후 `python 인사.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 കാര്യപ്രവര്_ത്തനം_മൂല്യം·변수·ഫയല് 이름과 문자열을 한글로 쓴다.

[한국어.py](예제/한글코딩/한국어.py)를 같은 디렉터리에 두면 അടുത്തത്_ഇനം 별칭을 사용할 수 있다.

```python
import 한국어
한국어.റൈറ്റ്_ചെയ്യുക_ഫയല്("인사.txt", "안녕하세요")
한국어.ഫലം(한국어.파일읽기("인사.txt").decode())
```

ഫലം·ഫയല് വായന/എഴുത്തു്/삭제·표준 입력·사각형·സമയ_മൂല്യം·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 അക്കം_മൂല്യം IPv4 ഇമെയിൽ 전송이다. `wait_key()`는 화면을 확인할 때 ഇടപെടാനുതകുന്ന 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor സ്ഥിരമായ_മൂല്യം 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 വിപുലീകരണം_മൂല്യം 모듈은 아직 없다. 제한형 `pip`의 ഉറവിടം_ശാഖി 설치는 [Python ബണ്ടിൽ readme_ഫയല്_eb81d7d9](파이썬꾸러미.md)를 따른다. [세 언어의 വാസ്തവമായ_ഡാറ്റാ 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 భాష 모두 한국어 헤더와 കാര്യപ്രവര്_ത്തനം_മൂല്യം 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 വാസ്തവമായ_ഡാറ്റാ EL0 നടപ്പാക്കുക_കമാന്_ഡ് 시험 대상이다.

```c
#include "파일규약.h"
#ifdef __cplusplus
extern "C"
#endif
int ആരംഭം_ഉപയോക്താവ്_പ്രോഗ്രാം(int 인수) {
    (void)인수;
    const char 인사말[] = "안녕하세요\n";
    int 문서 = തുറക്കുക_ഫയല്("인사.txt", വായനാ_റൈറ്റ് | 없으면만들기 | 내용비우기, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = റൈറ്റ്_ചെയ്യുക_ഫയല്_ഡാറ്റാ(문서, 인사말, sizeof(인사말) - 1);
    അടയ്ക്കുക_ഫയല്(문서);
    റൈറ്റ്_ചെയ്യുക_ഫയല്_ഡാറ്റാ(1, 인사말, sizeof(인사말) - 1); /* 현재 ടെ_ര്മിനല് stdout */
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 수 있다. C는 게스트 `cc` 또는 ഹോസ്റ്റ് SDK, C++는 ഹോസ്റ്റ് SDK의 Clang++로 컴파일한다. 아래 예제는 기존 ഹോസ്റ്റ് SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh
# 호스트에서 SDK സൃഷ്_ടിക്കുക·വേർതിരിക്കുക
make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/인사.c -o 인사-c.elf
python3 compile.py examples/인사.cpp -o 인사-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 വാസ്തവമായ_ഡാറ്റാ നടപ്പാക്കുക_കമാന്_ഡ്
cd /home/user/jkoros/platforms/rpi4-native
python3 ഉപകരണങ്ങൾ/നടപ്പാക്കുക_ഫയല്.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 ഉപകരണങ്ങൾ/നടപ്പാക്കുക_ഫയല്.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

현재 GUI VM에서 실행하려면 `python3 ഉപകരണങ്ങൾ/അപ്_ലോഡ്_ഫയലുകൾ.py വഴി/인사-c.elf`의 출력을 게스트에 보내고 `run 인사-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex ഫയല്_നാ_മം_ലിഖിതം`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 수 있다. 호스트와 게스트의 ഫയല് 시스템은 별개다.

| 한국어 പേരു് | C nbsp_ചിഹ്നം | ക്ലിപ്പ് |
|---|---|---|
| തുറക്കുക_ഫയല്/അടയ്ക്കുക_ഫയല് | pk_open/pk_close | RAM ഫയല്, പീര്_മൂല്യം/절대 വഴി |
| 파일자료읽기/റൈറ്റ്_ചെയ്യുക_ഫയല്_ഡാറ്റാ | pk_read/pk_write | ഫയല്, fd 0/1/2 표준 ഇന്_പുട്ട്_ഔട്ട്_പുട്ട്, 연결형 소켓 |
| തിരയുക_ഫയല് | pk_lseek | 처음기준/현재기준/끝기준 |
| ഫയല്_വലുപ്പം_ക്രമീകരിക്കുക/ഗണം_ഫയല്_ദൈര്_ഘ്യം | pk_size/pk_ftruncate | ദൈര്_ഘ്യം_മൂല്യം ചോദ്യം_മൂല്യം/മാറ്റികൊടുക്കുക_മൂല്യം |

| 파일저장확정 | pk_fsync | RAM이므로 -1, 오류번호=ENOSYS |
| സൃഷ്_ടിക്കുക_അവസാനബിന്ദു/బైండ్_చేయి_ഇമെയിൽ | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |

`통신규약.h`의 자체 `pk_sockaddr_in`을 사용하며 പോര്_ട്ട്_മൂല്യം·주소는 `망차례짧은수`/`നെറ്റ്_വർക്ക്_പൂര്_ണ്ണസംഖ്യ`로 변환한다. C 소켓 호출은 비차단이며 ഡാറ്റാ/연결이 없으면 -1과 `오류번호=11`(EAGAIN)을 반환한다. 양수 ഇന്_പുട്ട്_ഔട്ട്_പുട്ട് 결과가 요청보다 작을 수 있으므로 ആവര്_ത്തനം_മൂല്യം 처리한다. പരാജയം_മൂല്യം 후에만 오류번호를 확인한다.

[സ്ട്രീം_മൂല്യം.c](예제/한글코딩/സ്ട്രീം_മൂല്യം.c)는 C에서 한국어 이름으로 കണക്ടു്_ചെയ്യുക·accept·부분 വായന/എഴുത്തു്·큐 포화·EOF를 처리하는 നടപ്പാക്കുക_കമാന്_ഡ് 예제다. SDK의 `examples/സ്ട്രീം_മൂല്യം.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → വാസ്തവമായ_ഡാറ്റാ 한국어 C കാര്യപ്രവര്_ത്തനം_മൂല്യം 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·പോയിന്_റര് 검사 → Java RAM ഫയല്/루프백 또는 외부 lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 കെര്_ണല്_മൂല്യം 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 കണക്ടു്_ചെയ്യുക, 표준 C printf, libstdc++/STL, ഒഴിവാക്കൽ·RTTI는 제공하지 않으며 C++의 സ്ഥിരമായ_മൂല്യം 생성자·ലോക്കല്_സാധ്യത ഓബ്ജക്റ്റ്_മൂല്യം 소멸자는 지원한다. 상세 സൂചിക·മെമ്മറി_ഡാറ്റാ 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## 한국어 이름으로 직접 작성하는 창과 ത്രെഡ്_മൂല്യം

`example/java/창예제.java`는 `실행할일.പ്രവര്_ത്തിപ്പിയ്ക്കുക`,
`동작받이.동작받기(동작알림)`, `ബട്ടണ്`, `ഇവന്റ്_ക്യൂ.나중에실행`, `നടപ്പിലാക്കുക()`을 쓴다.
자체 JVM에 이 이름들의 ഓബ്ജക്റ്റ്_മൂല്യം·విధానం_മൂല്യം·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `작업가닥`도 자체 스케줄러와 직접 연결된다.
세부 메서드와 기존 한국어 API에서의 변경은 [한국어 API 문서](한국어자바/readme_ഫയല്_eb81d7d9.md)를 본다.

ഹോസ്റ്റ് javac는 배포 JAR를 ക്ലാസ്_മൂല്യം 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/창예제.java
python3 ഉപകരണങ്ങൾ/നടപ്പാക്കുക_കമാന്_ഡ്.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java 창예제
```

직접 화면/ത്രെഡ്_മൂല്യം API와 `നടപ്പിലാക്കുക()` 진입점은 자체 JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
