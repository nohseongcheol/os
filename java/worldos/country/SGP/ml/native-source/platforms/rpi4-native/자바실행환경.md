# 자체 ARM64 JVM 0.4와 한국어 లైబ్రరీ

한국어 통신·ഒഴിവാക്കൽ 사용법은 [한국어 Java API](한국어자바/readme_ഫയല്_eb81d7d9.md), കാര്യപ്രവര്_ത്തനം_മൂല്യം·변수·ഫയല് 이름의 변경과 어원 근거는 [명명 readme_ഫയല്_eb81d7d9](명명/readme_ഫയല്_eb81d7d9.md)를 참고한다.

JAR നടപ്പാക്കുക_കമാന്_ഡ്, 외부 IPv4 TCP/UDP, 별도 സ്ഥിരമായ_മൂല്യം 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 ഓബ്ജക്റ്റ്_മൂല്യം·Thread·Swing은 JVM 경로의 기능이며 AOT പിന്തുണ_മൂല്യം 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 നടപ്പാക്കുക_കമാന്_ഡ്**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK ക്ലാസ്_മൂല്യം లైబ్రరీ 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 ക്ലാസ്_മൂല്യം·സ്ഥിരമായ_മൂല്യം విధానం_മൂല്യം 중심이던 실행기를 ഓബ്ജക്റ്റ്_മൂല്യം·లైబ్రరీ നടപ്പാക്കുക_കമാന്_ഡ് 기반으로 넓힌 것이다.

## 실행과 കംപൈല്_ചെയ്യുക_ഉറവിടം

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# 자체 കെര്_ണല്_മൂല്യം 안에서 ഉറവിടം_ശാഖി കംപൈല്_ചെയ്യുക_ഉറവിടം → class നടപ്പാക്കുക_കമാന്_ഡ്, 한국어 API 호출
python3 ഉപകരണങ്ങൾ/നടപ്പാക്കുക_ഫയല്.py 시험/자바/한글소스.java

# ഓബ്ജക്റ്റ്_മൂല്യം·ഒഴിവാക്കൽ 등은 ഹോസ്റ്റ് JDK로 Java 8 class를 만든 후 자체 커널에서 നടപ്പാക്കുക_കമാന്_ഡ്
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 ഉപകരണങ്ങൾ/നടപ്പാക്കുക_ഫയല്.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 കൈമാറുക_മൂല്യം_630ba093
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 ഉപകരണങ്ങൾ/നടപ്പാക്കുക_ഫയല്.py build/my-java/객체시험.class \
  --include build/my-java/నేపథ్యం_മൂല്യം.class --include build/my-java/ശാഖ_മൂല്യം.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.ക്ലാസ്_മൂല്യം.class`라는 RAM ഫയല് 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.ക്ലാസ്_മൂല്യം`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.ക്ലാസ്_മൂല്യം`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar ഫയല്.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 한국어 클래스만 찾는다. 배포 한국어 లైబ్రరీ JAR는 ഹോസ്റ്റ് javac의 classpath로 사용하며, 같은 클래스가 ഉപയോക്താവ് JVM ELF에도 വായന 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 സ്ഥിരമായ_മൂല്യം విధానం_മൂല്യം, int/boolean/char/String, അവസ്ഥ·ആവര്_ത്തനം_മൂല്യം, സ്ട്രിംഗ്_മൂല്യം 결합, 일부 ഫയല് 스트림 등의 **자체 부분집합 컴파일러**다. ഓബ്ജക്റ്റ്_മൂല്യം പ്രസ്താവം·상속·try/catch·Thread 사용 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 자체 JVM에서 실행한다. 한국어 API 중 ഫലം·문자 스칼라 കാര്യപ്രവര്_ത്തനം_മൂല്യം·ഫയല് വായന/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] 인수) throws Exception {
        한국어.자체.ഫലം.റൈറ്റ്_ചെയ്യുക_ലൈൻ("안녕하세요😀");
        한국어.자체.ഫലം.수쓰기(한국어.자체.문자.코드포인트수("한글😀"));
        한국어.자체.ഫയല്.എഴുത്തു്("인사.txt", "한글 ഫയല്😀");
        한국어.자체.ഫലം.റൈറ്റ്_ചെയ്യുക_ലൈൻ(한국어.자체.ഫയല്.വായന("인사.txt"));
    }
}
```

컬렉션은 지정한 메서드만 제공하며 iterator/stream/വിന്യസിക്കുക_മൂല്യം·ഉപയോക്താവ് നിർവ്വചനം_മൂല്യം equals/hashCode 콜백은 없다. 사전의 열쇠는 String/Integer/null 사용을 시험했다. UTF-16 കോഡ്_മൂല്യം 단위와 Unicode കോഡ്_മൂല്യം 포인트 수는 구분한다. 한글 입력 조합·ക്രമാനുസരണമാക്കുക_മൂല്യം·아랍어 조판·GUI 다국어 글꼴은 이 സ്ട്രിംഗ്_മൂല്യം 지원과 별개다.

예외는 Throwable/Exception/RuntimeException, ArithmeticException, NullPointerException, IndexOutOfBoundsException/ArrayIndexOutOfBoundsException/StringIndexOutOfBoundsException, IllegalArgumentException/NumberFormatException/IllegalThreadStateException, IOException/FileNotFoundException, IllegalStateException, ClassCastException, NegativeArraySizeException, ArrayStoreException, UnknownHostException, SocketTimeoutException의 제한된 സൃഷ്_ടിക്കുക·വകുപ്പ്_മൂല്യം·처리를 제공한다. ഉപയോക്താവ് നിർവ്വചനം_മൂല്യം Throwable 상속, stack trace/cause/suppressed ഒഴിവാക്കൽ, try-with-resources의 addSuppressed, 완전한 തുടക്കമിടുക പിശക് 포장은 아직 없다. 잡히지 않은 예외는 현재 전체 Java 실행을 실패로 끝낸다.

## 한국어 API

독립 패키지 **`한국어.자체`**를 사용한다. Linux판 `한국어.자바`가 요구하는 NIO/Swing/HTTP API를 자체 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 ക്ലാസ്_മൂല്യം പേരു്·విధానం_മൂല്യം·인수·മണ്ഡലം_മൂല്യം·ഫയല് 이름에 한국어를 사용한다. 표준 Java ക്ലാസ്_മൂല്യം 이름은 호환성을 위해 보존한다.

| ക്ലാസ്_മൂല്യം | 공개 기능 | 이름의 의미 |
|---|---|---|
| ഫലം | എഴുത്തു്, റൈറ്റ്_ചെയ്യുക_ലൈൻ, 수쓰기 | ഫലം(出力): 내용을 바깥으로 내보냄 |
| 문자 | ദൈര്_ഘ്യം_മൂല്യം, 같음, ഒട്ടിക്കുക_ലിഖിതം, മുറിക്കുക_മൂല്യം, പാര്_സ്_ചെയ്യുക_പൂര്_ണ്ണസംഖ്യ/റൈറ്റ്_ചെയ്യുക_പൂര്_ണ്ണസംഖ്യ_മൂല്യം, 코드포인트수, 부호화/ഗൂഢഭാഷമാറ്റുക_ഡാറ്റാ | 문자(文字), എന്_കോഡുചെയ്യല്_മൂല്യം(符號): 글의 단위와 그 값을 바이트로 나타내는 നിയമം_മൂല്യം |
| ഫയല് | വായന/എഴുത്തു്(String പേരു്), 바이트읽기/റൈറ്റ്_ചെയ്യുക_బైట్_മൂല്യം | 널리 쓰는 ഉപയോക്താവ് 용어를 보존; RAM 자료의 പേരു് |
| എന്_ട്രി_ലിസ്റ്റ് | 더하기, വായന, പകരംവയ്ക്കുക_മൂല്യം, മായ്ക്കുക_എന്_ട്രി, വലിപ്പം, വിവര_സാങ്കേതികവിദ്യ_ശൂന്യം_മൂല്യം, മായ്ക്കുക_ഉള്ളടക്കങ്ങള് | എന്_ട്രി_ലിസ്റ്റ്(目錄): 순서가 있는 എന്_ട്രി_മൂല്യം 모음 |
| നിഘണ്ടു | 넣기, കണ്ടെത്തുക_എന്_ട്രി, 있는가, മായ്ക്കുക_എന്_ട്രി, വലിപ്പം, മായ്ക്കുക_ഉള്ളടക്കങ്ങള് | നിഘണ്ടു(辭典): 찾는 말인 열쇠에 값을 대응 |
| 작업 | നടപ്പിലാക്കുക(실행할일), 기다리기(작업가닥), താല്_ക്കാലികമായി_നിര്_ത്തുക_ചുമതല, 살아있는가 | 작업 ത്രെഡ്_മൂല്യം: 한 പ്രോഗ്രാം_f5044b9b 안의 നടപ്പാക്കുക_കമാന്_ഡ് സ്ട്രീം_മൂല്യം |
| 통신 | തുറക്കുക, അയയ്ക്കുക, 받기, ടൈംഔട്ട്, അടയ്ക്കു | 통신(通信), 전문(電文), പോര്_ട്ട്_മൂല്യം: ഡാറ്റാ 교환·메시지·포트의 역할 |
| 화면 | 사각형, മായ്ക്കുക_എന്_ട്രി | 화면(畫面): വാസ്തവമായ_ഡാറ്റാ 그림을 표시하는 면 |
| കെര്_ണല്_മൂല്യം | 밀리초, 사각형 | 자체 JVM의 고정 native കണക്ടു്_ചെയ്യുക; 일반 JNI는 아님 |

이 명명은 현재 기능을 설명하는 용어 선택이다. 기존 한국어에 없던 역사적 어원을 만들어 주장하지 않는다. ഫയല്_നാ_മം_ലിഖിതം·식별자는 UTF-8 소스로 보관한다. `문자.ഗൂഢഭാഷമാറ്റുക_ഡാറ്റാ`는 잘못된 UTF-8에 IllegalArgumentException을 던지며, `부호화`는 짝이 없는 서로게이트를 `?`로 바꾼다. `ഫയല്.വായന`는 엄격한 UTF-8 복호화를 적용한다. 화면 색은 `빨강 | (초록 << 8) | (파랑 << 16)` 형식이다.

## നടപ്പാക്കുക_കമാന്_ഡ് 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(한국어 ക്ലാസ്_മൂല്യം 포함), class당 16 KiB·സ്ഥിരം_മൂല്യം 풀 511항목, 전체 విధానం_മൂല്യം/മണ്ഡലം_മൂല്യം 각각 512개. విధానం_മൂല്യം കോഡ്_മൂല്യം 8 KiB, ലോക്കല്_സാധ്യത 변수·피연산자 스택 각각 128슬롯, 인수 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 നടപ്പാക്കുക_കമാന്_ഡ് 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- ഓബ്ജക്റ്റ്_മൂല്യം 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 വാസ്തവമായ_ഡാറ്റാ 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 ഫയല്·대형 സ്ട്രിംഗ്_മൂല്യം·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 ആജ്ഞ 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 ജാലകം സ്വിച്ച്_മോഡ് 시 중단·재개한다. 일반 സെര്_വര്_മൂല്യം·계산의 무제한 실행은 아직 없다. 미지원 ആജ്ഞ·ഉറവിടം_മൂല്യം 부족은 명시적인 오류로 종료한다.
- RAM ഫയല് 최대 64개, 파일당 16384바이트, വഴി UTF-8 63바이트. RAM 디렉터리와 പീര്_മൂല്യം/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 한국어 class는 RAM ഫയല് 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 현재 경로에서 ഉറവിടം_ശാഖി·ക്ലാസ്_മൂല്യം·ഡാറ്റാ 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 외부 IPv4를 제공한다. വാസ്തവമായ_ഡാറ്റാ GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. 전문 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 നടപ്പാക്കുക_കമാന്_ഡ് 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 അരേ_മൂല്യം, 완전한 അരേ_മൂല്യം 공변성·인터페이스 ലെയര്_മൂല്യം 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/ഗൂഢഭാഷയാക്കുക_ഡാറ്റാ/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 പിന്തുണ_മൂല്യം 부분집합은 아래 및 개발 매뉴얼을 참고한다. ക്ലാസ്_മൂല്യം ഫയല് 전체 검증기·ആക്സസ്_എന്_ട്രി അനുമതി_മൂല്യം/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 പരിരക്ഷിക്കുക_മൂല്യം 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM മൂല്യം/സാധൂകരിക്കുക/ക്ലാസ്_മൂല്യം 로더와 ഒഴിവാക്കൽ 모델 → 영속 VFS·mmap·ഘടികാരം·원자 ഓപ്പറേഷൻ_മൂല്യം·വാസ്തവമായ_ഡാറ്റാ 스레드/സമന്വയിപ്പിക്കുക ABI → OpenJDK java.base 및 native లైబ్రరీ 이식 → മൊബൈൽ_മൂല്യം 네트워크·TCP/IP → ജാലകം 시스템/ഫോണ്ട്_മൂല്യം/입력기·java.desktop → Java SE 호환성 시험. 현재 자체 JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## സാധൂകരിക്കുക

`ഉപകരണങ്ങൾ/자바가상기계시험.py`는 같은 Java 8 class 파일의 출력을 ഹോസ്റ്റ് OpenJDK `-Xverify:all`과 QEMU raspi4b 자체 커널에서 비교한다. ഓബ്ജക്റ്റ്_മൂല്യം/상속/인터페이스·switch·അരേ_മൂല്യം, ഒഴിവാക്കൽ/finally, 컬렉션/GC, Thread/ലോക്ക്_മൂല്യം, 한국어 UTF-8/ഫയല്/컬렉션, വാസ്തവമായ_ഡാറ്റാ UDP 루프백/സമയ_മൂല്യം 초과, 게스트 한글 ഉറവിടം_ശാഖി കംപൈല്_ചെയ്യുക_ഉറവിടം, അരേ_മൂല്യം ടൈപ്പ്_ചെയ്യുക_മൂല്യം/ദൃഷ്ടാന്തം_മൂല്യം/ഫയല് 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 ഫയല് നിരസിക്കുക_മൂല്യം 시험을 실행한다. UDP പ്രൊജക്റ്റ്_ചെയ്യുക_വർഗ്ഗമൂലം 실행에는 ഹോസ്റ്റ് 루프백 소켓 권한이 필요하다.

`ഉപകരണങ്ങൾ/부팅시험.py`는 കെര്_ണല്_മൂല്യം പരിരക്ഷിക്കുക_മൂല്യം/회귀 시험과 별도로 한국어 Java 화면 API가 വാസ്തവമായ_ഡാറ്റാ 픽셀을 그렸는지도 QMP 화면 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. വാസ്തവമായ_ഡാറ്റാ Pi4 하드웨어 부팅 시험과 전체 JDK 호환성 시험 결과는 아니다.


## JVM 0.3: 네트워크와 GUI വിപുലീകരണം_മൂല്യം

`Socket`/`ServerSocket` സൃഷ്_ടിക്കുക·കണക്ടു്_ചെയ്യുക·accept·양방향 InputStream/OutputStream·close·EOF·സമയ_മൂല്യം 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 외부 അക്കം_മൂല്യം IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 അവസാനിപ്പിക്കുക_പോയിന്റ് 16개, Java 루프백 버퍼 1024바이트, 외부 TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. ഇടപെടാനുതകുന്ന 이벤트 대기는 നടപ്പാക്കുക_കമാന്_ഡ് 기한을 갱신하고 ടെ_ര്മിനല് സ്വിച്ച്_മോഡ് 시 프로세스 상태를 സ്_റ്റോർ_മൂല്യം·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

한국어 `ജാലകം`, `വിജറ്റ്`, `연결통신` 클래스를 배포 JAR와 자체 JVM 내장 자원에 추가했다. 상세 విధానం_മൂല്യം·제한·ഉറവിടം_ശാഖി·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## 한국어 객체의 직접 നടപ്പാക്കുക_കമാന്_ഡ്

`ജാലകം`, `ലേബല്`, `പാഠ_മണ്ഡലം`, `ബട്ടണ്`, `ഇവന്റ്_ക്യൂ`, `동작알림`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. 자체 JVM의 ഓബ്ജക്റ്റ്_മൂല്യം സൃഷ്_ടിക്കുക,
ఫార్మాట్_മൂല്യം 검사, 화면 호출, ഇവന്റ് 큐, ത്രെഡ്_മൂല്യം 스케줄러에 한국어 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 നടപ്പാക്കുക_കമാന്_ഡ് 경로도 유지한다.
한국어 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

자체 실행기의 한국어 진입점은 `public static void നടപ്പിലാക്കുക()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 한국어 진입점을 우선한다.
명령행 인수는 `실행인수.개수()`와 `실행인수.പദാവലി(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. സ്ഥിരമായ_മൂല്യം ഫയല് 예제는 게스트
javac로도 컴파일하며, GUI/ത്രെഡ്_മൂല്യം 소스는 ഹോസ്റ്റ് `javac --release 8`을 사용한다.
직접 GUI/ത്രെഡ്_മൂല്യം API는 자체 JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
한국어 가닥의 നടപ്പാക്കുക_കമാന്_ഡ്·കാക്കുക_മൂല്യം·중복 നടപ്പിലാക്കുക നിരസിക്കുക_മൂല്യം, GUI ഇവന്റ് 출처·സൂചിക·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

విధానం_മൂല്യം 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
한국어 클래스도 실행되지만, സ്ട്രിംഗ്_മൂല്യം 리터럴·표준 లైబ్రరీ 재정의·native
കണക്ടു്_ചെയ്യുക·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 예제](한국어자바/readme_ഫയല്_eb81d7d9.md)를 참고한다.

## ടെ_ര്മിനല് 부분 പുതുക്കിയെടുക്കുക

നീക്കുക_മൂല്യം·വലിപ്പം 변경은 새 ജാലകം 영역과 이전 자리에서 드러난 띠만 합성한다.
1920×32 പെല്(240 KiB)의 임시 그림에서 배경·겹친 ജാലകം·പ്രതീകം_മൂല്യം·GUI를 먼저
완성하고, 현재 പ്രദർശനം_മൂല്യം 메모리와 비교하여 달라진 화소만 기록한다.
32줄보다 큰 영역은 여러 띠로 처리하므로 전체 프레임을 원자적으로
교체하거나 수직 동기에 맞추는 방식은 아니다. 전체 배경을 먼저 지우는
중간 화면은 표시하지 않는다. 좌표가 같으면 다시 그리지 않는다.

`make test-redraw`는 വാസ്തവമായ_ഡാറ്റാ C 그리기 코드를 호스트의 മെമ്മറി_ഡാറ്റാ 화면에 연결해
നീക്കുക_മൂല്യം 80회·വലിപ്പം മാറ്റികൊടുക്കുക_മൂല്യം 40회·겹친 ജാലകം 4개를 전체 합성 결과와 പെല് 단위로 대조한다.
영역 밖 ഉപയോക്താവ് ഡ്രോയിംഗ്_മൂല്യം, 동일 പെല് 무기록, പോയിന്_റര് 밑그림, വാസ്തവമായ_ഡാറ്റാ 화면 ലൈൻ 간격을
검사한다. 이 시험의 시간은 ഹോസ്റ്റ് CPU 측정이며 Pi 4/QEMU 속도로 해석하지 않는다.
`make test-resize`는 QEMU/VNC의 640×480 및 1920×1080에서 왼쪽 모서리 ഇഴയ്ക്കുക_മൂല്യം,
한글 입력·vi 미저장 ഉള്ളടക്കം_മൂല്യം·독립 ജാലകം 크기를 검사한다.
