# 전체 ਸਮਰਥਨ_ਕੀਮਤ 요청의 현재 ਸਥਿਤੀ_ਕੀਮਤ

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 ਅਸਲ_ਸਮੱਗਰੀ C POSIX 일부 기능, ਪੰਜਾਬੀ API/ਸਰੋਤ ਨਾਂ, IDE ਫਾਇਲ 보존, 게스트 Java ਫਾਇਲ 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/ਫਈਲ_ਮੈਨੂੰ_ਪੜਨ_ਦਿਉ_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 ਅਮਲ_ਕਰੋ_ਆਦੇਸ਼ 가능한 ਕਲਿਪ | 전체 지원에 필요한 작업 |
|---|---|---|
| Java ਬਣਾਊਣਾ_ਸਰੋਤ·ਅਮਲ_ਕਰੋ_ਆਦੇਸ਼ | 게스트 제한형 javac/JVM, ਸਥਾਈ_ਕੀਮਤ 단일 클래스와 일부 표준 ਔਬਜੈਕਟ_ਕੀਮਤ | 일반 ਔਬਜੈਕਟ_ਕੀਮਤ·ਸ੍ਰੇਣੀ_ਕੀਮਤ ਕੁਨੈਕਸ਼ਨ_ਕਰੋ·예외·GC·스레드, 완전한 javac와 표준 ਸ੍ਰੇਣੀ_ਕੀਮਤ ਪੁਸਤਕਾਲਾ |
| ਫਾਇਲ | POSIX 서술자, Java 단일 ਬਾਈਟ_ਕੀਮਤ ਫਾਇਲ ਸਟ੍ਰੀਮ_ਕੀਮਤ, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·ਆਗਿਆ_ਕੀਮਤ·잠금·일반 ਫਾਈਲ_ਸਿਸਟਮ·ਪ੍ਰਸਾਰ_ਕੀਮਤ 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP ਹੋਸਟ 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 ਇਵੈਂਟ·ਫੌਂਟ_ਕੀਮਤ·ਵਿੰਡੋ ਸਿਸਟਮ_ਚਲਾਉਣਾ_ਕੀਮਤ, AWT 네이티브 연결과 Swing ਅਮਲ_ਕਰੋ_ਆਦੇਸ਼ 기반 |
| POSIX | 문서화한 ਫਾਇਲ·단말·UDP 부분 | ਕਾਰਵਾਈ_ਕੀਮਤ·exec/fork·스레드·시그널·시간·mmap·poll·파이프 등과 적합성 ਪ੍ਰਮਾਣਿਤ |
| 언어별 ਨਾਂ | ਪੰਜਾਬੀ 46개 대응 ਦਾਖਲਾ_ਕੀਮਤ, ਅਸਲ_ਸਮੱਗਰੀ C/Java/ਫਾਇਲ ਨਾਂ 적용 | ਟੀਚਾ ਭਾਸ਼ਾ 확정, 언어별 용례·역사 근거와 해당 ਸਰੋਤ·도구의 ਪ੍ਰਮਾਣਿਤ |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 ਅਮਲ_ਕਰੋ_ਆਦੇਸ਼ 환경을 추가하는 방식은 별도의 ਪੱਕੇ_ਹੋਣਾ_ਕੀਮਤ·루트 ਫਾਈਲ_ਸਿਸਟਮ·OpenJDK·그래픽 ਸਰਵਰ_ਕੀਮਤ·영구 ਸੰਭਾਲੋ_ਕੀਮਤ 구성을 가진 ਅਮਲ_ਕਰੋ_ਆਦੇਸ਼ 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

ਅਮਲ_ਕਰੋ_ਆਦੇਸ਼ 기반과 추가 ਟੀਚਾ 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
