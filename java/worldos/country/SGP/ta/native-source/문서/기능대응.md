# engos 기능 대응표

이 표는 기존 `மரபுவழி_மூலம்/`의 பொருள்_மதிப்பு 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [அசல்_தரவு 부팅 기능과 한계](../os/பயனர்_உதவிக்_கோப்பு_eb81d7d9.md)를 따로 기록한다.

## 기존 பொருள்_மதிப்பு 기반 관리 கரு_மதிப்பு 전체를 부팅하기 위해 남은 இணைக்க

அடுத்து_உருப்படி 항목은 Java 문법만으로 실행할 수 없는 CPU/சாதனம்_மதிப்பு 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot நுழைவுப்_புள்ளி_மதிப்பு, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 சூழல்_மதிப்பு சேகரி_மதிப்பு
- அசல்_தரவு PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA சுழற்சி_மதிப்பு
- Java பொருள்_மதிப்பு·கோவை_மதிப்பு_ed437109 இணை_லேஅவுட், விதிவிலக்கு, மாறா_மதிப்பு தயார்படுத்து, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT நிலை_மதிப்பு_29ee1bb7
- FAT 디스크 구역을 அசல்_தரவு ATA 장치와 연결하는 உள்ளீடு_வெளியீடு 접착 அடுக்கு_மதிப்பு

위 관리 계층은 engos 기능의 Java 관리 구현과 ஓம்பு 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot நுழைவுப்_புள்ளி_மதிப்பு, மாறா_மதிப்பு தயார்படுத்து·முழு_எண் கோவை_மதிப்பு_ed437109, VGA/직렬/PS2, 명령해석기, பயனர் ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 ஓம்பு 루프백 패킷 왕복을 검증했다. 위 표의 பொருள்_மதிப்பு 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
