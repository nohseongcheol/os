# 中文 Java 辅助器值 库

OpenJDK 11 이상과 함께 쓰는 프로젝트 所有者值 API다. 표준 Java 库 전체의 번역판을 뜻하지 않는다. 기존 Java API·키워드·异常·자료형은 그대로 함께 쓴다.

전체 22개 辅助器值 메서드의 实参·已返回值·제약, 操作系统 안의 사용법, Python·C++ 调用 방법은 **[中文 库 用户指南](用户指南.md)**에 정리했다. [Python 调用 用例](用例/其他语言/Python调用.py)와 [C++ JNI 调用 用例](用例/其他语言/Java调用.cpp)도 제공한다.

`make`로 `build/中文Java.jar`를 만든다. `javac -encoding UTF-8 -cp build/中文Java.jar 用例/问候例.java`로 예제를 컴파일한다. 실행은 `java -cp build/中文Java.jar:用例 问候例`第三操作数.

`问候例` 예제는 그래픽 화면이 없으면 文件·字符·스레드 결과와 안내만 출력한다. Swing 창은 그래픽 세션에서 실행해야 한다. QEMU에서는 [그래픽 执行命令 指南](../platforms/rpi4/README.md)의 `make run`으로 부팅한 后端值 VNC 데스크톱의 터미널을 사용한다.

| 类值 | 제공 기능 |
|---|---|
| 文件 | UTF-8 텍스트·字节值 读取/写入, 디렉터리·条目列表 |
| 字符 | UTF-8 转换值, NFC 正规化值, 代码值 포인트 数, 언어별 词法用机器字 边界位置值 |
| 通信 | HTTP(S) 申请, 제한시간을 가진 TCP 连接 |
| 任务 | 스레드 运行·합류·等待状态值, 任务 运行器 |
| 屏幕 | Swing 이벤트 처리와 窗口 生成 |
| 工作区 | 源代码 编辑值·编译源代码·执行命令·执行命令 文件 生成 屏幕 |

`char`는 UTF-16 代码值 단위이므로 이모지 등을 한 글자로 처리할 때 代码值 포인트 또는 字符 边界位置值 API를 사용한다. 파일은 UTF-8로 저장한다. OpenJDK의 모든 Java2D/字体值/입력기 조합을 각각 검증한 것은 아니다.

이름은 当前项目 의미가 분명한 中文 용례를 사용했다. 개별 명칭의 역사적 어원 검토를 완료했다고 주장하지 않는다. 资源值 종료와 异常 처리는 표준 API의 계약을 따른다.
