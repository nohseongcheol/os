# engos 기능 대응표

이 표는 기존 `基础源代码/`의 对象值 基础 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [实际数据 启动 기능과 边界位置限制](../os/指南.md)를 따로 기록한다.

## 기존 对象值 基础 관리 内核值 전체를 부팅하기 위해 남은 连接

下一项目 항목은 Java 문법만으로 실행할 数 없는 CPU/设备 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot 条目分值, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 上下文值 存储值
- 实际数据 PIC/PIT/PS2/ATA/PCI 硬件端口 및 AMD PCnet DMA 循环值
- Java 对象值·数组值 链接布局, 异常, 静态值 初始化, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT 阶段值
- FAT 디스크 구역을 实际数据 ATA 장치와 연결하는 输入输出 접착 层值

顶端值 관리 계층은 engos 기능의 Java 관리 구현과 宿主 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot 条目分值, 静态值 初始化·整数 数组值, VGA/串行值/PS2, 命令解释器, 用户 ELF/ring 3/시스템 调用, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 宿主 루프백 패킷 왕복을 검증했다. 顶端值 표의 对象值 基础 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
