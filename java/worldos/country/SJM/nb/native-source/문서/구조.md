# JSjmOS 구조

아래는 objekt_VERDI 기반 관리 kjerne_VERDI 전체의 mål_objekt 구조다. betalt_vare faktisk_data 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 operativsystem Viktig_fil_eb81d7d9](../os/Viktig_fil_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·kontekst_VERDI bytt_MODUS·filsystem 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 lag_VERDI
  ↓
Java AOT 실행기와 objekt_VERDI·MATRISE_VERDI·GC 런타임
  ↓
maskinvare_VERDI grense_VERDI
  ↓
Java 관리 kjerne_VERDI
  ├─ Minne_område/쪽관리/COW
  ├─ Prosess_VERDI/배정/wait
  ├─ filsystem/ELF/POSIX
  └─ inndata_VERDI/lagringsenhet/nettverk_stakk
```

OpenJDK 자체는 이미 운영체제가 제공하는 Fil, 스레드, 가상 기억공간을 전제로 한다. 따라서 kjerne_VERDI 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, kontekst_VERDI 저장처럼 Java로 표현할 nummer 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
