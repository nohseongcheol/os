게스트 `vi 빛.java`로 Avanti_articolo 소스를 작성한다.



`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 generare·연결한다. Esegui_comando 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 Supporto_VALORE 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 statico_VALORE metodo_VALORE/valore_del_campo, int 계열, intero 배열과 fonti, argomenti array_VALORE, condizione·ramo·sprint_VALORE, stringa_VALORE 리터럴, `System.out.print/println`의 int/String, Italiano uscitaTesto·file Lettura/쓰기로 제한된다. Corso_VALORE/metodo_VALORE 수와 operando_Pila 등에도 고정 상한이 있다. Java eccezione Processi_VALORE_voce, oggetto_VALORE generare, 가상 metodo_VALORE 일반, switch/wide, long/float/double, invokedynamic, stringa_VALORE 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 array_VALORE accesso_voce/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java eccezione 객체로 전달하지 않는다.

input_VALORE 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 allineare_VALORE 때문에 짧은 클래스도 이 한도를 넘을 numero 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 oggetto_VALORE·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 Supporto_VALORE ritagliare 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 sviluppo 매뉴얼](sviluppo_guida.md)을 참고한다.

JAR는 하나의 애플리케이션 Corso_VALORE 경로다. 내부 Nome `aggregare/app_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 Italiano 클래스를 추가로 찾지만 Regolari_articolo 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·Crittografa_dati ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 numero/VM heap_VALORE 제한은 그대로 적용된다.

## Italiano 네트워크·작업·schermata API

| Corso_VALORE | 호출 예 | Esegui_comando percorso |
|---|---|---|
| `uscitaTesto` | `scrivere_riga("안녕")`, `scrivere_numero(42)` | JVM 및 제한형 AOT |
| `file` | `Scrittura("Guides.txt", "Contenuto_VALORE")`, `Lettura("Guides.txt")` | JVM 및 제한형 AOT |
| `comunicazione` | `Apri(0)`, `inviare(endpoint, "10.0.2.2", 9000, "한글")`, `ricevere(endpoint)` | JVM의 UDP |
| `connessione_trasporto` | `Connetti("10.0.2.2", 9000)`, `essere_in_ascolto_endpoint(9000)`, `ricevere(server_VALORE)` | JVM의 Socket/ServerSocket |
| `작업` | `avvia(Runnable)`, `기다리기(Thread)`, `REND_task()` | JVM의 협력식 thread_VALORE |
| `Finestra`, `elemento_grafico` | Finestra·버튼·carattere_VALORE·campo_di_testo·Evento Connetti | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 Italiano 호출 계층을 추가한다. `comunicazione(通信)`, `Connetti(連結)`, `uscitaTesto(出力)`은 기존 단어의 뜻을 사용한다. `작업 thread_VALORE`은 한 Esegui_comando 흐름을 가닥에 빗댄 descrittore_VALORE 표현, `porta_VALORE`는 포트의 접점을 설명하는 표현이다. 새 descrittore_VALORE 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

esterno_VALORE 주소는 cifra_VALORE IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 nativo ABI이며 JVM이 제한된 aspetta_VALORE/재시도를 제공한다. TCP connect 대기는 최대 1초, spazio_utente app_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 Esegui_comando spazio_utente 서버와 pthread는 아직 없다. FTP는 spazio_utente app_f5044b9b 기한과 별개인 kernel_VALORE 서비스다.

게스트의 spazio_utente TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 strumenti/Esegui_comando.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 valore_predefinito controllo_VALORE/데이터 포트와 겹치면 Esegui_comando 전에 거부한다.
