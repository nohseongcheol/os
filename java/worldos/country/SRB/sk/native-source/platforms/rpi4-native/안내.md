# Raspberry Pi 4 vlastné Java jadro_VALUE — používateľ Vykonať_príkaz 기반

v_termíne_splatnosti_položka vlastné 코드의 COSL 상업 podmienka, 제3자 고지 및 LGPL 재연결 자료는 [COSL 배포 안내](COSL배포안내.md)를 참고한다. SWITCH_MODE 전 GPL 구성의 판단은 [이전 라이선스 검토](licencia_recenzia.md)에 기록했다.

Slovenský 통신·výnimka 사용법은 [Slovenský Java API](한국어자바/안내.md), funkcia_VALUE·변수·Súbor 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

Linux 없이 부팅하는 vlastné AArch64 커널이다. Java AOT jadro_VALUE 위에 **príkazový_riadok 셸, 게스트 Java kompilátor·JVM, MicroPython, EL0 C++ Vykonať_príkaz, Súbor·UDP 루프백 시스템 호출, 여러 한글 GUI Terminál·vi Editor·Swing 부분집합**을 제공한다. 커널의 Súbor údaje/정책·루프백 prenos_VALUE·셸 상태는 Java, 화면 합성·pixel zmeniť_VALUE·ukazovateľ·클리핑도 Java로 구현하며, CPU/MMU/telefón_VALUE 경계와 Terminál·znak_VALUE 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 vlastné 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 Vykonať_príkaz, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 drôtový_VALUE 송수신은 아직 미검증이다.** Vykonať_príkaz·kontakt_e05f319b·heslo_VALUE 확인은 [externý_VALUE kontakt_e05f319b 안내](externý_kontakt_sprievodca.md)에 정리했다.

셸은 EL1 jadro_VALUE, `java` 등 používateľ Vykonať_príkaz 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 Vykonať_príkaz·kontakt_e05f319b 방법 및 skutočný_údaje 검증은
[Vykonať_príkaz 계층과 externý_VALUE 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 skutočný_údaje Vykonať_príkaz 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 정적 ELF는 `run --linux názov_súboru_SMS`으로 실행한다. [ELF·Linux ABI Podpora_VALUE 범위와 동일 바이너리 시험](실행파일규약.md).

GUI와 네트워크는 `python3 Nástroje/Vykonať_príkaz.py --desktop --network`로 함께 사용한다. Java·C·Python의 Slovenský 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 부팅 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 수 있다. Remmina에서 **F9/Shift+Space/한·영 Kľúč_VALUE**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·skutočný_údaje TCP/UDP·Súbor Byte_VALUE·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java UkážkaOkna`로 Slovenský Swing 예제를 실행한다. Terminál 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 v_termíne_splatnosti_položka COLUMN_VALUE·ROW_VALUE 수를 보여 준다.

## v_termíne_splatnosti_položka 컴퓨터에서 Vykonať_príkaz

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

Skončiť_program: **Ctrl+A Ďalej_položka X**. 게스트 C/AOT Nástroje 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. hostiteľ 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. kompilátor 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/Cesta/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` Podpora_VALUE 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 Vykonať_príkaz**한다. 기존 한 znak_VALUE 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 Argumenty 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

예를 들어 `edit 인사.java`를 입력한 Ďalej_položka 아래 소스를 입력한다.

```java
public class 인사 { public static void main(String[] args) { int VALUE = 7; System.out.println("한글=" + VALUE); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 인사.java`, `java 인사`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. zrušiť_operácia·잘못된 16진수·kapacita_VALUE 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, Vykonať_príkaz 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 Príkaz 인수는 최대 32개다. Citát·백슬래시·셸 변수·파이프·리다이렉션 범위는 [셸 설명](셸과터미널.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, adresa **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode vstup_VALUE·명시적 prilepiť_VALUE·Vykonať_príkaz 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 Nástroje/Vykonať_príkaz.py --desktop --network
# 다른 hardvér_port: python3 Nástroje/Vykonať_príkaz.py --desktop --port 5903
```

종료는 실행한 hostiteľ 터미널에서 Ctrl+C다. 기존 `python3 Nástroje/Vykonať_príkaz.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. skutočný_údaje Pi4 USB 입력기는 아직 없으며, VNC Pripojiť 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 skutočný_údaje C++/UDP ELF Vykonať_príkaz, `Hello.java` kompilovať_zdroj 후 JVM Vykonať_príkaz, `hello.py` Vykonať_príkaz, GUI Terminál 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 interaktívny 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 Pamäť_údaje·CPU 문맥을 보관한다. 셸·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

이미지는 확인된 공식 Pi 부팅 묶음에서 `start4.elf`, `fixup4.dat`, Pi4 DTB와 disable-bt overlay를 가져온다. Linux kernel/initramfs/rootfs는 넣지 않는다. 펌웨어·MicroPython·Terminál písmo_VALUE 라이선스와 písmo_VALUE 출처 해시도 동봉한다. Súbor generovať 스크립트는 물리 디스크에 기록하지 않는다.

예비 microSD에 zostava_IMAGE LOG_RECORD 도구로 `.img`를 기록하거나 FAT32 부팅 파티션 최상위에 ZIP 내용을 푼다. zostava_IMAGE 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 predvolená_hodnota EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD Súbor 구성·jadro_VALUE 체크섬 검사와 물리 Panel 부팅 검증은 별개다. MMU používať_VALUE 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 부팅 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

```cpp

```

[Súbor 예제](používateľ/UkážkaSúboru.cpp)와 [통신 예제](používateľ/통신예제.cpp)가 skutočný_údaje 부팅 시험 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 Súbor Proces_VALUE_položka 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 soket_VALUE 함수는 v_termíne_splatnosti_položka 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 jadro_VALUE 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 Ďalej_položka 도구를 사용하면 **새 QEMU를 부팅해 업로드한 skutočný_údaje 바이트를 재확인한 BACK_VALUE 게스트에서 Vykonať_príkaz**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

RAM 파일은 재부팅 시 사라진다. `potvrdenie_ukladací_priestor_súborov`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 povolenie_VALUE·dup/fcntl은 없다. 디렉터리와 partnerský_uzol_VALUE/절대 경로는 같은 RAM 저장소에서 처리한다.
