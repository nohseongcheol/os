# Slovenský Java 통신·vstup_a_výstup·výnimka API

패키지는 `Slovenský.vlastné`다. hostiteľ `javac --release 8`로 컴파일한 class를
vlastné ARM64 커널의 JVM에서 실행한다. 통신·Súbor·výnimka API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 vlákno_VALUE API는 vlastné JVM 전용이다.
기존 표준 Java knižnica 전체의 Slovenský 번역판은 아니다.

```java
import Slovenský.vlastné.*;

public class sieť {
    public static void main(String[] Argumenty) throws vstup_a_výstup_výnimka {
        kontakt Pripojiť = kontakt.Otvoriť("10.0.2.2", 9000);
        try {
            Pripojiť.TIMEOUT(700);
            Pripojiť.Výstup().Zápis(문자.kódovať("안녕하세요\n"));
            vstupný_prúd_údajov vstup_VALUE = Pripojiť.vstup_VALUE();
            Výstup.수쓰기(vstup_VALUE.Čítanie());
        } catch (počkaj_TIMEOUT_výnimka chyba) {
            Výstup.zapísať_linka(chyba.설명());
        } finally {
            Pripojiť.Zatvoriť();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
používateľ 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 reťazec_VALUE 리터럴에 사용하는 표준 클래스다. vlastné 실행기는 `public static void Spustiť_2()`도 진입점으로 받는다.

## 통신과 Stream_VALUE

| lekcia_VALUE | Slovenský 호출 |
|---|---|
| kontakt | `Otvoriť(adresa, číslo_portu)`, `vstup_VALUE()`, `Výstup()`, `TIMEOUT(밀리초)`, `číslo_portu()`, `miestny_číslo_portu()`, `연결됨()`, `닫힘()`, `Zatvoriť()` |
| dostať_port | `Otvoriť(číslo_portu)`, `dostať()`, `číslo_portu()`, `TIMEOUT(밀리초)`, `닫힘()`, `Zatvoriť()` |
| vstupný_prúd_údajov | `Čítanie()`, `Čítanie(byte[])`, `Čítanie(byte[], Spustiť_2, dĺžka_VALUE)`, `Zatvoriť()` |
| výstupný_prúd_údajov | `Zápis(int)`, `Zápis(byte[])`, `Zápis(byte[], Spustiť_2, dĺžka_VALUE)`, `내보내기()`, `Zatvoriť()` |
| datagram_Kanál | `Otvoriť(číslo_portu)`, `odoslať(adresa, číslo_portu, Spracovanie_textu)`, `dostať()`, `TIMEOUT(밀리초)`, `číslo_portu()`, `닫힘()`, `Zatvoriť()` |
| 연결통신 | `Otvoriť(...)`, `수신열기(...)`는 위 Slovenský 객체를 vrátiť_KR |
| 검사 | `참인지(podmienka, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`Čítanie()`의 Súbor 끝은 -1, pole_VALUE 읽기의 반환값은 skutočný_údaje 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. číslo_portu 0은 빈 번호를 자동 배정한다.
UDP 전문은 v_termíne_splatnosti_položka vlastné 커널에서 512바이트까지 받으며, 주소는 číslica_VALUE IPv4를 사용한다.
`localhost` 루프백 외의 Názov 풀이(DNS)는 vlastné 커널에 아직 없다.

기존 `연결통신.Pripojiť/načúvať_účastník/dostať`, `통신.Otvoriť/odoslať/dostať`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `kontakt`, `dostať_port`, `datagram_Kanál`를 쓴다.

## Slovenský výnimka

모든 아래 클래스는 predvolená_hodnota 생성자, `새예외("설명")` 형태의 reťazec_VALUE 생성자와
`설명()`을 제공한다. skutočný_údaje generovať 문법은 `new počkaj_TIMEOUT_výnimka("stav_čakania 끝")`이다.

| Slovenský výnimka | 상위 lekcia_VALUE / 용도 |
|---|---|
| výnimka | `java.lang.Exception`, 직접 던지는 일반 검사 výnimka |
| 실행예외 | `java.lang.RuntimeException` |
| vstup_a_výstup_výnimka | `java.io.IOException`, Slovenský Súbor·통신 API의 검사 výnimka |
| počkaj_TIMEOUT_výnimka | `vstup_a_výstup_výnimka`, 통신 TIMEOUT 초과 |
| adresa_LOOKUP_výnimka | `vstup_a_výstup_výnimka`, adresa overiť zlyhanie_VALUE |
| 파일없음예외 | `vstup_a_výstup_výnimka`, Súbor Otvoriť zlyhanie_VALUE |
| 통신예외 | `vstup_a_výstup_výnimka`, 표준 SocketException CONVERT_VALUE |
| neplatné_argument_výnimka | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `neplatné_argument_výnimka` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| NEPLATNÝ_zdroj_výnimka | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| Stav_výnimka | `java.lang.IllegalStateException` |
| Typ_vysielať_výnimka | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| pole_Store_zlyhanie | `java.lang.ArrayStoreException` |
| vlákno_Stav_výnimka | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 počkaj_VALUE 중단 |

`výnimka`와 `실행예외`는 모든 Slovenský 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, Súbor·통신 전체를 잡으려면 `catch (vstup_a_výstup_výnimka chyba)`를 쓴다.
Slovenský API가 표준 vstup_a_výstup 오류를 Slovenský 예외로 변환한다.
기존 Slovenský 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`počkaj_TIMEOUT_výnimka`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
výnimka 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
v_termíne_splatnosti_položka vlastné JVM에 이 20종을 추가했다. 임의의 používateľ Throwable 하위 lekcia_VALUE 전체를
지원하도록 확장했다는 뜻은 아니다.

## kompilovať_zdroj·Vykonať_príkaz

```sh
cd /home/user/jkoros/platforms/rpi4-native
make zostava_systém
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 Nástroje/Vykonať_Súbor.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 používateľ JVM ELF 안에 탑재된다. `.jar`는 hostiteľ javac의
lekcia_VALUE 경로로 사용한다. zdroj_strom 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 Slovenský 예외의 `throws` 선언과 그 import를 인식한다.
vlastné JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·objekt_VALUE·soket_VALUE 예제 전체의 zdroj_strom 컴파일은 hostiteľ javac를 사용한다.
`/example/java/UkážkaSúboru.java`는 게스트 javac로도 컴파일할 수 있다.

skutočný_údaje TCP/UDP 예제는 [UkážkaSiete.java](../../../example/java/UkážkaSiete.java),
Vykonať_príkaz 절차는 [example 안내](../../../example/README.md),
zdroj_strom 명명 원칙은 [명명 안내](../명명/안내.md)에 있다.

## Swing Okno 예제

`/example/java/UkážkaOkna.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` Ďalej_položka `java UkážkaOkna`로 연다. Názov vstup_VALUE, 인사하기 버튼,
인사말과 kliknúť_VALUE 횟수 obnoviť, X 닫기를 지원한다.

| 기능 | Slovenský 직접 API |
|---|---|
| Runnable / run | `실행할일.Spustiť()` |
| ActionListener / actionPerformed | `동작받이.dostať_Akcia(Akcia_upozornenie upozornenie)` |
| ActionEvent | `Akcia_upozornenie.príkaz_SMS()`, `zdroj_udalosti()`, `INDEX()` |
| JFrame | `Okno(okno_Názov, 폭, výška_VALUE)`, `Pridať_prvok(화면구성요소)`, `zobraziť_okno()`, `Zatvoriť()`, `보이는가()` |
| JButton | `Tlačidlo(Spracovanie_textu, 가로, vertikála_pozícia, 폭, výška_VALUE, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `Nápis(...)`, `textové_pole(...)` |
| 공통 화면 prvok_VALUE | `화면구성요소.글읽기()`, `zapísať_SMS(Spracovanie_textu)`, `자리정하기(가로, vertikála_pozícia, 폭, výška_VALUE)` |
| SwingUtilities.invokeLater | `udalosť_front.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `START_úloha()`, `기다리기()`, `살아있는가()`, `YIELD_úloha()` |
| 명령행 | `Spustiť_2()`, `실행인수.položka_COUNT()`, `실행인수.Spracovanie_textu(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
vlastné JVM의 `한국어화면호출`, `Proces_vlákno`가 Slovenský lekcia_VALUE·metóda_VALUE·서술자를
해석해 화면 요소와 Vykonať_príkaz 가닥을 직접 만든다. Akcia 알림도 vlastné 객체이며
콜백으로 `Spustiť`와 `dostať_Akcia`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 Vykonať_príkaz 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 vlastné JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 hostiteľ JVM에서 무동작 객체가 생기지 않도록 하는 odmietnuť_VALUE 경로다.
vlastné JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. hostiteľ javac로 컴파일한 BACK_VALUE vlastné JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import Slovenský.vlastné.*;
public class 가닥예제 implements 실행할일 {
    public void Spustiť() { Výstup.zapísať_linka("Slovenský 작업 Vykonať_príkaz"); }
    public static void Spustiť_2() throws 대기중단예외 {
        작업가닥 vlákno_VALUE = 작업.Spustiť_2(new 가닥예제());
        작업.기다리기(vlákno_VALUE);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
pole_VALUE Argumenty 대신 `실행인수`, 길이는 `문자.Byte_COUNT`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
vlastné 실행기는 Argumenty 없는 `Spustiť_2()`을 우선한다.
기존 Slovenský 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.Spustiť_2(Runnable)`을 사용하던 코드는 새 Slovenský 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API Podpora_VALUE 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 lekcia_VALUE·metóda_VALUE 이름과 서술자가 남는다.
Slovenský Názov 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·metóda_VALUE 재정의, native Pripojiť, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS identifikátor_VALUE](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS metóda_VALUE zdroj](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
