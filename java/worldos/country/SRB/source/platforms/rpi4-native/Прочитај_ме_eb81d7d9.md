# Raspberry Pi 4 자체 Java језгро_вриједност — корисник Изврши_команда 기반

актуелно_ставка 자체 코드의 COSL 상업 стање, 제3자 고지 및 LGPL 재연결 자료는 [COSL 배포 Прочитај_ме_eb81d7d9](COSL배포안내.md)를 참고한다. пребацити_мод 전 GPL 구성의 판단은 [이전 라이선스 검토](лиценца_коментар.md)에 기록했다.

한국어 통신·изузетак 사용법은 [한국어 Java API](한국어자바/Прочитај_ме_eb81d7d9.md), функција_вриједност·променљива_вриједност·Датотека 이름의 변경과 어원 근거는 [명명 Прочитај_ме_eb81d7d9](명명/Прочитај_ме_eb81d7d9.md)를 참고한다.

Linux 없이 부팅하는 자체 AArch64 커널이다. Java AOT језгро_вриједност 위에 **командни_ред љуска, 게스트 Java 컴파일러·JVM, MicroPython, EL0 C++ Изврши_команда, Датотека·UDP 루프백 시스템 호출, 여러 한글 GUI Терминал·vi уредник·Swing 부분집합**을 제공한다. 커널의 Датотека подаци/정책·루프백 пренос_вриједност·љуска 상태는 Java, 화면 합성·пиксел промијенити_вриједност·показивач·클리핑도 Java로 구현하며, CPU/MMU/уређај_вриједност 경계와 Терминал·знак_вриједност 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 자체 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 Изврши_команда, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 ожичен_вриједност 송수신은 아직 미검증이다.** Изврши_команда·веза_e05f319b·лозинка_вриједност 확인은 [екстерни_вриједност веза_e05f319b Прочитај_ме_eb81d7d9](екстерни_веза_водич.md)에 정리했다.

셸은 EL1 језгро_вриједност, `java` 등 корисник Изврши_команда 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 Изврши_команда·веза_e05f319b 방법 및 стваран_подаци 검증은
[Изврши_команда 계층과 екстерни_вриједност 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 стваран_подаци Изврши_команда 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 статични_вриједност ELF는 `run --linux фајл_име_Текст`으로 실행한다. [ELF·Linux ABI Подршка_вриједност 범위와 동일 바이너리 시험](실행파일규약.md).

GUI와 네트워크는 `python3 Алатке/Изврши_команда.py --desktop --network`로 함께 사용한다. Java·C·Python의 한국어 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 부팅 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 수 있다. Remmina에서 **F9/Shift+Space/한·영 Кључ_вриједност**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·стваран_подаци TCP/UDP·Датотека бајт_вриједност·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java 창예제`로 한국어 Swing 예제를 실행한다. Терминал 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 актуелно_ставка колона_вриједност·ред_вриједност 수를 보여 준다.

## актуелно_ставка 컴퓨터에서 Изврши_команда

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

Излаз_програм: **Ctrl+A Даље_ставка X**. 게스트 C/AOT Алатке 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. хост 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. 컴파일러 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/ПУТАЊА/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` Подршка_вриједност 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 Изврши_команда**한다. 기존 한 знак_вриједност 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 Аргументи 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

예를 들어 `edit 인사.java`를 입력한 Даље_ставка 아래 소스를 입력한다.

```java
public class 인사 { public static void main(String[] args) { int вриједност = 7; System.out.println("한글=" + вриједност); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 인사.java`, `java 인사`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. Откажи_операција·잘못된 16진수·капацитет_вриједност 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, Изврши_команда 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 Наредба 인수는 최대 32개다. Цитат·백슬래시·љуска променљива_вриједност·파이프·리다이렉션 범위는 [љуска 설명](셸과터미널.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, адреса **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode 입력·명시적 залијепити_вриједност·Изврши_команда 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 Алатке/Изврши_команда.py --desktop --network
# 다른 포트: python3 Алатке/Изврши_команда.py --desktop --port 5903
```

종료는 실행한 хост 터미널에서 Ctrl+C다. 기존 `python3 Алатке/Изврши_команда.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. стваран_подаци Pi4 USB 입력기는 아직 없으며, VNC Повежи_се 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 стваран_подаци C++/UDP ELF Изврши_команда, `Hello.java` направити_извор 후 JVM Изврши_команда, `hello.py` Изврши_команда, GUI Терминал 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 интерактивно 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 Меморија_подаци·CPU 문맥을 보관한다. љуска·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

이미지는 확인된 공식 Pi 부팅 묶음에서 `start4.elf`, `fixup4.dat`, Pi4 DTB와 disable-bt overlay를 가져온다. Linux kernel/initramfs/rootfs는 넣지 않는다. 펌웨어·MicroPython·Терминал фонт_вриједност 라이선스와 фонт_вриједност 출처 해시도 동봉한다. Датотека генерисати 스크립트는 물리 디스크에 기록하지 않는다.

예비 microSD에 градити_слика евиденција_ред 도구로 `.img`를 기록하거나 FAT32 부팅 파티션 최상위에 ZIP 내용을 푼다. градити_слика 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 задана_вриједност EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD Датотека 구성·језгро_вриједност 체크섬 검사와 물리 Табла 부팅 검증은 별개다. MMU 사용 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 부팅 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 한국어 API 사용

SDK를 풀고 호스트에서 컴파일한다.

```sh

python3 compile.py examples/파일예제.cpp -o demo.elf
```

진입점은 `extern "C" int Старт_корисник_програм(int)`이다. корисник C++는 FP/SIMD를 사용할 수 있다. језгро_вриједност C/Java AOT는 일반 레지스터만 사용하므로 изузетак Процес_вриједност_унос 중 корисник FP 상태를 건드리지 않는다. корисник унос_поен_вриједност 시 FP 상태를 초기화하고 језгро_вриједност 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int Старт_корисник_програм(int) {
    int Датотека = креирати_фајл("인사.txt", за_читање_писање | 없으면만들기 | 내용비우기, 0600);

    const char Садржај_вриједност[] = "안녕하세요";
    int ИСХОД = писати_фајл_подаци(Датотека, Садржај_вриједност, sizeof(Садржај_вриједност) - 1);
    затварање_фајл(Датотека);
    return ИСХОД == sizeof(Садржај_вриједност) - 1 ? 0 : 2;
}
```

[Датотека 예제](корисник/파일예제.cpp)와 [통신 예제](корисник/통신예제.cpp)가 стваран_подаци 부팅 시험 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 Датотека Процес_вриједност_унос 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 소켓 함수는 актуелно_ставка 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 језгро_вриједност 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 Даље_ставка 도구를 사용하면 **새 QEMU를 부팅해 업로드한 стваран_подаци 바이트를 재확인한 НАЗАД_вриједност 게스트에서 Изврши_команда**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 Алатке/Изврши_фајл.py build/jkoros-native-sdk/demo.elf
python3 Алатке/Изврши_фајл.py 예제/Hello.java "한글 Аргументи"
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 језгро_вриједност 묶음에 포함되어 이 Датотека 한도를 적용받지 않는다. **C++ 컴파일러는 хост SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 библиотека, PT_TLS, PT_INTERP, PT_DYNAMIC, Изврши_команда·Пише 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 индекс·адреса клип·오류는 [корисник ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `파일저장확정`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 дозвола_вриједност·dup/fcntl은 없다. 디렉터리와 상대/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, 수신 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. корисник Излаз_програм 시 열린 Датотека 서술자와 소켓을 회수한다.

## Java와 Python의 정확한 клип

자체 `javac`는 버전 49 `.class`를 생성하며 JVM은 Подршка_вриједност 명령으로 구성된 버전 45–52 클래스를 실행한다. статични_вриједност функција_вриједност·재귀·int/boolean/char/String·стање/спринт_вриједност·ниска_вриједност 결합과 일부 Датотека 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/조합 자모 식별자를 처리한다. Unicode идентификатор_вриједност 전체 Претрага_табела·Unicode извор_стабло 이스케이프는 구현하지 않았다. 게스트 извор_стабло 컴파일러는 일반 објекат_вриједност·изузетак·Thread 구문을 아직 컴파일하지 못한다. хост `javac --release 8`로 만든 Подршка_вриједност 부분집합 클래스는 자체 JVM 0.4의 објекат_вриједност·изузетак·Thread·UDP와 한국어 API를 사용할 수 있다. Swing은 문서화한 자체 API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [자체 JVM 설명](자바실행환경.md)이 기준이다. 상세 Језик 범위는 [공유 Java Алатке 설명](../../문서/자바개발환경.md)을 참고하되, 그 문서의 x86 љуска/похранити_вриједност/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 извор_стабло**를 자체 AArch64 EL0/SVC 대상으로 빌드했다. ## 한국어 C тип_података·Python ГРЕШКА·пакет инсталирај_вриједност

C 네트워크 API는 `struct 인터넷통신주소`, enum 상수와 стваран_подаци 한국어 함수로
구현한다. макро_вриједност 별칭을 사용하지 않으며 이전 pk_* ABI도 유지한다.
Python 예제는 `систем_грешка`, `ГРЕШКА.индекс`, `ГРЕШКА.설명`을 사용한다.

`python3 Алатке/Изврши_команда.py --desktop --network --pip`로 시작하면 게스트에서
`pip install micropython-bisect==3.3.3`을 사용할 수 있다. 현재는 хост 중계를
이용하는 제한형 MicroPython извор_стабло 설치기이며 CPython pip·자동 의존성 해결·C 확장은
미지원이다. 설치한 `/lib` 자료는 RAM이다. [사용법과 제한](파이썬꾸러미.md).

## 화면 Величина избор_вриједност

`python3 Алатке/Изврши_команда.py --desktop --network --resolution 1920x1080`으로 Full HD 화면을 사용한다. 기본값은 640×480이며 1280×720도 가능하다.
