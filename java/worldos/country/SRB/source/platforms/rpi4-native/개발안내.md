# 자체 커널에서 vi·여러 Терминал·한글 프로그래밍 사용하기

한국어 통신·изузетак 사용법은 [한국어 Java API](한국어자바/Прочитај_ме_eb81d7d9.md), функција_вриједност·променљива_вриједност·Датотека 이름의 변경과 어원 근거는 [명명 Прочитај_ме_eb81d7d9](명명/Прочитај_ме_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 자체 AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 Подршка_вриједност 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 Изврши_команда, екстерни_вриједност TCP/UDP와 FTP는 [새 Изврши_команда 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 Терминал

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, адреса **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 Терминал 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **오른쪽 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 Изврши_команда 버튼으로 다시 колона_вриједност 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 актуелно_ставка 디렉터리, љуска променљива_вриједност, Наредба евиденција_ред, 입력 중인 명령과 програм_f5044b9b Изврши_команда 상태를 보관한다. Датотека 저장소는 공유한다. vi와 Swing의 이벤트 чекај_вриједност 중에 다른 터미널로 전환하면 корисник Меморија_подаци·레지스터·Датотека/소켓 연결을 보존했다가 돌아올 때 재개한다. **актуелно_ставка 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 Даље_ставка 입력 чекај_вриједност 또는 기존 Изврши_команда 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 Изврши_команда 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 Уреди_вриједност 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. актуелно_ставка 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 Прозор 판단은 게스트 커널이 처리한다. QEMU Изврши_команда 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. стваран_подаци Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI Алатке 종료는 хост 터미널의 Ctrl+C다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **језгро_вриједност 내부 연결형 бајт_вриједност ток_вриједност**을 추가했다. Датотека/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket сервер_вриједност = new java.net.ServerSocket(9250);
java.net.Socket гост_вриједност = new java.net.Socket("localhost", 9250);
java.net.Socket Повежи_се = сервер_вриједност.accept();
гост_вриједност.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int дужина_вриједност = Повежи_се.getInputStream().read(받은것);
Повежи_се.close(); гост_вриједност.close(); сервер_вриједност.close();
```

генерисати·Повежи_се·accept·양방향 бајт_вриједност/низ_вриједност У_И·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 завршити_поен 16개, 수신 버퍼당 1024바이트, чекај_вриједност Повежи_се 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. задана_вриједност време_вриједност 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM Наредба 수/језгро_вриједност Изврши_команда 기한은 여전히 적용된다.

екстерни_вриједност цифра_вриједност IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. стваран_подаци Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP библиотека 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 стваран_подаци 송수신·EOF·기한·Повежи_се 회수의 시험 예제다.

## C·C++에서 posix-kor 호출

두 Језик 모두 한국어 헤더와 функција_вриједност 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 стваран_подаци EL0 Изврши_команда 시험 대상이다.

[ток_вриједност.c](예제/한글코딩/ток_вриједност.c)는 C에서 한국어 이름으로 Повежи_се·accept·부분 Чита/Пише·큐 포화·EOF를 처리하는 Изврши_команда 예제다. SDK의 `examples/ток_вриједност.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → стваран_подаци 한국어 C функција_вриједност 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·показивач 검사 → Java RAM Датотека/루프백 또는 екстерни_вриједност lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 језгро_вриједност 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 Повежи_се, 표준 C printf, libstdc++/STL, изузетак·RTTI는 제공하지 않으며 C++의 статични_вриједност 생성자·локални_обим објекат_вриједност 소멸자는 지원한다. 상세 индекс·Меморија_подаци 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.
