# 자체 ARM64 језгро_вриједност: FTP, C, JAR와 AOT Изврши_команда

대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT језгро_вриједност**이다. CPU·уређај_вриједност 경계는 C/어셈블리, Датотека 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 хост JVM으로 대신 실행하지 않는다.

JVM은 класа_вриједност 버전 45…52의 문서화한 부분집합이다. `java`는 바이트코드 실행기이고, `jaot`가 별도의 네이티브 Изврши_команда 파일을 만든다. **JAR Архива_вриједност 해제나 JVM을 함께 묶는 것을 AOT라고 표시하지 않는다.** 지원하지 않는 바이트코드/API는 `jaot`가 진단하고 출력을 만들지 않는다. 기존 Излаз ELF도 направити_извор неуспјех_вриједност 때 보존한다.

Android의 Dalvik/ART는 일반 JVM класа_вриједност/JAR가 아닌 **DEX**를 실행한다. ART의 AOT에는 GC, класа_вриједност 로딩, JNI 등 Изврши_команда 기반도 필요하다. 따라서 ART처럼 기계어로 바꾸는 기능만으로 임의의 OpenJDK JAR 및 Swing이 자동 호환되지는 않는다. [Android 공식 런타임 설명](https://source.android.com/docs/core/runtime)

## 한국어 Java를 게스트에서 컴파일하고 AOT Изврши_команда

게스트 `vi 빛.java`로 Даље_ставка 소스를 작성한다.

```java

    public static void main(String[] Аргументи) throws Exception {
        int 합 = 0;
        int 수 = 1;
        while (수 <= 10) {
            합 = 합 + 수;
            수 = 수 + 1;
        }
        한국어.자체.Излаз.수쓰기(합);
```


`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 генерисати·연결한다. Изврши_команда 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 Подршка_вриједност 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 статични_вриједност метода_вриједност/поље_вриједност, int 계열, цијели_број 배열과 Литература, Аргументи низ_вриједност, стање·грана·спринт_вриједност, ниска_вриједност 리터럴, `System.out.print/println`의 int/String, 한국어 Излаз·Датотека Чита/쓰기로 제한된다. класа_вриједност/метода_вриједност 수와 операнд_комплет 등에도 고정 상한이 있다. Java изузетак Процес_вриједност_унос, објекат_вриједност генерисати, 가상 метода_вриједност 일반, switch/wide, long/float/double, invokedynamic, ниска_вриједност 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 низ_вриједност приступ_унос/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java изузетак 객체로 전달하지 않는다.

입력 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 поравнати_вриједност 때문에 짧은 클래스도 이 한도를 넘을 수 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 објекат_вриједност·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 Подршка_вриједност клип 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 개발 매뉴얼](개발안내.md)을 참고한다.

JAR는 하나의 애플리케이션 класа_вриједност 경로다. 내부 Назив `пакет/програм_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 한국어 클래스를 추가로 찾지만 актуелно_ставка 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·шифровати_подаци ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 수/VM 힙 제한은 그대로 적용된다.

C/C++ хост SDK Изврши_команда 파일도 FTP로 업로드 후 `run` 또는 `./Датотека`로 실행하며 확장자는 필요 없다. Linux ARM64 статични_вриједност ELF에는 별도의 제한된 호환 ПУТАЊА `run --linux Датотека`을 추가했다. ## 한국어 네트워크·작업·화면 API

| класа_вриједност | 호출 예 | Изврши_команда ПУТАЊА |
|---|---|---|
| `Излаз` | `писати_редак("안녕")`, `수쓰기(42)` | JVM 및 제한형 AOT |
| `Датотека` | `Пише("문서.txt", "Садржај_вриједност")`, `Чита("문서.txt")` | JVM 및 제한형 AOT |
| `통신` | `Отвори(0)`, `послати(крајња_тачка, "10.0.2.2", 9000, "한글")`, `받기(крајња_тачка)` | JVM의 UDP |
| `연결통신` | `Повежи_се("10.0.2.2", 9000)`, `слушати_крајња_тачка(9000)`, `받기(сервер_вриједност)` | JVM의 Socket/ServerSocket |
| `작업` | `Покрени(Runnable)`, `기다리기(Thread)`, `обуставити_задатак()` | JVM의 협력식 нит_вриједност |
| `Прозор`, `виџет` | Прозор·버튼·знак_вриједност·текстуално_поље·Догађај Повежи_се | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 한국어 호출 계층을 추가한다. `통신(通信)`, `Повежи_се(連結)`, `Излаз(出力)`은 기존 단어의 뜻을 사용한다. `작업 нит_вриједност`은 한 Изврши_команда 흐름을 가닥에 빗댄 기술 표현, `порт_вриједност`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

екстерни_вриједност 주소는 цифра_вриједност IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 자체 ABI이며 JVM이 제한된 чекај_вриједност/재시도를 제공한다. TCP connect 대기는 최대 1초, корисник програм_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 Изврши_команда корисник 서버와 pthread는 아직 없다. FTP는 корисник програм_f5044b9b 기한과 별개인 језгро_вриједност 서비스다.

게스트의 корисник TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 Алатке/Изврши_команда.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 задана_вриједност контрола_вриједност/데이터 포트와 겹치면 Изврши_команда 전에 거부한다.
