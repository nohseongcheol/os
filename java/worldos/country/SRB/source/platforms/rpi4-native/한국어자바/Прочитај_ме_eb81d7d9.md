# 한국어 Java 통신·У_И·изузетак API

패키지는 `한국어.자체`다. хост `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·Датотека·изузетак API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 нит_вриједност API는 자체 JVM 전용이다.
기존 표준 Java библиотека 전체의 한국어 번역판은 아니다.

```java
import 한국어.자체.*;

public class Мрежа {
    public static void main(String[] Аргументи) throws У_И_изузетак {
        веза Повежи_се = веза.Отвори("10.0.2.2", 9000);
        try {
            Повежи_се.대기시간(700);
            Повежи_се.Излаз().Пише(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = Повежи_се.입력();
            Излаз.수쓰기(입력.Чита());
        } catch (대기시간초과예외 ГРЕШКА) {
            Излаз.писати_редак(ГРЕШКА.설명());
        } finally {
            Повежи_се.Затворен();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
корисник 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 ниска_вриједност 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void Покрени()`도 진입점으로 받는다.

## 통신과 ток_вриједност

| класа_вриједност | 한국어 호출 |
|---|---|
| веза | `Отвори(адреса, број_порта)`, `입력()`, `Излаз()`, `대기시간(밀리초)`, `број_порта()`, `локални_број_порта()`, `연결됨()`, `닫힘()`, `Затворен()` |
| 수신창구 | `Отвори(број_порта)`, `받기()`, `број_порта()`, `대기시간(밀리초)`, `닫힘()`, `Затворен()` |
| 입력흐름 | `Чита()`, `Чита(byte[])`, `Чита(byte[], Покрени, дужина_вриједност)`, `Затворен()` |
| 출력흐름 | `Пише(int)`, `Пише(byte[])`, `Пише(byte[], Покрени, дужина_вриједност)`, `내보내기()`, `Затворен()` |
| 전문통로 | `Отвори(број_порта)`, `послати(адреса, број_порта, Текст)`, `받기()`, `대기시간(밀리초)`, `број_порта()`, `닫힘()`, `Затворен()` |
| 연결통신 | `Отвори(...)`, `수신열기(...)`는 위 한국어 객체를 вратити_мера |
| 검사 | `참인지(стање, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`Чита()`의 Датотека 끝은 -1, низ_вриједност 읽기의 반환값은 стваран_подаци 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. број_порта 0은 빈 번호를 자동 배정한다.
UDP 전문은 актуелно_ставка 자체 커널에서 512바이트까지 받으며, 주소는 цифра_вриједност IPv4를 사용한다.
`localhost` 루프백 외의 Назив 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.Повежи_се/слушати_крајња_тачка/받기`, `통신.Отвори/послати/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `веза`, `수신창구`, `전문통로`를 쓴다.

## 한국어 изузетак

모든 아래 클래스는 задана_вриједност 생성자, `새예외("설명")` 형태의 ниска_вриједност 생성자와
`설명()`을 제공한다. стваран_подаци генерисати 문법은 `new 대기시간초과예외("чекај_стање 끝")`이다.

| 한국어 изузетак | 상위 класа_вриједност / 용도 |
|---|---|
| изузетак | `java.lang.Exception`, 직접 던지는 일반 검사 изузетак |
| 실행예외 | `java.lang.RuntimeException` |
| У_И_изузетак | `java.io.IOException`, 한국어 Датотека·통신 API의 검사 изузетак |
| 대기시간초과예외 | `У_И_изузетак`, 통신 대기시간 초과 |
| адреса_Претрага_изузетак | `У_И_изузетак`, адреса потврдити неуспјех_вриједност |
| 파일없음예외 | `У_И_изузетак`, Датотека Отвори неуспјех_вриједност |
| 통신예외 | `У_И_изузетак`, 표준 SocketException конвертовати_вриједност |
| неважеће_аргумент_изузетак | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `неважеће_аргумент_изузетак` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| без_вредности_Литература_изузетак | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| стање_изузетак | `java.lang.IllegalStateException` |
| тип_Емитовање_изузетак | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| низ_похранити_неуспјех | `java.lang.ArrayStoreException` |
| нит_стање_изузетак | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 чекај_вриједност 중단 |

`изузетак`와 `실행예외`는 모든 한국어 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, Датотека·통신 전체를 잡으려면 `catch (У_И_изузетак ГРЕШКА)`를 쓴다.
한국어 API가 표준 У_И 오류를 한국어 예외로 변환한다.
기존 한국어 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
изузетак 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
актуелно_ставка 자체 JVM에 이 20종을 추가했다. 임의의 корисник Throwable 하위 класа_вриједност 전체를
지원하도록 확장했다는 뜻은 아니다.


내장 라이브러리는 корисник JVM ELF 안에 탑재된다. `.jar`는 хост javac의
класа_вриједност 경로로 사용한다. извор_стабло 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 한국어 예외의 `throws` 선언과 그 import를 인식한다.

try/catch·објекат_вриједност·소켓 예제 전체의 извор_стабло 컴파일은 хост javac를 사용한다.

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` Даље_ставка `java 창예제`로 연다. Назив 입력, 인사하기 버튼,
인사말과 клик_вриједност 횟수 освежити, X 닫기를 지원한다.

| 기능 | 한국어 직접 API |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `Процес_нит`가 한국어 класа_вриједност·метода_вриједност·서술자를
해석해 화면 요소와 Изврши_команда 가닥을 직접 만든다. радња 알림도 자체 객체이며
콜백으로 `Изврши`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 Изврши_команда 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 хост JVM에서 무동작 객체가 생기지 않도록 하는 одбацити_вриједност_e3ecc00b 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. хост javac로 컴파일한 НАЗАД_вриједност 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import 한국어.자체.*;
public class 가닥예제 implements 실행할일 {
    public void Изврши() { Излаз.писати_редак("한국어 작업 Изврши_команда"); }
    public static void Покрени() throws 대기중단예외 {
        작업가닥 нит_вриједност = 작업.Покрени(new 가닥예제());
        작업.기다리기(нит_вриједност);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
низ_вриједност Аргументи 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 Аргументи 없는 `Покрени()`을 우선한다.
기존 한국어 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.Покрени(Runnable)`을 사용하던 코드는 새 한국어 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API Подршка_вриједност 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 класа_вриједност·метода_вриједност 이름과 서술자가 남는다.
한국어 Назив 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·метода_вриједност 재정의, native Повежи_се, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS идентификатор_вриједност](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS метода_вриједност Литература](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
