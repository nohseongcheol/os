# 자체 ARM64 Java 커널의 C/C++ Датотека·루프백 Повежи_се

이 디렉터리는 `platforms/rpi4-native` 자체 језгро_вриједност 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 한국어 함수명과 `extern "C"` ABI를 제공한다. `Повежи_се.c`는 језгро_вриједност 안에서 AOT Java Датотека 메서드에 직접 연결하고, `корисник_мост.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. стваран_подаци Датотека 처리는 `Меморија_Фајлови.java`, 루프백 전문 처리는 `되돌림망.java`, 연결형 흐름은 `ток_Мрежа.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 језгро_вриједност 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·плутајући_поен_вриједност операција_вриједност·Датотека·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

Подршка_вриједност: `креирати_фајл`, `파일자료읽기`, `писати_фајл_подаци`, `затварање_фајл`, `тражити_фајл`, `уклонити_фајл_унос_име`, `скуп_фајл_дужина`, 보조 функција_вриједност `фајл_подесити_величину`. ГРЕШКА 시 -1과 작업별 `број_грешке`를 반환한다. `파일저장확정`은 RAM 파일이므로 ENOSYS를 반환한다. Датотека 16개, 각 16384바이트, Назив 63바이트, 서술자 16개이며 RAM 디렉터리·상대/절대 경로를 제공한다. дозвола_вриједност/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 стваран_подаци 한국어 함수와 독립 구조체를 선언한다.
`Направи_крајња_тачка`, `повезати_адреса`, `자료전문보내기/받기`, `ПОВЕЖИ_Мрежа/기다리기/받기`는
`корисник_мост.c`에서 SVC를 호출하며 макро_вриједност 별칭이 아니다. `struct 인터넷통신주소`의
`адреса_Породица`, `број_порта`, `интернетска_адреса.адреса_вриједност`을 사용한다. 상수는 enum의
`облак_Породица`, `전문통신`, `전문전송규약`, `ток_Мрежа`, `ток_протокол_преноса`이다.
한국어·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. екстерни_вриједност 통신은 자체 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. стваран_подаци Pi 4 GENET 드라이버는 미지원이다.
소켓도 стваран_подаци функција_вриједност `затварање_фајл`로 닫는다.
