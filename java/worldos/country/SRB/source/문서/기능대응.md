## 기존 објекат_вриједност 기반 관리 језгро_вриједност 전체를 부팅하기 위해 남은 Повежи_се

Даље_ставка 항목은 Java 문법만으로 실행할 수 없는 CPU/уређај_вриједност 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot унос_поен_вриједност, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 Контекст_вриједност похранити_вриједност
- стваран_подаци PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA петља_вриједност
- Java објекат_вриједност·низ_вриједност Веза_изглед, изузетак, статични_вриједност иницијализовати, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT фаза_вриједност
- FAT 디스크 구역을 стваран_подаци ATA 장치와 연결하는 У_И 접착 слој_вриједност

위 관리 계층은 engos 기능의 Java 관리 구현과 хост 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot унос_поен_вриједност, статични_вриједност иницијализовати·цијели_број низ_вриједност, VGA/직렬/PS2, 명령해석기, корисник ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 хост 루프백 패킷 왕복을 검증했다. 위 표의 објекат_вриједност 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
