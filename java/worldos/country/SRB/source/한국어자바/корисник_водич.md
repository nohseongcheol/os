# jkoros 한국어 библиотека корисник_водич

확인일: 2026-09-27. 대상은 `platforms/rpi4`의 **ARM64 Linux + OpenJDK 실행판**이며, QEMU에서도 같은 Java 라이브러리를 사용한다. `os/`의 자체 x86 језгро_вриједност 및 `наслијеђе_извор/`의 관리 језгро_вриједност 모형과 구분한다.

## 1. актуелно_ставка 제공하는 библиотека

패키지는 `한국어.자바`, оперативни_систем 안의 JAR 경로는 `/opt/jkoros/lib/한국어자바.jar`다. **도우미 класа_вриједност 5개, 공개 статични_вриједност метода_вриједност 22개, 별도 GUI 프로그램인 радни_сто 1개**가 있다. JAR는 Java 11 이상을 대상으로 빌드하며 актуелно_ставка ARM64 배포판에는 OpenJDK 25가 포함돼 있다.

| класа_вриједност | метода_вриједност 수 | 기능 | ИЗВОР |
|---|---:|---|---|
| `Датотека` | 9 | UTF-8 텍스트·бајт_вриједност Датотека, именик_вриједност, унос_Листа | [Датотека.java](ИЗВОР/한국어/자바/Датотека.java) |
| `문자` | 5 | UTF-8 конвертовати_вриједност, NFC нормализовати_вриједност, шифра_вриједност 포인트, ниска_вриједност 경계 | [문자.java](ИЗВОР/한국어/자바/문자.java) |
| `통신` | 2 | HTTP(S) GET, TCP Повежи_се | [통신.java](ИЗВОР/한국어/자바/통신.java) |
| `작업` | 4 | 스레드 Изврши_команда·чекај_вриједност, 고정 Величина 작업 програм_покретач | [작업.java](ИЗВОР/한국어/자바/작업.java) |
| `화면` | 2 | Swing 이벤트 Процес_вриједност_унос 가닥에 작업 예약, Прозор генерисати | [화면.java](ИЗВОР/한국어/자바/화면.java) |
| `радни_сто` | унос_поен `main` | Java ИЗВОР Уреди_вриједност·похранити_вриједност·направити_извор·Изврши_команда | [радни_сто.java](ИЗВОР/한국어/자바/радни_сто.java) |

표준 JDK 전체를 한국어로 번역한 라이브러리는 아니다. Java 키워드와 `String`, `Path`, `Socket`, `JFrame`, `IOException` 같은 표준 тип_података·예외를 함께 사용한다. 이 도우미에 없는 기능은 OpenJDK의 표준 API 또는 별도 라이브러리로 구현한다. 예를 들어 HTTP POST, UDP, Swing дугме·메뉴에는 각각 표준 Java API를 사용한다.

## 2. Java에서 Старт_задатак

게스트 운영체제의 작업 폴더에서 `사용예.java`를 작성한다.

```java
import 한국어.자바.*;
import java.nio.file.Path;

public class 사용예 {
    public static void main(String[] Аргументи) throws Exception {
        Path именик_вриједност = Датотека.Направи_именик(Датотека.ПУТАЊА("사용예자료"));
        Path 문서 = именик_вриједност.resolve("인사.txt");
        Датотека.Пише(문서, "한글 😀");
        String Садржај_вриједност = Датотека.Чита(문서);
        System.out.println(Садржај_вриједност);
        System.out.println(문자.코드포인트수(Садржај_вриједност)); // 한, Текст, 공백, 😀 → 4
        Thread рад_вриједност = 작업.Покрени("인사 작업", () -> System.out.println("작업 Изврши_команда"));
        작업.기다리기(рад_вриједност);
    }
}
```

```sh
javac -encoding UTF-8 -cp /opt/jkoros/lib/한국어자바.jar 사용예.java
java -cp .:/opt/jkoros/lib/한국어자바.jar 사용예
```

로그인 환경에 задана_вриједност `CLASSPATH`도 설정돼 있지만, 명시적인 `-cp`는 다른 Изврши_команда 환경에서도 경로를 분명하게 한다. 사용자가 `-cp`를 지정하면 필요한 JAR와 класа_вриједност 폴더를 모두 그 값에 포함해야 한다.

хост 저장소에서는 다음처럼 градити_систем·실행한다. хост 경로와 게스트의 `/opt/...` 경로는 서로 다르다.

```sh
cd /home/user/jkoros/한국어자바
make
javac -encoding UTF-8 -cp build/한국어자바.jar 예제/인사.java
java -cp build/한국어자바.jar:예제 인사
```

## 3. 전체 도우미 API

아래 메서드는 모두 `public static`이며, 객체를 만들지 않고 `Датотека.Чита(...)`처럼 호출한다. 표의 이름은 стваран_подаци извор_стабло 및 JAR의 `javap -public` 결과와 대조했다. 선언된 검사 изузетак 외에도 잘못된 Аргументи 등에 대한 표준 Java Изврши_команда 시 예외가 발생할 수 있다.

### Датотека: `한국어.자바.Датотека`

`Path`는 `java.nio.file.Path`, `List`는 `java.util.List`다.

| метода_вриједност | вратити_тип | радња·стање |
|---|---|---|
| `ПУТАЊА(String Назив)` | `Path` | 이름을 ПУТАЊА 객체로 конвертовати_вриједност. стваран_подаци 파일을 만들지는 않음 |
| `Чита(Path ПУТАЊА)` | `String` | Датотека 전체를 UTF-8 텍스트로 읽음 |
| `Пише(Path ПУТАЊА, String Садржај_вриједност)` | `Path` | UTF-8 похранити_вриједност. 파일이 없으면 생성하고, 있으면 기존 내용을 비움 |
| `바이트읽기(Path ПУТАЊА)` | `byte[]` | Датотека 전체를 бајт_вриједност 배열로 읽음 |
| `писати_бајт_вриједност(Path ПУТАЊА, byte[] Садржај_вриједност)` | `Path` | бајт_вриједност похранити_вриједност. 없으면 생성하고, 있으면 기존 내용을 비움 |
| `Направи_именик(Path ПУТАЊА)` | `Path` | 필요한 상위 폴더까지 генерисати |
| `있는가(Path ПУТАЊА)` | `boolean` | 존재 여부 потврдити. 확인할 수 없는 경우도 `false`рад_вриједност 수 있음 |
| `지우기(Path ПУТАЊА)` | `boolean` | 삭제했으면 `true`, 없으면 `false`. 폴더의 재귀 삭제는 아님 |
| `унос_Листа(Path ПУТАЊА)` | `List<Path>` | 바로 아래 항목을 ПУТАЊА поравнати_вриједност 순서로 вратити_мера. 재귀 탐색은 아님 |

`ПУТАЊА`, `있는가`를 제외한 위 메서드는 `IOException`을 선언한다. `Пише`와 `писати_бајт_вриједност`는 상위 폴더를 자동으로 만들거나 내용을 이어 쓰지 않는다. 필요한 폴더는 먼저 생성한다. 큰 파일은 전체 내용을 메모리에 담는 대신 표준 Java 스트림·Канал_вриједност API를 사용하는 방식으로 작성할 수 있다.

### 문자: `한국어.자바.문자`

| метода_вриједност | вратити_тип | радња·стање |
|---|---|---|
| `부호화(String Садржај_вриједност)` | `byte[]` | 문자열을 UTF-8 바이트로 конвертовати_вриједност |
| `дешифровати_подаци(byte[] Садржај_вриједност)` | `String` | UTF-8 바이트를 문자열로 конвертовати_вриједност. 잘못된 입력은 대체 문자로 Процес_вриједност_унос |
| `нормализовати_вриједност(String Садржај_вриједност)` | `String` | Уникод_вриједност NFC нормализовати_вриједност. 예: 조합 자모 `ᄀ` + `ᅡ` → `가` |
| `코드포인트수(String Садржај_вриједност)` | `int` | UTF-16 шифра_вриједност 단위가 아닌 Уникод_вриједност шифра_вриједност 포인트 수 |
| `낱말(String Садржај_вриједност, Locale Језик)` | `List<String>` | Додели_вриједност 언어의 `BreakIterator` 낱말 경계로 나눈 Текст_опсег |

`낱말`은 공백·문장부호 구간도 반환한다. 자연어 형태소 분석기나 공백을 제거한 Укрштенице_вриједност унос_Листа API는 아니다. `нормализовати_вриједност`는 입력기나 превести_извор 기능이 아니다. шифра_вриједност 포인트 수 역시 사람이 보는 знак_вриједност 수와 항상 같지는 않다. 여러 шифра_вриједност 포인트로 이루어진 결합 문자·가족 이모지 등을 구분해야 한다.

### 통신: `한국어.자바.통신`

| метода_вриједност | вратити_тип | радња·стање |
|---|---|---|
| `가져오기(URI адреса, Duration временско_ограничење)` | `HttpResponse<String>` | HTTP(S) GET. Повежи_се 및 захтев временско_ограничење Поставке. одговор 본문을 UTF-8로 рашчланити_вриједност |
| `ПОВЕЖИ_крајња_тачка(String адреса, int 포트, int 제한밀리초)` | `Socket` | TCP Повежи_се 후 같은 값으로 Чита 제한시간도 Поставке |

`가져오기`는 `IOException`, `InterruptedException`을 선언한다. 제한시간은 양수다. 404·500 같은 HTTP ГРЕШКА 상태도 응답으로 반환하므로 `statusCode()`로 판단하고 `body()`로 본문을 읽는다. актуелно_ставка 구현은 호출마다 HTTP 클라이언트를 만들며 자동 리다이렉트 설정을 추가하지 않는다.

`ПОВЕЖИ_крајња_тачка`는 `IOException`을 선언한다. 연결된 소켓은 호출자가 `close()` 또는 try-with-resources로 닫아야 한다. 제한밀리초의 0은 제한 없음이며, Пише 전체의 마감 시간을 보장하는 옵션은 아니다.

```java
var одговор = 통신.가져오기(
    java.net.URI.create("http://127.0.0.1:8000/"),
    java.time.Duration.ofSeconds(5));
System.out.println(одговор.statusCode());
System.out.println(одговор.body());
```

위 조각은 метода_вриједност 안에서 실행하며 별도로 해당 주소의 서버를 실행해야 한다. Java изузетак 처리가 필요하다.

### 작업: `한국어.자바.작업`

| метода_вриједност | вратити_тип | радња·стање |
|---|---|---|
| `Покрени(String Назив, Runnable радња)` | `Thread` | 이름을 지정한 스레드를 만들고 즉시 Покрени |
| `기다리기(Thread нит_вриједност)` | `void` | 해당 스레드가 종료할 때까지 `join()` |
| `쉬기(long 밀리초)` | `void` | 호출한 스레드를 Додели_вриједност време_вриједност 동안 `sleep()` |
| `작업대(int 가닥수)` | `ExecutorService` | 고정 Величина 작업 програм_покретач генерисати. 가닥수는 양수 |

`기다리기`, `쉬기`는 `InterruptedException`을 선언한다. 작업 실행기는 사용 후 `shutdown()`으로 종료하고 필요하면 `awaitTermination(...)`으로 완료를 기다린다. Swing 이벤트 Процес_вриједност_унос 가닥에서 긴 작업이나 `기다리기`를 실행하면 화면이 멈출 수 있다.

### 화면: `한국어.자바.화면`

| метода_вриједност | вратити_тип | радња·стање |
|---|---|---|
| `나중에(Runnable радња)` | `void` | Swing 이벤트 Процес_вриједност_унос 가닥에 실행을 예약하고 вратити_мера |
| `Прозор(String прозор_Наслов, JComponent Садржај_вриједност, int 너비, int 높이)` | `JFrame` | Садржај_вриједност·크기를 지정한 창을 생성해 емисија_вриједност |

`Прозор`을 Swing 이벤트 Процес_вриједност_унос нит_вриједност 밖에서 부르면 `IllegalStateException`이 발생한다. 그래픽 세션도 필요하다. QEMU에서는 VNC 데스크톱의 터미널에서 실행한다.

```java
화면.나중에(() -> 화면.Прозор(
    "한국어 화면", new javax.swing.JLabel("안녕하세요"), 500, 180));
```

반환된 `JFrame`에 표준 Swing API를 추가로 사용할 수 있다. 창의 Затворен 동작은 `DISPOSE_ON_CLOSE`다. `화면.나중에`가 반환됐다고 Прозор 생성이 이미 끝난 것은 아니다.

### радни_сто: Уреди_вриједност·направити_извор GUI

```sh
java -cp /opt/jkoros/lib/한국어자바.jar 한국어.자바.радни_сто
```

`~/workspace`의 원문을 Отвори·저장하고, `javac`로 컴파일해 `java`로 실행한다. Изврши_команда Датотека 만들기는 `jclassc --target openjdk` 경로를 사용한다. 작업마당은 개발용 프로그램이며 별도의 Датотека·문자 API 클래스가 아니다. 생성하는 Изврши_команда Датотека 방식은 [컴파일러 설명](../compiler/OpenJDK-실행파일.md)을 따른다.

## 4. Python과 C++에서 사용할 수 있는가?

| метода_мод | актуелно_ставка 포함 стање_вриједност | 호출 가능 клип |
|---|---|---|
| Java → 한국어 JAR | задана_вриједност 포함 | 위 22개 메서드와 радни_сто |
| Python → `java` дете_вриједност 프로세스 | Python·Java задана_вриједност 포함 | 작은 Java 진입점을 통해 호출하고 표준 Излаз·Датотека 등으로 ИСХОД Напред_вриједност |
| Python → JPype → JVM | JPype는 задана_вриједност 배포에 없음 | 별도 инсталирај_вриједност 후 Java класа_вриједност·метода_вриједност 호출 가능. 이 배포판의 ARM64/musl/Python 3.14 조합은 додати_унос потврдити_5fb2b747 필요 |
| C++ → JNI → JVM | `g++`, JNI 헤더, `libjvm.so` 포함 | JVM을 생성하고 한국어 класа_вриједност·메서드를 직접 호출할 수 있음 |
| Python용 독립 한국어 библиотека | актуелно_ставка задана_вриједност 제공 없음 | 필요하면 Python 표준 라이브러리를 감싸는 한국어 모듈을 별도로 작성 |
| C/C++용 독립 한국어 библиотека | 자체 x86 `posix-kor`와 자체 ARM64 커널용 초기 RAM Датотека 연결이 별도로 존재 | 둘 다 이 Linux/OpenJDK 실행판의 libc 라이브러리는 아님 |

Python의 일반 `import`나 `ctypes.CDLL`로 JAR를 바로 읽을 수는 없다. C++의 `#include`나 일반 네이티브 링커만으로 Java 메서드를 연결할 수도 없다. JVM 프로세스 또는 JVM Повежи_се 계층을 거쳐야 한다.

### Python: додати_унос 패키지 없이 호출

Изврши_команда 가능한 예제 원문은 [문자명령.java](예제/다른언어/문자명령.java), [파이썬호출.py](예제/다른언어/파이썬호출.py)다. Python이 Java 진입점을 실행하고 `문자.코드포인트수`의 цијели_број 결과를 받는다. Аргументи 목록을 사용하며 љуска Наредба 문자열을 조립하지 않는다. `subprocess.run`의 프로세스 Изврши_команда·Излаз_програм шифра_вриједност·Излаз Процес_вриједност_унос 방식은 [Python 공식 문서](https://docs.python.org/3/library/subprocess.html)를 따른다.

두 예제 파일을 게스트의 같은 폴더에 복사한 НАЗАД_вриједност 그 폴더에서 실행한다. 예제 Датотека 자체는 задана_вриједност 시스템 이미지에 자동 설치돼 있지 않다.

```sh
mkdir -p classes
javac -encoding UTF-8 -cp /opt/jkoros/lib/한국어자바.jar -d classes 문자명령.java
python3 파이썬호출.py --text '한글 😀'
```

Излаз: `Python → 한국어.자바.문자.코드포인트수: 4`

이 예제의 Python функција_вриједност `코드포인트수`는 이번 문서의 Повежи_се 예제이며 기존에 설치된 Python 라이브러리는 아니다. актуелно_ставка 예제는 호출할 때마다 JVM 프로세스를 시작한다. Java објекат_вриједност 자체를 Python으로 가져오는 방식은 아니며, 다른 메서드를 사용하려면 진입점의 Аргументи·ИСХОД 형식을 확장한다.

### Python: JPype로 같은 프로세스에서 호출

JPype를 별도 설치한 환경에서는 Даље_ставка 형태로 연결할 수 있다. **아래는 избор_вриједност 가능한 Повежи_се 방법이며, актуелно_ставка 배포판에 JPype가 설치돼 있거나 Изврши_команда 검증됐다는 뜻은 아니다.** JVM 시작과 `JClass`를 통한 класа_вриједност 접근은 [JPype 공식 설명](https://jpype.readthedocs.io/en/latest/userguide.html)을 참고한다.

```python
import jpype

jpype.startJVM(
    "/usr/lib/jvm/java-25-openjdk/lib/server/libjvm.so",
    classpath=["/opt/jkoros/lib/한국어자바.jar"])
try:
    문자 = jpype.JClass("한국어.자바.문자")
    print(문자.코드포인트수(jpype.JString("한글 😀")))
finally:
    jpype.shutdownJVM()
```

Python·JVM·Повежи_се 모듈의 CPU 아키텍처가 맞아야 한다. 이 실행판은 ARM64 + musl이므로 일반 x86_64/glibc용 바이너리를 그대로 설치하는 방식은 맞지 않는다. JPype инсталирај_вриједност·패키지 빌드는 이번 문서 작업에서 수행하지 않았다.

### C++: JNI로 직접 호출

[자바호출.cpp](예제/다른언어/자바호출.cpp)는 стваран_подаци Изврши_команда 가능한 예제다. JVM을 작업 스레드에서 생성하고 Даље_ставка 메서드를 찾는다.

```cpp
jclass type = env->FindClass("한국어/자바/문자");
jmethodID method = env->GetStaticMethodID(
    type, "코드포인트수", "(Ljava/lang/String;)I");
```

JVM генерисати·종료와 스레드 연결은 [JNI Invocation API](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/invocation.html)의 방식이다. `JNIEnv*`는 генерисати·연결된 스레드에서 사용해야 한다. 예제는 Java 예외를 확인하고 JVM 종료까지 처리한다.

게스트에 `자바호출.cpp`를 복사한 НАЗАД_вриједност 컴파일한다. 로그인 환경의 `JAVA_HOME`은 `/usr/lib/jvm/java-25-openjdk`다.

```sh
g++ -std=c++11 -Wall -Wextra -pthread \
  -I"$JAVA_HOME/include" -I"$JAVA_HOME/include/linux" \
  자바호출.cpp -L"$JAVA_HOME/lib/server" \
  -Wl,-rpath,"$JAVA_HOME/lib/server" -ljvm -o 자바호출
./자바호출 /opt/jkoros/lib/한국어자바.jar
```

Излаз: `C++ → 한국어.자바.문자.코드포인트수: 4`

예제는 `한글 😀`을 UTF-16으로 만들어 `NewString`에 전달한다. `NewStringUTF`가 받는 modified UTF-8은 일반 UTF-8과 차이가 있으므로, 일반 UTF-8 이모지 바이트를 그대로 넘기는 예제로 작성하지 않았다. [JNI ниска_вриједност формат_вриједност](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/types.html#modified-utf-8-strings)

다른 한국어 메서드도 JNI 서명과 Аргументи 자료형을 맞춰 호출할 수 있다. 예를 들어 `Path`를 받는 Датотека API는 먼저 `Датотека.ПУТАЊА`로 Java ПУТАЊА 객체를 얻어 전달한다. Swing 호출에는 그래픽 세션과 이벤트 Процес_вриједност_унос нит_вриједност 규칙도 그대로 적용된다. JNI는 Java 실행을 기계어로 대체하는 기능이 아니며 JVM이 계속 필요하다.

### 기존 posix-kor와의 관계

추가된 [자체 ARM64 Повежи_се](../posix-kor/arm64-native/Прочитај_ме_eb81d7d9.md)은 C++에서 AOT Java 커널의 RAM Датотека API를 직접 호출하며, 별도 EL0 корисник 라이브러리로 Датотека/UDP 루프백 SVC 호출도 제공한다. JNI를 사용하지 않는다. 이 문서의 ARM64 **Linux** 및 한국어 Java JAR와는 다른 Изврши_команда 기반이며 자체 커널은 별도 제한형 Java 컴파일러/JVM과 MicroPython 1.24.1을 실행한다. MicroPython의 `import jkoros`로 Java језгро_вриједност Датотека·UDP 루프백·사각형 호출이 가능하지만 이 문서의 JAR를 가져오는 기능은 아니다. 자체 커널의 전체 OpenJDK/JRE/CPython 이식은 아직 미완성이다.

[posix-kor](../posix-kor/Прочитај_ме_eb81d7d9.md)에는 `креирати_фајл`, `파일자료읽기`, `писати_фајл_подаци`, `затварање_фајл`, `Направи_крајња_тачка`, `자료전문보내기` 등의 한국어 C 별칭이 있다. 그러나 구현은 **자체 jkoros i386 커널의 `int 0x80` 호출 규약용**이다.

이 `libposix-kor.a`와 자체 `sys/stat.h` 등의 헤더는 актуелно_ставка ARM64 Linux 실행판의 libc/C++용 라이브러리가 아니다. 해당 헤더·바이너리를 ARM64 Linux 프로그램에 그대로 연결해서는 ABI가 맞지 않는다. C++용 한국어 класа_вриједност 라이브러리나 Python용 바인딩을 задана_вриједност 제공하는 상태도 아니다. актуелно_ставка Linux 실행판에서 그와 같은 독립 API를 제공하려면 Linux 표준 라이브러리를 대상으로 별도로 구현·빌드해야 한다.

## 5. потврдити 범위와 재현

패키지 포함 여부는 [배포 패키지 унос_Листа](../platforms/rpi4/dist/packages.lock.json) 및 градити_систем 루트의 стваран_подаци 파일로 확인했다. JNI 헤더는 JDK의 `include/jni.h`, `include/linux/jni_md.h`, JVM 라이브러리는 `lib/server/libjvm.so`에 있다. 사용자가 이후 별도로 설치한 패키지는 이 задана_вриједност 배포 목록과 다를 수 있다.

이번에 **хост x86_64/OpenJDK 11에서** Python дете_вриједност 프로세스 호출과 C++ JNI 직접 호출을 направити_извор·실행해 각각 ИСХОД 4를 확인했다. JAR 공개 메서드도 소스와 대조했다. Python Повежи_се 예제는 додати_унос 패키지를 설치하지 않는다.

문서의 Java 사용 예제도 направити_извор·실행했고, 22개 메서드의 문서 포함 여부와 로컬 문서 링크를 확인했다. [예제 потврдити_5fb2b747 евиденција_ред](build/다른언어/провјера_извештај.json)

기존 ARM64 QEMU에서는 Java의 Датотека·Уникод_вриједност·스레드·HTTP 및 Swing 시험 결과가 있다. 이번 Python/C++ Повежи_се 예제의 **ARM64 게스트 실행과 JPype 설치는 별도 검증하지 않았다.** 이미지와 Изврши_команда 중인 корисник 환경은 이 문서 작업에서 변경하지 않았다. [기존 оперативни_систем потврдити_5fb2b747 евиденција_ред](../platforms/rpi4/VERIFICATION.md)

호스트에서 Python 예제를 재현하려면:

```sh
cd /home/user/jkoros/한국어자바
make
mkdir -p build/다른언어
javac -encoding UTF-8 --release 11 -cp build/한국어자바.jar \
  -d build/다른언어 예제/다른언어/문자명령.java
python3 예제/다른언어/파이썬호출.py \
  --jar build/한국어자바.jar --classes build/다른언어
```

хост C++ 예제는 위 JNI направити_извор 명령의 JDK 경로를 **хост JDK ПУТАЊА**로 바꾸고, ИЗВОР `예제/다른언어/자바호출.cpp`와 JAR `build/한국어자바.jar`를 지정한다. ARM64 게스트 JDK의 헤더·библиотека 경로를 хост x86_64 링크 명령에 섞지 않는다.
