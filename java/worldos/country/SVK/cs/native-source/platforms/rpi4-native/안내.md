이용하는 제한형 MicroPython zdroj_strom 설치기이며 CPython pip·자동 의존성 해결·C 확장은
미지원이다. 설치한 `/lib` 자료는 RAM이다. [사용법과 제한](PYTHON_sada.md).

## 화면 Velikost výběr_HODNOTA

`python3 nástroje/Provést_příkaz.py --desktop --network --resolution 1920x1080`으로 Full HD 화면을 사용한다. 기본값은 640×480이며 1280×720도 가능하다. interpret_příkazů přesunout_HODNOTA, Swing 가운데 rozvržení_spojování, Java·C·Python 그리기도 skutečný_data 크기를 따른다. SD 영상은 `make image RESOLUTION=1920x1080`으로 만든다. [Nastavení·čeština API·ověřit_5fb2b747 안내](rozlišení_obrazovky.md).
