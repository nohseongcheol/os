# vlastní ARM64 Java 커널의 C/C++ název_souboru·루프백 Připojit

이 디렉터리는 `platforms/rpi4-native` vlastní jádro_HODNOTA 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`deklarace/Soubor_ABI.h`는 čeština 함수명과 `extern "C"` ABI를 제공한다. `Připojit.c`는 jádro_HODNOTA 안에서 AOT Java název_souboru 메서드에 직접 연결하고, `uživatel_most.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. skutečný_data název_souboru 처리는 `Paměť_Files.java`, 루프백 datagram 처리는 `zpětná_smyčka_síť.java`, 연결형 흐름은 `tok_síť.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 jádro_HODNOTA 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·číslo_s_plovoucí_desetinnou_čárkou_HODNOTA operace_HODNOTA·název_souboru·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

vzpěra_HODNOTA: `otevřít_Soubor`, `파일자료읽기`, `zápis_Soubor_data`, `Zavřít_Soubor`, `hledat_Soubor`, `odebrat_Soubor_položka_název`, `sada_Soubor_délka`, 보조 funkce_HODNOTA `velikost_souboru`. chyba 시 -1과 작업별 `číslo_chyby`를 반환한다. `zápis_Files`은 RAM 파일이므로 ENOSYS를 반환한다. název_souboru 16개, 각 16384바이트, Název 63바이트, popisovač_položka 16개이며 RAM 디렉터리·partner_HODNOTA/절대 경로를 제공한다. oprávnění_HODNOTA/영속 저장은 없다.

사용자용 `deklarace/síť_ABI.h`는 skutečný_data čeština 함수와 독립 구조체를 선언한다.
`Create_účastník`, `vázat_ODKAZ`, `poslat_datagram_data/dostat`, `spojit_síť/기다리기/dostat`는
`uživatel_most.c`에서 SVC를 호출하며 makro_HODNOTA 별칭이 아니다. `struct cloud_soket_ODKAZ`의
`ODKAZ_řada`, `číslo_portu`, `internetová_adresa.ODKAZ_HODNOTA`을 사용한다. 상수는 enum의
`cloud_řada`, `datagramový_soket`, `datagram_protokol`, `tok_síť`, `tok_transportní_protokol`이다.
čeština·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. externí_HODNOTA 통신은 vlastní 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. skutečný_data Pi 4 GENET 드라이버는 미지원이다.
소켓도 skutečný_data funkce_HODNOTA `Zavřít_Soubor`로 닫는다.
