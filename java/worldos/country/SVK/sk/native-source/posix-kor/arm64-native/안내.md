# vlastné ARM64 Java 커널의 C/C++ Súbor·루프백 Pripojiť

이 디렉터리는 `platforms/rpi4-native` vlastné jadro_VALUE 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 Slovenský 함수명과 `extern "C"` ABI를 제공한다. `Pripojiť.c`는 jadro_VALUE 안에서 AOT Java Súbor 메서드에 직접 연결하고, `používateľ_most.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. skutočný_údaje Súbor 처리는 `Pamäť_Súbory.java`, 루프백 datagram 처리는 `spätná_slučka_sieť.java`, 연결형 흐름은 `Stream_sieť.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 jadro_VALUE 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·plávajúci_bod_VALUE operácia_VALUE·Súbor·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

Podpora_VALUE: `otvoriť_Súbor`, `파일자료읽기`, `zapísať_Súbor_údaje`, `Zavrieť_Súbor`, `hľadať_Súbor`, `odobrať_Súbor_položka_názov`, `množina_Súbor_dĺžka`, 보조 funkcia_VALUE `veľkosť_súboru`. chyba 시 -1과 작업별 `chybové_číslo`를 반환한다. `potvrdenie_ukladací_priestor_súborov`은 RAM 파일이므로 ENOSYS를 반환한다. Súbor 16개, 각 16384바이트, Názov 63바이트, 서술자 16개이며 RAM 디렉터리·partnerský_uzol_VALUE/절대 경로를 제공한다. povolenie_VALUE/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 skutočný_údaje Slovenský 함수와 독립 구조체를 선언한다.
`Create_účastník`, `BIND_adresa`, `odoslať_datagram_údaje/dostať`, `spojiť_sieť/기다리기/dostať`는
`používateľ_most.c`에서 SVC를 호출하며 makro_VALUE 별칭이 아니다. `struct cloud_soket_adresa`의
`adresa_séria`, `číslo_portu`, `internetová_adresa.adresa_VALUE`을 사용한다. 상수는 enum의
`cloud_séria`, `datagramový_soket`, `datagram_protokol`, `Stream_sieť`, `Stream_prenosový_protokol`이다.
Slovenský·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. externý_VALUE 통신은 vlastné 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. skutočný_údaje Pi 4 GENET 드라이버는 미지원이다.
소켓도 skutočný_údaje funkcia_VALUE `Zavrieť_Súbor`로 닫는다.
