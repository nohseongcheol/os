## 기존 об_єкт_значення 기반 관리 ядро_значення 전체를 부팅하기 위해 남은 З_єднання

Далі_елемент 항목은 Java 문법만으로 실행할 수 없는 CPU/пристрій_значення 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot запис_бал_значення, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 문맥 сховище_значення
- фактично_дані PIC/PIT/PS2/ATA/PCI обладнання_порт 및 AMD PCnet DMA цикл_значення_201e2521
- Java об_єкт_значення·масив_значення схема_компонування, виняток, 정적 ініціалізувати, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT етап_значення
- FAT 디스크 구역을 фактично_дані ATA 장치와 연결하는 ввід_вивід 접착 шар_значення

위 관리 계층은 engos 기능의 Java 관리 구현과 хост 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot запис_бал_значення, 정적 ініціалізувати·ціле_число масив_значення, VGA/직렬/PS2, ІнтерпретаторКоманд, простір_користувача ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 хост 루프백 패킷 왕복을 검증했다. 위 표의 об_єкт_значення 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
