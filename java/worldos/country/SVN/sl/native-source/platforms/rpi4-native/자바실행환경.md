# lastno ARM64 JVM 0.4와 slovenščina knjižnica

slovenščina 통신·izjema 사용법은 [slovenščina Java API](한국어자바/안내.md), FUNCTION_VALUE·변수·Datoteka 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

JAR Izvedi_ukaz, zunanji_VALUE IPv4 TCP/UDP, 별도 statičen_VALUE 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 predmet_VALUE·Thread·Swing은 JVM 경로의 기능이며 AOT Podpora_VALUE 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 Izvedi_ukaz**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK Razred_VALUE knjižnica 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 Razred_VALUE·statičen_VALUE metoda_VALUE 중심이던 실행기를 predmet_VALUE·knjižnica Izvedi_ukaz 기반으로 넓힌 것이다.

## 실행과 prevajati_vir

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# lastno jedro_VALUE 안에서 vir_drevo prevajati_vir → class Izvedi_ukaz, slovenščina API 호출
python3 Orodja/Izvedi_Datoteka.py 시험/자바/한글소스.java

# predmet_VALUE·izjema 등은 gostiti JDK로 Java 8 class를 만든 후 lastno 커널에서 Izvedi_ukaz
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 Orodja/Izvedi_Datoteka.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 Prenos_VALUE
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 Orodja/Izvedi_Datoteka.py build/my-java/객체시험.class \
  --include build/my-java/Ozadje_VALUE.class --include build/my-java/veja_VALUE.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.Razred_VALUE.class`라는 RAM Datoteka 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.Razred_VALUE`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.Razred_VALUE`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar Datoteka.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 slovenščina 클래스만 찾는다. 배포 slovenščina knjižnica JAR는 gostiti javac의 classpath로 사용하며, 같은 클래스가 uporabnik JVM ELF에도 Branje 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 statičen_VALUE metoda_VALUE, int/boolean/char/String, pogoj·sprint_VALUE, niz_VALUE 결합, 일부 Datoteka 스트림 등의 **lastno 부분집합 prevajalnik**다. predmet_VALUE deklaracija·상속·try/catch·Thread uporaba_VALUE 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 lastno JVM에서 실행한다. slovenščina API 중 Izpis·문자 스칼라 FUNCTION_VALUE·Datoteka Branje/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] Argumenti) throws Exception {
        slovenščina.lastno.Izpis.pisati_linija("안녕하세요😀");
        slovenščina.lastno.Izpis.수쓰기(slovenščina.lastno.문자.koda_znaka_COUNT("한글😀"));
        slovenščina.lastno.Datoteka.Pisanje("인사.txt", "한글 Datoteka😀");
        slovenščina.lastno.Izpis.pisati_linija(slovenščina.lastno.Datoteka.Branje("인사.txt"));
    }
}
```

## slovenščina API

독립 패키지 **`slovenščina.lastno`**를 사용한다. Linux판 `slovenščina.자바`가 요구하는 NIO/Swing/HTTP API를 lastno 커널에서 실행할 수 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 Razred_VALUE Ime·metoda_VALUE·Argumenti·polje_VALUE·Datoteka 이름에 한국어를 사용한다. 표준 Java Razred_VALUE 이름은 호환성을 위해 보존한다.

## Izvedi_ukaz 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(slovenščina Razred_VALUE 포함), class당 16 KiB·konstanta_VALUE 풀 511항목, 전체 metoda_VALUE/polje_VALUE 각각 512개. metoda_VALUE CODE_VALUE 8 KiB, lokalen_krajeven_obseg 변수·피연산자 operand_Sklad 각각 128슬롯, Argumenti 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 Izvedi_ukaz 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- predmet_VALUE 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 dejanski_podatki 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 Datoteka·대형 niz_VALUE·객체가 이 제한을 넘을 수 있다.
- 실행은 50만 바이트코드 Ukaz 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 okno SWITCH_MODE 시 중단·재개한다. 일반 strežnik_VALUE·계산의 무제한 실행은 아직 없다. 미지원 Ukaz·vir_VALUE 부족은 명시적인 오류로 종료한다.
- RAM Datoteka 최대 64개, 파일당 16384바이트, POT UTF-8 63바이트. RAM 디렉터리와 enakovreden_VALUE/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 slovenščina class는 RAM Datoteka 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 sprotno_element 경로에서 vir_drevo·Razred_VALUE·podatki 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 zunanji_VALUE IPv4를 제공한다. dejanski_podatki GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. datagram 512바이트, vtičnica_VALUE 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 Izvedi_ukaz 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 ARRAY_VALUE, 완전한 ARRAY_VALUE 공변성·인터페이스 sloj_VALUE 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/šifrirati_podatki/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 Podpora_VALUE 부분집합은 아래 및 개발 매뉴얼을 참고한다. Razred_VALUE Datoteka 전체 검증기·dostop_vnos dovoljenje_VALUE/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 zaščititi_VALUE 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM VALUE/preveriti_veljavnost/Razred_VALUE 로더와 izjema 모델 → 영속 VFS·mmap·Ura·원자 postopek_VALUE·dejanski_podatki 스레드/sinhronizirati ABI → OpenJDK java.base 및 native knjižnica 이식 → naprava_VALUE 네트워크·TCP/IP → okno 시스템/pisava_VALUE/입력기·java.desktop → Java SE 호환성 시험. sprotno_element lastno JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## preveriti_veljavnost

`Orodja/preskusiti_Javanski_navidezni_mehanizem.py`는 같은 Java 8 class 파일의 출력을 gostiti OpenJDK `-Xverify:all`과 QEMU raspi4b lastno 커널에서 비교한다. predmet_VALUE/상속/인터페이스·switch·ARRAY_VALUE, izjema/finally, 컬렉션/GC, Thread/zaklepanje_VALUE, slovenščina UTF-8/Datoteka/컬렉션, dejanski_podatki UDP 루프백/čas_VALUE 초과, 게스트 한글 vir_drevo prevajati_vir, ARRAY_VALUE Tip_VALUE/kopirati_VALUE/Datoteka 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 Datoteka zavrniti_VALUE 시험을 실행한다. UDP pobuda_koren 실행에는 gostiti 루프백 vtičnica_VALUE 권한이 필요하다.

`Orodja/부팅시험.py`는 jedro_VALUE zaščititi_VALUE/회귀 시험과 별도로 slovenščina Java 화면 API가 dejanski_podatki 픽셀을 그렸는지도 QMP 화면 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. dejanski_podatki Pi4 strojna_oprema_VALUE 부팅 시험과 전체 JDK 호환성 시험 결과는 아니다.


## JVM 0.3: 네트워크와 GUI pripona_VALUE

`Socket`/`ServerSocket` ustvariti·Poveži·accept·양방향 InputStream/OutputStream·close·EOF·čas_VALUE 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 zunanji_VALUE številka_VALUE IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 končati_klic_p 16개, Java 루프백 버퍼 1024바이트, zunanji_VALUE TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. interaktiven 이벤트 대기는 Izvedi_ukaz 기한을 갱신하고 Terminal SWITCH_MODE 시 프로세스 상태를 Store_VALUE·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

slovenščina `okno`, `pripomoček`, `연결통신` 클래스를 배포 JAR와 lastno JVM 내장 자원에 추가했다. 상세 metoda_VALUE·제한·vir_drevo·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## slovenščina 객체의 직접 Izvedi_ukaz

`okno`, `Oznaka`, `SMS_polje`, `Gumb`, `dogodek_čakalna_vrsta`, `akcija_obvestilo`, `작업가닥`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. lastno JVM의 predmet_VALUE ustvariti,
oblika_VALUE 검사, 화면 호출, dogodek 큐, nit_VALUE 스케줄러에 slovenščina 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 Izvedi_ukaz 경로도 유지한다.
slovenščina 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

lastno 실행기의 slovenščina 진입점은 `public static void Zaženi()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 slovenščina 진입점을 우선한다.
명령행 인수는 `실행인수.element_COUNT()`와 `실행인수.Besedilo(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. statičen_VALUE Datoteka 예제는 게스트
javac로도 컴파일하며, GUI/nit_VALUE 소스는 gostiti `javac --release 8`을 사용한다.
직접 GUI/nit_VALUE API는 lastno JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
