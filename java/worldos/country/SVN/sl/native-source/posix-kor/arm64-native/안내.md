# lastno ARM64 Java 커널의 C/C++ Datoteka·루프백 Poveži

이 디렉터리는 `platforms/rpi4-native` lastno jedro_VALUE 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 slovenščina 함수명과 `extern "C"` ABI를 제공한다. `Poveži.c`는 jedro_VALUE 안에서 AOT Java Datoteka 메서드에 직접 연결하고, `uporabnik_most.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. dejanski_podatki Datoteka 처리는 `pomnilnik_Datoteke.java`, 루프백 datagram 처리는 `povratna_zanka_mreža.java`, 연결형 흐름은 `tok_mreža.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 jedro_VALUE 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·plavajoče_p_VALUE postopek_VALUE·Datoteka·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

Podpora_VALUE: `odprto_Datoteka`, `파일자료읽기`, `pisati_Datoteka_podatki`, `Zapri_Datoteka`, `iskati_Datoteka`, `odstraniti_Datoteka_vnos_ime`, `파일길이정하기`, 보조 FUNCTION_VALUE `velikost_datoteke`. NAPAKA 시 -1과 작업별 `številka_napake`를 반환한다. `potrjevanje_datotečna_shramba`은 RAM 파일이므로 ENOSYS를 반환한다. Datoteka 16개, 각 16384바이트, Ime 63바이트, 서술자 16개이며 RAM 디렉터리·enakovreden_VALUE/절대 경로를 제공한다. dovoljenje_VALUE/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 dejanski_podatki slovenščina 함수와 독립 구조체를 선언한다.
`Ustvari_končna_točka`, `BIND_naslov`, `poslati_datagram_podatki/sprejeti_sprejemati_prejeti_prejemati`, `POVEŽI_mreža/기다리기/sprejeti_sprejemati_prejeti_prejemati`는
`uporabnik_most.c`에서 SVC를 호출하며 makro_VALUE 별칭이 아니다. `struct oblak_vtičnica_naslov`의
`naslov_Družina`, `številka_vrat`, `internetni_račun.naslov_VALUE`을 사용한다. 상수는 enum의
`oblak_Družina`, `vtičnica_za_prenos_datagramov`, `datagram_protokol`, `tok_mreža`, `tok_protokol_prenosa`이다.
slovenščina·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. zunanji_VALUE 통신은 lastno 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. dejanski_podatki Pi 4 GENET 드라이버는 미지원이다.
소켓도 dejanski_podatki FUNCTION_VALUE `Zapri_Datoteka`로 닫는다.
