# 전체 Podpora_VALUE 요청의 sprotno_element stanje_VALUE

zahteva 전체는 아직 완료되지 않았다. sprotno_element ISO는 lastno Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 dejanski_podatki C POSIX 일부 기능, slovenščina API/VIR Ime, IDE Datoteka 보존, 게스트 Java Datoteka 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/안내.md)를 기준으로 판단한다.

| zahteva 분야 | sprotno_element Izvedi_ukaz 가능한 izrezek | 전체 지원에 필요한 작업 |
|---|---|---|
| Java prevajati_vir·Izvedi_ukaz | 게스트 제한형 javac/JVM, statičen_VALUE 단일 클래스와 일부 표준 predmet_VALUE | 일반 predmet_VALUE·Razred_VALUE Poveži·izjema·GC·스레드, 완전한 javac와 표준 Razred_VALUE knjižnica |
| Datoteka | POSIX 서술자, Java 단일 bajt_VALUE Datoteka tok_VALUE, 전용 mediji_VALUE 보존 | 일반 java.io/nio, 디렉터리·dovoljenje_VALUE·zaklepanje_VALUE·일반 datotečni_sistem·pripona_VALUE 가능한 zmogljivost_VALUE |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP gostiti 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, dodati_vnos NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 dogodek·pisava_VALUE·okno operacijski_sistem_VALUE, AWT 네이티브 연결과 Swing Izvedi_ukaz 기반 |
| POSIX | 문서화한 Datoteka·단말·UDP 부분 | Proces_VALUE·exec/fork·스레드·시그널·čas_VALUE·mmap·poll·파이프 등과 적합성 preveriti_veljavnost |
| 언어별 Ime | slovenščina 46개 preslikava_VALUE vnos_VALUE, dejanski_podatki C/Java/Datoteka Ime 적용 | tarča jezik potrjevanje_VALUE, 언어별 용례·역사 근거와 해당 VIR·도구의 preveriti_veljavnost |

lastno 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 Izvedi_ukaz 환경을 추가하는 방식은 별도의 jedro_VALUE·루트 datotečni_sistem·OpenJDK·그래픽 strežnik_VALUE·영구 Store_VALUE 구성을 가진 Izvedi_ukaz 경로가 된다. 후자는 기존 lastno 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

Izvedi_ukaz 기반과 dodati_vnos tarča 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. sprotno_element 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
