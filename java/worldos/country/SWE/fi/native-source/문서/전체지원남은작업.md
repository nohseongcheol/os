# 전체 Tuki_ARVO 요청의 nykyinen_kohde Tila_ARVO

pyyntö 전체는 아직 완료되지 않았다. nykyinen_kohde ISO는 oma Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 todellinen_data C POSIX 일부 기능, suomi API/lähdetiedosto Nimi, IDE tiedoston_nimi 보존, 게스트 Java tiedoston_nimi 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/Lueminut_eb81d7d9.md)를 기준으로 판단한다.

| pyyntö 분야 | nykyinen_kohde Suorita_komento 가능한 leikata | 전체 지원에 필요한 작업 |
|---|---|---|
| Java kääntää_lähde·Suorita_komento | 게스트 제한형 javac/JVM, staattinen_ARVO 단일 클래스와 일부 표준 objekti_ARVO | 일반 objekti_ARVO·Luokka_ARVO Yhdistä·poikkeus·GC·스레드, 완전한 javac와 표준 Luokka_ARVO kirjasto |
| tiedoston_nimi | POSIX 서술자, Java 단일 tavu_ARVO tiedoston_nimi virta_ARVO, 전용 tietoväline_ARVO 보존 | 일반 java.io/nio, 디렉터리·lupa_ARVO·lukita_ARVO·일반 tiedostojärjestelmä·tarkenne_ARVO 가능한 kapasiteetti_ARVO |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP isäntä 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, liitä_merkintä NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·syöte_ARVO Tapahtuma·fontti_ARVO·Ikkuna käyttöjärjestelmä_ARVO, AWT 네이티브 연결과 Swing Suorita_komento 기반 |
| POSIX | 문서화한 tiedoston_nimi·단말·UDP 부분 | prosessi_ARVO·exec/fork·스레드·시그널·AIKA_ARVO·mmap·poll·파이프 등과 적합성 vahvista |
| 언어별 Nimi | suomi 46개 yhdistämismääritys_ARVO merkintä_ARVO_962f286b, todellinen_data C/Java/tiedoston_nimi Nimi 적용 | tavoite Kieli vahvistaa_muutokset_ARVO, 언어별 용례·역사 근거와 해당 lähdetiedosto·도구의 vahvista |

oma 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 Suorita_komento 환경을 추가하는 방식은 별도의 ydin_ARVO·루트 tiedostojärjestelmä·OpenJDK·그래픽 palvelin_ARVO·영구 Store_ARVO 구성을 가진 Suorita_komento 경로가 된다. 후자는 기존 oma 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

Suorita_komento 기반과 liitä_merkintä tavoite 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. nykyinen_kohde 원문과 testit 결과를 후속 구현의 출발점으로 보존한다.
