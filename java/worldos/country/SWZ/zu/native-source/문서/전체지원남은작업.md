# 전체 uxhaso_inani 요청의 현재 isimo_inani

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 ulwazi_ngokwenzekile_imininingwane C POSIX 일부 기능, Isi_Zulu API/umthombo Igama, IDE Ihele 보존, 게스트 Java Ihele 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/NGIFUNDE_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 yenza_umyalo 가능한 isiqeshana | 전체 지원에 필요한 작업 |
|---|---|---|
| Java akha_umthombo·yenza_umyalo | 게스트 제한형 javac/JVM, ngaguquki_inani 단일 클래스와 일부 표준 into_inani | 일반 into_inani·uhlobo_inani Xhumanisa·예외·GC·스레드, 완전한 javac와 표준 uhlobo_inani umtapo |
| Ihele | POSIX 서술자, Java 단일 ibhayithi_inani Ihele Stream_inani, 전용 imidiya_inani 보존 | 일반 java.io/nio, 디렉터리·imvume_inani·잠금·일반 isistimu_yefayela·iselulo_inani 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP singatha 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 isigameko·ubuso_bohlamvu_ifonti_inani·ifasitela isistimu_yokusebenza_inani, AWT 네이티브 연결과 Swing yenza_umyalo 기반 |
| POSIX | 문서화한 Ihele·단말·UDP 부분 | Inqubo_inani·exec/fork·스레드·시그널·시간·mmap·poll·파이프 등과 적합성 qinisekisa |
| 언어별 Igama | Isi_Zulu 46개 대응 okufakwayo_inani, ulwazi_ngokwenzekile_imininingwane C/Java/Ihele Igama 적용 | impokophelo Ulimi 확정, 언어별 용례·역사 근거와 해당 umthombo·도구의 qinisekisa |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 yenza_umyalo 환경을 추가하는 방식은 별도의 ikhenela_inani·루트 isistimu_yefayela·OpenJDK·그래픽 Iseva_inani·영구 Store_inani 구성을 가진 yenza_umyalo 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

yenza_umyalo 기반과 추가 impokophelo 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
