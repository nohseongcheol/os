# เอง 커널과 번역기의 ไทย ชื่อ

대상은 `platforms/rpi4-native`의 เอง Java เคอร์เนล_ค่า, ผู้ใช้ JVM, C เครื่อง เชื่อมต่อ,
TCP/UDP·FTP, C คอมไพเลอร์_เครื่องมือ 이식부, MicroPython 이식부, สร้าง·ดําเนินการ_คําสั่ง·시험 도구다.
`golang/worldos/คันทรี_ค่า/KOR/รหัสต้นฉบับ`의 원칙처럼 기능을 먼저 구분하고 이름을 정한다.
x86 Java 커널과 공용 x86·ARM64 미리 번역기의 เอง 선언도 명명 검사에 포함한다.
Linux 실행판의 โฮสต์ เครื่องมือ, OpenJDK 보조 เครื่องมือ 및 ภายนอก_ค่า การกระจาย_ค่า แหล่ง_ทรี 전체를
한국어로 ลองอีกครั้ง_ค่า 작성했다는 뜻은 아니다.

## 명명 원칙과 말의 근거

- 명사는 자료의 역할을 나타낸다: `แฟ้ม_จุดจับ`, `ชั้น_หมายเลขพอร์ต`, `ฮีป_ที่เก็บ`, `คีย์บอร์ด`.
- 함수는 행위를 나타낸다: `อ่าน`, `เขียน`, `เปิด`, `ปิด`, `สุทธิ_ผูก`, `ใช้งาน_แอป`.
- TCP의 이어진 ไบต์_ค่า 흐름과 UDP의 경계 있는 자료를 `เพื่อน`와 `เดตาแกรม_ช่อง`로 구별한다.
- 짧은 영어 변수도 쓰임에 따라 `길이`, `ข้อมูล_ตําแหน่ง`, `การค้นหา_ดัชนี`, `반환값`으로 풀어 쓴다.
  순번·임시 산술값처럼 여러 역할에 재사용되는 변수는 `순번`, `첫째값`, `둘째값`으로 구별한다.
- 이름이 같아도 ภายนอก_ค่า 구조체의 필드와 เอง 변수는 별도로 분석한다.

`ช่อง_รายการ(通路)`는 이동이나 교류가 이루어지는 길이라는 기존 의미를 통신 연결에
적용했다. `แปลง_ค่า(窓口)`의 주고받는 접점이라는 의미를 연결을 받는 곳에 적용했다.
이는 국립국어원 한국어기초사전의 [ช่อง_รายการ](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=49310),
[แปลง_ค่า](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=24898)의 뜻에 근거한다.

`เดตาแกรม(電文)`은 전보에 담는 글이라는 기존 통신 어휘에서 가져와, UDP 자료의
경계가 보존된다는 특징을 드러내는 데 쓴다. 근거는
[한국어기초사전 เดตาแกรม](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=74335)이다.
`สตรีม_ค่า`, `เธรด_ค่า`, `쌓임`은 우리말의 움직임·이어짐·쌓이는 모양을 빌린 표현이다.
`กระแสข้อมูลที่ป้อนเข้า`, `งานเบื้องหลัง`, `สแตก_ที่เก็บ` 같은 복합 이름은 이 프로젝트의 기능별 조어다.
이 พจนานุกรม 근거를 특정 중세 문헌의 최초 출현이나 공인 전산 번역으로 확대하지 않는다.
공인 표준 แปล_แหล่ง·국어사 เดตาแกรม 감수를 마쳤다는 뜻도 아니다.

| 기능 | 채택한 ชื่อ | 이유 |
|---|---|---|
| TCP Socket | เพื่อน | 상대와 연결되어 ลําดับ_ค่า 있는 바이트를 주고받음 |
| ServerSocket | รับ_แปลง | 새 연결이 들어오는 접점 |
| DatagramSocket | เดตาแกรม_ช่อง | 각 자료의 경계를 보존하는 통신 |
| InputStream / OutputStream | กระแสข้อมูลที่ป้อนเข้า / กระแสข้อมูลขาออก | 들어오고 나가는 바이트의 ลําดับ_ค่า |
| heap / stack | ฮีป_ที่เก็บ / สแตก_ที่เก็บ | จัดสรร_ที่เก็บ 방식과 쌓고 꺼내는 구조 |
| thread / keyboard | งานเบื้องหลัง / คีย์บอร์ด | 이어지는 실행과 글쇠의 อาร์เรย์_ค่า |
| exception / timeout | ข้อยกเว้น / 대기시간초과예외 | 정상 처리에서 벗어남과 그 구체적 이유 |

## 보존하는 규격 ชื่อ

`public`, `class`, `int`는 예약어다. `String`, `main`, 배열의 `length`는 예약어가 아니다.
ปัจจุบัน_รายการ 다섯 Java 예제는 `เรียกใช้งาน()`·`실행인수`·ไทย 화면/เธรด_ค่า API를 사용해
예약어·리터럴 외의 식별자를 한국어로 작성한다. 화면/가닥은 표준 객체를
감싸지 않고 เอง JVM에 직접 구현했다. 자세한 계약은 [ไทย Java API](../한국어자바/안내.md)를 본다.

표준 javac는 สตริง_ค่า 리터럴에 `java.lang.String`, สตริง_ค่า 결합에 `StringBuilder`
같은 이름을 생성한다. 이들은 ไทย 소스에서도 바이트코드에 남을 หมายเลข 있다.
기존 표준 class를 실행하는 JVM의 การแมป_ค่า สตริง_ค่า, 아직 표준 라이브러리를 쓰는
통신·แฟ้ม 연결부까지 모두 한국어로 재구현한 것은 아니다. 이름만 일괄 치환하면
서술자·재정의·native 연결이 달라져 호환성이 깨진다.

C 표준 ฟังก์ชัน_ค่า·จํานวนเต็ม_ชนิด·POSIX ABI, CPU ทะเบียน_ค่า ชื่อ, 어셈블리 คําสั่ง, 링커 절 ชื่อ,
TinyCC·lwIP·MicroPython이 요구하는 ตั้งค่า 매크로와 헤더 이름도 보존한다.
예: `main`, `memcpy`, `pk_bind`, `mpconfigport.h`, `lwipopts.h`, `stdint.h`.
เอง C 함수의 แหล่ง_ทรี 이름은 한국어이며, [기계연결이름.h](기계연결이름.h)가
기존 AOT·어셈블리·SDK에 공개한 เครื่อง 심볼과 연결한다.
Python의 `__init__`, `setUp`, `handle`, 표준 มอดูล_ค่า แอตทริบิวต์_ค่า, 명령행 옵션과 JSON 키도
ภายนอก_ค่า 계약이다. `build/`, การกระจาย_ค่า 바이너리 이름과 `/sdk`는 기존 ดําเนินการ_คําสั่ง 경로를 유지한다.
ภายนอก_ค่า 원본은 `vendor/`에서 이용허락·해시와 함께 관리한다.

## 검사와 재실행

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 เครื่องมือ/명명검사.py
make สร้าง
make 시험
make test-examples test-ftp test-elf
python3 เครื่องมือ/ดําเนินการ_คําสั่ง.py --desktop --network
```

`เครื่องมือ/시언어이름분석.py`는 libclang 6으로 C 선언과 참조를 검사한다.
`เครื่องมือ/*이름반영.py`는 เปลี่ยนแปลง_ค่า 전 แหล่ง_ทรี·분석표를 필요로 하는 일회성 이행 도구다.
이미 변경된 소스에 ลองอีกครั้ง_ค่า 적용하여 대응표를 덮어쓰지 않는다.

## C 통신 구조체와 Python ข้อผิดพลาด

C 통신에서 `갈래`는 อีเมล 체계를 구분하고 `หมายเลขพอร์ต`는 port, `อีเมล_ค่า`은
IPv4 주소의 32비트 값을 나타낸다. `เดตาแกรม_โพรโทคอล`은 앞서 설명한 เดตาแกรม(電文)과
มูลค่าตามสัญญา(規約)을 결합해 UDP의 기능을 드러낸 프로젝트 이름이다.

| 표준 표현 | ไทย 직접 구현 |
|---|---|
| AF_INET / SOCK_DGRAM / IPPROTO_UDP | enum의 คลาวด์_กลุ่ม / เดตาแกรมซ็อกเก็ต / เดตาแกรม_โพรโทคอล |
| struct pk_sockaddr_in | struct 인터넷통신주소 |
| sin_family / sin_port | อีเมล_กลุ่ม / หมายเลขพอร์ต |
| sin_addr.s_addr | ที่อยู่อินเทอร์เน็ต.อีเมล_ค่า |
| OSError / ข้อผิดพลาด.args[0] | ระบบ_ข้อผิดพลาด / ข้อผิดพลาด.ดัชนี |

ไทย 구조체는 `#define` 치환이나 ค่าเขตข้อมูล 별칭이 아닌 별개 자료형이다.
표준 구조체와 같은 16바이트 배치를 선언하며 เคอร์เนล_ค่า SVC에서 ไบต์_ค่า 복사로
검사한다. `เปิด_ปลายทาง`·`ส่ง_เดตาแกรม_ข้อมูล`와 แฟ้ม 함수는 คงที่_ค่า 라이브러리에
ค่าจริง_ข้อมูล ไทย 이름의 ฟังก์ชัน_ค่า 심볼을 갖는다. 기존 pk_* 심볼도 유지한다.
이전 코드에서 ไทย 통신 함수에 pk_sockaddr*를 전달했다면 ไทย 구조체로
옮기거나, 표준 구조체와 pk_* 함수의 짝을 유지한다.

Python의 `ระบบ_ข้อผิดพลาด`는 OSError의 ไทย 하위 클래스이며 연결부에서
ข้อผิดพลาด 번호를 보존하여 변환한다. 일반 Python 문법과 ภายนอก_ค่า 패키지의 API는 유지한다.

## 직접 GUI 이름의 뜻과 검토 คลิป

`실행할일`은 수행할 내용을, `เรียกทํางาน`는 그 수행을 나타낸다.
`동작받이`는 동작이 발생했다는 알림을 받는 역할, `แอคชัน_ข้อสังเกต`은 전달되는 사건이다.
`ปุ่ม`는 눌러 동작시키는 조작부, `ฉลาก`는 안내 글의 ดัชนีชี้ตําแหน่ง,
`เขตข้อมูลข้อความ`은 글을 적는 ดัชนีชี้ตําแหน่ง, `งานเบื้องหลัง`은 이어지는 ดําเนินการ_คําสั่ง 흐름을 뜻한다.
`ดําเนินการ_คําสั่ง(實行)`·`การกระทํา(動作)`의 기존 뜻과 `받다`·`알리다`·`เธรด_ค่า`의 기능을
결합한 프로젝트 이름이다. 새 복합어가 역사 문헌에 그대로 있었다거나
특정 시대에 처음 쓰였다고 주장하지 않는다.

전체 저장소는 `python3 เครื่องมือ/แหล่ง_รีวิว.py`로 검토한다.
결과는 `build/verification/naming/source-review.json`이며 파일별 แฮช_แฟ้ม,
ASCII 파일명과 Python의 영어 การประกาศ 위치를 기록한다.
공용 ARM64·x86 번역기의 구현은 `compiler/자바도구/기계어미리번역.java`로 전환했다. `compiler/기계어미리번역.py`는 호환 진입점이다.
`compiler/arm64.py`는 이전 경로와 `ARM64(...).generate(...)` 호출을 이어 주는
호환 진입점이다. `compiler/classfile.py`, OpenJDK 보조 เครื่องมือ, Linux รุ่น_ค่า 도구와
기존 호환 진입점에는 영어 이름이 남아 있다. 따라서 전체 저장소가
예약어 외 100% 한국어라고 판정하지 않는다.
`เครื่องมือ/명명검사.py --시언어`는 ว่าง ARM64 소스의 การประกาศ, C 의미 วิเคราะห์_ค่า,
x86 Java 커널과 공용 번역기의 เอง การประกาศ, Java 예제 전체 ตัวระบุ_ค่า,
ARM64 Python 예제와 직접 GUI/가닥에 표준 래퍼가 없는지를 별도로 검사한다.

## ปัจจุบัน_รายการ 기능을 기준으로 보완한 ชื่อ

번역은 글자를 음역하는 대신 자료의 역할과 함수의 행동을 구분한다.
동일한 영어 이름도 문맥이 다르면 ไทย 이름을 달리 정한다.
แฟ้ม 이름은 주된 기능을 나타내고, ฟังก์ชัน_ค่า 이름은 행동을, ตัวแปร_ค่า_541034c4 이름은 담는 자료를 나타낸다.
예약어, 표준 API 및 ภายนอก_ค่า เชื่อมต่อ 규약은 따로 기록한다.

| 이전 ชื่อ | 적용한 ชื่อ | ปัจจุบัน_รายการ 기능 |
|---|---|---|
| `arm64.py`의 구현 | `compiler/자바도구/기계어미리번역.java` | Java 바이트코드를 독립 실행용 C 원문으로 미리 แปล_แหล่ง |
| `ARM64`, `generate` | `เครื่อง_รหัส_คอมไพเลอร์`, `สร้าง_167eff27` | แปล_แหล่ง 상태를 담는 객체와 C รหัสต้นฉบับ สร้าง_167eff27 행동 |
| `prototype`, `method` | `เมธอด_ต้นแบบ`, `เมธอด_เนื้อความ` | 함수의 รูปแบบ_ค่า_d1a42ea5 선언과 ค่าจริง_ข้อมูล คําสั่ง รหัสต้นฉบับ |
| `profile`, `heap_words` | `실행대상`, `동적기억낱말수` | เคอร์เนล_ค่า·ผู้ใช้ 구분과 จัดสรร_ที่เก็บ ความจํา_ค่า 공간의 เครื่อง 낱말 หมายเลข |
| `pc`, `op` | `คําสั่ง_ตําแหน่ง`, `명령번호` | 바이트코드에서의 위치와 수행할 명령의 ดัชนี |
| `x`, `y`, `w`, `h` | `พิกัดแกน_x`, `세로좌표`, `영역너비`, `영역높이` | ระยะไกล_ค่า 화면의 위치와 직사각형 ขนาด |
| `p`, `n`, `i`, `j` | `ข้อมูล_ตําแหน่ง`, `ค่า`, `순번`, `안쪽순번` | ระยะไกล_ค่า 화면 ข้อมูล·ตัวเลข_ค่า·สปรินต์_ค่า ดัชนีชี้ตําแหน่ง; 파일별 기능을 확인해 적용 |

[공용번역기이름대응.tsv](공용번역기이름대응.tsv)에 คอมไพเลอร์_เครื่องมือ 참조의 ค่าจริง_ข้อมูล เปลี่ยนแปลง_ค่า 기록을 남겼다.

C เอง การประกาศ 분석에서는 제외한다. ค่าจริง_ข้อมูล เคอร์เนล_ค่า 빌드에서는 계속 컴파일한다.

### 말의 뿌리와 새로운 복합 ชื่อ

`ความจํา_ค่า(記憶)`과 `การค้นหา_ดัชนี(索引)`은 기존 한자어를 쓴다.
기억은 자료를 간직하는 기능에, 색인은 ลําดับ_ค่า 있는 항목을 찾아 지정하는 기능에 적용한다.
พจนานุกรม 근거는 국립국어원 한국어기초사전의
[ความจํา_ค่า](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=38812&nation=eng),
[การค้นหา_ดัชนี](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=63787)이다.

`สแตก_ที่เก็บ`, `ผลัก_ค่า`, `ป๊อบ_ค่า`는 자료를 포개고 마지막 자료부터 꺼내는 ดําเนินการ_คําสั่ง 구조를 드러낸다.
`쌓다`의 기존 뜻에 근거한 기능별 조어이며, 사전의
[쌓다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62095)를 참고한다.
`미리번역`은 ดําเนินการ_คําสั่ง 전에 번역한다는 기능을 직접 나타낸다.
`เครื่อง_คํา`은 처리기의 ข้อมูล 단위를 가리키며, 언어의 일반 낱말과 구별하도록 `เครื่อง`를 붙였다.
`기계어미리번역`, `동적기억낱말수` 같은 복합 이름은 ปัจจุบัน_รายการ 기능에 맞게 만든 프로젝트 용어다.
이 복합어가 옛 문헌에 그대로 있었다거나 특정 시대에 처음 나타났다는 뜻은 아니다.
확인되지 않은 중세 형태나 최초 ใช้_ค่า 연대는 어원 근거로 적지 않는다.

생성되는 C의 내부 ชนิดข้อมูล·อาร์เรย์_ค่า·ฟังก์ชัน_ค่า·ท้องถิ่น_ขอบเขต ตัวแปร_ค่า_541034c4·สาขา 이름도 한국어로 바꾼다.
직접 한글 식별자를 읽지 못하는 예전 GCC를 위해 호환 API는 같은 ไทย 이름을
표준 C 범용 문자 표기로 출력한다. ค่าจริง_ข้อมูล ARM64 빌드는 Clang으로 읽을 หมายเลข 있는 한글 원문을 사용한다.
สตริง_ค่า, C 표준 ฟังก์ชัน_ค่า, `java_entry` 같은 공개 เชื่อมต่อ 이름은 바꾸지 않는다.

셸의 사용법·문법 ข้อผิดพลาด·แฟ้ม 및 ความจํา_ค่า อีเมล_ขอบเขต 안내도 한국어로 보완했다.
`READY`, `PASS`, `HEX BEGIN`처럼 시험·แฟ้ม โอน_ค่า 도구가 읽는 มาร์กเกอร์_ค่า,
명령행 옵션과 기존 명령어, JVM คลาส_ค่า ชื่อ·แฟ้ม รูปแบบ_ค่า_d1a42ea5·อุปกรณ์_ค่า 이름은 호환 표기로 남는다.
x86 VGA 문자 화면은 한글을 표시하지 못하므로 ไทย 문구는 UTF-8 직렬 단말에서 확인한다.
