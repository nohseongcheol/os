# เอง ARM64 JVM 0.4와 ไทย ไลบรารี

ไทย 통신·ข้อยกเว้น 사용법은 [ไทย Java API](한국어자바/안내.md), ฟังก์ชัน_ค่า·ตัวแปร_ค่า_541034c4·แฟ้ม 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

JAR ดําเนินการ_คําสั่ง, ภายนอก_ค่า IPv4 TCP/UDP, 별도 คงที่_ค่า 부분집합 `jaot`와 게스트 C 컴파일은 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)에 설명한다. 아래 วัตถุ_ค่า·Thread·Swing은 JVM 경로의 기능이며 AOT สนับสนุน_ค่า 범위와 같지 않다.

이 구현은 **Linux 없이 부팅한 Java AOT 커널의 EL0에서 ดําเนินการ_คําสั่ง**한다. JDK/JRE의 거의 모든 기능을 제공하는 단계는 아직 아니다. HotSpot·OpenJDK คลาส_ค่า ไลบรารี 전체를 이식하거나 Java SE 인증/TCK를 통과한 구현도 아니다. 이번 확장은 단일 คลาส_ค่า·คงที่_ค่า เมธอด_ค่า 중심이던 실행기를 วัตถุ_ค่า·ไลบรารี ดําเนินการ_คําสั่ง 기반으로 넓힌 것이다.

## 실행과 คอมไพล์_แหล่ง

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
# เอง เคอร์เนล_ค่า 안에서 แหล่ง_ทรี คอมไพล์_แหล่ง → class ดําเนินการ_คําสั่ง, ไทย API 호출
python3 เครื่องมือ/ดําเนินการ_แฟ้ม.py 시험/자바/한글소스.java

# วัตถุ_ค่า·ข้อยกเว้น 등은 โฮสต์ JDK로 Java 8 class를 만든 후 เอง 커널에서 ดําเนินการ_คําสั่ง
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/한글시험.java
python3 เครื่องมือ/ดําเนินการ_แฟ้ม.py build/my-java/한글시험.class

# 의존 class 파일은 --include로 함께 โอน_ค่า
javac --release 8 -encoding UTF-8 -d build/my-java 시험/자바/객체시험.java
python3 เครื่องมือ/ดําเนินการ_แฟ้ม.py build/my-java/객체시험.class \
  --include build/my-java/พื้นหลัง_ค่า.class --include build/my-java/สาขา_ค่า.class \
  --include build/my-java/계산가능.class

make test-jvm
```

`--include DIR`는 그 디렉터리의 class 파일을 재귀적으로 읽어 `패키지.คลาส_ค่า.class`라는 RAM แฟ้ม 이름으로 전송한다. 주 클래스도 패키지가 있다면 `--class-name 패키지.คลาส_ค่า`를 지정한다. 셸에서는 해당 이름으로 업로드하고 `java 패키지.คลาส_ค่า`로 실행한다. JVM 0.4는 Main-Class가 있는 16 KiB 이하 JAR도 `java -jar แฟ้ม.jar`로 실행한다. JAR 모드에서는 JAR 내부 클래스와 내장 ไทย 클래스만 찾는다. การกระจาย_ค่า ไทย ไลบรารี JAR는 โฮสต์ javac의 classpath로 사용하며, 같은 클래스가 ผู้ใช้ JVM ELF에도 อ่าน 전용 자료로 포함된다. 일반 class 모드에서는 사용자가 같은 이름으로 올린 RAM class를 먼저 읽는다.

게스트 `javac`는 여전히 คงที่_ค่า เมธอด_ค่า, int/boolean/char/String, โรค·สปรินต์_ค่า, สตริง_ค่า 결합, 일부 แฟ้ม 스트림 등의 **เอง 부분집합 คอมไพเลอร์**다. วัตถุ_ค่า การประกาศ·상속·try/catch·Thread ใช้_ค่า 소스를 게스트 javac가 모두 컴파일하는 것은 아니다. 위 기능은 `javac --release 8`로 만든 class를 เอง JVM에서 실행한다. ไทย API 중 ข้อความออก·문자 스칼라 ฟังก์ชัน_ค่า·แฟ้ม อ่าน/쓰기는 게스트 컴파일러에도 연결했다. 다음처럼 전체 이름으로 호출한다.

```java
public class 인사 {
    public static void main(String[] อาร์กิวเมนต์) throws Exception {
        ไทย.เอง.ข้อความออก.줄쓰기("안녕하세요😀");
        ไทย.เอง.ข้อความออก.수쓰기(ไทย.เอง.문자.코드포인트수("한글😀"));
        ไทย.เอง.แฟ้ม.เขียน("인사.txt", "한글 แฟ้ม😀");
        ไทย.เอง.ข้อความออก.줄쓰기(ไทย.เอง.แฟ้ม.อ่าน("인사.txt"));
    }
}
```

## ไทย API

독립 패키지 **`ไทย.เอง`**를 사용한다. Linux판 `ไทย.자바`가 요구하는 NIO/Swing/HTTP API를 เอง 커널에서 실행할 หมายเลข 있다고 혼동하지 않도록 패키지를 나눴다. 이 라이브러리는 คลาส_ค่า ชื่อ·เมธอด_ค่า·อาร์กิวเมนต์·ค่าเขตข้อมูล·แฟ้ม 이름에 한국어를 사용한다. 표준 Java คลาส_ค่า 이름은 호환성을 위해 보존한다.

| คลาส_ค่า | 공개 기능 | 이름의 의미 |
|---|---|---|
| ข้อความออก | เขียน, 줄쓰기, 수쓰기 | ข้อความออก(出力): 내용을 바깥으로 내보냄 |
| 문자 | 길이, 같음, วาง_ข้อความ, ตัด_ค่า, แยกวิเคราะห์_จํานวนเต็ม/정수쓰기, 코드포인트수, เข้ารหัส/ถอดรหัสลับ_ข้อมูล | 문자(文字), การเข้ารหัส_ค่า(符號): 글의 단위와 그 값을 바이트로 나타내는 กฎ_ค่า |
| แฟ้ม | อ่าน/เขียน(String ชื่อ), 바이트읽기/바이트쓰기 | 널리 쓰는 ผู้ใช้ 용어를 보존; RAM 자료의 ชื่อ |
| รายการ_รายการ | 더하기, อ่าน, 바꾸기, ลบ_รายการ, ขนาด, 비었는가, ล้าง_สารบัญ | รายการ_รายการ(目錄): 순서가 있는 รายการ_ค่า 모음 |
| พจนานุกรม | 넣기, ค้นพบ_รายการ, 있는가, ลบ_รายการ, ขนาด, ล้าง_สารบัญ | พจนานุกรม(辭典): 찾는 말인 열쇠에 값을 การแมป_ค่า |
| 작업 | เรียกใช้งาน(실행할일), 기다리기(งานเบื้องหลัง), หยุดชั่วคราว_งาน, 살아있는가 | 작업 เธรด_ค่า: 한 แอป_f5044b9b 안의 ดําเนินการ_คําสั่ง สตรีม_ค่า |
| 통신 | เปิด, ส่ง, รับ, 대기시간, ปิด | 통신(通信), เดตาแกรม(電文), แปลง_ค่า: ข้อมูล 교환·메시지·포트의 역할 |
| 화면 | สี่เหลี่ยมผืนผ้า, ลบ_รายการ | 화면(畫面): ค่าจริง_ข้อมูล 그림을 표시하는 면 |
| เคอร์เนล_ค่า | 밀리초, สี่เหลี่ยมผืนผ้า | เอง JVM의 고정 native เชื่อมต่อ; 일반 JNI는 아님 |

이 명명은 ปัจจุบัน_รายการ 기능을 설명하는 용어 선택이다. 기존 한국어에 없던 역사적 어원을 만들어 주장하지 않는다. ชื่อแฟ้ม_ข้อความ·식별자는 UTF-8 소스로 보관한다. `문자.ถอดรหัสลับ_ข้อมูล`는 잘못된 UTF-8에 IllegalArgumentException을 던지며, `เข้ารหัส`는 짝이 없는 서로게이트를 `?`로 바꾼다. `แฟ้ม.อ่าน`는 엄격한 UTF-8 복호화를 적용한다. 화면 색은 `빨강 | (초록 << 8) | (파랑 << 16)` 형식이다.

## ดําเนินการ_คําสั่ง 제한과 남은 작업

- 동시에 적재하는 class 최대 16개(ไทย คลาส_ค่า 포함), class당 16 KiB·ค่าคงที่_ค่า 풀 511항목, 전체 เมธอด_ค่า/ค่าเขตข้อมูล 각각 512개. เมธอด_ค่า รหัส_ค่า 8 KiB, ท้องถิ่น_ขอบเขต ตัวแปร_ค่า_541034c4·피연산자 ตัวถูกดําเนินการ_สแตก 각각 128슬롯, อาร์กิวเมนต์ 최대 16개(this 포함).
- VM 가닥은 main 포함 **실행당 최대 4개**, 가닥당 호출 깊이 32. 100개 명령마다 ดําเนินการ_คําสั่ง 대상을 바꾼다. 네이티브 호출 도중에는 전환하지 않는다. pthread/SMP/OS 스레드가 아니며 Thread.sleep/interrupt/daemon/우선순위, Object.wait/notify, java.util.concurrent는 없다.
- วัตถุ_ค่า 힙은 32768개의 32비트 슬롯이다. 런타임의 AOT 배열은 ค่าจริง_ข้อมูล 메모리에서 64비트 슬롯을 사용한다. GC가 있어도 대형 แฟ้ม·대형 สตริง_ค่า·객체가 이 제한을 넘을 หมายเลข 있다.
- 실행은 50만 바이트코드 คําสั่ง 및 커널의 약 2초 EL0 기한으로 제한된다. Swing의 입력 대기는 기한을 갱신하고 หน้าต่าง สลับ_โหมด 시 중단·재개한다. 일반 เซิร์ฟเวอร์_ค่า·계산의 무제한 실행은 아직 없다. 미지원 คําสั่ง·ทรัพยากร_ค่า 부족은 명시적인 오류로 종료한다.
- RAM แฟ้ม 최대 64개, 파일당 16384바이트, เส้นทาง UTF-8 63바이트. RAM 디렉터리와 ชั้น_ค่า/절대 경로를 제공하며 영속 저장은 아직 없다. 내장 ไทย class는 RAM แฟ้ม 슬롯을 소비하지 않는다. 셸의 `cd`로 정한 ปัจจุบัน_รายการ 경로에서 แหล่ง_ทรี·คลาส_ค่า·ข้อมูล 파일을 읽는다.
- UDP는 Java 루프백 및 lwIP/SLIP를 통한 ภายนอก_ค่า IPv4를 제공한다. ค่าจริง_ข้อมูล GENET/Wi-Fi/DNS/TLS/HTTP 전체는 없다. เดตาแกรม 512바이트, 소켓 8개, 소켓당 큐 4개. receive는 VM 가닥을 양보하며 대기하고 setSoTimeout을 적용하지만 전체 ดําเนินการ_คําสั่ง 기한은 여전히 적용된다.
- long/float/double, invokedynamic/람다, enum/annotation, 다차원 อาร์เรย์_ค่า, 완전한 อาร์เรย์_ค่า 공변성·인터페이스 เลเยอร์_ค่า 검사, Reflection/JNI/JIT, NIO/ZIP API/Charset 전체, 보안/เข้ารหัสลับ_ข้อมูล/국제화 전체, 전체 AWT/Swing/JavaFX는 미지원이다. Swing의 별도 สนับสนุน_ค่า 부분집합은 아래 및 개발 매뉴얼을 참고한다. คลาส_ค่า แฟ้ม 전체 검증기·เข้าถึง_รายการ สิทธิ์_ค่า/보호된 멤버 검사는 아직 완전하지 않다. 손상된 입력은 EL0 ป้องกัน_ค่า 경계 내에서 종료되도록 한다.

전체 OpenJDK를 목표로 하려면 다음은 별도의 주요 구현 단계다: 완전한 JVM ค่า/ตรวจสอบความถูกต้อง/คลาส_ค่า 로더와 ข้อยกเว้น 모델 → 영속 VFS·mmap·นาฬิกา·원자 ศัลยกรรม_ค่า·ค่าจริง_ข้อมูล 스레드/ซิงค์ ABI → OpenJDK java.base 및 native ไลบรารี 이식 → อุปกรณ์_ค่า 네트워크·TCP/IP → หน้าต่าง 시스템/ฟอนต์_ค่า/입력기·java.desktop → Java SE 호환성 시험. ปัจจุบัน_รายการ เอง JVM의 일부 메서드를 더하는 것으로 이 작업이 완료되지는 않는다.

## ตรวจสอบความถูกต้อง

`เครื่องมือ/자바가상기계시험.py`는 같은 Java 8 class 파일의 출력을 โฮสต์ OpenJDK `-Xverify:all`과 QEMU raspi4b เอง 커널에서 비교한다. วัตถุ_ค่า/상속/인터페이스·switch·อาร์เรย์_ค่า, ข้อยกเว้น/finally, 컬렉션/GC, Thread/ล็อก_ค่า, ไทย UTF-8/แฟ้ม/컬렉션, ค่าจริง_ข้อมูล UDP 루프백/ค่าเวลา 초과, 게스트 한글 แหล่ง_ทรี คอมไพล์_แหล่ง, อาร์เรย์_ค่า ชนิด_ค่า/คัดลอก_ค่า/แฟ้ม 경계·한글 패키지의 9개 비교 시험과 잘못된 class 버전/잘린 แฟ้ม ปฏิเสธ_ค่า 시험을 실행한다. UDP แสดง_ราก 실행에는 โฮสต์ 루프백 소켓 권한이 필요하다.

`เครื่องมือ/부팅시험.py`는 เคอร์เนล_ค่า ป้องกัน_ค่า/회귀 시험과 별도로 ไทย Java 화면 API가 ค่าจริง_ข้อมูล 픽셀을 그렸는지도 QMP 화면 캡처로 검사한다. 보고서는 `build/verification/jvm/report.json`, `build/verification/report.json`이며 시험한 kernel8.img의 SHA-256을 기록한다. ค่าจริง_ข้อมูล Pi4 ฮาร์ดแวร์_ค่า 부팅 시험과 전체 JDK 호환성 시험 결과는 아니다.


## JVM 0.3: 네트워크와 GUI นามสกุล_ค่า

`Socket`/`ServerSocket` สร้าง_167eff27·เชื่อมต่อ·accept·양방향 InputStream/OutputStream·close·EOF·ค่าเวลา 제한과 UTF-8 `String.getBytes`를 추가했다. JVM 0.4에서는 ภายนอก_ค่า ตัวเลข_ค่า IPv4 TCP도 lwIP/SLIP에 연결했다. 연결형 สิ้นสุดการโทร_ชี้ 16개, Java 루프백 버퍼 1024바이트, ภายนอก_ค่า TCP 버퍼 4096바이트다. DNS·TLS는 없다.

`JFrame`, `JPanel`, `JLabel`, `JButton`, `JTextField`, `ActionListener`, `ActionEvent`, `SwingUtilities.invokeLater`의 문서화한 부분집합을 네이티브 GUI에 연결했다. `setLayout(null)`과 명시적 좌표를 사용한다. 전체 OpenJDK Swing 또는 Java SE 호환 구현은 아니다. 대화형 이벤트 대기는 ดําเนินการ_คําสั่ง 기한을 갱신하고 เทอร์มินัล สลับ_โหมด 시 프로세스 상태를 เก็บ_ค่า·복원한다. 이벤트 콜백 자체는 기존 바이트코드/CPU 기한을 따른다.

ไทย `หน้าต่าง`, `วิดเจ็ต`, `เพื่อน_การโอนถ่ายข้อมูล` 클래스를 การกระจาย_ค่า JAR와 เอง JVM 내장 자원에 추가했다. 상세 เมธอด_ค่า·제한·แหล่ง_ทรี·업로드 방법: [한글 개발 매뉴얼](개발안내.md).

## ไทย 객체의 직접 ดําเนินการ_คําสั่ง

`หน้าต่าง`, `ฉลาก`, `เขตข้อมูลข้อความ`, `ปุ่ม`, `กิจกรรม_คิว`, `แอคชัน_ข้อสังเกต`, `งานเบื้องหลัง`은
표준 GUI/Thread 객체를 보관하는 래퍼가 아니다. เอง JVM의 วัตถุ_ค่า สร้าง_167eff27,
รูปแบบ_ค่า_d1a42ea5 검사, 화면 호출, เหตุการณ์ 큐, เธรด_ค่า 스케줄러에 ไทย 계약을 직접 구현했다.
표준 `javax.swing`·`Thread` 코드의 ดําเนินการ_คําสั่ง 경로도 유지한다.
ไทย 단추와 표준 JButton은 서로 다른 형식이며, 해당 instanceof 검사도 검증한다.

เอง 실행기의 ไทย 진입점은 `public static void เรียกใช้งาน()`이다.
표준 `main(String[])`도 지원하며 둘 다 있으면 ไทย 진입점을 우선한다.
명령행 인수는 `실행인수.개수()`와 `실행인수.ข้อความ(순번)`으로 읽는다.
`example/java`의 다섯 예제는 이 규약을 사용한다. คงที่_ค่า แฟ้ม 예제는 게스트
javac로도 컴파일하며, GUI/เธรด_ค่า 소스는 โฮสต์ `javac --release 8`을 사용한다.
직접 GUI/เธรด_ค่า API는 เอง JVM 전용이다. 기존 OpenJDK 비교 시험과 별도로
ไทย 가닥의 ดําเนินการ_คําสั่ง·รอเดี๋ยว_ค่า·중복 เรียกใช้งาน ปฏิเสธ_ค่า, GUI เหตุการณ์ 출처·ดัชนี·콜백을 검사한다.
전체 JDK 번역이나 모든 API의 jaot 지원을 뜻하지 않는다.

เมธอด_ค่า 이름은 바이트코드에서도 유지된다. 이름과 참조를 같이 수정하면
ไทย 클래스도 실행되지만, สตริง_ค่า 리터럴·표준 ไลบรารี 재정의·native
เชื่อมต่อ·진입점은 각각 컴파일러와 실행기의 계약을 맞춰야 한다.
[상세 계약과 예제](한국어자바/안내.md)를 참고한다.

## เทอร์มินัล 부분 รีเฟรช

ขยับ_ค่า·ขนาด 변경은 새 หน้าต่าง 영역과 이전 자리에서 드러난 띠만 합성한다.
1920×32 พิกเซล(240 KiB)의 임시 그림에서 배경·겹친 หน้าต่าง·อักขระ_ค่า·GUI를 먼저
완성하고, ปัจจุบัน_รายการ แสดง_ค่า 메모리와 비교하여 달라진 화소만 기록한다.
32줄보다 큰 영역은 여러 띠로 처리하므로 전체 프레임을 원자적으로
교체하거나 수직 동기에 맞추는 방식은 아니다. 전체 배경을 먼저 지우는
중간 화면은 표시하지 않는다. 좌표가 같으면 ลองอีกครั้ง_ค่า 그리지 않는다.

`make test-redraw`는 ค่าจริง_ข้อมูล C 그리기 코드를 호스트의 ความจํา_ข้อมูล 화면에 연결해
ขยับ_ค่า 80회·ขนาด เปลี่ยนแปลง_ค่า 40회·겹친 หน้าต่าง 4개를 전체 합성 결과와 พิกเซล 단위로 대조한다.
ขอบเขต_ค่า 밖 ผู้ใช้ รูปวาด_ค่า, 동일 พิกเซล 무기록, ตัวชี้ 밑그림, ค่าจริง_ข้อมูล 화면 บรรทัด 간격을
검사한다. 이 시험의 시간은 โฮสต์ CPU 측정이며 Pi 4/QEMU 속도로 해석하지 않는다.
`make test-resize`는 QEMU/VNC의 640×480 및 1920×1080에서 왼쪽 모서리 ลาก_ค่า,
한글 입력·vi 미저장 เนื้อหา_ค่า·독립 หน้าต่าง 크기를 검사한다.
