# ไทย Java 통신·รับเข้า_ส่งออก·ข้อยกเว้น API

패키지는 `ไทย.เอง`다. โฮสต์ `javac --release 8`로 컴파일한 class를
เอง ARM64 커널의 JVM에서 실행한다. 통신·แฟ้ม·ข้อยกเว้น API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 เธรด_ค่า API는 เอง JVM 전용이다.
기존 표준 Java ไลบรารี 전체의 ไทย 번역판은 아니다.

```java
import ไทย.เอง.*;

public class เครือข่าย_9b2e3222 {
    public static void main(String[] อาร์กิวเมนต์) throws รับเข้า_ส่งออก_ข้อยกเว้น {
        เพื่อน เชื่อมต่อ = เพื่อน.เปิด("10.0.2.2", 9000);
        try {
            เชื่อมต่อ.대기시간(700);
            เชื่อมต่อ.ข้อความออก().เขียน(문자.เข้ารหัส("안녕하세요\n"));
            กระแสข้อมูลที่ป้อนเข้า 입력 = เชื่อมต่อ.입력();
            ข้อความออก.수쓰기(입력.อ่าน());
        } catch (대기시간초과예외 ข้อผิดพลาด) {
            ข้อความออก.줄쓰기(ข้อผิดพลาด.설명());
        } finally {
            เชื่อมต่อ.ปิด();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
ผู้ใช้ 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 สตริง_ค่า 리터럴에 사용하는 표준 클래스다. เอง 실행기는 `public static void เรียกใช้งาน()`도 진입점으로 받는다.

## 통신과 สตรีม_ค่า

| คลาส_ค่า | ไทย 호출 |
|---|---|
| เพื่อน | `เปิด(อีเมล, หมายเลขพอร์ต)`, `입력()`, `ข้อความออก()`, `대기시간(밀리초)`, `หมายเลขพอร์ต()`, `ท้องถิ่น_หมายเลขพอร์ต()`, `연결됨()`, `เทคโนโลยีสารสนเทศ_ปิด()`, `ปิด()` |
| รับ_แปลง | `เปิด(หมายเลขพอร์ต)`, `รับ()`, `หมายเลขพอร์ต()`, `대기시간(밀리초)`, `เทคโนโลยีสารสนเทศ_ปิด()`, `ปิด()` |
| กระแสข้อมูลที่ป้อนเข้า | `อ่าน()`, `อ่าน(byte[])`, `อ่าน(byte[], เรียกใช้งาน, 길이)`, `ปิด()` |
| กระแสข้อมูลขาออก | `เขียน(int)`, `เขียน(byte[])`, `เขียน(byte[], เรียกใช้งาน, 길이)`, `내보내기()`, `ปิด()` |
| เดตาแกรม_ช่อง | `เปิด(หมายเลขพอร์ต)`, `ส่ง(อีเมล, หมายเลขพอร์ต, ข้อความ)`, `รับ()`, `대기시간(밀리초)`, `หมายเลขพอร์ต()`, `เทคโนโลยีสารสนเทศ_ปิด()`, `ปิด()` |
| เพื่อน_การโอนถ่ายข้อมูล | `เปิด(...)`, `수신열기(...)`는 위 ไทย 객체를 ส่งคืน_เมตริก |
| 검사 | `참인지(โรค, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`อ่าน()`의 แฟ้ม 끝은 -1, อาร์เรย์_ค่า 읽기의 반환값은 ค่าจริง_ข้อมูล 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. หมายเลขพอร์ต 0은 빈 번호를 자동 배정한다.
UDP 전문은 ปัจจุบัน_รายการ เอง 커널에서 512바이트까지 받으며, 주소는 ตัวเลข_ค่า IPv4를 사용한다.
`localhost` 루프백 외의 ชื่อ 풀이(DNS)는 เอง 커널에 아직 없다.

기존 `เพื่อน_การโอนถ่ายข้อมูล.เชื่อมต่อ/รอการติดต่อ_ปลายทาง/รับ`, `통신.เปิด/ส่ง/รับ`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `เพื่อน`, `รับ_แปลง`, `เดตาแกรม_ช่อง`를 쓴다.

## ไทย ข้อยกเว้น

모든 아래 클래스는 ค่าเริ่มต้น 생성자, `새예외("설명")` 형태의 สตริง_ค่า 생성자와
`설명()`을 제공한다. ค่าจริง_ข้อมูล สร้าง_167eff27 문법은 `new 대기시간초과예외("ภาวะรอ 끝")`이다.

| ไทย ข้อยกเว้น | 상위 คลาส_ค่า / 용도 |
|---|---|
| ข้อยกเว้น | `java.lang.Exception`, 직접 던지는 일반 검사 ข้อยกเว้น |
| 실행예외 | `java.lang.RuntimeException` |
| รับเข้า_ส่งออก_ข้อยกเว้น | `java.io.IOException`, ไทย แฟ้ม·통신 API의 검사 ข้อยกเว้น |
| 대기시간초과예외 | `รับเข้า_ส่งออก_ข้อยกเว้น`, 통신 대기시간 초과 |
| อีเมล_การค้นหา_ข้อยกเว้น | `รับเข้า_ส่งออก_ข้อยกเว้น`, อีเมล ยืนยัน ความล้มเหลว_ค่า |
| 파일없음예외 | `รับเข้า_ส่งออก_ข้อยกเว้น`, แฟ้ม เปิด ความล้มเหลว_ค่า |
| 통신예외 | `รับเข้า_ส่งออก_ข้อยกเว้น`, 표준 SocketException แปลง_ค่า_4633b7f3 |
| ไม่ถูกต้อง_อาร์กิวเมนต์_ข้อยกเว้น | `java.lang.IllegalArgumentException` |
| หมายเลข_รูปแบบ_ความล้มเหลว | `ไม่ถูกต้อง_อาร์กิวเมนต์_ข้อยกเว้น` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| การอ้างอิงที่ว่าง_ข้อยกเว้น | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| สถานะ_ข้อยกเว้น | `java.lang.IllegalStateException` |
| ชนิด_แปลง_ข้อยกเว้น | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| อาร์เรย์_เก็บ_ความล้มเหลว | `java.lang.ArrayStoreException` |
| เธรด_สถานะ_ข้อยกเว้น | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 รอเดี๋ยว_ค่า 중단 |

`ข้อยกเว้น`와 `실행예외`는 모든 ไทย 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, แฟ้ม·통신 전체를 잡으려면 `catch (รับเข้า_ส่งออก_ข้อยกเว้น ข้อผิดพลาด)`를 쓴다.
ไทย API가 표준 รับเข้า_ส่งออก 오류를 ไทย 예외로 변환한다.
기존 ไทย 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
ข้อยกเว้น 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
ปัจจุบัน_รายการ เอง JVM에 이 20종을 추가했다. 임의의 ผู้ใช้ Throwable 하위 คลาส_ค่า 전체를
지원하도록 확장했다는 뜻은 아니다.

## คอมไพล์_แหล่ง·ดําเนินการ_คําสั่ง

```sh
cd /home/user/jkoros/platforms/rpi4-native
make สร้าง
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 เครื่องมือ/ดําเนินการ_แฟ้ม.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 ผู้ใช้ JVM ELF 안에 탑재된다. `.jar`는 โฮสต์ javac의
คลาส_ค่า 경로로 사용한다. แหล่ง_ทรี 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 ไทย 예외의 `throws` 선언과 그 import를 인식한다.
เอง JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·วัตถุ_ค่า·소켓 예제 전체의 แหล่ง_ทรี 컴파일은 โฮสต์ javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 หมายเลข 있다.

ค่าจริง_ข้อมูล TCP/UDP 예제는 [เครือข่าย.java](../../../example/java/เครือข่าย.java),
ดําเนินการ_คําสั่ง 절차는 [example 안내](../../../example/README.md),
แหล่ง_ทรี 명명 원칙은 [명명 안내](../명명/안내.md)에 있다.

## Swing หน้าต่าง 예제

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` ถัดไป_รายการ `java 창예제`로 연다. ชื่อ 입력, 인사하기 버튼,
인사말과 คลิก_ค่า 횟수 รีเฟรช, X 닫기를 지원한다.

| 기능 | ไทย 직접 API |
|---|---|
| Runnable / run | `실행할일.เรียกทํางาน()` |
| ActionListener / actionPerformed | `동작받이.รับ_แอคชัน(แอคชัน_ข้อสังเกต ข้อสังเกต)` |
| ActionEvent | `แอคชัน_ข้อสังเกต.คําสั่ง_ข้อความ()`, `กิจกรรม_แหล่ง()`, `ดัชนี()` |
| JFrame | `หน้าต่าง(หน้าต่าง_กรรมสิทธิ์, 폭, 높이)`, `เพิ่ม_องค์ประกอบ(화면구성요소)`, `แสดง_หน้าต่าง()`, `ปิด()`, `보이는가()` |
| JButton | `ปุ่ม(ข้อความ, 가로, แนวตั้ง_ตําแหน่ง, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `ฉลาก(...)`, `เขตข้อมูลข้อความ(...)` |
| 공통 화면 องค์ประกอบ_ค่า | `화면구성요소.글읽기()`, `글쓰기(ข้อความ)`, `자리정하기(가로, แนวตั้ง_ตําแหน่ง, 폭, 높이)` |
| SwingUtilities.invokeLater | `กิจกรรม_คิว.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `งานเบื้องหลัง(실행할일)`, `เริ่ม_งาน()`, `기다리기()`, `살아있는가()`, `หยุดชั่วคราว_งาน()` |
| 명령행 | `เรียกใช้งาน()`, `실행인수.개수()`, `실행인수.ข้อความ(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
เอง JVM의 `한국어화면호출`, `กระบวนการ_เธรด`가 ไทย คลาส_ค่า·เมธอด_ค่า·서술자를
해석해 화면 요소와 ดําเนินการ_คําสั่ง 가닥을 직접 만든다. การกระทํา 알림도 เอง 객체이며
콜백으로 `เรียกทํางาน`와 `รับ_แอคชัน`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 ดําเนินการ_คําสั่ง 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 เอง JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 โฮสต์ JVM에서 무동작 객체가 생기지 않도록 하는 ปฏิเสธ_ค่า 경로다.
เอง JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 หมายเลข 없다. โฮสต์ javac로 컴파일한 ย้อนกลับ_ค่า เอง JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import ไทย.เอง.*;
public class 가닥예제 implements 실행할일 {
    public void เรียกทํางาน() { ข้อความออก.줄쓰기("ไทย 작업 ดําเนินการ_คําสั่ง"); }
    public static void เรียกใช้งาน() throws 대기중단예외 {
        งานเบื้องหลัง เธรด_ค่า = 작업.เรียกใช้งาน(new 가닥예제());
        작업.기다리기(เธรด_ค่า);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
อาร์เรย์_ค่า อาร์กิวเมนต์ 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
เอง 실행기는 อาร์กิวเมนต์ 없는 `เรียกใช้งาน()`을 우선한다.
기존 ไทย 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.เรียกใช้งาน(Runnable)`을 사용하던 코드는 새 ไทย 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API สนับสนุน_ค่า 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 คลาส_ค่า·เมธอด_ค่า 이름과 서술자가 남는다.
ไทย ชื่อ 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·เมธอด_ค่า 재정의, native เชื่อมต่อ, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS ตัวระบุ_ค่า](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS เมธอด_ค่า อ้างอิง](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
