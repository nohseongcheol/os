# JThaOS 구조

아래는 วัตถุ_ค่า 기반 관리 เคอร์เนล_ค่า 전체의 เป้าหมาย_วัตถุ 구조다. ปัจจุบัน_รายการ ค่าจริง_ข้อมูล 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 ระบบปฏิบัติการ 안내](../os/안내.md)에 구현 범위를 명시한다. 아래의 GC·บริบท_ค่า สลับ_โหมด·ระบบแฟ้ม 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 เลเยอร์_ค่า
  ↓
Java AOT 실행기와 วัตถุ_ค่า·อาร์เรย์_ค่า·GC 런타임
  ↓
ฮาร์ดแวร์_ค่า 경계
  ↓
Java 관리 เคอร์เนล_ค่า
  ├─ ความจํา_ขอบเขต/쪽관리/COW
  ├─ กระบวนการ_ค่า/배정/wait
  ├─ ระบบแฟ้ม/ELF/POSIX
  └─ 입력/อุปกรณ์เก็บข้อมูล/เครือข่าย_สแตก
```

OpenJDK 자체는 이미 운영체제가 제공하는 แฟ้ม, 스레드, 가상 기억공간을 전제로 한다. 따라서 เคอร์เนล_ค่า 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, บริบท_ค่า 저장처럼 Java로 표현할 หมายเลข 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
