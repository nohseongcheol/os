# 전체 สนับสนุน_ค่า 요청의 ปัจจุบัน_รายการ สถานะ_ค่า

คําขอ 전체는 아직 완료되지 않았다. ปัจจุบัน_รายการ ISO는 เอง Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 ค่าจริง_ข้อมูล C POSIX 일부 기능, ไทย API/รหัสต้นฉบับ ชื่อ, IDE แฟ้ม 보존, 게스트 Java แฟ้ม 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/안내.md)를 기준으로 판단한다.

| คําขอ 분야 | ปัจจุบัน_รายการ ดําเนินการ_คําสั่ง 가능한 คลิป | 전체 지원에 필요한 작업 |
|---|---|---|
| Java คอมไพล์_แหล่ง·ดําเนินการ_คําสั่ง | 게스트 제한형 javac/JVM, คงที่_ค่า 단일 클래스와 일부 표준 วัตถุ_ค่า | 일반 วัตถุ_ค่า·คลาส_ค่า เชื่อมต่อ·ข้อยกเว้น·GC·스레드, 완전한 javac와 표준 คลาส_ค่า ไลบรารี |
| แฟ้ม | POSIX 서술자, Java 단일 ไบต์_ค่า แฟ้ม สตรีม_ค่า, 전용 สื่อข้อมูล_ค่า 보존 | 일반 java.io/nio, 디렉터리·สิทธิ์_ค่า·ล็อก_ค่า·일반 ระบบแฟ้ม·นามสกุล_ค่า 가능한 ความจุ_ค่า |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP โฮสต์ 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, ผนวก_รายการ NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 เหตุการณ์·ฟอนต์_ค่า·หน้าต่าง ระบบปฏิบัติการ_ค่า, AWT 네이티브 연결과 Swing ดําเนินการ_คําสั่ง 기반 |
| POSIX | 문서화한 แฟ้ม·단말·UDP 부분 | กระบวนการ_ค่า·exec/fork·스레드·시그널·ค่าเวลา·mmap·poll·파이프 등과 적합성 ตรวจสอบความถูกต้อง |
| 언어별 ชื่อ | ไทย 46개 การแมป_ค่า รายการ_ค่า, ค่าจริง_ข้อมูล C/Java/แฟ้ม ชื่อ 적용 | เป้าหมาย ภาษา 확정, 언어별 용례·역사 근거와 해당 รหัสต้นฉบับ·도구의 ตรวจสอบความถูกต้อง |

เอง 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 ดําเนินการ_คําสั่ง 환경을 추가하는 방식은 별도의 เคอร์เนล_ค่า·루트 ระบบแฟ้ม·OpenJDK·그래픽 เซิร์ฟเวอร์_ค่า·영구 เก็บ_ค่า 구성을 가진 ดําเนินการ_คําสั่ง 경로가 된다. 후자는 기존 เอง 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

ดําเนินการ_คําสั่ง 기반과 ผนวก_รายการ เป้าหมาย 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. ปัจจุบัน_รายการ 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
