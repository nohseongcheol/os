# JThaOS

ปัจจุบัน_รายการ เอง ARM64 배포판은 [LICENSE](LICENSE)의 COSL 상업 조건을 유지한다. 제3자 라이선스의 권리는 별도로 보장하며, การกระจาย_ค่า 시 แหล่ง_ทรี·재연결 자료를 포함하는 절차는 [COSL การกระจาย_ค่า 안내](platforms/rpi4-native/COSL배포안내.md)에 있다.

เอง ARM64 판의 `ipconfig`/`ip`, `ping`, `ps`/`top`, `free`/`df`, `poweroff`와 ไทย 명령은 [네트워크·ระบบปฏิบัติการ_ค่า คําสั่ง 안내](platforms/rpi4-native/네트워크와체계명령.md)를 참고한다. 새 커널을 부팅한 ย้อนกลับ_ค่า `help system`으로 볼 หมายเลข 있다.

Raspberry Pi 4 **เอง Java ARM64 เคอร์เนล_ค่า**은 [เอง Pi4 안내](platforms/rpi4-native/안내.md)에 있다. Linux 없이 부팅하며 GUI เทอร์มินัล·vi, เอง JVM의 Swing 일부 API, TCP/UDP·FTP, 게스트 TinyCC·MicroPython, C/C++의 posix-kor 호출을 제공한다. [ไทย Java 통신·ข้อยกเว้น API](platforms/rpi4-native/한국어자바/안내.md)와 [ไทย แหล่ง_ทรี 명명](platforms/rpi4-native/명명/안내.md)을 지원한다. [เอง SSH·VNC 및 GENET 드라이버](platforms/rpi4-native/ภายนอก_เพื่อน_เส้นบอกแนว.md)를 포함하며, 네트워크는 QEMU의 UART SLIP 경로로 검증했다. ค่าจริง_ข้อมูล Pi 4 GENET 동작은 미검증이고, USB 입력·영속 저장과 전체 OpenJDK·Swing은 아직 สนับสนุน_ค่า คลิป 밖이다.

Raspberry Pi 4용 Linux·OpenJDK 실행판과 ผู้ใช้ สภาพแวดล้อม ขยับ_ค่า 기능은 [라즈베리파이 실행판](platforms/rpi4/README.md)에 있다. ค่าจริง_ข้อมูล ARM64 JDK/JRE와 시스템·ผู้ใช้ รุ่น_รูป สร้าง 경로를 제공한다. 기존 เอง x86 커널과는 별도 ดําเนินการ_คําสั่ง 기반이다. 일반 Java `.class`/JAR의 ดําเนินการ_คําสั่ง แฟ้ม 생성은 [OpenJDK ดําเนินการ_คําสั่ง แฟ้ม](compiler/OpenJDK-แฟ้มปฏิบัติการ.md), ไทย API는 [ไทย Java ไลบรารี](한국어자바/안내.md)를 참고한다.

`jkoros`는 `engos`의 기능을 Java 관리 커널로 옮기는 프로젝트다. 프로젝트가 소유하는 Java ฟังก์ชัน_ค่า, ตัวแปร_ค่า_541034c4, รูปแบบ_ค่า_d1a42ea5 및 Java แฟ้ม 이름은 한국어로 작성한다. 표준 Java 실행기의 `main`, Java 표준 ไลบรารี รูปแบบ_ค่า_d1a42ea5, x86 부트 ABI 등 ภายนอก_ค่า 계약은 보존한다. เอง ARM64 실행기는 ไทย `เรียกใช้งาน()`도 진입점으로 지원하며, ไทย GUI·작업 가닥을 JVM에 직접 구현했다. เอง ARM64 C 연결부·Python 도구와 공용 x86·ARM64 AOT 번역기의 เอง 이름도 한국어로 작성한다. 이전 경로의 호환 จุดเข้าใช้งาน, OpenJDK 보조 도구와 Linux รุ่น_ค่า 도구에는 영어 이름이 남아 있고 [명명 원칙·말의 근거·전체 รหัสต้นฉบับ 검토 คลิป](platforms/rpi4-native/명명/안내.md)를 별도로 기록한다.

## ปัจจุบัน_รายการ 구현

아래 목록은 기존 `ดั้งเดิม_แหล่ง/`의 JVM 관리 커널에 대한 것이다. ค่าจริง_ข้อมูล 네이티브 커널의 범위는 `os/안내.md`에서 별도로 설명한다.

- จัดแนว_ค่า 할당과 해제를 지원하는 ความจํา_ขอบเขต ผู้จัดการ_ค่า
- อีเมล อีเมล_ขอบเขต, เพจ_ค่า เชื่อมต่อ, เขียน 시 คัดลอก_ค่า(COW)
- กระบวนการ_ค่า ตัวระบุ_ค่า, จัดเตรียม 대기열, fork/wait สถานะ_ค่า
- 과정별 แฟ้ม 서술자, open/read/seek/dup/close
- ELF32 식별 및 ส่วน_ค่า 검사
- 키보드·마우스 입력 เหตุการณ์ 대기열
- 직렬 단말과 네이티브 ฮาร์ดแวร์_ค่า 경계
- 관리 เคอร์เนล_ค่า 전체 자동 시험

세부 การแมป_ค่า 범위와 아직 필요한 네이티브 연결은 [기능 대응표](문서/ฟีเจอร์_การแมป.md)에 기록한다.

## 빌드와 시험

새 네이티브 구현은 `compiler/`와 `os/`에 있다. 기존 `ดั้งเดิม_แหล่ง/`의 JVM 관리 커널은 그대로 보존하며, 두 구현의 시험과 기능 범위는 서로 다르다.

```sh
cd /home/user/jkoros
make                 # 네이티브 계산 예제 + Java เคอร์เนล_ค่า ELF
make iso             # os/build/kernel.iso
make run             # QEMU 직렬 단말; help 입력 (종료는 Ctrl+A, X)
make run-gui         # ISO를 QEMU 화면/PS2 키보드로 ดําเนินการ_คําสั่ง
make vbox            # 전용 VirtualBox VM 자동 สร้าง_167eff27·ดําเนินการ_คําสั่ง (GUI)
make vbox-status     # VirtualBox สถานะ_ค่า·ISO·직렬 บันทึก_สถิติ เส้นทาง ยืนยัน
make test-vbox       # VirtualBox แอป_ลิ้นชักแอป สถานะ_ค่า กระบวนการ_ค่า_รายการ 시험 (ค่าจริง_ข้อมูล VM เปลี่ยนแปลง_ค่า 없음)
make test            # คอมไพเลอร์ 시험 + ELF/ISO 부팅 및 คําสั่ง 입력 시험
make apps            # 독립 ผู้ใช้ ELF แอป_f5044b9b สร้าง
make test-network    # ผู้ใช้ โหมด_ค่า·UDP 왕복·ความจํา_ข้อมูล ป้องกัน_ค่า 시험
make test-java       # 게스트 javac/JVM + OpenJDK 양방향 교차 ดําเนินการ_คําสั่ง 시험
make posix-kor       # ไทย C 헤더와 ค่าจริง_ข้อมูล เคอร์เนล_ค่า 호출 ไลบรารี
make test-posix      # แฟ้ม/UDP/เก็บ_ค่า/Java แฟ้ม รับเข้า_ส่งออก 시험
make -C os run-store # 전용 เก็บ_ค่า 매체로 QEMU 부팅
make legacy-test     # 아래 기존 JVM 관리 커널의 47개 시험
```

`compiler/`는 호스트의 `javac`를 문법·ชนิด_ค่า 검사 전단으로 사용하고 เอง 바이트코드→x86 변환기로 ELF32 기계어를 만든다. 빌드할 때는 JDK가 필요하지만 생성된 커널과 ELF는 ภายนอก_ค่า JVM 없이 실행된다. 전체 Java, วัตถุ_ค่า 모델, 표준 라이브러리와 기존 관리 เคอร์เนล_ค่า 전체의 AOT 변환은 아직 지원하지 않는다. 자세한 สนับสนุน_ค่า 문법과 명령은 [คอมไพเลอร์ 안내](compiler/안내.md), ค่าจริง_ข้อมูล 부팅 기능과 한계는 [네이티브 ระบบปฏิบัติการ 안내](os/안내.md)를 참고한다.

네이티브 셸에 เอง 제한형 `javac`와 `java`를 추가했다. `edit Demo.java`로 소스를 입력하고 `.save`로 저장한 ย้อนกลับ_ค่า `javac Demo.java`, `java Demo`로 **게스트 내부에서 컴파일하고 ดําเนินการ_คําสั่ง**할 หมายเลข 있다. ค่าเริ่มต้น 예제는 `javac Hello.java`, `java Hello`다. 파일은 RAM에서 동작하며, 전용 เก็บ_ค่า 매체를 연결하면 `sync`로 재부팅 후에도 보존할 หมายเลข 있다. **OpenJDK/JDK 전체 이식은 아니며**, 단일 คลาส_ค่า·คงที่_ค่า ฟังก์ชัน_ค่า·จํานวนเต็ม·สตริง_ค่า·โรค/반복문과 일부 표준 호출을 지원한다. สนับสนุน_ค่า คลิป, ภายนอก_ค่า แฟ้ม 적재와 시험은 [Java 개발 สภาพแวดล้อม 안내](문서/자바개발환경.md)에 있다.

네이티브 셸에서 `apps`, `run hello first second`, `net`, `run netcheck`를 사용할 หมายเลข 있다. 독립 ELF를 ring 3에 적재하고 `int 0x80` 호출을 통해 ข้อความออก·อาร์กิวเมนต์·UDP 네트워크를 제공한다. 별도 โฮสต์ 터미널에서 `python3 os/เครื่องมือ/자료되돌리기.py --port 9000`을 실행한 ย้อนกลับ_ค่า 게스트에서 `run udp 10.0.2.2 9000 hello`로 ค่าจริง_ข้อมูล 왕복을 확인한다. 새 แอป_f5044b9b ทะเบียน_รายการ, API 및 제한은 [ผู้ใช้ ดําเนินการ_คําสั่ง·네트워크 안내](os/ผู้ใช้/안내.md)를 참고한다. ปัจจุบัน_รายการ QEMU RTL8139·คงที่_ค่า IPv4·UDP 전용이며 TCP/DNS는 미지원이며, 전용 IDE เก็บ_ค่า 형식과 POSIX แฟ้ม/UDP 일부 기능을 추가했다.

`make vbox`는 `jkoros operating system` 전용 VM을 만들고 디스크 없이 ISO로 부팅한다. ดําเนินการ_คําสั่ง 중이면 유지하고, เก็บ_ค่า·일시정지 상태이면 재개하며, 꺼져 있을 때만 새 ISO를 빌드해 연결한다. VirtualBox에서 부팅과 셸의 ผู้ใช้ แอป_f5044b9b 실행을 확인했다. 다만 ปัจจุบัน_รายการ VirtualBox용 네트워크 드라이버는 없어 네트워크 장치를 비활성화한다. UDP 시험에는 `make run`을 사용한다. 상태별 동작과 새 สร้าง 반영 방법은 [VirtualBox ดําเนินการ_คําสั่ง 안내](문서/가상상자실행.md)에 있다.

기존 관리 커널만 시험하려면:

```sh
cd /home/user/jkoros
make -f เปิด_รายการ.mk 검사
make -f เปิด_รายการ.mk โฮสต์
```

`โฮสต์`는 여전히 JVM 관리 계층의 การกระทํา 시험이다. `make -f เปิด_รายการ.mk รุ่น_รูป`는 새 `os/`의 제한형 네이티브 เคอร์เนล_ค่า ISO를 만든다. 기존 `ดั้งเดิม_แหล่ง/`의 ระบบแฟ้ม·กระบวนการ_ค่า·เครือข่าย_สแตก 구현 전체를 이 ISO에 이식했다는 의미는 아니다.

ไทย ฟังก์ชัน_ค่า·ตัวแปร_ค่า_541034c4·แฟ้ม 이름과 ค่าจริง_ข้อมูล C API는 [posix-kor](posix-kor/안내.md)에 있다. 게스트 Java에서는 `FileInputStream`·`FileOutputStream`의 단일 ไบต์_ค่า 입출력도 지원한다. 전체 POSIX·OpenJDK·Swing 지원으로 확대된 것은 아니다.

ภายนอก_ค่า 배포용 `pack.sh` / `unpack.sh`와 자동 의존성 복원은 [การกระจาย_ค่า 안내](distribution/README.md)를 참고하세요.
