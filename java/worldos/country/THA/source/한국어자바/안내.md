# ไทย Java 도우미 ไลบรารี

OpenJDK 11 이상과 함께 쓰는 프로젝트 เจ้าของ_ค่า API다. 표준 Java ไลบรารี 전체의 번역판을 뜻하지 않는다. 기존 Java API·키워드·ข้อยกเว้น·자료형은 그대로 함께 쓴다.

전체 22개 도우미 메서드의 อาร์กิวเมนต์·반환값·제약, ระบบปฏิบัติการ 안의 사용법, Python·C++ 호출 방법은 **[ไทย ไลบรารี ผู้ใช้_เส้นบอกแนว](ผู้ใช้_เส้นบอกแนว.md)**에 정리했다. [Python 호출 예제](예제/다른언어/파이썬호출.py)와 [C++ JNI 호출 예제](예제/다른언어/자바호출.cpp)도 제공한다.

`make`로 `build/한국어자바.jar`를 만든다. `javac -encoding UTF-8 -cp build/한국어자바.jar 예제/인사.java`로 예제를 컴파일한다. 실행은 `java -cp build/한국어자바.jar:예제 인사`다.

`인사` 예제는 그래픽 화면이 없으면 แฟ้ม·문자·스레드 결과와 안내만 출력한다. Swing 창은 그래픽 세션에서 실행해야 한다. QEMU에서는 [그래픽 ดําเนินการ_คําสั่ง 안내](../platforms/rpi4/README.md)의 `make run`으로 부팅한 ย้อนกลับ_ค่า VNC 데스크톱의 터미널을 사용한다.

| คลาส_ค่า | 제공 기능 |
|---|---|
| แฟ้ม | UTF-8 텍스트·ไบต์_ค่า อ่าน/เขียน, 디렉터리·รายการ_รายการ |
| 문자 | UTF-8 แปลง_ค่า_4633b7f3, NFC นอร์มัลไลซ์_ค่า, รหัส_ค่า 포인트 หมายเลข, 언어별 낱말 경계 |
| 통신 | HTTP(S) คําขอ, 제한시간을 가진 TCP เชื่อมต่อ |
| 작업 | 스레드 เรียกใช้งาน·합류·รอเดี๋ยว_ค่า, 작업 แอป_ลิ้นชักแอป |
| 화면 | Swing 이벤트 처리와 หน้าต่าง สร้าง_167eff27 |
| พื้นที่ทํางาน | รหัสต้นฉบับ แก้ไข_ค่า·คอมไพล์_แหล่ง·ดําเนินการ_คําสั่ง·ดําเนินการ_คําสั่ง แฟ้ม สร้าง_167eff27 화면 |

`char`는 UTF-16 รหัส_ค่า 단위이므로 이모지 등을 한 글자로 처리할 때 รหัส_ค่า 포인트 또는 문자 경계 API를 사용한다. 파일은 UTF-8로 저장한다. OpenJDK의 모든 Java2D/ฟอนต์_ค่า/입력기 조합을 각각 검증한 것은 아니다.

이름은 ปัจจุบัน_รายการ 의미가 분명한 ไทย 용례를 사용했다. 개별 명칭의 역사적 어원 검토를 완료했다고 주장하지 않는다. ทรัพยากร_ค่า 종료와 ข้อยกเว้น 처리는 표준 API의 계약을 따른다.
