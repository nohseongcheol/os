# Java 네이티브 ระบบปฏิบัติการ

이 문서는 기존 **x86 เคอร์เนล_ค่า**을 설명한다. Raspberry Pi 4의 เอง ARM64 สภาวะเริ่มต้น 이식은 [별도 안내](../platforms/rpi4-native/README.md)를 참고한다. 아래 x86 ผู้ใช้ ELF·네트워크·IDE เก็บ_ค่า 기능이 ARM64에 모두 이식된 상태는 아니다.

Java 원문을 เอง AOT 후단으로 x86 기계어로 컴파일해 부팅하는 작은 운영체제다. 커널과 별도로 เอง 제한형 Java คอมไพเลอร์·JVM ELF를 ผู้ใช้ 모드에 적재할 หมายเลข 있다. Linux, engos, koros4와 ภายนอก_ค่า OpenJDK는 게스트에 적재하지 않는다. 부팅 진입과 ฮาร์ดแวร์_แปลง/물리 ความจํา_ขอบเขต 접근은 어셈블리이며, 문자 단말·입력 กระบวนการ_ค่า_รายการ·คําสั่ง แยกวิเคราะห์_ค่า·작업 ส่วน_ค่า 관리는 `รหัสต้นฉบับ/*.java`에 있다.

## 게스트 Java 개발

`javac Hello.java`, `java Hello`로 부팅된 ระบบปฏิบัติการ 안에서 คอมไพล์_แหล่ง·실행한다. `edit FILE.java`와 `.save`로 소스를 작성하며 `ls`, `cat`, `rm`을 제공한다. RAM 파일은 최대 8개, 각각 16KiB이다. 전용 IDE 매체를 연결하면 `sync`로 보존할 หมายเลข 있다. 이 기능은 เอง 제한형 구현이며 전체 OpenJDK/JDK 호환은 아니다. 사용법·สนับสนุน_ค่า 문법·แฟ้ม 적재·교차 시험은 [Java 개발 สภาพแวดล้อม](../문서/자바개발환경.md)에 있다. `make test-java`로 검증한다.

## 빌드와 ดําเนินการ_คําสั่ง

`compiler/`가 요구하는 도구에 더해 ISO 생성에는 `grub-file`, `grub-mkrescue`, GRUB BIOS มอดูล_ค่า, `xorriso`가 필요하다. 실행에는 QEMU 또는 VirtualBox가 필요하다. ปัจจุบัน_รายการ 설치된 도구만 사용한다. `make run-store`는 새 전용 가상 เก็บ_ค่า 매체를 만들어 연결한다. VirtualBox 실행기는 이 프로젝트가 만든 전용 VM만 설정하고 다른 VM은 변경하지 않는다. 가상 메모리는 ค่าเริ่มต้น 64MiB이며 최소 16MiB가 필요하다.

```sh
cd /home/user/jkoros/os
make                 # build/kernel.elf
make iso             # build/kernel.iso (ผู้ใช้ ELF กลุ่ม_ค่า 포함)
make run             # ELF 직접 부팅, 직렬 단말
make run-gui         # GRUB ISO 부팅, VGA 창과 PS/2 자판
make vbox            # 상위 폴더의 실행기로 전용 VirtualBox VM ดําเนินการ_คําสั่ง
make vbox-status     # 전용 VirtualBox VM สถานะ_ค่า ยืนยัน
make test            # ELF와 ISO 두 경로의 ค่าจริง_ข้อมูล 부팅/입력 시험
make apps            # ผู้ใช้ 프로그램만 สร้าง
make test-network    # ผู้ใช้ ดําเนินการ_คําสั่ง/UDP/ป้องกัน_ค่า 시험
```

`make run`은 QEMU의 직렬 표준 입출력을 쓴다. `Ctrl+A`를 누른 ย้อนกลับ_ค่า `X`로 QEMU를 종료할 หมายเลข 있다. `halt`는 게스트 CPU만 정지시키므로 QEMU หน้าต่าง/프로세스는 별도로 닫는다. 폴링 방식이라 รอเดี๋ยว_ค่า 중에도 โฮสต์ CPU를 사용할 หมายเลข 있다.

VirtualBox는 `make vbox`로 실행한다. 새 전용 VM을 ความจํา_ข้อมูล 64MiB, BIOS, 광학 드라이브 부팅으로 자동 설정하며 디스크는 필요 없다. ค่าจริง_ข้อมูล VirtualBox 5.2.42에서 부팅, Java เอง 시험, เชลล์ 입력, `run hello vbox`의 ring 3 실행과 정상 종료를 확인했다. ปัจจุบัน_รายการ 통신 드라이버는 QEMU의 RTL8139 전용이며 VirtualBox의 PCnet/E1000에서는 네트워크를 사용할 หมายเลข 없어 네트워크 장치를 비활성화한다. เก็บ_ค่า สถานะ_ค่า 재개와 새 สร้าง 반영 방법은 [VirtualBox ดําเนินการ_คําสั่ง 안내](../문서/가상상자실행.md)에 있다.

## 셸에서 ผู้ใช้ แอป_f5044b9b ดําเนินการ_คําสั่ง 및 네트워크 호출

독립 ELF32 ดําเนินการ_คําสั่ง 파일을 적재해 **ring 3**에서 실행한다. `int 0x80` 시스템 호출을 통해 단말 ข้อความออก, อาร์กิวเมนต์ คิวรี_ค่า, UDP เปิด·ส่ง·รับ·닫기를 제공한다. ผู้ใช้ 코드를 เคอร์เนล_ค่า 함수로 직접 호출하는 구조가 아니다.

```text
jkoros> apps
jkoros> run hello first second
jkoros> net
jkoros> run netcheck
jkoros> run udp 10.0.2.2 9000 hello
```

마지막 명령의 응답을 받으려면 호스트의 별도 터미널에서 `python3 /home/user/jkoros/os/เครื่องมือ/자료되돌리기.py --port 9000`을 먼저 실행한다. 상세 API, แอป_f5044b9b ผนวก_รายการ, อีเมล 공간과 제한은 [ผู้ใช้ ดําเนินการ_คําสั่ง·네트워크 안내](ผู้ใช้/안내.md)에 있다.

부팅 ยืนยัน 문구:

```text
JKOROS NATIVE JAVA
자바 기계어 เคอร์เนล_ค่า เรียกใช้งาน
JAVA SELFTEST PASS
USER ELF: ring 3 / paging / int 0x80
help | info | mem | alloc | free N | echo TEXT | clear | test | halt
apps | run NAME [ARGS] | net
READY
jkoros>
```

## 구현한 기능

- GRUB Multiboot 1 ELF 부팅, x86 ป้องกัน_ค่า โหมด_ค่า GDT, BSS เริ่มต้น, 64KiB ตัวถูกดําเนินการ_สแตก.
- Java ฟังก์ชัน_ค่า ค่าจริง_ข้อมูล 실행과 부팅 ข้อมูลระบบ มาร์กเกอร์_ค่า ยืนยัน.
- COM1 직렬 รับเข้า_ส่งออก, VGA 문자 화면·เคอร์เซอร์_ค่า·스크롤·ลบ_รายการ.
- PS/2 ค่าเริ่มต้น 자판, 좌우 Shift, Enter, Backspace. นามสกุล_ค่า คีย์_ค่า/마우스 자료는 คําสั่ง 입력으로 쓰지 않는다.
- 길이 128의 คําสั่ง 입력 버퍼, ยาวเกิน_ค่า 방지, CR/LF กระบวนการ_ค่า_รายการ.
- `help`, `info`, `mem`, `alloc`, `free N`, `echo TEXT`, `clear`, `test`, `halt`.
- 4KiB 작업 ส่วน_ค่า 8개의 จัดสรร_ที่เก็บ·ส่งคืน_เมตริก·재사용과 중복 ส่งคืน_เมตริก 방지.
- Java อาร์เรย์_ค่า 256KiB 영역의 ขนาด·ตัวห้อย_ค่า 검사와 런타임 ข้อผิดพลาด 중단.
- อ่าน 전용 JKAP ดําเนินการ_คําสั่ง กลุ่ม_ค่า, ELF32 ส่วน_ค่า/จุดเข้าใช้งาน ตรวจสอบความถูกต้อง, ผู้ใช้ โหมด_ค่า·อาร์กิวเมนต์·ออก_แอป รหัส_ค่า.
- เคอร์เนล_ค่า/ผู้ใช้ 페이지 สิทธิ์_ค่า 분리, TSS, IDT, PIT 100Hz, ผู้ใช้ CPU ข้อยกเว้น กระบวนการ_ค่า_รายการ 및 ดําเนินการ_คําสั่ง ค่าเวลา 상한.
- PCI RTL8139 폴링 드라이버, ARP, คงที่_ค่า IPv4, UDP 검사합·송수신·รอเดี๋ยว_ค่า 제한.

`mem`의 Upper memory는 Multiboot의 1MiB 위쪽 연속 ความจํา_ข้อมูล ขนาด(KiB)이며, 전체 ความจํา_ข้อมูล 지도 분석이나 자유 물리 ความจํา_ข้อมูล 수치가 아니다. `alloc`은 이미 확보한 จํานวนเต็ม อาร์เรย์_ค่า 안의 작업 ส่วน_ค่า 번호를 반환한다. 일반 물리 เพจ_ค่า จัดสรร_ที่เก็บ, อีเมล อีเมล_ขอบเขต 또는 ผู้ใช้ กระบวนการ_ค่า ความจํา_ข้อมูล 관리가 아니다.

## 명시적인 한계

이 커널은 **ผู้ใช้ 프로그램을 한 번에 하나 실행하는 สภาวะเริ่มต้น เคอร์เนล_ค่า**이다. PIT IRQ0만 사용하며 키보드와 NIC는 폴링한다. ผู้ใช้ CPU 예외는 해당 프로그램을 끝내고 셸로 복귀시키지만 เคอร์เนล_ค่า 예외는 중단한다. ดําเนินการ_คําสั่ง 시간은 약 3초로 제한한다. 완전한 선점 다중 กระบวนการ_ค่า 스케줄러, FAT/ext 등 일반 디스크 ระบบแฟ้ม, TCP·DNS·DHCP·IPv6·HTTP, 전체 POSIX, 일반 วัตถุ_ค่า 모델/GC는 아직 없다. 전용 IDE แฟ้ม 보존과 POSIX แฟ้ม/UDP 일부 기능은 구현했다. JVM은 RAM 파일의 단일 클래스를 ดําเนินการ_คําสั่ง 시 적재하며 일반 ClassLoader나 JAR 로딩은 지원하지 않는다. 네이티브 ดําเนินการ_คําสั่ง 파일은 สร้าง 시 อ่าน 전용 묶음에 넣으며, 일반 Linux ELF를 실행하는 환경이 아니다. 기존 `../ดั้งเดิม_แหล่ง/`의 JVM 관리 เคอร์เนล_ค่า 전체를 이식한 것도 아니다.

Java 식별자는 한국어다. 직렬 출력은 이 프로젝트의 한글(BMP 문자)을 UTF-8로 표시한다. VGA는 ค่าเริ่มต้น ASCII 글꼴만 사용하므로 한글 자리에 `?`가 나온다. คําสั่ง 입력도 ปัจจุบัน_รายการ ASCII만 지원하며 한글 ฟอนต์_ค่า·입력기 및 보조 평면 문자 출력은 후속 작업이다. `test`는 작은 배열을 새로 할당하고 GC가 없으므로 무한 반복하지 않는다.

## 자동 시험

`시험/부팅시험.py`는 디스크 없는 독립 QEMU를 생성해 다음을 검증하고 종료한다.

- ELF 직접 부팅 및 GRUB ISO 부팅.
- Java เอง 시험과 UTF-8 직렬 문구.
- คําสั่ง แสดง_ความช่วยเหลือ·ข้อมูลระบบ·ความจํา_ข้อมูล·ข้อความออก·ข้อผิดพลาด 입력·화면 ลบ_รายการ.
- 작업 ส่วน_ค่า 8개 จัดสรร_ที่เก็บ, 부족 กระบวนการ_ค่า_รายการ, ส่งคืน_เมตริก/중복 ส่งคืน_เมตริก/재할당.
- 직렬 줄바꿈·백스페이스·긴 입력 กระบวนการ_ค่า_รายการ.
- QEMU PS/2 คีย์_ค่า 입력으로 `info` ดําเนินการ_คําสั่ง, `halt` 정지.

성공 로그는 `build/부팅시험.json`에 남는다. 로컬 Unix 소켓을 금지하는 샌드박스에서는 시험 도구에 해당 권한이 필요하다. 시험 도중 새로 만든 QEMU만 종료하며 기존 VM과 ค่าจริง_ข้อมูล 디스크는 건드리지 않는다.

`시험/การทดสอบ_ผู้ใช้_เครือข่าย.py`는 ELF/ISO 각각에서 ผู้ใช้ ELF, ค่าจริง_ข้อมูล ring 3, อาร์กิวเมนต์, โฮสต์ 루프백 UDP 왕복, 1,023/1,024바이트 24회 연속 왕복, ค่าเวลา 초과, NIC 없음, ความจํา_ข้อมูล/ฮาร์ดแวร์_แปลง เข้าถึง_รายการ 차단, CPU ข้อยกเว้น, 무한 สปรินต์_ค่า, 잘못된 ELF를 시험한다. `build/การทดสอบ_ผู้ใช้_เครือข่าย.json`에 게스트 기록과 호스트가 받은 데이터의 길이·해시를 저장한다. `시험/แพคเก็ต_การทดสอบ.py`는 ค่าจริง_ข้อมูล Java มูลค่าตามสัญญา 처리기에 손상된 패킷을 넣어 2,201개 경계/검사합 조건을 검사한다. โฮสต์ 루프백 외 ภายนอก_ค่า 서버에는 시험 트래픽을 보내지 않는다.

부트 경계는 GNU의 [Multiboot 명세](https://www.gnu.org/software/grub/manual/multiboot/multiboot.html)를 따른다.

새 파일서술자·C ABI·IDE เก็บ_ค่า·Java แฟ้ม 흐름의 범위와 ไทย 명명 대응은 [posix-kor 안내](../posix-kor/안내.md)에 있다. `make test-posix`로 ELF/ISO 실행과 재부팅 보존을 검증한다.
