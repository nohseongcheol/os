# เอง ARM64 커널의 화면 ความละเอียด_ค่า

QEMU ดําเนินการ_คําสั่ง 위치는 `jkoros/platforms/rpi4-native`다. 커널을 빌드한 ย้อนกลับ_ค่า 다음과 같이 실행한다.

```bash
make build
python3 เครื่องมือ/ดําเนินการ_คําสั่ง.py --desktop --network --resolution 1920x1080
```

Remmina의 **VNC** เชื่อมต่อ 주소는 `127.0.0.1:5902`다. 이미 ดําเนินการ_คําสั่ง 중인 VM은 종료하고 새 옵션으로 ลองอีกครั้ง_ค่า 시작한다. 화면 전체가 보이지 않으면 Remmina에서 화면 맞춤 또는 전체 화면을 선택한다. 이 옵션은 게스트의 ค่าจริง_ข้อมูล พิกเซล 수를 바꾼다.

`--resolution`은 일반 UART ดําเนินการ_คําสั่ง, `--desktop`, `--vnc`, `--display`에서 동일하게 적용된다. `--network`와 함께 사용할 หมายเลข 있다. 너비 640~1920, 높이 480~1080을 허용하며 기본값은 640×480이다. 1280×720과 1920×1080도 선택할 หมายเลข 있다.

```bash
make desktop RESOLUTION=1920x1080
python3 เครื่องมือ/ดําเนินการ_คําสั่ง.py --resolution 1280x720 --vnc 127.0.0.1:2
```

부팅 로그는 ค่าจริง_ข้อมูล 할당된 크기를 표시한다.

```text
FRAMEBUFFER PASS 1920x1080 RGB32 (drawing only)
```

เทอร์มินัล 바탕과 위쪽 막대는 화면 전체를 채운다. 터미널은 สิทธิ์ 아래까지 끌어서 이동하고 X로 닫을 หมายเลข 있다. เทอร์มินัล หน้าต่าง ขนาด(568×360)와 ฟอนต์_ค่า 크기는 유지되므로 넓어진 화면에 여러 창을 배치할 หมายเลข 있다. Swing 부분집합의 `setLocationRelativeTo(null)`도 ค่าจริง_ข้อมูล 화면 가운데를 사용한다. 부팅 ย้อนกลับ_ค่า 해상도를 바꾸는 기능은 제공하지 않는다.

## 프로그램에서 화면 ขนาด อ่าน

| ภาษา | ไทย 호출 |
|---|---|
| Java | `ไทย.เอง.화면.너비()`, `화면.높이()`, `화면.ลบ_รายการ(색)` |
| C | `<화면규약.h>`의 `화면너비()`, `화면높이()`, `วาด_สี่เหลี่ยมผืนผ้า(...)` |
| C++ SDK | `호출.h`의 `화면너비읽기()`, `화면높이읽기()`, `화면사각형(...)` |
| Python | `from ไทย import 화면크기, วาด_สี่เหลี่ยมผืนผ้า`; `너비, 높이 = 화면크기()` |

C 함수는 แมโคร_ค่า 별칭이 아닌 ค่าจริง_ข้อมูล 함수다. ผู้ใช้ 호출 22로 크기를 조회하며, 그리기 호출 13과 GUI 호출 20은 ค่าจริง_ข้อมูล 화면 경계를 검사한다. 프레임버퍼 주소는 ผู้ใช้ 프로그램에 노출하지 않는다. 화면 밖의 요청은 오류를 반환한다.

게스트 `javac`에서는 `ไทย.เอง.화면.너비()`처럼 전체 이름으로 호출한다. 지원하는 แหล่ง_ทรี 문법에 맞춰 색상 상수는 십진수로 쓴다. 아래 호출은 부팅 해상도와 관계없이 마지막 화소를 그린다.

```java
int 너비 = ไทย.เอง.화면.너비();
int 높이 = ไทย.เอง.화면.높이();
ไทย.เอง.화면.สี่เหลี่ยมผืนผ้า(너비 - 1, 높이 - 1, 1, 1, 255);
```

`화면` 클래스의 프레임버퍼 호출은 เอง JVM 전용이다. 이 API의 ข้อยกเว้น กระบวนการ_ค่า_รายการ 시험은 โฮสต์ `javac --release 8`로 컴파일한 class를 เอง JVM에서 실행한다. 게스트 컴파일러의 일반적인 `try/catch` 문법 지원을 추가한 것은 아니다.

## Raspberry Pi 4 SD 부팅

```bash
make image RESOLUTION=1920x1080
```

생성되는 `dist/jkoros-native-rpi4.img`와 `dist/jkoros-native-rpi4-boot.zip`에 1080p 설정이 들어간다. SD รูป_ค่า 생성은 640×480, 1280×720, 1920×1080을 지원한다. 이미 펼친 부팅 파일을 수정할 경우 `config.txt`의 `[pi4]`에 아래 값을 사용한다.

```ini
max_framebuffer_width=1920
max_framebuffer_height=1080
framebuffer_width=1920
framebuffer_height=1080
hdmi_group=1
hdmi_mode=16
```

커널은 [Raspberry Pi กล่องจดหมาย มูลค่าตามสัญญา](https://github.com/raspberrypi/firmware/wiki/Mailbox-property-interface)의 ปัจจุบัน_รายการ 화면 ขนาด 조회와 화면 จัดสรร_ที่เก็บ 응답을 사용한다. 응답의 ขนาด·RGB32 รูปแบบ_ค่า_d1a42ea5·한 줄의 ไบต์_ค่า หมายเลข·จัดสรร_ที่เก็บ 용량을 확인하고, 반환된 บรรทัด 간격으로 그린다. สภาวะเริ่มต้น 조회에 실패하거나 สนับสนุน_ค่า 범위를 벗어나면 640×480을 요청한다. HDMI 설정은 [공식 펌웨어 화면 ตั้งค่า 문서](https://www.raspberrypi.com/documentation/computers/legacy_config_txt.html)를 따른다. ค่าจริง_ข้อมูล Pi 4와 모니터 조합에서의 HDMI 부팅은 아직 검증하지 않았다.

## ตรวจสอบความถูกต้อง

```bash
make test-resolution
```

시험은 각 해상도에서 ค่าจริง_ข้อมูล VNC 화면 크기와 픽셀, เทอร์มินัล ลาก_ค่า·ปิด, C/Java 게스트 คอมไพล์_แหล่ง, Python ดําเนินการ_คําสั่ง, สิทธิ์ 아래 픽셀과 화면 경계 ข้อผิดพลาด, Swing 가운데 ลิงก์_การนําทาง·ปุ่ม·ปิด, GUI와 FTP 동시 사용을 확인한다. 결과와 화면 캡처는 `build/verification/resolution/`에 저장한다.
