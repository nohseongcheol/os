# Raspberry Pi 4 เอง Java เคอร์เนล_ค่า — ผู้ใช้ ดําเนินการ_คําสั่ง 기반

ปัจจุบัน_รายการ เอง 코드의 COSL 상업 โรค, 제3자 고지 및 LGPL 재연결 자료는 [COSL การกระจาย_ค่า 안내](COSL배포안내.md)를 참고한다. สลับ_โหมด 전 GPL 구성의 판단은 [이전 라이선스 검토](สิทธิการใช้งาน_รีวิว.md)에 기록했다.

ไทย 통신·ข้อยกเว้น 사용법은 [ไทย Java API](한국어자바/안내.md), ฟังก์ชัน_ค่า·ตัวแปร_ค่า_541034c4·แฟ้ม 이름의 변경과 어원 근거는 [명명 안내](명명/안내.md)를 참고한다.

Linux 없이 부팅하는 เอง AArch64 커널이다. Java AOT เคอร์เนล_ค่า 위에 **บรรทัดคําสั่ง เชลล์, 게스트 Java คอมไพเลอร์·JVM, MicroPython, EL0 C++ ดําเนินการ_คําสั่ง, แฟ้ม·UDP 루프백 시스템 호출, 여러 한글 GUI เทอร์มินัล·vi ตัวแก้ไข·Swing 부분집합**을 제공한다. 커널의 แฟ้ม ข้อมูล/정책·루프백 โอน_ค่า·เชลล์ 상태는 Java, 화면 합성·พิกเซล เปลี่ยนแปลง_ค่า·ตัวชี้·클리핑도 Java로 구현하며, CPU/MMU/อุปกรณ์_ค่า 경계와 เทอร์มินัล·อักขระ_ค่า 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 เอง 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 ดําเนินการ_คําสั่ง, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 แบบผ่านสาย_ค่า 송수신은 아직 미검증이다.** ดําเนินการ_คําสั่ง·เพื่อน_e05f319b·รหัสผ่าน_ค่า 확인은 [ภายนอก_ค่า เพื่อน_e05f319b 안내](ภายนอก_เพื่อน_เส้นบอกแนว.md)에 정리했다.

셸은 EL1 เคอร์เนล_ค่า, `java` 등 ผู้ใช้ ดําเนินการ_คําสั่ง 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 ดําเนินการ_คําสั่ง·เพื่อน_e05f319b 방법 및 ค่าจริง_ข้อมูล 검증은
[ดําเนินการ_คําสั่ง 계층과 ภายนอก_ค่า 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 ค่าจริง_ข้อมูล ดําเนินการ_คําสั่ง 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 คงที่_ค่า ELF는 `run --linux ชื่อแฟ้ม_ข้อความ`으로 실행한다. [ELF·Linux ABI สนับสนุน_ค่า 범위와 동일 바이너리 시험](실행파일규약.md).

GUI와 네트워크는 `python3 เครื่องมือ/ดําเนินการ_คําสั่ง.py --desktop --network`로 함께 사용한다. Java·C·Python의 ไทย 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 부팅 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 หมายเลข 있다. Remmina에서 **F9/Shift+Space/한·ศูนย์_ตัวถูกดําเนินการ คีย์_ค่า**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·ค่าจริง_ข้อมูล TCP/UDP·แฟ้ม ไบต์_ค่า·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java 창예제`로 ไทย Swing 예제를 실행한다. เทอร์มินัล 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 ปัจจุบัน_รายการ คอลัมน์_ค่า·แถว_ค่า 수를 보여 준다.

ดําเนินการ_คําสั่ง 버튼 화면은 5×7 영문 글꼴을 쓰며, เทอร์มินัล 창은 Noto CJK/DejaVu에서 생성한 한글·Unicode 비트맵 글꼴을 쓴다. UART와 ค่าจริง_ข้อมูล 프레임버퍼의 한글 표시를 시험한다. 루프백은 동일 เคอร์เนล_ค่า 내부의 เดตาแกรม 전달이며 IP 패킷을 Ethernet으로 내보내는 드라이버가 아니다. 바깥 IPv4는 lwIP TCP/UDP 스택으로 보조 UART SLIP 경로를 사용한다. `python3 เครื่องมือ/ดําเนินการ_คําสั่ง.py --network`로 QEMU NAT를 연결하고 `ftpd start`로 서비스를 시작한다.

Java의 정확한 API·문법·ดําเนินการ_คําสั่ง 제한과 ไทย 사용법은 [เอง JVM과 ไทย ไลบรารี](자바실행환경.md)에 정리했다. คลาส_ค่า แฟ้ม/JAR 배포는 [한국어자바](한국어자바) 소스에서 재현한다. 기존 Linux판 `ไทย.자바`와 별도인 `ไทย.เอง` 패키지다.

**vi·여러 หน้าต่าง·Swing·한글 Java/Python/C/C++·posix-kor 예제는 [한글 개발 매뉴얼](개발안내.md)에 정리했다.**

GUI เทอร์มินัล ดําเนินการ_คําสั่ง·단축키·เชลล์ คําสั่ง·제한은 [셸과 เทอร์มินัล 사용법](셸과터미널.md)에 정리했다.

## ปัจจุบัน_รายการ 컴퓨터에서 ดําเนินการ_คําสั่ง

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

ออก_แอป: **Ctrl+A ถัดไป_รายการ X**. 게스트 C/AOT เครื่องมือ 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. โฮสต์ 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. คอมไพเลอร์ 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/เส้นทาง/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` สนับสนุน_ค่า 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 ดําเนินการ_คําสั่ง**한다. 기존 한 อักขระ_ค่า 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 อาร์กิวเมนต์ 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

| คําสั่ง | การกระทํา |
|---|---|
| `help` / `info` | คําสั่ง·ค่าจริง_ข้อมูล 구현 สถานะ_ค่า |
| `ls` / `cat FILE` / `rm FILE` | RAM แฟ้ม รายการ_รายการ·เนื้อหา_ค่า·삭제 |
| `vi FILE` | ผู้ใช้ ขอบเขต_ค่า vi 부분집합, 한글 แก้ไข_ค่า·เก็บ_ค่า·검색·되돌리기 |
| `edit FILE` | แฟ้ม 전체를 새로 입력; 단독 `.` 줄로 เก็บ_ค่า, Ctrl-C로 ยกเลิก_ศัลยกรรม |
| `javac FILE.java` / `java CLASS [ARGS]` | เอง 제한형 Java คอมไพล์_แหล่ง·ดําเนินการ_คําสั่ง |
| `python FILE.py [ARGS]` / `python -c 'CODE'` | MicroPython คอมไพล์_แหล่ง·ดําเนินการ_คําสั่ง |
| `load FILE` / `hex FILE` | 16진수 바이너리 입력/ข้อความออก; 입력은 단독 `.` 줄로 เก็บ_ค่า |
| `run FILE.elf [ARGS]` / `run cpp` | 업로드한 เอง ABI ELF / 내장 C++ 예제 |
| `net test` / `tasks` / `selftest` | UDP 루프백 / 협력식 작업 / EL0 ป้องกัน_ค่า 시험 |
| `gui` / `terminal` | ดําเนินการ_คําสั่ง 화면 / 한글 GUI เทอร์มินัล; F12로 เทอร์มินัล เปิด·ปิด |
| `samples` | 삭제한 ค่าเริ่มต้น 예제 กู้คืน_สถานะ; 기존 파일은 보존 |

예를 들어 `edit 인사.java`를 입력한 ถัดไป_รายการ 아래 소스를 입력한다.

```java
public class 인사 { public static void main(String[] args) { int ค่า = 7; System.out.println("한글=" + ค่า); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 인사.java`, `java 인사`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. ยกเลิก_ศัลยกรรม·잘못된 16진수·ความจุ_ค่า 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, ดําเนินการ_คําสั่ง 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 คําสั่ง 인수는 최대 32개다. ยกคําพูด·백슬래시·เชลล์ ตัวแปร_ค่า_541034c4·파이프·리다이렉션 범위는 [เชลล์ 설명](셸과터미널.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, อีเมล **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode 입력·명시적 วาง_ค่า·ดําเนินการ_คําสั่ง 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 เครื่องมือ/ดําเนินการ_คําสั่ง.py --desktop --network
# 다른 ฮาร์ดแวร์_แปลง: python3 เครื่องมือ/ดําเนินการ_คําสั่ง.py --desktop --port 5903
```

종료는 실행한 โฮสต์ 터미널에서 Ctrl+C다. 기존 `python3 เครื่องมือ/ดําเนินการ_คําสั่ง.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. ค่าจริง_ข้อมูล Pi4 USB 입력기는 아직 없으며, VNC เชื่อมต่อ 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 ค่าจริง_ข้อมูล C++/UDP ELF ดําเนินการ_คําสั่ง, `Hello.java` คอมไพล์_แหล่ง 후 JVM ดําเนินการ_คําสั่ง, `hello.py` ดําเนินการ_คําสั่ง, GUI เทอร์มินัล 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 대화형 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 ความจํา_ข้อมูล·CPU 문맥을 보관한다. เชลล์·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

예비 microSD에 รุ่น_รูป บันทึก_สถิติ 도구로 `.img`를 기록하거나 FAT32 부팅 파티션 최상위에 ZIP 내용을 푼다. รุ่น_รูป 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 ค่าเริ่มต้น EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD แฟ้ม 구성·เคอร์เนล_ค่า 체크섬 검사와 물리 บอร์ด 부팅 검증은 별개다. MMU ใช้_ค่า 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 부팅 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 ไทย API ใช้_ค่า

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/파일예제.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int เริ่ม_ผู้ใช้_แอป(int)`이다. ผู้ใช้ C++는 FP/SIMD를 사용할 หมายเลข 있다. เคอร์เนล_ค่า C/Java AOT는 일반 레지스터만 사용하므로 ข้อยกเว้น กระบวนการ_ค่า_รายการ 중 ผู้ใช้ FP 상태를 건드리지 않는다. ผู้ใช้ จุดเข้าใช้งาน_ค่า 시 FP 상태를 초기화하고 เคอร์เนล_ค่า 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int เริ่ม_ผู้ใช้_แอป(int) {
    int แฟ้ม = เปิด_แฟ้ม("인사.txt", 읽고쓰기 | 없으면만들기 | 내용비우기, 0600);
    if (แฟ้ม < 0) return 1;
    const char เนื้อหา_ค่า[] = "안녕하세요";
    int ผลลัพธ์ = 파일자료쓰기(แฟ้ม, เนื้อหา_ค่า, sizeof(เนื้อหา_ค่า) - 1);
    ปิด_แฟ้ม(แฟ้ม);
    return ผลลัพธ์ == sizeof(เนื้อหา_ค่า) - 1 ? 0 : 2;
}
```

[แฟ้ม 예제](ผู้ใช้/파일예제.cpp)와 [통신 예제](ผู้ใช้/통신예제.cpp)가 ค่าจริง_ข้อมูล 부팅 시험 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 แฟ้ม กระบวนการ_ค่า_รายการ 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 소켓 함수는 ปัจจุบัน_รายการ 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 เคอร์เนล_ค่า 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 ถัดไป_รายการ 도구를 사용하면 **새 QEMU를 부팅해 업로드한 ค่าจริง_ข้อมูล 바이트를 재확인한 ย้อนกลับ_ค่า 게스트에서 ดําเนินการ_คําสั่ง**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 เครื่องมือ/ดําเนินการ_แฟ้ม.py build/jkoros-native-sdk/demo.elf
python3 เครื่องมือ/ดําเนินการ_แฟ้ม.py 예제/Hello.java "한글 อาร์กิวเมนต์"
python3 เครื่องมือ/ดําเนินการ_แฟ้ม.py 예제/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 เคอร์เนล_ค่า 묶음에 포함되어 이 แฟ้ม 한도를 적용받지 않는다. **C++ 컴파일러는 โฮสต์ SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 ไลบรารี, PT_TLS, PT_INTERP, PT_DYNAMIC, ดําเนินการ_คําสั่ง·เขียน 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 ดัชนี·อีเมล คลิป·오류는 [ผู้ใช้ ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `파일저장확정`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 สิทธิ์_ค่า·dup/fcntl은 없다. 디렉터리와 ชั้น_ค่า/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, รับ_ค่า 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. ผู้ใช้ ออก_แอป 시 열린 แฟ้ม 서술자와 소켓을 회수한다.

## Java와 Python의 정확한 คลิป

เอง `javac`는 버전 49 `.class`를 생성하며 JVM은 สนับสนุน_ค่า 명령으로 구성된 버전 45–52 클래스를 실행한다. คงที่_ค่า ฟังก์ชัน_ค่า·재귀·int/boolean/char/String·โรค/สปรินต์_ค่า·สตริง_ค่า 결합과 일부 แฟ้ม 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/องค์ประกอบ_ค่า_40acfcb7 자모 식별자를 처리한다. Unicode ตัวระบุ_ค่า 전체 การค้นหา_ตาราง·Unicode แหล่ง_ทรี 이스케이프는 구현하지 않았다. 게스트 แหล่ง_ทรี 컴파일러는 일반 วัตถุ_ค่า·ข้อยกเว้น·Thread 구문을 아직 컴파일하지 못한다. โฮสต์ `javac --release 8`로 만든 สนับสนุน_ค่า 부분집합 클래스는 เอง JVM 0.4의 วัตถุ_ค่า·ข้อยกเว้น·Thread·UDP와 ไทย API를 사용할 หมายเลข 있다. Swing은 문서화한 เอง API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [เอง JVM 설명](자바실행환경.md)이 기준이다. 상세 ภาษา 범위는 [공유 Java เครื่องมือ 설명](../../문서/자바개발환경.md)을 참고하되, 그 문서의 x86 เชลล์/เก็บ_ค่า/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 แหล่ง_ทรี**를 เอง AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 ฟังก์ชัน_ค่า·คลาส_ค่า·ข้อยกเว้น·리스트/พจนานุกรม·Unicode·GC·가변 ความแม่นยํา_ค่า 정수를 제공한다. ปัจจุบัน_รายการ 구성은 จํานวนเต็ม 빌드로 `float`, `complex`, `math`가 없으며 CPython 전체 표준 ไลบรารี, pip, subprocess, threading, 일반 socket과 ค่าเริ่มต้น `open()` แฟ้ม 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 วัตถุ_ค่า·모듈은 ออก_แอป 시 회수되고 RAM 파일만 ถัดไป_รายการ 실행에 남는다.

`import jkoros`로 ถัดไป_รายการ 시스템 연결을 쓴다. 모두 SVC를 통해 เอง Java 커널에 접근한다.

| ฟังก์ชัน_ค่า | การกระทํา |
|---|---|
| `stdin(limit)` | ปัจจุบัน_รายการ 표준 입력에서 최대 limit바이트(0…16384)를 bytes로 읽음; EOF는 빈 bytes, UART ข้อมูล 없음은 OSError(11) |
| `read(name)` | ชั้น_ค่า/절대 RAM 경로의 แฟ้ม 전체를 bytes로 읽음 |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 เก็บ_ค่า, 쓴 ไบต์_ค่า หมายเลข ส่งคืน_เมตริก |
| `remove(name)` | RAM แฟ้ม 삭제 |
| `rect(x, y, w, h, color)` | 선택한 ค่าจริง_ข้อมูล 화면 ขนาด 안의 สี่เหลี่ยมผืนผ้า รูปวาด_ค่า; 기존 보드의 RGB32 ค่า |
| `ticks_ms()` | 부팅 후 밀리초, 32비트 วงกลม_ค่า |
| `udp_open(port)` | 127.0.0.1의 UDP 소켓 เปิด/ผูก_ปลายทาง; 0은 자동 ฮาร์ดแวร์_แปลง |
| `udp_send(fd, port, data)` | 루프백 ปลายทาง_ค่า_a0fbc067 포트에 str/bytes 버퍼 โอน_ค่า |
| `udp_recv(fd)` | `(bytes, 보낸포트)` ส่งคืน_เมตริก; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | 소켓 ปิด |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```

이식 รหัส_ค่า: [python/](파이썬연결/), [ผู้ใช้ Java เชื่อมต่อ](ผู้ใช้/자바연결.c). 공식 [MicroPython 이식 안내](https://docs.micropython.org/en/latest/develop/porting.html)를 참고했다. แหล่ง_ทรี URL·แฮช_แฟ้ม·라이선스는 [vendor 안내](vendor/README.md)에 기록했다.

## 남은 작업

| ถัดไป_รายการ สเตจ_ค่า | 완료 แสดง_ราก |
|---|---|
| 영속 เก็บ_ค่า·ดําเนินการ_คําสั่ง แฟ้ม 입력 | SD/MMC 및 디스크 แฟ้ม 시스템, 시스템/ผู้ใช้ 볼륨; ปัจจุบัน_รายการ ELF แฟ้ม 실행은 RAM에 한정 |
| 일반 프로세스·스레드 | 프로세스별 อีเมล อีเมล_ขอบเขต, 선점 스케줄러, TLS, ซิงค์/รอเดี๋ยว_ค่า, 신호, mmap/mprotect |
| libc와 C++ 런타임 | เอง ABI용 libc, malloc/free, 표준 รับเข้า_ส่งออก·นาฬิกา·สภาพแวดล้อม·locale, libstdc++/ข้อยกเว้น กระบวนการ_ค่า_รายการ ตรวจสอบความถูกต้อง |
| CPython | 해당 libc와 OS API 대상으로 이식·교차 빌드하고 แฟ้ม/Unicode/스레드/소켓 시험 |
| OpenJDK/JRE | HotSpot OS เลเยอร์_ค่า, GC/JIT/스레드/신호/동적 연결과 Java 네이티브 ไลบรารี 이식; javac/java ค่าจริง_ข้อมูล ดําเนินการ_คําสั่ง |
| ภายนอก_ค่า 네트워크 | 추가한 GENET/PHY·DHCP 드라이버의 ค่าจริง_ข้อมูล บอร์ด 송수신 ตรวจสอบความถูกต้อง, DNS·Wi-Fi |
| GUI นามสกุล_ค่า | USB HID, 게스트 입력기·문자 조판, Swing หน้าต่าง ขนาด 조절·클리핑 นามสกุล_ค่า, 전체 AWT/Swing 이식 |

이 표는 남은 작업이며 구현 완료 목록이 아니다. QEMU Pi4 모델에는 GENET Ethernet과 PCIe root port가 없어 ภายนอก_ค่า 네트워크 드라이버는 실물 검증도 필요하다. [QEMU อุปกรณ์_ค่า 지원표](https://www.qemu.org/docs/master/system/arm/raspi.html)

ฮาร์ดแวร์_ค่า 및 ABI 참고: [BCM2711 ชิ้นส่วนประกอบ](https://datasheets.raspberrypi.com/bcm2711/bcm2711-peripherals.pdf), [Pi4 GIC อีเมล](https://github.com/raspberrypi/linux/blob/rpi-6.12.y/arch/arm/boot/dts/broadcom/bcm2711.dtsi), [mailbox มูลค่าตามสัญญา](https://github.com/raspberrypi/firmware/wiki/Mailbox-property-interface), [Arm ELF64](https://github.com/ARM-software/abi-aa/blob/main/aaelf64/aaelf64.rst), [Arm FP ควบคุม_ค่า 레지스터 คําจํากัดความ_ค่า](https://github.com/ARM-software/arm-trusted-firmware/blob/master/include/arch/aarch64/arch.h).


## ไทย C ชนิดข้อมูล·Python ข้อผิดพลาด·รวม ติดตั้ง_ค่า

C 네트워크 API는 `struct 인터넷통신주소`, enum 상수와 ค่าจริง_ข้อมูล ไทย 함수로
구현한다. แมโคร_ค่า 별칭을 사용하지 않으며 이전 pk_* ABI도 유지한다.
Python 예제는 `ระบบ_ข้อผิดพลาด`, `ข้อผิดพลาด.ดัชนี`, `ข้อผิดพลาด.설명`을 사용한다.

`python3 เครื่องมือ/ดําเนินการ_คําสั่ง.py --desktop --network --pip`로 시작하면 게스트에서
`pip install micropython-bisect==3.3.3`을 사용할 หมายเลข 있다. 현재는 โฮสต์ 중계를
이용하는 제한형 MicroPython แหล่ง_ทรี 설치기이며 CPython pip·자동 의존성 해결·C 확장은
미지원이다. 설치한 `/lib` 자료는 RAM이다. [사용법과 제한](파이썬꾸러미.md).

## 화면 ขนาด การเลือก_ค่า

`python3 เครื่องมือ/ดําเนินการ_คําสั่ง.py --desktop --network --resolution 1920x1080`으로 Full HD 화면을 사용한다. 기본값은 640×480이며 1280×720도 가능하다. เทอร์มินัล ขยับ_ค่า, Swing 가운데 ลิงก์_การนําทาง, Java·C·Python 그리기도 ค่าจริง_ข้อมูล 크기를 따른다. SD 영상은 `make image RESOLUTION=1920x1080`으로 만든다. [ตั้งค่า·ไทย API·ตรวจสอบความถูกต้อง 안내](ความละเอียดของหน้าจอ.md).

## ไทย 직접 API와 화면 รีเฟรช

`example/java`는 `실행할일`, `동작받이`, `แอคชัน_ข้อสังเกต`, `ปุ่ม`, `กิจกรรม_คิว`,
`งานเบื้องหลัง`, `เรียกใช้งาน()`을 사용할 หมายเลข 있다. ไทย GUI/가닥을 เอง JVM에 직접
연결했으며, 표준 Swing/Thread를 감싸지 않는다. สตริง_ค่า 등 javac의 표준
계약과 전체 แหล่ง_ทรี 검토 범위는 [명명 안내](명명/안내.md), 사용법과 호환성 변경은
[ไทย Java API](한국어자바/안내.md)를 본다.

เทอร์มินัล ขยับ_ค่า·ขนาด 변경은 바뀐 영역만 합성하고 달라진 화소만 표시한다.
[화면 รีเฟรช 설명](자바실행환경.md#เทอร์มินัล-부분-รีเฟรช),
