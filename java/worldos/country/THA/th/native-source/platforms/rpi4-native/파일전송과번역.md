# เอง ARM64 เคอร์เนล_ค่า: FTP, C, JAR와 AOT ดําเนินการ_คําสั่ง

대상은 **Linux를 적재하지 않는 Raspberry Pi 4용 Java AOT เคอร์เนล_ค่า**이다. CPU·อุปกรณ์_ค่า 경계는 C/어셈블리, แฟ้ม 체계와 셸은 Java이며, 이번 TCP/IP 스택은 C로 작성된 lwIP 2.2.0을 이식했다. 게스트 TinyCC와 `jaot`도 EL0에서 실행한다. 호스트에 컴파일을 요청하거나 โฮสต์ JVM으로 대신 실행하지 않는다.

## 먼저 알아둘 สนับสนุน_ค่า 경계

| คําขอ | 이번 구현 | 남은 คลิป |
|---|---|---|
| JAR를 ดําเนินการ_คําสั่ง 파일처럼 ดําเนินการ_คําสั่ง | `java -jar แฟ้ม.jar`, `./แฟ้ม.jar อาร์กิวเมนต์`; Main-Class와 เก็บ_ค่า/DEFLATE ZIP, CRC 검사 | 전체 Java SE, 임의의 모든 JAR 호환성 |
| 게스트 AOT | `jaot แฟ้ม.class -o แฟ้ม.elf`, `jaot แฟ้ม.jar -o แฟ้ม.elf`; ค่าจริง_ข้อมูล ARM64 기계어 สร้าง_167eff27 | วัตถุ_ค่า·ข้อยกเว้น·Thread·Swing·Socket의 AOT แปลง_ค่า_4633b7f3, 여러 애플리케이션 คลาส_ค่า เชื่อมต่อ |
| C คอมไพล์_แหล่ง | 게스트 `cc`/`tcc`, TinyCC C 전처리기·ARM64 생성기·링커; ไทย 식별자와 posix-kor | 전체 libc, 일반 Linux ดําเนินการ_คําสั่ง แฟ้ม, 게스트 C++ คอมไพเลอร์ |
| 업로드한 ELF ดําเนินการ_คําสั่ง | ELF64/AArch64 헤더 검사, 확장자 없는 `./แฟ้ม`; เอง ABI 및 명시적인 제한형 Linux ABI | 일반 Linux 바이너리 호환, 동적 링커, 공유 ไลบรารี |
| ภายนอก_ค่า TCP/UDP | 게스트 lwIP IPv4 ตัวถูกดําเนินการ_สแตก, POSIX 소켓과 JVM의 ตัวเลข_ค่า IPv4 อีเมล | GENET/Wi-Fi 드라이버, DHCP·DNS·TLS, 실물 บอร์ด 네트워크 시험 |
| FTP | 게스트 서비스, 패시브 โอน_ค่า, UTF-8 ชื่อ, STOR/RETR/SIZE/LIST/NLST/MLSD/DELE | TLS·사용자별 สิทธิ์_ค่า·하위 디렉터리·영속 เก็บ_ค่า |
| 한글 Java | 기존 `ไทย.เอง` 클래스와 ภายนอก_ค่า อีเมล UDP 오버로드 | 전체 JDK의 일대일 ไทย การแมป_ค่า API |

JVM은 คลาส_ค่า 버전 45…52의 문서화한 부분집합이다. `java`는 바이트코드 실행기이고, `jaot`가 별도의 네이티브 ดําเนินการ_คําสั่ง 파일을 만든다. **JAR เก็บถาวร_ค่า 해제나 JVM을 함께 묶는 것을 AOT라고 표시하지 않는다.** 지원하지 않는 바이트코드/API는 `jaot`가 진단하고 출력을 만들지 않는다. 기존 ข้อความออก ELF도 คอมไพล์_แหล่ง ความล้มเหลว_ค่า 때 보존한다.

Android의 Dalvik/ART는 일반 JVM คลาส_ค่า/JAR가 아닌 **DEX**를 실행한다. ART의 AOT에는 GC, คลาส_ค่า 로딩, JNI 등 ดําเนินการ_คําสั่ง 기반도 필요하다. 따라서 ART처럼 기계어로 바꾸는 기능만으로 임의의 OpenJDK JAR 및 Swing이 자동 호환되지는 않는다. [Android 공식 런타임 설명](https://source.android.com/docs/core/runtime)

FTP는 루트 RAM 파일만 공개한다. 익명 로그인이며 비밀번호로 권한을 구분하지 않는다. ค่าเริ่มต้น โฮสต์ 바인딩은 `127.0.0.1`이고, ควบคุม_ค่า 포트는 2121, 데이터 포트는 50000…50007이다. `--ftp-port 2122`로 ควบคุม_ค่า 포트를 바꿀 หมายเลข 있다. 동시에 한 FTP 세션을 제공하며 명령이 없는 세션은 60초 후 닫는다. TYPE A도 바이트를 변경하지 않으므로 프로그램은 바이너리 전송한다.

파일은 **64개, 각각 16 KiB**, 경로는 UTF-8 63바이트이다. 부팅 시 준비되는 `/example`도 이 한도를 공유한다. 초과/끊어진 STOR는 기존 파일에 반영하지 않는다. FTP 업로드는 RAM에만 저장되며 재부팅하면 사라진다. 이 제한 때문에 일반적인 대형 JAR 배포판을 그대로 올릴 หมายเลข 없다.

QEMU의 raspi4b에는 GENET Ethernet 장치가 없다. 따라서 `network_bridge.py`가 QEMU NAT의 Ethernet과 보조 UART의 SLIP를 변환한다. **TCP เชื่อมต่อ กระบวนการ_ค่า_รายการ·체크섬·재전송·FTP 명령과 แฟ้ม 저장은 게스트 안에서 수행한다.** โฮสต์ 브리지는 FTP 서버가 아니다. [QEMU 공식 อุปกรณ์_ค่า สนับสนุน_ค่า รายการ_รายการ](https://www.qemu.org/docs/master/system/arm/raspi.html)

이 경로는 QEMU에서 검증했다. 보조 UART의 ค่าจริง_ข้อมูล Pi 4 핀/클럭 설정과 내장 RJ45 GENET 드라이버는 구현·검증하지 않았으므로, SD 이미지에 커널이 포함되어 있다는 사실을 ค่าจริง_ข้อมูล 보드의 LAN/FTP การกระทํา 보장으로 해석하면 안 된다.

## ไทย Java를 게스트에서 컴파일하고 AOT ดําเนินการ_คําสั่ง

게스트 `vi 빛.java`로 ถัดไป_รายการ 소스를 작성한다.

```java
public class 빛 {
    public static void main(String[] อาร์กิวเมนต์) throws Exception {
        int 합 = 0;
        int หมายเลข = 1;
        while (หมายเลข <= 10) {
            합 = 합 + หมายเลข;
            หมายเลข = หมายเลข + 1;
        }
        ไทย.เอง.ข้อความออก.수쓰기(합);
        ไทย.เอง.แฟ้ม.เขียน("aot.txt", "한글 AOT แฟ้ม 😀");
        ไทย.เอง.ข้อความออก.줄쓰기(ไทย.เอง.แฟ้ม.อ่าน("aot.txt"));
    }
}
```

```text
javac 빛.java
java 빛
jaot 빛.class -o 빛.elf
run 빛.elf
```

`jaot`은 클래스의 바이트코드를 C로 변환하고, **게스트 TinyCC**가 ARM64 명령어를 สร้าง_167eff27·연결한다. ดําเนินการ_คําสั่ง 때 JVM 인터프리터를 호출하지 않는다. JAR의 Main-Class가 같은 สนับสนุน_ค่า 범위이면 다음도 가능하다.

```text
jaot 빛.jar -o 빛.elf
run 빛.elf
```

AOT 지원은 한 애플리케이션 클래스의 คงที่_ค่า เมธอด_ค่า/ค่าเขตข้อมูล, int 계열, จํานวนเต็ม 배열과 อ้างอิง, อาร์กิวเมนต์ อาร์เรย์_ค่า, โรค·สาขา·สปรินต์_ค่า, สตริง_ค่า 리터럴, `System.out.print/println`의 int/String, ไทย ข้อความออก·แฟ้ม อ่าน/쓰기로 제한된다. คลาส_ค่า/เมธอด_ค่า 수와 ตัวถูกดําเนินการ_สแตก 등에도 고정 상한이 있다. Java ข้อยกเว้น กระบวนการ_ค่า_รายการ, วัตถุ_ค่า สร้าง_167eff27, 가상 เมธอด_ค่า 일반, switch/wide, long/float/double, invokedynamic, สตริง_ค่า 결합용 StringBuilder, 일반 JDK·Socket·Thread·Swing은 이 AOT 백엔드에서 미지원이다. 내장 NUL/고립된 서로게이트 문자열도 거부한다. 잘못된 อาร์เรย์_ค่า เข้าถึง_รายการ/0으로 나누기 등은 네이티브 런타임 오류로 종료하며 Java ข้อยกเว้น 객체로 전달하지 않는다.

입력 클래스뿐 아니라 **생성된 ELF도 16 KiB 이하**여야 한다. 기계어 확장과 ELF 페이지 จัดแนว_ค่า 때문에 짧은 클래스도 이 한도를 넘을 หมายเลข 있으며, 이 경우 오류를 내고 기존 출력을 보존한다.

게스트 `javac`도 부분집합이다. 일반적인 วัตถุ_ค่า·Thread·Swing 소스는 호스트에서 `javac --release 8`로 컴파일하고, **기존 JVM의 สนับสนุน_ค่า คลิป 안에서** `java`/`java -jar`로 실행한다. 정확한 API는 [JVM 매뉴얼](자바실행환경.md)과 [한글 개발 매뉴얼](개발안내.md)을 참고한다.

JAR는 하나의 애플리케이션 คลาส_ค่า 경로다. 내부 ชื่อ `รวม/แอป_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 ไทย 클래스를 추가로 찾지만 ปัจจุบัน_รายการ 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ZIP64·เข้ารหัสลับ_ข้อมูล ZIP·manifest Class-Path·서명 검증은 지원하지 않는다. JAR 하나가 16 KiB 이하이어도 클래스당/적재 หมายเลข/VM ฮีป_ค่า 제한은 그대로 적용된다.

## C에서 ไทย POSIX 호출

게스트에서 `vi 인사.c`로 작성하거나 FTP로 소스를 업로드한다.

```c
#include <파일규약.h>

int main(void) {
    const char 인사말[] = "เอง ARM64 C에서 한글 POSIX 호출\n";
    int 문서 = เปิด_แฟ้ม("인사.txt", 읽고쓰기 | 없으면만들기 | 내용비우기, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = 파일자료쓰기(문서, 인사말, sizeof(인사말) - 1);
    ปิด_แฟ้ม(문서);
    파일자료쓰기(1, 인사말, sizeof(인사말) - 1);
    return 기록한수 == sizeof(인사말) - 1 ? 0 : 2;
}
```

```text
cc 인사.c -o 인사.elf
run 인사.elf
cat 인사.txt
```

TinyCC의 표준 C จุดเข้าใช้งาน `main`을 사용한다. 기존 โฮสต์ C/C++ SDK의 `เริ่ม_ผู้ใช้_แอป(int)` 진입점과 구분한다. 포함 แฟ้ม·เรียกใช้งาน วัตถุ_ค่า·`libposix-kor-user.a`는 คอมไพเลอร์ 내부의 อ่าน 전용 SDK에 들어 있다. C 전처리기/구조체/ฟังก์ชัน_ค่า/재귀/ตัวชี้/부동소수점 สร้าง_167eff27 등을 사용하되 **일반 libc/libstdc++를 제공한다는 뜻은 아니다**. 제공하지 않는 함수는 เชื่อมต่อ 오류가 난다. คอมไพเลอร์ 자체의 문자/ตัวเลข_ค่า แปลง_ค่า_4633b7f3 지원도 완전한 libc 대체품이 아니다.

`เปิด_แฟ้ม` 등은 별도의 모의 호출이 아닌 기존 `pk_open` 등의 ไทย 매크로이며, ELF의 SVC를 통해 ค่าจริง_ข้อมูล Java แฟ้ม 체계에 도달한다. แฟ้ม/소켓 호출 목록은 [ผู้ใช้ ABI](사용자호출규약.md)에 있다. C/C++ โฮสต์ SDK ดําเนินการ_คําสั่ง 파일도 FTP로 업로드 후 `run` 또는 `./แฟ้ม`로 실행하며 확장자는 필요 없다. Linux ARM64 คงที่_ค่า ELF에는 별도의 제한된 호환 เส้นทาง `run --linux แฟ้ม`을 추가했다. [ELF·Linux ABI 매뉴얼](실행파일규약.md)에 정확한 รูปแบบ_ค่า_d1a42ea5·시스템 호출·อีเมล 제한을 정리했다.

## ไทย 네트워크·작업·화면 API

| คลาส_ค่า | 호출 예 | ดําเนินการ_คําสั่ง เส้นทาง |
|---|---|---|
| `ข้อความออก` | `줄쓰기("안녕")`, `수쓰기(42)` | JVM 및 제한형 AOT |
| `แฟ้ม` | `เขียน("문서.txt", "เนื้อหา_ค่า")`, `อ่าน("문서.txt")` | JVM 및 제한형 AOT |
| `통신` | `เปิด(0)`, `ส่ง(ปลายทาง, "10.0.2.2", 9000, "한글")`, `รับ(ปลายทาง)` | JVM의 UDP |
| `เพื่อน_การโอนถ่ายข้อมูล` | `เชื่อมต่อ("10.0.2.2", 9000)`, `รอการติดต่อ_ปลายทาง(9000)`, `รับ(เซิร์ฟเวอร์_ค่า)` | JVM의 Socket/ServerSocket |
| `작업` | `เรียกใช้งาน(Runnable)`, `기다리기(Thread)`, `หยุดชั่วคราว_งาน()` | JVM의 협력식 เธรด_ค่า |
| `หน้าต่าง`, `วิดเจ็ต` | หน้าต่าง·버튼·อักขระ_ค่า·เขตข้อมูลข้อความ·เหตุการณ์ เชื่อมต่อ | JVM의 Swing 부분집합 |

명명에서는 표준 영어 API를 보존하고 ไทย 호출 계층을 추가한다. `통신(通信)`, `เชื่อมต่อ(連結)`, `ข้อความออก(出力)`은 기존 단어의 뜻을 사용한다. `작업 เธรด_ค่า`은 한 ดําเนินการ_คําสั่ง 흐름을 가닥에 빗댄 기술 표현, `แปลง_ค่า`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

ภายนอก_ค่า 주소는 ตัวเลข_ค่า IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 เอง ABI이며 JVM이 제한된 รอเดี๋ยว_ค่า/재시도를 제공한다. TCP connect 대기는 최대 1초, ผู้ใช้ แอป_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 ดําเนินการ_คําสั่ง ผู้ใช้ 서버와 pthread는 아직 없다. FTP는 ผู้ใช้ แอป_f5044b9b 기한과 별개인 เคอร์เนล_ค่า 서비스다.

게스트의 ผู้ใช้ TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 เครื่องมือ/ดําเนินการ_คําสั่ง.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 ค่าเริ่มต้น ควบคุม_ค่า/데이터 포트와 겹치면 ดําเนินการ_คําสั่ง 전에 거부한다.

## 시험과 สร้าง 재현

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test-ftp
make test
make image
```

`build/verification/ftp/report.json`은 ค่าจริง_ข้อมูล FTP โอน_ค่า, 한글 แฟ้ม, ขนาด 초과 보존, เก็บถาวร_ค่า JAR ดําเนินการ_คําสั่ง, 게스트 C คอมไพล์_แหล่ง/ELF 재업로드, ภายนอก_ค่า Java TCP/UDP, 게스트 javac/AOT 실행을 기록한다. `serial.log`에서 게스트 명령과 결과를 확인할 หมายเลข 있다. 보고서의 เคอร์เนล_ค่า SHA-256과 การกระจาย_ค่า 이미지의 커널을 비교한다.

빌드는 기존 JDK/Clang/AArch64 binutils와 함께 `../rpi4/build/rootfs`의 ARM64 SDK การประกาศ 헤더와 libgcc 산술 보조 함수를 사용한다(`make rpi-prepare`). **musl libc, Linux เคอร์เนล_ค่า, 동적 로더를 게스트에 링크하지 않는다.** TinyCC/lwIP/uzlib 원본과 라이선스·버전 정보는 `vendor/`, 이식 코드는 `ccompiler/`, `network/`, `ผู้ใช้/รวม.c`에 있다.

전체 JDK/AOT JVM으로 확장하려면 타입 ตรวจสอบความถูกต้อง·วัตถุ_ค่า/ข้อยกเว้น/GC·동적 로딩·JNI, 영속 แฟ้ม ระบบปฏิบัติการ_ค่า·mmap/TLS/시그널·스레드 ABI, OpenJDK native ไลบรารี, GUI peer/폰트/입력기, GENET 및 실물 อุปกรณ์_ค่า 검증이 더 필요하다. 이 문서의 ดําเนินการ_คําสั่ง 시험은 그 전체 이식을 대신하지 않는다.
