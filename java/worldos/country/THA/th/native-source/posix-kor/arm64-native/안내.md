# เอง ARM64 Java 커널의 C/C++ แฟ้ม·루프백 เชื่อมต่อ

이 디렉터리는 `platforms/rpi4-native` เอง เคอร์เนล_ค่า 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 ไทย 함수명과 `extern "C"` ABI를 제공한다. `เชื่อมต่อ.c`는 เคอร์เนล_ค่า 안에서 AOT Java แฟ้ม 메서드에 직접 연결하고, `ผู้ใช้_บริดจ์.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. ค่าจริง_ข้อมูล แฟ้ม 처리는 `แฟ้มในหน่วยความจํา.java`, 루프백 เดตาแกรม 처리는 `วนกลับ_เครือข่าย.java`, 연결형 흐름은 `สตรีม_เครือข่าย.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 เคอร์เนล_ค่า 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·ลอย_ชี้_ค่า ศัลยกรรม_ค่า·แฟ้ม·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

สนับสนุน_ค่า: `เปิด_แฟ้ม`, `파일자료읽기`, `파일자료쓰기`, `ปิด_แฟ้ม`, `กรอ_แฟ้ม`, `นําออก_แฟ้ม_รายการ_ชื่อ`, `파일길이정하기`, 보조 ฟังก์ชัน_ค่า `ขนาดแฟ้ม`. ข้อผิดพลาด 시 -1과 작업별 `หมายเลขข้อผิดพลาด`를 반환한다. `파일저장확정`은 RAM 파일이므로 ENOSYS를 반환한다. แฟ้ม 16개, 각 16384바이트, ชื่อ 63바이트, 서술자 16개이며 RAM 디렉터리·ชั้น_ค่า/절대 경로를 제공한다. สิทธิ์_ค่า/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 ค่าจริง_ข้อมูล ไทย 함수와 독립 구조체를 선언한다.
`เปิด_ปลายทาง`, `ผูก_อีเมล`, `ส่ง_เดตาแกรม_ข้อมูล/รับ`, `เชื่อมต่อ_เครือข่าย/기다리기/รับ`는
`ผู้ใช้_บริดจ์.c`에서 SVC를 호출하며 แมโคร_ค่า 별칭이 아니다. `struct 인터넷통신주소`의
`อีเมล_กลุ่ม`, `หมายเลขพอร์ต`, `ที่อยู่อินเทอร์เน็ต.อีเมล_ค่า`을 사용한다. 상수는 enum의
`คลาวด์_กลุ่ม`, `เดตาแกรมซ็อกเก็ต`, `เดตาแกรม_โพรโทคอล`, `สตรีม_เครือข่าย`, `สตรีม_โพรโทคอลการส่งผ่าน`이다.
ไทย·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. ภายนอก_ค่า 통신은 เอง 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. ค่าจริง_ข้อมูล Pi 4 GENET 드라이버는 미지원이다.
소켓도 ค่าจริง_ข้อมูล ฟังก์ชัน_ค่า `ปิด_แฟ้ม`로 닫는다.
