# engos 기능 대응표

이 표는 기존 `ดั้งเดิม_แหล่ง/`의 วัตถุ_ค่า 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [ค่าจริง_ข้อมูล 부팅 기능과 한계](../os/안내.md)를 따로 기록한다.

## 기존 วัตถุ_ค่า 기반 관리 เคอร์เนล_ค่า 전체를 부팅하기 위해 남은 เชื่อมต่อ

ถัดไป_รายการ 항목은 Java 문법만으로 실행할 หมายเลข 없는 CPU/อุปกรณ์_ค่า 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot จุดเข้าใช้งาน_ค่า, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 บริบท_ค่า เก็บ_ค่า
- ค่าจริง_ข้อมูล PIC/PIT/PS2/ATA/PCI ฮาร์ดแวร์_แปลง 및 AMD PCnet DMA วน_ค่า
- Java วัตถุ_ค่า·อาร์เรย์_ค่า ลิงก์_การนําทาง, ข้อยกเว้น, คงที่_ค่า เริ่มต้น, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT สเตจ_ค่า
- FAT 디스크 구역을 ค่าจริง_ข้อมูล ATA 장치와 연결하는 รับเข้า_ส่งออก 접착 เลเยอร์_ค่า

위 관리 계층은 engos 기능의 Java 관리 구현과 โฮสต์ 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot จุดเข้าใช้งาน_ค่า, คงที่_ค่า เริ่มต้น·จํานวนเต็ม อาร์เรย์_ค่า, VGA/직렬/PS2, ตัวแปลคําสั่ง, ผู้ใช้ ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 โฮสต์ 루프백 패킷 왕복을 검증했다. 위 표의 วัตถุ_ค่า 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
