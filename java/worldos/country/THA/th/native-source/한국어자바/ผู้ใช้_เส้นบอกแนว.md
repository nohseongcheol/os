# jkoros ไทย ไลบรารี ผู้ใช้_เส้นบอกแนว

확인일: 2026-09-27. 대상은 `platforms/rpi4`의 **ARM64 Linux + OpenJDK 실행판**이며, QEMU에서도 같은 Java 라이브러리를 사용한다. `os/`의 เอง x86 เคอร์เนล_ค่า 및 `ดั้งเดิม_แหล่ง/`의 관리 เคอร์เนล_ค่า 모형과 구분한다.

## 1. ปัจจุบัน_รายการ 제공하는 ไลบรารี

패키지는 `ไทย.자바`, ระบบปฏิบัติการ 안의 JAR 경로는 `/opt/jkoros/lib/한국어자바.jar`다. **도우미 คลาส_ค่า 5개, 공개 คงที่_ค่า เมธอด_ค่า 22개, 별도 GUI 프로그램인 พื้นที่ทํางาน 1개**가 있다. JAR는 Java 11 이상을 대상으로 빌드하며 ปัจจุบัน_รายการ ARM64 배포판에는 OpenJDK 25가 포함돼 있다.

| คลาส_ค่า | เมธอด_ค่า หมายเลข | 기능 | รหัสต้นฉบับ |
|---|---:|---|---|
| `แฟ้ม` | 9 | UTF-8 텍스트·ไบต์_ค่า แฟ้ม, ไดเรกทอรี_ค่า, รายการ_รายการ | [แฟ้ม.java](รหัสต้นฉบับ/ไทย/자바/แฟ้ม.java) |
| `문자` | 5 | UTF-8 แปลง_ค่า_4633b7f3, NFC นอร์มัลไลซ์_ค่า, รหัส_ค่า 포인트, สตริง_ค่า 경계 | [문자.java](รหัสต้นฉบับ/ไทย/자바/문자.java) |
| `통신` | 2 | HTTP(S) GET, TCP เชื่อมต่อ | [통신.java](รหัสต้นฉบับ/ไทย/자바/통신.java) |
| `작업` | 4 | 스레드 ดําเนินการ_คําสั่ง·รอเดี๋ยว_ค่า, 고정 ขนาด 작업 แอป_ลิ้นชักแอป | [작업.java](รหัสต้นฉบับ/ไทย/자바/작업.java) |
| `화면` | 2 | Swing 이벤트 กระบวนการ_ค่า_รายการ 가닥에 작업 예약, หน้าต่าง สร้าง_167eff27 | [화면.java](รหัสต้นฉบับ/ไทย/자바/화면.java) |
| `พื้นที่ทํางาน` | จุดเข้าใช้งาน `main` | Java รหัสต้นฉบับ แก้ไข_ค่า·เก็บ_ค่า·คอมไพล์_แหล่ง·ดําเนินการ_คําสั่ง | [พื้นที่ทํางาน.java](รหัสต้นฉบับ/ไทย/자바/พื้นที่ทํางาน.java) |

표준 JDK 전체를 한국어로 번역한 라이브러리는 아니다. Java 키워드와 `String`, `Path`, `Socket`, `JFrame`, `IOException` 같은 표준 ชนิดข้อมูล·예외를 함께 사용한다. 이 도우미에 없는 기능은 OpenJDK의 표준 API 또는 별도 라이브러리로 구현한다. 예를 들어 HTTP POST, UDP, Swing ปุ่ม·메뉴에는 각각 표준 Java API를 사용한다.

## 2. Java에서 เริ่ม_งาน

게스트 운영체제의 작업 폴더에서 `사용예.java`를 작성한다.

```java
import ไทย.자바.*;
import java.nio.file.Path;

public class 사용예 {
    public static void main(String[] อาร์กิวเมนต์) throws Exception {
        Path ไดเรกทอรี_ค่า = แฟ้ม.เปิด_ไดเรกทอรี(แฟ้ม.เส้นทาง("사용예자료"));
        Path 문서 = ไดเรกทอรี_ค่า.resolve("인사.txt");
        แฟ้ม.เขียน(문서, "한글 😀");
        String เนื้อหา_ค่า = แฟ้ม.อ่าน(문서);
        System.out.println(เนื้อหา_ค่า);
        System.out.println(문자.코드포인트수(เนื้อหา_ค่า)); // 한, ข้อความ, 공백, 😀 → 4
        Thread งาน_ค่า = 작업.เรียกใช้งาน("인사 작업", () -> System.out.println("작업 ดําเนินการ_คําสั่ง"));
        작업.기다리기(งาน_ค่า);
    }
}
```

```sh
javac -encoding UTF-8 -cp /opt/jkoros/lib/한국어자바.jar 사용예.java
java -cp .:/opt/jkoros/lib/한국어자바.jar 사용예
```

로그인 환경에 ค่าเริ่มต้น `CLASSPATH`도 설정돼 있지만, 명시적인 `-cp`는 다른 ดําเนินการ_คําสั่ง 환경에서도 경로를 분명하게 한다. 사용자가 `-cp`를 지정하면 필요한 JAR와 คลาส_ค่า 폴더를 모두 그 값에 포함해야 한다.

โฮสต์ 저장소에서는 다음처럼 สร้าง·실행한다. โฮสต์ 경로와 게스트의 `/opt/...` 경로는 서로 다르다.

```sh
cd /home/user/jkoros/한국어자바
make
javac -encoding UTF-8 -cp build/한국어자바.jar 예제/인사.java
java -cp build/한국어자바.jar:예제 인사
```

## 3. 전체 도우미 API

아래 메서드는 모두 `public static`이며, 객체를 만들지 않고 `แฟ้ม.อ่าน(...)`처럼 호출한다. 표의 이름은 ค่าจริง_ข้อมูล แหล่ง_ทรี 및 JAR의 `javap -public` 결과와 대조했다. 선언된 검사 ข้อยกเว้น 외에도 잘못된 อาร์กิวเมนต์ 등에 대한 표준 Java ดําเนินการ_คําสั่ง 시 예외가 발생할 หมายเลข 있다.

### แฟ้ม: `ไทย.자바.แฟ้ม`

`Path`는 `java.nio.file.Path`, `List`는 `java.util.List`다.

| เมธอด_ค่า | ส่งคืน_ชนิด | การกระทํา·โรค |
|---|---|---|
| `เส้นทาง(String ชื่อ)` | `Path` | 이름을 เส้นทาง 객체로 แปลง_ค่า_4633b7f3. ค่าจริง_ข้อมูล 파일을 만들지는 않음 |
| `อ่าน(Path เส้นทาง)` | `String` | แฟ้ม 전체를 UTF-8 텍스트로 읽음 |
| `เขียน(Path เส้นทาง, String เนื้อหา_ค่า)` | `Path` | UTF-8 เก็บ_ค่า. 파일이 없으면 생성하고, 있으면 기존 내용을 비움 |
| `바이트읽기(Path เส้นทาง)` | `byte[]` | แฟ้ม 전체를 ไบต์_ค่า 배열로 읽음 |
| `바이트쓰기(Path เส้นทาง, byte[] เนื้อหา_ค่า)` | `Path` | ไบต์_ค่า เก็บ_ค่า. 없으면 생성하고, 있으면 기존 내용을 비움 |
| `เปิด_ไดเรกทอรี(Path เส้นทาง)` | `Path` | 필요한 상위 폴더까지 สร้าง_167eff27 |
| `있는가(Path เส้นทาง)` | `boolean` | 존재 여부 ยืนยัน. 확인할 หมายเลข 없는 경우도 `false`งาน_ค่า หมายเลข 있음 |
| `ลบ_รายการ(Path เส้นทาง)` | `boolean` | 삭제했으면 `true`, 없으면 `false`. 폴더의 재귀 삭제는 아님 |
| `รายการ_รายการ(Path เส้นทาง)` | `List<Path>` | 바로 아래 항목을 เส้นทาง จัดแนว_ค่า 순서로 ส่งคืน_เมตริก. 재귀 탐색은 아님 |

`เส้นทาง`, `있는가`를 제외한 위 메서드는 `IOException`을 선언한다. `เขียน`와 `바이트쓰기`는 상위 폴더를 자동으로 만들거나 내용을 이어 쓰지 않는다. 필요한 폴더는 먼저 생성한다. 큰 파일은 전체 내용을 메모리에 담는 대신 표준 Java 스트림·ช่อง_ค่า API를 사용하는 방식으로 작성할 หมายเลข 있다.

### 문자: `ไทย.자바.문자`

| เมธอด_ค่า | ส่งคืน_ชนิด | การกระทํา·โรค |
|---|---|---|
| `เข้ารหัส(String เนื้อหา_ค่า)` | `byte[]` | 문자열을 UTF-8 바이트로 แปลง_ค่า_4633b7f3 |
| `ถอดรหัสลับ_ข้อมูล(byte[] เนื้อหา_ค่า)` | `String` | UTF-8 바이트를 문자열로 แปลง_ค่า_4633b7f3. 잘못된 입력은 대체 문자로 กระบวนการ_ค่า_รายการ |
| `นอร์มัลไลซ์_ค่า(String เนื้อหา_ค่า)` | `String` | 유니코드 NFC นอร์มัลไลซ์_ค่า. 예: องค์ประกอบ_ค่า_40acfcb7 자모 `ᄀ` + `ᅡ` → `가` |
| `코드포인트수(String เนื้อหา_ค่า)` | `int` | UTF-16 รหัส_ค่า 단위가 아닌 유니코드 รหัส_ค่า 포인트 หมายเลข |
| `낱말(String เนื้อหา_ค่า, Locale ภาษา)` | `List<String>` | กําหนด_ค่า 언어의 `BreakIterator` 낱말 경계로 나눈 ข้อความ_ช่วง |

`낱말`은 공백·문장부호 구간도 반환한다. 자연어 형태소 분석기나 공백을 제거한 คํา_ค่า รายการ_รายการ API는 아니다. `นอร์มัลไลซ์_ค่า`는 입력기나 แปล_แหล่ง 기능이 아니다. รหัส_ค่า 포인트 หมายเลข 역시 사람이 보는 อักขระ_ค่า 수와 항상 같지는 않다. 여러 รหัส_ค่า 포인트로 이루어진 결합 문자·가족 이모지 등을 구분해야 한다.

### 통신: `ไทย.자바.통신`

| เมธอด_ค่า | ส่งคืน_ชนิด | การกระทํา·โรค |
|---|---|---|
| `가져오기(URI อีเมล, Duration ขีดจํากัดเวลา)` | `HttpResponse<String>` | HTTP(S) GET. เชื่อมต่อ 및 คําขอ ขีดจํากัดเวลา ตั้งค่า. ตอบกลับ 본문을 UTF-8로 แยกวิเคราะห์_ค่า |
| `เชื่อมต่อ_ปลายทาง(String อีเมล, int ฮาร์ดแวร์_แปลง, int 제한밀리초)` | `Socket` | TCP เชื่อมต่อ 후 같은 값으로 อ่าน 제한시간도 ตั้งค่า |

`가져오기`는 `IOException`, `InterruptedException`을 선언한다. 제한시간은 양수다. 404·500 같은 HTTP ข้อผิดพลาด 상태도 응답으로 반환하므로 `statusCode()`로 판단하고 `body()`로 본문을 읽는다. ปัจจุบัน_รายการ 구현은 호출마다 HTTP 클라이언트를 만들며 자동 리다이렉트 설정을 추가하지 않는다.

`เชื่อมต่อ_ปลายทาง`는 `IOException`을 선언한다. 연결된 소켓은 호출자가 `close()` 또는 try-with-resources로 닫아야 한다. 제한밀리초의 0은 제한 없음이며, เขียน 전체의 วันครบกําหนด_ค่า 시간을 보장하는 옵션은 아니다.

```java
var ตอบกลับ = 통신.가져오기(
    java.net.URI.create("http://127.0.0.1:8000/"),
    java.time.Duration.ofSeconds(5));
System.out.println(ตอบกลับ.statusCode());
System.out.println(ตอบกลับ.body());
```

위 조각은 เมธอด_ค่า 안에서 실행하며 별도로 해당 주소의 서버를 실행해야 한다. Java ข้อยกเว้น 처리가 필요하다.

### 작업: `ไทย.자바.작업`

| เมธอด_ค่า | ส่งคืน_ชนิด | การกระทํา·โรค |
|---|---|---|
| `เรียกใช้งาน(String ชื่อ, Runnable การกระทํา)` | `Thread` | 이름을 지정한 스레드를 만들고 즉시 เรียกใช้งาน |
| `기다리기(Thread เธรด_ค่า)` | `void` | 해당 스레드가 종료할 때까지 `join()` |
| `쉬기(long 밀리초)` | `void` | 호출한 스레드를 กําหนด_ค่า ค่าเวลา 동안 `sleep()` |
| `작업대(int 가닥수)` | `ExecutorService` | 고정 ขนาด 작업 แอป_ลิ้นชักแอป สร้าง_167eff27. 가닥수는 양수 |

`기다리기`, `쉬기`는 `InterruptedException`을 선언한다. 작업 실행기는 ใช้_ค่า 후 `shutdown()`으로 종료하고 필요하면 `awaitTermination(...)`으로 완료를 기다린다. Swing 이벤트 กระบวนการ_ค่า_รายการ 가닥에서 긴 작업이나 `기다리기`를 실행하면 화면이 멈출 หมายเลข 있다.

### 화면: `ไทย.자바.화면`

| เมธอด_ค่า | ส่งคืน_ชนิด | การกระทํา·โรค |
|---|---|---|
| `나중에(Runnable การกระทํา)` | `void` | Swing 이벤트 กระบวนการ_ค่า_รายการ 가닥에 실행을 예약하고 ส่งคืน_เมตริก |
| `หน้าต่าง(String หน้าต่าง_กรรมสิทธิ์, JComponent เนื้อหา_ค่า, int 너비, int 높이)` | `JFrame` | เนื้อหา_ค่า·크기를 지정한 창을 생성해 แสดง_ค่า |

`หน้าต่าง`을 Swing 이벤트 กระบวนการ_ค่า_รายการ เธรด_ค่า 밖에서 부르면 `IllegalStateException`이 발생한다. 그래픽 세션도 필요하다. QEMU에서는 VNC 데스크톱의 터미널에서 실행한다.

```java
화면.나중에(() -> 화면.หน้าต่าง(
    "ไทย 화면", new javax.swing.JLabel("안녕하세요"), 500, 180));
```

반환된 `JFrame`에 표준 Swing API를 추가로 사용할 หมายเลข 있다. 창의 ปิด 동작은 `DISPOSE_ON_CLOSE`다. `화면.나중에`가 반환됐다고 หน้าต่าง 생성이 이미 끝난 것은 아니다.

### พื้นที่ทํางาน: แก้ไข_ค่า·คอมไพล์_แหล่ง GUI

```sh
java -cp /opt/jkoros/lib/한국어자바.jar ไทย.자바.พื้นที่ทํางาน
```

`~/workspace`의 원문을 เปิด·저장하고, `javac`로 컴파일해 `java`로 실행한다. ดําเนินการ_คําสั่ง แฟ้ม 만들기는 `jclassc --target openjdk` 경로를 사용한다. 작업마당은 개발용 프로그램이며 별도의 แฟ้ม·문자 API 클래스가 아니다. 생성하는 ดําเนินการ_คําสั่ง แฟ้ม 방식은 [คอมไพเลอร์ 설명](../compiler/OpenJDK-แฟ้มปฏิบัติการ.md)을 따른다.

## 4. Python과 C++에서 사용할 หมายเลข 있는가?

| เมธอด_โหมด | ปัจจุบัน_รายการ 포함 สถานะ_ค่า | 호출 가능 คลิป |
|---|---|---|
| Java → ไทย JAR | ค่าเริ่มต้น 포함 | 위 22개 메서드와 พื้นที่ทํางาน |
| Python → `java` ลูก_ค่า 프로세스 | Python·Java ค่าเริ่มต้น 포함 | 작은 Java 진입점을 통해 호출하고 표준 ข้อความออก·แฟ้ม 등으로 ผลลัพธ์ ส่งต่อ_ค่า_24592b8a |
| Python → JPype → JVM | JPype는 ค่าเริ่มต้น 배포에 없음 | 별도 ติดตั้ง_ค่า 후 Java คลาส_ค่า·เมธอด_ค่า 호출 가능. 이 배포판의 ARM64/musl/Python 3.14 조합은 ผนวก_รายการ ตรวจสอบความถูกต้อง 필요 |
| C++ → JNI → JVM | `g++`, JNI 헤더, `libjvm.so` 포함 | JVM을 생성하고 ไทย คลาส_ค่า·메서드를 직접 호출할 หมายเลข 있음 |
| Python용 독립 ไทย ไลบรารี | ปัจจุบัน_รายการ ค่าเริ่มต้น 제공 없음 | 필요하면 Python 표준 라이브러리를 감싸는 ไทย 모듈을 별도로 작성 |
| C/C++용 독립 ไทย ไลบรารี | เอง x86 `posix-kor`와 เอง ARM64 커널용 สภาวะเริ่มต้น RAM แฟ้ม 연결이 별도로 존재 | 둘 다 이 Linux/OpenJDK 실행판의 libc 라이브러리는 아님 |

Python의 일반 `import`나 `ctypes.CDLL`로 JAR를 바로 읽을 수는 없다. C++의 `#include`나 일반 네이티브 링커만으로 Java 메서드를 연결할 수도 없다. JVM 프로세스 또는 JVM เชื่อมต่อ 계층을 거쳐야 한다.

### Python: ผนวก_รายการ 패키지 없이 호출

ดําเนินการ_คําสั่ง 가능한 예제 원문은 [문자명령.java](예제/다른언어/문자명령.java), [파이썬호출.py](예제/다른언어/파이썬호출.py)다. Python이 Java 진입점을 실행하고 `문자.코드포인트수`의 จํานวนเต็ม 결과를 받는다. อาร์กิวเมนต์ 목록을 사용하며 เชลล์ คําสั่ง 문자열을 조립하지 않는다. `subprocess.run`의 프로세스 ดําเนินการ_คําสั่ง·ออก_แอป รหัส_ค่า·ข้อความออก กระบวนการ_ค่า_รายการ 방식은 [Python 공식 문서](https://docs.python.org/3/library/subprocess.html)를 따른다.

두 예제 파일을 게스트의 같은 폴더에 복사한 ย้อนกลับ_ค่า 그 폴더에서 실행한다. 예제 แฟ้ม 자체는 ค่าเริ่มต้น 시스템 이미지에 자동 설치돼 있지 않다.

```sh
mkdir -p classes
javac -encoding UTF-8 -cp /opt/jkoros/lib/한국어자바.jar -d classes 문자명령.java
python3 파이썬호출.py --text '한글 😀'
```

ข้อความออก: `Python → ไทย.자바.문자.코드포인트수: 4`

이 예제의 Python ฟังก์ชัน_ค่า `코드포인트수`는 이번 문서의 เชื่อมต่อ 예제이며 기존에 설치된 Python 라이브러리는 아니다. ปัจจุบัน_รายการ 예제는 호출할 때마다 JVM 프로세스를 시작한다. Java วัตถุ_ค่า 자체를 Python으로 가져오는 방식은 아니며, 다른 메서드를 사용하려면 진입점의 อาร์กิวเมนต์·ผลลัพธ์ 형식을 확장한다.

### Python: JPype로 같은 프로세스에서 호출

JPype를 별도 설치한 환경에서는 ถัดไป_รายการ 형태로 연결할 หมายเลข 있다. **아래는 การเลือก_ค่า 가능한 เชื่อมต่อ 방법이며, ปัจจุบัน_รายการ 배포판에 JPype가 설치돼 있거나 ดําเนินการ_คําสั่ง 검증됐다는 뜻은 아니다.** JVM 시작과 `JClass`를 통한 คลาส_ค่า 접근은 [JPype 공식 설명](https://jpype.readthedocs.io/en/latest/userguide.html)을 참고한다.

```python
import jpype

jpype.startJVM(
    "/usr/lib/jvm/java-25-openjdk/lib/server/libjvm.so",
    classpath=["/opt/jkoros/lib/한국어자바.jar"])
try:
    문자 = jpype.JClass("ไทย.자바.문자")
    print(문자.코드포인트수(jpype.JString("한글 😀")))
finally:
    jpype.shutdownJVM()
```

Python·JVM·เชื่อมต่อ 모듈의 CPU 아키텍처가 맞아야 한다. 이 실행판은 ARM64 + musl이므로 일반 x86_64/glibc용 바이너리를 그대로 설치하는 방식은 맞지 않는다. JPype ติดตั้ง_ค่า·패키지 빌드는 이번 문서 작업에서 수행하지 않았다.

### C++: JNI로 직접 호출

[자바호출.cpp](예제/다른언어/자바호출.cpp)는 ค่าจริง_ข้อมูล ดําเนินการ_คําสั่ง 가능한 예제다. JVM을 작업 스레드에서 생성하고 ถัดไป_รายการ 메서드를 찾는다.

```cpp
jclass type = env->FindClass("ไทย/자바/문자");
jmethodID method = env->GetStaticMethodID(
    type, "코드포인트수", "(Ljava/lang/String;)I");
```

JVM สร้าง_167eff27·종료와 스레드 연결은 [JNI Invocation API](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/invocation.html)의 방식이다. `JNIEnv*`는 สร้าง_167eff27·연결된 스레드에서 사용해야 한다. 예제는 Java 예외를 확인하고 JVM 종료까지 처리한다.

게스트에 `자바호출.cpp`를 복사한 ย้อนกลับ_ค่า 컴파일한다. 로그인 환경의 `JAVA_HOME`은 `/usr/lib/jvm/java-25-openjdk`다.

```sh
g++ -std=c++11 -Wall -Wextra -pthread \
  -I"$JAVA_HOME/include" -I"$JAVA_HOME/include/linux" \
  자바호출.cpp -L"$JAVA_HOME/lib/server" \
  -Wl,-rpath,"$JAVA_HOME/lib/server" -ljvm -o 자바호출
./자바호출 /opt/jkoros/lib/한국어자바.jar
```

ข้อความออก: `C++ → ไทย.자바.문자.코드포인트수: 4`

예제는 `한글 😀`을 UTF-16으로 만들어 `NewString`에 전달한다. `NewStringUTF`가 받는 modified UTF-8은 일반 UTF-8과 차이가 있으므로, 일반 UTF-8 이모지 바이트를 그대로 넘기는 예제로 작성하지 않았다. [JNI สตริง_ค่า รูปแบบ_ค่า_d1a42ea5](https://docs.oracle.com/en/java/javase/25/docs/specs/jni/types.html#modified-utf-8-strings)

다른 ไทย 메서드도 JNI 서명과 อาร์กิวเมนต์ 자료형을 맞춰 호출할 หมายเลข 있다. 예를 들어 `Path`를 받는 แฟ้ม API는 먼저 `แฟ้ม.เส้นทาง`로 Java เส้นทาง 객체를 얻어 전달한다. Swing 호출에는 그래픽 세션과 이벤트 กระบวนการ_ค่า_รายการ เธรด_ค่า 규칙도 그대로 적용된다. JNI는 Java 실행을 기계어로 대체하는 기능이 아니며 JVM이 계속 필요하다.

### 기존 posix-kor와의 관계

추가된 [เอง ARM64 เชื่อมต่อ](../posix-kor/arm64-native/안내.md)은 C++에서 AOT Java 커널의 RAM แฟ้ม API를 직접 호출하며, 별도 EL0 ผู้ใช้ 라이브러리로 แฟ้ม/UDP 루프백 SVC 호출도 제공한다. JNI를 사용하지 않는다. 이 문서의 ARM64 **Linux** 및 ไทย Java JAR와는 다른 ดําเนินการ_คําสั่ง 기반이며 เอง 커널은 별도 제한형 Java คอมไพเลอร์/JVM과 MicroPython 1.24.1을 실행한다. MicroPython의 `import jkoros`로 Java เคอร์เนล_ค่า แฟ้ม·UDP 루프백·สี่เหลี่ยมผืนผ้า 호출이 가능하지만 이 문서의 JAR를 가져오는 기능은 아니다. เอง 커널의 전체 OpenJDK/JRE/CPython 이식은 아직 미완성이다.

[posix-kor](../posix-kor/안내.md)에는 `เปิด_แฟ้ม`, `파일자료읽기`, `파일자료쓰기`, `ปิด_แฟ้ม`, `เปิด_ปลายทาง`, `ส่ง_เดตาแกรม_ข้อมูล` 등의 ไทย C 별칭이 있다. 그러나 구현은 **เอง jkoros i386 커널의 `int 0x80` 호출 규약용**이다.

이 `libposix-kor.a`와 เอง `sys/stat.h` 등의 헤더는 ปัจจุบัน_รายการ ARM64 Linux 실행판의 libc/C++용 라이브러리가 아니다. 해당 헤더·바이너리를 ARM64 Linux 프로그램에 그대로 연결해서는 ABI가 맞지 않는다. C++용 ไทย คลาส_ค่า 라이브러리나 Python용 바인딩을 ค่าเริ่มต้น 제공하는 상태도 아니다. ปัจจุบัน_รายการ Linux 실행판에서 그와 같은 독립 API를 제공하려면 Linux 표준 라이브러리를 대상으로 별도로 구현·빌드해야 한다.

## 5. ยืนยัน 범위와 재현

패키지 포함 여부는 [การกระจาย_ค่า 패키지 รายการ_รายการ](../platforms/rpi4/dist/packages.lock.json) 및 สร้าง 루트의 ค่าจริง_ข้อมูล 파일로 확인했다. JNI 헤더는 JDK의 `include/jni.h`, `include/linux/jni_md.h`, JVM 라이브러리는 `lib/server/libjvm.so`에 있다. 사용자가 이후 별도로 설치한 패키지는 이 ค่าเริ่มต้น การกระจาย_ค่า 목록과 다를 หมายเลข 있다.

이번에 **โฮสต์ x86_64/OpenJDK 11에서** Python ลูก_ค่า 프로세스 호출과 C++ JNI 직접 호출을 คอมไพล์_แหล่ง·실행해 각각 ผลลัพธ์ 4를 확인했다. JAR 공개 메서드도 소스와 대조했다. Python เชื่อมต่อ 예제는 ผนวก_รายการ 패키지를 설치하지 않는다.

문서의 Java ใช้_ค่า 예제도 คอมไพล์_แหล่ง·실행했고, 22개 메서드의 문서 포함 여부와 로컬 문서 링크를 확인했다. [예제 ตรวจสอบความถูกต้อง บันทึก_สถิติ](build/다른언어/การตรวจสอบความถูกต้อง_รายงาน.json)

기존 ARM64 QEMU에서는 Java의 แฟ้ม·유니코드·스레드·HTTP 및 Swing 시험 결과가 있다. 이번 Python/C++ เชื่อมต่อ 예제의 **ARM64 게스트 실행과 JPype 설치는 별도 검증하지 않았다.** 이미지와 ดําเนินการ_คําสั่ง 중인 ผู้ใช้ 환경은 이 문서 작업에서 변경하지 않았다. [기존 ระบบปฏิบัติการ ตรวจสอบความถูกต้อง บันทึก_สถิติ](../platforms/rpi4/VERIFICATION.md)

호스트에서 Python 예제를 재현하려면:

```sh
cd /home/user/jkoros/한국어자바
make
mkdir -p build/다른언어
javac -encoding UTF-8 --release 11 -cp build/한국어자바.jar \
  -d build/다른언어 예제/다른언어/문자명령.java
python3 예제/다른언어/파이썬호출.py \
  --jar build/한국어자바.jar --classes build/다른언어
```

โฮสต์ C++ 예제는 위 JNI คอมไพล์_แหล่ง 명령의 JDK 경로를 **โฮสต์ JDK เส้นทาง**로 바꾸고, รหัสต้นฉบับ `예제/다른언어/자바호출.cpp`와 JAR `build/한국어자바.jar`를 지정한다. ARM64 게스트 JDK의 헤더·ไลบรารี 경로를 โฮสต์ x86_64 링크 명령에 섞지 않는다.
