# 中文 Java 輔助器值 庫

OpenJDK 11 이상과 함께 쓰는 프로젝트 所有者值 API다. 표준 Java 庫 전체의 번역판을 뜻하지 않는다. 기존 Java API·키워드·異常·자료형은 그대로 함께 쓴다.

전체 22개 輔助器值 메서드의 實參·已返回值·제약, 操作系統 안의 사용법, Python·C++ 調用 방법은 **[中文 庫 用戶指南](用戶指南.md)**에 정리했다. [Python 調用 範例](範例/其他語言/Python調用.py)와 [C++ JNI 調用 範例](範例/其他語言/Java調用.cpp)도 제공한다.

`make`로 `build/中文Java.jar`를 만든다. `javac -encoding UTF-8 -cp build/中文Java.jar 範例/問候例.java`로 예제를 컴파일한다. 실행은 `java -cp build/中文Java.jar:範例 問候例`第三操作數.

`問候例` 예제는 그래픽 화면이 없으면 檔案·字元·스레드 결과와 안내만 출력한다. Swing 창은 그래픽 세션에서 실행해야 한다. QEMU에서는 [그래픽 執行命令 指南](../platforms/rpi4/README.md)의 `make run`으로 부팅한 後端值 VNC 데스크톱의 터미널을 사용한다.

| 類別值 | 제공 기능 |
|---|---|
| 檔案 | UTF-8 텍스트·位元組值 讀取/寫入, 디렉터리·條目列表 |
| 字元 | UTF-8 轉換值, NFC 正規化值, 程式碼值 포인트 數, 언어별 詞法用機器字 邊界位置值 |
| 通信 | HTTP(S) 申請, 제한시간을 가진 TCP 連接 |
| 任務 | 스레드 運行·합류·等待狀態值, 任務 運行器 |
| 屏幕 | Swing 이벤트 처리와 窗口 生成 |
| 工作區 | 原始碼 編輯值·編譯原始碼·執行命令·執行命令 檔案 生成 屏幕 |

`char`는 UTF-16 程式碼值 단위이므로 이모지 등을 한 글자로 처리할 때 程式碼值 포인트 또는 字元 邊界位置值 API를 사용한다. 파일은 UTF-8로 저장한다. OpenJDK의 모든 Java2D/字體值/입력기 조합을 각각 검증한 것은 아니다.

이름은 當前項目 의미가 분명한 中文 용례를 사용했다. 개별 명칭의 역사적 어원 검토를 완료했다고 주장하지 않는다. 資源值 종료와 異常 처리는 표준 API의 계약을 따른다.
