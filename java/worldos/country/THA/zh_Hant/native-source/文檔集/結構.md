# JThaOS 結構

아래는 物件值 基礎 관리 內核值 전체의 目標物件 구조다. 當前項目 實際資料 啓動 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 操作系統 指南](../os/指南.md)에 實現 범위를 명시한다. 아래의 GC·上下文值 切換模式·檔案系統 등이 새 ISO에 構建全部 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 最小值 부트·트랩 層值
  ↓
Java AOT 실행기와 物件值·陣列值·GC 런타임
  ↓
硬件值 邊界位置值
  ↓
Java 관리 內核值
  ├─ 記憶體空間/頁管理工作/COW
  ├─ 程序值/배정/wait
  ├─ 檔案系統/ELF/POSIX
  └─ 輸入值/存儲裝置設備/通信網絡
```

OpenJDK 자체는 이미 운영체제가 제공하는 檔案, 스레드, 가상 기억공간을 전제로 한다. 따라서 內核值 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 字節碼 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, 上下文值 저장처럼 Java로 표현할 數 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
