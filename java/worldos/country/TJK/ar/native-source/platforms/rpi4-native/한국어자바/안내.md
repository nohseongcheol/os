# العربية Java 통신·إدخال_إخراج·استثناء API

패키지는 `العربية.ذاتي`다. مضيف `javac --release 8`로 컴파일한 class를
ذاتي ARM64 커널의 JVM에서 실행한다. 통신·ملف·استثناء API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 محادثة_قيمة API는 ذاتي JVM 전용이다.
기존 표준 Java مكتبة 전체의 العربية 번역판은 아니다.

```java
import العربية.ذاتي.*;

public class شبكة {
    public static void main(String[] وسائط) throws إدخال_إخراج_استثناء {
        صديق اتصال = صديق.فتح("10.0.2.2", 9000);
        try {
            اتصال.대기시간(700);
            اتصال.مخرجات().كتابة(문자.يرمّز("안녕하세요\n"));
            تدفق_المدخلات إدخال_قيمة = اتصال.إدخال_قيمة();
            مخرجات.كتابة_رقم(إدخال_قيمة.قراءة());
        } catch (대기시간초과예외 خطأ) {
            مخرجات.كتابة_خط(خطأ.설명());
        } finally {
            اتصال.إغلاق();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
فضاء_المستخدم 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 سلسلة_قيمة 리터럴에 사용하는 표준 클래스다. ذاتي 실행기는 `public static void تشغيل()`도 진입점으로 받는다.

## 통신과 بث_قيمة

| فئة_قيمة_55654bf1 | العربية 호출 |
|---|---|
| صديق | `فتح(عنوان, رقم_المنفذ)`, `إدخال_قيمة()`, `مخرجات()`, `대기시간(밀리초)`, `رقم_المنفذ()`, `محلي_رقم_المنفذ()`, `연결됨()`, `أنظمة_المعلومات_مغلق()`, `إغلاق()` |
| يستلم_منفذ | `فتح(رقم_المنفذ)`, `يستلم()`, `رقم_المنفذ()`, `대기시간(밀리초)`, `أنظمة_المعلومات_مغلق()`, `إغلاق()` |
| تدفق_المدخلات | `قراءة()`, `قراءة(byte[])`, `قراءة(byte[], تشغيل, 길이)`, `إغلاق()` |
| تدفق_الإنتاج | `كتابة(int)`, `كتابة(byte[])`, `كتابة(byte[], تشغيل, 길이)`, `내보내기()`, `إغلاق()` |
| مخطط_بيانات_قناة | `فتح(رقم_المنفذ)`, `يرسل(عنوان, رقم_المنفذ, نص)`, `يستلم()`, `대기시간(밀리초)`, `رقم_المنفذ()`, `أنظمة_المعلومات_مغلق()`, `إغلاق()` |
| صديق_نقل | `فتح(...)`, `수신열기(...)`는 위 العربية 객체를 إرجاع_مقياس |
| 검사 | `참인지(شرط, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`قراءة()`의 ملف 끝은 -1, صفيف_قيمة 읽기의 반환값은 الفعلي_بيانات 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. رقم_المنفذ 0은 빈 번호를 자동 배정한다.
UDP 전문은 حديث_عنصر ذاتي 커널에서 512바이트까지 받으며, 주소는 رقم_قيمة IPv4를 사용한다.
`localhost` 루프백 외의 اسم 풀이(DNS)는 ذاتي 커널에 아직 없다.

기존 `صديق_نقل.اتصال/انصات_المشارك/يستلم`, `통신.فتح/يرسل/يستلم`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `صديق`, `يستلم_منفذ`, `مخطط_بيانات_قناة`를 쓴다.

## العربية استثناء

모든 아래 클래스는 قيمة_افتراضية 생성자, `새예외("설명")` 형태의 سلسلة_قيمة 생성자와
`설명()`을 제공한다. الفعلي_بيانات إنشاء 문법은 `new 대기시간초과예외("حالة_انتظار 끝")`이다.

| العربية استثناء | 상위 فئة_قيمة_55654bf1 / 용도 |
|---|---|
| استثناء | `java.lang.Exception`, 직접 던지는 일반 검사 استثناء |
| 실행예외 | `java.lang.RuntimeException` |
| إدخال_إخراج_استثناء | `java.io.IOException`, العربية ملف·통신 API의 검사 استثناء |
| 대기시간초과예외 | `إدخال_إخراج_استثناء`, 통신 대기시간 초과 |
| عنوان_البحث_استثناء | `إدخال_إخراج_استثناء`, عنوان يتحقق فشل_قيمة |
| 파일없음예외 | `إدخال_إخراج_استثناء`, ملف فتح فشل_قيمة |
| 통신예외 | `إدخال_إخراج_استثناء`, 표준 SocketException تحويل_قيمة |
| غير_صالح_وسيطة_استثناء | `java.lang.IllegalArgumentException` |
| رقم_ينسق_فشل | `غير_صالح_وسيطة_استثناء` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| مرجع_فارغ_استثناء | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| حالة_استثناء | `java.lang.IllegalStateException` |
| نوع_بث_استثناء | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| صفيف_مخزن_فشل | `java.lang.ArrayStoreException` |
| محادثة_حالة_استثناء | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 انتظر_قيمة 중단 |

`استثناء`와 `실행예외`는 모든 العربية 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, ملف·통신 전체를 잡으려면 `catch (إدخال_إخراج_استثناء خطأ)`를 쓴다.
العربية API가 표준 إدخال_إخراج 오류를 العربية 예외로 변환한다.
기존 العربية 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
استثناء 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
حديث_عنصر ذاتي JVM에 이 20종을 추가했다. 임의의 فضاء_المستخدم Throwable 하위 فئة_قيمة_55654bf1 전체를
지원하도록 확장했다는 뜻은 아니다.

## يحول_برمجياً_مصدر·ينفذ_أمر

```sh
cd /home/user/jkoros/platforms/rpi4-native
make بنية_نظام
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 اختبارات/자바/한국어통신시험.java
python3 أدوات/ينفذ_ملف.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 فضاء_المستخدم JVM ELF 안에 탑재된다. `.jar`는 مضيف javac의
فئة_قيمة_55654bf1 경로로 사용한다. مصدر_شجرة 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 العربية 예외의 `throws` 선언과 그 import를 인식한다.
ذاتي JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·عنصر_قيمة_2ed200e9·مأخذ_التوصيل_قيمة 예제 전체의 مصدر_شجرة 컴파일은 مضيف javac를 사용한다.
`/example/java/مثالملف.java`는 게스트 javac로도 컴파일할 رقم 있다.

الفعلي_بيانات TCP/UDP 예제는 [مثالشبكة.java](../../../example/java/مثالشبكة.java),
ينفذ_أمر 절차는 [example 안내](../../../example/README.md),
مصدر_شجرة 명명 원칙은 [명명 안내](../명명/안내.md)에 있다.

## Swing نافذة 예제

`/example/java/مثالنافذة.java`와 컴파일된 `.class`가 إقلاع_الآلة 시 준비된다.
`cd /example/java` التالي_عنصر `java مثالنافذة`로 연다. اسم إدخال_قيمة, 인사하기 버튼,
인사말과 نقرة_قيمة 횟수 يحدث, X 닫기를 지원한다.

| 기능 | العربية 직접 API |
|---|---|
| Runnable / run | `실행할일.تنفيذ()` |
| ActionListener / actionPerformed | `동작받이.يستلم_إجراء(إجراء_إشعار إشعار)` |
| ActionEvent | `إجراء_إشعار.أمر_نص()`, `مصدر_الحدث()`, `فهرس()` |
| JFrame | `نافذة(نافذة_عنوان, 폭, ارتفاع_قيمة)`, `يضيف_عنصر(화면구성요소)`, `عرض_نافذة()`, `إغلاق()`, `보이는가()` |
| JButton | `زر(نص, 가로, عمودي_منصب, 폭, ارتفاع_قيمة, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `تسمية(...)`, `حقل_نصي(...)` |
| 공통 화면 عنصر_قيمة | `화면구성요소.يقرأ_نص()`, `كتابة_نص(نص)`, `자리정하기(가로, عمودي_منصب, 폭, ارتفاع_قيمة)` |
| SwingUtilities.invokeLater | `حدث_يدرج.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `خيطالعمل(실행할일)`, `بدء_مهمة()`, `기다리기()`, `살아있는가()`, `العائد_مهمة()` |
| 명령행 | `تشغيل()`, `실행인수.개수()`, `실행인수.نص(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
ذاتي JVM의 `한국어화면호출`, `عملية_محادثة`가 العربية فئة_قيمة_55654bf1·أسلوب_قيمة·서술자를
해석해 화면 요소와 ينفذ_أمر 가닥을 직접 만든다. إجراء 알림도 ذاتي 객체이며
콜백으로 `تنفيذ`와 `يستلم_إجراء`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 ينفذ_أمر 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 ذاتي JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 مضيف JVM에서 무동작 객체가 생기지 않도록 하는 يرفض_قيمة 경로다.
ذاتي JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 رقم 없다. مضيف javac로 컴파일한 عودة_قيمة ذاتي JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import العربية.ذاتي.*;
public class 가닥예제 implements 실행할일 {
    public void تنفيذ() { مخرجات.كتابة_خط("العربية 작업 ينفذ_أمر"); }
    public static void تشغيل() throws 대기중단예외 {
        خيطالعمل محادثة_قيمة = 작업.تشغيل(new 가닥예제());
        작업.기다리기(محادثة_قيمة);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
صفيف_قيمة وسائط 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
ذاتي 실행기는 وسائط 없는 `تشغيل()`을 우선한다.
기존 العربية 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.تشغيل(Runnable)`을 사용하던 코드는 새 العربية 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API دعم_قيمة 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 فئة_قيمة_55654bf1·أسلوب_قيمة 이름과 서술자가 남는다.
العربية اسم 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·أسلوب_قيمة 재정의, native اتصال, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS معرف_قيمة](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS أسلوب_قيمة مرجع](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
