## 빌드와 испытания

새 네이티브 구현은 `compiler/`와 `os/`에 있다. 기존 `устаревший_источник/`의 JVM 관리 커널은 그대로 보존하며, 두 구현의 시험과 기능 범위는 서로 다르다.

```sh

make                 # 네이티브 계산 예제 + Java ядро_ЗНАЧЕН ELF
make iso             # os/build/kernel.iso
make run             # QEMU 직렬 단말; help входные_данные_ЗНАЧЕН (종료는 Ctrl+A, X)
make run-gui         # ISO를 QEMU экран/PS2 키보드로 실행
make vbox            # 전용 VirtualBox VM 자동 генерировать·실행 (GUI)
make vbox-status     # VirtualBox Состояние_ЗНАЧЕН·ISO·직렬 LOG_ЗАПИСЬ путь проверять
make test-vbox       # VirtualBox программа_Launcher Состояние_ЗНАЧЕН Процесс_ЗНАЧЕН_ввод испытания (фактический_данные VM изменить_ЗНАЧЕН 없음)
make test            # компилятор испытания + ELF/ISO запуск_машины 및 команда входные_данные_ЗНАЧЕН испытания
make apps            # 독립 пространство_пользователя ELF программа_f5044b9b сборка
make test-network    # пространство_пользователя МОДА_ЗНАЧЕН·UDP 왕복·Память_данные защитить_ЗНАЧЕН испытания
make test-java       # 게스트 javac/JVM + OpenJDK 양방향 교차 실행 испытания
make posix-kor       # русский C 헤더와 фактический_данные ядро_ЗНАЧЕН 호출 библиотека
make test-posix      # файл/UDP/Store_ЗНАЧЕН/Java файл входные_данные_выход испытания
```

`compiler/`는 호스트의 `javac`를 문법·ТИП_ЗНАЧЕН 검사 전단으로 사용하고 свой 바이트코드→x86 변환기로 ELF32 기계어를 만든다. 빌드할 때는 JDK가 필요하지만 생성된 커널과 ELF는 внешний_ЗНАЧЕН JVM 없이 실행된다. 전체 Java, объект_ЗНАЧЕН 모델, 표준 라이브러리와 기존 관리 ядро_ЗНАЧЕН 전체의 AOT 변환은 아직 지원하지 않는다. 자세한 опора_ЗНАЧЕН 문법과 명령은 [компилятор файл_сведений_eb81d7d9](compiler/файл_сведений_eb81d7d9.md), фактический_данные запуск_машины 기능과 한계는 [네이티브 операционная_система файл_сведений_eb81d7d9](os/файл_сведений_eb81d7d9.md)를 참고한다.

네이티브 셸에 свой 제한형 `javac`와 `java`를 추가했다. `edit Demo.java`로 소스를 입력하고 `.save`로 저장한 BACK_ЗНАЧЕН `javac Demo.java`, `java Demo`로 **게스트 내부에서 컴파일하고 실행**할 수 있다. значение_по_умолчанию 예제는 `javac Hello.java`, `java Hello`다. 파일은 RAM에서 동작하며, 전용 Store_ЗНАЧЕН 매체를 연결하면 `sync`로 재부팅 후에도 보존할 수 있다. **OpenJDK/JDK 전체 이식은 아니며**, 단일 Класс_ЗНАЧЕН·статический_ЗНАЧЕН ФУНКЦИЯ_ЗНАЧЕН·целое_число·строка_ЗНАЧЕН·условие/반복문과 일부 표준 호출을 지원한다. опора_ЗНАЧЕН клип, внешний_ЗНАЧЕН файл 적재와 시험은 [Java 개발 среда файл_сведений_eb81d7d9](문서/Java_IDE.md)에 있다.

네이티브 셸에서 `apps`, `run hello first second`, `net`, `run netcheck`를 사용할 수 있다. 독립 ELF를 ring 3에 적재하고 `int 0x80` 호출을 통해 текстовыйВывод·аргументы·UDP 네트워크를 제공한다. 별도 узел 터미널에서 `python3 os/инструменты/вывод_на_экран_данные.py --port 9000`을 실행한 BACK_ЗНАЧЕН 게스트에서 `run udp 10.0.2.2 9000 hello`로 фактический_данные 왕복을 확인한다. 새 программа_f5044b9b регистр_ввод, API 및 제한은 [пространство_пользователя 실행·네트워크 файл_сведений_eb81d7d9](os/пространство_пользователя/файл_сведений_eb81d7d9.md)를 참고한다. текущий_товар QEMU RTL8139·статический_ЗНАЧЕН IPv4·UDP 전용이며 TCP/DNS는 미지원이며, 전용 IDE Store_ЗНАЧЕН 형식과 POSIX файл/UDP 일부 기능을 추가했다.

`make vbox`는 `jkoros operating system` 전용 VM을 만들고 디스크 없이 ISO로 부팅한다. 실행 중이면 유지하고, Store_ЗНАЧЕН·일시정지 상태이면 재개하며, 꺼져 있을 때만 새 ISO를 빌드해 연결한다. VirtualBox에서 부팅과 셸의 пространство_пользователя программа_f5044b9b 실행을 확인했다. 다만 текущий_товар VirtualBox용 네트워크 드라이버는 없어 네트워크 장치를 비활성화한다. UDP 시험에는 `make run`을 사용한다. 상태별 동작과 새 сборка 반영 방법은 [VirtualBox 실행 файл_сведений_eb81d7d9](문서/가상상자실행.md)에 있다.
