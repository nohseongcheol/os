# 자체 커널에서 vi·여러 터미널·한글 프로그래밍 사용하기

한국어 통신·예외 사용법은 [한국어 Java API](한국어자바/файли_тафсилот_eb81d7d9.md), функсия_қимат·변수·Файл 이름의 변경과 어원 근거는 [명명 файли_тафсилот_eb81d7d9](명명/файли_тафсилот_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 자체 AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 Дастгирӣ_қимат 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 иҷро_кардан_фармон, 외부 TCP/UDP와 FTP는 [새 иҷро_кардан_фармон 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 터미널

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, суроға **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 터미널 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **오른쪽 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 иҷро_кардан_фармон 버튼으로 다시 сутун_қимат 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 현재 디렉터리, восит 변수, фармон сабт_кардан_сабт, 입력 중인 명령과 барнома_f5044b9b иҷро_кардан_фармон 상태를 보관한다. Файл 저장소는 공유한다. vi와 Swing의 이벤트 대기 중에 다른 터미널로 전환하면 корбар ҳофиза_иттилоот·레지스터·Файл/소켓 연결을 보존했다가 돌아올 때 재개한다. **현재 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 다음 입력 대기 또는 기존 иҷро_кардан_фармон 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 иҷро_кардан_фармон 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 таҳрир_қимат 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. 현재 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 равзана 판단은 게스트 커널이 처리한다. QEMU иҷро_кардан_фармон 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. воқеӣ_иттилоот Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI Абзорҳо 종료는 мизбон 터미널의 Ctrl+C다.

vi와 Swing 프로그램은 **단독 фармон**으로 실행한다. 파이프·리다이렉션·скрипт_қимат·`;`/`&&`/`||`로 연결한 실행에서 интерактивӣ 대기를 시작하면 거부한다. 입력 대기는 약 2초 CPU 기한을 갱신하지만 입력 대기 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## 한글 Java

vi에서 다음을 `인사.java`에 입력하고 Esc → `:wq`로 저장한다.

```java

    static int 더하기(int 첫째, int 둘째) { return 첫째 + 둘째; }
    public static void main(String[] 인수) {

        System.out.println("안녕하세요 · 합계=" + 합계);

```

게스트 셸에서 실행한다.

```text

```

한글 файл_ном_Матн·синф_ном·сабк_ном_Матн·변수명·문자열을 사용할 수 있다. **게스트 javac는 собит_қимат Java 부분집합**이다. объект_қимат·리스너·Swing·소켓을 사용하는 소스는 현재 мизбон JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 자체 JVM에 class를 올린다. 자체 JVM에서 지원하는 바이트코드/API 범위는 [자바실행환경.md](자바실행환경.md)를 따른다.

```sh
# мизбон
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/스윙시험.java
python3 Абзорҳо/бор_кардан_Файлҳо.py build/my-java/스윙시험.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. 출력 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.синф_қимат.class` 형식이다. 내장 한국어 라이브러리는 별도 업로드가 필요 없다. 한국어 равзана API의 예제는 [한글창시험.java](시험/자바/한글창시험.java)이며 같은 방법으로 сохтан_манбаъ·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 манбаъ_дарахт/클래스는 호스트의 `python3 Абзорҳо/иҷро_кардан_файл.py масир/인사.java`로 별도 QEMU에 업로드·иҷро_кардан_фармон·종료할 수 있다. интерактивӣ Swing에는 иҷро_кардан_фармон 후 корбар 입력을 유지하는 `make desktop`을 사용한다.

`setLayout(null)`과 `setBounds`로 배치한다. [스윙시험.java](시험/자바/스윙시험.java)는 равзана·한글 барчасп_қимат·Матн_майдон·버튼·이벤트 처리의 иҷро_кардан_фармон 가능한 예제다. [자체 Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

- `한국어.자체.виҷет`: `барчасп_қимат`, `тугма`, `Матн_майдон` 생성.
- `한국어.자체.연결통신`: `ПАЙВАСТ`, `듣기`, `받기`.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **ҳаста_қимат 내부 연결형 байт_қимат ҷараён_қимат**을 추가했다. Файл/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket сервер_қимат = new java.net.ServerSocket(9250);
java.net.Socket меҳмон_қимат = new java.net.Socket("localhost", 9250);
java.net.Socket ПАЙВАСТ = сервер_қимат.accept();
меҳмон_қимат.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int дарозӣ_қимат = ПАЙВАСТ.getInputStream().read(받은것);
ПАЙВАСТ.close(); меҳмон_қимат.close(); сервер_қимат.close();
```

생성·ПАЙВАСТ·accept·양방향 байт_қимат/қатор_қимат вуруд_хуруҷ·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 анҷом_додан_нуқта 16개, 수신 버퍼당 1024바이트, 대기 ПАЙВАСТ 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. қимати_пешфарз 시간 제한 0은 별도 소켓 기한을 설정하지 않지만 JVM фармон 수/ҳаста_қимат иҷро_кардан_фармон 기한은 여전히 적용된다.

외부 рақам_қимат IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. воқеӣ_иттилоот Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP китобхона 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 воқеӣ_иттилоот 송수신·EOF·기한·ПАЙВАСТ 회수의 시험 예제다.

출력·Файл Хондан/Навиштан/삭제·표준 입력·사각형·시간·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 рақам_қимат IPv4 суроға 전송이다. `wait_key()`는 화면을 확인할 때 интерактивӣ 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor собит_қимат 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 изофа_қимат 모듈은 아직 없다. 제한형 `pip`의 манбаъ_дарахт 설치는 [Python баста файли_тафсилот_eb81d7d9](파이썬꾸러미.md)를 따른다. [세 언어의 воқеӣ_иттилоот 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 Забон 모두 한국어 헤더와 функсия_қимат 이름을 직접 사용한다. [인사.c](예제/한글코딩/인사.c), [인사.cpp](예제/한글코딩/인사.cpp)가 воқеӣ_иттилоот EL0 иҷро_кардан_фармон 시험 대상이다.

```c

#endif

python3 Абзорҳо/иҷро_кардан_файл.py build/sdk-work/jkoros-native-sdk/인사-c.elf
python3 Абзорҳо/иҷро_кардан_файл.py build/sdk-work/jkoros-native-sdk/인사-cpp.elf
```

현재 GUI VM에서 실행하려면 `python3 Абзорҳо/бор_кардан_Файлҳо.py масир/인사-c.elf`의 출력을 게스트에 보내고 `run 인사-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex файл_ном_Матн`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 수 있다. 호스트와 게스트의 Файл 시스템은 별개다.

| 한국어 Ном | C аломат | клип |
|---|---|---|
| кушодан_файл/пӯшидан_файл | pk_open/pk_close | RAM Файл, ҳамсон_қимат/절대 масир |
| 파일자료읽기/навиштан_файл_иттилоот | pk_read/pk_write | Файл, fd 0/1/2 표준 вуруд_хуруҷ, 연결형 소켓 |
| ҷустан_файл | pk_lseek | 처음기준/현재기준/끝기준 |
| файл_андоза_кардан/маҷмуъ_файл_дарозӣ | pk_size/pk_ftruncate | дарозӣ_қимат ковиш_қимат/тағйир_додан_қимат |
| тоза_кардан_файл_ворида_ном | pk_unlink | Файл Ном 삭제 |
| 파일저장확정 | pk_fsync | RAM이므로 -1, 오류번호=ENOSYS |
| 통신종단점만들기/иртибот_додан_суроға | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |
| 자료전문보내기/자료전문받기 | pk_sendto/pk_recvfrom | UDP 루프백 |
| ПАЙВАСТ_Шабака | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | 대기 ПАЙВАСТ 최대 4개 |
| қабул_кардан_пайвасти_шабака | pk_accept | 현재 суроға 인수는 NULL/NULL만 Дастгирӣ_қимат |
| 통신주소읽기 | pk_getsockname | 로컬 суроға/порт_қимат |

`통신규약.h`의 자체 `pk_sockaddr_in`을 사용하며 порт_қимат·주소는 `망차례짧은수`/`Шабака_адади_яклухт`로 변환한다. C 소켓 호출은 비차단이며 иттилоот/연결이 없으면 -1과 `오류번호=11`(EAGAIN)을 반환한다. 양수 вуруд_хуруҷ 결과가 요청보다 작을 수 있으므로 такрор_қимат 처리한다. нокомӣ_қимат 후에만 오류번호를 확인한다.

[ҷараён_қимат.c](예제/한글코딩/ҷараён_қимат.c)는 C에서 한국어 이름으로 ПАЙВАСТ·accept·부분 Хондан/Навиштан·큐 포화·EOF를 처리하는 иҷро_кардан_фармон 예제다. SDK의 `examples/ҷараён_қимат.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → воқеӣ_иттилоот 한국어 C функсия_қимат 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·курсор 검사 → Java RAM Файл/루프백 또는 외부 lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 ҳаста_қимат 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 ПАЙВАСТ, 표준 C printf, libstdc++/STL, 예외·RTTI는 제공하지 않으며 C++의 собит_қимат 생성자·маҳаллӣ_ҳаҷм объект_қимат 소멸자는 지원한다. 상세 индекс·ҳофиза_иттилоот 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## санҷидани_эътибор

`make test-windows`, `make test-swing`, `make test-stream`, `make test-coding`으로 새 기능을 각각 시험한다. `make test`는 기존 восит·VNC·JVM·AOT·ҳаста_қимат муҳофизат_кардан_қимат 시험까지 포함한다. воқеӣ_иттилоот 보드 대신 QEMU raspi4b에서 수행한다. 결과는 [이전 GUI изофа_қимат санҷидани_эътибор сабт_кардан_сабт](build/verification/release.json)과 [현재 вақти_иҷрои_умумии_забон санҷидани_эътибор сабт_кардан_сабт](build/verification/native-runtime-summary.json), [여러 터미널 화면](build/verification/windows/four-terminals.png), [Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

구현 시 참고한 표준 API: [Socket](https://docs.oracle.com/javase/8/docs/api/java/net/Socket.html), [JFrame](https://docs.oracle.com/javase/8/docs/api/javax/swing/JFrame.html), [JButton](https://docs.oracle.com/javase/8/docs/api/javax/swing/JButton.html). 이 문서의 구현 범위가 위 표준 전체를 지원한다는 뜻은 아니다.

## 한국어 이름으로 직접 작성하는 창과 ришта_қимат

`example/java/창예제.java`는 `실행할일.Иҷро_кардан`,
`동작받이.동작받기(동작알림)`, `тугма`, `рӯйдод_навбат.나중에실행`, `порча()`을 쓴다.
자체 JVM에 이 이름들의 объект_қимат·сабк_қимат·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `작업가닥`도 자체 스케줄러와 직접 연결된다.
세부 메서드와 기존 한국어 API에서의 변경은 [한국어 API 문서](한국어자바/файли_тафсилот_eb81d7d9.md)를 본다.

мизбон javac는 배포 JAR를 синф_қимат 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/창예제.java
python3 Абзорҳо/иҷро_кардан_фармон.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java 창예제
```

직접 화면/ришта_қимат API와 `порча()` 진입점은 자체 JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
