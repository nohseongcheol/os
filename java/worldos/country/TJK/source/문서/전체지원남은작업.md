# 전체 Дастгирӣ_қимат 요청의 현재 вазъият_қимат

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 воқеӣ_иттилоот C POSIX 일부 기능, 한국어 API/манбаъ Ном, IDE Файл 보존, 게스트 Java Файл 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/файли_тафсилот_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 иҷро_кардан_фармон 가능한 клип | 전체 지원에 필요한 작업 |
|---|---|---|
| Java сохтан_манбаъ·иҷро_кардан_фармон | 게스트 제한형 javac/JVM, собит_қимат 단일 클래스와 일부 표준 объект_қимат | 일반 объект_қимат·синф_қимат ПАЙВАСТ·예외·GC·스레드, 완전한 javac와 표준 синф_қимат китобхона |
| Файл | POSIX 서술자, Java 단일 байт_қимат Файл ҷараён_қимат, 전용 медиа_қимат 보존 | 일반 java.io/nio, 디렉터리·иҷозат_қимат·잠금·일반 системаи_файлӣ·изофа_қимат 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP мизбон 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 рӯйдод·шрифт_қимат·равзана системаи_омил_қимат, AWT 네이티브 연결과 Swing иҷро_кардан_фармон 기반 |
| POSIX | 문서화한 Файл·단말·UDP 부분 | Раванд_қимат·exec/fork·스레드·시그널·시간·mmap·poll·파이프 등과 적합성 санҷидани_эътибор |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 иҷро_кардан_фармон 환경을 추가하는 방식은 별도의 ҳаста_қимат·루트 системаи_файлӣ·OpenJDK·그래픽 сервер_қимат·영구 ҳифз_кардан_қимат 구성을 가진 иҷро_кардан_фармон 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

иҷро_кардан_фармон 기반과 추가 ҳадаф 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
