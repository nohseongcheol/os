# 한국어 Java 통신·შეტანა_გამოტანა·예외 API

패키지는 `한국어.자체`다. მასპინძელი `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·ფაილი·예외 API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 თემა_მნიშვნელობა API는 자체 JVM 전용이다.
기존 표준 Java ბიბლიოთეკა 전체의 한국어 번역판은 아니다.

```java
import 한국어.자체.*;

public class ქსელი {
    public static void main(String[] 인수) throws 입출력예외 {
        კავშირი დაკავშირება = კავშირი.გახსნა("10.0.2.2", 9000);
        try {
            დაკავშირება.დრო_ამოიწურა(700);
            დაკავშირება.출력().ჩაწერა(문자.부호화("안녕하세요\n"));
            입력흐름 입력 = დაკავშირება.입력();
            출력.수쓰기(입력.კითხვა());
        } catch (대기시간초과예외 შეცდომა) {
            출력.ჩაწერა_ხაზი(შეცდომა.설명());
        } finally {
            დაკავშირება.დახურვა();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
მომხმარებელი 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 სტრიქონი_მნიშვნელობა 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void გაშვება()`도 진입점으로 받는다.

## 통신과 ნაკადი_მნიშვნელობა

| კლასი_მნიშვნელობა | 한국어 호출 |
|---|---|
| კავშირი | `გახსნა(მისამართი, 접속번호)`, `입력()`, `출력()`, `დრო_ამოიწურა(밀리초)`, `접속번호()`, `지역접속번호()`, `연결됨()`, `닫힘()`, `დახურვა()` |
| 수신창구 | `გახსნა(접속번호)`, `받기()`, `접속번호()`, `დრო_ამოიწურა(밀리초)`, `닫힘()`, `დახურვა()` |
| 입력흐름 | `კითხვა()`, `კითხვა(byte[])`, `კითხვა(byte[], გაშვება, სიგრძე_მნიშვნელობა)`, `დახურვა()` |
| 출력흐름 | `ჩაწერა(int)`, `ჩაწერა(byte[])`, `ჩაწერა(byte[], გაშვება, სიგრძე_მნიშვნელობა)`, `내보내기()`, `დახურვა()` |
| 전문통로 | `გახსნა(접속번호)`, `გაგზავნა(მისამართი, 접속번호, ტექსტი)`, `받기()`, `დრო_ამოიწურა(밀리초)`, `접속번호()`, `닫힘()`, `დახურვა()` |
| 연결통신 | `გახსნა(...)`, `수신열기(...)`는 위 한국어 객체를 დაბრუნება_გაზომვა |
| 검사 | `참인지(პირობა, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`კითხვა()`의 ფაილი 끝은 -1, მასივი_მნიშვნელობა 읽기의 반환값은 რეალური_მონაცემები 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. 접속번호 0은 빈 번호를 자동 배정한다.
UDP 전문은 현재 자체 커널에서 512바이트까지 받으며, 주소는 ციფრი_მნიშვნელობა IPv4를 사용한다.
`localhost` 루프백 외의 სახელი 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.დაკავშირება/듣기/받기`, `통신.გახსნა/გაგზავნა/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `კავშირი`, `수신창구`, `전문통로`를 쓴다.

## 한국어 예외

모든 아래 클래스는 ნაგულისხმევი_მნიშვნელობა 생성자, `새예외("설명")` 형태의 სტრიქონი_მნიშვნელობა 생성자와
`설명()`을 제공한다. რეალური_მონაცემები დაგენერირება 문법은 `new 대기시간초과예외("მოლოდინი_სტატუსი 끝")`이다.

| 한국어 예외 | 상위 კლასი_მნიშვნელობა / 용도 |
|---|---|
| 예외 | `java.lang.Exception`, 직접 던지는 일반 검사 예외 |
| 실행예외 | `java.lang.RuntimeException` |
| 입출력예외 | `java.io.IOException`, 한국어 ფაილი·통신 API의 검사 예외 |
| 대기시간초과예외 | `입출력예외`, 통신 დრო_ამოიწურა 초과 |
| 주소확인예외 | `입출력예외`, მისამართი გადამოწმება მარცხი_მნიშვნელობა |
| 파일없음예외 | `입출력예외`, ფაილი გახსნა მარცხი_მნიშვნელობა |
| 통신예외 | `입출력예외`, 표준 SocketException 변환 |
| 잘못된인수예외 | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `잘못된인수예외` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| 빈참조예외 | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| 상태예외 | `java.lang.IllegalStateException` |
| 형변환예외 | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| მასივი_შენახვა_მარცხი | `java.lang.ArrayStoreException` |
| 가닥상태예외 | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 მოლოდინი_მნიშვნელობა 중단 |

`예외`와 `실행예외`는 모든 한국어 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, ფაილი·통신 전체를 잡으려면 `catch (입출력예외 შეცდომა)`를 쓴다.
한국어 API가 표준 შეტანა_გამოტანა 오류를 한국어 예외로 변환한다.
기존 한국어 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
예외 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
현재 자체 JVM에 이 20종을 추가했다. 임의의 მომხმარებელი Throwable 하위 კლასი_მნიშვნელობა 전체를
지원하도록 확장했다는 뜻은 아니다.

## აწყობა_წყარო·შესრულება_ბრძანება

```sh
cd /home/user/jkoros/platforms/rpi4-native
make აწყობა_სისტემა
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 ხელსაწყოები/შესრულება_ფაილი.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 მომხმარებელი JVM ELF 안에 탑재된다. `.jar`는 მასპინძელი javac의
კლასი_მნიშვნელობა 경로로 사용한다. წყარო_ხე 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 한국어 예외의 `throws` 선언과 그 import를 인식한다.
자체 JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·ობიექტი_მნიშვნელობა·소켓 예제 전체의 წყარო_ხე 컴파일은 მასპინძელი javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 수 있다.

რეალური_მონაცემები TCP/UDP 예제는 [네트워크예제.java](../../../example/java/네트워크예제.java),
შესრულება_ბრძანება 절차는 [example წასაკითხი_ფაილი_eb81d7d9](../../../example/README.md),
წყარო_ხე 명명 원칙은 [명명 წასაკითხი_ფაილი_eb81d7d9](../명명/წასაკითხი_ფაილი_eb81d7d9.md)에 있다.

## Swing ფანჯარა 예제

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` შემდეგი_ელემენტი `java 창예제`로 연다. სახელი 입력, 인사하기 버튼,
인사말과 დაწკაპუნება_მნიშვნელობა 횟수 განახლება, X 닫기를 지원한다.

| 기능 | 한국어 직접 API |
|---|---|
| Runnable / run | `실행할일.შესრულება()` |
| ActionListener / actionPerformed | `동작받이.동작받기(동작알림 알림)` |
| ActionEvent | `동작알림.ბრძანება_ტექსტი()`, `მოვლენა_წყარო()`, `ინდექსი()` |
| JFrame | `ფანჯარა(ფანჯარა_დასახელება, 폭, 높이)`, `დამატება_ელემენტი(화면구성요소)`, `ჩვენება_ფანჯარა()`, `დახურვა()`, `보이는가()` |
| JButton | `ღილაკი(ტექსტი, 가로, ვერტიკალური_პოზიცია, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `სათაური(...)`, `ტექსტური_ველი(...)` |
| 공통 화면 ელემენტი_მნიშვნელობა | `화면구성요소.글읽기()`, `ჩაწერა_ტექსტი(ტექსტი)`, `자리정하기(가로, ვერტიკალური_პოზიცია, 폭, 높이)` |
| SwingUtilities.invokeLater | `მოვლენა_რიგი.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `დაწყება_დავალება()`, `기다리기()`, `살아있는가()`, `შეჩერება_დავალება()` |
| 명령행 | `გაშვება()`, `실행인수.개수()`, `실행인수.ტექსტი(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `პროცესი_თემა`가 한국어 კლასი_მნიშვნელობა·მეთოდი_მნიშვნელობა·서술자를
해석해 화면 요소와 შესრულება_ბრძანება 가닥을 직접 만든다. ქმედება 알림도 자체 객체이며
콜백으로 `შესრულება`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 შესრულება_ბრძანება 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 მასპინძელი JVM에서 무동작 객체가 생기지 않도록 하는 거부 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. მასპინძელი javac로 컴파일한 უკან_მნიშვნელობა 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import 한국어.자체.*;
public class 가닥예제 implements 실행할일 {
    public void შესრულება() { 출력.ჩაწერა_ხაზი("한국어 작업 შესრულება_ბრძანება"); }
    public static void გაშვება() throws 대기중단예외 {
        작업가닥 თემა_მნიშვნელობა = 작업.გაშვება(new 가닥예제());
        작업.기다리기(თემა_მნიშვნელობა);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
მასივი_მნიშვნელობა 인수 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 인수 없는 `გაშვება()`을 우선한다.
기존 한국어 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.გაშვება(Runnable)`을 사용하던 코드는 새 한국어 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API მხარდაჭერა_მნიშვნელობა 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 კლასი_მნიშვნელობა·მეთოდი_მნიშვნელობა 이름과 서술자가 남는다.
한국어 სახელი 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·მეთოდი_მნიშვნელობა 재정의, native დაკავშირება, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS იდენტიფიკატორი_მნიშვნელობა](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS მეთოდი_მნიშვნელობა ცნობარები](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
