# 한국어 Java 통신·енгізу_шығару·ерекшелік API

패키지는 `한국어.자체`다. орналастыру `javac --release 8`로 컴파일한 class를
자체 ARM64 커널의 JVM에서 실행한다. 통신·Файл·ерекшелік API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 ағын_мән API는 자체 JVM 전용이다.
기존 표준 Java кітапхана 전체의 한국어 번역판은 아니다.

```java
import 한국어.자체.*;

public class желі {
    public static void main(String[] Аргументтер) throws енгізу_шығару_ерекшелік {
        қосылым Байланысу = қосылым.Ашу("10.0.2.2", 9000);
        try {
            Байланысу.ТАЙМ_АУТ(700);
            Байланысу.Шығысы().Жазу(문자.부호화("안녕하세요\n"));
            кіріс_ағыны 입력 = Байланысу.입력();
            Шығысы.수쓰기(입력.Оқу());
        } catch (күте_тұрыңыз_ТАЙМ_АУТ_ерекшелік Қате) {
            Шығысы.жазу_жол(Қате.설명());
        } finally {
            Байланысу.Жабу();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
пайдаланушы 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 жол_мән_6ca8363c 리터럴에 사용하는 표준 클래스다. 자체 실행기는 `public static void Орындау_2()`도 진입점으로 받는다.

## 통신과 ағым_мән

| оқу_мән | 한국어 호출 |
|---|---|
| қосылым | `Ашу(мекенжай, порт_нөмірі)`, `입력()`, `Шығысы()`, `ТАЙМ_АУТ(밀리초)`, `порт_нөмірі()`, `жергілікті_порт_нөмірі()`, `연결됨()`, `닫힘()`, `Жабу()` |
| 수신창구 | `Ашу(порт_нөмірі)`, `받기()`, `порт_нөмірі()`, `ТАЙМ_АУТ(밀리초)`, `닫힘()`, `Жабу()` |
| кіріс_ағыны | `Оқу()`, `Оқу(byte[])`, `Оқу(byte[], Орындау_2, ұзындық_мән)`, `Жабу()` |
| шығыс_ағыны | `Жазу(int)`, `Жазу(byte[])`, `Жазу(byte[], Орындау_2, ұзындық_мән)`, `내보내기()`, `Жабу()` |
| 전문통로 | `Ашу(порт_нөмірі)`, `жіберу(мекенжай, порт_нөмірі, Мәтін)`, `받기()`, `ТАЙМ_АУТ(밀리초)`, `порт_нөмірі()`, `닫힘()`, `Жабу()` |
| 연결통신 | `Ашу(...)`, `수신열기(...)`는 위 한국어 객체를 қайтару_өлшем |
| 검사 | `참인지(шарт, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`Оқу()`의 Файл 끝은 -1, массив_мән 읽기의 반환값은 нақты_деректер 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. порт_нөмірі 0은 빈 번호를 자동 배정한다.
UDP 전문은 ток_элемент 자체 커널에서 512바이트까지 받으며, 주소는 сан_мән IPv4를 사용한다.
`localhost` 루프백 외의 Аты 풀이(DNS)는 자체 커널에 아직 없다.

기존 `연결통신.Байланысу/деректердің_берілуін_күту_қатысушы/받기`, `통신.Ашу/жіберу/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `қосылым`, `수신창구`, `전문통로`를 쓴다.

## 한국어 ерекшелік

모든 아래 클래스는 әдепкі_мән 생성자, `새예외("설명")` 형태의 жол_мән_6ca8363c 생성자와
`설명()`을 제공한다. нақты_деректер жасау 문법은 `new күте_тұрыңыз_ТАЙМ_АУТ_ерекшелік("күту_күйі 끝")`이다.

| 한국어 ерекшелік | 상위 оқу_мән / 용도 |
|---|---|
| ерекшелік | `java.lang.Exception`, 직접 던지는 일반 검사 ерекшелік |
| 실행예외 | `java.lang.RuntimeException` |
| енгізу_шығару_ерекшелік | `java.io.IOException`, 한국어 Файл·통신 API의 검사 ерекшелік |
| күте_тұрыңыз_ТАЙМ_АУТ_ерекшелік | `енгізу_шығару_ерекшелік`, 통신 ТАЙМ_АУТ 초과 |
| мекенжай_Іздеу_ерекшелік | `енгізу_шығару_ерекшелік`, мекенжай тексеру қате_мән |
| 파일없음예외 | `енгізу_шығару_ерекшелік`, Файл Ашу қате_мән |
| 통신예외 | `енгізу_шығару_ерекшелік`, 표준 SocketException Түрлендіру_мән |
| дұрыс_емес_аргумент_ерекшелік | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `дұрыс_емес_аргумент_ерекшелік` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| бос_мән_Анықтамалық_ерекшелік | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| күй_ерекшелік | `java.lang.IllegalStateException` |
| Түрі_Тарату_ерекшелік | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| массив_сақтау_қате | `java.lang.ArrayStoreException` |
| ағын_күй_ерекшелік | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 күте_тұрыңыз_мән 중단 |

`ерекшелік`와 `실행예외`는 모든 한국어 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, Файл·통신 전체를 잡으려면 `catch (енгізу_шығару_ерекшелік Қате)`를 쓴다.
한국어 API가 표준 енгізу_шығару 오류를 한국어 예외로 변환한다.
기존 한국어 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`күте_тұрыңыз_ТАЙМ_АУТ_ерекшелік`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
ерекшелік 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
ток_элемент 자체 JVM에 이 20종을 추가했다. 임의의 пайдаланушы Throwable 하위 оқу_мән 전체를
지원하도록 확장했다는 뜻은 아니다.

## құрастыру_көз·орындау_пәрмен

```sh
cd /home/user/jkoros/platforms/rpi4-native
make құрастыру_жүйе
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 Құралдар/орындау_файл.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 пайдаланушы JVM ELF 안에 탑재된다. `.jar`는 орналастыру javac의
оқу_мән 경로로 사용한다. көз_дарақ 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 한국어 예외의 `throws` 선언과 그 import를 인식한다.
자체 JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·нысан_мән·소켓 예제 전체의 көз_дарақ 컴파일은 орналастыру javac를 사용한다.
`/example/java/파일예제.java`는 게스트 javac로도 컴파일할 수 있다.

нақты_деректер TCP/UDP 예제는 [네트워크예제.java](../../../example/java/네트워크예제.java),
орындау_пәрмен 절차는 [example readme_файлы_eb81d7d9](../../../example/README.md),
көз_дарақ 명명 원칙은 [명명 readme_файлы_eb81d7d9](../명명/readme_файлы_eb81d7d9.md)에 있다.

## Swing Терезе 예제

`/example/java/창예제.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` Келесі_элемент `java 창예제`로 연다. Аты 입력, 인사하기 버튼,
인사말과 басу_мән 횟수 жаңарту, X 닫기를 지원한다.

| 기능 | 한국어 직접 API |
|---|---|
| Runnable / run | `실행할일.Орындау()` |
| ActionListener / actionPerformed | `동작받이.동작받기(동작알림 알림)` |
| ActionEvent | `동작알림.пәрмен_Мәтін()`, `оқиға_көзі()`, `индекс()` |
| JFrame | `Терезе(терезе_Тақырып, 폭, 높이)`, `Қосу_элемент(화면구성요소)`, `көрсету_терезе()`, `Жабу()`, `보이는가()` |
| JButton | `батырма(Мәтін, 가로, Тік_лауазым, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `Белгі(...)`, `мәтіндік_өріс(...)` |
| 공통 화면 элемент_мән | `화면구성요소.글읽기()`, `жазу_Мәтін(Мәтін)`, `자리정하기(가로, Тік_лауазым, 폭, 높이)` |
| SwingUtilities.invokeLater | `оқиға_кезек.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `작업가닥(실행할일)`, `басы_тапсырма()`, `기다리기()`, `살아있는가()`, `кідірту_тапсырма()` |
| 명령행 | `Орындау_2()`, `실행인수.개수()`, `실행인수.Мәтін(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
자체 JVM의 `한국어화면호출`, `Процесс_ағын`가 한국어 оқу_мән·әдіс_мән·서술자를
해석해 화면 요소와 орындау_пәрмен 가닥을 직접 만든다. Әрекет 알림도 자체 객체이며
콜백으로 `Орындау`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 орындау_пәрмен 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 자체 JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 орналастыру JVM에서 무동작 객체가 생기지 않도록 하는 қабылдамау_мән 경로다.
자체 JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. орналастыру javac로 컴파일한 АРТҚА_мән 자체 JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import 한국어.자체.*;
public class 가닥예제 implements 실행할일 {
    public void Орындау() { Шығысы.жазу_жол("한국어 작업 орындау_пәрмен"); }
    public static void Орындау_2() throws 대기중단예외 {
        작업가닥 ағын_мән = 작업.Орындау_2(new 가닥예제());
        작업.기다리기(ағын_мән);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
массив_мән Аргументтер 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
자체 실행기는 Аргументтер 없는 `Орындау_2()`을 우선한다.
기존 한국어 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.Орындау_2(Runnable)`을 사용하던 코드는 새 한국어 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API тіреу_мән 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 оқу_мән·әдіс_мән 이름과 서술자가 남는다.
한국어 Аты 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·әдіс_мән 재정의, native Байланысу, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS идентификатор_мән](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS әдіс_мән Анықтамалық](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
