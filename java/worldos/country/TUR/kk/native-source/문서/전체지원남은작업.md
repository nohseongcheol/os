# 전체 тіреу_мән 요청의 ток_элемент күй_мән

요청 전체는 아직 완료되지 않았다. ток_элемент ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 нақты_деректер C POSIX 일부 기능, 한국어 API/Неден Аты, IDE Файл 보존, 게스트 Java Файл 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/readme_файлы_eb81d7d9.md)를 기준으로 판단한다.

|---|---|---|
| Java құрастыру_көз·орындау_пәрмен | 게스트 제한형 javac/JVM, тұрақты_мән 단일 클래스와 일부 표준 нысан_мән | 일반 нысан_мән·оқу_мән Байланысу·ерекшелік·GC·스레드, 완전한 javac와 표준 оқу_мән кітапхана |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 орындау_пәрмен 환경을 추가하는 방식은 별도의 ядро_мән·루트 файлдық_жүйе·OpenJDK·그래픽 сервер_мән·영구 сақтау_мән 구성을 가진 орындау_пәрмен 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

орындау_пәрмен 기반과 қосу_енгізу мақсатты_мән 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. ток_элемент 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
