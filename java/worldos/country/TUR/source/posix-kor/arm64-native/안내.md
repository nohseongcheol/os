# Öz ARM64 Java 커널의 C/C++ dosya·루프백 Bağlan

이 디렉터리는 `platforms/rpi4-native` Öz çekirdek_değer 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`bildirimler/Dosya_ABI.h`는 Türkçe 함수명과 `extern "C"` ABI를 제공한다. `Bağlan.c`는 çekirdek_değer 안에서 AOT Java dosya 메서드에 직접 연결하고, `kullanıcı_köprü.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. fiili_veri dosya 처리는 `BellekDosyaları.java`, 루프백 veri_birimi 처리는 `geri_döngü_ağ.java`, 연결형 흐름은 `akış_ağ.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 çekirdek_değer 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·kayan_nokta_değer işlem_değer_c96707fb·dosya·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

Destek_değer: `açık_Dosya`, `파일자료읽기`, `yazma_Dosya_veri`, `Kapat_Dosya`, `arama_Dosya`, `kaldırmak_Dosya_girdi_ad`, `küme_Dosya_süre`, 보조 işlev_değer `dosya_boyutu`. hata 시 -1과 작업별 `hata_numarası`를 반환한다. `commit_Dosyalar`은 RAM 파일이므로 ENOSYS를 반환한다. dosya 16개, 각 16384바이트, İsim 63바이트, tanımlayıcı_girdi 16개이며 RAM 디렉터리·eş_değer/절대 경로를 제공한다. izin_değer/영속 저장은 없다.

사용자용 `bildirimler/ağ_ABI.h`는 fiili_veri Türkçe 함수와 독립 구조체를 선언한다.
`açmak_uç_nokta`, `BIND_ADRES`, `göndermek_veri_birimi_veri/almak`, `bağla_ağ/기다리기/almak`는
`kullanıcı_köprü.c`에서 SVC를 호출하며 makro_değer 별칭이 아니다. `struct bulut_yuva_ADRES`의
`ADRES_Aile`, `bağlantı_noktası_numarası`, `İnternet_adresi.ADRES_değer`을 사용한다. 상수는 enum의
`bulut_Aile`, `veri_birimi_yuvası`, `veri_birimi_protokol`, `akış_ağ`, `akış_aktarım_protokolü`이다.
Türkçe·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. dış_değer 통신은 Öz 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. fiili_veri Pi 4 GENET 드라이버는 미지원이다.
소켓도 fiili_veri işlev_değer `Kapat_Dosya`로 닫는다.
