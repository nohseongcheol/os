# 전체 Destek_değer 요청의 geçerli_öğe Durum_değer

istek 전체는 아직 완료되지 않았다. geçerli_öğe ISO는 Öz Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 fiili_veri C POSIX 일부 기능, Türkçe API/kaynakKod İsim, IDE dosya 보존, 게스트 Java dosya 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/안내.md)를 기준으로 판단한다.

| istek 분야 | geçerli_öğe yürütmek_komut 가능한 klip | 전체 지원에 필요한 작업 |
|---|---|---|
| Java derlemek_kaynak·yürütmek_komut | 게스트 제한형 javac/JVM, statik_değer 단일 클래스와 일부 표준 nesne_değer | 일반 nesne_değer·Sınıf_değer Bağlan·özel_durum·GC·스레드, 완전한 javac와 표준 Sınıf_değer kitaplık |
| dosya | POSIX tanımlayıcı_girdi, Java 단일 bayt_değer dosya akış_değer, 전용 Medya_değer 보존 | 일반 java.io/nio, 디렉터리·izin_değer·kilit_değer·일반 dosya_sistemi·uzantı_değer 가능한 kapasite_değer |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP konak 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, Ekleme_girdi NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·artış_değer Olay·yazı_tipi_değer·Pencere işletim_sistemi_değer, AWT 네이티브 연결과 Swing yürütmek_komut 기반 |
| POSIX | 문서화한 dosya·단말·UDP 부분 | işlem_değer·exec/fork·스레드·시그널·zaman_değeri·mmap·poll·파이프 등과 적합성 doğrulamak_5fb2b747 |
| 언어별 İsim | Türkçe 46개 eşleme_değer girdi_değer, fiili_veri C/Java/dosya İsim 적용 | hedef Dil commit_değer, 언어별 용례·역사 근거와 해당 kaynakKod·도구의 doğrulamak_5fb2b747 |

Öz 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 yürütmek_komut 환경을 추가하는 방식은 별도의 çekirdek_değer·루트 dosya_sistemi·OpenJDK·그래픽 sunucu_değer·영구 depo_değer 구성을 가진 yürütmek_komut 경로가 된다. 후자는 기존 Öz 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

yürütmek_komut 기반과 Ekleme_girdi hedef 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. geçerli_öğe 원문과 sınamalar 결과를 후속 구현의 출발점으로 보존한다.
