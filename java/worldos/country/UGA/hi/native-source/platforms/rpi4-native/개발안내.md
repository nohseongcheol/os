# निज 커널에서 vi·여러 आदेशपटल·한글 프로그래밍 사용하기

हिंदी 통신·अपवाद 사용법은 [हिंदी Java API](한국어자바/ReadMe_फ़ाइल_eb81d7d9.md), फ़ंक्_शन_मान·चर_मान·संचिका 이름의 변경과 어원 근거는 [명명 ReadMe_फ़ाइल_eb81d7d9](명명/ReadMe_फ़ाइल_eb81d7d9.md)를 참고한다.

대상은 `platforms/rpi4-native`의 निज AArch64 Java 커널이다. vi와 Java/Python/C/C++ 프로그램은 EL0에서 실행한다. Linux 실행판과 별도이며 아래 समर्थन_मान 목록은 전체 OpenJDK·Vim·POSIX 구현을 뜻하지 않는다.

게스트 `cc`/`jaot`, JAR 직접 निष्पादित_करें_आदेश, बाहरी_मान TCP/UDP와 FTP는 [새 निष्पादित_करें_आदेश 매뉴얼](파일전송과번역.md)을 참고한다.

## GUI와 여러 आदेशपटल

```sh
cd /home/user/jkoros/platforms/rpi4-native
make desktop
```

Remmina에서 **VNC**, पता **127.0.0.1:5902**로 연결한다. 화면 위 **+ New terminal**, **Ctrl+Shift+T**로 터미널을 추가한다. 최대 네 개다. 위쪽 आदेशपटल 버튼 또는 창을 클릭해 선택하고 **F6**으로 순환한다. 제목줄을 끌어서 옮기고 **오른쪽 위 X**를 클릭하면 닫힌다. 마지막 창을 닫아도 위쪽 निष्पादित_करें_आदेश 버튼으로 다시 कालम_मान 수 있다. 기존 `terminal`, `exit`, F12도 사용할 수 있다.

창마다 अद्यतित_आइटम 디렉터리, शेल चर_मान, आदेश लॉग_रिकॉर्ड, 입력 중인 명령과 ऐप_f5044b9b निष्पादित_करें_आदेश 상태를 보관한다. संचिका 저장소는 공유한다. vi와 Swing의 이벤트 प्रतीक्षा_करें_मान 중에 다른 터미널로 전환하면 उपयोगकर्ता मेमोरी_डेटा·레지스터·संचिका/सॉकेट_मान 연결을 보존했다가 돌아올 때 재개한다. **अद्यतित_आइटम 네 프로그램이 동시에 CPU에서 실행되는 선점형 스케줄러는 아니다.** 계산 중인 프로그램은 अगला_आइटम 입력 प्रतीक्षा_करें_मान 또는 기존 निष्पादित_करें_आदेश 기한까지 전환이 지연될 수 있다.

X로 터미널을 닫으면 그 터미널의 निष्पादित_करें_आदेश 중인 프로그램도 종료하며 서술자·소켓을 회수한다. 저장하지 않은 संपादन_मान 내용은 사라진다. 종료한 슬롯은 새 창에서 재사용한다. अद्यतित_आइटम 모든 파일은 RAM에 있으며 VM 재시작 후에는 남지 않는다.

화면과 खिड़की 판단은 게스트 커널이 처리한다. QEMU निष्पादित_करें_आदेश 도구는 VNC 키와 마우스 좌표를 UART 패킷으로 전달한다. वास्तविक_डेटा Pi4 USB 입력기와 실물 부팅은 아직 검증하지 않았다. 일반 UART 셸은 `make run`, GUI उपकरण 종료는 आयोजक 터미널의 Ctrl+C다.

## vi 사용

```text
mkdir 작업
cd 작업
vi अभिनन्दन_ae353e94.py
```

`vi`는 새로 구현한 **vi आदेश 부분집합** 편집기다. 내장 `build/user/vi.elf`를 보호된 उपयोगकर्ता 영역에 적재한다. संचिका 크기는 UTF-8 बाइट_मान प्रोजेक्ट_करें_मूल 16 KiB, 경로는 63바이트까지다. 디스크에 설치한 Vim/Neovim 바이너리를 실행하는 것이 아니다.

| कुंजी_मान/आदेश | क्रिया |
|---|---|
| `i`, `a`, `I`, `A` | अद्यतित_आइटम/अगला_आइटम स्थान 또는 पंक्ति 처음/끝에서 입력 |
| `o`, `O` | 아래/위에 새 줄을 만들고 입력 |
| Esc | 일반 मोड_मान |
| `h j k l`, 방향키 | UTF-8 문자/पंक्ति ले_जाएँ_मान |
| `0`, `$`, Home, End | पंक्ति 처음/끝 |
| `gg`, `G`, `:इंडेक्स` | संचिका 처음/마지막 पंक्ति/असाइन_करें_मान पंक्ति |
| PgUp, PgDn | 화면 इकाई_मान ले_जाएँ_मान |
| `x`, Delete | अद्यतित_आइटम 문자 삭제 |
| `dd`, `yy`, `p` | पंक्ति 삭제/आवृत्ति_मान/चिपकाएँ_पाठ |
| `u` | 마지막 편집을 वापस_करें_ब्रिज; 한 स्टेज_मान 토글 |
| `/स्ट्रिंग_मान`, `n` | 단순 स्ट्रिंग_मान 검색/अगला_आइटम 일치; 정규식 없음 |
| `:w`, `:w 다른이름` | RAM संचिका स्टोर_मान/다른 경로로 स्टोर_मान |
| `:q` | 변경이 없을 때 निर्गमन_ऐप |
| `:q!` | 변경을 버리고 निर्गमन_ऐप |
| `:wq`, `ZZ` | 저장하고 निर्गमन_ऐप |

붙여 넣은 한글을 문자 경계에 맞춰 ले_जाएँ_मान·삭제한다. 일반 vi의 수량 접두사, मैक्रो_मान, विन्यास संचिका, 플러그인, 정규식, 여러 버퍼/분할 खिड़की, 문법 강조 등은 아직 없다. `--desktop`에서는 F9·Shift+Space·한/शून्य_ऑपरेंड 키로 두벌식 조합을 전환한다. PC 입력기를 영어로 두고 खिड़की विंडो_शीर्षक `[KO]`에서 입력하며, `help ko`에 단축키를 표시한다. 완성된 Unicode 문자와 VNC의 명시적 붙여넣기도 전달한다.

vi와 Swing 프로그램은 **단독 आदेश**으로 실행한다. 파이프·리다이렉션·स्क्रिप्ट_मान·`;`/`&&`/`||`로 연결한 실행에서 대화형 대기를 시작하면 거부한다. 입력 대기는 약 2초 CPU 기한을 갱신하지만 입력 प्रतीक्षा_करें_मान 없이 무한 반복하는 프로그램은 기존처럼 종료한다.

## 한글 Java

vi에서 다음을 `अभिनन्दन_ae353e94.java`에 입력하고 Esc → `:wq`로 저장한다.

```java
public class अभिनन्दन_ae353e94 {
    static int 더하기(int 첫째, int 둘째) { return 첫째 + 둘째; }
    public static void main(String[] तर्क) {
        int 합계 = 더하기(20, 22);
        System.out.println("안녕하세요 · 합계=" + 합계);
    }
}
```

게스트 셸에서 실행한다.

```text
javac अभिनन्दन_ae353e94.java
java अभिनन्दन_ae353e94
```

한글 फ़ाइल_नाम_पाठ·क्_लास_नाम·विधि_नाम_पाठ·변수명·문자열을 사용할 수 있다. **게스트 javac는 정적 Java 부분집합**이다. ऑब्जेक्ट_मान·리스너·Swing·소켓을 사용하는 소스는 अद्यतित_आइटम आयोजक JDK에서 `javac --release 8 -encoding UTF-8`로 컴파일하고 निज JVM에 class를 올린다. निज JVM에서 지원하는 바이트코드/API 범위는 [자바실행환경.md](자바실행환경.md)를 따른다.

```sh
# आयोजक
mkdir -p build/my-java
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/my-java 시험/자바/스윙시험.java
python3 उपकरण/अपलोड_फ़ाइलें.py build/my-java/스윙시험.class
```

`upload.py`는 게스트 `load`에 붙여 넣을 16진수 명령을 생성한다. निर्गम 전체를 GUI 터미널에 보내면 업로드한다. 업로드 후 **별도로** `java 스윙시험`을 실행한다. 종속 class가 있으면 각각 업로드한다. 패키지 class의 파일명은 `패키지.कक्षा_मान.class` 형식이다. 내장 हिंदी 라이브러리는 별도 업로드가 필요 없다. हिंदी खिड़की API의 예제는 [한글창시험.java](시험/자바/한글창시험.java)이며 같은 방법으로 कंपाइल_स्रोत·업로드해 `java 한글창시험`으로 실행한다.

GUI가 필요 없는 단일 स्रोत_ट्री/클래스는 호스트의 `python3 उपकरण/निष्पादित_करें_फ़ाइल.py पथ/अभिनन्दन_ae353e94.java`로 별도 QEMU에 업로드·निष्पादित_करें_आदेश·종료할 수 있다. 대화형 Swing에는 निष्पादित_करें_आदेश 후 उपयोगकर्ता 입력을 유지하는 `make desktop`을 사용한다.

## निज JVM의 Swing क्लिप

실제로 제공하는 것은 **표준 패키지 이름으로 호출하는 निज Swing API 부분집합**이다. OpenJDK `java.desktop` 모듈이나 AWT 전체를 이식한 것은 아니다.

| API | क्रिया |
|---|---|
| `JFrame` | विंडो_शीर्षक, आकार·स्थान, शो_विंडो, बंदकरें 정책, dispose |
| `JPanel` | बच्चा_मान 요소를 담는 패널 |
| `JLabel` | 한글을 포함한 स्ट्रिंग_मान शो_मान·परिवर्तित_करें_मान |
| `JButton` | 버튼과 ActionListener क्लिक_करना_मान प्रक्रिया_मान_एन्ट्री |
| `JTextField` | 한 पंक्ति UTF-8 입력, 삭제, getText/setText, Enter 이벤트 |
| 공통 | setBounds, setSize, add, getContentPane, repaint, validate |
| `SwingUtilities` | invokeLater, isEventDispatchThread |
| `ActionEvent` | getSource, getActionCommand, getID |

`setLayout(null)`과 `setBounds`로 배치한다. FlowLayout/BorderLayout/GridLayout, pack, 폰트·스타일 전체, 메뉴·테이블·트리·스크롤 패널, Java2D, 네이티브 AWT peer/JNI, 복잡한 문자 조판은 아직 없다. 이벤트 콜백은 निज JVM의 단일 이벤트 निष्पादित_करें_आदेश 흐름에서 처리하며 OpenJDK EDT 구현과 동일하지 않다. खिड़की·요소는 निष्पादित_करें_आदेश 하나당 합계 32개, तत्व_मान 글자는 최대 127 코드포인트다. डिफ़ॉल्ट_मान 서체와 색은 커널이 제공한다.

[스윙시험.java](시험/자바/스윙시험.java)는 खिड़की·한글 टैग_मान·पाठ_फ़ील्ड·버튼·이벤트 처리의 निष्पादित_करें_आदेश 가능한 예제다. [निज Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

हिंदी 라이브러리에는 다음을 추가했다. आयोजक कंपाइल_स्रोत 시 `dist/jkoros-native-korean.jar`를 classpath에 넣는다.

- `हिंदी.निज.खिड़की`: `जोड़ें_तत्व`, `शो_विंडो`, `बंदकरें`.
- `हिंदी.निज.विजेट`: `टैग_मान`, `बटन`, `पाठ_फ़ील्ड` जनरेट_करें.
- `हिंदी.निज.연결통신`: `जोड़ना`, `सुनिए_एंडपॉइंट`, `받기`.
- 기존 `निर्गम`, `문자`, `संचिका`, `작업`, `एन्ट्री_सूची`, `कोश`, `통신`, `화면`, `कर्नेल_मान`도 유지한다.

## Java 네트워크

기존 `DatagramSocket`/`DatagramPacket`의 UDP 루프백에 `Socket`/`ServerSocket`의 **कर्नेल_मान 내부 연결형 बाइट_मान स्ट्रीम_मान**을 추가했다. संचिका/소켓과 마찬가지로 SVC를 통해 Java 커널이 전송한다. 물리 NIC의 TCP/IP 패킷 스택은 아니다.

```java
java.net.ServerSocket 서버 = new java.net.ServerSocket(9250);
java.net.Socket अतिथि_मान = new java.net.Socket("localhost", 9250);
java.net.Socket जोड़ना = 서버.accept();
अतिथि_मान.getOutputStream().write("안녕하세요".getBytes("UTF-8"));
byte[] 받은것 = new byte[64];
int 길이 = जोड़ना.getInputStream().read(받은것);
जोड़ना.close(); अतिथि_मान.close(); 서버.close();
```

जनरेट_करें·जोड़ना·accept·양방향 बाइट_मान/सरणी_मान इनपुट_आउटपुट·close·EOF·setSoTimeout을 지원한다. `String.getBytes()`와 UTF-8 이름을 지정한 getBytes도 제공한다. 루프백 주소는 `localhost`/`127.0.0.1`이다. 연결형 समाप्त_करें_अंक 16개, 수신 버퍼당 1024바이트, प्रतीक्षा_करें_मान जोड़ना 최대 4개이며 Java의 대기는 내부 가닥에 실행을 양보한다. डिफ़ॉल्ट_मान समय_उपयोगिता 제한 0은 별도 सॉकेट_मान 기한을 설정하지 않지만 JVM आदेश 수/कर्नेल_मान निष्पादित_करें_आदेश 기한은 여전히 적용된다.

बाहरी_मान अंक_मान IPv4 TCP/UDP는 lwIP/SLIP로 지원한다. वास्तविक_डेटा Ethernet/Wi-Fi 드라이버, DNS·TLS·HTTP लाइब्रेरी 전체는 미지원이다. `java.net`의 모든 메서드와 옵션, `SocketChannel`/select, SSL, shutdownInput/Output는 아직 없다. [흐름시험.java](시험/자바/흐름시험.java)는 वास्तविक_डेटा 송수신·EOF·기한·जोड़ना 회수의 시험 예제다.

게스트 vi에서 한글 이름을 사용해 작성한다.

```python
मान = 21

def 두배(अंक_मान):
    return अंक_मान * 2

print("परिणाम:", 두배(मान))
```

स्टोर_मान 후 `python अभिनन्दन_ae353e94.py`로 실행한다. 실행기는 MicroPython 1.24.1이다. Python 문법 키워드는 그대로 사용하며 फ़ंक्_शन_मान·चर_मान·संचिका 이름과 문자열을 한글로 쓴다.

[हिंदी.py](예제/한글코딩/हिंदी.py)를 같은 디렉터리에 두면 अगला_आइटम 별칭을 사용할 수 있다.

```python
import हिंदी
हिंदी.लिखना_फ़ाइल("अभिनन्दन_ae353e94.txt", "안녕하세요")
हिंदी.निर्गम(हिंदी.पढें_फ़ाइल("अभिनन्दन_ae353e94.txt").decode())
```

निर्गम·संचिका पढ़ें/लिखें/삭제·표준 입력·रेक्_टेंगल·समय_उपयोगिता·UDP를 연결한다. 기존 `udp_send`는 루프백, 새 `udp_sendto(fd, "10.0.2.2", port, data)`는 अंक_मान IPv4 पता 전송이다. `wait_key()`는 화면을 확인할 때 대화형 입력을 기다린다. Python 함수는 `jkoros` 내장 모듈을 통해 SVC를 사용한다. C ABI인 posix-kor 정적 라이브러리를 Python이 직접 링크하는 구성은 아니다. CPython과 일반 एक्सटेंशन_मान 모듈은 아직 없다. 제한형 `pip`의 स्रोत_ट्री 설치는 [Python बंडल ReadMe_फ़ाइल_eb81d7d9](파이썬꾸러미.md)를 따른다. [세 언어의 वास्तविक_डेटा 예제](../../example/README.md).

## C·C++에서 posix-kor 호출

두 भाषा 모두 हिंदी 헤더와 फ़ंक्_शन_मान 이름을 직접 사용한다. [अभिनन्दन_ae353e94.c](예제/한글코딩/अभिनन्दन_ae353e94.c), [अभिनन्दन_ae353e94.cpp](예제/한글코딩/अभिनन्दन_ae353e94.cpp)가 वास्तविक_डेटा EL0 निष्पादित_करें_आदेश 시험 대상이다.

```c
#include "파일규약.h"
#ifdef __cplusplus
extern "C"
#endif
int प्रारंभ_उपयोगकर्ता_ऐप(int तर्क) {
    (void)तर्क;
    const char अभिनन्दन[] = "안녕하세요\n";
    int 문서 = जारी_फ़ाइल("अभिनन्दन_ae353e94.txt", पठन_लेखन | 없으면만들기 | कम_करें_सामग्री, 0600);
    if (문서 < 0) return 1;
    입출력결과형 기록한수 = लिखना_फ़ाइल_डेटा(문서, अभिनन्दन, sizeof(अभिनन्दन) - 1);
    बंद_फ़ाइल(문서);
    लिखना_फ़ाइल_डेटा(1, अभिनन्दन, sizeof(अभिनन्दन) - 1); /* अद्यतित_आइटम आदेशपटल stdout */
    return 기록한수 == sizeof(अभिनन्दन) - 1 ? 0 : 2;
}
```

파일은 게스트 vi로 작성할 수 있다. C는 게스트 `cc` 또는 आयोजक SDK, C++는 आयोजक SDK의 Clang++로 컴파일한다. 아래 예제는 기존 आयोजक SDK 경로다. 게스트 내부 GCC/Clang·libc/libstdc++ 전체를 탑재한 것은 아니다. SDK가 `.c`에는 C11, `.cpp`에는 C++11을 선택한다.

```sh
# 호스트에서 SDK जनरेट_करें·निकालें
make sdk
mkdir -p build/sdk-work
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build/sdk-work
cd build/sdk-work/jkoros-native-sdk
python3 compile.py examples/अभिनन्दन_ae353e94.c -o अभिनन्दन_ae353e94-c.elf
python3 compile.py examples/अभिनन्दन_ae353e94.cpp -o अभिनन्दन_ae353e94-cpp.elf

# 프로젝트로 돌아와 별도 QEMU에서 वास्तविक_डेटा निष्पादित_करें_आदेश
cd /home/user/jkoros/platforms/rpi4-native
python3 उपकरण/निष्पादित_करें_फ़ाइल.py build/sdk-work/jkoros-native-sdk/अभिनन्दन_ae353e94-c.elf
python3 उपकरण/निष्पादित_करें_फ़ाइल.py build/sdk-work/jkoros-native-sdk/अभिनन्दन_ae353e94-cpp.elf
```

अद्यतित_आइटम GUI VM에서 실행하려면 `python3 उपकरण/अपलोड_फ़ाइलें.py पथ/अभिनन्दन_ae353e94-c.elf`의 출력을 게스트에 보내고 `run अभिनन्दन_ae353e94-c.elf`를 입력한다. 게스트에서 작성한 소스의 전송은 `hex फ़ाइल_नाम_पाठ`으로 내용을 얻어 호스트에서 `bytes.fromhex(...)`로 복원할 수 있다. 호스트와 게스트의 संचिका 시스템은 별개다.

| हिंदी नाम | C प्रतीक | क्लिप |
|---|---|---|
| जारी_फ़ाइल/बंद_फ़ाइल | pk_open/pk_close | RAM संचिका, पीअर_मान/절대 पथ |
| पढें_फ़ाइल_डेटा/लिखना_फ़ाइल_डेटा | pk_read/pk_write | संचिका, fd 0/1/2 표준 इनपुट_आउटपुट, 연결형 सॉकेट_मान |
| खोजें_फ़ाइल | pk_lseek | 처음기준/अद्यतित_मूल/끝기준 |
| फ़ाइल_आकार/파일길이정하기 | pk_size/pk_ftruncate | 길이 क्वेरी_मान/परिवर्तित_करें_मान |
| निकालें_फ़ाइल_एन्ट्री_नाम | pk_unlink | संचिका नाम 삭제 |
| कमिट_फ़ाइल_संग्रहण | pk_fsync | RAM이므로 -1, त्रुटि_संख्या=ENOSYS |
| बनाएँ_एंडपॉइंट/बाइंड_करें_पता | pk_socket/pk_bind | AF_INET, SOCK_DGRAM 또는 SOCK_STREAM |
| 자료전문보내기/자료전문받기 | pk_sendto/pk_recvfrom | UDP 루프백 |
| कनेक्ट_नेटवर्क | pk_connect | 연결형 루프백 |
| 통신연결기다리기 | pk_listen | प्रतीक्षा_करें_मान जोड़ना 최대 4개 |
| स्वीकार_करें_नेटवर्क_कनेक्शन | pk_accept | अद्यतित_आइटम पता 인수는 NULL/NULL만 समर्थन_मान |
| पढें_सॉकेट_पता | pk_getsockname | 로컬 पता/पोर्ट_मान |

`통신규약.h`의 निज `pk_sockaddr_in`을 사용하며 पोर्ट_मान·주소는 `망차례짧은수`/`नेटवर्क_पूर्णांक`로 변환한다. C सॉकेट_मान 호출은 비차단이며 आँकड़े/연결이 없으면 -1과 `त्रुटि_संख्या=11`(EAGAIN)을 반환한다. 양수 इनपुट_आउटपुट 결과가 요청보다 작을 수 있으므로 पुनरावृति_मान 처리한다. विफलता_मान 후에만 오류번호를 확인한다.

[स्ट्रीम_मान.c](예제/한글코딩/स्ट्रीम_मान.c)는 C에서 हिंदी 이름으로 जोड़ना·accept·부분 पढ़ें/लिखें·큐 포화·EOF를 처리하는 निष्पादित_करें_आदेश 예제다. SDK의 `examples/स्ट्रीम_मान.c`를 같은 `compile.py`로 컴파일한다.

SDK는 **libposix-kor-user.a**를 링크한다. 호출 흐름은 C/C++ → वास्तविक_डेटा हिंदी C फ़ंक्_शन_मान 또는 호환용 `pk_*` → `svc #0` → 커널의 소유권·सूचक 검사 → Java RAM संचिका/루프백 또는 बाहरी_मान lwIP TCP/UDP 구현이다. `libposix-kor-arm64.a`는 कर्नेल_मान 내부용이므로 EL0 프로그램에 링크하지 않는다. Linux 헤더나 Linux ELF와 혼합하지 않는다. 동적 जोड़ना, 표준 C printf, libstdc++/STL, अपवाद·RTTI는 제공하지 않으며 C++의 정적 생성자·स्थानीय_दायरा ऑब्जेक्ट_मान 소멸자는 지원한다. 상세 इंडेक्स·मेमोरी_डेटा 범위는 [사용자호출규약.md](사용자호출규약.md)를 참고한다.

## मान्य_करें

`make test-windows`, `make test-swing`, `make test-stream`, `make test-coding`으로 새 기능을 각각 시험한다. `make test`는 기존 शेल·VNC·JVM·AOT·कर्नेल_मान रक्षित_करें_मान 시험까지 포함한다. वास्तविक_डेटा बोर्ड 대신 QEMU raspi4b에서 수행한다. 결과는 [이전 GUI एक्सटेंशन_मान मान्य_करें लॉग_रिकॉर्ड](build/verification/release.json)과 [अद्यतित_आइटम कॉमन_लैंग्वेज_रनटाइम मान्य_करें लॉग_रिकॉर्ड](build/verification/native-runtime-summary.json), [여러 आदेशपटल 화면](build/verification/windows/four-terminals.png), [Swing 화면](build/verification/swing/native-swing.png)을 참고한다.

구현 시 참고한 표준 API: [Socket](https://docs.oracle.com/javase/8/docs/api/java/net/Socket.html), [JFrame](https://docs.oracle.com/javase/8/docs/api/javax/swing/JFrame.html), [JButton](https://docs.oracle.com/javase/8/docs/api/javax/swing/JButton.html). 이 문서의 구현 범위가 위 표준 전체를 지원한다는 뜻은 아니다.

## हिंदी 이름으로 직접 작성하는 창과 थ्रेड_मान

`example/java/खिड़कीउदाहरण.java`는 `실행할일.निष्पादन`,
`동작받이.동작받기(एक्शन_सूचना)`, `बटन`, `घटना_कतार.나중에실행`, `चलाएँ()`을 쓴다.
निज JVM에 이 이름들의 ऑब्जेक्ट_मान·विधि_मान·콜백을 직접 구현했으며 영어 Swing 객체를
보관하는 래퍼가 아니다. `कार्यसूत्र`도 निज 스케줄러와 직접 연결된다.
세부 메서드와 기존 हिंदी API에서의 변경은 [हिंदी API 문서](한국어자바/ReadMe_फ़ाइल_eb81d7d9.md)를 본다.

आयोजक javac는 배포 JAR를 कक्षा_मान 경로로 사용한다.

```sh
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 ../../example/java/खिड़कीउदाहरण.java
python3 उपकरण/निष्पादित_करें_आदेश.py --desktop --network --resolution 1920x1080
```

게스트에는 빌드한 예제가 `/example/java`에 설치된다.

```text
cd /example/java
java खिड़कीउदाहरण
```

직접 화면/थ्रेड_मान API와 `चलाएँ()` 진입점은 निज JVM 전용이다.
전체 OpenJDK·Swing 재구현이나 일반 OpenJDK에서 같은 API의 실행을 보장하지 않는다.
기존 표준 `main(String[])` 프로그램은 계속 실행할 수 있다.
