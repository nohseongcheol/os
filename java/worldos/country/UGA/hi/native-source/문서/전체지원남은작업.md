# 전체 समर्थन_मान 요청의 अद्यतित_आइटम अवस्था_मान

अनुरोध 전체는 아직 완료되지 않았다. अद्यतित_आइटम ISO는 निज Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 वास्तविक_डेटा C POSIX 일부 기능, हिंदी API/स्रोत नाम, IDE संचिका 보존, 게스트 Java संचिका 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/ReadMe_फ़ाइल_eb81d7d9.md)를 기준으로 판단한다.

| अनुरोध 분야 | अद्यतित_आइटम निष्पादित_करें_आदेश 가능한 क्लिप | 전체 지원에 필요한 작업 |
|---|---|---|
| Java कंपाइल_स्रोत·निष्पादित_करें_आदेश | 게스트 제한형 javac/JVM, 정적 단일 클래스와 일부 표준 ऑब्जेक्ट_मान | 일반 ऑब्जेक्ट_मान·कक्षा_मान जोड़ना·अपवाद·GC·스레드, 완전한 javac와 표준 कक्षा_मान लाइब्रेरी |
| संचिका | POSIX 서술자, Java 단일 बाइट_मान संचिका स्ट्रीम_मान, 전용 मीडिया_मान 보존 | 일반 java.io/nio, 디렉터리·अनुमति_मान·लॉक_मान·일반 फ़ाइल_सिस्टम·एक्सटेंशन_मान 가능한 क्षमता_मान |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP आयोजक 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, जोड़ें_एन्ट्री NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 घटना·फ़ॉन्ट_मान·खिड़की ऑपरेटिंग_सिस्टम_मान, AWT 네이티브 연결과 Swing निष्पादित_करें_आदेश 기반 |
| POSIX | 문서화한 संचिका·단말·UDP 부분 | प्रक्रिया_मान·exec/fork·스레드·시그널·समय_उपयोगिता·mmap·poll·파이프 등과 적합성 मान्य_करें |
| 언어별 नाम | हिंदी 46개 대응 एन्ट्री_मान, वास्तविक_डेटा C/Java/संचिका नाम 적용 | लक्ष्य भाषा कमिट_मान, 언어별 용례·역사 근거와 해당 स्रोत·도구의 मान्य_करें |

निज 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 निष्पादित_करें_आदेश 환경을 추가하는 방식은 별도의 कर्नेल_मान·루트 फ़ाइल_सिस्टम·OpenJDK·그래픽 서버·영구 स्टोर_मान 구성을 가진 निष्पादित_करें_आदेश 경로가 된다. 후자는 기존 निज 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

निष्पादित_करें_आदेश 기반과 जोड़ें_एन्ट्री लक्ष्य 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. अद्यतित_आइटम 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
