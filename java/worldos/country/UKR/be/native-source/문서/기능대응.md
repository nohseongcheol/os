# engos 기능 대응표

이 표는 기존 `ранейшых_версій_крыніца/`의 аб_ект_значэнне 기반 JVM 관리 커널을 설명한다. 새 `compiler/`와 `os/`는 별도 제한형 네이티브 구현이며 [фактычны_дадзеныя 부팅 기능과 한계](../os/файл_звестак_eb81d7d9.md)를 따로 기록한다.

## 기존 аб_ект_значэнне 기반 관리 ядро_значэнне 전체를 부팅하기 위해 남은 Злучыцца

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/прылада_значэнне 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot увядзенне_бал_значэнне, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 Кантэкст_значэнне сховішча_значэнне
- фактычны_дадзеныя PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA цыкл_значэнне
- Java аб_ект_значэнне·масіў_значэнне сувязь_Макет, выключэнне, статычны_значэнне ініцыялізаваць, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT стадыя_значэнне
- FAT 디스크 구역을 фактычны_дадзеныя ATA 장치와 연결하는 увод_вывад 접착 слой_значэнне

위 관리 계층은 engos 기능의 Java 관리 구현과 вузел 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot увядзенне_бал_значэнне, статычны_значэнне ініцыялізаваць·цэлы_лік масіў_значэнне, VGA/직렬/PS2, 명령해석기, карыстальнік ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 вузел 루프백 패킷 왕복을 검증했다. 위 표의 аб_ект_значэнне 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
