# 셸에서 실행하는 χρήστης 프로그램과 UDP

게스트에서 일반적인 `main(String[] args)` 형식의 소스를 직접 작성하고 컴파일하려면 [제한형 Java 개발 περιβάλλον_5d36e09c αρχείο_readme_eb81d7d9](../../문서/περιβάλλον_ανάπτυξης_Java.md)를 참고한다. 아래의 네이티브 ELF 개발과 별도로 `javac FILE.java`, `java CLASS`를 제공한다.

## 바로 εκτελώ_εντολή

φιλοξενώ Τερματικό 1:

```sh
cd /home/user/jkoros
python3 os/Εργαλεία/ηχώ_δεδομένα.py --port 9000
```

이 서버는 `127.0.0.1`에만 바인딩한다. εξωτερικός_τιμή 연결을 받도록 방화벽이나 υλικό_θύρα 전달을 변경하지 않는다. Ctrl+C로 종료한다.

φιλοξενώ Τερματικό 2:

```sh
cd /home/user/jkoros
make run
```

게스트의 `jkoros>` 프롬프트에 είσοδος_τιμή:

```text
apps
run hello first second
net
run netcheck
run udp 10.0.2.2 9000 hello
run stress 9000
```

- `hello`: 독립 Java ELF 실행과 πραγματικός_δεδομένα CPU άδεια_τιμή `ring 3`, Παράμετροι Έξοδος.
- `netcheck`: θύρα_τιμή 중복, 잘못된 δείκτης_χειρισμού_τιμή/δείκτης/διάρκεια_τιμή, 비차단 받기와 τιμή_ώρας 초과 επαληθεύω.
- `udp`: IPv4 διεύθυνση·προορισμός_τιμή θύρα_τιμή·한 λέξη_τιμή 메시지를 받아 UDP로 보내고 같은 응답을 επαληθεύω. `UDP ECHO PASS`, `Exit: 0`이면 성공.
- `stress`: φιλοξενώ `10.0.2.2`의 εκχωρώ_τιμή 창구와 1,023/1,024바이트 데이터그램을 24회 왕복. λαμβάνω_τιμή_cef4d8ab βρόχος_τιμή 경계를 여러 번 지난다.

`make run`/`run-gui`는 `-netdev user,id=net0 -device rtl8139,netdev=net0`을 사용한다. τρέχων_στοιχείο 주소는 게스트 `10.0.2.15/24`, πύλη_τιμή `10.0.2.2`로 고정돼 있다. QEMU χρήστης 네트워크의 φιλοξενώ πρόσβαση_καταχώρηση 주소를 사용한 예제다. 다른 네트워크 설정에는 맞춰 수정해야 하며 자동 DHCP는 없다. NIC 없이 실행하려면 `make -C os run NET_ARGS='-net none'`을 사용한다. 이때 εφαρμογή_f5044b9b 실행은 되지만 UDP 열기는 `-19`로 실패한다.

## 새 Java εφαρμογή_f5044b9b προσαρτώ_καταχώρηση

`예제/내프로그램.java`를 Επόμενο_στοιχείο 형식으로 만든다. 진입점은 Παράμετροι 없는 `static int` 또는 `static void` 함수다. 인수는 χρήστης API로 조회한다.

```java
public final class 내프로그램 {
    public static int Εκτέλεση_2() {
        χρήστης.Εγγραφή("My program is running in user mode.\n");
        return 0;
    }
}
```

`os/χρήστης/εφαρμογή_f5044b9b.mk`에 추가한다.

```make
APP_NAMES += mine
APP_SOURCE_mine := χρήστης/예제/내프로그램.java
APP_ENTRY_mine := 내프로그램.Εκτέλεση_2
```

여러 Java 파일을 쓰면 `APP_SOURCE_mine`에 공백으로 모두 나열한다. `χρήστης/δήλωση/χρήστης.java`는 자동으로 함께 컴파일한다.

```sh
cd /home/user/jkoros
make iso
make run
```

새로 부팅한 셸에서 `run mine`을 실행한다. 이미 εκτελώ_εντολή 중인 VM에는 δομή_Σύστημα 결과가 자동 반영되지 않는다. εφαρμογή_f5044b9b 이름은 τρέχων_στοιχείο 셸의 ASCII είσοδος_τιμή 제한에 맞춘 1~15자의 소문자 이름이며 Java Τάξη_τιμή·συνάρτηση_τιμή·변수에는 한국어를 쓴다. 최대 32개 εφαρμογή_f5044b9b, 한 εκτελώ_εντολή 파일은 최대 2MiB다.

독립 ELF만 컴파일할 수도 있다.

```sh
cd /home/user/jkoros
python3 compiler/πρόγραμμα_μεταγλώττισης.py --target user --entry 인사.Εκτέλεση_2 \
    -o os/build/apps/hello.elf os/χρήστης/δήλωση/χρήστης.java os/χρήστης/예제/인사.java
```

`--target user`는 **jkoros 전용 ABI**다. Linux 대상과 시스템 호출 번호가 다르므로 φιλοξενώ 터미널에서 직접 실행하면 안 된다. `.class`는 별도 `java CLASS` 명령의 στήριγμα_τιμή απόσπασμα 안에서 실행한다. `.jar`와 일반 Linux εκτελώ_εντολή 파일은 지원하지 않는다.

## χρήστης 네트워크 API

선언은 `δήλωση/χρήστης.java`에 있다. `στέλνω_δεδομένα`/`λαμβάνω_δεδομένα`의 `int[]` στοιχείο_στοιχείο 한 개는 바이트 하나(0~255)를 나타낸다. 한 데이터그램의 최대 δεδομένα 길이는 1,024바이트다.

```java
int δείκτης_χειρισμού_τιμή = χρήστης.ανοίγω_δίκτυο(0); // 0: 임시 τοπικός_Πεδίο UDP θύρα_τιμή 자동 επιλογή_τιμή
int[] δεδομένα = new int[32];
δεδομένα[0] = 'H'; δεδομένα[1] = 'i';
int 보낸길이 = χρήστης.στέλνω_δεδομένα(δείκτης_χειρισμού_τιμή, 0x0a000202, 9000, δεδομένα, 2);
int 받은길이 = χρήστης.λαμβάνω_δεδομένα(δείκτης_χειρισμού_τιμή, δεδομένα, 1500);
χρήστης.κλείνω_δίκτυο(δείκτης_χειρισμού_τιμή);
```

πραγματικός_δεδομένα 프로그램에서는 Άνοιγμα·στέλνω·받기의 음수 반환값을 각각 검사한다. 완성된 예제는 `예제/자료통신.java`에 있다. `λαμβάνω_δεδομένα`의 περίμενε_τιμή 시간은 0~2,000밀리초이며 0은 즉시 반환이다. 받은 데이터그램이 배열보다 크면 해당 데이터그램을 버리고 `-90`을 반환한다. 창구당 λαμβάνω_τιμή_cef4d8ab 대기열은 한 개뿐이므로 προσαρτώ_καταχώρηση 도착분은 버린다. `보낸주소`와 `보낸창구`로 마지막으로 받은 상대를 조회한다.

| 반환값 | 의미 |
| --- | --- |
| 0 이상 | δείκτης_χειρισμού_τιμή·διεργασία_τιμή_καταχώρηση διάρκεια_τιμή·성공 등 해당 함수의 μέτρηση |
| -5 | συσκευή_τιμή στέλνω_τιμή αποτυχία_τιμή |
| -9 | 잘못되었거나 닫힌 통신 δείκτης_χειρισμού_τιμή |
| -11 | 비차단 받기에서 도착한 δεδομένα 없음 |
| -14 | χρήστης δείκτης/πίνακας_τιμή απόσπασμα ΣΦΑΛΜΑ |
| -19 | στήριγμα_τιμή NIC 없음 |
| -22 | θύρα_τιμή/περίμενε_τιμή τιμή_ώρας/Παράμετροι τιμή ΣΦΑΛΜΑ |
| -24 | 열린 δίκτυο_θύρα 4개 한도 |
| -38 | 알 수 없는 시스템 호출 |
| -90 | δεδομένα 또는 λαμβάνω_τιμή_cef4d8ab πίνακας_τιμή Μέγεθος 문제 |
| -98 | τοπικός_Πεδίο θύρα_τιμή Ευρετήριο 중복 |
| -101 | 지원하지 않는 προορισμός_τιμή διεύθυνση |
| -110 | ARP·συσκευή_τιμή·λαμβάνω_τιμή_cef4d8ab τιμή_ώρας 초과 |

IP 주소는 상위 바이트부터 표기한 32비트 값이다. `10.0.2.2`는 `0x0a000202`이다. 주소를 반환하는 함수는 κωδικοποίηση_τιμή 있는 Java `int`의 δυαδικό_ψηφίο_τιμή 패턴을 사용하므로 상위 비트가 1인 πληροφοριακά_συστήματα_απλά IP 주소가 음수로 보일 수 있다. 단순히 모든 API 반환값의 부호를 오류로 판단하면 안 된다.

## εκτελώ_εντολή 경계와 시스템 호출

```text
κέλυφος run → JKAP에서 ELF επικυρώνω·적재 → ring 3 χρήστης εφαρμογή_f5044b9b
                                 ↓ int 0x80
                      δείκτης 검사 → Java πυρήνας_τιμή API → RTL8139/UDP
                                 ↓ Έξοδος_εφαρμογή·εξαίρεση·τιμή_ώρας 초과
                                κέλυφος 복귀
```

시스템 호출 레지스터는 `EAX=Ευρετήριο`, `EBX,ECX,EDX,ESI,EDI=Παράμετροι`, `EAX=μέτρηση`다. Java 호출 τελεστέος_δέσμη ABI는 컴파일러가 χρήστης 스텁에서 이 형식으로 바꾼다. C의 POSIX/JNI ABI가 아니다.

| Ευρετήριο | 호출 |
| --- | --- |
| 0 | Έξοδος_εφαρμογή(Κατάσταση_τιμή κωδικός_τιμή) — Εκτέλεση_2/ΣΦΑΛΜΑ 런타임에서 χρήση_τιμή |
| 1 | συμβολοσειρά_τιμή Εγγραφή |
| 2 / 3 | Παράμετροι 개수 / Παράμετροι συμβολοσειρά_τιμή διεύθυνση |
| 10 | UDP Άνοιγμα |
| 11 | UDP στέλνω(δείκτης_χειρισμού_τιμή, IP, προορισμός_τιμή θύρα_τιμή, πίνακας_τιμή διεύθυνση, διάρκεια_τιμή) |
| 12 | UDP λαμβάνω(δείκτης_χειρισμού_τιμή, πίνακας_τιμή διεύθυνση, 제한 밀리초) |
| 13 | UDP Κλείσιμο |
| 14 | τοπικός_Πεδίο IP διεύθυνση |
| 15 / 16 | 마지막 ομότιμος_τιμή IP / UDP θύρα_τιμή |
| 20 | RAM Αρχείο Ανάγνωση(Όνομα int[] διεύθυνση, Έξοδος int[] διεύθυνση) |
| 21 | RAM Αρχείο Εγγραφή(Όνομα int[] διεύθυνση, είσοδος_τιμή int[] διεύθυνση, 바이트 διάρκεια_τιμή) |
| 22 | UTF-16 κωδικός_τιμή μάθημα_τιμή 문자 Έξοδος(0~65535) |

Αρχείο API는 `χρήστης.파일읽기(int[] Όνομα, int[] δεδομένα)`와 `χρήστης.εγγράφω_Αρχείο(int[] Όνομα, int[] δεδομένα, int διάρκεια_τιμή)`다. 이름은 ASCII κωδικός_τιμή πίνακας_τιμή(최대 64칸, 0 Έξοδος_εφαρμογή 또는 πίνακας_τιμή 끝), δεδομένα στοιχείο_στοιχείο 하나는 한 바이트다. 반환값은 읽거나 쓴 길이이며 Αρχείο 없음 `-2`, δείκτης ΣΦΑΛΜΑ `-14`, Όνομα/διάρκεια_τιμή ΣΦΑΛΜΑ `-22`, Αρχείο υποδοχή_τιμή_ff41a4f1 부족 `-28`, Μέγεθος 초과 `-90`을 반환한다. 쓰기는 επικυρώνω 후 Αρχείο 전체를 대체한다. `χρήστης.εγγράφω_χαρακτήρας_τιμή(int)`는 문자를 단말에 출력한다. Java 프로그램의 일반 `java.io` 구현은 아니다.

`εκτέλεση_άδεια()`은 시스템 호출이 아니라 χρήστης 모드에서 CS의 하위 비트를 직접 읽으므로 πραγματικός_δεδομένα εκτελώ_εντολή 권한을 확인한다. πυρήνας_τιμή υλικό_θύρα 접근용 `συσκευή_τιμή` native 함수는 χρήστης τιμή_στόχος 컴파일에서 거부한다. ELF에 직접 특권 명령을 넣더라도 CPU가 차단한다.

## 범위와 제한

- 한 번에 한 프로그램만 실행하며 완료 후 셸로 돌아온다. 백그라운드 εκτελώ_εντολή, 파이프, 프로세스 간 통신은 없다. εκτελώ_εντολή 파일은 커널의 Ανάγνωση 전용 JKAP 묶음에서 적재한다. δεδομένα 파일에는 주기억 파일체계와 전용 IDE 보존 형식이 있다.
- χρήστης 가상 διεύθυνση `0x04000000..0x043fffff`를 물리 8~12MiB에 연결한다. εκτελώ_εντολή 영상은 μπροστινή_τιμή 2MiB, 인수는 `0x04300000`부터, 스택은 περιοχή_τιμή_0e9a97ab 끝에서 시작한다. πυρήνας_τιμή identity 페이지는 supervisor 전용이다.
- 실행마다 4MiB χρήστης 영역을 비우고 Αρχείο 구역을 복사해 BSS·πίνακας_τιμή 영역을 초기화한다. χρήστης GC는 없지만 Έξοδος_εφαρμογή 후 Επόμενο_στοιχείο εκτελώ_εντολή 때 영역을 재사용한다. 인수는 공백으로 분리한 최대 16개이며 προσφορά/이스케이프 파싱은 없다.
- χρήστης 페이지의 κωδικός_τιμή/δεδομένα 분리 Ανάγνωση 전용 Ρυθμίσεις, NX, τελεστέος_δέσμη guard, ASLR은 아직 없다. 커널과 χρήστης Μνήμη_δεδομένα·υλικό_θύρα άδεια_τιμή 경계를 구현한 초기판이지 보안 인증된 샌드박스는 아니다.
- PIT 100Hz로 약 3초 εκτελώ_εντολή 상한을 두며 τιμή_ώρας 초과는 `Exit: 124`다. χρήστης CPU 예외는 `128 + εξαίρεση Ευρετήριο`(페이지 ΣΦΑΛΜΑ 142, 특권 위반 141), Java πίνακας_τιμή/계산 오류는 101~105다. πυρήνας_τιμή 오류까지 복구하는 구조는 아니다.
- 네트워크는 PCI bus 0/function 0의 RTL8139, στατικός_τιμή IPv4, ARP, UDP만 지원한다. NIC는 폴링하고 송신은 동기식이다. IPv4 단편 재조립·TCP·DNS·DHCP·IPv6·HTTP·TLS·일반 `java.net`은 미지원이다. IPv4 UDP άθροισμα_ελέγχου 0은 규약에 따라 허용하고, 그 외 UDP/IP 검사합과 길이는 검증한다.
- χρήστης εκτελώ_εντολή·네트워크·προστασία_τιμή όριο_τιμή 전체 시험은 QEMU에서 수행했다. VirtualBox에서도 `make vbox`로 부팅과 `run hello vbox`의 ring 3 εκτελώ_εντολή·πληροφοριακά_συστήματα_απλά 종료를 확인했다. VirtualBox PCnet/E1000용 드라이버는 없어 그 환경의 네트워크는 지원하지 않는다.

## επικυρώνω 근거

`make test`는 πρόγραμμα_μεταγλώττισης 14개 시험, Java 패킷 πάθηση 2,201개 검사, 기존 κέλυφος ELF/ISO 부팅 시험, χρήστης ELF/πραγματικός_δεδομένα UDP/προστασία_τιμή όριο_τιμή 시험을 실행한다. 네트워크 시험은 루프백 서버가 받은 자료의 διάρκεια_τιμή·해시까지 `os/build/δοκιμή_χρήστης_δίκτυο.json`에 기록한다. 시험용 손상된 ELF·특권 Εντολή·무한 επανάληψη_τιμή 프로그램은 임시 묶음에만 넣으며 배포용 `apps` 목록에는 넣지 않는다.
