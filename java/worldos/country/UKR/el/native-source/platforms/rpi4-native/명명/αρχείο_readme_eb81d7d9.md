# ίδιο 커널과 번역기의 ελληνικά Όνομα

대상은 `platforms/rpi4-native`의 ίδιο Java πυρήνας_τιμή, χρήστης JVM, C υπολογιστής_5eb260fa Σύνδεση,
TCP/UDP·FTP, C πρόγραμμα_μεταγλώττισης_εργαλείο 이식부, MicroPython 이식부, δομή_Σύστημα·εκτελώ_εντολή·시험 도구다.
`golang/worldos/Κάντρυ_τιμή/KOR/ΠΗΓΗ`의 원칙처럼 기능을 먼저 구분하고 이름을 정한다.
x86 Java 커널과 공용 x86·ARM64 미리 번역기의 ίδιο 선언도 명명 검사에 포함한다.
Linux 실행판의 φιλοξενώ Εργαλεία, OpenJDK 보조 Εργαλεία 및 εξωτερικός_τιμή 배포 προέλευση_δέντρο 전체를
한국어로 δοκιμάζω_ξανά_τιμή 작성했다는 뜻은 아니다.

## 명명 원칙과 말의 근거

- 명사는 자료의 역할을 나타낸다: `Αρχείο_δείκτης_χειρισμού`, `ομότιμος_αριθμός_θύρας`, `σωρός_Χώρος_αποθήκευσης`, `πληκτρολόγιο`.
- 함수는 행위를 나타낸다: `Ανάγνωση`, `Εγγραφή`, `Άνοιγμα`, `Κλείσιμο`, `망주소묶기`, `εκτελώ_εφαρμογή`.
- TCP의 이어진 바이트 흐름과 UDP의 όριο_τιμή 있는 자료를 `σύνδεση`와 `αυτοδύναμο_πακέτο_Κανάλι`로 구별한다.
- 짧은 영어 변수도 쓰임에 따라 `διάρκεια_τιμή`, `δεδομένα_θέση`, `Αναζήτηση_Ευρετήριο`, `반환값`으로 풀어 쓴다.
  순번·임시 산술값처럼 여러 역할에 재사용되는 변수는 `순번`, `첫째값`, `둘째값`으로 구별한다.
- 이름이 같아도 εξωτερικός_τιμή 구조체의 필드와 ίδιο 변수는 별도로 분석한다.

`Κανάλι_καταχώρηση(通路)`는 이동이나 교류가 이루어지는 길이라는 기존 의미를 통신 연결에
적용했다. `θύρα_τιμή(窓口)`의 주고받는 접점이라는 의미를 연결을 받는 곳에 적용했다.
이는 국립국어원 한국어기초사전의 [Κανάλι_καταχώρηση](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=49310),
[θύρα_τιμή](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=24898)의 뜻에 근거한다.

`αυτοδύναμο_πακέτο(電文)`은 전보에 담는 글이라는 기존 통신 어휘에서 가져와, UDP 자료의
경계가 보존된다는 특징을 드러내는 데 쓴다. 근거는
[한국어기초사전 αυτοδύναμο_πακέτο](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=74335)이다.
`ροή_τιμή`, `νήμα_τιμή`, `쌓임`은 우리말의 움직임·이어짐·쌓이는 모양을 빌린 표현이다.
`ροή_εισόδου`, `작업가닥`, `δέσμη_Χώρος_αποθήκευσης` 같은 복합 이름은 이 프로젝트의 기능별 조어다.
이 λεξικό 근거를 특정 중세 문헌의 최초 출현이나 공인 전산 번역으로 확대하지 않는다.
공인 표준 Μετάφραση_προέλευση·국어사 αυτοδύναμο_πακέτο 감수를 마쳤다는 뜻도 아니다.

## 보존하는 규격 Όνομα

`public`, `class`, `int`는 예약어다. `String`, `main`, 배열의 `length`는 예약어가 아니다.
τρέχων_στοιχείο 다섯 Java 예제는 `Εκτέλεση_2()`·`실행인수`·ελληνικά 화면/νήμα_τιμή API를 사용해
예약어·리터럴 외의 식별자를 한국어로 작성한다. 화면/가닥은 표준 객체를
감싸지 않고 ίδιο JVM에 직접 구현했다. 자세한 계약은 [ελληνικά Java API](../한국어자바/αρχείο_readme_eb81d7d9.md)를 본다.

표준 javac는 συμβολοσειρά_τιμή 리터럴에 `java.lang.String`, συμβολοσειρά_τιμή 결합에 `StringBuilder`
같은 이름을 생성한다. 이들은 ελληνικά 소스에서도 바이트코드에 남을 수 있다.
기존 표준 class를 실행하는 JVM의 αντιστοίχιση_τιμή συμβολοσειρά_τιμή, 아직 표준 라이브러리를 쓰는
통신·Αρχείο 연결부까지 모두 한국어로 재구현한 것은 아니다. 이름만 일괄 치환하면
서술자·재정의·native 연결이 달라져 호환성이 깨진다.

C 표준 συνάρτηση_τιμή·ακέραιος_Τύπος·POSIX ABI, CPU δήλωση_τιμή Όνομα, 어셈블리 Εντολή, 링커 절 Όνομα,
TinyCC·lwIP·MicroPython이 요구하는 Ρυθμίσεις 매크로와 헤더 이름도 보존한다.
예: `main`, `memcpy`, `pk_bind`, `mpconfigport.h`, `lwipopts.h`, `stdint.h`.
ίδιο C 함수의 προέλευση_δέντρο 이름은 한국어이며, [기계연결이름.h](기계연결이름.h)가
기존 AOT·어셈블리·SDK에 공개한 υπολογιστής_5eb260fa 심볼과 연결한다.
Python의 `__init__`, `setUp`, `handle`, 표준 μονάδα_τιμή χαρακτηριστικό_τιμή_286d43f0, 명령행 옵션과 JSON 키도
εξωτερικός_τιμή 계약이다. `build/`, 배포 바이너리 이름과 `/sdk`는 기존 εκτελώ_εντολή 경로를 유지한다.
εξωτερικός_τιμή 원본은 `vendor/`에서 이용허락·해시와 함께 관리한다.


`Εργαλεία/시언어이름분석.py`는 libclang 6으로 C 선언과 참조를 검사한다.

이미 변경된 소스에 δοκιμάζω_ξανά_τιμή 적용하여 대응표를 덮어쓰지 않는다.

## C 통신 구조체와 Python ΣΦΑΛΜΑ

C 통신에서 `갈래`는 διεύθυνση 체계를 구분하고 `αριθμός_θύρας`는 port, `διεύθυνση_τιμή`은
IPv4 주소의 32비트 값을 나타낸다. `αυτοδύναμο_πακέτο_πρωτόκολλο`은 앞서 설명한 αυτοδύναμο_πακέτο(電文)과
εργασία_τιμή(規約)을 결합해 UDP의 기능을 드러낸 프로젝트 이름이다.

| 표준 표현 | ελληνικά 직접 구현 |
|---|---|
| AF_INET / SOCK_DGRAM / IPPROTO_UDP | enum의 πλέγμα_παιδικά / υποδοχή_αυτοδύναμου_πακέτου / αυτοδύναμο_πακέτο_πρωτόκολλο |
| struct pk_sockaddr_in | struct πλέγμα_υποδοχή_διεύθυνση |
| sin_family / sin_port | διεύθυνση_παιδικά / αριθμός_θύρας |
| sin_addr.s_addr | διεύθυνση_Internet.διεύθυνση_τιμή |
| OSError / ΣΦΑΛΜΑ.args[0] | σφάλμα_συστήματος / ΣΦΑΛΜΑ.Ευρετήριο |

ελληνικά 구조체는 `#define` 치환이나 τιμή_πεδίου 별칭이 아닌 별개 자료형이다.
표준 구조체와 같은 16바이트 배치를 선언하며 πυρήνας_τιμή SVC에서 바이트 복사로
검사한다. `ανοίγω_τελικό_σημείο`·`στέλνω_αυτοδύναμο_πακέτο_δεδομένα`와 Αρχείο 함수는 στατικός_τιμή 라이브러리에
πραγματικός_δεδομένα ελληνικά 이름의 συνάρτηση_τιμή 심볼을 갖는다. 기존 pk_* 심볼도 유지한다.
이전 코드에서 ελληνικά 통신 함수에 pk_sockaddr*를 전달했다면 ελληνικά 구조체로
옮기거나, 표준 구조체와 pk_* 함수의 짝을 유지한다.

Python의 `σφάλμα_συστήματος`는 OSError의 ελληνικά 하위 클래스이며 연결부에서
ΣΦΑΛΜΑ 번호를 보존하여 변환한다. 일반 Python 문법과 εξωτερικός_τιμή 패키지의 API는 유지한다.

## 직접 GUI 이름의 뜻과 검토 απόσπασμα

`실행할일`은 수행할 내용을, `Εκτέλεση`는 그 수행을 나타낸다.
`동작받이`는 동작이 발생했다는 알림을 받는 역할, `έργο_γνωστοποίηση`은 전달되는 사건이다.
`κουμπί`는 눌러 동작시키는 조작부, `Ετικέτα`는 αρχείο_readme_eb81d7d9 글의 δείκτης_θέσης,
`πεδίο_κειμένου`은 글을 적는 δείκτης_θέσης, `작업가닥`은 이어지는 εκτελώ_εντολή 흐름을 뜻한다.
`εκτελώ_εντολή(實行)`·`Ενέργεια(動作)`의 기존 뜻과 `받다`·`알리다`·`νήμα_τιμή`의 기능을
결합한 프로젝트 이름이다. 새 복합어가 역사 문헌에 그대로 있었다거나
특정 시대에 처음 쓰였다고 주장하지 않는다.

전체 저장소는 `python3 Εργαλεία/προέλευση_κριτική.py`로 검토한다.
결과는 `build/verification/naming/source-review.json`이며 파일별 κατακερματισμός_Αρχείο,
ASCII 파일명과 Python의 영어 δήλωση 위치를 기록한다.
공용 ARM64·x86 번역기의 구현은 `compiler/자바도구/기계어미리번역.java`로 전환했다. `compiler/기계어미리번역.py`는 호환 진입점이다.
`compiler/arm64.py`는 이전 경로와 `ARM64(...).generate(...)` 호출을 이어 주는
호환 진입점이다. `compiler/classfile.py`, OpenJDK 보조 Εργαλεία, Linux έκδοση_τιμή 도구와
기존 호환 진입점에는 영어 이름이 남아 있다. 따라서 전체 저장소가
예약어 외 100% 한국어라고 판정하지 않는다.
`Εργαλεία/명명검사.py --Ταχυδρομικός_κώδικας_Γλώσσα`는 ενεργή ARM64 소스의 δήλωση, C 의미 Ανάλυσε_τιμή,
x86 Java 커널과 공용 번역기의 ίδιο δήλωση, Java 예제 전체 αναγνωριστικό_τιμή,
ARM64 Python 예제와 직접 GUI/가닥에 표준 래퍼가 없는지를 별도로 검사한다.

## τρέχων_στοιχείο 기능을 기준으로 보완한 Όνομα

번역은 글자를 음역하는 대신 자료의 역할과 함수의 행동을 구분한다.
동일한 영어 이름도 문맥이 다르면 ελληνικά 이름을 달리 정한다.
Αρχείο 이름은 주된 기능을 나타내고, συνάρτηση_τιμή 이름은 행동을, μεταβλητή_τιμή 이름은 담는 자료를 나타낸다.
예약어, 표준 API 및 εξωτερικός_τιμή Σύνδεση 규약은 따로 기록한다.

| 이전 Όνομα | 적용한 Όνομα | τρέχων_στοιχείο 기능 |
|---|---|---|
| `arm64.py`의 구현 | `compiler/자바도구/기계어미리번역.java` | Java 바이트코드를 독립 실행용 C 원문으로 미리 Μετάφραση_προέλευση |
| `ARM64`, `generate` | `υπολογιστής_κωδικός_πρόγραμμα_μεταγλώττισης`, `δημιουργώ` | Μετάφραση_προέλευση 상태를 담는 객체와 C ΠΗΓΗ δημιουργώ 행동 |
| `prototype`, `method` | `μέθοδος_πρωτότυπο`, `μέθοδος_σώμα` | 함수의 μορφή_τιμή 선언과 πραγματικός_δεδομένα Εντολή ΠΗΓΗ |
| `profile`, `heap_words` | `εκτέλεση_στόχος`, `동적기억낱말수` | πυρήνας_τιμή·χρήστης 구분과 εκχωρώ_Χώρος_αποθήκευσης Μνήμη_τιμή 공간의 υπολογιστής_5eb260fa 낱말 수 |
| `pc`, `op` | `εντολή_θέση`, `명령번호` | 바이트코드에서의 위치와 수행할 명령의 Ευρετήριο |
| `x`, `y`, `w`, `h` | `συντεταγμένη_x`, `κουμπί_Y_συντονισμός`, `영역너비`, `περιοχή_ύψος` | απομακρυσμένος_τιμή 화면의 위치와 직사각형 Μέγεθος |
| `p`, `n`, `i`, `j` | `δεδομένα_θέση`, `τιμή`, `순번`, `안쪽순번` | απομακρυσμένος_τιμή 화면 δεδομένα·ψηφίο_τιμή·επανάληψη_τιμή δείκτης_θέσης; 파일별 기능을 확인해 적용 |

| `앞캐리지` | `앞줄복귀` | 앞서 받은 문자가 줄복귀였는지 기억하여 중복 줄바꿈을 막음 |

`Ταχυδρομικός_κώδικας_πρόγραμμα_μεταγλώττισης/πρόγραμμα_μεταγλώττισης_εργαλείο.c`는 TinyCC εξωτερικός_τιμή 원문을 포함하는 Σύνδεση 파일로 ίδιο 선언이 없어서
C ίδιο δήλωση 분석에서는 제외한다. πραγματικός_δεδομένα πυρήνας_τιμή 빌드에서는 계속 컴파일한다.

### 말의 뿌리와 새로운 복합 Όνομα

`Μνήμη_τιμή(記憶)`과 `Αναζήτηση_Ευρετήριο(索引)`은 기존 한자어를 쓴다.
기억은 자료를 간직하는 기능에, 색인은 σειρά_τιμή 있는 항목을 찾아 지정하는 기능에 적용한다.
λεξικό 근거는 국립국어원 한국어기초사전의
[Μνήμη_τιμή](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=38812&nation=eng),
[Αναζήτηση_Ευρετήριο](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=63787)이다.

`δέσμη_Χώρος_αποθήκευσης`, `ωθώ_τιμή`, `Ποπ_τιμή`는 자료를 포개고 마지막 자료부터 꺼내는 εκτελώ_εντολή 구조를 드러낸다.
`쌓다`의 기존 뜻에 근거한 기능별 조어이며, 사전의
[쌓다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62095)를 참고한다.
`미리번역`은 εκτελώ_εντολή 전에 번역한다는 기능을 직접 나타낸다.
`υπολογιστής_λέξη`은 처리기의 δεδομένα 단위를 가리키며, 언어의 일반 낱말과 구별하도록 `υπολογιστής_5eb260fa`를 붙였다.
`기계어미리번역`, `동적기억낱말수` 같은 복합 이름은 τρέχων_στοιχείο 기능에 맞게 만든 프로젝트 용어다.
이 복합어가 옛 문헌에 그대로 있었다거나 특정 시대에 처음 나타났다는 뜻은 아니다.
확인되지 않은 중세 형태나 최초 χρήση_τιμή 연대는 어원 근거로 적지 않는다.

생성되는 C의 내부 τύπος_δεδομένων·πίνακας_τιμή·συνάρτηση_τιμή·τοπικός_Πεδίο μεταβλητή_τιμή·κλάδος 이름도 한국어로 바꾼다.
직접 한글 식별자를 읽지 못하는 예전 GCC를 위해 호환 API는 같은 ελληνικά 이름을
표준 C 범용 문자 표기로 출력한다. πραγματικός_δεδομένα ARM64 빌드는 Clang으로 읽을 수 있는 한글 원문을 사용한다.
συμβολοσειρά_τιμή, C 표준 συνάρτηση_τιμή, `java_entry` 같은 공개 Σύνδεση 이름은 바꾸지 않는다.

셸의 사용법·문법 ΣΦΑΛΜΑ·Αρχείο 및 Μνήμη_τιμή διεύθυνση_περιοχή 안내도 한국어로 보완했다.
`READY`, `PASS`, `HEX BEGIN`처럼 시험·Αρχείο Μεταφορά_τιμή 도구가 읽는 δείκτης_τιμή_7e8f90bd,
명령행 옵션과 기존 명령어, JVM Τάξη_τιμή Όνομα·Αρχείο μορφή_τιμή·συσκευή_τιμή 이름은 호환 표기로 남는다.
x86 VGA 문자 화면은 한글을 표시하지 못하므로 ελληνικά 문구는 UTF-8 직렬 단말에서 확인한다.
