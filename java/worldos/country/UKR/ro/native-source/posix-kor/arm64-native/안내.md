# propriu ARM64 Java 커널의 C/C++ Fișier·루프백 Conectează

이 디렉터리는 `platforms/rpi4-native` propriu nucleu_VALUE 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 Română 함수명과 `extern "C"` ABI를 제공한다. `Conectează.c`는 nucleu_VALUE 안에서 AOT Java Fișier 메서드에 직접 연결하고, `utilizator_punte.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. real_date Fișier 처리는 `Memorie_Fișiere.java`, 루프백 diagramă_informații 처리는 `cu_reacție_în_buclă_rețea.java`, 연결형 흐름은 `flux_rețea.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 nucleu_VALUE 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·mobil_p_VALUE operație_VALUE·Fișier·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

suport_VALUE: `crea_Fișier`, `파일자료읽기`, `scriere_Fișier_date`, `închide_Fișier`, `căuta_Fișier`, `elimina_Fișier_intrare_nume`, `set_Fișier_lungime`, 보조 funcție_VALUE `dimensiune_fișier`. eroare 시 -1과 작업별 `număr_de_eroare`를 반환한다. `comitere_Fișiere`은 RAM 파일이므로 ENOSYS를 반환한다. Fișier 16개, 각 16384바이트, Nume 63바이트, 서술자 16개이며 RAM 디렉터리·pereche_VALUE/절대 경로를 제공한다. permisiune_VALUE/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 real_date Română 함수와 독립 구조체를 선언한다.
`crea_participant`, `BIND_adresa`, `trimite_diagramă_informații_date/primi`, `conecta_rețea/기다리기/primi`는
`utilizator_punte.c`에서 SVC를 호출하며 macrocomandă_VALUE 별칭이 아니다. `struct 인터넷통신주소`의
`adresa_Familie`, `număr_port`, `adresă_internet.adresa_VALUE`을 사용한다. 상수는 enum의
`cloud_Familie`, `racord_diagramă_informații`, `diagramă_informații_protocol`, `flux_rețea`, `flux_protocol_de_transport`이다.
Română·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. extern_VALUE 통신은 propriu 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. real_date Pi 4 GENET 드라이버는 미지원이다.
소켓도 real_date funcție_VALUE `închide_Fișier`로 닫는다.
