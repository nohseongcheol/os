검증일: 2026-09-27 (Asia/Seoul)

мета: `jkoros-rpi4-aarch64-349b52891a471c8e782da597`

## реалізація 범위와 남은 затвердити

### QEMU 그래픽 Виконати_команда 보완

термінал 전용 실행에서 `인사.java`가 Swing 창을 만들 때 발생한 `HeadlessException`을 해결하기 위해 `make run`과 `make run-console`을 추가했다. 그래픽 실행은 bochs 가상 GPU, USB 키보드·태블릿, Xorg, 로컬 VNC를 사용한다. QEMU 전용 initramfs가 필요한 드라이버를 기존 루트 파일시스템에서 로딩한다. 배포 시스템 이미지와 base-id는 변경하지 않아 기존 простір_користувача дані 이미지를 계속 사용할 수 있다.

фактично_дані Xorg/VNC 화면에서 українська Java робоча_область, Swing випробування Вікно, 기존 이미지의 `인사.java` 창을 표시했다. VNC를 통한 USB 마우스 클릭과 키보드 입력이 Swing 이벤트로 전달되는 것도 확인했다. Вийти_програма 시 시스템 OverlayFS와 дані 파일시스템의 Читання 전용 전환을 확인했다. 이번 시험은 Xvfb를 사용하지 않는다.

### 한글 입력·шрифт_значення 보완

`make test-korean`으로 фактично_дані Xorg/VNC 화면의 Swing 입력창과 xterm에서 Ctrl+Space перехід_режим 및 두벌식 Ключ_значення 입력을 시험했다. 양쪽에서 `한글 입력`을 조합했고 UTF-8 파일의 내용과 일치했다. 시험은 별도 простір_користувача дані 이미지에서 실행했으며 정상 Вийти_програма 시 두 파일시스템의 Читання 전용 전환을 확인했다.

термінал шрифт_значення 진단에서 영문 DejaVu Sans Mono와 한글 Noto Sans Mono CJK KR의 фактично_дані файл 로딩을 확인했다. 한글용으로 요청한 글꼴이 영문 전용 글꼴로 대체되던 Fontconfig 규칙의 우선순위도 수정했다. 화면 캡처에서 한글·영문 показувати_значення, Java 작업마당의 확대된 글꼴과 안티앨리어싱을 확인했다.

수정은 QEMU 전용 initramfs를 통해 простір_користувача 시스템 변경분에 적용하며 배포 стандартне_значення 이미지와 base-id는 유지한다. 기존 файл 백업, 동일 수정의 спринт_значення 적용 방지, 손상된 수정 файл 및 다른 base-id відхилити_значення, простір_користувача 입력기 Налаштування 병합에 대한 хост випробування 4개도 통과했다. 원래 простір_користувача дані збірка_фото `build/manual-user.img`는 시험에 사용하지 않았다.

### 남은 кліп

- 새 компілювати_джерело мета `openjdk`는 **네이티브 програма_запускач + JVM/JRE** 방식이다. 모든 Java 바이트코드를 JVM 없이 기계어로 변환하는 범용 AOT 컴파일러는 구현하지 않았다. 기존 x86 AOT의 опора_значення 범위는 여전히 제한적이다.
- Виконати_команда 프로그램에는 main запис_бал, 호환 Клас_значення 버전과 의존 JAR/JNI가 필요하다. 개별 상용 програма_f5044b9b, 모든 Java модуль_значення, 모든 문자권을 시험한 것은 아니다.
- українська Java 라이브러리는 файл·문자·통신·스레드·Swing을 위한 보조 API이며 JDK 전체 API의 українська 번역판은 아니다.
- Pi 4 전용 펌웨어·ядро_значення·пристрій_значення 트리는 이미지에 들어 있지만 фактично_дані SD запуск_машини, HDMI/KMS, USB, Wi-Fi, 물리 키보드의 한글 입력은 실기 확인이 남아 있다. QEMU는 Pi 장치를 에뮬레이션하는 시험이 아니다.
- простір_користувача Каталог_значення 이동은 동일 시스템 збірка_фото ідентифікатор_значення, ARM64, `/home/user`, UID 1000을 전제로 한다. Вийти_програма 후 소유권·дозвіл_значення·링크·розширення_значення атрибут_значення·삭제 정보를 보존하여 복사해야 한다. 다른 OS 버전으로의 자동 이관은 제공하지 않는다.

інсталювати_значення·екземпляр_значення 절차는 [README.md](README.md), компілювати_джерело 방식은 [OpenJDK Виконати_команда файл файл_Readme_eb81d7d9](../../compiler/OpenJDK-실행파일.md)를 따른다. збірка_фото 파일만 생성했으며 фактично_дані SD 카드나 USB 디스크에 기록하지 않았다.
