# Raspberry Pi 4 своє Java ядро_значення — простір_користувача Виконати_команда 기반

чинний_елемент своє 코드의 COSL 상업 умова, 제3자 고지 및 LGPL 재연결 자료는 [COSL 배포 файл_Readme_eb81d7d9](COSL배포안내.md)를 참고한다. перехід_режим 전 GPL 구성의 판단은 [이전 라이선스 검토](ліцензія_відгук.md)에 기록했다.

українська 통신·виняток 사용법은 [українська Java API](한국어자바/файл_Readme_eb81d7d9.md), функція_значення·змінна_значення·файл 이름의 변경과 어원 근거는 [명명 файл_Readme_eb81d7d9](명명/файл_Readme_eb81d7d9.md)를 참고한다.

Linux 없이 부팅하는 своє AArch64 커널이다. Java AOT ядро_значення 위에 **командний_рядок оболонка, 게스트 Java компілятор·JVM, MicroPython, EL0 C++ Виконати_команда, файл·UDP 루프백 시스템 호출, 여러 한글 GUI термінал·vi Редактор·Swing 부분집합**을 제공한다. 커널의 файл дані/정책·루프백 передача_значення·оболонка 상태는 Java, 화면 합성·елемент_зображення змінювати_значення·курсор·클리핑도 Java로 구현하며, CPU/MMU/пристрій_значення 경계와 термінал·символ_значення_068c2631 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 своє 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 Виконати_команда, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 проводовий_значення 송수신은 아직 미검증이다.** Виконати_команда·зв_язок_e05f319b·пароль_значення 확인은 [зовнішній_значення зв_язок_e05f319b файл_Readme_eb81d7d9](зовнішній_зв_язок_напрямна.md)에 정리했다.

셸은 EL1 ядро_значення, `java` 등 простір_користувача Виконати_команда 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 Виконати_команда·зв_язок_e05f319b 방법 및 фактично_дані 검증은
[Виконати_команда 계층과 зовнішній_значення 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 фактично_дані Виконати_команда 형식으로 검사한다. `./인사`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 정적 ELF는 `run --linux ім_я_файлу_Текст`으로 실행한다. [ELF·Linux ABI опора_значення 범위와 동일 바이너리 випробування](실행파일규약.md).

GUI와 네트워크는 `python3 інструменти/Виконати_команда.py --desktop --network`로 함께 사용한다. Java·C·Python의 українська 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 запуск_машини 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 수 있다. Remmina에서 **F9/Shift+Space/한·нуль_операнд Ключ_значення**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·фактично_дані TCP/UDP·файл байт_значення·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java ПрикладВікна`로 українська Swing 예제를 실행한다. термінал 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 чинний_елемент стовпець_значення·запис_значення 수를 보여 준다.

Виконати_команда 버튼 화면은 5×7 영문 글꼴을 쓰며, термінал 창은 Noto CJK/DejaVu에서 생성한 한글·Unicode 비트맵 글꼴을 쓴다. UART와 фактично_дані 프레임버퍼의 한글 표시를 시험한다. 루프백은 동일 ядро_значення 내부의 дейтаграма 전달이며 IP 패킷을 Ethernet으로 내보내는 드라이버가 아니다. 바깥 IPv4는 lwIP TCP/UDP 스택으로 보조 UART SLIP 경로를 사용한다. `python3 інструменти/Виконати_команда.py --network`로 QEMU NAT를 연결하고 `ftpd start`로 서비스를 시작한다.

Java의 정확한 API·문법·Виконати_команда 제한과 українська 사용법은 [своє JVM과 українська бібліотека](자바실행환경.md)에 정리했다. Клас_значення файл/JAR 배포는 [한국어자바](한국어자바) 소스에서 재현한다. 기존 Linux판 `українська.자바`와 별도인 `українська.своє` 패키지다.

**vi·여러 Вікно·Swing·한글 Java/Python/C/C++·posix-kor 예제는 [한글 개발 매뉴얼](개발안내.md)에 정리했다.**

GUI термінал Виконати_команда·단축키·оболонка команда·제한은 [셸과 термінал 사용법](оболонка_і_Термінал.md)에 정리했다.

## чинний_елемент 컴퓨터에서 Виконати_команда

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

Вийти_програма: **Ctrl+A Далі_елемент X**. 게스트 C/AOT інструменти 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. хост 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. компілятор 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/шлях/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` опора_значення 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 Виконати_команда**한다. 기존 한 символ_значення_068c2631 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 аргументи 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

| команда | Дія |
|---|---|
| `help` / `info` | команда·фактично_дані реалізація Стан_значення |
| `ls` / `cat FILE` / `rm FILE` | RAM файл запис_список·Вміст_значення·삭제 |
| `vi FILE` | простір_користувача область_значення_0e9a97ab vi 부분집합, 한글 правка_значення·сховище_значення·검색·되돌리기 |
| `edit FILE` | файл 전체를 새로 입력; 단독 `.` 줄로 сховище_значення, Ctrl-C로 Скасувати_операція |
| `javac FILE.java` / `java CLASS [ARGS]` | своє 제한형 Java компілювати_джерело·Виконати_команда |
| `python FILE.py [ARGS]` / `python -c 'CODE'` | MicroPython компілювати_джерело·Виконати_команда |

예를 들어 `edit 인사.java`를 입력한 Далі_елемент 아래 소스를 입력한다.

```java
public class 인사 { public static void main(String[] args) { int значення = 7; System.out.println("한글=" + значення); } }
```

그다음 단독 `.` 줄로 저장하고 `javac 인사.java`, `java 인사`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. Скасувати_операція·잘못된 16진수·ресурс_значення_e6ac1362 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, Виконати_команда 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 команда 인수는 최대 32개다. Цитування·백슬래시·оболонка змінна_значення·파이프·리다이렉션 범위는 [оболонка 설명](оболонка_і_Термінал.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, Адреса **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode 입력·명시적 вставляти_значення·Виконати_команда 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 інструменти/Виконати_команда.py --desktop --network
# 다른 обладнання_порт: python3 інструменти/Виконати_команда.py --desktop --port 5903
```

종료는 실행한 хост 터미널에서 Ctrl+C다. 기존 `python3 інструменти/Виконати_команда.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. фактично_дані Pi4 USB 입력기는 아직 없으며, VNC З_єднання 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 фактично_дані C++/UDP ELF Виконати_команда, `Hello.java` компілювати_джерело 후 JVM Виконати_команда, `hello.py` Виконати_команда, GUI термінал 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 대화형 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 Пам_ять_дані·CPU 문맥을 보관한다. оболонка·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

| `dist/jkoros-native-rpi4-boot.zip` | FAT32 запуск_машини 파티션에 복사할 файл Група_значення |
| `dist/jkoros-native-aarch64-sdk.tar.gz` | 사용자용 헤더·запустити код_значення·бібліотека·링커 сценарій_значення·예제 |
| `dist/manifest.json`, `build/build.json` | SHA256과 фактично_дані опора_значення Стан_значення |

이미지는 확인된 공식 Pi запуск_машини 묶음에서 `start4.elf`, `fixup4.dat`, Pi4 DTB와 disable-bt overlay를 가져온다. Linux kernel/initramfs/rootfs는 넣지 않는다. 펌웨어·MicroPython·термінал шрифт_значення 라이선스와 шрифт_значення 출처 해시도 동봉한다. файл генерувати 스크립트는 물리 디스크에 기록하지 않는다.

예비 microSD에 збірка_фото журнал_запис 도구로 `.img`를 기록하거나 FAT32 запуск_машини 파티션 최상위에 ZIP 내용을 푼다. збірка_фото 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 стандартне_значення EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD файл 구성·ядро_значення 체크섬 검사와 물리 Дошка запуск_машини 검증은 별개다. MMU використання_значення 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 запуск_машини 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 українська API використання_значення

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/ПрикладФайлу.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int ПУСК_користувач_програма(int)`이다. простір_користувача C++는 FP/SIMD를 사용할 수 있다. ядро_значення C/Java AOT는 일반 레지스터만 사용하므로 виняток процес_значення_запис 중 простір_користувача FP 상태를 건드리지 않는다. простір_користувача запис_бал_значення 시 FP 상태를 초기화하고 ядро_значення 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int ПУСК_користувач_програма(int) {
    int файл = відкрито_Файл("인사.txt", 읽고쓰기 | 없으면만들기 | скорочувати_Зміст, 0600);
    if (файл < 0) return 1;
    const char Вміст_значення[] = "안녕하세요";
    int результат = записування_Файл_дані(файл, Вміст_значення, sizeof(Вміст_значення) - 1);
    Закрити_Файл(файл);
    return результат == sizeof(Вміст_значення) - 1 ? 0 : 2;
}
```

[файл 예제](простір_користувача/ПрикладФайлу.cpp)와 [통신 예제](простір_користувача/통신예제.cpp)가 фактично_дані запуск_машини випробування 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 файл процес_значення_запис 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 сокет_значення 함수는 чинний_елемент 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 ядро_значення 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 Далі_елемент 도구를 사용하면 **새 QEMU를 부팅해 업로드한 фактично_дані 바이트를 재확인한 НАЗАД_значення 게스트에서 Виконати_команда**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 інструменти/Виконати_Файл.py build/jkoros-native-sdk/demo.elf
python3 інструменти/Виконати_Файл.py 예제/Hello.java "한글 аргументи"
python3 інструменти/Виконати_Файл.py 예제/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 ядро_значення 묶음에 포함되어 이 файл 한도를 적용받지 않는다. **C++ 컴파일러는 хост SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 бібліотека, PT_TLS, PT_INTERP, PT_DYNAMIC, Виконати_команда·Запис 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 індекс·Адреса кліп·오류는 [простір_користувача ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `затвердження_файлове_сховище`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 дозвіл_значення·dup/fcntl은 없다. 디렉터리와 точка_значення/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, отримувати_значення_cef4d8ab 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. простір_користувача Вийти_програма 시 열린 файл 서술자와 소켓을 회수한다.

## Java와 Python의 정확한 кліп

своє `javac`는 버전 49 `.class`를 생성하며 JVM은 опора_значення 명령으로 구성된 버전 45–52 클래스를 실행한다. 정적 функція_значення·재귀·int/boolean/char/String·умова/спринт_значення·рядок_значення 결합과 일부 файл 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/조합 자모 식별자를 처리한다. Unicode ідентифікатор_значення 전체 таблиця_підстановки·Unicode джерело_дерево 이스케이프는 구현하지 않았다. 게스트 джерело_дерево 컴파일러는 일반 об_єкт_значення·виняток·Thread 구문을 아직 컴파일하지 못한다. хост `javac --release 8`로 만든 опора_значення 부분집합 클래스는 своє JVM 0.4의 об_єкт_значення·виняток·Thread·UDP와 українська API를 사용할 수 있다. Swing은 문서화한 своє API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [своє JVM 설명](자바실행환경.md)이 기준이다. 상세 Мови 범위는 [공유 Java інструменти 설명](../../문서/자바개발환경.md)을 참고하되, 그 문서의 x86 оболонка/сховище_значення/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 джерело_дерево**를 своє AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 функція_значення·Клас_значення·виняток·리스트/словник·Unicode·GC·가변 точність_значення 정수를 제공한다. чинний_елемент 구성은 ціле_число 빌드로 `float`, `complex`, `math`가 없으며 CPython 전체 표준 бібліотека, pip, subprocess, threading, 일반 socket과 стандартне_значення `open()` файл 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 об_єкт_значення·모듈은 Вийти_програма 시 회수되고 RAM 파일만 Далі_елемент 실행에 남는다.

`import jkoros`로 Далі_елемент 시스템 연결을 쓴다. 모두 SVC를 통해 своє Java 커널에 접근한다.

| функція_значення | Дія |
|---|---|
| `stdin(limit)` | чинний_елемент 표준 입력에서 최대 limit바이트(0…16384)를 bytes로 읽음; EOF는 빈 bytes, UART дані 없음은 OSError(11) |
| `read(name)` | точка_значення/절대 RAM 경로의 файл 전체를 bytes로 읽음 |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 сховище_значення, 쓴 байт_значення 수 повернути_КР |
| `remove(name)` | RAM файл 삭제 |
| `rect(x, y, w, h, color)` | 선택한 фактично_дані 화면 Розмір 안의 прямокутник малювання_значення; 기존 보드의 RGB32 значення |
| `ticks_ms()` | запуск_машини 후 밀리초, 32비트 цикл_значення |
| `udp_open(port)` | 127.0.0.1의 UDP сокет_значення Відкрити/зв_язувати_учасник; 0은 자동 обладнання_порт |
| `udp_send(fd, port, data)` | 루프백 місце_значення 포트에 str/bytes 버퍼 передача_значення |
| `udp_recv(fd)` | `(bytes, 보낸포트)` повернути_КР; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | сокет_значення Закрити |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```

이식 код_значення: [python/](파이썬연결/), [простір_користувача Java З_єднання](простір_користувача/자바연결.c). 공식 [MicroPython 이식 файл_Readme_eb81d7d9](https://docs.micropython.org/en/latest/develop/porting.html)를 참고했다. джерело_дерево URL·геш_код_Файл·라이선스는 [vendor файл_Readme_eb81d7d9](vendor/README.md)에 기록했다.

## українська C тип_даних·Python ПОМИЛКА·набір інсталювати_значення

C 네트워크 API는 `struct хмара_сокет_адреса`, enum 상수와 фактично_дані українська 함수로
구현한다. макрос_значення 별칭을 사용하지 않으며 이전 pk_* ABI도 유지한다.
Python 예제는 `Система_помилка`, `ПОМИЛКА.індекс`, `ПОМИЛКА.설명`을 사용한다.

`python3 інструменти/Виконати_команда.py --desktop --network --pip`로 시작하면 게스트에서
`pip install micropython-bisect==3.3.3`을 사용할 수 있다. 현재는 хост 중계를
이용하는 제한형 MicroPython джерело_дерево 설치기이며 CPython pip·자동 의존성 해결·C 확장은
미지원이다. 설치한 `/lib` 자료는 RAM이다. [사용법과 제한](파이썬꾸러미.md).

## 화면 Розмір вибране_значення

`python3 інструменти/Виконати_команда.py --desktop --network --resolution 1920x1080`으로 Full HD 화면을 사용한다. 기본값은 640×480이며 1280×720도 가능하다. термінал переміщати_значення, Swing 가운데 схема_компонування, Java·C·Python 그리기도 фактично_дані 크기를 따른다. SD 영상은 `make image RESOLUTION=1920x1080`으로 만든다. [Налаштування·українська API·затвердити файл_Readme_eb81d7d9](роздільна_здатність_екрана.md).
