# 자체 ARM64 Java 커널의 C/C++ ᎠᏍᏆᏂᎪᏙᏗ·루프백 ᎫᏓᎳ

이 디렉터리는 `platforms/rpi4-native` 자체 kernel_ᏧᎬᏩᎶᏗᏯ 전용이다. 기존 i386 `int 0x80` 라이브러리나 ARM64 Linux libc용 라이브러리가 아니다.

`포함/파일규약.h`는 한국어 함수명과 `extern "C"` ABI를 제공한다. `ᎫᏓᎳ.c`는 kernel_ᏧᎬᏩᎶᏗᏯ 안에서 AOT Java ᎠᏍᏆᏂᎪᏙᏗ 메서드에 직접 연결하고, `사용자연결.c`는 독립 EL0 프로그램에서 SVC로 커널을 호출한다. ᎤᏙᎯᏳ_ᎾᏍᎩ_ᎨᏒ_ᎦᏟᏌᏅᎯ ᎠᏍᏆᏂᎪᏙᏗ 처리는 `기억파일.java`, 루프백 전문 처리는 `되돌림망.java`, 연결형 흐름은 `ᎤᏪᎬ_ᏧᎾᏚᏓᎵ.java`에 있다.

```sh
make -C /home/user/jkoros/platforms/rpi4-native build
make -C /home/user/jkoros/platforms/rpi4-native test
```

산출물은 kernel_ᏧᎬᏩᎶᏗᏯ 내부용 `platforms/rpi4-native/build/libposix-kor-arm64.a`와 사용자용 `libposix-kor-user.a`다. 사용자용 라이브러리로 독립 ELF64 C/C++ 프로그램의 생성자·RAII·실수 ᎠᎢᏒᎢ_ᏧᎬᏩᎶᏗᏯ·ᎠᏍᏆᏂᎪᏙᏗ·UDP 루프백 호출을 검증했다. 일반 Linux 바이너리, 전체 POSIX/libc/libstdc++ 지원을 뜻하지 않는다. 서로 다른 두 라이브러리를 혼합하지 않는다.

ᎦᎫᏍᏛᏗ_ᏧᎬᏩᎶᏗᏯ: `ᎯᏍᏚᎢ_ᎠᏍᏆᏂᎪᏙᏗ`, `파일자료읽기`, `ᎪᏪᎶᏗ_ᎠᏍᏆᏂᎪᏙᏗ_ᎦᏟᏌᏅᎯ`, `ᎯᏍᏚᎲᎦ_ᎠᏍᏆᏂᎪᏙᏗ`, `파일위치옮기기`, `ᎯᎲᎾ_ᎠᏍᏆᏂᎪᏙᏗ_Ꭵ_ᎧᏁᏉᎢᏍᏙᏗ_ᏚᏙᎥᎢ`, `ᎦᎪᏗ_ᎠᏍᏆᏂᎪᏙᏗ_ᏱᎦᏅᎯᏓ`, 보조 ᏧᎸᏫᏍᏓᏁᏗᏱ_ᏧᎬᏩᎶᏗᏯ `ᎠᏍᏆᏂᎪᏙᏗ_ᎢᎩᏓ`. ᎦᎵᏓᏍᏔᏅ 시 -1과 작업별 `오류번호`를 반환한다. `파일저장확정`은 RAM 파일이므로 ENOSYS를 반환한다. ᎠᏍᏆᏂᎪᏙᏗ 16개, 각 16384바이트, ᏚᏙᎥᎢ 63바이트, 서술자 16개이며 RAM 디렉터리·ᏱᎦᏲᎩᎾᏛᏂ_ᏧᎬᏩᎶᏗᏯ/절대 경로를 제공한다. 권한/영속 저장은 없다.

사용자용 `포함/통신규약.h`는 ᎤᏙᎯᏳ_ᎾᏍᎩ_ᎨᏒ_ᎦᏟᏌᏅᎯ 한국어 함수와 독립 구조체를 선언한다.
`통신종단점만들기`, `BIND_ᎪᏪᎵ_ᏫᏗᎦᏅᏗ`, `자료전문보내기/받기`, `ᎫᏓᎳ_ᏧᎾᏚᏓᎵ/기다리기/받기`는
`사용자연결.c`에서 SVC를 호출하며 ᏍᏆᎳ_ᏱᏗᎬᏁᎸ_ᏧᎬᏩᎶᏗᏯ 별칭이 아니다. `struct 인터넷통신주소`의
`주소갈래`, `접속번호`, `ᎠᏏᎳᏕᏫᏒᎢ_ᎪᏪᎵ_ᏫᏗᎦᏅᏗ.ᎪᏪᎵ_ᏫᏗᎦᏅᏗ_ᏧᎬᏩᎶᏗᏯ`을 사용한다. 상수는 enum의
`인터넷주소갈래`, `전문통신`, `전문전송규약`, `ᎤᏪᎬ_ᏧᎾᏚᏓᎵ`, `흐름전송규약`이다.
한국어·표준 구조체는 16바이트 ABI 배치를 공유하지만 서로 다른 C 자료형이다.
기존 pk_* 함수와 표준 구조체는 호환용으로 유지한다. 외부 통신은 자체 커널의
lwIP TCP/UDP와 QEMU UART SLIP 연결을 사용한다. ᎤᏙᎯᏳ_ᎾᏍᎩ_ᎨᏒ_ᎦᏟᏌᏅᎯ Pi 4 GENET 드라이버는 미지원이다.
소켓도 ᎤᏙᎯᏳ_ᎾᏍᎩ_ᎨᏒ_ᎦᏟᏌᏅᎯ ᏧᎸᏫᏍᏓᏁᏗᏱ_ᏧᎬᏩᎶᏗᏯ `ᎯᏍᏚᎲᎦ_ᎠᏍᏆᏂᎪᏙᏗ`로 닫는다.
