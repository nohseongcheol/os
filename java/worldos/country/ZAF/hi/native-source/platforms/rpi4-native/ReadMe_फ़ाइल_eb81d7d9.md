# Raspberry Pi 4 निज Java कर्नेल_मान — उपयोगकर्ता निष्पादित_करें_आदेश 기반

अद्यतित_आइटम निज 코드의 COSL 상업 शर्त, 제3자 고지 및 LGPL 재연결 자료는 [COSL 배포 ReadMe_फ़ाइल_eb81d7d9](COSL배포안내.md)를 참고한다. स्विच_मोड 전 GPL 구성의 판단은 [이전 라이선스 검토](लाइसेंस_समीक्षा.md)에 기록했다.

हिंदी 통신·अपवाद 사용법은 [हिंदी Java API](한국어자바/ReadMe_फ़ाइल_eb81d7d9.md), फ़ंक्_शन_मान·चर_मान·संचिका 이름의 변경과 어원 근거는 [명명 ReadMe_फ़ाइल_eb81d7d9](명명/ReadMe_फ़ाइल_eb81d7d9.md)를 참고한다.

Linux 없이 부팅하는 निज AArch64 커널이다. Java AOT कर्नेल_मान 위에 **आदेश_पंक्ति शेल, 게스트 Java कंपाइलर·JVM, MicroPython, EL0 C++ निष्पादित_करें_आदेश, संचिका·UDP 루프백 시스템 호출, 여러 한글 GUI आदेशपटल·vi संपादक·Swing 부분집합**을 제공한다. 커널의 संचिका आँकड़े/정책·루프백 हस्तांतरण_मान·शेल 상태는 Java, 화면 합성·पिक्सेल परिवर्तित_करें_मान·सूचक·클리핑도 Java로 구현하며, CPU/MMU/उपकरण_मान 경계와 आदेशपटल·कैरेक्टर_मान 그리기 연결은 C와 어셈블리다.

**전체 JDK/JRE·CPython·표준 C++ 런타임·Swing 이식은 아직 완료되지 않았다.** 기존 [ARM64 Linux 실행판](../rpi4/README.md)의 OpenJDK/Python 패키지를 이 निज 커널에 탑재했다고 표시하지 않는다.

새로운 게스트 `cc`/`jaot`, JAR 직접 निष्पादित_करें_आदेश, lwIP TCP/UDP와 FTP는 [FTP·C·JAR·AOT 매뉴얼](파일전송과번역.md)을 참고한다. 게스트 SSH·VNC와 Pi4 GENET/PHY·DHCP 드라이버를 추가했다. **SSH·VNC는 QEMU에서 검증하며, 실물 Pi4의 वायर्ड_मान 송수신은 아직 미검증이다.** निष्पादित_करें_आदेश·कनेक्शन_e05f319b·पासवर्ड_मान 확인은 [बाहरी_मान कनेक्शन_e05f319b ReadMe_फ़ाइल_eb81d7d9](बाहरी_कनेक्शन_मार्गदर्शिका.md)에 정리했다.

셸은 EL1 कर्नेल_मान, `java` 등 उपयोगकर्ता निष्पादित_करें_आदेश 파일은 EL0에서 실행한다.
`ps`·`top`의 표시와 제한, QEMU 네트워크 निष्पादित_करें_आदेश·कनेक्शन_e05f319b 방법 및 वास्तविक_डेटा 검증은
[निष्पादित_करें_आदेश 계층과 बाहरी_मान 통신 점검](실행계층과외부통신점검.md)을 참고한다.

ELF는 확장자가 아닌 वास्तविक_डेटा निष्पादित_करें_आदेश 형식으로 검사한다. `./अभिनन्दन_ae353e94`처럼 확장자 없이 실행하며, 제한된 Linux ARM64 정적 ELF는 `run --linux फ़ाइल_नाम_पाठ`으로 실행한다. [ELF·Linux ABI समर्थन_मान 범위와 동일 바이너리 시험](실행파일규약.md).

GUI와 네트워크는 `python3 उपकरण/निष्पादित_करें_आदेश.py --desktop --network`로 함께 사용한다. Java·C·Python의 हिंदी 예제 13개는 [jkoros/example](../../example/README.md)에 있으며, **게스트 부팅 시 `/example/java`, `/example/c`, `/example/python`에 자동으로 준비된다.** `example java|c|python`으로 지운 예제를 복원할 수 있다. Remmina에서 **F9/Shift+Space/한·शून्य_ऑपरेंड कुंजी_मान**로 `[EN]`↔`[KO]` 두벌식을 전환한다(`help ko`). `make test-examples`는 같은 GUI VM에서 FTP·वास्तविक_डेटा TCP/UDP·संचिका बाइट_मान·그래픽 픽셀을 검증한다.

게스트에서 `cd /example/java` 후 `java खिड़कीउदाहरण`로 हिंदी Swing 예제를 실행한다. आदेशपटल 모서리에 마우스를 대고 **왼쪽 버튼으로 끌면 크기가 바뀐다**. `terminal size`는 अद्यतित_आइटम कालम_मान·पंक्ति_मान 수를 보여 준다.

निष्पादित_करें_आदेश 버튼 화면은 5×7 영문 글꼴을 쓰며, आदेशपटल 창은 Noto CJK/DejaVu에서 생성한 한글·Unicode 비트맵 글꼴을 쓴다. UART와 वास्तविक_डेटा 프레임버퍼의 한글 표시를 시험한다. 루프백은 동일 कर्नेल_मान 내부의 स्वतंत्रसंदेश 전달이며 IP 패킷을 Ethernet으로 내보내는 드라이버가 아니다. 바깥 IPv4는 lwIP TCP/UDP 스택으로 보조 UART SLIP 경로를 사용한다. `python3 उपकरण/निष्पादित_करें_आदेश.py --network`로 QEMU NAT를 연결하고 `ftpd start`로 서비스를 시작한다.

Java의 정확한 API·문법·निष्पादित_करें_आदेश 제한과 हिंदी 사용법은 [निज JVM과 हिंदी लाइब्रेरी](자바실행환경.md)에 정리했다. कक्षा_मान संचिका/JAR 배포는 [한국어자바](한국어자바) 소스에서 재현한다. 기존 Linux판 `हिंदी.자바`와 별도인 `हिंदी.निज` 패키지다.

**vi·여러 खिड़की·Swing·한글 Java/Python/C/C++·posix-kor 예제는 [한글 개발 매뉴얼](개발안내.md)에 정리했다.**

GUI आदेशपटल निष्पादित_करें_आदेश·단축키·शेल आदेश·제한은 [셸과 आदेशपटल 사용법](셸과터미널.md)에 정리했다.

## अद्यतित_आइटम 컴퓨터에서 निष्पादित_करें_आदेश

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test
make run
```

निर्गमन_ऐप: **Ctrl+A अगला_आइटम X**. 게스트 C/AOT उपकरण 빌드에는 `make rpi-prepare`로 준비한 ARM64 SDK 헤더와 libgcc 산술 보조 함수도 필요하다. libc나 Linux 커널을 게스트에 넣는 것은 아니다. आयोजक 도구는 JDK 11 이상, Python 3.6 이상, Clang/Clang++, AArch64 GNU binutils, Make, `libnewlib-dev` 헤더다. MicroPython은 `/usr/include/newlib` 헤더를 사용하며 다른 위치는 `NEWLIB_INCLUDE`로 지정한다. newlib 런타임을 이식·링크한 것은 아니다. कंपाइलर 의미 비교에는 GCC/UBSan도 사용한다. 기존 `../rpi4/build/host`의 QEMU 11.0.3이 있으면 이용하며, 그렇지 않으면 PATH의 QEMU를 사용한다. `QEMU_AARCH64=/절대/पथ/qemu-system-aarch64`로 지정할 수도 있다. `raspi4b` समर्थन_मान 여부를 확인한 후 실행한다.

명령은 **Enter를 눌러 निष्पादित_करें_आदेश**한다. 기존 한 कैरेक्टर_मान 명령도 Enter가 필요하다.

```text
javac Hello.java
java Hello "한글 तर्क 😀"
python hello.py
python -c 'print(2**100)'
ls
cat python.txt
run cpp
net test
gui
```

| आदेश | क्रिया |
|---|---|
| `help` / `info` | आदेश·वास्तविक_डेटा 구현 अवस्था_मान |
| `ls` / `cat FILE` / `rm FILE` | RAM संचिका एन्ट्री_सूची·सामग्री_मान·삭제 |
| `vi FILE` | उपयोगकर्ता क्षेत्र_मान vi 부분집합, 한글 संपादन_मान·स्टोर_मान·검색·되돌리기 |
| `edit FILE` | संचिका 전체를 새로 입력; 단독 `.` 줄로 स्टोर_मान, Ctrl-C로 रद्द_करें_ऑपरेशन |
| `javac FILE.java` / `java CLASS [ARGS]` | निज 제한형 Java कंपाइल_स्रोत·निष्पादित_करें_आदेश |
| `python FILE.py [ARGS]` / `python -c 'CODE'` | MicroPython कंपाइल_स्रोत·निष्पादित_करें_आदेश |

| `samples` | 삭제한 डिफ़ॉल्ट_मान 예제 पुनर्प्राप्त_करें_अवस्था; 기존 파일은 보존 |

예를 들어 `edit अभिनन्दन_ae353e94.java`를 입력한 अगला_आइटम 아래 소스를 입력한다.

```java
public class अभिनन्दन_ae353e94 { public static void main(String[] args) { int मान = 7; System.out.println("한글=" + मान); } }
```

그다음 단독 `.` 줄로 저장하고 `javac अभिनन्दन_ae353e94.java`, `java अभिनन्दन_ae353e94`를 실행한다. 편집기는 기존 파일에 커서를 이동하는 방식이 아니라 전체 교체 방식이다. रद्द_करें_ऑपरेशन·잘못된 16진수·क्षमता_मान 초과는 원본을 보존한다. 줄은 4096바이트, 파일은 16384바이트, निष्पादित_करें_आदेश 인수는 최대 8개·각각 UTF-8 255바이트다. 일반 आदेश 인수는 최대 32개다. कोट·백슬래시·शेल चर_मान·파이프·리다이렉션 범위는 [शेल 설명](셸과터미널.md)을 참고한다.

GUI 터미널은 다음과 같이 실행하고 Remmina에서 **VNC**, पता **127.0.0.1:5902**로 연결한다. 키보드·한글 Unicode 입력·명시적 चिपकाएँ_मान·निष्पादित_करें_आदेश 버튼의 마우스 클릭을 QEMU 도구가 UART에 전달한다.

```sh
make desktop
# GUI + 네트워크: python3 उपकरण/निष्पादित_करें_आदेश.py --desktop --network
# 다른 포트: python3 उपकरण/निष्पादित_करें_आदेश.py --desktop --port 5903
```

종료는 실행한 आयोजक 터미널에서 Ctrl+C다. 기존 `python3 उपकरण/निष्पादित_करें_आदेश.py --vnc 127.0.0.1:2`는 화면 보기와 별도 UART 입력을 유지한다. `make run`은 일반 UART 셸이다. वास्तविक_डेटा Pi4 USB 입력기는 아직 없으며, VNC जोड़ना 도구는 QEMU 시험용이다.

GUI의 다섯 버튼은 वास्तविक_डेटा C++/UDP ELF निष्पादित_करें_आदेश, `Hello.java` कंपाइल_स्रोत 후 JVM निष्पादित_करें_आदेश, `hello.py` निष्पादित_करें_आदेश, GUI आदेशपटल 열기를 수행한다. 한 번에 한 프로그램이 CPU에서 실행되며 일반 실행에는 약 2초 기한이 있다. vi·Swing은 대화형 대기에서 기한을 갱신하고 다른 터미널로 전환할 때 मेमोरी_डेटा·CPU 문맥을 보관한다. शेल·편집기에서 입력을 기다리는 시간에는 이 제한이 적용되지 않는다.

예비 microSD에 बिल्ड_छवि लॉग_रिकॉर्ड 도구로 `.img`를 기록하거나 FAT32 부팅 파티션 최상위에 ZIP 내용을 푼다. बिल्ड_छवि 기록은 선택한 카드의 기존 내용을 지우므로 대상을 확인한다. Pi4 डिफ़ॉल्ट_मान EEPROM SD 부팅을 전제로 한다. UART는 **3.3V TTL, 115200 8N1**, GPIO14/TXD(8번)→어댑터 RX, GPIO15/RXD(10번)→TX, GND(6번) 연결이다. GPIO에 5V 신호를 연결하지 않는다.

**실물 Pi4 부팅은 미검증이다.** QEMU `-kernel`은 SD의 VideoCore 펌웨어를 실행하지 않고 커널을 직접 적재한다. SD संचिका 구성·कर्नेल_मान 체크섬 검사와 물리 बोर्ड 부팅 검증은 별개다. MMU 사용 전에는 펌웨어의 캐시/MMU가 꺼져 있고 EL1 또는 EL2로 진입하는 통상 부팅 조건을 전제로 한다. 세 보조 코어는 대기시키며 한 코어만 사용한다.

## C++와 हिंदी API 사용

SDK를 풀고 호스트에서 컴파일한다.

```sh
tar -xzf dist/jkoros-native-aarch64-sdk.tar.gz -C build
cd build/jkoros-native-sdk
python3 compile.py examples/संचिकाउदाहरण.cpp -o demo.elf
python3 compile.py examples/통신예제.cpp -o network.elf
```

진입점은 `extern "C" int प्रारंभ_उपयोगकर्ता_ऐप(int)`이다. उपयोगकर्ता C++는 FP/SIMD를 사용할 수 있다. कर्नेल_मान C/Java AOT는 일반 레지스터만 사용하므로 अपवाद प्रक्रिया_मान_एन्ट्री 중 उपयोगकर्ता FP 상태를 건드리지 않는다. उपयोगकर्ता प्रवेश_बिदुं_मान 시 FP 상태를 초기화하고 कर्नेल_मान 복귀에 필요한 상태를 보존한다.

```cpp
#include "파일규약.h"
extern "C" int प्रारंभ_उपयोगकर्ता_ऐप(int) {
    int संचिका = जारी_फ़ाइल("अभिनन्दन_ae353e94.txt", पठन_लेखन | 없으면만들기 | कम_करें_सामग्री, 0600);
    if (संचिका < 0) return 1;
    const char सामग्री_मान[] = "안녕하세요";
    int परिणाम = लिखना_फ़ाइल_डेटा(संचिका, सामग्री_मान, sizeof(सामग्री_मान) - 1);
    बंद_फ़ाइल(संचिका);
    return परिणाम == sizeof(सामग्री_मान) - 1 ? 0 : 2;
}
```

[संचिका 예제](उपयोगकर्ता/संचिकाउदाहरण.cpp)와 [통신 예제](उपयोगकर्ता/통신예제.cpp)가 वास्तविक_डेटा 부팅 시험 대상이다. `파일규약.h`의 이름은 커널용/사용자용 모두 같지만 **링크하는 라이브러리가 다르다**. 사용자용은 `svc #0`으로 호출하고 संचिका प्रक्रिया_मान_एन्ट्री 및 루프백 전달은 Java 커널에서 실행한다. `통신규약.h`의 सॉकेट_मान 함수는 अद्यतित_आइटम 사용자용 라이브러리에 구현돼 있다.

새 프로그램은 कर्नेल_मान 재빌드 없이 `load FILE.elf`와 `run FILE.elf`로 실행한다. 호스트에서 अगला_आइटम 도구를 사용하면 **새 QEMU를 부팅해 업로드한 वास्तविक_डेटा 바이트를 재확인한 वापस_मान 게스트에서 निष्पादित_करें_आदेश**하고 종료한다. 이 도구의 새 VM에서 만든 RAM 자료는 종료할 때 사라진다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 उपकरण/निष्पादित_करें_फ़ाइल.py build/jkoros-native-sdk/demo.elf
python3 उपकरण/निष्पादित_करें_फ़ाइल.py 예제/Hello.java "한글 तर्क"
python3 उपकरण/निष्पादित_करें_फ़ाइल.py 예제/hello.py
```

이 경로는 16KiB 이하의 `.elf`, `.java`, `.class`, `.py`를 지원한다. 큰 내장 Java/MicroPython ELF 자체는 कर्नेल_मान 묶음에 포함되어 이 संचिका 한도를 적용받지 않는다. **C++ 컴파일러는 आयोजक SDK의 Clang++**이며 게스트 내부 GCC/Clang 컴파일러는 아직 없다. SDK만으로 일반 Linux 프로그램을 실행할 수는 없다. Linux ELF, 동적 लाइब्रेरी, PT_TLS, PT_INTERP, PT_DYNAMIC, निष्पादित_करें_आदेश·लिखें 겸용 세그먼트는 로더가 거부한다. 구체적인 호출 इंडेक्स·पता क्लिप·오류는 [उपयोगकर्ता ABI](사용자호출규약.md)를 참고한다.

RAM 파일은 재부팅 시 사라진다. `कमिट_फ़ाइल_संग्रहण`은 -1과 ENOSYS를 반환한다. 파일의 mode 인수를 저장하지 않으며 अनुमति_मान·dup/fcntl은 없다. 디렉터리와 पीअर_मान/절대 경로는 같은 RAM 저장소에서 처리한다. UDP 전문은 최대 512바이트, 소켓은 8개, 수신 큐는 소켓당 4개다. 수신할 자료가 없거나 큐가 가득 차면 EAGAIN을 반환한다. उपयोगकर्ता निर्गमन_ऐप 시 열린 संचिका 서술자와 소켓을 회수한다.

## Java와 Python의 정확한 क्लिप

निज `javac`는 버전 49 `.class`를 생성하며 JVM은 समर्थन_मान 명령으로 구성된 버전 45–52 클래스를 실행한다. 정적 फ़ंक्_शन_मान·재귀·int/boolean/char/String·शर्त/पुनरावृति_मान·स्ट्रिंग_मान 결합과 일부 संचिका 스트림을 지원한다. UTF-8 문자열과 문자 리터럴, ASCII 및 현대 한글 음절/조합 자모 식별자를 처리한다. Unicode पहचानकर्ता_मान 전체 लुकअप_तालिका·Unicode स्रोत_ट्री 이스케이프는 구현하지 않았다. 게스트 स्रोत_ट्री 컴파일러는 일반 ऑब्जेक्ट_मान·अपवाद·Thread 구문을 아직 컴파일하지 못한다. आयोजक `javac --release 8`로 만든 समर्थन_मान 부분집합 클래스는 निज JVM 0.4의 ऑब्जेक्ट_मान·अपवाद·Thread·UDP와 हिंदी API를 사용할 수 있다. Swing은 문서화한 निज API 부분집합을 제공하며 JAR 로더는 제공하지만 전체 AWT/Swing·JDK 표준 라이브러리는 없다. 정확한 범위는 [निज JVM 설명](자바실행환경.md)이 기준이다. 상세 भाषा 범위는 [공유 Java उपकरण 설명](../../문서/자바개발환경.md)을 참고하되, 그 문서의 x86 शेल/स्टोर_मान/실행시간과 이 ARM64 판의 차이에 유의한다.

MicroPython은 공식 **1.24.1 स्रोत_ट्री**를 निज AArch64 EL0/SVC 대상으로 빌드했다. Python 문법의 फ़ंक्_शन_मान·कक्षा_मान·अपवाद·리스트/कोश·Unicode·GC·가변 परिशुद्धता_मान 정수를 제공한다. अद्यतित_आइटम 구성은 पूर्णांक 빌드로 `float`, `complex`, `math`가 없으며 CPython 전체 표준 लाइब्रेरी, pip, subprocess, threading, 일반 socket과 डिफ़ॉल्ट_मान `open()` संचिका 객체는 제공하지 않는다. `python FILE.py` 및 `-c` 실행만 제공하며 REPL은 아직 없다. 각 실행의 ऑब्जेक्ट_मान·모듈은 निर्गमन_ऐप 시 회수되고 RAM 파일만 अगला_आइटम 실행에 남는다.

`import jkoros`로 अगला_आइटम 시스템 연결을 쓴다. 모두 SVC를 통해 निज Java 커널에 접근한다.

| फ़ंक्_शन_मान | क्रिया |
|---|---|
| `stdin(limit)` | अद्यतित_आइटम 표준 입력에서 최대 limit바이트(0…16384)를 bytes로 पढें_परिणाम; EOF는 빈 bytes, UART आँकड़े 없음은 OSError(11) |
| `read(name)` | पीअर_मान/절대 RAM 경로의 संचिका 전체를 bytes로 पढें_परिणाम |
| `write(name, data)` | str/bytes 버퍼를 RAM 파일에 새로 स्टोर_मान, 쓴 बाइट_मान 수 वापस_करें_परिणाम |
| `remove(name)` | RAM संचिका 삭제 |
| `rect(x, y, w, h, color)` | 선택한 वास्तविक_डेटा 화면 आकार 안의 रेक्_टेंगल ड्रॉइंग_मान; 기존 보드의 RGB32 मान |
| `ticks_ms()` | 부팅 후 밀리초, 32비트 चक्र_मान |
| `udp_open(port)` | 127.0.0.1의 UDP सॉकेट_मान खोलें/बाइंड_करें_एंडपॉइंट; 0은 자동 포트 |
| `udp_send(fd, port, data)` | 루프백 गंतव्य_मान 포트에 str/bytes 버퍼 हस्तांतरण_मान |
| `udp_recv(fd)` | `(bytes, 보낸포트)` वापस_करें_परिणाम; 비어 있으면 `OSError(11)` |
| `udp_close(fd)` | सॉकेट_मान बंदकरें |

```python
import jkoros
first = jkoros.udp_open(9401)
second = jkoros.udp_open(9402)
jkoros.udp_send(first, 9402, b"hello")
print(jkoros.udp_recv(second))  # (b'hello', 9401)
jkoros.udp_close(first)
jkoros.udp_close(second)
```

이식 कोड_मान: [python/](파이썬연결/), [उपयोगकर्ता Java जोड़ना](उपयोगकर्ता/자바연결.c). 공식 [MicroPython 이식 ReadMe_फ़ाइल_eb81d7d9](https://docs.micropython.org/en/latest/develop/porting.html)를 참고했다. स्रोत_ट्री URL·हैश_फ़ाइल·라이선스는 [vendor ReadMe_फ़ाइल_eb81d7d9](vendor/README.md)에 기록했다.

## 남은 작업

| अगला_आइटम स्टेज_मान | 완료 प्रोजेक्ट_करें_मूल |

| 일반 프로세스·스레드 | 프로세스별 पता पता_क्षेत्र, 선점 스케줄러, TLS, सिंक्रनाइज़_करें/प्रतीक्षा_करें_मान, 신호, mmap/mprotect |

## हिंदी C डेटा_प्रकार·Python त्रुटि·बंडल इंस्टॉल_करें_मान

C 네트워크 API는 `struct क्लाउड_सॉकेट_पता`, enum 상수와 वास्तविक_डेटा हिंदी 함수로
구현한다. मैक्रो_मान 별칭을 사용하지 않으며 이전 pk_* ABI도 유지한다.
Python 예제는 `सिस्टम_त्रुटि`, `त्रुटि.इंडेक्स`, `त्रुटि.설명`을 사용한다.

`python3 उपकरण/निष्पादित_करें_आदेश.py --desktop --network --pip`로 시작하면 게스트에서
`pip install micropython-bisect==3.3.3`을 사용할 수 있다. 현재는 आयोजक 중계를
이용하는 제한형 MicroPython स्रोत_ट्री 설치기이며 CPython pip·자동 의존성 해결·C 확장은
미지원이다. 설치한 `/lib` 자료는 RAM이다. [사용법과 제한](파이썬꾸러미.md).

## 화면 आकार चयन_मान

`python3 उपकरण/निष्पादित_करें_आदेश.py --desktop --network --resolution 1920x1080`으로 Full HD 화면을 사용한다. 기본값은 640×480이며 1280×720도 가능하다. आदेशपटल ले_जाएँ_मान, Swing 가운데 लिंक_लेआउट, Java·C·Python 그리기도 वास्तविक_डेटा 크기를 따른다. SD 영상은 `make image RESOLUTION=1920x1080`으로 만든다. [विन्यास·हिंदी API·मान्य_करें ReadMe_फ़ाइल_eb81d7d9](स्क्रीन_रिज़ॉल्यूशन.md).

## हिंदी 직접 API와 화면 ताज़ा_करें

`example/java`는 `실행할일`, `동작받이`, `एक्शन_सूचना`, `बटन`, `घटना_कतार`,
`कार्यसूत्र`, `चलाएँ()`을 사용할 수 있다. हिंदी GUI/가닥을 निज JVM에 직접

계약과 전체 स्रोत_ट्री 검토 범위는 [명명 ReadMe_फ़ाइल_eb81d7d9](명명/ReadMe_फ़ाइल_eb81d7d9.md), 사용법과 호환성 변경은
[हिंदी Java API](한국어자바/ReadMe_फ़ाइल_eb81d7d9.md)를 본다.

आदेशपटल ले_जाएँ_मान·आकार 변경은 바뀐 영역만 합성하고 달라진 화소만 표시한다.
