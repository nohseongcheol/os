# हिंदी Java 통신·इनपुट_आउटपुट·अपवाद API

패키지는 `हिंदी.निज`다. आयोजक `javac --release 8`로 컴파일한 class를
निज ARM64 커널의 JVM에서 실행한다. 통신·संचिका·अपवाद API는 OpenJDK와 대조한다. 아래의 직접 구현한 화면·작업 थ्रेड_मान API는 निज JVM 전용이다.
기존 표준 Java लाइब्रेरी 전체의 हिंदी 번역판은 아니다.

```java
import हिंदी.निज.*;

public class नेटवर्क {
    public static void main(String[] तर्क) throws इनपुट_आउटपुट_अपवाद {
        कनेक्शन जोड़ना = कनेक्शन.खोलें("10.0.2.2", 9000);
        try {
            जोड़ना.대기시간(700);
            जोड़ना.निर्गम().लिखें(문자.부호화("안녕하세요\n"));
            इनपुट_प्रवाह 입력 = जोड़ना.입력();
            निर्गम.수쓰기(입력.पढ़ें());
        } catch (대기시간초과예외 त्रुटि) {
            निर्गम.लिखना_लाइन(त्रुटि.설명());
        } finally {
            जोड़ना.बंदकरें();
        }
    }
}
```

`Socket`, `getOutputStream`, `write`, `getInputStream`, `read`, `close`를
उपयोगकर्ता 예제에서 직접 호출할 필요가 없다. `try/catch/throws` 등 Java 문법은 유지한다. `String`은 예약어가 아니라 javac가 स्ट्रिंग_मान 리터럴에 사용하는 표준 클래스다. निज 실행기는 `public static void चलाएँ()`도 진입점으로 받는다.

## 통신과 स्ट्रीम_मान

| कक्षा_मान | हिंदी 호출 |
|---|---|
| कनेक्शन | `खोलें(पता, पोर्ट_संख्या)`, `입력()`, `निर्गम()`, `대기시간(밀리초)`, `पोर्ट_संख्या()`, `स्थानीय_पोर्ट_संख्या()`, `연결됨()`, `닫힘()`, `बंदकरें()` |
| 수신창구 | `खोलें(पोर्ट_संख्या)`, `받기()`, `पोर्ट_संख्या()`, `대기시간(밀리초)`, `닫힘()`, `बंदकरें()` |
| इनपुट_प्रवाह | `पढ़ें()`, `पढ़ें(byte[])`, `पढ़ें(byte[], चलाएँ, 길이)`, `बंदकरें()` |
| आउटपुट_प्रवाह | `लिखें(int)`, `लिखें(byte[])`, `लिखें(byte[], चलाएँ, 길이)`, `내보내기()`, `बंदकरें()` |
| 전문통로 | `खोलें(पोर्ट_संख्या)`, `भेजें(पता, पोर्ट_संख्या, पाठ)`, `받기()`, `대기시간(밀리초)`, `पोर्ट_संख्या()`, `닫힘()`, `बंदकरें()` |
| 연결통신 | `खोलें(...)`, `수신열기(...)`는 위 हिंदी 객체를 वापस_करें_परिणाम |
| 검사 | `참인지(शर्त, 까닭)` |

TCP 입력은 한 번에 요청한 모든 바이트가 도착한다고 가정하지 않는다.
`पढ़ें()`의 संचिका 끝은 -1, सरणी_मान 읽기의 반환값은 वास्तविक_डेटा 읽은 길이다.
네트워크 흐름을 닫으면 연결도 닫힌다. पोर्ट_संख्या 0은 빈 번호를 자동 배정한다.
UDP 전문은 अद्यतित_आइटम निज 커널에서 512바이트까지 받으며, 주소는 अंक_मान IPv4를 사용한다.
`localhost` 루프백 외의 नाम 풀이(DNS)는 निज 커널에 아직 없다.

기존 `연결통신.जोड़ना/सुनिए_एंडपॉइंट/받기`, `통신.खोलें/भेजें/받기`는 표준 Java 객체를
사용하던 코드와의 연결용이다. 새 코드는 `कनेक्शन`, `수신창구`, `전문통로`를 쓴다.

## हिंदी अपवाद

모든 아래 클래스는 डिफ़ॉल्ट_मान 생성자, `새예외("설명")` 형태의 स्ट्रिंग_मान 생성자와
`설명()`을 제공한다. वास्तविक_डेटा जनरेट_करें 문법은 `new 대기시간초과예외("प्रतीक्षा_स्थिति 끝")`이다.

| हिंदी अपवाद | 상위 कक्षा_मान / 용도 |
|---|---|
| अपवाद | `java.lang.Exception`, 직접 던지는 일반 검사 अपवाद |
| 실행예외 | `java.lang.RuntimeException` |
| इनपुट_आउटपुट_अपवाद | `java.io.IOException`, हिंदी संचिका·통신 API의 검사 अपवाद |
| 대기시간초과예외 | `इनपुट_आउटपुट_अपवाद`, 통신 대기시간 초과 |
| पता_लुकअप_अपवाद | `इनपुट_आउटपुट_अपवाद`, पता सत्यापित_करें विफलता_मान |
| 파일없음예외 | `इनपुट_आउटपुट_अपवाद`, संचिका खोलें विफलता_मान |
| 통신예외 | `इनपुट_आउटपुट_अपवाद`, 표준 SocketException रूपांतरित_करें_मान |
| अमान्य_तर्क_अपवाद | `java.lang.IllegalArgumentException` |
| 숫자형식예외 | `अमान्य_तर्क_अपवाद` |
| 범위예외 | `java.lang.IndexOutOfBoundsException` |
| 배열범위예외 / 문자열범위예외 | `범위예외` |
| अकृत_उल्लेख_अपवाद | `java.lang.NullPointerException` |
| 산술예외 | `java.lang.ArithmeticException` |
| अवस्था_अपवाद | `java.lang.IllegalStateException` |
| लिखें_कास्ट_अपवाद | `java.lang.ClassCastException` |
| 음수배열크기예외 | `java.lang.NegativeArraySizeException` |
| सरणी_स्टोर_विफलता | `java.lang.ArrayStoreException` |
| थ्रेड_अवस्था_अपवाद | `java.lang.IllegalThreadStateException` |
| 대기중단예외 | `java.lang.InterruptedException`, `작업.기다리기`의 प्रतीक्षा_करें_मान 중단 |

`अपवाद`와 `실행예외`는 모든 हिंदी 예외의 공통 부모가 아니다. 위 상속 관계를
사용하며, संचिका·통신 전체를 잡으려면 `catch (इनपुट_आउटपुट_अपवाद त्रुटि)`를 쓴다.
हिंदी API가 표준 इनपुट_आउटपुट 오류를 हिंदी 예외로 변환한다.
기존 हिंदी 통신 호출에서 `SocketTimeoutException`을 잡던 코드는
`대기시간초과예외`를 잡도록 옮긴다. 표준 `java.net`을 직접 사용하는 코드의
अपवाद 유형은 기존 Java 규약을 따른다.
일반 Java 연산이 자동으로 던지는 표준 예외까지 이름을 바꾸지는 않는다.
예를 들어 `1 / 0`의 ArithmeticException과 직접 만든 산술예외는 서로 다른 형식이다.
अद्यतित_आइटम निज JVM에 이 20종을 추가했다. 임의의 उपयोगकर्ता Throwable 하위 कक्षा_मान 전체를
지원하도록 확장했다는 뜻은 아니다.

## कंपाइल_स्रोत·निष्पादित_करें_आदेश

```sh
cd /home/user/jkoros/platforms/rpi4-native
make बिल्ड_सिस्टम
javac --release 8 -encoding UTF-8 -cp dist/jkoros-native-korean.jar \
  -d build/한국어사용 시험/자바/한국어통신시험.java
python3 उपकरण/निष्पादित_करें_फ़ाइल.py build/한국어사용/한국어통신시험.class
make test-jvm
```

내장 라이브러리는 उपयोगकर्ता JVM ELF 안에 탑재된다. `.jar`는 आयोजक javac의
कक्षा_मान 경로로 사용한다. स्रोत_ट्री 묶음은 `dist/jkoros-native-korean-sources.zip`이다.
게스트의 제한형 `javac`는 हिंदी 예외의 `throws` 선언과 그 import를 인식한다.
निज JVM의 Thread.interrupt 동작을 새로 구현한 것은 아니다.
try/catch·ऑब्जेक्ट_मान·सॉकेट_मान 예제 전체의 स्रोत_ट्री 컴파일은 आयोजक javac를 사용한다.
`/example/java/संचिकाउदाहरण.java`는 게스트 javac로도 컴파일할 수 있다.

वास्तविक_डेटा TCP/UDP 예제는 [जालउदाहरण.java](../../../example/java/जालउदाहरण.java),
निष्पादित_करें_आदेश 절차는 [example ReadMe_फ़ाइल_eb81d7d9](../../../example/README.md),
स्रोत_ट्री 명명 원칙은 [명명 ReadMe_फ़ाइल_eb81d7d9](../명명/ReadMe_फ़ाइल_eb81d7d9.md)에 있다.

## Swing खिड़की 예제

`/example/java/खिड़कीउदाहरण.java`와 컴파일된 `.class`가 부팅 시 준비된다.
`cd /example/java` अगला_आइटम `java खिड़कीउदाहरण`로 연다. नाम 입력, 인사하기 버튼,
인사말과 क्लिक_करना_मान 횟수 ताज़ा_करें, X 닫기를 지원한다.

| 기능 | हिंदी 직접 API |
|---|---|
| Runnable / run | `실행할일.निष्पादन()` |
| ActionListener / actionPerformed | `동작받이.동작받기(एक्शन_सूचना सूचना)` |
| ActionEvent | `एक्शन_सूचना.आदेश_पाठ()`, `ईवेंट_स्रोत()`, `इंडेक्स()` |
| JFrame | `खिड़की(विंडो_शीर्षक, 폭, 높이)`, `जोड़ें_तत्व(화면구성요소)`, `शो_विंडो()`, `बंदकरें()`, `보이는가()` |
| JButton | `बटन(पाठ, 가로, अनुलंब_पद, 폭, 높이, 받이)`, `동작맡기기(받이)` |
| JLabel / JTextField | `लेबल(...)`, `पाठ_फ़ील्ड(...)` |
| 공통 화면 तत्व_मान | `화면구성요소.पढें_पाठ()`, `लिखना_पाठ(पाठ)`, `자리정하기(가로, अनुलंब_पद, 폭, 높이)` |
| SwingUtilities.invokeLater | `घटना_कतार.나중에실행(실행할일)`, `사건처리중인가()` |
| Thread | `कार्यसूत्र(실행할일)`, `प्रारंभ_कार्य()`, `기다리기()`, `살아있는가()`, `स्थगित_करें_कार्य()` |
| 명령행 | `चलाएँ()`, `실행인수.개수()`, `실행인수.पाठ(순번)` |

위 클래스들은 `JButton`·`Thread` 등의 객체를 만들거나 보관하지 않는다.
निज JVM의 `한국어화면호출`, `प्रक्रिया_थ्रेड`가 हिंदी कक्षा_मान·विधि_मान·서술자를
해석해 화면 요소와 निष्पादित_करें_आदेश 가닥을 직접 만든다. क्रिया 알림도 निज 객체이며
콜백으로 `निष्पादन`와 `동작받기`를 직접 찾는다. 표준 Swing/Thread를
사용하는 기존 프로그램의 निष्पादित_करें_आदेश 경로는 별도로 남아 있다.

Java 소스의 `native` 선언은 निज JVM에 구현한 계약이다. 생성자의 예외는
이 계약이 없는 आयोजक JVM에서 무동작 객체가 생기지 않도록 하는 अस्वीकृत_करें_मान 경로다.
निज JVM은 생성자를 직접 처리한다. 일반 OpenJDK에서는 이 직접 구현 API를
실행할 수 없다. आयोजक javac로 컴파일한 वापस_मान निज JVM에서 실행한다.
`StringUtilities`라는 표준 Swing 클래스는 없으며, 화면 큐 기능은 `SwingUtilities`에 해당한다.

```java
import हिंदी.निज.*;
public class 가닥예제 implements 실행할일 {
    public void निष्पादन() { निर्गम.लिखना_लाइन("हिंदी 작업 निष्पादित_करें_आदेश"); }
    public static void चलाएँ() throws 대기중단예외 {
        कार्यसूत्र थ्रेड_मान = 작업.चलाएँ(new 가닥예제());
        작업.기다리기(थ्रेड_मान);
    }
}
```

`example/java`의 다섯 소스는 예약어·리터럴 외 식별자를 한국어로 작성한다.
सरणी_मान तर्क 대신 `실행인수`, 길이는 `문자.바이트수`를 사용한다.
표준 Java의 `main(String[])`도 계속 지원한다. 둘 다 정의되어 있으면
निज 실행기는 तर्क 없는 `चलाएँ()`을 우선한다.
기존 हिंदी 화면 래퍼의 표준 `Component`/`Runnable`/`ActionListener` 인수와
`작업.चलाएँ(Runnable)`을 사용하던 코드는 새 हिंदी 계약으로 수정하고 재컴파일한다.
이는 전체 AWT/Swing·Thread API समर्थन_मान 또는 모든 JDK 소스의 번역을 뜻하지 않는다.

바이트코드에도 कक्षा_मान·विधि_मान 이름과 서술자가 남는다.
हिंदी नाम 자체는 합법이지만, 다른 클래스에서 그 이름을 참조하는 부분,
상속·विधि_मान 재정의, native जोड़ना, 런처의 진입점도 함께 맞춰야 한다.
근거는 [JLS पहचानकर्ता_मान](https://docs.oracle.com/javase/specs/jls/se25/html/jls-3.html#jls-3.8)와
[JVMS विधि_मान संदर्भ](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-4.html#jvms-4.4.2)다.
