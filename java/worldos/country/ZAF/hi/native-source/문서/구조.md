# JZafOS 구조

아래는 ऑब्जेक्ट_मान 기반 관리 कर्नेल_मान 전체의 लक्ष्य_ऑब्जेक्ट 구조다. अद्यतित_आइटम वास्तविक_डेटा 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 ऑपरेटिंग_सिस्टम ReadMe_फ़ाइल_eb81d7d9](../os/ReadMe_फ़ाइल_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·문맥 स्विच_मोड·फ़ाइल_सिस्टम 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 लेयर_मान
  ↓
Java AOT 실행기와 ऑब्जेक्ट_मान·सरणी_मान·GC 런타임
  ↓
하드웨어 경계
  ↓
Java 관리 कर्नेल_मान
  ├─ मेमोरी_क्षेत्र/쪽관리/COW
  ├─ प्रक्रिया_मान/배정/wait
  ├─ फ़ाइल_सिस्टम/ELF/POSIX
  └─ 입력/संग्रहण_उपकरण/नेटवर्क_स्टैक
```

OpenJDK 자체는 이미 운영체제가 제공하는 संचिका, 스레드, 가상 기억공간을 전제로 한다. 따라서 कर्नेल_मान 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, 문맥 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
