# हिंदी Java 도우미 लाइब्रेरी

OpenJDK 11 이상과 함께 쓰는 프로젝트 स्वामी_मान API다. 표준 Java लाइब्रेरी 전체의 번역판을 뜻하지 않는다. 기존 Java API·키워드·अपवाद·자료형은 그대로 함께 쓴다.

전체 22개 도우미 메서드의 तर्क·반환값·제약, ऑपरेटिंग_सिस्टम 안의 사용법, Python·C++ 호출 방법은 **[हिंदी लाइब्रेरी उपयोगकर्ता_मार्गदर्शिका](उपयोगकर्ता_मार्गदर्शिका.md)**에 정리했다. [Python 호출 예제](예제/다른언어/파이썬호출.py)와 [C++ JNI 호출 예제](예제/다른언어/자바호출.cpp)도 제공한다.

`make`로 `build/한국어자바.jar`를 만든다. `javac -encoding UTF-8 -cp build/한국어자바.jar 예제/अभिनन्दन_ae353e94.java`로 예제를 컴파일한다. 실행은 `java -cp build/한국어자바.jar:예제 अभिनन्दन_ae353e94`다.

`अभिनन्दन_ae353e94` 예제는 그래픽 화면이 없으면 संचिका·문자·스레드 결과와 안내만 출력한다. Swing 창은 그래픽 세션에서 실행해야 한다. QEMU에서는 [그래픽 निष्पादित_करें_आदेश ReadMe_फ़ाइल_eb81d7d9](../platforms/rpi4/README.md)의 `make run`으로 부팅한 वापस_मान VNC 데스크톱의 터미널을 사용한다.

| कक्षा_मान | 제공 기능 |
|---|---|
| संचिका | UTF-8 텍스트·बाइट_मान पढ़ें/लिखें, 디렉터리·एन्ट्री_सूची |
| 문자 | UTF-8 रूपांतरित_करें_मान, NFC सामान्य_करें_मान, कोड_मान 포인트 수, 언어별 낱말 경계 |
| 통신 | HTTP(S) अनुरोध, 제한시간을 가진 TCP जोड़ना |
| 작업 | 스레드 चलाएँ·합류·प्रतीक्षा_करें_मान, 작업 ऐप_लॉन्चर |
| 화면 | Swing 이벤트 처리와 खिड़की जनरेट_करें |
| कार्यस्थान | स्रोत संपादन_मान·कंपाइल_स्रोत·निष्पादित_करें_आदेश·निष्पादित_करें_आदेश संचिका जनरेट_करें 화면 |

`char`는 UTF-16 कोड_मान 단위이므로 이모지 등을 한 글자로 처리할 때 कोड_मान 포인트 또는 문자 경계 API를 사용한다. 파일은 UTF-8로 저장한다. OpenJDK의 모든 Java2D/फ़ॉन्ट_मान/입력기 조합을 각각 검증한 것은 아니다.

이름은 अद्यतित_आइटम 의미가 분명한 हिंदी 용례를 사용했다. 개별 명칭의 역사적 어원 검토를 완료했다고 주장하지 않는다. संसाधन_मान 종료와 अपवाद 처리는 표준 API의 계약을 따른다.
