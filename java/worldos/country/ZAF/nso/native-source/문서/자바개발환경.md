## 외부 Faele 적재

호스트에서 만든 소스나 Thekgo_boleng setsopolwa 안의 `.class`를 부팅 이미지에 포함할 수 있다. `JAVA_FILES`는 `게스트이름=호스트경로` 목록이다. 아래의 경로는 예시이며 kgonthe_data 파일의 절대 경로로 바꾼다. 공백 없는 경로를 사용한다.

```sh
# go_nea_ditirelo JDK로 컴파일한 클래스도 사용할 수 있다.
javac --release 8 /tmp/Demo.java
make -C /home/user/jkoros iso \
  JAVA_FILES='Demo.java=/tmp/Demo.java Demo.class=/tmp/Demo.class'
make -C /home/user/jkoros run \
  JAVA_FILES='Demo.java=/tmp/Demo.java Demo.class=/tmp/Demo.class'
```

새 부팅 후 `java Demo 12`를 실행한다. 소스만 넣었으면 게스트에서 `javac Demo.java`부터 실행한다. `JAVA_FILES`를 생략한 다음 빌드에서는 추가 파일을 포함하지 않는다. Faele Diteng_boleng 변경과 go_tsenya_tshedimošo_Lenaneo 제거도 다음 빌드에 반영된다. 원본 go_nea_ditirelo 파일에는 쓰지 않는다. setsenywa_sa_tirelwa `Hello.java`까지 합해 8개이며, 같은 이름을 명시하면 setsenywa_sa_tirelwa 예제를 대체한다. 새 `.class`를 저장할 빈 슬롯도 남겨 둔다.

[FileDemo.java](../posix-kor/자바예제/FileDemo.java)는 일반 Java 표준 legoro_boleng_55654bf1 이름을 사용한다. 소스를 `edit FileDemo.java`로 입력하거나 `JAVA_FILES`로 부팅 이미지에 넣은 Morago_boleng `javac FileDemo.java`, `java FileDemo`를 실행한다. 결과는 `65`, `255`, `66`, `-1`, `JAVA FILE IO PASS`다. `write(int)`는 하위 8비트를 쓰고 `read()`는 0~255 또는 EOF -1을 반환한다. setsenywa_sa_tirelwa 출력 생성자는 내용을 비우고, boolean 인수가 true이면 이어쓴다.
