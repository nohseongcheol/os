## 기존 kipengee_thamani 기반 관리 kiini_thamani_0611a8a8 전체를 부팅하기 위해 남은 UNGANISHA

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/kifaa_thamani 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot ingizo_pointi_thamani, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 Muktadha_thamani Store_thamani
- halisi_data PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA kitanzi_thamani
- Java kipengee_thamani·ARRAY_thamani Kiungo_Muundo, vighairi, tuli_thamani anzilisha, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT hatua_thamani
- FAT 디스크 구역을 halisi_data ATA 장치와 연결하는 I_T 접착 tabaka_thamani

위 관리 계층은 engos 기능의 Java 관리 구현과 mwenyeji 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot ingizo_pointi_thamani, tuli_thamani anzilisha·namba_kamili ARRAY_thamani, VGA/직렬/PS2, 명령해석기, mtumiaji ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 mwenyeji 루프백 패킷 왕복을 검증했다. 위 표의 kipengee_thamani 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
