JAR는 하나의 애플리케이션 iklasi_ixabiso 경로다. 내부 Igama `umqulu/inkqubo_f5044b9b.class`와 점으로 구분한 Main-Class를 지원한다. 내부 클래스는 파일로 풀어 VFS 슬롯을 소비하지 않는다. 내장 isiXhosa 클래스를 추가로 찾지만 현재 작업 폴더의 다른 클래스는 자동 혼합하지 않는다. ## isiXhosa 네트워크·작업·화면 API

| iklasi_ixabiso | 호출 예 | ukwenza_umyalelo INDLELA |
|---|---|---|

| `iFayili` | `Bhala("문서.txt", "Isiqulatho_ixabiso")`, `Funda("문서.txt")` | JVM 및 제한형 AOT |
| `통신` | `Vula(0)`, `thumela(종단, "10.0.2.2", 9000, "한글")`, `받기(종단)` | JVM의 UDP |

명명에서는 표준 영어 API를 보존하고 isiXhosa 호출 계층을 추가한다. `통신(通信)`, `Nxulumanisa(連結)`, `출력(出力)`은 기존 단어의 뜻을 사용한다. `작업 ithredi_ixabiso`은 한 ukwenza_umyalelo 흐름을 가닥에 빗댄 기술 표현, `iphothi_ixabiso`는 포트의 접점을 설명하는 표현이다. 새 기술 결합어를 고대에 이미 존재한 용어처럼 설명하지 않는다. 전체 JDK의 번역을 완료했다고 표시하지 않는다.

외부 주소는 inani_ixabiso IPv4이며 QEMU 호스트는 `10.0.2.2`, 게스트는 `10.0.2.15`다. UDP 전문은 512바이트까지다. 소켓은 비차단 자체 ABI이며 JVM이 제한된 대기/재시도를 제공한다. TCP connect 대기는 최대 1초, umsebenzisi inkqubo_f5044b9b 전체에는 기존 약 2초 CPU 기한이 적용된다. 일반적인 장기 ukwenza_umyalelo umsebenzisi 서버와 pthread는 아직 없다. FTP는 umsebenzisi inkqubo_f5044b9b 기한과 별개인 ikheneli_ixabiso 서비스다.

게스트의 umsebenzisi TCP/UDP 서버로 들어오는 연결은 NAT 포트를 추가한다. 예를 들어 `python3 Izixhobo/ukwenza_umyalelo.py --network --forward tcp:9300:9300 --forward udp:9301:9301`로 실행하면 호스트의 localhost 9300/TCP·9301/UDP를 게스트의 같은 포트로 전달한다. FTP의 ixabiso_elisisiseko isilawuli_ixabiso/데이터 포트와 겹치면 ukwenza_umyalelo 전에 거부한다.
