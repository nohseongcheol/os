## 기존 into_ixabiso 기반 관리 ikheneli_ixabiso 전체를 부팅하기 위해 남은 Nxulumanisa

다음 항목은 Java 문법만으로 실행할 수 없는 CPU/isixhobo_ixabiso 동작이므로 관리 계층과 별도로 AOT 런타임에 연결해야 한다.

- Multiboot ufako_nkcukacha_inqaku_ixabiso, CR0/CR2/CR3/CR4, IDT 적재, `iret`, x86 umxholo_ixabiso Store_ixabiso
- eyona_yenzekileyo_iingcombolo PIC/PIT/PS2/ATA/PCI 포트 및 AMD PCnet DMA iluphu_ixabiso
- Java into_ixabiso·ULUHLU_ixabiso Ilinki_ubume, 예외, imi_ndawonye_ixabiso qalisa_umsebenzi, 가비지 수집기
- 컴파일된 Java 메서드를 freestanding i386 기계어로 바꾸는 AOT umgangatho_ixabiso
- FAT 디스크 구역을 eyona_yenzekileyo_iingcombolo ATA 장치와 연결하는 i_I_O 접착 ileya_ixabiso

위 관리 계층은 engos 기능의 Java 관리 구현과 umsingathi 검증판이다. 별도 `os/`에서는 제한형 AOT, Multiboot ufako_nkcukacha_inqaku_ixabiso, imi_ndawonye_ixabiso qalisa_umsebenzi·inani_elipheleleyo ULUHLU_ixabiso, VGA/직렬/PS2, 명령해석기, umsebenzisi ELF/ring 3/시스템 호출, RTL8139/ARP/IPv4/UDP를 연결해 QEMU 부팅과 umsingathi 루프백 패킷 왕복을 검증했다. 위 표의 into_ixabiso 기반 관리 기능 전체나 VirtualBox 네트워크 실행까지 검증했다는 뜻은 아니다.
