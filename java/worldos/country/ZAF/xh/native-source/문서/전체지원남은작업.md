# 전체 inkxaso_ixabiso 요청의 현재 imo_ixabiso

요청 전체는 아직 완료되지 않았다. 현재 ISO는 자체 Java AOT 커널과 제한형 JVM을 유지한다. 이번 확장에서는 eyona_yenzekileyo_iingcombolo C POSIX 일부 기능, isiXhosa API/UMTHOMBO Igama, IDE iFayili 보존, 게스트 Java iFayili 흐름을 구현하고 시험했다. [구현과 한계](../posix-kor/i_README_eb81d7d9.md)를 기준으로 판단한다.

| 요청 분야 | 현재 ukwenza_umyalelo 가능한 ikliphu | 전체 지원에 필요한 작업 |
|---|---|---|
| Java yakha_umthombo·ukwenza_umyalelo | 게스트 제한형 javac/JVM, imi_ndawonye_ixabiso 단일 클래스와 일부 표준 into_ixabiso | 일반 into_ixabiso·iklasi_ixabiso Nxulumanisa·예외·GC·스레드, 완전한 javac와 표준 iklasi_ixabiso ilayibhrari |
| iFayili | POSIX 서술자, Java 단일 ibhayithi_ixabiso iFayili Stream_ixabiso, 전용 매체 보존 | 일반 java.io/nio, 디렉터리·imvume_ixabiso·잠금·일반 uhlobo_loseto_lwefayile·isongezelelo_ixabiso 가능한 용량 |
| 네트워크 | AOT Java와 POSIX C의 IPv4 UDP umsingathi 왕복 | 게스트 java.net, TCP·DNS·DHCP·IPv6·HTTP·TLS, 추가 NIC |
| GUI·Swing | VGA 문자 단말 | 프레임버퍼·입력 umcimbi·ifonti_ixabiso·i_window Indlela_yokusebenza_ixabiso, AWT 네이티브 연결과 Swing ukwenza_umyalelo 기반 |

| 언어별 Igama | isiXhosa 46개 대응 ufako_nkcukacha_ixabiso, eyona_yenzekileyo_iingcombolo C/Java/iFayili Igama 적용 | ithagethi Ulwimi 확정, 언어별 용례·역사 근거와 해당 UMTHOMBO·도구의 qinisekisa |

자체 커널을 유지하면 위 기반 기능과 런타임 이식을 순차적으로 구현해야 한다. Linux 기반 ukwenza_umyalelo 환경을 추가하는 방식은 별도의 ikheneli_ixabiso·루트 uhlobo_loseto_lwefayile·OpenJDK·그래픽 iseva_ixabiso·영구 Store_ixabiso 구성을 가진 ukwenza_umyalelo 경로가 된다. 후자는 기존 자체 커널에 OpenJDK가 이식되었다고 표시해서는 안 된다.

ukwenza_umyalelo 기반과 추가 ithagethi 언어는 사용자에게 확인을 요청했으며 아직 답변을 받지 못했다. 그 결정 없이 기존 커널을 Linux로 교체하거나 여러 국가의 번역을 임의로 만들지 않았다. 현재 원문과 시험 결과를 후속 구현의 출발점으로 보존한다.
