# JZafOS 구조

아래는 into_inani 기반 관리 ikhenela_inani 전체의 impokophelo_into 구조다. 현재 ulwazi_ngokwenzekile_imininingwane 부팅 가능한 제한형 구현은 `compiler/`와 `os/`에 있으며 [네이티브 isistimu_yokusebenza NGIFUNDE_eb81d7d9](../os/NGIFUNDE_eb81d7d9.md)에 구현 범위를 명시한다. 아래의 GC·Umongo_inani guqulela_kokunye_inqubo·isistimu_yefayela 등이 새 ISO에 모두 포함돼 있지는 않다.

```text
GRUB 또는 UEFI
  ↓
x86 최소 부트·트랩 ugqinsi_inani
  ↓
Java AOT 실행기와 into_inani·AMALUNGU_AFANAYO_inani·GC 런타임
  ↓
하드웨어 경계
  ↓
Java 관리 ikhenela_inani
  ├─ 기억공간/쪽관리/COW
  ├─ Inqubo_inani/배정/wait
  ├─ isistimu_yefayela/ELF/POSIX
  └─ 입력/Indawo_yokugcina_idivayisi/iNethiwekhi_Isitaki
```

OpenJDK 자체는 이미 운영체제가 제공하는 Ihele, 스레드, 가상 기억공간을 전제로 한다. 따라서 ikhenela_inani 부팅에는 OpenJDK를 그대로 넣지 않고 제한된 Java 바이트코드 AOT와 작은 런타임을 사용한다.

네이티브 계층에는 `in/out`, `hlt`, CR0/CR2/CR3/CR4, `iret`, Umongo_inani 저장처럼 Java로 표현할 수 없는 CPU 동작만 남긴다. 정책과 자료구조는 Java에 둔다.
