# 실행 기반과 자료 출처

이 프로젝트는 Linux, musl libc, Alpine 패키지, OpenJDK를 사용한 운영체제 구성 및 언어별 Java 작업 환경이다. 외부 프로젝트의 코드를 각 나라 언어로 새로 재작성했다고 주장하지 않는다.

- Alpine 실행 기반과 패키지: https://www.alpinelinux.org/ 및 https://gitlab.alpinelinux.org/alpine/aports
- OpenJDK: https://openjdk.org/projects/jdk/25/
- Linux: https://www.kernel.org/
- musl: https://musl.libc.org/
- Unicode CLDR 48 자료: https://github.com/unicode-org/cldr/tree/release-48
- ISO 국가 자료: 호스트 iso-codes의 `iso_3166-1.json` 복사본. https://salsa.debian.org/iso-codes-team/iso-codes
- 입력기: https://github.com/fcitx/fcitx5 및 m17n-db. 키보드 배치는 설치한 xkeyboard-config의 언어 연결 자료를 사용한다.
- 글꼴: https://github.com/notofonts/notofonts.github.io — Alpine의 `font-noto-all`, CJK 및 DejaVu 묶음을 설치한다. OpenJDK 자동 선택에서 누락된 타나 글꼴은 JVM의 추가 대체 글꼴 경로에 연결한다. [OpenJDK의 해당 경로 처리](https://github.com/openjdk/jdk/blob/jdk-25-ga/src/java.desktop/unix/classes/sun/font/FcFontConfiguration.java)
- 명명 제안: 기존 golang/worldos의 프로젝트 명명 자료, 이 프로젝트의 제안, 설치된 GNU gettext 번역 카탈로그. 개별 출처를 항목마다 기록한다.

패키지별 버전, 라이선스 식별자, 원본 프로젝트 URL과 서명 메타데이터 체크섬은 `runtime/packages.lock.json`에 기록한다. 파일 다운로드 기록은 `runtime/sources.lock.json`, 생성된 실행 이미지의 해시는 `build/runtime/manifest.json`에 기록한다. 여기서 lock 파일은 실제 취득 내역이며 모든 외부 저장소를 영구 보관하는 미러는 아니다.

`docs/licenses/`에는 수집한 국가 자료와 부트스트랩 BusyBox, Unicode 자료의 고지를 보관한다. 게스트 패키지가 제공하는 고지는 게스트 파일체계에 유지한다. 각 구성요소의 권리는 해당 프로젝트와 기여자에게 있다.
