# 자체 커널 국가별 현황

국가 코드는 ISO 3166-1, 언어판 관계는 Unicode CLDR 48과 프로젝트의 명시적 대표 언어 선택표로 검사한다.
국가 코드와 언어 코드는 구분하며, 하위 언어판의 언어를 대표 언어로 덮어쓰지 않는다.
전체 선택은 [국가·언어 정책](../naming/country-language-policy.json)에 기록한다.
아래 표는 대표판만 표시하며, 소수 언어·공동 공용어 전체를 수록한 목록은 아니다.
이름 수는 적용한 대응표 항목 수이며 완역률이 아니다. 한국어판은 원문이므로 치환 수가 0이다.
미번역 열은 원문에서 남은 한국어 식별자의 종류 수다. 현지어 검토와 역사적 어원 검토는 모두 별도 과제다.
입력 안내가 `기호`인 판은 `F9 / Shift+Space: [EN] ↔ [언어명]`으로 표시하며 문장 번역은 미완료다.
입력·UTF-8 보존과 복잡한 문자 조판은 구분한다. 인도계 문자 결합과 완전한 양방향 배치는 미완료다.
