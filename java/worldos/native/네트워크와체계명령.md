# 네트워크 설정·상태 조회·종료

`country/<국가코드>`의 독립 자체 커널 판에 적용된다. 현재 실행 중인 VM에는 새 명령이 자동 추가되지 않으므로, 작업을 마친 후 새 커널로 다시 시작한다.

```sh
cd /home/user/java/worldos/country/KOR
make desktop ARGS=--network
# 직렬 셸은 make run ARGS=--network
```

운영체제 안에서 다음 명령을 실행한다.

```sh
help system
ipconfig
ip addr show
ping -c 4 10.0.2.2
ipconfig set 10.0.2.20 255.255.255.0 10.0.2.2
ip route show
netstat
ps
free
df
top
# top에서 q로 나가기
poweroff
```

| 기능 | 공통 명령 | 한국어 | 일본어 | 중국어 간체 |
|---|---|---|---|---|
| IP 조회·설정 | ipconfig | 아이피설정 | 通信設定 | 网络设置 |
| 인터페이스·경로 | ip | 아이피 | 通信番地 | 网络地址 |
| ICMP 시험 | ping | 응답시험 | 応答試験 | 回声测试 |
| 경로 | route | 경로표 | 経路表 | 路由表 |
| TCP/UDP 끝점 | netstat | 통신현황 | 通信状況 | 网络状态 |
| 실행 작업 | ps | 작업목록 | 作業一覧 | 进程列表 |
| 반복 현황 | top | 작업현황 | 稼働状況 | 运行概况 |
| 메모리 | free | 기억현황 | 記憶状況 | 内存状态 |
| RAM 파일 용량 | df | 저장현황 | 保存容量 | 存储容量 |
| 부팅 경과 시간 | uptime | 가동시간 | 稼働時間 | 运行时间 |
| 종료 | poweroff | 전원끄기 | 電源を切る | 关机 |
| 안내 | help | 도움말 | 使い方 | 帮助 |

예: 일본어판의 `応答試験 -c 4 10.0.2.2`, 한국어판의 `아이피설정 set 10.0.2.20 255.255.255.0 10.0.2.2`.
명령어 첫 단어는 현지어 별칭을 사용할 수 있으며 옵션·하위 명령(`set`, `-c` 등)은 공통이다.
실제 연결된 UTF-8 셸과 Tab 완성에서 처리한다. 다른 판의 정확한 이름은 해당 `NATIVE.md`, `native-commands.json`, 게스트 `help system`에서 확인한다.

초기 주소 `10.0.2.15/24`, 관문 `10.0.2.2`, 인터페이스 `sl0`이다. 변경은 재부팅 전까지 유지한다.
`ip`는 표시된 부분집합 구문을 지원한다. `ping`은 숫자 IPv4 주소만 지원하고 DNS·DHCP·IPv6는 추가하지 않았다.
외부 통신에는 `--network`가 필요하다. 실물 Pi의 유선·무선 장치 드라이버가 아니라 UART SLIP와 QEMU NAT를 사용한다.
주소를 바꾸기 전에 `ftpd stop`과 사용자 프로그램의 소켓 닫기가 필요하다. 열려 있으면 `error -16`을 반환한다.

새 주소로 FTP 등 외부 접속도 받으려면 `make desktop ARGS="--network --guest-ip 10.0.2.20"`으로
NAT 전달 대상을 맞추고 게스트에서도 `.20`을 설정한다. 여러 VM은 `--network-host 127.0.0.2 --port 5903`처럼 구분한다.

`ps`/`top`은 실제 커널 작업과 최대 4개의 사용자 세션을 보여준다. 다른 터미널에서 열린 `vi`도 표시한다.
실행 시간은 정밀 CPU 백분율이 아니다. `free`는 실제 AOT 힙과 고정 메모리 영역·매핑량을 표시한다.
`df`는 RAM 파일 64칸 × 16 KiB의 예약량과 실제 자료량이다. 영구 SD 디스크 통계는 아직 없다.
`poweroff`는 게스트 서비스를 정리하고 BCM PM 종료를 요청한다. RAM 파일은 보존되지 않으며 실물 Pi 전원 회로는 미검증이다.

언어 이름은 현재 기능을 바탕으로 한 명명안이다. 원어민의 자연스러운 용례·역사적 어원 검토를 완료했다고 주장하지 않는다.
번역을 확정하지 못한 명령은 해당 판의 `pending`에 표시하고 표준 이름을 유지한다. `description_language`가 `en`이면 설명문도 영어다.
복잡한 문자 결합·양방향 조판의 기존 제한은 유지된다.

```sh
make -C /home/user/java/worldos native-test-system COUNTRY=KOR
python3 /home/user/java/worldos/native/verify_system.py KOR JPN CHN IND SAU
```

국가별 단독 시험은 `make test-system`이며 `build/verification/system-tools/`에 기록한다.
위 여러 국가 시험은 `java/worldos/build/native/system/<국가코드>/`에 커널 해시·직렬 기록·실제 ICMP 흔적·QEMU 종료 이벤트를 남긴다.
전체 소스·입력·글꼴 검사는 `make native-verify`이다. 부팅 시험한 국가와 소스만 검사한 국가는 [검증결과](검증결과.md)에 구분한다.
