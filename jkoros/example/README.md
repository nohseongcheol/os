# 자체 ARM64 jkoros의 한국어 예제

대상은 `platforms/rpi4-native`의 Raspberry Pi 4용 자체 Java 커널이다.
이 폴더에 Java·C·Python의 출력, 파일 입출력, 네트워크, 그래픽 예제 **13개**와
공용 한국어 호출 도우미를 보관한다. 현재 실행 검증은 QEMU raspi4b에서 한다.

## GUI와 네트워크를 함께 실행

호스트 터미널 1:

```sh
cd /home/user/jkoros/platforms/rpi4-native
make build
python3 도구/실행.py --desktop --network
```

Remmina에서 VNC `127.0.0.1:5902`로 접속한다. 게스트에서 `ftpd start`를 입력하면
같은 VM의 FTP에 `127.0.0.1:2121`로 접속할 수 있다. `--port`, `--ftp-port`,
`--forward tcp:호스트포트:게스트포트`/`--forward udp:호스트포트:게스트포트`도
함께 사용한다. VNC와 FTP/TCP 전달 포트는 서로 달라야 한다. 종료는 호스트 Ctrl+C.

네트워크 예제를 위해 호스트 터미널 2에서 응답기를 실행한다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
python3 도구/예제되돌림서버.py --tcp-port 9000 --udp-port 9001
```

게스트는 QEMU 호스트 주소 `10.0.2.2`로 실제 TCP/UDP 전문을 전송하고 응답을
검사한다. 응답기가 없으면 네트워크 예제는 실패한다.

## 게스트의 기본 example 폴더

```text
ls /example
cd /example/java
ls
```

부팅하면 `/example/java`, `/example/c`, `/example/python`에 모든 예제 소스와
도우미 파일이 자동으로 준비된다. 이 설명서도 `/example/README.md`에 있다.
설치 명령 없이 `cd`하여 바로 읽기·편집·컴파일·실행할 수 있다.
`example java`, `example c`, `example python`은 지운 예제 파일을 복원하며,
이미 있는 파일은 덮어쓰지 않는다. RAM 파일 총 한도는 **64개**이다.
수정한 자료는 먼저 호스트로 보관한다. RAM 자료는 재부팅하면 사라지며,
다음 부팅에서 원래 예제가 다시 준비된다.

Remmina 입력은 PC 입력기를 영어로 둔 상태에서 **F9**, **Shift+Space** 또는
**한/영 키**로 전환한다. 창 제목의 `[KO]`에서 `gksrmf`를 입력하면 `한글`이
된다. 다시 같은 키를 누르면 `[EN]`으로 돌아간다. `help ko`로 안내를 본다.

## Java

```text
cd /example/java
javac 출력예제.java
java 출력예제
javac 파일예제.java
java 파일예제
cat java.txt
java 네트워크예제 9000 9001
java 그래픽예제
java 창예제
```

출력/파일 예제는 게스트 `javac`로 컴파일한다. 네트워크/그래픽/창 소스는 현재
게스트 컴파일러의 문법·API 범위를 넘으므로 빌드 시 호스트 `javac --release 8`로
만든 `.class`도 함께 제공한다. **실행은 모두 자체 커널 EL0의 JVM에서 한다.**
이 예제들을 실행하기 위해 호스트 JVM에 원격 실행을 요청하지 않는다.

| 파일 | 한국어 호출과 확인 내용 |
|---|---|
| [출력예제.java](java/출력예제.java) | `출력.줄쓰기`, `수쓰기`; 한글·이모지·정수 출력 |
| [파일예제.java](java/파일예제.java) | `파일.쓰기`, `읽기`; UTF-8 파일 재읽기 |
| [네트워크예제.java](java/네트워크예제.java) | `연결통로`, `입력흐름.읽기`, `출력흐름.쓰기`, `전문통로.보내기/받기`; TCP 및 UDP 응답 검사 |
| [그래픽예제.java](java/그래픽예제.java) | `화면.사각형`; 프레임버퍼 그리기 |
| [창예제.java](java/창예제.java) | `창`, `글표지`, `입력칸`, `단추`; 한글 입력·버튼·안내 글 갱신·X 닫기 |

`java 창예제`는 이름 입력칸과 **인사하기** 단추가 있는 자체 한국어 창을 연다.
입력칸의 `누리`를 지우고 이름을 입력한 뒤 버튼을 누르면 인사말과 횟수가
갱신된다. 오른쪽 위 **X**로 닫으면 셸로 돌아온다. `F9`/`Shift+Space`로
한글 입력을 전환한다. 한국어 GUI 객체를 자체 JVM이 직접 생성하고 실행한다.
현재 게스트 `javac`는 이 GUI 소스의 객체·인터페이스 문법을 지원하지 않아,
빌드 시 컴파일한 `창예제.class`를 소스와 함께 탑재한다.
`실행할일.실행하기`, `동작받이.동작받기(동작알림)`,
`화면일정.나중에실행`과 `시작()`을 사용한다. 표준 Swing 객체를 감싸지 않는다.
다섯 Java 예제 모두 예약어·리터럴 외 식별자가 한국어다. 이 진입점과
직접 GUI API는 자체 JVM 전용이며 호스트 javac로 컴파일한다.
표준 `main(String[])` 실행도 계속 지원한다.

터미널의 **네 모서리 안쪽 8픽셀**에 마우스를 대면 대각선 크기 조절 포인터가
나타난다. **왼쪽 버튼을 누른 채 끌고 놓으면** 크기가 바뀐다. 제목 표시줄을
끌면 이동하고 X는 닫기다. `terminal size`로 현재 열·행 수를 확인한다.
이동·크기 변경은 이전 자리와 새 창 영역만 합성한다. 완성한 그림에서
달라진 화소만 표시하므로 전체 배경을 먼저 지우는 깜빡임을 줄인다.

한국어 예외는 `입출력예외`, `대기시간초과예외`, `파일없음예외` 등으로 선언하고
`오류.설명()`으로 읽는다. 자세한 목록은
[한국어 Java API](../platforms/rpi4-native/한국어자바/안내.md)에 있다.

## C

```text
cd /example/c
cc 출력예제.c -o 실행
./실행
cc 파일예제.c -o 실행
./실행
cat c.txt
cc 네트워크예제.c -o 실행
./실행 9001
cc 그래픽예제.c -o 실행
./실행
```

모두 **게스트 TinyCC가 ARM64 ELF를 생성**한다. `실행`이라는 출력 파일을
재사용해 RAM 파일 슬롯을 절약한다. 확장자는 필요 없다.

| 파일 | 한국어 호출과 확인 내용 |
|---|---|
| [출력예제.c](c/출력예제.c) | 공용 `출력` → `파일자료쓰기` |
| [파일예제.c](c/파일예제.c) | `파일열기/파일자료쓰기/파일위치옮기기/파일자료읽기/파일닫기` |
| [네트워크예제.c](c/네트워크예제.c) | `통신종단점만들기`, `자료전문보내기/받기`; 외부 UDP |
| [그래픽예제.c](c/그래픽예제.c) | 게스트 SDK의 `화면규약.h`, `네모그리기` |

`예제규약.h`는 예제의 한국어 출력 도우미이며, `파일규약.h`/`통신규약.h`는
실제 posix-kor 연결이다. `화면규약.h`의 네모그리기·밀리초는 게스트 시작
라이브러리에서 실제 화면/시계 시스템 호출에 연결한다. 일반 libc나 Linux ABI가 아니다.

C의 한국어 통신 상수는 `enum`, `struct 인터넷통신주소`와 `struct 통신주소`는
독립된 구조체다. `통신종단점만들기` 등은 매크로가 아닌 실제 C 함수다.
`주소.주소갈래`, `주소.접속번호`, `주소.인터넷주소.주소값`으로 설정하며,
`인터넷주소갈래`, `전문통신`, `전문전송규약`을 사용한다.

## Python

```text
cd /example/python
python 출력예제.py
python 파일예제.py
cat python.txt
python 네트워크예제.py 9001
python 그래픽예제.py
```

`출력(값, 사이=" ", 끝="\n")`처럼 출력의 키워드 인수도 한국어로 쓸 수 있다.
실행기는 자체 커널의 **MicroPython**이다. [한국어.py](python/한국어.py)는
`jkoros` 내장 모듈의 출력·파일·UDP·그래픽 함수를 한국어 이름으로 연결한다.

| 파일 | 한국어 호출과 확인 내용 |
|---|---|
| [출력예제.py](python/출력예제.py) | `출력`; 한글·이모지·정수 |
| [파일예제.py](python/파일예제.py) | `파일쓰기/파일읽기`; `글부호화/글해독` 변환과 동일성 검사 |
| [네트워크예제.py](python/네트워크예제.py) | `바깥전문보내기/전문받기`; 숫자 IPv4 UDP와 시간 제한 |
| [그래픽예제.py](python/그래픽예제.py) | `네모그리기`; 프레임버퍼 |

Python의 기존 `전문보내기`는 루프백용이고, 새 `바깥전문보내기(종단, 주소,
창구, 바이트자료)`가 외부 주소를 받는다. UDP 전문은 512바이트 이하이다.

한국어 통신·파일 함수의 오류는 `except 운영체제오류 as 오류:`로 잡고,
`오류.번호`와 `오류.설명`으로 읽는다. 자료를 기다리는 오류는 `다시시도오류`다.
영어 `OSError`와 `args`는 내부 연결부에서 변환하므로 예제에 쓸 필요가 없다.
일반 Python 연산이나 외부 라이브러리가 던지는 예외까지 자동 번역하지는 않는다.

호스트에서 `python3 도구/실행.py --desktop --network --pip`로 시작했다면
게스트에서 다음과 같이 외부 소스 꾸러미를 설치한다.

```text
pip install micropython-bisect==3.3.3
python -c 'from bisect import insort as 순서대로넣기; 값=[1,5]; 순서대로넣기(값,3); print(값)'
pip list
```

설치 위치는 `/lib`이며 재부팅하면 사라진다. CPython pip 전체가 아니며,
작은 MicroPython 호환 소스를 지원한다. 자동 의존성 해결·C 확장은 미지원이다.
자세한 지원 범위와 중계 역할은 [Python 꾸러미 안내](../platforms/rpi4-native/파이썬꾸러미.md)를 본다.

## 그래픽과 검증

세 그래픽 예제는 640×480 화면 오른쪽에 빨강·초록·파랑 사각형을 그린다.
그림을 확인한 뒤 **Enter**를 누르면 셸로 돌아온다. Java의 `화면.기다리기`,
C/Python의 `그림기다리기`는 대화형 입력을 기다리는 동안 실행 기한을 갱신하며
FTP도 계속 처리한다. 창을 움직여 바탕을 다시 그리면 사각형은 지워질 수 있다. 이는 프레임버퍼
예제이며 전체 Swing 창 관리 기능을 구현했다는 뜻은 아니다.

```sh
cd /home/user/jkoros/platforms/rpi4-native
make test-examples
```

검증은 언어마다 새 `--desktop --network` VM을 켜서 VNC 키로 명령을 입력하고,
동시에 FTP 업로드/다운로드를 수행한다. 예제 13개 실행, 파일의 실제 바이트,
독립된 호스트 TCP/UDP 응답기가 받은 전문, 화면의 세 색상 픽셀, 설치 시 기존
파일 보존을 확인한다. 결과와 화면은 `platforms/rpi4-native/build/verification/examples/`에 있다.

실제 Pi 4의 GENET LAN/USB 입력 드라이버와 실물 부팅은 아직 검증하지 않았다.
전체 OpenJDK·CPython·일반 Linux 바이너리 호환성은 별도 지원 범위다.
