# Java 소스 전환과 명명

Python으로 구현했던 ARM64 C 생성 및 x86 ELF32 미리 번역 후단을
`compiler/자바도구/기계어미리번역.java`로 전환했다. 클래스 파일 해석,
명령 변환, 배열·문자열, 초기화, native 허용 목록과 ELF 연결을 Java에서 수행한다.
`sh compiler/미리번역.sh`로 실행한다. Python 진입점은 기존 호출과
OpenJDK 빌드 경로를 유지하기 위한 호환 도구다.

화면의 클리핑, 띠 합성, 바뀐 화소 검사와 포인터 밑그림은
`platforms/rpi4-native/원문/화면합성.java`에서 직접 구현한다.
C의 화면 연결부는 실제 프레임버퍼 메모리 접근 및 기존 호출 규약을 연결한다.
고정 힙은 파일·셸·창 세션·통신·화면 배열을 함께 수용하도록 1,048,576낱말로 설정한다.

| 영역 | 현재 구현 |
|---|---|
| 자체 관리 커널·파일 정책·셸·부분집합 JVM/컴파일러·GUI API | 기존 Java 구현 유지 |
| ARM64/x86 미리 번역, 화면 합성 | Java로 전환 |
| worldos 국가판 의존성 확인·복원·실행 제어 | Java로 전환 |
| 호스트 빌드·다운로드·배포·시험 | Python/셸 유지 |
| CPU/MMU/장치, 터미널·글자·창 요소, TCP/FTP 연결 | C/어셈블리 유지 |
| MicroPython·TinyCC·lwIP·BearSSL 등 외부 소스 | 원래 구현 언어 및 공개 규약 유지 |

Java 전환은 진행된 영역의 실제 구현을 바꾼다. C나 Python 호출을 Java
함수 뒤에 숨긴 것만으로 전환 완료로 세지 않는다. 전체 프로젝트가 Java만으로
구현됐다는 의미는 아니다. 외부 라이브러리, 직접 메모리 접근, ABI와 부팅 코드는
별도 경계이며, 남은 호스트 도구 및 자체 C 로직의 전환도 별도 작업으로 기록한다.

자체 함수·변수·형식 이름은 한국어로 작성한다. Java 예약어뿐 아니라
JDK의 공개 형식·메서드, main/equals/hashCode/compareTo, JNI/기계 ABI,
명령행 옵션과 파일 형식의 고정 키는 계약에 맞춰 유지한다.
복합어는 현재 기능에 근거해 만든 프로젝트 이름이다.
사전에서 확인한 낱말의 의미와 실제 역사적 어원을 구분한다.
[명명 원칙과 근거](platforms/rpi4-native/명명/안내.md)를 참고한다.

worldos의 249개 국가 대표판 및 기존 1,578개 언어판(777개 언어)에
jkoros의 자체 ARM64/x86, POSIX, 관리형 Java 소스·라이브러리와 Linux 실행판
도구를 독립 일반 파일로 포함한다. 언어판의 native-source는 자체 소스 복사본이며,
의존성 압축파일은 부모 국가의 일반 파일을 사용한다. 외부로 옮길 때는 국가 폴더
전체를 옮긴다. 아키텍처가 다른 커널과 Linux판의 기능을 하나의 실행 이미지에
합쳤다는 의미는 아니다.

검증되지 않은 번역은 각 판의 native-pending.tsv, 이름 대응은
native-names.tsv, 사전 근거는 native-term-evidence.json에 남긴다.
777개 언어 모두의 원어민 검토나 역사 어원 검토가 완료됐다고 표시하지 않는다.
